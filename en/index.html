07 / FAQ

FAQ

Can I get an invoice from AnyAIGC?

Yes. You can issue invoices yourself in the console, for the amount you actually topped up.

Do new accounts get free trial credit?

Yes. New accounts get 2M free tokens, so you can try models and the integration at small scale.

Can unused balance be refunded?

Yes. Unused balance is refundable, with no fee.

Do you use substitute models? Is my data safe?

We use official model channels, with no low-spec or reverse-engineered substitutes. Except where required by law, we do not store inputs or outputs persistently or use them for training. See the Privacy Policy.

Which payment methods are supported?

You can top up with WeChat Pay, Alipay, USDT or a credit card. Your balance is in USD and works across every model on the platform. Invoices can be issued in the console for the amount you topped up.

How do I connect an existing project?

Most projects using the OpenAI SDK only need the Base URL changed to https://anyaigc.ai/v1, plus an API key and model ID from the console. Authentication uses Authorization: Bearer <API Key>. Model IDs, prices and availability follow the live console and the models page.

Which developer tools are supported?

Claude Code, Codex, OpenClaw, Hermes, Cursor, Dify, Cherry Studio, Chatbox, OpenWebUI and n8n. Setup guides are in the API docs.
