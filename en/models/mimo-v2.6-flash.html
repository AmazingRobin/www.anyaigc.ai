Python streaming
# pip install openai
import os
from openai import OpenAI

client = OpenAI(api_key=os.environ["ANYAIGC_API_KEY"], base_url="https://anyaigc.ai/v1")

stream = client.chat.completions.create(
    model="mimo-v2.6-flash",
    messages=[{"role": "user", "content": "Introduce yourself in three sentences and say what tasks you are best at."}],
    stream=True,
)
for chunk in stream:
    if chunk.choices and chunk.choices[0].delta.content:
        print(chunk.choices[0].delta.content, end="", flush=True)
print()

FAQ

MiMo-V2.6-Flash API FAQ

How much does the MiMo-V2.6-Flash API cost? Is it really ~60% off?

Billed per token in USD per 1M tokens: Input $0.0563 (official $0.14); Output $0.1126 (official $0.28); Cache hit $0.0011 (official $0.0028). Input and output are about 40% of Xiaomi MiMo's official pay-as-you-go USD price, roughly 60% off. See the catalog for current rates.

What inputs are supported, and how long is the context?

Official specs: text, image, video and audio input with text output, a 1M-token context and up to 128K output tokens. The AnyAIGC docs currently show text and image_url examples; follow the API docs for audio and video input.

Which API endpoint should I use?

Use the OpenAI-compatible POST https://anyaigc.ai/v1/chat/completions with Authorization: Bearer <API Key> and model set to mimo-v2.6-flash. Existing OpenAI SDK projects only need base_url set to https://anyaigc.ai/v1.

MiMo-V2.6-Flash or MiMo-V2.6-Pro: which should I use?

V2.6-Pro targets long-horizon agent, coding and research work; V2.6-Flash targets high-volume, at-scale office workloads at about a third of Pro's price. Both are about 40% of the official price, so test each on your own tasks.

Are there concurrency or RPM limits?

AnyAIGC offers MiMo with unlimited concurrency and no fixed RPM cap, for every account by default. Long-context and deep-thinking requests take longer, so set sensible timeouts and retries.

Can I use the output commercially?

Use of the models and their output is governed by Xiaomi MiMo's official terms. AnyAIGC is an independent API provider and is not affiliated with Xiaomi.

Can AnyAIGC issue invoices, including VAT special invoices?

Yes. AnyAIGC issues invoices for actual top-ups, including Chinese VAT general and VAT special invoices. Contact enterprise support to arrange them.

Can my company pay by bank transfer and sign a contract?

Yes. Companies can top up by corporate bank transfer, sign a service agreement, and work with dedicated support and a technical contact.

Which payment methods are supported?

You can top up with WeChat Pay, Alipay, USDT or a credit card. Companies can also pay by bank transfer and get VAT general or special invoices. Your balance is in USD and works across every model on the platform.

Is there free trial credit for new users?

Yes. New accounts get 2 million tokens of trial credit, so you can test before deciding to top up. Top-ups start at $1.

Can I get a refund on my balance?

Yes. Unused balance can be refunded with no fee. Contact support to start a refund.

Are these the real models? Is my data safe?

Requests go to official model channels, never cheaper or reverse-engineered substitutes. Unless the law requires it, we do not persistently store your prompts or outputs or use them for training, and the console shows tokens and cost for every request.
