About

A trillion-scale open-weight model for long tasks

Moonshot AI says Kimi K3 is the first open-source model to reach 2.8 trillion parameters. It is built on Kimi Delta Attention (KDA) hybrid linear attention and Attention Residuals, two architecture changes meant to keep information flowing across longer sequences and deeper networks.

Under the Stable LatentMoE framework, K3 activates 16 of 896 experts per token. Moonshot says that together with improved training methods and data recipes, K3 reaches about 2.5x the overall scaling efficiency of K2. It has native vision, a 1,048,576-token context window, and thinking is always on.

On AnyAIGC, kimi-k3 runs on the OpenAI-compatible /v1/chat/completions endpoint and works directly in Claude Code. You do not need a Moonshot platform account, there are no top-up tiers, and concurrency is unlimited.

Quickstart

Connect to the Kimi K3 API in three steps

  1. Sign up and add credit: create an account at anyaigc.ai. Top up from $1; your balance works across every model on the platform.
  2. Create an API key: create a key in the console, copy the value that starts with sk-, and store it in the ANYAIGC_API_KEY environment variable.
  3. Send a request: call POST https://anyaigc.ai/v1/chat/completions with model set to kimi-k3 and an Authorization: Bearer header. With the OpenAI SDK, just set base_url to https://anyaigc.ai/v1.

Tip: K3 always thinks, and the reasoning comes back in reasoning_content. Moonshot recommends temperature=1.0 and top_p=0.95. In multi-turn chats and tool calls, send the full assistant message from the API (including reasoning_content and tool_calls) back in the next request unchanged, not just the content.

See the Chat Completions reference for every parameter. Replace the model name in the docs examples with the Kimi model ID you want.

Claude Code

Use Kimi K3 in Claude Code

Switch Claude Code to Kimi K3. The 1M context suits long coding sessions in large repos.

  1. Install Claude Code: use the official installer (for example npm install -g @anthropic-ai/claude-code).
  2. Add the config: edit ~/.claude/settings.json, add the env block below, and replace ANTHROPIC_AUTH_TOKEN with the key you created on AnyAIGC.
  3. Start coding: run claude in your project folder. Type /model to confirm the current model is kimi-k3.

Save on side tasks: set ANTHROPIC_DEFAULT_HAIKU_MODEL to kimi-k2.7-code so Claude Code's lightweight subtasks use the cheaper model while the main task stays on K3.

For the full walkthrough and common errors, see the Claude Code setup guide. Swap the model name in the guide for kimi-k3.

FAQ

Kimi K3 API FAQ

How much does the Kimi K3 API cost?

On AnyAIGC, kimi-k3 is billed per token: input $1.2150 per 1M tokens, output $6.0750 per 1M tokens, cache hit $0.1215 per 1M tokens. Moonshot's official USD prices are input $3.00, output $15.00 and cache hit $0.30, so AnyAIGC is about 40% of official. Output includes thinking tokens. See the model catalog for live pricing.

What is the Kimi K3 model ID, and how large is the context?

The model ID is kimi-k3. Moonshot lists a 1,048,576-token (1M) context window. max_completion_tokens defaults to 131,072 and can be set as high as 1,048,576.

What sets Kimi K3 apart?

Moonshot says Kimi K3 is the first open-source model to reach 2.8 trillion parameters. It is built on Kimi Delta Attention (KDA) hybrid linear attention and Attention Residuals, and its MoE activates 16 of 896 experts per token, with native vision. Moonshot reports about 2.5x the overall scaling efficiency of K2, aimed at long-horizon coding, knowledge work and reasoning.

How do I adjust Kimi K3's thinking depth?

K3 always thinks and thinking cannot be turned off. Use the top-level reasoning_effort field in the request body to set depth: low, high or max (default max). Use low on simple tasks to cut output tokens.

Does Kimi K3 support tool calls and image input?

Yes. K3 supports function calling (tools / tool_choice), structured output (json_schema), streaming and image input. In multi-turn chats and tool calls, send the full assistant message (including reasoning_content and tool_calls) back in the next request unchanged.

Can I use Kimi K3 in Claude Code?

Yes. In the env block of ~/.claude/settings.json, set ANTHROPIC_BASE_URL to https://anyaigc.ai, ANTHROPIC_AUTH_TOKEN to your API key, and ANTHROPIC_MODEL to kimi-k3. Then run claude.

Kimi K3 or K2.7 Code: which should I use?

K3 is the 2.8T-parameter flagship with 1M context, suited to large repos, long-running tasks and the hardest reasoning. K2.7 Code is a 1T-parameter coding model with 256K context at $0.3847 input and $1.5980 output on AnyAIGC, about a third of K3. Many teams use K2.7 Code day to day and switch to K3 for hard problems, with the same key.

Are there concurrency or rate limits?

AnyAIGC does not cap concurrency for kimi-k3, and every user gets this by default. That suits batch jobs, CI pipelines and parallel agents. Moonshot's own platform limits concurrency, RPM, TPM and TPD by top-up tier; those tiers do not apply when you call through AnyAIGC.
