Integrate Grok 4.6 API

Start with a minimal request, then connect it to your application.

  1. 01Sign up and create an API key in the console.
  2. 02Set the ANYAIGC_API_KEY environment variable.
  3. 03Send a request with grok-4.6 and inspect usage in the console.
POST /v1/chat/completions ↗POST /v1/messages ↗

The cURL examples use Bash / WSL. Python uses the standard library without an SDK. Requests return complete JSON; Python reads choices[0].message.content.

cURL
curl https://anyaigc.ai/v1/chat/completions \
  -H "Authorization: Bearer $ANYAIGC_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
  "model": "grok-4.6",
  "messages": [
    {
      "role": "user",
      "content": "Break a task app into a data layer, API, and frontend. Give a step-by-step implementation plan."
    }
  ],
  "stream": false
}'
Python · standard library
import json
import os
import urllib.request

payload = {'model': 'grok-4.6', 'messages': [{'role': 'user', 'content': 'Break a task app into a data layer, API, and frontend. Give a step-by-step implementation plan.'}], 'stream': False}
request = urllib.request.Request(
    "https://anyaigc.ai/v1/chat/completions",
    data=json.dumps(payload).encode("utf-8"),
    headers={
        "Authorization": f"Bearer {os.environ['ANYAIGC_API_KEY']}",
        "Content-Type": "application/json",
    },
    method="POST",
)
with urllib.request.urlopen(request, timeout=180) as response:
    result = json.load(response)
print(result["choices"][0]["message"]["content"])
Messages · cURL

07 / FAQ

Grok 4.6 API FAQ

What model ID should I use for Grok 4.6?

Use grok-4.6 exactly as written. See the Grok 4.x overview for other models in the series.

How is the Grok API priced?

Input costs $0.1985 and output costs $0.5956 per million tokens. For Grok 4.6 requests with over 200,000 and up to 500,000 input tokens, input is $0.3971 and output is $1.191 per million tokens. These are the lowest displayed catalog rates; check the model catalog for current pricing.

Which API endpoints are supported?

Supports POST /v1/chat/completions and POST /v1/messages.

Are there concurrency or RPM limits?

All models listed here have unlimited concurrency by default for every user, with no separate activation. Manage connections, timeouts, and retries in your application.

Does the API automatically include live X data?

Ordinary chat does not automatically include live events. xAI requires search tools for live data; the basic examples here do not use search or promise support for every upstream search tool. Commercial use is governed by xAI terms.

Can AnyAIGC issue invoices, including VAT special invoices?

Yes. AnyAIGC issues Chinese VAT general and VAT special invoices based on the actual top-up amount.

Can my company pay by bank transfer and sign a contract?

Yes. Companies can top up by corporate bank transfer, sign a service contract, and work with dedicated support and technical contacts.

Which payment methods are supported?

You can top up with WeChat Pay, Alipay, USDT or a credit card. Companies can also pay by bank transfer and get VAT general or special invoices. Your balance is in USD and works across every model on the platform.

Is there free trial credit for new users?

Yes. New accounts get 2 million tokens of trial credit, so you can test before deciding to top up. Top-ups start at $1.

Can I get a refund on my balance?

Yes. Unused balance can be refunded with no fee. Contact support to start a refund.

Are these the real models? Is my data safe?

Requests go to official model channels, never cheaper or reverse-engineered substitutes. Unless the law requires it, we do not persistently store your prompts or outputs or use them for training, and the console shows tokens and cost for every request.
