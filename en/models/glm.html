Quickstart

Connect to the GLM API in three steps

  1. Sign up and add credit: create an account at anyaigc.ai. Top up from $1; your balance works across every model on the platform.
  2. Create an API key: create a key in the console, copy the value that starts with sk-, and store it in the ANYAIGC_API_KEY environment variable.
  3. Send a request: call POST https://anyaigc.ai/v1/chat/completions with model set to glm-5.3 and an Authorization: Bearer header. With the OpenAI SDK, just set base_url to https://anyaigc.ai/v1.

Tip: GLM returns its reasoning in the reasoning_content field. When streaming, reasoning deltas arrive first, then the final answer. Set thinking depth with reasoning_effort (low / high / max, default max). In multi-turn chats and tool calls, send the full assistant message from the API (including reasoning_content and tool_calls) back in the next request unchanged.

See the Chat Completions reference for every parameter. Replace the model name in the docs examples with the GLM model ID you want.

Claude Code

Use GLM in Claude Code

Switch Claude Code to GLM by editing one config file, and the coding agent in your terminal runs on GLM-5.3, billed per token.

  1. Install Claude Code: use the official installer, for example curl -fsSL https://claude.ai/install.sh | bash on macOS or Linux.
  2. Add the config: edit ~/.claude/settings.json, add the env block below, and replace ANTHROPIC_AUTH_TOKEN with the key you created on AnyAIGC.
  3. Start coding: run claude in your project folder. Type /model to confirm the current model is glm-5.3.

Save on light tasks: the config sets ANTHROPIC_DEFAULT_HAIKU_MODEL to glm-5.3-flash, so Claude Code's lightweight subtasks use the cheaper model while the main work stays on GLM-5.3.

For the full walkthrough and common errors, see the Claude Code setup guide. Swap the model name in the guide for glm-5.3.

FAQ

GLM API FAQ

How much does the GLM API cost?

GLM models on AnyAIGC are billed per token. Per 1M tokens: glm-5.3 input $0.9450, output $2.9700, cache hit $0.1758; glm-5.3-flash input $0.0607, output $0.2025, cache hit $0.0122; glm-5.2 input $0.9450, output $2.9700, cache hit $0.2362. GLM-5.3 and GLM-5.2 are about 30% off Zhipu's official USD prices, and GLM-5.3-Flash is about 60% off. See the model catalog for live pricing.

Which GLM models are on AnyAIGC, and what are the model IDs?

This page covers three: glm-5.3 (Zhipu's latest flagship, for complex coding and agents), glm-5.3-flash (the first natively multimodal GLM-5 model, at a low price) and glm-5.2 (the previous flagship, built for long-horizon tasks). Put the model ID in the model field of the request body. Switching models only means changing that one field. Older models such as GLM-5.1, GLM-5 and GLM-4.5 are also on the platform; see the model catalog.

GLM-5.3, GLM-5.3-Flash or GLM-5.2: which should I use?

Pick GLM-5.3 for the hardest coding, terminal and agent work. Pick GLM-5.3-Flash for high-volume, budget-sensitive or image tasks; it costs about 1/15 of GLM-5.3, and Zhipu says it beats GLM-5.2 overall. Stay on GLM-5.2 if you need to turn thinking off or already run it in production. GLM-5.3 and GLM-5.2 cost the same, so new projects should start with GLM-5.3.

Is the GLM API OpenAI compatible?

Yes. All three models use POST https://anyaigc.ai/v1/chat/completions with the same request and response format as OpenAI Chat Completions. With the official OpenAI SDK, set base_url to https://anyaigc.ai/v1. The reasoning trace, if any, comes back in the reasoning_content field.

Can I use GLM in Claude Code?

Yes. In the env block of ~/.claude/settings.json, set ANTHROPIC_BASE_URL to https://anyaigc.ai, ANTHROPIC_AUTH_TOKEN to your API key, and ANTHROPIC_MODEL to glm-5.3. Then run claude. You pay per token, with no 5-hour quota window like a subscription plan.

How large is the context window?

According to Zhipu, GLM-5.3, GLM-5.3-Flash and GLM-5.2 all support a 1M-token context and up to 128K output tokens. GLM-5.3 and GLM-5.2 accept text only; GLM-5.3-Flash also accepts images.

How is this different from the GLM Coding Plan?

The GLM Coding Plan is Zhipu's monthly coding subscription, with quotas that reset on 5-hour and weekly windows. AnyAIGC is a pay-per-token API: you pay for what you use, top up from $1, with no time windows and unlimited concurrency, and the same key calls 300+ other models.

Are GLM models open source? Can I use them commercially?

Zhipu has published the weights for GLM-5.3, GLM-5.3-Flash and GLM-5.2 on Hugging Face. GLM-5.2 and GLM-5.3-Flash use the MIT license; GLM-5.3 uses the GLM-5.3 License, a permissive license with an extra security review clause for very large MaaS companies. Calling the API through AnyAIGC means you do not have to host them yourself. Model licenses and commercial use are governed by Zhipu AI's official terms.

Are there concurrency or rate limits?

AnyAIGC does not cap concurrency for GLM models, and every user gets this by default. That suits batch jobs, CI pipelines and parallel agents. Billing is per token, so there is no quota that resets on a time window like a subscription plan.

Yes. AnyAIGC is optimized for access from mainland China, so you can usually call https://anyaigc.ai without a proxy. Usage is billed in USD, and you can pay with WeChat Pay, Alipay, USDT or a credit card. Companies can pay by bank transfer and get VAT invoices.
