What is Grok Imagine Image

Grok Imagine Image (grok-imagine-image) is the image model xAI launched with the Grok Imagine API in early 2026. xAI’s docs call it 1.0, with the snapshot name grok-imagine-image-2026-03-02. It turns a text description into an image, with multiple aspect ratios and 1k / 2k output.

In August 2026 xAI released Image 2.0, which is stronger at typography and editing for a slightly higher price on AnyAIGC (from $0.0179 / image versus $0.0119). The first-gen model hasn’t been retired, so existing integrations keep working.

On AnyAIGC it’s $0.0119 per image; xAI’s list price is $0.02 / image. On AnyAIGC this model uses the /v1/images/generations endpoint.

Get started with the Grok Imagine Image API

  1. Sign up for AnyAIGC. New accounts get 2M free tokens, and you can top up from $1.
  2. Create an API key in the console and save it as the ANYAIGC_API_KEY environment variable.
  3. Send a request to POST https://anyaigc.ai/v1/images/generations with model set to grok-imagine-image.

Authenticate with Authorization: Bearer <API Key>. The response looks like {"created": ..., "data": [{"b64_json": ...}], "usage": {"generated_images": 1, ...}}; with response_format set to url you get a temporary link, so download it promptly. Field reference in the AnyAIGC docs: Create image.

Grok Imagine Image API FAQ

How much does the Grok Imagine Image API cost?

On AnyAIGC, Grok Imagine Image (grok-imagine-image) costs $0.0119 per image, the same at 1k and 2k. xAI’s list price is $0.02 / image. Billed per successful generation; live prices are in the model catalog.

Image 2.0, Image or Quality: which one should I use?

Grok Imagine Image 2.0 (grok-imagine-image-2.0) is the model xAI currently recommends, with stronger typography, prompt following and editing. It starts at $0.0179 / image on AnyAIGC, so start new projects here. Grok Imagine Image (grok-imagine-image) is the first-generation Imagine model at $0.0119 / image, the lowest price in the series, fine for plain text to image and existing code. Grok Imagine Image Quality was retired by xAI on Nov 2, 2026, and its requests are now served by 2.0 at low quality.

Will grok-imagine-image be retired?

This change doesn’t affect it. The model xAI retired on Nov 2, 2026 is grok-imagine-image-quality; grok-imagine-image is still available. If you need edits or better text rendering, consider grok-imagine-image-2.0 (from $0.0179 / image).

Which aspect ratios and resolutions are supported?

Set aspect_ratio to values like 1:1, 16:9, 9:16, 3:2, 2:3, 4:3 or 3:4, and resolution to 1k or 2k. The quality parameter is only supported by Image 2.0.

Can it edit images?

On AnyAIGC, grok-imagine-image uses the generation endpoint /v1/images/generations. To upload and modify an image, call /v1/images/edits with grok-imagine-image-2.0.

Do I need an xAI account? Does it work from mainland China?

No xAI account needed. Sign up on AnyAIGC to get an API key, no overseas credit card required. The endpoint is https://anyaigc.ai, reachable directly from mainland China, and the same key works with 300+ other models on the platform.
