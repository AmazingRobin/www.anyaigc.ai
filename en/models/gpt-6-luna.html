$0.0135 per 1M input tokens, so high-volume jobs stay predictable

OpenAI released GPT-6 Luna alongside GPT-6 Sol on September 22, 2026, describing it as "our most efficient model for focused, high-volume tasks." OpenAI calls it the fastest and most cost-effective GPT-6 tier, aimed at scoped tasks, triage and frequent automations. Its list price is $0.10 input, $0.01 cached input and $0.50 output per 1M tokens, down from $0.20 and $1.20 for GPT-5.6 Luna: half the input price and about 58% less for output.

GPT-6 Luna supports six reasoning efforts: none, low, medium (default), high, xhigh and max. Use none or low for latency-sensitive classification and extraction, and raise it for harder questions. It has a 1,050,000-token context window, up to 128,000 output tokens, text and image input with text output, and a knowledge cutoff of May 18, 2026.

On AnyAIGC, gpt-6-luna works on both /v1/chat/completions and /v1/responses. With the official OpenAI SDK you only change base_url to https://anyaigc.ai/v1. There is no concurrency cap, so you can fan out large batches in parallel, and the same key also reaches 300+ other models.

Call the GPT-6 Luna API in three steps

  1. Sign up and top up: create an account at anyaigc.ai. Your balance works across every model.
  2. Create an API key: create a token in the console, copy the sk- key and store it in the ANYAIGC_API_KEY environment variable.
  3. Send a request: call https://anyaigc.ai/v1/chat/completions or https://anyaigc.ai/v1/responses with model set to gpt-6-luna and Authorization: Bearer auth.

Prefer the Responses API for tools. Per OpenAI, gpt-6-luna supports function calling on Chat Completions only when reasoning_effort is set to "none". For function calling at other efforts, or built-in tools such as web search and file search, switch to /v1/responses with the effort in reasoning.effort. Plain chat and streaming work fine on /v1/chat/completions.

See the Chat Completions reference and the Responses reference for every parameter. Fields match the official OpenAI API.

GPT-6 Luna API FAQ

How much does the GPT-6 Luna API cost?

On AnyAIGC, gpt-6-luna is billed per token: $0.0135 per 1M input tokens, $0.0675 per 1M output tokens and $0.0014 per 1M cached input tokens. OpenAI's list price is $0.10 input, $0.50 output and $0.01 cached input, so AnyAIGC is about 13.5% of list (86% off). When a request has more than 272K input tokens, the whole request is billed at 2x input and cache rates and 1.5x output.

GPT-6 Luna vs GPT-5.6 Luna: what changed?

GPT-6 Luna is the next generation after GPT-5.6 Luna. The list price drops from $0.20 input and $1.20 output to $0.10 and $0.50, so input is half price and output is about 58% lower. According to OpenAI, it scores 20.7% on AutomationBench at max effort against 17.0% for GPT-5.6 Luna, and at high effort it gains 5.4 points over the previous generation while cutting cost per task by 58%. Its knowledge cutoff is 2026-05-18. On AnyAIGC, GPT-6 Luna is $0.0135 input and $0.0675 output, and GPT-5.6 Luna is $0.0270 input and $0.1620 output per 1M tokens.

Is GPT-6 Luna the cheapest GPT model?

Among OpenAI's current GPT-6 tiers (Astra, Sol and Luna), Luna has the lowest list price, and OpenAI calls it the fastest and most cost-effective tier. On AnyAIGC its input price is about one seventh of GPT-6.1 Sol's and about one thirty-seventh of GPT-6 Astra's. See the AnyAIGC model catalog for live prices.

GPT-6 Luna or GPT-6.1 Sol: which should I use?

OpenAI positions Luna for scoped tasks, triage and frequent automations, and Sol for complex tasks where you also need to manage time and cost. Use GPT-6 Luna for high-volume work like classification, extraction, summaries and bulk rewriting. Move to GPT-6.1 Sol for multi-file coding, computer use and long agent runs.

Chat Completions or Responses API? Can I use tools?

Both endpoints work. For plain chat and streaming, use https://anyaigc.ai/v1/chat/completions. Per OpenAI, gpt-6-luna supports function calling on Chat Completions only when reasoning_effort is none. For function calling at other efforts, or for built-in tools, use https://anyaigc.ai/v1/responses and set the effort in reasoning.effort.

Can I use GPT-6 Luna in Codex?

Yes. Run curl -fsSL https://www.anyaigc.ai/install.sh | bash -s codex to install and configure it (on Windows, irm https://www.anyaigc.ai/install.ps1 | iex). The installer defaults to gpt-5.5, so change model in ~/.codex/config.toml to gpt-6-luna afterwards. Or edit ~/.codex/config.toml yourself: set base_url to https://anyaigc.ai/v1, wire_api to responses and model to gpt-6-luna, then put OPENAI_API_KEY in ~/.codex/auth.json.
