SPECS

Specs and how to choose it

Alibaba Cloud positions qwen-image-3.0-pro as its flagship-quality model. It supports intelligent prompt rewriting and renders Chinese and English text that blends naturally with physical materials.

It supports both text-to-image and image-to-image/editing, and editing accepts 1 to 3 input images.

Total output pixels must be between 512×512 and 2048×2048, the aspect ratio can range from 1:8 to 8:1, and each request returns 1 to 6 images.

This page lists Billing-unit base rate at $0.00159 / billing, matching the pricing table above.

Compared with wan2.7-image-pro: wan2.7-image-pro reaches 4K for text-to-image and accepts up to 9 input images, while qwen-image-3.0-pro tops out at 2048×2048 with up to 3 input images.

Specs come from the vendor's official documentation (alibabacloud.com). The table on this page is the price, and the model catalog is authoritative for live rates.
