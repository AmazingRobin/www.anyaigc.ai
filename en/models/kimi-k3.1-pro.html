About

The first K3.1 model, with heavier post-training

Moonshot AI says Kimi K3.1 Pro is the first model in the new K3.1 series and its strongest 3T-class open-weight model so far. Moonshot describes it as a post-trained version of Kimi K3, built with much more post-training compute and joint reinforcement learning across hundreds of downstream domains.

Moonshot reports gains in four areas: long-horizon coding (Unity, Unreal Engine and Godot support, plus more complete layout, typography and animation in front-end and Three.js work), 3D creation (Blender and CAD scripts for parametric modeling), financial research (64.4 on OfficeQA Pro v2), and a lower hallucination rate. It has a 1,048,576-token context, thinking is always on, and it accepts text, image and video input.

On AnyAIGC, kimi-k3.1-pro runs on the OpenAI-compatible /v1/chat/completions endpoint with the same parameter constraints as K3, so migrating from K3 only means changing the model name. It also works directly in Claude Code, with unlimited concurrency.

Quickstart

Connect to the Kimi K3.1 Pro API in three steps

  1. Sign up and add credit: create an account at anyaigc.ai. Top up from $1; your balance works across every model on the platform.
  2. Create an API key: create a key in the console, copy the value that starts with sk-, and store it in the ANYAIGC_API_KEY environment variable.
  3. Send a request: call POST https://anyaigc.ai/v1/chat/completions with model set to kimi-k3.1-pro and an Authorization: Bearer header. With the OpenAI SDK, just set base_url to https://anyaigc.ai/v1.

Tip: K3.1 Pro always thinks, and the reasoning comes back in reasoning_content. Sampling parameters such as temperature and top_p are fixed by Moonshot, so do not send them. In multi-turn chats and tool calls, send the full assistant message from the API (including reasoning_content and tool_calls) back in the next request unchanged.

See the Chat Completions reference for every parameter. Replace the model name in the docs examples with the Kimi model ID you want.

Claude Code

Use Kimi K3.1 Pro in Claude Code

Switch Claude Code to Kimi K3.1 Pro: 1M context, and Moonshot ran most of its coding benchmarks with Claude Code as the harness.

  1. Install Claude Code: use the official installer (for example npm install -g @anthropic-ai/claude-code).
  2. Add the config: edit ~/.claude/settings.json, add the env block below, and replace ANTHROPIC_AUTH_TOKEN with the key you created on AnyAIGC.
  3. Start coding: run claude in your project folder. Type /model to confirm the current model is kimi-k3.1-pro.

Save on side tasks: set ANTHROPIC_DEFAULT_HAIKU_MODEL to kimi-k2.7-code so Claude Code's lightweight subtasks use the cheaper model while the main task stays on K3.1 Pro.

For the full walkthrough and common errors, see the Claude Code setup guide. Swap the model name in the guide for kimi-k3.1-pro.

FAQ

Kimi K3.1 Pro API FAQ

How much does the Kimi K3.1 Pro API cost?

On AnyAIGC, kimi-k3.1-pro is billed per token: input $0.8100 per 1M tokens, output $4.0500 per 1M tokens, cache hit $0.0810 per 1M tokens. Moonshot's official USD prices are input $2.00, output $10.00 and cache hit $0.20, so AnyAIGC is about 40% of official. Output includes thinking tokens. See the model catalog for live pricing.

What is the Kimi K3.1 Pro model ID, and how large is the context?

The model ID is kimi-k3.1-pro. Moonshot lists a 1,048,576-token (1M) context window. max_completion_tokens defaults to 131,072 and can be set as high as 1,048,576.

How is Kimi K3.1 Pro different from K3?

Moonshot says K3.1 Pro is Kimi K3 trained with much more post-training compute, using joint reinforcement learning across hundreds of downstream domains. The gains Moonshot reports include long-horizon coding (Kimi Code Bench 3.0 up from 55.95 to 61.2), financial research (internal eval up from 58.8 to 70.4) and factual accuracy (per-claim hallucination rate down from 23.4% to 8.3%). Parameter constraints match K3, so migrating only means changing the model name. On AnyAIGC, K3.1 Pro costs $0.8100 input and $4.0500 output, about a third less than K3.

How do I adjust Kimi K3.1 Pro's thinking depth?

K3.1 Pro always thinks and thinking cannot be turned off. Use the top-level reasoning_effort field in the request body to set depth: low, high or max (default max). Sampling parameters such as temperature and top_p are fixed by Moonshot, so leave them out of the request.

Does Kimi K3.1 Pro support tool calls, image and video input?

Yes. Moonshot's docs list function calling (tools / tool_choice), structured output (json_schema), streaming, and image and video input. In multi-turn chats and tool calls, send the full assistant message (including reasoning_content and tool_calls) back in the next request unchanged.

Can I use Kimi K3.1 Pro in Claude Code?

Yes. In the env block of ~/.claude/settings.json, set ANTHROPIC_BASE_URL to https://anyaigc.ai, ANTHROPIC_AUTH_TOKEN to your API key, and ANTHROPIC_MODEL to kimi-k3.1-pro. Then run claude.

Is Kimi K3.1 Pro open source?

Moonshot calls K3.1 Pro its strongest 3T-class open-weight model so far and says the full weights will be released by November 4, 2026. Calling the API through AnyAIGC means you do not have to host it yourself. Model licenses and commercial use are governed by Moonshot AI's official terms.

Are there concurrency or rate limits?

AnyAIGC does not cap concurrency for kimi-k3.1-pro, and every user gets this by default. That suits batch jobs, CI pipelines and parallel agents. Moonshot's own platform limits concurrency, RPM, TPM and TPD by top-up tier; those tiers do not apply when you call through AnyAIGC.
