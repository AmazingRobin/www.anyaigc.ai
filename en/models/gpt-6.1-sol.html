Near-Astra intelligence for about 5% of the list price

OpenAI released GPT-6.1 Sol on September 29, 2026 as the upgrade to GPT-6 Sol. OpenAI says it comes close to GPT-6 Astra on agentic coding, computer use and professional work, while its standard input and output token prices are one fifth of Astra's. Cached input drops to $0.10 per 1M tokens on OpenAI's list, 50% below GPT-6 Sol.

GPT-6.1 Sol supports five reasoning efforts: low, medium (default), high, xhigh and max. It does not support none or minimal. It has a 1,050,000-token context window, up to 128,000 output tokens, text and image input with text output, and a knowledge cutoff of April 30, 2026.

On AnyAIGC, gpt-6.1-sol works on both /v1/chat/completions and /v1/responses. With the official OpenAI SDK you only change base_url to https://anyaigc.ai/v1, and the same key also reaches 300+ other models.

Call the GPT-6.1 Sol API in three steps

  1. Sign up and top up: create an account at anyaigc.ai. Your balance works across every model.
  2. Create an API key: create a token in the console, copy the sk- key and store it in the ANYAIGC_API_KEY environment variable.
  3. Send a request: call https://anyaigc.ai/v1/chat/completions or https://anyaigc.ai/v1/responses with model set to gpt-6.1-sol and Authorization: Bearer auth.

Use the Responses API for tools. Per OpenAI, gpt-6.1-sol does not support tool calling (function calling) on Chat Completions. Keep using /v1/chat/completions for plain chat and streaming, and switch to /v1/responses for function calling, computer use and other tools, with the effort in reasoning.effort.

See the Chat Completions reference and the Responses reference for every parameter. Fields match the official OpenAI API.

GPT-6.1 Sol API FAQ

How much does the GPT-6.1 Sol API cost?

On AnyAIGC, gpt-6.1-sol is billed per token: $0.0993 per 1M input tokens, $0.4964 per 1M output tokens and $0.0050 per 1M cached input tokens. OpenAI's list price is $2.00 input, $10.00 output and $0.10 cached input, so AnyAIGC is about 5% of list (95% off). When a request has more than 272K input tokens, the whole request is billed at 2x input and cache rates and 1.5x output.

What is the GPT-6.1 Sol model ID?

The model ID is gpt-6.1-sol. Put it in the model field of your request. OpenAI has not published a dated snapshot for it.

GPT-6.1 Sol vs GPT-6 Sol: what changed?

OpenAI describes GPT-6.1 Sol as the upgrade to GPT-6 Sol. The input and output list prices stay at $2 and $10, and cached input drops from $0.20 to $0.10. According to OpenAI, it beats GPT-6 Sol's best DeepSWE v1.1 score by 6.4 points, scores about 7 points higher on OSWorld 2.0, and more than doubles GPT-6 Sol on Terminal-Bench Science. The knowledge cutoff moves from 2026-04-20 to 2026-04-30. GPT-6.1 Sol does not support the none reasoning effort, and it does not support tool calling on Chat Completions.

GPT-6.1 Sol or GPT-6 Astra: which should I use?

OpenAI says GPT-6.1 Sol comes close to GPT-6 Astra on agentic coding, computer use and professional work, at one fifth of Astra's standard input and output price. Start with GPT-6.1 Sol for most coding and agent work, and move to GPT-6 Astra for the hardest reasoning or research tasks, where Astra still leads on benchmarks like Terminal-Bench Science. On AnyAIGC, GPT-6.1 Sol is $0.0993 input and $0.4964 output, and GPT-6 Astra is $0.4964 input and $2.4810 output per 1M tokens.

Chat Completions or Responses API? Can I use tools?

Both endpoints work. For plain chat and streaming, use https://anyaigc.ai/v1/chat/completions. Per OpenAI, gpt-6.1-sol does not support tool calling on Chat Completions, so use https://anyaigc.ai/v1/responses for function calling and built-in tools, and set the reasoning effort in reasoning.effort.

Can I use GPT-6.1 Sol in Codex?

Yes. Run curl -fsSL https://www.anyaigc.ai/install.sh | bash -s codex to install and configure it (on Windows, irm https://www.anyaigc.ai/install.ps1 | iex). The installer defaults to gpt-5.5, so change model in ~/.codex/config.toml to gpt-6.1-sol afterwards. Or edit ~/.codex/config.toml yourself: set base_url to https://anyaigc.ai/v1, wire_api to responses and model to gpt-6.1-sol, then put OPENAI_API_KEY in ~/.codex/auth.json.

Are there concurrency or rate limits?

AnyAIGC sets no concurrency limit on gpt-6.1-sol. Every account gets this by default, so batch jobs and parallel agents run without queuing.
