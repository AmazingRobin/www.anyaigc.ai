Native OpenAI endpoints, fully supported

Requests match the official OpenAI API, so the official SDK and your existing code move over by changing base_url.

  • Chat Completions

    Chat endpoint

    Call /v1/chat/completions with the standard messages format. Existing code and frameworks work as is (except GPT-5.5 Pro).

  • Responses API

    Responses and tool calling

    Call /v1/responses for function calling. Codex uses this endpoint too.

  • Structured Outputs

    Structured outputs

    Constrain the response with a JSON Schema, so you can parse and store results without regex fallbacks.

  • reasoning_effort

    Reasoning effort

    Use reasoning_effort on Chat Completions and reasoning.effort on Responses. GPT-6 goes up to max; GPT-6 Sol and GPT-6 Luna also support none, while GPT-6.1 Sol and GPT-6 Astra do not.

  • Image input

    Image input

    Every model takes text and image input and returns text, so you can send screenshots, charts and scans.

  • Streaming

    Streaming

    Set stream: true to get tokens as they are generated. GPT-5.5 Pro does not support streaming.

Use /v1/responses for tool calling on GPT-6. Per OpenAI, gpt-6.1-sol does not support tool calling on Chat Completions, gpt-6-sol and gpt-6-luna support function calling there only with reasoning_effort set to none, and gpt-6-astra is not documented either way. Plain chat and streaming still work on /v1/chat/completions. gpt-5.5-pro works only on /v1/responses.

Start calling the GPT API in three steps

  1. Sign up and top up: create an account at anyaigc.ai. Your balance works across every model.
  2. Create an API key: create a token in the console, copy the sk- key and store it in the ANYAIGC_API_KEY environment variable.
  3. Send a request: set the OpenAI SDK base_url to https://anyaigc.ai/v1, put any model ID from this page in model, and authenticate with Authorization: Bearer.

See the Chat Completions reference and Responses reference for every parameter. Fields match the official OpenAI API.

GPT API FAQ

How much does the GPT API cost?

Every GPT model on AnyAIGC is billed per token in USD per 1M tokens, with no subscription or monthly fee. The current tiers: GPT-6 Astra $0.4964 input and $2.4810 output; GPT-6.1 Sol $0.0993 input and $0.4964 output; GPT-6 Luna $0.0135 input and $0.0675 output. Most models are about 5% of OpenAI list price (95% off), GPT-6 Luna and GPT-5.6 Luna about 13.5%, and GPT-5.5 Pro about 59%. See the price table for all 9 models, and the AnyAIGC model catalog for real-time prices.

Can I call the OpenAI API from mainland China?

Yes. AnyAIGC is tuned for networks in mainland China, so you can usually call https://anyaigc.ai/v1 without a proxy. Billing is in USD, you can pay with WeChat Pay or Alipay, and companies can pay by bank transfer and get VAT invoices.

How do I get a GPT API key?

Sign up at anyaigc.ai, top up, and create a token in the console to get an sk- key. The same key works for all 9 GPT models on this page and 300+ other models, with one shared balance.

Does it work with the official OpenAI SDK?

Yes. Set base_url to https://anyaigc.ai/v1 and api_key to your AnyAIGC key, and existing code runs with little or no change. Both /v1/chat/completions and /v1/responses are supported, authentication uses Authorization: Bearer, and fields match the official OpenAI API.

GPT-6 Astra vs Sol vs Luna: which should I use?

They are OpenAI's three GPT-6 capability tiers. Per OpenAI, Astra has the highest intelligence, for the most demanding reasoning, coding and professional work. Sol balances speed, cost and intelligence; the current version is GPT-6.1 Sol, which OpenAI says comes close to Astra at one fifth of the list price. Luna is the fastest and most cost-effective, for scoped, frequent tasks. Start with GPT-6.1 Sol for most coding and agent work, move to GPT-6 Astra for the hardest tasks, and use GPT-6 Luna for high-volume simple work.

What is GPT-5.6 Terra?

Terra is the balanced tier of GPT-5.6. OpenAI calls it a balanced model for everyday work with GPT-5.5-level performance at lower cost. GPT-5.6 has Sol, Terra and Luna tiers; GPT-6 so far has only Astra, Sol and Luna, with no GPT-6 Terra announced. On AnyAIGC, gpt-5.6-terra is $0.0993 input and $0.5957 output per 1M tokens.

GPT-6.1 Sol vs GPT-6 Sol: what changed?

OpenAI describes GPT-6.1 Sol as the upgrade to GPT-6 Sol. Input and output list prices stay at $2 and $10, cached input drops from $0.20 to $0.10, and according to OpenAI it scores higher than GPT-6 Sol on benchmarks such as DeepSWE v1.1 and OSWorld 2.0. GPT-6.1 Sol does not support the none reasoning effort and does not support tool calling on Chat Completions. On AnyAIGC both are $0.0993 input and $0.4964 output, with cached input at $0.0050 and $0.0099. Use GPT-6.1 Sol for new projects; existing integrations can stay on gpt-6-sol.

Can I still use older GPT models?

GPT-6 Sol, GPT-5.6 Sol, GPT-5.6 Terra, GPT-5.6 Luna, GPT-5.5 and GPT-5.5 Pro all have newer replacements, but OpenAI has not announced API shutdown dates for them, and they all work on AnyAIGC today. For new projects, use GPT-6.1 Sol, GPT-6 Astra or GPT-6 Luna.

Can I use GPT models in Codex?

Yes. Run curl -fsSL https://www.anyaigc.ai/install.sh | bash -s codex to install and configure it (on Windows, irm https://www.anyaigc.ai/install.ps1 | iex). The installer defaults to gpt-5.5, so change model in ~/.codex/config.toml to gpt-6.1-sol or gpt-6-astra afterwards. Or edit ~/.codex/config.toml yourself: set base_url to https://anyaigc.ai/v1 and wire_api to responses, and put OPENAI_API_KEY in ~/.codex/auth.json.

Are there concurrency limits?

AnyAIGC sets no concurrency limit on any GPT model. Every account gets this by default, so batch jobs and parallel agents run without queuing.

You can top up with WeChat Pay, Alipay, USDT or a credit card. Companies can also pay by bank transfer and get VAT general or special invoices. Your balance is in USD and works across every model on the platform.

Requests go to official model channels, never cheaper or reverse-engineered substitutes. Unless the law requires it, we do not persistently store your prompts or outputs or use them for training, and the console shows tokens and cost for every request.

Is my data used for training?

No. Unless the law requires it, AnyAIGC does not persistently store your prompts or outputs or use them for training, and requests are encrypted in transit over HTTPS. See the AnyAIGC Privacy Policy for details. The model's own data policy is governed by OpenAI's official terms.
