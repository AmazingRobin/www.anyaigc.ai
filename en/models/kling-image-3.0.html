QUICKSTART

Integrate the Kling Image 3.0 API

  1. 1Sign up, create an API key and set ANYAIGC_API_KEY
  2. 2POST /tencent-vod/v1/aigc-image to submit a task and get its TaskId
  3. 3Poll GET /tencent-vod/v1/query/{task_id} and download the image once Status is FINISH

Set model_name to "Kling", model_version to "3.0", and output_config.resolution to upper-case "2K" or "4K". The result is at Response.AigcImageTask.Output.FileInfos[].FileUrl; it is temporary storage with an expiry time, so download it promptly.

Read the API reference ↗ · See task-query documentation ↗

cURL

curl --request POST "https://anyaigc.ai/tencent-vod/v1/aigc-image" \
  --header "Authorization: Bearer $ANYAIGC_API_KEY" \
  --header "Content-Type: application/json" \
  --data '{
  "model_name": "Kling",
  "model_version": "3.0",
  "prompt": "An orange cat on a rain-soaked windowsill, a neon-lit street outside, cinematic lighting, rich detail",
  "output_config": {
    "aspect_ratio": "16:9",
    "resolution": "2K"
  }
}'

# Query the result with the returned Response.TaskId
curl "https://anyaigc.ai/tencent-vod/v1/query/$TASK_ID" \
  --header "Authorization: Bearer $ANYAIGC_API_KEY"

Python

import json
import os
import time
import urllib.request

BASE = "https://anyaigc.ai"
HEADERS = {
    "Authorization": "Bearer " + os.environ["ANYAIGC_API_KEY"],
    "Content-Type": "application/json",
}


def call(method, path, payload=None):
    data = json.dumps(payload, ensure_ascii=False).encode("utf-8") if payload else None
    request = urllib.request.Request(BASE + path, data=data, headers=HEADERS, method=method)
    with urllib.request.urlopen(request, timeout=60) as response:
        return json.load(response)


payload = {
    "model_name": "Kling",
    "model_version": "3.0",
    "prompt": "An orange cat on a rain-soaked windowsill, a neon-lit street outside, cinematic lighting, rich detail",
    "output_config": {
        "aspect_ratio": "16:9",
        "resolution": "2K"
    }
}

task_id = call("POST", "/tencent-vod/v1/aigc-image", payload)["Response"]["TaskId"]
print("task_id:", task_id)

# Poll every 5 seconds; print the image URL once Status is FINISH
for _ in range(60):
    result = call("GET", f"/tencent-vod/v1/query/{task_id}")["Response"]
    if result["Status"] == "FINISH":
        break
    time.sleep(5)
else:
    raise TimeoutError(task_id)

for item in result["AigcImageTask"]["Output"]["FileInfos"]:
    print(item["FileUrl"])

FAQ

Kling Image 3.0 API FAQ

How much does the Kling Image 3.0 API cost?

$0.00169 per call, which returns one image, at 2K or 4K for the same price. Prices are in USD, charged on successful submission; see the model catalog for current rates.

Which endpoint should I call?

Submit with POST /tencent-vod/v1/aigc-image, setting model_name to Kling and model_version to 3.0, and fetch results with GET /tencent-vod/v1/query/{task_id}. The API host is https://anyaigc.ai and the header is Authorization: Bearer <API Key>.

How do I set the resolution?

Set output_config.resolution to upper-case "2K" or "4K". Both cost the same.

Which generation modes are supported?

Text-to-image, image-to-image, multi-image reference, style transfer, character reference and inpainting. Reference images go in file_infos; see the API reference for the exact fields.

How do I get the result?

The API is asynchronous. Submission returns Response.TaskId; poll the query endpoint and, once Status is FINISH, download the image from Response.AigcImageTask.Output.FileInfos[].FileUrl. Files are stored temporarily and expire.

Are there concurrency limits?

Kling models on AnyAIGC have unlimited concurrency by default for every account.

Can I use the images commercially?

Usage rights and content policy follow Kuaishou Kling's official terms. Make sure you have the rights to any reference images you upload.

Can AnyAIGC issue invoices, including VAT special invoices?

Yes. AnyAIGC issues invoices for actual top-ups, including Chinese VAT general and VAT special invoices. Contact enterprise support to arrange them.

Can my company pay by bank transfer and sign a contract?

Yes. Companies can top up by corporate bank transfer, sign a service agreement, and work with a dedicated support and technical contact.

Which payment methods are supported?

You can top up with WeChat Pay, Alipay, USDT or a credit card. Companies can also pay by bank transfer and get VAT general or special invoices. Your balance is in USD and works across every model on the platform.

Is there free trial credit for new users?

Yes. New accounts get 2 million tokens of trial credit, so you can test before deciding to top up. Top-ups start at $1.

Can I get a refund on my balance?

Yes. Unused balance can be refunded with no fee. Contact support to start a refund.

Are these the real models? Is my data safe?

Requests go to official model channels, never cheaper or reverse-engineered substitutes. Unless the law requires it, we do not persistently store your prompts or outputs or use them for training, and the console shows the cost of every request.
