After an 80% price cut, about 13.5% of that again

GPT-5.6 Luna launched on July 9, 2026 as the entry tier of the GPT-5.6 family, below Sol and Terra. OpenAI calls it its "fastest and lowest-priced model" and positions it for cost-sensitive, high-volume workloads, noting that it "can use tools and complete multistep workflows."

On July 30, 2026, OpenAI permanently cut GPT-5.6 Luna API prices by 80%, from $1 input and $6 output to $0.20 and $1.20, with cached input at $0.02. OpenAI says Luna performs on par with frontier models from a year earlier at about 6% of the cost per task.

It supports six reasoning efforts: none, low, medium, high, xhigh and max. It has a 1,050,000-token context window, up to 128,000 output tokens, text and image input with text output, and a knowledge cutoff of February 16, 2026. On AnyAIGC, gpt-5.6-luna works on both /v1/chat/completions and /v1/responses. With the official OpenAI SDK you only change base_url to https://anyaigc.ai/v1.

What GPT-5.6 Luna is good for

  • 01 · Batch

    High-volume classification and extraction

    Ticket routing, content moderation, field extraction and converting text between languages: lots of calls, each fairly simple. OpenAI positions Luna for cost-sensitive, high-volume workloads, and on AnyAIGC 1M input plus 1M output costs about $0.19.

  • 02 · Automation

    Tool calls and multistep flows

    OpenAI says Luna "can use tools and complete multistep workflows." Use it to query databases, call internal APIs and work through rule-based steps. Function calling works on both Chat Completions and Responses.

  • 03 · Professional work

    Document cleanup and first drafts

    A 1,050,000-token context fits a large pile of source material. In OpenAI's Agents' Last Exam results Luna scores 50.3%, against 40.5% for Fable 5. Cached input is $0.0027 per 1M tokens, so reusing the same material costs very little.

  • 04 · Coding

    Light coding and sub-agents

    Code completion, unit test generation, log analysis, or the worker tasks in a multi-agent system. In OpenAI's AA Coding Agent Index results Luna scores 74.6 and Claude Opus 4.8 scores 72.5. Hand complex changes to GPT-5.6 Sol.

Call the GPT-5.6 Luna API in three steps

  1. Sign up and top up: create an account at anyaigc.ai. Your balance works across every model.
  2. Create an API key: create a token in the console, copy the sk- key and store it in the ANYAIGC_API_KEY environment variable.
  3. Send a request: call https://anyaigc.ai/v1/chat/completions or https://anyaigc.ai/v1/responses with model set to gpt-5.6-luna and Authorization: Bearer auth.

Tool calling works on both endpoints. Per OpenAI, gpt-5.6-luna supports Chat Completions, Responses and Batch, with function calling and structured outputs. Use /v1/chat/completions for plain chat and function calling, and /v1/responses for the Responses API's built-in tools or multistep agent workflows, with the effort in reasoning.effort.

See the Chat Completions reference and the Responses reference for every parameter. Fields match the official OpenAI API.

GPT-5.6 Luna API FAQ

How much does the GPT-5.6 Luna API cost?

On AnyAIGC, gpt-5.6-luna is billed per token: $0.0270 per 1M input tokens, $0.1620 per 1M output tokens and $0.0027 per 1M cached input tokens. OpenAI's list price is $0.20 input, $1.20 output and $0.02 cached input, so AnyAIGC is about 13.5% of list (86% off). When a request has more than 272K input tokens, the whole request is billed at 2x input and 1.5x output.

What is the GPT-5.6 Luna model ID?

The model ID is gpt-5.6-luna. Put it in the model field of your request. OpenAI has not published a dated snapshot for it.

How big was the GPT-5.6 Luna price cut?

On July 30, 2026, OpenAI permanently cut GPT-5.6 Luna API prices by 80%: input went from $1 to $0.20, output from $6 to $1.20, and cached input from $0.10 to $0.02 per 1M tokens. AnyAIGC prices are based on the post-cut list price: $0.0270 input, $0.1620 output and $0.0027 cached input.

Is GPT-5.6 Luna deprecated? How long will it be available?

No. OpenAI has released the newer GPT-6 Luna, but GPT-5.6 Luna is still offered in the API. OpenAI has not announced a shutdown date, it is fully callable today, and nothing changes on AnyAIGC. Consider GPT-6 Luna for new projects, and keep using gpt-5.6-luna for batch jobs whose prompts are already tuned for it.

Chat Completions or Responses API? Can I use tools?

Both endpoints work, and both support tool calling. Per OpenAI, gpt-5.6-luna supports Chat Completions, Responses and Batch, with streaming, function calling and structured outputs. Use https://anyaigc.ai/v1/chat/completions for plain chat and function calling, and https://anyaigc.ai/v1/responses for the Responses API's built-in tools or multistep agent workflows, with the effort in reasoning.effort.

Can I use GPT-5.6 Luna in Codex?

Yes. Run curl -fsSL https://www.anyaigc.ai/install.sh | bash -s codex to install and configure it (on Windows, irm https://www.anyaigc.ai/install.ps1 | iex). The installer defaults to gpt-5.5, so change model in ~/.codex/config.toml to gpt-5.6-luna afterwards. Or edit ~/.codex/config.toml yourself: set base_url to https://anyaigc.ai/v1, wire_api to responses and model to gpt-5.6-luna, then put OPENAI_API_KEY in ~/.codex/auth.json.

Are there concurrency or rate limits?

AnyAIGC sets no concurrency limit on gpt-5.6-luna. Every account gets this by default, so large classification, extraction and parallel agent jobs run without queuing.

Can I call the GPT-5.6 Luna API from mainland China?

Yes. AnyAIGC is tuned for networks in mainland China, so you can usually call https://anyaigc.ai/v1 without a proxy. Billing is in USD, you can pay with WeChat Pay or Alipay, and companies can pay by bank transfer and get VAT invoices.
