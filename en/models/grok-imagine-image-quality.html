What happened to grok-imagine-image-quality

Grok Imagine Image Quality was the high-quality generation and editing mode xAI introduced in May 2026, focused on more realistic images and better multilingual text rendering. In August 2026 xAI released Image 2.0 and made it the new Quality mode on grok.com.

xAI announced in September 2026 and completed on Nov 2 the retirement of grok-imagine-image-quality. Generation and edit requests to that model name are now handled by grok-imagine-image-2.0 with quality: "low", and request and response formats are unchanged (xAI migration guide).

The model name still works on AnyAIGC from $0.0223 (1K) to $0.0313 (2K) per image. Image 2.0 at Low quality is $0.0044–$0.0045 cheaper per image at every resolution, so moving to grok-imagine-image-2.0 saves money and adds quality: "medium" and the new 21:9 and 5:2 ratios.

Migrate in three steps

  • Step 1

    Change the model name

    Replace "model": "grok-imagine-image-quality" with "grok-imagine-image-2.0" in your request.

  • Step 2

    Add quality if needed

    Add "quality": "medium" for more detail (it costs more than Low); leave it out to use the default auto.

  • Step 3

    Check the response

    The format is unchanged: data still holds b64_json or url, so your parsing code stays the same.

Grok Imagine Image Quality API FAQ

Has grok-imagine-image-quality been retired?

Yes. xAI retired grok-imagine-image-quality on Nov 2, 2026. Requests are now handled by grok-imagine-image-2.0 with quality: "low", and request and response formats are unchanged. The model name still works on AnyAIGC; for new projects use Grok Imagine Image 2.0.

How much does the Grok Imagine Image Quality API cost?

On AnyAIGC it’s $0.0223 at 1K, $0.0268 at 1.5K and $0.0313 at 2K per image, plus $0.00447 per input image for edits. That’s $0.0044–$0.0045 more than Image 2.0 at Low quality at each resolution. xAI no longer publishes a separate list price for Quality. Billed per successful generation; live prices are in the model catalog.

What code do I need to change to move to 2.0?

Only set model to grok-imagine-image-2.0. The endpoint, request fields and response format stay the same. 2.0 also supports quality (low / medium / auto) and the 21:9 and 5:2 ratios.

What happens if I don’t change anything?

Requests won’t fail. They’re served by 2.0 at low quality, and the model field in the response shows the model that actually handled them. You also keep paying the Quality price, which is higher than 2.0 Low. If you want medium quality, switch to 2.0 and pass quality.

Image 2.0, Image or Quality: which one should I use?

Grok Imagine Image 2.0 (grok-imagine-image-2.0) is the model xAI currently recommends, with stronger typography, prompt following and editing. It starts at $0.0179 / image on AnyAIGC, so start new projects here. Grok Imagine Image (grok-imagine-image) is the first-generation Imagine model at $0.0119 / image, the lowest price in the series, fine for plain text to image and existing code. Grok Imagine Image Quality was retired by xAI on Nov 2, 2026, and its requests are now served by 2.0 at low quality.
