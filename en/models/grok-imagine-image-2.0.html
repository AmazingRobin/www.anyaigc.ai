What is Grok Imagine Image 2.0

Grok Imagine Image 2.0 is the image model xAI released in August 2026. It’s the new Quality mode on grok.com and in the Grok app, and grok-imagine-image-2.0 in the API. xAI pitches it as a model for images you can actually use at work: it follows prompt details closely, plans text and layout like a designer, and keeps what you gave it across generations and edits.

According to xAI’s launch post, it placed second on both Arena’s image edit and text-to-image leaderboards (data as of Aug 7, 2026). Starting November 2026, xAI folded the older grok-imagine-image-quality into this model.

On AnyAIGC it’s priced by resolution and quality, from $0.0179 (1K Low) to $0.0357 (2K Medium) per image, about 55% below xAI’s list price of $0.04–$0.08 / image. Edits add $0.00447 per input image.

Grok Imagine Image 2.0 API FAQ

How much does the Grok Imagine Image 2.0 API cost?

On AnyAIGC, Grok Imagine Image 2.0 (grok-imagine-image-2.0) is priced by resolution and quality. Low is $0.0179 / $0.0223 / $0.0268 and Medium is $0.0268 / $0.0313 / $0.0357 per image at 1K / 1.5K / 2K. Edits add $0.00447 per input image. xAI’s list price is $0.04–$0.08 / image plus $0.01 per input image, so AnyAIGC is about 55% below it. Billed per successful generation; live prices are in the model catalog.

How is Image 2.0 different from the earlier Grok Imagine?

2.0 improves typography, prompt following and editing. Small text in infographics and posters is sharper, and multi-turn edits keep the original content. It also adds quality (low / medium / auto) and two new ratios, 21:9 and 5:2. The first-gen grok-imagine-image is still available at $0.0119 / image.

How should I set the quality parameter?

quality accepts low, medium or auto. Per xAI’s docs, the default auto currently uses low for generation and medium for edits. Low is faster, medium adds detail. Medium costs more on AnyAIGC: at 1K, Low is ${T20("1K", "Low")} and Medium is ${T20("1K", "Medium")} per image.

Which aspect ratios and resolutions are supported?

aspect_ratio supports 1:1, 3:4, 4:3, 9:16, 16:9, 2:3, 3:2, 9:19.5, 19.5:9, 9:20, 20:9, 1:2, 2:1, 21:9 and 5:2, or auto. Set resolution to 1k, 1.5k or 2k.

How do I edit an image? Can I use several references?

Send image, prompt and model to POST /v1/images/edits as multipart/form-data. Describe only what should change and the rest stays as is. xAI supports compositing up to 5 reference images per request; the AnyAIGC docs currently show a single-image example, so check the AnyAIGC API docs for multi-image input.

Does grok-imagine-image-quality still work?

xAI merged grok-imagine-image-quality into 2.0 on Nov 2, 2026, so those requests are served by 2.0 at low quality. Old code still runs on AnyAIGC (from $0.0223 / image), but 2.0 at Low quality is $0.0044–$0.0045 cheaper per image at every resolution, so switching model to grok-imagine-image-2.0 saves money.
