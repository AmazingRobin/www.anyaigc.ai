OpenAI's new frontier model for about 5% of list price

OpenAI released GPT-6.2 Astra and GPT-6.2 Sol together on November 17, 2026, and Astra is its new frontier model for the hardest projects. OpenAI says its slides, spreadsheets and documents read less like AI and follow your templates and field conventions more closely, and that it writes cleaner code and builds frontends that look and work better. Call the GPT-6.2 Astra API in three steps

  1. Sign up and top up: create an account at anyaigc.ai. Your balance works across every model.
  2. Create an API key: create a token in the console, copy the sk- key and store it in the ANYAIGC_API_KEY environment variable.
  3. Send a request: call https://anyaigc.ai/v1/chat/completions or https://anyaigc.ai/v1/responses with model set to gpt-6.2-astra and Authorization: Bearer auth.

We recommend /v1/responses for tool calling. Use /v1/chat/completions for plain chat and streaming, and /v1/responses for function calling, computer operations, web search and other tools, with the effort in reasoning.effort. The function-calling example on this page uses /v1/responses.

See the Chat Completions reference and the Responses reference for every parameter. Fields match the official OpenAI API.

GPT-6.2 Astra API FAQ

How much does the GPT-6.2 Astra API cost?

On AnyAIGC, gpt-6.2-astra is billed per token: $0.3971 per 1M input tokens, $1.9860 per 1M output tokens and $0.0199 per 1M cached input tokens. OpenAI's list price is $8.00 input, $40.00 output and $0.40 cached input, so AnyAIGC is about 5% of list (95% off). When a request has between 272K and 1M input tokens it is billed at the higher tier: $0.7942 input and $2.9780 output per 1M tokens.

What is the GPT-6.2 Astra model ID?

The model ID is gpt-6.2-astra. Put it in the model field of your request.

GPT-6.2 Astra vs GPT-6 Astra: what changed?

OpenAI calls GPT-6.2 Astra its new frontier model for the hardest projects. Its API list prices are lower than GPT-6 Astra: input and output tokens cost 20% less ($8 and $40) and cached input costs 60% less ($0.40). According to OpenAI, it scores 5.2 points above GPT-6 Astra on Agents’ Last Exam at under a third of the cost, 9 points higher on Terminal-Bench-Science 0.1 at under a third of the cost, and 6.2 points higher on GDPval v2 with 22% fewer output tokens. On AnyAIGC, gpt-6.2-astra is $0.3971 input and $1.9860 output, and gpt-6-astra is $0.4964 input and $2.4810 output per 1M tokens.

GPT-6.2 Astra or GPT-6.2 Sol: which should I use?

OpenAI says GPT-6.2 Sol comes within 0.5 points of GPT-6.2 Astra on Cognition's FrontierCode 2.0 at about one-fifth of the cost (both at max). Start with GPT-6.2 Sol for most coding and agent work, and move to GPT-6.2 Astra for the hardest projects, professional documents and research. On AnyAIGC, GPT-6.2 Astra is $0.3971 input and $1.9860 output, and GPT-6.2 Sol is $0.0993 input and $0.4964 output per 1M tokens.

Chat Completions or Responses API? Can I use tools?

Both endpoints work. For plain chat and streaming, use https://anyaigc.ai/v1/chat/completions. For function calling, web search, computer operations and other tools, we recommend https://anyaigc.ai/v1/responses, with the effort in reasoning.effort. In the Responses API you can also delegate tasks to sub-agents with the multi-agent beta.

Can I use GPT-6.2 Astra in Codex?

Yes. Run curl -fsSL https://www.anyaigc.ai/install.sh | bash -s codex to install and configure it (on Windows, irm https://www.anyaigc.ai/install.ps1 | iex). The installer defaults to gpt-5.5, so change model in ~/.codex/config.toml to gpt-6.2-astra afterwards. Or edit ~/.codex/config.toml yourself: set base_url to https://anyaigc.ai/v1, wire_api to responses and model to gpt-6.2-astra, then put OPENAI_API_KEY in ~/.codex/auth.json.

Are there concurrency or rate limits?
