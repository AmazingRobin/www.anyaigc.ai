About

The previous workhorse Flash model in the Gemini 3 series

Google released Gemini 3.7 Flash as generally available on August 13, 2026. The model card says it is based on Gemini 3.6 Flash, and the Vertex AI docs call it "our intelligent everyday driver for developers." Against 3.6 Flash, Google's published DeepSWE v1.1 score rose from 48.6% to 65.3%, and AutomationBench from 17.0% to 30.4%.

Gemini 3.8 Flash followed on September 2, 2026, and 3.7 Flash was marked deprecated on October 8. Google's model page now calls it a "previous-generation model", and it no longer appears on the Gemini API pricing page. On Vertex AI it retires on January 28, 2027.

If your code already uses gemini-3.7-flash, you can keep calling it on AnyAIGC through the native /v1beta/models/gemini-3.7-flash:generateContent endpoint or the OpenAI-compatible /v1/chat/completions. When you're ready to upgrade, change the model name to gemini-3.8-flash. The unit price stays the same.

    $0.0744 per 1M input tokens and $0.0074 per 1M cache-hit tokens suit classification, extraction and summarization at scale.

Upgrade

Stay on 3.7 Flash or move to 3.8 Flash

  • 01 · Existing apps

    Keep it running

    If your prompts and output parsing are tuned for 3.7 Flash, keep calling gemini-3.7-flash and switch after a round of regression tests.

  • 02 · New projects

    Start on 3.8 Flash

    Google has dropped 3.7 Flash from its pricing page and AI Studio. gemini-3.8-flash has the same context, modalities and thinking levels, and the same AnyAIGC price.

  • 03 · How to switch

    Change the model name

    In the native API, replace gemini-3.7-flash in the URL with gemini-3.8-flash. In the OpenAI-compatible API, change model. Base URL and API key stay the same.

  • 04 · Watch for

    Token usage

    The Vertex AI docs note that 3.8 Flash may use more tokens to maximize performance, especially at higher effort levels. Compare usage after switching and lower the thinking level if needed.

FAQ

Gemini 3.7 Flash API FAQ

How much does the Gemini 3.7 Flash API cost?

On AnyAIGC, gemini-3.7-flash is billed per token: $0.0744 per 1M input tokens, $0.3722 per 1M output tokens and $0.0074 per 1M cache-hit tokens. Google's launch price was $0.75 input and $3.75 output (introductory through December 31, 2026, then $1.50 / $7.50), so AnyAIGC is about 10% of Google's price. Google did not publish a cache price for 3.7 Flash.

Is Gemini 3.7 Flash deprecated? Can I still call it?

Google's changelog for October 8, 2026 says gemini-3.7-flash is deprecated and has been replaced by gemini-3.8-flash. It can no longer be selected in Google AI Studio, and Gemini API requests to gemini-3.7-flash are automatically routed to gemini-3.8-flash. On Vertex AI the retirement date is January 28, 2027. On AnyAIGC the model name gemini-3.7-flash still works, so existing code needs no changes. For new projects we recommend gemini-3.8-flash.

What is the difference between Gemini 3.7 Flash and Gemini 3.8 Flash?

Both have the same 1,048,576-token input limit, 65,536-token output limit, input modalities and thinking levels. Google calls 3.8 Flash its most intelligent Flash model, with significant improvements over 3.7 Flash in software engineering and agentic tasks. On AnyAIGC both cost the same, $0.0744 input and $0.3722 output per 1M tokens, so switching does not raise your unit price.

What are the context window and output limit?

Google lists an input limit of 1,048,576 tokens and an output limit of 65,536 tokens. Inputs can be text, images, video, audio and PDF; output is text.

Should I use the native Gemini API or the OpenAI-compatible API?

Either works. The native endpoint is POST https://anyaigc.ai/v1beta/models/gemini-3.7-flash:generateContent with the same request body as Google's Gemini API. The OpenAI-compatible endpoint is POST https://anyaigc.ai/v1/chat/completions; with the official OpenAI SDK, set base_url to https://anyaigc.ai/v1. Both use Authorization: Bearer.

How do I set the thinking level?

Gemini 3.7 Flash supports low, medium and high thinking, with medium as the default. In the native API, set generationConfig.thinkingConfig.thinkingLevel. Google notes that minimal is not supported and returns an error.

Are there concurrency or rate limits?

AnyAIGC does not cap concurrency for gemini-3.7-flash. Every account gets it by default, which suits batch jobs and high-traffic workloads.
