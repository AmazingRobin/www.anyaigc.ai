#How the Midjourney API works

It mirrors the web app and Discord: generate a grid of four, then press buttons on the result. The API hands you every button; send its customId back to run it.

  1. 01

    POST/mj/submit/imagine

    Submit a prompt

    Returns a task ID. Put --ar, --v or --niji straight into the prompt. $0.0595 per call

  2. 02

    GET/mj/task/{id}/fetch

    Fetch the task

    Poll until SUCCESS to get imageUrl and the buttons list. Fetching is free

  3. 03

    POST/mj/submit/action

    Press a button

    Send the taskId and a button's customId: upscales $0.0298, variations, zoom and pan $0.0595

  4. 04

    POST/mj/submit/modal

    Confirm the modal

    Vary (Region) and Custom Zoom need a second step with a mask or new prompt. $0.0595 per call

#What you can do with the Midjourney API

  • Imagine

    One prompt returns four candidates, with optional image prompts via base64Array. Midjourney is known for light, texture and composition in both photography and illustration.

  • Niji for anime and illustration

    Set botType to NIJI_JOURNEY to switch to Niji for anime, manga and illustrated styles.

  • Variations

    V1-V4 riff on one image. Vary (Strong) moves further, Vary (Subtle) only nudges.

  • Upscale

    U1-U4 pull out a single image, then Subtle or Creative upscales get it ready to ship.

  • Zoom Out and Pan

    Expand the frame 1.5x or 2x, or extend it in one direction, for example turning a portrait into a landscape.

  • Blend and Describe

    Merge 2-5 images into a new one, or send an image and get four prompts that describe it.

#Midjourney API FAQ

How much does the Midjourney API cost?

AnyAIGC bills Midjourney per call: Imagine, Blend, Variation, Reroll, Zoom, Pan and Modal are $0.0595 each, Upscale and Describe are $0.0298, image upload is $0.000595, and Custom Zoom and Vary (Region) are free (their modal step is billed as Modal). Fetching tasks is free, and live pricing is in the model catalog.

Does Midjourney have an official API?

Midjourney does not currently offer a public API; it runs on its website and Discord. AnyAIGC wraps the Midjourney service in HTTP endpoints, so images come from Midjourney's own models (including Niji) rather than a substitute, and one API key can run Imagine, upscales, variations, zoom and more without a Discord account of your own.

What are the 14 operations, and which endpoints do they use?

The 14 model names map to 14 Midjourney operations, all in the pricing table above. Imagine, Blend and Describe have their own endpoints. Upscale, Variation, Vary (Strong/Subtle), Reroll, Zoom, Pan, Custom Zoom and Vary (Region) all go through /mj/submit/action, selected by the button's customId. Modal is the confirmation step, and Upload sends reference images.

Which Midjourney versions are supported? Can I use Niji?

Pick the version with the --v parameter at the end of the prompt (the API docs use --v 6.1), written the same way as in the official app and passed through to Midjourney. Set botType to NIJI_JOURNEY for the Niji anime model; the default is MID_JOURNEY.

How many images does one call return?

Imagine, Variation, Reroll, Zoom, Pan and similar calls return a grid of four candidates and are billed once. For a single high-resolution image, run Upscale on one of them.

How do I run upscales and variations?

Fetch the task with /mj/task/{id}/fetch. Each entry in buttons has a customId; send the task ID and that customId to /mj/submit/action. Always take customId from the response rather than building it yourself.

Is there a concurrency limit?

No. AnyAIGC sets no concurrency limit on Midjourney for any account, so you can submit tasks in parallel. All requests go to the base URL https://anyaigc.ai, and the same key works for 300+ other models.

Can AnyAIGC issue invoices, including VAT special invoices?

Yes. AnyAIGC issues an invoice for every top-up, including Chinese VAT general and special invoices. Send your billing details to support.

Can my company pay by bank transfer and sign a contract?

Which payment methods are supported?

You can top up with WeChat Pay, Alipay, USDT or a credit card. Companies can also pay by bank transfer and get VAT general or special invoices. Your balance is in USD and works across every model on the platform.

Is there free trial credit for new users?
