Get started with the Seedream 5.0 Pro API

  1. Sign up for AnyAIGC. New accounts get 2M free tokens, and you can top up from $1.
  2. Create an API key in the console and save it as the ANYAIGC_API_KEY environment variable.
  3. Send a request to POST https://anyaigc.ai/v1/images/generations (OpenAI-compatible) with model set to doubao-seedream-5-0-pro-260628.

5.0 Pro does not support image sets (sequential_image_generation). To get several related images per request, change model to doubao-seedream-5-0-260128 (5.0 lite).

Authenticate with Authorization: Bearer <API Key>. The response looks like {"created": ..., "data": [{"url": ...}]}; set response_format to b64_json to get base64 instead. watermark defaults to true, so pass false explicitly for clean images. Field details are in the AnyAIGC Seedream API docs.

Seedream 5.0 Pro API FAQ

How much does the Seedream 5.0 Pro API cost?

On AnyAIGC, Seedream 5.0 Pro (doubao-seedream-5-0-pro-260628) starts at $0.0441 / image. Prices vary by resolution, and omitting size may bill a higher tier, so pass 1K or 2K explicitly. You are billed per successful generation; live prices are in the model catalog.

What is Seedream 5.0 Pro?

Seedream 5.0 Pro is the flagship image model from the ByteDance Seed team, described officially as a multimodal image generation model with reasoning built in for efficient creation and production. It focuses on dense information layouts, interactive precise editing, realistic photography and portraits, and native support for 10+ languages. AnyAIGC added it in August 2026.

Which resolutions are supported? Can it output 4K?

No 4K. Per the Volcano Engine Ark docs, 5.0 Pro accepts size values of 1K, 1.5K and 2K (default 2K), or pixel dimensions such as 2048x2048 and 2816x1584, with aspect ratios from 1:16 to 16:1. For 4K, use Seedream 5.0 lite or 4.5.

How many reference images can I send? Does it support image sets?

image accepts up to 10 reference images for editing and multi-image fusion. 5.0 Pro does not support image sets (several related images per request); use 5.0 lite, 4.5 or 4.0 for that.

Should I pick 5.0 Pro or 5.0 lite?

Pick 5.0 Pro for text-heavy images such as infographics, posters and UI, and for precise edits driven by annotations or selected regions. Pick 5.0 lite for everyday batch work, 4K, image sets or web search; it also costs less (from $0.0223 / image).

Is there a concurrency limit? What do I need to sign up?

AnyAIGC sets no concurrency limit on Seedream 5.0 Pro, and every account gets this by default. The base URL is https://anyaigc.ai. You do not need a Volcano Engine account or ID verification, and the same key also works with 300+ other models on the platform.

Yes. AnyAIGC issues invoices for every top-up based on the amount actually paid, including Chinese VAT general and special invoices. Send your billing details to support to get started.

Can my company pay by bank transfer and sign a contract?

Are these the real models? Is my data safe?

Requests go to official model channels, never cheaper or reverse-engineered substitutes. Unless the law requires it, we do not persistently store your prompts or outputs or use them for training, and the console shows tokens and cost for every request.

Can I use the images commercially? Can I remove the watermark?

Usage rights and content policies follow the official ByteDance / Volcano Engine terms. Set watermark to false in the request and no "AI generated" mark is added to the bottom-right corner.
