Call the GPT-6.2 Sol API in three steps

  1. Sign up and top up: create an account at anyaigc.ai. Your balance works across every model.
  2. Create an API key: create a token in the console, copy the sk- key and store it in the ANYAIGC_API_KEY environment variable.
  3. Send a request: call https://anyaigc.ai/v1/chat/completions or https://anyaigc.ai/v1/responses with model set to gpt-6.2-sol and Authorization: Bearer auth.

We recommend /v1/responses for tool calling. Use /v1/chat/completions for plain chat and streaming, and /v1/responses for function calling, computer operations, web search and other tools, with the effort in reasoning.effort. The function-calling example on this page uses /v1/responses.

See the Chat Completions reference and the Responses reference for every parameter. Fields match the official OpenAI API.

GPT-6.2 Sol API FAQ

How much does the GPT-6.2 Sol API cost?

On AnyAIGC, gpt-6.2-sol is billed per token: $0.0993 per 1M input tokens, $0.4964 per 1M output tokens and $0.0050 per 1M cached input tokens. OpenAI's list price is $2.00 input, $10.00 output and $0.10 cached input, so AnyAIGC is about 5% of list (95% off). When a request has between 272K and 1M input tokens it is billed at the higher tier: $0.1986 input and $0.7446 output per 1M tokens.

What is the GPT-6.2 Sol model ID?

The model ID is gpt-6.2-sol. Put it in the model field of your request.

GPT-6.2 Sol vs GPT-6.1 Sol: what changed?

OpenAI says GPT-6.2 Sol is smarter and more efficient than GPT-6.1 Sol and keeps its API list prices ($2 input, $0.10 cached input, $10 output). According to OpenAI, it scores 73.0% on Agents’ Last Exam at max effort (GPT-6.1 Sol: 72.5%), with a bigger gain at low effort (66.7% against 61.0%), and is 5.3 points higher on GDPval v2. On AnyAIGC both cost the same: $0.0993 input and $0.4964 output per 1M tokens.

GPT-6.2 Sol or GPT-6.2 Astra: which should I use?

OpenAI says GPT-6.2 Sol comes within 0.5 points of GPT-6.2 Astra on Cognition's FrontierCode 2.0 at about one-fifth of the cost (both at max). Start with GPT-6.2 Sol for most coding, agent and everyday work, and move to GPT-6.2 Astra for the hardest projects. On AnyAIGC, GPT-6.2 Sol is $0.0993 input and $0.4964 output, and GPT-6.2 Astra is $0.3971 input and $1.9860 output per 1M tokens.

Chat Completions or Responses API? Can I use tools?

Both endpoints work. For plain chat and streaming, use https://anyaigc.ai/v1/chat/completions. For function calling, web search, computer operations and other tools, we recommend https://anyaigc.ai/v1/responses, with the effort in reasoning.effort.

Can I use GPT-6.2 Sol in Codex?

Yes. Run curl -fsSL https://www.anyaigc.ai/install.sh | bash -s codex to install and configure it (on Windows, irm https://www.anyaigc.ai/install.ps1 | iex). The installer defaults to gpt-5.5, so change model in ~/.codex/config.toml to gpt-6.2-sol afterwards. Or edit ~/.codex/config.toml yourself: set base_url to https://anyaigc.ai/v1, wire_api to responses and model to gpt-6.2-sol, then put OPENAI_API_KEY in ~/.codex/auth.json.

Are there concurrency or rate limits?

AnyAIGC sets no concurrency limit on gpt-6.2-sol. Every account gets this by default, so batch jobs and parallel agents run without queuing.
