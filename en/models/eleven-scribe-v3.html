About the model

Eleven Scribe v3: Accurate recording transcription

Eleven Scribe v3 is the ElevenLabs speech-to-text (STT) model for recorded audio. The official model docs call it the most accurate speech recognition model for recorded audio, covering 90+ languages. The ElevenLabs changelog dates the Scribe v3 release to 9 November 2026 and says it makes 27% fewer word errors than Scribe v2 on the FLEURS benchmark across 102 languages. The AnyAIGC model catalog describes it as the same price and same interface as v2, with clearly better accuracy and speaker separation.

The official docs list word-level timestamps, speaker diarization for up to 32 speakers, keyterm prompting with up to 1,000 terms, audio event tagging such as laughter and applause, and entity detection. The official capabilities page gives a 5 GB file limit, up to 15 hours per file, and up to 5 channels for multichannel audio. Those are the capabilities listed in the official ElevenLabs docs.

On AnyAIGC, scribe_v3 runs on POST /v1/audio/transcriptions. You upload audio as multipart/form-data and are billed per second of audio, with no concurrency limit and a single Bearer key, so you do not need a separate ElevenLabs account.

Quick start

Call the Eleven Scribe v3 API in three steps

  1. Sign up and top up: create an account at anyaigc.ai. Top-ups start at $1, and the balance works across every model on the platform.
  2. Create an API key: create a token in the console, copy the key that starts with sk-, and store it in the ANYAIGC_API_KEY environment variable.
  3. Upload a recording: call POST https://anyaigc.ai/v1/audio/transcriptions as multipart/form-data with file (the audio file) and model set to scribe_v3, authenticate with Authorization: Bearer, and read the transcript from text in the response.

Parameter notes: the model ID is case-sensitive, so write scribe_v3. The request is multipart/form-data, and file is the audio file itself, not a file name. A successful call returns {"text": "..."}.

See the Speech to text API reference. To call Scribe, set model to scribe_v3 or scribe_v2.

FAQ

Eleven Scribe v3 API FAQ

How much does the Eleven Scribe v3 API cost?

On AnyAIGC, scribe_v3 is billed per second of audio at $0.0000450 per second, which is $0.0027 per minute or $0.162 per hour, about 19% off the ElevenLabs list price of $0.20 per hour. The price is fixed, with no subscription or monthly fee. Live prices are in the model catalog.

What is the Eleven Scribe v3 model ID, and how does it relate to ElevenLabs?

The model ID is scribe_v3 (case-sensitive), the same as the ElevenLabs model_id. AnyAIGC is an independent API provider that offers an OpenAI-style /v1/audio/transcriptions call, and is not affiliated with ElevenLabs.

How do I choose between Eleven Scribe v3 and the other Eleven models?

The Eleven models on AnyAIGC fall into two kinds: 7 text-to-speech models, starting with Eleven v4, and 2 speech-to-text models, Eleven Scribe v3 and Eleven Scribe v2. Pick Scribe to turn recordings into text, and pick v4, Multilingual v2 or another text-to-speech model to turn text into speech.

How do I get a Eleven Scribe v3 API key?

Sign up and top up at anyaigc.ai, then create a token in the console. One key works for 300+ models on the platform, and you do not need a separate ElevenLabs account. Set model to scribe_v3 in the request.

How do I call the Eleven Scribe v3 API?

Call POST https://anyaigc.ai/v1/audio/transcriptions as multipart/form-data with file (the audio file) and model set to scribe_v3, and authenticate with Authorization: Bearer. A successful call returns {"text": "..."}. See the API reference.

Which audio formats does Eleven Scribe v3 accept, and how large can a file be?

The API reference lists these file formats: flac, mp3, mp4, mpeg, mpga, m4a, ogg, wav and webm. The ElevenLabs capabilities page gives a limit of 5 GB and 15 hours per file.

Does Eleven Scribe v3 support Chinese, and how many languages?

Yes. The official docs say Scribe supports 90+ languages, and Mandarin and Cantonese are on the official language list. For the exact languages see the ElevenLabs model docs.

What is the difference between Scribe v3 and Scribe v2?

The ElevenLabs changelog says Scribe v3 makes 27% fewer word errors than Scribe v2 on the FLEURS benchmark across 102 languages, and that it labels speakers more accurately. On AnyAIGC the two have the same price and the same interface; only the model field differs. For a new project try v3 first, or transcribe the same recording with both and compare. See Eleven Scribe v2 for v2.

Is there a real-time (streaming) transcription model?

This page covers the recording-file models scribe_v3 and scribe_v2, called over HTTP at /v1/audio/transcriptions: you upload a complete recording and get the text back. ElevenLabs also offers real-time models (such as scribe_v3_live), which are out of scope here. Whether they are offered is shown in the model catalog.

Is there a rate limit?

AnyAIGC sets no concurrency limit on scribe_v3, and every account gets this by default, so batch transcription and parallel tasks are fine. Billing is per second of audio, with no monthly fee and no quota that resets on a time window.

Can I get an invoice from AnyAIGC?

Yes. You can issue invoices yourself in the console, for the amount you actually topped up.

Which payment methods are supported?

You can top up with WeChat Pay, Alipay, USDT or a credit card. Your balance is in USD and works across every model on the platform. Invoices can be issued in the console for the amount you topped up.

Is there free trial credit for new users?

Yes. New accounts get 5 million tokens of trial credit, so you can test before deciding to top up. Top-ups start at $1.

Can I get a refund on my balance?

Yes. Unused balance can be refunded with no fee. Contact support to start a refund.

Are these the real models? Is my data safe?

Requests go to official model channels, never cheaper or reverse-engineered substitutes. Unless the law requires it, we do not persistently store your prompts or outputs or use them for training, and the console shows tokens and cost for every request.

Are my uploaded recordings and the transcripts used for training?

No. Unless the law requires it, AnyAIGC does not persistently store your inputs or outputs and does not use them for training. Requests are encrypted with HTTPS. See the AnyAIGC Privacy Policy. The data policy of the model itself is set by ElevenLabs. If a recording contains personal information, make sure you have the right to process it.
