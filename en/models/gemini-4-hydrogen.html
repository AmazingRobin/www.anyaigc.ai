About the model

The fast-execution model in the Gemini 4 generation

Google released Gemini 4 Hydrogen on November 12, 2026. The model card says Gemini 4 Carbon and Argon are frontier models for deep, long-horizon reasoning on the hardest problems, while Hydrogen is built for fast execution across agent workflows. It is adapted from Gemini 4 Carbon and natively accepts text, images, audio, video and PDF input.

Google lists these improvements: cleaner code; it flags missing context instead of guessing, and fabricates less than a fifth as often as Gemini 3.8 Flash; it batches read and search tool calls in parallel and recovers better when a tool call fails. It can handle coding and agent tasks on its own, or run as a sub-agent alongside Carbon and Argon for parallel execution and verification. The Antigravity agent in Google's hosted agent service now defaults to Hydrogen.

On AnyAIGC, gemini-4-hydrogen works with both the native /v1beta/models/gemini-4-hydrogen:generateContent endpoint and the OpenAI-compatible /v1/chat/completions. You don't need a Google Cloud account, and the same key calls 300+ other models on the platform.

Capabilities

What Gemini 4 Hydrogen can do

  • Everyday coding and debugging

    Built for repeated repository-level edits and debugging, plus web development and everyday prototyping. Google reports 13.5% on SWE-sweep, against 3.1% for Claude Sonnet 5.5 and 5.8% for GPT-6.1 Terra.

  • Fast-executing agents

    Function calling, code execution, computer use, Google Search and Maps grounding are all supported. It scores 76.1% on AutomationBench-AA and 71.6% on Agents' Last Exam v1.1.

  • A sub-agent in multi-model setups

    Google suggests letting Carbon design the interface and handle the hard parts, then handing code changes, parallel subtasks and tests to Hydrogen, for lower latency and fewer tokens.

  • 1M-token context

    The 1,048,576-token window holds a full codebase or a large document set. Synchronous output is capped at 65,536 tokens by default; long output can extend to about 1M tokens through background execution.

  • Multimodal knowledge work

    Read spreadsheets, charts, dense PDFs, images, audio and video, and inspect specific frames in a video the way an agent would. Chartography chart understanding is 66.6%, and MKA is 53.4%.

  • Four thinking levels

    low, medium, high and xhigh let you trade latency, cost and reasoning depth. It scores 58.8% on the HLE-Diamond reasoning benchmark.

Call the Gemini 4 Hydrogen API in three steps

  1. Sign up and top up: create an account at anyaigc.ai. Your balance works across every model on the platform.
  2. Create an API key: create a token in the console, copy the key that starts with sk-, and store it in the ANYAIGC_API_KEY environment variable.
  3. Send a request: call the native endpoint https://anyaigc.ai/v1beta/models/gemini-4-hydrogen:generateContent, or the OpenAI-compatible https://anyaigc.ai/v1/chat/completions with model set to gemini-4-hydrogen. Both authenticate with Authorization: Bearer.

Parameter notes: Gemini 4 Hydrogen uses thinkingLevel (low / medium / high / xhigh), defaulting to high. Sending minimal returns an error, and temperature, topP and topK are ignored. maxOutputTokens caps both thinking and the answer; Google suggests not pinning it to a low ceiling like 8,192 and leaving the 65,536 default in place. To spend fewer tokens, lower the thinking level instead. Explicit caching (cachedContents) is not supported. For native streaming, call :streamGenerateContent?alt=sse.

For every parameter, see the native Gemini API docs and the Chat Completions docs. Replace the model name in the examples with gemini-4-hydrogen.

FAQ

Gemini 4 Hydrogen API FAQ

How much does the Gemini 4 Hydrogen API cost?

On AnyAIGC, gemini-4-hydrogen is billed per token: $0.5360 per 1M input tokens, $2.6800 per 1M output tokens and $0.0268 per 1M cached tokens. Google's paid-tier list price is $1.50 input, $7.50 output and $0.075 cache, so AnyAIGC costs about 36% of Google's list price, 64% off. Output includes thinking tokens.

What is the Gemini 4 Hydrogen model ID? Is it generally available?

The model ID is gemini-4-hydrogen. Google released it on November 12, 2026, and the model page marks it Stable, not a preview. The native endpoint puts the model name in the URL (/v1beta/models/gemini-4-hydrogen:generateContent); the OpenAI-compatible endpoint takes it in the model field.

What are the context window and maximum output?

Google lists a 1,048,576-token context window shared by input, thinking and output. A synchronous request returns up to 65,536 output tokens by default; output beyond 64K (up to about 1M tokens) runs through Google's background execution feature or client-side continuation.

How do I set the thinking level?

Gemini 4 Hydrogen supports four thinking levels, low, medium, high and xhigh, with high as the default. That differs from Argon and Carbon, which default to medium. On the native endpoint, set generationConfig.thinkingConfig.thinkingLevel. Google suggests starting most tasks at high and reserving xhigh for multi-step problems that high cannot solve; sending minimal returns an error, and temperature, top_p and top_k are ignored.

Should I use the native Gemini endpoint or the OpenAI-compatible one?

Either works. The native endpoint is POST https://anyaigc.ai/v1beta/models/gemini-4-hydrogen:generateContent with the same request body as the Google Gemini API, so you can use contents, systemInstruction, tools and thinkingConfig. The OpenAI-compatible endpoint is POST https://anyaigc.ai/v1/chat/completions; with the official OpenAI SDK, set base_url to https://anyaigc.ai/v1. Both use Authorization: Bearer.

Gemini 4 Hydrogen vs Argon, Carbon and 3.8 Flash: which should I use?

Google's positioning: Hydrogen handles fast execution, for everyday coding, interactive web apps, tool-calling agents, multimodal document work and parallel sub-agents. Argon and Carbon handle deep, long-horizon reasoning, and Carbon thinks the most. Google recommends upgrading from Gemini 3.8 Flash to Hydrogen, and having Carbon plan while Hydrogen makes code changes and runs tests. On Google's list price, Hydrogen costs less than Argon and Carbon. On AnyAIGC, Hydrogen is $0.5360 input and $2.6800 output, Argon is $0.1985 input and $0.9927 output, and Carbon is $0.7147 input and $3.5740 output. All three share one key; switch by changing the model name.

How is caching billed?

Gemini 4 Hydrogen supports implicit caching only, not explicit caching (cachedContents). Per Google, prompts of 4,096 tokens or more are automatically eligible for caching, and cached tokens cost $0.0268 per 1M on AnyAIGC, 5% of the input price.

Are there concurrency or rate limits?
