About the model

Flash speed and cost, with near-flagship coding and agents

Google made Gemini 3.8 Flash generally available on September 2, 2026. Google calls it "our most intelligent Flash model," built for long-horizon software engineering, autonomous agents and complex enterprise workflows, "all with the speed and cost efficiency of Flash." The launch post describes it as the best reasoning and coding model in the Flash line so far, at the same speed and low cost as 3.7 Flash.

The model card says 3.8 Flash is based on 3.7 Flash. It takes up to 1,048,576 input tokens, returns up to 65,536 output tokens, and accepts text, images, video, audio and PDF natively. Google deprecated 3.7 Flash in October 2026 and now routes its API requests to 3.8 Flash, which makes 3.8 Flash the main stable model in the Gemini 3 series.

On AnyAIGC, gemini-3.8-flash works with both the native /v1beta/models/gemini-3.8-flash:generateContent endpoint and OpenAI-compatible /v1/chat/completions. You don't need a Google Cloud account, and concurrency is unlimited, so it can take production traffic as is.

    Function calling, code execution, structured output, URL context, Google Search and Maps grounding, plus computer use in preview. 59.0% on OSWorld-2.0.

  • High-volume production

    $0.0744 per 1M input and $0.0074 per 1M cache-hit tokens, with no concurrency cap on AnyAIGC. Run classification, extraction, summaries and moderation at scale.

  • 1M-token context

    A 1,048,576-token input window holds a whole codebase, a long report or a batch of contracts, so cross-document search and comparison fit in one request.

    Images, video, audio and PDF go in directly. Google reports 87.8% on LVBench for long video and 86.2% on CharXiv chart reasoning.

  • Adjustable thinking

    Three thinking levels: use low to save tokens on simple calls and high for hard problems. One model covers quick replies through deep reasoning.

FAQ

Gemini 3.8 Flash API FAQ

How much does the Gemini 3.8 Flash API cost?

On AnyAIGC, gemini-3.8-flash is billed per token: $0.0744 per 1M input tokens, $0.3722 per 1M output tokens and $0.0074 per 1M cache-hit tokens. Google's Standard price (introductory through December 31, 2026) is $0.75 input, $3.75 output and $0.075 cache, so AnyAIGC is about 10% of list. Output includes thinking tokens.

Will AnyAIGC's price change after Google's introductory period?

No. Starting January 1, 2027, Google's Standard price becomes $1.50 input, $7.50 output and $0.15 cache per 1M tokens. AnyAIGC keeps its current price ($0.0744 input, $0.3722 output, $0.0074 cache), which is then about 5% of Google's price.

What is the model ID? Is Gemini 3.8 Flash generally available?

The model ID is gemini-3.8-flash. Google released it as generally available (GA) on September 2, 2026, and has not announced a shutdown date. The native API puts the model name in the URL (/v1beta/models/gemini-3.8-flash:generateContent); the OpenAI-compatible API takes it in the model field.

What are the context window and max output?

Google lists an input limit of 1,048,576 tokens and an output limit of 65,536 tokens. Inputs can be text, images, video, audio and PDF; output is text. The knowledge cutoff is March 2026.

Should I use the native Gemini API or the OpenAI-compatible API?

Either works. The native endpoint is POST https://anyaigc.ai/v1beta/models/gemini-3.8-flash:generateContent with the same request body as the Google Gemini API. The OpenAI-compatible endpoint is POST https://anyaigc.ai/v1/chat/completions; with the official OpenAI SDK, set base_url to https://anyaigc.ai/v1. Both authenticate with Authorization: Bearer.

How do I set the thinking level?

Gemini 3.8 Flash supports low, medium and high thinking levels, with medium as the default. In the native API set generationConfig.thinkingConfig.thinkingLevel. Google notes that minimal is not supported and returns an error, and that higher levels can use more tokens, so low is a good start for cost-sensitive batch jobs.

Gemini 3.8 Flash or Gemini 4 Argon?

Gemini 3.8 Flash fits high-volume, latency- and cost-sensitive work plus everyday coding and agent workflows, at $0.0744 input and $0.3722 output on AnyAIGC. Gemini 4 Argon is Google's current flagship and scores higher than 3.8 Flash on Google's published DeepSWE, Terminal-bench 4.0, legal and finance agent benchmarks, at $0.1985 input and $0.9927 output on AnyAIGC. Start with 3.8 Flash and send the hardest tasks to Argon; both use the same key.

Can I still use Gemini 3.7 Flash? How is 3.8 Flash different?

Google deprecated gemini-3.7-flash on October 8, 2026 and replaced it with gemini-3.8-flash; Google's own API routes 3.7 Flash requests to 3.8 Flash automatically. Google says 3.8 Flash is based on 3.7 Flash and improves notably on software engineering and agentic tasks, for example DeepSWE v1.1 rises from 65.3% to 73.7%. Both cost the same on AnyAIGC, so new projects should use gemini-3.8-flash.

Are there concurrency or rate limits?

AnyAIGC does not cap concurrency for gemini-3.8-flash. Every account gets this by default, which suits batch processing and parallel agents.
