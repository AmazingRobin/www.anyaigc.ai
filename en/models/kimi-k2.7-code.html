About

K2.6, further trained for coding

Moonshot AI calls Kimi K2.7 Code its strongest coding model so far. It is further trained from K2.6, follows instructions more reliably over long context, completes more coding tasks, and uses about 30% fewer thinking tokens than K2.6.

The architecture matches K2.6: MoE with 1T total and 32B active parameters, 8 of 384 experts per token, 256K context, and text and image input. K2.7 Code always thinks and supports interleaved thinking with multi-step tool calls, which suits coding agents.

On AnyAIGC, kimi-k2.7-code runs on the OpenAI-compatible /v1/chat/completions endpoint and works directly in Claude Code, with unlimited concurrency.

Quickstart

Connect to the Kimi K2.7 Code API in three steps

  1. Sign up and add credit: create an account at anyaigc.ai. Top up from $1; your balance works across every model on the platform.
  2. Create an API key: create a key in the console, copy the value that starts with sk-, and store it in the ANYAIGC_API_KEY environment variable.
  3. Send a request: call POST https://anyaigc.ai/v1/chat/completions with model set to kimi-k2.7-code and an Authorization: Bearer header. With the OpenAI SDK, just set base_url to https://anyaigc.ai/v1.

Tip: K2.7 Code always thinks, and the reasoning comes back in reasoning_content. Moonshot recommends temperature=1.0 and top_p=0.95. In multi-turn chats and tool calls, send the full assistant message from the API (including reasoning_content and tool_calls) back in the next request unchanged.

See the Chat Completions reference for every parameter. Replace the model name in the docs examples with the Kimi model ID you want.

Claude Code

Use Kimi K2.7 Code in Claude Code

Switch Claude Code to Kimi K2.7 Code. It is trained for coding and costs about a third of K3.

  1. Install Claude Code: use the official installer (for example npm install -g @anthropic-ai/claude-code).
  2. Add the config: edit ~/.claude/settings.json, add the env block below, and replace ANTHROPIC_AUTH_TOKEN with the key you created on AnyAIGC.
  3. Start coding: run claude in your project folder. Type /model to confirm the current model is kimi-k2.7-code.

For large repos: K2.7 Code has a 256K context. If a project is too big to read in one go, switch the model in the config to kimi-k3 (1M context).

For the full walkthrough and common errors, see the Claude Code setup guide. Swap the model name in the guide for kimi-k2.7-code.

FAQ

Kimi K2.7 Code API FAQ

How much does the Kimi K2.7 Code API cost?

On AnyAIGC, kimi-k2.7-code is billed per token: input $0.3847 per 1M tokens, output $1.5980 per 1M tokens, cache hit $0.0770 per 1M tokens. Moonshot's official USD prices are input $0.95, output $4.00 and cache hit $0.19, so AnyAIGC is about 40% of official. Output includes thinking tokens. See the model catalog for live pricing.

What is the Kimi K2.7 Code model ID, and how large is the context?

The model ID is kimi-k2.7-code. Moonshot lists a 262,144-token (256K) context window, with text and image input.

How is Kimi K2.7 Code different from K2.6?

K2.7 Code is further trained from K2.6 with a focus on coding, on the same architecture (1T total, 32B active parameters). Moonshot says it follows instructions more reliably over long context, completes more coding tasks, and uses about 30% fewer thinking tokens than K2.6; Kimi Code Bench v2 goes from 50.9 to 62.0. K2.7 Code only runs in thinking mode, while K2.6 can turn thinking off. Both have the same input and output prices on AnyAIGC.

Can I turn off thinking in Kimi K2.7 Code?

No. Moonshot says K2.7 Code always runs with thinking and preserve thinking on, and does not support non-thinking mode. For fast, non-thinking responses, use kimi-k2.6. Moonshot recommends temperature=1.0 and top_p=0.95.

Does Kimi K2.7 Code support tool calls?

Yes. K2.7 Code supports interleaved thinking and multi-step tool calls, which suits coding agents. In multi-turn chats and tool calls, send the full assistant message (including reasoning_content and tool_calls) back in the next request unchanged.

Can I use Kimi K2.7 Code in Claude Code?

Yes. In the env block of ~/.claude/settings.json, set ANTHROPIC_BASE_URL to https://anyaigc.ai, ANTHROPIC_AUTH_TOKEN to your API key, and ANTHROPIC_MODEL to kimi-k2.7-code. Then run claude.

Kimi K2.7 Code or Kimi K3: which should I use?

K2.7 Code is a 1T-parameter coding model with 256K context at $0.3847 input and $1.5980 output on AnyAIGC, suited to everyday coding and high-volume agent calls. Kimi K3 is the 2.8T-parameter flagship with 1M context at $1.2150 input and $6.0750 output, suited to large repos and the hardest tasks. Both use the same key.

Are there concurrency or rate limits?

AnyAIGC does not cap concurrency for kimi-k2.7-code, and every user gets this by default. That suits batch jobs, CI pipelines and parallel agents. Moonshot's own platform limits concurrency, RPM, TPM and TPD by top-up tier; those tiers do not apply when you call through AnyAIGC.
