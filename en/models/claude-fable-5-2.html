What Claude Fable 5.2 is good at

Hours-long agentic coding

Plan, edit, run tests, and keep correcting based on the results, across large migrations and refactors that touch many modules. Anthropic says a team of agents running an early version of Fable 5.2 migrated a production service from Python to Rust, with startup about 26x faster. Cache hits cost just $0.0476 per million tokens, which keeps long sessions over the same repo affordable.

Multi-agent orchestration

Anthropic suggests using Fable 5.2 as an Orchestrator that hands simpler tasks to smaller models, or as an Advisor that Haiku, Sonnet, and Opus consult when they get stuck. In an official demo, Fable 5.2 coordinated more than 1,000 sub-agents over 8 days and went from an empty folder to a prototype operating system that boots on a laptop.

Deep research and data analysis

Search, read, compare, and synthesize sources around a single question. It scores 82.1% on the WANDR agentic search benchmark, up from 68.7% for Fable 5.1.

Documents, spreadsheets, and business workflows

Use it to produce finished reports, financial models, and slide decks. It scores 41.3% on the Remote Labor Index knowledge-work benchmark (Fable 5.1: 17.9%) and 51.4% on the AutomationBench business-workflow benchmark.

Call the Claude Fable 5.2 API in three steps

  1. Sign up and add credit: create an account at anyaigc.ai. Your balance works across every model on the platform.
  2. Create an API key: create a token in the console and copy the key that starts with sk-.
  3. Send a request: POST an Anthropic Messages request to https://anyaigc.ai/v1/messages, authenticating with Authorization: Bearer.

Claude Fable 5.2 API FAQ

How much does the Claude Fable 5.2 API cost?

On AnyAIGC, claude-fable-5-2 is billed per token: $1.906 per million input tokens, $9.529 per million output tokens, $2.3820 for 5-minute cache writes, $3.8120 for 1-hour cache writes, and $0.0476 for cache hits. Anthropic's list price is $8 input, $40 output, and $0.20 for cache hits, so AnyAIGC comes in at about 23.8% of list price, roughly 76% off.

What is the Claude Fable 5.2 model ID?

The model ID is claude-fable-5-2. Put it in the model field of your request body.

How is Claude Fable 5.2 different from Fable 5.1?

Anthropic released Fable 5.2 on November 9, 2026. The list price drops from $10 input and $50 output to $8 and $40, output is up to 30% faster, it uses fewer tokens to solve hard problems at Medium effort, and its safety classifiers block about 55% fewer legitimate requests than Fable 5.1. On benchmarks, FrontierSWE v2 rises from 56.3% to 69.9% and Remote Labor Index from 17.9% to 41.3%. Both models are available on AnyAIGC, and Fable 5.2 is the cheaper one at $1.906 per million input tokens versus $2.382 for Fable 5.1.

Is the AnyAIGC Claude API compatible with Anthropic's official API?

Yes. The endpoint is https://anyaigc.ai/v1/messages and the request body follows the Anthropic Messages format (model, max_tokens, system, messages, tools, cache_control, and so on). Authenticate with Authorization: Bearer followed by your API key. With the official SDK, just set the base URL to https://anyaigc.ai.

Can I use Claude Fable 5.2 in Claude Code?

Yes. In the env block of ~/.claude/settings.json, set ANTHROPIC_BASE_URL to https://anyaigc.ai, ANTHROPIC_AUTH_TOKEN to your API key, and both ANTHROPIC_MODEL and ANTHROPIC_DEFAULT_OPUS_MODEL to claude-fable-5-2, then run claude. You can also install and configure everything with one command: curl -fsSL https://www.anyaigc.ai/install.sh | bash -s claude.

How is prompt caching billed?

Add cache_control to a content block to enable caching. The first write is billed at the cache write rate ($2.3820 for 5 minutes or $3.8120 for 1 hour, per million tokens). After that, cached tokens cost only $0.0476 per million, about 2.5% of the regular input price. Long-running agents that reread the same context benefit the most.

Are there concurrency or rate limits?

AnyAIGC sets no concurrency limit on claude-fable-5-2. Every account gets this by default, so it works well for batch jobs and running multiple agents in parallel.

What is Claude Fable 5.2 good at, and should I pick it over Opus 5.5?

Anthropic says Fable 5.2 is best for the most ambitious, open-ended technical work, such as hours-long agentic coding, multistep research, and data-heavy analysis. It can also act as an Advisor that Haiku, Sonnet, or Opus consult on hard problems, or as an Orchestrator that hands simpler tasks to smaller models. Anthropic recommends starting with Claude Opus 5.5 for most coding and knowledge work and stepping up to Fable 5.2 when you need it. Both work with the same AnyAIGC key, so you can switch per task by changing the model field.
