Quickstart

Connect to the Kimi API in three steps

  1. Sign up and add credit: create an account at anyaigc.ai. Top up from $1; your balance works across every model on the platform.
  2. Create an API key: create a key in the console, copy the value that starts with sk-, and store it in the ANYAIGC_API_KEY environment variable.
  3. Send a request: call POST https://anyaigc.ai/v1/chat/completions with model set to kimi-k3.1-pro and an Authorization: Bearer header. With the OpenAI SDK, just set base_url to https://anyaigc.ai/v1.

Tip: Kimi returns its reasoning in the reasoning_content field. When streaming, reasoning deltas arrive first, then the final answer. In multi-turn chats and tool calls, send the full assistant message from the API (including reasoning_content and tool_calls) back in the next request unchanged.

See the Chat Completions reference for every parameter. Replace the model name in the docs examples with the Kimi model ID you want.

Claude Code

Use Kimi in Claude Code

Switch Claude Code to Kimi by editing one config file, and the coding agent in your terminal runs on Kimi.

  1. Install Claude Code: use the official installer (for example npm install -g @anthropic-ai/claude-code).
  2. Add the config: edit ~/.claude/settings.json, add the env block below, and replace ANTHROPIC_AUTH_TOKEN with the key you created on AnyAIGC.
  3. Start coding: run claude in your project folder. Type /model to confirm the current model is kimi-k3.1-pro.

Switching models: for a cheaper coding model, replace every kimi-k3.1-pro in the config with kimi-k2.7-code. K3.1 Pro has 1M context for large repos; K2.7 Code costs about half as much.

For the full walkthrough and common errors, see the Claude Code setup guide. Swap the model name in the guide for kimi-k3.1-pro.

FAQ

Kimi API FAQ

How much does the Kimi API cost?

Kimi models on AnyAIGC are billed per token. Per 1M tokens: kimi-k3.1-pro input $0.8100, output $4.0500, cache hit $0.0810; kimi-k3 input $1.2150, output $6.0750, cache hit $0.1215; kimi-k2.7-code input $0.3847, output $1.5980, cache hit $0.0770; kimi-k2.6 input $0.3847, output $1.5980, cache hit $0.0651. That is about 40% of Moonshot's official USD prices. See the model catalog for live pricing.

Which Kimi models are on AnyAIGC, and what are the model IDs?

This page covers four: kimi-k3.1-pro (the first K3.1 series model, with 1M context), kimi-k3 (the previous-generation flagship, a 2.8T-parameter open-weight model), kimi-k2.7-code (a coding agent model) and kimi-k2.6 (a general multimodal agent model). Put the model ID in the model field of the request body. Switching models only means changing that one field.

Kimi K3.1 Pro, K3, K2.7 Code or K2.6: which should I use?

Pick Kimi K3.1 Pro when you need 1M context, the hardest long-horizon coding, 3D creation or financial research. It is the newest generation and costs about a third less than K3. Workloads already on K3 can stay there. Pick K2.7 Code for everyday coding and coding agents; Moonshot says it scores 21.8% higher than K2.6 on Kimi Code Bench v2. Pick K2.6 when you want non-thinking mode, fast responses or general chat. K2.7 Code and K2.6 cost the same, about half the price of K3.1 Pro.

Is the Kimi API OpenAI compatible?

Yes. All four models use POST https://anyaigc.ai/v1/chat/completions with the same request and response format as OpenAI Chat Completions. With the official OpenAI SDK, set base_url to https://anyaigc.ai/v1. The reasoning trace comes back in the reasoning_content field.

Can I use Kimi in Claude Code?

Yes. In the env block of ~/.claude/settings.json, set ANTHROPIC_BASE_URL to https://anyaigc.ai, ANTHROPIC_AUTH_TOKEN to your API key, and ANTHROPIC_MODEL to kimi-k3.1-pro. Then run claude.

How large is the context window?

According to Moonshot, Kimi K3.1 Pro and K3 support a 1,048,576-token context; K2.7 Code and K2.6 support 262,144 tokens (256K). All four accept image input and support tool calls.

Are Kimi models open source? Can I use them commercially?

Moonshot AI has published the weights for Kimi K3, K2.7 Code and K2.6 on Hugging Face, and Moonshot says the full K3.1 Pro weights will be released by November 4, 2026. Calling the API through AnyAIGC means you do not have to host them yourself. Model licenses and commercial use are governed by Moonshot AI's official terms.

Are there concurrency or rate limits?

AnyAIGC does not cap concurrency for Kimi models, and every user gets this by default. That suits batch jobs, CI pipelines and parallel agents. Moonshot's own platform limits concurrency, RPM, TPM and TPD by top-up tier; those tiers do not apply when you call through AnyAIGC.

Can I call the Kimi API from mainland China?

Yes. AnyAIGC is optimized for access from mainland China, so you can usually call https://anyaigc.ai without a proxy. Usage is billed in USD, and you can pay with WeChat Pay, Alipay, USDT or a credit card. Companies can pay by bank transfer and get VAT invoices.

Sign up at anyaigc.ai, add credit, and create a key in the console. The same key works for every Kimi model and 300+ other models on the platform, so you do not need a separate Moonshot platform account.
