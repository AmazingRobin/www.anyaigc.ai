About the model

Asymmetric design, more intelligence per dollar

DeepSeek released V4.1 Flash in September 2026, describing it as the smallest model in a new architecture family, with native vision. The new design aims for a higher ceiling, faster inference, more throughput and room to scale to larger models.

It is a 552B-parameter MoE built on a Causal-Encoder-Decoder design where input and output are asymmetric: 8B parameters are active on input and 16B on output. DeepSeek says the KV cache needs 1/4 the HBM and 1/8 the SSD of the previous generation, which cuts the cache costs that dominate agent workloads. In October DeepSeek updated it to V4.1-Flash-1017, citing clear gains on project-level coding.

On AnyAIGC, deepseek-v4.1-flash runs on the OpenAI-compatible /v1/chat/completions endpoint with text and image input. It also works directly in Claude Code, at one rate all day with no concurrency cap.

Quick start

Get started with the DeepSeek V4.1 Flash API

  1. Sign up and add credit: create an account at anyaigc.ai. Top up from $1; your balance works across every model on the platform.
  2. Create an API key: create a key in the console, copy the sk- key, and store it in the ANYAIGC_API_KEY environment variable.
  3. Send a request: call POST https://anyaigc.ai/v1/chat/completions with model set to deepseek-v4.1-flash and an Authorization: Bearer header. With the OpenAI SDK, just set base_url to https://anyaigc.ai/v1.

Parameters: DeepSeek says the V4 series thinks by default. The thinking field in the request body turns it on or off ({"type": "enabled"} or {"type": "disabled"}), and reasoning_effort sets the depth (officially low / high / max). Thinking tokens count as output and show up in usage.completion_tokens_details.reasoning_tokens. Sampling parameters such as temperature have no effect in thinking mode.

See the Chat Completions API reference for every parameter. Swap the model name in the doc examples for the DeepSeek model ID you want.

FAQ

DeepSeek V4.1 Flash API FAQ

How much does the DeepSeek V4.1 Flash API cost?

deepseek-v4.1-flash on AnyAIGC is billed per token: $0.1215 per 1M input tokens, $0.4860 per 1M output tokens and $0.0024 per 1M cache-hit tokens. DeepSeek's official off-peak USD price is $0.15 input, $0.60 output and $0.003 cache hit, and it doubles at peak times. Output includes thinking tokens. Live prices are shown in the model catalog.

Does AnyAIGC have peak and off-peak pricing?

No. The official DeepSeek API uses time-of-day pricing: weekdays 01:00–04:00 and 06:00–10:00 UTC (9:00–12:00 and 14:00–18:00 Beijing time) is peak time, and peak prices are double the off-peak prices. On AnyAIGC, deepseek-v4.1-flash is billed at one rate around the clock. That rate is about 60% off the official peak price. Live prices are shown in the model catalog.

What is new in DeepSeek V4.1 Flash?

According to DeepSeek, V4.1 Flash is the smallest model in its new architecture family: a 552B-parameter MoE with an asymmetric Causal-Encoder-Decoder design, 8B active parameters on input and 16B on output, and native vision. DeepSeek says its KV cache needs 1/4 the HBM and 1/8 the SSD of the previous generation, which sharply cuts caching costs for agent workloads.

Is V4.1 Flash better than V4 Pro?

DeepSeek says that across multiple tests, V4.1 Flash now beats V4 Pro on performance, cost, speed and total task time. Its model card reports DeepSWE v1.1 at 74.2 vs. 62.7 and Terminal-Bench 2.1 at 90.6 vs. 87.9. On AnyAIGC, V4.1 Flash input costs $0.1215, about a quarter of V4 Pro ($0.5346).

Does DeepSeek V4.1 Flash accept images? How do I send one?

Yes. Add an {"type": "image_url", "image_url": {"url": ...}} block to the messages[].content array. The url can be a public image URL or a Base64 data URL.

How long is the context? Does it support thinking mode?

DeepSeek lists a 1M-token context and up to 384K output tokens for V4.1 Flash. It supports both thinking and non-thinking modes (thinking is on by default), plus tool calls and JSON output.

Can I use DeepSeek V4.1 Flash in Claude Code?

Yes. DeepSeek models on AnyAIGC support both the OpenAI and the Anthropic API formats. In the env block of ~/.claude/settings.json, set ANTHROPIC_BASE_URL to https://anyaigc.ai, ANTHROPIC_AUTH_TOKEN to your API key and ANTHROPIC_MODEL to deepseek-v4.1-flash, then run claude. You pay per token.
