Get started with the GPT Image API in three steps

  1. Sign up: create an AnyAIGC account. New accounts get 2 million tokens of trial credit, and top-ups start at $1.
  2. Create an API key: generate a key in the console and store it in the ANYAIGC_API_KEY environment variable.
  3. Send a request: call https://anyaigc.ai/v1/images/generations with model set to gpt-image-2.5-flare. Use /v1/images/edits to edit images.

To switch models, change only the model field: gpt-image-2.5-sunburst, gpt-image-2.5-flare, gpt-image-2, or a per-image -c version. Do not send n or mask to -c versions.

The output format field is format (png / jpeg / webp), and the response returns data[0].url. Pass response_format=b64_json to get base64 instead. See the generations docs and edits docs for every parameter.

GPT Image API FAQ

How much does the GPT Image API cost?

Token-billed models: GPT Image 2.5 Sunburst and Flare cost $2.9700 for text input, $4.7520 for image input and $17.8200 for image output per 1M tokens, about 41% off list. GPT Image 2 costs $0.3971, $0.6354 and $2.3830, about 92% off list. Per-image -c versions: gpt-image-2.5-sunburst-c and gpt-image-2.5-flare-c are $0.0159 per 1K image and $0.0199 per 2K/4K image; gpt-image-2-c is $0.0119 and $0.0149. See the model catalog for live prices.

What is the difference between Sunburst, Flare and GPT Image 2?

Sunburst and Flare make up GPT Image 2.5, released by OpenAI in September 2026. OpenAI positions Sunburst as the model with the highest editing precision and Flare as the fastest high-quality model for everyday work. They share the same official token rates and both add xhigh and max quality levels. GPT Image 2 is the previous generation, released in April 2026, with low, medium, high and auto quality.

Token billing or per-image billing (-c): which should I pick?

With token billing, cost depends on size and quality: small low-quality images are very cheap, and cost rises with quality and resolution. The -c versions charge a flat price per image at any quality (1K and 2K/4K tiers), but return one image per request and do not support n, mask or transparent backgrounds. At 1024×1024 and high quality, GPT Image 2.5 costs about $0.0313 per image with token billing versus $0.0159 on -c.

Which endpoints are supported? Can I edit images?

Every GPT Image model, including the per-image -c versions, supports POST /v1/images/generations (text to image) and POST /v1/images/edits (image to image and multi-image compositing). Edits accept fewer than 16 reference images, 50MB in total. Token-billed models also support inpainting with a mask. See the AnyAIGC API docs for every field.

Are there concurrency limits? Does it work from mainland China?

AnyAIGC sets no concurrency limit on the whole GPT Image lineup, and every account gets this by default. The base URL is https://anyaigc.ai/v1, which is tuned for networks in mainland China, so you usually do not need a proxy. Billing is in USD, you can pay with WeChat Pay, Alipay, USDT or a credit card, and the same key works for 300+ other models.
