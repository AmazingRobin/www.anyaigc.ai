What is Nano Banana 2.1

Nano Banana 2.1 is an image generation and editing model Google released on October 6, 2026. Its official name is Gemini Nano Banana 2.1, and it upgrades Nano Banana 2 (Gemini 3.1 Flash Image). It keeps Flash-class speed and cost while improving image quality, text rendering and character consistency in multi-turn conversations.

On AnyAIGC the model ID is gemini-nano-banana-2.1, billed per image from $0.0128; live 2K and 4K prices are in the model catalog. You do not need a Google account or an overseas credit card, and it works directly from mainland China.

What Nano Banana 2.1 can do

  • Sharper text

    Poster headlines, packaging copy, menus and infographic labels render cleanly, and you can set the type style and layout.

  • One-line edits

    Upload an image and say what to change: lighting, background, removing an object. Everything else stays put, and you can keep refining over several turns.

  • Compositing with consistent characters

    Up to 14 reference images, including 4 character images that keep people looking the same across shots.

  • Ultra-wide and tall ratios

    Supports 4:1, 8:1, 1:4 and 1:8. 2.1 fixes stitching at these ratios in 2K / 4K, so banners and long images come out clean.

Get started with the Nano Banana 2.1 API

  1. Sign up: create an AnyAIGC account. New accounts get 2 million tokens of trial credit, and top-ups start at $1.
  2. Create an API key: generate a key in the console and store it in the ANYAIGC_API_KEY environment variable.
  3. Send a request: call POST https://anyaigc.ai/v1beta/models/gemini-nano-banana-2.1:generateContent (native Gemini format). Projects already on the OpenAI SDK can use /v1/chat/completions with model set to gemini-nano-banana-2.1.

For faster responses without thinking, use the model name gemini-nano-banana-2.1-nothinking; for stronger composition reasoning, use -thinking.

Authenticate with Authorization: Bearer <API Key>. imageConfig.imageSize accepts 1K, 2K or 4K and defaults to 1K. response_format is a platform extension: set it to url to get a temporary fileData.fileUri link (non-streaming only); leave it out to get base64. When a request is blocked by safety filters, finishReason is SAFETY or PROHIBITED_CONTENT and no image is returned.

Nano Banana 2.1 API FAQ

How much does the Nano Banana 2.1 API cost?

On AnyAIGC, Nano Banana 2.1 is billed per image, from $0.0128 per image (the lowest price in the model catalog; live 2K and 4K prices are shown in the model catalog). Google lists it at $0.0336 / $0.0504 / $0.113 per image for 1K / 2K / 4K. You are billed per successful request.

What is Nano Banana 2.1 and when was it released?

Nano Banana 2.1 (Gemini Nano Banana 2.1, model ID gemini-nano-banana-2.1) is an image generation and editing model Google released on October 6, 2026, as the upgrade to Nano Banana 2 (Gemini 3.1 Flash Image). Google positions it as the main high-efficiency model in the Nano Banana line.

How is Nano Banana 2.1 different from Nano Banana 2?

2.1 improves image quality, text rendering and character consistency across multi-turn edits, and fixes stitching issues at extreme ratios such as 1:4, 4:1, 1:8 and 8:1 in 2K / 4K. It also costs less per image. 2.1 drops the 512px (0.5K) tier and supports 1K, 2K and 4K only. The API is identical, so migrating means changing model to gemini-nano-banana-2.1.

Should I use Nano Banana 2.1 or Nano Banana Pro?

Pick 2.1 for everyday images, batch jobs and ultra-wide ratios; it costs less (from $0.0128 / image). Pick Pro (from $0.0328 / image) for complex layouts, dense text and commercial assets that need stronger reasoning and detail.

Which resolutions and aspect ratios are supported?

imageConfig.imageSize accepts 1K, 2K or 4K and defaults to 1K; 512 is not supported. imageConfig.aspectRatio supports 14 ratios: 1:1, 2:3, 3:2, 3:4, 4:3, 4:5, 5:4, 9:16, 16:9, 21:9, 1:4, 4:1, 1:8, 8:1. For example, 16:9 renders at 2752×1536 in 2K and 5504×3072 in 4K.

How many reference images can I upload? Can I turn thinking on or off?

Up to 14 reference images per request: up to 10 object images and 4 character images. Thinking is controlled with thinkingConfig.thinkingLevel, which accepts minimal and high; thinkingBudget is not supported. You can also append -thinking or -nothinking to the model name.

Are there concurrency limits? Does it work from mainland China?

AnyAIGC sets no concurrency limit on Nano Banana 2.1, and every account gets this by default. The base URL is https://anyaigc.ai, which is tuned for networks in mainland China, so you usually do not need a proxy, a Google account, or an overseas credit card. The same key works for 300+ other models.
