GPT Image 2.5 Flare: fast without losing quality

GPT Image 2.5 Flare shipped alongside Sunburst when OpenAI released GPT Image 2.5 in September 2026. OpenAI describes it as the fastest high-quality model for everyday image generation, rating its performance as Higher and its speed as Very fast.

Flare uses the same parameters as Sunburst: text and image input, image output, quality from low to max, and flexible sizes as long as the longest edge is at most 3840px, both sides are multiples of 16, the aspect ratio is no wider than 3:1, and the total pixel count is between 655,360 and 8,294,400. The snapshot is gpt-image-2.5-flare-2026-09-08.

On AnyAIGC, Flare and Sunburst cost the same. At low quality an image costs a fraction of a cent, which suits drafts, bulk assets and real-time generation inside your product. For a fixed cost per image, use gpt-image-2.5-flare-c at $0.0159 per 1K image.

GPT Image 2.5 Flare API FAQ

How much does the GPT Image 2.5 Flare API cost?

On AnyAIGC, gpt-image-2.5-flare is billed per token: $2.9700 for text input, $4.7520 for image input and $17.8200 for image output per 1M tokens, with cached text input at $1.1880 and cached image input at $1.9010. OpenAI lists $5.00, $8.00 and $30.00. A 1024×1024 image at medium quality costs about $0.0078 in image output (about $0.0132 at list). See the model catalog for live prices.

What is the difference between Flare and Sunburst?

Both are GPT Image 2.5, with the same official token rates and quality from low to max. Flare is built for speed (OpenAI rates it Very fast, performance Higher) and suits everyday and bulk generation. Sunburst is built for editing precision (performance Highest, speed Medium). They cost the same on AnyAIGC.

Which sizes, quality levels and formats are supported?

Common sizes are 1024×1024, 1536×1024, 1024×1536, 2048×2048, 2048×1152, 3840×2160, 2160×3840 and auto. Custom sizes work as long as the longest edge is at most 3840px, both sides are multiples of 16, the aspect ratio is no wider than 3:1, and the total pixel count is between 655,360 and 8,294,400. Quality levels are low, medium, high, xhigh, max and auto. Pick png, jpeg or webp with the format field, and get back an image URL or base64. The lowest price covers custom sizes; transparent backgrounds cost more, as listed in the model catalog.

How do I do image-to-image edits and inpainting?

Call POST /v1/images/edits with multipart/form-data. The image field accepts fewer than 16 reference images, 50MB in total. For inpainting, also send a mask: its transparent areas are what gets redrawn, and it must be a PNG under 4MB with the same size as the first image. See the edits docs for parameters.

Is there a per-image version? How is gpt-image-2.5-flare-c priced?

Yes. gpt-image-2.5-flare-c on AnyAIGC is the per-image version of GPT Image 2.5 Flare. It uses the same endpoints; only the model field changes. Each image has a flat price at any quality: $0.0159 for 1K output and $0.0199 for 2K and 4K output. Each request returns one image, and n, mask and transparent backgrounds are not supported. At high quality and above or larger sizes, per-image billing is usually cheaper.

Are there concurrency limits? Does it work from mainland China?

AnyAIGC sets no concurrency limit on gpt-image-2.5-flare, and every account gets this by default. The base URL is https://anyaigc.ai/v1, which is tuned for networks in mainland China, so you usually do not need a proxy. Billing is in USD, you can pay with WeChat Pay, Alipay, USDT or a credit card, and the same key works for 300+ other models.
