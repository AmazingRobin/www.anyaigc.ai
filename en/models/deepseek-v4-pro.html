About the model

The 1.6T-parameter V4 flagship

DeepSeek released the V4 preview in April 2026 with two models, V4 Pro and V4 Flash, and made a 1M-token context the default. V4 Pro reached general availability on August 13 with three reasoning effort levels: low, high and max.

V4 Pro is an MoE with 1.6T total and 49B active parameters. It uses a hybrid of Compressed Sparse Attention and Heavily Compressed Attention, was pretrained on 32T tokens, and has open weights under the MIT license. It offers a 1M-token context, up to 384K output tokens, and both thinking and non-thinking modes, with thinking on by default.

After V4.1 Flash shipped in September, DeepSeek briefly planned to retire V4 Pro, then said it would keep serving it with billing unchanged. On AnyAIGC, deepseek-v4-pro runs on the OpenAI-compatible /v1/chat/completions endpoint and works directly in Claude Code, at one rate all day with no concurrency cap.

Quick start

Get started with the DeepSeek V4 Pro API

  1. Sign up and add credit: create an account at anyaigc.ai. Top up from $1; your balance works across every model on the platform.
  2. Create an API key: create a key in the console, copy the sk- key, and store it in the ANYAIGC_API_KEY environment variable.
  3. Send a request: call POST https://anyaigc.ai/v1/chat/completions with model set to deepseek-v4-pro and an Authorization: Bearer header. With the OpenAI SDK, just set base_url to https://anyaigc.ai/v1.

Parameters: DeepSeek says the V4 series thinks by default. The thinking field in the request body turns it on or off ({"type": "enabled"} or {"type": "disabled"}), and reasoning_effort sets the depth (officially low / high / max). Thinking tokens count as output and show up in usage.completion_tokens_details.reasoning_tokens. Sampling parameters such as temperature have no effect in thinking mode.

See the Chat Completions API reference for every parameter. Swap the model name in the doc examples for the DeepSeek model ID you want.

Claude Code

Use DeepSeek V4 Pro in Claude Code

Point Claude Code at DeepSeek V4 Pro: edit one config file and your terminal coding agent runs on V4 Pro, billed per token.

  1. Install Claude Code: use the official installer, for example curl -fsSL https://claude.ai/install.sh | bash on macOS or Linux.
  2. Add the config: edit ~/.claude/settings.json, add the env block below, and replace ANTHROPIC_AUTH_TOKEN with the key you created on AnyAIGC.
  3. Start coding: run claude in your project folder. Type /model to confirm the current model is deepseek-v4-pro.

Save on subtasks: the config sets ANTHROPIC_DEFAULT_HAIKU_MODEL to deepseek-v4.1-flash, so Claude Code sends lightweight subtasks to the cheaper model while the main task stays on V4 Pro.

For full steps and common errors, see the Claude Code setup guide. Swap the model name in the guide for deepseek-v4-pro.

FAQ

DeepSeek V4 Pro API FAQ

How much does the DeepSeek V4 Pro API cost?

deepseek-v4-pro on AnyAIGC is billed per token: $0.5346 per 1M input tokens, $1.6038 per 1M output tokens and $0.0178 per 1M cache-hit tokens. DeepSeek's official off-peak USD price is $0.66 input, $1.98 output and $0.022 cache hit, and it doubles at peak times. Output includes thinking tokens. Live prices are shown in the model catalog.

Does AnyAIGC have peak and off-peak pricing?

No. The official DeepSeek API uses time-of-day pricing: weekdays 01:00–04:00 and 06:00–10:00 UTC (9:00–12:00 and 14:00–18:00 Beijing time) is peak time, and peak prices are double the off-peak prices. On AnyAIGC, deepseek-v4-pro is billed at one rate around the clock. That rate is about 60% off the official peak price. Live prices are shown in the model catalog.

Is DeepSeek V4 Pro being retired?

Not at this time. On September 10, 2026 DeepSeek announced a plan to retire V4 Pro, then said in its official changelog that, in response to user demand, it will keep serving the V4 Pro API after September 14 with billing unchanged.

Should I use V4 Pro or V4.1 Flash?

DeepSeek says V4.1 Flash now beats V4 Pro on performance, cost, speed and total task time. Its input price is about a quarter of V4 Pro's and it accepts images, so try it first on new projects. If your prompts and workflows are already tuned for V4 Pro in production, you can keep using V4 Pro.

How do I set V4 Pro's reasoning effort?

The August V4 Pro GA release added three reasoning effort levels: low, high and max. Thinking is on by default at high. Set the level with reasoning_effort, or turn thinking off with {"type": "disabled"} in the thinking field. See the quick start on this page for an example.

What are V4 Pro's parameters and context length?

DeepSeek lists V4 Pro as an MoE with 1.6T total and 49B active parameters, a hybrid attention design and 32T pretraining tokens. It has a 1M-token context and up to 384K output tokens, accepts text only, and its weights are open under the MIT license.

Can I use DeepSeek V4 Pro in Claude Code?

Yes. DeepSeek models on AnyAIGC support both the OpenAI and the Anthropic API formats. In the env block of ~/.claude/settings.json, set ANTHROPIC_BASE_URL to https://anyaigc.ai, ANTHROPIC_AUTH_TOKEN to your API key and ANTHROPIC_MODEL to deepseek-v4-pro, then run claude. You pay per token.

Are there concurrency or rate limits?

AnyAIGC does not cap concurrency for deepseek-v4-pro, and every user gets this by default. That suits batch jobs, CI pipelines and parallel agents.
