FAQ

Qwen Image 3.0 API FAQ

What is Qwen Image 3.0 for?

Create posters, infographics, and interfaces with up to 4.5K instruction tokens and detailed text layouts.

How is API usage priced?

Billing-unit base rate $0.00159/billing unit. Apply these multipliers: Output image ×18; Reference image ×2; output and reference fees are added. The base rate is not the final price of one output image. See the catalog for live prices.

Is concurrency capped?

AnyAIGC does not set a concurrency cap for this model; it is available by default.

How do I get an API key?

Create an AnyAIGC account, then create an API key in the console.

Can I use outputs commercially?

Commercial usage is governed by official Qwen and Alibaba Cloud terms.

Can AnyAIGC issue invoices, including VAT special invoices?

Yes. We issue Chinese VAT general and special invoices for the actual top-up amount.

Can my company pay by bank transfer and sign a contract?

Yes. Companies can pay by bank transfer, sign a service agreement, and receive dedicated support and technical contact.

Which payment methods are supported?

WeChat Pay, Alipay, USDT, and credit cards are supported; companies can also use bank transfer.

Is there free trial credit for new users?

Yes. New accounts get 2 million tokens of trial credit.

Can I get a refund on my balance?

Yes. Unused balance can be refunded with no fee.

Is my data safe?

Prompts and outputs are not persistently stored or used for training unless required by law.
