The same GPT-5.5, given more time and compute to think

OpenAI released GPT-5.5 and GPT-5.5 Pro on April 23, 2026, with API access the next day. In OpenAI's words, GPT-5.5 Pro "uses more compute to think harder and provide consistently better answers," and the launch post describes it as designed for extremely complex problems that demand very high accuracy. According to OpenAI, testers rated its answers as more comprehensive, better structured and more accurate than GPT-5.4 Pro, with strong results in business, law, education and data science.

GPT-5.5 Pro supports three reasoning efforts: medium, high (default) and xhigh. It has a 1,050,000-token context window, up to 128,000 output tokens, text and image input with text output, and a knowledge cutoff of December 1, 2025. OpenAI also publishes the dated snapshot gpt-5.5-pro-2026-04-23.

Per OpenAI, GPT-5.5 Pro is available only through the Responses API. It does not support Chat Completions or streaming, and it has no cached input discount. Some requests take several minutes, so OpenAI recommends background mode to avoid timeouts. On AnyAIGC, call https://anyaigc.ai/v1/responses. With the official OpenAI SDK you only change base_url to https://anyaigc.ai/v1.

Call the GPT-5.5 Pro API in three steps

  1. Sign up and top up: create an account at anyaigc.ai. Your balance works across every model.
  2. Create an API key: create a token in the console, copy the sk- key and store it in the ANYAIGC_API_KEY environment variable. Pro is expensive, so set a spend cap on this key.
  3. Send a request: call https://anyaigc.ai/v1/responses with model set to gpt-5.5-pro and Authorization: Bearer auth.

Responses API only. Per OpenAI, gpt-5.5-pro does not support /v1/chat/completions or streaming (stream). Call /v1/responses, set the effort in reasoning.effort, and raise your client timeout. Some requests take several minutes, so OpenAI recommends background mode (background: true) and polling for the result.

See the Responses reference for every parameter. Fields match the official OpenAI API.

GPT-5.5 Pro API FAQ

How much does the GPT-5.5 Pro API cost?

On AnyAIGC, gpt-5.5-pro is billed per token: $17.8200 per 1M input tokens and $106.9200 per 1M output tokens. OpenAI's list price is $30.00 input and $180.00 output, so AnyAIGC is about 59.4% of list (41% off). Per OpenAI, GPT-5.5 Pro has no cached input discount, so repeated input bills at the input rate.

What is the GPT-5.5 Pro model ID?

The model ID is gpt-5.5-pro. Put it in the model field of your request. OpenAI also publishes the dated snapshot gpt-5.5-pro-2026-04-23.

GPT-5.5 Pro vs GPT-5.5: what's the difference?

OpenAI describes GPT-5.5 Pro as a version of GPT-5.5 that uses more compute to think harder, aimed at extremely complex problems where accuracy matters most. In OpenAI's results, Pro scores 90.1% on BrowseComp against 84.4% for standard GPT-5.5, while standard GPT-5.5 scores higher on GDPval (84.9% vs 82.3%). Pro is Responses API only, has no streaming or cache discount, and supports medium, high (default) and xhigh effort. On AnyAIGC, GPT-5.5 is $0.2482 input and $1.4890 output, and Pro is $17.8200 input and $106.9200 output per 1M tokens. Start with standard GPT-5.5 and move up to Pro for hard problems where a wrong answer is costly.

GPT-5.5 Pro is expensive. How do I keep costs down?

Start with high effort and use xhigh only when needed, because reasoning tokens bill as output. Send only the context you need, since Pro has no cache discount. Cap each reply with max_output_tokens, set a spend cap on the API key you use for Pro in the console, and route routine questions to GPT-5.5 or GPT-6.1 Sol so only hard ones reach Pro.

Can I use Chat Completions or streaming?

No. Per OpenAI, gpt-5.5-pro is available only through the Responses API (including Batch). It does not support /v1/chat/completions or streaming. Call https://anyaigc.ai/v1/responses and set the effort in reasoning.effort.

Why are requests slow, and how do I avoid timeouts?

Pro spends more compute on reasoning, and OpenAI says some requests take several minutes. Raise your client timeout to 10 minutes or more. The safer option, as OpenAI recommends, is background mode: add background: true to the request, then poll responses.retrieve with the returned id until the status is no longer queued or in_progress.

Can I use GPT-5.5 Pro in Codex?

Yes, but it makes a poor default because it is slow and expensive. Run curl -fsSL https://www.anyaigc.ai/install.sh | bash -s codex to install (on Windows, irm https://www.anyaigc.ai/install.ps1 | iex), then add a [profiles.pro] block to ~/.codex/config.toml with model set to gpt-5.5-pro. Use your default model day to day and run codex --profile pro for hard tasks.

Is GPT-5.5 Pro deprecated? How long will it be available?

It is not deprecated. OpenAI has released the GPT-5.6 and GPT-6 families, but it has not announced a shutdown date for gpt-5.5-pro in the API, and it works normally on AnyAIGC today. For older Pro models that are deprecated, OpenAI's deprecations page points to GPT-5.6 Sol in pro mode (reasoning.mode: pro). For new projects, evaluate GPT-6 Astra or GPT-5.6 Sol.
