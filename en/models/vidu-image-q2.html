cURL
# 1. Create the task; the response contains task_id
curl -X POST "https://anyaigc.ai/ent/v2/reference2image" \
  -H "Authorization: Bearer $ANYAIGC_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
  "model": "vidu-image-q2",
  "images": [
    "https://www.anyaigc.ai/assets/models/vidu/skycity.webp"
  ],
  "prompt": "Use the sky city in the reference as the backdrop for a film poster at golden hour, with space for a title in the center.",
  "resolution": "1080p",
  "aspect_ratio": "16:9"
}'

# 2. Fetch the result with the task_id
curl "https://anyaigc.ai/ent/v2/tasks/$TASK_ID/creations" \
  -H "Authorization: Bearer $ANYAIGC_API_KEY"
Python
import json
import os
import time
import urllib.request

BASE = "https://anyaigc.ai"
HEADERS = {
    "Authorization": "Bearer " + os.environ["ANYAIGC_API_KEY"],
    "Content-Type": "application/json",
}


def call(method, path, body=None):
    data = json.dumps(body, ensure_ascii=False).encode("utf-8") if body else None
    request = urllib.request.Request(BASE + path, data=data, headers=HEADERS, method=method)
    with urllib.request.urlopen(request, timeout=60) as response:
        return json.load(response)


payload = {
    "model": "vidu-image-q2",
    "images": [
        "https://www.anyaigc.ai/assets/models/vidu/skycity.webp"
    ],
    "prompt": "Use the sky city in the reference as the backdrop for a film poster at golden hour, with space for a title in the center.",
    "resolution": "1080p",
    "aspect_ratio": "16:9"
}

created = call("POST", "/ent/v2/reference2image", payload)
task_id = (created.get("data") or created)["task_id"]
print("task_id:", task_id)

# Poll every 10 seconds until the task leaves the queue
for _ in range(120):
    result = call("GET", f"/ent/v2/tasks/{task_id}/creations")
    state = (result.get("data") or result).get("state") or (result.get("data") or result).get("status")
    if state not in ("created", "queueing", "processing"):
        break
    time.sleep(10)

# creations holds the video or image URLs; they expire, so download promptly
print(json.dumps(result, ensure_ascii=False, indent=2))

Replace the sample image with your own URL or Base64 (png, jpeg or webp, up to 50 MB). Read the status field from the live response; the example stops polling once the task leaves created, queueing or processing.

FAQ

Vidu Q2 Image API FAQ

Pricing, endpoints, results and enterprise access in one place.

How much does the Vidu Q2 Image API cost?

Text to image 1080p $0.0298 / image; Text to image 2K $0.0397 / image; Text to image 4K $0.0496 / image; Reference 1–3 images 1080p $0.0397 / image; Reference 1–3 images 2K $0.0596 / image; Reference 1–3 images 4K $0.0993 / image; Reference 4–7 images 1080p $0.0496 / image; Reference 4–7 images 2K $0.0794 / image; Reference 4–7 images 4K $0.1489 / image. Prices are in USD; check the model catalog for current rates.

Which endpoint should I call?

POST /ent/v2/reference2image with model set to vidu-image-q2. Creation returns a task_id; fetch the result with GET /ent/v2/tasks/{id}/creations. The base URL is https://anyaigc.ai and the key goes in Authorization: Bearer.

How many reference images, resolutions and aspect ratios are supported?

Omit images for text-to-image, or pass 1–7 for reference generation, billed in 1–3 and 4–7 image tiers. Resolution is 1080p (default), 2K or 4K. Aspect ratios are 16:9, 9:16, 1:1, 3:4, 4:3, 21:9, 2:3, 3:2 and auto. Passing viduq2 as the model is billed as vidu-image-q2.

How do I get the result?

Tasks are asynchronous. Keep the task_id, poll GET /ent/v2/tasks/{id}/creations, and read the video or image URL from creations when the task finishes. You can also pass callback_url when creating the task. Result URLs expire, so store files promptly.

Are there concurrency or RPM limits?

Vidu on AnyAIGC has unlimited concurrency for every account by default, with no fixed RPM cap. Video generation takes time, so set a polling interval and timeout in your application.

Can I use the output commercially?

Commercial use is governed by Vidu's (ShengShu Technology) official terms, and you need rights to any reference images, people or brand assets you upload. AnyAIGC is an independent API provider.
