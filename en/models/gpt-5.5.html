The GPT-5.5 flagship, with no rush to migrate

OpenAI released GPT-5.5 on April 23, 2026 and opened it in the API the next day. OpenAI positions it as a flagship for coding and complex professional work and calls it its "strongest agentic coding model to date," with 82.7% on Terminal-Bench 2.0. OpenAI also says its per-token latency matches GPT-5.4 while it uses noticeably fewer tokens on the same Codex tasks.

GPT-5.5 supports five reasoning efforts: none, low, medium (default), high and xhigh. It does not support max. It has a 1,050,000-token context window, up to 128,000 output tokens, text and image input with text output, and a knowledge cutoff of December 1, 2025. OpenAI also publishes the dated snapshot gpt-5.5-2026-04-23.

OpenAI has since released the GPT-5.6 and GPT-6 families, but gpt-5.5 has no deprecation notice in the API. On AnyAIGC, gpt-5.5 works on both /v1/chat/completions and /v1/responses. With the official OpenAI SDK you only change base_url to https://anyaigc.ai/v1, and the same key reaches 300+ other models, so upgrading later means changing only the model field.

Call the GPT-5.5 API in three steps

  1. Sign up and top up: create an account at anyaigc.ai. Your balance works across every model.
  2. Create an API key: create a token in the console, copy the sk- key and store it in the ANYAIGC_API_KEY environment variable.
  3. Send a request: call https://anyaigc.ai/v1/chat/completions or https://anyaigc.ai/v1/responses with model set to gpt-5.5 and Authorization: Bearer auth.

Tool calling works on both endpoints. gpt-5.5 supports function calling on /v1/chat/completions and /v1/responses, so existing Chat Completions code keeps working. For new integrations, multi-step agents and Codex, use the Responses API with the effort in reasoning.effort; on Chat Completions, use the top-level reasoning_effort.

See the Chat Completions reference and the Responses reference for every parameter. Fields match the official OpenAI API.

GPT-5.5 API FAQ

How much does the GPT-5.5 API cost?

On AnyAIGC, gpt-5.5 is billed per token: $0.2482 per 1M input tokens, $1.4890 per 1M output tokens and $0.0248 per 1M cached input tokens. OpenAI's list price is $5.00 input, $30.00 output and $0.50 cached input, so AnyAIGC is about 5% of list (95% off). When a request has more than 272K input tokens, the whole request is billed at 2x input and 1.5x output.

What is the GPT-5.5 model ID?

The model ID is gpt-5.5. Put it in the model field of your request. OpenAI also publishes a dated snapshot, gpt-5.5-2026-04-23, if you need to pin a version.

Is GPT-5.5 deprecated? How long will it be available?

No. OpenAI has released the newer GPT-5.6 and GPT-6 families, but there is no deprecation notice for gpt-5.5 in the API. OpenAI has not announced a shutdown date, and it is still fully callable today. You can keep using gpt-5.5 on AnyAIGC without changing any code. For new projects, consider GPT-6.1 Sol.

I get "model not found" for gpt-5.5. What should I check?

Check three things: the model field is exactly gpt-5.5 (lowercase, with a dot); base_url is https://anyaigc.ai/v1; and the request header is Authorization: Bearer with your AnyAIGC API key. In Codex, make sure model_provider in ~/.codex/config.toml points to AnyAIGC. If it still fails, contact 24/7 support.

Should I move from GPT-5.5 to GPT-5.6 Sol or GPT-6.1 Sol?

It depends. Integrations with tuned prompts that run well can stay on gpt-5.5, which also has a pinned snapshot. In OpenAI's GPT-5.6 launch results, GPT-5.6 Sol scores 88.8% on Terminal-Bench 2.1 against 85.6% for GPT-5.5. On AnyAIGC, GPT-5.6 Sol costs the same as GPT-5.5 ($0.2482 input, $1.4890 output), and GPT-6.1 Sol is cheaper at $0.0993 input and $0.4964 output per 1M tokens. For new projects, try GPT-6.1 Sol first.

Chat Completions or Responses API? Can I use tools?

Both endpoints work, and function calling is supported on both https://anyaigc.ai/v1/chat/completions and https://anyaigc.ai/v1/responses. Existing Chat Completions code works as is. For new integrations, multi-step agents and Codex, use the Responses API and set the effort in reasoning.effort: none, low, medium (default), high or xhigh.

Can I use GPT-5.5 in Codex?

Yes. Run curl -fsSL https://www.anyaigc.ai/install.sh | bash -s codex to install and configure it (on Windows, irm https://www.anyaigc.ai/install.ps1 | iex). The installer already sets the model to gpt-5.5, so it works right away. Or edit ~/.codex/config.toml yourself: set base_url to https://anyaigc.ai/v1, wire_api to responses and model to gpt-5.5, then put OPENAI_API_KEY in ~/.codex/auth.json.

AnyAIGC sets no concurrency limit on gpt-5.5. Every account gets this by default, so batch jobs and parallel agents run without queuing.
