01 · WHAT IS JEV-1.13.0

jev-1.13.0: the first public System One model

A chat LLM hands you a paragraph to parse. jev-1.13.0 hands your code a value it can use: a probability, an option or a score.

TypeSafe AI announced jev-1.13.0 on September 15, 2026 as the first public System One model. The name comes from Kahneman's System 1, the fast and intuitive side of human judgment. According to TypeSafe, Jev is trained with RLCD (Reinforcement Learning for Calibrated Decisions) and a parallel sampler, and it returns typed answers with calibrated probabilities rather than free text.

Think of it as a smart if-statement. Put the content to judge in state, define named, typed questions in questions, and every question is answered in parallel in a single request, with no cap on how many you ask. TypeSafe guarantees answers always match the type you requested, so there is no parsing or retry logic to write.

02 · QUESTION TYPES

Three question types in jev-1.13.0

Give each question a name in questions; the answer comes back under the same name.

  • type: noul

    noulprobability that it's true

    Returns a probability from 0 to 1. Ask with instructions, or describe the true and false cases in criteria.

    request 
    "is_urgent": {
  "type": "noul",
  "instructions": "Does this convey urgency?"
}
    answer 
    {"type": "noul", "noul": 0.95}
  • type: choice

    choicepick one option

    criteria maps each option to a description, from 1 to 255 options. Returns the chosen option, a confidence and a probability for every option.

    request 
    "department": {
  "type": "choice",
  "criteria": {"billing": "…", "sales": "…", "technical": "…"}
}
    answer 
    {"choice": "billing", "confidence": 0.81,
 "probabilities": {"billing": 0.88, "sales": 0, "technical": 0.12}}
  • type: score

    scorerate on a scale

    criteria is an ordered array of 2 to 10 levels. Returns a probability-weighted score (it can be a decimal), a confidence, a legend and per-level probabilities.

    request 
    "frustration": {
  "type": "score",
  "criteria": ["Calm", "Frustrated", "Very angry"]
}
    answer 
    {"score": 1.05, "confidence": 0.92,
 "probabilities": {"0": 0, "1": 0.95, "2": 0.05}}
  • need images or box?

    jev-1.14.0256k context, images, box

    On AnyAIGC, jev-1.13.0 takes text input with a 32k context. The experimental box type for locating objects in images, image input and the 256k context are on jev-1.14.0, at the same price.

    switch 
    "model": "jev-1.14.0"

04 · USE CASES

What jev-1.13.0 is good for

Anywhere your code needs a result it can branch on, sort by or alert from.

  • 01 · choice

    Classification and intent

    Sort messages, products or documents into fixed categories with a probability for each, and send low-confidence cases to a human or an LLM.

  • 02 · choice + noul

    Ticket routing

    One request answers which team owns it, whether it's urgent and how upset the customer is, so you know who gets it and where it goes in the queue.

  • 03 · score

    Risk scoring

    Score transactions, orders or accounts against your own levels. The score is a probability-weighted decimal, which makes thresholds easy.

  • 04 · noul

    Content moderation

    Check comments and user-generated content for policy violations, with each rule as its own question answered in parallel.

  • 05 · noul

    LLM guardrails

    Add a check before and after your LLM: detect jailbreaks and prompt injection, or confirm an answer sticks to the sources you provided.

  • 06 · score

    LLM-as-judge grading

    Take over part of your LLM-as-judge evals and grade answers on a scale, paying for input only. The arXiv paper found rubric-style quality judgments to be a weak spot, so spot-check first.

  • 07 · if

    Smart if-statements

    Pull conditions out of text: is this a refund request, does it mention a competitor, does the customer want a call back. Wire the answer straight into your logic.

  • 08 · map-reduce

    Large-scale batch jobs

    Label millions of records one by one and aggregate the results. Unlimited concurrency and free output suit offline batch work.

  • 09 · realtime

    Real-time apps

    TypeSafe reports typical responses around 100 ms, fast enough to sit inside a user-facing request path.

06 · LIMITATIONS

Know the limits before you ship

From TypeSafe's official guidance. Let code handle what code can compute, and ask one thing per question.

  • Reads wording literallyIt answers the question you wrote, not the one you meant. Word it precisely.
  • Not a calculatorSkip math and counting; do that in code.
  • Weak on dates and multi-hopCompare dates and break multi-step reasoning apart before asking Jev.
  • Irrelevant state hurtsA large state full of unrelated text lowers accuracy. Send only what matters.
  • Prompt injection riskUntrusted content in state can sway answers. Add safeguards for critical flows.
  • First-option biasChoice questions slightly favor the first option. Shuffle the order to check.
  • No text generationNo chat, summaries or rewrites. Pair it with an LLM when you need words.
  • English is strongestOther languages work but are weaker; jev-1.14.0 improves multilingual most.

FAQ

jev-1.13.0 API FAQ

What is jev-1.13.0?

jev-1.13.0 is the first public version of Jev, TypeSafe AI's System One model, announced on September 15, 2026. System One is named after Kahneman's fast, intuitive judgment. You send the content to judge (state) and a set of typed questions, and Jev returns typed answers with calibrated probabilities instead of free text. On AnyAIGC it has a 32k-token context and supports the noul, choice and score question types.

Is jev-1.13.0 deprecated?

No. A newer version, jev-1.14.0, was released on October 14, 2026, but jev-1.13.0 is still callable on AnyAIGC and no shutdown date has been announced. TypeSafe says it will give 60 days' notice before retiring jev-1.13.0. Existing integrations can keep running; for new projects we recommend jev-1.14.0.

How much does the jev-1.13.0 API cost?

On AnyAIGC, jev-1.13.0 costs $0.0227 per 1M input tokens and output is free. Billing is per token and only input tokens are charged. For example, 1,000,000 requests at 300 input tokens each is 300M tokens, which comes to $6.81. Concurrency is unlimited for all users. The live price is on the AnyAIGC model catalog.

What is the difference between jev-1.13.0 and jev-1.14.0?

jev-1.13.0 is the first public release (September 15, 2026) with a 32k-token context, text input and the noul, choice and score question types. jev-1.14.0 (October 14, 2026) brings small improvements across the board, with the biggest gain in multilingual according to TypeSafe. On AnyAIGC it has a 256k-token context and adds experimental image input and the box question type. Both cost the same.

Is the jev-1.13.0 API OpenAI-compatible?

No. Jev uses TypeSafe's System One API: POST https://anyaigc.ai/v1/systemone with model, state and questions in the body, and answers plus usage in the response. There are no messages or choices, so OpenAI SDKs cannot call it. Use plain HTTP with requests, fetch or cURL and the usual Authorization: Bearer <API Key> header. The call is synchronous: no streaming and no task polling.

What are jev-1.13.0's limitations?

According to TypeSafe, Jev reads wording literally, is not a calculator (avoid math and counting), is weak at date comparisons and multi-hop questions, loses accuracy when the state holds a lot of irrelevant text, can be affected by prompt injection, and slightly favors the first option in choice questions. It does not generate text. English works best; other languages work but are weaker. The third-party arXiv paper also found it weaker on low-resource languages, noisy labels and rubric-style quality judgments.
