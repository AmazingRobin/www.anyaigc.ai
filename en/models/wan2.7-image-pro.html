SPECS

Specs and how to choose it

Text-to-image supports 1K, 2K (default) and 4K, with custom sizes from 768×768 to 4096×4096. Editing and image sets are capped at 2K (2048×2048).

Standard mode returns 1 to 4 images. With image set mode (enable_sequential) enabled it returns up to 12, and the model decides the actual count.

It accepts 0 to 9 input images, each up to 20 MB with width and height between 240 and 8,000 pixels. Prompts can be up to 5,000 characters.

Thinking mode is on by default and applies only when image set mode is off and no image is provided. It improves output quality but takes longer.

This page lists Image output at $0.0645 / image, matching the pricing table above.

Compared with z-image-turbo: z-image-turbo always returns 1 image at up to 2048×2048, while wan2.7-image-pro reaches 4K for text-to-image and up to 12 images in image set mode.

Specs come from the vendor's official documentation (alibabacloud.com). The table on this page is the price, and the model catalog is authoritative for live rates.
