Quick start

Start with Chat Completions

  1. Create an account and an API key in the console.
  2. Set Base URL to https://anyaigc.ai/v1.
  3. Set model and send messages.
cURL · POST /v1/chat/completions
curl https://anyaigc.ai/v1/chat/completions \
  -H "Authorization: Bearer $ANYAIGC_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"qwen3.8-27b","messages":[{"role":"user","content":"Explain what a MoE model is in three sentences."}]}'
Python · OpenAI SDK
from openai import OpenAI
import os
client = OpenAI(api_key=os.environ["ANYAIGC_API_KEY"], base_url="https://anyaigc.ai/v1")
response = client.chat.completions.create(model="qwen3.8-27b", messages=[{"role":"user","content":"Explain what a MoE model is in three sentences."}])
print(response.choices[0].message.content)
