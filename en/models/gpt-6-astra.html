The top tier of GPT-6, billed at about 5% of list

OpenAI released GPT-6 Astra on September 3, 2026, opening the GPT-6 generation. Its model page describes it as "our most capable model for the most demanding work", and the announcement says Astra leads in computer use, web browsing, software engineering, cybersecurity, science and professional work. OpenAI's model catalog puts it plainly: if you're not sure where to start, use GPT-6 Astra.

Astra's list price per token is five times GPT-6.1 Sol's, but OpenAI says its estimated API cost per task came in lower than earlier models. It supports five reasoning efforts: low, medium, high, xhigh and max, with no none option. It has a 1,050,000-token context window, up to 128,000 output tokens, text and image input with text output, and a knowledge cutoff of April 30, 2026. OpenAI also runs Astra with misalignment monitoring: when a safety check pauses work, the API task stops.

On AnyAIGC, gpt-6-astra works on both /v1/chat/completions and /v1/responses. With the official OpenAI SDK you only change base_url to https://anyaigc.ai/v1, and the same key reaches 300+ other models, so lighter tasks can move to GPT-6.1 Sol or GPT-6 Luna without a new account.

Call the GPT-6 Astra API in three steps

  1. Sign up and top up: create an account at anyaigc.ai. Your balance works across every model.
  2. Create an API key: create a token in the console, copy the sk- key and store it in the ANYAIGC_API_KEY environment variable.
  3. Send a request: call https://anyaigc.ai/v1/chat/completions or https://anyaigc.ai/v1/responses with model set to gpt-6-astra and Authorization: Bearer auth.

We recommend /v1/responses for tool calling. OpenAI's model page does not state a tool-calling restriction for gpt-6-astra on Chat Completions, while GPT-6.1 Sol from the same generation does not support tool calling there. Use /v1/chat/completions for plain chat and streaming, and /v1/responses for function calling, computer use, web search and other tools, with the effort in reasoning.effort. Astra's rate is higher, so low or medium effort keeps simple tasks cheaper.

See the Chat Completions reference and the Responses reference for every parameter. Fields match the official OpenAI API.

GPT-6 Astra API FAQ

How much does the GPT-6 Astra API cost?

On AnyAIGC, gpt-6-astra is billed per token: $0.4964 per 1M input tokens, $2.4810 per 1M output tokens and $0.0496 per 1M cached input tokens. OpenAI's list price is $10.00 input, $50.00 output and $1.00 cached input, so AnyAIGC is about 5% of list (95% off). When a request has more than 272K input tokens, the whole request is billed at 2x input and cache rates and 1.5x output.

What is the GPT-6 Astra model ID?

The model ID is gpt-6-astra. Put it in the model field of your request. OpenAI has not published a dated snapshot for it.

GPT-6 Astra vs GPT-6.1 Sol: which should I use?

OpenAI says GPT-6.1 Sol comes close to GPT-6 Astra on agentic coding, computer use and professional work, at one fifth of Astra's standard price. In OpenAI's results Astra still leads on Terminal-Bench Science (68.1% vs 57.0%), at about $23.80 per task against $5.47 for GPT-6.1 Sol (both at list price). Start with GPT-6.1 Sol for everyday coding and agent work, and use GPT-6 Astra for the hardest reasoning, research and long end-to-end tasks. On AnyAIGC, GPT-6 Astra is $0.4964 input and $2.4810 output, and GPT-6.1 Sol is $0.0993 input and $0.4964 output per 1M tokens.

Why is there no GPT-6.1 Astra?

As of now, OpenAI has not released a GPT-6.1 Astra. GPT-6.1 only upgraded the Sol tier. OpenAI's current API lineup is gpt-6-astra, gpt-6.1-sol and gpt-6-luna, so the Astra tier is still gpt-6-astra. OpenAI's model catalog says: if you're not sure where to start, use GPT-6 Astra.

Chat Completions or Responses API? Can I use tools?

Both endpoints work. For plain chat and streaming, use https://anyaigc.ai/v1/chat/completions. OpenAI's model page does not state a tool-calling restriction for gpt-6-astra on Chat Completions, but GPT-6.1 Sol from the same generation does not support tool calling there, so we recommend https://anyaigc.ai/v1/responses for function calling and built-in tools, with the effort in reasoning.effort.

Can I use GPT-6 Astra in Codex?

Yes. Run curl -fsSL https://www.anyaigc.ai/install.sh | bash -s codex to install and configure it (on Windows, irm https://www.anyaigc.ai/install.ps1 | iex). The installer defaults to gpt-5.5, so change model in ~/.codex/config.toml to gpt-6-astra afterwards. Or edit ~/.codex/config.toml yourself: set base_url to https://anyaigc.ai/v1, wire_api to responses and model to gpt-6-astra, then put OPENAI_API_KEY in ~/.codex/auth.json.

Are there concurrency or rate limits?

AnyAIGC sets no concurrency limit on gpt-6-astra. Every account gets this by default, so batch jobs and parallel agents run without queuing.
