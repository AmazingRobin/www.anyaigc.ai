01 · WHAT IS JEV

What Jev is: decisions, not paragraphs

A chat LLM hands you text that you still have to parse. Jev hands your code a value it can use right away: a probability, an option or a score.

Jev is TypeSafe AI's first public System One model. The name borrows Daniel Kahneman's "System 1", the fast, intuitive judgment your brain makes without deliberating. According to TypeSafe, Jev is trained with RLCD (Reinforcement Learning for Calibrated Decisions) and a parallel sampler, and it returns typed answers with calibrated probabilities instead of free text.

Think of it as a smart if-statement. Put the content to judge in state, define named, typed questions in questions, and every question is answered in parallel in a single request, with no cap on how many you ask. TypeSafe guarantees answers match the type and schema you asked for, so there is no parsing or retry logic to write.

02 · QUESTION TYPES

Four question types: noul, choice, score, box

Give each question a name in questions, and its answer comes back under the same name.

  • type: noul

    noulprobability of true

    How likely is something true? Returns a probability from 0 to 1. Ask with instructions, or describe true and false in criteria.

    Request 
    "is_urgent": {
  "type": "noul",
  "instructions": "Does this convey urgency?"
}
    Answer 
    {"type": "noul", "noul": 0.95}
  • type: choice

    choicepick one option

    criteria maps each option name to a description, from 1 to 255 options. Returns the chosen option, a confidence and a probability for every option.

    Request 
    "department": {
  "type": "choice",
  "criteria": {"billing": "…", "sales": "…", "technical": "…"}
}
    Answer 
    {"choice": "billing", "confidence": 0.81,
 "probabilities": {"billing": 0.88, "sales": 0, "technical": 0.12}}
  • type: score

    scorerate on a scale

    criteria is an ordered array of 2 to 10 levels. Returns a probability-weighted score (it can be a decimal), a confidence, the legend and per-level probabilities.

    Request 
    "frustration": {
  "type": "score",
  "criteria": ["Calm", "Frustrated", "Very angry"]
}
    Answer 
    {"score": 1.05, "confidence": 0.92,
 "probabilities": {"0": 0, "1": 0.95, "2": 0.05}}
  • type: box · jev-1.14.0

    boxlocate an object in an image Experimental

    jev-1.14.0 only. Needs an image in assets and the header TypeSafe-Danger-Zone-Images: true. Per TypeSafe's docs, the answer gives the object's top, bottom, left and right edges as 0–1 fractions, plus a confidence that may be null.

    Request 
    "mug": {
  "type": "box",
  "instructions": "the coffee mug in `photo`"
}

What teams use Jev for

Anywhere your code needs a result it can branch on, sort by or alert on.

  • 01 · choice

    Classification and intent

    Sort messages, products or documents into fixed categories with a probability for each, and send low-confidence cases to a human or an LLM.

  • 02 · choice + noul

    Ticket routing

    One request decides the owning team, urgency and frustration level, so you know who gets the ticket and where it sits in the queue.

  • 03 · score

    Risk scoring

    Score transactions, documents or accounts against your own rubric. The score is a probability-weighted decimal, which makes thresholds easy.

  • 04 · noul

    Content moderation

    Check comments and user-generated content for violations, with each policy rule as its own question answered in parallel.

  • 05 · noul

    LLM guardrails

    Add a check before and after your LLM: flag jailbreaks and prompt injection, and verify that output sticks to the provided sources.

  • 06 · score

    Grading and evals

    Take over some LLM-as-judge work by scoring responses on a scale, paying for input only. A third-party paper found rubric-style quality judgments are a weak spot, so spot-check before relying on it.

  • 07 · if

    Smart if-statements

    Pull conditions out of text: is this a refund request, does it mention a competitor, does the customer want a callback. Then wire the answer straight into business logic.

  • 08 · map-reduce

    Batch over big datasets

    Label millions of records one by one and aggregate the results. Unlimited concurrency and free output suit offline batch jobs.

  • 09 · realtime

    Real-time apps

    According to TypeSafe, typical responses land around 100 ms, fast enough to sit inside a user-facing request path.

07 · LIMITATIONS

Know Jev's limits before you ship

From TypeSafe's official guidance. Let code handle what code can compute, and ask one thing per question.

  • Literal readingIt answers the question you wrote, not the one you meant. Word it precisely.
  • Not a calculatorSkip math and counting. Do that logic in code.
  • Dates and multi-hopCompare dates and break multi-step reasoning apart before asking Jev.
  • Irrelevant state hurtsLarge amounts of unrelated content lower accuracy. Send only what needs judging.
  • Prompt injectionUntrusted content in state can sway answers. Add safeguards where it matters.
  • First-option biasChoice questions lean slightly toward the first option. Shuffle the order to check.
  • No text generationNo chat, summaries or rewrites. Pair it with an LLM when you need words.
  • English firstEnglish works best. Other languages work, but accuracy is lower.

FAQ

Jev API FAQ

What is Jev?

Jev is TypeSafe AI's first public System One model. The name comes from Daniel Kahneman's "System 1", the fast, intuitive kind of judgment. You send Jev the content to judge (state) plus a set of typed questions (questions), and it returns typed answers with calibrated probabilities: which category something belongs to, how likely a statement is true, or where it lands on a scale. According to TypeSafe, Jev is trained with RLCD (Reinforcement Learning for Calibrated Decisions) and a parallel sampler.

Does Jev generate text? Can I use it as a chat model?

No. Jev does not generate text and has no chat, completion or summarization ability. It only answers the questions you define, and every answer matches the requested type (a probability, an option or a score). For writing, use an LLM such as GPT or Claude on the same platform, and use Jev for classification, routing, moderation and scoring.

Is the Jev API OpenAI-compatible? Can I use the OpenAI SDK?

No. Jev uses TypeSafe's own System One interface: POST https://anyaigc.ai/v1/systemone with a body of model, state and questions (plus assets for images). It returns answers and usage, with no messages or choices. OpenAI SDKs cannot call it, so send a plain HTTP request with requests, fetch or cURL. Authentication is still Authorization: Bearer <API Key>. The endpoint is synchronous, with no streaming and no task polling.

How much does the Jev API cost? Is output really free?

On AnyAIGC, jev-1.14.0 and jev-1.13.0 cost the same: $0.0227 per 1M input tokens, with free output. You pay per token and only input tokens are charged. Images are billed as regular input tokens. For example, 1,000,000 requests at 300 input tokens each is 300M tokens, which costs $6.81. Concurrency is unlimited for every user. Live prices are on the AnyAIGC model marketplace.

What is the difference between jev-1.14.0 and jev-1.13.0?

jev-1.13.0 is the first public version, released September 15, 2026, with a 32k-token context. jev-1.14.0 was released October 14, 2026. TypeSafe describes small improvements across the board, with the biggest gain in multilingual performance. On AnyAIGC it offers a 256k context and adds experimental image input and the box question type. Both cost the same, and we recommend jev-1.14.0 for new projects.

What is Jev's context length?

According to the AnyAIGC model marketplace, jev-1.13.0 has a 32k-token context and jev-1.14.0 has a 256k-token context. TypeSafe's docs require the request header TypeSafe-Danger-Zone-Long-Context: true for long context, and AnyAIGC passes that header through. TypeSafe also notes that long context is slower and less accurate than the default length, so split content when you can.

Can Jev take images? What is the box question type?

jev-1.14.0 supports experimental image input: put a base64-encoded PNG or JPEG in the request body's assets (up to 16 MiB, 280-1568 px per side), reference its placeholder from state, and send the header TypeSafe-Danger-Zone-Images: true. Box is a new experimental question type in 1.14 for locating an object in an image, and it needs the same header and an image. Images are billed as regular input tokens. TypeSafe says image features are not yet recommended for production.

Which languages does Jev support?

English works best. According to TypeSafe, other languages work but with lower accuracy, and jev-1.14.0 improves multilingual performance over 1.13. A third-party paper measured 86.7% accuracy for jev-1.13.0 on Belebele across 122 languages, with weaker results on low-resource languages. If accuracy matters, write your questions in English and test with your own samples before going live.

What are Jev's limitations?

According to TypeSafe: Jev reads your wording literally; it is not suited to math or counting ("Jev is not a calculator"), and it is weak at date comparisons and multi-hop questions; lots of irrelevant state lowers accuracy; prompt injection is a risk; choice questions have a slight bias toward the first option; and it cannot generate text. Compute what code can compute, and ask one thing per question.
