About the model

Eleven Flash v2: Light, fast announcements

Eleven Flash v2 is the light, fast text-to-speech model from ElevenLabs. In the official model table it lists English (en) only, with a stated latency of about 135ms and a 30,000-character limit per generation. The model catalog describes it as a light, fast announcement model with good value, suited to reading short lines.

Keep in mind that the official docs list English only, so for Chinese or other languages pick Eleven Flash v2.5, Multilingual v2 or v4.

On AnyAIGC, eleven_flash_v2 runs on POST /v1/audio/speech, billed by the number of input characters at half the price of Eleven v4, with no concurrency limit.

Quick start

Call the Eleven Flash v2 API in three steps

  1. Sign up and top up: create an account at anyaigc.ai. Top-ups start at $1, and the balance works across every model on the platform.
  2. Create an API key: create a token in the console, copy the key that starts with sk-, and store it in the ANYAIGC_API_KEY environment variable.
  3. Send a request: call POST https://anyaigc.ai/v1/audio/speech with model set to eleven_flash_v2 and voice set to an ElevenLabs voice_id, authenticate with Authorization: Bearer, and save the returned audio as mp3.

Parameter notes: the model ID is case-sensitive, so write eleven_flash_v2. voice takes an ElevenLabs voice_id, and an unknown or unavailable one returns 400. The reference lists input at 4,096 characters max, so split longer text. The examples save the response body as an mp3 file.

Full parameters are in the Create speech API reference. Swap the model name in the example for the Eleven model ID you want.

FAQ

Eleven Flash v2 API FAQ

How much does the Eleven Flash v2 API cost?

On AnyAIGC, eleven_flash_v2 is billed per character at $0.3240 per 10K characters, about 19% off the ElevenLabs list price of $0.40 per 10K characters. The price is fixed, with no subscription or monthly fee. Live prices are in the model catalog.

What is the Eleven Flash v2 model ID, and how does it relate to ElevenLabs?

The model ID is eleven_flash_v2 (case-sensitive), the same as the ElevenLabs model_id. AnyAIGC is an independent API provider that offers an OpenAI-style /v1/audio/speech call, and is not affiliated with ElevenLabs.

How do I choose between Eleven Flash v2 and the other Eleven models?

The platform has 7 Eleven voice models: Eleven v4 (flagship), Eleven v4 Turbo (low latency), Eleven v3, Eleven v3 Conversational, Eleven Multilingual v2, Eleven Flash v2.5 and Eleven Flash v2. Pick v4 for polished final audio, v4 Turbo for voice assistants, Multilingual v2 for long text and mixed languages, and Flash v2.5 for large subtitle batches. Audition the same text before you commit.

How do I get a Eleven Flash v2 API key?

Sign up and top up at anyaigc.ai, then create a token in the console. One key works for 300+ models on the platform, and you do not need a separate ElevenLabs account. Set model to eleven_flash_v2 in the request body.

How do I call the Eleven Flash v2 API, and what goes in voice?

Call POST https://anyaigc.ai/v1/audio/speech with the required model, input and voice fields. voice takes an ElevenLabs voice_id, and an unknown or unavailable voice_id returns 400. response_format supports mp3, opus, aac and flac. See the API reference.

How long can the text be for one Eleven Flash v2 request?

The ElevenLabs docs state a limit of 30,000 characters per generation for this model. The AnyAIGC Create speech reference lists the maximum length of input as 4,096 characters, so split longer text by that length and join the audio afterwards.

Does Eleven Flash v2 support Chinese, and how many languages?

In the official model table it lists English only, so use another model for Chinese. For the exact languages see the ElevenLabs model docs.

Does Eleven Flash v2 support Chinese?

In the official model table Flash v2 lists English (en) only, so do not pick it for Chinese or other languages. Use Eleven Flash v2.5, Eleven Multilingual v2 or Eleven v4 instead.

Is there a rate limit?

AnyAIGC sets no concurrency limit on eleven_flash_v2, and every account gets this by default, so batch generation and parallel tasks are fine. Billing is per character, with no monthly fee and no quota that resets on a time window.

Can I use my own cloned voice?

The API reference only says that voice takes an ElevenLabs voice_id. It does not say whether a cloned voice from your own ElevenLabs account can be used with an AnyAIGC key. Please ask AnyAIGC support to confirm.
