Call the Suno API in three steps

Async task flow: submit a request, get a task_id, then poll for the result. You can hear your first song in minutes.

  1. Sign up and add credit

    Create an account at anyaigc.ai and add credit. Your balance works across every model on the platform.

  2. Create an API key

    Create a token in the console and copy the key. The base URL is https://anyaigc.ai and auth uses Authorization: Bearer.

  3. Submit and poll

    POST to /suno/submit/music to get a task_id, then call GET /suno/fetch/{id} every 5–10 seconds and grab the audio URL when it finishes.

For more modes (extend, cover, Persona, sound effects, mashup, partial rewrite and more) and the full parameter list, see the AnyAIGC Suno API docs. mv accepts chirp-v3-5 through chirp-v6; check the docs for the current list.

Suno API FAQ

What you need to know about using the Suno API on AnyAIGC.

How much does the Suno API cost?

Fixed, pay-per-request pricing: generate song $0.1191, Max Mode $0.2382, sound effects $0.0238, vocal/instrumental separation $0.1191, full stem separation + MIDI $0.5956, and lyrics timeline $0.0596 per request. Generating lyrics, boosting music style, uploading reference audio and creating a Persona are free, and suno_uploads file upload is $0.000993 per request. No subscription, no monthly fee.

Does Suno have an official API?

As of October 2026, Suno does not offer a public self-serve official API. AnyAIGC is an independent third-party API platform that provides a unified interface to Suno music generation and is not affiliated with Suno, Inc.

How do I get a Suno API key?

Sign up at anyaigc.ai, add credit, and create an API key on the Tokens page in the console. The same key works for Suno and 300+ other models on the platform.

What are the Suno API rate limits?

The Suno API supports 300 RPM (300 requests per minute), which is good for batch soundtrack generation, UGC platforms and automated pipelines. Every user gets it by default, no application needed. Contact support if you need a higher quota.

Is the Suno API synchronous or asynchronous? How long does a song take?

It is asynchronous. Submit to /suno/submit/music to get a task_id, then poll /suno/fetch/{id} until the task finishes. Most songs complete in 1–3 minutes, depending on song length and current load.

What can I do with the Suno API?

Generate full songs with vocals or instrumentals from a text description or your own lyrics, generate lyrics and sound effects, boost style tags, upload reference audio, split vocals from instrumentals, separate every stem and export MIDI, get line-by-line lyrics timelines, and create artist-style Personas.

Which Suno model versions are supported?

Pick a version with the mv parameter: chirp-v3-0, chirp-v3-5, chirp-v4, chirp-v4-5, chirp-v5, chirp-v5-5, chirp-v6, chirp-v6-wild and chirp-v6-mini, covering Suno v3 through the latest v6 family. If mv is omitted, the default version is used. See the AnyAIGC docs for the current list.

What is the difference between Max Mode and standard generation?

Max Mode uses higher-quality generation settings and usually delivers better vocal detail and fuller arrangements, at 2x the standard price ($0.2382 per request). Use Max Mode for release-ready tracks and standard mode for demos and batch exploration.

Can I call the Suno API from mainland China?

Yes. AnyAIGC is optimized for networks in mainland China, so you can usually call the API without an extra proxy. Companies can pay by bank transfer and get VAT invoices.

Can AnyAIGC issue invoices, including VAT special invoices?

Yes. AnyAIGC issues invoices for the amount you top up, including Chinese VAT general invoices and VAT special invoices. Send your billing details to support to request one.

Can my company pay by bank transfer and sign a contract?

Yes. Companies can top up by corporate bank transfer and sign a service agreement, and get a dedicated support and technical contact. Contact AnyAIGC support to get started.

Can I use the generated music commercially?

Commercial rights depend on Suno's latest license terms and your specific use case. Review Suno's official terms before any commercial release, and contact AnyAIGC support if you have questions.

Which genres and languages are supported?

Suno covers major genres including pop, rock, electronic, lo-fi, hip-hop, folk and film scores, with lyrics and vocals in English, Chinese, Japanese, Korean and many other languages.
