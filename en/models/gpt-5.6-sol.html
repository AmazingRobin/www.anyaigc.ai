The GPT-5.6 flagship, billed at about 6% of the promo price

OpenAI released the GPT-5.6 family in ChatGPT, Codex and the API on July 9, 2026. The number marks the generation, and Sol, Terra and Luna are capability tiers. Sol is the flagship, roughly matching the unsuffixed model in earlier GPT-5 families, and the gpt-5.6 alias routes to it. OpenAI describes GPT-5.6 Sol as its "flagship model for complex professional work", with frontier results in coding, knowledge work, cybersecurity and science.

GPT-5.6 Sol supports none, low, medium (default), high, xhigh and max reasoning effort. OpenAI's launch post also describes an ultra setting that "coordinates multiple agents across parallel workstreams", running four agents in parallel by default. It has a 1,050,000-token context window, up to 128,000 output tokens, text and image input with text output, and a knowledge cutoff of February 16, 2026.

OpenAI launched it at $5 input and $30 output, and now charges a promotional $4 input, $0.40 cached input and $20 output, available at least through November 21, 2026. On AnyAIGC, gpt-5.6-sol works on both /v1/chat/completions and /v1/responses. With the official OpenAI SDK you only change base_url to https://anyaigc.ai/v1, and the same key also reaches 300+ other models.

Call the GPT-5.6 Sol API in three steps

  1. Sign up and top up: create an account at anyaigc.ai. Your balance works across every model.
  2. Create an API key: create a token in the console, copy the sk- key and store it in the ANYAIGC_API_KEY environment variable.
  3. Send a request: call https://anyaigc.ai/v1/chat/completions or https://anyaigc.ai/v1/responses with model set to gpt-5.6-sol and Authorization: Bearer auth.

Function tools work on both endpoints. Per OpenAI, gpt-5.6-sol supports function calling and structured outputs, so you can pass tools on /v1/chat/completions as well. Built-in tools such as web search, computer use, hosted shell and MCP, plus multi-agent (beta), are Responses API features, so switch to /v1/responses for those, with the effort in reasoning.effort.

See the Chat Completions reference and the Responses reference for every parameter. Fields match the official OpenAI API.

GPT-5.6 Sol API FAQ

How much does the GPT-5.6 Sol API cost?

On AnyAIGC, gpt-5.6-sol is billed per token: $0.2482 per 1M input tokens, $1.4890 per 1M output tokens and $0.0248 per 1M cached input tokens. OpenAI currently charges a promotional price of $4.00 input, $20.00 output and $0.40 cached input, available at least through November 21, 2026 (the launch price was $5 input and $30 output). AnyAIGC is about 6.2% of that promotional price (94% off). When a request has more than 272K input tokens, the whole request is billed at 2x input and 1.5x output.

What is the GPT-5.6 Sol model ID?

The model ID is gpt-5.6-sol. Put it in the model field of your request. Per OpenAI, the gpt-5.6 alias also routes to GPT-5.6 Sol. OpenAI has not published a dated snapshot for it.

GPT-5.6 Sol vs GPT-6.1 Sol: which should I use?

GPT-6.1 Sol is the newer generation. OpenAI lists it at $2 input and $10 output, below GPT-5.6 Sol's $4 / $20 promotional price. On AnyAIGC, GPT-6.1 Sol is $0.0993 input and $0.4964 output, and GPT-5.6 Sol is $0.2482 input and $1.4890 output per 1M tokens. Start new projects on GPT-6.1 Sol. Stay on GPT-5.6 Sol if your prompts and evals are already tuned for GPT-5.6, if you need the none reasoning effort (GPT-6.1 Sol does not support it), or if you need tool calling on Chat Completions (GPT-6.1 Sol does not support tools there).

Is GPT-5.6 Sol deprecated? How long will it be available?

No. OpenAI has released the newer GPT-6 Sol and GPT-6.1 Sol, but it has not announced a shutdown date for GPT-5.6 Sol, and the model still works normally in the API and on AnyAIGC. For new projects, use GPT-6.1 Sol.

Chat Completions or Responses API? Can I use tools?

Both endpoints work. Per OpenAI, gpt-5.6-sol supports function calling, structured outputs and streaming, so you can call function tools on https://anyaigc.ai/v1/chat/completions too. Built-in tools such as web search, computer use, hosted shell and MCP, plus multi-agent (beta), are Responses API features, so use https://anyaigc.ai/v1/responses for those and set the effort in reasoning.effort.

Can I use GPT-5.6 Sol in Codex?

Yes. Run curl -fsSL https://www.anyaigc.ai/install.sh | bash -s codex to install and configure it (on Windows, irm https://www.anyaigc.ai/install.ps1 | iex). The installer defaults to gpt-5.5, so change model in ~/.codex/config.toml to gpt-5.6-sol afterwards. Or edit ~/.codex/config.toml yourself: set base_url to https://anyaigc.ai/v1, wire_api to responses and model to gpt-5.6-sol, then put OPENAI_API_KEY in ~/.codex/auth.json.

Are there concurrency or rate limits?

AnyAIGC sets no concurrency limit on gpt-5.6-sol. Every account gets this by default, so batch jobs and parallel agents run without queuing.

Can I call the GPT-5.6 Sol API from mainland China?
