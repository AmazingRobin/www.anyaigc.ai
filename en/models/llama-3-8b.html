No local deployment required. Start with one text request, then connect your application.

POST https://anyaigc.ai/v1/chat/completionsRead the API reference ↗
cURL
curl --request POST "https://anyaigc.ai/v1/chat/completions" \
  --header "Authorization: Bearer $ANYAIGC_API_KEY" \
  --header "Content-Type: application/json" \
  --data '{
  "model": "llama-3-8b",
  "messages": [
    {
      "role": "user",
      "content": "Explain what an API is in three sentences."
    }
  ],
  "n": 1,
  "stream": false
}'
Python
import json
import os
import urllib.request

payload = {
  "model": "llama-3-8b",
  "messages": [
    {
      "role": "user",
      "content": "Explain what an API is in three sentences."
    }
  ],
  "n": 1,
  "stream": False
}
request = urllib.request.Request(
    "https://anyaigc.ai/v1/chat/completions",
    data=json.dumps(payload, ensure_ascii=False).encode("utf-8"),
    headers={
        "Authorization": "Bearer " + os.environ["ANYAIGC_API_KEY"],
        "Content-Type": "application/json",
    },
    method="POST",
)
with urllib.request.urlopen(request, timeout=120) as response:
    result = json.load(response)

print(json.dumps(result, ensure_ascii=False, indent=2))

The cURL example uses Bash / zsh syntax; Python uses only the standard library. With n=1 and stream=false, the response contains one reply candidate in choices plus usage. Set stream=true for SSE output.

Llama 3 8B API FAQ

Pricing, versions, integration and enterprise purchasing.

How much does Llama 3 8B API cost?

Input is $1.3500 and output is $1.3500 per million tokens, in USD. Models marked with the offer save 32% as displayed in the marketplace. Listed rates already include the discount; do not apply it again. Check the marketplace for current rates.

How are Llama and Ollama related? Which versions are listed?

Meta develops the Llama model family. Ollama is a model runtime and the provider category used in the AnyAIGC marketplace. These guides cover 12 models across Llama 2, 3, 3.1, 3.2 and 3.3. Commercial use is subject to Meta’s official terms.

Which model ID do I send, and what does a request return?

Use POST /v1/chat/completions with llama-3-8b and Bearer API key authentication. The examples set n=1 and stream=false to return one assistant reply candidate and token usage. The name llama is used for this overview.

Are concurrency or RPM limited? Do I need to install Ollama?

All users have unlimited concurrency and no fixed RPM cap by default. Call the AnyAIGC cloud API without installing Ollama or deploying the model locally. Your application should still handle network timeouts and API errors.

Which models accept images? What about language support?

The 11B and 90B Llama 3.2 Vision Instruct models are vision models; the other listed models are text models. Llama 3.1–3.3 officially support eight text languages, excluding Chinese. Image-text tasks officially support English. Evaluate other languages on your own data; these examples demonstrate text requests.

Can AnyAIGC issue invoices, including VAT special invoices?

Yes. AnyAIGC issues Chinese VAT general and special invoices based on the actual top-up amount. Contact the enterprise support team to arrange invoicing.

Can my company pay by bank transfer and sign a contract?

Yes. Corporate bank transfer, service contracts, dedicated support and a technical contact are available.

Which payment methods are supported?

You can top up with WeChat Pay, Alipay, USDT or a credit card. Companies can also pay by bank transfer and get VAT general or special invoices. Your balance is in USD and works across every model on the platform.

Is there free trial credit for new users?

Yes. New accounts get 2 million tokens of trial credit, so you can test before deciding to top up. Top-ups start at $1.

Can I get a refund on my balance?

Yes. Unused balance can be refunded with no fee. Contact support to start a refund.

Are these the real models? Is my data safe?

Requests go to official model channels, never cheaper or reverse-engineered substitutes. Unless the law requires it, we do not persistently store your prompts or outputs or use them for training, and the console shows tokens and cost for every request.
