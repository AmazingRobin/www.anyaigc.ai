About

Same base model, much stronger post-training

Zhipu calls GLM-5.3 its latest flagship, with across-the-board gains in complex software engineering and agent tasks. Zhipu says it uses the same base model as GLM-5.2, and every improvement comes from scaled-up post-training that builds on the reinforcement learning approach introduced with GLM-5.2.

The reported gains center on coding and agents: Zhipu's internal Z.ai Code Bench is 50% higher than GLM-5.2 while using fewer output tokens on the same tasks, and Terminal Bench 3.0 rose from 4.6 to 28.3. Zhipu also reports state-of-the-art results on the CyberGym vulnerability benchmark. It has a 1M-token context, up to 128K output, and thinking is always on.

On AnyAIGC, glm-5.3 runs on the OpenAI-compatible /v1/chat/completions endpoint and works directly in Claude Code. No Zhipu platform account or Coding Plan needed: you pay per token, with unlimited concurrency.

Quickstart

Connect to the GLM-5.3 API in three steps

  1. Sign up and add credit: create an account at anyaigc.ai. Top up from $1; your balance works across every model on the platform.
  2. Create an API key: create a key in the console, copy the value that starts with sk-, and store it in the ANYAIGC_API_KEY environment variable.
  3. Send a request: call POST https://anyaigc.ai/v1/chat/completions with model set to glm-5.3 and an Authorization: Bearer header. With the OpenAI SDK, just set base_url to https://anyaigc.ai/v1.

Tip: GLM-5.3 always thinks. Its reasoning comes back in the reasoning_content field, and reasoning_effort sets the depth. Zhipu's defaults are temperature=1.0 and top_p=0.95; if you tune them, change only one. In multi-turn chats and tool calls, send the full assistant message from the API (including reasoning_content and tool_calls) back in the next request unchanged.

See the Chat Completions reference for every parameter. Replace the model name in the docs examples with the GLM model ID you want.

Claude Code

Use GLM-5.3 in Claude Code

Switch Claude Code to GLM-5.3 by editing one config file, and code in your terminal with Zhipu's latest flagship, billed per token.

  1. Install Claude Code: use the official installer, for example curl -fsSL https://claude.ai/install.sh | bash on macOS or Linux.
  2. Add the config: edit ~/.claude/settings.json, add the env block below, and replace ANTHROPIC_AUTH_TOKEN with the key you created on AnyAIGC.
  3. Start coding: run claude in your project folder. Type /model to confirm the current model is glm-5.3.

Save on light tasks: the config sets ANTHROPIC_DEFAULT_HAIKU_MODEL to glm-5.3-flash, so Claude Code's lightweight subtasks use the cheaper model while the main work stays on GLM-5.3.

For the full walkthrough and common errors, see the Claude Code setup guide. Swap the model name in the guide for glm-5.3.

FAQ

GLM-5.3 API FAQ

How much does the GLM-5.3 API cost?

On AnyAIGC, glm-5.3 is billed per token: input $0.9450 per 1M tokens, output $2.9700 per 1M tokens, cache hit $0.1758 per 1M tokens. Zhipu's official USD prices are input $1.40, output $4.40 and cache hit $0.26, so AnyAIGC input and output cost about 67.5% of official (about 30% off). Output includes thinking tokens. See the model catalog for live pricing.

What is the GLM-5.3 model ID, and how large is the context?

The model ID is glm-5.3. Zhipu lists a 1M-token context window and up to 128K output tokens. It currently accepts text input only.

How is GLM-5.3 different from GLM-5.2?

Zhipu says GLM-5.3 uses the same base model as GLM-5.2, and every gain comes from scaled-up post-training. Reported changes: Z.ai Code Bench is 50% higher than GLM-5.2, Terminal Bench 3.0 rose from 4.6 to 28.3, and DeepSWE rose from 46.2 to 66.9. GLM-5.3 also always thinks and thinking cannot be turned off. On AnyAIGC both cost the same for input and output, and GLM-5.3 has a lower cache-hit price ($0.1758 vs $0.2362).

How do I adjust GLM-5.3's thinking depth? Can I turn thinking off?

GLM-5.3 always thinks, and Zhipu does not support turning it off. Use the reasoning_effort field in the request body to set depth: low, high or max (default max, which Zhipu recommends for coding). Use low on simple tasks to cut output tokens.

Does GLM-5.3 support tool calls and structured output?

Yes. Zhipu's docs list function calling, structured output (JSON), streaming and context caching. In multi-turn chats and tool calls, send the full assistant message (including reasoning_content and tool_calls) back in the next request unchanged.

Can I use GLM-5.3 in Claude Code?

Yes. In the env block of ~/.claude/settings.json, set ANTHROPIC_BASE_URL to https://anyaigc.ai, ANTHROPIC_AUTH_TOKEN to your API key, and ANTHROPIC_MODEL to glm-5.3. Then run claude. You pay per token, with no 5-hour quota window like a subscription plan.

Is GLM-5.3 open source?

Yes. Zhipu has published the GLM-5.3 weights on Hugging Face (zai-org/GLM-5.3) under the GLM-5.3 License. It is a permissive license overall, with one extra rule: companies with annual revenue above $10 billion that run model-as-a-service businesses must pass a Z.ai security review before commercial use. Calling the API through AnyAIGC means you do not have to host it yourself. Commercial use is governed by Zhipu AI's official terms.

AnyAIGC does not cap concurrency for glm-5.3, and every user gets this by default. That suits batch jobs, CI pipelines and parallel agents. Billing is per token, so there is no quota that resets on a time window like a subscription plan.
