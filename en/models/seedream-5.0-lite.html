Get started with the Seedream 5.0 lite API

  1. Sign up for AnyAIGC. New accounts get 2M free tokens, and you can top up from $1.
  2. Create an API key in the console and save it as the ANYAIGC_API_KEY environment variable.
  3. Send a request to POST https://anyaigc.ai/v1/images/generations (OpenAI-compatible) with model set to doubao-seedream-5-0-260128.

5.0 lite supports stream for image sets, and web search is enabled with tools: [{"type": "web_search"}] (see the AnyAIGC API docs for the current fields).

Authenticate with Authorization: Bearer <API Key>. The response looks like {"created": ..., "data": [{"url": ...}]}; set response_format to b64_json to get base64 instead. watermark defaults to true, so pass false explicitly for clean images. Field details are in the AnyAIGC Seedream API docs.

Seedream 5.0 lite API FAQ

How much does the Seedream 5.0 lite API cost?

On AnyAIGC, Seedream 5.0 lite (doubao-seedream-5-0-260128) starts at $0.0223 / image. Prices vary by resolution; live 2K, 3K and 4K rates are in the model catalog. An image set returns several images and is billed per image generated. You are billed per successful generation; live prices are in the model catalog.

What is Seedream 5.0 lite?

Seedream 5.0 lite is the lightweight model in the Seedream 5.0 generation, with the model ID doubao-seedream-5-0-260128 on AnyAIGC. Its official focus is deep thinking plus real-time retrieval: it reads intent more accurately, controls style and layout, and can pull in live information from the web. AnyAIGC added it in February 2026.

Which resolutions are supported? Can it output 4K?

Yes. Per the Volcano Engine Ark docs, 5.0 lite accepts size values of 2K, 3K and 4K, or pixel dimensions, with aspect ratios from 1:16 to 16:1.

How do image sets work, and how many images can I get?

Pass sequential_image_generation: "auto" and set the cap with sequential_image_generation_options.max_images (1–15). Text-only prompts return up to 15 images; with reference images, references plus generated images cannot exceed 15.

How many reference images can I send? Can it search the web?

image accepts up to 14 reference images. 5.0 lite is the only Seedream model with web search, which helps with holiday themes, trending topics and anything that needs current information.

Is there a concurrency limit? What do I need to sign up?

AnyAIGC sets no concurrency limit on Seedream 5.0 lite, and every account gets this by default. The base URL is https://anyaigc.ai. You do not need a Volcano Engine account or ID verification, and the same key also works with 300+ other models on the platform.
