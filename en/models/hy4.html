import os
from openai import OpenAI

Python streaming
# pip install openai
import os
from openai import OpenAI

client = OpenAI(api_key=os.environ["ANYAIGC_API_KEY"], base_url="https://anyaigc.ai/v1")

stream = client.chat.completions.create(
    model="hy4",
    messages=[{"role": "user", "content": "Introduce yourself in three sentences and say what tasks you are best at."}],
    stream=True,
)
for chunk in stream:
    if chunk.choices and chunk.choices[0].delta.content:
        print(chunk.choices[0].delta.content, end="", flush=True)
print()

FAQ

Hy4 API FAQ

How much does the Hy4 API cost, and how far below list price is it?

Billed per token in USD per 1M tokens: input $0.5630 (list $0.834), output $1.6880 (list $2.501), cache hit $0.0283 (list $0.042). Tencent Cloud's list price is ¥6 input, ¥18 output and ¥0.3 cache hit; USD list prices use about 7.19 CNY per USD. All three AnyAIGC rates are about 67.5% of list, roughly 32% off. See the model catalog for live rates.

What is the difference between Hy4 and Hy4 preview?

Per Tencent's release notes (2026-11-04), the official Hy4 adds vision and computer use for the first time, strengthens agent and long-horizon work, and cuts the hallucination rate in its own test from 15.76% on preview to 5.45%. Tencent also says API pricing is unchanged from preview. These figures come from the release notes; AnyAIGC has not re-tested them.

Does Hy4 accept image input?

Yes. Tencent says Hy4 adds vision for the first time. Send an image URL or base64 data in an image_url content part on POST /v1/chat/completions; the output is text. The AnyAIGC docs do not currently state image size or count limits, so follow the docs.

Which API endpoint should I use?

Both formats work: the OpenAI-compatible POST https://anyaigc.ai/v1/chat/completions and the Anthropic-style POST https://anyaigc.ai/v1/messages, both with Authorization: Bearer <API Key> and model set to hy4. With the OpenAI SDK, set base_url to https://anyaigc.ai/v1.

Is concurrency limited?

AnyAIGC offers Hy4 with unlimited concurrency for every account by default. Long-context and agent requests take longer, so set sensible timeouts and retries.

Can I use the output commercially?

Use of the model and its output is governed by Tencent Hunyuan's official terms. AnyAIGC is an independent API provider and is not affiliated with Tencent.

Can AnyAIGC issue invoices, including VAT special invoices?

Yes. AnyAIGC issues invoices for actual top-ups, including Chinese VAT general and VAT special invoices. Contact enterprise support to arrange them.

Can my company pay by bank transfer and sign a contract?

Yes. Companies can top up by corporate bank transfer, sign a service agreement, and work with dedicated support and a technical contact.

Which payment methods are supported?

You can top up with WeChat Pay, Alipay, USDT or a credit card. Companies can also pay by bank transfer and get VAT general or special invoices. Your balance is in USD and works across every model on the platform.

Is there free trial credit for new users?

Yes. New accounts get 2 million tokens of trial credit, so you can test before deciding to top up. Top-ups start at $1.

Can I get a refund on my balance?

Yes. Unused balance can be refunded with no fee. Contact support to start a refund.

Are these the real models? Is my data safe?

Requests go to official model channels, never cheaper or reverse-engineered substitutes. Unless the law requires it, we do not persistently store your prompts or outputs or use them for training, and the console shows tokens and cost for every request.
