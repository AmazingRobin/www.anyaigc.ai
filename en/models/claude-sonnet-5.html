Claude Sonnet 5 API FAQ

How much does the Claude Sonnet 5 API cost?

On AnyAIGC, claude-sonnet-5 is billed per token: $0.2382 per million input tokens, $1.191 per million output tokens, $0.2978 for 5-minute cache writes, $0.4765 for 1-hour cache writes, and $0.0238 for cache hits. Anthropic's list price is $2 input and $10 output, so AnyAIGC comes in at about 11.9% of list price.

What is the Claude Sonnet 5 model ID, and is the API Anthropic-compatible?

The model ID is claude-sonnet-5. Put it in the model field of your request body. The API is Anthropic-compatible: the endpoint is https://anyaigc.ai/v1/messages and the request body follows the Anthropic Messages format (model, max_tokens, system, messages, tools, cache_control, and so on). Authenticate with Authorization: Bearer followed by your API key. With the official SDK, just set the base URL to https://anyaigc.ai.

Can I use Claude Sonnet 5 in Claude Code?

Yes. In the env block of ~/.claude/settings.json, set ANTHROPIC_BASE_URL to https://anyaigc.ai, ANTHROPIC_AUTH_TOKEN to your API key, and both ANTHROPIC_MODEL and ANTHROPIC_DEFAULT_SONNET_MODEL to claude-sonnet-5, then run claude. You can also install and configure everything with one command: curl -fsSL https://www.anyaigc.ai/install.sh | bash.

How is prompt caching billed?

Add cache_control to a content block to enable caching. The first write is billed at the cache write rate ($0.2978 for 5 minutes or $0.4765 for 1 hour, per million tokens). After that, cached tokens cost only $0.0238 per million, about 10% of the regular input price. Caching works best for long system prompts, codebase context, and multi-turn agent tasks.

Are there concurrency or rate limits?

AnyAIGC sets no concurrency limit on claude-sonnet-5. Every account gets this by default, so it works well for batch jobs and running multiple agents in parallel.

What is Claude Sonnet 5 good at?

Anthropic says Sonnet 5 can make plans, use tools like browsers and terminals, and run autonomously, with performance close to Opus 4.8 at lower prices. It fits everyday coding and bug fixing, agentic tool use, computer use, and document-heavy knowledge work. In Anthropic's published results it scores 63.2% on SWE-bench Pro and 80.4% on Terminal-Bench 2.1.

Is Claude Sonnet 5 deprecated? How long can I keep using it?

It is not deprecated. Anthropic lists Claude Sonnet 5 as a legacy model (Active · Legacy) and commits to retiring it no earlier than June 30, 2027. You can still call claude-sonnet-5 on AnyAIGC today. For new projects, Anthropic's newer Claude Sonnet 5.5 (claude-sonnet-5-5) is the recommended choice.
