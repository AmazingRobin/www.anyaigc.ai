About the model

iFLYTEK Spark's early 2.x release

SparkDesk-v2.1 is an early 2.x API release of iFLYTEK's Spark cognitive model. The catalog describes it as a model with cross-domain knowledge and language understanding that carries out tasks through natural conversation, covering language understanding, knowledge Q&A, logical reasoning, math problem solving and code comprehension.

The current iFLYTEK Open Platform version table no longer lists this tier, so this page gives no official context window, maximum output or feature limits rather than print numbers without a source. It has the lowest price of the three on AnyAIGC, which suits workloads that already use it or low-cost tasks where quality matters less.

On AnyAIGC, SparkDesk-v2.1 uses the OpenAI-compatible /v1/chat/completions endpoint with a single Bearer key. For new projects, evaluate SparkDesk-v3.1 or SparkDesk-v3.5 first. Billing is per token with no concurrency limit.

Quickstart

Call the SparkDesk-v2.1 API in three steps

  1. Sign up and top up: create an account at anyaigc.ai. Top-ups start at $1, and the balance works across every model on the platform.
  2. Create an API key: make a token in the console, copy the key that starts with sk-, and store it in the ANYAIGC_API_KEY environment variable.
  3. Send a request: call POST https://anyaigc.ai/v1/chat/completions with model set to SparkDesk-v2.1 and Authorization: Bearer. With the OpenAI SDK, just set base_url to https://anyaigc.ai/v1.

Parameter tip: the model ID is case-sensitive, so write SparkDesk-v2.1. The response format matches OpenAI Chat Completions, and token counts for the request are in the usage field. The context is limited, so split or retrieve long documents before asking.

See the Chat Completions reference for every parameter. Swap the model name in the examples for the SparkDesk model ID.

FAQ

SparkDesk-v2.1 API FAQ

How much does the SparkDesk-v2.1 API cost?

On AnyAIGC, SparkDesk-v2.1 is billed per token: $8.7360 per million input tokens and $8.7360 per million output tokens, the same for both. Prices are fixed, with no subscription or monthly fee. Live prices are in the model catalog.

What is the SparkDesk-v2.1 model ID, and how does it relate to iFLYTEK Spark?

The model ID is SparkDesk-v2.1 (case-sensitive). It is a release of iFLYTEK's Spark cognitive model, and AnyAIGC exposes it through an OpenAI-compatible API. It is unrelated to Apache Spark or the Spark email app.

How do I choose between SparkDesk-v2.1 and the other SparkDesk models?

SparkDesk-v3.5 and SparkDesk-v3.1 are the other two in the series. A higher version number maps to a newer iFLYTEK tier: v3.5 is Max, v3.1 is Pro, and v2.1 is an early 2.x release. Pick v3.5 if you need a system prompt. Consider v2.1 when cost matters most and quality needs are modest, and test on your own data before launch. All three charge the same for input and output on AnyAIGC.

Is SparkDesk compatible with the OpenAI API, and how do I call it?

Yes. SparkDesk-v2.1 uses POST https://anyaigc.ai/v1/chat/completions, and requests and responses match OpenAI Chat Completions. With the official OpenAI SDK, set base_url to https://anyaigc.ai/v1. You do not need iFLYTEK's WebSocket signing, only Authorization: Bearer.

How large is the SparkDesk-v2.1 context window?

The current iFLYTEK Open Platform version table no longer lists the 2.x release, so there is no official context figure to quote. Test with your real input lengths, or choose SparkDesk-v3.1 or SparkDesk-v3.5 when you need documented limits.

Is there a rate limit?

AnyAIGC sets no concurrency limit on SparkDesk-v2.1, and every account gets this by default, so batch jobs and parallel tasks are fine. Billing is per token, with no monthly fee or time-window quota.

Is SparkDesk-v2.1 deprecated?

The current iFLYTEK Open Platform version table no longer lists the 2.x release, so treat it as a legacy model. SparkDesk-v2.1 is still callable in the AnyAIGC model catalog today. New projects should use SparkDesk-v3.1 or SparkDesk-v3.5; check the catalog for current availability.

How do I get a SparkDesk-v2.1 API key?

Sign up and top up at anyaigc.ai, then create a token in the console. One key works for 300+ models on the platform, so you do not need an iFLYTEK Open Platform APPID, APIKey and APISecret. Set model to SparkDesk-v2.1 in the request body.

Can AnyAIGC issue invoices, including VAT special invoices?

Yes. AnyAIGC can issue invoices for every top-up, including Chinese VAT general invoices and VAT special invoices. Send your invoicing details to support.

Can my company pay by bank transfer and sign a contract?

Yes. You can top up by corporate bank transfer and sign a service agreement, with a dedicated support contact and technical contact. For company purchases, contact AnyAIGC support.

Which payment methods are supported?

You can top up with WeChat Pay, Alipay, USDT or a credit card. Companies can also pay by bank transfer and get VAT general or special invoices. Your balance is in USD and works across every model on the platform.

Is there free trial credit for new users?

Yes. New accounts get 2 million tokens of trial credit, so you can test before deciding to top up. Top-ups start at $1.

Can I get a refund on my balance?

Yes. Unused balance can be refunded with no fee. Contact support to start a refund.

Are these the real models? Is my data safe?

Requests go to official model channels, never cheaper or reverse-engineered substitutes. Unless the law requires it, we do not persistently store your prompts or outputs or use them for training, and the console shows tokens and cost for every request.

Are my prompts used for training?

No. Unless the law requires it, AnyAIGC does not persistently store your prompts or outputs and does not use them for training. Requests are encrypted with HTTPS. See the AnyAIGC Privacy Policy. The model vendor's own data policy is governed by iFLYTEK's terms.
