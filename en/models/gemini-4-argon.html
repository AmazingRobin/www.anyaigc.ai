About the model

A new Gemini 4 frontier model, not a fine-tune of a prior one

Google released Gemini 4 Argon to general availability on October 13, 2026. The model card calls it a new frontier model that "is not a modification or a fine-tune of a prior model." It uses a sparse mixture-of-experts architecture and natively accepts text, images, audio and video. Google positions it for frontier performance on real-world software engineering, enterprise knowledge work in law and finance, and complex workflows such as cyber defense.

Argon has a 1,048,576-token context window shared by input, thinking and output, and three thinking levels, low, medium and high, with medium as the default. Google also says Argon answers more directly, follows style instructions better than earlier Gemini models, and is its most resistant model yet to indirect prompt injection.

On AnyAIGC, gemini-4-argon works with both the native /v1beta/models/gemini-4-argon:generateContent endpoint and the OpenAI-compatible /v1/chat/completions. You don't need a Google Cloud account, and the same key calls 300+ other models on the platform.

Capabilities

What Gemini 4 Argon can do

  • Repository-scale coding

    Built for real, long-horizon software engineering. Google reports 77.9% on DeepSWE v1.1, which makes it a fit for cross-module refactors, large migrations and long-running coding agents.

  • Deep professional work

    Google reports it leads the comparison models on Vals Index, Vals Finance Agent v2 and the Harvey legal agent benchmark, so it suits financial analysis, legal drafting and tax work.

  • Multi-step agents and tools

    Function calling, code execution, structured output, URL context and Google Search grounding. It scores 51.3% on AutomationBench, which tests end-to-end business workflows.

  • 1M-token context

    The 1,048,576-token window holds a whole book, a full codebase or a stack of contracts. It scores 84.2% on the GraphWalks 256k–1M long-context test.

  • Native multimodal understanding

    Send text, images, audio, video and PDFs directly. Google reports 91.7% on LVBench for long video and 71.6% on Chartography for chart understanding.

  • Math and science

    The high thinking level is meant for hard math and science. Google reports 76.0% on RiemannBench and 88.8% on the LABBench 2 life-science research benchmark.

Parameter notes: Gemini 4 Argon uses thinkingLevel (low / medium / high). It does not support thinkingBudget or minimal and returns a 400 error if you send them; temperature, topP and topK are ignored. Google recommends setting maxOutputTokens to at least 32,768 because thinking counts toward output. For native streaming, call :streamGenerateContent?alt=sse.

For every parameter, see the native Gemini API docs and the Chat Completions docs. Replace the model name in the examples with gemini-4-argon.

FAQ

Gemini 4 Argon API FAQ

How much does the Gemini 4 Argon API cost?

On AnyAIGC, gemini-4-argon is billed per token: $0.1985 per 1M input tokens, $0.9927 per 1M output tokens and $0.0099 per 1M cached tokens. Google's promotional price (through November 30, 2026) is $2.00 input, $10.00 output and $0.10 cache, so AnyAIGC costs about 10% of Google's rate. Output includes thinking tokens.

Will AnyAIGC's price change after Google's promotion ends?

No. Google returns to its standard price on December 1, 2026: $4.00 input, $20.00 output and $0.20 cache per 1M tokens. AnyAIGC keeps its current price ($0.1985 input, $0.9927 output, $0.0099 cache), which is then about 5% of Google's standard price.

What is the Gemini 4 Argon model ID? Is it generally available?

The model ID is gemini-4-argon. Google made it generally available on October 13, 2026, and it is a stable model, not a preview. The native endpoint puts the model name in the URL (/v1beta/models/gemini-4-argon:generateContent); the OpenAI-compatible endpoint takes it in the model field.

What are the context window and maximum output?

Google lists a 1,048,576-token context window shared by input, thinking and output. A synchronous request returns up to 65,536 output tokens by default; Google's long decoding (up to about 1M output tokens) runs through its background execution feature. Hard problems can think for several minutes, so set your HTTP client timeout to 15 minutes or more.

Should I use the native Gemini endpoint or the OpenAI-compatible one?

Either works. The native endpoint is POST https://anyaigc.ai/v1beta/models/gemini-4-argon:generateContent with the same request body as the Google Gemini API, so you can use contents, systemInstruction, tools and thinkingConfig. The OpenAI-compatible endpoint is POST https://anyaigc.ai/v1/chat/completions; with the official OpenAI SDK, set base_url to https://anyaigc.ai/v1. Both use Authorization: Bearer.

How do I set the thinking level?

Gemini 4 Argon supports three thinking levels, low, medium and high, with medium as the default. On the native endpoint, set generationConfig.thinkingConfig.thinkingLevel. Google says the model does not support thinkingBudget or minimal and returns a 400 error if you send them; temperature, top_p and top_k are ignored.

Gemini 4 Argon vs Gemini 3.8 Flash vs Gemini 3.1 Pro: which should I use?

Gemini 4 Argon is Google's current flagship, built for complex software engineering, professional work in finance and law, long-running agents and very long documents. Gemini 3.8 Flash is what Google calls its most intelligent Flash model, at $0.0744 input and $0.3722 output on AnyAIGC, a good fit for high volume and latency-sensitive work. Gemini 3.1 Pro is still in preview at $0.1985 input and $1.1910 output on AnyAIGC (prompts ≤200K); its output costs more than Argon, so new projects should usually start with Argon.

Are there concurrency or rate limits?

AnyAIGC sets no concurrency limit on gemini-4-argon. Every account gets this by default, which suits batch jobs and many agents running in parallel.
