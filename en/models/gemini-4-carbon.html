About the model

Built on Argon for long-horizon agents and the hardest problems

Google announced Gemini 4 Carbon in October 2026, then published its model card and opened it in the Gemini API on November 10, 2026. The model card says Carbon is based on Gemini 4 Argon and delivers frontier performance in long-horizon agentic workflows across complex knowledge work, engineering, cybersecurity and scientific reasoning.

Compared with Argon, Carbon spends more thinking tokens to explore hypotheses, reason deeply and run extended verification loops, with configurable thinking levels to trade off quality, latency and cost. Google notes it can use more tokens and occasionally respond slowly at higher thinking levels, while Argon is faster and spends fewer tokens per turn. Both share a 1,048,576-token context window and a March 2026 knowledge cutoff.

On AnyAIGC, gemini-4-carbon works with both the native /v1beta/models/gemini-4-carbon:generateContent endpoint and the OpenAI-compatible /v1/chat/completions. You don't need a Google Cloud account, and the same key calls 300+ other models on the platform.

Capabilities

What Gemini 4 Carbon can do

  • Long-horizon coding agents

    Built for complex, multi-step coding and debugging and for engineering work that needs several agents working together. Google reports 65.2% on Terminal-Bench 4.0 (AA), up from Argon's 57.1%.

  • Computer use and automation

    77.4% on Agents' Last Exam v1.1, 81.5% on the OSWorld-2.1 offline subset and 53.9% on AutomationBench, for agents that operate software and run whole business workflows.

  • High-precision knowledge work

    The model card lists high-precision knowledge work, artifact generation and data analysis as core uses. It scores 70.4% on Vals Index v2.2 and ends Vending-Bench 2 with a $16,484 balance.

  • 1M-token context

    The 1,048,576-token window holds a full codebase, a whole book or a stack of contracts. It scores 96.2% on the GraphWalks 256k–1M long-context test, versus 84.2% for Argon.

  • Visual and spatial reasoning

    Send text, images, audio, video and PDFs directly. It scores 72.5% on Chartography and 58.6% on Blueprint-Bench 2, so it can read drawings and charts and review visual designs.

  • Cyber defense and science

    71.0% on CWE-bench, 88.2% on SEC-bench Pro and 64.8% on Terminal-Bench-Science. A fit for finding and patching vulnerabilities and for reasoning in physics, math and life sciences.

Quick start

Call the Gemini 4 Carbon API in three steps

  1. Sign up and top up: create an account at anyaigc.ai. Your balance works across every model on the platform.
  2. Create an API key: create a token in the console, copy the key that starts with sk-, and store it in the ANYAIGC_API_KEY environment variable.
  3. Send a request: call the native endpoint https://anyaigc.ai/v1beta/models/gemini-4-carbon:generateContent, or the OpenAI-compatible https://anyaigc.ai/v1/chat/completions with model set to gemini-4-carbon. Both authenticate with Authorization: Bearer.

Parameter notes: Gemini 4 Carbon uses thinkingLevel (low / medium / high), with medium as the default. Carbon thinks more than Argon and thinking counts toward output, so set maxOutputTokens to 32,768 or more and your HTTP timeout to 15 minutes or more; start with low or medium for cost-sensitive work. For native streaming, call :streamGenerateContent?alt=sse.

For every parameter, see the native Gemini API docs and the Chat Completions docs. Replace the model name in the examples with gemini-4-carbon.

Gemini 4 Carbon API FAQ

How much does the Gemini 4 Carbon API cost?

On AnyAIGC, gemini-4-carbon is billed per token: $0.7147 per 1M input tokens, $3.5740 per 1M output tokens and $0.0357 per 1M cached tokens. Google's promotional list price (through November 30, 2026) is $2.00 input, $10.00 output and $0.10 cache, so AnyAIGC is 64% off, about 36% of Google's rate. Output includes thinking tokens.

Is it still a good deal after Google's promotion ends?

Google returns to its standard price on December 1, 2026: $4.00 input, $20.00 output and $0.20 cache per 1M tokens. At AnyAIGC's current price ($0.7147 input, $3.5740 output, $0.0357 cache), that works out to about 18% of Google's standard price. The model catalog always shows the live price.

What is the Gemini 4 Carbon model ID, and what is it based on?

The model ID is gemini-4-carbon. Google's model card says Gemini 4 Carbon is based on Gemini 4 Argon; the card was published on November 10, 2026, when the model opened in the Gemini API. The native endpoint puts the model name in the URL (/v1beta/models/gemini-4-carbon:generateContent); the OpenAI-compatible endpoint takes it in the model field.

What are the context window and maximum output?

Google lists a 1,048,576-token context window shared by input, thinking and output. A synchronous request returns up to 65,536 output tokens by default; Google's long decoding (up to about 1M output tokens) runs through its background execution feature. Carbon can think for a long time on hard problems, so set your HTTP client timeout to 15 minutes or more.

Should I use the native Gemini endpoint or the OpenAI-compatible one?

Either works. The native endpoint is POST https://anyaigc.ai/v1beta/models/gemini-4-carbon:generateContent with the same request body as the Google Gemini API, so you can use contents, systemInstruction, tools and thinkingConfig. The OpenAI-compatible endpoint is POST https://anyaigc.ai/v1/chat/completions; with the official OpenAI SDK, set base_url to https://anyaigc.ai/v1. Both use Authorization: Bearer.

How do I set the thinking level?

Gemini 4 Carbon supports three thinking levels, low, medium and high, with medium as the default. On the native endpoint, set generationConfig.thinkingConfig.thinkingLevel. Carbon spends more thinking tokens than Argon; higher levels give better results but take longer and use more output tokens, and thinking tokens are billed at the output rate.

Gemini 4 Carbon vs Gemini 4 Argon: which should I use?

Google lists both at the same price. Carbon is built on Argon and thinks and verifies more, which suits long-horizon agents, complex engineering, cybersecurity and scientific reasoning; Argon responds faster and spends fewer tokens per turn. On AnyAIGC, Gemini 4 Argon costs $0.1985 input and $0.9927 output, less than Carbon's $0.7147 and $3.5740. Start with Argon, switch to Carbon for the hardest tasks, and use Gemini 3.8 Flash for high volume. All three share one key.

Are there concurrency or rate limits?

AnyAIGC sets no concurrency limit on gemini-4-carbon. Every account gets this by default, which suits batch jobs and many agents running in parallel.
