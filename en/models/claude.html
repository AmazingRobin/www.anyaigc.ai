The native Anthropic API, fully supported

Requests use Anthropic's Messages format, so the official SDKs and your existing code carry over.

  • Messages API

    Call /v1/messages. With Anthropic's official SDK, set the base URL to https://anyaigc.ai.

  • Prompt caching

    Add cache_control to a content block for 5-minute or 1-hour caching. Cache hits cost about 2.5–10% of the regular input price.

  • Tool use and structured output

    Define functions with tools, or constrain output with a JSON schema to plug into your systems.

  • Adaptive thinking

    Use the thinking and effort parameters. Per Anthropic's docs, models such as Fable 5.1 and Sonnet 5 use adaptive thinking by default; see each model page.

  • Image and PDF input

    The AnyAIGC docs include PDF document examples, and Anthropic's docs cover image input for Claude models.

  • Streaming

    Set "stream": true to receive output as it's generated, for chat UIs and long responses.

Get started in three steps

  1. Sign up and add credit: create an account at anyaigc.ai. Your balance works across every model on the platform.
  2. Create an API key: create a token in the console and copy the key that starts with sk-.
  3. Send a request: call https://anyaigc.ai/v1/messages with an Anthropic Messages request, using Authorization: Bearer for auth.

For more parameters (tools, thinking, streaming, PDF and image input, and more), see the AnyAIGC Messages API docs. Fields mean the same as in Anthropic's API docs.

Claude API FAQ

How much does the Claude API cost?

Every Claude model on AnyAIGC is billed per token in USD per million tokens, with no subscription or monthly fee. Current models: Opus 5.5 at $0.4765 input and $2.3820 output; Sonnet 5.5 at $0.2382 input and $1.1910 output; Haiku 5.5 at $0.0119 input and $0.0596 output; Fable 5.1 at $2.3820 input and $11.9120 output. Opus, Sonnet and Haiku are 88% off Anthropic's list price, and Fable is 76% off. Cache writes, cache hits and legacy models are in the pricing table on this page; see the AnyAIGC model catalog for live prices.

Can I call the Claude API from mainland China?

Yes. AnyAIGC is optimized for networks in mainland China, so you can usually call https://anyaigc.ai/v1/messages without an extra proxy. Billing is in USD, and companies can pay by bank transfer and get VAT invoices.

How do I get a Claude API key?

Sign up at anyaigc.ai, add credit, and create a token in the console. The same key works for all 10 Claude models on this page and 300+ other models on the platform, all drawing from one balance.

Does the AnyAIGC Claude API work with Anthropic's official SDKs?

Yes. The endpoint is https://anyaigc.ai/v1/messages and the request body follows Anthropic's Messages format (model, max_tokens, system, messages, tools, cache_control and so on). Authenticate with Authorization: Bearer and your API key. With the official anthropic SDK, set base_url to https://anyaigc.ai and the rest of your code stays the same.

Which Claude models are available, and which should I use?

AnyAIGC offers 10 Claude models. The current ones are Opus 5.5, Sonnet 5.5, Haiku 5.5 and Fable 5.1. Use Opus 5.5 for complex coding and AI agents; Sonnet 5.5 for well-scoped everyday coding, bug fixes and documents; Haiku 5.5, which Anthropic calls the fastest and most efficient model in the Claude 5.5 family, for high-volume classification, real-time support and sub-agents; and Fable 5.1 for the hardest long-running work. Legacy Opus 5, Fable 5, Sonnet 5, Opus 4.8, Opus 4.7 and Opus 4.6 remain available for existing projects.

What's the difference between Claude Opus and Sonnet?

Anthropic positions Sonnet 5.5 as a faster, lower-cost complement to Opus 5.5. Opus 5.5 is aimed at complex work that needs careful judgment; Sonnet 5.5 is built for well-scoped everyday tasks, bug fixes, and polished documents, slides and spreadsheets. Sonnet 5.5 costs half as much: on AnyAIGC it is $0.2382 input and $1.1910 output, versus $0.4765 and $2.3820 for Opus 5.5 (per million tokens).

What's the difference between Claude Fable and Opus?

Fable is Anthropic's line of Mythos-class models, and Anthropic says Mythos-class models sit above the Opus class in capability. Anthropic's docs recommend starting with Claude Opus 5.5 for most workloads and using Fable 5.1 for the hardest ones. Fable 5.1 costs more than twice as much as Opus 5.5: $2.3820 input and $11.9120 output per million tokens on AnyAIGC. Both use the same key, so you can switch per task by changing the model field.

Can I still use older Claude models?

Yes. Anthropic lists Opus 5, Fable 5, Sonnet 5, Opus 4.8, Opus 4.7 and Opus 4.6 as legacy, and they are all still available on AnyAIGC. Anthropic's earliest retirement dates are Feb 5, 2027 for Opus 4.6, Apr 16, 2027 for Opus 4.7, May 28, 2027 for Opus 4.8, Jun 9, 2027 for Fable 5, Jun 30, 2027 for Sonnet 5, and Jul 24, 2027 for Opus 5. For new projects, use the matching current model.

Can I use it with Claude Code?

Yes. Run curl -fsSL https://www.anyaigc.ai/install.sh | bash -s claude to install and configure everything, or set ANTHROPIC_BASE_URL to https://anyaigc.ai, ANTHROPIC_AUTH_TOKEN to your API key and ANTHROPIC_MODEL to claude-opus-5-5 in the env block of ~/.claude/settings.json. Set ANTHROPIC_DEFAULT_HAIKU_MODEL to claude-haiku-5-5 to run background tasks and sub-agents on Haiku 5.5.

Are there concurrency limits?

No. AnyAIGC doesn't cap concurrency on any Claude model, and every user gets this by default, so batch jobs and parallel agents don't have to queue.

Can AnyAIGC issue invoices, including VAT special invoices?

Yes. AnyAIGC issues invoices for the amount you top up, including Chinese VAT general invoices and VAT special invoices. Send your billing details to support to request one.

Can my company pay by bank transfer and sign a contract?

Yes. Companies can top up by corporate bank transfer and sign a service agreement, and get a dedicated support and technical contact. Contact AnyAIGC support to get started.
