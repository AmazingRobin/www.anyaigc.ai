Quick start

Get started with the DeepSeek API in three steps

  1. Sign up and add credit: create an account at anyaigc.ai. Top up from $1; your balance works across every model on the platform.
  2. Create an API key: create a key in the console, copy the sk- key, and store it in the ANYAIGC_API_KEY environment variable.
  3. Send a request: call POST https://anyaigc.ai/v1/chat/completions with model set to deepseek-v4.1-flash and an Authorization: Bearer header. With the OpenAI SDK, just set base_url to https://anyaigc.ai/v1.

Parameters: DeepSeek says the V4 series thinks by default. The thinking field in the request body turns it on or off ({"type": "enabled"} or {"type": "disabled"}), and reasoning_effort sets the depth (officially low / high / max). Thinking tokens count as output and show up in usage.completion_tokens_details.reasoning_tokens. Sampling parameters such as temperature have no effect in thinking mode.

See the Chat Completions API reference for every parameter. Swap the model name in the doc examples for the DeepSeek model ID you want.

Claude Code

Use DeepSeek in Claude Code

Point Claude Code at DeepSeek: edit one config file and your terminal coding agent runs on DeepSeek V4.1 Flash, billed per token.

  1. Install Claude Code: use the official installer, for example curl -fsSL https://claude.ai/install.sh | bash on macOS or Linux.
  2. Add the config: edit ~/.claude/settings.json, add the env block below, and replace ANTHROPIC_AUTH_TOKEN with the key you created on AnyAIGC.
  3. Start coding: run claude in your project folder. Type /model to confirm the current model is deepseek-v4.1-flash.

Switch models: to use V4 Pro, replace deepseek-v4.1-flash with deepseek-v4-pro in the config. You can also keep ANTHROPIC_DEFAULT_HAIKU_MODEL on V4.1 Flash for lightweight subtasks.

For full steps and common errors, see the Claude Code setup guide. Swap the model name in the guide for deepseek-v4.1-flash.

FAQ

DeepSeek API FAQ

How much does the DeepSeek API cost?

DeepSeek on AnyAIGC is billed per token. Per 1M tokens: deepseek-v4.1-flash is $0.1215 input, $0.4860 output and $0.0024 cache hit; deepseek-v4-pro is $0.5346 input, $1.6038 output and $0.0178 cache hit; deepseek-v4-flash costs the same as V4.1 Flash. Live prices are shown in the model catalog.

Does AnyAIGC have peak and off-peak pricing?

No. The official DeepSeek API uses time-of-day pricing: weekdays 01:00–04:00 and 06:00–10:00 UTC (9:00–12:00 and 14:00–18:00 Beijing time) is peak time, and peak prices are double the off-peak prices. On AnyAIGC, every DeepSeek model is billed at one rate around the clock. That rate is about 60% off the official peak price. Live prices are shown in the model catalog.

Which DeepSeek models does AnyAIGC offer, and what are the model IDs?

This page covers three: deepseek-v4.1-flash (DeepSeek's latest Flash model, with native vision), deepseek-v4-pro (the 1.6T-parameter V4 flagship) and deepseek-v4-flash (the V4 preview Flash model, which DeepSeek has replaced with V4.1 Flash). Put the model ID in the model field of the request body. Switching models means changing only that field.

Should I use V4.1 Flash or V4 Pro?

Start with V4.1 Flash for most work. DeepSeek says it now beats V4 Pro on performance, cost, speed and total task time, its input price is about a quarter of V4 Pro's, and it can read images. If you already have V4 Pro tuned in production, you can keep using V4 Pro: DeepSeek has said it will keep serving the V4 Pro API after September 14, 2026.

How big is the context window? Can I send images?

DeepSeek lists a 1M-token context and up to 384K output tokens for both V4.1 Flash and V4 Pro. Only V4.1 Flash accepts images; V4 Pro and V4 Flash are text-only.

Is the DeepSeek API OpenAI-compatible?

Yes. All three models use POST https://anyaigc.ai/v1/chat/completions with the same request and response format as OpenAI Chat Completions. With the official OpenAI SDK, set base_url to https://anyaigc.ai/v1. The Anthropic format is supported too, so Claude Code works.

Can I use DeepSeek in Claude Code?

Yes. DeepSeek models on AnyAIGC support both the OpenAI and the Anthropic API formats. In the env block of ~/.claude/settings.json, set ANTHROPIC_BASE_URL to https://anyaigc.ai, ANTHROPIC_AUTH_TOKEN to your API key and ANTHROPIC_MODEL to deepseek-v4.1-flash, then run claude. You pay per token.

Are there concurrency or rate limits?

AnyAIGC does not cap concurrency for the DeepSeek series, and every user gets this by default. That suits batch jobs, CI pipelines and parallel agents.

Can I call the DeepSeek API from mainland China?

Yes. AnyAIGC is optimized for networks in mainland China, so you can usually call https://anyaigc.ai without a proxy. Usage is billed in USD, and you can pay with WeChat Pay, Alipay, USDT or a credit card. Companies can pay by bank transfer and get VAT invoices.

How do I get a DeepSeek API key?

Sign up at anyaigc.ai, add credit, and create a key in the console. The same key works for every DeepSeek model and 300+ other models on the platform, so you do not need a separate DeepSeek Platform account.

Can AnyAIGC issue invoices, including VAT special invoices?

Yes. AnyAIGC issues invoices for every top-up based on the amount you actually paid, including Chinese VAT general invoices and VAT special invoices. Send your billing details to support to get one.

Which payment methods are supported?

You can top up with WeChat Pay, Alipay, USDT or a credit card. Companies can also pay by bank transfer and get VAT general or special invoices. Your balance is in USD and works across every model on the platform.

Is there free trial credit for new users?

Yes. New accounts get 2 million tokens of trial credit, so you can test before deciding to top up. Top-ups start at $1.

Can I get a refund on my balance?

Yes. Unused balance can be refunded with no fee. Contact support to start a refund.

Are these the real models? Is my data safe?

Requests go to official model channels, never cheaper or reverse-engineered substitutes. Unless the law requires it, we do not persistently store your prompts or outputs or use them for training, and the console shows tokens and cost for every request.

Can my company pay by bank transfer and sign a contract?

Yes. Companies can top up by corporate bank transfer and sign a service agreement with AnyAIGC, with a dedicated support and technical contact. For procurement, contact AnyAIGC support.
