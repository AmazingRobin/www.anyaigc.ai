About

A general-purpose open multimodal agent model

Moonshot AI positions Kimi K2.6 as an open native multimodal agent model. Moonshot says it writes long code more capably and more consistently, with clear gains in instruction following and self-correction. It takes text and image input and has thinking and non-thinking modes, so it works for chat and agent tasks alike.

Under the hood it is MoE with 1T total and 32B active parameters, 256K context and native INT4 quantization. Moonshot highlights four areas: long-horizon coding, UI from prompts or images (Coding-Driven Design), Agent Swarm scaling out to 300 sub-agents, and proactive agents that run 24/7.

On AnyAIGC, kimi-k2.6 runs on the OpenAI-compatible /v1/chat/completions endpoint and works directly in Claude Code, with unlimited concurrency.

Quickstart

Connect to the Kimi K2.6 API in three steps

  1. Sign up and add credit: create an account at anyaigc.ai. Top up from $1; your balance works across every model on the platform.
  2. Create an API key: create a key in the console, copy the value that starts with sk-, and store it in the ANYAIGC_API_KEY environment variable.
  3. Send a request: call POST https://anyaigc.ai/v1/chat/completions with model set to kimi-k2.6 and an Authorization: Bearer header. With the OpenAI SDK, just set base_url to https://anyaigc.ai/v1.

Tip: K2.6 thinks by default, and the reasoning comes back in reasoning_content. On Moonshot's API, thinking: {"type": "disabled"} turns thinking off (pass it in extra_body with the OpenAI SDK); Moonshot recommends temperature=0.6 in non-thinking mode. In thinking mode, for multi-turn chats and tool calls, send the full assistant message back in the next request unchanged.

See the Chat Completions reference for every parameter. Replace the model name in the docs examples with the Kimi model ID you want.

FAQ

Kimi K2.6 API FAQ

How much does the Kimi K2.6 API cost?

On AnyAIGC, kimi-k2.6 is billed per token: input $0.3847 per 1M tokens, output $1.5980 per 1M tokens, cache hit $0.0651 per 1M tokens. Moonshot's official USD prices are input $0.95, output $4.00 and cache hit $0.16, so AnyAIGC is about 40% of official. See the model catalog for live pricing.

What is the Kimi K2.6 model ID, and how large is the context?

The model ID is kimi-k2.6. Moonshot lists a 262,144-token (256K) context window, with text and image input.

Can I turn off thinking in Kimi K2.6?

K2.6 supports both thinking and non-thinking (Instant) modes. On Moonshot's API, thinking: {"type": "disabled"} turns thinking off; with the OpenAI SDK, pass it in extra_body. Moonshot recommends temperature=1.0 for thinking mode and temperature=0.6 for non-thinking mode, with top_p 0.95 for both.

What sets Kimi K2.6 apart?

Moonshot positions K2.6 as an open native multimodal agent model with four focus areas: long-horizon coding (Rust, Go, Python, front end, DevOps and performance tuning), production-ready UI from prompts or images, Agent Swarm (scaling out to 300 sub-agents and 4,000 coordinated steps), and proactive agents that run in the background 24/7.

Kimi K2.6 or K2.7 Code: which should I use?

They share an architecture and cost the same for input and output on AnyAIGC. K2.7 Code is K2.6 further trained for coding, with higher coding scores and fewer thinking tokens, but it only runs in thinking mode. K2.6 can turn thinking off, which fits fast chat, classification, extraction and general agents.

Can I use Kimi K2.6 in Claude Code?

Yes. In the env block of ~/.claude/settings.json, set ANTHROPIC_BASE_URL to https://anyaigc.ai, ANTHROPIC_AUTH_TOKEN to your API key, and ANTHROPIC_MODEL to kimi-k2.6. Then run claude.

Does Kimi K2.6 support tool calls and image input?

Yes. K2.6 supports multi-step tool calls, streaming and image input. In thinking mode, for multi-turn chats and tool calls, send the full assistant message (including reasoning_content and tool_calls) back in the next request unchanged.

Are there concurrency or rate limits?

AnyAIGC does not cap concurrency for kimi-k2.6, and every user gets this by default. That suits batch jobs, CI pipelines and parallel agents. Moonshot's own platform limits concurrency, RPM, TPM and TPD by top-up tier; those tiers do not apply when you call through AnyAIGC.
