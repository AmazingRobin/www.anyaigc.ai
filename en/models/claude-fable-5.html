Claude Fable 5 API FAQ

How much does the Claude Fable 5 API cost?

On AnyAIGC, claude-fable-5 is billed per token: $2.382 per million input tokens, $11.912 per million output tokens, $2.9779 for 5-minute cache writes, $4.7647 for 1-hour cache writes, and $0.2382 for cache hits. Anthropic's list price is $10 input and $50 output, so AnyAIGC comes in at about 23.8% of list price, or 76% off.

What is the Claude Fable 5 model ID, and is the API Anthropic-compatible?

The model ID is claude-fable-5. Put it in the model field of your request body. The endpoint is https://anyaigc.ai/v1/messages and the request body follows the Anthropic Messages format (model, max_tokens, system, messages, tools, cache_control, and so on). Authenticate with Authorization: Bearer followed by your API key. With the official SDK, just set the base URL to https://anyaigc.ai.

What is Claude Fable, and how is it different from Opus?

Claude Fable is Anthropic's line of Mythos-class models. Anthropic describes Claude Fable 5 as a Mythos-class model it has made safe for general use, and says Mythos-class models sit above the Opus class in capability. Claude Mythos 5 is the same underlying model with fewer safeguards and is offered only to verified organizations. According to Anthropic, the longer and more complex the task, the larger Fable 5's lead over its other models.

Is Claude Fable 5 deprecated? How long can I use it?

It still works. Anthropic lists Claude Fable 5 as Active (Legacy) and commits to retiring it no earlier than June 9, 2027. For new projects, Anthropic recommends Claude Fable 5.1 (claude-fable-5-1).

What is Claude Fable 5 good at?

It fits hard, long-horizon work: long-running agentic coding, multistep research, document, spreadsheet and slide work, and computer-use agents. Anthropic's docs list a 1M-token context window and 128K max output. In Anthropic's published results it scores 80.3% on SWE-Bench Pro and 85.0% on OSWorld-Verified.

Can I use Claude Fable 5 in Claude Code?

Yes. In the env block of ~/.claude/settings.json, set ANTHROPIC_BASE_URL to https://anyaigc.ai, ANTHROPIC_AUTH_TOKEN to your API key, and both ANTHROPIC_MODEL and ANTHROPIC_DEFAULT_OPUS_MODEL to claude-fable-5, then run claude. You can also install and configure everything with one command: curl -fsSL https://www.anyaigc.ai/install.sh | bash.

How is prompt caching billed?

Add cache_control to a content block to enable caching. The first write is billed at the cache write rate ($2.9779 for 5 minutes or $4.7647 for 1 hour, per million tokens). After that, cached tokens cost only $0.2382 per million, 10% of the regular input price. Caching works best for long system prompts, large codebase context, and long-running agent tasks.

Are there concurrency or rate limits?

AnyAIGC sets no concurrency limit on claude-fable-5. Every account gets this by default, so it works well for batch jobs and running multiple agents in parallel.

Can I call the Claude Fable 5 API from mainland China?

Yes. AnyAIGC is optimized for networks in mainland China, so you can usually call https://anyaigc.ai/v1/messages without an extra proxy. Billing is in USD, and companies can pay by bank transfer and get VAT invoices.
