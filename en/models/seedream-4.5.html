What is Seedream 4.5

Seedream 4.5 is an image creation model from the ByteDance Seed team. It takes text, a single image or several images as input and handles subject-consistent multi-image fusion, image editing and image sets in one model.

The official highlights are threefold: edits keep the faces, lighting and detail of the source image; posters and logos lay out more reliably with legible small text; and multi-image fusion locks onto the subject so characters stay consistent. On AnyAIGC the model ID is doubao-seedream-4-5-251128, from $0.0253 per image.

What Seedream 4.5 can do

  • Poster layouts and small text

  • Consistent characters across images

Seedream 4.5 API FAQ

How much does the Seedream 4.5 API cost?

On AnyAIGC, Seedream 4.5 (doubao-seedream-4-5-251128) starts at $0.0253 / image. Prices vary by resolution; live 2K and 4K rates are in the model catalog. Image sets are billed per image generated. You are billed per successful generation; live prices are in the model catalog.

What is Seedream 4.5?

Seedream 4.5 is an image creation model from the ByteDance Seed team, with the model ID doubao-seedream-4-5-251128 on AnyAIGC. It takes text, a single image or several images as input and handles subject-consistent multi-image fusion, image editing and image sets. Officially it keeps faces, lighting and detail from the source image, lays out posters and logos more reliably, and renders small text legibly.

Which resolutions are supported?

Per the Volcano Engine Ark docs, 4.5 accepts size values of 2K and 4K, or pixel dimensions, with aspect ratios from 1:16 to 16:1.

How many reference images can I send? How large can an image set be?

image accepts up to 14 reference images. Image sets use sequential_image_generation: "auto" and return up to 15 images per request; with reference images, references plus generated images cannot exceed 15.

Should I pick 4.5 or 5.0 lite?

Both support 4K, image sets and 14 reference images. Pick 5.0 lite (from $0.0223 / image) for web search or stronger intent understanding. If you already integrate 4.5 and care most about poster layouts and preserving source details, keep using 4.5.

Is there a concurrency limit? What do I need to sign up?

AnyAIGC sets no concurrency limit on Seedream 4.5, and every account gets this by default. The base URL is https://anyaigc.ai. You do not need a Volcano Engine account or ID verification, and the same key also works with 300+ other models on the platform.
