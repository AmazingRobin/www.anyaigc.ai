GPT Image 2.6 Flare: fast images, and animated ones too

OpenAI released Images 2.6 on November 4, 2026, with two API models, Sunburst and Flare. OpenAI describes Flare as image generation and editing for fast iteration. Images 2.6 generates images 50% faster than before, Flare can finish a low-quality image in as little as six seconds, and layout quality improves for posters, product imagery and other professional visuals.

Flare uses the same parameters as Sunburst. It adds complexity (low, medium or high), markup-guided edits with markup, SVG output and animated GIF output. Quality levels are low, medium, high, xhigh, max and auto. Custom sizes work as long as the longest edge is at most 3840px, both sides are multiples of 16, the aspect ratio is no wider than 3:1, and the total pixel count is between 655,360 and 8,294,400.

On AnyAIGC, Flare and 2.6 Sunburst cost the same. With token billing, a 1024×1024 image costs about $0.0196 at low quality and $0.0345 at medium. For a fixed cost per image, use gpt-image-2.6-flare-c at $0.0199 per image.

GPT Image 2.6 Flare API FAQ

How much does the GPT Image 2.6 Flare API cost?

On AnyAIGC, gpt-image-2.6-flare is billed per token: $3.9710 for text input, $6.3530 for image input and $23.8240 for image output per 1M tokens, with cached text input at $1.5880 and cached image input at $2.5410. A 1024×1024 image costs about $0.0196 in image output at low quality and $0.0345 at medium. The per-image version gpt-image-2.6-flare-c is $0.0199 per image. See the model catalog for live prices.

Flare or Sunburst? And what changed from GPT Image 2.5?

Both are GPT Image 2.6, with the same rates on AnyAIGC and the same parameters. Flare is built for fast iteration and can return a low-quality image in as little as six seconds, which suits in-app generation, drafts and GIFs. Sunburst is built for detailed visual work, with steadier multi-round edits. Compared with GPT Image 2.5 Flare, 2.6 adds complexity, markup, SVG and GIF. At low and medium quality it uses more output tokens per image than 2.5; from high up the counts are the same.

How do I generate GIFs and SVGs?

Both use POST /v1/images/generations. For a GIF, set format to gif, frame_count to 2–64 (default 9) and frame_duration_ms to 20–2000 ms (default 200); size sets each frame. For an SVG, set format to svg and n to 1. quality applies to the reference image behind the SVG, and the result is static vector content. Neither works with the edits endpoint, streaming or compression settings.

How do complexity and markup-guided edits work?

complexity takes low, medium or high and defaults to high. Changing it costs nothing extra. OpenAI recommends low for most edits, paired with the quality you need, and medium or high for scenes with many elements or constraints. Markup edits use POST /v1/images/edits: send the original as the first image, plus a transparent PNG as markup with the same width and height. Mark the areas to change and describe the change in the prompt. Markup cannot be combined with mask.

Is there a per-image version? How is gpt-image-2.6-flare-c priced?

Yes. gpt-image-2.6-flare-c is the per-image version of GPT Image 2.6 Flare. It uses the same endpoints; only the model field changes. Each image costs a flat $0.0199 at 1K, 2K or 4K and at any quality level. Each request returns one image, and n, mask and transparent backgrounds are not supported. At medium quality and above, or for large images, per-image billing is usually cheaper.

AnyAIGC sets no concurrency limit on gpt-image-2.6-flare, and every account gets this by default. The base URL is https://anyaigc.ai/v1, which is tuned for networks in mainland China, so you usually do not need a proxy. Billing is in USD, you can pay with WeChat Pay, Alipay, USDT or a credit card, and the same key works for 300+ other models.
