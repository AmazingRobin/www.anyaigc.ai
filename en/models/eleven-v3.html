About the model

Eleven v3: Dramatic voiceover

Eleven v3 is the previous-generation flagship text-to-speech model from ElevenLabs. ElevenLabs describes it as producing natural, life-like speech with a high emotional range and contextual understanding. The model catalog describes it as strongly dramatic, a fit for stories and short-drama dubbing, with a lot of atmosphere.

The official docs list 70+ languages and a 5,000-character limit per generation. The docs now call v3 the previous generation, with Eleven v4 as the latest flagship. The two are priced the same on AnyAIGC, so for a new project it is worth auditioning the same text on both.

On AnyAIGC, eleven_v3 runs on POST /v1/audio/speech, billed by the number of input characters, with no concurrency limit.

Quick start

Call the Eleven v3 API in three steps

  1. Sign up and top up: create an account at anyaigc.ai. Top-ups start at $1, and the balance works across every model on the platform.
  2. Create an API key: create a token in the console, copy the key that starts with sk-, and store it in the ANYAIGC_API_KEY environment variable.
  3. Send a request: call POST https://anyaigc.ai/v1/audio/speech with model set to eleven_v3 and voice set to an ElevenLabs voice_id, authenticate with Authorization: Bearer, and save the returned audio as mp3.

Parameter notes: the model ID is case-sensitive, so write eleven_v3. voice takes an ElevenLabs voice_id, and an unknown or unavailable one returns 400. The reference lists input at 4,096 characters max, so split longer text. The examples save the response body as an mp3 file.

Full parameters are in the Create speech API reference. Swap the model name in the example for the Eleven model ID you want.

FAQ

Eleven v3 API FAQ

How much does the Eleven v3 API cost?

On AnyAIGC, eleven_v3 is billed per character at $0.6480 per 10K characters, about 19% off the ElevenLabs list price of $0.80 per 10K characters. The price is fixed, with no subscription or monthly fee. Live prices are in the model catalog.

What is the Eleven v3 model ID, and how does it relate to ElevenLabs?

The model ID is eleven_v3 (case-sensitive), the same as the ElevenLabs model_id. AnyAIGC is an independent API provider that offers an OpenAI-style /v1/audio/speech call, and is not affiliated with ElevenLabs.

How do I choose between Eleven v3 and the other Eleven models?

The platform has 7 Eleven voice models: Eleven v4 (flagship), Eleven v4 Turbo (low latency), Eleven v3, Eleven v3 Conversational, Eleven Multilingual v2, Eleven Flash v2.5 and Eleven Flash v2. Pick v4 for polished final audio, v4 Turbo for voice assistants, Multilingual v2 for long text and mixed languages, and Flash v2.5 for large subtitle batches. Audition the same text before you commit.

How do I get a Eleven v3 API key?

Sign up and top up at anyaigc.ai, then create a token in the console. One key works for 300+ models on the platform, and you do not need a separate ElevenLabs account. Set model to eleven_v3 in the request body.

How do I call the Eleven v3 API, and what goes in voice?

Call POST https://anyaigc.ai/v1/audio/speech with the required model, input and voice fields. voice takes an ElevenLabs voice_id, and an unknown or unavailable voice_id returns 400. response_format supports mp3, opus, aac and flac. See the API reference.

How long can the text be for one Eleven v3 request?

The ElevenLabs docs state a limit of 5,000 characters per generation for this model. The AnyAIGC Create speech reference lists the maximum length of input as 4,096 characters, so split longer text by that length and join the audio afterwards.

Does Eleven v3 support Chinese, and how many languages?

Yes. The official docs list 70+ languages for this model, and Mandarin (zh) is among them. For the exact languages see the ElevenLabs model docs.

Has Eleven v3 been retired?

No. The official docs call v3 the previous generation and Eleven v4 the latest flagship, and v3 is not in the official list of deprecated models (that list names eleven_turbo_v2_5, eleven_turbo_v2 and others). For a new project, audition the same text on Eleven v4 too; the two cost the same on AnyAIGC. Whether a model stays available is shown in the model catalog.

Is there a rate limit?

AnyAIGC sets no concurrency limit on eleven_v3, and every account gets this by default, so batch generation and parallel tasks are fine. Billing is per character, with no monthly fee and no quota that resets on a time window.

Can I use my own cloned voice?

The API reference only says that voice takes an ElevenLabs voice_id. It does not say whether a cloned voice from your own ElevenLabs account can be used with an AnyAIGC key. Please ask AnyAIGC support to confirm.

Can AnyAIGC issue invoices, including VAT special invoices?

Yes. AnyAIGC can issue invoices for every top-up, including Chinese VAT general invoices and VAT special invoices. Send your invoicing details to support.

Can my company pay by bank transfer and sign a contract?

Yes. You can top up by corporate bank transfer and sign a service agreement, with a dedicated support contact and technical contact. For company purchases, contact AnyAIGC support.

Which payment methods are supported?

You can top up with WeChat Pay, Alipay, USDT or a credit card. Companies can also pay by bank transfer and get VAT general or special invoices. Your balance is in USD and works across every model on the platform.

Is there free trial credit for new users?

Yes. New accounts get 2 million tokens of trial credit, so you can test before deciding to top up. Top-ups start at $1.

Can I get a refund on my balance?

Yes. Unused balance can be refunded with no fee. Contact support to start a refund.

Are these the real models? Is my data safe?

Requests go to official model channels, never cheaper or reverse-engineered substitutes. Unless the law requires it, we do not persistently store your prompts or outputs or use them for training, and the console shows tokens and cost for every request.

Are my text and the generated audio used for training?

No. Unless the law requires it, AnyAIGC does not persistently store your inputs or outputs and does not use them for training. Requests are encrypted with HTTPS. See the AnyAIGC Privacy Policy. The data policy of the model itself is set by ElevenLabs.
