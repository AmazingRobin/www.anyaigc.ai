About

A 1M-context flagship built for long tasks

Zhipu positions GLM-5.2 as a flagship for the era of long tasks. Zhipu says its 1M context is usable in practice and fits project-scale engineering context, and that it runs long tasks more reliably and follows engineering conventions more consistently.

Context grew from 200K on GLM-5.1 to 1M. The architecture keeps MoE with DSA sparse attention and adds IndexShare, where every 4 sparse attention layers share one indexer; Zhipu says this cuts per-token compute by 2.9x at 1M context. GLM-5.2 uses dynamic thinking by default, thinking can be turned off, and it is open source under the MIT license.

On AnyAIGC, glm-5.2 runs on the OpenAI-compatible /v1/chat/completions endpoint and works directly in Claude Code, with unlimited concurrency. For new projects, consider GLM-5.3 at the same price; it builds on the same base model with stronger coding.

Quickstart

Connect to the GLM-5.2 API in three steps

  1. Sign up and add credit: create an account at anyaigc.ai. Top up from $1; your balance works across every model on the platform.
  2. Create an API key: create a key in the console, copy the value that starts with sk-, and store it in the ANYAIGC_API_KEY environment variable.
  3. Send a request: call POST https://anyaigc.ai/v1/chat/completions with model set to glm-5.2 and an Authorization: Bearer header. With the OpenAI SDK, just set base_url to https://anyaigc.ai/v1.

Tip: GLM-5.2 uses dynamic thinking by default. Its reasoning, if any, comes back in the reasoning_content field, and reasoning_effort sets the depth. In multi-turn chats and tool calls, send the full assistant message from the API (including reasoning_content and tool_calls) back in the next request unchanged.

See the Chat Completions reference for every parameter. Replace the model name in the docs examples with the GLM model ID you want.

Claude Code

Use GLM-5.2 in Claude Code

Switch Claude Code to GLM-5.2: its 1M context suits long coding sessions in large repos.

  1. Install Claude Code: use the official installer, for example curl -fsSL https://claude.ai/install.sh | bash on macOS or Linux.
  2. Add the config: edit ~/.claude/settings.json, add the env block below, and replace ANTHROPIC_AUTH_TOKEN with the key you created on AnyAIGC.
  3. Start coding: run claude in your project folder. Type /model to confirm the current model is glm-5.2.

Upgrade tip: for a higher coding success rate, replace every glm-5.2 in the config with glm-5.3. Both cost the same.

For the full walkthrough and common errors, see the Claude Code setup guide. Swap the model name in the guide for glm-5.2.

FAQ

GLM-5.2 API FAQ

How much does the GLM-5.2 API cost?

On AnyAIGC, glm-5.2 is billed per token: input $0.9450 per 1M tokens, output $2.9700 per 1M tokens, cache hit $0.2362 per 1M tokens. Zhipu's official USD prices are input $1.40, output $4.40 and cache hit $0.26, so AnyAIGC input and output cost about 67.5% of official (about 30% off). See the model catalog for live pricing.

What is the GLM-5.2 model ID, and how large is the context?

The model ID is glm-5.2. Zhipu lists a 1M-token context window and up to 128K output tokens. It accepts text input only.

Can I turn off thinking on GLM-5.2?

Yes. Zhipu says GLM-5.2 uses dynamic thinking by default, letting the model decide whether to think, and thinking can also be turned off. That is one of the main differences from GLM-5.3, which always thinks. On AnyAIGC you can set thinking depth with reasoning_effort.

What makes GLM-5.2 stand out?

Zhipu positions GLM-5.2 as a flagship for the era of long tasks. Its 1M context is usable in practice and fits project-scale engineering context. It runs long tasks more reliably, follows engineering conventions more consistently, and can take one task from requirements to multi-platform deployment. Zhipu says its IndexShare design cuts per-token compute by 2.9x at 1M context.

GLM-5.2 or GLM-5.3: which should I use?

They share the same base model and cost the same for input and output on AnyAIGC. GLM-5.3 adds scaled-up post-training; Zhipu reports 50% better coding, and its cache-hit price is lower ($0.1758 vs $0.2362). New projects should start with GLM-5.3. Stay on GLM-5.2 if you need to turn thinking off or already have it tuned in production.

Can I use GLM-5.2 in Claude Code?

Yes. In the env block of ~/.claude/settings.json, set ANTHROPIC_BASE_URL to https://anyaigc.ai, ANTHROPIC_AUTH_TOKEN to your API key, and ANTHROPIC_MODEL to glm-5.2. Then run claude. You pay per token, with no 5-hour quota window like a subscription plan.

Is GLM-5.2 open source? Can I use it commercially?

Yes. Zhipu has published the GLM-5.2 weights under the MIT license on Hugging Face (zai-org/GLM-5.2) and ModelScope. Calling the API through AnyAIGC means you do not have to host it yourself. Commercial use is governed by Zhipu AI's official terms.

AnyAIGC does not cap concurrency for glm-5.2, and every user gets this by default. That suits batch jobs, CI pipelines and parallel agents. Billing is per token, so there is no quota that resets on a time window like a subscription plan.
