What is Seedream 4.0

Seedream 4.0 is a multimodal image model from the ByteDance Seed team that unifies text-to-image, image editing and multi-image compositing in one framework. It reasons over the prompt to choose a suitable aspect ratio and image count, returning up to 15 thematically related images per request.

ByteDance also reports clear gains in Chinese text accuracy and output variety, plus 4K output. On AnyAIGC the model ID is doubao-seedream-4-0-250828, from $0.0203 per image.

  • Image sets

Seedream 4.0 API FAQ

How much does the Seedream 4.0 API cost?

On AnyAIGC, Seedream 4.0 (doubao-seedream-4-0-250828) starts at $0.0203 / image. Prices vary by resolution; live 2K and 4K rates are in the model catalog. Image sets are billed per image generated. You are billed per successful generation; live prices are in the model catalog.

What is Seedream 4.0?

Seedream 4.0 is a multimodal image model from the ByteDance Seed team, with the model ID doubao-seedream-4-0-250828 on AnyAIGC. It unifies text-to-image, image editing and multi-image compositing in one framework, picks a suitable aspect ratio and image count from the prompt, returns up to 15 related images per request, and supports 4K.

Which resolutions are supported?

Per the Volcano Engine Ark docs, 4.0 accepts size values of 1K, 2K and 4K, or pixel dimensions, with aspect ratios from 1:16 to 16:1.

How many reference images can I send? How large can an image set be?

image accepts up to 14 reference images (per the current Volcano Engine Ark docs). Image sets return up to 15 images per request; with reference images, references plus generated images cannot exceed 15.

Is 4.0 still worth using?

4.0 remains available, costs less than 4.5 (from $0.0203 / image) and offers a 1K tier. For new projects, try 5.0 lite or 4.5 first. The API is identical, so migrating only changes the model ID.

Is there a concurrency limit? What do I need to sign up?

AnyAIGC sets no concurrency limit on Seedream 4.0, and every account gets this by default. The base URL is https://anyaigc.ai. You do not need a Volcano Engine account or ID verification, and the same key also works with 300+ other models on the platform.
