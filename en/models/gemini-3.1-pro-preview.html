About

The Pro tier of Gemini 3, built for complex reasoning

Google released Gemini 3.1 Pro Preview on February 19, 2026, under the headline "A smarter model for your most complex tasks", adding that "3.1 Pro is designed for tasks where a simple answer isn't enough." The model card says it is based on Gemini 3 Pro. Since March 9, 2026, gemini-3-pro-preview on Google's API has pointed to gemini-3.1-pro-preview.

It takes up to 1,048,576 input tokens and returns up to 65,536 output tokens, with text, image, video, audio and PDF input. Thinking has three levels, low, medium and high, and high (dynamic) is the default. Supported tools include function calling, code execution, structured outputs, URL context, grounding with Google Search and Google Maps, and context caching.

On AnyAIGC, gemini-3.1-pro-preview works on the native /v1beta/models/gemini-3.1-pro-preview:generateContent endpoint and the OpenAI-compatible /v1/chat/completions. You don't need a Google Cloud account, and the same key calls 300+ other models.

    99.3% on τ2-bench Telecom, 90.8% on Retail and 69.2% on MCP Atlas. Function calling, code execution and structured outputs support multi-step agents.

    85.9% on BrowseComp. Turn on Google Search and Maps grounding or URL context so answers draw on current information.

    Send text, images, video, audio and PDFs directly. Google reports 80.5% on MMMU-Pro, useful for charts, scans and video.

    A 1,048,576-token input window fits large codebases or full document sets. MRCR v2 scores 84.9% at 128k.

FAQ

Gemini 3.1 Pro API FAQ

How much does the Gemini 3.1 Pro Preview API cost?

On AnyAIGC, gemini-3.1-pro-preview uses tiered per-token pricing. For prompts up to 200K tokens: $0.1985 input, $1.1910 output and $0.0199 cache hit per 1M tokens. For prompts over 200K tokens: $0.3970 input, $1.7865 output and $0.0398 cache hit. Google's standard prices are $2.00 / $12.00 / $0.20 and $4.00 / $18.00 / $0.40, so AnyAIGC is about 10% of Google's price. Output includes thinking tokens.

How are prompts over 200K tokens billed?

When a single request's prompt exceeds 200K tokens, the whole request is billed at the higher tier: input and cache hits at 2x, output at 1.5x. That works out to $0.3970 input, $1.7865 output and $0.0398 cache hit per 1M tokens, the same tier rule Google uses. Live prices are on the model catalog.

Is Gemini 3.1 Pro still in preview? Will it be shut down?

Yes, it is still a preview. Google released Gemini 3.1 Pro Preview on February 19, 2026, and as of October 2026 it remains a public preview with the model ID gemini-3.1-pro-preview. Google's deprecations page says "No shutdown date announced", and no general availability date has been published. Preview behavior and pricing can change, so new projects that need a stable model can use Gemini 4 Argon, which is generally available.

What are the context window and max output?

Google lists an input limit of 1,048,576 tokens, a maximum of 65,536 output tokens per request, and a knowledge cutoff of January 2025. It accepts text, image, video, audio and PDF input and returns text.

Should I use the native Gemini API or the OpenAI-compatible endpoint?

Either works. The native endpoint is POST https://anyaigc.ai/v1beta/models/gemini-3.1-pro-preview:generateContent and takes the same request body as Google's Gemini API. The OpenAI-compatible endpoint is POST https://anyaigc.ai/v1/chat/completions: point the official OpenAI SDK at base_url https://anyaigc.ai/v1 and set model to gemini-3.1-pro-preview. Both use Authorization: Bearer.

How do I set the thinking level?

Gemini 3.1 Pro supports three thinking levels, low, medium and high. The default is high (dynamic thinking), and minimal is not supported. On the native API set generationConfig.thinkingConfig.thinkingLevel. Use low for simple tasks to cut latency and output tokens.

Gemini 3.1 Pro or Gemini 4 Argon: which should I use?

On AnyAIGC both cost $0.1985 per 1M input tokens, but Gemini 4 Argon has cheaper output ($0.9927 vs $1.1910) and is generally available, while 3.1 Pro is still a preview. New projects should start with Gemini 4 Argon. If you already tuned prompts and evals for 3.1 Pro, keep it and compare before migrating. For high-volume or latency-sensitive work, look at Gemini 3.8 Flash ($0.0744 input, $0.3722 output).

Are there rate or concurrency limits?

AnyAIGC sets no concurrency limit on gemini-3.1-pro-preview. Every account gets this by default, so batch jobs and parallel agents work out of the box.
