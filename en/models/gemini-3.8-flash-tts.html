About the model

Built for long-form narration and expressive voiceover

Google released Gemini 3.8 Flash TTS as generally available on September 22, 2026, with the model ID gemini-3.8-flash-tts. It does one job: text in, audio out.

Choose one of 30 prebuilt voices, or put two speakers in the same request for podcast-style conversations and support dialogues. Language is detected automatically, and Google lists support for 130+ languages. Fine-tune delivery with inline tags such as <sigh>, <whispers> and <long pause>.

On AnyAIGC you call gemini-3.8-flash-tts through the native /v1beta/models/gemini-3.8-flash-tts:generateContent endpoint and get base64-encoded audio back. No Google Cloud account, no concurrency cap.

Capabilities

What Gemini 3.8 Flash TTS can do

  • 30 prebuilt voices

    From bright Zephyr and firm Kore to warm Sulafat. Each voice has its own character, and switching takes one field: voiceName.

  • Two-speaker dialogue

    Give each of two speakers a voice and render a full podcast segment, interview or support call from one script, with no stitching.

  • Tone and pacing control

    Drop tags like <laugh>, <sigh>, <whispers> and <short pause> into the text to place laughs, breaths and pauses exactly.

  • 130+ languages

    English, Chinese, Japanese and more are detected automatically, no language code needed. The same voice can read in different languages.

  • Stable long-form output

    Google highlights long-form stability. One request returns up to 16,384 audio tokens, about 10 minutes, enough for an audiobook chapter or long narration.

  • Per-token billing

    Audio output is $3.2163 per million tokens. At Google's 25 audio tokens per second, a minute of speech costs about $0.0048, with no per-character minimums.

Start with the Gemini 3.8 Flash TTS API in three steps

  1. Sign up and top up: create an account at anyaigc.ai. Your balance works for every model on the platform.
  2. Create an API key: create a token in the console, copy the key that starts with sk-, and store it in ANYAIGC_API_KEY.
  3. Send a request: call https://anyaigc.ai/v1beta/models/gemini-3.8-flash-tts:generateContent with generationConfig.responseModalities set to ["AUDIO"] and Authorization: Bearer, then decode the audio from inlineData.data.

Tip: Google notes that 3.8 Flash TTS treats text as a literal transcript, so a leading instruction like "Say cheerfully:" may be read aloud. Use inline tags for tone, laughs and pauses instead, such as <laugh>, <sigh>, <whispers>, <short pause> and <long pause>. In two-speaker scripts, the names in the script must match each speaker value.

See the native Gemini TTS API docs and swap the model name for gemini-3.8-flash-tts. Voices, tags and multi-speaker rules are in Google's speech generation docs.

FAQ

Gemini 3.8 Flash TTS API FAQ

How much does the Gemini 3.8 Flash TTS API cost?

On AnyAIGC, gemini-3.8-flash-tts is billed per token: $0.1787 per million text input tokens and $3.2163 per million audio output tokens. Google's standard list price (through December 31, 2026) is $0.50 for text input and $9.00 for audio output, so AnyAIGC is about 36% of list, or roughly 64% off.

How much is one minute of speech? How are audio tokens counted?

Google counts audio at 25 tokens per second, so one minute is 1,500 output tokens, about $0.0048 on AnyAIGC plus a tiny text input charge. An hour of audio is about 90,000 output tokens, roughly $0.29.

What will Google's list price be after 2026?

From January 1, 2027, Google's list price becomes $1.00 for text input and $18.00 for audio output per million tokens. At AnyAIGC's current prices ($0.1787 input, $3.2163 output), that works out to about 18% of list. Live prices are on the AnyAIGC model catalog.

What is the model ID? Is it generally available?

The model ID is gemini-3.8-flash-tts, with no preview suffix. Google made it generally available on September 22, 2026. The native API puts the model name in the URL: /v1beta/models/gemini-3.8-flash-tts:generateContent.

Which voices are available? Which languages?

There are 30 prebuilt voices, such as Kore (Firm), Puck (Upbeat), Charon (Informative) and Sulafat (Warm), set in speechConfig.voiceConfig.prebuiltVoiceConfig.voiceName. Language is detected automatically, and Google lists 130+ supported languages.

Does it support multiple speakers?

Yes, up to 2 speakers per request, using prebuilt voices only. Assign a voice to each speaker in speechConfig.multiSpeakerVoiceConfig.speakerVoiceConfigs, and make sure the names in your script match each speaker value. For shows with more people, synthesize segments and join them.

How do I control tone, emotion and pauses?

Insert inline tags into the text, such as <laugh>, <sigh>, <whispers>, <short pause> and <long pause>. Google notes that 3.8 Flash TTS treats text as a literal transcript, so instructions like "Say cheerfully:" may be read aloud and are no longer recommended.

What audio format comes back? How do I get an MP3?

The audio is base64 in candidates[0].content.parts[0].inlineData.data, and mimeType tells you the format. The AnyAIGC docs example returns audio/L16;codec=pcm;rate=24000: 24kHz, 16-bit, mono PCM. Add a WAV header to play it, or convert to MP3 with ffmpeg -f s16le -ar 24000 -ac 1 -i output.pcm output.mp3. If mimeType is audio/wav, just save the decoded bytes.

How long can one request be?

Google lists an 8,192-token input limit and a 16,384-token output limit, about 10 minutes of audio at 25 tokens per second. For audiobooks and long narration, split by paragraph or chapter, run requests in parallel and join them in order.

Are there concurrency or rate limits?

AnyAIGC does not cap concurrency for gemini-3.8-flash-tts. Every account gets this by default, so whole books or large prompt batches can run at once.
