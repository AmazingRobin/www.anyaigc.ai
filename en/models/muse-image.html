What is Muse Image?

Muse Image is the image generation model Meta Superintelligence Labs released in July 2026, part of the same Muse family as Muse Spark. Meta positions it around three things: following instructions faithfully, editing with precision, and composing from multiple references.

It is not a straight prompt-to-pixels model. Before it renders, it can search for real landmarks, products and current events, or write code to get charts and QR codes exactly right, and it reviews and fixes its own drafts along the way. According to Meta, Muse Image ranked No. 2 on Arena for text-to-image, single-image editing and multi-image editing as of July 5, 2026.

On AnyAIGC the model name is muse-image. It uses the OpenAI-compatible /v1/images/generations endpoint and costs $0.00596 per image, below Meta's list price of $0.01.

What Muse Image can do

  • Faithful prompts and typography

    Headlines, fine print, dates and prices land in the image as written, which suits posters, covers and packaging.

  • Precise edits

    It changes only what you ask for. Prompt: "Edit this to clear up the fog and reveal the beautiful valley below." The car, sign and framing stay put.

  • Multi-turn refinement

    Keep editing in one conversation and every turn stays coherent. Restyle a living room in Japandi, then bring the original lamp and cabinet back.

  • Multi-image composition

    Combine people, objects, clothing, styles and settings from several reference images, with text and images interleaved in the prompt.

  • Web-grounded facts

    It looks up sources and reference images first, so knowledge-heavy and current-events prompts come out more accurate.

  • Code for precise graphics

    It learned to write code for accurate plots and QR codes and then draws the result in. The QR code in this sample points to meta.ai and scans.

Muse Image API FAQ

How much does the Muse Image API cost?

On AnyAIGC, Muse Image (muse-image) costs $0.00596 per image, billed per request rather than by tokens. Meta's list price is $0.01 per image. A request for n images is billed for n images, only successful generations are charged, and live pricing is in the model catalog.

What is Muse Image?

Muse Image is the image generation and editing model Meta Superintelligence Labs released in July 2026. It can search the web and write code before rendering, refines its own drafts, and is built for faithful prompts, precise edits and multi-image composition.

How do I control size and aspect ratio?

Pass size as "WxH", for example "1024x1536". Per Meta's docs this sets the aspect ratio only; the model renders at its own resolution, so returned dimensions will not match exactly. Ratios beyond 16:1 return an error, and omitting size uses the default ratio.

How many images per request, and in what format?

n accepts 1 to 10 (default 1), with one data entry per image. output_format is webp (default), png or jpeg. response_format returns base64 by default, or a temporary link with url.

Can it edit images and combine several references?

Yes. One model handles generation and editing: send an image with an instruction to change only that part, or several images to compose them into one scene. The AnyAIGC model catalog lists muse-image on the image edit endpoint /v1/images/edits as well; check the AnyAIGC API docs for its fields.

Do web search and code tools cost extra?

No. Meta includes its built-in search and code tools in the per-image price, and AnyAIGC bills the same way: $0.00596 per image with no separate tool charge.
