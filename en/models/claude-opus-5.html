Claude Opus 5 API FAQ

How much does the Claude Opus 5 API cost?

On AnyAIGC, claude-opus-5 is billed per token: $0.5956 per million input tokens, $2.978 per million output tokens, $0.7445 for 5-minute cache writes, $1.1912 for 1-hour cache writes, and $0.0596 for cache hits. Anthropic's list price is $5 input and $25 output, so AnyAIGC comes in at about 11.9% of list price.

What is the Claude Opus 5 model ID, and is the API Anthropic-compatible?

The model ID is claude-opus-5. Put it in the model field of your request body. The endpoint is https://anyaigc.ai/v1/messages and the request body follows the Anthropic Messages format (model, max_tokens, system, messages, tools, cache_control, and so on). Authenticate with Authorization: Bearer followed by your API key. With the official SDK, just set the base URL to https://anyaigc.ai.

Opus 4.8 vs Opus 5: what's the difference?

Both have the same list price ($5 input, $25 output), and Anthropic says Opus 5 delivers greatly improved performance for the same cost. In Anthropic's published results, Opus 5 scores 43.3% on Frontier-Bench v0.1 versus 21.1% for Opus 4.8, and 70.6% versus 55.7% on OSWorld 2.0. On AnyAIGC both are billed at about 12% of list price, so upgrading only means changing model to claude-opus-5.

Is Claude Opus 5 deprecated? How long can I use it?

It is not retired. Anthropic lists Claude Opus 5 as a legacy model (Active · Legacy) and commits to retiring it no earlier than July 24, 2027. It still works normally today. For new projects, Anthropic recommends Claude Opus 5.5 (claude-opus-5-5).

Can I use Claude Opus 5 in Claude Code?

Yes. In the env block of ~/.claude/settings.json, set ANTHROPIC_BASE_URL to https://anyaigc.ai, ANTHROPIC_AUTH_TOKEN to your API key, and both ANTHROPIC_MODEL and ANTHROPIC_DEFAULT_OPUS_MODEL to claude-opus-5, then run claude. You can also install and configure everything with one command: curl -fsSL https://www.anyaigc.ai/install.sh | bash.

How is prompt caching billed?

Add cache_control to a content block to enable caching. The first write is billed at the cache write rate ($0.7445 for 5 minutes or $1.1912 for 1 hour, per million tokens). After that, cached tokens cost only $0.0596 per million, about 10% of the regular input price. Caching works well for long system prompts, large codebase context, and multi-turn agent tasks.

Are there concurrency or rate limits?

AnyAIGC sets no concurrency limit on claude-opus-5. Every account gets this by default, so it works well for batch jobs and running multiple agents in parallel.

What is Claude Opus 5 good at?

Anthropic describes Opus 5 as a thoughtful and proactive model that comes close to the frontier intelligence of Claude Fable 5 at half the price. It fits existing Opus 5 integrations, long-running agent tasks, computer use automation, knowledge work, and agentic search. In Anthropic's published results, it scores 43.3% on Frontier-Bench v0.1 and 70.6% on OSWorld 2.0.
