What is Seedream 3.0

Seedream 3.0 is a bilingual Chinese and English image generation foundation model released by the ByteDance Seed team in April 2025. It outputs native 2K and clearly improves on the previous generation in small text, typography, instruction following and aesthetics.

On AnyAIGC the model ID is doubao-seedream-3-0-t2i-250415, billed at $0.0101 per request. It is text-to-image only, with no reference images, editing or image sets.

Get started with the Seedream 3.0 API

  1. Sign up for AnyAIGC. New accounts get 2M free tokens, and you can top up from $1.
  2. Create an API key in the console and save it as the ANYAIGC_API_KEY environment variable.
  3. Send a request to POST https://anyaigc.ai/v1/images/generations (OpenAI-compatible) with model set to doubao-seedream-3-0-t2i-250415.

To migrate, change model to doubao-seedream-4-0-250828 or another newer model, and switch size to tier values such as 2K.

Authenticate with Authorization: Bearer <API Key>. The response looks like {"created": ..., "data": [{"url": ...}]}; set response_format to b64_json to get base64 instead. watermark defaults to true, so pass false explicitly for clean images. Field details are in the AnyAIGC Seedream API docs.

Seedream 3.0 API FAQ

How much does the Seedream 3.0 API cost?

On AnyAIGC, Seedream 3.0 (doubao-seedream-3-0-t2i-250415) starts at $0.0101 / request. 3.0 is billed per request in the model catalog, and each request returns 1 image. You are billed per successful generation; live prices are in the model catalog.

Has Seedream 3.0 been retired?

No. doubao-seedream-3-0-t2i-250415 works normally on AnyAIGC today. However, the current Volcano Engine Ark image generation docs no longer list 3.0, so it may be retired later. For new projects, use Seedream 4.0 or 5.0 lite; the API is identical, so migrating only changes the model ID.

What is Seedream 3.0?

Seedream 3.0 is a bilingual Chinese and English text-to-image foundation model released by the ByteDance Seed team in April 2025. It outputs native 2K, renders small text and typography more accurately, and improves instruction following and aesthetics over the previous generation.

Can 3.0 edit images or take reference images?

No. 3.0 (t2i) is text-to-image only, with no reference images, editing or image sets. Use 4.0 or newer for editing.

What should I put in size?

3.0 takes pixel dimensions for size, for example 1024x1024, 1280x720 or 720x1280.

Is there a concurrency limit? What do I need to sign up?

AnyAIGC sets no concurrency limit on Seedream 3.0, and every account gets this by default. The base URL is https://anyaigc.ai. You do not need a Volcano Engine account or ID verification, and the same key also works with 300+ other models on the platform.

Can AnyAIGC issue invoices, including VAT special invoices?

Yes. AnyAIGC issues invoices for every top-up based on the amount actually paid, including Chinese VAT general and special invoices. Send your billing details to support to get started.

Can my company pay by bank transfer and sign a contract?

Yes. Companies can top up by corporate bank transfer and sign a service agreement with AnyAIGC, with a dedicated support and technical contact. For procurement, contact AnyAIGC sales.

Which payment methods are supported?

You can top up with WeChat Pay, Alipay, USDT or a credit card. Companies can also pay by bank transfer and get VAT general or special invoices. Your balance is in USD and works across every model on the platform.

Is there free trial credit for new users?

Yes. New accounts get 2 million tokens of trial credit, so you can test before deciding to top up. Top-ups start at $1.

Can I get a refund on my balance?

Yes. Unused balance can be refunded with no fee. Contact support to start a refund.

Are these the real models? Is my data safe?

Requests go to official model channels, never cheaper or reverse-engineered substitutes. Unless the law requires it, we do not persistently store your prompts or outputs or use them for training, and the console shows tokens and cost for every request.

Can I use the images commercially? Can I remove the watermark?

Usage rights and content policies follow the official ByteDance / Volcano Engine terms. Set watermark to false in the request and no "AI generated" mark is added to the bottom-right corner. AnyAIGC only provides API access and adds no extra restrictions on how you use the output; for portraits of real people, brand logos and similar content, make sure you have the rights you need.
