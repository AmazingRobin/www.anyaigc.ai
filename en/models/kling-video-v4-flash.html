Kling Video V4 Flash API

Kling Video V4 Flash is the lightweight model in Kuaishou's Kling 4.0 series, built for high-frequency creative work with a focus on speed and cost. It supports text-to-video, first-frame image-to-video and reference-to-video at 720p. On AnyAIGC it is billed per second at $0.1206 / second with unlimited concurrency.

MODEL CAPABILITIES

What Kling Video V4 Flash can do

Summarized from the current model catalog and API reference. Use the API docs for exact parameters.

Text-to-video

Send a prompt and a duration to get a 720p clip of 3–30 seconds. Duration defaults to 5 seconds.

First and last frames

Mark an image in image_list as first_frame. An end_frame must be paired with a first_frame; sending only an end frame returns 400.

Multi-image reference

Up to 10 reference images, cited in the prompt as @image_1, @image_2 in the order you send them, to reuse characters, product looks and scenes.

Reference video

Up to 5 reference videos, feature reference only: public http(s) URLs, at least 3 seconds each and 30 seconds in total, to reuse camera moves and motion rhythm.

Subjects and voices

Up to 7 subjects in element_list and 3 voices in voice_list, cited as @element_1 and so on. All reference assets together may not exceed 15.

Aspect ratio and resolution

Output is fixed at 720p (send mode std or omit it). Aspect ratios are 21:9, 16:9, 9:16, 1:1, or adaptive to follow your assets.

Python

import json
import os
import time
import urllib.request

BASE = "https://anyaigc.ai"
HEADERS = {
    "Authorization": "Bearer " + os.environ["ANYAIGC_API_KEY"],
    "Content-Type": "application/json",
}


def call(method, path, payload=None):
    data = json.dumps(payload, ensure_ascii=False).encode("utf-8") if payload else None
    request = urllib.request.Request(BASE + path, data=data, headers=HEADERS, method=method)
    with urllib.request.urlopen(request, timeout=60) as response:
        return json.load(response)


payload = {
    "model_name": "kling-video-v4-flash",
    "prompt": "The camera glides down to a neon street after rain as an orange cat walks across the wet pavement, cinematic lighting",
    "duration": 5,
    "aspect_ratio": "16:9"
}

task_id = call("POST", "/kling/v1/videos/omni-video", payload)["data"]["task_id"]
print("task_id:", task_id)

# Poll every 10 seconds; print the video URL once the task succeeds
for _ in range(90):
    data = call("GET", f"/kling/v1/videos/omni-video/{task_id}")["data"]
    if data["task_status"] == "succeed":
        break
    if data["task_status"] == "failed":
        raise RuntimeError(data.get("task_status_msg"))
    time.sleep(10)
else:
    raise TimeoutError(task_id)

for video in data["task_result"]["videos"]:
    print(video["url"])

FAQ

Kling Video V4 Flash API FAQ

How much does the Kling Video V4 Flash API cost?

It is billed per second: $0.1206 per second without a reference video and $0.0808 per second with one, always at 720p. Prices are in USD, charged on successful submission; see the model catalog for current rates.

Which endpoint should I call?

Submit with POST /kling/v1/videos/omni-video, setting model_name to kling-video-v4-flash, and fetch results with GET /kling/v1/videos/omni-video/{id}. The API host is https://anyaigc.ai and the header is Authorization: Bearer <API Key>.

Which generation modes are supported?

Text-to-video, first-frame and first-and-last-frame image-to-video, up to 10 reference images, up to 5 reference videos, plus up to 7 subjects and 3 voices. All reference assets together may not exceed 15. See the API reference for the exact fields.

How is it billed, and why is the rate lower with a reference video?

Without a reference video, billed seconds equal the output duration at $0.1206 per second. With one, the rate is $0.0808 per second but billed seconds = output duration + max(total reference-video duration, output duration); a 5-second output with a 5-second reference video bills 10 seconds, or $0.808. Reference images, subjects and voices are free.

What are the resolution, duration and aspect-ratio limits?

Output is fixed at 720p: mode must be std or omitted and resolution must be 720p or omitted; pro or 1080p returns 400 with no charge. duration is an integer from 3 to 30 seconds, default 5. Aspect ratios are 21:9, 16:9, 9:16, 1:1 and adaptive.

What is not supported?

This model does not support sound (on returns 400), multi_shot, the 4K mode, or video editing with refer_type base. Reference videos must use feature.

How do I get the result?

The API is asynchronous. Submission returns a task_id; poll the query endpoint and, once the task succeeds, read the video URL from task_result. Check the API reference for the exact status values and response fields.

Are there concurrency limits?

Kling models on AnyAIGC have unlimited concurrency by default for every account.

Can I use the videos commercially?

Usage rights and content policy follow Kuaishou Kling's official terms. Make sure you have the rights to any reference images or videos you upload.
