AnyAIGC(이하 “본 플랫폼” 또는 “저희”, 웹사이트 주소 anyaigc.ai)에 오신 것을 환영합니다. 저희는 귀하의 개인정보와 데이터 보안을 매우 중요하게 여깁니다. 본 개인정보 처리방침은 귀하의 정보를 어떻게 수집·이용·저장·공유하는지 이해하실 수 있도록 마련되었습니다. 귀하가 저희의 서비스, 웹사이트 및 관련 제품을 이용하시면 본 방침의 조항에 동의하는 것으로 봅니다.

1. 수집하는 정보

안정적인 서비스를 제공하기 위해 저희는 다음과 같은 유형의 정보를 수집해야 합니다.

1.1 계정 정보

귀하가 계정을 등록할 때 저희는 다음 정보를 수집합니다.

  • 이메일 주소
  • 사용자명 / 닉네임
  • 비밀번호(암호화하여 저장)
  • 연락처(예: 휴대폰 번호, 인증 또는 긴급 통지에 사용)

1.2 이용 데이터와 로그

귀하가 본 플랫폼의 서비스를 이용할 때, 저희는 과금, 장애 원인 파악 및 보안 모니터링을 위해 특정 기술 데이터를 자동으로 기록합니다.

  • 메타데이터: 요청 시각, 출발지 IP 주소, 요청 유형, 사용량 등
  • 콘텐츠 데이터(전송 중): 귀하의 입력 내용과 모델의 출력 내용
설명: 법령에서 요구하는 경우를 제외하고, 저희는 귀하의 콘텐츠 데이터를 모델 학습을 위해 영구 저장하지 않습니다.

1.3 결제 정보

저희는 제3자 결제 처리업체를 통해 거래를 처리합니다. 저희는 귀하의 신용카드 전체 번호나 민감한 은행 계좌 정보를 직접 저장하지 않으며, 장부 확인을 위해 거래 기록, 주문 번호 및 충전 금액만 보관합니다.

2. 귀하의 정보를 이용하는 방법

  • 핵심 서비스 제공: 귀하의 신원을 확인하고, 귀하의 요청을 처리하여 결과를 반환합니다.
  • 과금과 관리: 귀하의 사용량을 정확히 계산하고 계정 잔액에서 해당 요금을 차감합니다.
  • 시스템 유지와 보안: 서버 부하를 모니터링하고, 이상 트래픽을 탐지하며, 기술 장애를 처리합니다.
  • 통지와 소통: 귀하에게 서비스 변경 통지, 충전 알림 또는 계정 보안 경보를 발송합니다.
  • 법령 준수: 적용되는 법령의 요구를 준수합니다.

3. 정보의 공유와 공개

3.1 제3자 서비스 제공업체

귀하가 본 플랫폼의 서비스를 이용할 때, 귀하의 요청 내용은 처리를 위해 해당 제3자 서비스 제공업체에 전달될 수 있습니다. 이러한 제공업체는 각자의 개인정보 처리방침에 따라 귀하의 데이터를 처리합니다.

3.2 인프라 서비스 제공업체

저희는 플랫폼 운영을 유지하기 위해 호스팅, 데이터베이스, 보안 및 결제 서비스를 제공하는 제3자 회사와 필요한 비콘텐츠 데이터를 공유할 수 있습니다.

3.3 법령상 요구

다음과 같은 경우 저희는 귀하의 정보를 공개할 수 있습니다.

  • 법원 명령, 법적 절차 또는 정부 기관의 강제적 요구를 준수하기 위한 경우
  • AnyAIGC, 저희의 사용자 또는 공중의 권리, 재산 또는 안전을 보호하기 위하여

4. 데이터 저장과 보안

4.1 데이터 저장

귀하의 계정 및 메타데이터는 저희의 보안 서버에 저장됩니다. 로그 데이터는 주로 성능 최적화와 감사를 위해 전문 데이터베이스를 사용하여 보관·분석할 수 있습니다.

4.2 데이터 보안

저희는 귀하의 데이터를 보호하기 위해 업계 표준의 보안 조치를 취하며, 여기에는 다음이 포함됩니다.

  • 모든 트래픽을 TLS/SSL로 암호화하여 전송
  • 민감한 인증 정보를 암호화된 해시로 저장
  • 엄격한 내부 접근 통제를 시행하여 권한을 부여받은 인원만 핵심 시스템에 접근 가능

4.3 데이터 보관

저희는 귀하가 계정을 해지할 때까지 귀하의 개인정보를 보관합니다. 접속 로그는 장애 원인 파악을 위해 일반적으로 30일간 보관하며, 그 이후에는 삭제하거나 익명 처리합니다.

5. 귀하의 권리

  • 열람과 정정: 관리 화면에 로그인하여 귀하의 이용 기록, 잔액 및 프로필을 확인합니다.
  • 계정 삭제: 귀하는 저희에게 연락하여 계정 해지를 신청할 수 있습니다. 해지 후 저희는 귀하의 민감한 개인정보를 삭제합니다(법령상 보관이 요구되는 거래 기록은 제외).
  • 데이터 내보내기: 귀하는 귀하의 거래 기록과 주요 이용 데이터의 내보내기를 요청할 권리가 있습니다.

6. 국경 간 데이터 이전

본 플랫폼의 서비스를 이용하시면, 귀하의 데이터가 국경을 넘어 이전될 수 있음을 이해하시는 것으로 봅니다. 귀하의 요청이 해외 서비스와 관련되는 경우, 데이터는 해당 서비스 제공업체가 소재한 관할 지역으로 전송됩니다. 저희는 데이터 전송의 안전을 확보하기 위해 상업적으로 합리적인 노력을 다합니다.

7. 개인정보 처리방침의 변경

저희는 사업 발전에 따라 본 방침을 변경할 수 있습니다. 중대한 변경이 있을 경우 웹사이트 공지 또는 이메일로 알려 드립니다. 최신 개인정보 처리방침을 확인하시려면 이 페이지를 정기적으로 살펴보실 것을 권합니다.
