07 / FAQ

자주 묻는 질문

AnyAIGC에서 인보이스를 받을 수 있습니까?

네. 콘솔에서 직접 인보이스를 발급할 수 있으며, 실제 충전한 금액 기준으로 발급됩니다.

신규 계정에 무료 체험 크레딧이 제공됩니까?

네. 신규 계정에는 200만 토큰이 무료로 제공되므로 모델과 연동을 소규모로 먼저 시험해 볼 수 있습니다.

사용하지 않은 잔액을 환불받을 수 있습니까?

네. 사용하지 않은 잔액은 수수료 없이 환불받을 수 있습니다.

대체 모델을 사용합니까? 내 데이터는 안전합니까?

공식 모델 채널을 사용하며, 저가 모델이나 리버스 엔지니어링 방식의 대체 모델은 쓰지 않습니다. 법령에서 요구하는 경우를 제외하고 입력과 출력을 영구 저장하거나 학습에 사용하지 않습니다. 개인정보 처리방침을 참고하세요.

어떤 결제 수단을 지원합니까?

WeChat Pay, Alipay, USDT, 신용카드로 충전할 수 있습니다. 잔액은 USD 기준이며 플랫폼의 모든 모델에서 공통으로 사용할 수 있습니다. 인보이스는 콘솔에서 충전한 금액 기준으로 발급할 수 있습니다.

기존 프로젝트는 어떻게 연결합니까?

OpenAI SDK를 쓰는 대부분의 프로젝트는 Base URL을 https://anyaigc.ai/v1로 바꾸고 콘솔에서 받은 API 키와 모델 ID를 넣으면 됩니다. 인증에는 Authorization: Bearer <API Key>를 사용합니다. 모델 ID, 가격, 제공 여부는 콘솔과 모델 페이지의 실시간 정보를 따릅니다.

어떤 개발 도구를 지원합니까?

Claude Code, Codex, OpenClaw, Hermes, Cursor, Dify, Cherry Studio, Chatbox, OpenWebUI, n8n을 지원합니다. 설정 가이드는 API 문서에 있습니다.
