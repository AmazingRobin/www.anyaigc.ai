GPT Image 2.6 Flare: 빠른 이미지, 애니메이션까지

OpenAI는 2026년 11월 4일 Sunburst와 Flare, 두 가지 API 모델로 Images 2.6을 출시했습니다. OpenAI는 Flare를 빠른 반복 작업을 위한 이미지 생성 및 편집 모델로 설명합니다. Images 2.6은 이전보다 이미지를 50% 더 빠르게 생성하고, Flare는 낮은 품질 이미지를 최단 6초에 완성할 수 있으며, 포스터, 제품 이미지 등 전문 비주얼의 레이아웃 품질도 향상되었습니다.

Flare는 Sunburst와 같은 파라미터를 사용합니다. 여기에 complexity(low, medium, high), markup을 이용한 마크업 기반 편집, SVG 출력, 애니메이션 GIF 출력이 추가됩니다. 품질 단계는 low, medium, high, xhigh, max, auto입니다. 가장 긴 변이 3840px 이하, 두 변 모두 16의 배수, 가로세로 비율 3:1 이하, 전체 픽셀 수 655,360 이상 8,294,400 이하이면 크기를 자유롭게 지정할 수 있습니다.

AnyAIGC에서 Flare와 2.6 Sunburst의 가격은 같으며, 공식 정가의 약 8%입니다. 토큰 단위 과금에서 1024×1024 이미지는 low 품질에서 약 $0.0020, medium 품질에서 $0.0036입니다. 이미지당 고정 비용으로 예산을 쉽게 잡으려면 이미지당 $0.0206인 gpt-image-2.6-flare-c를 사용하세요.

2.6 Flare의 새로운 기능

Sunburst와 Flare 모두 지원하며, 요청 필드도 같습니다.

  • 더 빠른 생성

    OpenAI에 따르면 Images 2.6은 이전보다 50% 빠르며, Flare는 낮은 품질 이미지를 최단 6초에 반환할 수 있습니다.

  • 더 안정적인 편집

    Sunburst는 medium과 high 품질에서 여러 번 편집해도 캐릭터, 제품, 브랜드 디테일을 일관되게 유지합니다.

  • 애니메이션 GIF

    format을 gif로 설정하고 frame_count(2–64)와 frame_duration_ms로 애니메이션을 제어하세요.

  • SVG 출력

    format을 svg로 설정하면 편집 가능한 경로, 도형, 색상을 얻을 수 있어 로고와 아이콘에 적합합니다.

  • 마크업 기반 편집

    투명 PNG 주석 레이어를 markup으로 보내 변경할 부분을 표시한 뒤, 프롬프트에 변경 내용을 설명하세요.

  • complexity 설정

    low, medium, high로 모델이 얼마나 계획을 세울지 조절합니다. 빠른 편집에는 low, 밀도 높은 레이아웃에는 high를 사용하세요. 추가 비용은 없습니다.

GPT Image 2.6 Flare API 가격은 얼마입니까?

AnyAIGC에서 gpt-image-2.6-flare는 토큰 단위로 과금되며, 100만 토큰당 텍스트 입력 $0.4118, 이미지 입력 $0.6589, 이미지 출력 $2.4710이고, 캐시 텍스트 입력은 $0.1647, 캐시 이미지 입력은 $0.2636입니다. OpenAI 공식 정가는 $5.00, $8.00, $30.00이므로 AnyAIGC는 공식 정가 대비 약 92% 할인입니다. 1024×1024 이미지의 이미지 출력 비용은 low 품질에서 약 $0.0020(공식 정가 기준 $0.0247), medium 품질에서 $0.0036(공식 정가 기준 $0.0435)입니다. 이미지당 과금 버전 gpt-image-2.6-flare-c는 이미지당 $0.0206입니다. 실시간 가격은 모델 카탈로그에서 확인하세요.

Flare와 Sunburst 중 무엇을 써야 합니까? GPT Image 2.5와 달라진 점은 무엇입니까?

둘 다 GPT Image 2.6이며 AnyAIGC에서 요율과 파라미터가 같습니다. Flare는 빠른 반복 작업을 위해 만들어졌고 low 품질 이미지를 최단 6초 만에 반환할 수 있어 앱 내 생성, 초안, GIF에 적합합니다. Sunburst는 디테일이 중요한 시각 작업을 위해 만들어졌으며 여러 차례의 편집에서 더 안정적입니다. GPT Image 2.5 Flare와 비교하면 2.6에는 complexity, markup, SVG, GIF가 추가되었습니다. low와 medium 품질에서는 이미지당 출력 토큰이 2.5보다 많고, high 이상에서는 같습니다.

GIF와 SVG는 어떻게 생성합니까?

둘 다 POST /v1/images/generations를 사용합니다. GIF는 format을 gif로, frame_count를 2–64(기본값 9)로, frame_duration_ms를 20–2000 ms(기본값 200)로 지정하며, size는 각 프레임의 크기입니다. SVG는 format을 svg로, n을 1로 지정합니다. quality는 SVG의 바탕이 되는 참조 이미지에 적용되며, 결과물은 정적 벡터 콘텐츠입니다. 둘 다 edits 엔드포인트, 스트리밍, 압축 설정과는 함께 사용할 수 없습니다.

complexity와 마크업 기반 편집은 어떻게 동작합니까?

complexity에는 low, medium, high를 지정할 수 있으며 기본값은 high입니다. 값을 바꿔도 추가 요금은 없습니다. OpenAI는 대부분의 편집에는 필요한 품질과 함께 low를 쓰고, 요소나 제약이 많은 장면에는 medium 또는 high를 쓰도록 권장합니다. 마크업 편집은 POST /v1/images/edits를 사용합니다. 원본을 첫 번째 image로 보내고, 같은 가로세로 크기의 투명 PNG를 markup으로 함께 보냅니다. 변경할 영역을 표시하고 프롬프트에 변경 내용을 설명하세요. markup은 mask와 함께 사용할 수 없습니다.

이미지당 과금 버전이 있습니까? gpt-image-2.6-flare-c는 요금이 어떻게 됩니까?

네. gpt-image-2.6-flare-c는 GPT Image 2.6 Flare의 이미지당 과금 버전입니다. 같은 엔드포인트를 쓰며 model 필드만 바뀝니다. 1K, 2K, 4K 모두, 어떤 품질 수준에서도 이미지당 $0.0206의 고정 가격입니다. 요청 한 번에 이미지 한 장을 반환하며 n, mask, 투명 배경은 지원하지 않습니다. 대부분의 품질 수준과 크기에서는 토큰 과금이 이미지당 더 저렴합니다(1024×1024, medium 품질에서 약 $0.0036). 이미지당 과금은 주로 예산을 쉽게 잡을 수 있는 고정 가격이 필요할 때 유용하며, 2048×2048과 3840×2160의 max 품질에서만 더 저렴해집니다.
