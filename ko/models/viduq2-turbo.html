Python
import json
import os
import time
import urllib.request

BASE = "https://anyaigc.ai"
HEADERS = {
    "Authorization": "Bearer " + os.environ["ANYAIGC_API_KEY"],
    "Content-Type": "application/json",
}


def call(method, path, body=None):
    data = json.dumps(body, ensure_ascii=False).encode("utf-8") if body else None
    request = urllib.request.Request(BASE + path, data=data, headers=HEADERS, method=method)
    with urllib.request.urlopen(request, timeout=60) as response:
        return json.load(response)


payload = {
    "model": "viduq2-turbo",
    "images": [
        "https://www.anyaigc.ai/assets/models/vidu/skycity.webp"
    ],
    "prompt": "Slow push-in as the sea of clouds rolls, distant city lights flicker on and the girl's red cape lifts in the wind.",
    "duration": 5,
    "resolution": "540p"
}

created = call("POST", "/ent/v2/img2video", payload)
task_id = (created.get("data") or created)["task_id"]
print("task_id:", task_id)

# Poll every 10 seconds until the task leaves the queue
for _ in range(120):
    result = call("GET", f"/ent/v2/tasks/{task_id}/creations")
    state = (result.get("data") or result).get("state") or (result.get("data") or result).get("status")
    if state not in ("created", "queueing", "processing"):
        break
    time.sleep(10)

# creations holds the video or image URLs; they expire, so download promptly
print(json.dumps(result, ensure_ascii=False, indent=2))

샘플 이미지를 직접 준비한 URL 또는 Base64(png, jpeg, webp, 최대 50 MB)로 바꾸세요. status 필드는 실제 응답에서 읽으세요. 예제는 작업이 created, queueing, processing 상태를 벗어나면 폴링을 멈춥니다.

사양

사양과 선택 기준

Vidu는 viduq2-turbo를 빠른 생성이 가능한 새 모델이라고 설명합니다.

viduq2-turbo는 이미지→비디오와 첫/마지막 프레임을 지원하지만, 참조→비디오와 텍스트→비디오는 지원하지 않습니다.

출력은 24fps의 540p, 720p, 1080p이며, 길이는 1초부터 10초까지 선택할 수 있습니다.

이 페이지에는 이미지 & 첫/마지막 프레임 540p $0.0223, 이미지 & 첫/마지막 프레임 720p $0.0298, 이미지 & 첫/마지막 프레임 1080p $0.1303이 표시되어 있으며, 위 가격표와 일치합니다.

더 나은 시각적 미감이 필요하거나 참조→비디오와 비디오 편집이 필요하면 viduq2-pro를 선택하세요.

사양은 벤더의 공식 문서(platform.vidu.com)를 따릅니다. 이 페이지의 표는 가격이며, 실시간 요금은 모델 카탈로그를 기준으로 합니다.

FAQ

Vidu Q2 Turbo API 자주 묻는 질문

가격, 엔드포인트, 결과물, 기업 도입을 한곳에서 확인하세요.

Vidu Q2 Turbo API 요금은 얼마입니까?

이미지 & 첫/마지막 프레임 540p: 첫 1초 $0.0223, 이후 초당 +$0.00744; 이미지 & 첫/마지막 프레임 720p: 첫 1초 $0.0298, 2초 $0.0372, 이후 초당 +$0.0372; 이미지 & 첫/마지막 프레임 1080p: 첫 1초 $0.1303, 이후 초당 +$0.0372. 이미지 또는 참조 입력에서 네이티브 오디오를 사용하면 작업당 $0.0558, 추천 프롬프트를 사용하면 $0.0372가 추가됩니다. 가격 단위는 USD이며, 현재 요금은 모델 카탈로그에서 확인하세요.

어떤 엔드포인트를 호출해야 합니까?

POST /ent/v2/img2video, POST /ent/v2/start-end2video를 호출하며 model을 viduq2-turbo로 지정합니다. 생성 요청은 task_id를 반환하고, 결과는 GET /ent/v2/tasks/{id}/creations로 조회합니다. 기본 URL은 https://anyaigc.ai이고, 키는 Authorization: Bearer에 넣습니다.

첫 1초 + 초당 과금은 어떻게 계산합니까?

요금은 길이에 따라 누적됩니다. 첫 1초는 한 가지 요율이고, 이후 1초마다 고정 금액이 추가됩니다. 이미지 & 첫/마지막 프레임 540p에서 5초 클립은 $0.05206입니다. 길이는 540p / 720p / 1080p에서 1–10초입니다.

결과는 어떻게 받습니까?

작업은 비동기입니다. task_id를 보관하고 GET /ent/v2/tasks/{id}/creations를 폴링하세요. 작업이 끝나면 creations에서 비디오 또는 이미지 URL을 읽습니다. 작업을 생성할 때 callback_url을 전달할 수도 있습니다. 결과 URL은 만료되므로 파일을 바로 저장하세요.

동시 실행 수나 RPM 제한이 있습니까?

AnyAIGC의 Vidu는 모든 계정에 기본으로 동시 실행 제한이 없으며, 고정 RPM 상한도 없습니다. 비디오 생성에는 시간이 걸리므로 애플리케이션에서 폴링 간격과 타임아웃을 설정하세요.

출력물을 상업적으로 사용할 수 있습니까?

상업적 이용은 Vidu(ShengShu Technology)의 공식 약관을 따르며, 업로드하는 참조 이미지, 인물, 브랜드 자산에 대한 권리는 직접 확보해야 합니다. AnyAIGC는 독립 API 제공업체입니다.

AnyAIGC에서 인보이스를 받을 수 있습니까?

네. 콘솔에서 실제 충전한 금액 기준으로 직접 인보이스를 발급할 수 있습니다.

어떤 결제 수단을 지원합니까?

WeChat Pay, Alipay, USDT, 신용카드로 충전할 수 있습니다. 잔액은 USD 기준이며 플랫폼의 모든 모델에서 사용할 수 있습니다. 인보이스는 콘솔에서 충전한 금액 기준으로 발급할 수 있습니다.

신규 사용자에게 무료 체험 크레딧이 있습니까?

네. 신규 계정에는 토큰 200만 개 분량의 체험 크레딧이 제공되므로 충전 여부를 결정하기 전에 먼저 테스트할 수 있습니다. 충전은 $1부터 가능합니다.

잔액을 환불받을 수 있습니까?

네. 사용하지 않은 잔액은 수수료 없이 환불받을 수 있습니다. 환불은 고객 지원에 문의해 진행하세요.

실제 모델이 맞습니까? 데이터는 안전합니까?
