01 · JEV-1.13.0 소개

jev-1.13.0: 첫 공개 System One 모델

채팅 LLM은 파싱해야 할 문단을 돌려줍니다. jev-1.13.0은 코드가 바로 쓸 수 있는 값, 즉 확률, 선택지, 점수를 돌려줍니다.

TypeSafe AI는 2026년 9월 15일 jev-1.13.0을 첫 공개 System One 모델로 발표했습니다. 이름은 카너먼의 시스템 1, 곧 인간 판단의 빠르고 직관적인 측면에서 따왔습니다. TypeSafe에 따르면 Jev는 RLCD(Reinforcement Learning for Calibrated Decisions)와 병렬 샘플러로 학습했으며, 자유 형식 텍스트 대신 보정된 확률이 포함된 타입 지정 응답을 반환합니다.

스마트한 if 문이라고 생각하세요. 판단할 내용은 state에 넣고, 이름과 타입이 있는 질문은 questions에 정의하면, 모든 질문이 요청 한 번에 병렬로 처리됩니다. 질문 개수에는 제한이 없습니다. TypeSafe는 응답이 항상 요청한 타입과 일치하도록 보장하므로, 파싱이나 재시도 로직을 작성할 필요가 없습니다.

04 · 활용 사례

jev-1.13.0이 잘 맞는 작업

코드가 분기하고, 정렬하고, 알림을 보낼 수 있는 결과가 필요한 모든 곳에 사용하세요.

    분류와 의도 파악

    티켓 라우팅

    요청 한 번으로 어느 팀 담당인지, 긴급한지, 고객이 얼마나 화가 났는지 알 수 있어 담당자와 큐의 우선순위를 정할 수 있습니다.

    위험 점수화

    거래, 주문, 계정을 직접 정의한 단계로 점수화하세요. 점수는 확률 가중 소수라서 임곗값을 정하기 쉽습니다.

    콘텐츠 검수

08 · 빠른 시작

세 단계로 jev-1.13.0 API 호출하기

Jev는 OpenAI 호환이 아닙니다. 일반 HTTP로 /v1/systemone을 호출하세요.

  1. 가입 후 충전: anyaigc.ai에서 계정을 만드세요. 잔액은 모든 모델에서 공통으로 사용할 수 있습니다.
  2. API 키 만들기: 콘솔에서 sk-로 시작하는 키를 만들고 ANYAIGC_API_KEY 환경 변수에 저장하세요.
  3. 요청 보내기: https://anyaigc.ai/v1/systemone로 POST하고, model은 jev-1.13.0으로 설정하며 state와 questions를 함께 보내세요. 응답은 동기식이므로 폴링할 필요가 없습니다.

요청은 32k 토큰 이내로 유지하세요. AnyAIGC에서 jev-1.13.0의 컨텍스트 길이는 32k 토큰입니다. 더 긴 입력은 여러 요청으로 나누거나, state에서 관련 없는 텍스트를 줄이거나, 256k 컨텍스트의 jev-1.14.0으로 옮기세요.

응답 값은 AnyAIGC API 문서에서 가져왔습니다. model은 실행된 버전을 그대로 돌려주며, usage.output_tokens는 과금되지 않습니다. 잘못된 본문은 400, 잘못된 키는 401을 반환하며, 오류 본문은 {"error": {"code", "message", "param", "type"}} 형태입니다. 전체 파라미터는 AnyAIGC System One API 문서에서 확인하세요.

jev-1.13.0 API 자주 묻는 질문

jev-1.13.0이란 무엇입니까?

jev-1.13.0은 2026년 9월 15일에 발표된 TypeSafe AI의 System One 모델 Jev의 최초 공개 버전입니다. System One이라는 이름은 카너먼이 말한 빠르고 직관적인 판단에서 따왔습니다. 판단할 콘텐츠(state)와 유형이 지정된 질문 묶음을 보내면, Jev는 자유 텍스트 대신 보정된 확률이 포함된 타입 지정 답변을 반환합니다. AnyAIGC에서는 32k 토큰 컨텍스트를 갖추고 noul, choice, score 질문 유형을 지원합니다.

jev-1.13.0은 지원이 중단되었습니까?

아니요. 새 버전인 jev-1.14.0이 2026년 10월 14일에 출시되었지만, jev-1.13.0은 AnyAIGC에서 계속 호출할 수 있으며 종료 일정은 발표되지 않았습니다. TypeSafe는 jev-1.13.0을 종료하기 60일 전에 공지하겠다고 밝혔습니다. 기존 연동은 계속 실행할 수 있으며, 새 프로젝트에는 jev-1.14.0을 권장합니다.

jev-1.13.0 API 요금은 얼마입니까?

AnyAIGC에서 jev-1.13.0은 입력 100만 토큰당 $0.0227이며 출력은 무료입니다. 토큰 단위로 과금하며 입력 토큰에만 요금이 부과됩니다. 예를 들어 입력 300토큰짜리 요청 1,000,000건은 300M 토큰이며 $6.81입니다. 동시 실행은 모든 사용자에게 제한이 없습니다. 실시간 가격은 AnyAIGC 모델 카탈로그에서 확인하세요.

jev-1.13.0과 jev-1.14.0은 무엇이 다릅니까?

jev-1.13.0은 32k 토큰 컨텍스트, 텍스트 입력, noul, choice, score 질문 유형을 갖춘 최초 공개 릴리스(2026년 9월 15일)입니다. jev-1.14.0(2026년 10월 14일)은 전반적으로 소폭 개선되었고, TypeSafe에 따르면 다국어에서 가장 크게 좋아졌습니다. AnyAIGC에서는 256k 토큰 컨텍스트를 갖추고 실험적 이미지 입력과 box 질문 유형이 추가되었습니다. 두 모델의 가격은 같습니다.

jev-1.13.0 API는 OpenAI 호환입니까?

아니요. Jev는 TypeSafe의 System One API를 사용합니다. 본문에 model, state, questions를 넣어 POST https://anyaigc.ai/v1/systemone를 호출하면 응답으로 answers와 usage가 돌아옵니다. messages나 choices가 없으므로 OpenAI SDK로는 호출할 수 없습니다. requests, fetch, cURL로 일반 HTTP를 사용하고 평소처럼 Authorization: Bearer <API Key> 헤더를 붙이세요. 호출은 동기식이며 스트리밍과 작업 폴링이 없습니다.

jev-1.13.0의 한계는 무엇입니까?

TypeSafe에 따르면 Jev는 표현을 문자 그대로 읽고, 계산기가 아니며(수학과 개수 세기는 피하세요), 날짜 비교와 다단계 질문에 약하고, state에 관련 없는 텍스트가 많으면 정확도가 떨어지며, 프롬프트 인젝션의 영향을 받을 수 있고, 선택형 질문에서 첫 번째 선택지를 약간 선호합니다. 텍스트는 생성하지 않습니다. 영어에서 가장 잘 동작하며 다른 언어도 동작하지만 정확도가 낮습니다. 제3자 arXiv 논문에서도 저자원 언어, 노이즈 레이블, 루브릭 방식의 품질 판단에서 더 약하다고 보고했습니다.

실제 모델이 맞습니까? 데이터는 안전합니까?

요청은 공식 모델 채널로 전달되며, 저가 모델이나 리버스 엔지니어링 방식의 대체 모델은 사용하지 않습니다. 법령에서 요구하는 경우를 제외하고 프롬프트와 출력을 영구 저장하거나 학습에 사용하지 않으며, 콘솔에서 모든 요청의 토큰 수와 비용을 확인할 수 있습니다.
