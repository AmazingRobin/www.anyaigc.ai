Claude Haiku 5.5 API FAQ

Claude Haiku 5.5 API 가격은 얼마입니까?

AnyAIGC에서 claude-haiku-5-5는 토큰 단위로 과금됩니다. 100K 토큰 이하 프롬프트 기준으로 입력은 100만 토큰당 $0.0119, 출력은 $0.0596, 5분 캐시 쓰기는 $0.0149, 1시간 캐시 쓰기는 $0.0238, 캐시 히트는 $0.0012입니다. Anthropic 공식 정가는 입력 $0.10, 출력 $0.50이므로 AnyAIGC는 공식 정가의 약 11.9% 수준입니다. Haiku 5.5는 구간별 가격을 적용합니다. 단일 프롬프트가 100K 토큰을 넘으면 모든 항목이 5배로 과금됩니다(Anthropic은 이 구간을 입력 $0.50, 출력 $2.50으로 표기합니다).

Claude Haiku 5.5의 모델 ID는 무엇입니까?

모델 ID는 claude-haiku-5-5입니다. 요청 본문의 model 필드에 넣으세요.

AnyAIGC Claude API는 Anthropic 공식 API와 호환됩니까?

네. 엔드포인트는 https://anyaigc.ai/v1/messages이며 요청 본문은 Anthropic Messages 형식(model, max_tokens, system, messages, tools, cache_control 등)을 따릅니다. 인증은 Authorization: Bearer 뒤에 API 키를 붙여 사용합니다. 공식 SDK를 사용한다면 base URL만 https://anyaigc.ai로 설정하면 됩니다.

Claude Code에서 Claude Haiku 5.5를 사용할 수 있습니까?

네. ~/.claude/settings.json의 env 블록에서 ANTHROPIC_BASE_URL을 https://anyaigc.ai로, ANTHROPIC_AUTH_TOKEN을 API 키로, ANTHROPIC_DEFAULT_HAIKU_MODEL을 claude-haiku-5-5로 설정합니다. 그러면 백그라운드 작업과 서브 에이전트는 Haiku 5.5로 실행되고, ANTHROPIC_MODEL은 claude-opus-5-5로 유지할 수 있습니다. 모든 작업에 Haiku 5.5를 쓰려면 ANTHROPIC_MODEL도 claude-haiku-5-5로 설정합니다. 명령어 하나로 설치와 설정을 한 번에 진행할 수도 있습니다: curl -fsSL https://www.anyaigc.ai/install.sh | bash.

프롬프트 캐싱은 어떻게 과금됩니까?

콘텐츠 블록에 cache_control을 추가하면 캐싱이 활성화됩니다. 첫 쓰기는 캐시 쓰기 요금(100만 토큰당 5분 $0.0149, 1시간 $0.0238)으로 과금됩니다. 이후 캐시된 토큰은 100만 토큰당 $0.0012만 청구되며, 이는 일반 입력 가격의 약 10%입니다. 캐싱은 고정된 분류 규칙, 긴 시스템 프롬프트, 반복해서 보내는 서브 에이전트 지침에 가장 효과적입니다.

동시 실행 수나 속도 제한이 있습니까?

AnyAIGC는 claude-haiku-5-5에 동시 실행 제한을 두지 않습니다. 모든 계정에 기본으로 적용되므로 배치 분류, 실시간 지원 트래픽, 다수 서브 에이전트의 병렬 실행에 적합합니다.

Claude Haiku 5.5는 어떤 작업에 적합합니까?

Anthropic은 Haiku 5.5를 Claude 5.5 제품군에서 가장 빠르고 효율적인 모델이라고 설명하며, 대량 처리와 비용에 민감한 작업용으로 만들었다고 밝혔습니다. 배치 분류와 라우팅, 코딩 작업의 서브 에이전트, 실시간 고객 지원, 브라우저 사용에 적합합니다. Anthropic이 공개한 결과에 따르면 OSWorld 2.1(오프라인 하위 집합)에서 72.4%를 기록했습니다. 또한 Anthropic은 복잡한 에이전틱 코딩에는 Sonnet 5.5와 Opus 5.5가 여전히 더 나은 선택이라고 설명합니다.

Claude Haiku 5.5 API 키는 어떻게 발급받습니까?

anyaigc.ai에서 가입하고 잔액을 충전한 뒤 콘솔에서 토큰을 생성합니다. 같은 키로 Claude Haiku 5.5와 플랫폼의 300개 이상 다른 모델을 사용할 수 있습니다.

AnyAIGC에서 인보이스를 받을 수 있습니까?

네. 콘솔에서 실제 충전한 금액 기준으로 직접 인보이스를 발급할 수 있습니다.

어떤 결제 수단을 지원합니까?

WeChat Pay, Alipay, USDT, 신용카드로 충전할 수 있습니다. 잔액은 USD 기준이며 플랫폼의 모든 모델에서 사용할 수 있습니다. 인보이스는 콘솔에서 충전한 금액 기준으로 발급할 수 있습니다.

신규 사용자에게 무료 체험 크레딧이 있습니까?

네. 신규 계정에는 토큰 200만 개 분량의 체험 크레딧이 제공되므로 충전 여부를 결정하기 전에 먼저 테스트할 수 있습니다. 충전은 $1부터 가능합니다.

잔액을 환불받을 수 있습니까?

네. 사용하지 않은 잔액은 수수료 없이 환불받을 수 있습니다. 환불은 고객 지원에 문의해 진행하세요.

실제 모델이 맞습니까? 데이터는 안전합니까?

요청은 공식 모델 채널로 전달되며, 저가 모델이나 리버스 엔지니어링 방식의 대체 모델은 사용하지 않습니다. 법령에서 요구하는 경우를 제외하고 프롬프트와 출력을 영구 저장하거나 학습에 사용하지 않으며, 콘솔에서 모든 요청의 토큰 수와 비용을 확인할 수 있습니다.

내 데이터가 학습에 사용됩니까?

요청은 HTTPS로 전송 중 암호화됩니다. 데이터 처리에 관한 자세한 내용은 AnyAIGC 개인정보 처리방침을 참고하세요. 모델 자체의 데이터 정책은 Anthropic 공식 약관을 따릅니다.
