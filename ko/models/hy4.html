import os
from openai import OpenAI

client = OpenAI(api_key=os.environ["ANYAIGC_API_KEY"], base_url="https://anyaigc.ai/v1")

stream = client.chat.completions.create(
    model="hy4",
    messages=[{"role": "user", "content": "Introduce yourself in three sentences and say what tasks you are best at."}],
    stream=True,
)
for chunk in stream:
    if chunk.choices and chunk.choices[0].delta.content:
        print(chunk.choices[0].delta.content, end="", flush=True)
print()

FAQ

Hy4 API 자주 묻는 질문

Hy4 API 가격은 얼마이며, 공식 정가보다 얼마나 저렴합니까?

토큰 단위로 USD 기준 100만 토큰당 과금합니다. 입력 $0.5630(공식 정가 $0.834), 출력 $1.6880(공식 정가 $2.501), 캐시 히트 $0.0283(공식 정가 $0.042)입니다. Tencent Cloud의 공식 정가는 입력 ¥6, 출력 ¥18, 캐시 히트 ¥0.3이며, USD 정가는 1달러당 약 7.19 CNY로 환산했습니다. AnyAIGC의 세 가지 요금은 모두 공식 정가의 약 67.5%로, 약 32% 저렴합니다. 실시간 요금은 모델 카탈로그에서 확인하세요.

Hy4와 Hy4 프리뷰는 무엇이 다릅니까?

Tencent의 릴리스 노트(2026-11-04)에 따르면 정식 Hy4는 처음으로 비전과 컴퓨터 사용을 지원하고, 에이전트와 장시간 작업 성능을 강화했으며, 자체 테스트의 환각률을 프리뷰의 15.76%에서 5.45%로 낮췄습니다. 또 Tencent는 API 가격이 프리뷰와 같다고 밝혔습니다. 이 수치는 릴리스 노트에서 가져온 것이며 AnyAIGC에서 다시 테스트하지 않았습니다.

Hy4는 이미지 입력을 지원합니까?

네. Tencent는 Hy4가 처음으로 비전을 지원한다고 밝혔습니다. POST /v1/chat/completions에서 image_url 콘텐츠 파트에 이미지 URL 또는 base64 데이터를 보내세요. 출력은 텍스트입니다. 현재 AnyAIGC 문서에는 이미지 크기나 개수 제한이 명시되어 있지 않으므로 문서를 따르세요.

어떤 API 엔드포인트를 사용해야 합니까?

두 형식 모두 사용할 수 있습니다. OpenAI 호환 POST https://anyaigc.ai/v1/chat/completions와 Anthropic 스타일 POST https://anyaigc.ai/v1/messages이며, 둘 다 Authorization: Bearer <API Key>를 사용하고 model은 hy4로 지정합니다. OpenAI SDK에서는 base_url을 https://anyaigc.ai/v1로 설정하세요.

동시 실행에 제한이 있습니까?

AnyAIGC는 모든 계정에 기본적으로 동시 실행 제한 없이 Hy4를 제공합니다. 긴 컨텍스트와 에이전트 요청은 시간이 더 걸리므로 타임아웃과 재시도를 적절히 설정하세요.

출력물을 상업적으로 사용할 수 있습니까?

모델과 출력물의 사용은 Tencent Hunyuan 공식 약관을 따릅니다. AnyAIGC는 독립 API 제공업체이며 Tencent와 제휴 관계가 없습니다.

AnyAIGC에서 인보이스를 받을 수 있습니까?
