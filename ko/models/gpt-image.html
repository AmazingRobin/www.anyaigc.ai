Sunburst, Flare, GPT Image 2는 무엇이 다릅니까?

OpenAI가 2026년 11월에 출시한 GPT Image 2.6이 최신 세대입니다. Sunburst(더 많은 디테일, 더 안정적인 다회차 편집)와 Flare(더 빠름)로 나뉘며, GIF와 SVG 출력, 마크업 기반 편집, 복잡도 설정이 추가되었습니다. GPT Image 2.5의 Sunburst와 Flare는 2026년 9월에 출시되었습니다. OpenAI는 Sunburst를 편집 정밀도가 가장 높은 모델, Flare를 일상 작업용 가장 빠른 고품질 모델로 소개합니다. 두 모델은 공식 토큰 요율이 같고 xhigh와 max 품질 단계가 추가되었습니다. GPT Image 2는 2026년 4월에 출시된 이전 세대로, low, medium, high, auto 품질을 지원합니다.

토큰 과금과 이미지당 과금(-c) 중 무엇을 선택해야 합니까?

토큰 과금은 크기와 품질에 따라 비용이 달라집니다. 작은 저품질 이미지는 매우 저렴하고, 품질과 해상도가 올라갈수록 비용도 늘어납니다. -c 버전은 품질과 관계없이 이미지당 고정 가격(1K와 2K/4K 구간)이 적용되지만, 요청 한 번에 이미지 한 장만 반환하며 n, mask, 투명 배경은 지원하지 않습니다. 1024×1024 높은 품질 기준으로 GPT Image 2.5는 토큰 과금 시 이미지당 약 $0.0313, -c는 $0.0159입니다.

이미지당 과금 -c 버전을 포함한 모든 GPT Image 모델이 POST /v1/images/generations(텍스트에서 이미지)와 POST /v1/images/edits(이미지에서 이미지, 다중 이미지 합성)를 지원합니다. edits는 참조 이미지 16장 미만, 총 50MB까지 받습니다. 토큰 과금 모델은 마스크를 사용한 인페인팅도 지원합니다. 모든 필드는 AnyAIGC API 문서를 참고하세요.

동시 실행 제한이 있습니까?

AnyAIGC는 GPT Image 전체 라인업에 동시 실행 제한을 두지 않으며, 모든 계정에 기본으로 적용됩니다. base URL은 https://anyaigc.ai/v1입니다. 요금은 USD로 과금되고, WeChat Pay, Alipay, USDT, 신용카드로 결제할 수 있으며, 같은 키로 300개 이상의 다른 모델도 사용할 수 있습니다.

AnyAIGC에서 인보이스를 받을 수 있습니까?

네. 콘솔에서 실제 충전한 금액 기준으로 직접 인보이스를 발급할 수 있습니다.

어떤 결제 수단을 지원합니까?

WeChat Pay, Alipay, USDT, 신용카드로 충전할 수 있습니다. 잔액은 USD 기준이며 플랫폼의 모든 모델에서 사용할 수 있습니다. 인보이스는 콘솔에서 충전한 금액 기준으로 발급할 수 있습니다.

신규 사용자에게 무료 체험 크레딧이 있습니까?

네. 신규 계정에는 토큰 200만 개 분량의 체험 크레딧이 제공되므로 충전 여부를 결정하기 전에 먼저 테스트할 수 있습니다. 충전은 $1부터 가능합니다.

잔액을 환불받을 수 있습니까?

네. 사용하지 않은 잔액은 수수료 없이 환불받을 수 있습니다. 환불은 고객 지원에 문의해 진행하세요.

실제 모델이 맞습니까? 데이터는 안전합니까?

요청은 공식 모델 채널로 전달되며, 저가 모델이나 리버스 엔지니어링 방식의 대체 모델은 사용하지 않습니다. 법령에서 요구하는 경우를 제외하고 프롬프트와 출력을 영구 저장하거나 학습에 사용하지 않으며, 콘솔에서 모든 요청의 토큰 수와 비용을 확인할 수 있습니다.

생성한 이미지를 상업적으로 사용할 수 있습니까?

사용 권리와 콘텐츠 정책은 OpenAI 공식 약관을 따릅니다. AnyAIGC는 API 접근만 제공하며 출력물 사용에 별도 제한을 두지 않습니다. 이미지에 실존 인물의 초상이나 제3자 상표가 포함된다면 필요한 권리를 갖추었는지 확인하세요.
