GPT Image 2: 텍스트 렌더링과 사실감의 도약

OpenAI는 2026년 4월 21일 ChatGPT Images 2.0을 공개하고 같은 시기에 API로 gpt-image-2(스냅샷 gpt-image-2-2026-04-21)를 출시했습니다. OpenAI는 이 모델을 유연한 크기를 지원하는 빠르고 고품질인 이미지 생성 및 편집 모델로 설명합니다. 입력 이미지는 항상 high fidelity로 처리되므로 input_fidelity는 필요하지 않으며 허용되지도 않습니다.

품질 수준은 low, medium, high, auto입니다. 가장 긴 변이 3840px 이하이고, 양쪽 변이 모두 16의 배수이며, 가로세로 비율이 3:1을 넘지 않고, 전체 픽셀 수가 655,360에서 8,294,400 사이이면 크기를 자유롭게 지정할 수 있습니다. 자주 쓰는 크기로는 1024×1024, 1536×1024, 1024×1536, 2048×2048, 2048×1152, 3840×2160이 있습니다.

OpenAI는 이후 GPT Image 2.5(Sunburst와 Flare)를 출시했으며, 가이드에서는 새 연동에 2.5를 권장합니다. gpt-image-2는 API에서 계속 동작하며, AnyAIGC에서는 요금이 2.5의 약 7분의 1이므로 비용에 민감한 대량 작업에 적합합니다. 이미지당 과금은 1K 이미지당 $0.0119인 gpt-image-2-c를 사용하세요.

사양과 선택 기준

OpenAI는 GPT Image 2를 빠르고 고품질의 이미지 생성과 편집을 위한 최첨단 이미지 모델로 소개하며, 유연한 이미지 크기와 고충실도 이미지 입력을 지원한다고 밝혔습니다.

텍스트와 이미지를 입력받아 이미지를 반환하며, 오디오와 비디오는 지원하지 않습니다. 공식 평가는 성능 Higher, 속도 Medium입니다.

공식 페이지에 표기된 고정 스냅샷은 gpt-image-2-2026-04-21입니다.

이 페이지의 가격은 텍스트 입력 $0.3971, 이미지 입력 $0.6354, 이미지 출력 $2.3830, 캐시 텍스트 입력 $0.1588이며, 위의 가격표와 같습니다.

gpt-image-2.5-flare와 비교: OpenAI에 따르면 GPT-Image-2.5 Flare는 GPT-Image-2보다 지연 시간이 50% 짧으면서 더 높은 품질의 이미지를 생성합니다.

사양은 제공사의 공식 문서(developers.openai.com)를 따릅니다. 이 페이지의 표는 가격이며, 실시간 요금은 모델 카탈로그가 기준입니다.

AnyAIGC에서 gpt-image-2는 토큰 단위로 과금됩니다. 100만 토큰당 텍스트 입력 $0.3971, 이미지 입력 $0.6354, 이미지 출력 $2.3830이며, 캐시 텍스트 입력은 $0.1588, 캐시 이미지 입력은 $0.2541입니다. OpenAI 공식 정가는 $5.00, $8.00, $30.00입니다. 1024×1024 중간 품질 이미지 한 장의 이미지 출력 비용은 약 $0.0042입니다(공식 정가로는 약 $0.0530). 실시간 가격은 모델 카탈로그를 확인하세요.

gpt-image-2를 계속 사용할 수 있습니까? GPT Image 2.5로 바꿔야 합니까?

네, 계속 사용할 수 있습니다. OpenAI 가이드는 신규 연동에 GPT Image 2.5를 권장하지만 gpt-image-2에 대한 지원 중단 공지는 없으며 AnyAIGC에서도 정상 작동합니다. GPT Image 2.5는 xhigh와 max 품질이 추가되었고, gpt-image-2는 가격 면에서 유리합니다. AnyAIGC 기준 이미지 출력은 100만 토큰당 gpt-image-2가 $2.3830, 2.5가 $17.8200입니다. 전환은 model 필드만 바꾸면 되므로, 같은 프롬프트를 2.5 Flare에서 실행해 비교해 보세요.

지원하는 크기, 품질 수준, 형식은 무엇입니까?

일반적인 크기는 1024×1024, 1536×1024, 1024×1536, 2048×2048, 2048×1152, 3840×2160, 2160×3840, auto입니다. 가장 긴 변이 3840px 이하이고, 두 변이 모두 16의 배수이며, 가로세로 비율이 3:1 이하이고, 전체 픽셀 수가 655,360에서 8,294,400 사이라면 사용자 지정 크기도 사용할 수 있습니다. 품질 단계는 low, medium, high, auto입니다. format 필드로 png, jpeg, webp 중 하나를 고르면 이미지 URL 또는 base64로 받을 수 있습니다. 최저 가격은 위의 프리셋 크기에 적용되며, 사용자 지정 크기와 투명 배경은 모델 카탈로그에 표시된 대로 더 비쌉니다.

이미지 투 이미지 편집과 인페인팅은 어떻게 합니까?

multipart/form-data로 POST /v1/images/edits를 호출하세요. image 필드는 참조 이미지 16장 미만, 총 50MB까지 받습니다. 인페인팅을 하려면 mask도 함께 보내세요. 마스크의 투명한 영역이 다시 그려지며, 4MB 미만의 PNG로 첫 번째 이미지와 크기가 같아야 합니다. 파라미터는 edits 문서를 참고하세요.

이미지당 과금 버전이 있습니까? gpt-image-2-c의 요금은 어떻게 됩니까?

네. AnyAIGC의 gpt-image-2-c는 GPT Image 2의 이미지당 과금 버전입니다. 같은 엔드포인트를 사용하며 model 필드만 바뀝니다. 품질과 관계없이 이미지당 고정 가격이며, 1K 출력은 $0.0119, 2K와 4K 출력은 $0.0149입니다. 요청 한 번에 이미지 한 장이 반환되고 n, mask, 투명 배경은 지원하지 않습니다. 높은 품질이나 큰 크기에서는 이미지당 과금이 보통 더 저렴합니다.

동시 실행 제한이 있습니까?

AnyAIGC는 gpt-image-2에 동시 실행 제한을 두지 않으며, 모든 계정에 기본으로 적용됩니다. base URL은 https://anyaigc.ai/v1입니다. 요금은 USD로 과금되고, WeChat Pay, Alipay, USDT, 신용카드로 결제할 수 있으며, 같은 키로 300개 이상의 다른 모델도 사용할 수 있습니다.

AnyAIGC에서 인보이스를 받을 수 있습니까?

네. 콘솔에서 실제 충전한 금액 기준으로 직접 인보이스를 발급할 수 있습니다.

어떤 결제 수단을 지원합니까?

WeChat Pay, Alipay, USDT, 신용카드로 충전할 수 있습니다. 잔액은 USD 기준이며 플랫폼의 모든 모델에서 사용할 수 있습니다. 인보이스는 콘솔에서 충전한 금액 기준으로 발급할 수 있습니다.

신규 사용자에게 무료 체험 크레딧이 있습니까?

네. 신규 계정에는 토큰 200만 개 분량의 체험 크레딧이 제공되므로 충전 여부를 결정하기 전에 먼저 테스트할 수 있습니다. 충전은 $1부터 가능합니다.

잔액을 환불받을 수 있습니까?

네. 사용하지 않은 잔액은 수수료 없이 환불받을 수 있습니다. 환불은 고객 지원에 문의해 진행하세요.

실제 모델이 맞습니까? 데이터는 안전합니까?

요청은 공식 모델 채널로 전달되며, 저가 모델이나 리버스 엔지니어링 방식의 대체 모델은 사용하지 않습니다. 법령에서 요구하는 경우를 제외하고 프롬프트와 출력을 영구 저장하거나 학습에 사용하지 않으며, 콘솔에서 모든 요청의 토큰 수와 비용을 확인할 수 있습니다.

생성한 이미지를 상업적으로 사용할 수 있습니까?

사용 권리와 콘텐츠 정책은 OpenAI 공식 약관을 따릅니다. AnyAIGC는 API 접근만 제공하며 출력물 사용에 별도 제한을 두지 않습니다. 이미지에 실존 인물의 초상이나 제3자 상표가 포함된다면 필요한 권리를 갖추었는지 확인하세요.
