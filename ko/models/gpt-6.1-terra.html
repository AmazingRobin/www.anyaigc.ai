GPT-6.1 Terra API

화면을 읽고 앱을 조작합니다. 공식 정가의 약 5%

GPT-6.1 Terra는 시각적 추론, 컴퓨터 사용, 자연스러운 글쓰기를 위한 OpenAI의 중간 등급 모델입니다. GPT-5.6 Terra의 후속 모델이며 공식 정가는 절반입니다. AnyAIGC에서 gpt-6.1-terra를 입력 100만 토큰당 $0.0496부터 호출할 수 있으며, OpenAI 가격 대비 95% 할인됩니다.

일상적인 컴퓨터 작업을 위한 중간 등급 멀티모달 모델

OpenAI는 2026년 10월 26일 GPT-5.6 Terra의 후속 모델로 GPT-6.1 Terra를 출시했습니다. OpenAI는 이 모델을 "시각적 추론, 정밀한 컴퓨터 사용, 명확하고 자연스러운 글쓰기를 위한 빠르고 효율적인 모델"이라고 소개하며, 상품 사진과 카탈로그 매칭, 기술 도면 읽기, 앱 인터페이스 조작, 텍스트 작성과 수정에 적합하다고 설명합니다. 공식 정가는 100만 토큰당 입력 $1, 출력 $5, 캐시 입력 $0.05로, GPT-5.6 Terra의 절반이고 토큰당 GPT-6 Astra의 약 10분의 1입니다.

GPT-6 라인업에서 Terra는 크기와 성능 면에서 Luna와 Sol 사이에 있습니다. OpenAI에 따르면 GPT-6 Astra, GPT-6.1 Sol보다 평균 3× 이상 빠르게 작업을 마치며, 한 작업에서 화면을 보고 여러 번 동작하는 에이전트에 유리합니다. 추론 강도(reasoning effort)는 none, low, medium(기본값), high, xhigh, max의 여섯 단계를 지원하고, 강도가 none일 때는 temperature와 top_p를 사용할 수 있습니다. 컨텍스트 길이는 1,050,000 토큰, 최대 출력은 128,000 토큰이며, 텍스트와 이미지를 입력받아 텍스트를 출력합니다. 지식 기준일은 2026년 6월 1일입니다.

AnyAIGC에서 gpt-6.1-terra는 /v1/chat/completions와 /v1/responses 두 엔드포인트에서 모두 사용할 수 있습니다. 공식 OpenAI SDK에서는 base_url만 https://anyaigc.ai/v1로 바꾸면 되며, 같은 키로 300개 이상의 다른 모델도 호출할 수 있습니다.

3단계로 GPT-6.1 Terra API 호출하기

  1. 가입 후 충전: anyaigc.ai에서 계정을 만드세요. 잔액은 모든 모델에서 공통으로 사용할 수 있습니다.
  2. API 키 만들기: 콘솔에서 토큰을 만들고 sk- 키를 복사해 ANYAIGC_API_KEY 환경 변수에 저장하세요.
  3. 요청 보내기: model을 gpt-6.1-terra로 지정하고 Authorization: Bearer 인증으로 https://anyaigc.ai/v1/chat/completions 또는 https://anyaigc.ai/v1/responses를 호출하세요.

도구는 Responses API로 사용하세요. OpenAI에 따르면 gpt-6.1-terra의 도구 호출(함수 호출, 컴퓨터 사용 등 여러 도구)에는 Responses API가 필요합니다. 일반 대화, 이미지 입력, 스트리밍에는 계속 /v1/chat/completions를 사용하고, 도구가 필요할 때 /v1/responses로 전환해 추론 강도를 reasoning.effort에 지정하세요.

모든 파라미터는 Chat Completions 레퍼런스와 Responses 레퍼런스를 참고하세요. 필드는 공식 OpenAI API와 같습니다.

이 페이지에는 입력 $0.0496, 출력 $0.2482, 캐시 입력 $0.0025가 표기되어 있으며, 위의 가격표와 일치합니다.

gpt-6.1-terra는 gpt-6.1-sol보다 3배 이상 빠르게 작업을 마치지만, OpenAI는 가장 복잡한 코딩에는 여전히 gpt-6.1-sol을 권장합니다.

사양은 제공사의 공식 문서(openai.com)를 따랐습니다. 이 페이지의 표는 가격이며, 실시간 요율은 모델 카탈로그가 기준입니다.

GPT-6.1 Terra API FAQ

GPT-6.1 Terra API 요금은 얼마입니까?

AnyAIGC에서 gpt-6.1-terra는 토큰 단위로 과금됩니다. 입력 100만 토큰당 $0.0496, 출력 100만 토큰당 $0.2482, 캐시 입력 100만 토큰당 $0.0025입니다. OpenAI 공식 정가는 입력 $1.00, 출력 $5.00, 캐시 입력 $0.05이므로 AnyAIGC는 공식 정가의 약 5%(95% 할인)입니다. 한 요청의 입력이 272K 토큰을 넘으면 해당 요청 전체에 입력과 캐시는 2배, 출력은 1.5배가 적용됩니다. 실시간 가격은 모델 카탈로그에서 확인하세요.

GPT-6.1 Terra의 모델 ID는 무엇입니까?

모델 ID는 gpt-6.1-terra입니다. 요청의 model 필드에 지정하세요.

GPT-6.1 Terra와 GPT-5.6 Terra는 무엇이 달라졌습니까?

GPT-6.1 Terra는 GPT-5.6 Terra의 후속 모델입니다. 공식 정가는 100만 토큰당 입력 $2, 출력 $12, 캐시 입력 $0.20에서 $1, $5, $0.05로 내려갔습니다. OpenAI에 따르면 Terminal-Bench 4.0 점수는 21.5%에서 50.3%로 올랐고, Agents' Last Exam에서는 15포인트 높으며, 내부 사실 오류율은 53.6%에서 16.7%로 줄었습니다. 지식 기준일은 2026-02-16에서 2026-06-01로 바뀌었습니다. AnyAIGC에서 100만 토큰당 GPT-6.1 Terra는 입력 $0.0496, 출력 $0.2482이고, GPT-5.6 Terra는 입력 $0.0993, 출력 $0.5957입니다.

GPT-6.1 Terra와 GPT-6.1 Sol 중 무엇을 사용해야 합니까?

Terra의 공식 정가는 Sol의 절반이며, OpenAI에 따르면 작업을 3× 이상 빠르게 마칩니다. 시각적 추론, 컴퓨터 사용, 기술 문서 작성에서는 Sol에 근접하고, 그 밖의 대부분의 작업에서는 조금 약합니다. 비전, 폼 입력, 문구, 문서 작업은 Terra로 시작하고, 여러 파일에 걸친 복잡한 코딩, 긴 에이전트 체인, 깊은 추론에는 GPT-6.1 Sol을 선택하세요. AnyAIGC에서 100만 토큰당 GPT-6.1 Terra는 입력 $0.0496, 출력 $0.2482이고, GPT-6.1 Sol은 입력 $0.0993, 출력 $0.4964입니다.

Chat Completions와 Responses API 중 무엇을 써야 합니까? 도구도 사용할 수 있습니까?

두 엔드포인트 모두 사용할 수 있습니다. 일반 대화, 이미지 입력, 스트리밍에는 https://anyaigc.ai/v1/chat/completions를 사용하세요. OpenAI에 따르면 도구 호출에는 Responses API가 필요하므로, 함수 호출, 컴퓨터 사용 등 도구에는 https://anyaigc.ai/v1/responses를 사용하고 추론 강도는 reasoning.effort에 지정하세요.
