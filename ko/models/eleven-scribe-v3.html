Eleven Scribe v3: 정확한 녹음 음성 텍스트 변환

Eleven Scribe v3는 녹음 파일용 ElevenLabs 음성 텍스트 변환(STT) 모델입니다. 공식 모델 문서는 이를 녹음 오디오 기준 가장 정확한 음성 인식 모델이라고 소개하며, 90개 이상의 언어를 지원합니다. ElevenLabs 변경 로그는 Scribe v3 출시일을 2026년 11월 9일로 적고, 102개 언어의 FLEURS 벤치마크에서 Scribe v2보다 단어 오류가 27% 적다고 밝힙니다. AnyAIGC 모델 카탈로그는 v2와 가격과 인터페이스가 같고, 정확도와 화자 분리가 분명하게 나아졌다고 설명합니다.

공식 문서에는 단어 단위 타임스탬프, 최대 32명까지 구분하는 화자 분리, 최대 1,000개 용어를 넣는 keyterm prompting(주요 용어 지정), 웃음과 박수 같은 오디오 이벤트 태깅, 개체 감지가 나열되어 있습니다. 공식 기능 페이지는 파일당 5 GB, 파일당 최대 15시간, 멀티채널 오디오 최대 5채널을 명시합니다. 이는 ElevenLabs 공식 문서에 적힌 기능입니다.

AnyAIGC에서 scribe_v3는 POST /v1/audio/transcriptions로 호출합니다. 오디오를 multipart/form-data로 업로드하고 오디오 길이 기준 초당 과금되며, 동시 실행 제한이 없고 Bearer 키 하나면 됩니다. 별도의 ElevenLabs 계정은 필요하지 않습니다.

빠른 시작

세 단계로 Eleven Scribe v3 API 호출하기

  1. 가입하고 충전하기: anyaigc.ai에서 계정을 만드세요. 충전은 $1부터 가능하며, 잔액은 플랫폼의 모든 모델에서 사용할 수 있습니다.
  2. API 키 만들기: 콘솔에서 토큰을 만들고 sk-로 시작하는 키를 복사해 ANYAIGC_API_KEY 환경 변수에 저장하세요.
  3. 녹음 업로드하기: POST https://anyaigc.ai/v1/audio/transcriptions를 multipart/form-data로 호출하고, file(오디오 파일)과 model을 scribe_v3로 지정한 뒤 Authorization: Bearer로 인증하고, 응답의 text에서 변환 결과를 읽으세요.

파라미터 안내: 모델 ID는 대소문자를 구분하므로 scribe_v3로 적으세요. 요청은 multipart/form-data이며, file은 파일 이름이 아니라 오디오 파일 자체입니다. 호출에 성공하면 {"text": "..."}를 반환합니다.

음성 텍스트 변환 API 레퍼런스를 참고하세요. Scribe를 호출하려면 model을 scribe_v3나 scribe_v2로 지정하세요.

Eleven Scribe v3의 모델 ID는 무엇이며 ElevenLabs와 어떤 관계입니까?

모델 ID는 scribe_v3(대소문자 구분)로, ElevenLabs의 model_id와 같습니다. AnyAIGC는 OpenAI 방식의 /v1/audio/transcriptions 호출을 제공하는 독립 API 제공업체이며, ElevenLabs와 제휴 관계가 없습니다.

Eleven Scribe v3와 다른 Eleven 모델 중 어떻게 고릅니까?

AnyAIGC의 Eleven 모델은 두 종류입니다. Eleven v4를 비롯한 텍스트 음성 변환 모델 7개와, Eleven Scribe v3와 Eleven Scribe v2의 음성 텍스트 변환 모델 2개입니다. 녹음을 텍스트로 바꾸려면 Scribe를, 텍스트를 음성으로 바꾸려면 v4, Multilingual v2 등 텍스트 음성 변환 모델을 고르세요.

Eleven Scribe v3 API 키는 어떻게 받습니까?

anyaigc.ai에서 가입하고 충전한 뒤 콘솔에서 토큰을 만드세요. 키 하나로 플랫폼의 300개 이상 모델을 사용할 수 있으며, 별도의 ElevenLabs 계정은 필요하지 않습니다. 요청의 model을 scribe_v3로 지정하세요.

Eleven Scribe v3 API는 어떻게 호출합니까?

POST https://anyaigc.ai/v1/audio/transcriptions를 multipart/form-data로 호출하고, file(오디오 파일)과 model을 scribe_v3로 지정한 뒤 Authorization: Bearer로 인증하세요. 호출에 성공하면 {"text": "..."}를 반환합니다. API 레퍼런스를 참고하세요.

Eleven Scribe v3는 어떤 오디오 형식을 받으며 파일은 얼마나 클 수 있습니까?

API 레퍼런스는 다음 파일 형식을 명시합니다. flac, mp3, mp4, mpeg, mpga, m4a, ogg, wav, webm. ElevenLabs 기능 페이지는 파일당 5 GB, 15시간 제한을 명시합니다.

Eleven Scribe v3는 중국어를 지원합니까? 언어는 몇 개입니까?

네. 공식 문서는 Scribe가 90개 이상의 언어를 지원하며 만다린과 광둥어가 공식 언어 목록에 있다고 밝힙니다. 정확한 언어 목록은 ElevenLabs 모델 문서를 참고하세요.

Scribe v3와 Scribe v2의 차이는 무엇입니까?

ElevenLabs 변경 로그는 Scribe v3가 102개 언어의 FLEURS 벤치마크에서 Scribe v2보다 단어 오류가 27% 적고, 화자를 더 정확하게 구분한다고 밝힙니다. AnyAIGC에서 둘은 가격과 인터페이스가 같고 model 필드만 다릅니다. 새 프로젝트는 v3를 먼저 써 보거나, 같은 녹음을 두 모델로 각각 변환해 비교하세요. v2는 Eleven Scribe v2를 참고하세요.

실시간(스트리밍) 음성 텍스트 변환 모델이 있습니까?

이 페이지는 녹음 파일 모델 scribe_v3와 scribe_v2를 다루며, /v1/audio/transcriptions로 HTTP 호출합니다. 완성된 녹음을 업로드하면 텍스트를 돌려받습니다. ElevenLabs는 scribe_v3_live 같은 실시간 모델도 제공하지만, 여기서는 다루지 않습니다. 제공 여부는 모델 카탈로그에서 확인하세요.

요청 제한이 있습니까?

AnyAIGC는 scribe_v3에 동시 실행 제한을 두지 않으며 모든 계정에 기본 적용되므로, 배치 변환과 병렬 작업이 가능합니다. 오디오 길이 기준 초당 과금이며, 월 이용료나 일정 기간마다 초기화되는 할당량은 없습니다.

AnyAIGC에서 인보이스를 받을 수 있습니까?

네. 콘솔에서 실제 충전한 금액 기준으로 직접 인보이스를 발급할 수 있습니다.

어떤 결제 수단을 지원합니까?

WeChat Pay, Alipay, USDT, 신용카드로 충전할 수 있습니다. 잔액은 USD 기준이며 플랫폼의 모든 모델에서 사용할 수 있습니다. 인보이스는 콘솔에서 충전한 금액 기준으로 발급할 수 있습니다.

신규 사용자에게 무료 체험 크레딧이 있습니까?

네. 신규 계정에는 토큰 200만 개 분량의 체험 크레딧이 제공되므로 충전 여부를 결정하기 전에 먼저 테스트할 수 있습니다. 충전은 $1부터 가능합니다.

잔액을 환불받을 수 있습니까?

네. 사용하지 않은 잔액은 수수료 없이 환불받을 수 있습니다. 환불은 고객 지원에 문의해 진행하세요.

실제 모델이 맞습니까? 데이터는 안전합니까?

요청은 공식 모델 채널로 전달되며, 저가 모델이나 리버스 엔지니어링 방식의 대체 모델은 사용하지 않습니다. 법령에서 요구하는 경우를 제외하고 프롬프트와 출력을 영구 저장하거나 학습에 사용하지 않으며, 콘솔에서 모든 요청의 토큰 수와 비용을 확인할 수 있습니다.

업로드한 녹음과 변환된 텍스트가 학습에 사용됩니까?

아니요. 법령에서 요구하는 경우를 제외하고 AnyAIGC는 입력과 출력을 영구 저장하지 않으며 학습에 사용하지 않습니다. 요청은 HTTPS로 암호화됩니다. AnyAIGC 개인정보 처리방침을 참고하세요. 모델 자체의 데이터 정책은 ElevenLabs가 정합니다. 녹음에 개인정보가 포함되어 있다면 이를 처리할 권한이 있는지 확인하세요.
