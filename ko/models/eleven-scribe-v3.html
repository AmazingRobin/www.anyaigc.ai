Eleven Scribe v3: 정확한 녹음 전사

Eleven Scribe v3는 녹음 오디오용 ElevenLabs 음성 인식(STT) 모델입니다. 공식 모델 문서는 이 모델을 녹음 오디오에서 가장 정확한 음성 인식 모델이라고 설명하며, 90개 이상의 언어를 지원합니다. ElevenLabs 변경 로그에 따르면 Scribe v3는 2026년 11월 9일에 출시되었고, 102개 언어를 대상으로 한 FLEURS 벤치마크에서 Scribe v2보다 단어 오류가 27% 적습니다. AnyAIGC 모델 카탈로그는 v2와 가격과 인터페이스가 같고 정확도와 화자 분리가 뚜렷하게 향상되었다고 설명합니다.

공식 문서에는 단어 단위 타임스탬프, 최대 32명 화자 분리, 최대 1,000개 용어를 지정하는 키텀 프롬프팅, 웃음과 박수 같은 오디오 이벤트 태깅, 엔터티 감지가 나열되어 있습니다. 공식 기능 페이지에는 파일당 5 GB, 최대 15시간, 멀티채널 오디오 최대 5채널 제한이 표기되어 있습니다. 이는 ElevenLabs 공식 문서에 나열된 기능입니다.

AnyAIGC에서 scribe_v3는 POST /v1/audio/transcriptions로 실행됩니다. 오디오는 multipart/form-data로 업로드하며 오디오 길이(초) 기준으로 과금합니다. 동시 실행 제한이 없고 Bearer 키 하나로 호출하므로 별도의 ElevenLabs 계정이 필요 없습니다.

빠른 시작

세 단계로 Eleven Scribe v3 API 호출하기

  1. 가입 및 충전: anyaigc.ai에서 계정을 만드세요. 충전은 $1부터 가능하며, 잔액은 플랫폼의 모든 모델에서 공통으로 사용됩니다.
  2. API 키 만들기: 콘솔에서 토큰을 만들고 sk-로 시작하는 키를 복사해 ANYAIGC_API_KEY 환경 변수에 저장하세요.
  3. 녹음 업로드: POST https://anyaigc.ai/v1/audio/transcriptions를 multipart/form-data로 호출하고, file(오디오 파일)과 model(scribe_v3)을 보내세요. Authorization: Bearer로 인증하며, 응답의 text에서 전사 결과를 읽습니다.

파라미터 안내: 모델 ID는 대소문자를 구분하므로 scribe_v3로 쓰세요. 요청은 multipart/form-data이며 file에는 파일 이름이 아니라 오디오 파일 자체를 넣습니다. 호출에 성공하면 {"text": "..."}가 반환됩니다.

음성 인식 API 레퍼런스를 참고하세요. Scribe를 호출하려면 model을 scribe_v3 또는 scribe_v2로 설정하세요.

Eleven Scribe v3의 모델 ID는 무엇이며 ElevenLabs와 어떤 관계입니까?

모델 ID는 scribe_v3(대소문자 구분)이며 ElevenLabs의 model_id와 같습니다. AnyAIGC는 OpenAI 스타일의 /v1/audio/transcriptions 호출을 제공하는 독립 API 제공업체이며 ElevenLabs와 제휴 관계가 없습니다.

Eleven Scribe v3와 다른 Eleven 모델 중 무엇을 선택해야 합니까?

AnyAIGC의 Eleven 모델은 두 종류입니다. Eleven v4를 비롯한 음성 합성 모델 7개와 음성 인식 모델 2개인 Eleven Scribe v3, Eleven Scribe v2입니다. 녹음을 텍스트로 바꾸려면 Scribe를, 텍스트를 음성으로 바꾸려면 v4, Multilingual v2 등 음성 합성 모델을 선택하세요.

Eleven Scribe v3 API 키는 어떻게 받습니까?

anyaigc.ai에서 가입하고 충전한 뒤 콘솔에서 토큰을 만드세요. 키 하나로 플랫폼의 300개 이상 모델을 사용할 수 있으며, 별도의 ElevenLabs 계정은 필요 없습니다. 요청의 model을 scribe_v3로 설정하세요.

Eleven Scribe v3 API는 어떻게 호출합니까?

POST https://anyaigc.ai/v1/audio/transcriptions를 multipart/form-data로 호출하고, file(오디오 파일)과 model(scribe_v3)을 보내며 Authorization: Bearer로 인증하세요. 호출에 성공하면 {"text": "..."}가 반환됩니다. API 레퍼런스를 참고하세요.

Eleven Scribe v3가 지원하는 오디오 형식과 파일 크기 제한은 어떻게 됩니까?

API 레퍼런스에는 다음 파일 형식이 나열되어 있습니다: flac, mp3, mp4, mpeg, mpga, m4a, ogg, wav, webm. ElevenLabs 기능 페이지에는 파일당 5 GB, 15시간 제한이 표기되어 있습니다.

Eleven Scribe v3는 중국어를 지원합니까? 몇 개 언어를 지원합니까?

네. 공식 문서에 따르면 Scribe는 90개 이상의 언어를 지원하며, 공식 언어 목록에 표준 중국어(만다린)와 광둥어가 포함되어 있습니다. 정확한 언어 목록은 ElevenLabs 모델 문서를 참고하세요.

Scribe v3와 Scribe v2는 어떻게 다릅니까?

ElevenLabs 변경 로그에 따르면 Scribe v3는 102개 언어를 대상으로 한 FLEURS 벤치마크에서 Scribe v2보다 단어 오류가 27% 적고, 화자를 더 정확하게 구분합니다. AnyAIGC에서 두 모델은 가격과 인터페이스가 같고 model 필드만 다릅니다. 새 프로젝트라면 v3를 먼저 써 보거나, 같은 녹음을 두 모델로 전사해 비교하세요. v2는 Eleven Scribe v2를 참고하세요.

실시간(스트리밍) 전사 모델이 있습니까?

이 페이지는 녹음 파일용 모델 scribe_v3와 scribe_v2를 다루며, HTTP로 /v1/audio/transcriptions를 호출합니다. 완성된 녹음 파일을 업로드하면 텍스트를 받습니다. ElevenLabs는 실시간 모델(예: scribe_v3_live)도 제공하지만 이 페이지의 범위가 아닙니다. 제공 여부는 모델 카탈로그에서 확인할 수 있습니다.

속도 제한(rate limit)이 있습니까?

AnyAIGC는 scribe_v3에 동시 실행 제한을 두지 않으며 모든 계정에 기본 적용되므로, 일괄 전사와 병렬 작업도 문제없습니다. 오디오 길이(초) 단위로 과금하며 월 요금이 없고, 일정 기간마다 초기화되는 할당량도 없습니다.

AnyAIGC에서 인보이스를 받을 수 있습니까?

네. 콘솔에서 실제 충전한 금액 기준으로 직접 인보이스를 발급할 수 있습니다.

어떤 결제 수단을 지원합니까?

WeChat Pay, Alipay, USDT, 신용카드로 충전할 수 있습니다. 잔액은 USD 기준이며 플랫폼의 모든 모델에서 사용할 수 있습니다. 인보이스는 콘솔에서 충전한 금액 기준으로 발급할 수 있습니다.

신규 사용자에게 무료 체험 크레딧이 있습니까?

네. 신규 계정에는 토큰 500만 개 분량의 체험 크레딧이 제공되므로 충전 여부를 결정하기 전에 먼저 테스트할 수 있습니다. 충전은 $1부터 가능합니다.

잔액을 환불받을 수 있습니까?

네. 사용하지 않은 잔액은 수수료 없이 환불받을 수 있습니다. 환불은 고객 지원에 문의해 진행하세요.

실제 모델이 맞습니까? 데이터는 안전합니까?

요청은 공식 모델 채널로 전달되며, 저가 모델이나 리버스 엔지니어링 방식의 대체 모델은 사용하지 않습니다. 법령에서 요구하는 경우를 제외하고 프롬프트와 출력을 영구 저장하거나 학습에 사용하지 않으며, 콘솔에서 모든 요청의 토큰 수와 비용을 확인할 수 있습니다.

업로드한 녹음 파일과 전사 결과가 학습에 사용됩니까?

아니요. 법령에서 요구하는 경우를 제외하고 AnyAIGC는 입력과 출력을 영구 저장하지 않으며 학습에 사용하지 않습니다. 요청은 HTTPS로 암호화됩니다. AnyAIGC 개인정보 처리방침을 참고하세요. 모델 자체의 데이터 정책은 ElevenLabs가 정합니다. 녹음에 개인정보가 포함되어 있다면 처리할 권한이 있는지 확인하세요.
