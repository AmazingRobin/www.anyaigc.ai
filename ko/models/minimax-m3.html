import json
import os
import urllib.request

payload = {
    "model": "MiniMax-M3",
    "messages": [
        {
            "role": "user",
            "content": "Design three clear API endpoints for a to-do application."
        }
    ]

request = urllib.request.Request(
    "https://anyaigc.ai/v1/chat/completions",
    data=json.dumps(payload, ensure_ascii=False).encode("utf-8"),
    headers={
        "Authorization": "Bearer " + os.environ["ANYAIGC_API_KEY"],
        "Content-Type": "application/json",
    },
    method="POST",
)
with urllib.request.urlopen(request, timeout=120) as response:
    result = json.load(response)

print(json.dumps(result, ensure_ascii=False, indent=2))

사양

사양과 선택 기준

M3는 네이티브 멀티모달 모델로, 텍스트, 이미지, 비디오 입력을 받아 텍스트를 반환합니다.

M3의 컨텍스트 길이는 최대 1M 토큰이며 최소 512K를 보장합니다. MiniMax 자체 Sparse Attention(MSA) 아키텍처를 기반으로 합니다.

M3는 오픈 웨이트 모델이며, MiniMax의 자체 호스팅 참고 구성은 MXFP8을 적용한 8 x B200입니다.

이 페이지에는 입력 (≤512K) $0.2025 / 100만 토큰, 출력 (≤512K) $0.8100 / 100만 토큰, 캐시 히트 (≤512K) $0.0405 / 100만 토큰, 입력 (>512K, ≤1M) $0.4050 / 100만 토큰이 표시되며, 위 가격표와 일치합니다.

minimax-m3.1-flash와 비교: 출력 속도가 더 빠르고 사고 깊이를 조절할 수 있는 최신 M3.1-Flash를 선택하세요.

사양은 벤더의 공식 문서(minimax.io)를 따랐습니다. 이 페이지의 표는 가격 정보이며, 실시간 요금은 모델 카탈로그를 기준으로 합니다.

MiniMax M3 API 가격은 얼마입니까?

입력 (≤512K) $0.2025/100만 토큰, 출력 (≤512K) $0.8100/100만 토큰, 캐시 히트 (≤512K) $0.0405/100만 토큰, 입력 (>512K, ≤1M) $0.4050/100만 토큰, 출력 (>512K, ≤1M) $1.6200/100만 토큰, 캐시 히트 (>512K, ≤1M) $0.0810/100만 토큰입니다. 모든 가격은 USD 기준이며, 현재 요금은 모델 카탈로그에서 확인하세요. 카탈로그에는 여기에 표시된 요금에 대해 공식 정가 대비 32% 할인이 표시됩니다. 현재 가격과 할인율은 카탈로그를 확인하세요.

어떤 API 엔드포인트를 사용해야 합니까?

https://anyaigc.ai의 POST /v1/chat/completions를 사용하고, API 키는 Authorization: Bearer로 전달하세요.

MiniMax M3는 어떤 용도에 적합합니까?

에이전트 추론, 도구 호출, 코딩, 긴 컨텍스트 작업을 위한 M 시리즈 언어 모델입니다. 입력이 512K 이하이면 첫 번째 가격 구간이 적용되고, 512K를 넘어 1M 이하이면 출력 요금을 포함해 두 번째 구간이 적용됩니다.

요청 한 번에 무엇이 반환됩니까?

요청 한 번에 모델 응답 하나가 반환되며, 입력이 512K 토큰을 넘으면 두 번째 가격 구간이 적용됩니다.

동시 실행 수나 RPM 제한이 있습니까?

AnyAIGC는 MiniMax에 동시 실행 제한을 두지 않으며 고정 RPM 상한도 없습니다. 다만 생성에는 시간이 걸리므로 타임아웃, 오류 처리, 적절한 재시도를 애플리케이션에서 설정하세요.

생성한 콘텐츠를 상업적으로 사용할 수 있습니까?

모델과 출력물의 상업적 사용은 MiniMax 공식 약관을 따릅니다. 참조 자료, 음성, 생성된 콘텐츠에 대해 필요한 권리를 갖추었는지 확인하세요. AnyAIGC는 독립 API 제공업체입니다.

AnyAIGC에서 인보이스를 받을 수 있습니까?

네. 콘솔에서 실제 충전한 금액 기준으로 직접 인보이스를 발급할 수 있습니다.

어떤 결제 수단을 지원합니까?

WeChat Pay, Alipay, USDT, 신용카드로 충전할 수 있습니다. 잔액은 USD 기준이며 플랫폼의 모든 모델에서 사용할 수 있습니다. 인보이스는 콘솔에서 충전한 금액 기준으로 발급할 수 있습니다.

신규 사용자에게 무료 체험 크레딧이 있습니까?

네. 신규 계정에는 토큰 200만 개 분량의 체험 크레딧이 제공되므로 충전 여부를 결정하기 전에 먼저 테스트할 수 있습니다. 충전은 $1부터 가능합니다.

잔액을 환불받을 수 있습니까?

네. 사용하지 않은 잔액은 수수료 없이 환불받을 수 있습니다. 환불은 고객 지원에 문의해 진행하세요.

실제 모델이 맞습니까? 데이터는 안전합니까?

요청은 공식 모델 채널로 전달되며, 저가 모델이나 리버스 엔지니어링 방식의 대체 모델은 사용하지 않습니다. 법령에서 요구하는 경우를 제외하고 프롬프트와 출력을 영구 저장하거나 학습에 사용하지 않으며, 콘솔에서 모든 요청의 토큰 수와 비용을 확인할 수 있습니다.
