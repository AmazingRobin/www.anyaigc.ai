사양과 선택 기준

ByteDance는 Seedream 5.0 lite를 심층 사고와 온라인 검색을 갖춘 통합 멀티모달 이미지 생성 모델로 소개합니다.

Seedream 5.0 lite는 실시간 뉴스와 주제에 연동된 이미지를 만들 수 있도록 web_search 도구를 지원합니다.

Seedream 5.0 lite는 size 값으로 2K, 3K, 4K를 받으며, 총 픽셀 수를 2560×1440에서 4096×4096 사이로 직접 지정할 수도 있습니다.

Seedream 5.0 lite는 최대 14장의 참조 이미지를 받으며, 이미지 세트 모드에서는 참조 이미지와 출력 이미지의 합계가 최대 15장입니다.

이 페이지에는 Seedream 5.0 lite가 이미지당 $0.0223로 표기되어 있으며, 위의 가격표와 일치합니다.

seedream-5.0-pro와 비교: Seedream 5.0 lite는 이미지 세트, 14장의 참조 이미지, 최대 4K를 지원하는 반면, Seedream 5.0 pro는 호출당 이미지 1장을 출력하고 참조 이미지는 최대 10장, 해상도는 최대 2K입니다.

사양은 벤더 공식 문서(docs.volcengine.com)를 따랐습니다. 이 페이지의 표는 가격이며, 실시간 요금은 모델 카탈로그가 기준입니다.

AnyAIGC에서 Seedream 5.0 lite(doubao-seedream-5-0-260128)는 이미지당 $0.0223부터 시작합니다. 가격은 해상도에 따라 다르며, 2K, 3K, 4K 실시간 요금은 모델 카탈로그에서 확인할 수 있습니다. 이미지 세트는 여러 장을 반환하며 생성된 이미지 수만큼 과금됩니다. 생성에 성공한 건에 대해서만 과금되며, 실시간 가격은 모델 카탈로그에서 확인하세요.

Seedream 5.0 lite란 무엇입니까?

Seedream 5.0 lite는 Seedream 5.0 세대의 경량 모델이며, AnyAIGC에서의 모델 ID는 doubao-seedream-5-0-260128입니다. 공식적으로는 심층 사고와 실시간 검색에 초점을 두어, 의도를 더 정확히 읽고 스타일과 레이아웃을 제어하며 웹의 최신 정보를 가져올 수 있습니다. AnyAIGC에는 2026년 2월에 추가되었습니다.

어떤 해상도를 지원합니까? 4K로 출력할 수 있습니까?

네. Volcano Engine Ark 문서에 따르면 5.0 lite는 size 값으로 2K, 3K, 4K 또는 픽셀 크기를 받으며, 가로세로 비율은 1:16에서 16:1까지 지원합니다.

이미지 세트는 어떻게 동작하며 몇 장까지 받을 수 있습니까?

sequential_image_generation: "auto"를 전달하고 sequential_image_generation_options.max_images(1–15)로 상한을 설정하세요. 텍스트만 입력하면 최대 15장을 반환하며, 참조 이미지를 쓰면 참조 이미지와 생성 이미지의 합계가 15장을 넘을 수 없습니다.

참조 이미지를 몇 장까지 보낼 수 있습니까? 웹 검색도 가능합니까?

image는 최대 14장의 참조 이미지를 받습니다. 5.0 lite는 웹 검색을 지원하는 유일한 Seedream 모델로, 명절 테마, 트렌드 주제 등 최신 정보가 필요한 작업에 도움이 됩니다.

동시 실행 제한이 있습니까? 가입에 무엇이 필요합니까?

AnyAIGC는 Seedream 5.0 lite에 동시 실행 제한을 두지 않으며, 모든 계정에 기본으로 제공됩니다. 기본 URL은 https://anyaigc.ai입니다. Volcano Engine 계정이나 본인 인증은 필요 없으며, 같은 키로 플랫폼의 300개 이상의 다른 모델도 사용할 수 있습니다.

AnyAIGC에서 인보이스를 받을 수 있습니까?

네. 콘솔에서 실제 충전한 금액 기준으로 직접 인보이스를 발급할 수 있습니다.

어떤 결제 수단을 지원합니까?

WeChat Pay, Alipay, USDT, 신용카드로 충전할 수 있습니다. 잔액은 USD 기준이며 플랫폼의 모든 모델에서 사용할 수 있습니다. 인보이스는 콘솔에서 충전한 금액 기준으로 발급할 수 있습니다.

신규 사용자에게 무료 체험 크레딧이 있습니까?

네. 신규 계정에는 토큰 200만 개 분량의 체험 크레딧이 제공되므로 충전 여부를 결정하기 전에 먼저 테스트할 수 있습니다. 충전은 $1부터 가능합니다.

잔액을 환불받을 수 있습니까?

네. 사용하지 않은 잔액은 수수료 없이 환불받을 수 있습니다. 환불은 고객 지원에 문의해 진행하세요.

실제 모델이 맞습니까? 데이터는 안전합니까?

요청은 공식 모델 채널로 전달되며, 저가 모델이나 리버스 엔지니어링 방식의 대체 모델은 사용하지 않습니다. 법령에서 요구하는 경우를 제외하고 프롬프트와 출력을 영구 저장하거나 학습에 사용하지 않으며, 콘솔에서 모든 요청의 토큰 수와 비용을 확인할 수 있습니다.

상업적으로 사용할 수 있습니까? 워터마크를 제거할 수 있습니까?

사용 권한과 콘텐츠 정책은 ByteDance / Volcano Engine 공식 약관을 따릅니다. 요청에서 watermark를 false로 설정하면 오른쪽 아래에 "AI 생성" 표시가 추가되지 않습니다. AnyAIGC는 API 접근만 제공하며 결과물 사용에 추가 제한을 두지 않습니다. 실존 인물 초상, 브랜드 로고 등은 필요한 권리를 갖고 있는지 확인하세요.
