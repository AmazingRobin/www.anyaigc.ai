GPT-6의 최상위 등급, 공식 정가의 약 5%로 과금

OpenAI는 2026년 9월 3일 GPT-6 Astra를 출시하며 GPT-6 세대를 열었습니다. 모델 페이지는 이 모델을 "가장 까다로운 작업을 위한 가장 유능한 모델"로 소개하고, 발표문은 Astra가 컴퓨터 사용, 웹 브라우징, 소프트웨어 엔지니어링, 사이버 보안, 과학, 전문 업무에서 앞선다고 밝힙니다. OpenAI 모델 카탈로그는 어디서 시작할지 모르겠다면 GPT-6 Astra를 사용하라고 안내합니다.

Astra의 토큰당 공식 정가는 GPT-6.1 Sol의 5배이지만, OpenAI는 작업당 예상 API 비용이 이전 모델보다 낮게 나왔다고 밝혔습니다. 추론 강도는 low, medium, high, xhigh, max의 다섯 가지를 지원하며 none은 없습니다. 컨텍스트 길이는 1,050,000 토큰, 최대 출력은 128,000 토큰이고, 텍스트와 이미지를 입력받아 텍스트를 출력하며, 지식 기준일은 2026년 4월 30일입니다. OpenAI는 Astra에 정렬 이탈(misalignment) 모니터링도 적용합니다. 안전 검사로 작업이 일시 중지되면 API 작업이 중단됩니다.

AnyAIGC에서 gpt-6-astra는 /v1/chat/completions와 /v1/responses 모두에서 작동합니다. 공식 OpenAI SDK에서는 base_url만 https://anyaigc.ai/v1로 바꾸면 되고, 같은 키로 300개 이상의 다른 모델에 접근할 수 있으므로 가벼운 작업은 새 계정 없이 GPT-6.1 Sol이나 GPT-6 Luna로 옮길 수 있습니다.

GPT-6 Astra가 적합한 작업

  • 01 · 소프트웨어 엔지니어링

    대규모 코드베이스와 장시간 작업

    OpenAI는 GPT-6 Astra를 지금까지 출시한 모델 중 소프트웨어 엔지니어링 성능이 가장 높다고 소개합니다. 모듈에 걸친 리팩터링, 재현하기 어려운 버그, 장시간 실행되는 코딩 에이전트를 맡기거나 Codex의 기본 모델로 지정하세요.

  • 02 · 컴퓨터 사용

    UI 조작과 웹 브라우징

    Responses API에서 컴퓨터 사용(computer use), 웹 검색 등의 도구로 다단계 작업을 실행하세요. OpenAI는 OSWorld 2.0에서 72.6%, BrowseComp에서 91.5%를 기록했다고 밝혔으며, 클릭하고 검색하고 교차 확인하는 흐름에 적합합니다.

  • 03 · 사이버 보안

    승인된 보안 점검

    OpenAI는 사이버 보안을 Astra가 앞서는 분야로 꼽았으며 ExploitBench에서 100%를 기록했다고 밝혔습니다. OpenAI 공식 약관 범위 안에서 자사 코드의 취약점 점검, 패치 검증, 보안 테스트에 사용하세요.

  • 04 · 과학과 수학

    연구와 어려운 문제

    OpenAI는 GPQA Diamond에서 96.0%, FrontierMath Tier 4에서 97.6%를 기록했다고 밝혔습니다. 컨텍스트 길이 1,050,000 토큰이면 논문과 데이터를 한 번의 요청에 담을 수 있고, 캐시 입력은 100만 토큰당 $0.0496이라 반복해서 읽는 비용이 낮아집니다.

3단계로 GPT-6 Astra API 호출하기

  1. 가입 후 충전: anyaigc.ai에서 계정을 만드세요. 잔액은 모든 모델에서 공통으로 사용할 수 있습니다.
  2. API 키 만들기: 콘솔에서 토큰을 만들고 sk- 키를 복사해 ANYAIGC_API_KEY 환경 변수에 저장하세요.
  3. 요청 보내기: model을 gpt-6-astra로 설정하고 Authorization: Bearer 인증으로 https://anyaigc.ai/v1/chat/completions 또는 https://anyaigc.ai/v1/responses를 호출하세요.

도구 호출에는 /v1/responses를 권장합니다. OpenAI 모델 페이지에는 Chat Completions에서의 gpt-6-astra 도구 호출 제한이 명시되어 있지 않지만, 같은 세대의 GPT-6.1 Sol은 이 엔드포인트에서 도구 호출을 지원하지 않습니다. 일반 채팅과 스트리밍에는 /v1/chat/completions를, 함수 호출, 컴퓨터 사용, 웹 검색 등의 도구에는 /v1/responses를 사용하고 추론 강도는 reasoning.effort에 지정하세요. Astra는 요율이 높으므로 단순한 작업은 low나 medium 강도로 비용을 낮추세요.

모든 파라미터는 Chat Completions 레퍼런스와 Responses 레퍼런스를 참고하세요. 필드는 공식 OpenAI API와 같습니다.

Codex에서 GPT-6 Astra 사용하기

명령 한 줄로 Codex CLI를 설치하고 AnyAIGC 설정을 작성합니다. ~/.codex/ 아래 파일 두 개를 직접 수정해도 됩니다.

한 줄 설치 스크립트는 모델을 gpt-5.5로 설정하므로, 설치 후 ~/.codex/config.toml의 model을 gpt-6-astra로 바꾸세요. 두 파일을 저장한 뒤 프로젝트 폴더에서 codex를 실행하세요. Codex는 Responses API를 사용하므로 도구 호출이 정상적으로 작동합니다. 작은 수정에는 model_reasoning_effort를 medium으로 두고, 어려운 문제에는 high나 xhigh로 올리세요. 전체 절차와 자주 발생하는 오류는 Codex 설정 가이드를 참고하세요.

GPT-6 Astra와 GPT-6.1 Sol 중 어느 쪽을 써야 합니까?

OpenAI는 GPT-6.1 Sol이 에이전트 코딩, 컴퓨터 사용, 전문 업무에서 GPT-6 Astra에 근접하며 표준 가격은 Astra의 5분의 1이라고 밝혔습니다. GPT-6.1 Astra는 왜 없습니까?

현재까지 OpenAI는 GPT-6.1 Astra를 출시하지 않았습니다. GPT-6.1은 지금까지 Sol과 Terra 등급만 업그레이드했습니다. OpenAI의 현재 GPT-6 API 라인업은 gpt-6-astra, gpt-6.1-sol, gpt-6.1-terra, gpt-6-luna이므로 Astra 등급은 여전히 gpt-6-astra입니다. OpenAI 모델 카탈로그는 어디서 시작할지 모르겠다면 GPT-6 Astra를 사용하라고 안내합니다.

두 엔드포인트 모두 사용할 수 있습니다. 일반 채팅과 스트리밍에는 https://anyaigc.ai/v1/chat/completions를 사용하세요. OpenAI 모델 페이지에는 Chat Completions에서의 gpt-6-astra 도구 호출 제한이 명시되어 있지 않지만, 같은 세대의 GPT-6.1 Sol은 이 엔드포인트에서 도구 호출을 지원하지 않으므로, 함수 호출과 내장 도구에는 https://anyaigc.ai/v1/responses를 권장하며 추론 강도는 reasoning.effort에 지정하세요.
