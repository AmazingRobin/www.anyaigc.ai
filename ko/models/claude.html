네이티브 Anthropic API를 완전하게 지원

요청이 Anthropic Messages 형식을 따르므로 공식 SDK와 기존 코드를 그대로 사용할 수 있습니다.

  • Messages API

    /v1/messages를 호출합니다. Anthropic 공식 SDK에서는 base URL을 https://anyaigc.ai로 설정하세요.

  • 프롬프트 캐싱

    콘텐츠 블록에 cache_control을 추가하면 5분 또는 1시간 캐싱을 사용할 수 있습니다. 캐시 히트는 일반 입력 가격의 약 2.5–10%입니다.

  • 도구 사용과 구조화된 출력

    tools로 함수를 정의하거나 JSON 스키마로 출력을 제한해 기존 시스템과 연동할 수 있습니다.

  • 적응형 사고

    thinking과 effort 매개변수를 사용합니다. Anthropic 문서에 따르면 Fable 5.1, Sonnet 5 같은 모델은 기본적으로 적응형 사고를 사용합니다. 자세한 내용은 각 모델 페이지를 참고하세요.

  • 이미지 및 PDF 입력

    AnyAIGC 문서에 PDF 문서 예제가 있으며, Claude 모델의 이미지 입력은 Anthropic 문서에서 다룹니다.

  • 스트리밍

    "stream": true를 설정하면 생성되는 대로 출력을 받을 수 있어 채팅 UI와 긴 응답에 적합합니다.

세 단계로 시작하기

  1. 가입 및 충전: anyaigc.ai에서 계정을 만드세요. 잔액은 플랫폼의 모든 모델에서 사용할 수 있습니다.
  2. API 키 생성: 콘솔에서 토큰을 만들고 sk-로 시작하는 키를 복사하세요.
  3. 요청 보내기: Anthropic Messages 요청으로 https://anyaigc.ai/v1/messages를 호출하고, 인증에는 Authorization: Bearer를 사용합니다.

그 밖의 매개변수(tools, thinking, 스트리밍, PDF 및 이미지 입력 등)는 AnyAIGC Messages API 문서를 참고하세요. 각 필드의 의미는 Anthropic API 문서와 같습니다.

Claude API FAQ

Claude API 가격은 얼마입니까?

AnyAIGC의 모든 Claude 모델은 구독료나 월 요금 없이 100만 토큰당 USD 기준 토큰 단위로 과금됩니다. 현재 모델은 Opus 5.5가 입력 $0.4765, 출력 $2.3820, Sonnet 5.5가 입력 $0.2382, 출력 $1.1910, Haiku 5.5가 입력 $0.0119, 출력 $0.0596, Fable 5.2가 입력 $1.9060, 출력 $9.5290입니다. Opus, Sonnet, Haiku는 Anthropic 공식 정가 대비 88% 할인, Fable은 76% 할인입니다. 캐시 쓰기, 캐시 히트, 이전 세대 모델의 가격은 이 페이지의 가격표에 있으며, 실시간 가격은 AnyAIGC 모델 카탈로그에서 확인하세요.

Claude API 키는 어떻게 받습니까?

anyaigc.ai에서 가입하고 잔액을 충전한 뒤, 콘솔에서 토큰을 만드세요. 같은 키로 이 페이지의 Claude 11개 모델과 플랫폼의 다른 300개 이상 모델을 모두 사용할 수 있으며, 하나의 잔액에서 차감됩니다.

AnyAIGC Claude API는 Anthropic 공식 SDK와 함께 사용할 수 있습니까?

네. 엔드포인트는 https://anyaigc.ai/v1/messages이며, 요청 본문은 Anthropic Messages 형식(model, max_tokens, system, messages, tools, cache_control 등)을 따릅니다. 인증은 Authorization: Bearer와 API 키로 합니다. 공식 anthropic SDK에서는 base_url을 https://anyaigc.ai로 설정하면 나머지 코드는 그대로 사용할 수 있습니다.

어떤 Claude 모델을 사용할 수 있으며, 무엇을 골라야 합니까?

AnyAIGC는 Claude 11개 모델을 제공합니다. 현재 모델은 Opus 5.5, Sonnet 5.5, Haiku 5.5, Fable 5.2입니다. 복잡한 코딩과 AI 에이전트에는 Opus 5.5, 범위가 분명한 일상 코딩, 버그 수정, 문서 작업에는 Sonnet 5.5, 대량 분류, 실시간 지원, 서브 에이전트에는 Haiku 5.5(Anthropic이 Claude 5.5 제품군에서 가장 빠르고 효율적인 모델이라고 설명), 범위가 가장 넓은 기술 작업과 장시간 실행 에이전트에는 Fable 5.2를 사용하세요. 이전 모델인 Fable 5.1과 이전 세대 모델인 Opus 5, Fable 5, Sonnet 5, Opus 4.8, Opus 4.7, Opus 4.6도 기존 프로젝트를 위해 계속 제공됩니다.

Claude Opus와 Sonnet은 어떻게 다릅니까?

Anthropic은 Sonnet 5.5를 Opus 5.5를 보완하는 더 빠르고 저렴한 모델로 설명합니다. Opus 5.5는 신중한 판단이 필요한 복잡한 작업을 겨냥하고, Sonnet 5.5는 범위가 분명한 일상 작업, 버그 수정, 완성도 높은 문서, 슬라이드, 스프레드시트에 맞춰져 있습니다. Sonnet 5.5는 가격이 절반입니다. AnyAIGC에서 입력 $0.2382, 출력 $1.1910이며, Opus 5.5는 $0.4765, $2.3820입니다(100만 토큰당).

Claude Fable과 Opus는 어떻게 다릅니까?

Anthropic은 Fable 5.2를 장시간 실행 에이전트를 위한 차세대 인텔리전스이자 범위가 가장 넓은 기술 작업을 위한 모델로 설명합니다. Anthropic은 대부분의 코딩과 지식 업무를 Claude Opus 5.5로 시작하고 필요에 따라 Fable로 올려 사용할 것을 권장합니다. AnyAIGC에서 Fable 5.2는 100만 토큰당 입력 $1.9060, 출력 $9.5290이고, Opus 5.5는 $0.4765, $2.3820입니다. 같은 키를 쓰므로 model 필드만 바꿔 작업마다 전환할 수 있습니다.

이전 Claude 모델도 계속 사용할 수 있습니까?

네. Anthropic은 Opus 5, Fable 5, Sonnet 5, Opus 4.8, Opus 4.7, Opus 4.6을 이전 세대 모델로 분류하며, 모두 AnyAIGC에서 계속 사용할 수 있습니다. Anthropic이 밝힌 가장 이른 종료일은 Opus 4.6이 2027년 2월 5일, Opus 4.7이 2027년 4월 16일, Opus 4.8이 2027년 5월 28일, Fable 5가 2027년 6월 9일, Sonnet 5가 2027년 6월 30일, Opus 5가 2027년 7월 24일입니다. 이전 모델인 Fable 5.1도 계속 사용할 수 있습니다. 새 프로젝트에는 해당하는 현재 모델을 사용하세요.

Claude Code에서 사용할 수 있습니까?

네. curl -fsSL https://www.anyaigc.ai/install.sh | bash -s claude를 실행하면 설치와 설정이 한 번에 끝납니다. 또는 ~/.claude/settings.json의 env 블록에서 ANTHROPIC_BASE_URL을 https://anyaigc.ai로, ANTHROPIC_AUTH_TOKEN을 API 키로, ANTHROPIC_MODEL을 claude-opus-5-5로 설정하세요. ANTHROPIC_DEFAULT_HAIKU_MODEL을 claude-haiku-5-5로 설정하면 백그라운드 작업과 서브 에이전트를 Haiku 5.5로 실행할 수 있습니다.

동시 실행 제한이 있습니까?

없습니다. AnyAIGC는 어떤 Claude 모델에도 동시 실행 제한을 두지 않으며, 모든 사용자에게 기본으로 적용되므로 배치 작업이나 병렬 에이전트도 대기할 필요가 없습니다.

AnyAIGC에서 인보이스를 받을 수 있습니까?

네. 콘솔에서 실제 충전한 금액 기준으로 직접 인보이스를 발급할 수 있습니다.

어떤 결제 수단을 지원합니까?

WeChat Pay, Alipay, USDT, 신용카드로 충전할 수 있습니다. 잔액은 USD 기준이며 플랫폼의 모든 모델에서 사용할 수 있습니다. 인보이스는 콘솔에서 충전한 금액 기준으로 발급할 수 있습니다.

신규 사용자에게 무료 체험 크레딧이 있습니까?

네. 신규 계정에는 토큰 200만 개 분량의 체험 크레딧이 제공되므로 충전 여부를 결정하기 전에 먼저 테스트할 수 있습니다. 충전은 $1부터 가능합니다.

잔액을 환불받을 수 있습니까?

네. 사용하지 않은 잔액은 수수료 없이 환불받을 수 있습니다. 환불은 고객 지원에 문의해 진행하세요.

실제 모델이 맞습니까? 데이터는 안전합니까?

요청은 공식 모델 채널로 전달되며, 저가 모델이나 리버스 엔지니어링 방식의 대체 모델은 사용하지 않습니다. 법령에서 요구하는 경우를 제외하고 프롬프트와 출력을 영구 저장하거나 학습에 사용하지 않으며, 콘솔에서 모든 요청의 토큰 수와 비용을 확인할 수 있습니다.
