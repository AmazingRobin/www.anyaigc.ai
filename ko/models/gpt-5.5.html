GPT 5.5 API

지난 세대의 플래그십, API에서 계속 사용할 수 있으며 공식 정가의 약 5%

GPT-5.5는 OpenAI가 2026년 4월에 출시한 플래그십 모델입니다. OpenAI는 Terminal-Bench 2.0에서 82.7%를 기록했다고 밝혔습니다. AnyAIGC에서 gpt-5.5를 입력 100만 토큰당 $0.2482부터 호출할 수 있으며, OpenAI 가격 대비 95% 할인됩니다.

서둘러 옮길 필요가 없는 GPT-5.5 플래그십

OpenAI는 2026년 4월 23일 GPT-5.5를 출시하고 다음 날 API에 공개했습니다. OpenAI는 이 모델을 코딩과 복잡한 전문 업무를 위한 플래그십으로 소개하며 "지금까지 가장 강력한 에이전트 코딩 모델"이라고 설명합니다. Terminal-Bench 2.0에서는 82.7%를 기록했습니다. 또한 OpenAI에 따르면 토큰당 지연 시간은 GPT-5.4와 같고, 같은 Codex 작업에서 사용하는 토큰은 눈에 띄게 적습니다.

GPT-5.5는 none, low, medium(기본값), high, xhigh의 다섯 가지 추론 강도(reasoning effort)를 지원하며 max는 지원하지 않습니다. 컨텍스트 길이는 1,050,000 토큰, 최대 출력은 128,000 토큰이고, 텍스트와 이미지를 입력받아 텍스트를 출력합니다. 지식 기준일은 2025년 12월 1일입니다. OpenAI는 날짜가 붙은 스냅샷 gpt-5.5-2026-04-23도 제공합니다.

이후 OpenAI는 GPT-5.6과 GPT-6 제품군을 출시했지만, API의 gpt-5.5에는 지원 중단 공지가 없습니다. AnyAIGC에서 gpt-5.5는 /v1/chat/completions와 /v1/responses 모두에서 동작합니다. 공식 OpenAI SDK를 쓴다면 base_url만 https://anyaigc.ai/v1로 바꾸면 되고, 같은 키로 300개 이상의 다른 모델도 호출할 수 있으므로 나중에 업그레이드할 때는 model 필드만 바꾸면 됩니다.

GPT-5.5가 잘 맞는 작업

  • 01 · 코딩

    에이전트 코딩과 Codex

    터미널이나 저장소에서 버그를 추적하고, 파일을 수정하고, 테스트를 실행합니다. OpenAI는 Terminal-Bench 2.0에서 82.7%를 기록했고 같은 Codex 작업에서 토큰을 더 적게 쓴다고 밝혔으며, AnyAIGC의 한 줄 Codex 설치 스크립트는 기본으로 이 모델을 사용합니다.

  • 02 · 컴퓨터 사용

    UI와 브라우저 조작

    Responses API에서 도구를 사용해 여러 단계의 작업과 웹 리서치를 실행합니다. OpenAI가 공개한 수치는 OSWorld-Verified 78.7%, BrowseComp 84.4%입니다.

  • 03 · 전문 업무

    지식 업무와 긴 문서

    OpenAI는 GPT-5.5를 복잡한 전문 업무용 플래그십으로 소개하며, GDPval에서 승리 또는 동률 84.9%를 기록했습니다. 컨텍스트 길이 1,050,000 토큰이면 계약서, 보고서, PDF를 한 번의 요청에 담을 수 있고, 캐시 입력은 100만 토큰당 $0.0248입니다.

  • 04 · 기존 연동

    안정적인 운영 시스템

    프롬프트와 평가를 GPT-5.5에 맞춰 튜닝한 시스템은 그대로 두어도 되며, 고정된 버전이 필요하면 gpt-5.5-2026-04-23을 지정할 수 있습니다. 업그레이드할 준비가 되면 model 필드만 바꾸세요. 같은 키로 GPT-5.6이나 GPT-6로 옮길 수 있습니다.

3단계로 GPT-5.5 API 호출하기

  1. 가입 후 충전: anyaigc.ai에서 계정을 만드세요. 잔액은 모든 모델에서 공통으로 사용할 수 있습니다.
  2. API 키 만들기: 콘솔에서 토큰을 만들고 sk- 키를 복사해 ANYAIGC_API_KEY 환경 변수에 저장하세요.
  3. 요청 보내기: model을 gpt-5.5로 지정하고 Authorization: Bearer 인증으로 https://anyaigc.ai/v1/chat/completions 또는 https://anyaigc.ai/v1/responses를 호출하세요.

두 엔드포인트 모두 도구 호출이 가능합니다. gpt-5.5는 /v1/chat/completions와 /v1/responses 모두에서 함수 호출을 지원하므로 기존 Chat Completions 코드가 그대로 동작합니다. 새로 연동하거나 다단계 에이전트, Codex를 쓸 때는 Responses API를 사용하고 reasoning.effort에 강도를 지정하세요. Chat Completions에서는 최상위 reasoning_effort를 사용합니다.

모든 파라미터는 Chat Completions 레퍼런스와 Responses 레퍼런스를 참고하세요. 필드는 공식 OpenAI API와 같습니다.

Codex에서 GPT-5.5 사용하기

명령 한 줄로 Codex CLI를 설치하고 AnyAIGC 설정을 작성합니다. ~/.codex/ 아래 파일 두 개를 직접 수정해도 됩니다.

한 줄 설치 스크립트가 이미 모델을 gpt-5.5로 설정하므로 설치 후 바꿀 것이 없습니다. 나중에 모델을 바꾸려면 ~/.codex/config.toml의 model을 수정하세요. 두 파일을 저장한 뒤 프로젝트 폴더에서 codex를 실행하세요. Codex는 Responses API를 사용합니다. 전체 절차와 자주 발생하는 오류는 Codex 설정 가이드를 참고하세요.

GPT-5.5는 Terminal-Bench 2.0에서 82.7%, SWE-Bench Pro에서 58.6%를 기록했습니다.

이 페이지는 입력 $0.2482, 출력 $1.4890, 캐시 입력 $0.0248을 안내하며, 위 가격표와 일치합니다.

gpt-5.5는 이 세대의 표준 모델이고, gpt-5.5-pro는 OpenAI가 더 높은 정확도용으로 내놓은 버전입니다.

사양은 제공사의 공식 문서(openai.com)를 따랐습니다. 이 페이지의 표가 가격이며, 실시간 요금은 모델 카탈로그를 기준으로 합니다.

GPT-5.5 API 자주 묻는 질문

GPT-5.5 API 가격은 얼마입니까?

AnyAIGC에서 gpt-5.5는 토큰 단위로 과금합니다. 입력 100만 토큰당 $0.2482, 출력 100만 토큰당 $1.4890, 캐시 입력 100만 토큰당 $0.0248입니다. OpenAI 공식 정가는 입력 $5.00, 출력 $30.00, 캐시 입력 $0.50이므로 AnyAIGC는 공식 정가의 약 5%(95% 할인)입니다. 한 요청의 입력이 272K 토큰을 넘으면 요청 전체에 입력 2배, 출력 1.5배 요율이 적용됩니다.

GPT-5.5의 모델 ID는 무엇입니까?

모델 ID는 gpt-5.5입니다. 요청의 model 필드에 넣으세요. 버전을 고정해야 한다면 OpenAI가 제공하는 날짜 스냅샷 gpt-5.5-2026-04-23도 사용할 수 있습니다.

GPT-5.5는 지원 중단되었습니까? 언제까지 사용할 수 있습니까?

아니요. OpenAI가 GPT-5.6과 GPT-6 제품군을 출시했지만, API의 gpt-5.5에는 지원 중단 공지가 없습니다. OpenAI는 종료 일정을 발표하지 않았고 지금도 문제없이 호출할 수 있습니다. AnyAIGC에서 코드 변경 없이 계속 gpt-5.5를 사용할 수 있습니다. 새 프로젝트에는 GPT-6.1 Sol을 고려해 보세요.

gpt-5.5에서 "model not found" 오류가 납니다. 무엇을 확인해야 합니까?

세 가지를 확인하세요. model 필드가 정확히 gpt-5.5(소문자, 점 포함)인지, base_url이 https://anyaigc.ai/v1인지, 요청 헤더가 AnyAIGC API 키를 담은 Authorization: Bearer인지 확인하세요. Codex에서는 ~/.codex/config.toml의 model_provider가 AnyAIGC를 가리키는지 확인하세요. 그래도 실패하면 연중무휴 24시간 고객 지원에 문의하세요.

GPT-5.5에서 GPT-5.6 Sol이나 GPT-6.1 Sol로 옮겨야 합니까?

상황에 따라 다릅니다. 튜닝한 프롬프트로 잘 동작하는 연동은 고정 스냅샷도 있는 gpt-5.5에 그대로 두어도 됩니다. OpenAI의 GPT-5.6 출시 결과에서 GPT-5.6 Sol은 Terminal-Bench 2.1에서 88.8%로, GPT-5.5의 85.6%보다 높습니다. AnyAIGC에서 GPT-5.6 Sol은 GPT-5.5와 가격이 같고(입력 $0.2482, 출력 $1.4890), GPT-6.1 Sol은 100만 토큰당 입력 $0.0993, 출력 $0.4964로 더 저렴합니다. 새 프로젝트에는 GPT-6.1 Sol을 먼저 시도해 보세요.

Chat Completions와 Responses API 중 무엇을 써야 합니까? 도구도 사용할 수 있습니까?

두 엔드포인트 모두 사용할 수 있으며, https://anyaigc.ai/v1/chat/completions와 https://anyaigc.ai/v1/responses 모두에서 함수 호출을 지원합니다. 기존 Chat Completions 코드는 그대로 동작합니다. 새로 연동하거나 다단계 에이전트, Codex를 쓸 때는 Responses API를 사용하고 reasoning.effort에 none, low, medium(기본값), high, xhigh 중 하나를 지정하세요.

Codex에서 GPT-5.5를 사용할 수 있습니까?

네. curl -fsSL https://www.anyaigc.ai/install.sh | bash -s codex를 실행하면 설치와 설정이 끝납니다(Windows에서는 irm https://www.anyaigc.ai/install.ps1 | iex). 설치 스크립트가 이미 모델을 gpt-5.5로 설정하므로 바로 동작합니다. 직접 설정하려면 ~/.codex/config.toml에서 base_url을 https://anyaigc.ai/v1, wire_api를 responses, model을 gpt-5.5로 지정한 뒤 OPENAI_API_KEY를 ~/.codex/auth.json에 넣으세요.

동시 실행 수나 속도 제한이 있습니까?

AnyAIGC는 gpt-5.5에 동시 실행 제한을 두지 않습니다. 모든 계정에 기본으로 적용되므로 배치 작업과 병렬 에이전트를 대기 없이 실행할 수 있습니다.

AnyAIGC에서 인보이스를 받을 수 있습니까?

네. 콘솔에서 실제 충전한 금액 기준으로 직접 인보이스를 발급할 수 있습니다.

어떤 결제 수단을 지원합니까?

WeChat Pay, Alipay, USDT, 신용카드로 충전할 수 있습니다. 잔액은 USD 기준이며 플랫폼의 모든 모델에서 사용할 수 있습니다. 인보이스는 콘솔에서 충전한 금액 기준으로 발급할 수 있습니다.

신규 사용자에게 무료 체험 크레딧이 있습니까?

네. 신규 계정에는 토큰 500만 개 분량의 체험 크레딧이 제공되므로 충전 여부를 결정하기 전에 먼저 테스트할 수 있습니다. 충전은 $1부터 가능합니다.

잔액을 환불받을 수 있습니까?

네. 사용하지 않은 잔액은 수수료 없이 환불받을 수 있습니다. 환불은 고객 지원에 문의해 진행하세요.

실제 모델이 맞습니까? 데이터는 안전합니까?

요청은 공식 모델 채널로 전달되며, 저가 모델이나 리버스 엔지니어링 방식의 대체 모델은 사용하지 않습니다. 법령에서 요구하는 경우를 제외하고 프롬프트와 출력을 영구 저장하거나 학습에 사용하지 않으며, 콘솔에서 모든 요청의 토큰 수와 비용을 확인할 수 있습니다.

내 데이터가 학습에 사용됩니까?

아니요. 법령에서 요구하는 경우를 제외하고 AnyAIGC는 프롬프트와 출력을 영구 저장하지 않으며 학습에 사용하지 않습니다. 요청은 HTTPS로 전송 중에 암호화됩니다. 자세한 내용은 AnyAIGC 개인정보 처리방침을 참고하세요. 모델 자체의 데이터 정책은 OpenAI 공식 약관을 따릅니다.
