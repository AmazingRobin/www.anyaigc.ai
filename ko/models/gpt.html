작업에 맞는 모델 고르기

어디서 시작할지 모르겠다면 지금 할 작업에 맞게 고르고, 언제든 바꾸세요. 아래 분류는 OpenAI의 설명을 따랐습니다.

  • 01 · 가장 어려운 작업

    가장 어려운 프로젝트, 전문 문서, 리서치 → GPT-6.2 Astra

    OpenAI는 GPT-6.2 Astra를 가장 어려운 프로젝트를 위한 새로운 최상위 모델이라고 소개하며, API 공식 정가는 GPT-6 Astra보다 낮습니다. 입력 100만 토큰당 $0.3971.

  • 02 · 기본 선택

    일상적인 코딩과 에이전트 → GPT-6.2 Sol

    OpenAI는 GPT-6.2 Sol을 일상 업무를 위한 기본 모델이라고 소개하며, 공식 정가는 GPT-6.1 Sol과 같고 더 똑똑하고 효율적이라고 밝혔습니다. 기본 선택으로 적합합니다. 입력 100만 토큰당 $0.0993.

  • 03 · 대량 처리

    분류, 추출, 요약 → GPT-6 Luna

    OpenAI는 Luna를 가장 빠르고 비용 효율적인 등급이라고 설명하며, 범위가 정해진 빈번한 자동화에 적합합니다. 입력 100만 토큰당 $0.0135.

  • 04 · Codex

    Codex에서 코딩 → GPT-6.2 Sol + GPT-6.2 Astra

    일상적인 수정에는 gpt-6.2-sol을, 여러 파일에 걸친 어려운 문제에는 gpt-6.2-astra를 사용하세요. Codex는 Responses API를 사용합니다. 아래 Codex 섹션을 참고하세요.

  • 05 · 정확도

    정확도가 가장 중요한 리서치 → GPT-5.5 Pro

    OpenAI에 따르면 매우 복잡한 문제에서 더 많은 연산을 사용해 더 깊이 생각합니다. Responses API(/v1/responses)만 지원하고 가격이 높으므로 중요한 요청에만 사용하세요.

  • 06 · 비전과 컴퓨터 사용

    화면 읽기, 양식 작성, 도면 분석, 문구 작성 → GPT-6.1 Terra

API 키 받기 모델 카탈로그에서 보기

OpenAI 네이티브 엔드포인트를 완전히 지원

요청 형식이 OpenAI 공식 API와 같으므로 공식 SDK와 기존 코드를 base_url만 바꿔 그대로 옮길 수 있습니다.

  • Chat Completions API

    채팅 엔드포인트

    표준 messages 형식으로 /v1/chat/completions를 호출하세요. 기존 코드와 프레임워크가 그대로 동작합니다(GPT-5.5 Pro 제외).

  • Responses API 엔드포인트

    Responses와 도구 호출

    함수 호출에는 /v1/responses를 호출하세요. Codex도 이 엔드포인트를 사용합니다.

  • 구조화된 출력(Structured Outputs)

    구조화된 출력

    JSON Schema로 응답을 제한하면 정규식 폴백 없이 결과를 파싱하고 저장할 수 있습니다.

  • reasoning_effort

    추론 강도(Reasoning effort)

    Chat Completions에서는 reasoning_effort, Responses에서는 reasoning.effort를 사용하세요. GPT-6는 max까지 지원하며, GPT-6 Sol과 GPT-6 Luna는 none도 지원하지만 GPT-6.1 Sol과 GPT-6 Astra는 지원하지 않습니다.

  • 이미지 입력

    이미지 입력

    모든 모델이 텍스트와 이미지 입력을 받아 텍스트를 반환하므로 스크린샷, 차트, 스캔 문서를 보낼 수 있습니다.

  • 스트리밍

    스트리밍

    stream: true를 설정하면 토큰이 생성되는 대로 받을 수 있습니다. GPT-5.5 Pro는 스트리밍을 지원하지 않습니다.

GPT-6의 도구 호출에는 /v1/responses를 사용하세요. OpenAI에 따르면 gpt-6.1-sol은 Chat Completions에서 도구 호출을 지원하지 않고, gpt-6.2-sol과 gpt-6.2-astra는 해당 제한이 명시되어 있지 않지만 이 모델들도 /v1/responses를 권장하며, gpt-6-sol과 gpt-6-luna는 그 엔드포인트에서 reasoning_effort를 none으로 설정한 경우에만 함수 호출을 지원하고, gpt-6-astra는 어느 쪽으로도 문서화되어 있지 않습니다. 일반 채팅과 스트리밍은 /v1/chat/completions에서 그대로 작동합니다. gpt-5.5-pro는 /v1/responses에서만 작동합니다.

3단계로 GPT API 호출 시작하기

  1. 가입 후 충전: anyaigc.ai에서 계정을 만드세요. 잔액은 모든 모델에서 공통으로 사용할 수 있습니다.
  2. API 키 만들기: 콘솔에서 토큰을 만들고 sk- 키를 복사해 ANYAIGC_API_KEY 환경 변수에 저장하세요.
  3. 요청 보내기: OpenAI SDK의 base_url을 https://anyaigc.ai/v1로 설정하고, model에 이 페이지의 모델 ID를 넣은 뒤, Authorization: Bearer로 인증하세요.

모든 파라미터는 Chat Completions 레퍼런스와 Responses 레퍼런스를 참고하세요. 필드는 OpenAI 공식 API와 같습니다.

anyaigc.ai에서 가입하고 충전한 뒤, 콘솔에서 토큰을 생성하면 sk- 키를 받을 수 있습니다. 같은 키로 이 페이지의 GPT 모델 12종과 300개 이상의 다른 모델을 하나의 공유 잔액으로 사용할 수 있습니다.

OpenAI 공식 SDK와 호환됩니까?

네. base_url을 https://anyaigc.ai/v1로, api_key를 AnyAIGC 키로 설정하면 기존 코드가 거의 또는 전혀 수정 없이 동작합니다. /v1/chat/completions와 /v1/responses를 모두 지원하고, 인증은 Authorization: Bearer를 사용하며, 필드는 OpenAI 공식 API와 같습니다.

GPT Astra, Sol, Terra, Luna 중 무엇을 써야 합니까?

이 네 가지는 OpenAI의 현재 성능 등급입니다. OpenAI에 따르면 Astra의 지능이 가장 높고, 현재 버전은 가장 어려운 프로젝트를 위한 GPT-6.2 Astra이며 공식 정가는 GPT-6 Astra보다 20% 낮습니다. Sol은 속도, 비용, 지능의 균형을 맞추며, 현재 버전은 GPT-6.2 Sol로 OpenAI는 같은 공식 정가($2 / $10)에서 GPT-6.1 Sol보다 더 똑똑하고 효율적이라고 밝혔습니다. Terra는 Sol과 Luna 사이에 있고, 현재 버전은 시각적 추론, 컴퓨터 사용(computer use), 글쓰기를 위해 만든 GPT-6.1 Terra로 빠르고 공식 정가는 Sol의 절반입니다. Luna는 가장 빠르고 비용 효율적이며 범위가 정해진 반복 작업에 적합합니다. 대부분의 코딩과 에이전트 작업은 GPT-6.2 Sol로 시작하고, 가장 어려운 작업은 GPT-6.2 Astra로, 대량의 단순한 작업은 GPT-6 Luna를 사용하세요.

GPT-5.6 Terra와 GPT-6.1 Terra는 어떤 관계입니까?

Terra는 GPT-5.6의 균형형 등급입니다. OpenAI는 이 모델을 GPT-5.5 수준의 성능을 더 낮은 비용으로 제공하는, 일상 업무용 균형형 모델이라고 설명합니다. 2026년 10월 26일 OpenAI는 후속 모델인 GPT-6.1 Terra를 출시하면서 공식 정가를 $2 / $12에서 $1 / $5로 낮췄습니다. GPT-5.6 Terra도 계속 호출할 수 있습니다. AnyAIGC에서 gpt-5.6-terra는 100만 토큰당 입력 $0.0993, 출력 $0.5957이고, gpt-6.1-terra는 입력 $0.0496, 출력 $0.2482입니다.

GPT-6.1 Sol과 GPT-6 Sol: 무엇이 달라졌습니까?

OpenAI는 GPT-6.1 Sol을 GPT-6 Sol의 업그레이드 버전이라고 설명합니다. 입력과 출력 공식 정가는 $2와 $10으로 그대로이고, 캐시 입력은 $0.20에서 $0.10으로 내려갔으며, OpenAI에 따르면 DeepSWE v1.1, OSWorld 2.0 같은 벤치마크에서 GPT-6 Sol보다 높은 점수를 기록했습니다. GPT-6.1 Sol은 none 추론 강도를 지원하지 않으며 Chat Completions에서 도구 호출을 지원하지 않습니다. AnyAIGC에서는 두 모델 모두 입력 $0.0993, 출력 $0.4964이고, 캐시 입력은 각각 $0.0050과 $0.0099입니다. 새 프로젝트에는 GPT-6.1 Sol을 사용하고, 기존 연동은 gpt-6-sol을 그대로 써도 됩니다.

이전 GPT 모델도 계속 사용할 수 있습니까?

GPT-6 Sol, GPT-5.6 Sol, GPT-5.6 Terra, GPT-5.6 Luna, GPT-5.5, GPT-5.5 Pro는 모두 새 후속 모델이 나왔지만, OpenAI는 이 모델들의 API 종료 일정을 발표하지 않았으며 현재 AnyAIGC에서 모두 동작합니다. 새 프로젝트에는 GPT-6.1 Sol, GPT-6.1 Terra, GPT-6 Astra, GPT-6 Luna를 사용하세요.

Codex에서 GPT 모델을 사용할 수 있습니까?

네. curl -fsSL https://www.anyaigc.ai/install.sh | bash -s codex를 실행하면 설치와 설정이 완료됩니다(Windows에서는 irm https://www.anyaigc.ai/install.ps1 | iex). 설치 스크립트의 기본 모델은 gpt-5.5이므로, 설치 후 ~/.codex/config.toml의 model을 gpt-6.1-sol 또는 gpt-6-astra로 바꾸세요. 직접 설정하려면 ~/.codex/config.toml에서 base_url을 https://anyaigc.ai/v1로, wire_api를 responses로 지정하고, OPENAI_API_KEY를 ~/.codex/auth.json에 넣으세요.

동시 실행 제한이 있습니까?

AnyAIGC는 어떤 GPT 모델에도 동시 실행 제한을 두지 않습니다. 모든 계정에 기본 적용되므로 배치 작업과 병렬 에이전트도 대기 없이 실행됩니다.

AnyAIGC에서 인보이스를 받을 수 있습니까?

네. 콘솔에서 실제 충전한 금액 기준으로 직접 인보이스를 발급할 수 있습니다.

어떤 결제 수단을 지원합니까?

WeChat Pay, Alipay, USDT, 신용카드로 충전할 수 있습니다. 잔액은 USD 기준이며 플랫폼의 모든 모델에서 사용할 수 있습니다. 인보이스는 콘솔에서 충전한 금액 기준으로 발급할 수 있습니다.

신규 사용자에게 무료 체험 크레딧이 있습니까?

네. 신규 계정에는 토큰 200만 개 분량의 체험 크레딧이 제공되므로 충전 여부를 결정하기 전에 먼저 테스트할 수 있습니다. 충전은 $1부터 가능합니다.

잔액을 환불받을 수 있습니까?

네. 사용하지 않은 잔액은 수수료 없이 환불받을 수 있습니다. 환불은 고객 지원에 문의해 진행하세요.

실제 모델이 맞습니까? 데이터는 안전합니까?

요청은 공식 모델 채널로 전달되며, 저가 모델이나 리버스 엔지니어링 방식의 대체 모델은 사용하지 않습니다. 법령에서 요구하는 경우를 제외하고 프롬프트와 출력을 영구 저장하거나 학습에 사용하지 않으며, 콘솔에서 모든 요청의 토큰 수와 비용을 확인할 수 있습니다.

내 데이터가 학습에 사용됩니까?

아니요. 법령에서 요구하는 경우를 제외하고 AnyAIGC는 프롬프트와 출력을 영구 저장하지 않으며 학습에 사용하지 않습니다. 요청은 HTTPS로 전송 중에 암호화됩니다. 자세한 내용은 AnyAIGC 개인정보 처리방침을 참고하세요. 모델 자체의 데이터 정책은 OpenAI 공식 약관을 따릅니다.
