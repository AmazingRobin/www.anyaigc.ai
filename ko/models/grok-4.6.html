Grok 4.6 API 연동

최소한의 요청으로 시작한 뒤 애플리케이션에 연결하세요.

  1. 01가입한 뒤 콘솔에서 API 키를 만드세요.
  2. 02ANYAIGC_API_KEY 환경 변수를 설정하세요.
  3. 03grok-4.6으로 요청을 보내고 콘솔에서 사용량을 확인하세요.
POST /v1/chat/completions ↗POST /v1/messages ↗

cURL 예제는 Bash / WSL 기준입니다. Python 예제는 SDK 없이 표준 라이브러리를 사용합니다. 응답은 전체 JSON으로 반환되며, Python 예제는 choices[0].message.content를 읽습니다.

cURL
curl https://anyaigc.ai/v1/chat/completions \
  -H "Authorization: Bearer $ANYAIGC_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
  "model": "grok-4.6",
  "messages": [
    {
      "role": "user",
      "content": "Break a task app into a data layer, API, and frontend. Give a step-by-step implementation plan."
    }
  ],
  "stream": false
}'
Python · 표준 라이브러리
import json
import os
import urllib.request

payload = {'model': 'grok-4.6', 'messages': [{'role': 'user', 'content': 'Break a task app into a data layer, API, and frontend. Give a step-by-step implementation plan.'}], 'stream': False}
request = urllib.request.Request(
    "https://anyaigc.ai/v1/chat/completions",
    data=json.dumps(payload).encode("utf-8"),
    headers={
        "Authorization": f"Bearer {os.environ['ANYAIGC_API_KEY']}",
        "Content-Type": "application/json",
    },
    method="POST",
)
with urllib.request.urlopen(request, timeout=180) as response:
    result = json.load(response)
print(result["choices"][0]["message"]["content"])
Messages · cURL
curl https://anyaigc.ai/v1/messages \
  -H "Authorization: Bearer $ANYAIGC_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
  "model": "grok-4.6",
  "messages": [
    {
      "role": "user",
      "content": "Break a task app into a data layer, API, and frontend. Give a step-by-step implementation plan."
    }
  ],
  "stream": false,
  "max_tokens": 1024
}'

요청 및 응답 필드는 AnyAIGC 문서를 따릅니다. Messages 페이지에는 Grok 고유의 응답 차이가 문서화되어 있지 않으므로, 해당 예제는 추가 응답 필드를 가정하지 않고 요청만 보여 줍니다.

사양과 선택 기준

grok-4.6은 2026년 8월 12일에 출시되었으며, 제공사는 이 모델을 코딩, 에이전트 작업, 지식 업무를 위한 플래그십으로 소개했습니다.

컨텍스트 길이는 500,000 토큰이며, 텍스트와 이미지를 입력받아 텍스트를 반환하고, 텍스트 출력 한도는 없습니다.

추론 강도(reasoning effort)는 low, medium, high(기본값), xhigh 중에서 선택할 수 있습니다.

이 페이지는 (Grok 4.6 기본 구간 · 입력 ≤ 200,000 토큰) 기준으로 입력 100만 토큰당 $0.1985, 출력 100만 토큰당 $0.5956, 캐시 히트 입력 100만 토큰당 $0.0496을 표시합니다. 다른 구간은 위의 가격표를 참고하세요.

공식 문서는 코드와 대화 모두에서 grok-4.7을 첫 번째 선택지로 제시하며, 지식 기준일은 2026년 5월입니다.

사양은 제공사의 공식 문서(docs.x.ai)를 따릅니다. 이 페이지의 표는 가격이며, 실시간 요금은 모델 카탈로그가 기준입니다.

07 / FAQ

Grok 4.6 API FAQ

Grok 4.6에는 어떤 모델 ID를 사용해야 합니까?

grok-4.6을 표기된 그대로 사용하세요. 시리즈의 다른 모델은 Grok 4.x 개요를 참고하세요.

Grok API 요금은 어떻게 책정됩니까?

입력은 100만 토큰당 $0.1985, 출력은 100만 토큰당 $0.5956입니다. 입력이 200,000 토큰을 초과하고 500,000 토큰 이하인 Grok 4.6 요청은 입력 100만 토큰당 $0.3971, 출력 100만 토큰당 $1.191입니다. 이는 카탈로그에 표시된 최저 요금이므로, 현재 가격은 모델 카탈로그에서 확인하세요.

어떤 API 엔드포인트를 지원합니까?

POST /v1/chat/completions와 POST /v1/messages를 지원합니다.

동시 실행 수나 RPM 제한이 있습니까?

여기에 나열된 모든 모델은 모든 사용자에게 기본적으로 동시 실행 제한이 없으며, 별도의 활성화가 필요 없습니다. 연결, 타임아웃, 재시도는 애플리케이션에서 관리하세요.

API가 실시간 X 데이터를 자동으로 포함합니까?

일반 대화에는 실시간 이벤트가 자동으로 포함되지 않습니다. xAI는 실시간 데이터에 검색 도구를 요구하며, 여기의 기본 예제는 검색을 사용하지 않고 모든 업스트림 검색 도구의 지원을 보장하지도 않습니다. 상업적 이용은 xAI 약관을 따릅니다.

AnyAIGC에서 인보이스를 받을 수 있습니까?

네. 콘솔에서 실제 충전한 금액 기준으로 직접 인보이스를 발급할 수 있습니다.

어떤 결제 수단을 지원합니까?

WeChat Pay, Alipay, USDT, 신용카드로 충전할 수 있습니다. 잔액은 USD 기준이며 플랫폼의 모든 모델에서 사용할 수 있습니다. 인보이스는 콘솔에서 충전한 금액 기준으로 발급할 수 있습니다.

신규 사용자에게 무료 체험 크레딧이 있습니까?

네. 신규 계정에는 토큰 200만 개 분량의 체험 크레딧이 제공되므로 충전 여부를 결정하기 전에 먼저 테스트할 수 있습니다. 충전은 $1부터 가능합니다.

잔액을 환불받을 수 있습니까?

네. 사용하지 않은 잔액은 수수료 없이 환불받을 수 있습니다. 환불은 고객 지원에 문의해 진행하세요.

실제 모델이 맞습니까? 데이터는 안전합니까?

요청은 공식 모델 채널로 전달되며, 저가 모델이나 리버스 엔지니어링 방식의 대체 모델은 사용하지 않습니다. 법령에서 요구하는 경우를 제외하고 프롬프트와 출력을 영구 저장하거나 학습에 사용하지 않으며, 콘솔에서 모든 요청의 토큰 수와 비용을 확인할 수 있습니다.
