소개

코딩용으로 추가 학습한 K2.6

Moonshot AI는 Kimi K2.7 Code를 지금까지 만든 가장 강력한 코딩 모델이라고 설명합니다. K2.6을 추가 학습한 모델로, 긴 컨텍스트에서 지시를 더 안정적으로 따르고, 더 많은 코딩 작업을 완료하며, 사고 토큰은 K2.6보다 약 30% 적게 사용합니다.

아키텍처는 K2.6과 같습니다. 총 1T, 활성 32B 파라미터의 MoE로, 토큰당 384개 전문가 중 8개를 사용하고, 컨텍스트 길이는 256K이며, 텍스트와 이미지 입력을 지원합니다. K2.7 Code는 항상 사고 모드로 동작하며 다단계 도구 호출과 함께 인터리브드 사고를 지원하므로 코딩 에이전트에 적합합니다.

AnyAIGC에서 kimi-k2.7-code는 OpenAI 호환 /v1/chat/completions 엔드포인트로 동작하며 Claude Code에서 바로 사용할 수 있고, 동시 실행 제한이 없습니다.

빠른 시작

세 단계로 Kimi K2.7 Code API 연동하기

  1. 가입 및 충전: anyaigc.ai에서 계정을 만듭니다. $1부터 충전할 수 있으며, 잔액은 플랫폼의 모든 모델에서 공통으로 사용됩니다.
  2. API 키 만들기: 콘솔에서 키를 만들고 sk-로 시작하는 값을 복사해 ANYAIGC_API_KEY 환경 변수에 저장하세요.
  3. 요청 보내기: model을 kimi-k2.7-code로 설정하고 Authorization: Bearer 헤더를 포함해 POST https://anyaigc.ai/v1/chat/completions를 호출하세요. OpenAI SDK에서는 base_url을 https://anyaigc.ai/v1로 설정하기만 하면 됩니다.

팁: K2.7 Code는 항상 사고 모드로 동작하며, 추론 내용은 reasoning_content로 반환됩니다. Moonshot은 temperature=1.0과 top_p=0.95를 권장합니다. 멀티턴 대화와 도구 호출에서는 API가 반환한 어시스턴트 메시지 전체(reasoning_content와 tool_calls 포함)를 다음 요청에 그대로 다시 보내세요.

모든 파라미터는 Chat Completions 레퍼런스를 참고하세요. 문서 예제의 모델 이름을 사용할 Kimi 모델 ID로 바꾸세요.

Claude Code

Claude Code에서 Kimi K2.7 Code 사용하기

Claude Code를 Kimi K2.7 Code로 전환하세요. 코딩용으로 학습된 모델이며 가격은 K3.1 Pro의 약 절반입니다.

  1. Claude Code 설치: 공식 설치 프로그램을 사용하세요(예: npm install -g @anthropic-ai/claude-code).
  2. 설정 추가: ~/.claude/settings.json을 열어 아래 env 블록을 추가하고, ANTHROPIC_AUTH_TOKEN 값을 AnyAIGC에서 만든 키로 바꿉니다.
  3. 코딩 시작: 프로젝트 폴더에서 claude를 실행하세요. /model을 입력해 현재 모델이 kimi-k2.7-code인지 확인하세요.

대형 저장소: K2.7 Code의 컨텍스트 길이는 256K입니다. 프로젝트가 너무 커서 한 번에 읽을 수 없으면 설정에서 모델을 kimi-k3.1-pro(1M 컨텍스트)로 바꾸세요.

전체 절차와 자주 발생하는 오류는 Claude Code 설정 가이드를 참고하세요. 가이드에 나온 모델 이름을 kimi-k2.7-code로 바꿔서 사용하세요.

Kimi K2.7 Code API FAQ

Kimi K2.7 Code API 요금은 얼마입니까?

AnyAIGC에서 kimi-k2.7-code는 토큰 단위로 과금됩니다. 입력 100만 토큰당 $0.3847, 출력 100만 토큰당 $1.5980, 캐시 히트 100만 토큰당 $0.0770입니다. Moonshot의 공식 USD 정가는 입력 $0.95, 출력 $4.00, 캐시 히트 $0.19이므로 AnyAIGC는 공식 정가의 약 40%입니다. 출력에는 사고 토큰이 포함됩니다. 실시간 가격은 모델 카탈로그에서 확인하세요.

Kimi K2.7 Code의 모델 ID와 컨텍스트 길이는 어떻게 됩니까?

모델 ID는 kimi-k2.7-code입니다. Moonshot은 262,144 토큰(256K) 컨텍스트 길이를 제공하며 텍스트와 이미지 입력을 지원한다고 밝혔습니다.

Kimi K2.7 Code는 K2.6과 어떻게 다릅니까?

K2.7 Code는 K2.6을 코딩 중심으로 추가 학습한 모델이며, 아키텍처는 같습니다(전체 1T, 활성 32B 파라미터). Moonshot에 따르면 긴 컨텍스트에서 지시를 더 안정적으로 따르고, 더 많은 코딩 작업을 완료하며, 사고 토큰을 K2.6보다 약 30% 적게 사용합니다. Kimi Code Bench v2 점수는 50.9에서 62.0으로 올랐습니다. K2.7 Code는 사고 모드로만 실행되지만, K2.6은 사고 모드를 끌 수 있습니다. AnyAIGC에서 두 모델의 입력 및 출력 가격은 같습니다.

Kimi K2.7 Code에서 사고 모드를 끌 수 있습니까?

아니요. Moonshot에 따르면 K2.7 Code는 항상 사고 모드와 preserve thinking이 켜진 상태로 실행되며 비사고 모드를 지원하지 않습니다. 빠른 비사고 응답이 필요하면 kimi-k2.6을 사용하세요. Moonshot은 temperature=1.0과 top_p=0.95를 권장합니다.

Kimi K2.7 Code는 도구 호출을 지원합니까?

네. K2.7 Code는 인터리브드 사고와 다단계 도구 호출을 지원하므로 코딩 에이전트에 적합합니다. 멀티턴 대화와 도구 호출에서는 어시스턴트 메시지 전체(reasoning_content와 tool_calls 포함)를 다음 요청에 그대로 다시 보내세요.

Claude Code에서 Kimi K2.7 Code를 사용할 수 있습니까?

네. ~/.claude/settings.json의 env 블록에서 ANTHROPIC_BASE_URL을 https://anyaigc.ai로, ANTHROPIC_AUTH_TOKEN을 API 키로, ANTHROPIC_MODEL을 kimi-k2.7-code로 설정한 다음 claude를 실행하세요.

Kimi K2.7 Code와 Kimi K3.1 Pro 중 어느 쪽을 써야 합니까?

K2.7 Code는 256K 컨텍스트를 갖춘 1T 파라미터 코딩 모델로, AnyAIGC에서 입력 $0.3847, 출력 $1.5980이며 일상적인 코딩과 대량 에이전트 호출에 적합합니다. Kimi K3.1 Pro는 1M 컨텍스트를 지원하는 최신 3T급 모델로, 입력 $0.8100, 출력 $4.0500이며 대형 저장소와 가장 어려운 작업에 적합합니다. 두 모델 모두 같은 키를 사용합니다.

동시 실행 수나 속도 제한이 있습니까?

AnyAIGC는 kimi-k2.7-code의 동시 실행을 제한하지 않으며, 모든 사용자에게 기본으로 적용됩니다. 배치 작업, CI 파이프라인, 병렬 에이전트에 적합합니다. Moonshot 자체 플랫폼은 충전 등급에 따라 동시 실행, RPM, TPM, TPD를 제한하지만, AnyAIGC를 통해 호출할 때는 이 등급이 적용되지 않습니다.

Kimi K2.7 Code API 키는 어떻게 받습니까?

anyaigc.ai에 가입하고 잔액을 충전한 뒤 콘솔에서 키를 만드세요. 같은 키로 모든 Kimi 모델과 플랫폼의 다른 300개 이상의 모델을 호출할 수 있으므로 별도의 Moonshot 플랫폼 계정이 필요 없습니다.

AnyAIGC에서 인보이스를 받을 수 있습니까?

네. 콘솔에서 실제 충전한 금액 기준으로 직접 인보이스를 발급할 수 있습니다.

어떤 결제 수단을 지원합니까?

WeChat Pay, Alipay, USDT, 신용카드로 충전할 수 있습니다. 잔액은 USD 기준이며 플랫폼의 모든 모델에서 사용할 수 있습니다. 인보이스는 콘솔에서 충전한 금액 기준으로 발급할 수 있습니다.

신규 사용자에게 무료 체험 크레딧이 있습니까?

네. 신규 계정에는 토큰 200만 개 분량의 체험 크레딧이 제공되므로 충전 여부를 결정하기 전에 먼저 테스트할 수 있습니다. 충전은 $1부터 가능합니다.

잔액을 환불받을 수 있습니까?

네. 사용하지 않은 잔액은 수수료 없이 환불받을 수 있습니다. 환불은 고객 지원에 문의해 진행하세요.

실제 모델이 맞습니까? 데이터는 안전합니까?

요청은 공식 모델 채널로 전달되며, 저가 모델이나 리버스 엔지니어링 방식의 대체 모델은 사용하지 않습니다. 법령에서 요구하는 경우를 제외하고 프롬프트와 출력을 영구 저장하거나 학습에 사용하지 않으며, 콘솔에서 모든 요청의 토큰 수와 비용을 확인할 수 있습니다.

내 데이터가 학습에 사용됩니까?

아니요. 법령에서 요구하는 경우를 제외하고 AnyAIGC는 프롬프트와 출력을 영구 저장하지 않으며 모델 학습에도 사용하지 않습니다. 요청은 HTTPS로 암호화됩니다. AnyAIGC 개인정보 처리방침을 참고하세요. 모델 자체의 데이터 정책은 Moonshot AI의 공식 약관을 따릅니다.
