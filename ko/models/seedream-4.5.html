Seedream 4.5란

Seedream 4.5는 ByteDance Seed 팀의 이미지 생성 모델입니다. 텍스트, 이미지 한 장 또는 여러 장을 입력으로 받아, 피사체 일관성을 유지하는 다중 이미지 합성, 이미지 편집, 이미지 세트를 하나의 모델로 처리합니다.

Seedream 4.5는 ByteDance Seed 팀의 이미지 생성 모델이며, AnyAIGC에서 모델 ID는 doubao-seedream-4-5-251128입니다. 텍스트, 이미지 한 장 또는 여러 장을 입력으로 받아, 피사체 일관성을 유지하는 다중 이미지 합성, 이미지 편집, 이미지 세트를 처리합니다. 공식 설명에 따르면 원본 이미지의 얼굴, 조명, 디테일을 유지하고, 포스터와 로고 배치가 더 안정적이며, 작은 글자도 읽기 쉽게 표현합니다.

지원하는 해상도는 무엇입니까?

Volcano Engine Ark 문서에 따르면 4.5는 size 값으로 2K와 4K 또는 픽셀 크기를 받으며, 가로세로 비율은 1:16에서 16:1까지 지원합니다.

참조 이미지는 몇 장까지 보낼 수 있습니까? 이미지 세트는 최대 몇 장입니까?

image는 참조 이미지를 최대 14장까지 받습니다. 이미지 세트는 sequential_image_generation: "auto"를 사용하며 요청당 최대 15장을 반환합니다. 참조 이미지가 있으면 참조 이미지와 생성 이미지의 합계가 15장을 넘을 수 없습니다.

4.5와 5.0 lite 중 무엇을 선택해야 합니까?

둘 다 4K, 이미지 세트, 참조 이미지 14장을 지원합니다. 웹 검색이나 더 강한 의도 이해가 필요하면 5.0 lite($0.0223 / 이미지부터)를 선택하세요. 이미 4.5를 연동했고 포스터 레이아웃과 원본 디테일 보존이 가장 중요하다면 4.5를 계속 사용하세요.

동시 실행 제한이 있습니까? 가입에 무엇이 필요합니까?

AnyAIGC는 Seedream 4.5에 동시 실행 제한을 두지 않으며, 모든 계정에 기본으로 적용됩니다. 기본 URL은 https://anyaigc.ai입니다. Volcano Engine 계정이나 본인 인증은 필요 없으며, 같은 키로 플랫폼의 300개 이상 다른 모델도 사용할 수 있습니다.

AnyAIGC에서 인보이스를 받을 수 있습니까?

네. 콘솔에서 실제 충전한 금액 기준으로 직접 인보이스를 발급할 수 있습니다.

어떤 결제 수단을 지원합니까?

WeChat Pay, Alipay, USDT, 신용카드로 충전할 수 있습니다. 잔액은 USD 기준이며 플랫폼의 모든 모델에서 사용할 수 있습니다. 인보이스는 콘솔에서 충전한 금액 기준으로 발급할 수 있습니다.

신규 사용자에게 무료 체험 크레딧이 있습니까?

네. 신규 계정에는 토큰 200만 개 분량의 체험 크레딧이 제공되므로 충전 여부를 결정하기 전에 먼저 테스트할 수 있습니다. 충전은 $1부터 가능합니다.

잔액을 환불받을 수 있습니까?

네. 사용하지 않은 잔액은 수수료 없이 환불받을 수 있습니다. 환불은 고객 지원에 문의해 진행하세요.

실제 모델이 맞습니까? 데이터는 안전합니까?

요청은 공식 모델 채널로 전달되며, 저가 모델이나 리버스 엔지니어링 방식의 대체 모델은 사용하지 않습니다. 법령에서 요구하는 경우를 제외하고 프롬프트와 출력을 영구 저장하거나 학습에 사용하지 않으며, 콘솔에서 모든 요청의 토큰 수와 비용을 확인할 수 있습니다.

상업적으로 사용할 수 있습니까? 워터마크를 제거할 수 있습니까?

사용 권한과 콘텐츠 정책은 ByteDance / Volcano Engine 공식 약관을 따릅니다. 요청에서 watermark를 false로 설정하면 오른쪽 아래에 "AI 생성" 표시가 추가되지 않습니다. AnyAIGC는 API 접근만 제공하며 결과물 사용에 추가 제한을 두지 않습니다. 실존 인물 초상, 브랜드 로고 등은 필요한 권리를 갖고 있는지 확인하세요.
