소개

같은 베이스 모델, 훨씬 강화된 사후 학습

Zhipu는 GLM-5.3을 최신 플래그십이라고 부르며, 복잡한 소프트웨어 엔지니어링과 에이전트 작업 전반에서 성능이 향상되었다고 설명합니다. Zhipu에 따르면 GLM-5.2와 같은 베이스 모델을 사용하며, 모든 개선은 GLM-5.2에서 도입한 강화 학습 방식을 바탕으로 사후 학습을 확장한 데서 나왔습니다.

보고된 향상은 코딩과 에이전트에 집중되어 있습니다. Zhipu 내부 Z.ai Code Bench는 같은 작업에서 더 적은 출력 토큰을 쓰면서 GLM-5.2보다 50% 높고, Terminal Bench 3.0은 4.6에서 28.3으로 올랐습니다. Zhipu는 CyberGym 취약점 벤치마크에서도 최고 수준의 결과를 보고했습니다. 1M 토큰 컨텍스트 길이와 최대 128K 출력을 지원하며, 사고 모드는 항상 켜져 있습니다.

AnyAIGC에서 glm-5.3은 OpenAI 호환 /v1/chat/completions 엔드포인트로 동작하며 Claude Code에서 바로 사용할 수 있습니다. Zhipu 플랫폼 계정이나 Coding Plan은 필요 없습니다. 토큰 단위로 과금하며 동시 실행 제한이 없습니다.

기능

GLM-5.3의 기능

  • 01

    터미널과 장시간 코딩

    Zhipu는 Terminal Bench 2.1에서 88.2, Terminal Bench 3.0에서 28.3(GLM-5.2: 4.6)을 보고했습니다. 터미널에서 진행되는 긴 엔지니어링 작업을 위한 지표입니다.

  • 02

    소프트웨어 엔지니어링

    Zhipu는 DeepSWE v1.1에서 66.9, FrontierSWE에서 78.1, NL2Repo에서 58을 보고했으며, 버그 수정부터 처음부터 저장소를 만드는 작업까지 다룹니다.

  • 03

    더 적은 토큰으로 코딩

    max effort로 실행한 Zhipu 내부 Z.ai Code Bench에서 GLM-5.3은 평균 약 75K 출력 토큰으로 34.5%를, GLM-5.2는 약 96K로 23.4%를 기록했습니다.

  • 04

    보안 연구

    Zhipu는 CyberGym 취약점 재현 벤치마크에서 84.5를 보고했으며, GLM-5.3이 오픈 소스 프로젝트 269개에서 취약점 2,436건을 발견했다고 밝혔습니다.

  • 05

    에이전트와 도구 호출

    Zhipu는 Toolathlon Verified 73, AutomationBench 48.2, Agents' Last Exam 28.5를 보고했으며, 함수 호출과 구조화된 출력을 지원합니다.

  • 06

    조절 가능한 사고 깊이

    사고 모드는 항상 켜져 있습니다. reasoning_effort를 low, high, max 중 하나로 설정하세요. 간단한 작업에서는 토큰을 아끼고, 어려운 문제에는 max를 사용하세요.

    Claude Code와 커스텀 에이전트

  • 03 · 보안

    코드 감사와 취약점 탐지

    모델에게 의존성과 애플리케이션 코드를 검토하고, 알려진 취약점을 재현하고, 패치를 작성하게 하세요. Zhipu는 CyberGym에서 최고 수준(SOTA) 결과를 달성했다고 밝혔습니다.

  • 04 · 자동화

    도구 호출과 워크플로 오케스트레이션

    함수 호출과 구조화된 출력을 결합해 사내 시스템, 스크립트, API를 자동화 워크플로로 연결하세요. 반복되는 시스템 프롬프트는 캐시 히트 요금으로 과금됩니다.

빠른 시작

세 단계로 GLM-5.3 API에 연결하기

  1. 가입 및 충전: anyaigc.ai에서 계정을 만듭니다. $1부터 충전할 수 있으며, 잔액은 플랫폼의 모든 모델에서 공통으로 사용됩니다.
  2. API 키 만들기: 콘솔에서 키를 만들고 sk-로 시작하는 값을 복사해 ANYAIGC_API_KEY 환경 변수에 저장하세요.
  3. 요청 보내기: POST https://anyaigc.ai/v1/chat/completions를 호출하고, model은 glm-5.3으로 지정하며 Authorization: Bearer 헤더를 함께 보내세요. OpenAI SDK를 쓰는 경우 base_url만 https://anyaigc.ai/v1로 설정하면 됩니다.

팁: GLM-5.3은 항상 사고 모드로 동작합니다. 추론 내용은 reasoning_content 필드로 반환되며, reasoning_effort로 깊이를 설정합니다. Zhipu의 기본값은 temperature=1.0과 top_p=0.95이며, 조정할 때는 둘 중 하나만 바꾸세요. 멀티턴 대화와 도구 호출에서는 API가 반환한 어시스턴트 메시지 전체(reasoning_content와 tool_calls 포함)를 다음 요청에 그대로 다시 보내세요.

모든 파라미터는 Chat Completions 레퍼런스를 참고하세요. 문서 예제의 모델 이름은 사용할 GLM 모델 ID로 바꾸세요.

Claude Code

Claude Code에서 GLM-5.3 사용하기

설정 파일 하나만 수정하면 Claude Code를 GLM-5.3으로 전환할 수 있습니다. Zhipu의 최신 플래그십 모델로 터미널에서 코딩하고, 토큰 단위로 과금됩니다.

  1. Claude Code 설치: 공식 설치 프로그램을 사용합니다. macOS 또는 Linux에서는 curl -fsSL https://claude.ai/install.sh | bash를 실행하면 됩니다.
  2. 설정 추가: ~/.claude/settings.json을 열어 아래 env 블록을 추가하고, ANTHROPIC_AUTH_TOKEN 값을 AnyAIGC에서 만든 키로 바꿉니다.
  3. 코딩 시작: 프로젝트 폴더에서 claude를 실행하세요. /model을 입력해 현재 모델이 glm-5.3인지 확인하세요.

가벼운 작업은 비용 절감: 설정에서 ANTHROPIC_DEFAULT_HAIKU_MODEL을 glm-5.3-flash로 지정했으므로, Claude Code의 경량 하위 작업은 더 저렴한 모델을 쓰고 주요 작업은 GLM-5.3에서 처리합니다.

전체 절차와 자주 발생하는 오류는 Claude Code 설정 가이드를 참고하세요. 가이드의 모델 이름을 glm-5.3으로 바꿔서 사용하세요.

사양

사양과 선택 기준

Z.ai 문서는 GLM-5.3을 최신 플래그십 모델이라고 설명합니다. GLM-5.2와 같은 베이스 모델을 사용하며, 모든 개선은 사후 학습(post-training)에서 이루어졌습니다.

벤더는 Z.ai Code Bench에서 GLM-5.2보다 50% 향상되었고, Terminal Bench 3.0을 포함한 공개 벤치마크에서 오픈 소스 모델 중 최고 수준(SOTA)의 성능을 달성했다고 밝힙니다.

현재는 텍스트 입력만 지원하며, 컨텍스트 길이는 1M 토큰, 최대 출력은 128K 토큰입니다. 추론은 항상 켜져 있고 추론 강도는 low, high, max(기본값 max)이며, 추론 끄기는 더 이상 지원하지 않습니다.

이 페이지에는 입력 $0.9450, 출력 $2.9700, 캐시 히트 $0.1758이 표시되며, 위의 가격표와 일치합니다.

glm-5.2와 비교하면, 공식 문서에 따르면 GLM-5.3은 추론을 끌 수 없습니다. 따라서 thinking.type을 disabled로 설정한 요청은 모델을 바꾸기 전에 enabled로 변경해야 하며, 그렇지 않으면 실패합니다.

사양은 벤더 공식 문서(docs.z.ai)를 따랐습니다. 이 페이지의 표는 가격이며, 실시간 요금은 모델 카탈로그가 기준입니다.

FAQ

GLM-5.3 API FAQ

GLM-5.3 API 가격은 얼마입니까?

AnyAIGC에서 glm-5.3은 토큰 단위로 과금됩니다. 입력 100만 토큰당 $0.9450, 출력 100만 토큰당 $2.9700, 캐시 히트 100만 토큰당 $0.1758입니다. Zhipu의 공식 USD 정가는 입력 $1.40, 출력 $4.40, 캐시 히트 $0.26이므로, AnyAIGC의 입력과 출력 가격은 공식 정가의 약 67.5%(약 30% 할인)입니다. 출력에는 사고 토큰이 포함됩니다. 실시간 가격은 모델 카탈로그에서 확인하세요.

GLM-5.3 모델 ID는 무엇이며 컨텍스트 길이는 얼마입니까?

모델 ID는 glm-5.3입니다. Zhipu는 컨텍스트 길이 1M 토큰, 최대 출력 128K 토큰을 명시합니다. 현재는 텍스트 입력만 지원합니다.

GLM-5.3은 GLM-5.2와 무엇이 다릅니까?

Zhipu에 따르면 GLM-5.3은 GLM-5.2와 같은 베이스 모델을 사용하며, 모든 향상은 확대된 사후 학습(post-training)에서 나왔습니다. 보고된 변화는 다음과 같습니다. Z.ai Code Bench는 GLM-5.2보다 50% 높고, Terminal Bench 3.0은 4.6에서 28.3으로, DeepSWE는 46.2에서 66.9로 올랐습니다. 또한 GLM-5.3은 항상 사고 모드로 동작하며 끌 수 없습니다. AnyAIGC에서는 두 모델의 입력과 출력 가격이 같고, GLM-5.3의 캐시 히트 가격이 더 낮습니다($0.1758 vs $0.2362).

GLM-5.3의 사고 깊이는 어떻게 조절합니까? 사고 모드를 끌 수 있습니까?

GLM-5.3은 항상 사고 모드로 동작하며, Zhipu는 이를 끄는 기능을 지원하지 않습니다. 깊이는 요청 본문의 reasoning_effort 필드로 설정하며, 값은 low, high, max입니다(기본값은 max이며 Zhipu는 코딩에 이 값을 권장합니다). 간단한 작업에서는 low를 사용해 출력 토큰을 줄이세요.

GLM-5.3은 도구 호출과 구조화된 출력을 지원합니까?

네. Zhipu 문서에는 함수 호출, 구조화된 출력(JSON), 스트리밍, 컨텍스트 캐싱이 명시되어 있습니다. 멀티턴 대화와 도구 호출에서는 어시스턴트 메시지 전체(reasoning_content와 tool_calls 포함)를 다음 요청에 그대로 다시 보내세요.

Claude Code에서 GLM-5.3을 사용할 수 있습니까?

네. ~/.claude/settings.json의 env 블록에서 ANTHROPIC_BASE_URL을 https://anyaigc.ai로, ANTHROPIC_AUTH_TOKEN을 API 키로, ANTHROPIC_MODEL을 glm-5.3으로 설정한 뒤 claude를 실행하세요. 토큰 단위로 결제하므로 구독 플랜처럼 5시간 단위의 사용 한도 구간이 없습니다.

GLM-5.3은 오픈 소스입니까?

네. Zhipu는 GLM-5.3 가중치를 GLM-5.3 License에 따라 Hugging Face(zai-org/GLM-5.3)에 공개했습니다. 전반적으로 허용적인 라이선스이지만 한 가지 추가 규칙이 있습니다. 연 매출이 100억 달러($10 billion)를 넘고 model-as-a-service 사업을 운영하는 기업은 상업적으로 사용하기 전에 Z.ai 보안 심사를 통과해야 합니다. AnyAIGC를 통해 API를 호출하면 직접 호스팅할 필요가 없습니다. 상업적 사용은 Zhipu AI의 공식 약관을 따릅니다.

동시 실행 수나 속도 제한이 있습니까?

AnyAIGC는 glm-5.3의 동시 실행에 상한을 두지 않으며, 모든 사용자에게 기본으로 적용됩니다. 배치 작업, CI 파이프라인, 병렬 에이전트에 적합합니다. 토큰 단위로 과금하므로 구독 플랜처럼 시간 구간마다 초기화되는 한도가 없습니다.

GLM-5.3 API 키는 어떻게 받습니까?

anyaigc.ai에서 가입하고 크레딧을 충전한 뒤 콘솔에서 키를 만드세요. 같은 키로 모든 GLM 모델과 플랫폼의 300개 이상의 다른 모델을 사용할 수 있으므로, 별도의 Zhipu 플랫폼 계정이나 GLM Coding Plan이 필요 없습니다.

AnyAIGC에서 인보이스를 받을 수 있습니까?

네. 콘솔에서 실제 충전한 금액 기준으로 직접 인보이스를 발급할 수 있습니다.

어떤 결제 수단을 지원합니까?

WeChat Pay, Alipay, USDT, 신용카드로 충전할 수 있습니다. 잔액은 USD 기준이며 플랫폼의 모든 모델에서 사용할 수 있습니다. 인보이스는 콘솔에서 충전한 금액 기준으로 발급할 수 있습니다.

신규 사용자에게 무료 체험 크레딧이 있습니까?

네. 신규 계정에는 토큰 500만 개 분량의 체험 크레딧이 제공되므로 충전 여부를 결정하기 전에 먼저 테스트할 수 있습니다. 충전은 $1부터 가능합니다.

잔액을 환불받을 수 있습니까?

네. 사용하지 않은 잔액은 수수료 없이 환불받을 수 있습니다. 환불은 고객 지원에 문의해 진행하세요.

실제 모델이 맞습니까? 데이터는 안전합니까?

요청은 공식 모델 채널로 전달되며, 저가 모델이나 리버스 엔지니어링 방식의 대체 모델은 사용하지 않습니다. 법령에서 요구하는 경우를 제외하고 프롬프트와 출력을 영구 저장하거나 학습에 사용하지 않으며, 콘솔에서 모든 요청의 토큰 수와 비용을 확인할 수 있습니다.

내 데이터가 학습에 사용됩니까?

아니요. 법령에서 요구하는 경우를 제외하고 AnyAIGC는 프롬프트와 출력을 영구적으로 저장하지 않으며 모델 학습에 사용하지 않습니다. 요청은 HTTPS로 암호화됩니다. AnyAIGC 개인정보 처리방침을 확인하세요. 모델 자체의 데이터 정책은 Zhipu AI의 공식 약관을 따릅니다.
