Grok Imagine Image란

Grok Imagine Image(grok-imagine-image)는 xAI가 2026년 초 Grok Imagine API와 함께 출시한 이미지 모델입니다. xAI 문서에서는 1.0이라 부르며 스냅샷 이름은 grok-imagine-image-2026-03-02입니다. 텍스트 설명을 이미지로 바꾸며, 여러 종횡비와 1k / 2k 출력을 지원합니다.

2026년 8월 xAI는 타이포그래피와 편집이 더 강한 Image 2.0을 출시했으며, AnyAIGC에서는 가격이 조금 더 높습니다(이미지당 $0.0179부터, 1세대는 $0.0119). 1세대 모델은 종료되지 않았으므로 기존 연동은 계속 작동합니다.

AnyAIGC에서는 이미지당 $0.0119이며, xAI 공식 정가는 이미지당 $0.02입니다. AnyAIGC에서 이 모델은 /v1/images/generations 엔드포인트를 사용합니다.

Grok Imagine Image로 할 수 있는 것

  • 01

    텍스트→이미지

    한 문장으로 이미지를 생성합니다. 실사, 일러스트, 포스터 등 일반적인 스타일을 지원합니다.

  • 02

    다양한 종횡비

    aspect_ratio로 1:1, 16:9, 9:16, 3:2 등을 지정해 커버, 세로 포스터, 배너에 맞출 수 있습니다.

  • 03

    1k / 2k 출력

    resolution으로 1k 또는 2k를 선택하세요. xAI는 두 해상도에 같은 가격을 적용합니다.

  • 04

    base64 또는 URL

    response_format을 b64_json으로 설정하면 원본 이미지 데이터를, url로 설정하면 임시 링크를 받습니다.

  • 05

    호환 인터페이스

    요청 형식이 OpenAI의 /v1/images/generations와 같으므로, 기존 이미지 코드는 새 model만 지정하면 됩니다.

  • 06

    2.0으로 간편하게 업그레이드

    편집이나 더 나은 타이포그래피가 필요하면 model을 grok-imagine-image-2.0으로 바꾸세요. 이미지당 $0.0179부터입니다.

Grok Imagine Image API 시작하기

  1. AnyAIGC에 가입하세요. 신규 계정에는 무료 토큰 500만 개가 제공되며, $1부터 충전할 수 있습니다.

Grok Imagine Image API FAQ

Grok Imagine Image API 요금은 얼마입니까?

AnyAIGC에서 Grok Imagine Image(grok-imagine-image)는 1k와 2k 모두 이미지당 $0.0119입니다. xAI 공식 정가는 이미지당 $0.02입니다. 생성에 성공한 건에 대해서만 과금하며, 실시간 가격은 모델 카탈로그에서 확인하세요.

Image 2.0, Image, Quality 중 어떤 모델을 써야 합니까?

Grok Imagine Image 2.0(grok-imagine-image-2.0)은 xAI가 현재 권장하는 모델로, 타이포그래피, 프롬프트 준수, 편집이 더 강화되었습니다. AnyAIGC에서 이미지당 $0.0179부터 시작하므로 새 프로젝트는 이 모델로 시작하세요. Grok Imagine Image(grok-imagine-image)는 1세대 Imagine 모델로 이미지당 $0.0119이며 시리즈 최저 가격입니다. 단순한 텍스트→이미지와 기존 코드에는 충분합니다. Grok Imagine Image Quality는 xAI가 2026년 11월 2일에 종료했으며, 이 모델로 보낸 요청은 이제 low 품질의 2.0이 처리합니다.

grok-imagine-image는 종료됩니까?

이번 변경은 이 모델에 영향을 주지 않습니다. xAI가 2026년 11월 2일에 종료한 모델은 grok-imagine-image-quality이며, grok-imagine-image는 계속 사용할 수 있습니다. 편집이나 더 나은 텍스트 렌더링이 필요하면 grok-imagine-image-2.0(이미지당 $0.0179부터)을 고려하세요.

지원하는 종횡비와 해상도는 무엇입니까?

aspect_ratio는 1:1, 16:9, 9:16, 3:2, 2:3, 4:3, 3:4 등으로, resolution은 1k 또는 2k로 설정하세요. quality 파라미터는 Image 2.0에서만 지원됩니다.

이미지를 편집할 수 있습니까?

AnyAIGC에서 grok-imagine-image는 생성 엔드포인트 /v1/images/generations를 사용합니다. 이미지를 업로드해 수정하려면 grok-imagine-image-2.0으로 /v1/images/edits를 호출하세요.

xAI 계정이 필요합니까?

필요하지 않습니다. AnyAIGC에 가입해 API 키를 받으세요. 엔드포인트는 https://anyaigc.ai이며, 같은 키로 플랫폼의 300개 이상의 다른 모델도 사용할 수 있습니다.

동시 실행 제한이 있습니까?

AnyAIGC는 Grok Image 모델에 동시 실행 제한을 두지 않습니다. 모든 계정에 기본 적용되므로 배치 작업에 할당량 신청이 필요 없습니다.

AnyAIGC에서 인보이스를 받을 수 있습니까?

네. 콘솔에서 실제 충전한 금액 기준으로 직접 인보이스를 발급할 수 있습니다.

어떤 결제 수단을 지원합니까?

WeChat Pay, Alipay, USDT, 신용카드로 충전할 수 있습니다. 잔액은 USD 기준이며 플랫폼의 모든 모델에서 사용할 수 있습니다. 인보이스는 콘솔에서 충전한 금액 기준으로 발급할 수 있습니다.

신규 사용자에게 무료 체험 크레딧이 있습니까?

네. 신규 계정에는 토큰 500만 개 분량의 체험 크레딧이 제공되므로 충전 여부를 결정하기 전에 먼저 테스트할 수 있습니다. 충전은 $1부터 가능합니다.

네. 사용하지 않은 잔액은 수수료 없이 환불받을 수 있습니다. 환불은 고객 지원에 문의해 진행하세요.

실제 모델이 맞습니까? 데이터는 안전합니까?
