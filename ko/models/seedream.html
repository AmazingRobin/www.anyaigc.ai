model을 doubao-seedream-5-5-261028, doubao-seedream-5-0-pro-260628, doubao-seedream-5-0-260128, doubao-seedream-4-5-251128 또는 doubao-seedream-4-0-250828로 바꾸면 모델이 전환됩니다. 요청과 응답 형식은 그대로입니다.

Seedream API 자주 묻는 질문

Seedream API 요금은 얼마입니까?

AnyAIGC의 모든 Seedream 모델은 고정 요금입니다. 5.5는 이미지당 $0.0229부터(2K는 이미지당 $0.0402, 입력 이미지는 별도 과금), 5.0 Pro는 이미지당 $0.0441부터, 5.0 lite는 이미지당 $0.0223부터, 4.5는 이미지당 $0.0253부터, 4.0은 이미지당 $0.0203부터, 3.0은 요청당 $0.0101입니다. 해상도가 높을수록 요금이 높아지며, 실시간 요금은 모델 카탈로그에서 확인하세요.

Seedream이란 무엇입니까? Doubao, Jimeng과는 어떤 관계입니까?

Seedream은 ByteDance Seed 팀의 이미지 생성 모델 제품군입니다. Volcano Engine에서는 "Doubao Seedream"(doubao-seedream)으로 제공되며, Jimeng 같은 ByteDance 제품의 이미지 생성도 이 모델을 기반으로 합니다. AnyAIGC는 공식 Seedream 모델에 대한 API 접근을 제공합니다.

5.5, 5.0 Pro, 5.0 lite, 4.5, 4.0의 차이는 무엇입니까?

5.5는 최신 모델로, 일관된 멀티턴 편집, 네이티브 RGBA 투명도, 최대 99개 레이어의 레이어 분리에 가장 강합니다. 요청당 이미지 1장을 반환하며 이미지 세트는 지원하지 않습니다. 5.0 Pro는 플래그십으로 인포그래픽, 정밀 편집, 다국어 텍스트에 강하고 최대 2K를 지원하며 이미지 세트는 지원하지 않습니다. 5.0 lite는 웹 검색을 지원하는 경량 모델로 최대 4K를 지원합니다. 4.5는 포스터 레이아웃과 원본 디테일 유지에 뛰어납니다. 4.0은 생성과 편집을 하나로 합친 버전이었습니다. 5.0 lite, 4.5, 4.0은 모두 이미지 세트와 최대 14장의 참조 이미지를 지원합니다.

어떤 엔드포인트를 사용합니까? 이미지를 편집할 수 있습니까?

모든 모델이 OpenAI 호환 POST /v1/images/generations를 사용하며, 모델을 바꿀 때는 model만 바꾸면 됩니다. 편집과 다중 이미지 합성은 image에 이미지 URL 배열을 전달하세요. 이미지 세트는 sequential_image_generation: "auto"를 사용하세요. 모든 필드는 AnyAIGC API 문서를 참고하세요.

동시 실행 제한이 있습니까? 가입에 무엇이 필요합니까?

AnyAIGC는 모든 Seedream 모델에 동시 실행 제한을 두지 않으며, 모든 계정에 기본으로 적용됩니다. 기본 URL은 https://anyaigc.ai입니다. Volcano Engine 계정이나 본인 인증은 필요 없으며, 같은 키로 플랫폼의 300개 이상의 다른 모델도 사용할 수 있습니다.

AnyAIGC에서 인보이스를 받을 수 있습니까?

네. 콘솔에서 실제 충전한 금액 기준으로 직접 인보이스를 발급할 수 있습니다.

어떤 결제 수단을 지원합니까?

WeChat Pay, Alipay, USDT, 신용카드로 충전할 수 있습니다. 잔액은 USD 기준이며 플랫폼의 모든 모델에서 사용할 수 있습니다. 인보이스는 콘솔에서 충전한 금액 기준으로 발급할 수 있습니다.

신규 사용자에게 무료 체험 크레딧이 있습니까?

네. 신규 계정에는 토큰 500만 개 분량의 체험 크레딧이 제공되므로 충전 여부를 결정하기 전에 먼저 테스트할 수 있습니다. 충전은 $1부터 가능합니다.

잔액을 환불받을 수 있습니까?

네. 사용하지 않은 잔액은 수수료 없이 환불받을 수 있습니다. 환불은 고객 지원에 문의해 진행하세요.

실제 모델이 맞습니까? 데이터는 안전합니까?

요청은 공식 모델 채널로 전달되며, 저가 모델이나 리버스 엔지니어링 방식의 대체 모델은 사용하지 않습니다. 법령에서 요구하는 경우를 제외하고 프롬프트와 출력을 영구 저장하거나 학습에 사용하지 않으며, 콘솔에서 모든 요청의 토큰 수와 비용을 확인할 수 있습니다.

상업적으로 사용할 수 있습니까? 워터마크를 제거할 수 있습니까?

사용 권한과 콘텐츠 정책은 ByteDance / Volcano Engine 공식 약관을 따릅니다. 요청에서 watermark를 false로 설정하면 오른쪽 아래에 "AI 생성" 표시가 추가되지 않습니다. AnyAIGC는 API 접근만 제공하며 결과물 사용에 추가 제한을 두지 않습니다. 실존 인물 초상, 브랜드 로고 등은 필요한 권리를 갖고 있는지 확인하세요.
