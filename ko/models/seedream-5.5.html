Seedream 5.5란

Seedream 5.5는 ByteDance Seed 팀의 멀티모달 이미지 생성 모델로, 창의성과 정밀한 실행을 함께 높였다고 공식 설명합니다. 텍스트→이미지, 단일 이미지 생성, 다중 참조 생성을 지원하며, 여러 턴에 걸친 편집 일관성, 네이티브 RGBA 이미지 생성, 레이어 분리를 강화했습니다.

AnyAIGC에서 모델 ID는 doubao-seedream-5-5-261028이며, OpenAI 호환 /v1/images/generations로 제공되고 출력 해상도 구간별로 과금됩니다. 1K / 1.5K는 이미지당 $0.0229부터이며 입력 이미지는 별도로 과금됩니다. Volcano Engine 계정이나 본인 인증은 필요 없습니다.

Seedream 5.5로 할 수 있는 일

이 네 가지 기능은 ByteDance Seed 공식 모델 페이지와 Volcano Engine Ark 문서를 근거로 합니다.

  • 여러 턴에 걸친 일관된 편집

    한 이미지를 여러 차례 수정해도 요청한 부분만 바뀝니다. 공식 페이지에 따르면 편집 영역 밖의 픽셀은 그대로 유지될 수 있습니다.

  • 네이티브 RGBA 투명도

    투명 배경과 반투명 배경을 기본 지원하므로, 텍스트나 참조 이미지로 수동 배경 제거 없이 RGBA 이미지를 만들 수 있습니다.

  • 레이어 분리

    이미지 하나를 기본 이미지 1장과 최대 99개 레이어로 분리한 뒤 교체, 이동, 재배치할 수 있습니다. 기본 이미지와 각 레이어는 이미지당 과금됩니다.

  • 일반 텍스트용 리치 텍스트 OCR

    일반 텍스트 레이어는 텍스트, 위치, 대략적인 시각 스타일을 반환합니다. 장식용 글자와 손글씨는 아무것도 반환하지 않습니다.

Seedream 5.5는 ByteDance Seed 팀의 멀티모달 이미지 생성 모델로, 창의성과 정밀한 실행을 함께 높였다고 공식 설명합니다. 텍스트→이미지, 단일 이미지 생성, 다중 참조 생성을 지원하며, 여러 턴에 걸친 편집 일관성, 네이티브 RGBA 이미지 생성, 레이어 분리를 강화했습니다.

어떤 해상도를 지원합니까? 4K로 출력할 수 있습니까?

4K는 지원하지 않습니다. Volcano Engine Ark 문서에 따르면 5.5는 이미지 생성에서 size 값으로 1K, 1.5K, 2K(기본값 2K) 또는 가로 x 세로 픽셀 크기를 받으며, 총 픽셀 수는 921,600(1280x720)~4,624,220, 가로세로 비율은 1:16~16:1입니다. 4K가 필요하면 Seedream 5.0 lite 또는 4.5를 사용하세요.

참조 이미지는 몇 장까지 보낼 수 있습니까? 이미지 세트를 지원합니까?

image는 편집과 다중 이미지 합성에 참조 이미지를 최대 10장까지 받으며, 각각 입력 이미지로 과금됩니다. 5.5는 요청당 이미지 1장을 반환하며 이미지 세트, 웹 검색, 스트리밍을 지원하지 않습니다. 이미지 세트가 필요하면 5.0 lite, 4.5, 4.0을 사용하세요.

레이어 분리와 RGBA 출력으로 무엇을 할 수 있습니까?

레이어 분리는 이미지 하나를 기본 이미지 1장과 최대 99개 레이어로 나누며, 일반 텍스트 레이어는 텍스트, 위치, 대략적인 시각 스타일을 반환할 수 있습니다(리치 텍스트 OCR). 장식용 글자와 손글씨는 아무것도 반환하지 않습니다. 5.5는 투명 배경과 반투명 배경도 기본 지원하므로 RGBA 이미지를 바로 출력할 수 있습니다. 이 기능들의 요청 필드는 공식 문서와 AnyAIGC API 문서를 따르며, 연동하기 전에 고객 지원에 문의해 확인하세요.

5.5와 5.0 Pro 중 무엇을 선택해야 합니까?

5.5는 시작 가격이 더 낮고(이미지당 $0.0229부터, 5.0 Pro는 $0.0441), 최대 99개 레이어를 분리하며 텍스트만으로 RGBA 이미지를 생성할 수 있습니다. 5.0 Pro는 최대 16개 레이어를 분리하며 텍스트만으로는 RGBA를 생성하지 않습니다. 둘 다 최대 2K, 참조 이미지 최대 10장이며 이미지 세트는 없습니다. 그 외 강점은 Seedream 5.0 Pro를 참고하세요.

동시 실행 제한이 있습니까? 가입에 무엇이 필요합니까?

AnyAIGC는 Seedream 5.5에 동시 실행 제한을 두지 않으며, 모든 계정에 기본으로 적용됩니다. 기본 URL은 https://anyaigc.ai입니다. Volcano Engine 계정이나 본인 인증은 필요 없으며, 같은 키로 플랫폼의 300개 이상의 다른 모델도 사용할 수 있습니다.

AnyAIGC에서 인보이스를 받을 수 있습니까?

네. 콘솔에서 실제 충전한 금액 기준으로 직접 인보이스를 발급할 수 있습니다.

어떤 결제 수단을 지원합니까?

WeChat Pay, Alipay, USDT, 신용카드로 충전할 수 있습니다. 잔액은 USD 기준이며 플랫폼의 모든 모델에서 사용할 수 있습니다. 인보이스는 콘솔에서 충전한 금액 기준으로 발급할 수 있습니다.

신규 사용자에게 무료 체험 크레딧이 있습니까?

네. 신규 계정에는 토큰 200만 개 분량의 체험 크레딧이 제공되므로 충전 여부를 결정하기 전에 먼저 테스트할 수 있습니다. 충전은 $1부터 가능합니다.

잔액을 환불받을 수 있습니까?

네. 사용하지 않은 잔액은 수수료 없이 환불받을 수 있습니다. 환불은 고객 지원에 문의해 진행하세요.

실제 모델이 맞습니까? 데이터는 안전합니까?

요청은 공식 모델 채널로 전달되며, 저가 모델이나 리버스 엔지니어링 방식의 대체 모델은 사용하지 않습니다. 법령에서 요구하는 경우를 제외하고 프롬프트와 출력을 영구 저장하거나 학습에 사용하지 않으며, 콘솔에서 모든 요청의 토큰 수와 비용을 확인할 수 있습니다.

상업적으로 사용할 수 있습니까? 워터마크를 제거할 수 있습니까?

사용 권한과 콘텐츠 정책은 ByteDance / Volcano Engine 공식 약관을 따릅니다. 요청에서 watermark를 false로 설정하면 오른쪽 아래에 "AI 생성" 표시가 추가되지 않습니다. AnyAIGC는 API 접근만 제공하며 결과물 사용에 추가 제한을 두지 않습니다. 실존 인물 초상, 브랜드 로고 등은 필요한 권리를 갖고 있는지 확인하세요.
