GLM API

Zhipu의 GLM-5.3, GLM-5.3-Flash, GLM-5.2를 API 키 하나로 사용하세요. GLM-5.3은 공식 정가 대비 약 30%, GLM-5.3-Flash는 약 60% 할인됩니다.

GLM으로 이 저장소를 읽고, 실패하는 테스트를 수정하고, 누락된 타입 정의를 추가하세요

사용 사례

팀이 GLM API로 만드는 것

  • 01 · 복잡한 코딩

    대규모 리팩터링과 터미널 작업

    GLM-5.3의 컨텍스트 길이 1M은 코드베이스 전체를 담을 수 있고, 터미널 도구를 사용하며 작업을 이어 갑니다. Zhipu는 Terminal Bench 2.1에서 88.2점을 보고했습니다.

  • 02 · 코딩 에이전트

    Claude Code, CI, 자동 수정

    GLM을 Claude Code나 직접 만든 에이전트 프레임워크에 연결해 테스트를 실행하고, 오류를 읽고, 코드를 수정하세요. AnyAIGC는 동시 실행을 제한하지 않으므로 여러 에이전트를 동시에 실행할 수 있습니다.

  • 03 · 디자인에서 코드로

    스크린샷에서 UI로

    GLM-5.3-Flash는 이미지를 읽습니다. 디자인 파일이나 페이지 스크린샷을 넘기면 HTML, CSS 또는 컴포넌트 코드를 돌려줍니다.

  • 04 · 배치 작업

    분류, 추출, 요약

    GLM-5.3-Flash는 입력 100만 토큰당 $0.0607로, 티켓 분류, 필드 추출, 긴 문서 요약 같은 대량 작업에 적합합니다.

빠른 시작

세 단계로 GLM API 연결하기

  1. 가입 및 충전: anyaigc.ai에서 계정을 만듭니다. $1부터 충전할 수 있으며, 잔액은 플랫폼의 모든 모델에서 공통으로 사용됩니다.
  2. API 키 만들기: 콘솔에서 키를 만들고 sk-로 시작하는 값을 복사해 ANYAIGC_API_KEY 환경 변수에 저장하세요.
  3. 요청 보내기: POST https://anyaigc.ai/v1/chat/completions를 호출하고, model은 glm-5.3으로 지정하며 Authorization: Bearer 헤더를 함께 보내세요. OpenAI SDK를 쓰는 경우 base_url만 https://anyaigc.ai/v1로 설정하면 됩니다.

팁: GLM은 추론 내용을 reasoning_content 필드로 반환합니다. 스트리밍할 때는 추론 델타가 먼저 도착하고 그다음에 최종 답변이 옵니다. 사고 깊이는 reasoning_effort(low / high / max, 기본값 max)로 설정하세요. 멀티턴 대화와 도구 호출에서는 API가 반환한 어시스턴트 메시지 전체(reasoning_content와 tool_calls 포함)를 다음 요청에 그대로 다시 보내세요.

모든 파라미터는 Chat Completions 레퍼런스를 참고하세요. 문서 예제의 모델 이름은 사용할 GLM 모델 ID로 바꾸세요.

Claude Code

Claude Code에서 GLM 사용하기

설정 파일 하나만 수정하면 Claude Code를 GLM으로 전환할 수 있습니다. 터미널의 코딩 에이전트가 GLM-5.3 기반으로 동작하며 토큰 단위로 과금됩니다.

  1. Claude Code 설치: 공식 설치 프로그램을 사용합니다. macOS 또는 Linux에서는 curl -fsSL https://claude.ai/install.sh | bash를 실행하면 됩니다.
  2. 설정 추가: ~/.claude/settings.json을 열어 아래 env 블록을 추가하고, ANTHROPIC_AUTH_TOKEN 값을 AnyAIGC에서 만든 키로 바꿉니다.
  3. 코딩 시작: 프로젝트 폴더에서 claude를 실행하세요. /model을 입력해 현재 모델이 glm-5.3인지 확인하세요.

가벼운 작업은 비용 절감: 설정에서 ANTHROPIC_DEFAULT_HAIKU_MODEL을 glm-5.3-flash로 지정했으므로, Claude Code의 경량 하위 작업은 더 저렴한 모델을 쓰고 주요 작업은 GLM-5.3에서 처리합니다.

전체 절차와 자주 발생하는 오류는 Claude Code 설정 가이드를 참고하세요. 가이드의 모델 이름을 glm-5.3으로 바꿔서 사용하세요.

FAQ

GLM API FAQ

GLM API 요금은 얼마입니까?

AnyAIGC의 GLM 모델은 토큰 단위로 과금됩니다. 100만 토큰당 glm-5.3 입력 $0.9450, 출력 $2.9700, 캐시 히트 $0.1758; glm-5.3-flash 입력 $0.0607, 출력 $0.2025, 캐시 히트 $0.0122; glm-5.2 입력 $0.9450, 출력 $2.9700, 캐시 히트 $0.2362입니다. GLM-5.3과 GLM-5.2는 Zhipu 공식 USD 정가보다 약 30% 저렴하고, GLM-5.3-Flash는 약 60% 저렴합니다. 실시간 가격은 모델 카탈로그를 확인하세요.

AnyAIGC에서 사용할 수 있는 GLM 모델과 모델 ID는 무엇입니까?

이 페이지에서 다루는 모델은 세 가지입니다. glm-5.3(Zhipu의 최신 플래그십, 복잡한 코딩과 에이전트용), glm-5.3-flash(최초의 네이티브 멀티모달 GLM-5 모델, 낮은 가격), glm-5.2(이전 플래그십, 장시간 작업용)입니다. 모델 ID를 요청 본문의 model 필드에 넣으세요. 모델을 바꿀 때는 이 필드 하나만 바꾸면 됩니다. GLM-5.1, GLM-5, GLM-4.5 같은 이전 모델도 플랫폼에서 사용할 수 있으니 모델 카탈로그를 확인하세요.

GLM-5.3, GLM-5.3-Flash, GLM-5.2 중 무엇을 써야 합니까?

가장 어려운 코딩, 터미널, 에이전트 작업에는 GLM-5.3을 선택하세요. 대량 처리, 비용에 민감한 작업, 이미지 작업에는 GLM-5.3-Flash를 선택하세요. 비용은 GLM-5.3의 약 1/15이며, Zhipu는 전반적으로 GLM-5.2보다 낫다고 밝혔습니다. 사고 모드를 꺼야 하거나 이미 프로덕션에서 사용 중이라면 GLM-5.2를 그대로 사용하세요. GLM-5.3과 GLM-5.2는 가격이 같으므로 새 프로젝트는 GLM-5.3으로 시작하세요.

GLM API는 OpenAI 호환입니까?

네. 세 모델 모두 POST https://anyaigc.ai/v1/chat/completions를 사용하며, 요청과 응답 형식은 OpenAI Chat Completions와 같습니다. 공식 OpenAI SDK에서는 base_url을 https://anyaigc.ai/v1로 설정하세요. 추론 내용이 있으면 reasoning_content 필드로 반환됩니다.

Claude Code에서 GLM을 사용할 수 있습니까?

네. ~/.claude/settings.json의 env 블록에서 ANTHROPIC_BASE_URL을 https://anyaigc.ai로, ANTHROPIC_AUTH_TOKEN을 API 키로, ANTHROPIC_MODEL을 glm-5.3으로 설정한 뒤 claude를 실행하세요. 토큰 단위로 결제하므로 구독 플랜처럼 5시간 단위의 사용 한도 구간이 없습니다.

컨텍스트 길이는 얼마입니까?

Zhipu에 따르면 GLM-5.3, GLM-5.3-Flash, GLM-5.2는 모두 1M 토큰 컨텍스트와 최대 128K 출력 토큰을 지원합니다. GLM-5.3과 GLM-5.2는 텍스트만 입력할 수 있고, GLM-5.3-Flash는 이미지도 입력할 수 있습니다.

GLM Coding Plan과 무엇이 다릅니까?

GLM Coding Plan은 Zhipu의 월 구독형 코딩 상품으로, 사용 한도가 5시간 및 주 단위 구간마다 초기화됩니다. AnyAIGC는 토큰 단위 종량제 API입니다. 사용한 만큼만 지불하고 $1부터 충전할 수 있으며, 시간 구간 제한이 없고 동시 실행도 제한이 없습니다. 같은 키로 300개 이상의 다른 모델도 호출할 수 있습니다.

GLM 모델은 오픈 소스입니까? 상업적으로 사용할 수 있습니까?

Zhipu는 GLM-5.3, GLM-5.3-Flash, GLM-5.2의 가중치를 Hugging Face에 공개했습니다. GLM-5.2와 GLM-5.3-Flash는 MIT 라이선스를, GLM-5.3은 GLM-5.3 License를 사용합니다. GLM-5.3 License는 허용 범위가 넓은 라이선스이지만, 매우 큰 MaaS 기업에는 추가 보안 검토 조항이 적용됩니다. AnyAIGC를 통해 API를 호출하면 직접 호스팅할 필요가 없습니다. 모델 라이선스와 상업적 사용은 Zhipu AI의 공식 약관을 따릅니다.

동시 실행 수나 속도 제한이 있습니까?

AnyAIGC는 GLM 모델의 동시 실행을 제한하지 않으며, 모든 사용자에게 기본으로 적용됩니다. 배치 작업, CI 파이프라인, 병렬 에이전트에 적합합니다. 과금은 토큰 단위이므로 구독 플랜처럼 시간 구간마다 초기화되는 한도가 없습니다.

GLM API 키는 어떻게 받습니까?

anyaigc.ai에서 가입하고 크레딧을 충전한 뒤 콘솔에서 키를 만드세요. 같은 키로 모든 GLM 모델과 플랫폼의 300개 이상의 다른 모델을 사용할 수 있으므로, 별도의 Zhipu 플랫폼 계정이나 GLM Coding Plan이 필요 없습니다.

AnyAIGC에서 인보이스를 받을 수 있습니까?

네. 콘솔에서 실제 충전한 금액 기준으로 직접 인보이스를 발급할 수 있습니다.

어떤 결제 수단을 지원합니까?

WeChat Pay, Alipay, USDT, 신용카드로 충전할 수 있습니다. 잔액은 USD 기준이며 플랫폼의 모든 모델에서 사용할 수 있습니다. 인보이스는 콘솔에서 충전한 금액 기준으로 발급할 수 있습니다.

신규 사용자에게 무료 체험 크레딧이 있습니까?

네. 신규 계정에는 토큰 200만 개 분량의 체험 크레딧이 제공되므로 충전 여부를 결정하기 전에 먼저 테스트할 수 있습니다. 충전은 $1부터 가능합니다.

잔액을 환불받을 수 있습니까?

네. 사용하지 않은 잔액은 수수료 없이 환불받을 수 있습니다. 환불은 고객 지원에 문의해 진행하세요.

실제 모델이 맞습니까? 데이터는 안전합니까?

요청은 공식 모델 채널로 전달되며, 저가 모델이나 리버스 엔지니어링 방식의 대체 모델은 사용하지 않습니다. 법령에서 요구하는 경우를 제외하고 프롬프트와 출력을 영구 저장하거나 학습에 사용하지 않으며, 콘솔에서 모든 요청의 토큰 수와 비용을 확인할 수 있습니다.

내 데이터가 학습에 사용됩니까?

아니요. 법령에서 요구하는 경우를 제외하고 AnyAIGC는 프롬프트와 출력을 영구적으로 저장하지 않으며 모델 학습에 사용하지 않습니다. 요청은 HTTPS로 암호화됩니다. AnyAIGC 개인정보 처리방침을 확인하세요. 모델 자체의 데이터 정책은 Zhipu AI의 공식 약관을 따릅니다.
