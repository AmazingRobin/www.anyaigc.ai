GPT-6.2 Astra가 적합한 작업

  • 01 · 전문 문서

    슬라이드, 스프레드시트, 문서

    OpenAI는 GPT-6.2 Astra가 만든 슬라이드, 스프레드시트, 문서가 AI 느낌이 덜하고, 템플릿과 분야별 관례를 더 잘 따르며, 더 직접적이고 구체적인 문장을 쓴다고 밝혔습니다. 컨설팅, 금융, 법률, 영업 업무에 유용합니다.

  • 02 · 소프트웨어와 프론트엔드

    더 깔끔한 코드, 더 나은 프론트엔드

    OpenAI는 이 모델이 더 깔끔한 코드를 작성하고, 기존 코드베이스에서 복잡한 변경을 구현하고 테스트하는 데 더 뛰어나며, 특히 웹사이트, 게임, 3D 디자인에서 보기에도 좋고 잘 작동하는 프론트엔드를 만든다고 밝혔습니다. Codex의 기본 모델로 설정하세요.

  • 03 · 리서치

    터미널에서의 과학 작업

    OpenAI는 GPT-6.2 Astra가 Terminal-Bench-Science 0.1에서 GPT-6 Astra보다 9%p 높으면서 비용은 3분의 1 미만이라고 밝혔으며, Vals Science Index에서도 최고 기록을 세웠습니다.

  • 04 · 컴퓨터 사용

    CAD, 시뮬레이션, 3D

    OpenAI는 이 모델의 컴퓨터 사용(computer use)이 더 정밀해져 CAD와 시뮬레이션 도구에서 개별 부품과 그 연결까지 다룰 수 있다고 밝혔습니다. 컴퓨터 사용과 기타 도구는 Responses API로 사용하세요. Astra는 요율이 높으므로 단순한 작업은 low나 medium 강도로 비용을 낮추세요.

3단계로 GPT-6.2 Astra API 호출하기

  1. 가입 후 충전: anyaigc.ai에서 계정을 만드세요. 잔액은 모든 모델에서 공통으로 사용할 수 있습니다.
  2. API 키 만들기: 콘솔에서 토큰을 만들고 sk- 키를 복사해 ANYAIGC_API_KEY 환경 변수에 저장하세요.
  3. 요청 보내기: model을 gpt-6.2-astra로 설정하고 Authorization: Bearer 인증으로 https://anyaigc.ai/v1/chat/completions 또는 https://anyaigc.ai/v1/responses를 호출하세요.

도구 호출에는 /v1/responses를 권장합니다. 일반 채팅과 스트리밍에는 /v1/chat/completions를, 함수 호출, 컴퓨터 조작, 웹 검색 등의 도구에는 /v1/responses를 사용하고 추론 강도는 reasoning.effort에 지정하세요. 이 페이지의 함수 호출 예시는 /v1/responses를 사용합니다.

모든 파라미터는 Chat Completions 레퍼런스와 Responses 레퍼런스를 참고하세요. 필드는 공식 OpenAI API와 같습니다.
