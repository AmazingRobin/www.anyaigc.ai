소개

사후 학습을 대폭 강화한 첫 K3.1 모델

Moonshot AI는 Kimi K3.1 Pro가 새 K3.1 시리즈의 첫 모델이며 지금까지 나온 3T급 오픈 웨이트 모델 중 가장 강력하다고 밝혔습니다. Moonshot은 이 모델을 Kimi K3를 사후 학습을 거친 버전으로 설명하며, 훨씬 많은 사후 학습 연산과 수백 개 다운스트림 도메인에 걸친 통합 강화 학습으로 만들었다고 합니다.

Moonshot은 네 가지 영역의 향상을 보고했습니다. 장시간 코딩(Unity, Unreal Engine, Godot 지원, 프런트엔드와 Three.js 작업에서 더 완성도 높은 레이아웃, 타이포그래피, 애니메이션), 3D 제작(파라메트릭 모델링용 Blender 및 CAD 스크립트), 금융 리서치(OfficeQA Pro v2 64.4), 그리고 낮아진 환각 비율입니다. 컨텍스트 길이는 1,048,576 토큰이며 사고 모드가 항상 켜져 있고, 텍스트, 이미지, 비디오 입력을 지원합니다.

AnyAIGC에서 kimi-k3.1-pro는 OpenAI 호환 /v1/chat/completions 엔드포인트에서 K3와 같은 파라미터 제약으로 동작하므로, K3에서 옮길 때는 모델 이름만 바꾸면 됩니다. Claude Code에서도 바로 사용할 수 있으며 동시 실행 제한이 없습니다.

빠른 시작

세 단계로 Kimi K3.1 Pro API 연동하기

  1. 가입 및 충전: anyaigc.ai에서 계정을 만듭니다. $1부터 충전할 수 있으며, 잔액은 플랫폼의 모든 모델에서 공통으로 사용됩니다.
  2. API 키 만들기: 콘솔에서 키를 만들고 sk-로 시작하는 값을 복사해 ANYAIGC_API_KEY 환경 변수에 저장하세요.
  3. 요청 보내기: model을 kimi-k3.1-pro로 지정하고 Authorization: Bearer 헤더를 붙여 POST https://anyaigc.ai/v1/chat/completions를 호출하세요. OpenAI SDK에서는 base_url만 https://anyaigc.ai/v1로 설정하면 됩니다.

팁: K3.1 Pro는 항상 사고하며, 추론 내용은 reasoning_content로 반환됩니다. temperature, top_p 같은 샘플링 파라미터는 Moonshot이 고정하므로 보내지 마세요. 멀티턴 대화와 도구 호출에서는 API가 반환한 어시스턴트 메시지 전체(reasoning_content와 tool_calls 포함)를 다음 요청에 그대로 다시 보내세요.

모든 파라미터는 Chat Completions 레퍼런스를 참고하세요. 문서 예제의 모델 이름을 사용할 Kimi 모델 ID로 바꾸세요.

Claude Code

Claude Code에서 Kimi K3.1 Pro 사용하기

Claude Code를 Kimi K3.1 Pro로 전환하세요. 1M 컨텍스트 길이를 지원하며, Moonshot은 대부분의 코딩 벤치마크를 Claude Code 환경에서 실행했습니다.

  1. Claude Code 설치: 공식 설치 프로그램을 사용하세요(예: npm install -g @anthropic-ai/claude-code).
  2. 설정 추가: ~/.claude/settings.json을 열어 아래 env 블록을 추가하고, ANTHROPIC_AUTH_TOKEN 값을 AnyAIGC에서 만든 키로 바꿉니다.
  3. 코딩 시작: 프로젝트 폴더에서 claude를 실행하세요. /model을 입력해 현재 모델이 kimi-k3.1-pro인지 확인합니다.

부가 작업 비용 절감: ANTHROPIC_DEFAULT_HAIKU_MODEL을 kimi-k2.7-code로 설정하면 Claude Code의 가벼운 하위 작업은 더 저렴한 모델이 처리하고, 주 작업은 K3.1 Pro가 계속 맡습니다.

전체 절차와 자주 발생하는 오류는 Claude Code 설정 가이드를 참고하세요. 가이드의 모델 이름을 kimi-k3.1-pro로 바꿔 사용하세요.

FAQ

Kimi K3.1 Pro API FAQ

Kimi K3.1 Pro API 요금은 얼마입니까?

AnyAIGC에서 kimi-k3.1-pro는 토큰 단위로 과금됩니다. 입력 100만 토큰당 $0.8100, 출력 100만 토큰당 $4.0500, 캐시 히트 100만 토큰당 $0.0810입니다. Moonshot 공식 USD 가격은 입력 $2.00, 출력 $10.00, 캐시 히트 $0.20이므로 AnyAIGC는 공식 정가의 약 40%입니다. 출력에는 사고 토큰이 포함됩니다. 실시간 가격은 모델 카탈로그에서 확인하세요.

Kimi K3.1 Pro의 모델 ID와 컨텍스트 길이는 어떻게 됩니까?

모델 ID는 kimi-k3.1-pro입니다. Moonshot은 1,048,576 토큰(1M) 컨텍스트 길이를 명시합니다. max_completion_tokens의 기본값은 131,072이며, 최대 1,048,576까지 설정할 수 있습니다.

Kimi K3.1 Pro는 K3와 무엇이 다릅니까?

Moonshot에 따르면 K3.1 Pro는 Kimi K3에 훨씬 많은 사후 학습 연산을 투입하고, 수백 개 다운스트림 도메인에 걸친 공동 강화 학습을 적용한 모델입니다. Moonshot이 보고한 향상은 장기 코딩(Kimi Code Bench 3.0이 55.95에서 61.2로 상승), 금융 리서치(내부 평가가 58.8에서 70.4로 상승), 사실 정확도(주장 단위 환각률이 23.4%에서 8.3%로 하락)입니다. 파라미터 제약은 K3와 같으므로 마이그레이션은 모델 이름만 바꾸면 됩니다. AnyAIGC에서 K3.1 Pro는 입력 $0.8100, 출력 $4.0500으로 K3보다 약 3분의 1 저렴합니다.

Kimi K3.1 Pro의 사고 깊이는 어떻게 조절합니까?

K3.1 Pro는 항상 사고하며, 사고 모드를 끌 수 없습니다. 요청 본문 최상위의 reasoning_effort 필드로 깊이를 지정하세요: low, high, max(기본값 max). temperature, top_p 같은 샘플링 파라미터는 Moonshot이 고정하므로 요청에 포함하지 마세요.

Kimi K3.1 Pro는 도구 호출과 이미지, 비디오 입력을 지원합니까?

네. Moonshot 문서에는 함수 호출(tools / tool_choice), 구조화된 출력(json_schema), 스트리밍, 이미지와 비디오 입력이 명시되어 있습니다. 멀티턴 대화와 도구 호출에서는 어시스턴트 메시지 전체(reasoning_content와 tool_calls 포함)를 다음 요청에 그대로 다시 보내세요.

Claude Code에서 Kimi K3.1 Pro를 사용할 수 있습니까?

네. ~/.claude/settings.json의 env 블록에서 ANTHROPIC_BASE_URL을 https://anyaigc.ai로, ANTHROPIC_AUTH_TOKEN을 API 키로, ANTHROPIC_MODEL을 kimi-k3.1-pro로 설정한 다음 claude를 실행하세요.

Kimi K3.1 Pro는 오픈 소스입니까?

Moonshot은 K3.1 Pro를 지금까지 가장 강력한 3T급 오픈 웨이트 모델이라고 부르며, 전체 가중치를 2026년 11월 4일까지 공개한다고 밝혔습니다. AnyAIGC를 통해 API를 호출하면 직접 호스팅할 필요가 없습니다. 모델 라이선스와 상업적 이용은 Moonshot AI 공식 약관을 따릅니다.

동시 실행 수나 속도 제한이 있습니까?

AnyAIGC는 kimi-k3.1-pro의 동시 실행을 제한하지 않으며, 모든 사용자에게 기본으로 적용됩니다. 배치 작업, CI 파이프라인, 병렬 에이전트에 적합합니다. Moonshot 자체 플랫폼은 충전 등급별로 동시 실행, RPM, TPM, TPD를 제한하지만, AnyAIGC를 통해 호출할 때는 이 등급이 적용되지 않습니다.

Kimi K3.1 Pro API 키는 어떻게 받습니까?

anyaigc.ai에 가입하고 잔액을 충전한 뒤 콘솔에서 키를 만드세요. 같은 키로 모든 Kimi 모델과 플랫폼의 다른 300개 이상의 모델을 호출할 수 있으므로 별도의 Moonshot 플랫폼 계정이 필요 없습니다.

AnyAIGC에서 인보이스를 받을 수 있습니까?

네. 콘솔에서 실제 충전한 금액 기준으로 직접 인보이스를 발급할 수 있습니다.

WeChat Pay, Alipay, USDT, 신용카드로 충전할 수 있습니다. 잔액은 USD 기준이며 플랫폼의 모든 모델에서 사용할 수 있습니다. 인보이스는 콘솔에서 충전한 금액 기준으로 발급할 수 있습니다.
