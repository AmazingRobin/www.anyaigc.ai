소개

새로운 베이스 모델과 아키텍처의 네이티브 멀티모달 모델

Zhipu는 GLM-5.3-Flash를 첫 네이티브 멀티모달 GLM-5 모델이라고 부르며, 매우 낮은 비용으로 GLM-5.2 이상의 성능을 제공한다고 설명합니다. GLM-5.3과 달리 새로 학습한 베이스 모델에서 출발했으며, 멀티모달 데이터를 포함한 약 30T 토큰으로 사전 학습했습니다.

총 320B, 활성 18B 파라미터의 MoE입니다. Zhipu에 따르면 희소 어텐션과 선형 어텐션을 결합한 첫 오픈 프런티어 모델이며, 매니폴드 제약 하이퍼 커넥션(mHC)을 사용합니다. GLM-5.3과 비교해 어텐션 연산량은 약 3배, KV 캐시는 약 4.4배 줄어, 긴 컨텍스트 성능을 유지하면서 서빙 비용을 크게 낮춥니다. 컨텍스트 길이는 1M 토큰, 최대 출력은 128K이며 사고 모드는 항상 켜져 있습니다.

AnyAIGC에서 glm-5.3-flash는 OpenAI 호환 /v1/chat/completions 엔드포인트로 동작하고, 텍스트와 이미지를 입력받으며, Claude Code에서 바로 사용할 수 있고, 동시 실행 제한이 없습니다.

빠른 시작

3단계로 GLM-5.3-Flash API에 연결하기

  1. 가입 및 충전: anyaigc.ai에서 계정을 만듭니다. $1부터 충전할 수 있으며, 잔액은 플랫폼의 모든 모델에서 공통으로 사용됩니다.
  2. API 키 만들기: 콘솔에서 키를 만들고 sk-로 시작하는 값을 복사해 ANYAIGC_API_KEY 환경 변수에 저장하세요.
  3. 요청 보내기: POST https://anyaigc.ai/v1/chat/completions를 호출하고 model에 glm-5.3-flash를 지정한 뒤 Authorization: Bearer 헤더를 넣으세요. OpenAI SDK에서는 base_url만 https://anyaigc.ai/v1로 설정하면 됩니다.

팁: GLM-5.3-Flash는 항상 사고 모드로 동작합니다. 추론 내용은 reasoning_content 필드로 반환되며, reasoning_effort(low / high / max)로 깊이를 설정합니다. 이미지는 공개 URL 또는 Base64를 사용해 image_url 콘텐츠 블록으로 보내세요. 멀티턴 대화와 도구 호출에서는 어시스턴트 메시지 전체를 수정 없이 다음 요청에 그대로 다시 보내세요.

모든 파라미터는 Chat Completions 레퍼런스를 참고하세요. 문서 예제의 모델 이름은 사용할 GLM 모델 ID로 바꾸세요.

Claude Code

Claude Code에서 GLM-5.3-Flash 사용하기

Claude Code를 GLM-5.3-Flash로 전환하세요. 가격이 GLM-5.3의 약 1/15 수준이어서 일상적인 코딩을 처리하고, 스크린샷을 읽어 UI도 수정할 수 있습니다.

  1. Claude Code 설치: 공식 설치 프로그램을 사용합니다. macOS 또는 Linux에서는 curl -fsSL https://claude.ai/install.sh | bash를 실행하면 됩니다.
  2. 설정 추가: ~/.claude/settings.json을 열어 아래 env 블록을 추가하고, ANTHROPIC_AUTH_TOKEN 값을 AnyAIGC에서 만든 키로 바꿉니다.
  3. 코딩 시작: 프로젝트 폴더에서 claude를 실행하세요. /model을 입력해 현재 모델이 glm-5.3-flash인지 확인하세요.

어려운 작업: 여러 모듈에 걸친 복잡한 리팩터링이나 장시간 작업에는 설정의 ANTHROPIC_MODEL을 glm-5.3으로 바꾸고, 가벼운 하위 작업에는 Flash를 계속 사용하세요.

전체 과정과 자주 발생하는 오류는 Claude Code 설정 가이드를 참고하세요. 가이드의 모델 이름을 glm-5.3-flash로 바꿔 사용하세요.

사양

사양과 선택 기준

Z.ai 문서는 GLM-5.3-Flash를 GLM-5 시리즈 최초의 네이티브 멀티모달 모델이라고 설명하며, GLM-5.2보다 지능이 높다고 밝힙니다.

문서에는 전체 320B, 활성 18B 파라미터로 명시되어 있습니다. 희소 어텐션과 선형 어텐션을 결합한 최초의 오픈 소스 프런티어 모델이며, GLM-5.3 대비 어텐션 연산을 3.01배, KV 캐시를 4.44배 줄였다고 설명합니다.

공식 모델 개요 표에는 1M 토큰 컨텍스트 길이가 기재되어 있습니다.

이 페이지에는 입력 $0.0607, 출력 $0.2025, 캐시 히트 $0.0122가 표시되며, 위의 가격표와 일치합니다.

glm-5.3과 비교: 공식 문서에 따르면 GLM-5.3은 현재 텍스트 입력만 받습니다. 이미지 등 멀티모달 입력이 필요하면 GLM-5.3-Flash를 선택하세요.

사양은 벤더 공식 문서(docs.z.ai)를 따랐습니다. 이 페이지의 표는 가격이며, 실시간 요금은 모델 카탈로그가 기준입니다.

FAQ

GLM-5.3-Flash API FAQ

GLM-5.3-Flash API 가격은 얼마입니까?

AnyAIGC에서 glm-5.3-flash는 토큰 단위로 과금됩니다. 입력 100만 토큰당 $0.0607, 출력 100만 토큰당 $0.2025, 캐시 히트 100만 토큰당 $0.0122입니다. Zhipu의 공식 USD 정가는 입력 $0.15, 출력 $0.50, 캐시 히트 $0.03이므로 AnyAIGC는 공식 정가의 약 40.5%(약 60% 할인)입니다. 출력에는 사고 토큰이 포함됩니다. 실시간 요금은 모델 카탈로그를 확인하세요.

GLM-5.3-Flash의 모델 ID는 무엇이며 컨텍스트 길이는 얼마입니까?

모델 ID는 glm-5.3-flash입니다. Zhipu는 1M 토큰 컨텍스트 길이와 최대 128K 출력 토큰을 명시합니다. AnyAIGC를 통해 텍스트와 이미지 입력을 받을 수 있습니다.

GLM-5.3-Flash는 GLM-5.3과 어떻게 다릅니까?

GLM-5.3-Flash는 새로 학습한 베이스 모델을 기반으로 하며, 전체 320B, 활성 18B 파라미터와 희소+선형 하이브리드 어텐션을 사용합니다. GLM-5 시리즈 최초의 네이티브 멀티모달 모델입니다. Zhipu에 따르면 GLM-5.3과 비교해 어텐션 연산이 약 3배, KV 캐시가 약 4.4배 적게 필요합니다. GLM-5.3은 가장 어려운 코딩 작업에 더 강한 플래그십이며 텍스트만 받습니다. Flash는 이미지를 받고 가격은 약 1/15입니다(입력 $0.0607 vs $0.9450).

GLM-5.3-Flash가 GLM-5.2보다 더 낫습니까?

Zhipu는 GLM-5.3-Flash가 GLM-5.2를 전반적으로 앞서면서 가격은 약 10분의 1이라고 밝혔습니다. 보고된 비교: DeepSWE 63.4 vs 46.2, Toolathlon Verified 78.4 vs 59.9, AutomationBench 48.8 vs 26.2, GDPval-AA v2 1773 vs 1504.

GLM-5.3-Flash는 이미지를 받습니까? 어떻게 보냅니까?

네. messages[].content 배열에 {"type": "image_url", "image_url": {"url": ...}} 콘텐츠 블록을 추가하세요. url에는 공개 이미지 URL 또는 Base64 데이터 URL을 넣을 수 있습니다. 이미지가 여러 장이면 블록을 여러 개 추가하세요.

Claude Code에서 GLM-5.3-Flash를 사용할 수 있습니까?

네. ~/.claude/settings.json의 env 블록에서 ANTHROPIC_BASE_URL을 https://anyaigc.ai로, ANTHROPIC_AUTH_TOKEN을 API 키로, ANTHROPIC_MODEL을 glm-5.3-flash로 설정한 뒤 claude를 실행하세요. 토큰 단위로 결제하며, 구독 플랜처럼 5시간 단위의 사용 한도 구간이 없습니다.

GLM-5.3-Flash의 사고 모드를 끌 수 있습니까?

아니요. GLM-5.3-Flash는 항상 사고 모드로 동작하며, Zhipu는 이를 끄는 기능을 지원하지 않습니다. reasoning_effort로 깊이를 설정하세요: low, high, max(기본값 max). 분류, 추출 같은 간단한 작업에서는 low가 출력 토큰을 줄여 줍니다.

GLM-5.3-Flash는 오픈 소스입니까?

네. Zhipu는 GLM-5.3-Flash 가중치를 MIT 라이선스로 Hugging Face(zai-org/GLM-5.3-Flash)에 공개했습니다. AnyAIGC를 통해 API를 호출하면 직접 호스팅할 필요가 없습니다. 상업적 사용은 Zhipu AI의 공식 약관을 따릅니다.

동시 실행 수나 속도 제한이 있습니까?

AnyAIGC는 glm-5.3-flash의 동시 실행을 제한하지 않으며, 모든 사용자에게 기본으로 적용됩니다. 배치 작업, CI 파이프라인, 병렬 에이전트에 적합합니다. 토큰 단위로 과금하므로 구독 플랜처럼 시간 구간마다 초기화되는 한도가 없습니다.

GLM-5.3-Flash API 키는 어떻게 받습니까?

anyaigc.ai에서 가입하고 크레딧을 충전한 뒤 콘솔에서 키를 만드세요. 같은 키로 모든 GLM 모델과 플랫폼의 300개 이상의 다른 모델을 사용할 수 있으므로, 별도의 Zhipu 플랫폼 계정이나 GLM Coding Plan이 필요 없습니다.

AnyAIGC에서 인보이스를 받을 수 있습니까?

네. 콘솔에서 실제 충전한 금액 기준으로 직접 인보이스를 발급할 수 있습니다.

어떤 결제 수단을 지원합니까?

WeChat Pay, Alipay, USDT, 신용카드로 충전할 수 있습니다. 잔액은 USD 기준이며 플랫폼의 모든 모델에서 사용할 수 있습니다. 인보이스는 콘솔에서 충전한 금액 기준으로 발급할 수 있습니다.

신규 사용자에게 무료 체험 크레딧이 있습니까?

네. 신규 계정에는 토큰 200만 개 분량의 체험 크레딧이 제공되므로 충전 여부를 결정하기 전에 먼저 테스트할 수 있습니다. 충전은 $1부터 가능합니다.

잔액을 환불받을 수 있습니까?

네. 사용하지 않은 잔액은 수수료 없이 환불받을 수 있습니다. 환불은 고객 지원에 문의해 진행하세요.

실제 모델이 맞습니까? 데이터는 안전합니까?

요청은 공식 모델 채널로 전달되며, 저가 모델이나 리버스 엔지니어링 방식의 대체 모델은 사용하지 않습니다. 법령에서 요구하는 경우를 제외하고 프롬프트와 출력을 영구 저장하거나 학습에 사용하지 않으며, 콘솔에서 모든 요청의 토큰 수와 비용을 확인할 수 있습니다.

내 데이터가 학습에 사용됩니까?

아니요. 법령에서 요구하는 경우를 제외하고 AnyAIGC는 프롬프트와 출력을 영구적으로 저장하지 않으며 모델 학습에 사용하지 않습니다. 요청은 HTTPS로 암호화됩니다. AnyAIGC 개인정보 처리방침을 확인하세요. 모델 자체의 데이터 정책은 Zhipu AI의 공식 약관을 따릅니다.
