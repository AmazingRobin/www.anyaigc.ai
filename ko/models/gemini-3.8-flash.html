Gemini 3.8 Flash API

Google의 가장 지능적인 Flash 모델입니다. Flash의 속도와 가격에 코딩과 에이전트 성능이 크게 향상되었습니다. AnyAIGC에서는 공식 정가의 약 10%입니다.

Google은 Gemini 3.8 Flash를 "장시간 소프트웨어 엔지니어링, 자율 에이전트, 복잡한 엔터프라이즈 워크플로를 위해 설계되었다"고 설명합니다. 네이티브 Gemini API 또는 OpenAI 호환 API로 gemini-3.8-flash를 입력 100만 토큰당 $0.0744, 출력 100만 토큰당 $0.3722에 호출할 수 있습니다.

모델 소개

Flash의 속도와 비용에 플래그십에 가까운 코딩·에이전트 성능

Google은 2026년 9월 2일 Gemini 3.8 Flash를 정식 출시(GA)했습니다. Google은 이 모델을 "가장 지능적인 Flash 모델"이라고 부르며, 장시간 소프트웨어 엔지니어링, 자율 에이전트, 복잡한 엔터프라이즈 워크플로를 위해 만들어졌고 "Flash의 속도와 비용 효율을 그대로 갖췄다"고 설명합니다. 출시 글에서는 3.7 Flash와 같은 속도와 낮은 비용으로, 지금까지 Flash 라인업에서 추론과 코딩 성능이 가장 높은 모델이라고 소개합니다.

모델 카드에 따르면 3.8 Flash는 3.7 Flash를 기반으로 합니다. 최대 1,048,576 입력 토큰을 받고 최대 65,536 출력 토큰을 반환하며, 텍스트, 이미지, 동영상, 오디오, PDF를 네이티브로 입력할 수 있습니다. Google은 2026년 10월에 3.7 Flash를 지원 중단(deprecated)하고 해당 API 요청을 3.8 Flash로 라우팅하므로, 3.8 Flash는 Gemini 3 시리즈의 주력 안정 모델입니다.

AnyAIGC에서 gemini-3.8-flash는 네이티브 /v1beta/models/gemini-3.8-flash:generateContent 엔드포인트와 OpenAI 호환 /v1/chat/completions를 모두 지원합니다. Google Cloud 계정이 필요 없고 동시 실행 제한이 없으므로 프로덕션 트래픽에 그대로 사용할 수 있습니다.

Gemini 3.8 Flash가 잘하는 것

  • 일상적인 코딩 작업의 주력 모델

    Google은 DeepSWE v1.1에서 73.7%, Terminal-bench 2.1에서 89.4%를 기록했다고 밝혔습니다. 자동 완성, 버그 수정, 테스트처럼 호출이 잦은 작업을 빠르고 저렴하게 맡기세요.

  • 자율 에이전트

    함수 호출, 코드 실행, 구조화된 출력, URL 컨텍스트, Google Search와 Maps 그라운딩을 지원하며, 컴퓨터 사용은 프리뷰입니다. OSWorld-2.0에서 59.0%.

  • 대규모 프로덕션

    입력 100만 토큰당 $0.0744, 캐시 히트 100만 토큰당 $0.0074이며 AnyAIGC에는 동시 실행 상한이 없습니다. 분류, 추출, 요약, 콘텐츠 검수를 대규모로 실행하세요.

  • 100만 토큰 컨텍스트

    1,048,576 토큰의 입력 윈도우에는 코드베이스 전체, 긴 보고서, 계약서 묶음을 담을 수 있어 문서 간 검색과 비교를 한 번의 요청으로 처리할 수 있습니다.

  • 네이티브 멀티모달

    이미지, 동영상, 오디오, PDF를 바로 입력할 수 있습니다. Google은 긴 동영상 벤치마크 LVBench에서 87.8%, 차트 추론 CharXiv에서 86.2%를 기록했다고 밝혔습니다.

  • 조절 가능한 사고

    사고 수준이 세 단계입니다. 간단한 호출에서는 low로 토큰을 아끼고, 어려운 문제에는 high를 쓰세요. 모델 하나로 빠른 응답부터 깊은 추론까지 처리합니다.

빠른 시작

3단계로 시작하는 Gemini 3.8 Flash API

  1. 가입 및 충전: anyaigc.ai에서 계정을 만드세요. 잔액은 플랫폼의 모든 모델에서 사용할 수 있습니다.
  2. API 키 생성: 콘솔에서 토큰을 만들고 sk-로 시작하는 키를 복사해 ANYAIGC_API_KEY에 저장하세요.
  3. 요청 보내기: 네이티브 엔드포인트 https://anyaigc.ai/v1beta/models/gemini-3.8-flash:generateContent 또는 OpenAI 호환 https://anyaigc.ai/v1/chat/completions를 호출하고 model을 gemini-3.8-flash로 지정하세요. 둘 다 Authorization: Bearer를 사용합니다.

파라미터 참고: Gemini 3.8 Flash는 thinkingLevel(low / medium / high)로 사고를 제어합니다. 기본값은 medium이며 minimal은 지원되지 않습니다. Google에 따르면 수준이 높을수록 토큰을 더 사용할 수 있으므로 배치 작업은 low로 시작하세요. 네이티브 스트리밍은 :streamGenerateContent?alt=sse를 호출하세요.

전체 파라미터는 네이티브 Gemini API 문서와 Chat Completions 문서에 있습니다. 예제의 모델 이름을 gemini-3.8-flash로 바꾸세요.

Google 문서는 Gemini 3.8 Flash를 장시간 소프트웨어 엔지니어링, 자율 에이전트, 복잡한 엔터프라이즈 워크플로를 위해 설계된 가장 지능적인 Flash 모델로 소개하며, Flash의 속도와 비용 효율을 갖췄다고 설명합니다.

입력 한도는 1,048,576 토큰, 출력 한도는 65,536 토큰입니다. 입력은 텍스트, 이미지, 동영상, 오디오, PDF이고 출력은 텍스트입니다.

이 페이지의 가격은 입력 $0.0744, 출력 $0.3722, 캐시 히트 $0.0074이며 위 가격표와 일치합니다.

gemini-4-hydrogen과 비교하면, Google은 Gemini 4 Hydrogen을 일상적인 코딩과 에이전트 워크플로용으로 포지셔닝하며, 긴 디코딩을 켜면 출력이 최대 1,048,576 토큰까지 가능합니다.

사양은 제공사 공식 문서(aistudio.google.com)를 따랐습니다. 이 페이지의 표는 가격이며, 실시간 요금은 모델 카탈로그가 기준입니다.

FAQ

Gemini 3.8 Flash API FAQ

Gemini 3.8 Flash API 가격은 얼마입니까?

AnyAIGC에서 gemini-3.8-flash는 토큰 단위로 과금됩니다. 입력 100만 토큰당 $0.0744, 출력 100만 토큰당 $0.3722, 캐시 히트 100만 토큰당 $0.0074입니다. Google 표준 가격(2026년 12월 31일까지의 도입 가격)은 입력 $0.75, 출력 $3.75, 캐시 $0.075이므로 AnyAIGC는 공식 정가의 약 10%입니다. 출력에는 사고 토큰이 포함됩니다.

Google의 도입 기간이 끝나면 AnyAIGC 가격도 바뀝니까?

아니요. 2027년 1월 1일부터 Google 표준 가격은 100만 토큰당 입력 $1.50, 출력 $7.50, 캐시 $0.15가 됩니다. AnyAIGC는 현재 가격(입력 $0.0744, 출력 $0.3722, 캐시 $0.0074)을 유지하며, 이는 그때 Google 가격의 약 5%입니다.

모델 ID는 무엇입니까? Gemini 3.8 Flash는 정식 출시되었습니까?

모델 ID는 gemini-3.8-flash입니다. Google은 2026년 9월 2일 정식 출시(GA)했으며 종료 일정은 발표하지 않았습니다. 네이티브 API는 URL에 모델 이름을 넣고(/v1beta/models/gemini-3.8-flash:generateContent), OpenAI 호환 API는 model 필드에 넣습니다.

컨텍스트 길이와 최대 출력은 어떻게 됩니까?

Google은 입력 한도 1,048,576 토큰, 출력 한도 65,536 토큰으로 안내합니다. 입력은 텍스트, 이미지, 동영상, 오디오, PDF이고 출력은 텍스트입니다. 지식 기준일은 2026년 3월입니다.

네이티브 Gemini API와 OpenAI 호환 API 중 무엇을 써야 합니까?

둘 다 사용할 수 있습니다. 네이티브 엔드포인트는 POST https://anyaigc.ai/v1beta/models/gemini-3.8-flash:generateContent이며 요청 본문은 Google Gemini API와 같습니다. OpenAI 호환 엔드포인트는 POST https://anyaigc.ai/v1/chat/completions이며, 공식 OpenAI SDK에서는 base_url을 https://anyaigc.ai/v1로 설정하세요. 둘 다 Authorization: Bearer로 인증합니다.

사고 수준(thinking level)은 어떻게 설정합니까?

Gemini 3.8 Flash는 low, medium, high 사고 수준을 지원하며 기본값은 medium입니다. 네이티브 API에서는 generationConfig.thinkingConfig.thinkingLevel을 설정하세요. Google에 따르면 minimal은 지원되지 않으며 오류를 반환하고, 수준이 높을수록 토큰을 더 사용할 수 있으므로 비용에 민감한 배치 작업은 low로 시작하는 것이 좋습니다.

Gemini 3.8 Flash와 Gemini 4 Argon 중 무엇을 선택해야 합니까?

Gemini 3.8 Flash는 대량 처리, 지연 시간과 비용에 민감한 작업, 일상적인 코딩과 에이전트 워크플로에 적합하며 AnyAIGC에서 입력 $0.0744, 출력 $0.3722입니다. Gemini 4 Argon은 Google의 현재 플래그십으로, Google이 공개한 DeepSWE, Terminal-bench 4.0, 법률·금융 에이전트 벤치마크에서 3.8 Flash보다 점수가 높으며 AnyAIGC에서 입력 $0.1985, 출력 $0.9927입니다. 3.8 Flash로 시작하고 가장 어려운 작업은 Argon에 보내세요. 둘 다 같은 키를 사용합니다.

Gemini 3.7 Flash를 아직 쓸 수 있습니까? 3.8 Flash는 무엇이 다릅니까?

Google은 2026년 10월 8일 gemini-3.7-flash를 지원 중단하고 gemini-3.8-flash로 대체했으며, Google 자체 API는 3.7 Flash 요청을 3.8 Flash로 자동 라우팅합니다. Google에 따르면 3.8 Flash는 3.7 Flash를 기반으로 소프트웨어 엔지니어링과 에이전트 작업이 크게 향상되었고, 예를 들어 DeepSWE v1.1이 65.3%에서 73.7%로 올랐습니다. AnyAIGC에서는 둘의 가격이 같으므로 새 프로젝트에는 gemini-3.8-flash를 사용하세요.

동시 실행 수나 속도 제한이 있습니까?

AnyAIGC는 gemini-3.8-flash의 동시 실행을 제한하지 않습니다. 모든 계정에 기본 적용되며, 배치 처리와 병렬 에이전트에 적합합니다.

실제 모델이 맞습니까? 데이터는 안전합니까?

요청은 공식 모델 채널로 전달되며, 저가 모델이나 리버스 엔지니어링 방식의 대체 모델은 사용하지 않습니다. 법령에서 요구하는 경우를 제외하고 프롬프트와 출력을 영구 저장하거나 학습에 사용하지 않으며, 콘솔에서 모든 요청의 토큰 수와 비용을 확인할 수 있습니다.

내 데이터가 학습에 사용됩니까?

아니요. 법률상 요구되는 경우를 제외하고 AnyAIGC는 프롬프트와 출력을 영구 저장하거나 학습에 사용하지 않으며, 요청은 HTTPS로 전송됩니다. AnyAIGC 개인정보 처리방침을 참고하세요. 모델 자체에는 Google의 약관이 적용됩니다.
