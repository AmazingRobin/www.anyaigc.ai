세 단계로 Suno API 호출하기

비동기 작업 흐름: 요청을 제출해 task_id를 받고, 결과가 나올 때까지 폴링하세요. 몇 분 안에 첫 곡을 들어볼 수 있습니다.

  1. 가입 후 크레딧 충전

    anyaigc.ai에서 계정을 만들고 크레딧을 충전하세요. 잔액은 플랫폼의 모든 모델에서 공통으로 사용할 수 있습니다.

  2. API 키 만들기

    콘솔에서 토큰을 만들고 키를 복사하세요. base URL은 https://anyaigc.ai이며 인증은 Authorization: Bearer를 사용합니다.

  3. 제출 및 폴링

    /suno/submit/music에 POST해 task_id를 받은 다음, 5–10초마다 GET /suno/fetch/{id}를 호출하세요. 작업이 끝나면 오디오 URL을 가져오면 됩니다.

더 많은 모드(연장, 커버, Persona, 효과음, 매시업, 부분 재작성 등)와 전체 파라미터 목록은 AnyAIGC Suno API 문서를 참고하세요. mv에는 chirp-v3-5부터 chirp-v6까지 지정할 수 있으며, 최신 목록은 문서에서 확인하세요.

Suno API 요금은 얼마입니까?

요청당 고정 요금의 종량제입니다. 곡 생성 $0.1191, Max Mode $0.2382, 효과음 $0.0238, 보컬/반주 분리 $0.1191, 전체 스템 분리 + MIDI $0.5956, 가사 타임라인 $0.0596이며 모두 요청당 요금입니다. 가사 생성, 음악 스타일 강화, 참조 오디오 업로드, Persona 생성은 무료이고, suno_uploads 파일 업로드는 요청당 $0.000993입니다. 구독이나 월 요금은 없습니다.

Suno에 공식 API가 있습니까?

2026년 10월 기준으로 Suno는 누구나 직접 가입해 쓸 수 있는 공개 공식 API를 제공하지 않습니다. AnyAIGC는 Suno 음악 생성을 통합 인터페이스로 제공하는 독립 서드파티 API 플랫폼이며, Suno, Inc.와 제휴 관계가 없습니다.

Suno API 키는 어떻게 받습니까?

anyaigc.ai에서 가입하고 크레딧을 충전한 뒤, 콘솔의 토큰 페이지에서 API 키를 만드세요. 같은 키로 Suno와 플랫폼의 다른 300개 이상 모델을 모두 사용할 수 있습니다.

Suno API의 요청 제한은 어떻게 됩니까?

Suno API는 기본적으로 200 RPM(분당 요청 200건)을 지원하며, 배치 사운드트랙 생성, UGC 플랫폼, 자동화 파이프라인에 적합합니다. 모든 사용자에게 적용되고 별도 신청이 필요 없으며, 더 필요하면 상향할 수 있습니다. 한도를 늘리려면 고객 지원에 문의하세요.

Suno API는 동기 방식입니까, 비동기 방식입니까? 곡 하나를 만드는 데 얼마나 걸립니까?

비동기 방식입니다. /suno/submit/music에 제출해 task_id를 받고, 작업이 끝날 때까지 /suno/fetch/{id}를 폴링하세요. 대부분의 곡은 곡 길이와 현재 부하에 따라 1–3분 안에 완료됩니다.

Suno API로 무엇을 할 수 있습니까?

텍스트 설명이나 직접 쓴 가사로 보컬 포함 또는 반주만 있는 완성곡을 생성하고, 가사와 효과음을 생성하며, 스타일 태그를 강화하고, 참조 오디오를 업로드하고, 보컬과 반주를 분리하고, 모든 스템을 분리해 MIDI로 내보내고, 줄 단위 가사 타임라인을 받고, 아티스트 스타일의 Persona를 만들 수 있습니다.

어떤 Suno 모델 버전을 지원합니까?

mv 파라미터로 버전을 선택하세요: chirp-v3-0, chirp-v3-5, chirp-v4, chirp-v4-5, chirp-v5, chirp-v5-5, chirp-v6, chirp-v6-wild, chirp-v6-mini를 지원하며, Suno v3부터 최신 v6 계열까지 포함합니다. mv를 생략하면 기본 버전이 사용됩니다. 최신 목록은 AnyAIGC 문서를 참고하세요.

Max Mode와 일반 생성은 어떻게 다릅니까?

Max Mode는 더 높은 품질의 생성 설정을 사용하며, 보통 보컬 표현이 더 섬세하고 편곡이 더 풍성합니다. 가격은 일반 생성의 2배(요청당 $0.2382)입니다. 발매용 트랙에는 Max Mode를, 데모와 대량 탐색에는 일반 모드를 사용하세요.

상업적 사용 권한은 Suno의 최신 라이선스 약관과 사용 사례에 따라 달라집니다. 상업적으로 발매하기 전에 Suno 공식 약관을 확인하세요. 궁금한 점이 있으면 AnyAIGC 고객 지원에 문의하세요.

어떤 결제 수단을 지원합니까?

WeChat Pay, Alipay, USDT, 신용카드로 충전할 수 있습니다. 잔액은 USD 기준이며 플랫폼의 모든 모델에서 사용할 수 있습니다. 인보이스는 콘솔에서 충전한 금액 기준으로 발급할 수 있습니다.

신규 사용자에게 무료 체험 크레딧이 있습니까?

네. 신규 계정에는 토큰 500만 개 분량의 체험 크레딧이 제공되므로 충전 여부를 결정하기 전에 먼저 테스트할 수 있습니다. 충전은 $1부터 가능합니다.

잔액을 환불받을 수 있습니까?

네. 사용하지 않은 잔액은 수수료 없이 환불받을 수 있습니다. 환불은 고객 지원에 문의해 진행하세요.

실제 모델이 맞습니까? 데이터는 안전합니까?

요청은 공식 모델 채널로 전달되며, 저가 모델이나 리버스 엔지니어링 방식의 대체 모델은 사용하지 않습니다. 법령에서 요구하는 경우를 제외하고 프롬프트와 출력을 영구 저장하거나 학습에 사용하지 않으며, 콘솔에서 모든 요청의 토큰 수와 비용을 확인할 수 있습니다.

어떤 장르와 언어를 지원합니까?

Suno는 팝, 록, 일렉트로닉, 로파이, 힙합, 포크, 영화 음악 등 주요 장르를 지원하며, 영어, 중국어, 일본어, 한국어 등 다양한 언어로 가사와 보컬을 만들 수 있습니다.
