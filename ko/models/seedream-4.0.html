Seedream 4.0이란

Seedream 4.0은 ByteDance Seed 팀의 멀티모달 이미지 모델로, 텍스트→이미지, 이미지 편집, 다중 이미지 합성을 하나의 프레임워크로 통합했습니다. 프롬프트를 추론해 알맞은 가로세로 비율과 이미지 수를 정하고, 요청 한 번에 주제가 연결된 이미지를 최대 15장 반환합니다.

ByteDance는 중국어 텍스트 정확도와 출력 다양성이 뚜렷하게 개선되었고 4K 출력도 지원한다고 밝혔습니다. AnyAIGC에서 모델 ID는 doubao-seedream-4-0-250828이며, 이미지당 $0.0203부터입니다.

사양은 벤더 공식 문서(docs.volcengine.com)를 따랐습니다. 이 페이지의 표는 가격이며, 실시간 요금은 모델 카탈로그가 기준입니다.

Seedream 4.0 API FAQ

Seedream 4.0 API 요금은 얼마입니까?

AnyAIGC에서 Seedream 4.0(doubao-seedream-4-0-250828)은 이미지당 $0.0203부터 시작합니다. 해상도에 따라 요금이 다르며, 2K와 4K 실시간 요금은 모델 카탈로그에서 확인할 수 있습니다. 이미지 세트는 생성된 이미지 수만큼 과금됩니다. 과금은 생성에 성공한 건에 대해서만 이루어지며, 실시간 가격은 모델 카탈로그에서 확인하세요.

Seedream 4.0이란 무엇입니까?

Seedream 4.0은 ByteDance Seed 팀의 멀티모달 이미지 모델이며, AnyAIGC에서의 모델 ID는 doubao-seedream-4-0-250828입니다. 텍스트→이미지, 이미지 편집, 다중 이미지 합성을 하나의 프레임워크로 통합하고, 프롬프트에 맞춰 가로세로 비율과 이미지 수를 정하며, 요청 한 번에 관련 이미지를 최대 15장 반환하고 4K를 지원합니다.

지원하는 해상도는 무엇입니까?

Volcano Engine Ark 문서에 따르면 4.0은 size 값으로 1K, 2K, 4K 또는 픽셀 크기를 받으며, 가로세로 비율은 1:16부터 16:1까지입니다.

참조 이미지는 몇 장까지 보낼 수 있습니까? 이미지 세트는 최대 몇 장입니까?

image는 참조 이미지를 최대 14장까지 받습니다(현재 Volcano Engine Ark 문서 기준). 이미지 세트는 요청 한 번에 최대 15장을 반환하며, 참조 이미지를 쓰면 참조 이미지와 생성 이미지를 합쳐 15장을 넘을 수 없습니다.

4.0은 지금도 쓸 만합니까?

4.0은 계속 사용할 수 있고, 4.5보다 저렴하며(이미지당 $0.0203부터) 1K 구간을 제공합니다. 새 프로젝트에는 5.0 lite 또는 4.5를 먼저 써 보세요. API가 같아서 마이그레이션은 모델 ID만 바꾸면 됩니다.

동시 실행 제한이 있습니까? 가입에 무엇이 필요합니까?

AnyAIGC는 Seedream 4.0에 동시 실행 제한을 두지 않으며, 모든 계정에 기본으로 적용됩니다. base URL은 https://anyaigc.ai입니다. Volcano Engine 계정이나 본인 인증이 필요 없고, 같은 키로 플랫폼의 다른 300개 이상 모델도 사용할 수 있습니다.

AnyAIGC에서 인보이스를 받을 수 있습니까?

네. 콘솔에서 실제 충전한 금액 기준으로 직접 인보이스를 발급할 수 있습니다.

어떤 결제 수단을 지원합니까?

WeChat Pay, Alipay, USDT, 신용카드로 충전할 수 있습니다. 잔액은 USD 기준이며 플랫폼의 모든 모델에서 사용할 수 있습니다. 인보이스는 콘솔에서 충전한 금액 기준으로 발급할 수 있습니다.

신규 사용자에게 무료 체험 크레딧이 있습니까?

네. 신규 계정에는 토큰 200만 개 분량의 체험 크레딧이 제공되므로 충전 여부를 결정하기 전에 먼저 테스트할 수 있습니다. 충전은 $1부터 가능합니다.

잔액을 환불받을 수 있습니까?

네. 사용하지 않은 잔액은 수수료 없이 환불받을 수 있습니다. 환불은 고객 지원에 문의해 진행하세요.

실제 모델이 맞습니까? 데이터는 안전합니까?

요청은 공식 모델 채널로 전달되며, 저가 모델이나 리버스 엔지니어링 방식의 대체 모델은 사용하지 않습니다. 법령에서 요구하는 경우를 제외하고 프롬프트와 출력을 영구 저장하거나 학습에 사용하지 않으며, 콘솔에서 모든 요청의 토큰 수와 비용을 확인할 수 있습니다.

상업적으로 사용할 수 있습니까? 워터마크를 제거할 수 있습니까?

사용 권한과 콘텐츠 정책은 ByteDance / Volcano Engine 공식 약관을 따릅니다. 요청에서 watermark를 false로 설정하면 오른쪽 아래에 "AI 생성" 표시가 추가되지 않습니다. AnyAIGC는 API 접근만 제공하며 결과물 사용에 추가 제한을 두지 않습니다. 실존 인물 초상, 브랜드 로고 등은 필요한 권리를 갖고 있는지 확인하세요.
