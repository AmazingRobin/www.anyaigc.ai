#Midjourney API 작동 방식

웹 앱과 Discord의 흐름을 그대로 따릅니다. 네 장짜리 그리드를 생성한 뒤 결과에서 버튼을 누르는 방식입니다. API가 모든 버튼을 반환하며, 해당 버튼의 customId를 다시 보내면 실행됩니다.

  1. 01

    POST/mj/submit/imagine

    프롬프트 제출

    작업 ID를 반환합니다. --ar, --v, --niji는 프롬프트에 그대로 넣으세요. 1회당 $0.0595

  2. 02

    GET/mj/task/{id}/fetch

    작업 조회

    SUCCESS가 될 때까지 폴링하여 imageUrl과 buttons 목록을 받으세요. 조회는 무료입니다

  3. 03

    POST/mj/submit/action

    버튼 누르기

    taskId와 버튼의 customId를 보내세요. 업스케일 $0.0298, 변형, 줌, 팬 $0.0595

  4. 04

    POST/mj/submit/modal

    모달 확인

    Vary (Region)와 Custom Zoom은 마스크 또는 새 프롬프트를 사용하는 두 번째 단계가 필요합니다. 1회당 $0.0595

#Midjourney API로 할 수 있는 일

  • Imagine(이미지 생성)

    프롬프트 하나로 네 가지 후보를 받으며, base64Array로 이미지 프롬프트도 선택적으로 보낼 수 있습니다. Midjourney는 사진과 일러스트 모두에서 빛, 질감, 구도로 알려져 있습니다.

  • 애니메이션·일러스트용 Niji

    botType을 NIJI_JOURNEY로 설정하면 애니메이션, 만화, 일러스트 스타일에 맞는 Niji로 전환됩니다.

  • 변형

    V1-V4는 한 이미지를 바탕으로 변주합니다. Vary (Strong)는 더 크게 바뀌고, Vary (Subtle)는 약간만 바뀝니다.

  • 업스케일

    U1-U4로 이미지 한 장을 뽑은 뒤, Subtle 또는 Creative 업스케일로 바로 쓸 수 있는 상태로 만드세요.

  • 줌 아웃과 팬

    프레임을 1.5배 또는 2배로 확장하거나 한 방향으로 늘릴 수 있습니다. 예를 들어 세로 이미지를 가로 이미지로 바꿀 수 있습니다.

  • Blend와 Describe

    이미지 2-5장을 합쳐 새 이미지를 만들거나, 이미지를 보내 그 이미지를 설명하는 프롬프트 네 개를 받을 수 있습니다.

Authorization: Bearer <API Key>로 인증하세요. 제출 엔드포인트는 {"code": 1, "result": "task ID"}를 반환하고, 조회 엔드포인트는 status, progress, imageUrl, buttons 등을 반환합니다. 모든 필드는 AnyAIGC Midjourney API 문서를 참고하세요.

#Midjourney API FAQ

Midjourney API 요금은 얼마입니까?

AnyAIGC는 Midjourney를 1회당 과금합니다. Imagine, Blend, Variation, Reroll, Zoom, Pan, Modal은 각각 $0.0595, 업스케일과 Describe는 $0.0298, 이미지 업로드는 $0.000595이며, Custom Zoom과 Vary (Region)는 무료입니다(Modal 단계가 Modal로 과금됩니다). 작업 조회는 무료이고, 실시간 가격은 모델 카탈로그에서 확인할 수 있습니다.

Midjourney에 공식 API가 있습니까?

Midjourney는 현재 공개 API를 제공하지 않으며, 웹사이트와 Discord에서 동작합니다. AnyAIGC는 Midjourney 서비스를 HTTP 엔드포인트로 감싸 제공하므로, 이미지는 대체 모델이 아니라 Midjourney 자체 모델(Niji 포함)에서 생성됩니다. API 키 하나로 별도의 Discord 계정 없이 Imagine, 업스케일, 변형, 줌 등을 실행할 수 있습니다.

14가지 작업은 무엇이며 어떤 엔드포인트를 사용합니까?

14개의 모델 이름은 14가지 Midjourney 작업에 대응하며, 모두 위의 가격표에 있습니다. Imagine, Blend, Describe는 각각 전용 엔드포인트가 있습니다. 업스케일, Variation, 변형 (Strong/Subtle), Reroll, Zoom, Pan, Custom Zoom, Vary (Region)는 모두 /mj/submit/action을 통하며, 버튼의 customId로 작업을 선택합니다. Modal은 확인 단계이고, Upload는 참조 이미지를 전송합니다.

어떤 Midjourney 버전을 지원합니까? Niji도 사용할 수 있습니까?

프롬프트 끝에 --v 파라미터로 버전을 지정하세요(API 문서에서는 --v 6.1을 사용합니다). 공식 앱과 같은 방식으로 작성하며 그대로 Midjourney에 전달됩니다. Niji 애니메이션 모델은 botType을 NIJI_JOURNEY로 설정하세요. 기본값은 MID_JOURNEY입니다.

한 번 호출하면 이미지가 몇 장 반환됩니까?

Imagine, Variation, Reroll, Zoom, Pan 등은 후보 이미지 4장 그리드를 반환하며 한 번만 과금됩니다. 고해상도 이미지 한 장이 필요하면 그중 하나에 업스케일을 실행하세요.

업스케일과 변형은 어떻게 실행합니까?

/mj/task/{id}/fetch로 작업을 조회하세요. buttons의 각 항목에는 customId가 있으며, 작업 ID와 해당 customId를 /mj/submit/action에 보내면 됩니다. customId는 직접 만들지 말고 항상 응답에서 가져오세요.

동시 실행 제한이 있습니까?

아니요. AnyAIGC는 어떤 계정에도 Midjourney 동시 실행 제한을 두지 않으므로 작업을 병렬로 제출할 수 있습니다. 모든 요청은 base URL https://anyaigc.ai로 보내며, 같은 키로 300개 이상의 다른 모델도 사용할 수 있습니다.

AnyAIGC에서 인보이스를 받을 수 있습니까?

네. 콘솔에서 실제 충전한 금액 기준으로 직접 인보이스를 발급할 수 있습니다.

어떤 결제 수단을 지원합니까?

WeChat Pay, Alipay, USDT, 신용카드로 충전할 수 있습니다. 잔액은 USD 기준이며 플랫폼의 모든 모델에서 사용할 수 있습니다. 인보이스는 콘솔에서 충전한 금액 기준으로 발급할 수 있습니다.

신규 사용자에게 무료 체험 크레딧이 있습니까?

네. 신규 계정에는 토큰 200만 개 분량의 체험 크레딧이 제공되므로 충전 여부를 결정하기 전에 먼저 테스트할 수 있습니다. 충전은 $1부터 가능합니다.

잔액을 환불받을 수 있습니까?

네. 사용하지 않은 잔액은 수수료 없이 환불받을 수 있습니다. 환불은 고객 지원에 문의해 진행하세요.

실제 모델이 맞습니까? 데이터는 안전합니까?

요청은 공식 모델 채널로 전달되며, 저가 모델이나 리버스 엔지니어링 방식의 대체 모델은 사용하지 않습니다. 법령에서 요구하는 경우를 제외하고 프롬프트와 출력을 영구 저장하거나 학습에 사용하지 않으며, 콘솔에서 모든 요청의 토큰 수와 비용을 확인할 수 있습니다.
