모델 소개

iFLYTEK Spark Pro의 3.1 버전

SparkDesk-v3.1은 iFLYTEK Spark 인지 모델의 3.1 API 버전이며 공식 Spark Pro 등급에 대응합니다. 카탈로그는 여러 분야의 지식과 언어 이해를 갖추고 자연스러운 대화로 작업을 수행하는 모델로 설명하며, 언어 이해, 지식 Q&A, 논리 추론, 수학 문제 풀이, 코드 이해를 지원합니다.

iFLYTEK 문서는 이 등급의 컨텍스트 길이를 8,192 토큰, 최대 출력을 8,192 토큰으로 안내합니다. 시스템 역할은 Max와 Ultra에서만 지원하고, Pro에는 웹 검색 플러그인이 안내되어 있습니다. 고정 시스템 프롬프트가 필요하면 대신 SparkDesk-v3.5를 사용하세요.

AnyAIGC에서 SparkDesk-v3.1은 OpenAI 호환 /v1/chat/completions 엔드포인트를 Bearer 키 하나로 사용하며, iFLYTEK APPID, APIKey, APISecret은 필요 없습니다. 토큰 단위로 과금하며 동시 실행 제한은 없습니다.

사양

사양과 선택 기준

iFLYTEK 공식 WebSocket 문서에서 v3.1 엔드포인트(wss://spark-api.xf-yun.com/v3.1/chat)는 Spark Pro에 대응하며, domain 값은 generalv3입니다.

문서에 따르면 Pro의 max_tokens 범위는 1에서 8192이고 기본값은 4096입니다.

문서에 따르면 Pro는 웹 검색 플러그인을 지원합니다. 출처 제목과 URL 반환은 Ultra와 Max에서만 가능합니다.

이 페이지에는 입력 $13.1040, 출력 $13.1040으로 표기되어 있으며 위 가격표와 일치합니다.

웹 검색 결과에 출처 제목과 URL이 함께 반환되어야 한다면 sparkdesk-v3.5(Max)를 선택하세요. 문서에는 Pro에서 지원하지 않는 것으로 안내되어 있습니다.

사양은 제공사 공식 문서(xfyun.cn)를 기준으로 합니다. 이 페이지의 표가 가격이며, 실시간 요금은 모델 카탈로그가 기준입니다.

FAQ

SparkDesk-v3.1 API 자주 묻는 질문

SparkDesk-v3.1 API 가격은 얼마입니까?

AnyAIGC에서 SparkDesk-v3.1은 토큰 단위로 과금합니다. 입력 100만 토큰당 $13.1040, 출력 100만 토큰당 $13.1040으로 동일합니다. 가격은 고정이며 구독료나 월 요금이 없습니다. 실시간 가격은 모델 카탈로그에서 확인하세요.

SparkDesk-v3.1의 모델 ID는 무엇이며 iFLYTEK Spark와 어떤 관계입니까?

모델 ID는 SparkDesk-v3.1(대소문자 구분)입니다. iFLYTEK Spark 인지 모델의 한 버전이며, AnyAIGC가 OpenAI 호환 API로 제공합니다. Apache Spark나 Spark 이메일 앱과는 관련이 없습니다.

SparkDesk-v3.1과 다른 SparkDesk 모델 중 무엇을 선택해야 합니까?

이 시리즈의 나머지 두 모델은 SparkDesk-v3.5와 SparkDesk-v2.1입니다. 버전 번호가 높을수록 iFLYTEK의 더 새로운 등급에 대응합니다. v3.5는 Max, v3.1은 Pro, v2.1은 초기 2.x 버전입니다. 시스템 프롬프트가 필요하면 v3.5를 선택하세요. 비용이 가장 중요하고 품질 요구가 높지 않다면 v2.1을 고려하되, 출시 전에 직접 가진 데이터로 테스트하세요. AnyAIGC에서는 세 모델 모두 입력과 출력 가격이 같습니다.

SparkDesk는 OpenAI API와 호환됩니까? 어떻게 호출합니까?

예. SparkDesk-v3.1은 POST https://anyaigc.ai/v1/chat/completions를 사용하며, 요청과 응답은 OpenAI Chat Completions와 같습니다. 공식 OpenAI SDK에서는 base_url을 https://anyaigc.ai/v1로 설정하세요. iFLYTEK의 WebSocket 서명은 필요 없고 Authorization: Bearer만 있으면 됩니다.

SparkDesk-v3.1의 컨텍스트 길이는 어느 정도입니까?

iFLYTEK 문서는 이 등급의 컨텍스트 길이를 8,192 토큰, 최대 출력을 8,192 토큰으로 안내합니다. 긴 문서는 질문하기 전에 분할하거나 필요한 부분만 검색해서 넣으세요. 실제 동작은 AnyAIGC에서 테스트 요청으로 확인하세요.

속도 제한(rate limit)이 있습니까?

AnyAIGC는 SparkDesk-v3.1에 동시 실행 제한을 두지 않으며 모든 계정에 기본으로 적용됩니다. 일괄 작업과 병렬 작업도 사용할 수 있습니다. 토큰 단위로 과금하며 월 요금이나 시간대별 할당량은 없습니다.

SparkDesk-v3.1은 지원 중단되었습니까?

현재 iFLYTEK Open Platform 버전 표에는 Pro 등급이 여전히 올라 있습니다. SparkDesk-v3.1은 현재 AnyAIGC 모델 카탈로그에서 호출할 수 있으며, 최신 제공 여부는 카탈로그에서 확인하세요.

SparkDesk-v3.1 API 키는 어떻게 받습니까?

anyaigc.ai에서 가입하고 충전한 뒤 콘솔에서 토큰을 생성하세요. 키 하나로 플랫폼의 300개 이상의 모델을 쓸 수 있으므로 iFLYTEK Open Platform의 APPID, APIKey, APISecret은 필요 없습니다. 요청 본문의 model을 SparkDesk-v3.1로 설정하세요.

AnyAIGC에서 인보이스를 받을 수 있습니까?

네. 콘솔에서 실제 충전한 금액 기준으로 직접 인보이스를 발급할 수 있습니다.

어떤 결제 수단을 지원합니까?

WeChat Pay, Alipay, USDT, 신용카드로 충전할 수 있습니다. 잔액은 USD 기준이며 플랫폼의 모든 모델에서 사용할 수 있습니다. 인보이스는 콘솔에서 충전한 금액 기준으로 발급할 수 있습니다.

신규 사용자에게 무료 체험 크레딧이 있습니까?

네. 신규 계정에는 토큰 200만 개 분량의 체험 크레딧이 제공되므로 충전 여부를 결정하기 전에 먼저 테스트할 수 있습니다. 충전은 $1부터 가능합니다.

잔액을 환불받을 수 있습니까?

네. 사용하지 않은 잔액은 수수료 없이 환불받을 수 있습니다. 환불은 고객 지원에 문의해 진행하세요.

실제 모델이 맞습니까? 데이터는 안전합니까?

요청은 공식 모델 채널로 전달되며, 저가 모델이나 리버스 엔지니어링 방식의 대체 모델은 사용하지 않습니다. 법령에서 요구하는 경우를 제외하고 프롬프트와 출력을 영구 저장하거나 학습에 사용하지 않으며, 콘솔에서 모든 요청의 토큰 수와 비용을 확인할 수 있습니다.

내 프롬프트가 학습에 사용됩니까?

아니요. 법령에서 요구하는 경우를 제외하고 AnyAIGC는 프롬프트와 출력을 영구 저장하지 않으며 학습에도 사용하지 않습니다. 요청은 HTTPS로 암호화됩니다. AnyAIGC 개인정보 처리방침을 참고하세요. 모델 제공사 자체의 데이터 정책은 iFLYTEK의 약관을 따릅니다.
