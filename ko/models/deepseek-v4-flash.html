모델 소개

V4 프리뷰의 경량 모델

DeepSeek는 2026년 4월 V4 프리뷰로 V4 Pro와 V4 Flash 두 모델을 공개했습니다. V4 Flash는 그중 가벼운 모델로, 전체 284B·활성 13B 파라미터의 MoE이며 V4 Pro와 같은 아키텍처를 사용합니다. 컨텍스트 길이는 1M 토큰이고, 가중치는 MIT 라이선스로 공개되어 있습니다.

9월 10일 DeepSeek는 V4.1 Flash를 공개하면서 V4 Flash를 종료했습니다. 호환성을 위해 공식 API는 deepseek-v4-flash 요청을 일시적으로 V4.1 Flash로 처리하고 Flash 가격으로 과금합니다.

코드에서 아직 deepseek-v4-flash를 사용하고 있다면 AnyAIGC에서도 계속 호출할 수 있습니다. 새 프로젝트에서는 모델 이름을 deepseek-v4.1-flash로 바꾸시길 권장합니다. 요금은 같고 이미지 입력도 지원합니다.

빠른 시작

DeepSeek V4 Flash API 시작하기

  1. 가입 및 충전: anyaigc.ai에서 계정을 만듭니다. $1부터 충전할 수 있으며, 잔액은 플랫폼의 모든 모델에서 공통으로 사용됩니다.
  2. API 키 생성: 콘솔에서 키를 생성하고 sk- 키를 복사해 ANYAIGC_API_KEY 환경 변수에 저장합니다.
  3. 요청 보내기: model을 deepseek-v4-flash로 지정하고 Authorization: Bearer 헤더를 포함해 POST https://anyaigc.ai/v1/chat/completions를 호출합니다. OpenAI SDK를 사용한다면 base_url을 https://anyaigc.ai/v1로 설정하면 됩니다.

마이그레이션 팁: deepseek-v4-flash에서 deepseek-v4.1-flash로 옮길 때는 model 필드만 바꾸면 됩니다. 파라미터, 엔드포인트, 인증은 그대로이고 가격도 같습니다.

모든 파라미터는 Chat Completions API 레퍼런스에서 확인하세요. 문서 예제의 모델 이름을 사용하려는 DeepSeek 모델 ID로 바꾸면 됩니다.

Claude Code

Claude Code에서 DeepSeek V4 Flash 사용하기

Claude Code에서 V4 Flash를 사용할 수 있지만, 대신 deepseek-v4.1-flash로 설정하시길 권장합니다. 아래 설정에서 모델 이름만 바꾸면 됩니다.

  1. Claude Code 설치: 공식 설치 프로그램을 사용합니다. macOS 또는 Linux에서는 curl -fsSL https://claude.ai/install.sh | bash를 실행하면 됩니다.
  2. 설정 추가: ~/.claude/settings.json을 열어 아래 env 블록을 추가하고, ANTHROPIC_AUTH_TOKEN 값을 AnyAIGC에서 만든 키로 바꿉니다.
  3. 코딩 시작: 프로젝트 폴더에서 claude를 실행합니다. /model을 입력해 현재 모델이 deepseek-v4-flash인지 확인하세요.

권장: 설정의 deepseek-v4-flash를 모두 deepseek-v4.1-flash로 바꾸세요. 가격은 같고 결과는 더 좋습니다.

전체 절차와 자주 발생하는 오류는 Claude Code 설정 가이드를 참고하세요. 가이드의 모델 이름을 deepseek-v4-flash로 바꿔서 사용하면 됩니다.

제공사는 추론 능력이 V4-Pro에 근접하고, 단순한 에이전트 작업에서는 V4-Pro와 대등한 성능을 내며, 크기는 더 작고 응답은 더 빠르다고 설명합니다.

릴리스 노트에는 1M 컨텍스트 길이가 이제 모든 DeepSeek 공식 서비스의 기본값이라는 내용도 있습니다.

이 페이지의 가격은 입력 $0.1215, 출력 $0.4860, 캐시 히트 $0.0024이며, 위의 가격표와 일치합니다.

deepseek-v4-pro와의 비교: 릴리스 노트는 V4-Pro를 전체 1.6T, 활성 49B의 더 큰 모델로 설명하며, 에이전트 코딩 분야에서 오픈 모델 중 선두라고 밝힙니다.

사양은 제공사의 공식 문서(api-docs.deepseek.com)를 따랐습니다. 이 페이지의 표는 가격 정보이며, 실시간 요금은 모델 카탈로그를 기준으로 합니다.

FAQ

DeepSeek V4 Flash API FAQ

DeepSeek V4 Flash는 서비스가 종료되었습니까?

네. DeepSeek는 2026년 9월 10일 V4.1 Flash를 공개하면서 V4 Flash를 종료했습니다. 호환성을 위해 공식 API는 지금도 deepseek-v4-flash 모델 이름을 받아 V4.1 Flash로 처리하고 Flash 가격으로 과금합니다. 새 프로젝트에서는 deepseek-v4.1-flash를 직접 사용하세요. AnyAIGC에서는 두 모델의 요금이 같습니다.

DeepSeek V4 Flash API 요금은 얼마입니까?

AnyAIGC의 deepseek-v4-flash는 토큰 단위로 과금합니다. 입력 100만 토큰당 $0.1215, 출력 100만 토큰당 $0.4860, 캐시 히트 100만 토큰당 $0.0024로, V4.1 Flash와 같습니다. DeepSeek는 이전 모델명을 Flash 가격으로 과금하며, 비피크 시간에는 입력 $0.15, 출력 $0.60, 캐시 히트 $0.003이고 피크 시간에는 두 배입니다. 실시간 가격은 모델 카탈로그에서 확인할 수 있습니다.

AnyAIGC에도 피크 시간과 비피크 시간 요금제가 있습니까?

아니요. DeepSeek 공식 API는 시간대별 가격을 적용합니다. 평일 UTC 01:00–04:00 및 06:00–10:00(베이징 시간 9:00–12:00, 14:00–18:00)이 피크 시간이며, 피크 가격은 비피크 가격의 두 배입니다. AnyAIGC에서는 deepseek-v4-flash를 하루 종일 같은 요금으로 과금하며, 이 요금은 공식 피크 가격 대비 약 60% 저렴합니다. 실시간 가격은 모델 카탈로그에서 확인할 수 있습니다.

V4 Flash에서 V4.1 Flash로 옮기려면 무엇을 바꿔야 합니까?

요청 본문의 model을 deepseek-v4-flash에서 deepseek-v4.1-flash로 바꾸면 됩니다. 엔드포인트, 인증, 파라미터는 그대로입니다. V4.1 Flash는 이미지 입력이 추가되었으며, DeepSeek는 벤치마크에서 V4 Pro를 앞선다고 밝혔습니다.

V4 Flash의 파라미터 수와 컨텍스트 길이는 얼마입니까?

DeepSeek는 V4 Flash를 전체 284B, 활성 13B 파라미터의 MoE로 소개하며 V4 Pro와 같은 아키텍처를 사용한다고 밝혔습니다. 컨텍스트 길이는 1M 토큰이고, 텍스트 입력만 지원하며, 가중치는 MIT 라이선스로 공개되어 있습니다.

Claude Code에서 DeepSeek V4 Flash를 사용할 수 있습니까?

네. AnyAIGC의 DeepSeek 모델은 OpenAI와 Anthropic API 형식을 모두 지원합니다. ~/.claude/settings.json의 env 블록에서 ANTHROPIC_BASE_URL을 https://anyaigc.ai로, ANTHROPIC_AUTH_TOKEN을 API 키로, ANTHROPIC_MODEL을 deepseek-v4-flash로 설정한 뒤 claude를 실행하세요. 사용한 토큰만큼 과금됩니다.

동시 실행 수나 속도 제한이 있습니까?

AnyAIGC는 deepseek-v4-flash의 동시 실행을 제한하지 않으며, 모든 사용자에게 기본으로 적용됩니다. 배치 작업, CI 파이프라인, 병렬 에이전트에 적합합니다.

DeepSeek V4 Flash API 키는 어떻게 발급받습니까?

anyaigc.ai에서 가입하고 잔액을 충전한 뒤 콘솔에서 키를 만드세요. 같은 키로 모든 DeepSeek 모델과 플랫폼의 다른 300개 이상의 모델을 사용할 수 있으므로 별도의 DeepSeek Platform 계정이 필요 없습니다.

AnyAIGC에서 인보이스를 받을 수 있습니까?

네. 콘솔에서 실제 충전한 금액 기준으로 직접 인보이스를 발급할 수 있습니다.

어떤 결제 수단을 지원합니까?

위챗페이, 알리페이, USDT, 신용카드로 충전할 수 있습니다. 잔액은 USD 기준이며 플랫폼의 모든 모델에서 사용할 수 있습니다. 인보이스는 콘솔에서 충전한 금액 기준으로 발급할 수 있습니다.

신규 사용자에게 무료 체험 크레딧이 있습니까?

네. 신규 계정에는 토큰 200만 개 분량의 체험 크레딧이 제공되므로 충전 여부를 결정하기 전에 먼저 테스트할 수 있습니다. 충전은 $1부터 가능합니다.

잔액을 환불받을 수 있습니까?

네. 사용하지 않은 잔액은 수수료 없이 환불받을 수 있습니다. 환불은 고객 지원에 문의해 진행하세요.

실제 모델이 맞습니까? 데이터는 안전합니까?

요청은 공식 모델 채널로 전달되며, 저가 모델이나 리버스 엔지니어링 방식의 대체 모델은 사용하지 않습니다. 법령에서 요구하는 경우를 제외하고 프롬프트와 출력을 영구 저장하거나 학습에 사용하지 않으며, 콘솔에서 모든 요청의 토큰 수와 비용을 확인할 수 있습니다.
