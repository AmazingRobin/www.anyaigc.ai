Claude Opus 4.7 API FAQ

Claude Opus 4.7 API 가격은 얼마입니까?

AnyAIGC에서 claude-opus-4-7은 토큰 단위로 과금됩니다. 입력 100만 토큰당 $0.6177, 출력 100만 토큰당 $3.088, 5분 캐시 쓰기 $0.7721, 1시간 캐시 쓰기 $1.2350, 캐시 히트 $0.0618입니다. Anthropic의 공식 정가는 입력 $5, 출력 $25이므로 AnyAIGC는 공식 정가의 약 12.4% 수준입니다.

Claude Opus 4.7의 모델 ID는 무엇이며, API는 Anthropic과 호환됩니까?

모델 ID는 claude-opus-4-7이며, 요청 본문의 model 필드에 넣습니다. API는 Anthropic Messages 형식을 따릅니다. 엔드포인트는 https://anyaigc.ai/v1/messages이고, 요청 필드(model, max_tokens, system, messages, tools, cache_control 등)는 그대로이며, 인증은 Authorization: Bearer 뒤에 API 키를 붙입니다. 공식 SDK를 사용한다면 base URL만 https://anyaigc.ai로 설정하면 됩니다.

Claude Code에서 Claude Opus 4.7을 사용할 수 있습니까?

네. ~/.claude/settings.json의 env 블록에서 ANTHROPIC_BASE_URL을 https://anyaigc.ai로, ANTHROPIC_AUTH_TOKEN을 API 키로, ANTHROPIC_MODEL과 ANTHROPIC_DEFAULT_OPUS_MODEL을 모두 claude-opus-4-7로 설정한 뒤 claude를 실행하면 됩니다. 명령어 하나로 설치와 설정을 한 번에 할 수도 있습니다: curl -fsSL https://www.anyaigc.ai/install.sh | bash.

프롬프트 캐싱은 어떻게 과금됩니까?

콘텐츠 블록에 cache_control을 추가하면 캐싱이 활성화됩니다. 첫 쓰기는 캐시 쓰기 요금(100만 토큰당 5분 $0.7721 또는 1시간 $1.2350)으로 과금됩니다. 그 이후 캐시된 토큰은 100만 토큰당 $0.0618만 부과되며, 이는 일반 입력 가격의 약 10%입니다. 캐싱은 긴 시스템 프롬프트, 대규모 코드베이스 컨텍스트, 멀티턴 에이전트 작업에 특히 효과적입니다.

AnyAIGC는 claude-opus-4-7에 동시 실행 제한을 두지 않습니다. 모든 계정에 기본으로 적용되므로 배치 작업이나 여러 에이전트의 병렬 실행에 적합합니다.

Claude Opus 4.7은 어떤 작업에 강하며, Opus 4.6과 어떻게 다릅니까?

Anthropic은 Opus 4.7이 고급 소프트웨어 엔지니어링에서 Opus 4.6보다 눈에 띄게 향상되었고 가장 어려운 작업에서 개선 폭이 가장 크며, 이미지를 더 높은 해상도로 인식할 수 있다고 밝혔습니다. Anthropic이 공개한 결과에서 SWE-bench Verified는 80.8%에서 87.6%로, SWE-bench Pro는 53.4%에서 64.3%로 상승했습니다. 공식 정가는 둘이 같지만, Anthropic은 Claude 4.7 이후 모델이 같은 텍스트에 대해 약 30% 더 많은 토큰을 생성하는 새 토크나이저를 사용한다고 안내하므로, 마이그레이션할 때 실제 사용량을 확인하세요. 어려운 코딩 작업, 장시간 실행 에이전트, 세부 묘사가 중요한 이미지 작업에 적합합니다.

Claude Opus 4.7은 지원이 중단되었습니까? 얼마나 오래 사용할 수 있습니까?

종료되지 않았습니다. Anthropic은 Claude Opus 4.7을 Active (Legacy)로 분류하며 2027년 4월 16일 이전에는 종료하지 않겠다고 약속했으므로, 현재도 정상적으로 동작합니다. 기존 프로젝트는 계속 claude-opus-4-7을 사용할 수 있습니다. 신규 프로젝트에는 Anthropic이 Claude Opus 5.5(claude-opus-5-5)를 권장합니다.

실제 모델이 맞습니까? 데이터는 안전합니까?

요청은 공식 모델 채널로 전달되며, 저가 모델이나 리버스 엔지니어링 방식의 대체 모델은 사용하지 않습니다. 법령에서 요구하는 경우를 제외하고 프롬프트와 출력을 영구 저장하거나 학습에 사용하지 않으며, 콘솔에서 모든 요청의 토큰 수와 비용을 확인할 수 있습니다.

내 데이터가 학습에 사용됩니까?
