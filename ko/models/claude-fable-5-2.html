계획 수립, 수정, 테스트 실행, 결과에 따른 재수정을 반복하며 여러 모듈에 걸친 대규모 마이그레이션과 리팩터링을 처리합니다. Anthropic에 따르면 Fable 5.2 초기 버전으로 구성한 에이전트 팀이 운영 중인 서비스를 Python에서 Rust로 마이그레이션했고, 시작 속도가 약 26배 빨라졌습니다. 캐시 히트는 100만 토큰당 $0.0476에 불과해, 같은 저장소에서 이어지는 긴 세션도 부담이 적습니다.

사양과 선택 기준

Anthropic은 Claude Fable 5.2를 고난도 추론과 장기 에이전트 작업용 모델로 소개하며, 2026년 11월 9일에 출시되었습니다.

Anthropic이 제시하는 대표적인 용도는 수 시간 동안 실행되는 에이전트 세션, 여러 단계의 심층 리서치, 그리고 완성된 문서, 스프레드시트, 슬라이드 덱까지 이어지는 분석입니다.

컨텍스트 길이는 1M 토큰, 출력은 요청당 최대 128K 토큰이며, 상대적 지연 시간은 Moderate로 평가됩니다.

사고는 적응형이며 항상 켜져 있고, 기본 추론 강도(effort)는 high이며, 신뢰할 수 있는 지식 컷오프는 2026년 6월입니다.

이 페이지의 가격은 입력 $1.9060, 출력 $9.5290, 5분 캐시 쓰기 $2.3820, 1시간 캐시 쓰기 $3.8120이며, 위 가격표와 일치합니다.

claude-opus-5-5와 비교: Claude Opus 5.5와 컨텍스트 길이, 최대 출력, 지연 시간 등급은 같지만, 기본 추론 강도는 Fable 5.2가 high, Opus 5.5가 medium입니다.

사양은 공급업체의 공식 문서(platform.claude.com)를 따릅니다. 이 페이지의 표는 가격이며, 실시간 요금은 모델 카탈로그가 기준입니다.

AnyAIGC에서 claude-fable-5-2는 토큰 단위로 과금됩니다. 100만 토큰당 입력 $1.906, 출력 $9.529, 5분 캐시 쓰기 $2.3820, 1시간 캐시 쓰기 $3.8120, 캐시 히트 $0.0476입니다. Anthropic 공식 정가는 입력 $8, 출력 $40, 캐시 히트 $0.20이므로 AnyAIGC 가격은 공식 정가의 약 23.8%, 즉 대략 76% 할인된 수준입니다.

Claude Fable 5.2의 모델 ID는 무엇입니까?

모델 ID는 claude-fable-5-2입니다. 요청 본문의 model 필드에 넣으세요.

Claude Fable 5.2는 Fable 5.1과 무엇이 다릅니까?

Anthropic은 2026년 11월 9일에 Fable 5.2를 출시했습니다. 공식 정가는 입력 $10, 출력 $50에서 $8과 $40으로 내려갔고, 출력은 최대 30% 더 빠르며, Medium 추론 강도에서 어려운 문제를 풀 때 더 적은 토큰을 사용하고, 안전 분류기가 정상 요청을 차단하는 비율은 Fable 5.1보다 약 55% 낮습니다. 벤치마크에서는 FrontierSWE v2가 56.3%에서 69.9%로, Remote Labor Index가 17.9%에서 41.3%로 올랐습니다. 두 모델 모두 AnyAIGC에서 사용할 수 있으며, Fable 5.2는 입력 100만 토큰당 $1.906으로 Fable 5.1의 $2.382보다 저렴합니다.

AnyAIGC Claude API는 Anthropic 공식 API와 호환됩니까?

네. 엔드포인트는 https://anyaigc.ai/v1/messages이며 요청 본문은 Anthropic Messages 형식(model, max_tokens, system, messages, tools, cache_control 등)을 따릅니다. 인증은 Authorization: Bearer 뒤에 API 키를 붙여 사용합니다. 공식 SDK를 사용한다면 base URL만 https://anyaigc.ai로 설정하면 됩니다.

Claude Code에서 Claude Fable 5.2를 사용할 수 있습니까?

네. ~/.claude/settings.json의 env 블록에서 ANTHROPIC_BASE_URL을 https://anyaigc.ai로, ANTHROPIC_AUTH_TOKEN을 API 키로, ANTHROPIC_MODEL과 ANTHROPIC_DEFAULT_OPUS_MODEL을 모두 claude-fable-5-2로 설정한 뒤 claude를 실행하세요. 한 번의 명령으로 설치와 설정을 마칠 수도 있습니다: curl -fsSL https://www.anyaigc.ai/install.sh | bash -s claude.

프롬프트 캐싱은 어떻게 과금됩니까?

콘텐츠 블록에 cache_control을 추가하면 캐싱이 활성화됩니다. 첫 쓰기는 캐시 쓰기 요금(100만 토큰당 5분 $2.3820, 1시간 $3.8120)으로 과금됩니다. 이후 캐시된 토큰은 100만 토큰당 $0.0476만 들며, 이는 일반 입력 가격의 약 2.5%입니다. 같은 컨텍스트를 반복해서 읽는 장시간 실행 에이전트에 가장 유리합니다.

동시 실행 수나 속도 제한이 있습니까?

AnyAIGC는 claude-fable-5-2에 동시 실행 제한을 두지 않습니다. 모든 계정에 기본으로 적용되므로 배치 작업과 여러 에이전트의 병렬 실행에 적합합니다.

Claude Fable 5.2는 어떤 작업에 적합하며, Opus 5.5 대신 선택해야 합니까?

Anthropic은 Fable 5.2가 수 시간 이어지는 에이전트 코딩, 여러 단계의 리서치, 데이터 중심 분석처럼 가장 야심 찬 개방형 기술 작업에 가장 적합하다고 설명합니다. 어려운 문제에서 Haiku, Sonnet, Opus가 조언을 구하는 어드바이저(Advisor)나, 단순한 작업을 작은 모델에 넘기는 오케스트레이터(Orchestrator)로도 쓸 수 있습니다. Anthropic은 대부분의 코딩과 지식 업무에는 Claude Opus 5.5로 시작하고, 필요할 때 Fable 5.2로 올릴 것을 권장합니다. 두 모델은 같은 AnyAIGC 키로 사용할 수 있으므로 model 필드만 바꿔 작업별로 전환할 수 있습니다.

Claude Fable 5.2 API 키는 어떻게 받습니까?

anyaigc.ai에서 가입하고 잔액을 충전한 뒤 콘솔에서 토큰을 생성하세요. 같은 키로 Claude Fable 5.2와 플랫폼의 300개 이상 다른 모델을 모두 사용할 수 있습니다.

AnyAIGC에서 인보이스를 받을 수 있습니까?

네. 콘솔에서 실제 충전한 금액 기준으로 직접 인보이스를 발급할 수 있습니다.

어떤 결제 수단을 지원합니까?

WeChat Pay, Alipay, USDT, 신용카드로 충전할 수 있습니다. 잔액은 USD 기준이며 플랫폼의 모든 모델에서 사용할 수 있습니다. 인보이스는 콘솔에서 충전한 금액 기준으로 발급할 수 있습니다.

신규 사용자에게 무료 체험 크레딧이 있습니까?

네. 신규 계정에는 토큰 500만 개 분량의 체험 크레딧이 제공되므로 충전 여부를 결정하기 전에 먼저 테스트할 수 있습니다. 충전은 $1부터 가능합니다.

잔액을 환불받을 수 있습니까?

네. 사용하지 않은 잔액은 수수료 없이 환불받을 수 있습니다. 환불은 고객 지원에 문의해 진행하세요.

실제 모델이 맞습니까? 데이터는 안전합니까?

요청은 공식 모델 채널로 전달되며, 저가 모델이나 리버스 엔지니어링 방식의 대체 모델은 사용하지 않습니다. 법령에서 요구하는 경우를 제외하고 프롬프트와 출력을 영구 저장하거나 학습에 사용하지 않으며, 콘솔에서 모든 요청의 토큰 수와 비용을 확인할 수 있습니다.

내 데이터가 학습에 사용됩니까?

요청은 HTTPS로 전송 중 암호화됩니다. 데이터 처리에 관한 자세한 내용은 AnyAIGC 개인정보 처리방침을 참고하세요. 모델 자체의 데이터 정책은 Anthropic 공식 약관을 따릅니다. Anthropic에 따르면 제로 데이터 보존(ZDR)을 적용하지 않은 경우 안전 모니터링을 위해 Fable 5.2 데이터를 30일간 보관합니다.
