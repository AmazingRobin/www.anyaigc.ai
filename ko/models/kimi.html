빠른 시작

세 단계로 Kimi API에 연결하기

  1. 가입 및 충전: anyaigc.ai에서 계정을 만듭니다. $1부터 충전할 수 있으며, 잔액은 플랫폼의 모든 모델에서 공통으로 사용됩니다.
  2. API 키 만들기: 콘솔에서 키를 만들고 sk-로 시작하는 값을 복사해 ANYAIGC_API_KEY 환경 변수에 저장하세요.
  3. 요청 보내기: model을 kimi-k3.1-pro로 지정하고 Authorization: Bearer 헤더를 붙여 POST https://anyaigc.ai/v1/chat/completions를 호출하세요. OpenAI SDK에서는 base_url만 https://anyaigc.ai/v1로 설정하면 됩니다.

팁: Kimi는 추론 내용을 reasoning_content 필드로 반환합니다. 스트리밍 시에는 추론 델타가 먼저 오고 그 뒤에 최종 답변이 옵니다. 멀티턴 대화와 도구 호출에서는 API가 반환한 어시스턴트 메시지 전체(reasoning_content와 tool_calls 포함)를 다음 요청에 그대로 다시 보내세요.

모든 파라미터는 Chat Completions 레퍼런스를 참고하세요. 문서 예제의 모델 이름을 사용할 Kimi 모델 ID로 바꾸세요.

Claude Code

Claude Code에서 Kimi 사용하기

설정 파일 하나만 수정하면 Claude Code를 Kimi로 전환할 수 있으며, 터미널의 코딩 에이전트가 Kimi로 실행됩니다.

  1. Claude Code 설치: 공식 설치 프로그램을 사용하세요(예: npm install -g @anthropic-ai/claude-code).
  2. 설정 추가: ~/.claude/settings.json을 열어 아래 env 블록을 추가하고, ANTHROPIC_AUTH_TOKEN 값을 AnyAIGC에서 만든 키로 바꿉니다.
  3. 코딩 시작: 프로젝트 폴더에서 claude를 실행하세요. /model을 입력해 현재 모델이 kimi-k3.1-pro인지 확인합니다.

모델 전환: 더 저렴한 코딩 모델을 쓰려면 설정의 kimi-k3.1-pro를 모두 kimi-k2.7-code로 바꾸세요. K3.1 Pro는 대규모 저장소용 1M 컨텍스트 길이를 제공하고, K2.7 Code는 비용이 약 절반입니다.

전체 절차와 자주 발생하는 오류는 Claude Code 설정 가이드를 참고하세요. 가이드의 모델 이름을 kimi-k3.1-pro로 바꿔 사용하세요.

Kimi API 요금은 얼마입니까?

AnyAIGC의 Kimi 모델은 토큰 단위로 과금됩니다. 100만 토큰당 요금은 kimi-k3.1-pro 입력 $0.8100, 출력 $4.0500, 캐시 히트 $0.0810, kimi-k3 입력 $1.2150, 출력 $6.0750, 캐시 히트 $0.1215, kimi-k2.7-code 입력 $0.3847, 출력 $1.5980, 캐시 히트 $0.0770, kimi-k2.6 입력 $0.3847, 출력 $1.5980, 캐시 히트 $0.0651입니다. Moonshot 공식 USD 가격의 약 40%입니다. 실시간 가격은 모델 카탈로그를 참고하세요.

AnyAIGC에서 쓸 수 있는 Kimi 모델은 무엇이고, 모델 ID는 무엇입니까?

이 페이지는 네 가지를 다룹니다. kimi-k3.1-pro(K3.1 시리즈의 첫 모델, 1M 컨텍스트 길이), kimi-k3(이전 세대 플래그십, 2.8T 파라미터 오픈 웨이트 모델), kimi-k2.7-code(코딩 에이전트 모델), kimi-k2.6(범용 멀티모달 에이전트 모델)입니다. 모델 ID는 요청 본문의 model 필드에 넣으세요. 모델을 바꿀 때는 이 필드 하나만 바꾸면 됩니다.

Kimi K3.1 Pro, K3, K2.7 Code, K2.6 중 무엇을 써야 합니까?

1M 컨텍스트 길이, 가장 어려운 장기 코딩, 3D 제작, 금융 리서치가 필요하면 Kimi K3.1 Pro를 선택하세요. 최신 세대이며 K3보다 약 3분의 1 저렴합니다. 이미 K3에서 돌리는 워크로드는 그대로 두어도 됩니다. 일상적인 코딩과 코딩 에이전트에는 K2.7 Code를 선택하세요. Moonshot에 따르면 Kimi Code Bench v2에서 K2.6보다 21.8% 높은 점수를 기록했습니다. 비사고 모드, 빠른 응답, 일반 대화가 필요하면 K2.6을 선택하세요. K2.7 Code와 K2.6은 가격이 같으며, K3.1 Pro의 약 절반입니다.

Kimi API는 OpenAI 호환입니까?

예. 네 모델 모두 POST https://anyaigc.ai/v1/chat/completions를 사용하며, 요청과 응답 형식은 OpenAI Chat Completions와 같습니다. 공식 OpenAI SDK에서는 base_url을 https://anyaigc.ai/v1로 설정하세요. 추론 내용은 reasoning_content 필드로 반환됩니다.

Claude Code에서 Kimi를 사용할 수 있습니까?

네. ~/.claude/settings.json의 env 블록에서 ANTHROPIC_BASE_URL을 https://anyaigc.ai로, ANTHROPIC_AUTH_TOKEN을 API 키로, ANTHROPIC_MODEL을 kimi-k3.1-pro로 설정한 다음 claude를 실행하세요.

컨텍스트 길이는 얼마입니까?

Moonshot에 따르면 Kimi K3.1 Pro와 K3는 1,048,576 토큰 컨텍스트 길이를, K2.7 Code와 K2.6은 262,144 토큰(256K)을 지원합니다. 네 모델 모두 이미지 입력을 받고 도구 호출을 지원합니다.

Kimi 모델은 오픈 소스입니까? 상업적으로 사용할 수 있습니까?

Moonshot AI는 Kimi K3, K2.7 Code, K2.6의 가중치를 Hugging Face에 공개했으며, K3.1 Pro의 전체 가중치는 2026년 11월 4일까지 공개한다고 밝혔습니다. AnyAIGC를 통해 API로 호출하면 직접 호스팅할 필요가 없습니다. 모델 라이선스와 상업적 사용은 Moonshot AI의 공식 약관을 따릅니다.

동시 실행 수나 속도 제한이 있습니까?

AnyAIGC는 Kimi 모델의 동시 실행을 제한하지 않으며, 모든 사용자에게 기본으로 적용됩니다. 배치 작업, CI 파이프라인, 병렬 에이전트에 적합합니다. Moonshot 자체 플랫폼은 충전 등급에 따라 동시 실행, RPM, TPM, TPD를 제한하지만, AnyAIGC를 통해 호출할 때는 이 등급이 적용되지 않습니다.

Kimi API 키는 어떻게 받습니까?

anyaigc.ai에 가입하고 잔액을 충전한 뒤 콘솔에서 키를 만드세요. 같은 키로 모든 Kimi 모델과 플랫폼의 다른 300개 이상의 모델을 호출할 수 있으므로 별도의 Moonshot 플랫폼 계정이 필요 없습니다.

AnyAIGC에서 인보이스를 받을 수 있습니까?

네. 콘솔에서 실제 충전한 금액 기준으로 직접 인보이스를 발급할 수 있습니다.

어떤 결제 수단을 지원합니까?

WeChat Pay, Alipay, USDT, 신용카드로 충전할 수 있습니다. 잔액은 USD 기준이며 플랫폼의 모든 모델에서 사용할 수 있습니다. 인보이스는 콘솔에서 충전한 금액 기준으로 발급할 수 있습니다.

신규 사용자에게 무료 체험 크레딧이 있습니까?

네. 신규 계정에는 토큰 200만 개 분량의 체험 크레딧이 제공되므로 충전 여부를 결정하기 전에 먼저 테스트할 수 있습니다. 충전은 $1부터 가능합니다.

잔액을 환불받을 수 있습니까?

네. 사용하지 않은 잔액은 수수료 없이 환불받을 수 있습니다. 환불은 고객 지원에 문의해 진행하세요.

실제 모델이 맞습니까? 데이터는 안전합니까?

요청은 공식 모델 채널로 전달되며, 저가 모델이나 리버스 엔지니어링 방식의 대체 모델은 사용하지 않습니다. 법령에서 요구하는 경우를 제외하고 프롬프트와 출력을 영구 저장하거나 학습에 사용하지 않으며, 콘솔에서 모든 요청의 토큰 수와 비용을 확인할 수 있습니다.

내 데이터가 학습에 사용됩니까?

아니요. 법령에서 요구하는 경우를 제외하고 AnyAIGC는 프롬프트와 출력을 영구 저장하지 않으며 모델 학습에도 사용하지 않습니다. 요청은 HTTPS로 암호화됩니다. AnyAIGC 개인정보 처리방침을 참고하세요. 모델 자체의 데이터 정책은 Moonshot AI의 공식 약관을 따릅니다.
