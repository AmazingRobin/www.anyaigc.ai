소개

범용 오픈 멀티모달 에이전트 모델

Moonshot AI는 Kimi K2.6을 오픈 네이티브 멀티모달 에이전트 모델로 소개합니다. Moonshot에 따르면 긴 코드를 더 능숙하고 일관되게 작성하며, 지시 따르기와 자기 수정이 눈에 띄게 개선되었습니다. 텍스트와 이미지 입력을 받고 사고 모드와 비사고 모드를 갖추고 있어 채팅과 에이전트 작업 모두에 사용할 수 있습니다.

내부적으로는 총 1T, 활성 32B 파라미터의 MoE이며, 컨텍스트 길이 256K와 네이티브 INT4 양자화를 지원합니다. Moonshot은 네 가지 영역을 강조합니다. 장시간 코딩, 프롬프트나 이미지에서 만드는 UI(Coding-Driven Design), 최대 300개 서브 에이전트로 확장하는 Agent Swarm, 24/7로 실행되는 능동형 에이전트입니다.

AnyAIGC에서 kimi-k2.6은 OpenAI 호환 /v1/chat/completions 엔드포인트로 실행되며 Claude Code에서 바로 사용할 수 있고, 동시 실행 제한이 없습니다.

빠른 시작

세 단계로 Kimi K2.6 API 연동하기

  1. 가입 및 충전: anyaigc.ai에서 계정을 만듭니다. $1부터 충전할 수 있으며, 잔액은 플랫폼의 모든 모델에서 공통으로 사용됩니다.
  2. API 키 만들기: 콘솔에서 키를 만들고 sk-로 시작하는 값을 복사해 ANYAIGC_API_KEY 환경 변수에 저장하세요.
  3. 요청 보내기: model을 kimi-k2.6으로 설정하고 Authorization: Bearer 헤더를 붙여 POST https://anyaigc.ai/v1/chat/completions를 호출하세요. OpenAI SDK에서는 base_url만 https://anyaigc.ai/v1로 설정하면 됩니다.

팁: K2.6은 기본적으로 사고 모드로 동작하며, 추론 내용은 reasoning_content로 반환됩니다. Moonshot API에서는 thinking: {"type": "disabled"}로 사고 모드를 끌 수 있습니다(OpenAI SDK에서는 extra_body로 전달). 비사고 모드에서는 Moonshot이 temperature=0.6을 권장합니다. 사고 모드에서 멀티턴 대화와 도구 호출을 할 때는 어시스턴트 메시지 전체를 수정하지 않고 다음 요청에 그대로 다시 보내세요.

모든 파라미터는 Chat Completions 레퍼런스를 참고하세요. 문서 예제의 모델 이름을 사용할 Kimi 모델 ID로 바꾸세요.

Claude Code

Claude Code에서 Kimi K2.6 사용하기

Claude Code를 Kimi K2.6으로 전환하세요. 멀티모달이면서 비용이 낮아 일상적인 코딩과 스크린샷 기반 UI 수정에 적합합니다.

  1. Claude Code 설치: 공식 설치 프로그램을 사용하세요(예: npm install -g @anthropic-ai/claude-code).
  2. 설정 추가: ~/.claude/settings.json을 열어 아래 env 블록을 추가하고, ANTHROPIC_AUTH_TOKEN 값을 AnyAIGC에서 만든 키로 바꿉니다.
  3. 코딩 시작: 프로젝트 폴더에서 claude를 실행하세요. /model을 입력해 현재 모델이 kimi-k2.6인지 확인하세요.

코딩 모델로 전환: 코딩 성공률을 더 높이려면 설정의 kimi-k2.6을 kimi-k2.7-code로 바꾸세요. 두 모델의 가격은 같습니다.

전체 절차와 자주 발생하는 오류는 Claude Code 설정 가이드를 참고하세요. 가이드의 모델 이름을 kimi-k2.6으로 바꾸세요.

Kimi K2.6 API 요금은 얼마입니까?

AnyAIGC에서 kimi-k2.6은 토큰 단위로 과금됩니다. 입력 100만 토큰당 $0.3847, 출력 100만 토큰당 $1.5980, 캐시 히트 100만 토큰당 $0.0651입니다. Moonshot의 공식 USD 정가는 입력 $0.95, 출력 $4.00, 캐시 히트 $0.16이므로 AnyAIGC는 공식 정가의 약 40%입니다. 실시간 가격은 모델 카탈로그에서 확인하세요.

Kimi K2.6의 모델 ID와 컨텍스트 길이는 어떻게 됩니까?

모델 ID는 kimi-k2.6입니다. Moonshot은 262,144토큰(256K)의 컨텍스트 길이와 텍스트·이미지 입력을 지원한다고 명시합니다.

Kimi K2.6에서 사고 모드를 끌 수 있습니까?

K2.6은 사고 모드와 비사고(Instant) 모드를 모두 지원합니다. Moonshot API에서는 thinking: {"type": "disabled"}로 사고 모드를 끄며, OpenAI SDK에서는 extra_body로 전달합니다. Moonshot은 사고 모드에 temperature=1.0, 비사고 모드에 temperature=0.6을 권장하며, top_p는 둘 다 0.95입니다.

Kimi K2.6의 특징은 무엇입니까?

Moonshot은 K2.6을 네 가지 중점 영역을 가진 오픈 네이티브 멀티모달 에이전트 모델로 소개합니다. 장시간 코딩(Rust, Go, Python, 프런트엔드, DevOps, 성능 튜닝), 프롬프트나 이미지로 만드는 프로덕션 수준 UI, Agent Swarm(서브 에이전트 300개, 조율된 단계 4,000개까지 확장), 그리고 백그라운드에서 24/7 실행되는 능동형 에이전트입니다.

Kimi K2.6과 K2.7 Code 중 무엇을 써야 합니까?

두 모델은 아키텍처가 같고 AnyAIGC에서 입력과 출력 가격도 같습니다. K2.7 Code는 K2.6을 코딩용으로 추가 학습한 모델로, 코딩 점수가 더 높고 사고 토큰이 더 적지만 사고 모드로만 동작합니다. K2.6은 사고 모드를 끌 수 있어 빠른 채팅, 분류, 추출, 범용 에이전트에 적합합니다.

Claude Code에서 Kimi K2.6을 쓸 수 있습니까?

네. ~/.claude/settings.json의 env 블록에서 ANTHROPIC_BASE_URL을 https://anyaigc.ai로, ANTHROPIC_AUTH_TOKEN을 API 키로, ANTHROPIC_MODEL을 kimi-k2.6으로 설정한 뒤 claude를 실행하세요.

Kimi K2.6은 도구 호출과 이미지 입력을 지원합니까?

네. K2.6은 다단계 도구 호출, 스트리밍, 이미지 입력을 지원합니다. 사고 모드에서 멀티턴 대화와 도구 호출을 할 때는 어시스턴트 메시지 전체(reasoning_content와 tool_calls 포함)를 수정하지 않고 다음 요청에 그대로 다시 보내세요.

동시 실행 수나 속도 제한이 있습니까?

AnyAIGC는 kimi-k2.6의 동시 실행을 제한하지 않으며, 모든 사용자에게 기본으로 적용됩니다. 배치 작업, CI 파이프라인, 병렬 에이전트에 적합합니다. Moonshot 자체 플랫폼은 충전 등급에 따라 동시 실행, RPM, TPM, TPD를 제한하지만, AnyAIGC를 통해 호출할 때는 이 등급이 적용되지 않습니다.

Kimi K2.6 API 키는 어떻게 받습니까?

anyaigc.ai에 가입하고 잔액을 충전한 뒤 콘솔에서 키를 만드세요. 같은 키로 모든 Kimi 모델과 플랫폼의 다른 300개 이상의 모델을 호출할 수 있으므로 별도의 Moonshot 플랫폼 계정이 필요 없습니다.

AnyAIGC에서 인보이스를 받을 수 있습니까?

네. 콘솔에서 실제 충전한 금액 기준으로 직접 인보이스를 발급할 수 있습니다.

어떤 결제 수단을 지원합니까?

WeChat Pay, Alipay, USDT, 신용카드로 충전할 수 있습니다. 잔액은 USD 기준이며 플랫폼의 모든 모델에서 사용할 수 있습니다. 인보이스는 콘솔에서 충전한 금액 기준으로 발급할 수 있습니다.

신규 사용자에게 무료 체험 크레딧이 있습니까?

네. 신규 계정에는 토큰 500만 개 분량의 체험 크레딧이 제공되므로 충전 여부를 결정하기 전에 먼저 테스트할 수 있습니다. 충전은 $1부터 가능합니다.

잔액을 환불받을 수 있습니까?

네. 사용하지 않은 잔액은 수수료 없이 환불받을 수 있습니다. 환불은 고객 지원에 문의해 진행하세요.

실제 모델이 맞습니까? 데이터는 안전합니까?

요청은 공식 모델 채널로 전달되며, 저가 모델이나 리버스 엔지니어링 방식의 대체 모델은 사용하지 않습니다. 법령에서 요구하는 경우를 제외하고 프롬프트와 출력을 영구 저장하거나 학습에 사용하지 않으며, 콘솔에서 모든 요청의 토큰 수와 비용을 확인할 수 있습니다.

내 데이터가 학습에 사용됩니까?

아니요. 법령에서 요구하는 경우를 제외하고 AnyAIGC는 프롬프트와 출력을 영구 저장하지 않으며 모델 학습에도 사용하지 않습니다. 요청은 HTTPS로 암호화됩니다. AnyAIGC 개인정보 처리방침을 참고하세요. 모델 자체의 데이터 정책은 Moonshot AI의 공식 약관을 따릅니다.
