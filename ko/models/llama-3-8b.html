Python
import json
import os
import urllib.request

payload = {
  "model": "llama-3-8b",
  "messages": [
    {
      "role": "user",
      "content": "Explain what an API is in three sentences."
    }
  ],
  "n": 1,
  "stream": False
}
request = urllib.request.Request(
    "https://anyaigc.ai/v1/chat/completions",
    data=json.dumps(payload, ensure_ascii=False).encode("utf-8"),
    headers={
        "Authorization": "Bearer " + os.environ["ANYAIGC_API_KEY"],
        "Content-Type": "application/json",
    },
    method="POST",
)
with urllib.request.urlopen(request, timeout=120) as response:
    result = json.load(response)

print(json.dumps(result, ensure_ascii=False, indent=2))

cURL 예제는 Bash / zsh 문법을 사용하고, Python은 표준 라이브러리만 사용합니다. n=1, stream=false이면 응답의 choices에 응답 후보 1개와 usage가 포함됩니다. SSE 출력을 받으려면 stream=true로 설정하세요.

사양과 선택 기준

파라미터 수, 컨텍스트 길이, 가장 가까운 대안과의 비교.

Llama 3 모델: 8B 파라미터, 8,192 토큰 컨텍스트 길이.

Meta의 모델 카드에 따르면 컨텍스트 길이는 8,192 토큰이고 출시일은 2024-04입니다.

이 페이지에는 입력 100만 토큰당 $1.3500, 출력 100만 토큰당 $1.3500이 표시되어 있으며, 위 가격표와 같은 수치입니다.

Llama 3.1 8B와 나란히 비교해 보고, 같은 8B 크기에서 컨텍스트 길이를 8,192에서 131,072로 늘리고 싶다면 해당 모델을 선택하세요.

이 사양은 Meta 공식 모델 카드에서 가져왔습니다. 이 페이지의 표는 가격 안내이며, 실시간 요금은 모델 카탈로그가 기준입니다.

Llama 3 8B API 가격은 얼마입니까?

입력은 100만 토큰당 $1.3500, 출력은 100만 토큰당 $1.3500이며 USD 기준입니다. 할인 표시가 있는 모델은 모델 카탈로그에 표시된 대로 32% 저렴합니다. 게시된 요금에는 이미 할인이 반영되어 있으니 다시 적용하지 마세요. 실시간 요금은 모델 카탈로그에서 확인하세요.

Llama와 Ollama는 어떤 관계입니까? 어떤 버전이 있습니까?

Meta가 Llama 모델 계열을 개발합니다. Ollama는 모델 런타임이며 AnyAIGC 모델 카탈로그에서 쓰는 제공자 분류입니다. 이 가이드는 Llama 2, 3, 3.1, 3.2, 3.3의 12개 모델을 다룹니다. 상업적 사용은 Meta 공식 약관을 따릅니다.

어떤 모델 ID를 보내야 하며, 요청은 무엇을 반환합니까?

llama-3-8b와 Bearer API 키 인증으로 POST /v1/chat/completions를 사용하세요. 예제는 n=1, stream=false로 설정해 어시스턴트 응답 후보 1개와 토큰 사용량을 반환받습니다. 이 개요 페이지에서는 llama라는 이름을 사용합니다.

동시 실행이나 RPM에 제한이 있습니까? Ollama를 설치해야 합니까?

모든 사용자는 기본적으로 동시 실행 제한이 없고 고정 RPM 상한도 없습니다. Ollama를 설치하거나 모델을 로컬에 배포하지 않고 AnyAIGC 클라우드 API를 호출하세요. 다만 애플리케이션에서 네트워크 타임아웃과 API 오류는 처리해야 합니다.

이미지를 받는 모델은 무엇입니까? 지원 언어는 어떻게 됩니까?

Llama 3.2 Vision Instruct의 11B와 90B는 비전 모델이고, 나머지 목록의 모델은 텍스트 모델입니다. Llama 3.1~3.3은 중국어를 제외한 8개 텍스트 언어를 공식 지원합니다. 이미지-텍스트 작업은 영어를 공식 지원합니다. 다른 언어는 직접 데이터로 평가하세요. 이 예제는 텍스트 요청을 보여 줍니다.

AnyAIGC에서 인보이스를 받을 수 있습니까?

네. 콘솔에서 실제 충전한 금액 기준으로 직접 인보이스를 발급할 수 있습니다.

어떤 결제 수단을 지원합니까?

WeChat Pay, Alipay, USDT, 신용카드로 충전할 수 있습니다. 잔액은 USD 기준이며 플랫폼의 모든 모델에서 사용할 수 있습니다. 인보이스는 콘솔에서 충전한 금액 기준으로 발급할 수 있습니다.

신규 사용자에게 무료 체험 크레딧이 있습니까?

네. 신규 계정에는 토큰 200만 개 분량의 체험 크레딧이 제공되므로 충전 여부를 결정하기 전에 먼저 테스트할 수 있습니다. 충전은 $1부터 가능합니다.

잔액을 환불받을 수 있습니까?

네. 사용하지 않은 잔액은 수수료 없이 환불받을 수 있습니다. 환불은 고객 지원에 문의해 진행하세요.

실제 모델이 맞습니까? 데이터는 안전합니까?

요청은 공식 모델 채널로 전달되며, 저가 모델이나 리버스 엔지니어링 방식의 대체 모델은 사용하지 않습니다. 법령에서 요구하는 경우를 제외하고 프롬프트와 출력을 영구 저장하거나 학습에 사용하지 않으며, 콘솔에서 모든 요청의 토큰 수와 비용을 확인할 수 있습니다.
