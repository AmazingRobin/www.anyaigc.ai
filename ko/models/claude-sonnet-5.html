Claude Sonnet 5 API FAQ

Claude Sonnet 5 API 가격은 얼마입니까?

AnyAIGC에서 claude-sonnet-5는 토큰 단위로 과금됩니다. 입력 100만 토큰당 $0.2471, 출력 100만 토큰당 $1.235, 5분 캐시 쓰기 $0.3088, 1시간 캐시 쓰기 $0.4941, 캐시 히트 $0.0247입니다. Anthropic 공식 정가는 입력 $2, 출력 $10이므로 AnyAIGC 가격은 공식 정가의 약 12.4%입니다.

Claude Sonnet 5의 모델 ID는 무엇이며, API는 Anthropic과 호환됩니까?

모델 ID는 claude-sonnet-5이며, 요청 본문의 model 필드에 넣으면 됩니다. API는 Anthropic과 호환됩니다. 엔드포인트는 https://anyaigc.ai/v1/messages이고, 요청 본문은 Anthropic Messages 형식(model, max_tokens, system, messages, tools, cache_control 등)을 따릅니다. 인증은 Authorization: Bearer 뒤에 API 키를 넣어 진행합니다. 공식 SDK에서는 base URL을 https://anyaigc.ai로 설정하기만 하면 됩니다.

Claude Code에서 Claude Sonnet 5를 사용할 수 있습니까?

네. ~/.claude/settings.json의 env 블록에서 ANTHROPIC_BASE_URL을 https://anyaigc.ai로, ANTHROPIC_AUTH_TOKEN을 API 키로, ANTHROPIC_MODEL과 ANTHROPIC_DEFAULT_SONNET_MODEL을 모두 claude-sonnet-5로 설정한 뒤 claude를 실행하면 됩니다. 명령 한 줄로 설치와 설정을 한 번에 끝낼 수도 있습니다: curl -fsSL https://www.anyaigc.ai/install.sh | bash.

프롬프트 캐싱은 어떻게 과금됩니까?

캐싱을 켜려면 콘텐츠 블록에 cache_control을 추가합니다. 첫 쓰기는 캐시 쓰기 요금(5분 $0.3088, 1시간 $0.4941, 100만 토큰당)으로 과금됩니다. 이후 캐시된 토큰은 100만 토큰당 $0.0247만 부과되며, 이는 일반 입력 가격의 약 10%입니다. 캐싱은 긴 시스템 프롬프트, 코드베이스 컨텍스트, 멀티 턴 에이전트 작업에서 효과가 큽니다.

AnyAIGC는 claude-sonnet-5에 동시 실행 제한을 두지 않습니다. 모든 계정에 기본으로 적용되므로 배치 작업이나 여러 에이전트의 병렬 실행에 적합합니다.

Claude Sonnet 5는 어떤 작업에 강합니까?

Anthropic에 따르면 Sonnet 5는 계획을 세우고, 브라우저와 터미널 같은 도구를 사용하며, 자율적으로 작업을 수행할 수 있고, 더 낮은 가격으로 Opus 4.8에 가까운 성능을 냅니다. 일상적인 코딩과 버그 수정, 에이전트형 도구 사용, 컴퓨터 사용(computer use), 문서 중심의 지식 업무에 적합합니다. Anthropic이 공개한 결과에서는 SWE-bench Pro 63.2%, Terminal-Bench 2.1 80.4%를 기록했습니다.

Claude Sonnet 5는 지원이 중단되었습니까? 얼마나 오래 사용할 수 있습니까?

지원이 중단되지 않았습니다. Anthropic은 Claude Sonnet 5를 이전 세대 모델(Active · Legacy)로 분류하며, 2027년 6월 30일보다 빨리 종료하지 않겠다고 밝혔습니다. 지금도 AnyAIGC에서 claude-sonnet-5를 호출할 수 있습니다. 새 프로젝트에는 Anthropic의 최신 모델인 Claude Sonnet 5.5(claude-sonnet-5-5)를 권장합니다.

Claude Sonnet 5 API 키는 어떻게 받습니까?

anyaigc.ai에서 가입하고 잔액을 충전한 뒤, 콘솔에서 토큰을 만드세요. 같은 키로 Claude Sonnet 5와 플랫폼의 다른 300개 이상 모델을 모두 사용할 수 있습니다.

AnyAIGC에서 인보이스를 받을 수 있습니까?

네. 콘솔에서 실제 충전한 금액 기준으로 직접 인보이스를 발급할 수 있습니다.

어떤 결제 수단을 지원합니까?

WeChat Pay, Alipay, USDT, 신용카드로 충전할 수 있습니다. 잔액은 USD 기준이며 플랫폼의 모든 모델에서 사용할 수 있습니다. 인보이스는 콘솔에서 충전한 금액 기준으로 발급할 수 있습니다.

신규 사용자에게 무료 체험 크레딧이 있습니까?

네. 신규 계정에는 토큰 500만 개 분량의 체험 크레딧이 제공되므로 충전 여부를 결정하기 전에 먼저 테스트할 수 있습니다. 충전은 $1부터 가능합니다.

잔액을 환불받을 수 있습니까?

네. 사용하지 않은 잔액은 수수료 없이 환불받을 수 있습니다. 환불은 고객 지원에 문의해 진행하세요.

실제 모델이 맞습니까? 데이터는 안전합니까?

요청은 공식 모델 채널로 전달되며, 저가 모델이나 리버스 엔지니어링 방식의 대체 모델은 사용하지 않습니다. 법령에서 요구하는 경우를 제외하고 프롬프트와 출력을 영구 저장하거나 학습에 사용하지 않으며, 콘솔에서 모든 요청의 토큰 수와 비용을 확인할 수 있습니다.

내 데이터가 학습에 사용됩니까?

요청은 HTTPS로 전송 중 암호화됩니다. 데이터 처리에 관한 자세한 내용은 AnyAIGC 개인정보 처리방침을 참고하세요. 모델 자체의 데이터 정책은 Anthropic 공식 약관을 따릅니다.
