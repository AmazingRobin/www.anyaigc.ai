Python
import json
import os
import urllib.request

# MINIMAX_VOICE_ID must be a voice ID available to your account.
payload = {
    "model": "speech-2.8-hd",
    "text": "Hello, welcome to speech synthesis with AnyAIGC.",
    "voice_setting": {
        "voice_id": os.environ["MINIMAX_VOICE_ID"]
    }
}

request = urllib.request.Request(
    "https://anyaigc.ai/minimax/v1/t2a_v2",
    data=json.dumps(payload, ensure_ascii=False).encode("utf-8"),
    headers={
        "Authorization": "Bearer " + os.environ["ANYAIGC_API_KEY"],
        "Content-Type": "application/json",
    },
    method="POST",
)
with urllib.request.urlopen(request, timeout=300) as response:
    result = json.load(response)

print(json.dumps(result, ensure_ascii=False, indent=2))

MINIMAX_VOICE_ID를 계정에서 사용할 수 있는 음성으로 설정하세요. 예제는 동기 합성을 사용합니다. 비동기 파라미터, 결과 조회, 다운로드는 최신 문서를 따르세요.

Speech 2.8

사양과 선택 기준

MiniMax는 speech-2.8-hd를 다음과 같이 소개합니다. 사운드 태그를 지원하는 초현실적 음질.

Speech 2.8은 "um", "uh", "ah" 같은 필러용 네이티브 사운드 태그를 추가했습니다. 10초 샘플로 음성을 복제할 수 있고, 배경 노이즈와 합성 아티팩트를 줄이며, 중국어-일본어를 시작으로 다국어 간 출력을 개선했습니다.

요청당 텍스트는 10,000자 미만이며, 샘플링 레이트는 8000~44100 Hz, 출력 형식은 mp3, pcm, flac, wav, opus 등을 지원합니다.

이 페이지는 음성 합성을 10,000자당 $0.5559로 표기하며, 위 가격표와 같은 수치입니다.

같은 세대의 speech-2.8-turbo는 "끊김 없는 속도, 자연스러운 흐름"으로 소개됩니다. 실시간처럼 지연 시간에 민감한 용도에는 이 모델을, 음성 유사도와 음질이 최우선이라면 HD를 사용하세요.

출처: MiniMax 모델 개요와 MiniMax 릴리스 노트. 가격은 이 페이지의 표를 기준으로 하며, 실시간 요금은 모델 카탈로그가 우선합니다.

FAQ

MiniMax API 자주 묻는 질문

가격, 엔드포인트, 결과물, 기업 도입을 한곳에서 확인하세요.

MiniMax Speech 2.8 HD API 가격은 얼마입니까?

음성 합성은 10,000자당 $0.5559입니다. 모든 가격은 USD 기준이며, 현재 요금은 모델 카탈로그에서 확인하세요.

speech-2.8-hd와 speech-2.8-turbo는 어떻게 다릅니까?

MiniMax는 speech-2.8-hd를 "사운드 태그를 지원하는 초현실적 음질", speech-2.8-turbo를 "끊김 없는 속도, 자연스러운 흐름"으로 소개합니다. HD는 음성 유사도와 음질에, Turbo는 낮은 지연 시간에 초점을 맞추며, 두 모델은 같은 API와 파라미터를 사용합니다.

speech-2.8-hd는 어떤 언어와 오디오 형식을 지원합니까?

Speech 2.8은 "um", "uh", "ah" 같은 필러용 네이티브 사운드 태그를 추가했습니다. 10초 샘플로 음성을 복제할 수 있고, 배경 노이즈와 합성 아티팩트를 줄이며, 중국어-일본어를 시작으로 다국어 간 출력을 개선했습니다. 요청 1건당 텍스트는 10,000자 미만, 샘플링 레이트는 8000~44100 Hz이며, 출력은 mp3, pcm, flac, wav, opus 등의 형식을 지원합니다.

어떤 API 엔드포인트를 사용해야 합니까?

https://anyaigc.ai의 POST /minimax/v1/t2a_v2 또는 POST /minimax/v1/t2a_async_v2를 사용하고, API 키는 Authorization: Bearer로 전달하세요.

음성은 어떻게 선택하며, 추가 비용이 발생합니까?

voice_setting.voice_id에 계정에서 사용할 수 있는 음성을 지정하세요. 카탈로그에 따르면 기본 제공 음성이 아닌 음성은 별도의 음성 요금이 발생할 수 있으니, 선택한 음성의 요금을 확인하세요.

요청 한 번에 무엇이 반환됩니까?

동기 방식 예제는 JSON을 반환하며, data.audio에는 요청과 실제 응답에 따라 오디오 데이터 또는 URL이 담깁니다. 카탈로그에는 비동기 엔드포인트도 있습니다. 작업 조회와 다운로드는 최신 문서를 따르세요.

동시 실행 수나 RPM 제한이 있습니까?

AnyAIGC는 MiniMax에 동시 실행 제한을 두지 않으며 고정 RPM 상한도 없습니다. 다만 생성에는 시간이 걸리므로 타임아웃, 오류 처리, 적절한 재시도를 애플리케이션에서 설정하세요.

생성한 콘텐츠를 상업적으로 사용할 수 있습니까?

모델과 출력물의 상업적 사용은 MiniMax 공식 약관을 따릅니다. 참조 자료, 음성, 생성된 콘텐츠에 대해 필요한 권리를 갖추었는지 확인하세요. AnyAIGC는 독립 API 제공업체입니다.

AnyAIGC에서 인보이스를 받을 수 있습니까?

네. 콘솔에서 실제 충전한 금액 기준으로 직접 인보이스를 발급할 수 있습니다.

어떤 결제 수단을 지원합니까?

WeChat Pay, Alipay, USDT, 신용카드로 충전할 수 있습니다. 잔액은 USD 기준이며 플랫폼의 모든 모델에서 사용할 수 있습니다. 인보이스는 콘솔에서 충전한 금액 기준으로 발급할 수 있습니다.

신규 사용자에게 무료 체험 크레딧이 있습니까?

네. 신규 계정에는 토큰 200만 개 분량의 체험 크레딧이 제공되므로 충전 여부를 결정하기 전에 먼저 테스트할 수 있습니다. 충전은 $1부터 가능합니다.

잔액을 환불받을 수 있습니까?

네. 사용하지 않은 잔액은 수수료 없이 환불받을 수 있습니다. 환불은 고객 지원에 문의해 진행하세요.

실제 모델이 맞습니까? 데이터는 안전합니까?

요청은 공식 모델 채널로 전달되며, 저가 모델이나 리버스 엔지니어링 방식의 대체 모델은 사용하지 않습니다. 법령에서 요구하는 경우를 제외하고 프롬프트와 출력을 영구 저장하거나 학습에 사용하지 않으며, 콘솔에서 모든 요청의 토큰 수와 비용을 확인할 수 있습니다.
