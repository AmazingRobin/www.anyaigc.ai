Seedream 5.0 Pro란 무엇입니까?

Seedream 5.0 Pro는 ByteDance Seed 팀의 플래그십 이미지 모델로, 공식적으로는 효율적인 창작과 제작을 위해 추론 기능을 내장한 멀티모달 이미지 생성 모델로 설명됩니다. 고밀도 정보 레이아웃, 인터랙티브 정밀 편집, 사실적인 사진과 인물, 10개 이상 언어의 네이티브 지원에 중점을 둡니다. AnyAIGC는 2026년 8월에 추가했습니다.

어떤 해상도를 지원합니까? 4K로 출력할 수 있습니까?

4K는 지원하지 않습니다. Volcano Engine Ark 문서에 따르면 5.0 Pro는 size 값으로 1K, 1.5K, 2K(기본값 2K) 또는 2048x2048, 2816x1584 같은 픽셀 크기를 받으며, 가로세로 비율은 1:16부터 16:1까지입니다. 4K가 필요하면 Seedream 5.0 lite 또는 4.5를 사용하세요.

참조 이미지는 몇 장까지 보낼 수 있습니까? 이미지 세트를 지원합니까?

image는 편집과 다중 이미지 합성용 참조 이미지를 최대 10장까지 받습니다. 5.0 Pro는 이미지 세트(요청 한 번에 관련 이미지 여러 장)를 지원하지 않으므로, 필요하면 5.0 lite, 4.5 또는 4.0을 사용하세요.

5.0 Pro와 5.0 lite 중 무엇을 선택해야 합니까?

인포그래픽, 포스터, UI처럼 텍스트 비중이 큰 이미지와 주석이나 선택 영역 기반의 정밀 편집에는 5.0 Pro를 선택하세요. 일상적인 일괄 작업, 4K, 이미지 세트, 웹 검색에는 5.0 lite를 선택하세요. 요금도 더 낮습니다($0.0223 / 이미지부터).

동시 실행 제한이 있습니까? 가입에 무엇이 필요합니까?

AnyAIGC는 Seedream 5.0 Pro에 동시 실행 제한을 두지 않으며, 모든 계정에 기본으로 적용됩니다. 기본 URL은 https://anyaigc.ai입니다. Volcano Engine 계정이나 본인 인증은 필요 없고, 같은 키로 플랫폼의 300개 이상의 다른 모델도 사용할 수 있습니다.

AnyAIGC에서 인보이스를 받을 수 있습니까?

네. 콘솔에서 실제 충전한 금액 기준으로 직접 인보이스를 발급할 수 있습니다.

어떤 결제 수단을 지원합니까?

WeChat Pay, Alipay, USDT, 신용카드로 충전할 수 있습니다. 잔액은 USD 기준이며 플랫폼의 모든 모델에서 사용할 수 있습니다. 인보이스는 콘솔에서 충전한 금액 기준으로 발급할 수 있습니다.

신규 사용자에게 무료 체험 크레딧이 있습니까?

네. 신규 계정에는 토큰 200만 개 분량의 체험 크레딧이 제공되므로 충전 여부를 결정하기 전에 먼저 테스트할 수 있습니다. 충전은 $1부터 가능합니다.

잔액을 환불받을 수 있습니까?

네. 사용하지 않은 잔액은 수수료 없이 환불받을 수 있습니다. 환불은 고객 지원에 문의해 진행하세요.

실제 모델이 맞습니까? 데이터는 안전합니까?

요청은 공식 모델 채널로 전달되며, 저가 모델이나 리버스 엔지니어링 방식의 대체 모델은 사용하지 않습니다. 법령에서 요구하는 경우를 제외하고 프롬프트와 출력을 영구 저장하거나 학습에 사용하지 않으며, 콘솔에서 모든 요청의 토큰 수와 비용을 확인할 수 있습니다.

상업적으로 사용할 수 있습니까? 워터마크를 제거할 수 있습니까?

사용 권한과 콘텐츠 정책은 ByteDance / Volcano Engine 공식 약관을 따릅니다. 요청에서 watermark를 false로 설정하면 오른쪽 아래에 "AI 생성" 표시가 추가되지 않습니다. AnyAIGC는 API 접근만 제공하며 결과물 사용에 추가 제한을 두지 않습니다. 실존 인물 초상, 브랜드 로고 등은 필요한 권리를 갖고 있는지 확인하세요.
