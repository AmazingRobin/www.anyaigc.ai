Nano Banana Pro API 시작하기

  1. 가입: AnyAIGC 계정을 만드세요. 신규 계정에는 토큰 200만 개 분량의 체험 크레딧이 제공되며, 충전은 $1부터 가능합니다.
  2. API 키 만들기: 콘솔에서 키를 생성하고 ANYAIGC_API_KEY 환경 변수에 저장하세요.
  3. 요청 보내기: POST https://anyaigc.ai/v1beta/models/gemini-3-pro-image:generateContent(Gemini 네이티브 형식)를 호출하세요. 이미 OpenAI SDK를 쓰는 프로젝트는 model을 gemini-3-pro-image로 설정해 /v1/chat/completions를 사용할 수 있습니다.

Nano Banana Pro는 사고(Thinking) 기능이 항상 켜져 있으며 끌 수 없습니다. 종횡비는 10가지만 지원하며 1:4, 4:1, 1:8, 8:1은 지원하지 않습니다.

Authorization: Bearer <API Key>로 인증합니다. imageConfig.imageSize는 1K, 2K, 4K를 받으며 기본값은 1K입니다. response_format은 플랫폼 확장 파라미터로, url로 설정하면 임시 fileData.fileUri 링크를 받고(비스트리밍에서만 가능) 생략하면 base64를 받습니다. 안전 필터에 요청이 차단되면 finishReason은 SAFETY 또는 PROHIBITED_CONTENT이며 이미지는 반환되지 않습니다.

사양과 선택 기준

Nano Banana Pro는 Gemini 3 Pro를 기반으로 한 Gemini 3 Pro Image이며, Google이 2025년 11월 20일에 출시했습니다.

여러 언어의 텍스트를 정확하게 렌더링하고, 현지화 편집과 함께 카메라 앵글, 초점, 컬러 그레이딩, 조명을 제어할 수 있습니다.

최대 14장의 이미지를 합성하면서 최대 5명의 인물 외형을 유지할 수 있으며, 다양한 종횡비와 2K, 4K 해상도를 지원합니다.

인포그래픽을 만들 때 Google Search에 연결해 날씨나 스포츠 같은 실시간 정보를 반영할 수 있으며, 생성된 이미지에는 SynthID 워터마크가 들어갑니다.

Google 문서에 따르면 모델 코드는 gemini-3-pro-image이며, 이미지와 텍스트를 입력받아 이미지와 텍스트를 반환합니다. 입력은 65,536 토큰, 출력은 32,768 토큰까지입니다.

이 페이지는 Nano Banana Pro를 $0.134로 표기하며, 위의 가격표와 일치합니다.

nano-banana-2와 비교: 더 빠른 생성과 빠른 반복 작업이 필요하거나 512px 같은 작은 출력이 필요하면 Nano Banana 2를 선택하세요.

사양은 제공사 공식 문서(blog.google)를 기준으로 합니다. 이 페이지의 표는 가격이며, 실시간 요금은 모델 카탈로그가 기준입니다.

복잡한 레이아웃, 빽빽한 텍스트, 일관된 다중 캐릭터 장면, 전문가급 디테일에는 Pro를 선택하세요. 일상적인 이미지, 일괄 작업, 1:8과 8:1 초광각 비율에는 Nano Banana 2.1을 선택하세요. 비용이 더 낮습니다(이미지당 $0.0128부터).

Nano Banana Pro는 4K를 지원합니까? 어떤 종횡비를 지원합니까?

예. imageConfig.imageSize에는 1K, 2K, 4K를 지정할 수 있으며, 2K와 4K 실시간 가격은 모델 카탈로그에서 확인하세요. imageConfig.aspectRatio는 1:1, 2:3, 3:2, 3:4, 4:3, 4:5, 5:4, 9:16, 16:9, 21:9의 10가지 비율을 지원합니다.

참조 이미지는 몇 장까지 올릴 수 있습니까? 캐릭터 일관성이 유지됩니까?

요청당 최대 14장의 참조 이미지를 사용할 수 있으며, 오브젝트 이미지 최대 6장, 캐릭터 이미지 5장, 스타일 참조 3장입니다. 캐릭터 이미지를 쓰면 여러 컷에서 같은 인물이 일관되게 유지됩니다.

동시 실행 제한이 있습니까?

AnyAIGC는 Nano Banana Pro에 동시 실행 제한을 두지 않으며, 모든 계정에 기본으로 적용됩니다. base URL은 https://anyaigc.ai이고 Google 계정은 필요 없습니다. 같은 키로 300개 이상의 다른 모델을 사용할 수 있습니다.

AnyAIGC에서 인보이스를 받을 수 있습니까?

네. 콘솔에서 실제 충전한 금액 기준으로 직접 인보이스를 발급할 수 있습니다.

어떤 결제 수단을 지원합니까?

WeChat Pay, Alipay, USDT, 신용카드로 충전할 수 있습니다. 잔액은 USD 기준이며 플랫폼의 모든 모델에서 사용할 수 있습니다. 인보이스는 콘솔에서 충전한 금액 기준으로 발급할 수 있습니다.

신규 사용자에게 무료 체험 크레딧이 있습니까?

네. 신규 계정에는 토큰 200만 개 분량의 체험 크레딧이 제공되므로 충전 여부를 결정하기 전에 먼저 테스트할 수 있습니다. 충전은 $1부터 가능합니다.

잔액을 환불받을 수 있습니까?

네. 사용하지 않은 잔액은 수수료 없이 환불받을 수 있습니다. 환불은 고객 지원에 문의해 진행하세요.

실제 모델이 맞습니까? 데이터는 안전합니까?

요청은 공식 모델 채널로 전달되며, 저가 모델이나 리버스 엔지니어링 방식의 대체 모델은 사용하지 않습니다. 법령에서 요구하는 경우를 제외하고 프롬프트와 출력을 영구 저장하거나 학습에 사용하지 않으며, 콘솔에서 모든 요청의 토큰 수와 비용을 확인할 수 있습니다.

이미지를 상업적으로 사용할 수 있습니까? 워터마크가 있습니까?

사용 권리와 콘텐츠 정책은 Google 공식 약관을 따릅니다. Google은 Nano Banana가 생성하는 모든 이미지에 보이지 않는 SynthID 디지털 워터마크를 삽입하며, 그림에서는 눈에 보이지 않습니다. AnyAIGC는 API 접근만 제공하며 결과물 사용 방식에 별도 제한을 추가하지 않습니다. 이미지에 실존 인물의 초상이나 제3자 상표가 포함된다면 필요한 권리를 갖고 있는지 확인하세요.
