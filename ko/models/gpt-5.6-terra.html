공식 정가가 20% 내려간 GPT-5.5급 일상용 모델

OpenAI는 2026년 7월 9일 GPT-5.6 계열을 Sol, Terra, Luna의 세 등급으로 출시했습니다. OpenAI는 Terra를 더 낮은 비용으로 "GPT-5.5에 견줄 만한 성능을 갖춘 균형형 일상용 모델"이라고 설명합니다. OpenAI의 명명 방식에서 숫자는 세대를 나타내고, Sol, Terra, Luna는 각자의 일정에 따라 발전하는 지속적인 성능 등급입니다. Terra는 이전 GPT-5 제품군의 mini 등급에 대략 해당합니다.

OpenAI는 2026년 7월 30일 GPT-5.6 Terra의 가격을 영구적으로 20% 인하했습니다. 출시 당시 $2.50 / $15였던 가격이 100만 토큰당 입력 $2.00, 캐시 입력 $0.20, 출력 $12.00이 되었습니다. OpenAI의 지원 중단 안내 페이지는 GPT-5.6 Terra를 gpt-5-mini, o4-mini, gpt-3.5-turbo의 대체 모델로 지정합니다.

GPT-5.6 Terra는 none, low, medium(기본값), high, xhigh, max의 6단계 추론 강도(reasoning effort)를 지원합니다. 컨텍스트 길이는 1,050,000 토큰, 최대 출력은 128,000 토큰이며, 텍스트와 이미지를 입력받아 텍스트를 출력하고, 지식 기준일은 2026년 2월 16일입니다. AnyAIGC에서 gpt-5.6-terra는 /v1/chat/completions와 /v1/responses 모두에서 작동합니다. 공식 OpenAI SDK에서는 base_url만 https://anyaigc.ai/v1로 바꾸면 되고, 같은 키로 300개 이상의 다른 모델도 사용할 수 있습니다.

GPT-5.6 Terra가 잘 맞는 작업

  • 01 · 코딩

    일상적인 코딩과 코드 리뷰

    함수 작성, 버그 수정, PR 리뷰, 테스트 추가에 사용할 수 있습니다. OpenAI 수치로는 Terminal-Bench 2.1 87.4%, SWE-Bench Pro 63.4%로 둘 다 GPT-5.5보다 높아, IDE 어시스턴트와 Codex에서 매일 쓰기 좋은 실용적인 모델입니다.

  • 02 · 지식 업무

    문서, 보고서, 분석

    OpenAI는 Terra가 더 낮은 비용으로 지식 업무에서 GPT-5.5를 앞선다고 밝혔습니다. 컨텍스트 길이 1,050,000 토큰이면 계약서, 보고서, 회의록을 한 번의 요청에 담을 수 있고, 캐시 입력은 100만 토큰당 $0.0099이므로 같은 자료를 반복해서 써도 부담이 적습니다.

  • 03 · 브라우징

    웹 리서치와 요약

    Responses API의 웹 검색과 기타 도구로 정보를 찾고, 확인하고, 요약합니다. OpenAI 수치로는 BrowseComp 87.5%로 GPT-5.5의 84.4%보다 높습니다.

  • 04 · 마이그레이션

    이전 mini 모델 대체

    OpenAI는 GPT-5.6 Terra를 gpt-5-mini, o4-mini, gpt-3.5-turbo의 대체 모델로 지정합니다. 기존 고객 지원 봇, 티켓 분류, 콘텐츠 검수 흐름은 model 값만 바꾸면 되며, Chat Completions의 함수 호출도 그대로 작동합니다.

3단계로 GPT-5.6 Terra API 호출하기

  1. 가입 후 충전: anyaigc.ai에서 계정을 만드세요. 잔액은 모든 모델에서 공통으로 사용할 수 있습니다.
  2. API 키 만들기: 콘솔에서 토큰을 만들고 sk- 키를 복사해 ANYAIGC_API_KEY 환경 변수에 저장하세요.
  3. 요청 보내기: model을 gpt-5.6-terra로 지정하고 Authorization: Bearer 인증으로 https://anyaigc.ai/v1/chat/completions 또는 https://anyaigc.ai/v1/responses를 호출하세요.

두 엔드포인트 모두 도구를 지원합니다. OpenAI 모델 문서에 따르면 gpt-5.6-terra는 Chat Completions, Responses, Batch 엔드포인트를 지원하며, 함수 호출은 /v1/chat/completions와 /v1/responses 모두에서 작동합니다. 웹 검색, 파일 검색, 코드 인터프리터 같은 OpenAI 내장 도구는 Responses API에 속하며, 이때 추론 강도는 reasoning.effort에 지정합니다.

모든 파라미터는 Chat Completions 레퍼런스와 Responses 레퍼런스를 참고하세요. 필드는 공식 OpenAI API와 같습니다.

OpenAI는 GPT-5.6 Terra를 GPT-5.5에 견줄 만한 성능을 갖춘 일상 업무용 균형형 모델로 소개합니다.

OpenAI의 지식 업무 평가에서 GPT-5.6 Terra는 GPT-5.5를 앞섰습니다.

이 페이지에는 입력 $0.0993, 출력 $0.5957, 캐시 입력 $0.0099가 표기되어 있으며, 위의 가격 표와 일치합니다.

gpt-5.6-terra는 균형형 등급이고, gpt-5.6-luna는 같은 세대에서 더 빠르고 저렴한 등급입니다.

사양은 제공사의 공식 문서(openai.com)를 기준으로 합니다. 이 페이지의 표는 가격이며, 실시간 요금은 모델 카탈로그가 기준입니다.

GPT-5.6 Terra API 자주 묻는 질문

GPT-5.6 Terra API 요금은 얼마입니까?

AnyAIGC에서 gpt-5.6-terra는 토큰 단위로 과금되며, 입력 100만 토큰당 $0.0993, 출력 100만 토큰당 $0.5957, 캐시 입력 100만 토큰당 $0.0099입니다. OpenAI 공식 정가는 2026년 7월 30일의 영구 20% 인하 이후 입력 $2.00, 출력 $12.00, 캐시 입력 $0.20이며(출시 가격은 $2.50 / $15), AnyAIGC는 공식 정가의 약 5%(95% 할인)입니다. 요청의 입력이 272K 토큰을 넘으면 요청 전체가 입력 2배, 출력 1.5배로 과금됩니다.

GPT-5.6 Terra의 모델 ID는 무엇입니까?

모델 ID는 gpt-5.6-terra입니다. 요청의 model 필드에 넣으세요. OpenAI는 이 모델의 날짜가 붙은 스냅샷을 공개하지 않았습니다.

Terra는 무엇이며 GPT-5.6 Sol과 어떻게 다릅니까?

OpenAI의 명명 방식에서 숫자는 세대를 나타내고, Sol, Terra, Luna는 각자 독립적으로 발전하는 성능 등급입니다. Sol은 플래그십, Terra는 일상 업무용 균형형 모델, Luna는 가장 빠르고 저렴한 등급입니다. Terra는 이전 GPT-5 제품군의 mini 등급에 대략 해당합니다. OpenAI가 공개한 결과에서 Terra는 Terminal-Bench 2.1 87.4%(Sol 88.8%), OSWorld 2.0 50.2%(Sol 62.6%)를 기록했습니다. Terra의 공식 정가는 $2 / $12이고, GPT-5.6 Sol은 $4 / $20의 프로모션 가격입니다. AnyAIGC에서는 100만 토큰당 Terra가 입력 $0.0993, 출력 $0.5957이고, Sol은 입력 $0.2482, 출력 $1.4890입니다.

GPT-5.6 Terra와 GPT-5.6 Luna 중 어느 쪽을 써야 합니까?

두 모델은 컨텍스트 길이, 최대 출력, 엔드포인트가 같습니다. OpenAI가 공개한 결과에서 Terra는 대부분의 벤치마크에서 Luna보다 높습니다. 예를 들어 Terminal-Bench 2.1은 87.4% 대 84.7%, OSWorld 2.0은 50.2% 대 45.6%, BrowseComp는 87.5% 대 83.3%입니다. Luna의 공식 정가는 Terra의 10분의 1($0.20 / $1.20)입니다. 코딩, 지식 업무, 다단계 작업에는 Terra를 사용하고, 대량 분류, 추출, 요약에는 먼저 GPT-5.6 Luna를 시도해 보세요. AnyAIGC에서 Luna는 100만 토큰당 입력 $0.0270, 출력 $0.1620입니다.

GPT-5.6 Terra는 GPT-5.5와 비교해 어떻습니까?

OpenAI는 Terra를 더 낮은 비용으로 GPT-5.5에 견줄 만한 모델이라고 설명하며, 지식 업무에서는 GPT-5.5를 앞선다고 밝혔습니다. OpenAI가 공개한 결과에서 Terra는 Terminal-Bench 2.1(87.4% 대 85.6%), SWE-Bench Pro(63.4% 대 59.4%), BrowseComp(87.5% 대 84.4%)에서 GPT-5.5보다 높고, GPQA Diamond(92.9% 대 93.6%)에서는 약간 낮습니다. Terra의 공식 정가는 $2 / $12, GPT-5.5는 $5 / $30입니다. 지식 기준일은 Terra가 2026-02-16, GPT-5.5가 2025-12-01입니다.

GPT-5.6 Terra는 지원 중단되었습니까? 언제까지 사용할 수 있습니까?

지원 중단되지 않았습니다. OpenAI는 GPT-5.6 Terra의 종료 일정을 발표하지 않았으며, 지금도 정상적으로 호출할 수 있습니다. OpenAI의 지원 중단 페이지는 지금도 이 모델을 gpt-5-mini, o4-mini 같은 이전 모델의 대체 모델로 안내합니다. OpenAI는 후속 모델로 GPT-6.1 Terra(gpt-6.1-terra)를 출시했으며, AnyAIGC에서는 입력 100만 토큰당 $0.0496, 출력 100만 토큰당 $0.2482입니다. 새 프로젝트에는 이 모델을 권장합니다. 도구 호출에는 Responses API가 필요하므로 전환하기 전에 테스트하세요.
