기능

비디오와 이미지 작업을 키 하나로

Vidu 생성 기능을 제품과 파이프라인에 바로 연결하세요.

01

텍스트→비디오

Q3 Pro, Q3 Turbo, Q2는 텍스트만으로 비디오를 생성합니다.

02

이미지와 첫/마지막 프레임

Q4, Q3, Q2 Pro/Turbo는 첫 프레임을 움직이게 합니다. Q3와 Q2 Pro/Turbo는 마지막 프레임도 받습니다.

03

참조→비디오

Q4 Preview, Q2, Q2 Pro에서 여러 이미지나 피사체로 캐릭터를 일관되게 유지하세요.

04

네이티브 오디오

Q4 Preview와 Q3는 기본으로 사운드를 생성하고, Q2는 작업마다 네이티브 오디오를 추가할 수 있습니다.

05

540p에서 4K까지

Q4 Preview는 4K까지, Q3와 Q2는 1080p까지 지원하며 초 단위로 과금됩니다.

06

이미지 생성

Q2 Image는 텍스트→이미지와 최대 4K, 1–7장의 참조 이미지를 지원합니다.

Python
import json
import os
import time
import urllib.request

BASE = "https://anyaigc.ai"
HEADERS = {
    "Authorization": "Bearer " + os.environ["ANYAIGC_API_KEY"],
    "Content-Type": "application/json",
}


def call(method, path, body=None):
    data = json.dumps(body, ensure_ascii=False).encode("utf-8") if body else None
    request = urllib.request.Request(BASE + path, data=data, headers=HEADERS, method=method)
    with urllib.request.urlopen(request, timeout=60) as response:
        return json.load(response)


payload = {
    "model": "viduq3-turbo",
    "prompt": "A red fox crosses thin ice on a mountain lake at dawn; low tracking shot, its breath drifting in the sunlight.",
    "duration": 5,
    "resolution": "540p",
    "aspect_ratio": "16:9"
}

created = call("POST", "/ent/v2/text2video", payload)
task_id = (created.get("data") or created)["task_id"]
print("task_id:", task_id)

# Poll every 10 seconds until the task leaves the queue
for _ in range(120):
    result = call("GET", f"/ent/v2/tasks/{task_id}/creations")
    state = (result.get("data") or result).get("state") or (result.get("data") or result).get("status")
    if state not in ("created", "queueing", "processing"):
        break
    time.sleep(10)

# creations holds the video or image URLs; they expire, so download promptly
print(json.dumps(result, ensure_ascii=False, indent=2))

샘플 이미지를 직접 준비한 URL 또는 Base64(png, jpeg, webp, 최대 50 MB)로 바꾸세요. status 필드는 실제 응답에서 읽으세요. 예제는 작업이 created, queueing, processing 상태를 벗어나면 폴링을 멈춥니다.

팀이 AnyAIGC를 신뢰하는 이유

  • 시작은 무료 토큰 200만 개

    신규 계정에는 체험 크레딧이 제공되므로 충전 전에 먼저 테스트할 수 있습니다.

    $1부터 충전할 수 있습니다. 사용하지 않은 잔액은 수수료 없이 환불받을 수 있습니다.

    요청은 공식 모델 채널로 전달되며, 저가 모델이나 리버스 엔지니어링 방식의 대체 모델은 사용하지 않습니다.

    콘솔에서 모든 요청의 토큰 수와 비용을 확인할 수 있고, API 키마다 한도를 설정할 수 있습니다.

  • 연중무휴 24시간 지원

    연동, 과금, 장애와 관련된 문의는 언제든지 고객 지원으로 연락하세요.

Vidu API 자주 묻는 질문

가격, 엔드포인트, 결과물, 기업 도입을 한곳에서 확인하세요.

Vidu API의 시작 가격은 얼마입니까?

비디오는 Q2 Turbo 540p 첫 1초 $0.0223부터 시작하며(이후 +$0.00744/초), Q3 Turbo 540p는 $0.0298/초, Q4 Preview 540p는 $0.0486/초, Q2 Image 텍스트→이미지 1080p는 이미지당 $0.0298입니다. 가격 단위는 USD이며, 현재 요금은 모델 카탈로그에서 확인하세요.

7개 모델 중 어떤 것을 골라야 합니까?

2K/4K와 최신 모델이 필요하면 Q4 Preview, 동기화된 오디오와 스마트 샷 전환이 필요하면 Q3 Pro, 속도가 중요하면 Q3 Turbo를 고르세요. 예산형 이미지 또는 첫/마지막 프레임 클립에는 Q2 Turbo, 더 높은 품질에는 Q2 Pro, 텍스트와 다중 이미지 참조 비디오에는 Q2, 정지 이미지에는 Q2 Image를 고르세요.

이 모델들은 엔드포인트를 공유합니까?

엔드포인트는 작업에 따라 나뉩니다: /ent/v2/text2video, /ent/v2/img2video, /ent/v2/start-end2video, /ent/v2/reference2video, /ent/v2/reference2image. 모델은 model 필드로 선택하고, 모든 결과는 GET /ent/v2/tasks/{id}/creations로 가져옵니다.

결과는 어떻게 받습니까?

모든 작업은 비동기입니다. 작업을 생성하면 task_id가 반환되고, 조회 엔드포인트를 폴링해 creations에서 비디오 또는 이미지 URL을 읽거나, callback_url을 전달해 콜백을 받을 수 있습니다.

동시 실행 수나 RPM 제한이 있습니까?

AnyAIGC의 Vidu는 모든 계정에 기본으로 동시 실행 제한이 없으며, 고정 RPM 상한도 없습니다. 비디오 생성에는 시간이 걸리므로 애플리케이션에서 폴링 간격과 타임아웃을 설정하세요.

출력물을 상업적으로 사용할 수 있습니까?

상업적 이용은 Vidu(ShengShu Technology)의 공식 약관을 따르며, 업로드하는 참조 이미지, 인물, 브랜드 자산에 대한 권리는 직접 확보해야 합니다. AnyAIGC는 독립 API 제공업체입니다.

AnyAIGC에서 인보이스를 받을 수 있습니까?

네. 콘솔에서 실제 충전한 금액 기준으로 직접 인보이스를 발급할 수 있습니다.

어떤 결제 수단을 지원합니까?

WeChat Pay, Alipay, USDT, 신용카드로 충전할 수 있습니다. 잔액은 USD 기준이며 플랫폼의 모든 모델에서 사용할 수 있습니다. 인보이스는 콘솔에서 충전한 금액 기준으로 발급할 수 있습니다.

신규 사용자에게 무료 체험 크레딧이 있습니까?

네. 신규 계정에는 토큰 200만 개 분량의 체험 크레딧이 제공되므로 충전 여부를 결정하기 전에 먼저 테스트할 수 있습니다. 충전은 $1부터 가능합니다.

잔액을 환불받을 수 있습니까?

네. 사용하지 않은 잔액은 수수료 없이 환불받을 수 있습니다. 환불은 고객 지원에 문의해 진행하세요.

실제 모델이 맞습니까? 데이터는 안전합니까?

요청은 공식 모델 채널로 전달되며, 저가 모델이나 리버스 엔지니어링 방식의 대체 모델은 사용하지 않습니다. 법령에서 요구하는 경우를 제외하고 프롬프트와 출력을 영구 저장하거나 학습에 사용하지 않으며, 콘솔에서 모든 요청의 토큰 수와 비용을 확인할 수 있습니다.
