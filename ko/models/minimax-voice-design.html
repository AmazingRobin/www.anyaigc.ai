cURL
# Set MINIMAX_DESIGNED_VOICE_ID to a unique custom voice ID.
curl --request POST "https://anyaigc.ai/minimax/v1/voice_design" \
  --header "Authorization: Bearer $ANYAIGC_API_KEY" \
  --header "Content-Type: application/json" \
  --data @- <<JSON
{
  "preview_text": "Night fell, the streetlights went dark, and a soft knock echoed in the distance.",
  "prompt": "A suspense-story narrator with a deep, resonant voice.",
  "voice_id": "${MINIMAX_DESIGNED_VOICE_ID}"
}
JSON
Python
import json
import os
import urllib.request

# MINIMAX_DESIGNED_VOICE_ID must be a unique custom voice ID.
payload = {
    "preview_text": "Night fell, the streetlights went dark, and a soft knock echoed in the distance.",
    "prompt": "A suspense-story narrator with a deep, resonant voice.",
    "voice_id": os.environ["MINIMAX_DESIGNED_VOICE_ID"]
}

request = urllib.request.Request(
    "https://anyaigc.ai/minimax/v1/voice_design",
    data=json.dumps(payload, ensure_ascii=False).encode("utf-8"),
    headers={
        "Authorization": "Bearer " + os.environ["ANYAIGC_API_KEY"],
        "Content-Type": "application/json",
    },
    method="POST",
)
with urllib.request.urlopen(request, timeout=300) as response:
    result = json.load(response)

print(json.dumps(result, ensure_ascii=False, indent=2))

문서에는 voice_id가 설명되어 있지만 응답 예시에는 data.task_id가 표시됩니다. 이 예제는 결과 필드를 가정하지 않고 전체 JSON을 출력합니다. 연동하기 전에 실제 응답과 과금 대상 텍스트를 확인하세요.

FAQ

MiniMax API FAQ

가격, 엔드포인트, 결과물, 기업 도입을 한곳에서 확인하세요.

MiniMax Voice Design API 가격은 얼마입니까?

카탈로그 가격은 10,000자당 $0.3176입니다. 일괄 적용 전에 어떤 텍스트가 과금 대상인지, 요금이 언제 부과되는지 고객 지원에 확인하세요.

어떤 API 엔드포인트를 사용해야 합니까?

https://anyaigc.ai의 POST /minimax/v1/voice_design을 사용하고 Authorization: Bearer로 API 키를 전달하세요. Voice Design은 prompt, preview_text, 커스텀 voice_id를 받으며 model 필드는 사용하지 않습니다.

Voice Design에는 무엇을 제공해야 합니까?

prompt에 원하는 음성과 전달 방식을 설명하고, preview_text에 샘플 텍스트를 넣고, 고유한 커스텀 voice_id를 정하세요. 예제는 이 ID를 MINIMAX_DESIGNED_VOICE_ID에서 읽습니다.

요청 한 번에 무엇이 반환됩니까?

문서에는 voice_id 결과가 설명되어 있지만 예제 응답에는 data.task_id가 표시됩니다. 예제는 특정 필드나 다운로드 흐름을 가정하지 않고 전체 JSON 응답을 출력합니다. 연동하기 전에 실제 응답을 확인하세요.

동시 실행 수나 RPM 제한이 있습니까?

AnyAIGC는 MiniMax에 동시 실행 제한을 두지 않으며 고정 RPM 상한도 없습니다. 다만 생성에는 시간이 걸리므로 타임아웃, 오류 처리, 적절한 재시도를 애플리케이션에서 설정하세요.

생성한 콘텐츠를 상업적으로 사용할 수 있습니까?

모델과 출력물의 상업적 사용은 MiniMax 공식 약관을 따릅니다. 참조 자료, 음성, 생성된 콘텐츠에 대해 필요한 권리를 갖추었는지 확인하세요. AnyAIGC는 독립 API 제공업체입니다.

AnyAIGC에서 인보이스를 받을 수 있습니까?

네. 콘솔에서 실제 충전한 금액 기준으로 직접 인보이스를 발급할 수 있습니다.

어떤 결제 수단을 지원합니까?

WeChat Pay, Alipay, USDT, 신용카드로 충전할 수 있습니다. 잔액은 USD 기준이며 플랫폼의 모든 모델에서 사용할 수 있습니다. 인보이스는 콘솔에서 충전한 금액 기준으로 발급할 수 있습니다.

신규 사용자에게 무료 체험 크레딧이 있습니까?

네. 신규 계정에는 토큰 200만 개 분량의 체험 크레딧이 제공되므로 충전 여부를 결정하기 전에 먼저 테스트할 수 있습니다. 충전은 $1부터 가능합니다.

잔액을 환불받을 수 있습니까?

네. 사용하지 않은 잔액은 수수료 없이 환불받을 수 있습니다. 환불은 고객 지원에 문의해 진행하세요.

실제 모델이 맞습니까? 데이터는 안전합니까?

요청은 공식 모델 채널로 전달되며, 저가 모델이나 리버스 엔지니어링 방식의 대체 모델은 사용하지 않습니다. 법령에서 요구하는 경우를 제외하고 프롬프트와 출력을 영구 저장하거나 학습에 사용하지 않으며, 콘솔에서 모든 요청의 토큰 수와 비용을 확인할 수 있습니다.
