소개

긴 작업을 위한 조 단위 규모의 오픈 웨이트 모델

Moonshot AI는 Kimi K3가 파라미터 2.8조에 도달한 최초의 오픈소스 모델이라고 밝혔습니다. Kimi Delta Attention(KDA) 하이브리드 선형 어텐션과 Attention Residuals를 기반으로 하며, 이 두 가지 아키텍처 변경은 더 긴 시퀀스와 더 깊은 네트워크에서도 정보가 끊기지 않고 흐르도록 하기 위한 것입니다.

Stable LatentMoE 프레임워크에서 K3는 토큰마다 896개 전문가 중 16개를 활성화합니다. Moonshot은 개선된 학습 방법과 데이터 레시피를 함께 적용해 K3의 전체 스케일링 효율이 K2의 약 2.5배에 이른다고 밝혔습니다. 네이티브 비전을 지원하고, 컨텍스트 길이는 1,048,576 토큰이며, 사고 모드는 항상 켜져 있습니다.

AnyAIGC에서 kimi-k3는 OpenAI 호환 /v1/chat/completions 엔드포인트로 동작하며 Claude Code에서도 바로 사용할 수 있습니다. Moonshot 플랫폼 계정이 필요 없고, 충전 등급도 없으며, 동시 실행 제한도 없습니다.

빠른 시작

세 단계로 Kimi K3 API 연동하기

  1. 가입 및 충전: anyaigc.ai에서 계정을 만듭니다. $1부터 충전할 수 있으며, 잔액은 플랫폼의 모든 모델에서 공통으로 사용됩니다.
  2. API 키 만들기: 콘솔에서 키를 만들고 sk-로 시작하는 값을 복사해 ANYAIGC_API_KEY 환경 변수에 저장하세요.
  3. 요청 보내기: model을 kimi-k3로 설정하고 Authorization: Bearer 헤더를 포함해 POST https://anyaigc.ai/v1/chat/completions를 호출하세요. OpenAI SDK에서는 base_url만 https://anyaigc.ai/v1로 지정하면 됩니다.

팁: K3는 항상 사고하며, 추론 내용은 reasoning_content로 반환됩니다. Moonshot은 temperature=1.0, top_p=0.95를 권장합니다. 멀티턴 대화와 도구 호출에서는 content만이 아니라 API가 반환한 어시스턴트 메시지 전체(reasoning_content와 tool_calls 포함)를 다음 요청에 그대로 다시 보내세요.

모든 파라미터는 Chat Completions 레퍼런스를 참고하세요. 문서 예제의 모델 이름을 사용할 Kimi 모델 ID로 바꾸세요.

Claude Code

Claude Code에서 Kimi K3 사용하기

Claude Code를 Kimi K3로 전환하세요. 1M 컨텍스트는 대형 저장소에서의 긴 코딩 세션에 적합합니다.

  1. Claude Code 설치: 공식 설치 프로그램을 사용하세요(예: npm install -g @anthropic-ai/claude-code).
  2. 설정 추가: ~/.claude/settings.json을 열어 아래 env 블록을 추가하고, ANTHROPIC_AUTH_TOKEN 값을 AnyAIGC에서 만든 키로 바꿉니다.
  3. 코딩 시작: 프로젝트 폴더에서 claude를 실행하세요. /model을 입력해 현재 모델이 kimi-k3인지 확인하세요.

보조 작업 비용 절감: ANTHROPIC_DEFAULT_HAIKU_MODEL을 kimi-k2.7-code로 설정하면 Claude Code의 가벼운 하위 작업은 더 저렴한 모델을 사용하고, 주 작업은 K3로 계속 실행됩니다.

전체 절차와 자주 발생하는 오류는 Claude Code 설정 가이드를 참고하세요. 가이드의 모델 이름을 kimi-k3로 바꾸면 됩니다.

FAQ

Kimi K3 API FAQ

Kimi K3 API 요금은 얼마입니까?

AnyAIGC에서 kimi-k3는 토큰 단위로 과금됩니다. 입력 100만 토큰당 $1.2150, 출력 100만 토큰당 $6.0750, 캐시 히트 100만 토큰당 $0.1215입니다. Moonshot 공식 USD 가격은 입력 $3.00, 출력 $15.00, 캐시 히트 $0.30이므로 AnyAIGC는 공식 정가의 약 40%입니다. 출력에는 사고 토큰이 포함됩니다. 실시간 가격은 모델 카탈로그에서 확인하세요.

Kimi K3의 모델 ID와 컨텍스트 길이는 어떻게 됩니까?

모델 ID는 kimi-k3입니다. Moonshot은 컨텍스트 길이를 1,048,576 토큰(1M)으로 명시합니다. max_completion_tokens의 기본값은 131,072이며 최대 1,048,576까지 설정할 수 있습니다.

Kimi K3의 차별점은 무엇입니까?

Moonshot은 Kimi K3가 파라미터 2.8조에 도달한 최초의 오픈소스 모델이라고 밝혔습니다. Kimi Delta Attention(KDA) 하이브리드 선형 어텐션과 Attention Residuals를 기반으로 하고, MoE는 토큰마다 896개 전문가 중 16개를 활성화하며, 네이티브 비전을 지원합니다. Moonshot은 K2 대비 전체 스케일링 효율이 약 2.5배라고 보고했으며, 장시간 코딩, 지식 업무, 추론을 목표로 합니다.

Kimi K3의 사고 깊이는 어떻게 조절합니까?

K3는 항상 사고하며 사고 모드를 끌 수 없습니다. 요청 본문 최상위의 reasoning_effort 필드로 깊이를 설정하세요: low, high, max(기본값 max). 간단한 작업에는 low를 사용해 출력 토큰을 줄이세요.

Kimi K3는 도구 호출과 이미지 입력을 지원합니까?

네. K3는 함수 호출(tools / tool_choice), 구조화된 출력(json_schema), 스트리밍, 이미지 입력을 지원합니다. 멀티턴 대화와 도구 호출에서는 어시스턴트 메시지 전체(reasoning_content와 tool_calls 포함)를 다음 요청에 그대로 다시 보내세요.

Claude Code에서 Kimi K3를 사용할 수 있습니까?

네. ~/.claude/settings.json의 env 블록에서 ANTHROPIC_BASE_URL을 https://anyaigc.ai로, ANTHROPIC_AUTH_TOKEN을 API 키로, ANTHROPIC_MODEL을 kimi-k3로 설정한 뒤 claude를 실행하세요.

Kimi K3와 K3.1 Pro는 어떻게 다릅니까?

Kimi K3.1 Pro는 K3.1 시리즈의 첫 모델입니다. Moonshot은 K3에 훨씬 많은 사후 학습 연산을 투입한 모델이며 코딩, 3D 제작, 금융 리서치, 장기 에이전트에서 뚜렷한 향상이 있다고 밝혔습니다. K3와 동일한 파라미터 제약을 유지하므로 모델 이름만 바꾸면 마이그레이션할 수 있습니다. AnyAIGC에서 K3.1 Pro는 입력 $0.8100, 출력 $4.0500으로 K3보다 약 3분의 1 저렴합니다. 새 프로젝트는 K3.1 Pro부터 시작하세요.

Kimi K3와 K2.7 Code 중 무엇을 써야 합니까?

K3는 컨텍스트 길이 1M의 2.8T 파라미터 이전 세대 플래그십으로, 대형 저장소, 장시간 작업, 가장 어려운 추론에 적합합니다. K2.7 Code는 컨텍스트 길이 256K의 1T 파라미터 코딩 모델이며, AnyAIGC에서 입력 $0.3847, 출력 $1.5980이라 K3의 약 3분의 1입니다. 많은 팀이 평소에는 K2.7 Code를 쓰다가 어려운 문제에서만 같은 키로 K3로 전환합니다.

동시 실행 수나 속도 제한이 있습니까?

AnyAIGC는 kimi-k3의 동시 실행을 제한하지 않으며, 모든 사용자에게 기본으로 적용됩니다. 배치 작업, CI 파이프라인, 병렬 에이전트에 적합합니다. Moonshot 자체 플랫폼은 충전 등급에 따라 동시 실행, RPM, TPM, TPD를 제한하지만, AnyAIGC를 통해 호출할 때는 이 등급이 적용되지 않습니다.

Kimi K3 API 키는 어떻게 받습니까?

anyaigc.ai에 가입하고 잔액을 충전한 뒤 콘솔에서 키를 만드세요. 같은 키로 모든 Kimi 모델과 플랫폼의 다른 300개 이상의 모델을 호출할 수 있으므로 별도의 Moonshot 플랫폼 계정이 필요 없습니다.

AnyAIGC에서 인보이스를 받을 수 있습니까?

네. 콘솔에서 실제 충전한 금액 기준으로 직접 인보이스를 발급할 수 있습니다.

어떤 결제 수단을 지원합니까?

WeChat Pay, Alipay, USDT, 신용카드로 충전할 수 있습니다. 잔액은 USD 기준이며 플랫폼의 모든 모델에서 사용할 수 있습니다. 인보이스는 콘솔에서 충전한 금액 기준으로 발급할 수 있습니다.

신규 사용자에게 무료 체험 크레딧이 있습니까?

네. 신규 계정에는 토큰 200만 개 분량의 체험 크레딧이 제공되므로 충전 여부를 결정하기 전에 먼저 테스트할 수 있습니다. 충전은 $1부터 가능합니다.

잔액을 환불받을 수 있습니까?

네. 사용하지 않은 잔액은 수수료 없이 환불받을 수 있습니다. 환불은 고객 지원에 문의해 진행하세요.

실제 모델이 맞습니까? 데이터는 안전합니까?

요청은 공식 모델 채널로 전달되며, 저가 모델이나 리버스 엔지니어링 방식의 대체 모델은 사용하지 않습니다. 법령에서 요구하는 경우를 제외하고 프롬프트와 출력을 영구 저장하거나 학습에 사용하지 않으며, 콘솔에서 모든 요청의 토큰 수와 비용을 확인할 수 있습니다.

내 데이터가 학습에 사용됩니까?

아니요. 법령에서 요구하는 경우를 제외하고 AnyAIGC는 프롬프트와 출력을 영구 저장하지 않으며 모델 학습에도 사용하지 않습니다. 요청은 HTTPS로 암호화됩니다. AnyAIGC 개인정보 처리방침을 참고하세요. 모델 자체의 데이터 정책은 Moonshot AI의 공식 약관을 따릅니다.
