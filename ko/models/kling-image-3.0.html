빠른 시작

Kling Image 3.0 API 연동

  1. 1가입하고 API 키를 만든 다음 ANYAIGC_API_KEY 설정
  2. 2POST /tencent-vod/v1/aigc-image로 작업을 제출하고 TaskId 받기
  3. 3GET /tencent-vod/v1/query/{task_id}를 폴링하고 Status가 FINISH가 되면 이미지 다운로드

model_name은 "Kling", model_version은 "3.0", output_config.resolution은 대문자 "2K" 또는 "4K"로 설정하세요. 결과는 Response.AigcImageTask.Output.FileInfos[].FileUrl에 있으며, 만료 시간이 있는 임시 저장소이므로 바로 다운로드하세요.

Python

import json
import os
import time
import urllib.request

BASE = "https://anyaigc.ai"
HEADERS = {
    "Authorization": "Bearer " + os.environ["ANYAIGC_API_KEY"],
    "Content-Type": "application/json",
}


def call(method, path, payload=None):
    data = json.dumps(payload, ensure_ascii=False).encode("utf-8") if payload else None
    request = urllib.request.Request(BASE + path, data=data, headers=HEADERS, method=method)
    with urllib.request.urlopen(request, timeout=60) as response:
        return json.load(response)


payload = {
    "model_name": "Kling",
    "model_version": "3.0",
    "prompt": "An orange cat on a rain-soaked windowsill, a neon-lit street outside, cinematic lighting, rich detail",
    "output_config": {
        "aspect_ratio": "16:9",
        "resolution": "2K"
    }
}

task_id = call("POST", "/tencent-vod/v1/aigc-image", payload)["Response"]["TaskId"]
print("task_id:", task_id)

# Poll every 5 seconds; print the image URL once Status is FINISH
for _ in range(60):
    result = call("GET", f"/tencent-vod/v1/query/{task_id}")["Response"]
    if result["Status"] == "FINISH":
        break
    time.sleep(5)
else:
    raise TimeoutError(task_id)

for item in result["AigcImageTask"]["Output"]["FileInfos"]:
    print(item["FileUrl"])

FAQ

Kling Image 3.0 API 자주 묻는 질문

Kling Image 3.0 API 가격은 얼마입니까?

호출당 $0.00169이며 이미지 1장을 반환합니다. 2K와 4K의 가격은 같습니다. 가격은 USD 기준이며 제출 성공 시 과금됩니다. 현재 요금은 모델 카탈로그를 확인하세요.

어떤 엔드포인트를 호출해야 합니까?

POST /tencent-vod/v1/aigc-image로 제출하면서 model_name을 Kling, model_version을 3.0으로 설정하고, GET /tencent-vod/v1/query/{task_id}로 결과를 가져옵니다. API 호스트는 https://anyaigc.ai이고 헤더는 Authorization: Bearer <API Key>입니다.

해상도는 어떻게 설정합니까?

output_config.resolution을 대문자 "2K" 또는 "4K"로 설정하세요. 두 해상도의 가격은 같습니다.

어떤 생성 모드를 지원합니까?

텍스트→이미지, 이미지→이미지, 다중 이미지 참조, 스타일 변환, 캐릭터 참조, 인페인팅을 지원합니다. 참조 이미지는 file_infos에 넣으세요. 정확한 필드는 API 레퍼런스를 참고하세요.

결과는 어떻게 받습니까?

API는 비동기입니다. 제출하면 Response.TaskId가 반환되며, 조회 엔드포인트를 폴링해 Status가 FINISH가 되면 Response.AigcImageTask.Output.FileInfos[].FileUrl에서 이미지를 다운로드하세요. 파일은 임시로 저장되며 만료됩니다.

동시 실행 제한이 있습니까?

AnyAIGC의 Kling 모델은 모든 계정에 기본적으로 동시 실행 제한이 없습니다.

생성한 이미지를 상업적으로 사용할 수 있습니까?

사용 권한과 콘텐츠 정책은 Kuaishou Kling의 공식 약관을 따릅니다. 업로드하는 참조 이미지에 대한 권리가 있는지 확인하세요.

AnyAIGC에서 인보이스를 받을 수 있습니까?

네. 콘솔에서 실제 충전한 금액 기준으로 직접 인보이스를 발급할 수 있습니다.

어떤 결제 수단을 지원합니까?

WeChat Pay, Alipay, USDT, 신용카드로 충전할 수 있습니다. 잔액은 USD 기준이며 플랫폼의 모든 모델에서 사용할 수 있습니다. 인보이스는 콘솔에서 충전한 금액 기준으로 발급할 수 있습니다.

신규 사용자에게 무료 체험 크레딧이 있습니까?

네. 신규 계정에는 토큰 500만 개 분량의 체험 크레딧이 제공되므로 충전 여부를 결정하기 전에 먼저 테스트할 수 있습니다. 충전은 $1부터 가능합니다.

잔액을 환불받을 수 있습니까?

네. 사용하지 않은 잔액은 수수료 없이 환불받을 수 있습니다. 환불은 고객 지원에 문의해 진행하세요.

실제 모델이 맞습니까? 데이터는 안전합니까?

요청은 공식 모델 채널로 전달되며, 더 저렴하거나 리버스 엔지니어링한 대체 모델은 사용하지 않습니다. 법률상 필요한 경우를 제외하고 프롬프트와 출력을 영구 저장하거나 학습에 사용하지 않으며, 콘솔에서 모든 요청의 비용을 확인할 수 있습니다.
