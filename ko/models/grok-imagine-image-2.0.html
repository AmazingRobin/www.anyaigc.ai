Grok Imagine Image 2.0이란

Grok Imagine Image 2.0은 xAI가 2026년 8월에 출시한 이미지 모델입니다. grok.com과 Grok 앱에서는 새로운 Quality 모드이고, API에서는 grok-imagine-image-2.0입니다. xAI는 업무에 바로 쓸 수 있는 이미지를 만드는 모델로 소개합니다. 프롬프트의 세부 사항을 충실히 따르고, 디자이너처럼 텍스트와 레이아웃을 구성하며, 사용자가 제공한 내용을 생성과 편집을 거쳐도 유지합니다.

xAI의 출시 게시글에 따르면 Arena의 이미지 편집과 텍스트→이미지 리더보드에서 모두 2위를 기록했습니다(2026년 8월 7일 기준 데이터). xAI는 2026년 11월부터 기존 grok-imagine-image-quality를 이 모델에 통합했습니다.

AnyAIGC에서는 해상도와 품질에 따라 이미지당 $0.0179(1K Low)에서 $0.0357(2K Medium)까지이며, xAI 공식 정가 이미지당 $0.04–$0.08보다 약 55% 저렴합니다. 편집 시 입력 이미지당 $0.00447이 추가됩니다.

Grok Imagine Image 2.0 API FAQ

Grok Imagine Image 2.0 API 요금은 얼마입니까?

AnyAIGC에서 Grok Imagine Image 2.0(grok-imagine-image-2.0)은 해상도와 품질에 따라 과금합니다. 1K / 1.5K / 2K 기준 이미지당 Low는 $0.0179 / $0.0223 / $0.0268, Medium은 $0.0268 / $0.0313 / $0.0357입니다. 편집 시 입력 이미지당 $0.00447이 추가됩니다. xAI 공식 정가는 이미지당 $0.04–$0.08에 입력 이미지당 $0.01이므로 AnyAIGC가 약 55% 저렴합니다. 생성에 성공한 건에 대해서만 과금하며, 실시간 가격은 모델 카탈로그에서 확인하세요.

Image 2.0은 이전 Grok Imagine과 무엇이 다릅니까?

2.0은 타이포그래피, 프롬프트 준수, 편집이 개선되었습니다. 인포그래픽과 포스터의 작은 글씨가 더 선명해졌고, 여러 차례 편집해도 원본 내용이 유지됩니다. 또한 quality(low / medium / auto)와 21:9, 5:2 두 가지 새 비율이 추가되었습니다. 1세대 grok-imagine-image는 이미지당 $0.0119로 계속 사용할 수 있습니다.

quality 파라미터는 어떻게 설정합니까?

quality는 low, medium, auto를 받습니다. xAI 문서에 따르면 기본값 auto는 현재 생성에는 low, 편집에는 medium을 사용합니다. Low는 더 빠르고 medium은 디테일이 더해집니다. AnyAIGC에서는 Medium이 더 비쌉니다. 1K 기준 이미지당 Low는 $0.0179, Medium은 $0.0268입니다.

지원하는 종횡비와 해상도는 무엇입니까?

aspect_ratio는 1:1, 3:4, 4:3, 9:16, 16:9, 2:3, 3:2, 9:19.5, 19.5:9, 9:20, 20:9, 1:2, 2:1, 21:9, 5:2 또는 auto를 지원합니다. resolution은 1k, 1.5k, 2k 중에서 설정하세요.

이미지는 어떻게 편집합니까? 참조 이미지를 여러 장 쓸 수 있습니까?

image, prompt, model을 multipart/form-data로 POST /v1/images/edits에 보내세요. 바꿀 부분만 설명하면 나머지는 그대로 유지됩니다. xAI는 요청당 최대 5장의 참조 이미지 합성을 지원하지만, AnyAIGC 문서에는 현재 이미지 1장 예시만 있으므로 다중 이미지 입력은 AnyAIGC API 문서를 확인하세요.

grok-imagine-image-quality는 아직 작동합니까?

xAI는 2026년 11월 2일에 grok-imagine-image-quality를 2.0에 통합했으므로, 해당 요청은 2.0이 low 품질로 처리합니다. AnyAIGC에서는 기존 코드가 계속 실행되지만(이미지당 $0.0223부터), 2.0의 Low 품질이 모든 해상도에서 이미지당 $0.0044–$0.0045 더 저렴하므로 model을 grok-imagine-image-2.0으로 바꾸면 비용을 아낄 수 있습니다.

xAI 계정이 필요합니까?

필요하지 않습니다. AnyAIGC에 가입해 API 키를 받으세요. 엔드포인트는 https://anyaigc.ai이며, 같은 키로 플랫폼의 300개 이상의 다른 모델도 사용할 수 있습니다.

동시 실행 제한이 있습니까?

AnyAIGC는 Grok Image 모델에 동시 실행 제한을 두지 않습니다. 모든 계정에 기본 적용되므로 배치 작업에 할당량 신청이 필요 없습니다.

AnyAIGC에서 인보이스를 받을 수 있습니까?

네. 콘솔에서 실제 충전한 금액 기준으로 직접 인보이스를 발급할 수 있습니다.

어떤 결제 수단을 지원합니까?

WeChat Pay, Alipay, USDT, 신용카드로 충전할 수 있습니다. 잔액은 USD 기준이며 플랫폼의 모든 모델에서 사용할 수 있습니다. 인보이스는 콘솔에서 충전한 금액 기준으로 발급할 수 있습니다.

신규 사용자에게 무료 체험 크레딧이 있습니까?

네. 신규 계정에는 토큰 200만 개 분량의 체험 크레딧이 제공되므로 충전 여부를 결정하기 전에 먼저 테스트할 수 있습니다. 충전은 $1부터 가능합니다.

잔액을 환불받을 수 있습니까?

네. 사용하지 않은 잔액은 수수료 없이 환불받을 수 있습니다. 환불은 고객 지원에 문의해 진행하세요.

실제 모델이 맞습니까? 데이터는 안전합니까?

요청은 공식 모델 채널로 전달되며, 저가 모델이나 리버스 엔지니어링 방식의 대체 모델은 사용하지 않습니다. 법령에서 요구하는 경우를 제외하고 프롬프트와 출력을 영구 저장하거나 학습에 사용하지 않으며, 콘솔에서 모든 요청의 토큰 수와 비용을 확인할 수 있습니다.

생성한 이미지를 상업적으로 사용할 수 있습니까?

사용 권한과 콘텐츠 정책은 xAI 공식 약관을 따릅니다. AnyAIGC는 API 접근만 제공하며, 결과물 사용에 별도 제한을 추가하지 않습니다.
