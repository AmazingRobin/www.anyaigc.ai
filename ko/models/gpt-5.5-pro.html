GPT-5.5 Pro API

더 많은 연산, 더 깊은 답변, 공식 정가 대비 41% 할인

OpenAI는 GPT-5.5 Pro가 더 많은 연산으로 더 깊이 생각하며, 정확도가 가장 중요한 매우 복잡한 문제를 위해 만들었다고 설명합니다. OpenAI는 BrowseComp 90.1%, FrontierMath Tier 4 39.6%를 보고했습니다. AnyAIGC에서 gpt-5.5-pro를 입력 100만 토큰당 $17.8200, 출력 100만 토큰당 $106.9200에 호출할 수 있습니다. 여전히 비싸므로 가치가 큰 소수의 질문에만 사용하세요.

OpenAI는 2026년 4월 23일 GPT-5.5와 GPT-5.5 Pro를 출시했고, API는 다음 날부터 사용할 수 있었습니다. OpenAI는 GPT-5.5 Pro를 "더 많은 연산으로 더 깊이 생각해 일관되게 더 나은 답변을 제공한다"고 설명하며, 출시 글에서는 매우 높은 정확도가 필요한 극도로 복잡한 문제를 위해 설계했다고 밝혔습니다. OpenAI에 따르면 테스터들은 이 모델의 답변이 GPT-5.4 Pro보다 더 포괄적이고 구조가 좋으며 정확하다고 평가했고, 비즈니스, 법률, 교육, 데이터 사이언스에서 강한 결과를 보였습니다.

GPT-5.5 Pro는 medium, high(기본값), xhigh의 세 가지 추론 강도(reasoning effort)를 지원합니다. 컨텍스트 길이는 1,050,000 토큰, 최대 출력은 128,000 토큰이며, 텍스트와 이미지를 입력받아 텍스트를 출력합니다. 지식 기준일은 2025년 12월 1일입니다. OpenAI는 날짜가 붙은 스냅샷 gpt-5.5-pro-2026-04-23도 제공합니다.

OpenAI에 따르면 GPT-5.5 Pro는 Responses API로만 사용할 수 있습니다. Chat Completions와 스트리밍은 지원하지 않으며, 캐시 입력 할인도 없습니다. 일부 요청은 몇 분이 걸리므로 OpenAI는 타임아웃을 피하기 위해 백그라운드 모드(background mode)를 권장합니다. AnyAIGC에서는 https://anyaigc.ai/v1/responses를 호출하세요. 공식 OpenAI SDK를 쓴다면 base_url만 https://anyaigc.ai/v1로 바꾸면 됩니다.

3단계로 GPT-5.5 Pro API 호출하기

  1. 가입 후 충전: anyaigc.ai에서 계정을 만드세요. 잔액은 모든 모델에서 공통으로 사용할 수 있습니다.
  2. API 키 만들기: 콘솔에서 토큰을 만들고 sk- 키를 복사해 ANYAIGC_API_KEY 환경 변수에 저장하세요. Pro는 비싸므로 이 키에 사용 한도를 설정하세요.
  3. 요청 보내기: model을 gpt-5.5-pro로 지정하고 Authorization: Bearer 인증으로 https://anyaigc.ai/v1/responses를 호출하세요.

Responses API 전용. OpenAI에 따르면 gpt-5.5-pro는 /v1/chat/completions와 스트리밍(stream)을 지원하지 않습니다. /v1/responses를 호출하고 reasoning.effort로 강도를 지정하며, 클라이언트 타임아웃을 늘리세요. 일부 요청은 몇 분이 걸리므로 OpenAI는 백그라운드 모드(background: true)로 요청한 뒤 결과를 폴링하도록 권장합니다.

모든 파라미터는 Responses 레퍼런스를 참고하세요. 필드는 공식 OpenAI API와 동일합니다.

Codex에서 GPT-5.5 Pro 사용하기

Pro는 느리고 비싸므로 대화형 코딩의 기본 모델로는 적합하지 않습니다. 더 빠른 기본 모델을 유지하고, 어려운 일회성 작업에만 Pro로 전환하세요.

한 줄 설치 스크립트는 모델을 gpt-5.5로 설정합니다. 이후 위와 같은 [profiles.pro] 블록을 추가하고 model을 gpt-5.5-pro로 지정하세요. 평소에는 codex를 실행하고, Pro를 쓸 만큼 어려운 작업에는 codex --profile pro를 실행하세요. Pro는 응답 하나에 몇 분이 걸릴 수 있고 비용도 훨씬 큽니다. 전체 절차와 자주 발생하는 오류는 Codex 설정 가이드를 참고하세요.

초기 테스터들은 GPT-5.5 Pro의 답변이 포괄성, 구조, 정확성, 유용성에서 GPT-5.4 Pro보다 낫다고 평가했으며, 특히 비즈니스, 법률, 교육, 데이터 사이언스 분야에서 그랬습니다.

이 페이지에는 입력 $17.8200, 출력 $106.9200으로 표시되어 있으며, 위 가격표와 일치합니다.

gpt-5.5와 비교하면 gpt-5.5-pro는 더 높은 정확도가 필요한 어려운 작업을 대상으로 합니다.

사양은 제공사의 공식 문서(openai.com)를 따랐습니다. 이 페이지의 표가 가격이며, 실시간 요금은 모델 카탈로그를 기준으로 합니다.

GPT-5.5 Pro API 자주 묻는 질문

GPT-5.5 Pro API 요금은 얼마입니까?

AnyAIGC에서 gpt-5.5-pro는 토큰 단위로 과금하며, 입력 100만 토큰당 $17.8200, 출력 100만 토큰당 $106.9200입니다. OpenAI 공식 정가는 입력 $30.00, 출력 $180.00이므로 AnyAIGC는 공식 정가의 약 59.4%(41% 할인)입니다. OpenAI에 따르면 GPT-5.5 Pro에는 캐시 입력 할인이 없어 반복 입력도 입력 요율로 과금됩니다.

GPT-5.5 Pro의 모델 ID는 무엇입니까?

모델 ID는 gpt-5.5-pro입니다. 요청의 model 필드에 넣으세요. OpenAI는 날짜가 붙은 스냅샷 gpt-5.5-pro-2026-04-23도 제공합니다.

GPT-5.5 Pro와 GPT-5.5는 무엇이 다릅니까?

OpenAI는 GPT-5.5 Pro를 더 많은 연산으로 더 깊이 생각하는 GPT-5.5의 버전이라고 설명하며, 정확도가 가장 중요한 극도로 복잡한 문제를 대상으로 합니다. OpenAI가 공개한 결과에서 Pro는 BrowseComp 90.1%로 표준 GPT-5.5의 84.4%보다 높고, 표준 GPT-5.5는 GDPval에서 더 높은 점수를 받았습니다(84.9% vs 82.3%). Pro는 Responses API 전용이며 스트리밍과 캐시 할인이 없고, medium, high(기본값), xhigh 강도를 지원합니다. AnyAIGC에서 GPT-5.5는 100만 토큰당 입력 $0.2482, 출력 $1.4890이고, Pro는 입력 $17.8200, 출력 $106.9200입니다. 표준 GPT-5.5로 시작하고, 틀린 답의 비용이 큰 어려운 문제에서 Pro로 올리세요.

GPT-5.5 Pro는 비쌉니다. 비용을 줄이려면 어떻게 합니까?

high 강도로 시작하고 xhigh는 필요할 때만 사용하세요. 추론 토큰은 출력으로 과금되기 때문입니다. Pro에는 캐시 할인이 없으므로 필요한 컨텍스트만 보내세요. max_output_tokens로 응답마다 상한을 두고, 콘솔에서 Pro용 API 키에 사용 한도를 설정하며, 일상적인 질문은 GPT-5.5나 GPT-6.1 Sol로 보내 어려운 질문만 Pro에 도달하게 하세요.

Chat Completions나 스트리밍을 사용할 수 있습니까?

아니요. OpenAI에 따르면 gpt-5.5-pro는 Responses API(Batch 포함)로만 사용할 수 있습니다. /v1/chat/completions와 스트리밍은 지원하지 않습니다. https://anyaigc.ai/v1/responses를 호출하고 reasoning.effort로 강도를 지정하세요.

요청이 느린 이유는 무엇이며 타임아웃을 어떻게 피합니까?

Pro는 추론에 더 많은 연산을 쓰며, OpenAI에 따르면 일부 요청은 몇 분이 걸립니다. 클라이언트 타임아웃을 10분 이상으로 늘리세요. OpenAI가 권장하는 더 안전한 방법은 백그라운드 모드입니다. 요청에 background: true를 추가한 뒤, 반환된 id로 responses.retrieve를 폴링해 상태가 queued나 in_progress가 아닐 때까지 기다리세요.

Codex에서 GPT-5.5 Pro를 사용할 수 있습니까?

가능하지만 느리고 비싸서 기본 모델로는 적합하지 않습니다. curl -fsSL https://www.anyaigc.ai/install.sh | bash -s codex를 실행해 설치하고(Windows에서는 irm https://www.anyaigc.ai/install.ps1 | iex), ~/.codex/config.toml에 [profiles.pro] 블록을 추가해 model을 gpt-5.5-pro로 지정하세요. 평소에는 기본 모델을 쓰고, 어려운 작업에만 codex --profile pro를 실행하세요.

GPT-5.5 Pro는 지원 중단되었습니까? 언제까지 사용할 수 있습니까?

지원 중단되지 않았습니다. OpenAI는 GPT-5.6과 GPT-6 제품군을 출시했지만 API의 gpt-5.5-pro 종료 일정은 발표하지 않았으며, AnyAIGC에서는 지금도 정상적으로 작동합니다. 지원이 중단된 이전 Pro 모델의 경우 OpenAI의 지원 중단 안내 페이지는 pro 모드의 GPT-5.6 Sol(reasoning.mode: pro)을 가리킵니다. 새 프로젝트에는 GPT-6 Astra나 GPT-5.6 Sol을 검토하세요.

API 키는 어떻게 받습니까?

anyaigc.ai에서 가입하고 충전한 뒤 콘솔에서 토큰을 만드세요. 같은 키로 GPT-5.5 Pro와 300개 이상의 다른 모델을 사용할 수 있습니다. 공식 OpenAI SDK를 쓴다면 base_url만 https://anyaigc.ai/v1로 설정하면 됩니다.

AnyAIGC에서 인보이스를 받을 수 있습니까?

네. 콘솔에서 실제 충전한 금액 기준으로 직접 인보이스를 발급할 수 있습니다.

어떤 결제 수단을 지원합니까?

WeChat Pay, Alipay, USDT, 신용카드로 충전할 수 있습니다. 잔액은 USD 기준이며 플랫폼의 모든 모델에서 사용할 수 있습니다. 인보이스는 콘솔에서 충전한 금액 기준으로 발급할 수 있습니다.

신규 사용자에게 무료 체험 크레딧이 있습니까?

네. 신규 계정에는 토큰 500만 개 분량의 체험 크레딧이 제공되므로 충전 여부를 결정하기 전에 먼저 테스트할 수 있습니다. 충전은 $1부터 가능합니다.

잔액을 환불받을 수 있습니까?

네. 사용하지 않은 잔액은 수수료 없이 환불받을 수 있습니다. 환불은 고객 지원에 문의해 진행하세요.

실제 모델이 맞습니까? 데이터는 안전합니까?

요청은 공식 모델 채널로 전달되며, 저가 모델이나 리버스 엔지니어링 방식의 대체 모델은 사용하지 않습니다. 법령에서 요구하는 경우를 제외하고 프롬프트와 출력을 영구 저장하거나 학습에 사용하지 않으며, 콘솔에서 모든 요청의 토큰 수와 비용을 확인할 수 있습니다.

내 데이터가 학습에 사용됩니까?

아니요. 법령에서 요구하는 경우를 제외하고 AnyAIGC는 프롬프트와 출력을 영구 저장하지 않으며 학습에 사용하지 않습니다. 요청은 HTTPS로 전송 중에 암호화됩니다. 자세한 내용은 AnyAIGC 개인정보 처리방침을 참고하세요. 모델 자체의 데이터 정책은 OpenAI 공식 약관을 따릅니다.
