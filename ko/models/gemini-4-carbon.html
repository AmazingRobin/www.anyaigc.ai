Gemini 4 Carbon API

Gemini 4 Argon을 기반으로 한 Google의 프런티어 모델로, 장시간 에이전트, 복잡한 엔지니어링, 사이버 방어에 적합합니다. AnyAIGC에서는 Google 공식 정가보다 64% 저렴합니다.

Google에 따르면 Gemini 4 Carbon은 더 많은 사고 토큰을 사용해 깊이 추론하고 결과를 검증하며, 모델에게 가장 어려운 작업을 대상으로 합니다. gemini-4-carbon의 요금은 입력 100만 토큰당 $0.7147, 출력 100만 토큰당 $3.5740이며, 네이티브 Gemini API와 OpenAI 호환 API를 모두 지원합니다.

모델 소개

Argon 기반, 장시간 에이전트와 가장 어려운 문제를 위한 모델

Google은 2026년 10월에 Gemini 4 Carbon을 발표한 뒤, 2026년 11월 10일에 모델 카드를 공개하고 Gemini API에서 사용할 수 있게 했습니다. 모델 카드에 따르면 Carbon은 Gemini 4 Argon을 기반으로 하며, 복잡한 지식 업무, 엔지니어링, 사이버 보안, 과학적 추론에 걸친 장시간 에이전트 워크플로에서 프런티어급 성능을 제공합니다.

Argon과 비교하면 Carbon은 더 많은 사고 토큰을 사용해 가설을 탐색하고, 깊이 추론하며, 확장된 검증 루프를 실행합니다. 품질, 지연 시간, 비용 사이의 균형은 사고 수준(thinking level)으로 조절할 수 있습니다. Google은 높은 사고 수준에서는 토큰을 더 많이 사용하고 가끔 응답이 느릴 수 있으며, Argon은 더 빠르고 턴당 토큰을 적게 사용한다고 설명합니다. 두 모델 모두 1,048,576 토큰 컨텍스트 길이와 2026년 3월 지식 컷오프를 공유합니다.

AnyAIGC에서 gemini-4-carbon은 네이티브 /v1beta/models/gemini-4-carbon:generateContent 엔드포인트와 OpenAI 호환 /v1/chat/completions를 모두 지원합니다. Google Cloud 계정이 필요 없으며, 같은 키로 플랫폼의 300개 이상 다른 모델도 호출할 수 있습니다.

사용 사례

Gemini 4 Carbon으로 만들 수 있는 것

  • 01 · 소프트웨어 엔지니어링

    장시간 실행 코딩 에이전트

    저장소 전체를 1M 토큰 컨텍스트에 넣고 모듈 간 리팩터링, 까다로운 버그, 멀티 에이전트 개발을 Carbon에 맡기세요. 가장 어려운 작업에는 high 사고 수준을 사용하고, 일상적인 변경은 Argon으로 바꿔 비용을 줄이세요.

  • 02 · 지식 업무

    고정밀 분석과 아티팩트

    리서치를 종합하고 데이터를 분석하며 보고서와 스프레드시트를 생성하세요. 구조화된 출력을 시스템에 바로 연결할 수 있습니다. Carbon은 추론을 추가로 검증하는 데 시간을 쓰므로 정확도가 가장 중요할 때 도움이 됩니다.

  • 03 · 사이버 보안

    코드 감사와 취약점 수정

    자사 시스템을 감사하고 취약점을 찾아 패치를 작성하세요. 모델 카드에는 CWE-bench 71.0%가 기재되어 있습니다. 반드시 정당하게 승인된 범위 안에서만 사용하세요.

  • 04 · 연구

    물리, 수학, 생명과학

    논문, 실험 데이터, 코드를 하나의 컨텍스트에 불러와 분석을 유도하고 검증하고 스크립트로 작성하세요. 캐시 히트는 100만 토큰당 $0.0357이므로 같은 자료를 다시 읽어도 비용이 낮습니다.

빠른 시작

3단계로 Gemini 4 Carbon API 호출하기

  1. 가입 및 충전: anyaigc.ai에서 계정을 만드세요. 잔액은 플랫폼의 모든 모델에서 공통으로 사용됩니다.
  2. API 키 만들기: 콘솔에서 토큰을 만들고 sk-로 시작하는 키를 복사해 ANYAIGC_API_KEY 환경 변수에 저장하세요.
  3. 요청 보내기: 네이티브 엔드포인트 https://anyaigc.ai/v1beta/models/gemini-4-carbon:generateContent를 호출하거나, model을 gemini-4-carbon으로 지정해 OpenAI 호환 https://anyaigc.ai/v1/chat/completions를 호출하세요. 둘 다 Authorization: Bearer로 인증합니다.

파라미터 참고: Gemini 4 Carbon은 thinkingLevel(low / medium / high)을 사용하며 기본값은 medium입니다. Carbon은 Argon보다 더 많이 사고하고 사고 토큰도 출력에 포함되므로 maxOutputTokens를 32,768 이상, HTTP 타임아웃을 15분 이상으로 설정하세요. 비용에 민감한 작업은 low 또는 medium으로 시작하세요. 네이티브 스트리밍은 :streamGenerateContent?alt=sse를 호출하세요.

모든 파라미터는 네이티브 Gemini API 문서와 Chat Completions 문서를 참고하세요. 예제의 모델 이름을 gemini-4-carbon으로 바꾸면 됩니다.

사양과 선택 기준

Google 문서는 Gemini 4 Carbon을 복잡한 소프트웨어 엔지니어링, 수학·과학 문제, 높은 사실 정확도, 자율적인 다단계 에이전트를 위한 가장 높은 성능의 추론 모델로 소개합니다.

컨텍스트 길이는 1,048,576 토큰(입력과 출력 합산)이고, 최대 출력은 기본 65,536 토큰, 긴 디코딩 사용 시 최대 1,048,576 토큰입니다. 입력은 텍스트, 이미지, 동영상, 오디오, PDF이며 출력은 텍스트입니다.

이 페이지에는 위 가격표와 같이 입력 $0.7147, 출력 $3.5740, 캐시 히트 $0.0357이 표시되어 있습니다.

gemini-4-argon과 비교: Google에 따르면 Argon은 복잡한 코딩, 에이전트, 수학, 과학 작업 전반에서 더 빠르게 응답하고 턴당 토큰을 적게 사용합니다.

사양은 제공사 공식 문서(aistudio.google.com)를 기준으로 합니다. 이 페이지의 표는 가격이며, 실시간 요금은 모델 카탈로그가 기준입니다.

FAQ

Gemini 4 Carbon API 자주 묻는 질문

Gemini 4 Carbon API 요금은 얼마입니까?

AnyAIGC에서 gemini-4-carbon은 토큰 단위로 과금되며, 입력 100만 토큰당 $0.7147, 출력 100만 토큰당 $3.5740, 캐시된 토큰 100만 개당 $0.0357입니다. Google의 프로모션 공식 정가(2026년 11월 30일까지)는 입력 $2.00, 출력 $10.00, 캐시 $0.10이므로 AnyAIGC는 Google 프로모션 공식 정가의 약 36%, 즉 64% 할인된 가격입니다. 출력에는 사고 토큰이 포함됩니다.

Google 프로모션이 끝난 뒤에도 이득입니까?

Google은 2026년 12월 1일부터 표준 가격인 입력 $4.00, 출력 $20.00, 캐시 $0.20(100만 토큰당)으로 돌아갑니다. AnyAIGC의 현재 가격(입력 $0.7147, 출력 $3.5740, 캐시 $0.0357)은 Google 표준 가격의 약 18%입니다. 실시간 가격은 모델 카탈로그에서 확인하세요.

Gemini 4 Carbon의 모델 ID는 무엇이며 어떤 모델을 기반으로 합니까?

모델 ID는 gemini-4-carbon입니다. Google 모델 카드에 따르면 Gemini 4 Carbon은 Gemini 4 Argon을 기반으로 하며, 모델 카드는 Gemini API에서 모델이 공개된 2026년 11월 10일에 게시되었습니다. 네이티브 엔드포인트는 URL에 모델 이름을 넣고(/v1beta/models/gemini-4-carbon:generateContent), OpenAI 호환 엔드포인트는 model 필드로 지정합니다.

컨텍스트 길이와 최대 출력은 얼마입니까?

Google은 입력, 사고, 출력이 함께 쓰는 1,048,576 토큰 컨텍스트 길이를 제공합니다. 동기 요청은 기본적으로 최대 65,536 출력 토큰을 반환하며, Google의 긴 디코딩(최대 약 1M 출력 토큰)은 백그라운드 실행 기능으로 처리됩니다. Carbon은 어려운 문제에서 오래 사고할 수 있으므로 HTTP 클라이언트 타임아웃을 15분 이상으로 설정하세요.

네이티브 Gemini 엔드포인트와 OpenAI 호환 엔드포인트 중 무엇을 써야 합니까?

둘 다 사용할 수 있습니다. 네이티브 엔드포인트는 POST https://anyaigc.ai/v1beta/models/gemini-4-carbon:generateContent이며 요청 본문은 Google Gemini API와 같으므로 contents, systemInstruction, tools, thinkingConfig를 사용할 수 있습니다. OpenAI 호환 엔드포인트는 POST https://anyaigc.ai/v1/chat/completions입니다. 공식 OpenAI SDK에서는 base_url을 https://anyaigc.ai/v1로 설정하세요. 둘 다 Authorization: Bearer를 사용합니다.

사고 수준(thinking level)은 어떻게 설정합니까?

Gemini 4 Carbon은 low, medium, high 세 가지 사고 수준을 지원하며 기본값은 medium입니다. 네이티브 엔드포인트에서는 generationConfig.thinkingConfig.thinkingLevel을 설정하세요. Carbon은 Argon보다 사고 토큰을 더 많이 사용합니다. 수준이 높을수록 결과가 좋아지지만 시간이 더 걸리고 출력 토큰도 더 많이 사용하며, 사고 토큰은 출력 요율로 과금됩니다.

Gemini 4 Carbon과 Gemini 4 Argon 중 무엇을 써야 합니까?

Google은 두 모델을 같은 가격으로 책정했습니다. Carbon은 Argon을 기반으로 더 많이 사고하고 검증하므로 장시간 에이전트, 복잡한 엔지니어링, 사이버 보안, 과학적 추론에 적합하며, Argon은 응답이 더 빠르고 턴당 토큰을 적게 사용합니다. AnyAIGC에서 Gemini 4 Argon은 입력 $0.1985, 출력 $0.9927로 Carbon의 $0.7147, $3.5740보다 저렴합니다. Argon으로 시작하고 가장 어려운 작업에서 Carbon으로 전환하며, 대량 처리에는 Gemini 3.8 Flash를 사용하세요. 세 모델 모두 키 하나로 사용할 수 있습니다.

동시 실행 수나 속도 제한이 있습니까?

AnyAIGC는 gemini-4-carbon에 동시 실행 제한을 두지 않습니다. 모든 계정에 기본 적용되므로 배치 작업이나 병렬로 실행되는 많은 에이전트에 적합합니다.
