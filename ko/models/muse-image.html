Muse Image란 무엇입니까?

Muse Image는 Meta Superintelligence Labs가 2026년 7월에 출시한 이미지 생성 모델로, Muse Spark와 같은 Muse 제품군입니다. Meta는 지시를 충실히 따르는 것, 정밀하게 편집하는 것, 여러 참조 이미지로 합성하는 것 세 가지를 중심에 둡니다.

프롬프트를 곧바로 픽셀로 바꾸는 모델이 아닙니다. 이미지를 그리기 전에 실제 랜드마크, 제품, 최신 이슈를 검색하거나 코드를 작성해 차트와 QR 코드를 정확하게 만들 수 있고, 그 과정에서 초안을 직접 검토하고 수정합니다. Meta에 따르면 Muse Image는 2026년 7월 5일 기준 Arena의 텍스트-이미지, 단일 이미지 편집, 다중 이미지 편집 부문에서 모두 2위를 기록했습니다.

AnyAIGC에서 모델 이름은 muse-image입니다. OpenAI 호환 /v1/images/generations 엔드포인트를 사용하며 이미지당 $0.00596로, Meta의 공식 정가 $0.01보다 낮습니다.

사양과 선택 기준

Meta 공식 개발자 문서에 따르면 Muse Image는 대화형 인터페이스로 이미지를 생성하고 편집합니다. 텍스트와 참조 이미지를 번갈아 입력하면 이미지가 반환되고, 같은 대화에서 턴마다 계속 다듬을 수 있습니다.

편집은 요청한 부분만 바꾸고 나머지는 그대로 유지합니다. 한 요청에 여러 참조 이미지를 넣을 수 있고, 이후 턴에서 새 이미지를 추가할 수도 있습니다.

제공사는 이 모델을 에이전트형이라고 설명합니다. 렌더링 전에 웹에서 참조 이미지와 실제 장소, 제품, 브랜드에 관한 최신 정보를 검색할 수 있고, 코드를 실행해 인포그래픽, 차트 등 구조화된 그래픽을 구성할 수 있습니다.

단일 요청 이미지 엔드포인트는 OpenAI Images API와 호환되므로, base_url을 https://api.meta.ai/v1로 지정하면 OpenAI 클라이언트를 사용할 수 있습니다. size 파라미터는 정확한 픽셀이 아니라 종횡비만 정하며, 출력 형식은 기본 webp이고 png와 jpeg도 선택할 수 있습니다.

이 페이지는 텍스트→이미지 $0.00596 / 이미지, 편집 / 다중 이미지 $0.00596 / 이미지로 표기하며, 위 가격표와 일치합니다.

사양은 제공사의 공식 문서(dev.meta.ai)를 기준으로 합니다. 이 페이지의 표는 가격이며, 실시간 요금은 모델 카탈로그가 기준입니다.

Muse Image란 무엇입니까?

Muse Image는 Meta Superintelligence Labs가 2026년 7월에 공개한 이미지 생성 및 편집 모델입니다. 렌더링 전에 웹을 검색하고 코드를 작성할 수 있으며, 스스로 초안을 다듬습니다. 프롬프트 충실도, 정밀한 편집, 다중 이미지 합성에 맞춰 만들어졌습니다.

크기와 종횡비는 어떻게 지정합니까?

size를 "WxH" 형식으로 전달하세요(예: "1024x1536"). Meta 문서에 따르면 종횡비만 정해지고 모델은 자체 해상도로 렌더링하므로 반환된 크기가 정확히 일치하지 않습니다. 16:1을 넘는 비율은 오류를 반환하며, size를 생략하면 기본 비율을 사용합니다.

요청당 이미지는 몇 장이며 어떤 형식으로 받습니까?

n은 1~10(기본값 1)을 지정할 수 있으며 이미지마다 data 항목이 하나씩 반환됩니다. output_format은 webp(기본값), png, jpeg 중에서 고릅니다. response_format은 기본적으로 base64를 반환하고, url을 지정하면 임시 링크를 반환합니다.

이미지를 편집하거나 여러 참조 이미지를 합칠 수 있습니까?

가능합니다. 하나의 모델이 생성과 편집을 모두 처리합니다. 이미지와 지시를 보내면 해당 부분만 바꾸고, 이미지 여러 장을 보내면 하나의 장면으로 합성합니다. AnyAIGC 모델 카탈로그에는 muse-image가 이미지 편집 엔드포인트 /v1/images/edits에도 등록되어 있으니, 필드는 AnyAIGC API 문서에서 확인하세요.

웹 검색과 코드 도구는 추가 요금이 있습니까?

없습니다. Meta는 내장 검색 및 코드 도구를 이미지당 가격에 포함하며, AnyAIGC도 같은 방식으로 과금합니다. 이미지당 $0.00596이고 도구 요금은 별도로 없습니다.

동시 실행 제한이 있습니까?

네. 콘솔에서 실제 충전한 금액 기준으로 직접 인보이스를 발급할 수 있습니다.

WeChat Pay, Alipay, USDT, 신용카드로 충전할 수 있습니다. 잔액은 USD 기준이며 플랫폼의 모든 모델에서 사용할 수 있습니다. 인보이스는 콘솔에서 충전한 금액 기준으로 발급할 수 있습니다.

신규 사용자에게 무료 체험 크레딧이 있습니까?

네. 신규 계정에는 토큰 200만 개 분량의 체험 크레딧이 제공되므로 충전 여부를 결정하기 전에 먼저 테스트할 수 있습니다. 충전은 $1부터 가능합니다.

잔액을 환불받을 수 있습니까?

네. 사용하지 않은 잔액은 수수료 없이 환불받을 수 있습니다. 환불은 고객 지원에 문의해 진행하세요.

실제 모델이 맞습니까? 데이터는 안전합니까?

요청은 공식 모델 채널로 전달되며, 저가 모델이나 리버스 엔지니어링 방식의 대체 모델은 사용하지 않습니다. 법령에서 요구하는 경우를 제외하고 프롬프트와 출력을 영구 저장하거나 학습에 사용하지 않으며, 콘솔에서 모든 요청의 토큰 수와 비용을 확인할 수 있습니다.

생성한 이미지를 상업적으로 사용할 수 있습니까?

사용 권리와 콘텐츠 정책은 Meta 공식 약관을 따릅니다. AnyAIGC는 API 접근만 제공하며, 결과물 사용 방식에 별도 제한을 두지 않습니다.
