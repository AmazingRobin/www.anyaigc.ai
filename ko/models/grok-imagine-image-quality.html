grok-imagine-image-quality는 어떻게 되었습니까

Grok Imagine Image Quality는 xAI가 2026년 5월에 도입한 고품질 생성·편집 모드로, 더 사실적인 이미지와 향상된 다국어 텍스트 렌더링에 중점을 두었습니다. 2026년 8월 xAI는 Image 2.0을 출시하고 이를 grok.com의 새 Quality 모드로 삼았습니다.

xAI는 2026년 9월에 grok-imagine-image-quality 종료를 발표했고 11월 2일에 완료했습니다. 이 모델명으로 보내는 생성 및 편집 요청은 이제 quality: "low"인 grok-imagine-image-2.0이 처리하며, 요청과 응답 형식은 그대로입니다(xAI 마이그레이션 가이드).

이 모델명은 AnyAIGC에서 계속 사용할 수 있으며 이미지당 $0.0223(1K)에서 $0.0313(2K)까지입니다. Image 2.0 Low 품질은 모든 해상도에서 이미지당 $0.0044–$0.0045 더 저렴하므로 grok-imagine-image-2.0으로 옮기면 비용을 아낄 수 있고, quality: "medium"과 새 21:9, 5:2 비율도 쓸 수 있습니다.

Grok Imagine Image Quality API FAQ

grok-imagine-image-quality는 종료되었습니까?

네. xAI는 2026년 11월 2일에 grok-imagine-image-quality를 종료했습니다. 요청은 이제 quality: "low"인 grok-imagine-image-2.0이 처리하며, 요청과 응답 형식은 그대로입니다. 이 모델명은 AnyAIGC에서 계속 작동하지만, 새 프로젝트에는 Grok Imagine Image 2.0을 사용하세요.

Grok Imagine Image Quality API 요금은 얼마입니까?

AnyAIGC에서는 이미지당 1K $0.0223, 1.5K $0.0268, 2K $0.0313이며, 편집 시 입력 이미지당 $0.00447이 추가됩니다. 각 해상도에서 Image 2.0 Low 품질보다 $0.0044–$0.0045 더 비쌉니다. xAI는 더 이상 Quality의 별도 공식 정가를 게시하지 않습니다. 생성에 성공한 건에 대해서만 과금하며, 실시간 가격은 모델 카탈로그에서 확인하세요.

2.0으로 옮기려면 어떤 코드를 바꿔야 합니까?

model만 grok-imagine-image-2.0으로 바꾸면 됩니다. 엔드포인트, 요청 필드, 응답 형식은 그대로입니다. 2.0은 quality(low / medium / auto)와 21:9, 5:2 비율도 지원합니다.

아무것도 바꾸지 않으면 어떻게 됩니까?

요청은 실패하지 않습니다. 2.0이 low 품질로 처리하며, 응답의 model 필드에 실제로 처리한 모델이 표시됩니다. 계속 Quality 가격을 지불하게 되며, 이는 2.0 Low보다 높습니다. medium 품질을 원하면 2.0으로 바꾸고 quality를 전달하세요.

Image 2.0, Image, Quality 중 어떤 모델을 써야 합니까?

Grok Imagine Image 2.0(grok-imagine-image-2.0)은 xAI가 현재 권장하는 모델로, 타이포그래피, 프롬프트 준수, 편집이 더 강화되었습니다. AnyAIGC에서 이미지당 $0.0179부터 시작하므로 새 프로젝트는 이 모델로 시작하세요. Grok Imagine Image(grok-imagine-image)는 1세대 Imagine 모델로 이미지당 $0.0119이며 시리즈 최저 가격입니다. 단순한 텍스트→이미지와 기존 코드에는 충분합니다. Grok Imagine Image Quality는 xAI가 2026년 11월 2일에 종료했으며, 이 모델로 보낸 요청은 이제 low 품질의 2.0이 처리합니다.
