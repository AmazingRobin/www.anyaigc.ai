Python
import json
import os
import urllib.request

payload = {
    "content": [
        {
            "text": "A sunset over the sea, with the camera slowly pushing forward.",
            "type": "text"
        }
    ],
    "duration": 5,
    "model": "MiniMax-H3",
    "ratio": "16:9",
    "resolution": "768P"
}

request = urllib.request.Request(
    "https://anyaigc.ai/minimax/v2/video_generation",
    data=json.dumps(payload, ensure_ascii=False).encode("utf-8"),
    headers={
        "Authorization": "Bearer " + os.environ["ANYAIGC_API_KEY"],
        "Content-Type": "application/json",
    },
    method="POST",
)
with urllib.request.urlopen(request, timeout=120) as response:
    result = json.load(response)

print(json.dumps(result, ensure_ascii=False, indent=2))

사양

사양과 선택 기준

MiniMax 문서는 MiniMax-H3를 텍스트, 이미지, 비디오, 오디오 입력을 통합적으로 이해하는 개방형 범용 멀티모달 비디오 모델로 설명하며, 비디오 생성, 참조 기반 제작, 비디오 편집을 지원합니다.

공식 출력 사양은 768P와 2K, 길이 4~15초(정수 값만 가능)이며, 일반적인 화면 비율 또는 adaptive를 지원합니다.

요청은 멀티모달 content[] 구조를 사용하며, 각 요소는 type으로 구분하고 참조 이미지와 비디오는 role 필드로 표시합니다.

문서에 따르면 MiniMax-H3를 사용하려면 종량제 API가 필요합니다.

이 페이지에는 768P 출력 비디오 초당 $0.0750, 768P 입력 비디오 초당 $0.0750, 2K 출력 비디오 초당 $0.1219, 2K 입력 비디오 초당 $0.1219가 표시되어 있으며, 위의 가격표와 일치합니다.

사양은 제공사의 공식 문서(platform.minimax.io)를 따랐습니다. 이 페이지의 표는 가격이며, 실시간 요금은 모델 카탈로그가 기준입니다.

FAQ

MiniMax API FAQ

가격, 엔드포인트, 결과물, 기업 도입을 한곳에서 확인하세요.

MiniMax H3 API 요금은 얼마입니까?

768P 출력 비디오 초당 $0.0750, 768P 입력 비디오 초당 $0.0750, 2K 출력 비디오 초당 $0.1219, 2K 입력 비디오 초당 $0.1219, 비디오 재생성 초당 $0.0450, 참조 이미지(처음 5장) 이미지당 $0, 참조 이미지(6번째부터) 이미지당 $0.0375입니다. 모든 가격은 USD이며, 현재 요율은 모델 카탈로그에서 확인하세요.

어떤 API 엔드포인트를 사용해야 합니까?

https://anyaigc.ai의 POST /minimax/v2/video_generation을 사용하고, API 키는 Authorization: Bearer로 전달하세요.

H3는 어떤 길이, 해상도, 참조를 지원합니까?

MiniMax-H3는 768P 또는 2K에서 4–15초를 지원합니다. content 배열에는 비어 있지 않은 text 항목이 정확히 하나 있어야 합니다. 첫/마지막 프레임을 쓰거나 참조 이미지, 비디오, 오디오를 쓸 수 있으며, 두 모드를 섞어서는 안 됩니다. 텍스트만 사용하는 생성에는 ratio가 필요합니다.

요청 한 번에 무엇이 반환됩니까?

비동기 작업 한 건으로 4–15초 길이의 비디오를 생성합니다.

동시 실행 수나 RPM 제한이 있습니까?

AnyAIGC는 MiniMax에 동시 실행 제한을 두지 않으며 고정 RPM 상한도 없습니다. 다만 생성에는 시간이 걸리므로 타임아웃, 오류 처리, 적절한 재시도를 애플리케이션에서 설정하세요.

생성한 콘텐츠를 상업적으로 사용할 수 있습니까?

모델과 출력물의 상업적 사용은 MiniMax 공식 약관을 따릅니다. 참조 자료, 음성, 생성된 콘텐츠에 대해 필요한 권리를 갖추었는지 확인하세요. AnyAIGC는 독립 API 제공업체입니다.

AnyAIGC에서 인보이스를 받을 수 있습니까?

네. 콘솔에서 실제 충전한 금액 기준으로 직접 인보이스를 발급할 수 있습니다.

어떤 결제 수단을 지원합니까?

WeChat Pay, Alipay, USDT, 신용카드로 충전할 수 있습니다. 잔액은 USD 기준이며 플랫폼의 모든 모델에서 사용할 수 있습니다. 인보이스는 콘솔에서 충전한 금액 기준으로 발급할 수 있습니다.

신규 사용자에게 무료 체험 크레딧이 있습니까?

네. 신규 계정에는 토큰 200만 개 분량의 체험 크레딧이 제공되므로 충전 여부를 결정하기 전에 먼저 테스트할 수 있습니다. 충전은 $1부터 가능합니다.

잔액을 환불받을 수 있습니까?

네. 사용하지 않은 잔액은 수수료 없이 환불받을 수 있습니다. 환불은 고객 지원에 문의해 진행하세요.

실제 모델이 맞습니까? 데이터는 안전합니까?

요청은 공식 모델 채널로 전달되며, 저가 모델이나 리버스 엔지니어링 방식의 대체 모델은 사용하지 않습니다. 법령에서 요구하는 경우를 제외하고 프롬프트와 출력을 영구 저장하거나 학습에 사용하지 않으며, 콘솔에서 모든 요청의 토큰 수와 비용을 확인할 수 있습니다.
