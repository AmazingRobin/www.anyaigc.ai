Astra에 근접한 성능을 공식 정가의 약 5%에

OpenAI는 2026년 9월 29일 GPT-6 Sol의 업그레이드로 GPT-6.1 Sol을 출시했습니다. OpenAI에 따르면 에이전트 코딩, 컴퓨터 사용(computer use), 전문 업무에서 GPT-6 Astra에 근접하며, 표준 입력·출력 토큰 가격은 Astra의 5분의 1입니다. 캐시 입력은 OpenAI 공식 정가 기준 100만 토큰당 $0.10으로, GPT-6 Sol보다 50% 낮아졌습니다.

AnyAIGC에서 gpt-6.1-sol은 /v1/chat/completions와 /v1/responses 모두에서 작동합니다. 공식 OpenAI SDK에서는 base_url만 https://anyaigc.ai/v1로 바꾸면 되며, 같은 키로 300개 이상의 다른 모델도 호출할 수 있습니다.

3단계로 GPT-6.1 Sol API 호출하기

  1. 가입 후 충전: anyaigc.ai에서 계정을 만드세요. 잔액은 모든 모델에서 공통으로 사용할 수 있습니다.
  2. API 키 만들기: 콘솔에서 토큰을 만들고 sk- 키를 복사해 ANYAIGC_API_KEY 환경 변수에 저장하세요.
  3. 요청 보내기: https://anyaigc.ai/v1/chat/completions 또는 https://anyaigc.ai/v1/responses를 호출하고, model에 gpt-6.1-sol을 지정한 뒤 Authorization: Bearer 인증을 사용하세요.

도구에는 Responses API를 사용하세요. OpenAI에 따르면 gpt-6.1-sol은 Chat Completions에서 도구 호출(함수 호출)을 지원하지 않습니다. 일반 채팅과 스트리밍에는 계속 /v1/chat/completions를 사용하고, 함수 호출, 컴퓨터 사용(computer use) 등 도구에는 /v1/responses로 전환해 reasoning.effort에 강도를 지정하세요.

모든 파라미터는 Chat Completions 레퍼런스와 Responses 레퍼런스를 참고하세요. 필드는 공식 OpenAI API와 같습니다.

사양과 선택 기준

OpenAI는 GPT-6.1 Sol을 GPT-6 Sol의 업그레이드로 소개하며, 에이전트 코딩, 컴퓨터 사용(computer use), 전문 업무에서 GPT-6 Astra에 근접하다고 밝힙니다.

DeepSWE v1.1에서 GPT-6.1 Sol은 GPT-6 Astra와 같은 점수를 기록했고, GPT-6 Sol의 최고 점수를 6.4점 앞섰습니다.

low 추론 강도에서 사실 오류가 있는 GPT-6.1 Sol 응답의 비율은 GPT-6 Sol의 11.4%에서 7.7%로 줄었습니다.

이 페이지에는 입력 $0.0993, 출력 $0.4964, 캐시 입력 $0.0050이 표기되어 있으며, 위의 가격표와 일치합니다.

OpenAI는 가장 복잡한 코딩 작업에 gpt-6.1-sol을 권장하며, gpt-6.1-terra는 작업을 3배 넘게 빠르게 끝냅니다.

사양은 모델 제공사의 공식 문서(openai.com)를 따릅니다. 이 페이지의 표는 가격이며, 실시간 요율은 모델 카탈로그가 기준입니다.

AnyAIGC에서 gpt-6.1-sol은 토큰 단위로 과금되며, 입력 100만 토큰당 $0.0993, 출력 100만 토큰당 $0.4964, 캐시 입력 100만 토큰당 $0.0050입니다. OpenAI 공식 정가는 입력 $2.00, 출력 $10.00, 캐시 입력 $0.10이므로 AnyAIGC는 공식 정가의 약 5%(95% 할인)입니다. 요청의 입력이 272K 토큰을 넘으면 요청 전체가 입력과 캐시 요율 2배, 출력 1.5배로 과금됩니다.

모델 ID는 gpt-6.1-sol입니다. 요청의 model 필드에 넣으세요. OpenAI는 이 모델의 날짜가 붙은 스냅샷을 공개하지 않았습니다.

GPT-6.1 Sol과 GPT-6 Sol: 무엇이 달라졌습니까?

OpenAI는 GPT-6.1 Sol을 GPT-6 Sol의 업그레이드로 설명합니다. 입력과 출력 공식 정가는 $2, $10으로 그대로이고, 캐시 입력은 $0.20에서 $0.10으로 내려갑니다. OpenAI에 따르면 DeepSWE v1.1에서 GPT-6 Sol의 최고 점수를 6.4점 앞서고, OSWorld 2.0에서 약 7점 높으며, Terminal-Bench Science에서는 GPT-6 Sol의 두 배를 넘습니다. 지식 기준일은 2026-04-20에서 2026-04-30으로 바뀝니다. GPT-6.1 Sol은 none 추론 강도를 지원하지 않으며, Chat Completions에서 도구 호출도 지원하지 않습니다.

GPT-6.1 Sol과 GPT-6 Astra 중 어느 쪽을 써야 합니까?

OpenAI에 따르면 GPT-6.1 Sol은 에이전트 코딩, 컴퓨터 사용(computer use), 전문 업무에서 GPT-6 Astra에 근접하며, 표준 입력·출력 가격은 Astra의 5분의 1입니다. 대부분의 코딩과 에이전트 작업은 GPT-6.1 Sol로 시작하고, 가장 어려운 추론이나 연구 작업에는 GPT-6 Astra로 옮기세요. Terminal-Bench Science 같은 벤치마크에서는 Astra가 여전히 앞섭니다. AnyAIGC에서 100만 토큰당 GPT-6.1 Sol은 입력 $0.0993, 출력 $0.4964이고, GPT-6 Astra는 입력 $0.4964, 출력 $2.4810입니다.

Chat Completions와 Responses API 중 무엇을 써야 합니까? 도구도 사용할 수 있습니까?

두 엔드포인트 모두 사용할 수 있습니다. 일반 채팅과 스트리밍에는 https://anyaigc.ai/v1/chat/completions를 사용하세요. OpenAI에 따르면 gpt-6.1-sol은 Chat Completions에서 도구 호출을 지원하지 않으므로, 함수 호출과 내장 도구에는 https://anyaigc.ai/v1/responses를 사용하고 reasoning.effort에 추론 강도를 지정하세요.

Codex에서 GPT-6.1 Sol을 사용할 수 있습니까?

네. curl -fsSL https://www.anyaigc.ai/install.sh | bash -s codex를 실행하면 설치와 설정이 완료됩니다(Windows에서는 irm https://www.anyaigc.ai/install.ps1 | iex). 설치 스크립트의 기본 모델은 gpt-5.5이므로, 설치 후 ~/.codex/config.toml의 model을 gpt-6.1-sol로 바꾸세요. 직접 설정하려면 ~/.codex/config.toml에서 base_url을 https://anyaigc.ai/v1, wire_api를 responses, model을 gpt-6.1-sol로 설정한 다음 OPENAI_API_KEY를 ~/.codex/auth.json에 넣으세요.

동시 실행 수나 속도 제한이 있습니까?

AnyAIGC는 gpt-6.1-sol에 동시 실행 제한을 두지 않습니다. 모든 계정에 기본으로 적용되므로 배치 작업과 병렬 에이전트도 대기열 없이 실행됩니다.
