Nano Banana API 시작하기

  1. 가입: AnyAIGC 계정을 만드세요. 신규 계정에는 토큰 200만 개 분량의 체험 크레딧이 제공되며, 충전은 $1부터 가능합니다.
  2. API 키 만들기: 콘솔에서 키를 생성하고 ANYAIGC_API_KEY 환경 변수에 저장하세요.
  3. 요청 보내기: POST https://anyaigc.ai/v1beta/models/gemini-nano-banana-2.1:generateContent(네이티브 Gemini 형식)를 호출하세요. 이미 OpenAI SDK를 쓰는 프로젝트는 /v1/chat/completions에서 model을 gemini-nano-banana-2.1로 지정하면 됩니다.

모델을 바꾸려면 MODEL만 변경하세요: gemini-nano-banana-2.1, gemini-3.1-flash-image, gemini-3-pro-image. 요청과 응답은 동일합니다.

Authorization: Bearer <API Key>로 인증합니다. imageConfig.imageSize는 1K, 2K, 4K를 받으며 기본값은 1K입니다. response_format은 플랫폼 확장 파라미터로, url로 설정하면 임시 fileData.fileUri 링크를 받고(비스트리밍에서만 가능) 생략하면 base64를 받습니다. 안전 필터에 요청이 차단되면 finishReason은 SAFETY 또는 PROHIBITED_CONTENT이며 이미지는 반환되지 않습니다.

Nano Banana API 자주 묻는 질문

Nano Banana API 요금은 얼마입니까?

AnyAIGC의 모든 Nano Banana 모델은 이미지당 과금됩니다. Nano Banana 2.1은 $0.0128부터, Nano Banana 2는 $0.0164부터, Nano Banana Pro는 이미지당 $0.0328부터입니다. 모두 모델 카탈로그의 최저가이며, 2K와 4K 실시간 가격은 모델 카탈로그에서 확인하세요. 성공한 요청에 대해서만 과금됩니다.

Nano Banana 2.1, Nano Banana 2, Nano Banana Pro는 무엇이 다릅니까?

Nano Banana 2.1(gemini-nano-banana-2.1)은 Google이 2026년 10월 6일에 출시한 Nano Banana 2의 업그레이드로, 이미지 품질, 텍스트 렌더링, 멀티턴 일관성이 개선되었습니다. Nano Banana 2(gemini-3.1-flash-image)는 Flash급의 높은 처리량을 갖춘 이미지 모델입니다. Nano Banana Pro(gemini-3-pro-image)는 Gemini 3 Pro 기반의 추론형 모델로, 복잡한 레이아웃과 전문가급 리터칭에 적합합니다. 세 모델 모두 1K, 2K, 4K를 출력합니다.

Nano Banana란 무엇이며 Gemini와 어떤 관계입니까?

Nano Banana는 Google Gemini 이미지 생성 모델의 별칭입니다. 최초의 Nano Banana는 Gemini 2.5 Flash Image였고, 이후 Nano Banana Pro(Gemini 3 Pro Image), Nano Banana 2(Gemini 3.1 Flash Image), Nano Banana 2.1이 나왔습니다. 모두 Gemini API의 generateContent 엔드포인트로 호출합니다.

어떤 엔드포인트를 지원합니까? 이미지를 편집할 수 있습니까?

Gemini 네이티브 형식 POST /v1beta/models/<model>:generateContent와 OpenAI 호환 /v1/chat/completions를 모두 지원합니다. 텍스트로 이미지를 생성할 때는 텍스트 part 하나를 보내세요. 편집이나 합성을 하려면 지시문과 참조 이미지(inlineData)를 같은 parts 목록에 넣으세요. 참조 이미지는 최대 14장입니다. 모든 필드는 AnyAIGC API 문서를 참고하세요.

동시 실행 제한이 있습니까?

AnyAIGC는 모든 Nano Banana 모델에 동시 실행 제한을 두지 않으며, 모든 계정에 기본으로 적용됩니다. base URL은 https://anyaigc.ai이고 Google 계정은 필요 없습니다. 같은 키로 300개 이상의 다른 모델을 사용할 수 있습니다.

AnyAIGC에서 인보이스를 받을 수 있습니까?

네. 콘솔에서 실제 충전한 금액 기준으로 직접 인보이스를 발급할 수 있습니다.

어떤 결제 수단을 지원합니까?

WeChat Pay, Alipay, USDT, 신용카드로 충전할 수 있습니다. 잔액은 USD 기준이며 플랫폼의 모든 모델에서 사용할 수 있습니다. 인보이스는 콘솔에서 충전한 금액 기준으로 발급할 수 있습니다.

신규 사용자에게 무료 체험 크레딧이 있습니까?

네. 신규 계정에는 토큰 200만 개 분량의 체험 크레딧이 제공되므로 충전 여부를 결정하기 전에 먼저 테스트할 수 있습니다. 충전은 $1부터 가능합니다.

잔액을 환불받을 수 있습니까?

네. 사용하지 않은 잔액은 수수료 없이 환불받을 수 있습니다. 환불은 고객 지원에 문의해 진행하세요.

실제 모델이 맞습니까? 데이터는 안전합니까?

요청은 공식 모델 채널로 전달되며, 저가 모델이나 리버스 엔지니어링 방식의 대체 모델은 사용하지 않습니다. 법령에서 요구하는 경우를 제외하고 프롬프트와 출력을 영구 저장하거나 학습에 사용하지 않으며, 콘솔에서 모든 요청의 토큰 수와 비용을 확인할 수 있습니다.

이미지를 상업적으로 사용할 수 있습니까? 워터마크가 있습니까?

사용 권리와 콘텐츠 정책은 Google 공식 약관을 따릅니다. Google은 Nano Banana가 생성하는 모든 이미지에 보이지 않는 SynthID 디지털 워터마크를 삽입하며, 그림에서는 눈에 보이지 않습니다. AnyAIGC는 API 접근만 제공하며 결과물 사용 방식에 별도 제한을 추가하지 않습니다. 이미지에 실존 인물의 초상이나 제3자 상표가 포함된다면 필요한 권리를 갖고 있는지 확인하세요.
