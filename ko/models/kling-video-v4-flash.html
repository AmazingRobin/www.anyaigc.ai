Kling Video V4 Flash API

Kling Video V4 Flash는 Kuaishou의 Kling 4.0 시리즈 중 경량 모델로, 속도와 비용에 초점을 맞춰 잦은 창작 작업에 맞게 만들어졌습니다. 720p에서 텍스트→비디오, 첫 프레임 이미지→비디오, 참조→비디오를 지원합니다. AnyAIGC에서는 초 단위로 $0.1206 / 초에 과금되며 동시 실행 제한이 없습니다.

모델 기능

Kling Video V4 Flash로 할 수 있는 것

현재 모델 카탈로그와 API 레퍼런스를 정리한 내용입니다. 정확한 파라미터는 API 문서를 확인하세요.

텍스트→비디오

프롬프트와 길이를 보내면 3–30초 길이의 720p 클립을 받을 수 있습니다. 길이 기본값은 5초입니다.

첫 프레임과 마지막 프레임

image_list의 이미지를 first_frame으로 지정하세요. end_frame은 반드시 first_frame과 함께 보내야 하며, 마지막 프레임만 보내면 400이 반환됩니다.

다중 이미지 참조

최대 10장의 참조 이미지를 보낸 순서대로 프롬프트에서 @image_1, @image_2로 지정해 캐릭터, 제품 외형, 장면을 재사용할 수 있습니다.

참조 비디오

최대 5개의 참조 비디오를 사용할 수 있으며 feature 참조만 지원합니다. 공개 http(s) URL이어야 하고 각각 3초 이상, 합계 30초 이내여야 합니다. 카메라 움직임과 모션 리듬을 재사용할 수 있습니다.

피사체와 음성

element_list에 최대 7개의 피사체, voice_list에 최대 3개의 음성을 넣고 @element_1 등으로 지정합니다. 모든 참조 에셋을 합쳐 15개를 넘을 수 없습니다.

화면 비율과 해상도

출력은 720p로 고정됩니다(mode는 std로 보내거나 생략하세요). 화면 비율은 21:9, 16:9, 9:16, 1:1 또는 에셋에 맞추는 adaptive입니다.

Kling Video V4 Flash API 연동

  1. 1가입하고 API 키를 만든 다음 ANYAIGC_API_KEY 설정
  2. 2POST /kling/v1/videos/omni-video로 작업을 제출하고 task_id 받기
  3. 3GET /kling/v1/videos/omni-video/{id}를 폴링하고, 성공하면 비디오 다운로드

model_name을 "kling-video-v4-flash"로 설정하세요. 이 모델은 720p만 출력합니다. mode는 std이거나 생략해야 하고 resolution은 720p이거나 생략해야 하며, pro 또는 1080p를 보내면 400이 반환되고 과금되지 않습니다. 참조 이미지와 비디오는 image_list와 video_list에 넣고 프롬프트에서 @image_1, @video_1로 지정하세요.

Python

import json
import os
import time
import urllib.request

BASE = "https://anyaigc.ai"
HEADERS = {
    "Authorization": "Bearer " + os.environ["ANYAIGC_API_KEY"],
    "Content-Type": "application/json",
}


def call(method, path, payload=None):
    data = json.dumps(payload, ensure_ascii=False).encode("utf-8") if payload else None
    request = urllib.request.Request(BASE + path, data=data, headers=HEADERS, method=method)
    with urllib.request.urlopen(request, timeout=60) as response:
        return json.load(response)


payload = {
    "model_name": "kling-video-v4-flash",
    "prompt": "The camera glides down to a neon street after rain as an orange cat walks across the wet pavement, cinematic lighting",
    "duration": 5,
    "aspect_ratio": "16:9"
}

task_id = call("POST", "/kling/v1/videos/omni-video", payload)["data"]["task_id"]
print("task_id:", task_id)

# Poll every 10 seconds; print the video URL once the task succeeds
for _ in range(90):
    data = call("GET", f"/kling/v1/videos/omni-video/{task_id}")["data"]
    if data["task_status"] == "succeed":
        break
    if data["task_status"] == "failed":
        raise RuntimeError(data.get("task_status_msg"))
    time.sleep(10)
else:
    raise TimeoutError(task_id)

for video in data["task_result"]["videos"]:
    print(video["url"])

사양

사양과 선택 기준

Kling 4.0 Flash(kling-4.0-flash)는 3초에서 20초 길이의 비디오를 생성하며, 출력은 720P SDR만 지원합니다.

지원하는 화면 비율은 21:9, 16:9, 1:1, 9:16, 4:3, 3:4, adaptive입니다.

Omni 참조 생성은 최대 5개의 참조 비디오와 7개의 피사체를 받으며, 각 참조 비디오와 전체 길이는 3초에서 20초 사이여야 합니다.

Kling은 이 모델을 더 가볍고 비용이 낮은 모델로 설명하며, omni 참조, 비디오 편집, 다국어 음성을 지원한다고 밝힙니다.

이 페이지에는 텍스트, 첫 프레임, 다중 이미지 참조(참조 비디오 제외)가 $0.1206 / 초, 참조 비디오를 사용한 참조→비디오가 $0.0808 / 초로 표시되어 있으며, 위 가격표와 일치합니다.

사양은 제공사 공식 문서(klingai.com)를 따릅니다. 이 페이지의 표는 가격이며, 실시간 요금은 모델 카탈로그를 기준으로 합니다.

FAQ

Kling Video V4 Flash API 자주 묻는 질문

Kling Video V4 Flash API 요금은 얼마입니까?

초 단위로 과금됩니다. 참조 비디오가 없으면 초당 $0.1206, 있으면 초당 $0.0808이며 항상 720p입니다. 가격은 USD 기준이며 제출에 성공하면 과금됩니다. 현재 요금은 모델 카탈로그를 확인하세요.

어떤 엔드포인트를 호출해야 합니까?

POST /kling/v1/videos/omni-video로 제출하고 model_name을 kling-video-v4-flash로 설정하세요. 결과는 GET /kling/v1/videos/omni-video/{id}로 조회합니다. API 호스트는 https://anyaigc.ai이고 헤더는 Authorization: Bearer <API Key>입니다.

어떤 생성 모드를 지원합니까?

텍스트→비디오, 첫 프레임 및 첫·마지막 프레임 이미지→비디오, 최대 10장의 참조 이미지, 최대 5개의 참조 비디오, 그리고 최대 7개의 피사체와 3개의 음성을 지원합니다. 모든 참조 에셋을 합쳐 15개를 넘을 수 없습니다. 정확한 필드는 API 레퍼런스를 참조하세요.

과금은 어떻게 됩니까? 참조 비디오를 사용하면 단가가 낮은 이유는 무엇입니까?

참조 비디오가 없으면 과금 초는 출력 길이와 같고 초당 $0.1206입니다. 참조 비디오가 있으면 초당 $0.0808이지만 과금 초 = 출력 길이 + max(참조 비디오 총 길이, 출력 길이)입니다. 출력 5초에 참조 비디오 5초이면 10초, 즉 $0.808이 과금됩니다. 참조 이미지, 피사체, 음성은 무료입니다.

해상도, 길이, 화면 비율 제한은 어떻게 됩니까?

출력은 720p로 고정됩니다. mode는 std이거나 생략해야 하고 resolution은 720p이거나 생략해야 하며, pro 또는 1080p를 보내면 400이 반환되고 과금되지 않습니다. duration은 3초에서 30초 사이의 정수이며 기본값은 5입니다. 화면 비율은 21:9, 16:9, 9:16, 1:1, adaptive입니다.

지원하지 않는 기능은 무엇입니까?

이 모델은 사운드(on을 보내면 400 반환), multi_shot, 4K 모드, refer_type이 base인 비디오 편집을 지원하지 않습니다. 참조 비디오는 feature를 사용해야 합니다.

결과는 어떻게 받습니까?

API는 비동기 방식입니다. 제출하면 task_id가 반환되며, 조회 엔드포인트를 폴링하다가 작업이 성공하면 task_result에서 비디오 URL을 읽으세요. 정확한 상태 값과 응답 필드는 API 레퍼런스를 확인하세요.
