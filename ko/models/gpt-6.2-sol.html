3단계로 GPT-6.2 Sol API 호출하기

  1. 가입 후 충전: anyaigc.ai에서 계정을 만드세요. 잔액은 모든 모델에서 공통으로 사용할 수 있습니다.
  2. API 키 만들기: 콘솔에서 토큰을 만들고 sk- 키를 복사해 ANYAIGC_API_KEY 환경 변수에 저장하세요.
  3. 요청 보내기: model을 gpt-6.2-sol로 설정하고 Authorization: Bearer 인증으로 https://anyaigc.ai/v1/chat/completions 또는 https://anyaigc.ai/v1/responses를 호출하세요.

도구 호출에는 /v1/responses를 권장합니다. 일반 채팅과 스트리밍에는 /v1/chat/completions를, 함수 호출, 컴퓨터 조작, 웹 검색 등의 도구에는 /v1/responses를 사용하고 추론 강도는 reasoning.effort에 지정하세요. 이 페이지의 함수 호출 예시는 /v1/responses를 사용합니다.

모든 파라미터는 Chat Completions 레퍼런스와 Responses 레퍼런스를 참고하세요. 필드는 공식 OpenAI API와 같습니다.

OpenAI에 따르면 GPT-6.2 Sol은 GPT-6.1 Sol보다 더 똑똑하고 효율적이며, GPT-6.1 Sol의 API 가격을 그대로 유지합니다. 100만 토큰당 입력 $2, 캐시 입력 $0.10, 출력 $10입니다.

Cognition의 FrontierCode 2.0에서 GPT-6.2 Sol은 max 기준 GPT-6.2 Astra와 0.5점 이내 차이를 약 5분의 1 비용으로 기록합니다.

이 페이지에는 입력 $0.0993, 출력 $0.4964, 캐시 입력 $0.0050이 표기되어 있으며, 위의 가격표와 일치합니다.

gpt-6.2-sol은 일상 업무용으로 만들어졌고, gpt-6.2-astra는 가장 어려운 프로젝트를 위한 새로운 프론티어 모델로, 공식 정가 입력 가격이 Sol의 4배입니다.

사양은 제공사의 공식 문서(openai.com)를 따랐습니다. 이 페이지의 표는 가격이며, 실시간 요금은 모델 카탈로그가 기준입니다.

GPT-6.2 Sol API 자주 묻는 질문

GPT-6.2 Sol API 요금은 얼마입니까?

AnyAIGC에서 gpt-6.2-sol은 토큰 단위로 과금됩니다. 입력 100만 토큰당 $0.0993, 출력 100만 토큰당 $0.4964, 캐시 입력 100만 토큰당 $0.0050입니다. OpenAI 공식 정가는 입력 $2.00, 출력 $10.00, 캐시 입력 $0.10이므로 AnyAIGC는 공식 정가의 약 5%(95% 할인)입니다. 요청의 입력이 272K에서 1M 토큰 사이이면 상위 구간으로 과금됩니다. 100만 토큰당 입력 $0.1986, 출력 $0.7446입니다.

GPT-6.2 Sol의 모델 ID는 무엇입니까?

모델 ID는 gpt-6.2-sol입니다. 요청의 model 필드에 넣으세요.

GPT-6.2 Sol과 GPT-6.1 Sol: 무엇이 달라졌습니까?

OpenAI에 따르면 GPT-6.2 Sol은 GPT-6.1 Sol보다 더 똑똑하고 효율적이며, API 공식 정가는 그대로입니다(입력 $2, 캐시 입력 $0.10, 출력 $10). OpenAI에 따르면 Agents’ Last Exam에서 max 강도로 73.0%를 기록했고(GPT-6.1 Sol: 72.5%), low 강도에서는 격차가 더 큽니다(66.7% 대 61.0%). GDPval v2에서는 5.3점 높습니다. AnyAIGC에서 둘의 요금은 같습니다. 100만 토큰당 입력 $0.0993, 출력 $0.4964입니다.

GPT-6.2 Sol과 GPT-6.2 Astra 중 어느 쪽을 써야 합니까?

OpenAI에 따르면 GPT-6.2 Sol은 Cognition의 FrontierCode 2.0에서 max 기준 GPT-6.2 Astra와 0.5점 이내 차이를 약 5분의 1 비용으로 기록합니다. 대부분의 코딩, 에이전트, 일상 업무는 GPT-6.2 Sol로 시작하고, 가장 어려운 프로젝트에는 GPT-6.2 Astra로 옮기세요. AnyAIGC에서 100만 토큰당 GPT-6.2 Sol은 입력 $0.0993, 출력 $0.4964이고, GPT-6.2 Astra는 입력 $0.3971, 출력 $1.9860입니다.

Chat Completions와 Responses API 중 무엇을 써야 합니까? 도구도 사용할 수 있습니까?

두 엔드포인트 모두 사용할 수 있습니다. 일반 채팅과 스트리밍에는 https://anyaigc.ai/v1/chat/completions를 사용하세요. 함수 호출, 웹 검색, 컴퓨터 조작 등의 도구에는 https://anyaigc.ai/v1/responses를 권장하며, 추론 강도는 reasoning.effort에 지정하세요.

Codex에서 GPT-6.2 Sol을 사용할 수 있습니까?

네. curl -fsSL https://www.anyaigc.ai/install.sh | bash -s codex를 실행하면 설치와 설정이 완료됩니다(Windows에서는 irm https://www.anyaigc.ai/install.ps1 | iex). 설치 스크립트의 기본 모델은 gpt-5.5이므로, 설치 후 ~/.codex/config.toml의 model을 gpt-6.2-sol로 바꾸세요. 직접 설정하려면 ~/.codex/config.toml에서 base_url을 https://anyaigc.ai/v1, wire_api를 responses, model을 gpt-6.2-sol로 설정한 뒤 OPENAI_API_KEY를 ~/.codex/auth.json에 넣으세요.

AnyAIGC는 gpt-6.2-sol에 동시 실행 제한을 두지 않습니다. 모든 계정에 기본으로 적용되므로 배치 작업과 병렬 에이전트도 대기열 없이 실행됩니다.
