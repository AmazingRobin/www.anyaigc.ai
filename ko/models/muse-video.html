Muse Video란 무엇입니까?

Muse Video는 Meta Superintelligence Labs가 Muse Image와 함께 공개한 비디오 모델로, 같은 사전 학습 기반 위에 만들어졌습니다. Meta는 프롬프트 충실도, 시각적 완성도, 시간적 일관성에서 경쟁력이 있다고 밝혔으며, 오디오도 기본으로 생성합니다. 주변 소리, 효과음, 내레이션, 대사가 영상과 함께 나옵니다.

Meta에 따르면 Muse Video는 2026년 7월 5일 기준 Arena 텍스트→비디오 부문 3위였습니다. Meta는 오디오와 영상의 싱크, 물리적으로 정확한 빠른 움직임에서 아직 격차를 줄이는 중이라고 밝혔습니다.

AnyAIGC의 모델 이름은 muse-video입니다. POST /v1/videos의 비동기 작업으로 실행되고, 텍스트→비디오와 첫 프레임 이미지→비디오를 지원하며, 가로 1280×720 또는 세로 720×1280 MP4를 초당 $0.0397에 반환합니다.

Muse Video API 시작하기

  1. AnyAIGC에 가입하세요. 신규 계정에는 무료 토큰 500만 개가 제공되며, 충전은 $1부터 가능합니다.
  2. 콘솔에서 API 키를 만들고 ANYAIGC_API_KEY로 저장하세요.
  3. model을 muse-video로 설정해 POST https://anyaigc.ai/v1/videos로 작업을 제출한 뒤, status가 completed가 될 때까지 GET /v1/videos/{id}를 폴링하세요.

상태는 queued → in_progress → completed / failed 순으로 바뀝니다. 10초 이하 클립은 약 1–2분, 15–30초 클립은 약 3–7분이 걸립니다. 실패하면 error가 반환됩니다. video_generation_failed는 영상이 생성되지 않았다는 뜻으로(정책 또는 일시적인 업스트림 오류), 프롬프트를 바꾸거나 나중에 다시 시도하세요. video_rejected는 출력이 검사를 통과하지 못해 폐기되었다는 뜻이므로 다시 시도하면 됩니다. 모든 필드는 AnyAIGC API 문서를 참고하세요.

Muse Video API 자주 묻는 질문

Muse Video API 가격은 얼마입니까?

AnyAIGC에서 Muse Video(muse-video)는 요청한 seconds 기준으로 초당 $0.0397이 과금됩니다. 5초는 $0.199, 10초는 $0.397, 30초는 $1.19입니다. 금액은 제출 시 예약되고 실패한 작업은 환불되며, 실시간 가격은 모델 카탈로그에서 확인할 수 있습니다.

Muse Video란 무엇입니까?

Muse Video는 Meta Superintelligence Labs가 Muse Image와 함께 공개한 비디오 모델로, 같은 사전 학습 기반 위에서 만들어졌고 네이티브 오디오를 지원합니다. Meta에 따르면 2026년 7월 5일 기준 Arena 텍스트→비디오 부문 3위입니다.

영상은 최대 몇 초까지 만들 수 있습니까?

seconds는 4에서 30 사이의 정수를 받으며 기본값은 4입니다. 출력은 올림만 적용됩니다. 4 또는 5는 5초, 7 또는 8은 8초, 11–15는 15초가 되는 식입니다. 10초를 넘는 클립은 구간별로 생성되며 10초와 20초 지점에서 컷이 생깁니다. 과금은 요청한 초 수를 기준으로 합니다.

어떤 크기와 해상도를 지원합니까?

size는 1280x720(가로) 또는 720x1280(세로)이며 기본값은 가로입니다. resolution은 720p만 가능하고 생략할 수 있습니다. 출력은 오디오가 포함된 MP4입니다.

이미지로 영상을 만들 수 있습니까?

예. 이미지를 input_reference로 전달하면 첫 프레임으로 사용됩니다. 이미지 URL 또는 data URL(PNG, JPEG, WebP)을 쓰거나, multipart/form-data로 파일을 직접 업로드하세요. 파일 ID는 지원하지 않습니다.

시간은 얼마나 걸리며 결과는 어떻게 받습니까?

비동기 방식입니다. POST /v1/videos가 작업 id를 반환하면, 10–20초 간격으로 GET /v1/videos/{id}를 폴링하세요. 10초 이하 클립은 약 1–2분, 15–30초 클립은 약 3–7분이 걸립니다.

생성에 실패해도 과금됩니까?

아니요. 실패한 작업은 자동으로 환불되며, 잘못된 파라미터는 작업을 만들거나 과금하지 않고 400(client_local_validation)을 반환합니다.

동시 실행 제한이 있습니까?

AnyAIGC는 어떤 계정에도 Muse Video에 동시 실행 제한을 두지 않습니다. base URL은 https://anyaigc.ai이며 Meta 계정은 필요 없고, 같은 키로 다른 300개 이상의 모델도 사용할 수 있습니다.

AnyAIGC에서 인보이스를 받을 수 있습니까?

네. 콘솔에서 실제 충전한 금액 기준으로 직접 인보이스를 발급할 수 있습니다.

어떤 결제 수단을 지원합니까?

WeChat Pay, Alipay, USDT, 신용카드로 충전할 수 있습니다. 잔액은 USD 기준이며 플랫폼의 모든 모델에서 사용할 수 있습니다. 인보이스는 콘솔에서 충전한 금액 기준으로 발급할 수 있습니다.

신규 사용자에게 무료 체험 크레딧이 있습니까?

잔액을 환불받을 수 있습니까?

네. 사용하지 않은 잔액은 수수료 없이 환불받을 수 있습니다. 환불은 고객 지원에 문의해 진행하세요.

실제 모델이 맞습니까? 데이터는 안전합니까?

요청은 공식 모델 채널로 전달되며, 저가 모델이나 리버스 엔지니어링 방식의 대체 모델은 사용하지 않습니다. 법령에서 요구하는 경우를 제외하고 프롬프트와 출력을 영구 저장하거나 학습에 사용하지 않으며, 콘솔에서 모든 요청의 토큰 수와 비용을 확인할 수 있습니다.
