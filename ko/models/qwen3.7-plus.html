빠른 시작

Chat Completions로 시작하세요

  1. 콘솔에서 계정과 API 키를 만드세요.
  2. Base URL을 https://anyaigc.ai/v1로 설정하세요.
  3. model을 지정하고 messages를 보내세요.
cURL · POST /v1/chat/completions
curl https://anyaigc.ai/v1/chat/completions \
  -H "Authorization: Bearer $ANYAIGC_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"qwen3.7-plus","messages":[{"role":"user","content":"Explain what a MoE model is in three sentences."}]}'
Python · OpenAI SDK
from openai import OpenAI
import os
client = OpenAI(api_key=os.environ["ANYAIGC_API_KEY"], base_url="https://anyaigc.ai/v1")
response = client.chat.completions.create(model="qwen3.7-plus", messages=[{"role":"user","content":"Explain what a MoE model is in three sentences."}])
print(response.choices[0].message.content)

Qwen3.7

사양과 선택 기준

균형형 Qwen3.7 모델로, 1,000,000 토큰 컨텍스트와 사고 모드, 비사고 모드를 지원합니다.

컨텍스트 길이는 1,000,000 토큰이며 응답당 최대 131,072 토큰을 출력할 수 있습니다. Qwen3.7 세대의 균형형 모델입니다.

이 페이지의 가격은 입력 100만 토큰당 $0.4050, 출력 100만 토큰당 $1.6200이며, 위 가격표와 같은 수치입니다.

qwen3.7-max와 나란히 비교해 보고, 복잡한 작업에 플래그십이 필요하면 그 모델을 선택하세요.

이 사양은 Qwen 공식 모델 문서에서 가져온 것입니다. 가격은 이 페이지의 표를 기준으로 하며, 실시간 요금은 모델 카탈로그가 기준입니다.

FAQ

Qwen3.7 Plus API 자주 묻는 질문

Qwen3.7 Plus API는 어떤 엔드포인트를 사용합니까?

대화 모델은 POST https://anyaigc.ai/v1/chat/completions를 사용합니다. model과 messages를 보내고, Authorization: Bearer <API Key> 헤더를 포함하세요.

Qwen3.7 Plus API 가격은 얼마입니까?

Qwen3.7 Plus는 토큰 단위로 과금됩니다. 입력 100만 토큰당 $0.4050, 출력 100만 토큰당 $1.6200, 캐시 히트 100만 토큰당 $0.0810입니다. 실시간 가격은 모델 카탈로그에서 확인하세요.

동시 실행에 제한이 있습니까?

이 페이지의 Qwen 대화 모델은 동시 실행 제한이 없으며 모든 사용자가 이용할 수 있습니다.

API 키는 어떻게 받습니까?

AnyAIGC 계정을 만들고 콘솔에서 API 키를 생성하세요. 키 하나로 300개 이상의 모델을 사용할 수 있습니다.

이미지와 도구 호출을 지원합니까?

지원 기능은 모델마다 다릅니다. 모델 카탈로그의 태그를 확인하세요. 엔드포인트는 동일합니다.

AnyAIGC에서 인보이스를 받을 수 있습니까?

네. 콘솔에서 실제 충전한 금액 기준으로 직접 인보이스를 발급할 수 있습니다.

어떤 결제 수단을 지원합니까?

WeChat Pay, Alipay, USDT, 신용카드로 충전할 수 있습니다. 잔액은 USD 기준이며 플랫폼의 모든 모델에서 사용할 수 있습니다. 인보이스는 콘솔에서 충전한 금액 기준으로 발급할 수 있습니다.

신규 사용자에게 무료 체험 크레딧이 있습니까?

네. 신규 계정에는 200만 토큰의 체험 크레딧이 제공됩니다.

잔액을 환불받을 수 있습니까?

네. 미사용 잔액은 수수료 없이 환불받을 수 있습니다.

공식 모델이며 데이터는 안전합니까?

요청은 공식 모델 채널을 통해 처리됩니다. 법률상 요구되는 경우를 제외하고 프롬프트와 출력은 영구 저장되거나 학습에 사용되지 않습니다.
