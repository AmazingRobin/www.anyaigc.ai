사양과 선택 기준

Seedream 3.0은 중국어·영어 이중 언어 텍스트→이미지 파운데이션 모델입니다.

Seedream 3.0은 후처리 없이 네이티브 2K 이미지를 출력하며, 다양한 종횡비에서 512×512부터 2048×2048까지의 해상도를 지원합니다.

Seedream 3.0은 1K 해상도 이미지를 처음부터 끝까지 약 3초 만에 생성합니다.

Seedream 3.0은 작은 글자와 여러 줄 텍스트 레이아웃의 렌더링을 개선했습니다.

이 페이지는 위 가격표와 동일하게 Seedream 3.0을 $0.0101 / 요청으로 안내합니다.

seedream-4.0과 비교하면, Seedream 3.0은 텍스트→이미지 전용이며 최대 2048×2048까지인 반면 Seedream 4.0은 편집, 최대 14장의 참조 이미지, 최대 4K 출력을 지원합니다.

사양은 벤더 공식 문서(seed.bytedance.com)를 따랐습니다. 이 페이지의 표는 가격이며, 실시간 요금은 모델 카탈로그가 기준입니다.

Seedream 3.0 API FAQ

Seedream 3.0 API 요금은 얼마입니까?

AnyAIGC에서 Seedream 3.0(doubao-seedream-3-0-t2i-250415)은 $0.0101 / 요청부터 시작합니다. 모델 카탈로그에서 3.0은 요청당 과금되며, 요청마다 이미지 1장이 반환됩니다. 성공한 생성 건에 대해서만 과금되고, 실시간 가격은 모델 카탈로그에서 확인할 수 있습니다.

Seedream 3.0은 종료되었습니까?

아니요. doubao-seedream-3-0-t2i-250415는 현재 AnyAIGC에서 정상 동작합니다. 다만 현재 Volcano Engine Ark 이미지 생성 문서에는 3.0이 더 이상 표시되지 않으므로 이후 종료될 수 있습니다. 새 프로젝트에는 Seedream 4.0 또는 5.0 lite를 사용하세요. API가 동일해서 마이그레이션 시 바꾸는 것은 모델 ID뿐입니다.

Seedream 3.0이란 무엇입니까?

Seedream 3.0은 2025년 4월 ByteDance Seed 팀이 공개한 중국어·영어 이중 언어 텍스트→이미지 파운데이션 모델입니다. 네이티브 2K로 출력하고 작은 글자와 타이포그래피를 더 정확하게 렌더링하며, 이전 세대보다 지시 따르기와 미적 품질이 향상되었습니다.

3.0에서 이미지를 편집하거나 참조 이미지를 사용할 수 있습니까?

아니요. 3.0(t2i)은 텍스트→이미지 전용이며 참조 이미지, 편집, 이미지 세트를 지원하지 않습니다. 편집에는 4.0 이상을 사용하세요.

size에는 무엇을 넣어야 합니까?

3.0은 size에 픽셀 크기를 사용하며, 예를 들어 1024x1024, 1280x720, 720x1280입니다.

동시 실행 제한이 있습니까? 가입에 무엇이 필요합니까?

AnyAIGC는 Seedream 3.0에 동시 실행 제한을 두지 않으며, 모든 계정에 기본으로 적용됩니다. base URL은 https://anyaigc.ai입니다. Volcano Engine 계정이나 본인 인증은 필요 없고, 같은 키로 플랫폼의 다른 300개 이상 모델도 사용할 수 있습니다.

네. 콘솔에서 실제 충전한 금액 기준으로 직접 인보이스를 발급할 수 있습니다.

어떤 결제 수단을 지원합니까?

WeChat Pay, Alipay, USDT, 신용카드로 충전할 수 있습니다. 잔액은 USD 기준이며 플랫폼의 모든 모델에서 사용할 수 있습니다. 인보이스는 콘솔에서 충전한 금액 기준으로 발급할 수 있습니다.

신규 사용자에게 무료 체험 크레딧이 있습니까?

네. 신규 계정에는 토큰 200만 개 분량의 체험 크레딧이 제공되므로 충전 여부를 결정하기 전에 먼저 테스트할 수 있습니다. 충전은 $1부터 가능합니다.

잔액을 환불받을 수 있습니까?

네. 사용하지 않은 잔액은 수수료 없이 환불받을 수 있습니다. 환불은 고객 지원에 문의해 진행하세요.

실제 모델이 맞습니까? 데이터는 안전합니까?

요청은 공식 모델 채널로 전달되며, 저가 모델이나 리버스 엔지니어링 방식의 대체 모델은 사용하지 않습니다. 법령에서 요구하는 경우를 제외하고 프롬프트와 출력을 영구 저장하거나 학습에 사용하지 않으며, 콘솔에서 모든 요청의 토큰 수와 비용을 확인할 수 있습니다.

상업적으로 사용할 수 있습니까? 워터마크를 제거할 수 있습니까?

사용 권한과 콘텐츠 정책은 ByteDance / Volcano Engine 공식 약관을 따릅니다. 요청에서 watermark를 false로 설정하면 오른쪽 아래에 "AI 생성" 표시가 추가되지 않습니다. AnyAIGC는 API 접근만 제공하며 결과물 사용에 추가 제한을 두지 않습니다. 실존 인물 초상, 브랜드 로고 등은 필요한 권리를 갖고 있는지 확인하세요.
