06 / FAQ

자주 묻는 질문

어떤 Kling API 모델을 사용할 수 있습니까?

Kling 제품군에는 생성, 참조, 아바타, 오디오, 립싱크, 피사체, 효과, 연장을 다루는 이미지, 비디오, 오디오, 크리에이티브 도구 모델 16종이 있습니다.

Kling 모델은 어떻게 선택합니까?

비디오 생성에는 Kling Video, Kling 3.0 Turbo, Kling Video V4로 시작하세요. 모션 전이에는 Motion Control, 아바타에는 Avatar Image2Video, 효과음이나 음성에는 Kling Audio를 사용하세요.

Kling API 가격은 얼마입니까?

모델에 따라 호출당 또는 초당으로 과금됩니다. 가격은 호출당 $0.00169부터 시작하며, 실시간 가격은 모델 카탈로그에서 확인하세요.

동시 실행에 제한이 있습니까?

AnyAIGC에서 Kling 모델은 기본적으로 동시 실행 제한이 없습니다.

인증은 어떻게 처리합니까?

Authorization: Bearer <API Key> 헤더를 사용하고, 키는 ANYAIGC_API_KEY 환경 변수에서 읽어 오세요.

AnyAIGC에서 인보이스를 받을 수 있습니까?

네. 콘솔에서 실제 충전한 금액 기준으로 직접 인보이스를 발급할 수 있습니다.

어떤 결제 수단을 지원합니까?

WeChat Pay, Alipay, USDT, 신용카드로 충전할 수 있습니다. 잔액은 USD 기준이며 플랫폼의 모든 모델에서 사용할 수 있습니다. 인보이스는 콘솔에서 충전한 금액 기준으로 발급할 수 있습니다.

체험 크레딧이 있습니까?

신규 계정에는 가입 후 토큰 500만 개 분량의 체험 크레딧이 제공됩니다.

미사용 잔액을 환불받을 수 있습니까?

미사용 잔액은 고객 지원에 문의하면 환불받을 수 있습니다.

생성한 콘텐츠를 상업적으로 사용할 수 있습니까?

사용 권한과 콘텐츠 정책은 Kling 공식 약관을 따릅니다.
