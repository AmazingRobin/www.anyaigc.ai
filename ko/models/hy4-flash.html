토큰 단위로 100만 토큰당 USD로 과금됩니다. 입력 $0.0281(공식 정가 $0.0695), 출력 $0.1130(공식 정가 $0.2782), 캐시 히트 $0.0012(공식 정가 $0.0028)입니다. Tencent Hunyuan 릴리스 노트에는 입력 ¥0.5, 출력 ¥2, 캐시 히트 ¥0.02로 게시되어 있으며, USD 공식 정가는 약 7.19 CNY/USD로 환산했습니다. AnyAIGC의 입력과 출력은 공식 정가의 약 40%, 캐시 히트는 약 43%로, 전체적으로 약 60% 할인입니다. Tencent Cloud TokenHub는 2026-11-30까지 기간 한정 50% 할인 프로모션도 진행하지만, 이 페이지는 프로모션 가격을 기준으로 삼지 않습니다. 실시간 요금은 모델 카탈로그에서 확인하세요.

Hy4 flash와 Hy4는 어떻게 다릅니까?

Tencent Hunyuan 릴리스 노트(2026-11-16)에 따르면 Hy4 flash는 전체 224B 파라미터(이 중 64B가 Engram)에 활성 12B이며, API 가격은 입력 ¥0.5, 출력 ¥2로 Hy4의 ¥6, ¥18보다 낮습니다. Tencent는 flash의 KV 캐시가 Hy4의 6분의 1이고 디코딩 속도가 150 tps를 넘는다고 밝혔습니다. WorkBuddy 일상 업무 평가에서 평균 작업 시간은 Hy4보다 70% 짧고 평균 비용은 약 15분의 1이며, 일상 업무 품질은 대체로 같고 장기 코딩에서는 소폭 낮아집니다. Tencent는 일상 업무에는 flash를, 장기 소프트웨어 엔지니어링 같은 복잡한 작업에는 Hy4를 권장합니다. 이 수치는 Tencent의 자체 수치이며, AnyAIGC가 다시 검증한 것은 아닙니다.

Hy4 Flash는 이미지 입력을 지원합니까?

예. 모델 카탈로그에 이미지 이해가 표시되어 있고, Tencent도 Hy4 flash를 멀티모달 모델로 설명합니다. POST /v1/chat/completions 요청의 image_url content part에 이미지 URL이나 base64 데이터를 담아 보내세요. 출력은 텍스트입니다. AnyAIGC 문서에는 현재 이미지 크기와 개수 제한이 명시되어 있지 않으므로 문서를 따르세요.

어떤 API 엔드포인트를 사용해야 합니까?

WeChat Pay, Alipay, USDT, 신용카드로 충전할 수 있습니다. 잔액은 USD 기준이며 플랫폼의 모든 모델에서 사용할 수 있습니다. 인보이스는 콘솔에서 충전한 금액 기준으로 발급할 수 있습니다.

신규 사용자에게 무료 체험 크레딧이 있습니까?

네. 신규 계정에는 토큰 200만 개 분량의 체험 크레딧이 제공되므로 충전 여부를 결정하기 전에 먼저 테스트할 수 있습니다. 충전은 $1부터 가능합니다.

잔액을 환불받을 수 있습니까?

네. 사용하지 않은 잔액은 수수료 없이 환불받을 수 있습니다. 환불은 고객 지원에 문의해 진행하세요.

실제 모델이 맞습니까? 데이터는 안전합니까?

요청은 공식 모델 채널로 전달되며, 저가 모델이나 리버스 엔지니어링 방식의 대체 모델은 사용하지 않습니다. 법령에서 요구하는 경우를 제외하고 프롬프트와 출력을 영구 저장하거나 학습에 사용하지 않으며, 콘솔에서 모든 요청의 토큰 수와 비용을 확인할 수 있습니다.
