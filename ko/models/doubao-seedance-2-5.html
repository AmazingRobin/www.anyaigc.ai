Seedance 비디오 기능

프롬프트, 참조 자료, 움직임, 사운드를 하나의 비디오 제작 워크플로로 통합하세요.

  • 01

    30초 서사

    최대 30초 길이의 클립을 한 번에 만들 수 있으며, 일관된 스토리, 안정적인 움직임, 사실적인 장면에 중점을 둡니다.

  • 02

    정밀한 참조와 편집

    참조로 샷 언어를 안내하고, 작업 의도로 참조, 편집, 확장 중 하나를 지정할 수 있습니다.

  • 03

    전문가용 크리에이티브 제어

    공식 모델 페이지에서는 제작 워크플로를 위한 화이트 모델 제어와 그린스크린 편집을 시연합니다.

  • 04

    MP4 또는 MOV 출력

    output_format으로 mp4 또는 mov를 선택하세요. 기본 형식은 mp4입니다.

사양과 선택 기준

Volcengine 문서에 따르면 Seedance 2.5는 4–30초 길이의 클립을 지원하며, -1로 설정하면 모델이 길이를 정합니다.

참조 이미지 최대 30개, 비디오 10개, 오디오 클립 10개를 받을 수 있으며, 2.0 시리즈보다 많습니다.

480p, 720p(8비트)와 1080p(10비트)로 출력하며 4K는 지원하지 않고, MP4 또는 MOV로 내보냅니다.

ByteDance Seed는 단일 클립이 이제 30초까지 늘어나고 최대 두 번 확장할 수 있으며, 화이트 모델 제어와 그린스크린 편집도 지원한다고 밝혔습니다.

이 페이지의 가격은 비디오 생성 $13.001 / 100만 토큰, 비디오 참조 $7.776 / 100만 토큰, 비디오 생성 $14.216 / 100만 토큰, 비디오 참조 $8.505 / 100만 토큰이며, 위 가격표와 일치합니다.

4K 출력이 필요하거나 15초 이하의 클립으로 충분하다면 doubao-seedance-2-0을 선택하세요.

사양은 제공사의 공식 문서(docs.volcengine.com)를 따릅니다. 이 페이지의 표는 가격이며, 실시간 요금은 모델 카탈로그가 기준입니다.

Seedance API FAQ

Seedance 2.5 API 요금은 얼마입니까?

AnyAIGC는 100만 토큰당 요금으로 과금하며, 요금은 해상도와 참조 비디오 입력 여부에 따라 달라집니다. 480p / 720p(참조 비디오 없음): 100만 토큰당 $13.001, 480p / 720p(참조 비디오 포함): 100만 토큰당 $7.776, 1080p(참조 비디오 없음): 100만 토큰당 $14.216, 1080p(참조 비디오 포함): 100만 토큰당 $8.505. 실시간 요금은 모델 카탈로그에서 확인하세요.

Seedance는 어떤 입력을 받을 수 있습니까?

Seedance 2.0은 텍스트, 이미지, 오디오, 비디오를 참조로 받으며, 비디오 편집, 확장, 네이티브 오디오를 지원합니다. 2.0 Fast는 속도를 우선하고, 2.0 mini는 고빈도 워크로드용으로 설계되었으며, 2.5는 더 강력한 긴 서사, 참조, 정밀 편집을 더하고, 2.5 flash는 속도와 멀티모달 제어의 균형을 맞춥니다.

요청 한 번에 비디오가 몇 개 반환됩니까?

생성 요청은 작업 ID 하나를 반환합니다. 비동기 작업이 끝나면 작업을 조회해 비디오 URL 하나를 받습니다. 길이는 duration 필드 또는 모델이 결정합니다.

어떤 해상도, 비율, 길이를 지원합니까?

Seedance 2.0은 480p, 720p, 1080p, 4K를 지원하며, 4K 구간은 지금 사용할 수 있습니다. Seedance 2.5는 480p, 720p, 1080p를 지원하고 duration은 4–30 또는 -1입니다. Fast, mini, 2.5 flash에는 480p / 720p 요금 구간이 있으며, 2.5 flash는 최대 720p로 출력합니다. 화면 비율과 duration 파라미터는 각 모델의 API 문서를 따르세요.

결과는 어떻게 가져옵니까?

생성 호출에서 반환된 id를 저장한 뒤 GET /api/v3/contents/generations/tasks/{id}를 호출하세요. 성공하면 content.video_url을 읽으세요. 정확한 상태 값은 API 응답을 따릅니다.

동시 실행 제한이 있습니까?

AnyAIGC는 Seedance에 동시 실행 제한을 두지 않으며, 모든 계정에 기본으로 적용됩니다. 대량 배치에는 큐와 재시도 전략을 사용하세요.

AnyAIGC에서 인보이스를 받을 수 있습니까?

네. 콘솔에서 실제 충전한 금액 기준으로 직접 인보이스를 발급할 수 있습니다.

어떤 결제 수단을 지원합니까?

WeChat Pay, Alipay, USDT, 신용카드로 충전할 수 있습니다. 잔액은 USD 기준이며 플랫폼의 모든 모델에서 사용할 수 있습니다. 인보이스는 콘솔에서 충전한 금액 기준으로 발급할 수 있습니다.

신규 사용자에게 무료 체험 크레딧이 있습니까?

예. 신규 계정에는 500만 토큰의 체험 크레딧이 제공되며, 충전은 $1부터 가능합니다.

잔액을 환불받을 수 있습니까?

사용하지 않은 잔액은 수수료 없이 환불받을 수 있습니다. 절차는 고객 지원에 문의하세요.

실제 모델이 맞습니까? 데이터는 안전합니까?

요청은 공식 모델 채널을 통해 처리됩니다. 법령에서 요구하는 경우를 제외하고 프롬프트와 출력은 영구 저장되지 않으며 학습에도 사용되지 않습니다. 요청 상세는 콘솔에서 확인할 수 있습니다.
