모델 소개

1.6T 파라미터 규모의 V4 플래그십

DeepSeek는 2026년 4월 V4 Pro와 V4 Flash 두 모델로 V4 프리뷰를 공개하고, 1M 토큰 컨텍스트를 기본으로 제공했습니다. V4 Pro는 8월 13일에 정식 출시(GA)되었으며 low, high, max 세 가지 추론 강도를 제공합니다.

V4 Pro는 총 1.6T, 활성 49B 파라미터의 MoE입니다. Compressed Sparse Attention과 Heavily Compressed Attention을 결합한 하이브리드 구조를 사용하며, 32T 토큰으로 사전 학습되었고 가중치는 MIT 라이선스로 공개되어 있습니다. 1M 토큰 컨텍스트, 최대 384K 출력 토큰, thinking 모드와 non-thinking 모드를 지원하며 기본값은 thinking 모드입니다.

9월에 V4.1 Flash가 출시된 후 DeepSeek는 V4 Pro 종료를 잠시 계획했으나, 이후 요금 변경 없이 계속 제공하겠다고 밝혔습니다. AnyAIGC에서 deepseek-v4-pro는 OpenAI 호환 /v1/chat/completions 엔드포인트로 동작하며 Claude Code에서 바로 사용할 수 있습니다. 하루 종일 동일한 요금이고 동시 실행 제한이 없습니다.

빠른 시작

DeepSeek V4 Pro API 시작하기

  1. 가입 및 충전: anyaigc.ai에서 계정을 만듭니다. $1부터 충전할 수 있으며, 잔액은 플랫폼의 모든 모델에서 공통으로 사용됩니다.
  2. API 키 생성: 콘솔에서 키를 생성하고 sk- 키를 복사해 ANYAIGC_API_KEY 환경 변수에 저장합니다.
  3. 요청 보내기: model을 deepseek-v4-pro로 설정하고 Authorization: Bearer 헤더를 붙여 POST https://anyaigc.ai/v1/chat/completions를 호출합니다. OpenAI SDK를 사용한다면 base_url을 https://anyaigc.ai/v1로 설정하기만 하면 됩니다.

파라미터: DeepSeek에 따르면 V4 시리즈는 기본적으로 thinking이 켜져 있습니다. 요청 본문의 thinking 필드로 thinking을 켜거나 끌 수 있고({"type": "enabled"} 또는 {"type": "disabled"}), reasoning_effort로 추론 강도를 설정합니다(공식 값은 low / high / max). thinking 토큰은 출력으로 계산되며 usage.completion_tokens_details.reasoning_tokens에 표시됩니다. temperature 같은 샘플링 파라미터는 thinking 모드에서 적용되지 않습니다.

모든 파라미터는 Chat Completions API 레퍼런스에서 확인하세요. 문서 예제의 모델 이름을 사용하려는 DeepSeek 모델 ID로 바꾸면 됩니다.

Claude Code

Claude Code에서 DeepSeek V4 Pro 사용하기

Claude Code가 DeepSeek V4 Pro를 사용하도록 연결합니다. 설정 파일 하나만 수정하면 터미널 코딩 에이전트가 V4 Pro로 동작하며, 토큰 단위로 과금됩니다.

  1. Claude Code 설치: 공식 설치 프로그램을 사용합니다. macOS 또는 Linux에서는 curl -fsSL https://claude.ai/install.sh | bash를 실행하면 됩니다.
  2. 설정 추가: ~/.claude/settings.json을 열어 아래 env 블록을 추가하고, ANTHROPIC_AUTH_TOKEN 값을 AnyAIGC에서 만든 키로 바꿉니다.
  3. 코딩 시작: 프로젝트 폴더에서 claude를 실행합니다. /model을 입력해 현재 모델이 deepseek-v4-pro인지 확인합니다.

하위 작업 비용 절감: 이 설정은 ANTHROPIC_DEFAULT_HAIKU_MODEL을 deepseek-v4.1-flash로 지정하므로, Claude Code는 가벼운 하위 작업을 더 저렴한 모델로 보내고 주 작업은 V4 Pro에서 처리합니다.

전체 절차와 자주 발생하는 오류는 Claude Code 설정 가이드를 참고하세요. 가이드의 모델 이름은 deepseek-v4-pro로 바꿔 사용합니다.

사양과 선택 기준

DeepSeek의 릴리스 노트에 따르면 DeepSeek-V4-Pro는 총 1.6T, 활성 49B 파라미터를 가지며, 에이전트 코딩, 세계 지식, 수학·STEM·코딩 추론 분야에서 오픈 모델 중 선두라고 밝히고 있습니다.

공식 가격 페이지에는 DeepSeek-V4-Pro-0813 버전이 1M 컨텍스트 길이, 최대 출력 384K로 표기되어 있으며, thinking 모드와 non-thinking 모드를 모두 지원합니다.

JSON 출력, 도구 호출, Responses API, Anthropic API를 지원하며 비전은 지원하지 않습니다. 공식 동시 실행 제한은 500입니다.

이 페이지에는 입력 $0.5346, 출력 $1.6038, 캐시 히트 $0.0178이 표기되어 있으며, 위의 가격표와 일치합니다.

deepseek-v4.1-flash와 비교하면, 공식 가격 페이지 기준으로 V4.1 Flash는 비전을 지원하고 Pro는 지원하지 않습니다. 동시 실행 제한은 V4.1 Flash가 2500, Pro가 500입니다.

사양은 제공사의 공식 문서(api-docs.deepseek.com)를 기준으로 합니다. 이 페이지의 표가 가격 기준이며, 실시간 요금은 모델 카탈로그에서 확인하시기 바랍니다.

FAQ

DeepSeek V4 Pro API FAQ

DeepSeek V4 Pro API 요금은 얼마입니까?

AnyAIGC의 deepseek-v4-pro는 토큰 단위로 과금되며, 100만 입력 토큰당 $0.5346, 100만 출력 토큰당 $1.6038, 100만 캐시 히트 토큰당 $0.0178입니다. DeepSeek 공식 비피크 시간 USD 가격은 입력 $0.66, 출력 $1.98, 캐시 히트 $0.022이며, 피크 시간에는 두 배가 됩니다. 출력에는 thinking 토큰이 포함됩니다. 실시간 가격은 모델 카탈로그에서 확인할 수 있습니다.

AnyAIGC에도 피크 시간과 비피크 시간 요금제가 있습니까?

아니요. DeepSeek 공식 API는 시간대별 요금제를 사용합니다. 평일 UTC 01:00–04:00 및 06:00–10:00(베이징 시간 9:00–12:00 및 14:00–18:00)이 피크 시간이며, 피크 시간 가격은 비피크 시간 가격의 두 배입니다. AnyAIGC에서는 deepseek-v4-pro를 하루 종일 단일 요금으로 과금합니다. 이 요금은 공식 피크 시간 가격 대비 약 60% 저렴합니다. 실시간 가격은 모델 카탈로그에서 확인할 수 있습니다.

DeepSeek V4 Pro는 서비스가 종료됩니까?

현재는 아닙니다. DeepSeek는 2026년 9월 10일에 V4 Pro 종료 계획을 발표했으나, 이후 공식 변경 로그를 통해 사용자 요청에 따라 9월 14일 이후에도 요금 변경 없이 V4 Pro API를 계속 제공하겠다고 밝혔습니다.

V4 Pro와 V4.1 Flash 중 어느 것을 사용해야 합니까?

DeepSeek는 V4.1 Flash가 이제 성능, 비용, 속도, 전체 작업 시간에서 V4 Pro보다 우수하다고 밝혔습니다. 입력 가격은 V4 Pro의 약 4분의 1이고 이미지도 입력할 수 있으므로, 새 프로젝트에서는 먼저 V4.1 Flash를 사용해 보시기 바랍니다. 프로덕션에서 프롬프트와 워크플로를 이미 V4 Pro에 맞춰 튜닝했다면 V4 Pro를 계속 사용해도 됩니다.

V4 Pro의 추론 강도는 어떻게 설정합니까?

8월 V4 Pro GA 릴리스에서 추론 강도 세 단계 low, high, max가 추가되었습니다. thinking은 기본적으로 high로 켜져 있습니다. reasoning_effort로 단계를 지정하거나, thinking 필드에 {"type": "disabled"}를 지정해 thinking을 끌 수 있습니다. 예시는 이 페이지의 빠른 시작을 참고하세요.

V4 Pro의 파라미터 수와 컨텍스트 길이는 얼마입니까?

DeepSeek는 V4 Pro를 총 1.6T, 활성 49B 파라미터의 MoE로, 하이브리드 어텐션 구조와 32T 사전 학습 토큰을 갖춘 모델로 소개합니다. 컨텍스트 길이는 1M 토큰, 출력은 최대 384K 토큰이며 텍스트만 입력할 수 있고, 가중치는 MIT 라이선스로 공개되어 있습니다.

Claude Code에서 DeepSeek V4 Pro를 사용할 수 있습니까?

예. AnyAIGC의 DeepSeek 모델은 OpenAI와 Anthropic API 형식을 모두 지원합니다. ~/.claude/settings.json의 env 블록에서 ANTHROPIC_BASE_URL을 https://anyaigc.ai로, ANTHROPIC_AUTH_TOKEN을 API 키로, ANTHROPIC_MODEL을 deepseek-v4-pro로 설정한 다음 claude를 실행합니다. 사용한 토큰만큼 과금됩니다.

동시 실행 수나 속도 제한이 있습니까?

AnyAIGC는 deepseek-v4-pro의 동시 실행 수를 제한하지 않으며, 모든 사용자에게 기본으로 적용됩니다. 배치 작업, CI 파이프라인, 병렬 에이전트에 적합합니다.

DeepSeek V4 Pro API 키는 어떻게 발급받습니까?

anyaigc.ai에서 가입하고 잔액을 충전한 뒤 콘솔에서 키를 만드세요. 같은 키로 모든 DeepSeek 모델과 플랫폼의 다른 300개 이상의 모델을 사용할 수 있으므로 별도의 DeepSeek Platform 계정이 필요 없습니다.

AnyAIGC에서 인보이스를 받을 수 있습니까?

네. 콘솔에서 실제 충전한 금액 기준으로 직접 인보이스를 발급할 수 있습니다.

어떤 결제 수단을 지원합니까?

WeChat Pay, Alipay, USDT, 신용카드로 충전할 수 있습니다. 잔액은 USD 기준이며 플랫폼의 모든 모델에서 사용할 수 있습니다. 인보이스는 콘솔에서 충전한 금액 기준으로 발급할 수 있습니다.

신규 사용자에게 무료 체험 크레딧이 있습니까?

네. 신규 계정에는 토큰 200만 개 분량의 체험 크레딧이 제공되므로 충전 여부를 결정하기 전에 먼저 테스트할 수 있습니다. 충전은 $1부터 가능합니다.

잔액을 환불받을 수 있습니까?

네. 사용하지 않은 잔액은 수수료 없이 환불받을 수 있습니다. 환불은 고객 지원에 문의해 진행하세요.

실제 모델이 맞습니까? 데이터는 안전합니까?

요청은 공식 모델 채널로 전달되며, 저가 모델이나 리버스 엔지니어링 방식의 대체 모델은 사용하지 않습니다. 법령에서 요구하는 경우를 제외하고 프롬프트와 출력을 영구 저장하거나 학습에 사용하지 않으며, 콘솔에서 모든 요청의 토큰 수와 비용을 확인할 수 있습니다.
