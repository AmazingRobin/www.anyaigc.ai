Gemini 4 Argon API

Google의 새로운 플래그십 추론 모델로, 가장 어려운 문제를 위해 만들어졌습니다. AnyAIGC에서는 Google 가격의 약 10분의 1입니다.

Google은 Gemini 4 Argon이 코딩, 금융, 법률, 사이버 보안, 과학 분야의 복잡한 실무를 위해 만들어졌다고 설명합니다. gemini-4-argon은 입력 토큰 100만 개당 $0.1985, 출력 토큰 100만 개당 $0.9927이며, 네이티브 Gemini API와 OpenAI 호환 API를 모두 지원합니다.

모델 소개

이전 모델의 파인튜닝이 아닌, 새로운 Gemini 4 프런티어 모델

Google은 2026년 10월 13일 Gemini 4 Argon을 정식 출시(GA)했습니다. 모델 카드는 이 모델을 "이전 모델의 수정이나 파인튜닝이 아닌" 새로운 프런티어 모델이라고 설명합니다. 희소 mixture-of-experts 아키텍처를 사용하며 텍스트, 이미지, 오디오, 동영상을 네이티브로 입력받습니다. Google은 실제 소프트웨어 엔지니어링, 법률·금융 분야의 기업 지식 업무, 사이버 방어 같은 복잡한 워크플로에서 프런티어급 성능을 내는 모델로 포지셔닝합니다.

Argon은 입력, 사고, 출력이 함께 쓰는 1,048,576 토큰 컨텍스트 길이를 가지며, 사고 수준(thinking level)은 low, medium, high 세 단계이고 기본값은 medium입니다. 또한 Google에 따르면 Argon은 이전 Gemini 모델보다 답변이 더 직접적이고 스타일 지시를 더 잘 따르며, 간접 프롬프트 인젝션에 가장 강한 모델입니다.

AnyAIGC에서 gemini-4-argon은 네이티브 /v1beta/models/gemini-4-argon:generateContent 엔드포인트와 OpenAI 호환 /v1/chat/completions를 모두 지원합니다. Google Cloud 계정이 필요 없으며, 같은 키로 플랫폼의 300개 이상 다른 모델도 호출할 수 있습니다.

기능

Gemini 4 Argon으로 할 수 있는 일

  • 저장소 규모의 코딩

    실제 장시간 소프트웨어 엔지니어링을 위해 만들어졌습니다. Google은 DeepSWE v1.1에서 77.9%를 기록했다고 밝혔으며, 모듈 간 리팩터링, 대규모 마이그레이션, 장시간 실행 코딩 에이전트에 적합합니다.

  • 깊이 있는 전문 업무

    Google은 Vals Index, Vals Finance Agent v2, Harvey 법률 에이전트 벤치마크에서 비교 모델보다 앞선다고 밝혔습니다. 재무 분석, 법률 문서 작성, 세무 업무에 적합합니다.

  • 다단계 에이전트와 도구

    함수 호출, 코드 실행, 구조화된 출력, URL 컨텍스트, Google Search 그라운딩을 지원합니다. 엔드 투 엔드 비즈니스 워크플로를 평가하는 AutomationBench에서 51.3%를 기록했습니다.

  • 100만 토큰 컨텍스트

    1,048,576 토큰 컨텍스트 길이에는 책 한 권, 전체 코드베이스, 계약서 묶음이 들어갑니다. GraphWalks 256k–1M 긴 컨텍스트 테스트에서 84.2%를 기록했습니다.

  • 네이티브 멀티모달 이해

    텍스트, 이미지, 오디오, 동영상, PDF를 그대로 보낼 수 있습니다. Google은 긴 동영상을 평가하는 LVBench에서 91.7%, 차트 이해를 평가하는 Chartography에서 71.6%를 기록했다고 밝혔습니다.

  • 수학과 과학

    high 사고 수준은 어려운 수학과 과학 문제를 위한 설정입니다. Google은 RiemannBench에서 76.0%, 생명과학 연구 벤치마크 LABBench 2에서 88.8%를 기록했다고 밝혔습니다.

빠른 시작

3단계로 Gemini 4 Argon API 호출하기

  1. 가입 및 충전: anyaigc.ai에서 계정을 만드세요. 잔액은 플랫폼의 모든 모델에서 공통으로 사용됩니다.
  2. API 키 만들기: 콘솔에서 토큰을 만들고 sk-로 시작하는 키를 복사해 ANYAIGC_API_KEY 환경 변수에 저장하세요.
  3. 요청 보내기: 네이티브 엔드포인트 https://anyaigc.ai/v1beta/models/gemini-4-argon:generateContent를 호출하거나, OpenAI 호환 https://anyaigc.ai/v1/chat/completions에서 model을 gemini-4-argon으로 지정하세요. 둘 다 Authorization: Bearer로 인증합니다.

파라미터 참고: Gemini 4 Argon은 thinkingLevel(low / medium / high)을 사용합니다. thinkingBudget과 minimal은 지원하지 않으며, 보내면 400 오류가 반환됩니다. temperature, topP, topK는 무시됩니다. 사고 토큰도 출력에 포함되므로 Google은 maxOutputTokens를 32,768 이상으로 설정하길 권장합니다. 네이티브 스트리밍은 :streamGenerateContent?alt=sse를 호출하세요.

모든 파라미터는 네이티브 Gemini API 문서와 Chat Completions 문서를 참고하세요. 예제의 모델 이름을 gemini-4-argon으로 바꾸면 됩니다.

사양과 선택 기준

Google 문서는 Gemini 4 Argon을 효율적인 Gemini 4 프런티어 추론 모델로 설명합니다. Carbon과 비교하면 복잡한 코딩, 에이전트, 수학, 과학 작업에서 응답이 더 빠르고 턴당 토큰을 더 적게 사용합니다.

컨텍스트 길이는 1,048,576 토큰(입력과 출력 합산)이고, 최대 출력은 기본 65,536 토큰, 긴 디코딩 사용 시 최대 1,048,576 토큰입니다. 입력은 텍스트, 이미지, 동영상, 오디오, PDF이며 출력은 텍스트입니다.

이 페이지의 입력 $0.1985, 출력 $0.9927, 캐시 히트 $0.0099는 위 가격표와 일치합니다.

gemini-4-carbon과 비교: Google은 Carbon을 가장 뛰어난 추론 모델로 소개하므로, 복잡한 소프트웨어 엔지니어링과 높은 사실 정확도가 필요하면 Carbon을 선택하세요.

사양은 제공사 공식 문서(aistudio.google.com)를 기준으로 합니다. 이 페이지의 표가 가격이며, 실시간 요금은 모델 카탈로그가 기준입니다.

FAQ

Gemini 4 Argon API FAQ

Gemini 4 Argon API 가격은 얼마입니까?

AnyAIGC에서 gemini-4-argon은 토큰 단위로 과금합니다. 입력 100만 토큰당 $0.1985, 출력 100만 토큰당 $0.9927, 캐시 100만 토큰당 $0.0099입니다. Google 프로모션 가격(2026년 11월 30일까지)은 입력 $2.00, 출력 $10.00, 캐시 $0.10이므로 AnyAIGC는 Google 프로모션 가격의 약 10%입니다. 출력에는 사고 토큰이 포함됩니다.

Google 프로모션이 끝나면 AnyAIGC 가격도 바뀝니까?

아니요. Google은 2026년 12월 1일부터 표준 가격으로 돌아가며, 100만 토큰당 입력 $4.00, 출력 $20.00, 캐시 $0.20입니다. AnyAIGC는 현재 가격(입력 $0.1985, 출력 $0.9927, 캐시 $0.0099)을 유지하며, 이는 Google 표준 가격의 약 5%입니다.

Gemini 4 Argon의 모델 ID는 무엇입니까? 정식 출시된 모델입니까?

모델 ID는 gemini-4-argon입니다. Google이 2026년 10월 13일 정식 출시했으며, 프리뷰가 아닌 안정 버전 모델입니다. 네이티브 엔드포인트는 URL에 모델 이름을 넣고(/v1beta/models/gemini-4-argon:generateContent), OpenAI 호환 엔드포인트는 model 필드에 넣습니다.

컨텍스트 길이와 최대 출력은 얼마입니까?

Google은 입력, 사고, 출력이 공유하는 1,048,576 토큰 컨텍스트 길이를 제시합니다. 동기 요청은 기본적으로 최대 65,536 출력 토큰을 반환하며, Google의 긴 디코딩(최대 약 100만 출력 토큰)은 백그라운드 실행 기능으로 처리됩니다. 어려운 문제는 몇 분간 사고할 수 있으므로 HTTP 클라이언트 타임아웃을 15분 이상으로 설정하세요.

네이티브 Gemini 엔드포인트와 OpenAI 호환 엔드포인트 중 무엇을 써야 합니까?

어느 쪽이든 사용할 수 있습니다. 네이티브 엔드포인트는 POST https://anyaigc.ai/v1beta/models/gemini-4-argon:generateContent이며 Google Gemini API와 요청 본문이 같아서 contents, systemInstruction, tools, thinkingConfig를 사용할 수 있습니다. OpenAI 호환 엔드포인트는 POST https://anyaigc.ai/v1/chat/completions이며, 공식 OpenAI SDK에서는 base_url을 https://anyaigc.ai/v1로 설정하세요. 둘 다 Authorization: Bearer를 사용합니다.

사고 수준(thinking level)은 어떻게 설정합니까?

Gemini 4 Argon은 low, medium, high 세 가지 사고 수준을 지원하며 기본값은 medium입니다. 네이티브 엔드포인트에서는 generationConfig.thinkingConfig.thinkingLevel을 설정하세요. Google에 따르면 이 모델은 thinkingBudget과 minimal을 지원하지 않으며, 보내면 400 오류가 반환됩니다. temperature, top_p, top_k는 무시됩니다.

Gemini 4 Argon, Gemini 3.8 Flash, Gemini 3.1 Pro 중 무엇을 써야 합니까?

Gemini 4 Argon은 Google의 현재 플래그십으로, 복잡한 소프트웨어 엔지니어링, 금융·법률 전문 업무, 장시간 실행 에이전트, 매우 긴 문서를 위해 만들어졌습니다. Gemini 3.8 Flash는 Google이 가장 지능적인 Flash 모델이라고 부르는 모델로, AnyAIGC에서 입력 $0.0744, 출력 $0.3722이며 대량 처리와 지연 시간에 민감한 작업에 적합합니다. Gemini 3.1 Pro는 아직 프리뷰이며 AnyAIGC에서 입력 $0.1985, 출력 $1.1910입니다(프롬프트 ≤200K). 출력 가격이 Argon보다 높으므로 새 프로젝트는 보통 Argon으로 시작하는 것이 좋습니다. 더 깊은 추론과 더 긴 에이전트 작업이 필요하면 Argon을 기반으로 만든 Gemini 4 Carbon(AnyAIGC에서 입력 $0.7147, 출력 $3.5740)으로 올리세요. 더 많이 사고하는 만큼 비용도 더 듭니다.

동시 실행 수나 속도 제한이 있습니까?

AnyAIGC는 gemini-4-argon에 동시 실행 제한을 두지 않습니다. 모든 계정에 기본 적용되므로 배치 작업이나 여러 에이전트를 병렬로 실행하는 데 적합합니다.

Google Cloud 계정이 필요합니까?

아니요. AnyAIGC 계정만 있으면 됩니다. 요청은 https://anyaigc.ai로 보내고, 요금은 USD로 과금되며, 카드, WeChat Pay, Alipay, USDT로 결제할 수 있습니다.

Gemini 4 Argon API 키는 어떻게 받습니까?

anyaigc.ai에서 가입하고 충전한 뒤 콘솔에서 토큰을 만드세요. 같은 키로 Gemini 4 Argon과 플랫폼의 300개 이상 다른 모델을 사용할 수 있으며, Google Cloud 계정은 필요 없습니다.

AnyAIGC에서 인보이스를 받을 수 있습니까?

네. 콘솔에서 실제 충전한 금액 기준으로 직접 인보이스를 발급할 수 있습니다.

어떤 결제 수단을 지원합니까?

WeChat Pay, Alipay, USDT, 신용카드로 충전할 수 있습니다. 잔액은 USD 기준이며 플랫폼의 모든 모델에서 사용할 수 있습니다. 인보이스는 콘솔에서 충전한 금액 기준으로 발급할 수 있습니다.

신규 사용자에게 무료 체험 크레딧이 있습니까?

네. 신규 계정에는 토큰 200만 개 분량의 체험 크레딧이 제공되므로 충전 여부를 결정하기 전에 먼저 테스트할 수 있습니다. 충전은 $1부터 가능합니다.

잔액을 환불받을 수 있습니까?

네. 사용하지 않은 잔액은 수수료 없이 환불받을 수 있습니다. 환불은 고객 지원에 문의해 진행하세요.

실제 모델이 맞습니까? 데이터는 안전합니까?

요청은 공식 모델 채널로 전달되며, 저가 모델이나 리버스 엔지니어링 방식의 대체 모델은 사용하지 않습니다. 법령에서 요구하는 경우를 제외하고 프롬프트와 출력을 영구 저장하거나 학습에 사용하지 않으며, 콘솔에서 모든 요청의 토큰 수와 비용을 확인할 수 있습니다.

내 데이터가 학습에 사용됩니까?

아니요. 법적으로 요구되는 경우를 제외하고 AnyAIGC는 프롬프트와 출력을 영구 저장하거나 학습에 사용하지 않으며, 요청은 HTTPS로 전송 중 암호화됩니다. 자세한 내용은 AnyAIGC 개인정보 처리방침을 참고하세요. 모델 자체의 데이터 정책은 Google 공식 약관을 따릅니다.
