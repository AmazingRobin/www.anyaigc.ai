H3는 여러 장의 참조 이미지와 비디오를 받을 수 있습니다. 처음 5장은 무료이고, 그 이후 이미지부터 과금됩니다.

04

768P / 2K / 480P

H3는 768P 또는 2K, H3-Max는 480P 또는 768P로 렌더링하며, 실제 출력 초 단위로 과금됩니다.

Python
import json
import os
import time
import urllib.request

BASE = "https://anyaigc.ai"
HEADERS = {
    "Authorization": "Bearer " + os.environ["ANYAIGC_API_KEY"],
    "Content-Type": "application/json",
}


def call(method, path, payload=None):
    data = json.dumps(payload, ensure_ascii=False).encode("utf-8") if payload else None
    request = urllib.request.Request(BASE + path, data=data, headers=HEADERS, method=method)
    with urllib.request.urlopen(request, timeout=120) as response:
        return json.load(response)


payload = {
    "model_name": "Hailuo",
    "model_version": "H3",
    "prompt": "A sunset over the sea, the camera slowly pushing in as waves wash over the rocks.",
    "output_config": {
        "aspect_ratio": "16:9",
        "duration": 6,
        "resolution": "768P"
    }
}

task_id = call("POST", "/tencent-vod/v1/aigc-video", payload)["Response"]["TaskId"]
print("task_id:", task_id)

# Poll every 10 seconds; print the full result (with the video URL) once Status is FINISH
while True:
    result = call("GET", f"/tencent-vod/v1/query/{task_id}")["Response"]
    if result["Status"] == "FINISH":
        break
    time.sleep(10)

print(json.dumps(result, ensure_ascii=False, indent=2))

작업을 생성하면 Response.TaskId가 반환됩니다. GET /tencent-vod/v1/query/{task_id}를 폴링하고, Status가 FINISH가 되면 Output.FileInfos[].FileUrl에서 비디오를 내려받으세요(만료 시간이 있는 임시 저장소). 작업 조회 문서 보기 ↗

FAQ

MiniMax API FAQ

가격, 엔드포인트, 결과물, 기업 도입을 한곳에서 확인하세요.

Hailuo H3 API 가격은 얼마입니까?

H3 768P 출력 비디오 초당 $0.0972, H3 768P 입력 비디오 초당 $0.0972, H3 2K 출력 비디오 초당 $0.1579, H3 2K 입력 비디오 초당 $0.1579, H3-Max 480P 출력 비디오 초당 $0.0607, H3-Max 768P 출력 비디오 초당 $0.0972, 입력 이미지(처음 5장) 이미지당 $0, 입력 이미지(6번째부터) 이미지당 $0.0486입니다. 모든 가격은 USD이며, 현재 요율은 모델 카탈로그에서 확인하세요.

어떤 API 엔드포인트를 사용해야 합니까?

https://anyaigc.ai에서 POST /tencent-vod/v1/aigc-video와 GET /tencent-vod/v1/query/{task_id}를 사용하고, API 키는 Authorization: Bearer로 전달하세요.

H3와 H3-Max는 무엇이 다릅니까?

H3는 768P 또는 2K(1080P 요청은 768P로, 4K 요청은 2K로 렌더링)에서 4–15초를 생성하며, 21:9, 16:9, 4:3, 1:1, 3:4, 9:16 비율과 텍스트, 첫/마지막 프레임, 멀티모달 참조 입력을 지원합니다. H3-Max는 빠른 버전으로 480P 또는 768P에서 5–15초를 생성하고, 텍스트와 첫/마지막 프레임 입력만 지원하며 중간 프레임, 멀티모달 참조, 입력 비디오는 지원하지 않습니다.

요청 한 번에 무엇이 반환됩니까?

비동기 작업 하나가 비디오 하나를 생성합니다. H3는 4–15초, H3-Max는 5–15초이며 실제 출력 초 단위로 과금됩니다.

동시 실행 수나 RPM 제한이 있습니까?

AnyAIGC는 MiniMax에 동시 실행 제한을 두지 않으며 고정 RPM 상한도 없습니다. 다만 생성에는 시간이 걸리므로 타임아웃, 오류 처리, 적절한 재시도를 애플리케이션에서 설정하세요.

생성한 콘텐츠를 상업적으로 사용할 수 있습니까?

모델과 출력물의 상업적 사용은 MiniMax 공식 약관을 따릅니다. 참조 자료, 음성, 생성된 콘텐츠에 대해 필요한 권리를 갖추었는지 확인하세요. AnyAIGC는 독립 API 제공업체입니다.

AnyAIGC에서 인보이스를 받을 수 있습니까?

네. 콘솔에서 실제 충전한 금액 기준으로 직접 인보이스를 발급할 수 있습니다.

어떤 결제 수단을 지원합니까?

WeChat Pay, Alipay, USDT, 신용카드로 충전할 수 있습니다. 잔액은 USD 기준이며 플랫폼의 모든 모델에서 사용할 수 있습니다. 인보이스는 콘솔에서 충전한 금액 기준으로 발급할 수 있습니다.

신규 사용자에게 무료 체험 크레딧이 있습니까?

네. 신규 계정에는 토큰 200만 개 분량의 체험 크레딧이 제공되므로 충전 여부를 결정하기 전에 먼저 테스트할 수 있습니다. 충전은 $1부터 가능합니다.

잔액을 환불받을 수 있습니까?

네. 사용하지 않은 잔액은 수수료 없이 환불받을 수 있습니다. 환불은 고객 지원에 문의해 진행하세요.

실제 모델이 맞습니까? 데이터는 안전합니까?

요청은 공식 모델 채널로 전달되며, 저가 모델이나 리버스 엔지니어링 방식의 대체 모델은 사용하지 않습니다. 법령에서 요구하는 경우를 제외하고 프롬프트와 출력을 영구 저장하거나 학습에 사용하지 않으며, 콘솔에서 모든 요청의 토큰 수와 비용을 확인할 수 있습니다.
