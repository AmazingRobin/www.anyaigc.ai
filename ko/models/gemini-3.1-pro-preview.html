Gemini 3.1 Pro Preview API

단순한 답으로는 부족한 작업을 위한 Gemini 3 Pro 추론 모델입니다. AnyAIGC에서는 Google 공식 정가의 약 10%에 사용할 수 있습니다.

Google은 Gemini 3.1 Pro를 "멀티모달 이해, 에이전트 기능, 바이브 코딩을 위해 만든 3세대 Pro 모델"이라고 소개합니다. gemini-3.1-pro-preview의 가격은 네이티브 Gemini API와 OpenAI 호환 엔드포인트 모두 입력 100만 토큰당 $0.1985, 출력 100만 토큰당 $1.1910입니다.

소개

복잡한 추론을 위한 Gemini 3의 Pro 등급 모델

Google은 2026년 2월 19일 Gemini 3.1 Pro Preview를 출시하면서 "가장 복잡한 작업을 위한 더 똑똑한 모델"이라는 제목을 달았고, "3.1 Pro는 단순한 답으로는 부족한 작업을 위해 설계되었다"고 밝혔습니다. 모델 카드에 따르면 이 모델은 Gemini 3 Pro를 기반으로 합니다. 2026년 3월 9일부터 Google API의 gemini-3-pro-preview는 gemini-3.1-pro-preview를 가리킵니다.

입력은 최대 1,048,576 토큰, 출력은 최대 65,536 토큰이며, 텍스트, 이미지, 동영상, 오디오, PDF를 입력으로 받을 수 있습니다. 사고 수준(thinking level)은 low, medium, high의 세 단계이고 기본값은 high(동적)입니다. 함수 호출, 코드 실행, 구조화된 출력, URL 컨텍스트, Google Search 및 Google Maps 그라운딩, 컨텍스트 캐싱 도구를 지원합니다.

AnyAIGC에서 gemini-3.1-pro-preview는 네이티브 /v1beta/models/gemini-3.1-pro-preview:generateContent 엔드포인트와 OpenAI 호환 /v1/chat/completions에서 모두 사용할 수 있습니다. Google Cloud 계정이 필요 없으며, 같은 키로 300개 이상의 다른 모델도 호출할 수 있습니다.

사양

사양과 선택 기준

Google 문서에 따르면 Gemini 3.1 Pro Preview는 Gemini 3 Pro 시리즈의 성능과 신뢰성을 개선한 모델로, 더 나은 사고, 향상된 토큰 효율, 더 근거 있고 사실에 부합하는 답변을 제공하며, 소프트웨어 엔지니어링과 정밀한 도구 사용 및 안정적인 다단계 실행이 필요한 에이전트 워크플로에 최적화되어 있습니다.

입력 한도는 1,048,576 토큰, 출력 한도는 65,536 토큰입니다. 입력은 텍스트, 이미지, 동영상, 오디오, PDF를 지원하고 출력은 텍스트입니다. 호출할 모델 이름은 gemini-3.1-pro-preview입니다.

이 페이지에는 (프롬프트 ≤ 200K 토큰) 입력 $0.1985, 출력 $1.1910, 캐시 히트 $0.0199가 표시되어 있으며, 다른 구간은 위의 가격표에서 확인할 수 있습니다.

gemini-4-argon과 비교하면, Google은 Gemini 4 Argon을 효율적인 Gemini 4 최상위 추론 모델이라고 설명하며, 긴 디코딩을 켜면 출력이 최대 1,048,576 토큰까지 가능합니다.

사양은 제공사의 공식 문서(aistudio.google.com)를 따랐습니다. 이 페이지의 표는 가격이며, 실시간 요율은 모델 카탈로그가 기준입니다.

FAQ

Gemini 3.1 Pro API FAQ

Gemini 3.1 Pro Preview API 가격은 얼마입니까?

AnyAIGC에서 gemini-3.1-pro-preview는 토큰 단위 구간별 요금이 적용됩니다. 프롬프트 200K 토큰 이하는 100만 토큰당 입력 $0.1985, 출력 $1.1910, 캐시 히트 $0.0199입니다. 프롬프트가 200K 토큰을 넘으면 입력 $0.3970, 출력 $1.7865, 캐시 히트 $0.0398입니다. Google 공식 정가는 $2.00 / $12.00 / $0.20과 $4.00 / $18.00 / $0.40이므로, AnyAIGC는 Google 공식 정가의 약 10%입니다. 출력에는 사고 토큰이 포함됩니다.

프롬프트가 200K 토큰을 넘으면 어떻게 과금됩니까?

한 요청의 프롬프트가 200K 토큰을 넘으면 요청 전체가 더 높은 구간으로 과금됩니다. 입력과 캐시 히트는 2배, 출력은 1.5배이며, 100만 토큰당 입력 $0.3970, 출력 $1.7865, 캐시 히트 $0.0398입니다. Google이 쓰는 구간 규칙과 같습니다. 실시간 가격은 모델 카탈로그에서 확인하세요.

Gemini 3.1 Pro는 아직 프리뷰입니까? 서비스가 종료됩니까?

네, 아직 프리뷰입니다. Google은 2026년 2월 19일 Gemini 3.1 Pro Preview를 출시했으며, 2026년 10월 기준으로 모델 ID gemini-3.1-pro-preview의 공개 프리뷰 상태가 이어지고 있습니다. Google의 지원 중단 페이지에는 "종료 날짜 미발표"(No shutdown date announced)로 표시되어 있고, 정식 출시(GA) 일정도 공개되지 않았습니다. 프리뷰는 동작이 바뀔 수 있으므로, 안정적인 모델이 필요한 새 프로젝트에는 정식 출시된 Gemini 4 Argon을 사용할 수 있습니다.

컨텍스트 길이와 최대 출력은 어떻게 됩니까?

Google은 입력 한도 1,048,576 토큰, 요청당 최대 출력 65,536 토큰, 지식 기준일 2025년 1월로 명시합니다. 텍스트, 이미지, 동영상, 오디오, PDF 입력을 받고 텍스트를 반환합니다.

네이티브 Gemini API와 OpenAI 호환 엔드포인트 중 무엇을 써야 합니까?

어느 쪽이든 사용할 수 있습니다. 네이티브 엔드포인트는 POST https://anyaigc.ai/v1beta/models/gemini-3.1-pro-preview:generateContent이며 Google Gemini API와 같은 요청 본문을 받습니다. OpenAI 호환 엔드포인트는 POST https://anyaigc.ai/v1/chat/completions입니다. 공식 OpenAI SDK의 base_url을 https://anyaigc.ai/v1로 지정하고 model을 gemini-3.1-pro-preview로 설정하세요. 두 방식 모두 Authorization: Bearer를 사용합니다.

사고 수준(thinking level)은 어떻게 설정합니까?

Gemini 3.1 Pro는 low, medium, high의 세 가지 사고 수준을 지원합니다. 기본값은 high(동적 사고)이며 minimal은 지원하지 않습니다. 네이티브 API에서는 generationConfig.thinkingConfig.thinkingLevel을 설정하세요. 단순한 작업에는 low를 사용해 지연 시간과 출력 토큰을 줄이세요.

Gemini 3.1 Pro와 Gemini 4 Argon 중 무엇을 써야 합니까?

AnyAIGC에서 두 모델의 입력 가격은 100만 토큰당 $0.1985로 같지만, Gemini 4 Argon은 출력 가격이 더 낮고($0.9927 대 $1.1910) 정식 출시된 반면 3.1 Pro는 아직 프리뷰입니다. 새 프로젝트는 Gemini 4 Argon으로 시작하세요. 이미 3.1 Pro에 맞춰 프롬프트와 평가를 조정했다면 그대로 사용하고, 전환하기 전에 비교해 보세요. 대량 처리나 지연 시간에 민감한 작업에는 Gemini 3.8 Flash(입력 $0.0744, 출력 $0.3722)를 검토하세요.

요청 속도나 동시 실행에 제한이 있습니까?

AnyAIGC는 gemini-3.1-pro-preview에 동시 실행 제한을 두지 않습니다. 모든 계정에 기본으로 적용되므로 배치 작업과 병렬 에이전트를 바로 실행할 수 있습니다.

anyaigc.ai에서 가입하고 충전한 뒤 콘솔에서 토큰을 생성하세요. 같은 키로 Gemini 3.1 Pro Preview와 300개 이상의 다른 모델을 사용할 수 있습니다. Google Cloud 계정은 필요하지 않습니다.

네. 콘솔에서 실제 충전한 금액 기준으로 직접 인보이스를 발급할 수 있습니다.

어떤 결제 수단을 지원합니까?

WeChat Pay, Alipay, USDT, 신용카드로 충전할 수 있습니다. 잔액은 USD 기준이며 플랫폼의 모든 모델에서 사용할 수 있습니다. 인보이스는 콘솔에서 충전한 금액 기준으로 발급할 수 있습니다.

잔액을 환불받을 수 있습니까?

실제 모델이 맞습니까? 데이터는 안전합니까?

요청은 공식 모델 채널로 전달되며, 저가 모델이나 리버스 엔지니어링 방식의 대체 모델은 사용하지 않습니다. 법령에서 요구하는 경우를 제외하고 프롬프트와 출력을 영구 저장하거나 학습에 사용하지 않으며, 콘솔에서 모든 요청의 토큰 수와 비용을 확인할 수 있습니다.

내 데이터가 학습에 사용됩니까?

아니요. 법률에서 요구하는 경우를 제외하고 AnyAIGC는 프롬프트와 출력을 영구 저장하거나 학습에 사용하지 않으며, 요청은 HTTPS로 전송됩니다. AnyAIGC 개인정보 처리방침을 확인하세요. 모델 자체의 데이터 정책은 Google의 약관을 따릅니다.
