import json
import os
import urllib.request

payload = {
    "model": "MiniMax-M3.1-Flash",
    "messages": [
        {
            "role": "user",
            "content": "Design three clear API endpoints for a to-do application."
        }
    ]
}

request = urllib.request.Request(
    "https://anyaigc.ai/v1/chat/completions",
    data=json.dumps(payload, ensure_ascii=False).encode("utf-8"),
    headers={
        "Authorization": "Bearer " + os.environ["ANYAIGC_API_KEY"],
        "Content-Type": "application/json",
    },
    method="POST",
)
with urllib.request.urlopen(request, timeout=120) as response:
    result = json.load(response)

print(json.dumps(result, ensure_ascii=False, indent=2))

팀이 AnyAIGC를 신뢰하는 이유

체험 크레딧, 충전, 환불, 데이터 처리, 과금 방식을 미리 분명하게 안내합니다.

  • 시작은 무료 토큰 500만 개

    신규 계정에는 체험 크레딧이 제공되므로 충전 전에 먼저 테스트할 수 있습니다.

  • $1부터 충전, 환불 가능

    $1부터 충전할 수 있습니다. 사용하지 않은 잔액은 수수료 없이 환불받을 수 있습니다.

  • 공식 채널, 실제 모델

    요청은 공식 모델 채널로 전달되며, 저가 모델이나 리버스 엔지니어링 방식의 대체 모델은 사용하지 않습니다.

    콘솔에서 모든 요청의 토큰 수와 비용을 확인할 수 있고, API 키마다 한도를 설정할 수 있습니다.

FAQ

MiniMax API FAQ

가격, 엔드포인트, 결과물, 기업 도입을 한곳에서 확인하세요.

MiniMax API의 시작 가격은 얼마입니까?

M3.1 Flash 입력은 100만 토큰당 $0.0603이고, Speech Turbo는 10,000자당 $0.3176, HD는 10,000자당 $0.5559입니다. H3 768P 출력은 초당 $0.0750입니다. 서비스마다 과금 단위가 다릅니다. 전체 가격표와 모델 카탈로그에서 실시간 가격을 확인하세요. M3.1 Flash는 공식 정가 대비 59%, M3와 M2.5는 32% 할인됩니다. 할인은 여기 표시된 요금에 적용되며, 현재 혜택은 카탈로그에서 확인하세요.

13개 모델 중 무엇을 선택해야 합니까?

대화와 개발에는 M3.1 Flash, M3, M2.7, M2.5를, 비디오에는 MiniMax H3 또는 Hailuo H3(빠른 H3-Max 포함)를, 내레이션에는 Speech 여섯 가지 버전과 HD/Turbo 변형 중 하나를, 텍스트로 음성을 설계할 때는 Voice Design을 선택하세요. 먼저 실제 워크로드와 음성으로 테스트하세요.

이 모델들은 하나의 엔드포인트를 공유합니까?

AnyAIGC API 키와 도메인은 공유합니다. 채팅은 /v1/chat/completions, MiniMax H3는 /minimax/v2/video_generation, Hailuo H3는 /tencent-vod/v1/aigc-video, 음성은 /minimax/v1/t2a_v2 또는 /minimax/v1/t2a_async_v2, Voice Design은 /minimax/v1/voice_design을 사용합니다.

비디오, 음성, 보이스 디자인 결과는 어떻게 받습니까?

H3 생성 요청은 먼저 task_id를 반환하고, 동기 방식 음성 요청은 오디오 관련 JSON을 반환합니다. Voice Design은 문서에 결과 필드가 일관되지 않게 적혀 있으므로, 전체 응답을 보관하고 응답 규격을 확인하세요. 각 가이드에 최소 요청 예시가 있습니다.

동시 실행 수나 RPM 제한이 있습니까?

AnyAIGC는 MiniMax에 동시 실행 제한을 두지 않으며 고정 RPM 상한도 없습니다. 다만 생성에는 시간이 걸리므로 타임아웃, 오류 처리, 적절한 재시도를 애플리케이션에서 설정하세요.

생성한 콘텐츠를 상업적으로 사용할 수 있습니까?

모델과 출력물의 상업적 사용은 MiniMax 공식 약관을 따릅니다. 참조 자료, 음성, 생성된 콘텐츠에 대해 필요한 권리를 갖추었는지 확인하세요. AnyAIGC는 독립 API 제공업체입니다.

AnyAIGC에서 인보이스를 받을 수 있습니까?

네. 콘솔에서 실제 충전한 금액 기준으로 직접 인보이스를 발급할 수 있습니다.

어떤 결제 수단을 지원합니까?

WeChat Pay, Alipay, USDT, 신용카드로 충전할 수 있습니다. 잔액은 USD 기준이며 플랫폼의 모든 모델에서 사용할 수 있습니다. 인보이스는 콘솔에서 충전한 금액 기준으로 발급할 수 있습니다.

신규 사용자에게 무료 체험 크레딧이 있습니까?

네. 신규 계정에는 토큰 500만 개 분량의 체험 크레딧이 제공되므로 충전 여부를 결정하기 전에 먼저 테스트할 수 있습니다. 충전은 $1부터 가능합니다.

잔액을 환불받을 수 있습니까?

네. 사용하지 않은 잔액은 수수료 없이 환불받을 수 있습니다. 환불은 고객 지원에 문의해 진행하세요.

실제 모델이 맞습니까? 데이터는 안전합니까?

요청은 공식 모델 채널로 전달되며, 저가 모델이나 리버스 엔지니어링 방식의 대체 모델은 사용하지 않습니다. 법령에서 요구하는 경우를 제외하고 프롬프트와 출력을 영구 저장하거나 학습에 사용하지 않으며, 콘솔에서 모든 요청의 토큰 수와 비용을 확인할 수 있습니다.
