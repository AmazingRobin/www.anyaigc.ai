Python
import json
import os
import time
import urllib.request

BASE = "https://anyaigc.ai"
HEADERS = {
    "Authorization": "Bearer " + os.environ["ANYAIGC_API_KEY"],
    "Content-Type": "application/json",
}


def call(method, path, body=None):
    data = json.dumps(body, ensure_ascii=False).encode("utf-8") if body else None
    request = urllib.request.Request(BASE + path, data=data, headers=HEADERS, method=method)
    with urllib.request.urlopen(request, timeout=60) as response:
        return json.load(response)


payload = {
    "model": "vidu-image-q2",
    "images": [
        "https://www.anyaigc.ai/assets/models/vidu/skycity.webp"
    ],
    "prompt": "Use the sky city in the reference as the backdrop for a film poster at golden hour, with space for a title in the center.",
    "resolution": "1080p",
    "aspect_ratio": "16:9"
}

created = call("POST", "/ent/v2/reference2image", payload)
task_id = (created.get("data") or created)["task_id"]
print("task_id:", task_id)

# Poll every 10 seconds until the task leaves the queue
for _ in range(120):
    result = call("GET", f"/ent/v2/tasks/{task_id}/creations")
    state = (result.get("data") or result).get("state") or (result.get("data") or result).get("status")
    if state not in ("created", "queueing", "processing"):
        break
    time.sleep(10)

# creations holds the video or image URLs; they expire, so download promptly
print(json.dumps(result, ensure_ascii=False, indent=2))

샘플 이미지를 직접 준비한 URL 또는 Base64(png, jpeg, webp, 최대 50 MB)로 바꾸세요. status 필드는 실제 응답에서 읽으세요. 예제는 작업이 created, queueing, processing 상태를 벗어나면 폴링을 멈춥니다.

사양

사양과 선택 기준

Vidu 공식 이미지 생성 API에서 viduq2는 텍스트→이미지, 이미지 편집, 참조→이미지를 지원하고, viduq1은 참조→이미지만 지원합니다.

viduq2는 참조 이미지를 0장에서 7장까지 받습니다. 이미지가 없으면 프롬프트만으로 생성합니다.

viduq2는 1080p, 2K, 4K로 출력하며 기본값은 1080p입니다.

viduq2는 16:9, 9:16, 1:1, 3:4, 4:3, 21:9, 2:3, 3:2를 지원하며, auto를 지정하면 첫 번째 입력 이미지에 맞춥니다.

이 페이지에는 텍스트→이미지 1080p $0.0298 / 이미지, 텍스트→이미지 2K $0.0397 / 이미지, 텍스트→이미지 4K $0.0496 / 이미지, 참조 이미지 1–3장 1080p $0.0397 / 이미지가 표시되어 있으며, 위의 가격표와 일치합니다.

사양은 제공사 공식 문서(platform.vidu.com)를 기준으로 합니다. 이 페이지의 표는 가격이며, 실시간 요금은 모델 카탈로그가 기준입니다.

Vidu Q2 Image API 자주 묻는 질문

가격, 엔드포인트, 결과물, 기업 도입을 한곳에서 확인하세요.

Vidu Q2 Image API 가격은 얼마입니까?

텍스트→이미지 1080p $0.0298 / 이미지, 텍스트→이미지 2K $0.0397 / 이미지, 텍스트→이미지 4K $0.0496 / 이미지, 참조 이미지 1–3장 1080p $0.0397 / 이미지, 참조 이미지 1–3장 2K $0.0596 / 이미지, 참조 이미지 1–3장 4K $0.0993 / 이미지, 참조 이미지 4–7장 1080p $0.0496 / 이미지, 참조 이미지 4–7장 2K $0.0794 / 이미지, 참조 이미지 4–7장 4K $0.1489 / 이미지. 가격은 USD 기준이며, 현재 요금은 모델 카탈로그에서 확인하세요.

어떤 엔드포인트를 호출해야 합니까?

model을 vidu-image-q2로 설정해 POST /ent/v2/reference2image를 호출하세요. 작업을 생성하면 task_id가 반환되며, 결과는 GET /ent/v2/tasks/{id}/creations로 가져옵니다. 기본 URL은 https://anyaigc.ai이고, 키는 Authorization: Bearer에 넣습니다.

지원하는 참조 이미지 수, 해상도, 화면 비율은 무엇입니까?

텍스트→이미지는 images를 생략하고, 참조→이미지는 1–7장을 전달하세요. 과금은 1–3장과 4–7장 구간으로 나뉩니다. 해상도는 1080p(기본값), 2K, 4K이며, 화면 비율은 16:9, 9:16, 1:1, 3:4, 4:3, 21:9, 2:3, 3:2, auto입니다. model로 viduq2를 전달하면 vidu-image-q2로 과금됩니다.

결과는 어떻게 받습니까?

작업은 비동기입니다. task_id를 보관하고 GET /ent/v2/tasks/{id}/creations를 폴링하세요. 작업이 끝나면 creations에서 비디오 또는 이미지 URL을 읽습니다. 작업을 생성할 때 callback_url을 전달할 수도 있습니다. 결과 URL은 만료되므로 파일을 바로 저장하세요.

동시 실행 수나 RPM 제한이 있습니까?

AnyAIGC의 Vidu는 모든 계정에 기본으로 동시 실행 제한이 없으며, 고정 RPM 상한도 없습니다. 비디오 생성에는 시간이 걸리므로 애플리케이션에서 폴링 간격과 타임아웃을 설정하세요.

출력물을 상업적으로 사용할 수 있습니까?

상업적 이용은 Vidu(ShengShu Technology)의 공식 약관을 따르며, 업로드하는 참조 이미지, 인물, 브랜드 자산에 대한 권리는 직접 확보해야 합니다. AnyAIGC는 독립 API 제공업체입니다.

요청은 공식 모델 채널로 전달되며, 저가 모델이나 리버스 엔지니어링 방식의 대체 모델은 사용하지 않습니다. 법령에서 요구하는 경우를 제외하고 프롬프트와 출력을 영구 저장하거나 학습에 사용하지 않으며, 콘솔에서 모든 요청의 토큰 수와 비용을 확인할 수 있습니다.
