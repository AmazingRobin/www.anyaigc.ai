Gemini 4 Hydrogen API

일상적인 코딩과 에이전트 워크플로를 위한 Google의 빠른 모델입니다. AnyAIGC에서는 Google 공식 정가의 약 36%입니다.

Google은 이 모델을 모두에게 프런티어 수준의 지능을 제공하는 모델로 소개합니다. Carbon과 Argon은 가장 어려운 심층 추론을 맡고, Hydrogen은 빠른 실행을 맡습니다. gemini-4-hydrogen은 입력 100만 토큰당 $0.5360, 출력 100만 토큰당 $2.6800이며, 네이티브 Gemini API와 OpenAI 호환 API를 모두 지원합니다.

모델 소개

Gemini 4 세대의 빠른 실행 모델

Google은 2026년 11월 12일에 Gemini 4 Hydrogen을 출시했습니다. 모델 카드에 따르면 Gemini 4 Carbon과 Argon은 가장 어려운 문제를 위한 깊고 장시간에 걸친 추론용 프런티어 모델이고, Hydrogen은 에이전트 워크플로 전반의 빠른 실행을 위해 만들어졌습니다. Gemini 4 Carbon에서 파생되었으며 텍스트, 이미지, 오디오, 동영상, PDF 입력을 기본으로 받습니다.

Google이 밝힌 개선점은 다음과 같습니다. 더 깔끔한 코드를 작성하고, 맥락이 부족하면 추측하지 않고 부족하다고 알리며, 사실을 지어내는 빈도가 Gemini 3.8 Flash의 5분의 1 미만입니다. 읽기·검색 도구 호출을 병렬로 묶어 처리하고, 도구 호출이 실패했을 때 더 잘 복구합니다. 코딩과 에이전트 작업을 단독으로 처리할 수도 있고, Carbon, Argon과 함께 서브 에이전트로 실행해 병렬 실행과 검증을 맡길 수도 있습니다. Google의 호스팅 에이전트 서비스에서 Antigravity 에이전트는 이제 기본값으로 Hydrogen을 사용합니다.

AnyAIGC에서 gemini-4-hydrogen은 네이티브 /v1beta/models/gemini-4-hydrogen:generateContent 엔드포인트와 OpenAI 호환 /v1/chat/completions를 모두 지원합니다. Google Cloud 계정이 필요 없으며, 같은 키로 플랫폼의 300개 이상의 다른 모델도 호출할 수 있습니다.

기능

Gemini 4 Hydrogen이 잘하는 일

  • 일상적인 코딩과 디버깅

    저장소 단위의 반복적인 수정과 디버깅, 웹 개발, 일상적인 프로토타입 제작을 위해 만들어졌습니다. Google은 SWE-sweep에서 13.5%를 기록했다고 밝혔으며, Claude Sonnet 5.5는 3.1%, GPT-6.1 Terra는 5.8%입니다.

  • 빠르게 실행하는 에이전트

    함수 호출, 코드 실행, 컴퓨터 사용(computer use), Google Search 및 Maps 그라운딩을 모두 지원합니다. AutomationBench-AA에서 76.1%, Agents' Last Exam v1.1에서 71.6%를 기록했습니다.

  • 멀티 모델 구성의 서브 에이전트

    Google은 Carbon에 인터페이스 설계와 어려운 부분을 맡기고, 코드 수정, 병렬 하위 작업, 테스트는 Hydrogen에 넘기면 지연 시간과 토큰 사용량을 줄일 수 있다고 제안합니다.

  • 100만 토큰 컨텍스트

    1,048,576 토큰의 컨텍스트 길이에 전체 코드베이스나 대량의 문서를 담을 수 있습니다. 동기 출력은 기본적으로 65,536 토큰으로 제한되며, 긴 출력은 백그라운드 실행을 통해 약 1M 토큰까지 늘릴 수 있습니다.

  • 멀티모달 지식 업무

    스프레드시트, 차트, 빽빽한 PDF, 이미지, 오디오, 동영상을 읽고, 에이전트처럼 동영상의 특정 프레임을 살펴볼 수 있습니다. Chartography 차트 이해 점수는 66.6%, MKA는 53.4%입니다.

  • 네 가지 사고 수준(thinking level)

    low, medium, high, xhigh로 지연 시간, 비용, 추론 깊이를 조절할 수 있습니다. 추론 벤치마크 HLE-Diamond에서 58.8%를 기록했습니다.

모든 파라미터는 네이티브 Gemini API 문서와 Chat Completions 문서를 참고하세요. 예제의 모델 이름을 gemini-4-hydrogen으로 바꾸면 됩니다.

컨텍스트 길이는 1,048,576 토큰(입력과 출력 합산)이고, 최대 출력은 기본 65,536 토큰, 긴 디코딩 사용 시 최대 1,048,576 토큰입니다. 입력은 텍스트, 이미지, 동영상, 오디오, PDF이며 출력은 텍스트입니다.

이 페이지는 입력 $0.5360, 출력 $2.6800, 캐시 히트 $0.0268로 표기하며, 위의 가격표와 같습니다.

gemini-4-argon과 비교: Google은 Argon을 더 강력한 효율형 추론 모델로 규정하므로, 복잡한 코딩, 수학, 과학 작업에는 Argon을 선택하세요.

사양은 제공사의 공식 문서(aistudio.google.com)를 기준으로 합니다. 이 페이지의 표는 가격이며, 실시간 요금은 모델 카탈로그가 기준입니다.

FAQ

Gemini 4 Hydrogen API FAQ

Gemini 4 Hydrogen API 가격은 얼마입니까?

AnyAIGC에서 gemini-4-hydrogen은 토큰 단위로 과금됩니다. 입력 100만 토큰당 $0.5360, 출력 100만 토큰당 $2.6800, 캐시 100만 토큰당 $0.0268입니다. Google 유료 티어 공식 정가는 입력 $1.50, 출력 $7.50, 캐시 $0.075이므로 AnyAIGC는 Google 공식 정가의 약 36%, 즉 64% 할인입니다. 출력에는 사고 토큰이 포함됩니다.

Gemini 4 Hydrogen의 모델 ID는 무엇이며 정식 출시되었습니까?

모델 ID는 gemini-4-hydrogen입니다. Google은 2026년 11월 12일에 출시했으며, 모델 페이지에는 프리뷰가 아닌 Stable로 표시되어 있습니다. 네이티브 엔드포인트는 URL에 모델 이름을 넣고(/v1beta/models/gemini-4-hydrogen:generateContent), OpenAI 호환 엔드포인트는 model 필드에 넣습니다.

컨텍스트 길이와 최대 출력은 얼마입니까?

Google은 입력, 사고, 출력이 함께 사용하는 1,048,576 토큰의 컨텍스트 길이를 명시합니다. 동기 요청은 기본적으로 최대 65,536 출력 토큰을 반환하며, 64K를 초과하는 출력(최대 약 1M 토큰)은 Google의 백그라운드 실행 기능이나 클라이언트 측 이어 쓰기로 처리합니다.

사고 수준(thinking level)은 어떻게 설정합니까?

Gemini 4 Hydrogen은 low, medium, high, xhigh의 네 가지 사고 수준(thinking level)을 지원하며 기본값은 high입니다. 기본값이 medium인 Argon, Carbon과 다릅니다. 네이티브 엔드포인트에서는 generationConfig.thinkingConfig.thinkingLevel을 설정하세요. Google은 대부분의 작업을 high로 시작하고, xhigh는 high로 풀리지 않는 다단계 문제에만 쓰기를 권장합니다. minimal을 보내면 오류가 반환되고, temperature, top_p, top_k는 무시됩니다.

네이티브 Gemini 엔드포인트와 OpenAI 호환 엔드포인트 중 무엇을 써야 합니까?

둘 다 사용할 수 있습니다. 네이티브 엔드포인트는 POST https://anyaigc.ai/v1beta/models/gemini-4-hydrogen:generateContent이며 Google Gemini API와 같은 요청 본문을 사용하므로 contents, systemInstruction, tools, thinkingConfig를 쓸 수 있습니다. OpenAI 호환 엔드포인트는 POST https://anyaigc.ai/v1/chat/completions이며, 공식 OpenAI SDK에서는 base_url을 https://anyaigc.ai/v1로 설정하세요. 둘 다 Authorization: Bearer를 사용합니다.

Gemini 4 Hydrogen과 Argon, Carbon, 3.8 Flash 중 무엇을 써야 합니까?

Google의 포지셔닝은 다음과 같습니다. Hydrogen은 일상적인 코딩, 인터랙티브 웹 앱, 도구 호출 에이전트, 멀티모달 문서 작업, 병렬 서브 에이전트 같은 빠른 실행을 담당합니다. Argon과 Carbon은 깊고 긴 호흡의 추론을 담당하며, 가장 오래 사고하는 모델은 Carbon입니다. Google은 Gemini 3.8 Flash에서 Hydrogen으로 업그레이드하고, Carbon이 계획을 세우는 동안 Hydrogen이 코드를 수정하고 테스트를 실행하도록 구성하기를 권장합니다. Google 공식 정가 기준으로 Hydrogen은 Argon, Carbon보다 저렴합니다. AnyAIGC에서는 Hydrogen이 입력 $0.5360, 출력 $2.6800, Argon이 입력 $0.1985, 출력 $0.9927, Carbon이 입력 $0.7147, 출력 $3.5740입니다. 세 모델은 키 하나를 공유하며, 모델 이름만 바꿔서 전환할 수 있습니다.

캐싱은 어떻게 과금됩니까?

Gemini 4 Hydrogen은 암시적 캐싱만 지원하며 명시적 캐싱(cachedContents)은 지원하지 않습니다. Google에 따르면 4,096 토큰 이상의 프롬프트는 자동으로 캐싱 대상이 되며, AnyAIGC에서 캐시 토큰은 100만 토큰당 $0.0268로 입력 가격의 5%입니다.

AnyAIGC는 gemini-4-hydrogen에 동시 실행 제한을 두지 않습니다. 모든 계정에 기본으로 적용되므로 배치 작업이나 여러 서브 에이전트를 병렬로 실행하는 데 적합합니다.
