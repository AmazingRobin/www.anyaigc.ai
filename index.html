07 / FAQ

常见问题

AnyAIGC 能开发票吗？支持增值税专票吗？

可以。增值税普通发票和增值税专用发票都能开，按实际充值金额开具。

企业可以对公转账和签合同吗？

可以。支持企业对公转账充值，也可以签订服务合同，并提供专属客服和技术对接。需要的话请联系企业客服。

新用户有免费试用额度吗？

有。新用户注册即送 200 万 tokens 试用额度，可以先小规模验证模型和接入方式。

余额可以退款吗？

未使用的余额可以退款，没有手续费。

会不会用低配模型冒充？我的数据安全吗？

使用官方模型渠道，不用低配或逆向模型冒充。除法律法规要求外，不对输入输出做持久化存储，也不用于训练，详见隐私政策。

支持哪些支付方式？

支持微信支付、支付宝、USDT 和信用卡，企业另有对公转账。

现有项目怎么接入？

多数使用 OpenAI SDK 的项目只需把 Base URL 换成 https://anyaigc.ai/v1，再换上在控制台创建的 API Key 和模型 ID。鉴权方式是 Authorization: Bearer <API Key>。模型 ID、价格与维护状态以控制台和模型广场实时展示为准。

支持哪些开发工具？

支持 Claude Code、Codex、OpenClaw、Hermes、Cursor、Dify、Cherry Studio、Chatbox、OpenWebUI 与 n8n，配置教程见API 文档。

准备开始第一次调用？

先查看控制台中的真实模型 ID 和价格，再创建 API Key 进行小规模验证。
