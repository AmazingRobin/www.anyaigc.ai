GPT-5.6 Luna API in drei Schritten aufrufen

  1. Registrieren und Guthaben aufladen: Erstellen Sie ein Konto unter anyaigc.ai. Ihr Guthaben gilt für alle Modelle der Plattform.
  2. API-Schlüssel erstellen: Erstellen Sie in der Konsole einen Token, kopieren Sie den Schlüssel mit dem Präfix sk- und speichern Sie ihn in der Umgebungsvariablen ANYAIGC_API_KEY.
  3. Anfrage senden: Rufen Sie https://anyaigc.ai/v1/chat/completions oder https://anyaigc.ai/v1/responses auf, setzen Sie model auf gpt-5.6-luna und authentifizieren Sie sich mit Authorization: Bearer.

Tool-Aufrufe funktionieren über beide Endpunkte. Laut OpenAI unterstützt gpt-5.6-luna Chat Completions, Responses und Batch, mit Funktionsaufrufen und strukturierter Ausgabe. Nutzen Sie /v1/chat/completions für normalen Chat und Funktionsaufrufe und /v1/responses für die integrierten Tools der Responses API oder mehrstufige Agent-Workflows, wobei der Aufwand in reasoning.effort steht.

Alle Parameter finden Sie in der Chat-Completions-Referenz und in der Responses-Referenz. Die Felder entsprechen der offiziellen OpenAI-API.

Häufige Fragen zur GPT-5.6 Luna API

Was kostet die GPT-5.6 Luna API?

Bei AnyAIGC wird gpt-5.6-luna pro Token abgerechnet: $0.0270 pro 1 Mio. Eingabe-Tokens, $0.1620 pro 1 Mio. Ausgabe-Tokens und $0.0027 pro 1 Mio. zwischengespeicherte Eingabe-Tokens. Der OpenAI-Listenpreis liegt bei $0.20 für die Eingabe, $1.20 für die Ausgabe und $0.02 für die zwischengespeicherte Eingabe, AnyAIGC kostet also rund 13.5 % des Listenpreises (86 % Rabatt). Hat eine Anfrage mehr als 272K Eingabe-Tokens, wird die gesamte Anfrage mit dem 2-Fachen für die Eingabe und dem 1.5-Fachen für die Ausgabe abgerechnet.

Wie lautet die Modell-ID von GPT-5.6 Luna?

Die Modell-ID ist gpt-5.6-luna. Tragen Sie sie in das Feld model Ihrer Anfrage ein. OpenAI hat dafür keinen datierten Snapshot veröffentlicht.

Wie stark wurde der Preis von GPT-5.6 Luna gesenkt?

Am 30. Juli 2026 hat OpenAI die API-Preise von GPT-5.6 Luna dauerhaft um 80 % gesenkt: Die Eingabe von $1 auf $0.20, die Ausgabe von $6 auf $1.20 und die zwischengespeicherte Eingabe von $0.10 auf $0.02 pro 1 Mio. Tokens. Die AnyAIGC-Preise basieren auf dem Listenpreis nach der Senkung: $0.0270 Eingabe, $0.1620 Ausgabe und $0.0027 zwischengespeicherte Eingabe.

Ist GPT-5.6 Luna veraltet? Wie lange bleibt es verfügbar?

Nein. OpenAI hat das neuere GPT-6 Luna veröffentlicht, aber GPT-5.6 Luna wird weiterhin in der API angeboten. OpenAI hat kein Abschaltdatum angekündigt, das Modell ist heute uneingeschränkt aufrufbar, und bei AnyAIGC ändert sich nichts. Erwägen Sie GPT-6 Luna für neue Projekte und bleiben Sie für Batch-Jobs, deren Prompts bereits darauf abgestimmt sind, bei gpt-5.6-luna.

Chat Completions oder Responses API? Kann ich Tools verwenden?

Beide Endpunkte funktionieren, und beide unterstützen Tool-Aufrufe. Laut OpenAI unterstützt gpt-5.6-luna Chat Completions, Responses und Batch, mit Streaming, Funktionsaufrufen und strukturierter Ausgabe. Nutzen Sie https://anyaigc.ai/v1/chat/completions für normalen Chat und Funktionsaufrufe und https://anyaigc.ai/v1/responses für die integrierten Tools der Responses API oder mehrstufige Agent-Workflows, wobei der Aufwand in reasoning.effort steht.

Kann ich GPT-5.6 Luna in Codex verwenden?

Ja. Führen Sie curl -fsSL https://www.anyaigc.ai/install.sh | bash -s codex aus, um es zu installieren und zu konfigurieren (unter Windows irm https://www.anyaigc.ai/install.ps1 | iex). Das Installationsskript verwendet standardmäßig gpt-5.5; ändern Sie danach model in ~/.codex/config.toml auf gpt-5.6-luna. Oder bearbeiten Sie ~/.codex/config.toml selbst: Setzen Sie base_url auf https://anyaigc.ai/v1, wire_api auf responses und model auf gpt-5.6-luna und tragen Sie dann OPENAI_API_KEY in ~/.codex/auth.json ein.

Gibt es Limits für Parallelität oder Ratenlimits?

AnyAIGC setzt für gpt-5.6-luna kein Limit für die Parallelität. Das gilt standardmäßig für jedes Konto, sodass große Klassifizierungs-, Extraktions- und parallele Agent-Jobs ohne Warteschlange laufen.

Wie erhalte ich einen API-Schlüssel für GPT-5.6 Luna?

Registrieren Sie sich bei anyaigc.ai, laden Sie Guthaben auf und erstellen Sie in der Konsole einen API-Schlüssel (Token). Derselbe Schlüssel funktioniert für GPT-5.6 Luna und 300+ weitere Modelle. Beim offiziellen OpenAI-SDK setzen Sie einfach base_url auf https://anyaigc.ai/v1.

Kann ich bei AnyAIGC eine Rechnung bekommen?

Ja. Sie können Rechnungen in der Konsole selbst ausstellen, und zwar über den tatsächlich aufgeladenen Betrag.

Welche Zahlungsmethoden werden unterstützt?

Sie können Guthaben per WeChat Pay, Alipay, USDT oder Kreditkarte aufladen. Ihr Guthaben ist in USD und gilt für alle Modelle der Plattform. Rechnungen über den aufgeladenen Betrag können Sie in der Konsole ausstellen.

Gibt es kostenloses Testguthaben für neue Nutzer?

Ja. Neue Konten erhalten Testguthaben von 2 Millionen Tokens, damit Sie testen können, bevor Sie sich fürs Aufladen entscheiden. Aufladungen beginnen bei $1.

Kann ich mein Guthaben erstatten lassen?

Ja. Nicht genutztes Guthaben kann gebührenfrei erstattet werden. Wenden Sie sich an den Support, um eine Erstattung zu veranlassen.

Sind das die echten Modelle? Sind meine Daten sicher?
