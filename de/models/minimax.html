Python
import json
import os
import urllib.request

payload = {
    "model": "MiniMax-M3.1-Flash",
    "messages": [
        {
            "role": "user",
            "content": "Design three clear API endpoints for a to-do application."
        }
    ]
}

request = urllib.request.Request(
    "https://anyaigc.ai/v1/chat/completions",
    data=json.dumps(payload, ensure_ascii=False).encode("utf-8"),
    headers={
        "Authorization": "Bearer " + os.environ["ANYAIGC_API_KEY"],
        "Content-Type": "application/json",
    },
    method="POST",
)
with urllib.request.urlopen(request, timeout=120) as response:
    result = json.load(response)

print(json.dumps(result, ensure_ascii=False, indent=2))

FAQ

Häufige Fragen zur MiniMax API

Preise, Endpunkte, Ergebnisse und Unternehmenszugang an einem Ort.

Ab welchem Preis gibt es die MiniMax-APIs?

Die Eingabe bei M3.1 Flash kostet $0.0603 pro 1 Mio. Tokens; Speech Turbo kostet $0.3176 und HD $0.5559 pro 10.000 Zeichen; die Ausgabe von H3 768P kostet $0.0750 pro Sekunde. Die Einheiten unterscheiden sich je nach Dienst. Die vollständige Tabelle steht auf dieser Seite, aktuelle Preise im Modellkatalog. M3.1 Flash spart 59 %; M3 und M2.5 sparen 32 % gegenüber dem Listenpreis. Die Ersparnis gilt für die hier gezeigten Preise; aktuelle Angebote stehen im Modellkatalog.

Wie wähle ich unter den 13 Modellen aus?

Wählen Sie M3.1 Flash, M3, M2.7 oder M2.5 für Chat und Entwicklung; MiniMax H3 oder Hailuo H3 (einschließlich des schnellen H3-Max) für Video; eine von sechs Speech-Versionen sowie die HD- und Turbo-Varianten für Sprecherstimmen; Voice Design für textgesteuerte Stimmen. Testen Sie zuerst mit Ihrer eigenen Workload und Stimme.

Nutzen diese Modelle denselben Endpunkt?

Sie teilen sich einen AnyAIGC-API-Schlüssel und eine Domain. Chat nutzt /v1/chat/completions, MiniMax H3 nutzt /minimax/v2/video_generation, Hailuo H3 nutzt /tencent-vod/v1/aigc-video, Sprache nutzt /minimax/v1/t2a_v2 oder /minimax/v1/t2a_async_v2, und Voice Design nutzt /minimax/v1/voice_design.

Wie erhalte ich Video-, Sprach- und Voice-Design-Ergebnisse?

Beim Erstellen eines H3-Videos wird zuerst eine task_id zurückgegeben, während die synchrone Sprachsynthese JSON mit Audiobezug liefert. Bei Voice Design sind die Ergebnisfelder in der Dokumentation uneinheitlich; speichern Sie die vollständige Antwort und prüfen Sie das tatsächliche Format. Jede Anleitung enthält eine minimale Anfrage.

Gibt es Limits für Parallelität oder RPM?

AnyAIGC bietet für MiniMax unbegrenzte Parallelität ohne festes RPM-Limit. Die Generierung braucht trotzdem Zeit; konfigurieren Sie Timeouts, Fehlerbehandlung und geeignete Wiederholungen in Ihrer Anwendung.

Dürfen generierte Inhalte kommerziell genutzt werden?

Die kommerzielle Nutzung der Modelle und ihrer Ausgaben richtet sich nach den offiziellen Bedingungen von MiniMax. Stellen Sie sicher, dass Sie die nötigen Rechte an Referenzmaterial, Stimmen und generierten Inhalten haben. AnyAIGC ist ein unabhängiger API-Anbieter.

Kann ich bei AnyAIGC eine Rechnung bekommen?

Ja. Sie können Rechnungen in der Konsole selbst ausstellen, und zwar über den tatsächlich aufgeladenen Betrag.

Welche Zahlungsmethoden werden unterstützt?

Sie können Guthaben per WeChat Pay, Alipay, USDT oder Kreditkarte aufladen. Ihr Guthaben ist in USD und gilt für alle Modelle der Plattform. Rechnungen über den aufgeladenen Betrag können Sie in der Konsole ausstellen.

Gibt es kostenloses Testguthaben für neue Nutzer?

Ja. Neue Konten erhalten Testguthaben von 2 Millionen Tokens, damit Sie testen können, bevor Sie sich fürs Aufladen entscheiden. Aufladungen beginnen bei $1.

Kann ich mein Guthaben erstatten lassen?

Ja. Nicht genutztes Guthaben kann gebührenfrei erstattet werden. Wenden Sie sich an den Support, um eine Erstattung zu veranlassen.

Sind das die echten Modelle? Sind meine Daten sicher?

Anfragen laufen über offizielle Modellkanäle, nie über günstigere oder per Reverse Engineering nachgebaute Ersatzmodelle. Sofern das Gesetz es nicht verlangt, speichern wir Ihre Prompts und Ausgaben nicht dauerhaft und verwenden sie nicht für Training, und die Konsole zeigt Tokens und Kosten jeder Anfrage.
