Schnellstart

Einstieg mit Chat Completions

  1. Legen Sie in der Konsole ein Konto und einen API-Schlüssel an.
  2. Setzen Sie die Base-URL auf https://anyaigc.ai/v1.
  3. Setzen Sie model und senden Sie messages.
cURL · POST /v1/chat/completions
curl https://anyaigc.ai/v1/chat/completions \
  -H "Authorization: Bearer $ANYAIGC_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"qwen3.5-35b-a3b","messages":[{"role":"user","content":"Explain what a MoE model is in three sentences."}]}'
Python · OpenAI SDK
from openai import OpenAI
import os
client = OpenAI(api_key=os.environ["ANYAIGC_API_KEY"], base_url="https://anyaigc.ai/v1")
response = client.chat.completions.create(model="qwen3.5-35b-a3b", messages=[{"role":"user","content":"Explain what a MoE model is in three sentences."}])
print(response.choices[0].message.content)

Qwen3.5

Spezifikationen und Auswahlhilfe

Ein Mixture-of-Experts-Modell: insgesamt 35 Milliarden Parameter, davon rund 3 Milliarden pro Token aktiv, und 262.144 Tokens Kontext.

Es bietet ein Kontextfenster von 262.144 Tokens und bis zu 65.536 Ausgabe-Tokens pro Antwort.

Diese Seite nennt $0.1688 pro 1 Mio. Eingabe-Tokens und $1.3500 pro 1 Mio. Ausgabe-Tokens, dieselben Werte wie in der Preistabelle oben.

Vergleichen Sie es mit qwen3.5-122b-a10b und wählen Sie stattdessen dieses Modell, wenn Sie das größere Mixture-of-Experts-Modell derselben Generation brauchen.

Diese Angaben stammen aus der offiziellen Qwen-Modelldokumentation. Die Preise stehen in der Tabelle auf dieser Seite, für aktuelle Preise ist der Modellkatalog maßgeblich.

FAQ

Häufige Fragen zur Qwen3.5 35B-A3B API

Welchen Endpunkt nutzt die Qwen3.5 35B-A3B API?

Dialogmodelle nutzen POST https://anyaigc.ai/v1/chat/completions. Senden Sie model und messages mit Authorization: Bearer <API Key>.

Was kostet die Qwen3.5 35B-A3B API?

Qwen3.5 35B-A3B wird pro Token abgerechnet: Eingabe $0.1688, Ausgabe $1.3500 pro 1 Mio. Tokens. Aktuelle Preise finden Sie im Modellkatalog.

Ist die Parallelität begrenzt?

Für die Qwen-Dialogmodelle auf dieser Seite gibt es keine Begrenzung der Parallelität, sie stehen allen Nutzern zur Verfügung.

Wie erhalte ich einen API-Schlüssel?

Erstellen Sie ein AnyAIGC-Konto und legen Sie dann in der Konsole einen API-Schlüssel an. Ein Schlüssel funktioniert für 300+ Modelle.

Werden Bilder und Tool-Aufrufe unterstützt?

Die Funktionen unterscheiden sich je nach Modell. Prüfen Sie die Tags im Live-Katalog. Der Endpunkt bleibt derselbe.

Kann ich bei AnyAIGC eine Rechnung bekommen?

Ja. Sie können Rechnungen in der Konsole selbst ausstellen, und zwar über den tatsächlich aufgeladenen Betrag.

Welche Zahlungsmethoden werden unterstützt?

Sie können Guthaben per WeChat Pay, Alipay, USDT oder Kreditkarte aufladen. Ihr Guthaben lautet auf USD und gilt für alle Modelle der Plattform. Rechnungen über den aufgeladenen Betrag können Sie in der Konsole ausstellen.

Gibt es kostenloses Testguthaben für neue Nutzer?

Ja. Neue Konten erhalten 2 Millionen Tokens Testguthaben.

Kann ich mein Guthaben erstatten lassen?

Ja. Nicht verbrauchtes Guthaben wird ohne Gebühr erstattet.

Sind das offizielle Modelle, und sind meine Daten sicher?

Anfragen laufen über offizielle Modellkanäle. Prompts und Ausgaben werden nicht dauerhaft gespeichert oder für Training verwendet, außer wenn gesetzlich vorgeschrieben.
