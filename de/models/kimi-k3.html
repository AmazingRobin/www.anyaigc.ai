Über das Modell

Ein Modell im Billionen-Maßstab mit offenen Gewichten für lange Aufgaben

Laut Moonshot AI ist Kimi K3 das erste Open-Source-Modell mit 2.8 Billionen Parametern. Es basiert auf Kimi Delta Attention (KDA), einer hybriden linearen Attention, und auf Attention Residuals. Beide Architekturänderungen sollen den Informationsfluss über längere Sequenzen und tiefere Netze erhalten.

Im Framework Stable LatentMoE aktiviert K3 pro Token 16 von 896 Experten. Zusammen mit verbesserten Trainingsmethoden und Datenrezepten erreicht K3 laut Moonshot etwa die 2.5-fache Gesamt-Skalierungseffizienz von K2. Es hat native Vision und ein Kontextfenster von 1.048.576 Tokens, und der Denkmodus (thinking) ist immer aktiv.

Bei AnyAIGC läuft kimi-k3 über den OpenAI-kompatiblen Endpunkt /v1/chat/completions und funktioniert direkt in Claude Code. Sie brauchen kein Moonshot-Plattformkonto, es gibt keine Aufladestufen, und die Parallelität ist unbegrenzt.

Schnellstart

Kimi K3 API in drei Schritten anbinden

  1. Registrieren und Guthaben aufladen: Erstellen Sie ein Konto unter anyaigc.ai. Aufladen ab $1; Ihr Guthaben gilt für alle Modelle der Plattform.
  2. API-Schlüssel erstellen: Erstellen Sie in der Konsole einen Schlüssel, kopieren Sie den Wert, der mit sk- beginnt, und speichern Sie ihn in der Umgebungsvariable ANYAIGC_API_KEY.
  3. Anfrage senden: Rufen Sie POST https://anyaigc.ai/v1/chat/completions auf, mit model auf kimi-k3 und einem Authorization: Bearer-Header. Mit dem OpenAI-SDK setzen Sie einfach base_url auf https://anyaigc.ai/v1.

Tipp: K3 denkt immer, und das Reasoning kommt in reasoning_content zurück. Moonshot empfiehlt temperature=1.0 und top_p=0.95. Senden Sie bei mehrstufigen Chats und Tool-Aufrufen die vollständige Assistant-Nachricht der API (einschließlich reasoning_content und tool_calls) in der nächsten Anfrage unverändert zurück, nicht nur den Inhalt.

Alle Parameter finden Sie in der Chat-Completions-Referenz. Ersetzen Sie den Modellnamen in den Beispielen der Dokumentation durch die gewünschte Kimi-Modell-ID.

Claude Code

Kimi K3 in Claude Code nutzen

Stellen Sie Claude Code auf Kimi K3 um. Das Kontextfenster von 1M eignet sich für lange Coding-Sitzungen in großen Repos.

  1. Claude Code installieren: Verwenden Sie das offizielle Installationsprogramm (zum Beispiel npm install -g @anthropic-ai/claude-code).
  2. Konfiguration hinzufügen: Bearbeiten Sie ~/.claude/settings.json, fügen Sie den folgenden env-Block ein und ersetzen Sie ANTHROPIC_AUTH_TOKEN durch den Schlüssel, den Sie bei AnyAIGC erstellt haben.
  3. Loslegen: Führen Sie claude in Ihrem Projektordner aus. Geben Sie /model ein, um zu prüfen, dass das aktuelle Modell kimi-k3 ist.

Bei Nebenaufgaben sparen: Setzen Sie ANTHROPIC_DEFAULT_HAIKU_MODEL auf kimi-k2.7-code, damit die leichtgewichtigen Teilaufgaben von Claude Code das günstigere Modell nutzen, während die Hauptaufgabe auf K3 bleibt.

Die vollständige Anleitung und häufige Fehler finden Sie in der Einrichtungsanleitung für Claude Code. Ersetzen Sie den Modellnamen in der Anleitung durch kimi-k3.

FAQ

Häufige Fragen zur Kimi K3 API

Was kostet die Kimi K3 API?

Bei AnyAIGC wird kimi-k3 pro Token abgerechnet: Eingabe $1.2150 pro 1 Mio. Tokens, Ausgabe $6.0750 pro 1 Mio. Tokens, Cache-Treffer $0.1215 pro 1 Mio. Tokens. Die offiziellen USD-Preise von Moonshot sind Eingabe $3.00, Ausgabe $15.00 und Cache-Treffer $0.30, AnyAIGC liegt also bei rund 40 % des offiziellen Preises. Die Ausgabe umfasst Denk-Tokens. Live-Preise finden Sie im Modellkatalog.

Wie lautet die Modell-ID von Kimi K3, und wie groß ist das Kontextfenster?

Die Modell-ID ist kimi-k3. Moonshot nennt ein Kontextfenster von 1.048.576 Tokens (1M). max_completion_tokens ist standardmäßig 131.072 und lässt sich bis auf 1.048.576 setzen.

Was zeichnet Kimi K3 aus?

Laut Moonshot ist Kimi K3 das erste Open-Source-Modell mit 2.8 Billionen Parametern. Es basiert auf Kimi Delta Attention (KDA), einer hybriden linearen Attention, und auf Attention Residuals. Sein MoE aktiviert pro Token 16 von 896 Experten, dazu kommt native Vision. Moonshot nennt etwa die 2.5-fache Gesamt-Skalierungseffizienz von K2, ausgelegt auf lange Coding-Aufgaben, Wissensarbeit und Reasoning.

Wie stelle ich die Denktiefe von Kimi K3 ein?

K3 denkt immer, und der Denkmodus (thinking) lässt sich nicht abschalten. Mit dem Feld reasoning_effort auf oberster Ebene im Body der Anfrage legen Sie die Tiefe fest: low, high oder max (Standard ist max). Nutzen Sie low bei einfachen Aufgaben, um Ausgabe-Tokens zu sparen.

Unterstützt Kimi K3 Tool-Aufrufe und Bildeingabe?

Ja. K3 unterstützt Funktionsaufrufe (tools / tool_choice), strukturierte Ausgabe (json_schema), Streaming und Bildeingabe. Senden Sie bei mehrstufigen Chats und Tool-Aufrufen die vollständige Assistant-Nachricht (einschließlich reasoning_content und tool_calls) in der nächsten Anfrage unverändert zurück.

Kann ich Kimi K3 in Claude Code nutzen?

Ja. Setzen Sie im env-Block von ~/.claude/settings.json ANTHROPIC_BASE_URL auf https://anyaigc.ai, ANTHROPIC_AUTH_TOKEN auf Ihren API-Schlüssel und ANTHROPIC_MODEL auf kimi-k3. Führen Sie danach claude aus.

Worin unterscheidet sich Kimi K3 von K3.1 Pro?

Kimi K3.1 Pro ist das erste Modell der K3.1-Serie. Laut Moonshot ist es K3 mit deutlich mehr Rechenaufwand im Post-Training, mit klaren Verbesserungen bei Coding, 3D-Erstellung, Finanzrecherche und langlaufenden Agenten. Es behält dieselben Parameterbeschränkungen wie K3, für die Migration genügt also ein anderer Modellname. Bei AnyAIGC kostet K3.1 Pro $0.8100 für die Eingabe und $4.0500 für die Ausgabe, rund ein Drittel weniger als K3. Für neue Projekte beginnen Sie mit K3.1 Pro.

Kimi K3 oder K2.7 Code: Welches soll ich nutzen?

K3 ist das Flaggschiff der vorherigen Generation mit 2.8T Parametern und einem Kontextfenster von 1M, geeignet für große Repos, lange Aufgaben und die schwierigsten Reasoning-Probleme. K2.7 Code ist ein Coding-Modell mit 1T Parametern und einem Kontextfenster von 256K, bei AnyAIGC für $0.3847 Eingabe und $1.5980 Ausgabe, rund ein Drittel von K3. Viele Teams nutzen im Alltag K2.7 Code und wechseln für schwierige Probleme mit demselben Schlüssel zu K3.

Gibt es Limits für Parallelität oder Ratenlimits?

AnyAIGC begrenzt die Parallelität für kimi-k3 nicht, und jeder Nutzer erhält das standardmäßig. Das passt zu Batch-Jobs, CI-Pipelines und parallelen Agenten. Die Plattform von Moonshot begrenzt Parallelität, RPM, TPM und TPD nach Aufladestufe; diese Stufen gelten nicht, wenn Sie über AnyAIGC aufrufen.

Wie bekomme ich einen API-Schlüssel für Kimi K3?

Registrieren Sie sich bei anyaigc.ai, laden Sie Guthaben auf und erstellen Sie in der Konsole einen Schlüssel. Derselbe Schlüssel funktioniert für alle Kimi-Modelle und 300+ weitere Modelle der Plattform, ein separates Konto auf der Moonshot-Plattform brauchen Sie also nicht.

Ja. Sie können Rechnungen in der Konsole selbst ausstellen, und zwar über den tatsächlich aufgeladenen Betrag.

Welche Zahlungsmethoden werden unterstützt?

Sie können Guthaben per WeChat Pay, Alipay, USDT oder Kreditkarte aufladen. Ihr Guthaben ist in USD und gilt für alle Modelle der Plattform. Rechnungen über den aufgeladenen Betrag können Sie in der Konsole ausstellen.

Gibt es kostenloses Testguthaben für neue Nutzer?

Ja. Neue Konten erhalten Testguthaben von 2 Millionen Tokens, damit Sie testen können, bevor Sie sich fürs Aufladen entscheiden. Aufladungen beginnen bei $1.

Kann ich mein Guthaben erstatten lassen?

Sind das die echten Modelle? Sind meine Daten sicher?

Werden meine Daten zum Training verwendet?

Nein. Außer wo es gesetzlich vorgeschrieben ist, speichert AnyAIGC Ihre Prompts oder Ausgaben nicht dauerhaft und nutzt sie nicht zum Training von Modellen. Anfragen werden per HTTPS verschlüsselt.
