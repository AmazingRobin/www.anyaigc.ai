Über das Modell

K2.6, für Coding weitertrainiert

Moonshot AI bezeichnet Kimi K2.7 Code als sein bisher stärkstes Coding-Modell. Es ist aus K2.6 weitertrainiert, befolgt Anweisungen über langen Kontext zuverlässiger, löst mehr Coding-Aufgaben und nutzt rund 30 % weniger Denk-Tokens als K2.6.

Die Architektur entspricht K2.6: MoE mit insgesamt 1T und 32B aktiven Parametern, 8 von 384 Experten pro Token, 256K Kontext sowie Text- und Bildeingabe. K2.7 Code denkt immer und unterstützt Interleaved Thinking mit mehrstufigen Tool-Aufrufen, was zu Coding-Agenten passt.

Bei AnyAIGC läuft kimi-k2.7-code am OpenAI-kompatiblen Endpunkt /v1/chat/completions und funktioniert direkt in Claude Code, mit unbegrenzter Parallelität.

Schnellstart

Kimi K2.7 Code API in drei Schritten anbinden

  1. Registrieren und Guthaben aufladen: Erstellen Sie ein Konto unter anyaigc.ai. Aufladen ab $1; Ihr Guthaben gilt für alle Modelle der Plattform.
  2. API-Schlüssel erstellen: Erstellen Sie in der Konsole einen Schlüssel, kopieren Sie den Wert, der mit sk- beginnt, und speichern Sie ihn in der Umgebungsvariable ANYAIGC_API_KEY.
  3. Anfrage senden: Rufen Sie POST https://anyaigc.ai/v1/chat/completions auf, setzen Sie model auf kimi-k2.7-code und senden Sie einen Authorization: Bearer-Header. Mit dem OpenAI-SDK setzen Sie einfach base_url auf https://anyaigc.ai/v1.

Tipp: K2.7 Code denkt immer, und das Reasoning kommt in reasoning_content zurück. Moonshot empfiehlt temperature=1.0 und top_p=0.95. Senden Sie in Multi-Turn-Chats und bei Tool-Aufrufen die vollständige Assistant-Nachricht der API (einschließlich reasoning_content und tool_calls) in der nächsten Anfrage unverändert zurück.

Alle Parameter finden Sie in der Chat-Completions-Referenz. Ersetzen Sie den Modellnamen in den Beispielen der Dokumentation durch die gewünschte Kimi-Modell-ID.

Claude Code

Kimi K2.7 Code in Claude Code nutzen

Stellen Sie Claude Code auf Kimi K2.7 Code um. Es ist auf Coding trainiert und kostet etwa halb so viel wie K3.1 Pro.

  1. Claude Code installieren: Verwenden Sie das offizielle Installationsprogramm (zum Beispiel npm install -g @anthropic-ai/claude-code).
  2. Konfiguration hinzufügen: Bearbeiten Sie ~/.claude/settings.json, fügen Sie den folgenden env-Block ein und ersetzen Sie ANTHROPIC_AUTH_TOKEN durch den Schlüssel, den Sie bei AnyAIGC erstellt haben.
  3. Loslegen: Führen Sie claude in Ihrem Projektordner aus. Geben Sie /model ein, um zu prüfen, dass das aktuelle Modell kimi-k2.7-code ist.

Für große Repos: K2.7 Code hat ein Kontextfenster von 256K. Ist ein Projekt zu groß, um es auf einmal zu lesen, stellen Sie das Modell in der Konfiguration auf kimi-k3.1-pro um (Kontextfenster 1M).

Die vollständige Anleitung und häufige Fehler finden Sie in der Einrichtungsanleitung für Claude Code. Ersetzen Sie den Modellnamen in der Anleitung durch kimi-k2.7-code.

FAQ

Häufige Fragen zur Kimi K2.7 Code API

Was kostet die Kimi K2.7 Code API?

Bei AnyAIGC wird kimi-k2.7-code pro Token abgerechnet: Eingabe $0.3847 pro 1 Mio. Tokens, Ausgabe $1.5980 pro 1 Mio. Tokens, Cache-Treffer $0.0770 pro 1 Mio. Tokens. Die offiziellen USD-Preise von Moonshot liegen bei $0.95 für die Eingabe, $4.00 für die Ausgabe und $0.19 für Cache-Treffer, AnyAIGC kostet also rund 40 % des offiziellen Preises. Die Ausgabe enthält Denk-Tokens. Aktuelle Preise finden Sie im Modellkatalog.

Wie lautet die Modell-ID von Kimi K2.7 Code, und wie groß ist der Kontext?

Die Modell-ID lautet kimi-k2.7-code. Moonshot berichtet ein Kontextfenster von 262.144 Tokens (256K) an, mit Text- und Bildeingabe.

Worin unterscheidet sich Kimi K2.7 Code von K2.6?

K2.7 Code ist ein auf Coding ausgerichtetes Weitertraining von K2.6 auf derselben Architektur (1T Parameter insgesamt, 32B aktiv). Laut Moonshot befolgt es Anweisungen über langen Kontext zuverlässiger, schließt mehr Coding-Aufgaben ab und nutzt rund 30 % weniger Denk-Tokens als K2.6; Kimi Code Bench v2 steigt von 50.9 auf 62.0. K2.7 Code läuft nur im Denkmodus (thinking), während K2.6 den Denkmodus abschalten kann. Beide haben bei AnyAIGC dieselben Eingabe- und Ausgabepreise.

Kann ich den Denkmodus in Kimi K2.7 Code abschalten?

Nein. Laut Moonshot läuft K2.7 Code immer mit aktiviertem Denkmodus und Preserve Thinking und unterstützt keinen Nicht-Denkmodus. Für schnelle Antworten ohne Denkmodus nutzen Sie kimi-k2.6. Moonshot empfiehlt temperature=1.0 und top_p=0.95.

Unterstützt Kimi K2.7 Code Tool-Aufrufe?

Ja. K2.7 Code unterstützt Interleaved Thinking und mehrstufige Tool-Aufrufe, was zu Coding-Agenten passt. Senden Sie in Multi-Turn-Chats und bei Tool-Aufrufen die vollständige Assistant-Nachricht (einschließlich reasoning_content und tool_calls) in der nächsten Anfrage unverändert zurück.

Kann ich Kimi K2.7 Code in Claude Code nutzen?

Ja. Setzen Sie im env-Block von ~/.claude/settings.json ANTHROPIC_BASE_URL auf https://anyaigc.ai, ANTHROPIC_AUTH_TOKEN auf Ihren API-Schlüssel und ANTHROPIC_MODEL auf kimi-k2.7-code. Führen Sie danach claude aus.

Kimi K2.7 Code oder Kimi K3.1 Pro: Welches Modell sollte ich nutzen?

K2.7 Code ist ein Coding-Modell mit 1T Parametern und 256K Kontext zu $0.3847 Eingabe und $1.5980 Ausgabe bei AnyAIGC, geeignet für alltägliches Coding und Agent-Aufrufe mit hohem Volumen. Kimi K3.1 Pro ist das neueste Modell der 3T-Klasse mit 1M Kontext zu $0.8100 Eingabe und $4.0500 Ausgabe, geeignet für große Repos und die schwierigsten Aufgaben. Beide verwenden denselben Schlüssel.

Gibt es Limits für Parallelität oder Ratenlimits?

AnyAIGC begrenzt die Parallelität für kimi-k2.7-code nicht, und jeder Nutzer hat das standardmäßig. Das eignet sich für Batch-Jobs, CI-Pipelines und parallele Agenten. Die Plattform von Moonshot begrenzt Parallelität, RPM, TPM und TPD nach Aufladestufe; diese Stufen gelten nicht, wenn Sie über AnyAIGC aufrufen.

Wie erhalte ich einen API-Schlüssel für Kimi K2.7 Code?

Registrieren Sie sich bei anyaigc.ai, laden Sie Guthaben auf und erstellen Sie in der Konsole einen Schlüssel. Derselbe Schlüssel funktioniert für alle Kimi-Modelle und 300+ weitere Modelle der Plattform, ein separates Konto auf der Moonshot-Plattform brauchen Sie also nicht.

Kann ich bei AnyAIGC eine Rechnung bekommen?

Ja. Sie können Rechnungen in der Konsole selbst ausstellen, und zwar über den tatsächlich aufgeladenen Betrag.

Welche Zahlungsmethoden werden unterstützt?

Sie können Guthaben per WeChat Pay, Alipay, USDT oder Kreditkarte aufladen. Ihr Guthaben ist in USD und gilt für alle Modelle der Plattform. Rechnungen über den aufgeladenen Betrag können Sie in der Konsole ausstellen.

Gibt es kostenloses Testguthaben für neue Nutzer?

Ja. Neue Konten erhalten Testguthaben von 2 Millionen Tokens, damit Sie testen können, bevor Sie sich fürs Aufladen entscheiden. Aufladungen beginnen bei $1.

Kann ich mein Guthaben erstatten lassen?

Ja. Nicht genutztes Guthaben kann gebührenfrei erstattet werden. Wenden Sie sich an den Support, um eine Erstattung zu veranlassen.

Sind das die echten Modelle? Sind meine Daten sicher?

Anfragen laufen über offizielle Modellkanäle, nie über günstigere oder per Reverse Engineering nachgebaute Ersatzmodelle. Sofern das Gesetz es nicht verlangt, speichern wir Ihre Prompts und Ausgaben nicht dauerhaft und verwenden sie nicht für Training, und die Konsole zeigt Tokens und Kosten jeder Anfrage.

Werden meine Daten zum Training verwendet?

Nein. Außer wo es gesetzlich vorgeschrieben ist, speichert AnyAIGC Ihre Prompts oder Ausgaben nicht dauerhaft und nutzt sie nicht zum Training von Modellen. Anfragen werden per HTTPS verschlüsselt. Siehe die Datenschutzerklärung von AnyAIGC. Die Datenrichtlinie des Modells selbst richtet sich nach den offiziellen Bedingungen von Moonshot AI.
