Die Claude Fable 5.1 API in drei Schritten aufrufen

  1. Registrieren und Guthaben aufladen: Erstellen Sie ein Konto unter anyaigc.ai. Ihr Guthaben gilt für alle Modelle der Plattform.
  2. API-Schlüssel erstellen: Erstellen Sie in der Konsole einen API-Schlüssel und kopieren Sie den Schlüssel, der mit sk- beginnt.
  3. Anfrage senden: Senden Sie eine Anthropic-Messages-Anfrage per POST an https://anyaigc.ai/v1/messages und authentifizieren Sie sich mit Authorization: Bearer.

Fable 5.1 nutzt standardmäßig adaptives Denken, planen Sie bei langen Aufgaben daher großzügige Werte für max_tokens und das Anfrage-Timeout ein. Laut der Dokumentation von Anthropic wird erzwungene Tool-Nutzung nicht unterstützt (wer mit tool_choice ein Tool erzwingt, erhält einen Fehler). Weitere Parameter (Tools, Thinking, Streaming, PDF- und Bildeingabe und mehr) finden Sie in der Dokumentation zur AnyAIGC-Messages-API. Die Felder verhalten sich wie in der offiziellen Dokumentation von Anthropic.

FAQ zur Claude Fable 5.1 API

Was kostet die Claude Fable 5.1 API?

Bei AnyAIGC wird claude-fable-5-1 pro Token abgerechnet: $2.382 pro 1 Mio. Eingabe-Tokens, $11.912 pro 1 Mio. Ausgabe-Tokens, $2.9779 für Cache-Schreibvorgänge mit 5 Minuten, $4.7647 für Cache-Schreibvorgänge mit 1 Stunde und $0.0596 für Cache-Treffer. Der Listenpreis von Anthropic beträgt $10 für Eingabe, $50 für Ausgabe und $0.25 für Cache-Lesezugriffe. AnyAIGC liegt damit bei rund 23.8 % des Listenpreises, also 76 % darunter.

Wie lautet die Modell-ID von Claude Fable 5.1?

Die Modell-ID lautet claude-fable-5-1. Tragen Sie sie im Feld model Ihres Anfragetexts ein.

Ist die AnyAIGC-Claude-API mit der offiziellen API von Anthropic kompatibel?

Ja. Der Endpunkt ist https://anyaigc.ai/v1/messages, und der Anfragetext folgt dem Anthropic-Messages-Format (model, max_tokens, system, messages, tools, cache_control und so weiter). Authentifizieren Sie sich mit Authorization: Bearer gefolgt von Ihrem API-Schlüssel. Beim offiziellen SDK setzen Sie einfach die Base-URL auf https://anyaigc.ai. Eine Besonderheit: Laut der Dokumentation von Anthropic unterstützt Fable 5.1 keine erzwungene Tool-Nutzung, daher führt das Erzwingen eines bestimmten Tools mit tool_choice zu einem Fehler.

Kann ich Claude Fable 5.1 in Claude Code verwenden?

Ja. Setzen Sie im env-Block von ~/.claude/settings.json ANTHROPIC_BASE_URL auf https://anyaigc.ai, ANTHROPIC_AUTH_TOKEN auf Ihren API-Schlüssel und sowohl ANTHROPIC_MODEL als auch ANTHROPIC_DEFAULT_OPUS_MODEL auf claude-fable-5-1, und führen Sie dann claude aus. Sie können auch alles mit einem Befehl installieren und konfigurieren: curl -fsSL https://www.anyaigc.ai/install.sh | bash.

Wie wird Prompt-Caching abgerechnet?

Fügen Sie einem Inhaltsblock cache_control hinzu, um das Caching zu aktivieren. Das erste Schreiben wird zum Preis für Cache-Schreibvorgänge abgerechnet ($2.9779 für 5 Minuten oder $4.7647 für 1 Stunde, jeweils pro 1 Mio. Tokens). Danach kosten gecachte Tokens nur noch $0.0596 pro 1 Mio., rund 2.5 % des regulären Eingabepreises. Anthropic hat den Preis für Cache-Lesezugriffe bei Fable 5.1 auf ein Viertel des Preises von Fable 5 gesenkt, davon profitieren langlaufende Agenten, die denselben Kontext immer wieder lesen, am meisten.

Gibt es Limits für Parallelität oder Ratenlimits?

AnyAIGC setzt für claude-fable-5-1 kein Limit für die Parallelität. Jedes Konto erhält dies standardmäßig, das Modell eignet sich daher gut für Batch-Jobs und für mehrere parallel laufende Agenten.

Wofür ist Claude Fable 5.1 gut, und sollte ich es Opus 5.5 vorziehen?

Anthropic beschreibt Fable 5.1 als Modell auf Mythos-Niveau, gebaut für Ihre anspruchsvollsten, langlaufenden Projekte, mit besserem langlaufendem agentischem Coding, besserer mehrstufiger Recherche und besserer Arbeit mit Dokumenten, Tabellen und Folien. Die Dokumentation von Anthropic empfiehlt, für die meisten Workloads mit Claude Opus 5.5 zu beginnen und Fable 5.1 für die schwierigsten einzusetzen. Beide funktionieren mit demselben AnyAIGC-Schlüssel, Sie können also je Aufgabe wechseln, indem Sie das Feld model ändern.

Wie erhalte ich einen API-Schlüssel für Claude Fable 5.1?

Registrieren Sie sich unter anyaigc.ai, laden Sie Guthaben auf und erstellen Sie in der Konsole einen API-Schlüssel. Derselbe Schlüssel funktioniert für Claude Fable 5.1 und über 300 weitere Modelle der Plattform.

Kann ich bei AnyAIGC eine Rechnung bekommen?

Ja. Sie können Rechnungen in der Konsole selbst ausstellen, und zwar über den tatsächlich aufgeladenen Betrag.

Welche Zahlungsmethoden werden unterstützt?

Sie können Guthaben per WeChat Pay, Alipay, USDT oder Kreditkarte aufladen. Ihr Guthaben ist in USD und gilt für alle Modelle der Plattform. Rechnungen über den aufgeladenen Betrag können Sie in der Konsole ausstellen.

Gibt es kostenloses Testguthaben für neue Nutzer?

Ja. Neue Konten erhalten Testguthaben von 2 Millionen Tokens, damit Sie testen können, bevor Sie sich fürs Aufladen entscheiden. Aufladungen beginnen bei $1.

Kann ich mein Guthaben erstatten lassen?

Ja. Nicht genutztes Guthaben kann gebührenfrei erstattet werden. Wenden Sie sich an den Support, um eine Erstattung zu veranlassen.

Sind das die echten Modelle? Sind meine Daten sicher?

Anfragen laufen über offizielle Modellkanäle, nie über günstigere oder per Reverse Engineering nachgebaute Ersatzmodelle. Sofern das Gesetz es nicht verlangt, speichern wir Ihre Prompts und Ausgaben nicht dauerhaft und verwenden sie nicht für Training, und die Konsole zeigt Tokens und Kosten jeder Anfrage.

Werden meine Daten für Training verwendet?

Anfragen werden per HTTPS verschlüsselt übertragen. Einzelheiten zur Datenverarbeitung finden Sie in der Datenschutzerklärung von AnyAIGC. Die Datenrichtlinie des Modells selbst richtet sich nach den offiziellen Bedingungen von Anthropic. Anthropic weist darauf hin, dass die Nutzung von Fable standardmäßig eine 30-tägige Datenaufbewahrung zur Sicherheitsüberwachung erfordert.
