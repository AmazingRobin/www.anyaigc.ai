Über das Modell

Ein Flaggschiff mit 1M Kontext für langlaufende Aufgaben

Zhipu positioniert GLM-5.2 als Flaggschiff für die Ära langlaufender Aufgaben. Laut Zhipu ist das 1M-Kontextfenster in der Praxis nutzbar und reicht für den Engineering-Kontext ganzer Projekte; außerdem führe das Modell lange Aufgaben zuverlässiger aus und halte Engineering-Konventionen konsequenter ein.

Das Kontextfenster wuchs von 200K bei GLM-5.1 auf 1M. Die Architektur bleibt MoE mit DSA-Sparse-Attention und ergänzt IndexShare: Je 4 Sparse-Attention-Layer teilen sich einen Indexer. Laut Zhipu senkt das den Rechenaufwand pro Token bei 1M Kontext um den Faktor 2.9. GLM-5.2 nutzt standardmäßig dynamisches Denken, der Denkmodus lässt sich abschalten, und das Modell ist unter der MIT-Lizenz Open Source.

Bei AnyAIGC läuft glm-5.2 über den OpenAI-kompatiblen Endpunkt /v1/chat/completions und funktioniert direkt in Claude Code, mit unbegrenzter Parallelität. Für neue Projekte lohnt sich GLM-5.3 zum gleichen Preis; es baut auf demselben Basismodell auf und ist beim Coding stärker.

Schnellstart

In drei Schritten zur GLM-5.2 API

  1. Registrieren und Guthaben aufladen: Erstellen Sie ein Konto unter anyaigc.ai. Aufladen ab $1; Ihr Guthaben gilt für alle Modelle der Plattform.
  2. API-Schlüssel erstellen: Erstellen Sie in der Konsole einen Schlüssel, kopieren Sie den Wert, der mit sk- beginnt, und speichern Sie ihn in der Umgebungsvariable ANYAIGC_API_KEY.
  3. Anfrage senden: Rufen Sie POST https://anyaigc.ai/v1/chat/completions auf, setzen Sie model auf glm-5.2 und senden Sie den Header Authorization: Bearer. Beim OpenAI-SDK genügt es, base_url auf https://anyaigc.ai/v1 zu setzen.

Tipp: GLM-5.2 nutzt standardmäßig dynamisches Denken. Falls es nachdenkt, kommt das Reasoning im Feld reasoning_content zurück, und reasoning_effort steuert die Tiefe. Senden Sie bei mehrstufigen Chats und Tool-Aufrufen die vollständige Assistant-Nachricht der API (einschließlich reasoning_content und tool_calls) in der nächsten Anfrage unverändert zurück.

Alle Parameter finden Sie in der Chat-Completions-Referenz. Ersetzen Sie in den Beispielen der Dokumentation den Modellnamen durch die gewünschte GLM-Modell-ID.

Claude Code

GLM-5.2 in Claude Code nutzen

Stellen Sie Claude Code auf GLM-5.2 um: Der 1M-Kontext eignet sich für lange Coding-Sessions in großen Repos.

  1. Claude Code installieren: Verwenden Sie das offizielle Installationsprogramm, unter macOS oder Linux zum Beispiel curl -fsSL https://claude.ai/install.sh | bash.
  2. Konfiguration hinzufügen: Bearbeiten Sie ~/.claude/settings.json, fügen Sie den folgenden env-Block ein und ersetzen Sie ANTHROPIC_AUTH_TOKEN durch den Schlüssel, den Sie bei AnyAIGC erstellt haben.
  3. Loslegen: Starten Sie claude in Ihrem Projektordner. Geben Sie /model ein, um zu prüfen, ob das aktuelle Modell glm-5.2 ist.

Upgrade-Tipp: Für eine höhere Erfolgsquote beim Coding ersetzen Sie in der Konfiguration jedes glm-5.2 durch glm-5.3. Beide kosten gleich viel.

Die vollständige Anleitung und häufige Fehler finden Sie in der Einrichtungsanleitung für Claude Code. Ersetzen Sie den Modellnamen in der Anleitung durch glm-5.2.

FAQ

GLM-5.2 API: Häufige Fragen

Was kostet die GLM-5.2 API?

Bei AnyAIGC wird glm-5.2 pro Token abgerechnet: Eingabe $0.9450 pro 1 Mio. Tokens, Ausgabe $2.9700 pro 1 Mio. Tokens, Cache-Treffer $0.2362 pro 1 Mio. Tokens. Die offiziellen USD-Preise von Zhipu betragen $1.40 für die Eingabe, $4.40 für die Ausgabe und $0.26 für Cache-Treffer. Eingabe und Ausgabe kosten bei AnyAIGC also rund 67.5 % des offiziellen Preises (rund 30 % Rabatt). Aktuelle Preise finden Sie im Modellkatalog.

Wie lautet die Modell-ID von GLM-5.2, und wie groß ist der Kontext?

Die Modell-ID lautet glm-5.2. Zhipu nennt ein Kontextfenster von 1M Tokens und bis zu 128K Ausgabe-Tokens. Das Modell akzeptiert nur Text als Eingabe.

Kann ich den Denkmodus bei GLM-5.2 abschalten?

Ja. Laut Zhipu nutzt GLM-5.2 standardmäßig dynamisches Denken: Das Modell entscheidet selbst, ob es nachdenkt, und der Denkmodus (thinking) lässt sich auch ganz abschalten. Das ist einer der wichtigsten Unterschiede zu GLM-5.3, das immer nachdenkt. Bei AnyAIGC steuern Sie die Denktiefe mit reasoning_effort.

Was zeichnet GLM-5.2 aus?

Zhipu positioniert GLM-5.2 als Flaggschiff für die Ära langlaufender Aufgaben. Das 1M-Kontextfenster ist in der Praxis nutzbar und reicht für Engineering-Kontext im Projektmaßstab. Das Modell führt lange Aufgaben zuverlässiger aus, hält Engineering-Konventionen konsistenter ein und kann eine Aufgabe von den Anforderungen bis zum Multi-Plattform-Deployment begleiten. Laut Zhipu senkt das IndexShare-Design den Rechenaufwand pro Token bei 1M Kontext um den Faktor 2.9.

GLM-5.2 oder GLM-5.3: Welches sollte ich nutzen?

Beide teilen dasselbe Basismodell und kosten bei AnyAIGC für Eingabe und Ausgabe gleich viel. GLM-5.3 ergänzt ein hochskaliertes Post-Training; Zhipu berichtet 50 % bessere Coding-Leistung, und der Preis für Cache-Treffer ist niedriger ($0.1758 statt $0.2362). Neue Projekte sollten mit GLM-5.3 starten. Bleiben Sie bei GLM-5.2, wenn Sie den Denkmodus abschalten müssen oder es bereits produktiv abgestimmt haben.

Kann ich GLM-5.2 in Claude Code verwenden?

Ja. Setzen Sie im env-Block von ~/.claude/settings.json den Wert ANTHROPIC_BASE_URL auf https://anyaigc.ai, ANTHROPIC_AUTH_TOKEN auf Ihren API-Schlüssel und ANTHROPIC_MODEL auf glm-5.2. Starten Sie danach claude. Sie zahlen pro Token, ohne 5-Stunden-Kontingentfenster wie bei einem Abo-Tarif.

Ist GLM-5.2 Open Source? Darf ich es kommerziell nutzen?

Ja. Zhipu hat die Gewichte von GLM-5.2 unter der MIT-Lizenz auf Hugging Face (zai-org/GLM-5.2) und ModelScope veröffentlicht. Wenn Sie die API über AnyAIGC aufrufen, müssen Sie das Modell nicht selbst hosten. Für die kommerzielle Nutzung gelten die offiziellen Bedingungen von Zhipu AI.

Gibt es Limits für Parallelität oder Ratenlimits?

AnyAIGC begrenzt die Parallelität für glm-5.2 nicht, und jeder Nutzer erhält das standardmäßig. Das passt zu Batch-Jobs, CI-Pipelines und parallelen Agenten. Die Abrechnung erfolgt pro Token, es gibt also kein Kontingent, das sich wie bei einem Abo-Tarif nach einem Zeitfenster zurücksetzt.

Wie erhalte ich einen API-Schlüssel für GLM-5.2?

Registrieren Sie sich auf anyaigc.ai, laden Sie Guthaben auf und erstellen Sie in der Konsole einen Schlüssel. Derselbe Schlüssel funktioniert für alle GLM-Modelle und für 300+ weitere Modelle auf der Plattform. Sie brauchen also weder ein separates Zhipu-Plattformkonto noch einen GLM Coding Plan.

Kann ich bei AnyAIGC eine Rechnung bekommen?

Ja. Sie können Rechnungen in der Konsole selbst ausstellen, und zwar über den tatsächlich aufgeladenen Betrag.

Welche Zahlungsmethoden werden unterstützt?

Sie können Guthaben per WeChat Pay, Alipay, USDT oder Kreditkarte aufladen. Ihr Guthaben ist in USD und gilt für alle Modelle der Plattform. Rechnungen über den aufgeladenen Betrag können Sie in der Konsole ausstellen.

Gibt es kostenloses Testguthaben für neue Nutzer?

Ja. Neue Konten erhalten Testguthaben von 2 Millionen Tokens, damit Sie testen können, bevor Sie sich fürs Aufladen entscheiden. Aufladungen beginnen bei $1.

Kann ich mein Guthaben erstatten lassen?

Ja. Nicht genutztes Guthaben kann gebührenfrei erstattet werden. Wenden Sie sich an den Support, um eine Erstattung zu veranlassen.

Sind das die echten Modelle? Sind meine Daten sicher?

Anfragen laufen über offizielle Modellkanäle, nie über günstigere oder per Reverse Engineering nachgebaute Ersatzmodelle. Sofern das Gesetz es nicht verlangt, speichern wir Ihre Prompts und Ausgaben nicht dauerhaft und verwenden sie nicht für Training, und die Konsole zeigt Tokens und Kosten jeder Anfrage.

Werden meine Daten zum Training verwendet?

Nein. Außer wenn das Gesetz es verlangt, speichert AnyAIGC Ihre Prompts und Ausgaben nicht dauerhaft und nutzt sie nicht zum Training von Modellen. Anfragen werden per HTTPS verschlüsselt. Siehe die Datenschutzerklärung von AnyAIGC. Die Datenrichtlinie des Modells selbst richtet sich nach den offiziellen Bedingungen von Zhipu AI.
