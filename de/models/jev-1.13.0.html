01 · WAS IST JEV-1.13.0

jev-1.13.0: das erste öffentliche System-One-Modell

Ein Chat-LLM gibt Ihnen einen Absatz zum Parsen. jev-1.13.0 gibt Ihrem Code einen Wert, den er direkt nutzen kann: eine Wahrscheinlichkeit, eine Option oder einen Score.

TypeSafe AI hat jev-1.13.0 am 15. September 2026 als erstes öffentliches System-One-Modell angekündigt. Der Name geht auf Kahnemans System 1 zurück, die schnelle, intuitive Seite menschlichen Urteilens. Laut TypeSafe wird Jev mit RLCD (Reinforcement Learning for Calibrated Decisions) und einem parallelen Sampler trainiert und liefert typisierte Antworten mit kalibrierten Wahrscheinlichkeiten statt Freitext.

Stellen Sie es sich als intelligente If-Anweisung vor. Legen Sie den zu beurteilenden Inhalt in state ab und definieren Sie benannte, typisierte Fragen in questions. Jede Frage wird in einer einzigen Anfrage parallel beantwortet, ohne Obergrenze für die Anzahl. TypeSafe garantiert, dass die Antworten immer dem angeforderten Typ entsprechen, sodass Sie keine Parsing- oder Retry-Logik schreiben müssen.

02 · FRAGETYPEN

Drei Fragetypen in jev-1.13.0

Geben Sie jeder Frage in questions einen Namen; die Antwort kommt unter demselben Namen zurück.

  • type: noul

    noulWahrscheinlichkeit, dass es zutrifft

    Liefert eine Wahrscheinlichkeit von 0 bis 1. Fragen Sie über instructions, oder beschreiben Sie in criteria die Fälle true und false.

    Anfrage 
    "is_urgent": {
  "type": "noul",
  "instructions": "Does this convey urgency?"
}
    Antwort 
    {"type": "noul", "noul": 0.95}
  • type: choice

    choiceeine Option wählen

    criteria ordnet jeder Option eine Beschreibung zu, von 1 bis 255 Optionen. Liefert die gewählte Option, eine Konfidenz und eine Wahrscheinlichkeit für jede Option.

    Anfrage 
    "department": {
  "type": "choice",
  "criteria": {"billing": "…", "sales": "…", "technical": "…"}
}
    Antwort 
    {"choice": "billing", "confidence": 0.81,
 "probabilities": {"billing": 0.88, "sales": 0, "technical": 0.12}}
  • type: score

    scoreauf einer Skala bewerten

    criteria ist ein geordnetes Array mit 2 bis 10 Stufen. Liefert einen wahrscheinlichkeitsgewichteten Score (er kann eine Dezimalzahl sein), eine Konfidenz, eine Legende und Wahrscheinlichkeiten pro Stufe.

    Anfrage 
    "frustration": {
  "type": "score",
  "criteria": ["Calm", "Frustrated", "Very angry"]
}
    Antwort 
    {"score": 1.05, "confidence": 0.92,
 "probabilities": {"0": 0, "1": 0.95, "2": 0.05}}
  • Bilder oder box nötig?

    jev-1.14.0256k Kontext, Bilder, box

    Bei AnyAIGC nimmt jev-1.13.0 Texteingaben mit 32k Kontext an. Der experimentelle Typ box zur Lokalisierung von Objekten in Bildern, die Bildeingabe und der 256k-Kontext sind bei jev-1.14.0 verfügbar, zum selben Preis.

    wechseln 
    "model": "jev-1.14.0"

04 · EINSATZBEREICHE

Wofür sich jev-1.13.0 eignet

Überall dort, wo Ihr Code ein Ergebnis braucht, nach dem er verzweigen, sortieren oder Alarm auslösen kann.

  • 01 · choice

    Klassifikation und Intent

    Sortieren Sie Nachrichten, Produkte oder Dokumente mit je einer Wahrscheinlichkeit in feste Kategorien und leiten Sie unsichere Fälle an einen Menschen oder ein LLM weiter.

  • 02 · choice + noul

    Ticket-Routing

    Eine Anfrage beantwortet, welches Team zuständig ist, ob es dringend ist und wie verärgert der Kunde ist. So wissen Sie, wer das Ticket bekommt und wo es in der Warteschlange landet.

  • 03 · score

    Risikobewertung

    Bewerten Sie Transaktionen, Bestellungen oder Konten anhand Ihrer eigenen Stufen. Der Score ist eine wahrscheinlichkeitsgewichtete Dezimalzahl, mit der sich Schwellenwerte leicht festlegen lassen.

  • 04 · noul

    Content-Moderation

    Prüfen Sie Kommentare und nutzergenerierte Inhalte auf Richtlinienverstöße. Jede Regel ist eine eigene Frage, die parallel beantwortet wird.

  • 05 · noul

    LLM-Guardrails

    Setzen Sie eine Prüfung vor und nach Ihr LLM: Erkennen Sie Jailbreaks und Prompt-Injection oder bestätigen Sie, dass eine Antwort bei den von Ihnen bereitgestellten Quellen bleibt.

  • 06 · score

    Bewertung als LLM-as-Judge

    Übernehmen Sie einen Teil Ihrer LLM-as-Judge-Evals und bewerten Sie Antworten auf einer Skala, bei Abrechnung nur der Eingabe. Das arXiv-Paper sah rubrikartige Qualitätsurteile als Schwachstelle, prüfen Sie daher zuerst stichprobenartig.

  • 07 · if

    Intelligente If-Anweisungen

    Ziehen Sie Bedingungen aus Text: Ist das eine Erstattungsanfrage, wird ein Wettbewerber erwähnt, möchte der Kunde zurückgerufen werden? Binden Sie die Antwort direkt in Ihre Logik ein.

  • 08 · map-reduce

    Große Batch-Jobs

    Labeln Sie Millionen Datensätze einzeln und aggregieren Sie die Ergebnisse. Unbegrenzte Parallelität und kostenlose Ausgabe passen zu Offline-Batch-Aufgaben.

  • 09 · realtime

    Echtzeit-Anwendungen

    TypeSafe gibt typische Antwortzeiten von rund 100 ms an, schnell genug für einen Anfragepfad, den Nutzer direkt erleben.

06 · GRENZEN

Kennen Sie die Grenzen, bevor Sie live gehen

Aus den offiziellen Hinweisen von TypeSafe. Überlassen Sie dem Code, was Code berechnen kann, und stellen Sie pro Frage nur eine Sache.

  • Nimmt Formulierungen wörtlichEs beantwortet die Frage, die Sie geschrieben haben, nicht die, die Sie meinten. Formulieren Sie präzise.
  • Kein TaschenrechnerVerzichten Sie auf Rechnen und Zählen; erledigen Sie das im Code.
  • Schwach bei Datumsangaben und Multi-HopVergleichen Sie Datumsangaben selbst und zerlegen Sie mehrstufige Schlussfolgerungen, bevor Sie Jev fragen.
  • Irrelevanter State schadetEin großer State voller fachfremden Texts senkt die Genauigkeit. Senden Sie nur, was zählt.
  • Risiko durch Prompt InjectionNicht vertrauenswürdige Inhalte im State können die Antworten beeinflussen. Sichern Sie kritische Abläufe zusätzlich ab.
  • Bevorzugung der ersten OptionBei Auswahlfragen wird die erste Option leicht bevorzugt. Prüfen Sie das, indem Sie die Reihenfolge mischen.
  • Keine TextgenerierungKein Chat, keine Zusammenfassungen oder Umformulierungen. Kombinieren Sie es mit einem LLM, wenn Sie Text brauchen.
  • Englisch funktioniert am bestenAndere Sprachen funktionieren, aber schwächer; jev-1.14.0 verbessert vor allem die Mehrsprachigkeit.

jev-1.13.0 API in drei Schritten aufrufen

Jev ist nicht OpenAI-kompatibel. Rufen Sie /v1/systemone per einfachem HTTP auf.

  1. Registrieren und Guthaben aufladen: Erstellen Sie ein Konto unter anyaigc.ai. Ihr Guthaben gilt für alle Modelle der Plattform.
  2. API-Schlüssel erstellen: Erstellen Sie in der Konsole einen Schlüssel, der mit sk- beginnt, und speichern Sie ihn in der Umgebungsvariable ANYAIGC_API_KEY.
  3. Anfrage senden: Senden Sie einen POST an https://anyaigc.ai/v1/systemone mit model gleich jev-1.13.0 sowie state und questions. Die Antwort kommt synchron, ein Polling ist also nicht nötig.

Halten Sie Anfragen unter 32k Tokens. Bei AnyAIGC hat jev-1.13.0 ein Kontextfenster von 32k Tokens. Teilen Sie längere Eingaben auf mehrere Anfragen auf, kürzen Sie irrelevanten Text aus state oder wechseln Sie zu jev-1.14.0 mit 256k Kontext.

Die Antwortwerte stammen aus der AnyAIGC-API-Dokumentation. model gibt die ausgeführte Version zurück, und usage.output_tokens wird nicht berechnet. Ein ungültiger Body liefert 400, ein ungültiger Schlüssel 401, jeweils mit einem Fehler-Body der Form {"error": {"code", "message", "param", "type"}}. FAQ

jev-1.13.0 API: Häufige Fragen

Was ist jev-1.13.0?

jev-1.13.0 ist die erste öffentliche Version von Jev, dem System-One-Modell von TypeSafe AI, angekündigt am 15. September 2026. System One ist nach Kahnemans schnellem, intuitivem Urteilen benannt. Sie senden den zu beurteilenden Inhalt (state) und eine Reihe typisierter Fragen, und Jev liefert typisierte Antworten mit kalibrierten Wahrscheinlichkeiten statt Freitext. Bei AnyAIGC hat es ein Kontextfenster von 32k Tokens und unterstützt die Fragetypen noul, choice und score.

Ist jev-1.13.0 veraltet?

Nein. Eine neuere Version, jev-1.14.0, erschien am 14. Oktober 2026, aber jev-1.13.0 ist bei AnyAIGC weiterhin aufrufbar, und ein Abschaltdatum wurde nicht bekannt gegeben. TypeSafe gibt 60 Tage vor der Einstellung von jev-1.13.0 Bescheid. Bestehende Integrationen können weiterlaufen; für neue Projekte empfehlen wir jev-1.14.0.

Was kostet die jev-1.13.0 API?

Bei AnyAIGC kostet jev-1.13.0 $0.0227 pro 1 Mio. Eingabe-Tokens, die Ausgabe ist kostenlos. Abgerechnet wird pro Token, und nur Eingabe-Tokens werden berechnet. Beispiel: 1.000.000 Anfragen mit je 300 Eingabe-Tokens sind 300 Millionen Tokens, das ergibt $6.81. Die Parallelität ist für alle Nutzer unbegrenzt. Den aktuellen Preis finden Sie im AnyAIGC-Modellkatalog.

Was unterscheidet jev-1.13.0 von jev-1.14.0?

jev-1.13.0 ist die erste öffentliche Version (15. September 2026) mit 32k Tokens Kontext, Texteingabe und den Fragetypen noul, choice und score. jev-1.14.0 (14. Oktober 2026) bringt laut TypeSafe kleine Verbesserungen auf ganzer Linie, mit dem größten Zuwachs bei Mehrsprachigkeit. Bei AnyAIGC hat es 256k Tokens Kontext und ergänzt experimentelle Bildeingabe und den Fragetyp box. Beide kosten gleich viel.

Ist die jev-1.13.0 API OpenAI-kompatibel?

Nein. Jev nutzt die System One API von TypeSafe: POST https://anyaigc.ai/v1/systemone mit model, state und questions im Body, in der Antwort kommen answers und usage zurück. Es gibt weder messages noch choices, daher können OpenAI-SDKs es nicht aufrufen. Nutzen Sie einfaches HTTP mit requests, fetch oder cURL und den üblichen Header Authorization: Bearer <API Key>. Der Aufruf ist synchron: kein Streaming und kein Task-Polling.

Welche Einschränkungen hat jev-1.13.0?

Laut TypeSafe nimmt Jev Formulierungen wörtlich, ist kein Taschenrechner (vermeiden Sie Rechnen und Zählen), ist schwach bei Datumsvergleichen und Multi-Hop-Fragen, verliert an Genauigkeit, wenn der State viel irrelevanten Text enthält, kann durch Prompt-Injection beeinflusst werden und bevorzugt bei Auswahlfragen leicht die erste Option. Es generiert keinen Text. Englisch funktioniert am besten; andere Sprachen funktionieren, aber schwächer. Das unabhängige arXiv-Paper fand es außerdem schwächer bei ressourcenarmen Sprachen, verrauschten Labels und rubrikbasierten Qualitätsurteilen.

Kann ich bei AnyAIGC eine Rechnung bekommen?

Ja. Sie können Rechnungen in der Konsole selbst ausstellen, und zwar über den tatsächlich aufgeladenen Betrag.

Welche Zahlungsmethoden werden unterstützt?

Sie können Guthaben per WeChat Pay, Alipay, USDT oder Kreditkarte aufladen. Ihr Guthaben ist in USD und gilt für alle Modelle der Plattform. Rechnungen über den aufgeladenen Betrag können Sie in der Konsole ausstellen.

Gibt es kostenloses Testguthaben für neue Nutzer?

Ja. Neue Konten erhalten Testguthaben von 2 Millionen Tokens, damit Sie testen können, bevor Sie sich fürs Aufladen entscheiden. Aufladungen beginnen bei $1.

Kann ich mein Guthaben erstatten lassen?

Ja. Nicht genutztes Guthaben kann gebührenfrei erstattet werden. Wenden Sie sich an den Support, um eine Erstattung zu veranlassen.

Sind das die echten Modelle? Sind meine Daten sicher?

Anfragen laufen über offizielle Modellkanäle, nie über günstigere oder per Reverse Engineering nachgebaute Ersatzmodelle. Sofern das Gesetz es nicht verlangt, speichern wir Ihre Prompts und Ausgaben nicht dauerhaft und verwenden sie nicht für Training, und die Konsole zeigt Tokens und Kosten jeder Anfrage.
