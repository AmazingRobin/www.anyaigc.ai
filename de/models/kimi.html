Schnellstart

Die Kimi API in drei Schritten anbinden

  1. Registrieren und Guthaben aufladen: Erstellen Sie ein Konto unter anyaigc.ai. Aufladen ab $1; Ihr Guthaben gilt für alle Modelle der Plattform.
  2. API-Schlüssel erstellen: Erstellen Sie in der Konsole einen Schlüssel, kopieren Sie den Wert, der mit sk- beginnt, und speichern Sie ihn in der Umgebungsvariable ANYAIGC_API_KEY.
  3. Anfrage senden: Rufen Sie POST https://anyaigc.ai/v1/chat/completions auf, setzen Sie model auf kimi-k3.1-pro und senden Sie einen Authorization: Bearer-Header mit. Beim OpenAI SDK setzen Sie einfach base_url auf https://anyaigc.ai/v1.

Tipp: Kimi liefert sein Reasoning im Feld reasoning_content zurück. Beim Streaming kommen zuerst die Reasoning-Deltas, danach die endgültige Antwort. Senden Sie bei mehrstufigen Chats und Tool-Aufrufen die vollständige Assistant-Nachricht der API (einschließlich reasoning_content und tool_calls) in der nächsten Anfrage unverändert zurück.

Alle Parameter finden Sie in der Chat-Completions-Referenz. Ersetzen Sie den Modellnamen in den Beispielen der Dokumentation durch die gewünschte Kimi-Modell-ID.

Claude Code

Kimi in Claude Code nutzen

Stellen Sie Claude Code auf Kimi um, indem Sie eine einzige Konfigurationsdatei bearbeiten, und der Coding-Agent in Ihrem Terminal läuft mit Kimi.

  1. Claude Code installieren: Verwenden Sie das offizielle Installationsprogramm (zum Beispiel npm install -g @anthropic-ai/claude-code).
  2. Konfiguration hinzufügen: Bearbeiten Sie ~/.claude/settings.json, fügen Sie den folgenden env-Block ein und ersetzen Sie ANTHROPIC_AUTH_TOKEN durch den Schlüssel, den Sie bei AnyAIGC erstellt haben.
  3. Loslegen: Führen Sie claude in Ihrem Projektordner aus. Geben Sie /model ein, um zu prüfen, dass das aktuelle Modell kimi-k3.1-pro ist.

Modell wechseln: Für ein günstigeres Coding-Modell ersetzen Sie jedes kimi-k3.1-pro in der Konfiguration durch kimi-k2.7-code. K3.1 Pro hat ein Kontextfenster von 1M für große Repos; K2.7 Code kostet rund die Hälfte.

Die ausführliche Anleitung und häufige Fehler finden Sie in der Einrichtungsanleitung für Claude Code. Ersetzen Sie darin den Modellnamen durch kimi-k3.1-pro.

FAQ

Häufige Fragen zur Kimi API

Was kostet die Kimi API?

Kimi-Modelle bei AnyAIGC werden pro Token abgerechnet. Pro 1 Mio. Tokens: kimi-k3.1-pro Eingabe $0.8100, Ausgabe $4.0500, Cache-Treffer $0.0810; kimi-k3 Eingabe $1.2150, Ausgabe $6.0750, Cache-Treffer $0.1215; kimi-k2.7-code Eingabe $0.3847, Ausgabe $1.5980, Cache-Treffer $0.0770; kimi-k2.6 Eingabe $0.3847, Ausgabe $1.5980, Cache-Treffer $0.0651. Das sind rund 40 % der offiziellen USD-Preise von Moonshot. Aktuelle Preise finden Sie im Modellkatalog.

Welche Kimi-Modelle gibt es bei AnyAIGC, und wie lauten die Modell-IDs?

Diese Seite behandelt vier: kimi-k3.1-pro (das erste Modell der K3.1-Serie, mit Kontextfenster von 1M), kimi-k3 (das Flaggschiff der vorherigen Generation, ein Modell mit offenen Gewichten und 2.8T Parametern), kimi-k2.7-code (ein Coding-Agent-Modell) und kimi-k2.6 (ein allgemeines multimodales Agent-Modell). Tragen Sie die Modell-ID in das Feld model im Body der Anfrage ein. Um das Modell zu wechseln, ändern Sie nur dieses eine Feld.

Kimi K3.1 Pro, K3, K2.7 Code oder K2.6: Welches soll ich nehmen?

Wählen Sie Kimi K3.1 Pro, wenn Sie ein Kontextfenster von 1M, das anspruchsvollste langlaufende Coding, 3D-Erstellung oder Finanzrecherche brauchen. Es ist die neueste Generation und kostet rund ein Drittel weniger als K3. Workloads, die bereits auf K3 laufen, können dort bleiben. Wählen Sie K2.7 Code für alltägliches Coding und Coding-Agenten; laut Moonshot erreicht es bei Kimi Code Bench v2 21.8 % mehr als K2.6. Wählen Sie K2.6, wenn Sie den Modus ohne Thinking, schnelle Antworten oder allgemeinen Chat möchten. K2.7 Code und K2.6 kosten gleich viel, rund die Hälfte von K3.1 Pro.

Ist die Kimi API OpenAI-kompatibel?

Ja. Alle vier Modelle nutzen POST https://anyaigc.ai/v1/chat/completions mit demselben Anfrage- und Antwortformat wie OpenAI Chat Completions. Setzen Sie beim offiziellen OpenAI-SDK base_url auf https://anyaigc.ai/v1. Der Reasoning-Verlauf kommt im Feld reasoning_content zurück.

Kann ich Kimi in Claude Code nutzen?

Ja. Setzen Sie im env-Block von ~/.claude/settings.json ANTHROPIC_BASE_URL auf https://anyaigc.ai, ANTHROPIC_AUTH_TOKEN auf Ihren API-Schlüssel und ANTHROPIC_MODEL auf kimi-k3.1-pro. Führen Sie dann claude aus.

Wie groß ist das Kontextfenster?

Laut Moonshot unterstützen Kimi K3.1 Pro und K3 ein Kontextfenster von 1.048.576 Tokens; K2.7 Code und K2.6 unterstützen 262.144 Tokens (256K). Alle vier akzeptieren Bildeingaben und unterstützen Tool-Aufrufe.

Sind die Kimi-Modelle Open Source? Darf ich sie kommerziell nutzen?

Moonshot AI hat die Gewichte von Kimi K3, K2.7 Code und K2.6 auf Hugging Face veröffentlicht, und laut Moonshot erscheinen die vollständigen Gewichte von K3.1 Pro bis zum 4. November 2026. Wenn Sie die API über AnyAIGC aufrufen, müssen Sie die Modelle nicht selbst hosten. Modelllizenzen und kommerzielle Nutzung richten sich nach den offiziellen Bedingungen von Moonshot AI.

Gibt es Limits für Parallelität oder Ratenlimits?

AnyAIGC begrenzt die Parallelität für Kimi-Modelle nicht, und jeder Nutzer erhält das standardmäßig. Das passt zu Batch-Jobs, CI-Pipelines und parallelen Agenten. Die Plattform von Moonshot selbst begrenzt Parallelität, RPM, TPM und TPD je nach Aufladestufe; diese Stufen gelten nicht, wenn Sie über AnyAIGC aufrufen.

Wie bekomme ich einen Kimi-API-Schlüssel?

Registrieren Sie sich bei anyaigc.ai, laden Sie Guthaben auf und erstellen Sie in der Konsole einen Schlüssel. Derselbe Schlüssel funktioniert für alle Kimi-Modelle und 300+ weitere Modelle der Plattform, ein separates Konto auf der Moonshot-Plattform brauchen Sie also nicht.

Kann ich bei AnyAIGC eine Rechnung bekommen?

Ja. Sie können Rechnungen in der Konsole selbst ausstellen, und zwar über den tatsächlich aufgeladenen Betrag.

Welche Zahlungsmethoden werden unterstützt?

Sie können Guthaben per WeChat Pay, Alipay, USDT oder Kreditkarte aufladen. Ihr Guthaben ist in USD und gilt für alle Modelle der Plattform. Rechnungen über den aufgeladenen Betrag können Sie in der Konsole ausstellen.

Gibt es kostenloses Testguthaben für neue Nutzer?

Ja. Neue Konten erhalten Testguthaben von 2 Millionen Tokens, damit Sie testen können, bevor Sie sich fürs Aufladen entscheiden. Aufladungen beginnen bei $1.

Kann ich mein Guthaben erstatten lassen?

Ja. Nicht genutztes Guthaben kann gebührenfrei erstattet werden. Wenden Sie sich an den Support, um eine Erstattung zu veranlassen.

Sind das die echten Modelle? Sind meine Daten sicher?

Anfragen laufen über offizielle Modellkanäle, nie über günstigere oder per Reverse Engineering nachgebaute Ersatzmodelle. Sofern das Gesetz es nicht verlangt, speichern wir Ihre Prompts und Ausgaben nicht dauerhaft und verwenden sie nicht für Training, und die Konsole zeigt Tokens und Kosten jeder Anfrage.

Werden meine Daten zum Training verwendet?

Nein. Außer wo es gesetzlich vorgeschrieben ist, speichert AnyAIGC Ihre Prompts oder Ausgaben nicht dauerhaft und nutzt sie nicht zum Training von Modellen. Anfragen werden per HTTPS verschlüsselt. Siehe die Datenschutzerklärung von AnyAIGC. Die Datenrichtlinie des Modells selbst richtet sich nach den offiziellen Bedingungen von Moonshot AI.
