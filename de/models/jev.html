01 · WAS IST JEV

Was Jev ist: Entscheidungen statt Absätze

Ein Chat-LLM liefert Text, den Sie noch parsen müssen. Jev liefert Ihrem Code einen Wert, den er sofort nutzen kann: eine Wahrscheinlichkeit, eine Option oder einen Score.

Jev ist das erste öffentliche System-One-Modell von TypeSafe AI. Der Name lehnt sich an Daniel Kahnemans „System 1“ an, das schnelle, intuitive Urteil, das Ihr Gehirn ohne langes Abwägen fällt. Laut TypeSafe wird Jev mit RLCD (Reinforcement Learning for Calibrated Decisions) und einem parallelen Sampler trainiert und liefert statt Freitext typisierte Antworten mit kalibrierten Wahrscheinlichkeiten.

Stellen Sie es sich als intelligentes if-Statement vor. Legen Sie den zu beurteilenden Inhalt in state ab und definieren Sie in questions benannte, typisierte Fragen. Jede Frage wird in einer einzigen Anfrage parallel beantwortet, ohne Obergrenze für die Anzahl der Fragen. TypeSafe garantiert, dass die Antworten zu Typ und Schema Ihrer Frage passen, sodass Sie weder Parsing noch Retry-Logik schreiben müssen.

02 · FRAGETYPEN

Vier Fragetypen: noul, choice, score, box

Geben Sie jeder Frage in questions einen Namen, dann kommt die Antwort unter demselben Namen zurück.

  • type: noul

    noulWahrscheinlichkeit von true

    Wie wahrscheinlich ist etwas wahr? Liefert eine Wahrscheinlichkeit von 0 bis 1. Stellen Sie die Frage über instructions oder beschreiben Sie true und false in criteria.

    Anfrage 
    "is_urgent": {
  "type": "noul",
  "instructions": "Does this convey urgency?"
}
    Antwort 
    {"type": "noul", "noul": 0.95}
  • type: choice

    choiceeine Option wählen

    criteria ordnet jedem Optionsnamen eine Beschreibung zu, von 1 bis 255 Optionen. Liefert die gewählte Option, eine Konfidenz und eine Wahrscheinlichkeit für jede Option.

    Anfrage 
    "department": {
  "type": "choice",
  "criteria": {"billing": "…", "sales": "…", "technical": "…"}
}
    Antwort 
    {"choice": "billing", "confidence": 0.81,
 "probabilities": {"billing": 0.88, "sales": 0, "technical": 0.12}}
  • type: score

    scoreauf einer Skala bewerten

    criteria ist ein geordnetes Array mit 2 bis 10 Stufen. Liefert einen wahrscheinlichkeitsgewichteten Score (kann eine Dezimalzahl sein), eine Konfidenz, die Legende und Wahrscheinlichkeiten pro Stufe.

    Anfrage 
    "frustration": {
  "type": "score",
  "criteria": ["Calm", "Frustrated", "Very angry"]
}
    Antwort 
    {"score": 1.05, "confidence": 0.92,
 "probabilities": {"0": 0, "1": 0.95, "2": 0.05}}
  • type: box · jev-1.14.0

    boxObjekt in einem Bild lokalisieren Experimentell

    Nur mit jev-1.14.0. Erfordert ein Bild in assets und den Header TypeSafe-Danger-Zone-Images: true. Laut TypeSafe-Dokumentation enthält die Antwort die obere, untere, linke und rechte Kante des Objekts als Bruchteile von 0 bis 1 sowie eine Konfidenz, die null sein kann.

    Anfrage 
    "mug": {
  "type": "box",
  "instructions": "the coffee mug in `photo`"
}

05 · EINSATZBEREICHE

Wofür Teams Jev einsetzen

Überall dort, wo Ihr Code ein Ergebnis braucht, nach dem er verzweigen, sortieren oder alarmieren kann.

  • 01 · choice

    Klassifikation und Intent

    Sortieren Sie Nachrichten, Produkte oder Dokumente mit je einer Wahrscheinlichkeit in feste Kategorien und leiten Sie unsichere Fälle an einen Menschen oder ein LLM weiter.

  • 02 · choice + noul

    Ticket-Routing

    Eine Anfrage legt zuständiges Team, Dringlichkeit und Frustrationsgrad fest. So wissen Sie, wer das Ticket bekommt und wo es in der Warteschlange steht.

  • 03 · score

    Risikobewertung

    Bewerten Sie Transaktionen, Dokumente oder Konten nach Ihrem eigenen Raster. Der Score ist eine wahrscheinlichkeitsgewichtete Dezimalzahl, was Schwellenwerte einfach macht.

  • 04 · noul

    Content-Moderation

    Prüfen Sie Kommentare und nutzergenerierte Inhalte auf Verstöße, wobei jede Richtlinienregel eine eigene, parallel beantwortete Frage ist.

  • 05 · noul

    LLM-Guardrails

    Setzen Sie vor und nach Ihrem LLM eine Prüfung ein: Jailbreaks und Prompt Injection markieren und kontrollieren, dass die Ausgabe bei den bereitgestellten Quellen bleibt.

  • 06 · score

    Bewertung und Evals

    Übernehmen Sie einen Teil der LLM-as-Judge-Arbeit, indem Sie Antworten auf einer Skala bewerten und nur die Eingabe bezahlen. Eine Studie Dritter sah bei Qualitätsurteilen nach Rubrik eine Schwäche. Prüfen Sie daher stichprobenartig, bevor Sie sich darauf verlassen.

  • 07 · if

    Intelligente If-Anweisungen

    Ziehen Sie Bedingungen aus Texten: Ist das eine Erstattungsanfrage, wird ein Wettbewerber erwähnt, möchte der Kunde zurückgerufen werden? Die Antwort können Sie direkt in Ihre Geschäftslogik einbinden.

  • 08 · map-reduce

    Batch über große Datensätze

    Labeln Sie Millionen Datensätze einzeln und aggregieren Sie die Ergebnisse. Unbegrenzte Parallelität und kostenlose Ausgabe eignen sich für Offline-Batch-Jobs.

  • 09 · realtime

    Echtzeit-Anwendungen

    Laut TypeSafe liegen typische Antworten bei rund 100 ms, schnell genug für den Einsatz direkt im Anfragepfad für Nutzer.

07 · EINSCHRÄNKUNGEN

Kennen Sie die Grenzen von Jev, bevor Sie live gehen

Aus den offiziellen Hinweisen von TypeSafe. Überlassen Sie dem Code, was Code berechnen kann, und stellen Sie pro Frage nur eine Sache.

  • Wörtliches LesenEs beantwortet die Frage, die Sie geschrieben haben, nicht die, die Sie meinten. Formulieren Sie präzise.
  • Kein TaschenrechnerVerzichten Sie auf Rechnen und Zählen. Diese Logik gehört in den Code.
  • Datumsangaben und Multi-HopVergleichen Sie Daten selbst und zerlegen Sie mehrstufiges Reasoning, bevor Sie Jev fragen.
  • Irrelevanter State schadetViel themenfremder Inhalt senkt die Genauigkeit. Senden Sie nur, was beurteilt werden soll.
  • Prompt-InjectionNicht vertrauenswürdige Inhalte im State können Antworten beeinflussen. Sichern Sie kritische Stellen ab.
  • Bias zur ersten OptionChoice-Fragen neigen leicht zur ersten Option. Mischen Sie die Reihenfolge, um das zu prüfen.
  • Keine TextgenerierungKein Chat, keine Zusammenfassungen oder Umformulierungen. Kombinieren Sie es mit einem LLM, wenn Sie Text brauchen.
  • Englisch zuerstEnglisch funktioniert am besten. Andere Sprachen funktionieren, aber mit geringerer Genauigkeit.

09 · SCHNELLSTART

Jev API in drei Schritten anbinden

Jev ist nicht OpenAI-kompatibel. Rufen Sie /v1/systemone mit einer einfachen HTTP-Anfrage auf.

  1. Registrieren und Guthaben aufladen: Erstellen Sie ein Konto unter anyaigc.ai. Ihr Guthaben gilt für alle Modelle der Plattform.
  2. API-Schlüssel erstellen: Erstellen Sie in der Konsole einen API-Schlüssel, kopieren Sie ihn (er beginnt mit sk-) und speichern Sie ihn in der Umgebungsvariable ANYAIGC_API_KEY.
  3. Anfrage senden: POST an https://anyaigc.ai/v1/systemone mit model auf jev-1.14.0 sowie state und questions. Die Antwort kommt synchron, Polling ist nicht nötig. Alle Felder finden Sie in der API-Dokumentation.

Englisch funktioniert am besten. Laut TypeSafe ist Jev auf Englisch am stärksten. Andere Sprachen funktionieren, aber mit geringerer Genauigkeit. Liegt Ihr Inhalt in einer anderen Sprache vor, halten Sie instructions und criteria auf Englisch und testen Sie Schwellenwerte mit eigenen Beispielen, bevor Sie live gehen.

Die Antwortwerte stammen aus der AnyAIGC-API-Dokumentation. model nennt die Version, die tatsächlich lief, und usage.output_tokens wird nicht berechnet. Ein ungültiger Body liefert 400, ein ungültiger Schlüssel 401, jeweils mit einem Fehler-Body der Form {"error": {"code", "message", "param", "type"}}. Alle Parameter stehen in der AnyAIGC-System-One-API-Dokumentation.

10 · BILDER & BOX

Bildeingabe und Box-Lokalisierung mit jev-1.14.0

Kodieren Sie das Bild als Base64 in assets, verweisen Sie aus state auf den Platzhalter und fügen Sie einen Header hinzu.

Experimentell. Laut TypeSafe-Dokumentation sind Bilder als PNG oder JPEG möglich, bis 16 MiB, 280–1568 px pro Seite, und werden wie normale Eingabe-Tokens abgerechnet. Anfragen müssen TypeSafe-Danger-Zone-Images: true enthalten. TypeSafe weist darauf hin, dass Bilder und box noch nicht für den Produktivbetrieb empfohlen sind. Der lange 256k-Kontext erfordert zusätzlich den Header TypeSafe-Danger-Zone-Long-Context: true. AnyAIGC reicht diese Header und assets unverändert durch.

Box lokalisiert nur. Das Beispiel ergänzt eine noul-Frage, die prüft, ob das Objekt überhaupt im Bild ist, bevor Sie der Box vertrauen. Der Platzhalter ist nur ein String, verwenden Sie daher pro Bild eine neue zufällige ID, damit er nicht mit echtem Text kollidiert.

FAQ

Häufige Fragen zur Jev API

Was ist Jev?

Jev ist das erste öffentliche System-One-Modell von TypeSafe AI. Der Name geht auf Daniel Kahnemans „System 1“ zurück, die schnelle, intuitive Form des Urteilens. Sie senden Jev den zu beurteilenden Inhalt (state) und eine Reihe typisierter Fragen (questions). Jev liefert typisierte Antworten mit kalibrierten Wahrscheinlichkeiten zurück: zu welcher Kategorie etwas gehört, wie wahrscheinlich eine Aussage zutrifft oder wo es auf einer Skala liegt. Laut TypeSafe wird Jev mit RLCD (Reinforcement Learning for Calibrated Decisions) und einem parallelen Sampler trainiert.

Erzeugt Jev Text? Kann ich es als Chat-Modell nutzen?

Nein. Jev erzeugt keinen Text und kann weder chatten noch Vervollständigungen oder Zusammenfassungen liefern. Es beantwortet nur die Fragen, die Sie definieren, und jede Antwort entspricht dem angeforderten Typ (Wahrscheinlichkeit, Option oder Score). Zum Schreiben nutzen Sie auf derselben Plattform ein LLM wie GPT oder Claude, Jev setzen Sie für Klassifizierung, Routing, Moderation und Scoring ein.

Ist die Jev API OpenAI-kompatibel? Kann ich das OpenAI SDK verwenden?

Nein. Jev nutzt die eigene System-One-Schnittstelle von TypeSafe: POST https://anyaigc.ai/v1/systemone mit einem Body aus model, state und questions (bei Bildern zusätzlich assets). Die Antwort enthält answers und usage, aber kein messages und kein choices. OpenAI SDKs können den Endpunkt nicht aufrufen, senden Sie also eine einfache HTTP-Anfrage mit requests, fetch oder cURL. Die Authentifizierung bleibt Authorization: Bearer <API Key>. Der Endpunkt arbeitet synchron, ohne Streaming und ohne Polling von Aufgaben.

Was kostet die Jev API? Ist die Ausgabe wirklich kostenlos?

Bei AnyAIGC kosten jev-1.14.0 und jev-1.13.0 gleich viel: $0.0227 pro 1 Mio. Eingabe-Tokens, bei kostenloser Ausgabe. Die Abrechnung erfolgt pro Token, und nur Eingabe-Tokens werden berechnet. Bilder werden wie normale Eingabe-Tokens abgerechnet. Beispiel: 1.000.000 Anfragen mit je 300 Eingabe-Tokens ergeben 300 Mio. Tokens und kosten $6.81. Die Parallelität ist für alle Nutzer unbegrenzt. Aktuelle Preise finden Sie im AnyAIGC-Modellkatalog.

Worin unterscheiden sich jev-1.14.0 und jev-1.13.0?

jev-1.13.0 ist die erste öffentliche Version, veröffentlicht am 15. September 2026, mit einem Kontextfenster von 32k Tokens. jev-1.14.0 erschien am 14. Oktober 2026. TypeSafe beschreibt kleine Verbesserungen auf ganzer Linie, den größten Zugewinn bei der mehrsprachigen Leistung. Bei AnyAIGC bietet diese Version ein Kontextfenster von 256k und ergänzt experimentelle Bildeingabe sowie den Fragetyp box. Beide kosten gleich viel, für neue Projekte empfehlen wir jev-1.14.0.

Wie groß ist das Kontextfenster von Jev?

Laut AnyAIGC-Modellkatalog hat jev-1.13.0 ein Kontextfenster von 32k Tokens und jev-1.14.0 eines von 256k Tokens. In der Dokumentation von TypeSafe ist für langen Kontext der Request-Header TypeSafe-Danger-Zone-Long-Context: true vorgeschrieben, AnyAIGC reicht diesen Header durch. TypeSafe weist außerdem darauf hin, dass langer Kontext langsamer und weniger genau ist als die Standardlänge. Teilen Sie Inhalte daher nach Möglichkeit auf.

Kann Jev Bilder verarbeiten? Was ist der Fragetyp box?

jev-1.14.0 unterstützt experimentelle Bildeingabe: Legen Sie ein base64-kodiertes PNG oder JPEG in assets des Request-Bodys ab (bis 16 MiB, 280-1568 px pro Seite), verweisen Sie in state auf den Platzhalter und senden Sie den Header TypeSafe-Danger-Zone-Images: true. Box ist ein neuer experimenteller Fragetyp in 1.14, der ein Objekt in einem Bild lokalisiert. Er braucht denselben Header und ein Bild. Bilder werden wie normale Eingabe-Tokens abgerechnet. Laut TypeSafe sind die Bildfunktionen noch nicht für den Produktivbetrieb empfohlen.

Welche Sprachen unterstützt Jev?

Englisch funktioniert am besten. Laut TypeSafe funktionieren andere Sprachen, aber mit geringerer Genauigkeit, und jev-1.14.0 verbessert die mehrsprachige Leistung gegenüber 1.13. Eine Studie Dritter maß für jev-1.13.0 eine Genauigkeit von 86.7 % auf Belebele über 122 Sprachen, mit schwächeren Ergebnissen bei ressourcenarmen Sprachen. Wenn es auf Genauigkeit ankommt, formulieren Sie Ihre Fragen auf Englisch und testen Sie vor dem Livegang mit Ihren eigenen Beispielen.

Welche Einschränkungen hat Jev?

Laut TypeSafe: Jev liest Ihre Formulierung wörtlich. Es eignet sich nicht für Mathematik oder Zählen („Jev is not a calculator“), ist schwach bei Datumsvergleichen und mehrstufigen Fragen, viel irrelevanter State senkt die Genauigkeit, Prompt Injection ist ein Risiko, bei Auswahlfragen gibt es eine leichte Tendenz zur ersten Option, und Jev kann keinen Text erzeugen. Berechnen Sie im Code, was sich im Code berechnen lässt, und stellen Sie pro Frage nur eine Sache.

Darf ich Jev kommerziell nutzen?

Wie erhalte ich einen Jev API-Schlüssel?

Kann ich bei AnyAIGC eine Rechnung bekommen?

Ja. Sie können Rechnungen in der Konsole selbst ausstellen, und zwar über den tatsächlich aufgeladenen Betrag.

Welche Zahlungsmethoden werden unterstützt?

Sie können Guthaben per WeChat Pay, Alipay, USDT oder Kreditkarte aufladen. Ihr Guthaben ist in USD und gilt für alle Modelle der Plattform. Rechnungen über den aufgeladenen Betrag können Sie in der Konsole ausstellen.

Gibt es kostenloses Testguthaben für neue Nutzer?

Ja. Neue Konten erhalten Testguthaben von 2 Millionen Tokens, damit Sie testen können, bevor Sie sich fürs Aufladen entscheiden. Aufladungen beginnen bei $1.

Ja. Nicht genutztes Guthaben kann gebührenfrei erstattet werden. Wenden Sie sich an den Support, um eine Erstattung zu veranlassen.
