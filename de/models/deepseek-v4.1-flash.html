Über das Modell

Asymmetrisches Design, mehr Intelligenz pro Dollar

DeepSeek hat V4.1 Flash im September 2026 veröffentlicht und beschreibt es als kleinstes Modell einer neuen Architekturfamilie mit nativer Vision. Das neue Design zielt auf eine höhere Leistungsgrenze, schnellere Inferenz, mehr Durchsatz und Spielraum für größere Modelle.

Es ist ein MoE-Modell mit 552B Parametern auf Basis eines Causal-Encoder-Decoder-Designs, bei dem Eingabe und Ausgabe asymmetrisch sind: 8B Parameter sind bei der Eingabe aktiv, 16B bei der Ausgabe. Laut DeepSeek braucht der KV-Cache nur 1/4 des HBM und 1/8 des SSD-Speichers der Vorgängergeneration, was die Cache-Kosten senkt, die bei Agenten-Workloads dominieren. Im Oktober hat DeepSeek es auf V4.1-Flash-1017 aktualisiert und verweist auf deutliche Verbesserungen beim Coding auf Projektebene.

Bei AnyAIGC läuft deepseek-v4.1-flash über den OpenAI-kompatiblen Endpunkt /v1/chat/completions mit Text- und Bildeingabe. Es funktioniert auch direkt in Claude Code, rund um die Uhr zum selben Preis und ohne Parallelitätslimit.

Schnellstart

Erste Schritte mit der DeepSeek V4.1 Flash API

  1. Registrieren und Guthaben aufladen: Erstellen Sie ein Konto unter anyaigc.ai. Aufladen ab $1; Ihr Guthaben gilt für alle Modelle der Plattform.
  2. API-Schlüssel erstellen: Erstellen Sie in der Konsole einen Schlüssel, kopieren Sie den sk--Schlüssel und speichern Sie ihn in der Umgebungsvariable ANYAIGC_API_KEY.
  3. Anfrage senden: Rufen Sie POST https://anyaigc.ai/v1/chat/completions auf, setzen Sie model auf deepseek-v4.1-flash und senden Sie einen Authorization: Bearer-Header. Beim OpenAI SDK setzen Sie einfach base_url auf https://anyaigc.ai/v1.

Parameter: Laut DeepSeek denkt die V4-Serie standardmäßig nach. Mit dem Feld thinking im Request-Body schalten Sie den Thinking-Modus ein oder aus ({"type": "enabled"} oder {"type": "disabled"}), und reasoning_effort legt die Tiefe fest (offiziell low / high / max). Thinking-Tokens zählen als Ausgabe und erscheinen in usage.completion_tokens_details.reasoning_tokens. Sampling-Parameter wie temperature haben im Thinking-Modus keine Wirkung.

Alle Parameter finden Sie in der Referenz zur Chat-Completions-API. Ersetzen Sie in den Beispielen der Dokumentation den Modellnamen durch die gewünschte DeepSeek-Modell-ID.

Claude Code

DeepSeek V4.1 Flash in Claude Code nutzen

Richten Sie Claude Code auf DeepSeek V4.1 Flash aus: Bearbeiten Sie eine Konfigurationsdatei und schreiben Sie im Terminal Code mit DeepSeek, abgerechnet pro Token.

  1. Claude Code installieren: Verwenden Sie das offizielle Installationsprogramm, unter macOS oder Linux zum Beispiel curl -fsSL https://claude.ai/install.sh | bash.
  2. Konfiguration hinzufügen: Bearbeiten Sie ~/.claude/settings.json, fügen Sie den folgenden env-Block ein und ersetzen Sie ANTHROPIC_AUTH_TOKEN durch den Schlüssel, den Sie bei AnyAIGC erstellt haben.
  3. Loslegen: Führen Sie claude in Ihrem Projektordner aus. Geben Sie /model ein, um zu prüfen, dass das aktuelle Modell deepseek-v4.1-flash ist.

Modell wechseln: Für den Vergleich mit V4 Pro ersetzen Sie in der Konfiguration deepseek-v4.1-flash durch deepseek-v4-pro. Sonst ändert sich nichts.

Alle Schritte und häufige Fehler finden Sie in der Einrichtungsanleitung für Claude Code. Ersetzen Sie den Modellnamen in der Anleitung durch deepseek-v4.1-flash.

FAQ

FAQ zur DeepSeek V4.1 Flash API

Was kostet die DeepSeek V4.1 Flash API?

deepseek-v4.1-flash wird bei AnyAIGC pro Token abgerechnet: $0,1215 pro 1 Mio. Eingabe-Tokens, $0,4860 pro 1 Mio. Ausgabe-Tokens und $0,0024 pro 1 Mio. Cache-Treffer-Tokens. Der offizielle Preis von DeepSeek in USD außerhalb der Spitzenzeiten liegt bei $0,15 für Eingabe, $0,60 für Ausgabe und $0,003 für Cache-Treffer und verdoppelt sich zu Spitzenzeiten. Die Ausgabe umfasst Thinking-Tokens. Aktuelle Preise stehen im Modellkatalog.

Gibt es bei AnyAIGC getrennte Preise für Spitzenzeiten und außerhalb der Spitzenzeiten?

Nein. Die offizielle DeepSeek API rechnet nach Tageszeit ab: Werktags 01:00–04:00 und 06:00–10:00 UTC (9:00–12:00 und 14:00–18:00 Pekinger Zeit) gilt als Spitzenzeit, und die Spitzenpreise sind doppelt so hoch wie die Preise außerhalb der Spitzenzeiten. Bei AnyAIGC wird deepseek-v4.1-flash rund um die Uhr zu einem einheitlichen Preis abgerechnet. Dieser Preis liegt rund 60 % unter dem offiziellen Spitzenpreis. Aktuelle Preise stehen im Modellkatalog.

Was ist neu bei DeepSeek V4.1 Flash?

Laut DeepSeek ist V4.1 Flash das kleinste Modell der neuen Architekturfamilie: ein MoE mit 552B Parametern und asymmetrischem Causal-Encoder-Decoder-Design, 8B aktiven Parametern bei der Eingabe und 16B bei der Ausgabe sowie nativer Vision. DeepSeek gibt an, dass der KV-Cache nur 1/4 des HBM und 1/8 des SSD-Speichers der Vorgängergeneration benötigt, was die Caching-Kosten für Agenten-Workloads deutlich senkt.

Ist V4.1 Flash besser als V4 Pro?

Laut DeepSeek übertrifft V4.1 Flash in mehreren Tests jetzt V4 Pro bei Leistung, Kosten, Geschwindigkeit und Gesamtdauer der Aufgaben. Die Model Card nennt für DeepSWE v1.1 74,2 gegenüber 62,7 und für Terminal-Bench 2.1 90,6 gegenüber 87,9. Bei AnyAIGC kostet die Eingabe von V4.1 Flash $0,1215, etwa ein Viertel des Preises von V4 Pro ($0,5346).

Akzeptiert DeepSeek V4.1 Flash Bilder? Wie sende ich eines?

Ja. Fügen Sie dem Array messages[].content einen Block {"type": "image_url", "image_url": {"url": ...}} hinzu. Die url kann eine öffentliche Bild-URL oder eine Base64-Data-URL sein.

Wie groß ist das Kontextfenster? Wird der Thinking-Modus unterstützt?

DeepSeek nennt für V4.1 Flash ein Kontextfenster von 1M Tokens und bis zu 384K Ausgabe-Tokens. Unterstützt werden Thinking- und Non-Thinking-Modus (Thinking ist standardmäßig aktiv) sowie Tool-Aufrufe und JSON-Ausgabe.

Kann ich DeepSeek V4.1 Flash in Claude Code verwenden?

Ja. DeepSeek-Modelle bei AnyAIGC unterstützen sowohl das OpenAI- als auch das Anthropic-API-Format. Setzen Sie im env-Block von ~/.claude/settings.json ANTHROPIC_BASE_URL auf https://anyaigc.ai, ANTHROPIC_AUTH_TOKEN auf Ihren API-Schlüssel und ANTHROPIC_MODEL auf deepseek-v4.1-flash, und starten Sie dann claude. Sie zahlen pro Token.

Gibt es Limits für Parallelität oder Ratenlimits?

AnyAIGC begrenzt die Parallelität für deepseek-v4.1-flash nicht, und das gilt standardmäßig für alle Nutzer. Das eignet sich für Batch-Jobs, CI-Pipelines und parallele Agenten.

Wie erhalte ich einen API-Schlüssel für DeepSeek V4.1 Flash?

Registrieren Sie sich auf anyaigc.ai, laden Sie Guthaben auf und erstellen Sie in der Konsole einen Schlüssel. Derselbe Schlüssel funktioniert für alle DeepSeek-Modelle und für 300+ weitere Modelle der Plattform, ein separates Konto bei der DeepSeek Platform brauchen Sie also nicht.

Kann ich bei AnyAIGC eine Rechnung bekommen?

Ja. Sie können Rechnungen in der Konsole selbst ausstellen, und zwar über den tatsächlich aufgeladenen Betrag.

Welche Zahlungsmethoden werden unterstützt?

Gibt es kostenloses Testguthaben für neue Nutzer?

Ja. Neue Konten erhalten Testguthaben von 2 Millionen Tokens, damit Sie testen können, bevor Sie sich fürs Aufladen entscheiden. Aufladungen beginnen bei $1.
