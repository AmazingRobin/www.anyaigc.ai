Über das Modell

Das schlanke Modell der V4-Preview

DeepSeek hat im April 2026 die V4-Preview mit zwei Modellen veröffentlicht: V4 Pro und V4 Flash. V4 Flash ist das leichtere der beiden: ein MoE mit 284B Gesamtparametern und 13B aktiven Parametern, das die Architektur von V4 Pro übernimmt, ein Kontextfenster von 1M Tokens bietet und dessen Gewichte unter der MIT-Lizenz offenliegen.

Am 10. September hat DeepSeek V4.1 Flash veröffentlicht und V4 Flash eingestellt. Aus Kompatibilitätsgründen leitet die offizielle API Anfragen an deepseek-v4-flash vorübergehend an V4.1 Flash weiter und rechnet sie zum Flash-Preis ab.

Wenn Ihr Code noch deepseek-v4-flash verwendet, können Sie es bei AnyAIGC weiter aufrufen. Stellen Sie neue Projekte auf deepseek-v4.1-flash um: Das Modell kostet genauso viel und akzeptiert zusätzlich Bilder.

Schnellstart

Erste Schritte mit der DeepSeek V4 Flash API

  1. Registrieren und Guthaben aufladen: Erstellen Sie ein Konto unter anyaigc.ai. Aufladen ab $1; Ihr Guthaben gilt für alle Modelle der Plattform.
  2. API-Schlüssel erstellen: Erstellen Sie in der Konsole einen Schlüssel, kopieren Sie den sk--Schlüssel und speichern Sie ihn in der Umgebungsvariable ANYAIGC_API_KEY.
  3. Anfrage senden: Rufen Sie POST https://anyaigc.ai/v1/chat/completions auf, setzen Sie model auf deepseek-v4-flash und senden Sie einen Authorization: Bearer-Header mit. Beim OpenAI-SDK genügt es, base_url auf https://anyaigc.ai/v1 zu setzen.

Tipp zur Migration: Für den Wechsel von deepseek-v4-flash zu deepseek-v4.1-flash müssen Sie nur das Feld model ändern. Parameter, Endpunkt und Authentifizierung bleiben gleich, ebenso der Preis.

Alle Parameter finden Sie in der Referenz zur Chat-Completions-API. Ersetzen Sie in den Beispielen der Dokumentation den Modellnamen durch die gewünschte DeepSeek-Modell-ID.

Claude Code

DeepSeek V4 Flash in Claude Code verwenden

Claude Code funktioniert mit V4 Flash, wir empfehlen jedoch, stattdessen deepseek-v4.1-flash zu konfigurieren. Tauschen Sie dazu einfach den Modellnamen in der folgenden Konfiguration aus.

  1. Claude Code installieren: Verwenden Sie das offizielle Installationsprogramm, unter macOS oder Linux zum Beispiel curl -fsSL https://claude.ai/install.sh | bash.
  2. Konfiguration hinzufügen: Bearbeiten Sie ~/.claude/settings.json, fügen Sie den folgenden env-Block ein und ersetzen Sie ANTHROPIC_AUTH_TOKEN durch den Schlüssel, den Sie bei AnyAIGC erstellt haben.
  3. Loslegen: Führen Sie claude in Ihrem Projektordner aus. Geben Sie /model ein, um zu prüfen, ob das aktuelle Modell deepseek-v4-flash ist.

Empfohlen: Ersetzen Sie in der Konfiguration jedes deepseek-v4-flash durch deepseek-v4.1-flash. Gleicher Preis, bessere Ergebnisse.

Die vollständigen Schritte und häufige Fehler finden Sie in der Anleitung zur Einrichtung von Claude Code. Ersetzen Sie in der Anleitung den Modellnamen durch deepseek-v4-flash.

FAQ

FAQ zur DeepSeek V4 Flash API

Wurde DeepSeek V4 Flash eingestellt?

Ja. DeepSeek hat V4 Flash mit der Veröffentlichung von V4.1 Flash am 10. September 2026 eingestellt. Aus Kompatibilitätsgründen akzeptiert die offizielle API den Modellnamen deepseek-v4-flash weiterhin, beantwortet diese Anfragen mit V4.1 Flash und rechnet sie zum Flash-Preis ab. Nutzen Sie für neue Projekte direkt deepseek-v4.1-flash; beide kosten bei AnyAIGC genauso viel.

Was kostet die DeepSeek V4 Flash API?

deepseek-v4-flash wird bei AnyAIGC pro Token abgerechnet: $0,1215 pro 1 Mio. Eingabe-Tokens, $0,4860 pro 1 Mio. Ausgabe-Tokens und $0,0024 pro 1 Mio. Cache-Treffer-Tokens, genauso viel wie V4.1 Flash. DeepSeek rechnet den alten Namen zum Flash-Preis ab: außerhalb der Spitzenzeiten $0,15 für Eingabe, $0,60 für Ausgabe und $0,003 für Cache-Treffer, zu Spitzenzeiten das Doppelte. Aktuelle Preise zeigt der Modellkatalog.

Gibt es bei AnyAIGC getrennte Preise für Spitzenzeiten und außerhalb der Spitzenzeiten?

Nein. Die offizielle DeepSeek-API rechnet nach Tageszeit ab: Werktags von 01:00–04:00 und 06:00–10:00 UTC (9:00–12:00 und 14:00–18:00 Pekinger Zeit) ist Spitzenzeit, und die Preise zu Spitzenzeiten sind doppelt so hoch wie außerhalb der Spitzenzeiten. Bei AnyAIGC wird deepseek-v4-flash rund um die Uhr zu einem Preis abgerechnet. Dieser Preis liegt rund 60 % unter dem offiziellen Spitzenpreis. Aktuelle Preise zeigt der Modellkatalog.

Was muss ich ändern, um von V4 Flash auf V4.1 Flash zu wechseln?

Ändern Sie model im Request-Body von deepseek-v4-flash in deepseek-v4.1-flash. Endpunkt, Authentifizierung und Parameter bleiben gleich. V4.1 Flash unterstützt zusätzlich Bildeingaben, und laut DeepSeek übertrifft es V4 Pro in Benchmarks.

Welche Parameterzahl und Kontextfenster hat V4 Flash?

DeepSeek führt V4 Flash als MoE mit 284B Gesamtparametern und 13B aktiven Parametern, das die Architektur von V4 Pro übernimmt. Es bietet 1M Tokens Kontext, akzeptiert nur Text, und seine Gewichte sind unter der MIT-Lizenz offen.

Kann ich DeepSeek V4 Flash in Claude Code verwenden?

Ja. DeepSeek-Modelle bei AnyAIGC unterstützen sowohl das OpenAI- als auch das Anthropic-API-Format. Setzen Sie im env-Block von ~/.claude/settings.json ANTHROPIC_BASE_URL auf https://anyaigc.ai, ANTHROPIC_AUTH_TOKEN auf Ihren API-Schlüssel und ANTHROPIC_MODEL auf deepseek-v4-flash und starten Sie dann claude. Sie zahlen pro Token.

Gibt es Limits für Parallelität oder Ratenlimits?

AnyAIGC begrenzt die Parallelität für deepseek-v4-flash nicht, und das gilt standardmäßig für alle Nutzer. Das eignet sich für Batch-Jobs, CI-Pipelines und parallele Agenten.

Wie erhalte ich einen API-Schlüssel für DeepSeek V4 Flash?

Registrieren Sie sich auf anyaigc.ai, laden Sie Guthaben auf und erstellen Sie in der Konsole einen Schlüssel. Derselbe Schlüssel funktioniert für alle DeepSeek-Modelle und für 300+ weitere Modelle der Plattform, ein separates Konto bei der DeepSeek Platform brauchen Sie also nicht.

Kann ich bei AnyAIGC eine Rechnung bekommen?

Ja. Sie können Rechnungen in der Konsole selbst ausstellen, und zwar über den tatsächlich aufgeladenen Betrag.

Welche Zahlungsmethoden werden unterstützt?

Sie können Guthaben per WeChat Pay, Alipay, USDT oder Kreditkarte aufladen. Ihr Guthaben ist in USD und gilt für alle Modelle der Plattform. Rechnungen über den aufgeladenen Betrag können Sie in der Konsole ausstellen.

Gibt es kostenloses Testguthaben für neue Nutzer?

Ja. Neue Konten erhalten Testguthaben von 2 Millionen Tokens, damit Sie testen können, bevor Sie sich fürs Aufladen entscheiden. Aufladungen beginnen bei $1.

Kann ich mein Guthaben erstatten lassen?

Ja. Nicht genutztes Guthaben kann gebührenfrei erstattet werden. Wenden Sie sich an den Support, um eine Erstattung zu veranlassen.

Sind das die echten Modelle? Sind meine Daten sicher?

Anfragen laufen über offizielle Modellkanäle, nie über günstigere oder per Reverse Engineering nachgebaute Ersatzmodelle. Sofern das Gesetz es nicht verlangt, speichern wir Ihre Prompts und Ausgaben nicht dauerhaft und verwenden sie nicht für Training, und die Konsole zeigt Tokens und Kosten jeder Anfrage.
