Python
import json
import os
import time
import urllib.request

BASE = "https://anyaigc.ai"
HEADERS = {
    "Authorization": "Bearer " + os.environ["ANYAIGC_API_KEY"],
    "Content-Type": "application/json",
}


def call(method, path, body=None):
    data = json.dumps(body, ensure_ascii=False).encode("utf-8") if body else None
    request = urllib.request.Request(BASE + path, data=data, headers=HEADERS, method=method)
    with urllib.request.urlopen(request, timeout=60) as response:
        return json.load(response)


payload = {
    "model": "viduq2",
    "prompt": "A red fox crosses thin ice on a mountain lake at dawn; low tracking shot, its breath drifting in the sunlight.",
    "duration": 5,
    "resolution": "540p",
    "aspect_ratio": "16:9"
}

created = call("POST", "/ent/v2/text2video", payload)
task_id = (created.get("data") or created)["task_id"]
print("task_id:", task_id)

# Poll every 10 seconds until the task leaves the queue
for _ in range(120):
    result = call("GET", f"/ent/v2/tasks/{task_id}/creations")
    state = (result.get("data") or result).get("state") or (result.get("data") or result).get("status")
    if state not in ("created", "queueing", "processing"):
        break
    time.sleep(10)

# creations holds the video or image URLs; they expire, so download promptly
print(json.dumps(result, ensure_ascii=False, indent=2))

Ersetzen Sie das Beispielbild durch Ihre eigene URL oder Base64 (png, jpeg oder webp, bis zu 50 MB). Lesen Sie das Feld status aus der Live-Antwort; das Beispiel beendet das Polling, sobald die Aufgabe nicht mehr created, queueing oder processing ist.

Vidu Q2 API: Häufige Fragen

Preise, Endpunkte, Ergebnisse und Unternehmenszugang an einem Ort.

Was kostet die Vidu Q2 API?

Text 540p $0,0372 für die 1. Sekunde, danach +$0,00744/s; Text 720p $0,0558 für die 1. Sekunde, danach +$0,0186/s; Text 1080p $0,0744 für die 1. Sekunde, danach +$0,0372/s; Referenz 540p $0,0558 für die 1. Sekunde, danach +$0,0186/s; Referenz 720p $0,0931 für die 1. Sekunde, danach +$0,0186/s; Referenz 1080p $0,2792 für die 1. Sekunde, danach +$0,0372/s. Natives Audio bei Bild- oder Referenzeingabe kostet $0,0558 pro Aufgabe extra, empfohlene Prompts $0,0372 extra. Preise in USD; aktuelle Preise finden Sie im Modellkatalog.

Welchen Endpunkt soll ich aufrufen?

POST /ent/v2/text2video; POST /ent/v2/reference2video; POST /ent/v2/reference2image mit model auf viduq2 gesetzt. Die Erstellung liefert eine task_id; das Ergebnis rufen Sie mit GET /ent/v2/tasks/{id}/creations ab. Die Base-URL ist https://anyaigc.ai, der Schlüssel kommt in Authorization: Bearer.

Wie funktioniert die Abrechnung nach erster Sekunde plus Preis pro Sekunde?

Die Kosten wachsen mit der Länge: ein Preis für die erste Sekunde, danach ein fester Betrag pro weiterer Sekunde. Bei Text 540p kostet ein 5-Sekunden-Clip $0,06696. Die Dauer beträgt 1–10 Sekunden bei 540p / 720p / 1080p.

Wie erhalte ich das Ergebnis?

Aufgaben sind asynchron. Speichern Sie die task_id, fragen Sie per Polling GET /ent/v2/tasks/{id}/creations ab und lesen Sie die Video- oder Bild-URL aus creations, sobald die Aufgabe abgeschlossen ist. Beim Erstellen der Aufgabe können Sie auch callback_url übergeben. Ergebnis-URLs laufen ab, speichern Sie die Dateien daher zeitnah.

Gibt es Limits für Parallelität oder RPM?

Vidu auf AnyAIGC bietet jedem Konto standardmäßig unbegrenzte Parallelität, ohne festes RPM-Limit. Die Videogenerierung braucht Zeit, legen Sie daher in Ihrer Anwendung ein Polling-Intervall und ein Timeout fest.

Darf ich die Ausgabe kommerziell nutzen?

Die kommerzielle Nutzung richtet sich nach den offiziellen Bedingungen von Vidu (ShengShu Technology). Sie benötigen die Rechte an allen hochgeladenen Referenzbildern, Personen oder Markenmaterialien. AnyAIGC ist ein unabhängiger API-Anbieter.

Kann ich bei AnyAIGC eine Rechnung bekommen?

Ja. Sie können Rechnungen in der Konsole selbst ausstellen, und zwar über den tatsächlich aufgeladenen Betrag.

Welche Zahlungsmethoden werden unterstützt?

Sie können Guthaben per WeChat Pay, Alipay, USDT oder Kreditkarte aufladen. Ihr Guthaben ist in USD und gilt für alle Modelle der Plattform. Rechnungen über den aufgeladenen Betrag können Sie in der Konsole ausstellen.

Gibt es kostenloses Testguthaben für neue Nutzer?

Ja. Neue Konten erhalten Testguthaben von 2 Millionen Tokens, damit Sie testen können, bevor Sie sich fürs Aufladen entscheiden. Aufladungen beginnen bei $1.

Kann ich mein Guthaben erstatten lassen?

Ja. Nicht genutztes Guthaben kann gebührenfrei erstattet werden. Wenden Sie sich an den Support, um eine Erstattung zu veranlassen.

Sind das die echten Modelle? Sind meine Daten sicher?

Anfragen laufen über offizielle Modellkanäle, nie über günstigere oder per Reverse Engineering nachgebaute Ersatzmodelle. Sofern das Gesetz es nicht verlangt, speichern wir Ihre Prompts und Ausgaben nicht dauerhaft und verwenden sie nicht für Training, und die Konsole zeigt Tokens und Kosten jeder Anfrage.
