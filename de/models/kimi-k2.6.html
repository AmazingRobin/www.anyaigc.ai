Über das Modell

Ein universelles, offenes multimodales Agent-Modell

Moonshot AI positioniert Kimi K2.6 als offenes, nativ multimodales Agent-Modell. Laut Moonshot schreibt es langen Code leistungsfähiger und konsistenter, mit deutlichen Verbesserungen bei der Befolgung von Anweisungen und bei der Selbstkorrektur. Es nimmt Text- und Bildeingaben entgegen und hat einen Denkmodus und einen Nicht-Denkmodus, sodass es sich für Chat und Agent-Aufgaben gleichermaßen eignet.

Technisch ist es ein MoE mit 1T Gesamtparametern und 32B aktiven Parametern, 256K Kontext und nativer INT4-Quantisierung. Moonshot hebt vier Bereiche hervor: langlaufendes Coding, UI aus Prompts oder Bildern (Coding-Driven Design), Agent Swarm mit Skalierung auf 300 Sub-Agenten sowie proaktive Agenten, die rund um die Uhr laufen.

Bei AnyAIGC läuft kimi-k2.6 über den OpenAI-kompatiblen Endpunkt /v1/chat/completions und funktioniert direkt in Claude Code, mit unbegrenzter Parallelität.

Schnellstart

Kimi K2.6 API in drei Schritten anbinden

  1. Registrieren und Guthaben aufladen: Erstellen Sie ein Konto unter anyaigc.ai. Aufladen ab $1; Ihr Guthaben gilt für alle Modelle der Plattform.
  2. API-Schlüssel erstellen: Erstellen Sie in der Konsole einen Schlüssel, kopieren Sie den Wert, der mit sk- beginnt, und speichern Sie ihn in der Umgebungsvariable ANYAIGC_API_KEY.
  3. Anfrage senden: Rufen Sie POST https://anyaigc.ai/v1/chat/completions auf, mit model auf kimi-k2.6 und einem Authorization: Bearer-Header. Beim OpenAI SDK setzen Sie einfach base_url auf https://anyaigc.ai/v1.

Tipp: K2.6 denkt standardmäßig, das Reasoning kommt in reasoning_content zurück. In der Moonshot-API schaltet thinking: {"type": "disabled"} den Denkmodus aus (beim OpenAI SDK über extra_body übergeben); Moonshot empfiehlt im Nicht-Denkmodus temperature=0.6. Senden Sie im Denkmodus bei mehrstufigen Chats und Tool-Aufrufen die vollständige Assistant-Nachricht in der nächsten Anfrage unverändert zurück.

Alle Parameter finden Sie in der Chat-Completions-Referenz. Ersetzen Sie den Modellnamen in den Beispielen der Dokumentation durch die gewünschte Kimi-Modell-ID.

Claude Code

Kimi K2.6 in Claude Code nutzen

Stellen Sie Claude Code auf Kimi K2.6 um. Das Modell ist multimodal und günstig, geeignet für alltägliches Coding und das Korrigieren von UIs anhand von Screenshots.

  1. Claude Code installieren: Verwenden Sie das offizielle Installationsprogramm (zum Beispiel npm install -g @anthropic-ai/claude-code).
  2. Konfiguration hinzufügen: Bearbeiten Sie ~/.claude/settings.json, fügen Sie den folgenden env-Block ein und ersetzen Sie ANTHROPIC_AUTH_TOKEN durch den Schlüssel, den Sie bei AnyAIGC erstellt haben.
  3. Loslegen: Führen Sie claude in Ihrem Projektordner aus. Geben Sie /model ein, um zu prüfen, ob das aktuelle Modell kimi-k2.6 ist.

Zum Coding-Modell wechseln: Für eine höhere Erfolgsquote beim Coding ersetzen Sie kimi-k2.6 in der Konfiguration durch kimi-k2.7-code. Beide kosten gleich viel.

Die vollständige Anleitung und häufige Fehler finden Sie in der Einrichtungsanleitung für Claude Code. Ersetzen Sie den Modellnamen in der Anleitung durch kimi-k2.6.

FAQ

Kimi K2.6 API FAQ

Was kostet die Kimi K2.6 API?

Bei AnyAIGC wird kimi-k2.6 pro Token abgerechnet: Eingabe $0.3847 pro 1 Mio. Tokens, Ausgabe $1.5980 pro 1 Mio. Tokens, Cache-Treffer $0.0651 pro 1 Mio. Tokens. Die offiziellen USD-Preise von Moonshot betragen $0.95 für die Eingabe, $4.00 für die Ausgabe und $0.16 für Cache-Treffer. AnyAIGC kostet also rund 40 % des offiziellen Preises. Aktuelle Preise finden Sie im Modellkatalog.

Wie lautet die Modell-ID von Kimi K2.6, und wie groß ist der Kontext?

Die Modell-ID ist kimi-k2.6. Moonshot berichtet ein Kontextfenster von 262.144 Tokens (256K) an, mit Text- und Bildeingabe.

Kann ich den Denkmodus in Kimi K2.6 ausschalten?

K2.6 unterstützt Denkmodus und Nicht-Denkmodus (Instant). In der Moonshot-API schaltet thinking: {"type": "disabled"} den Denkmodus aus; beim OpenAI SDK übergeben Sie ihn in extra_body. Moonshot empfiehlt temperature=1.0 für den Denkmodus und temperature=0.6 für den Nicht-Denkmodus, jeweils mit top_p 0.95.

Was zeichnet Kimi K2.6 aus?

Moonshot positioniert K2.6 als offenes, nativ multimodales Agent-Modell mit vier Schwerpunkten: langlaufendes Coding (Rust, Go, Python, Frontend, DevOps und Performance-Tuning), produktionsreife UIs aus Prompts oder Bildern, Agent Swarm (Skalierung auf 300 Sub-Agenten und 4.000 koordinierte Schritte) und proaktive Agenten, die 24/7 im Hintergrund laufen.

Kimi K2.6 oder K2.7 Code: Welches sollte ich nutzen?

Beide teilen sich die Architektur und kosten bei AnyAIGC für Eingabe und Ausgabe gleich viel. K2.7 Code ist ein für Coding weitertrainiertes K2.6 mit höheren Coding-Werten und weniger Denk-Tokens, läuft aber nur im Denkmodus. K2.6 lässt sich ohne Denkmodus betreiben, was zu schnellem Chat, Klassifikation, Extraktion und allgemeinen Agenten passt.

Kann ich Kimi K2.6 in Claude Code nutzen?

Ja. Setzen Sie im env-Block von ~/.claude/settings.json ANTHROPIC_BASE_URL auf https://anyaigc.ai, ANTHROPIC_AUTH_TOKEN auf Ihren API-Schlüssel und ANTHROPIC_MODEL auf kimi-k2.6. Führen Sie dann claude aus.

Unterstützt Kimi K2.6 Tool-Aufrufe und Bildeingabe?

Ja. K2.6 unterstützt mehrstufige Tool-Aufrufe, Streaming und Bildeingabe. Senden Sie im Denkmodus bei mehrstufigen Chats und Tool-Aufrufen die vollständige Assistant-Nachricht (einschließlich reasoning_content und tool_calls) in der nächsten Anfrage unverändert zurück.

Gibt es Limits für Parallelität oder Ratenlimits?

AnyAIGC begrenzt die Parallelität für kimi-k2.6 nicht, und jeder Nutzer hat das standardmäßig. Das passt zu Batch-Jobs, CI-Pipelines und parallelen Agenten. Die Plattform von Moonshot begrenzt Parallelität, RPM, TPM und TPD nach Aufladestufe; diese Stufen gelten nicht, wenn Sie über AnyAIGC aufrufen.

Wie bekomme ich einen API-Schlüssel für Kimi K2.6?

Registrieren Sie sich bei anyaigc.ai, laden Sie Guthaben auf und erstellen Sie in der Konsole einen Schlüssel. Derselbe Schlüssel funktioniert für alle Kimi-Modelle und 300+ weitere Modelle der Plattform, ein separates Konto auf der Moonshot-Plattform brauchen Sie also nicht.

Kann ich bei AnyAIGC eine Rechnung bekommen?

Ja. Sie können Rechnungen in der Konsole selbst ausstellen, und zwar über den tatsächlich aufgeladenen Betrag.

Welche Zahlungsmethoden werden unterstützt?

Sie können Guthaben per WeChat Pay, Alipay, USDT oder Kreditkarte aufladen. Ihr Guthaben ist in USD und gilt für alle Modelle der Plattform. Rechnungen über den aufgeladenen Betrag können Sie in der Konsole ausstellen.

Gibt es kostenloses Testguthaben für neue Nutzer?

Ja. Neue Konten erhalten Testguthaben von 2 Millionen Tokens, damit Sie testen können, bevor Sie sich fürs Aufladen entscheiden. Aufladungen beginnen bei $1.

Kann ich mein Guthaben erstatten lassen?

Ja. Nicht genutztes Guthaben kann gebührenfrei erstattet werden. Wenden Sie sich an den Support, um eine Erstattung zu veranlassen.

Sind das die echten Modelle? Sind meine Daten sicher?

Anfragen laufen über offizielle Modellkanäle, nie über günstigere oder per Reverse Engineering nachgebaute Ersatzmodelle. Sofern das Gesetz es nicht verlangt, speichern wir Ihre Prompts und Ausgaben nicht dauerhaft und verwenden sie nicht für Training, und die Konsole zeigt Tokens und Kosten jeder Anfrage.

Werden meine Daten zum Training verwendet?

Nein. Außer wo es gesetzlich vorgeschrieben ist, speichert AnyAIGC Ihre Prompts oder Ausgaben nicht dauerhaft und nutzt sie nicht zum Training von Modellen. Anfragen werden per HTTPS verschlüsselt. Siehe die Datenschutzerklärung von AnyAIGC. Die Datenrichtlinie des Modells selbst richtet sich nach den offiziellen Bedingungen von Moonshot AI.
