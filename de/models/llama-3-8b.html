cURL
curl --request POST "https://anyaigc.ai/v1/chat/completions" \
  --header "Authorization: Bearer $ANYAIGC_API_KEY" \
  --header "Content-Type: application/json" \
  --data '{
  "model": "llama-3-8b",
  "messages": [
    {
      "role": "user",
      "content": "Explain what an API is in three sentences."
    }
  ],
  "n": 1,
  "stream": false
}'
Python
import json
import os
import urllib.request

payload = {
  "model": "llama-3-8b",
  "messages": [
    {
      "role": "user",
      "content": "Explain what an API is in three sentences."
    }
  ],
  "n": 1,
  "stream": False
}
request = urllib.request.Request(
    "https://anyaigc.ai/v1/chat/completions",
    data=json.dumps(payload, ensure_ascii=False).encode("utf-8"),
    headers={
        "Authorization": "Bearer " + os.environ["ANYAIGC_API_KEY"],
        "Content-Type": "application/json",
    },
    method="POST",
)
with urllib.request.urlopen(request, timeout=120) as response:
    result = json.load(response)

print(json.dumps(result, ensure_ascii=False, indent=2))

Das cURL-Beispiel nutzt Bash-/zsh-Syntax, Python nur die Standardbibliothek. Mit n=1 und stream=false enthält die Antwort in choices einen Antwortkandidaten sowie usage. Setzen Sie stream=true für SSE-Ausgabe.

Llama 3 8B API: Häufige Fragen

Preise, Versionen, Integration und Einkauf im Unternehmen.

Was kostet die Llama 3 8B API?

Eingabe kostet $1.3500 und Ausgabe $1.3500 pro 1 Mio. Tokens, in USD. Modelle mit dem Angebot sparen 32 %, wie im Modellkatalog angezeigt. Die aufgeführten Preise enthalten den Rabatt bereits; wenden Sie ihn nicht erneut an. Die aktuellen Preise finden Sie im Modellkatalog.

Wie hängen Llama und Ollama zusammen? Welche Versionen sind aufgeführt?

Meta entwickelt die Modellfamilie Llama. Ollama ist eine Modell-Laufzeitumgebung und die Anbieterkategorie im AnyAIGC-Modellkatalog. Diese Guides decken 12 Modelle aus Llama 2, 3, 3.1, 3.2 und 3.3 ab. Für die kommerzielle Nutzung gelten die offiziellen Bedingungen von Meta.

Welche Modell-ID sende ich, und was liefert eine Anfrage zurück?

Verwenden Sie POST /v1/chat/completions mit llama-3-8b und Bearer-Authentifizierung per API-Schlüssel. Die Beispiele setzen n=1 und stream=false, damit eine Antwortvariante des Assistenten samt Token-Verbrauch zurückkommt. Der Name llama wird für diese Übersicht verwendet.

Sind Parallelität oder RPM begrenzt? Muss ich Ollama installieren?

Standardmäßig haben alle Nutzer unbegrenzte Parallelität und kein festes RPM-Limit. Sie rufen die AnyAIGC-Cloud-API auf, ohne Ollama zu installieren oder das Modell lokal bereitzustellen. Ihre Anwendung sollte weiterhin Netzwerk-Timeouts und API-Fehler behandeln.

Welche Modelle verarbeiten Bilder? Wie steht es um Sprachen?

Die Modelle Llama 3.2 11B und 90B Vision Instruct sind Vision-Modelle, die übrigen aufgeführten Modelle sind Textmodelle. Llama 3.1 bis 3.3 unterstützen offiziell acht Textsprachen, Chinesisch ausgenommen. Bild-Text-Aufgaben unterstützen offiziell Englisch. Prüfen Sie andere Sprachen mit Ihren eigenen Daten; die Beispiele zeigen Textanfragen.

Kann ich bei AnyAIGC eine Rechnung bekommen?

Ja. Sie können Rechnungen in der Konsole selbst ausstellen, und zwar über den tatsächlich aufgeladenen Betrag.

Welche Zahlungsmethoden werden unterstützt?

Sie können Guthaben per WeChat Pay, Alipay, USDT oder Kreditkarte aufladen. Ihr Guthaben ist in USD und gilt für alle Modelle der Plattform. Rechnungen über den aufgeladenen Betrag können Sie in der Konsole ausstellen.

Gibt es kostenloses Testguthaben für neue Nutzer?

Ja. Neue Konten erhalten Testguthaben von 2 Millionen Tokens, damit Sie testen können, bevor Sie sich fürs Aufladen entscheiden. Aufladungen beginnen bei $1.

Kann ich mein Guthaben erstatten lassen?

Ja. Nicht genutztes Guthaben kann gebührenfrei erstattet werden. Wenden Sie sich an den Support, um eine Erstattung zu veranlassen.

Sind das die echten Modelle? Sind meine Daten sicher?

Anfragen laufen über offizielle Modellkanäle, nie über günstigere oder per Reverse Engineering nachgebaute Ersatzmodelle. Sofern das Gesetz es nicht verlangt, speichern wir Ihre Prompts und Ausgaben nicht dauerhaft und verwenden sie nicht für Training, und die Konsole zeigt Tokens und Kosten jeder Anfrage.
