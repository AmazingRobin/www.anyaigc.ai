Bringen Sie die Fähigkeiten des Modells in Ihr Produkt, Ihren Workflow oder Ihr Kreativ-Tool.

Versionen H3 und H3-Max

Setzen Sie model_version auf H3 oder H3-Max: H3 bietet das umfangreichere Referenz-Toolkit, H3-Max ist die schnelle Version.

02

Text, erstes und letztes Frame

Erzeugen Sie Videos aus einer schriftlichen Szenenbeschreibung, oder geben Sie ein erstes Frame bzw. erstes und letztes Frame vor, um Anfang und Ende festzulegen.

03

Multimodale Referenzen (H3)

H3 akzeptiert mehrere Referenzbilder und Referenzvideos. Die ersten 5 Bilder sind kostenlos, jedes weitere Bild wird berechnet.

04

768P / 2K / 480P

H3 rendert in 768P oder 2K, H3-Max in 480P oder 768P, abgerechnet nach tatsächlich ausgegebenen Sekunden.

Python
import json
import os
import time
import urllib.request

BASE = "https://anyaigc.ai"
HEADERS = {
    "Authorization": "Bearer " + os.environ["ANYAIGC_API_KEY"],
    "Content-Type": "application/json",
}


def call(method, path, payload=None):
    data = json.dumps(payload, ensure_ascii=False).encode("utf-8") if payload else None
    request = urllib.request.Request(BASE + path, data=data, headers=HEADERS, method=method)
    with urllib.request.urlopen(request, timeout=120) as response:
        return json.load(response)


payload = {
    "model_name": "Hailuo",
    "model_version": "H3",
    "prompt": "A sunset over the sea, the camera slowly pushing in as waves wash over the rocks.",
    "output_config": {
        "aspect_ratio": "16:9",
        "duration": 6,
        "resolution": "768P"
    }
}

task_id = call("POST", "/tencent-vod/v1/aigc-video", payload)["Response"]["TaskId"]
print("task_id:", task_id)

# Poll every 10 seconds; print the full result (with the video URL) once Status is FINISH
while True:
    result = call("GET", f"/tencent-vod/v1/query/{task_id}")["Response"]
    if result["Status"] == "FINISH":
        break
    time.sleep(10)

print(json.dumps(result, ensure_ascii=False, indent=2))

Beim Erstellen erhalten Sie Response.TaskId zurück. Rufen Sie per Polling GET /tencent-vod/v1/query/{task_id} ab; sobald Status FINISH ist, laden Sie das Video von Output.FileInfos[].FileUrl herunter (temporärer Speicher mit Ablaufzeit). Dokumentation zur Aufgabenabfrage ↗

FAQ

Häufige Fragen zur MiniMax API

Preise, Endpunkte, Ergebnisse und Unternehmenszugang an einem Ort.

Was kostet die Hailuo H3 API?

H3 768P Ausgabevideo $0.0972/Sekunde; H3 768P Eingabevideo $0.0972/Sekunde; H3 2K Ausgabevideo $0.1579/Sekunde; H3 2K Eingabevideo $0.1579/Sekunde; H3-Max 480P Ausgabevideo $0.0607/Sekunde; H3-Max 768P Ausgabevideo $0.0972/Sekunde; Eingabebilder (die ersten 5) $0/Bild; Eingabebilder (ab dem 6.) $0.0486/Bild. Alle Preise in USD; aktuelle Preise finden Sie im Modellkatalog.

Welchen API-Endpunkt soll ich verwenden?

Verwenden Sie POST /tencent-vod/v1/aigc-video; GET /tencent-vod/v1/query/{task_id} unter https://anyaigc.ai und übergeben Sie Ihren API-Schlüssel über Authorization: Bearer.

Was ist der Unterschied zwischen H3 und H3-Max?

H3 läuft 4–15 Sekunden in 768P oder 2K (1080P-Anfragen werden in 768P gerendert, 4K in 2K) in 21:9, 16:9, 4:3, 1:1, 3:4 oder 9:16, mit Text, erstem/letztem Frame und multimodalen Referenzeingaben. H3-Max ist die schnelle Version: 5–15 Sekunden in 480P oder 768P, nur Text und erstes/letztes Frame, ohne Zwischenframes, multimodale Referenzen oder Eingabevideo.

Was liefert eine Anfrage zurück?

Eine asynchrone Aufgabe erzeugt ein Video: 4–15 Sekunden bei H3, 5–15 bei H3-Max, abgerechnet nach tatsächlich ausgegebenen Sekunden.

Gibt es Limits für Parallelität oder RPM?

AnyAIGC bietet für MiniMax unbegrenzte Parallelität ohne festes RPM-Limit. Die Generierung braucht trotzdem Zeit; konfigurieren Sie Timeouts, Fehlerbehandlung und geeignete Wiederholungen in Ihrer Anwendung.

Dürfen generierte Inhalte kommerziell genutzt werden?

Die kommerzielle Nutzung der Modelle und ihrer Ausgaben richtet sich nach den offiziellen Bedingungen von MiniMax. Stellen Sie sicher, dass Sie die nötigen Rechte an Referenzmaterial, Stimmen und generierten Inhalten haben. AnyAIGC ist ein unabhängiger API-Anbieter.

Kann ich bei AnyAIGC eine Rechnung bekommen?

Ja. Sie können Rechnungen in der Konsole selbst ausstellen, und zwar über den tatsächlich aufgeladenen Betrag.

Welche Zahlungsmethoden werden unterstützt?

Sie können Guthaben per WeChat Pay, Alipay, USDT oder Kreditkarte aufladen. Ihr Guthaben ist in USD und gilt für alle Modelle der Plattform. Rechnungen über den aufgeladenen Betrag können Sie in der Konsole ausstellen.

Gibt es kostenloses Testguthaben für neue Nutzer?

Ja. Neue Konten erhalten Testguthaben von 2 Millionen Tokens, damit Sie testen können, bevor Sie sich fürs Aufladen entscheiden. Aufladungen beginnen bei $1.

Kann ich mein Guthaben erstatten lassen?

Ja. Nicht genutztes Guthaben kann gebührenfrei erstattet werden. Wenden Sie sich an den Support, um eine Erstattung zu veranlassen.

Sind das die echten Modelle? Sind meine Daten sicher?

Anfragen laufen über offizielle Modellkanäle, nie über günstigere oder per Reverse Engineering nachgebaute Ersatzmodelle. Sofern das Gesetz es nicht verlangt, speichern wir Ihre Prompts und Ausgaben nicht dauerhaft und verwenden sie nicht für Training, und die Konsole zeigt Tokens und Kosten jeder Anfrage.
