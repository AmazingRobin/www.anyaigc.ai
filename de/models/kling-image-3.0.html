SCHNELLSTART

Kling Image 3.0 API einbinden

  1. 1Registrieren, API-Schlüssel erstellen und ANYAIGC_API_KEY setzen
  2. 2Mit POST /tencent-vod/v1/aigc-image eine Aufgabe senden und die TaskId erhalten
  3. 3GET /tencent-vod/v1/query/{task_id} abfragen und das Bild laden, sobald Status FINISH lautet

Setzen Sie model_name auf "Kling", model_version auf "3.0" und output_config.resolution auf "2K" oder "4K" (Großbuchstaben). Das Ergebnis liegt unter Response.AigcImageTask.Output.FileInfos[].FileUrl; es wird nur temporär mit Ablaufzeit gespeichert, laden Sie es daher zeitnah herunter.

cURL

curl --request POST "https://anyaigc.ai/tencent-vod/v1/aigc-image" \
  --header "Authorization: Bearer $ANYAIGC_API_KEY" \
  --header "Content-Type: application/json" \
  --data '{
  "model_name": "Kling",
  "model_version": "3.0",
  "prompt": "An orange cat on a rain-soaked windowsill, a neon-lit street outside, cinematic lighting, rich detail",
  "output_config": {
    "aspect_ratio": "16:9",
    "resolution": "2K"
  }
}'

# Query the result with the returned Response.TaskId
curl "https://anyaigc.ai/tencent-vod/v1/query/$TASK_ID" \
  --header "Authorization: Bearer $ANYAIGC_API_KEY"

Python

import json
import os
import time
import urllib.request

BASE = "https://anyaigc.ai"
HEADERS = {
    "Authorization": "Bearer " + os.environ["ANYAIGC_API_KEY"],
    "Content-Type": "application/json",
}


def call(method, path, payload=None):
    data = json.dumps(payload, ensure_ascii=False).encode("utf-8") if payload else None
    request = urllib.request.Request(BASE + path, data=data, headers=HEADERS, method=method)
    with urllib.request.urlopen(request, timeout=60) as response:
        return json.load(response)


payload = {
    "model_name": "Kling",
    "model_version": "3.0",
    "prompt": "An orange cat on a rain-soaked windowsill, a neon-lit street outside, cinematic lighting, rich detail",
    "output_config": {
        "aspect_ratio": "16:9",
        "resolution": "2K"
    }
}

task_id = call("POST", "/tencent-vod/v1/aigc-image", payload)["Response"]["TaskId"]
print("task_id:", task_id)

# Poll every 5 seconds; print the image URL once Status is FINISH
for _ in range(60):
    result = call("GET", f"/tencent-vod/v1/query/{task_id}")["Response"]
    if result["Status"] == "FINISH":
        break
    time.sleep(5)
else:
    raise TimeoutError(task_id)

for item in result["AigcImageTask"]["Output"]["FileInfos"]:
    print(item["FileUrl"])

FAQ

Häufige Fragen zur Kling Image 3.0 API

Was kostet die Kling Image 3.0 API?

$0.00169 pro Aufruf, der ein Bild liefert, in 2K oder 4K zum selben Preis. Preise in USD, Abrechnung bei erfolgreicher Übermittlung; aktuelle Preise stehen im Modellkatalog.

Welchen Endpunkt rufe ich auf?

Senden Sie die Aufgabe mit POST /tencent-vod/v1/aigc-image, setzen Sie model_name auf Kling und model_version auf 3.0 und holen Sie das Ergebnis mit GET /tencent-vod/v1/query/{task_id}. Der API-Host ist https://anyaigc.ai, der Header lautet Authorization: Bearer <API Key>.

Wie stelle ich die Auflösung ein?

Setzen Sie output_config.resolution auf "2K" oder "4K" (Großbuchstaben). Beide kosten dasselbe.

Welche Generierungsmodi werden unterstützt?

Text-zu-Bild, Bild-zu-Bild, Mehrbild-Referenz, Stilübertragung, Charakterreferenz und Inpainting. Referenzbilder werden in file_infos übergeben; die genauen Felder stehen in der API-Referenz.

Wie erhalte ich das Ergebnis?

Die API ist asynchron. Die Übermittlung liefert Response.TaskId; fragen Sie den Abfrage-Endpunkt per Polling ab und laden Sie das Bild von Response.AigcImageTask.Output.FileInfos[].FileUrl herunter, sobald Status FINISH lautet. Dateien werden nur temporär gespeichert und laufen ab.

Gibt es Limits für die Parallelität?

Kling-Modelle auf AnyAIGC haben für jedes Konto standardmäßig unbegrenzte Parallelität.

Kann ich die Bilder kommerziell nutzen?

Nutzungsrechte und Inhaltsrichtlinien richten sich nach den offiziellen Bedingungen von Kuaishou Kling. Stellen Sie sicher, dass Sie die Rechte an den von Ihnen hochgeladenen Referenzbildern besitzen.

Kann ich bei AnyAIGC eine Rechnung bekommen?

Ja. Sie können Rechnungen in der Konsole selbst ausstellen, und zwar über den tatsächlich aufgeladenen Betrag.

Welche Zahlungsmethoden werden unterstützt?

Sie können Guthaben per WeChat Pay, Alipay, USDT oder Kreditkarte aufladen. Ihr Guthaben ist in USD und gilt für alle Modelle der Plattform. Rechnungen über den aufgeladenen Betrag können Sie in der Konsole ausstellen.

Gibt es kostenloses Testguthaben für neue Nutzer?

Ja. Neue Konten erhalten Testguthaben von 2 Millionen Tokens, damit Sie testen können, bevor Sie sich fürs Aufladen entscheiden. Aufladungen beginnen bei $1.

Kann ich mein Guthaben erstatten lassen?

Ja. Nicht genutztes Guthaben kann gebührenfrei erstattet werden. Wenden Sie sich an den Support, um eine Erstattung zu veranlassen.

Sind das die echten Modelle? Sind meine Daten sicher?

Anfragen laufen über offizielle Modellkanäle, nie über günstigere oder per Reverse Engineering nachgebaute Ersatzmodelle. Sofern das Gesetz es nicht verlangt, speichern wir Ihre Prompts und Ausgaben nicht dauerhaft und verwenden sie nicht für Training; die Konsole zeigt die Kosten jeder Anfrage.
