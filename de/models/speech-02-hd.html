Python
import json
import os
import urllib.request

# MINIMAX_VOICE_ID must be a voice ID available to your account.
payload = {
    "model": "speech-02-hd",
    "text": "Hello, welcome to speech synthesis with AnyAIGC.",
    "voice_setting": {
        "voice_id": os.environ["MINIMAX_VOICE_ID"]
    }
}

request = urllib.request.Request(
    "https://anyaigc.ai/minimax/v1/t2a_v2",
    data=json.dumps(payload, ensure_ascii=False).encode("utf-8"),
    headers={
        "Authorization": "Bearer " + os.environ["ANYAIGC_API_KEY"],
        "Content-Type": "application/json",
    },
    method="POST",
)
with urllib.request.urlopen(request, timeout=300) as response:
    result = json.load(response)

print(json.dumps(result, ensure_ascii=False, indent=2))

Speech 02

Spezifikationen und Auswahlhilfe

MiniMax beschreibt speech-02-hd so: Stärkere Replikationsähnlichkeit, hochwertige Stimmerzeugung.

Speech-02 unterstützt 32 Sprachen und nutzt Zero-Shot-Synthese mit einem lernbaren Speaker-Encoder. Speech-02-HD lag sowohl in der Artificial Analysis Speech Arena als auch in der Hugging Face TTS Arena auf Platz eins.

Jede Anfrage nimmt Text mit weniger als 10.000 Zeichen entgegen, Abtastraten von 8000 bis 44100 Hz und Ausgabe in mp3, pcm, flac, wav, opus und weiteren Formaten.

Diese Seite führt die Sprachsynthese mit $0.5559 / 10.000 Zeichen auf, dieselben Werte wie in der Preistabelle oben.

speech-02-turbo derselben Generation wird als „Überlegener Rhythmus und Stabilität, geringe Latenz“ positioniert. Wählen Sie es für Echtzeit- und latenzkritische Einsätze; bleiben Sie bei HD, wenn Stimmähnlichkeit und Audioqualität Vorrang haben.

Vergleichen Sie bei einem neuen Projekt zuerst speech-2.6-hd. Beide Generationen nutzen dieselbe API, ein Wechsel ändert also nur den Parameter model.

FAQ

Häufige Fragen zur MiniMax API

Preise, Endpunkte, Ergebnisse und Unternehmenszugang an einem Ort.

Was kostet die MiniMax Speech 02 HD API?

Sprachsynthese $0.5559/10.000 Zeichen. Alle Preise sind in USD; aktuelle Preise finden Sie im Modellkatalog.

Was ist der Unterschied zwischen speech-02-hd und speech-02-turbo?

MiniMax positioniert speech-02-hd als „Stronger replication similarity, high-quality voice generation“ und speech-02-turbo als „Superior rhythm and stability, low latency“. HD legt den Schwerpunkt auf Stimmähnlichkeit und Audioqualität, Turbo auf niedrige Latenz; beide nutzen dieselbe API und dieselben Parameter.

Welche Sprachen und Audioformate unterstützt speech-02-hd?

Speech-02 unterstützt 32 Sprachen und arbeitet mit Zero-Shot-Synthese über einen lernfähigen Sprecher-Encoder. Speech-02-HD belegte sowohl in der Artificial Analysis Speech Arena als auch in der Hugging Face TTS Arena den ersten Platz. Jede Anfrage nimmt weniger als 10.000 Zeichen Text entgegen, Abtastraten von 8000 bis 44100 Hz und gibt mp3, pcm, flac, wav, opus und weitere Formate aus.

Welchen API-Endpunkt soll ich verwenden?

Verwenden Sie POST /minimax/v1/t2a_v2; POST /minimax/v1/t2a_async_v2 unter https://anyaigc.ai und übergeben Sie Ihren API-Schlüssel über Authorization: Bearer.

Wie wähle ich eine Stimme aus, und kann das extra kosten?

Setzen Sie voice_setting.voice_id auf eine Stimme, die Ihrem Konto zur Verfügung steht. Laut Modellkatalog können für Stimmen außerhalb der Voreinstellungen separate Stimmgebühren anfallen; prüfen Sie die Kosten der gewählten Stimme.

Was liefert eine Anfrage zurück?

Das synchrone Beispiel liefert JSON; data.audio enthält je nach Anfrage und tatsächlicher Antwort Audiodaten oder eine URL. Der Modellkatalog nennt außerdem einen asynchronen Endpunkt. Für Aufgabenabfrage und Download gilt die aktuelle Dokumentation.

Gibt es Limits für Parallelität oder RPM?

AnyAIGC bietet für MiniMax unbegrenzte Parallelität ohne festes RPM-Limit. Die Generierung braucht trotzdem Zeit; konfigurieren Sie Timeouts, Fehlerbehandlung und geeignete Wiederholungen in Ihrer Anwendung.

Dürfen generierte Inhalte kommerziell genutzt werden?

Die kommerzielle Nutzung der Modelle und ihrer Ausgaben richtet sich nach den offiziellen Bedingungen von MiniMax. Stellen Sie sicher, dass Sie die nötigen Rechte an Referenzmaterial, Stimmen und generierten Inhalten haben. AnyAIGC ist ein unabhängiger API-Anbieter.

Kann ich bei AnyAIGC eine Rechnung bekommen?

Ja. Sie können Rechnungen in der Konsole selbst ausstellen, und zwar über den tatsächlich aufgeladenen Betrag.

Welche Zahlungsmethoden werden unterstützt?

Sie können Guthaben per WeChat Pay, Alipay, USDT oder Kreditkarte aufladen. Ihr Guthaben ist in USD und gilt für alle Modelle der Plattform. Rechnungen über den aufgeladenen Betrag können Sie in der Konsole ausstellen.

Gibt es kostenloses Testguthaben für neue Nutzer?

Ja. Neue Konten erhalten Testguthaben von 2 Millionen Tokens, damit Sie testen können, bevor Sie sich fürs Aufladen entscheiden. Aufladungen beginnen bei $1.

Kann ich mein Guthaben erstatten lassen?

Ja. Nicht genutztes Guthaben kann gebührenfrei erstattet werden. Wenden Sie sich an den Support, um eine Erstattung zu veranlassen.

Sind das die echten Modelle? Sind meine Daten sicher?

Anfragen laufen über offizielle Modellkanäle, nie über günstigere oder per Reverse Engineering nachgebaute Ersatzmodelle. Sofern das Gesetz es nicht verlangt, speichern wir Ihre Prompts und Ausgaben nicht dauerhaft und verwenden sie nicht für Training, und die Konsole zeigt Tokens und Kosten jeder Anfrage.
