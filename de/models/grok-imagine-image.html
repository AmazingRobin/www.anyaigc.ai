Was ist Grok Imagine Image

Grok Imagine Image (grok-imagine-image) ist das Bildmodell, das xAI Anfang 2026 mit der Grok Imagine API eingeführt hat. In der Dokumentation von xAI heißt es Version 1.0, der Snapshot-Name lautet grok-imagine-image-2026-03-02. Es erzeugt aus einer Textbeschreibung ein Bild, mit mehreren Seitenverhältnissen und Ausgabe in 1k / 2k.

Im August 2026 hat xAI Image 2.0 veröffentlicht, das bei Typografie und Bildbearbeitung stärker ist, bei AnyAIGC aber etwas mehr kostet (ab $0.0179 / Bild gegenüber $0.0119). Das Modell der ersten Generation ist nicht eingestellt, bestehende Integrationen laufen also weiter.

Bei AnyAIGC kostet es $0.0119 pro Bild; der Listenpreis von xAI beträgt $0.02 / Bild. Bei AnyAIGC nutzt dieses Modell den Endpunkt /v1/images/generations.

Was Grok Imagine Image kann

  • 01

    Text-zu-Bild

    Erzeugen Sie aus einem Satz ein Bild, in gängigen Stilen wie Fotorealismus, Illustration und Poster.

  • 02

    Mehrere Seitenverhältnisse

    Mit aspect_ratio wählen Sie 1:1, 16:9, 9:16, 3:2 und weitere Formate, passend für Titelbilder, Poster im Hochformat und Banner.

  • 03

    1k- / 2k-Ausgabe

    Wählen Sie mit resolution zwischen 1k und 2k. xAI berechnet beide zum selben Preis.

  • 04

    base64 oder URL

    Setzen Sie response_format auf b64_json, um rohe Bilddaten zu erhalten, oder auf url für einen temporären Link.

  • 05

    Kompatible Schnittstelle

    Das Anfrageformat entspricht /v1/images/generations von OpenAI. Bestehender Bildcode braucht daher nur ein neues model.

  • 06

    Einfaches Upgrade auf 2.0

    Wenn Sie Bildbearbeitung oder bessere Typografie brauchen, stellen Sie model auf grok-imagine-image-2.0 um, ab $0.0179 / Bild.

Erste Schritte mit der Grok Imagine Image API

  1. Bei AnyAIGC registrieren. Neue Konten erhalten 2 Mio. kostenlose Tokens, Guthaben aufladen können Sie ab $1.
  2. Erstellen Sie in der Konsole einen API-Schlüssel und speichern Sie ihn in der Umgebungsvariable ANYAIGC_API_KEY.
  3. Senden Sie eine Anfrage an POST https://anyaigc.ai/v1/images/generations und setzen Sie model auf grok-imagine-image.

Authentifizieren Sie sich mit Authorization: Bearer <API Key>. Die Antwort sieht so aus: {"created": ..., "data": [{"b64_json": ...}], "usage": {"generated_images": 1, ...}}. Wenn response_format auf url steht, erhalten Sie einen temporären Link, den Sie zeitnah herunterladen sollten. Feldreferenz in der AnyAIGC-Dokumentation: Create image.

FAQ zur Grok Imagine Image API

Was kostet die Grok Imagine Image API?

Bei AnyAIGC kostet Grok Imagine Image (grok-imagine-image) $0.0119 pro Bild, bei 1k und 2k gleich viel. Der Listenpreis von xAI beträgt $0.02 / Bild. Abgerechnet wird pro erfolgreicher Generierung; aktuelle Preise stehen im Modellkatalog.

Image 2.0, Image oder Quality: Welches Modell sollte ich nehmen?

Grok Imagine Image 2.0 (grok-imagine-image-2.0) ist das Modell, das xAI derzeit empfiehlt, mit besserer Typografie, besserer Prompt-Treue und besserer Bearbeitung. Bei AnyAIGC beginnt es bei $0.0179 / Bild; starten Sie neue Projekte daher damit. Grok Imagine Image (grok-imagine-image) ist das Imagine-Modell der ersten Generation für $0.0119 / Bild, der niedrigste Preis der Reihe, und eignet sich für einfaches Text-zu-Bild und bestehenden Code. Grok Imagine Image Quality wurde von xAI am 2. November 2026 eingestellt, und 2.0 mit niedriger Qualität verarbeitet Anfragen an dieses Modell jetzt.

Wird grok-imagine-image eingestellt?

Diese Änderung betrifft es nicht. Das Modell, das xAI am 2. Nov. 2026 eingestellt hat, ist grok-imagine-image-quality; grok-imagine-image ist weiterhin verfügbar. Wenn Sie Bildbearbeitung oder bessere Textdarstellung brauchen, bietet sich grok-imagine-image-2.0 an (ab $0.0179 / Bild).

Welche Seitenverhältnisse und Auflösungen werden unterstützt?

Setzen Sie aspect_ratio auf Werte wie 1:1, 16:9, 9:16, 3:2, 2:3, 4:3 oder 3:4 und resolution auf 1k oder 2k. Der Parameter quality wird nur von Image 2.0 unterstützt.

Kann es Bilder bearbeiten?

Bei AnyAIGC nutzt grok-imagine-image den Generierungs-Endpunkt /v1/images/generations. Um ein Bild hochzuladen und zu verändern, rufen Sie /v1/images/edits mit grok-imagine-image-2.0 auf.

Brauche ich ein xAI-Konto?

Nein, Sie brauchen kein xAI-Konto. Registrieren Sie sich bei AnyAIGC, um einen API-Schlüssel zu erhalten. Der Endpunkt ist https://anyaigc.ai, und derselbe Schlüssel funktioniert mit 300+ weiteren Modellen der Plattform.

Gibt es ein Parallelitätslimit?

AnyAIGC setzt für die Grok-Image-Modelle kein Parallelitätslimit. Das gilt standardmäßig für jedes Konto, sodass Batch-Jobs keine Kontingentanfrage brauchen.

Kann ich bei AnyAIGC eine Rechnung bekommen?

Ja. Sie können Rechnungen in der Konsole selbst ausstellen, und zwar über den tatsächlich aufgeladenen Betrag.

Welche Zahlungsmethoden werden unterstützt?

Sie können Guthaben per WeChat Pay, Alipay, USDT oder Kreditkarte aufladen. Ihr Guthaben ist in USD und gilt für alle Modelle der Plattform. Rechnungen über den aufgeladenen Betrag können Sie in der Konsole ausstellen.

Gibt es kostenloses Testguthaben für neue Nutzer?

Ja. Neue Konten erhalten Testguthaben von 2 Millionen Tokens, damit Sie testen können, bevor Sie sich fürs Aufladen entscheiden. Aufladungen beginnen bei $1.

Kann ich mein Guthaben erstatten lassen?

Ja. Nicht genutztes Guthaben kann gebührenfrei erstattet werden. Wenden Sie sich an den Support, um eine Erstattung zu veranlassen.

Sind das die echten Modelle? Sind meine Daten sicher?

Anfragen laufen über offizielle Modellkanäle, nie über günstigere oder per Reverse Engineering nachgebaute Ersatzmodelle. Sofern das Gesetz es nicht verlangt, speichern wir Ihre Prompts und Ausgaben nicht dauerhaft und verwenden sie nicht für Training, und die Konsole zeigt Tokens und Kosten jeder Anfrage.

Kann ich die Bilder kommerziell nutzen?

Nutzungsrechte und Inhaltsrichtlinien richten sich nach den offiziellen Bedingungen von xAI. AnyAIGC stellt nur den API-Zugang bereit und fügt keine zusätzlichen Einschränkungen dafür hinzu, was Sie mit den Ergebnissen tun.
