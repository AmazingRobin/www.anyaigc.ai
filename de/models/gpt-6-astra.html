Die oberste Stufe von GPT-6, abgerechnet zu rund 5 % des Listenpreises

OpenAI hat GPT-6 Astra am 3. September 2026 veröffentlicht und damit die GPT-6-Generation eröffnet. Auf seiner Modellseite wird es als „unser leistungsfähigstes Modell für die anspruchsvollsten Aufgaben“ beschrieben, und laut Ankündigung liegt Astra bei Computer Use, Web-Browsing, Softwareentwicklung, Cybersicherheit, Wissenschaft und professioneller Arbeit vorn. Im Modellkatalog von OpenAI heißt es unmissverständlich: Wenn Sie nicht wissen, wo Sie anfangen sollen, nehmen Sie GPT-6 Astra.

Der Listenpreis pro Token ist bei Astra fünfmal so hoch wie bei GPT-6.1 Sol, doch laut OpenAI lagen die geschätzten API-Kosten pro Aufgabe unter denen früherer Modelle. Astra unterstützt fünf Stufen für den Reasoning-Aufwand: low, medium, high, xhigh und max, eine Option none gibt es nicht. Es hat ein Kontextfenster von 1.050.000 Tokens, bis zu 128.000 Ausgabe-Tokens, nimmt Text und Bilder als Eingabe entgegen und gibt Text aus, der Wissensstichtag ist der 30. April 2026. OpenAI betreibt Astra außerdem mit Überwachung auf Fehlausrichtung: Pausiert eine Sicherheitsprüfung die Arbeit, wird die API-Aufgabe beendet.

Bei AnyAIGC funktioniert gpt-6-astra sowohl über /v1/chat/completions als auch über /v1/responses. Mit dem offiziellen OpenAI-SDK ändern Sie nur base_url auf https://anyaigc.ai/v1, und derselbe Schlüssel erreicht über 300 weitere Modelle, sodass sich leichtere Aufgaben ohne neues Konto auf GPT-6.1 Sol oder GPT-6 Luna verlagern lassen.

Die GPT-6 Astra API in drei Schritten aufrufen

  1. Registrieren und Guthaben aufladen: Erstellen Sie ein Konto unter anyaigc.ai. Ihr Guthaben gilt für alle Modelle der Plattform.
  2. API-Schlüssel erstellen: Erstellen Sie in der Konsole einen Token, kopieren Sie den Schlüssel mit dem Präfix sk- und speichern Sie ihn in der Umgebungsvariablen ANYAIGC_API_KEY.
  3. Anfrage senden: Rufen Sie https://anyaigc.ai/v1/chat/completions oder https://anyaigc.ai/v1/responses auf, setzen Sie model auf gpt-6-astra und authentifizieren Sie sich mit Authorization: Bearer.

Für Tool-Aufrufe empfehlen wir /v1/responses. Auf der Modellseite von OpenAI steht keine Einschränkung für Tool-Aufrufe von gpt-6-astra in Chat Completions, GPT-6.1 Sol aus derselben Generation unterstützt dort aber keine Tool-Aufrufe. Nutzen Sie /v1/chat/completions für einfachen Chat und Streaming und /v1/responses für Funktionsaufrufe, Computer Use, Websuche und weitere Tools, mit dem Aufwand in reasoning.effort. Astra ist teurer, daher halten low oder medium einfache Aufgaben günstiger.

Alle Parameter finden Sie in der Chat-Completions-Referenz und in der Responses-Referenz. Die Felder entsprechen der offiziellen OpenAI-API.

GPT-6 Astra in Codex nutzen

Ein Befehl installiert die Codex CLI und schreibt die AnyAIGC-Konfiguration. Sie können auch die beiden Dateien unter ~/.codex/ selbst bearbeiten.

Der Ein-Zeilen-Installer setzt das Modell auf gpt-5.5. Ändern Sie danach model in ~/.codex/config.toml auf gpt-6-astra. Speichern Sie beide Dateien und starten Sie codex in Ihrem Projektordner. Codex nutzt die Responses API, daher funktionieren Tool-Aufrufe normal. Lassen Sie model_reasoning_effort bei kleinen Änderungen auf medium und erhöhen Sie ihn bei schwierigen Problemen auf high oder xhigh. Alle Schritte und häufige Fehler finden Sie in der Codex-Einrichtungsanleitung.

Häufige Fragen zur GPT-6 Astra API

Was kostet die GPT-6 Astra API?

Bei AnyAIGC wird gpt-6-astra pro Token abgerechnet: $0.4964 pro 1 Mio. Eingabe-Tokens, $2.4810 pro 1 Mio. Ausgabe-Tokens und $0.0496 pro 1 Mio. zwischengespeicherte Eingabe-Tokens. Der Listenpreis von OpenAI beträgt $10.00 Eingabe, $50.00 Ausgabe und $1.00 zwischengespeicherte Eingabe, AnyAIGC liegt also bei rund 5 % des Listenpreises (95 % Rabatt). Hat eine Anfrage mehr als 272K Eingabe-Tokens, wird die gesamte Anfrage mit dem 2x-Satz für Eingabe und Cache und dem 1.5x-Satz für Ausgabe abgerechnet.

Wie lautet die Modell-ID von GPT-6 Astra?

Die Modell-ID ist gpt-6-astra. Tragen Sie sie in das Feld model Ihrer Anfrage ein. OpenAI hat dafür keinen datierten Snapshot veröffentlicht.

GPT-6 Astra oder GPT-6.1 Sol: Welches Modell soll ich nehmen?

Laut OpenAI kommt GPT-6.1 Sol bei agentischem Coding, Computer Use und professioneller Arbeit nahe an GPT-6 Astra heran, zu einem Fünftel des Astra-Standardpreises. In den Ergebnissen von OpenAI liegt Astra bei Terminal-Bench Science weiterhin vorn (68.1 % gegenüber 57.0 %), bei rund $23.80 pro Aufgabe gegenüber $5.47 für GPT-6.1 Sol (jeweils zum Listenpreis). Beginnen Sie für alltägliches Coding und Agentenarbeit mit GPT-6.1 Sol und nutzen Sie GPT-6 Astra für das anspruchsvollste Reasoning, Recherche und lange Aufgaben von Anfang bis Ende. Bei AnyAIGC kostet GPT-6 Astra $0.4964 Eingabe und $2.4810 Ausgabe, GPT-6.1 Sol $0.0993 Eingabe und $0.4964 Ausgabe pro 1 Mio. Tokens.

Warum gibt es kein GPT-6.1 Astra?

Stand heute hat OpenAI kein GPT-6.1 Astra veröffentlicht. GPT-6.1 hat bisher die Stufen Sol und Terra aktualisiert. Die aktuelle GPT-6-API-Reihe von OpenAI besteht aus gpt-6-astra, gpt-6.1-sol, gpt-6.1-terra und gpt-6-luna, die Stufe Astra ist also weiterhin gpt-6-astra. Im Modellkatalog von OpenAI heißt es: Wenn Sie nicht wissen, wo Sie anfangen sollen, nehmen Sie GPT-6 Astra.

Chat Completions oder Responses API? Kann ich Tools verwenden?

Beide Endpunkte funktionieren. Für einfachen Chat und Streaming nutzen Sie https://anyaigc.ai/v1/chat/completions. Auf der Modellseite von OpenAI steht keine Einschränkung für Tool-Aufrufe von gpt-6-astra in Chat Completions, GPT-6.1 Sol aus derselben Generation unterstützt dort aber keine Tool-Aufrufe. Wir empfehlen daher https://anyaigc.ai/v1/responses für Funktionsaufrufe und integrierte Tools, mit dem Aufwand in reasoning.effort.

Kann ich GPT-6 Astra in Codex nutzen?

Ja. Führen Sie curl -fsSL https://www.anyaigc.ai/install.sh | bash -s codex aus, um Codex zu installieren und einzurichten (unter Windows: irm https://www.anyaigc.ai/install.ps1 | iex). Der Installer verwendet standardmäßig gpt-5.5, ändern Sie danach model in ~/.codex/config.toml auf gpt-6-astra. Sie können ~/.codex/config.toml auch selbst bearbeiten: Setzen Sie base_url auf https://anyaigc.ai/v1, wire_api auf responses und model auf gpt-6-astra und tragen Sie dann OPENAI_API_KEY in ~/.codex/auth.json ein.

Gibt es Limits für Parallelität oder Ratenlimits?

AnyAIGC setzt für gpt-6-astra kein Limit für die Parallelität. Das gilt standardmäßig für jedes Konto, sodass Batch-Jobs und parallele Agenten ohne Warteschlange laufen.

Wie bekomme ich einen API-Schlüssel für GPT-6 Astra?

Registrieren Sie sich bei anyaigc.ai, laden Sie Guthaben auf und legen Sie in der Konsole einen Token an. Derselbe Schlüssel funktioniert für GPT-6 Astra und über 300 weitere Modelle. Beim offiziellen OpenAI-SDK setzen Sie einfach base_url auf https://anyaigc.ai/v1.

Kann ich bei AnyAIGC eine Rechnung bekommen?

Ja. Sie können Rechnungen in der Konsole selbst ausstellen, und zwar über den tatsächlich aufgeladenen Betrag.

Welche Zahlungsmethoden werden unterstützt?

Sie können Guthaben per WeChat Pay, Alipay, USDT oder Kreditkarte aufladen. Ihr Guthaben ist in USD und gilt für alle Modelle der Plattform. Rechnungen über den aufgeladenen Betrag können Sie in der Konsole ausstellen.

Gibt es kostenloses Testguthaben für neue Nutzer?

Ja. Neue Konten erhalten Testguthaben von 2 Millionen Tokens, damit Sie testen können, bevor Sie sich fürs Aufladen entscheiden. Aufladungen beginnen bei $1.

Kann ich mein Guthaben erstatten lassen?

Ja. Nicht genutztes Guthaben kann gebührenfrei erstattet werden. Wenden Sie sich an den Support, um eine Erstattung zu veranlassen.

Sind das die echten Modelle? Sind meine Daten sicher?
