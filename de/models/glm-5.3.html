Über das Modell

Gleiches Basismodell, deutlich stärkeres Post-Training

Zhipu nennt GLM-5.3 sein aktuelles Flaggschiff, mit durchgängigen Verbesserungen bei komplexer Softwareentwicklung und Agent-Aufgaben. Laut Zhipu nutzt es dasselbe Basismodell wie GLM-5.2, und alle Verbesserungen stammen aus einem ausgebauten Post-Training, das auf dem mit GLM-5.2 eingeführten Reinforcement-Learning-Ansatz aufbaut.

Die berichteten Verbesserungen betreffen vor allem Coding und Agenten: Zhipus interner Z.ai Code Bench liegt 50 % über GLM-5.2, bei weniger Ausgabe-Tokens für dieselben Aufgaben, und Terminal Bench 3.0 stieg von 4.6 auf 28.3. Zhipu berichtet außerdem Spitzenergebnisse im CyberGym-Benchmark für Schwachstellen. Es hat ein Kontextfenster von 1M Tokens, bis zu 128K Ausgabe, und der Denkmodus ist immer aktiv.

Bei AnyAIGC läuft glm-5.3 über den OpenAI-kompatiblen Endpunkt /v1/chat/completions und funktioniert direkt in Claude Code. Sie brauchen weder ein Zhipu-Plattformkonto noch einen Coding Plan: Sie zahlen pro Token, bei unbegrenzter Parallelität.

Schnellstart

GLM-5.3 API in drei Schritten anbinden

  1. Registrieren und Guthaben aufladen: Erstellen Sie ein Konto unter anyaigc.ai. Aufladen ab $1; Ihr Guthaben gilt für alle Modelle der Plattform.
  2. API-Schlüssel erstellen: Erstellen Sie in der Konsole einen Schlüssel, kopieren Sie den Wert, der mit sk- beginnt, und speichern Sie ihn in der Umgebungsvariable ANYAIGC_API_KEY.
  3. Anfrage senden: Rufen Sie POST https://anyaigc.ai/v1/chat/completions auf, setzen Sie model auf glm-5.3 und senden Sie einen Authorization: Bearer-Header. Beim OpenAI-SDK setzen Sie einfach base_url auf https://anyaigc.ai/v1.

Tipp: GLM-5.3 denkt immer. Das Reasoning kommt im Feld reasoning_content zurück, und reasoning_effort legt die Tiefe fest. Die Standardwerte von Zhipu sind temperature=1.0 und top_p=0.95; wenn Sie sie anpassen, ändern Sie nur einen davon. Senden Sie bei mehrstufigen Chats und Tool-Aufrufen die vollständige Assistant-Nachricht der API (einschließlich reasoning_content und tool_calls) in der nächsten Anfrage unverändert zurück.

Alle Parameter finden Sie in der Chat-Completions-Referenz. Ersetzen Sie in den Beispielen der Dokumentation den Modellnamen durch die gewünschte GLM-Modell-ID.

Claude Code

GLM-5.3 in Claude Code nutzen

Stellen Sie Claude Code mit einer einzigen Konfigurationsdatei auf GLM-5.3 um und programmieren Sie im Terminal mit dem neuesten Flaggschiff von Zhipu, abgerechnet pro Token.

  1. Claude Code installieren: Verwenden Sie das offizielle Installationsprogramm, unter macOS oder Linux zum Beispiel curl -fsSL https://claude.ai/install.sh | bash.
  2. Konfiguration hinzufügen: Bearbeiten Sie ~/.claude/settings.json, fügen Sie den folgenden env-Block ein und ersetzen Sie ANTHROPIC_AUTH_TOKEN durch den Schlüssel, den Sie bei AnyAIGC erstellt haben.
  3. Loslegen: Führen Sie claude in Ihrem Projektordner aus. Geben Sie /model ein, um zu prüfen, ob das aktuelle Modell glm-5.3 ist.

Bei leichten Aufgaben sparen: Die Konfiguration setzt ANTHROPIC_DEFAULT_HAIKU_MODEL auf glm-5.3-flash, sodass die leichten Teilaufgaben von Claude Code das günstigere Modell nutzen, während die Hauptarbeit bei GLM-5.3 bleibt.

Die vollständige Anleitung und häufige Fehler finden Sie in der Einrichtungsanleitung für Claude Code. Ersetzen Sie in der Anleitung den Modellnamen durch glm-5.3.

SPEZIFIKATIONEN

Spezifikationen und Auswahlhilfe

Laut der Dokumentation von Z.ai ist GLM-5.3 das neueste Flaggschiffmodell; es nutzt dasselbe Basismodell wie GLM-5.2, alle Verbesserungen stammen aus dem Post-Training.

Der Hersteller gibt an, dass es auf Z.ai Code Bench 50 % besser abschneidet als GLM-5.2 und auf öffentlichen Benchmarks wie Terminal Bench 3.0 unter den Open-Source-Modellen Spitzenleistung (State of the Art) erreicht.

Es nimmt derzeit nur Texteingaben an, mit einem Kontextfenster von 1M Tokens und maximal 128K Tokens Ausgabe; Reasoning ist immer aktiv, mit den Stufen low, high und max (Standard max), und das Abschalten von Reasoning wird nicht mehr unterstützt.

Diese Seite nennt Eingabe $0.9450, Ausgabe $2.9700 und Cache-Treffer $0.1758, passend zur Preistabelle oben.

Im Vergleich zu glm-5.2: Laut offizieller Dokumentation lässt sich Reasoning bei GLM-5.3 nicht abschalten. Eine Anfrage, die thinking.type auf disabled setzt, muss daher vor dem Modellwechsel auf enabled geändert werden, sonst schlägt sie fehl.

Die Spezifikationen stammen aus der offiziellen Dokumentation des Herstellers (docs.z.ai). Die Tabelle auf dieser Seite zeigt den Preis; maßgeblich für aktuelle Preise ist der Modellkatalog.

FAQ

GLM-5.3 API: häufige Fragen

Was kostet die GLM-5.3 API?

Bei AnyAIGC wird glm-5.3 pro Token abgerechnet: Eingabe $0.9450 pro 1 Mio. Tokens, Ausgabe $2.9700 pro 1 Mio. Tokens, Cache-Treffer $0.1758 pro 1 Mio. Tokens. Die offiziellen USD-Preise von Zhipu betragen für Eingabe $1.40, für Ausgabe $4.40 und für Cache-Treffer $0.26. Eingabe und Ausgabe kosten bei AnyAIGC also rund 67.5 % des offiziellen Preises (rund 30 % Rabatt). Die Ausgabe schließt Denk-Tokens ein. Aktuelle Preise finden Sie im Modellkatalog.

Wie lautet die Modell-ID von GLM-5.3, und wie groß ist der Kontext?

Die Modell-ID lautet glm-5.3. Zhipu nennt ein Kontextfenster von 1M Tokens und bis zu 128K Ausgabe-Tokens. Es akzeptiert derzeit nur Texteingaben.

Worin unterscheidet sich GLM-5.3 von GLM-5.2?

Laut Zhipu nutzt GLM-5.3 dasselbe Basismodell wie GLM-5.2, und alle Verbesserungen stammen aus hochskaliertem Post-Training. Gemeldete Änderungen: Z.ai Code Bench liegt 50 % über GLM-5.2, Terminal Bench 3.0 stieg von 4.6 auf 28.3 und DeepSWE von 46.2 auf 66.9. GLM-5.3 denkt außerdem immer, der Denkmodus lässt sich nicht abschalten. Bei AnyAIGC kosten beide für Eingabe und Ausgabe gleich viel, und GLM-5.3 hat den niedrigeren Cache-Treffer-Preis ($0.1758 gegenüber $0.2362).

Wie passe ich die Denktiefe von GLM-5.3 an? Kann ich den Denkmodus abschalten?

GLM-5.3 denkt immer, und Zhipu unterstützt kein Abschalten. Legen Sie die Tiefe mit dem Feld reasoning_effort im Anfrage-Body fest: low, high oder max (Standard max, das Zhipu für Coding empfiehlt). Verwenden Sie low bei einfachen Aufgaben, um Ausgabe-Tokens zu sparen.

Unterstützt GLM-5.3 Tool-Aufrufe und strukturierte Ausgabe?

Ja. Die Dokumentation von Zhipu nennt Funktionsaufrufe, strukturierte Ausgabe (JSON), Streaming und Context Caching. Senden Sie bei mehrstufigen Chats und Tool-Aufrufen die vollständige Assistant-Nachricht (einschließlich reasoning_content und tool_calls) in der nächsten Anfrage unverändert zurück.

Kann ich GLM-5.3 in Claude Code nutzen?

Ja. Setzen Sie im Block env von ~/.claude/settings.json den Wert ANTHROPIC_BASE_URL auf https://anyaigc.ai, ANTHROPIC_AUTH_TOKEN auf Ihren API-Schlüssel und ANTHROPIC_MODEL auf glm-5.3. Starten Sie dann claude. Sie zahlen pro Token, ohne ein 5-Stunden-Kontingentfenster wie bei einem Abo-Tarif.

Ist GLM-5.3 Open Source?

Ja. Zhipu hat die Gewichte von GLM-5.3 auf Hugging Face (zai-org/GLM-5.3) unter der GLM-5.3 License veröffentlicht. Insgesamt ist es eine freizügige Lizenz, mit einer zusätzlichen Regel: Unternehmen mit mehr als $10 Mrd. Jahresumsatz, die Model-as-a-Service-Geschäfte betreiben, müssen vor der kommerziellen Nutzung eine Sicherheitsprüfung von Z.ai bestehen. Wenn Sie die API über AnyAIGC aufrufen, müssen Sie das Modell nicht selbst hosten. Die kommerzielle Nutzung richtet sich nach den offiziellen Bedingungen von Zhipu AI.

Gibt es Limits für Parallelität oder Ratenlimits?

AnyAIGC begrenzt die Parallelität für glm-5.3 nicht, und jeder Nutzer erhält das standardmäßig. Das passt zu Batch-Jobs, CI-Pipelines und parallelen Agenten. Die Abrechnung erfolgt pro Token, es gibt also kein Kontingent, das sich wie bei einem Abo-Tarif nach einem Zeitfenster zurücksetzt.

Wie bekomme ich einen GLM-5.3 API-Schlüssel?

Registrieren Sie sich auf anyaigc.ai, laden Sie Guthaben auf und erstellen Sie in der Konsole einen Schlüssel. Derselbe Schlüssel funktioniert für alle GLM-Modelle und für 300+ weitere Modelle auf der Plattform. Sie brauchen also weder ein separates Zhipu-Plattformkonto noch einen GLM Coding Plan.

Kann ich bei AnyAIGC eine Rechnung bekommen?

Ja. Sie können Rechnungen in der Konsole selbst ausstellen, und zwar über den tatsächlich aufgeladenen Betrag.

Welche Zahlungsmethoden werden unterstützt?

Sie können Guthaben per WeChat Pay, Alipay, USDT oder Kreditkarte aufladen. Ihr Guthaben ist in USD und gilt für alle Modelle der Plattform. Rechnungen über den aufgeladenen Betrag können Sie in der Konsole ausstellen.

Gibt es kostenloses Testguthaben für neue Nutzer?

Ja. Neue Konten erhalten Testguthaben von 2 Millionen Tokens, damit Sie testen können, bevor Sie sich fürs Aufladen entscheiden. Aufladungen beginnen bei $1.

Kann ich mein Guthaben erstatten lassen?

Ja. Nicht genutztes Guthaben kann gebührenfrei erstattet werden. Wenden Sie sich an den Support, um eine Erstattung zu veranlassen.

Sind das die echten Modelle? Sind meine Daten sicher?

Anfragen laufen über offizielle Modellkanäle, nie über günstigere oder per Reverse Engineering nachgebaute Ersatzmodelle. Sofern das Gesetz es nicht verlangt, speichern wir Ihre Prompts und Ausgaben nicht dauerhaft und verwenden sie nicht für Training, und die Konsole zeigt Tokens und Kosten jeder Anfrage.

Werden meine Daten zum Training verwendet?

Nein. Außer wenn das Gesetz es verlangt, speichert AnyAIGC Ihre Prompts und Ausgaben nicht dauerhaft und nutzt sie nicht zum Training von Modellen. Anfragen werden per HTTPS verschlüsselt. Siehe die Datenschutzerklärung von AnyAIGC. Die Datenrichtlinie des Modells selbst richtet sich nach den offiziellen Bedingungen von Zhipu AI.
