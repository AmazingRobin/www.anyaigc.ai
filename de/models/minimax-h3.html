cURL
curl --request POST "https://anyaigc.ai/minimax/v2/video_generation" \
  --header "Authorization: Bearer $ANYAIGC_API_KEY" \
  --header "Content-Type: application/json" \
  --data '{
  "content": [
    {
      "text": "A sunset over the sea, with the camera slowly pushing forward.",
      "type": "text"
    }
  ],
  "duration": 5,
  "model": "MiniMax-H3",
  "ratio": "16:9",
  "resolution": "768P"
}'
Python
import json
import os
import urllib.request

payload = {
    "content": [
        {
            "text": "A sunset over the sea, with the camera slowly pushing forward.",
            "type": "text"
        }
    ],
    "duration": 5,
    "model": "MiniMax-H3",
    "ratio": "16:9",
    "resolution": "768P"
}

request = urllib.request.Request(
    "https://anyaigc.ai/minimax/v2/video_generation",
    data=json.dumps(payload, ensure_ascii=False).encode("utf-8"),
    headers={
        "Authorization": "Bearer " + os.environ["ANYAIGC_API_KEY"],
        "Content-Type": "application/json",
    },
    method="POST",
)
with urllib.request.urlopen(request, timeout=120) as response:
    result = json.load(response)

print(json.dumps(result, ensure_ascii=False, indent=2))

SPEZIFIKATIONEN

Spezifikationen und Auswahlhilfe

Laut der Dokumentation von MiniMax ist MiniMax-H3 ein offenes, universelles multimodales Videomodell, das Text-, Bild-, Video- und Audioeingaben einheitlich versteht und Videogenerierung, referenzbasierte Erstellung und Videobearbeitung unterstützt.

Die offizielle Ausgabespezifikation lautet 768P und 2K bei einer Dauer von 4 bis 15 Sekunden, nur ganzzahlige Werte; gängige Seitenverhältnisse oder adaptive werden unterstützt.

Anfragen verwenden eine multimodale Struktur content[], in der jedes Element über type unterschieden wird; Referenzbilder und -videos werden über das Feld role gekennzeichnet.

Laut Dokumentation setzt die Nutzung von MiniMax-H3 die API mit Abrechnung nach Verbrauch voraus.

Diese Seite führt 768P-Ausgabevideo mit $0.0750 / Sekunde, 768P-Eingabevideo mit $0.0750 / Sekunde, 2K-Ausgabevideo mit $0.1219 / Sekunde und 2K-Eingabevideo mit $0.1219 / Sekunde auf, passend zur Preistabelle oben.

Die Spezifikationen stammen aus der offiziellen Dokumentation des Anbieters (platform.minimax.io). Die Tabelle auf dieser Seite enthält die Preise, für aktuelle Preise ist der Modellkatalog maßgeblich.

FAQ

Häufige Fragen zur MiniMax API

Preise, Endpunkte, Ergebnisse und Unternehmenszugang an einem Ort.

Was kostet die MiniMax H3 API?

768P Ausgabevideo $0.0750/Sekunde; 768P Eingabevideo $0.0750/Sekunde; 2K Ausgabevideo $0.1219/Sekunde; 2K Eingabevideo $0.1219/Sekunde; Video-Neugenerierung $0.0450/Sekunde; Referenzbilder (die ersten 5) $0/Bild; Referenzbilder (ab dem 6.) $0.0375/Bild. Alle Preise in USD; aktuelle Preise finden Sie im Modellkatalog.

Welchen API-Endpunkt soll ich verwenden?

Verwenden Sie POST /minimax/v2/video_generation auf https://anyaigc.ai und übergeben Sie Ihren API-Schlüssel über Authorization: Bearer.

Welche Dauern, Auflösungen und Referenzen unterstützt H3?

MiniMax-H3 unterstützt 4–15 Sekunden in 768P oder 2K. Das Array content muss genau ein nicht leeres Text-Element enthalten. Nutzen Sie erstes/letztes Frame oder Referenzbild, -video und -audio; mischen Sie diese Modi nicht. Reine Textgenerierung erfordert ratio.

Was liefert eine Anfrage zurück?

Eine asynchrone Aufgabe erzeugt ein Video von 4–15 Sekunden Länge.

Gibt es Limits für Parallelität oder RPM?

AnyAIGC bietet für MiniMax unbegrenzte Parallelität ohne festes RPM-Limit. Die Generierung braucht trotzdem Zeit; konfigurieren Sie Timeouts, Fehlerbehandlung und geeignete Wiederholungen in Ihrer Anwendung.

Dürfen generierte Inhalte kommerziell genutzt werden?

Die kommerzielle Nutzung der Modelle und ihrer Ausgaben richtet sich nach den offiziellen Bedingungen von MiniMax. Stellen Sie sicher, dass Sie die nötigen Rechte an Referenzmaterial, Stimmen und generierten Inhalten haben. AnyAIGC ist ein unabhängiger API-Anbieter.

Kann ich bei AnyAIGC eine Rechnung bekommen?

Ja. Sie können Rechnungen in der Konsole selbst ausstellen, und zwar über den tatsächlich aufgeladenen Betrag.

Welche Zahlungsmethoden werden unterstützt?

Sie können Guthaben per WeChat Pay, Alipay, USDT oder Kreditkarte aufladen. Ihr Guthaben ist in USD und gilt für alle Modelle der Plattform. Rechnungen über den aufgeladenen Betrag können Sie in der Konsole ausstellen.

Gibt es kostenloses Testguthaben für neue Nutzer?

Ja. Neue Konten erhalten Testguthaben von 2 Millionen Tokens, damit Sie testen können, bevor Sie sich fürs Aufladen entscheiden. Aufladungen beginnen bei $1.

Kann ich mein Guthaben erstatten lassen?

Ja. Nicht genutztes Guthaben kann gebührenfrei erstattet werden. Wenden Sie sich an den Support, um eine Erstattung zu veranlassen.

Sind das die echten Modelle? Sind meine Daten sicher?

Anfragen laufen über offizielle Modellkanäle, nie über günstigere oder per Reverse Engineering nachgebaute Ersatzmodelle. Sofern das Gesetz es nicht verlangt, speichern wir Ihre Prompts und Ausgaben nicht dauerhaft und verwenden sie nicht für Training, und die Konsole zeigt Tokens und Kosten jeder Anfrage.
