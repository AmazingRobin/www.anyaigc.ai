Schnellstart

Mit Chat Completions starten

  1. Erstellen Sie in der Konsole ein Konto und einen API-Schlüssel.
  2. Setzen Sie die Base URL auf https://anyaigc.ai/v1.
  3. Setzen Sie das Modell und senden Sie Ihre Nachrichten.
cURL · POST /v1/chat/completions
curl https://anyaigc.ai/v1/chat/completions \
  -H "Authorization: Bearer $ANYAIGC_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"qwen3.8-flash","messages":[{"role":"user","content":"Explain what a MoE model is in three sentences."}]}'
Python · OpenAI SDK
from openai import OpenAI
import os
client = OpenAI(api_key=os.environ["ANYAIGC_API_KEY"], base_url="https://anyaigc.ai/v1")
response = client.chat.completions.create(model="qwen3.8-flash", messages=[{"role":"user","content":"Explain what a MoE model is in three sentences."}])
print(response.choices[0].message.content)

FAQ

Qwen API: Häufige Fragen

Welchen Endpunkt nutzt Qwen?

Dialogmodelle nutzen POST https://anyaigc.ai/v1/chat/completions. Senden Sie model und messages mit Authorization: Bearer <API Key>.

Was kostet die Qwen API?

Qwen-Dialogmodelle werden für Eingabe- und Ausgabe-Tokens getrennt abgerechnet, in USD pro 1 Mio. Tokens. Die Eingabe reicht von $0,0338 (qwen-flash) bis $1,6875 (qwen3.7-max), die Ausgabe von $0,2700 (qwen-flash) bis $5,0625 (qwen3.7-max). Den Preis des jeweiligen Modells finden Sie in der Preistabelle oben, für aktuelle Preise gilt der Modellkatalog.

Gibt es ein Parallelitätslimit?

Für die Qwen-Dialogmodelle auf dieser Seite gibt es kein Parallelitätslimit; sie stehen allen Nutzern zur Verfügung.

Wie erhalte ich einen API-Schlüssel?

Erstellen Sie ein AnyAIGC-Konto und legen Sie dann in der Konsole einen API-Schlüssel an. Ein Schlüssel gilt für 300+ Modelle.

Werden Bilder und Tool-Aufrufe unterstützt?

Das hängt vom Modell ab. Prüfen Sie die Tags im aktuellen Modellkatalog; der Endpunkt bleibt derselbe.

Kann ich bei AnyAIGC eine Rechnung bekommen?

Ja. Sie können Rechnungen in der Konsole selbst ausstellen, und zwar über den tatsächlich aufgeladenen Betrag.

Welche Zahlungsmethoden werden unterstützt?

Sie können Guthaben per WeChat Pay, Alipay, USDT oder Kreditkarte aufladen. Ihr Guthaben ist in USD und gilt für alle Modelle der Plattform. Rechnungen über den aufgeladenen Betrag können Sie in der Konsole ausstellen.

Gibt es kostenloses Testguthaben für neue Nutzer?

Ja. Neue Konten erhalten ein Testguthaben von 2 Mio. Tokens.

Kann ich mein Guthaben erstatten lassen?

Ja. Nicht genutztes Guthaben kann gebührenfrei erstattet werden.

Sind das offizielle Modelle, und sind meine Daten sicher?

Anfragen laufen über offizielle Modellkanäle. Prompts und Ausgaben werden weder dauerhaft gespeichert noch für Training verwendet, sofern das Gesetz es nicht verlangt.
