SPEZIFIKATIONEN

Spezifikationen und Auswahlhilfe

Videobasierte Motive erfordern einen MP4- oder MOV-Clip von 3 bis 8 Sekunden in 1080P im Format 16:9 oder 9:16.

Pro Motiv kann nur ein Video mit bis zu 200MB hochgeladen werden.

Die videobasierte Anpassung unterstützt derzeit nur realistische menschliche Figuren.

Aus Video erstellte Motive lassen sich nur mit kling-video-o3 und neueren Modellen verwenden.

Diese Seite führt Custom Elements mit $0,00169/Aufruf auf, passend zur Preistabelle oben.

Im Vergleich zu kling-custom-elements: Erweiterte Motive entstehen aus einem 3 bis 8 Sekunden langen Video einer realistischen Person, Standardmotive dagegen aus Bildern.

Die Spezifikationen stammen aus der offiziellen Dokumentation des Herstellers (klingai.com). Die Tabelle auf dieser Seite zeigt den Preis; maßgeblich für aktuelle Preise ist der Modellkatalog.

FAQ

Was kostet die Kling Advanced Custom Elements API?

Kling Advanced Custom Elements kostet auf AnyAIGC ab $0,00169 / Aufruf. Abgerechnet wird in der im Modellkatalog angezeigten Einheit; aktuelle Preise finden Sie dort.

Was kann Kling Advanced Custom Elements?

Erstellen Sie Motive mit dem erweiterten Kling-Dienst, der Quellclips von 3–8 Sekunden unterstützt.

Ist die API asynchron?

Ja. Senden Sie eine Aufgabe an /kling/v1/general/custom-elements, erhalten Sie eine Aufgaben-ID und rufen Sie das Ergebnis über den dokumentierten Abfrage-Endpunkt per Polling ab.

Ist die Parallelität begrenzt?

Kling-Modelle auf AnyAIGC haben standardmäßig unbegrenzte Parallelität.

Wie funktioniert die Authentifizierung?

Senden Sie Authorization: Bearer <API Key>; lesen Sie den Schlüssel aus der Umgebungsvariable ANYAIGC_API_KEY.

Dürfen generierte Inhalte kommerziell genutzt werden?

Nutzungsrechte und Inhaltsrichtlinien richten sich nach den offiziellen Bedingungen von Kling.

Kann ich bei AnyAIGC eine Rechnung bekommen?

Ja. Sie können Rechnungen in der Konsole selbst ausstellen, und zwar über den tatsächlich aufgeladenen Betrag.

Welche Zahlungsmethoden werden unterstützt?

Sie können Guthaben per WeChat Pay, Alipay, USDT oder Kreditkarte aufladen. Ihr Guthaben ist in USD und gilt für alle Modelle der Plattform. Rechnungen über den aufgeladenen Betrag können Sie in der Konsole ausstellen.

Gibt es Testguthaben für neue Nutzer?

Neue Nutzer erhalten nach der Registrierung ein Testguthaben von 2 Mio. Tokens.

Kann ungenutztes Guthaben erstattet werden?

Ungenutztes Guthaben kann über den Support erstattet werden.

Wofür eignet sich Kling Advanced Custom Elements am besten?

Kling Advanced Custom Elements ist für die Erstellung von Motiven gedacht. Lesen Sie die Abschnitte zu Funktionen und Anwendungsfällen auf dieser Seite, bevor Sie einen Workflow wählen.

Wo kann ich Kling Advanced Custom Elements mit anderen Kling-Modellen vergleichen?

Im Abschnitt zur Kling-Modellfamilie auf dieser Seite vergleichen Sie verwandte Tools für Generierung, Steuerung, Audio und Assets.

Wie setze ich den Endpunkt um?

Nutzen Sie die endpunktspezifische API-Dokumentation. Gehen Sie nicht davon aus, dass jeder Kling-Endpunkt einen generischen Prompt-Payload akzeptiert.
