Über das Modell

Das erste K3.1-Modell, mit deutlich mehr Post-Training

Laut Moonshot AI ist Kimi K3.1 Pro das erste Modell der neuen K3.1-Reihe und bisher sein stärkstes Modell der 3T-Klasse mit offenen Gewichten. Moonshot beschreibt es als nachtrainierte Version von Kimi K3, entstanden mit deutlich mehr Rechenleistung für das Post-Training und mit gemeinsamem Reinforcement Learning über Hunderte nachgelagerter Domänen.

Moonshot berichtet Verbesserungen in vier Bereichen: Coding über lange Zeiträume (Unterstützung für Unity, Unreal Engine und Godot sowie vollständigere Layouts, Typografie und Animationen in Frontend- und Three.js-Arbeiten), 3D-Erstellung (Blender- und CAD-Skripte für parametrische Modellierung), Finanzrecherche (64,4 bei OfficeQA Pro v2) und eine geringere Halluzinationsrate. Es hat einen Kontext von 1.048.576 Tokens, Thinking ist immer aktiv, und es akzeptiert Text-, Bild- und Videoeingaben.

Bei AnyAIGC läuft kimi-k3.1-pro auf dem OpenAI-kompatiblen Endpunkt /v1/chat/completions mit denselben Parameterbeschränkungen wie K3, sodass für die Migration von K3 nur der Modellname geändert werden muss. Es funktioniert außerdem direkt in Claude Code, mit unbegrenzter Parallelität.

Schnellstart

Kimi K3.1 Pro API in drei Schritten anbinden

  1. Registrieren und Guthaben aufladen: Erstellen Sie ein Konto unter anyaigc.ai. Aufladen ab $1; Ihr Guthaben gilt für alle Modelle der Plattform.
  2. API-Schlüssel erstellen: Erstellen Sie in der Konsole einen Schlüssel, kopieren Sie den Wert, der mit sk- beginnt, und speichern Sie ihn in der Umgebungsvariable ANYAIGC_API_KEY.
  3. Anfrage senden: Rufen Sie POST https://anyaigc.ai/v1/chat/completions auf, setzen Sie model auf kimi-k3.1-pro und senden Sie einen Authorization: Bearer-Header mit. Beim OpenAI SDK setzen Sie einfach base_url auf https://anyaigc.ai/v1.

Tipp: K3.1 Pro denkt immer, und das Reasoning kommt in reasoning_content zurück. Sampling-Parameter wie temperature und top_p legt Moonshot fest, senden Sie sie daher nicht mit. Senden Sie bei mehrstufigen Chats und Tool-Aufrufen die vollständige Assistant-Nachricht der API (einschließlich reasoning_content und tool_calls) in der nächsten Anfrage unverändert zurück.

Alle Parameter finden Sie in der Chat-Completions-Referenz. Ersetzen Sie den Modellnamen in den Beispielen der Dokumentation durch die gewünschte Kimi-Modell-ID.

Claude Code

Kimi K3.1 Pro in Claude Code nutzen

Stellen Sie Claude Code auf Kimi K3.1 Pro um: Kontextfenster mit 1M, und Moonshot hat die meisten seiner Coding-Benchmarks mit Claude Code als Harness ausgeführt.

  1. Claude Code installieren: Verwenden Sie das offizielle Installationsprogramm (zum Beispiel npm install -g @anthropic-ai/claude-code).
  2. Konfiguration hinzufügen: Bearbeiten Sie ~/.claude/settings.json, fügen Sie den folgenden env-Block ein und ersetzen Sie ANTHROPIC_AUTH_TOKEN durch den Schlüssel, den Sie bei AnyAIGC erstellt haben.
  3. Loslegen: Führen Sie claude in Ihrem Projektordner aus. Geben Sie /model ein, um zu prüfen, dass das aktuelle Modell kimi-k3.1-pro ist.

Bei Nebenaufgaben sparen: Setzen Sie ANTHROPIC_DEFAULT_HAIKU_MODEL auf kimi-k2.7-code, damit die leichten Teilaufgaben von Claude Code das günstigere Modell nutzen, während die Hauptaufgabe auf K3.1 Pro bleibt.

Die ausführliche Anleitung und häufige Fehler finden Sie in der Einrichtungsanleitung für Claude Code. Ersetzen Sie darin den Modellnamen durch kimi-k3.1-pro.

FAQ

Häufige Fragen zur Kimi K3.1 Pro API

Was kostet die Kimi K3.1 Pro API?

Bei AnyAIGC wird kimi-k3.1-pro pro Token abgerechnet: Eingabe $0,8100 pro 1 Mio. Tokens, Ausgabe $4,0500 pro 1 Mio. Tokens, Cache-Treffer $0,0810 pro 1 Mio. Tokens. Die offiziellen USD-Preise von Moonshot sind Eingabe $2,00, Ausgabe $10,00 und Cache-Treffer $0,20, AnyAIGC liegt also bei rund 40 % des offiziellen Preises. Die Ausgabe umfasst Denk-Tokens. Die aktuellen Preise finden Sie im Modellkatalog.

Wie lautet die Modell-ID von Kimi K3.1 Pro, und wie groß ist das Kontextfenster?

Die Modell-ID lautet kimi-k3.1-pro. Moonshot nennt ein Kontextfenster von 1.048.576 Tokens (1M). max_completion_tokens ist standardmäßig 131.072 und kann bis auf 1.048.576 gesetzt werden.

Worin unterscheidet sich Kimi K3.1 Pro von K3?

Laut Moonshot ist K3.1 Pro das Kimi K3 mit deutlich mehr Rechenaufwand im Post-Training, das über gemeinsames Reinforcement Learning in Hunderten nachgelagerter Domänen lief. Zu den von Moonshot gemeldeten Verbesserungen gehören Langzeit-Coding (Kimi Code Bench 3.0 von 55,95 auf 61,2), Finanzrecherche (interne Evaluierung von 58,8 auf 70,4) und Faktentreue (Halluzinationsrate pro Aussage von 23,4 % auf 8,3 % gesunken). Die Parameterbeschränkungen entsprechen denen von K3, für die Migration ändern Sie also nur den Modellnamen. Bei AnyAIGC kostet K3.1 Pro $0,8100 für die Eingabe und $4,0500 für die Ausgabe, etwa ein Drittel weniger als K3.

Wie stelle ich die Denktiefe von Kimi K3.1 Pro ein?

K3.1 Pro denkt immer, der Denkmodus lässt sich nicht abschalten. Die Tiefe legen Sie mit dem Feld reasoning_effort auf oberster Ebene im Body der Anfrage fest: low, high oder max (Standard max). Sampling-Parameter wie temperature und top_p legt Moonshot fest, lassen Sie sie in der Anfrage weg.

Unterstützt Kimi K3.1 Pro Tool-Aufrufe sowie Bild- und Videoeingabe?

Ja. Die Dokumentation von Moonshot nennt Funktionsaufrufe (tools / tool_choice), strukturierte Ausgabe (json_schema), Streaming sowie Bild- und Videoeingabe. Senden Sie bei mehrstufigen Chats und Tool-Aufrufen die vollständige Assistant-Nachricht (einschließlich reasoning_content und tool_calls) in der nächsten Anfrage unverändert zurück.

Kann ich Kimi K3.1 Pro in Claude Code nutzen?

Ja. Setzen Sie im env-Block von ~/.claude/settings.json ANTHROPIC_BASE_URL auf https://anyaigc.ai, ANTHROPIC_AUTH_TOKEN auf Ihren API-Schlüssel und ANTHROPIC_MODEL auf kimi-k3.1-pro. Führen Sie dann claude aus.

Ist Kimi K3.1 Pro Open Source?

Moonshot nennt K3.1 Pro sein bisher stärkstes Modell der 3T-Klasse mit offenen Gewichten und gibt an, dass die vollständigen Gewichte bis zum 4. November 2026 veröffentlicht werden. Wenn Sie die API über AnyAIGC aufrufen, müssen Sie das Modell nicht selbst hosten. Modelllizenzen und kommerzielle Nutzung richten sich nach den offiziellen Bedingungen von Moonshot AI.

Gibt es Limits für Parallelität oder Ratenlimits?

AnyAIGC begrenzt die Parallelität für kimi-k3.1-pro nicht, und jeder Nutzer erhält das standardmäßig. Das eignet sich für Batch-Jobs, CI-Pipelines und parallele Agenten. Die eigene Plattform von Moonshot begrenzt Parallelität, RPM, TPM und TPD je nach Aufladestufe; diese Stufen gelten nicht, wenn Sie über AnyAIGC aufrufen.
