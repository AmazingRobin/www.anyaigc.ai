Schnellstart

Die DeepSeek API in drei Schritten nutzen

  1. Registrieren und Guthaben aufladen: Erstellen Sie ein Konto unter anyaigc.ai. Aufladen ab $1; Ihr Guthaben gilt für alle Modelle der Plattform.
  2. API-Schlüssel erstellen: Erstellen Sie in der Konsole einen Schlüssel, kopieren Sie den sk--Schlüssel und speichern Sie ihn in der Umgebungsvariable ANYAIGC_API_KEY.
  3. Anfrage senden: Rufen Sie POST https://anyaigc.ai/v1/chat/completions auf, setzen Sie model auf deepseek-v4.1-flash und senden Sie einen Authorization: Bearer-Header. Beim OpenAI SDK setzen Sie einfach base_url auf https://anyaigc.ai/v1.

Parameter: Laut DeepSeek denkt die V4-Serie standardmäßig nach. Mit dem Feld thinking im Request-Body schalten Sie den Thinking-Modus ein oder aus ({"type": "enabled"} oder {"type": "disabled"}), und reasoning_effort legt die Tiefe fest (offiziell low / high / max). Thinking-Tokens zählen als Ausgabe und erscheinen in usage.completion_tokens_details.reasoning_tokens. Sampling-Parameter wie temperature haben im Thinking-Modus keine Wirkung.

Alle Parameter finden Sie in der Referenz zur Chat-Completions-API. Ersetzen Sie in den Beispielen der Dokumentation den Modellnamen durch die gewünschte DeepSeek-Modell-ID.

Claude Code

DeepSeek in Claude Code nutzen

Richten Sie Claude Code auf DeepSeek aus: Sie ändern eine Konfigurationsdatei, und Ihr Coding-Agent im Terminal läuft auf DeepSeek V4.1 Flash, abgerechnet pro Token.

  1. Claude Code installieren: Verwenden Sie das offizielle Installationsprogramm, unter macOS oder Linux zum Beispiel curl -fsSL https://claude.ai/install.sh | bash.
  2. Konfiguration hinzufügen: Bearbeiten Sie ~/.claude/settings.json, fügen Sie den folgenden env-Block ein und ersetzen Sie ANTHROPIC_AUTH_TOKEN durch den Schlüssel, den Sie bei AnyAIGC erstellt haben.
  3. Loslegen: Führen Sie claude in Ihrem Projektordner aus. Geben Sie /model ein, um zu prüfen, dass das aktuelle Modell deepseek-v4.1-flash ist.

Modell wechseln: Um V4 Pro zu nutzen, ersetzen Sie in der Konfiguration deepseek-v4.1-flash durch deepseek-v4-pro. ANTHROPIC_DEFAULT_HAIKU_MODEL können Sie für leichte Teilaufgaben auch weiter auf V4.1 Flash belassen.

Alle Schritte und häufige Fehler finden Sie in der Einrichtungsanleitung für Claude Code. Ersetzen Sie den Modellnamen in der Anleitung durch deepseek-v4.1-flash.

FAQ

FAQ zur DeepSeek-API

Was kostet die DeepSeek-API?

DeepSeek wird bei AnyAIGC pro Token abgerechnet. Pro 1 Mio. Tokens kostet deepseek-v4.1-flash $0.1215 für Eingabe, $0.4860 für Ausgabe und $0.0024 bei Cache-Treffer; deepseek-v4-pro kostet $0.5346 für Eingabe, $1.6038 für Ausgabe und $0.0178 bei Cache-Treffer; deepseek-v4-flash kostet dasselbe wie V4.1 Flash. Aktuelle Preise zeigt der Modellkatalog.

Gibt es bei AnyAIGC getrennte Preise für Spitzenzeiten und außerhalb der Spitzenzeiten?

Nein. Die offizielle DeepSeek-API rechnet zeitabhängig ab: Werktags von 01:00–04:00 und 06:00–10:00 UTC (9:00–12:00 und 14:00–18:00 Uhr Pekinger Zeit) ist Spitzenzeit, und die Spitzenpreise sind doppelt so hoch wie die Preise außerhalb der Spitzenzeiten. Bei AnyAIGC werden alle DeepSeek-Modelle rund um die Uhr zu einem einheitlichen Preis abgerechnet. Dieser liegt rund 60 % unter dem offiziellen Spitzenpreis. Aktuelle Preise zeigt der Modellkatalog.

Welche DeepSeek-Modelle bietet AnyAIGC an, und wie lauten die Modell-IDs?

Diese Seite behandelt drei Modelle: deepseek-v4.1-flash (das neueste Flash-Modell von DeepSeek mit nativer Vision), deepseek-v4-pro (das V4-Flaggschiff mit 1.6T Parametern) und deepseek-v4-flash (das Flash-Modell der V4-Preview, das DeepSeek durch V4.1 Flash ersetzt hat). Tragen Sie die Modell-ID in das Feld model des Request-Body ein. Zum Wechseln des Modells ändern Sie nur dieses Feld.

Sollte ich V4.1 Flash oder V4 Pro verwenden?

Beginnen Sie für die meisten Aufgaben mit V4.1 Flash. Laut DeepSeek übertrifft es V4 Pro inzwischen bei Leistung, Kosten, Geschwindigkeit und Gesamtbearbeitungszeit, sein Eingabepreis liegt bei etwa einem Viertel von V4 Pro, und es kann Bilder lesen. Wenn Sie V4 Pro bereits produktiv abgestimmt haben, können Sie V4 Pro weiter nutzen: DeepSeek hat angekündigt, die V4-Pro-API auch nach dem 14. September 2026 weiter bereitzustellen.

Wie groß ist das Kontextfenster? Kann ich Bilder senden?

DeepSeek gibt für V4.1 Flash und V4 Pro ein Kontextfenster von 1M Tokens und bis zu 384K Ausgabe-Tokens an. Nur V4.1 Flash akzeptiert Bilder; V4 Pro und V4 Flash verarbeiten nur Text.

Ist die DeepSeek-API OpenAI-kompatibel?

Ja. Alle drei Modelle verwenden POST https://anyaigc.ai/v1/chat/completions mit demselben Request- und Response-Format wie OpenAI Chat Completions. Beim offiziellen OpenAI-SDK setzen Sie base_url auf https://anyaigc.ai/v1. Das Anthropic-Format wird ebenfalls unterstützt, daher funktioniert auch Claude Code.

Kann ich DeepSeek in Claude Code verwenden?

Ja. DeepSeek-Modelle bei AnyAIGC unterstützen sowohl das OpenAI- als auch das Anthropic-API-Format. Setzen Sie im env-Block von ~/.claude/settings.json ANTHROPIC_BASE_URL auf https://anyaigc.ai, ANTHROPIC_AUTH_TOKEN auf Ihren API-Schlüssel und ANTHROPIC_MODEL auf deepseek-v4.1-flash, und starten Sie dann claude. Sie zahlen pro Token.

Gibt es Limits für Parallelität oder Ratenlimits?

AnyAIGC begrenzt die Parallelität für die DeepSeek-Serie nicht, und das gilt standardmäßig für alle Nutzer. Das eignet sich für Batch-Jobs, CI-Pipelines und parallel laufende Agenten.

Wie erhalte ich einen DeepSeek-API-Schlüssel?

Registrieren Sie sich auf anyaigc.ai, laden Sie Guthaben auf und erstellen Sie in der Konsole einen Schlüssel. Derselbe Schlüssel funktioniert für alle DeepSeek-Modelle und für 300+ weitere Modelle der Plattform, ein separates Konto bei der DeepSeek Platform brauchen Sie also nicht.

Kann ich bei AnyAIGC eine Rechnung bekommen?

Ja. Sie können Rechnungen in der Konsole selbst ausstellen, und zwar über den tatsächlich aufgeladenen Betrag.

Welche Zahlungsmethoden werden unterstützt?

Sie können Guthaben per WeChat Pay, Alipay, USDT oder Kreditkarte aufladen. Ihr Guthaben ist in USD und gilt für alle Modelle der Plattform. Rechnungen über den aufgeladenen Betrag können Sie in der Konsole ausstellen.

Gibt es kostenloses Testguthaben für neue Nutzer?

Ja. Neue Konten erhalten Testguthaben von 2 Millionen Tokens, damit Sie testen können, bevor Sie sich fürs Aufladen entscheiden. Aufladungen beginnen bei $1.

Kann ich mein Guthaben erstatten lassen?

Ja. Nicht genutztes Guthaben kann gebührenfrei erstattet werden. Wenden Sie sich an den Support, um eine Erstattung zu veranlassen.

Sind das die echten Modelle? Sind meine Daten sicher?

Anfragen laufen über offizielle Modellkanäle, nie über günstigere oder per Reverse Engineering nachgebaute Ersatzmodelle. Sofern das Gesetz es nicht verlangt, speichern wir Ihre Prompts und Ausgaben nicht dauerhaft und verwenden sie nicht für Training, und die Konsole zeigt Tokens und Kosten jeder Anfrage.
