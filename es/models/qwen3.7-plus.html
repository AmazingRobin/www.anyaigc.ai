Inicio rápido

Empieza con Chat Completions

  1. Crea una cuenta y una clave de API en la consola.
  2. Configura la Base URL como https://anyaigc.ai/v1.
  3. Indica el modelo (model) y envía los mensajes (messages).
cURL · POST /v1/chat/completions
curl https://anyaigc.ai/v1/chat/completions \
  -H "Authorization: Bearer $ANYAIGC_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"qwen3.7-plus","messages":[{"role":"user","content":"Explain what a MoE model is in three sentences."}]}'
Python · SDK de OpenAI
from openai import OpenAI
import os
client = OpenAI(api_key=os.environ["ANYAIGC_API_KEY"], base_url="https://anyaigc.ai/v1")
response = client.chat.completions.create(model="qwen3.7-plus", messages=[{"role":"user","content":"Explain what a MoE model is in three sentences."}])
print(response.choices[0].message.content)

Preguntas frecuentes

Preguntas frecuentes sobre la API de Qwen3.7 Plus

¿Qué endpoint usa la API de Qwen3.7 Plus?

Los modelos de conversación usan POST https://anyaigc.ai/v1/chat/completions. Envía model y messages, con Authorization: Bearer <API Key>.

¿Cuánto cuesta la API de Qwen3.7 Plus?

Qwen3.7 Plus se factura por token: entrada $0,4050, salida $1,6200 y acierto de caché $0,0810 por millón de tokens. Los precios en tiempo real están en el catálogo de modelos.

¿Hay un límite de concurrencia?

Los modelos de conversación de Qwen de esta página no tienen límite de concurrencia y están disponibles para todos los usuarios.

¿Cómo obtengo una clave de API?

Crea una cuenta de AnyAIGC y luego crea una clave de API en la consola. Una sola clave funciona con más de 300 modelos.

¿Se admiten imágenes y llamadas a herramientas?

Las capacidades varían según el modelo. Consulta las etiquetas del catálogo en vivo; el endpoint es el mismo.

¿Puedo obtener una factura de AnyAIGC?

Sí. Puedes emitir tus propias facturas en la consola, por el importe que hayas recargado realmente.

¿Qué métodos de pago se admiten?

Puedes recargar saldo con WeChat Pay, Alipay, USDT o tarjeta de crédito. Tu saldo está en USD y sirve para todos los modelos de la plataforma. Las facturas se pueden emitir en la consola por el importe recargado.

¿Hay crédito de prueba gratuito para usuarios nuevos?

Sí. Las cuentas nuevas reciben 2 millones de tokens de crédito de prueba.

¿Puedo pedir el reembolso de mi saldo?

Sí. El saldo no utilizado se puede reembolsar sin comisión.

¿Son modelos oficiales y están seguros mis datos?

Las peticiones usan canales oficiales de los modelos. Los prompts y las salidas no se almacenan de forma persistente ni se usan para entrenamiento, salvo que la ley lo exija.
