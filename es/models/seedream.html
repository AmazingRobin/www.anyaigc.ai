Empieza con la API de Seedream

  1. Regístrate en AnyAIGC. Las cuentas nuevas reciben 2M de tokens gratis y puedes recargar saldo desde $1.
  2. Crea una clave de API en la consola y guárdala en la variable de entorno ANYAIGC_API_KEY.
  3. Envía una petición a POST https://anyaigc.ai/v1/images/generations (compatible con OpenAI) con model establecido en doubao-seedream-5-0-pro-260628.

Cambia de modelo poniendo en model el valor doubao-seedream-5-5-261028, doubao-seedream-5-0-pro-260628, doubao-seedream-5-0-260128, doubao-seedream-4-5-251128 o doubao-seedream-4-0-250828. Las peticiones y las respuestas mantienen el mismo formato.

Autentica con Authorization: Bearer <API Key>. La respuesta tiene la forma {"created": ..., "data": [{"url": ...}]}; define response_format como b64_json para recibir base64. watermark es true por defecto, así que pasa false de forma explícita para obtener imágenes limpias. Los detalles de los campos están en la documentación de la API de Seedream de AnyAIGC.

Preguntas frecuentes sobre la API de Seedream

¿Cuánto cuesta la API de Seedream?

Cada modelo Seedream de AnyAIGC tiene un precio fijo: 5.5 desde $0.0229 / imagen (2K cuesta $0.0402 / imagen, con las imágenes de entrada facturadas aparte), 5.0 Pro desde $0.0441 / imagen, 5.0 lite desde $0.0223 / imagen, 4.5 desde $0.0253 / imagen, 4.0 desde $0.0203 / imagen y 3.0 a $0.0101 / petición. Las resoluciones más altas cuestan más; los precios actuales figuran en el catálogo de modelos.

¿Qué es Seedream? ¿Qué relación tiene con Doubao y Jimeng?

Seedream es la familia de modelos de generación de imágenes del equipo ByteDance Seed. En Volcano Engine se ofrece como "Doubao Seedream" (doubao-seedream), y la generación de imágenes de productos de ByteDance como Jimeng se basa en ella. AnyAIGC ofrece acceso por API a los modelos oficiales de Seedream.

¿Qué diferencia hay entre 5.5, 5.0 Pro, 5.0 lite, 4.5 y 4.0?

5.5 es el modelo más reciente y el más sólido en ediciones coherentes de varios turnos, transparencia RGBA nativa y separación de hasta 99 capas; devuelve 1 imagen por petición y no admite conjuntos de imágenes. 5.0 Pro es el modelo insignia: destaca en infografías, edición precisa y texto multilingüe, hasta 2K, sin conjuntos de imágenes. 5.0 lite es el modelo ligero con búsqueda web, hasta 4K. 4.5 destaca en maquetación de carteles y en conservar los detalles de la imagen original. 4.0 fue la versión que unificó generación y edición. 5.0 lite, 4.5 y 4.0 admiten conjuntos de imágenes y hasta 14 imágenes de referencia.

¿Qué endpoint usa? ¿Puede editar imágenes?

Todos los modelos usan el endpoint POST /v1/images/generations, compatible con OpenAI; al cambiar de modelo solo cambia model. Para edición y fusión de varias imágenes, pasa en image un array de URL de imágenes. Para conjuntos de imágenes, usa sequential_image_generation: "auto". Consulta la documentación de la API de AnyAIGC para ver todos los campos.

¿Hay límite de concurrencia? ¿Qué necesito para registrarme?

AnyAIGC no fija ningún límite de concurrencia en los modelos de Seedream, y todas las cuentas lo tienen por defecto. La URL base es https://anyaigc.ai. No necesitas una cuenta de Volcano Engine ni verificación de identidad, y la misma clave también funciona con más de 300 modelos de la plataforma.

¿Puedo obtener una factura de AnyAIGC?

Sí. Puedes emitir tus propias facturas en la consola, por el importe que hayas recargado realmente.

¿Qué métodos de pago se admiten?

Puedes recargar saldo con WeChat Pay, Alipay, USDT o tarjeta de crédito. Tu saldo está en USD y sirve para todos los modelos de la plataforma. Las facturas se pueden emitir en la consola por el importe recargado.

¿Hay crédito de prueba gratuito para usuarios nuevos?

Sí. Las cuentas nuevas reciben 2 millones de tokens de crédito de prueba para que pruebes antes de decidir si recargas saldo. Las recargas empiezan en $1.

¿Puedo pedir el reembolso de mi saldo?

Sí. El saldo no utilizado se puede reembolsar sin comisión. Contacta con soporte para iniciar el reembolso.

¿Son los modelos reales? ¿Están seguros mis datos?

Las peticiones van a los canales oficiales de los modelos, nunca a sustitutos más baratos o de ingeniería inversa. Salvo que la ley lo exija, no almacenamos de forma persistente tus prompts ni tus resultados, ni los usamos para entrenar modelos, y la consola muestra los tokens y el coste de cada petición.

¿Puedo usar las imágenes con fines comerciales? ¿Puedo quitar la marca de agua?

Los derechos de uso y las políticas de contenido se rigen por los términos oficiales de ByteDance / Volcano Engine. Define watermark como false en la petición y no se añadirá la marca «generado por IA» en la esquina inferior derecha. AnyAIGC solo ofrece acceso a la API y no añade restricciones adicionales sobre cómo usas el resultado; para retratos de personas reales, logotipos de marca y contenido similar, asegúrate de tener los derechos necesarios.
