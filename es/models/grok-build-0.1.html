04 / INICIO RÁPIDO

Integra la API de Grok Build 0.1

Empieza con una petición mínima y después conéctala a tu aplicación.

  1. 01Regístrate y crea una clave de API en la consola.
  2. 02Define la variable de entorno ANYAIGC_API_KEY.
  3. 03Envía una petición con grok-build-0.1 y revisa el uso en la consola.
POST /v1/chat/completions ↗

Los ejemplos de cURL usan Bash / WSL. Python usa la biblioteca estándar, sin SDK. Las peticiones devuelven JSON completo; Python lee choices[0].message.content.

cURL
curl https://anyaigc.ai/v1/chat/completions \
  -H "Authorization: Bearer $ANYAIGC_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
  "model": "grok-build-0.1",
  "messages": [
    {
      "role": "user",
      "content": "Plan the directory structure for a Python CLI. Describe the roles of the entry point, config, and tests."
    }
  ],
  "stream": false
}'
Python · biblioteca estándar
import json
import os
import urllib.request

payload = {'model': 'grok-build-0.1', 'messages': [{'role': 'user', 'content': 'Plan the directory structure for a Python CLI. Describe the roles of the entry point, config, and tests.'}], 'stream': False}
request = urllib.request.Request(
    "https://anyaigc.ai/v1/chat/completions",
    data=json.dumps(payload).encode("utf-8"),
    headers={
        "Authorization": f"Bearer {os.environ['ANYAIGC_API_KEY']}",
        "Content-Type": "application/json",
    },
    method="POST",
)
with urllib.request.urlopen(request, timeout=180) as response:
    result = json.load(response)
print(result["choices"][0]["message"]["content"])

La documentación de AnyAIGC define los campos de la petición y de la respuesta. La página de Messages no documenta diferencias de respuesta específicas de Grok, así que ese ejemplo muestra la petición sin suponer campos adicionales en la respuesta.

07 / PREGUNTAS FRECUENTES

Preguntas frecuentes sobre la API de Grok Build 0.1

¿Qué ID de modelo debo usar para Grok Build 0.1?

Usa grok-build-0.1 exactamente como está escrito. Consulta la visión general de Grok 4.x para ver los demás modelos de la serie.

¿Cuál es el precio de la API de Grok?

La entrada cuesta $0.0993 y la salida $0.1985 por millón de tokens. En las peticiones a Grok Build 0.1 con más de 200.000 y hasta 500.000 tokens de entrada, la entrada cuesta $0.1985 y la salida $0.3971 por millón de tokens. Son las tarifas más bajas que muestra el catálogo; consulta el catálogo de modelos para ver los precios actuales.

¿Qué endpoints de la API se admiten?

Admite POST /v1/chat/completions, según figura actualmente en el catálogo de modelos.

¿Hay límites de concurrencia o de RPM?

Todos los modelos indicados aquí tienen concurrencia sin límite por defecto para todos los usuarios, sin activación aparte. Gestiona las conexiones, los tiempos de espera y los reintentos en tu aplicación.

¿La API incluye automáticamente datos en vivo de X?

El chat normal no incluye automáticamente acontecimientos en vivo. xAI exige herramientas de búsqueda para los datos en vivo; los ejemplos básicos de aquí no usan búsqueda ni prometen compatibilidad con todas las herramientas de búsqueda del proveedor. El uso comercial se rige por las condiciones de xAI.

¿Puedo obtener una factura de AnyAIGC?

Sí. Puedes emitir tus propias facturas en la consola, por el importe que hayas recargado realmente.

¿Qué métodos de pago se admiten?

Puedes recargar saldo con WeChat Pay, Alipay, USDT o tarjeta de crédito. Tu saldo está en USD y sirve para todos los modelos de la plataforma. Las facturas se pueden emitir en la consola por el importe recargado.

¿Hay crédito de prueba gratuito para usuarios nuevos?

Sí. Las cuentas nuevas reciben 2 millones de tokens de crédito de prueba para que pruebes antes de decidir si recargas saldo. Las recargas empiezan en $1.

¿Puedo pedir el reembolso de mi saldo?

Sí. El saldo no utilizado se puede reembolsar sin comisión. Contacta con soporte para iniciar el reembolso.

¿Son los modelos reales? ¿Están seguros mis datos?

Las peticiones van a los canales oficiales de los modelos, nunca a sustitutos más baratos o de ingeniería inversa. Salvo que la ley lo exija, no almacenamos de forma persistente tus prompts ni tus resultados, ni los usamos para entrenar modelos, y la consola muestra los tokens y el coste de cada petición.
