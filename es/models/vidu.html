Python
import json
import os
import time
import urllib.request

BASE = "https://anyaigc.ai"
HEADERS = {
    "Authorization": "Bearer " + os.environ["ANYAIGC_API_KEY"],
    "Content-Type": "application/json",
}


def call(method, path, body=None):
    data = json.dumps(body, ensure_ascii=False).encode("utf-8") if body else None
    request = urllib.request.Request(BASE + path, data=data, headers=HEADERS, method=method)
    with urllib.request.urlopen(request, timeout=60) as response:
        return json.load(response)


payload = {
    "model": "viduq3-turbo",
    "prompt": "A red fox crosses thin ice on a mountain lake at dawn; low tracking shot, its breath drifting in the sunlight.",
    "duration": 5,
    "resolution": "540p",
    "aspect_ratio": "16:9"
}

created = call("POST", "/ent/v2/text2video", payload)
task_id = (created.get("data") or created)["task_id"]
print("task_id:", task_id)

# Poll every 10 seconds until the task leaves the queue
for _ in range(120):
    result = call("GET", f"/ent/v2/tasks/{task_id}/creations")
    state = (result.get("data") or result).get("state") or (result.get("data") or result).get("status")
    if state not in ("created", "queueing", "processing"):
        break
    time.sleep(10)

# creations holds the video or image URLs; they expire, so download promptly
print(json.dumps(result, ensure_ascii=False, indent=2))

Sustituye la imagen de ejemplo por tu propia URL o Base64 (png, jpeg o webp, hasta 50 MB). Lee el campo status de la respuesta real; el ejemplo deja de sondear cuando la tarea sale de created, queueing o processing.

Preguntas frecuentes

Preguntas frecuentes sobre la API de Vidu

Precios, endpoints, resultados y acceso para empresas en un solo lugar.

¿Cuáles son los precios iniciales de la API de Vidu?

El vídeo empieza en $0.0223 por el primer segundo de Q2 Turbo 540p (luego +$0.00744/s). Q3 Turbo 540p cuesta $0.0298/s, Q4 Preview 540p cuesta $0.0486/s y la generación de texto a imagen de Q2 Image en 1080p cuesta $0.0298 por imagen. Los precios están en USD; consulta el catálogo de modelos para ver las tarifas vigentes.

¿Cómo elijo entre los 7 modelos?

Elige Q4 Preview para 2K/4K y el modelo más reciente; Q3 Pro para audio sincronizado y transiciones de plano inteligentes, o Q3 Turbo si priorizas la velocidad; Q2 Turbo para clips económicos de imagen o de primer/último fotograma y Q2 Pro para mayor calidad; Q2 para texto a vídeo y referencia a vídeo con varias imágenes; Q2 Image para imágenes fijas.

¿Estos modelos comparten endpoints?

Los endpoints dependen de la tarea: /ent/v2/text2video, /ent/v2/img2video, /ent/v2/start-end2video, /ent/v2/reference2video y /ent/v2/reference2image. Elige el modelo con el campo model y obtén cada resultado con GET /ent/v2/tasks/{id}/creations.

¿Cómo obtengo el resultado?

Todas las tareas son asíncronas: al crear una tarea se devuelve un task_id; consulta el resultado con sondeo en el endpoint de consulta y lee la URL del vídeo o de la imagen en creations, o pasa callback_url para recibir un callback.

¿Hay límites de concurrencia o de RPM?

En AnyAIGC, Vidu tiene concurrencia sin límite por defecto para todas las cuentas, sin un tope fijo de RPM. La generación de vídeo lleva tiempo, así que define un intervalo de sondeo y un tiempo de espera en tu aplicación.

¿Puedo usar los resultados con fines comerciales?

El uso comercial se rige por los términos oficiales de Vidu (ShengShu Technology), y necesitas tener los derechos sobre las imágenes de referencia, las personas o los recursos de marca que subas. AnyAIGC es un proveedor de API independiente.

¿Puedo obtener una factura de AnyAIGC?

Sí. Puedes emitir tus propias facturas en la consola, por el importe que hayas recargado realmente.

¿Qué métodos de pago se admiten?

Puedes recargar saldo con WeChat Pay, Alipay, USDT o tarjeta de crédito. Tu saldo está en USD y sirve para todos los modelos de la plataforma. Las facturas se pueden emitir en la consola por el importe recargado.

¿Hay crédito de prueba gratuito para usuarios nuevos?

Sí. Las cuentas nuevas reciben 2 millones de tokens de crédito de prueba para que pruebes antes de decidir si recargas saldo. Las recargas empiezan en $1.

¿Puedo pedir el reembolso de mi saldo?

Sí. El saldo no utilizado se puede reembolsar sin comisión. Contacta con soporte para iniciar el reembolso.

¿Son los modelos reales? ¿Están seguros mis datos?

Las peticiones van a los canales oficiales de los modelos, nunca a sustitutos más baratos o de ingeniería inversa. Salvo que la ley lo exija, no almacenamos de forma persistente tus prompts ni tus resultados, ni los usamos para entrenar modelos, y la consola muestra los tokens y el coste de cada petición.
