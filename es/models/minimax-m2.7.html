cURL
curl --request POST "https://anyaigc.ai/v1/chat/completions" \
  --header "Authorization: Bearer $ANYAIGC_API_KEY" \
  --header "Content-Type: application/json" \
  --data '{
  "model": "MiniMax-M2.7",
  "messages": [
    {
      "role": "user",
      "content": "Design three clear API endpoints for a to-do application."
    }
  ]
}'
Python
import json
import os
import urllib.request

payload = {
    "model": "MiniMax-M2.7",
    "messages": [
        {
            "role": "user",
            "content": "Design three clear API endpoints for a to-do application."
        }
    ]
}

request = urllib.request.Request(
    "https://anyaigc.ai/v1/chat/completions",
    data=json.dumps(payload, ensure_ascii=False).encode("utf-8"),
    headers={
        "Authorization": "Bearer " + os.environ["ANYAIGC_API_KEY"],
        "Content-Type": "application/json",
    },
    method="POST",
)
with urllib.request.urlopen(request, timeout=120) as response:
    result = json.load(response)

print(json.dumps(result, ensure_ascii=False, indent=2))

ESPECIFICACIONES

Especificaciones y cuándo elegirlo

M2.7 está disponible por completo en MiniMax Agent y en la plataforma de API de MiniMax; MiniMax lo presenta como su primer modelo que participa a fondo en su propia evolución.

MiniMax reporta una tasa de cumplimiento de habilidades del 97 % cuando M2.7 trabaja con más de 40 habilidades complejas.

M2.7 es un modelo de texto de entrada y salida, con razonamiento y llamadas a herramientas, y se puede autoalojar (configuración de referencia: 4 GPU NVIDIA de gran memoria con TP 4).

Esta página indica Entrada a $0,4455 / 1M de tokens y Salida a $1,7820 / 1M de tokens, igual que la tabla de precios anterior.

En comparación con minimax-m3: elige M3 si necesitas entrada de imagen o vídeo o una ventana de contexto de 1M de tokens.

Las especificaciones proceden de la documentación oficial del proveedor (minimax.io). La tabla de esta página muestra los precios; para las tarifas en tiempo real, la referencia es el catálogo de modelos.

Preguntas frecuentes

Preguntas frecuentes sobre la API de MiniMax

Precios, endpoints, resultados y acceso para empresas en un solo lugar.

¿Cuánto cuesta la API de MiniMax M2.7?

Entrada $0,4455/1M de tokens; Salida $1,7820/1M de tokens. Todos los precios están en USD; consulta el catálogo de modelos para ver las tarifas actuales.

¿Qué endpoint de la API debo usar?

Usa POST /v1/chat/completions en https://anyaigc.ai y envía tu clave de API mediante Authorization: Bearer.

¿Para qué sirve MiniMax M2.7?

Un modelo de lenguaje para programación, uso de herramientas, búsqueda y flujos de trabajo de oficina.

¿Qué devuelve una petición?

Una petición devuelve una respuesta del modelo; tu aplicación se encarga de ejecutar las herramientas.

¿Hay límites de concurrencia o de RPM?

AnyAIGC ofrece concurrencia sin límite para MiniMax, sin tope fijo de RPM. La generación sigue requiriendo tiempo; configura tiempos de espera, gestión de errores y reintentos adecuados en tu aplicación.

¿Se puede usar el contenido generado con fines comerciales?

El uso comercial de los modelos y sus resultados se rige por los términos oficiales de MiniMax. Asegúrate de contar con los derechos necesarios sobre el material de referencia, las voces y el contenido generado. AnyAIGC es un proveedor de API independiente.

¿Puedo obtener una factura de AnyAIGC?

Sí. Puedes emitir tus propias facturas en la consola, por el importe que hayas recargado realmente.

¿Qué métodos de pago se admiten?

Puedes recargar saldo con WeChat Pay, Alipay, USDT o tarjeta de crédito. Tu saldo está en USD y sirve para todos los modelos de la plataforma. Las facturas se pueden emitir en la consola por el importe recargado.

¿Hay crédito de prueba gratuito para usuarios nuevos?

Sí. Las cuentas nuevas reciben 2 millones de tokens de crédito de prueba para que pruebes antes de decidir si recargas saldo. Las recargas empiezan en $1.

¿Puedo pedir el reembolso de mi saldo?

Sí. El saldo no utilizado se puede reembolsar sin comisión. Contacta con soporte para iniciar el reembolso.

¿Son los modelos reales? ¿Están seguros mis datos?

Las peticiones van a los canales oficiales de los modelos, nunca a sustitutos más baratos o de ingeniería inversa. Salvo que la ley lo exija, no almacenamos de forma persistente tus prompts ni tus resultados, ni los usamos para entrenar modelos, y la consola muestra los tokens y el coste de cada petición.
