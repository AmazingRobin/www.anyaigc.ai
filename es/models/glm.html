Inicio rápido

Conéctate a la API de GLM en tres pasos

  1. Regístrate y recarga saldo: crea una cuenta en anyaigc.ai. Recarga desde $1; tu saldo sirve para todos los modelos de la plataforma.
  2. Crea una clave de API: crea una clave en la consola, copia el valor que empieza por sk- y guárdalo en la variable de entorno ANYAIGC_API_KEY.
  3. Envía una petición: llama a POST https://anyaigc.ai/v1/chat/completions con model igual a glm-5.3 y una cabecera Authorization: Bearer. Con el SDK de OpenAI, basta con establecer base_url en https://anyaigc.ai/v1.

Consejo: GLM devuelve su razonamiento en el campo reasoning_content. En streaming, los deltas de razonamiento llegan primero y después la respuesta final. Define la profundidad del razonamiento con reasoning_effort (low / high / max, por defecto max). En chats de varios turnos y llamadas a herramientas, reenvía sin cambios en la siguiente petición el mensaje completo del asistente que devolvió la API (incluidos reasoning_content y tool_calls).

Consulta la referencia de Chat Completions para ver todos los parámetros. Sustituye el nombre del modelo en los ejemplos de la documentación por el ID del modelo GLM que quieras.

Claude Code

Usa GLM en Claude Code

Cambia Claude Code a GLM editando un único archivo de configuración, y el agente de programación de tu terminal se ejecutará con GLM-5.3, facturado por token.

  1. Instala Claude Code: usa el instalador oficial, por ejemplo curl -fsSL https://claude.ai/install.sh | bash en macOS o Linux.
  2. Añade la configuración: edita ~/.claude/settings.json, añade el bloque env de abajo y sustituye ANTHROPIC_AUTH_TOKEN por la clave que creaste en AnyAIGC.
  3. Empieza a programar: ejecuta claude en la carpeta de tu proyecto. Escribe /model para confirmar que el modelo actual es glm-5.3.

Ahorra en tareas ligeras: la configuración asigna ANTHROPIC_DEFAULT_HAIKU_MODEL a glm-5.3-flash, de modo que las subtareas ligeras de Claude Code usan el modelo más barato mientras el trabajo principal sigue en GLM-5.3.

Para ver la guía completa y los errores habituales, consulta la guía de configuración de Claude Code. Sustituye en la guía el nombre del modelo por glm-5.3.

Preguntas frecuentes

Preguntas frecuentes sobre la API de GLM

¿Cuánto cuesta la API de GLM?

Los modelos GLM de AnyAIGC se facturan por token. Por millón de tokens: glm-5.3 entrada $0.9450, salida $2.9700, acierto de caché $0.1758; glm-5.3-flash entrada $0.0607, salida $0.2025, acierto de caché $0.0122; glm-5.2 entrada $0.9450, salida $2.9700, acierto de caché $0.2362. GLM-5.3 y GLM-5.2 cuestan aproximadamente un 30 % menos que los precios oficiales en USD de Zhipu, y GLM-5.3-Flash aproximadamente un 60 % menos. Consulta el catálogo de modelos para ver los precios en tiempo real.

¿Qué modelos GLM hay en AnyAIGC y cuáles son sus ID?

Esta página cubre tres: glm-5.3 (el último modelo insignia de Zhipu, para programación compleja y agentes), glm-5.3-flash (el primer modelo GLM-5 nativamente multimodal, a bajo precio) y glm-5.2 (el modelo insignia anterior, pensado para tareas de larga duración). Escribe el ID del modelo en el campo model del cuerpo de la petición. Cambiar de modelo solo requiere modificar ese campo. En la plataforma también hay modelos anteriores como GLM-5.1, GLM-5 y GLM-4.5; consulta el catálogo de modelos.

GLM-5.3, GLM-5.3-Flash o GLM-5.2: ¿cuál debo usar?

Elige GLM-5.3 para el trabajo más exigente de programación, terminal y agentes. Elige GLM-5.3-Flash para tareas de alto volumen, con presupuesto ajustado o con imágenes; cuesta aproximadamente 1/15 de GLM-5.3 y, según Zhipu, supera a GLM-5.2 en conjunto. Quédate con GLM-5.2 si necesitas desactivar el modo de razonamiento (thinking) o ya lo usas en producción. GLM-5.3 y GLM-5.2 cuestan lo mismo, así que los proyectos nuevos deberían empezar con GLM-5.3.

¿La API de GLM es compatible con OpenAI?

Sí. Los tres modelos usan POST https://anyaigc.ai/v1/chat/completions con el mismo formato de petición y respuesta que OpenAI Chat Completions. Con el SDK oficial de OpenAI, establece base_url en https://anyaigc.ai/v1. La traza de razonamiento, si la hay, se devuelve en el campo reasoning_content.

¿Puedo usar GLM en Claude Code?

Sí. En el bloque env de ~/.claude/settings.json, establece ANTHROPIC_BASE_URL en https://anyaigc.ai, ANTHROPIC_AUTH_TOKEN en tu clave de API y ANTHROPIC_MODEL en glm-5.3. Después ejecuta claude. Pagas por token, sin ventana de cuota de 5 horas como en un plan de suscripción.

¿Qué tamaño tiene la ventana de contexto?

Según Zhipu, GLM-5.3, GLM-5.3-Flash y GLM-5.2 admiten un contexto de 1M de tokens y hasta 128K tokens de salida. GLM-5.3 y GLM-5.2 aceptan solo texto; GLM-5.3-Flash también acepta imágenes.

¿En qué se diferencia del GLM Coding Plan?

El GLM Coding Plan es la suscripción mensual de programación de Zhipu, con cuotas que se reinician en ventanas de 5 horas y semanales. AnyAIGC es una API de pago por token: pagas por lo que usas, recargas desde $1, sin ventanas de tiempo y con concurrencia sin límite, y la misma clave llama a más de 300 modelos.

¿Los modelos GLM son de código abierto? ¿Puedo usarlos con fines comerciales?

Zhipu ha publicado los pesos de GLM-5.3, GLM-5.3-Flash y GLM-5.2 en Hugging Face. GLM-5.2 y GLM-5.3-Flash usan la licencia MIT; GLM-5.3 usa la GLM-5.3 License, una licencia permisiva con una cláusula adicional de revisión de seguridad para empresas MaaS muy grandes. Llamar a la API a través de AnyAIGC significa que no tienes que alojarlos por tu cuenta. Las licencias de los modelos y el uso comercial se rigen por los términos oficiales de Zhipu AI.

¿Hay límites de concurrencia o de peticiones?

AnyAIGC no limita la concurrencia de los modelos GLM, y todos los usuarios la tienen por defecto. Es adecuado para trabajos por lotes, pipelines de CI y agentes en paralelo. La facturación es por token, así que no hay una cuota que se reinicie por ventana de tiempo como en un plan de suscripción.

¿Cómo obtengo una clave de API de GLM?

Regístrate en anyaigc.ai, recarga saldo y crea una clave en la consola. La misma clave sirve para todos los modelos GLM y para más de 300 modelos de la plataforma, así que no necesitas una cuenta aparte en la plataforma de Zhipu ni un GLM Coding Plan.

¿Puedo obtener una factura de AnyAIGC?

Sí. Puedes emitir tus propias facturas en la consola, por el importe que hayas recargado realmente.

¿Qué métodos de pago se admiten?

Puedes recargar saldo con WeChat Pay, Alipay, USDT o tarjeta de crédito. Tu saldo está en USD y sirve para todos los modelos de la plataforma. Las facturas se pueden emitir en la consola por el importe recargado.

¿Hay crédito de prueba gratuito para usuarios nuevos?

Sí. Las cuentas nuevas reciben 2 millones de tokens de crédito de prueba para que pruebes antes de decidir si recargas saldo. Las recargas empiezan en $1.

¿Puedo pedir el reembolso de mi saldo?

Sí. El saldo no utilizado se puede reembolsar sin comisión. Contacta con soporte para iniciar el reembolso.

¿Son los modelos reales? ¿Están seguros mis datos?

Las peticiones van a los canales oficiales de los modelos, nunca a sustitutos más baratos o de ingeniería inversa. Salvo que la ley lo exija, no almacenamos de forma persistente tus prompts ni tus resultados, ni los usamos para entrenar modelos, y la consola muestra los tokens y el coste de cada petición.

¿Se usarán mis datos para entrenar modelos?

No. Salvo cuando lo exija la ley, AnyAIGC no almacena de forma persistente tus prompts ni tus resultados, y no los usa para entrenar modelos. Las peticiones se cifran mediante HTTPS. Consulta la Política de privacidad de AnyAIGC. La política de datos del propio modelo se rige por los términos oficiales de Zhipu AI.
