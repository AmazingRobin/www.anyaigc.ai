Casos de uso

Qué construyen los equipos con la API de Kimi

  • 01 · Programación de larga duración

    Grandes refactorizaciones y cambios entre archivos

    La ventana de contexto de 1M de K3.1 Pro abarca un repositorio completo, y el modelo trabaja paso a paso con herramientas de terminal. Con un presupuesto más ajustado, cambia a K2.7 Code, que cuesta aproximadamente la mitad del precio de K3.1 Pro.

  • 02 · Agentes de programación

    Claude Code, CI y correcciones automáticas

    Conecta Kimi a Claude Code o a tu propio framework de agentes para ejecutar pruebas, leer errores y corregir código. AnyAIGC no limita la concurrencia, así que puedes ejecutar muchos agentes a la vez.

  • 03 · Front end y diseño

    De capturas de pantalla a interfaces listas para producción

    Los cuatro modelos leen imágenes. Entrega un archivo de diseño o una captura de pantalla de una página y recibe HTML, CSS o código de componentes.

  • 04 · Trabajo del conocimiento

    Investigación financiera y documentos largos

    Carga informes financieros completos, contratos o paquetes de investigación en el contexto para extraer campos, construir modelos financieros y redactar informes. Moonshot reporta 64.4 en OfficeQA Pro v2 para K3.1 Pro.

Inicio rápido

Conéctate a la API de Kimi en tres pasos

  1. Regístrate y recarga saldo: crea una cuenta en anyaigc.ai. Recarga desde $1; tu saldo sirve para todos los modelos de la plataforma.
  2. Crea una clave de API: crea una clave en la consola, copia el valor que empieza por sk- y guárdalo en la variable de entorno ANYAIGC_API_KEY.
  3. Envía una petición: llama a POST https://anyaigc.ai/v1/chat/completions con model establecido en kimi-k3.1-pro y una cabecera Authorization: Bearer. Con el SDK de OpenAI, basta con establecer base_url en https://anyaigc.ai/v1.

Consejo: Kimi devuelve su razonamiento en el campo reasoning_content. En streaming, primero llegan los deltas de razonamiento y después la respuesta final. En chats de varios turnos y en llamadas a herramientas, reenvía sin cambios en la siguiente petición el mensaje completo del asistente que devuelve la API (incluidos reasoning_content y tool_calls).

Consulta la referencia de Chat Completions para ver todos los parámetros. Sustituye el nombre del modelo de los ejemplos de la documentación por el ID del modelo Kimi que quieras usar.

Claude Code

Usa Kimi en Claude Code

Cambia Claude Code a Kimi editando un solo archivo de configuración, y el agente de programación de tu terminal funcionará con Kimi.

  1. Instala Claude Code: usa el instalador oficial (por ejemplo, npm install -g @anthropic-ai/claude-code).
  2. Añade la configuración: edita ~/.claude/settings.json, añade el bloque env de abajo y sustituye ANTHROPIC_AUTH_TOKEN por la clave que creaste en AnyAIGC.
  3. Empieza a programar: ejecuta claude en la carpeta de tu proyecto. Escribe /model para confirmar que el modelo actual es kimi-k3.1-pro.

Cambiar de modelo: para usar un modelo de programación más barato, sustituye cada kimi-k3.1-pro de la configuración por kimi-k2.7-code. K3.1 Pro tiene una ventana de contexto de 1M para repositorios grandes; K2.7 Code cuesta aproximadamente la mitad.

Para ver la guía completa y los errores comunes, consulta la guía de configuración de Claude Code. Sustituye en la guía el nombre del modelo por kimi-k3.1-pro.

Preguntas frecuentes

Preguntas frecuentes sobre la API de Kimi

¿Cuánto cuesta la API de Kimi?

Los modelos Kimi en AnyAIGC se facturan por token. Por millón de tokens: kimi-k3.1-pro entrada $0.8100, salida $4.0500, acierto de caché $0.0810; kimi-k3 entrada $1.2150, salida $6.0750, acierto de caché $0.1215; kimi-k2.7-code entrada $0.3847, salida $1.5980, acierto de caché $0.0770; kimi-k2.6 entrada $0.3847, salida $1.5980, acierto de caché $0.0651. Eso equivale a aproximadamente el 40 % de los precios oficiales de Moonshot en USD. Consulta el catálogo de modelos para ver los precios en tiempo real.

¿Qué modelos Kimi hay en AnyAIGC y cuáles son sus ID de modelo?

Esta página cubre cuatro: kimi-k3.1-pro (el primer modelo de la serie K3.1, con una ventana de contexto de 1M), kimi-k3 (el modelo insignia de la generación anterior, un modelo de pesos abiertos con 2.8T de parámetros), kimi-k2.7-code (un modelo de agente de programación) y kimi-k2.6 (un modelo de agente multimodal de uso general). Pon el ID del modelo en el campo model del cuerpo de la petición. Para cambiar de modelo solo tienes que modificar ese campo.

¿Qué debería usar: Kimi K3.1 Pro, K3, K2.7 Code o K2.6?

Elige Kimi K3.1 Pro cuando necesites una ventana de contexto de 1M, la programación de larga duración más exigente, creación 3D o investigación financiera. Es la generación más reciente y cuesta aproximadamente un tercio menos que K3. Las cargas de trabajo que ya usan K3 pueden quedarse ahí. Elige K2.7 Code para la programación diaria y los agentes de programación; según Moonshot, puntúa un 21.8 % más que K2.6 en Kimi Code Bench v2. Elige K2.6 cuando quieras el modo sin razonamiento, respuestas rápidas o chat general. K2.7 Code y K2.6 cuestan lo mismo, aproximadamente la mitad que K3.1 Pro.

¿La API de Kimi es compatible con OpenAI?

Sí. Los cuatro modelos usan POST https://anyaigc.ai/v1/chat/completions con el mismo formato de petición y respuesta que OpenAI Chat Completions. Con el SDK oficial de OpenAI, establece base_url en https://anyaigc.ai/v1. La traza de razonamiento se devuelve en el campo reasoning_content.

¿Puedo usar Kimi en Claude Code?

Sí. En el bloque env de ~/.claude/settings.json, establece ANTHROPIC_BASE_URL en https://anyaigc.ai, ANTHROPIC_AUTH_TOKEN en tu clave de API y ANTHROPIC_MODEL en kimi-k3.1-pro. Después ejecuta claude.

¿Qué tamaño tiene la ventana de contexto?

Según Moonshot, Kimi K3.1 Pro y K3 admiten una ventana de contexto de 1.048.576 tokens; K2.7 Code y K2.6 admiten 262.144 tokens (256K). Los cuatro aceptan imágenes como entrada y admiten llamadas a herramientas.

¿Los modelos Kimi son de código abierto? ¿Puedo usarlos con fines comerciales?

Moonshot AI ha publicado en Hugging Face los pesos de Kimi K3, K2.7 Code y K2.6, y Moonshot indica que los pesos completos de K3.1 Pro se publicarán a más tardar el 4 de noviembre de 2026. Si llamas a la API a través de AnyAIGC, no necesitas alojarlos tú mismo. Las licencias de los modelos y el uso comercial se rigen por los términos oficiales de Moonshot AI.

¿Hay límites de concurrencia o de peticiones?

AnyAIGC no limita la concurrencia de los modelos Kimi, y todos los usuarios la tienen por defecto. Es adecuado para trabajos por lotes, pipelines de CI y agentes en paralelo. La plataforma propia de Moonshot limita la concurrencia, las RPM, los TPM y los TPD según el nivel de recarga; esos niveles no se aplican cuando llamas a través de AnyAIGC.

¿Cómo obtengo una clave de API de Kimi?

Regístrate en anyaigc.ai, recarga saldo y crea una clave en la consola. La misma clave sirve para todos los modelos Kimi y para más de 300 modelos adicionales de la plataforma, así que no necesitas una cuenta aparte en la plataforma de Moonshot.

¿Puedo obtener una factura de AnyAIGC?

Sí. Puedes emitir tus propias facturas en la consola, por el importe que hayas recargado realmente.

¿Qué métodos de pago se admiten?

Puedes recargar saldo con WeChat Pay, Alipay, USDT o tarjeta de crédito. Tu saldo está en USD y sirve para todos los modelos de la plataforma. Las facturas se pueden emitir en la consola por el importe recargado.

¿Hay crédito de prueba gratuito para usuarios nuevos?

Sí. Las cuentas nuevas reciben 2 millones de tokens de crédito de prueba para que pruebes antes de decidir si recargas saldo. Las recargas empiezan en $1.

¿Puedo pedir el reembolso de mi saldo?

Sí. El saldo no utilizado se puede reembolsar sin comisión. Contacta con soporte para iniciar el reembolso.

¿Son los modelos reales? ¿Están seguros mis datos?

Las peticiones van a los canales oficiales de los modelos, nunca a sustitutos más baratos o de ingeniería inversa. Salvo que la ley lo exija, no almacenamos de forma persistente tus prompts ni tus resultados, ni los usamos para entrenar modelos, y la consola muestra los tokens y el coste de cada petición.

¿Se usarán mis datos para entrenar modelos?

No. Salvo que lo exija la ley, AnyAIGC no almacena de forma persistente tus prompts ni las salidas y no los usa para entrenar modelos. Las peticiones se cifran mediante HTTPS. Consulta la Política de privacidad de AnyAIGC. La política de datos del propio modelo se rige por las condiciones oficiales de Moonshot AI.
