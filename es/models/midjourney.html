API de Midjourney

Llama a Midjourney por HTTP: un prompt devuelve una cuadrícula de cuatro, y después puedes ampliar, variar, alejar (zoom out) o repintar una región. Imagine cuesta $0,0595 por llamada y las ampliaciones y describe $0,0298, con concurrencia sin límite.

#Cómo funciona la API de Midjourney

Replica la aplicación web y Discord: generas una cuadrícula de cuatro y luego pulsas botones sobre el resultado. La API te entrega todos los botones; devuelve su customId para ejecutarlo.

  1. 01

    POST/mj/submit/imagine

    Enviar un prompt

    Devuelve un ID de tarea. Escribe --ar, --v o --niji directamente en el prompt. $0,0595 por llamada

  2. 02

    GET/mj/task/{id}/fetch

    Consultar la tarea

    Sondea (polling) hasta que aparezca SUCCESS para obtener imageUrl y la lista buttons. Consultar es gratis

  3. 03

    POST/mj/submit/action

    Pulsar un botón

    Envía el taskId y el customId de un botón: ampliaciones $0,0298; variaciones, zoom y pan $0,0595

  4. 04

    POST/mj/submit/modal

    Confirmar el modal

    Variar (Region) y Custom Zoom necesitan un segundo paso con una máscara o un nuevo prompt. $0,0595 por llamada

#Qué puedes hacer con la API de Midjourney

  • Imagine

    Un prompt devuelve cuatro candidatos, con prompts de imagen opcionales mediante base64Array. Midjourney es conocido por la luz, la textura y la composición, tanto en fotografía como en ilustración.

  • Niji para anime e ilustración

    Define botType como NIJI_JOURNEY para cambiar a Niji, pensado para estilos anime, manga e ilustrados.

  • Variaciones

    V1-V4 hacen variaciones sobre una imagen. Variar (Strong) se aleja más; Variar (Subtle) solo la retoca un poco.

  • Ampliar

    U1-U4 extraen una sola imagen, y después las ampliaciones Subtle o Creative la dejan lista para publicar.

  • Alejar (zoom out) y desplazar (pan)

    Amplía el encuadre 1,5x o 2x, o extiéndelo en una dirección, por ejemplo para convertir un retrato en un paisaje.

  • Mezclar y describir

    Fusiona de 2 a 5 imágenes en una nueva, o envía una imagen y recibe cuatro prompts que la describen.

#Preguntas frecuentes sobre la API de Midjourney

¿Cuánto cuesta la API de Midjourney?

AnyAIGC factura Midjourney por llamada: Imagine, Blend, Variation, Reroll, Zoom, Pan y Modal cuestan $0,0595 cada uno, Upscale y Describe $0,0298, la subida de imágenes $0,000595, y Custom Zoom y Variar (Region) son gratuitos (su paso Modal se factura como Modal). Consultar tareas es gratis y los precios en tiempo real están en el catálogo de modelos.

¿Midjourney tiene una API oficial?

Midjourney no ofrece actualmente una API pública; funciona en su sitio web y en Discord. AnyAIGC envuelve el servicio de Midjourney en endpoints HTTP, de modo que las imágenes salen de los propios modelos de Midjourney (incluido Niji) y no de un sustituto, y una sola clave de API permite ejecutar Imagine, ampliaciones, variaciones, zoom y más sin una cuenta de Discord propia.

¿Cuáles son las 14 operaciones y qué endpoints usan?

Los 14 nombres de modelo corresponden a 14 operaciones de Midjourney, todas en la tabla de precios de arriba. Imagine, Blend y Describe tienen sus propios endpoints. Upscale, Variation, Variar (Strong/Subtle), Reroll, Zoom, Pan, Custom Zoom y Variar (Region) pasan todos por /mj/submit/action, y la operación se elige con el customId del botón. Modal es el paso de confirmación y Upload envía imágenes de referencia.

¿Qué versiones de Midjourney se admiten? ¿Puedo usar Niji?

Elige la versión con el parámetro --v al final del prompt (la documentación de la API usa --v 6.1), escrito igual que en la app oficial y transmitido tal cual a Midjourney. Establece botType en NIJI_JOURNEY para el modelo de anime Niji; el valor predeterminado es MID_JOURNEY.

¿Cuántas imágenes devuelve una llamada?

Imagine, Variation, Reroll, Zoom, Pan y llamadas similares devuelven una cuadrícula de cuatro candidatos y se facturan una sola vez. Para obtener una única imagen de alta resolución, ejecuta Upscale sobre una de ellas.

¿Cómo hago ampliaciones y variaciones?

Consulta la tarea con /mj/task/{id}/fetch. Cada elemento de buttons tiene un customId; envía el ID de tarea y ese customId a /mj/submit/action. Toma siempre el customId de la respuesta en lugar de construirlo tú mismo.

¿Hay un límite de concurrencia?

No. AnyAIGC no fija ningún límite de concurrencia para Midjourney en ninguna cuenta, así que puedes enviar tareas en paralelo. Todas las peticiones van a la URL base https://anyaigc.ai y la misma clave sirve para más de 300 modelos.

¿Puedo obtener una factura de AnyAIGC?

Sí. Puedes emitir tus propias facturas en la consola, por el importe que hayas recargado realmente.

¿Qué métodos de pago se admiten?

Puedes recargar saldo con WeChat Pay, Alipay, USDT o tarjeta de crédito. Tu saldo está en USD y sirve para todos los modelos de la plataforma. Las facturas se pueden emitir en la consola por el importe recargado.

¿Hay crédito de prueba gratuito para usuarios nuevos?

Sí. Las cuentas nuevas reciben 2 millones de tokens de crédito de prueba para que pruebes antes de decidir si recargas saldo. Las recargas empiezan en $1.

¿Puedo pedir el reembolso de mi saldo?

Sí. El saldo no utilizado se puede reembolsar sin comisión. Contacta con soporte para iniciar el reembolso.

¿Son los modelos reales? ¿Están seguros mis datos?

Las peticiones van a los canales oficiales de los modelos, nunca a sustitutos más baratos o de ingeniería inversa. Salvo que la ley lo exija, no almacenamos de forma persistente tus prompts ni tus resultados, ni los usamos para entrenar modelos, y la consola muestra los tokens y el coste de cada petición.

¿Puedo usar las imágenes con fines comerciales?

Los derechos de uso y las políticas de contenido siguen los términos oficiales de Midjourney. AnyAIGC solo ofrece acceso a la API y no impone límites adicionales sobre cómo uses el resultado.
