Qué es Seedream 5.5

Seedream 5.5 es un modelo multimodal de generación de imágenes del equipo ByteDance Seed, descrito oficialmente como un modelo que eleva a la vez la creatividad y la ejecución precisa. Admite de texto a imagen, generación con una sola imagen y con varias referencias, y refuerza la coherencia en las ediciones de varios turnos, la generación nativa de imágenes RGBA y la separación en capas.

En AnyAIGC el ID del modelo es doubao-seedream-5-5-261028, que se sirve a través de /v1/images/generations, compatible con OpenAI, y se factura por niveles según la resolución de salida: desde $0.0229 por imagen en 1K / 1.5K, con las imágenes de entrada facturadas aparte. No necesitas una cuenta de Volcano Engine ni verificación de identidad.

Qué puede hacer Seedream 5.5

Estas cuatro capacidades proceden de la página oficial del modelo de ByteDance Seed y de la documentación de Volcano Engine Ark.

  • Ediciones coherentes de varios turnos

    Sigue revisando una misma imagen a lo largo de varias rondas y solo cambia la zona solicitada; la página oficial indica que los píxeles fuera del área editada pueden permanecer fijos.

  • Transparencia RGBA nativa

    Compatibilidad nativa con fondos transparentes y semitransparentes, de modo que un texto o unas imágenes de referencia pueden generar imágenes RGBA sin recortes manuales.

  • Separación en capas

    Divide una imagen en una imagen base más hasta 99 capas, y después sustitúyelas, muévelas o reorganízalas; la imagen base y cada capa se facturan por imagen.

  • OCR de texto enriquecido para texto normal

    En las capas de texto normal devuelve el texto, su posición y un estilo visual aproximado; el texto decorativo y el manuscrito no devuelven nada.

Las imágenes de ejemplo proceden de las páginas oficiales de modelos de ByteDance Seed, fueron generadas por el modelo Seedream correspondiente y ByteDance posee sus derechos de autor. Ver fuente

Empieza con la API de Seedream 5.5

  1. Regístrate en AnyAIGC. Las cuentas nuevas reciben 2M de tokens gratis y puedes recargar saldo desde $1.
  2. Crea una clave de API en la consola y guárdala en la variable de entorno ANYAIGC_API_KEY.
  3. Envía una petición a POST https://anyaigc.ai/v1/images/generations (compatible con OpenAI) con model establecido en doubao-seedream-5-5-261028.

5.5 devuelve 1 imagen por petición y no admite conjuntos de imágenes (sequential_image_generation), búsqueda web ni streaming. Para conjuntos de imágenes, cambia model a doubao-seedream-5-0-260128 (5.0 lite).

Autentica con Authorization: Bearer <API Key>. La respuesta tiene la forma {"created": ..., "data": [{"url": ...}]}; define response_format como b64_json para recibir base64. watermark es true por defecto, así que pasa false de forma explícita para obtener imágenes limpias. Los detalles de los campos están en la documentación de la API de Seedream de AnyAIGC.

Preguntas frecuentes sobre la API de Seedream 5.5

¿Cuánto cuesta la API de Seedream 5.5?

En AnyAIGC, Seedream 5.5 (doubao-seedream-5-5-261028) se factura por niveles según los píxeles de cada imagen de salida: 1K / 1.5K (hasta ≤ 2.601.123 píxeles) cuesta $0.0229 / imagen, 2K (2.601.124 ~ 4.624.220 píxeles) cuesta $0.0402 / imagen, y si omites size se factura 2K. Las imágenes de entrada (cada imagen de referencia, o la imagen de origen que quieres dividir) cuestan $0.00918 / imagen. En la separación en capas, la imagen base y cada capa se facturan por imagen. Se factura cada generación correcta; los precios en tiempo real están en el catálogo de modelos.

¿Qué es Seedream 5.5?

Seedream 5.5 es un modelo multimodal de generación de imágenes del equipo ByteDance Seed, descrito oficialmente como un modelo que eleva a la vez la creatividad y la ejecución precisa. Admite de texto a imagen, generación con una sola imagen y con varias referencias, y refuerza la coherencia en las ediciones de varios turnos, la generación nativa de imágenes RGBA y la separación en capas.

¿Qué resoluciones admite? ¿Puede generar 4K?

No hay 4K. Según la documentación de Volcano Engine Ark, 5.5 acepta valores de size de 1K, 1.5K y 2K (2K por defecto) para generar imágenes, o dimensiones en píxeles de ancho x alto con un total de entre 921.600 (1280x720) y 4.624.220 píxeles y relaciones de aspecto de 1:16 a 16:1. Para 4K, usa Seedream 5.0 lite o 4.5.

¿Cuántas imágenes de referencia puedo enviar? ¿Admite conjuntos de imágenes?

image admite hasta 10 imágenes de referencia para edición y fusión de varias imágenes, y cada una se factura como imagen de entrada. 5.5 devuelve 1 imagen por petición y no admite conjuntos de imágenes, búsqueda web ni streaming; usa 5.0 lite, 4.5 o 4.0 para conjuntos de imágenes.

¿Qué pueden hacer la separación en capas y la salida RGBA?

La separación en capas divide una imagen en una imagen base más hasta 99 capas, y en las capas de texto normal puede devolver el texto, su posición y un estilo visual aproximado (OCR de texto enriquecido); el texto decorativo o manuscrito no devuelve nada. 5.5 también admite de forma nativa fondos transparentes y semitransparentes, así que puede generar imágenes RGBA directamente. Los campos de la petición de estas funciones siguen la documentación oficial y la documentación de la API de AnyAIGC; contacta con soporte para confirmarlos antes de integrar.

¿Elijo 5.5 o 5.0 Pro?

5.5 empieza más bajo (desde $0.0229 / imagen frente a $0.0441 de 5.0 Pro), separa hasta 99 capas y puede generar imágenes RGBA a partir de texto; 5.0 Pro separa hasta 16 capas y no genera RGBA solo a partir de texto. Ambos llegan como máximo a 2K, aceptan hasta 10 imágenes de referencia y no tienen conjuntos de imágenes. Consulta Seedream 5.0 Pro para ver sus otras fortalezas.

¿Hay límite de concurrencia? ¿Qué necesito para registrarme?

AnyAIGC no fija ningún límite de concurrencia en Seedream 5.5, y todas las cuentas lo tienen por defecto. La URL base es https://anyaigc.ai. No necesitas una cuenta de Volcano Engine ni verificación de identidad, y la misma clave también funciona con más de 300 modelos de la plataforma.

¿Puedo obtener una factura de AnyAIGC?

Sí. Puedes emitir tus propias facturas en la consola, por el importe que hayas recargado realmente.

¿Qué métodos de pago se admiten?

Puedes recargar saldo con WeChat Pay, Alipay, USDT o tarjeta de crédito. Tu saldo está en USD y sirve para todos los modelos de la plataforma. Las facturas se pueden emitir en la consola por el importe recargado.

¿Hay crédito de prueba gratuito para usuarios nuevos?

Sí. Las cuentas nuevas reciben 2 millones de tokens de crédito de prueba para que pruebes antes de decidir si recargas saldo. Las recargas empiezan en $1.

¿Puedo pedir el reembolso de mi saldo?

Sí. El saldo no utilizado se puede reembolsar sin comisión. Contacta con soporte para iniciar el reembolso.

¿Son los modelos reales? ¿Están seguros mis datos?

Las peticiones van a los canales oficiales de los modelos, nunca a sustitutos más baratos o de ingeniería inversa. Salvo que la ley lo exija, no almacenamos de forma persistente tus prompts ni tus resultados, ni los usamos para entrenar modelos, y la consola muestra los tokens y el coste de cada petición.

¿Puedo usar las imágenes con fines comerciales? ¿Puedo quitar la marca de agua?

Los derechos de uso y las políticas de contenido se rigen por los términos oficiales de ByteDance / Volcano Engine. Define watermark como false en la petición y no se añadirá la marca «generado por IA» en la esquina inferior derecha. AnyAIGC solo ofrece acceso a la API y no añade restricciones adicionales sobre cómo usas el resultado; para retratos de personas reales, logotipos de marca y contenido similar, asegúrate de tener los derechos necesarios.
