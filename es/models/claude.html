La API nativa de Anthropic, con compatibilidad completa

Las peticiones usan el formato Messages de Anthropic, así que los SDK oficiales y tu código actual siguen funcionando.

  • API Messages

    Llama a /v1/messages. Con el SDK oficial de Anthropic, define la URL base como https://anyaigc.ai.

  • Caché de prompts

    Añade cache_control a un bloque de contenido para usar caché de 5 minutos o de 1 hora. Los aciertos de caché cuestan aproximadamente el 2,5–10% del precio de entrada normal.

  • Uso de herramientas y salida estructurada

    Define funciones con tools o restringe la salida con un esquema JSON para integrarla en tus sistemas.

  • Razonamiento adaptativo

    Usa el parámetro thinking y el nivel de esfuerzo (effort). Según la documentación de Anthropic, modelos como Fable 5.1 y Sonnet 5 usan razonamiento adaptativo de forma predeterminada; consulta la página de cada modelo.

  • Entrada de imágenes y PDF

    La documentación de AnyAIGC incluye ejemplos con documentos PDF, y la de Anthropic cubre la entrada de imágenes en los modelos Claude.

  • Streaming

    Define "stream": true para recibir la salida a medida que se genera, ideal para interfaces de chat y respuestas largas.

Empieza en tres pasos

  1. Regístrate y recarga saldo: crea una cuenta en anyaigc.ai. Tu saldo sirve para todos los modelos de la plataforma.
  2. Crea una clave de API: crea un token en la consola y copia la clave que empieza por sk-.
  3. Envía una petición: llama a https://anyaigc.ai/v1/messages con una petición en formato Messages de Anthropic y autentícate con Authorization: Bearer.

Para más parámetros (tools, thinking, streaming, entrada de PDF e imágenes y más), consulta la documentación de la API Messages de AnyAIGC. Los campos significan lo mismo que en la documentación de la API de Anthropic.

Preguntas frecuentes sobre la API de Claude

¿Cuánto cuesta la API de Claude?

Todos los modelos de Claude en AnyAIGC se facturan por token, en USD por millón de tokens, sin suscripción ni cuota mensual. Modelos actuales: Opus 5.5 a $0,4765 de entrada y $2,3820 de salida; Sonnet 5.5 a $0,2382 de entrada y $1,1910 de salida; Haiku 5.5 a $0,0119 de entrada y $0,0596 de salida; Fable 5.2 a $1,9060 de entrada y $9,5290 de salida. Opus, Sonnet y Haiku tienen un 88% de descuento sobre el precio de lista de Anthropic, y Fable un 76%. Las escrituras en caché, los aciertos de caché y los modelos de generación anterior aparecen en la tabla de precios de esta página; consulta el catálogo de modelos de AnyAIGC para ver los precios en tiempo real.

¿Cómo obtengo una clave de API de Claude?

Regístrate en anyaigc.ai, recarga saldo y crea un token en la consola. La misma clave sirve para los 11 modelos de Claude de esta página y para más de 300 modelos de la plataforma, todos con cargo a un único saldo.

¿Funciona la API de Claude de AnyAIGC con los SDK oficiales de Anthropic?

Sí. El endpoint es https://anyaigc.ai/v1/messages y el cuerpo de la petición sigue el formato Messages de Anthropic (model, max_tokens, system, messages, tools, cache_control, etc.). Autentícate con Authorization: Bearer y tu clave de API. Con el SDK oficial de anthropic, define base_url como https://anyaigc.ai y el resto de tu código no cambia.

¿Qué modelos de Claude hay disponibles y cuál debo usar?

AnyAIGC ofrece 11 modelos de Claude. Los actuales son Opus 5.5, Sonnet 5.5, Haiku 5.5 y Fable 5.2. Usa Opus 5.5 para programación compleja y agentes de IA; Sonnet 5.5 para programación cotidiana bien delimitada, corrección de errores y documentos; Haiku 5.5, que Anthropic describe como el modelo más rápido y eficiente de la familia Claude 5.5, para clasificación de alto volumen, atención en tiempo real y subagentes; y Fable 5.2 para el trabajo técnico abierto más ambicioso y los agentes de larga duración. El anterior Fable 5.1 y los modelos de generación anterior Opus 5, Fable 5, Sonnet 5, Opus 4.8, Opus 4.7 y Opus 4.6 siguen disponibles para proyectos existentes.

¿Cuál es la diferencia entre Claude Opus y Sonnet?

Anthropic presenta Sonnet 5.5 como un complemento más rápido y económico de Opus 5.5. Opus 5.5 está pensado para trabajo complejo que requiere buen criterio; Sonnet 5.5 está pensado para tareas cotidianas bien delimitadas, corrección de errores y documentos, presentaciones y hojas de cálculo bien acabados. Sonnet 5.5 cuesta la mitad: en AnyAIGC son $0,2382 de entrada y $1,1910 de salida, frente a $0,4765 y $2,3820 de Opus 5.5 (por millón de tokens).

¿Cuál es la diferencia entre Claude Fable y Opus?

Anthropic describe Fable 5.2 como inteligencia de nueva generación para agentes de larga duración, diseñada para el trabajo técnico abierto más ambicioso. Anthropic recomienda empezar la mayor parte del trabajo de programación y de conocimiento con Claude Opus 5.5 y pasar a Fable cuando haga falta. En AnyAIGC, Fable 5.2 cuesta $1,9060 de entrada y $9,5290 de salida por millón de tokens, frente a $0,4765 y $2,3820 de Opus 5.5. Ambos usan la misma clave, así que puedes cambiar según la tarea modificando el campo model.

¿Puedo seguir usando modelos de Claude más antiguos?

Sí. Anthropic lista Opus 5, Fable 5, Sonnet 5, Opus 4.8, Opus 4.7 y Opus 4.6 como generación anterior, y todos siguen disponibles en AnyAIGC. Las fechas de retirada más tempranas de Anthropic son el 5 de febrero de 2027 para Opus 4.6, el 16 de abril de 2027 para Opus 4.7, el 28 de mayo de 2027 para Opus 4.8, el 9 de junio de 2027 para Fable 5, el 30 de junio de 2027 para Sonnet 5 y el 24 de julio de 2027 para Opus 5. El anterior Fable 5.1 también sigue disponible. Para proyectos nuevos, usa el modelo actual equivalente.

¿Puedo usarlo con Claude Code?

Sí. Ejecuta curl -fsSL https://www.anyaigc.ai/install.sh | bash -s claude para instalar y configurar todo, o define ANTHROPIC_BASE_URL como https://anyaigc.ai, ANTHROPIC_AUTH_TOKEN como tu clave de API y ANTHROPIC_MODEL como claude-opus-5-5 en el bloque env de ~/.claude/settings.json. Define ANTHROPIC_DEFAULT_HAIKU_MODEL como claude-haiku-5-5 para ejecutar las tareas en segundo plano y los subagentes con Haiku 5.5.

¿Hay límites de concurrencia?

No. AnyAIGC no limita la concurrencia en ningún modelo de Claude y todos los usuarios lo tienen de forma predeterminada, así que los trabajos por lotes y los agentes en paralelo no tienen que hacer cola.

¿Puedo obtener una factura de AnyAIGC?

Sí. Puedes emitir tus propias facturas en la consola, por el importe que hayas recargado realmente.

¿Qué métodos de pago se admiten?

Puedes recargar saldo con WeChat Pay, Alipay, USDT o tarjeta de crédito. Tu saldo está en USD y sirve para todos los modelos de la plataforma. Las facturas se pueden emitir en la consola por el importe recargado.

¿Hay crédito de prueba gratuito para usuarios nuevos?

Sí. Las cuentas nuevas reciben 2 millones de tokens de crédito de prueba para que pruebes antes de decidir si recargas saldo. Las recargas empiezan en $1.

¿Puedo pedir el reembolso de mi saldo?

Sí. El saldo no utilizado se puede reembolsar sin comisión. Contacta con soporte para iniciar el reembolso.

¿Son los modelos reales? ¿Están seguros mis datos?

Las peticiones van a los canales oficiales de los modelos, nunca a sustitutos más baratos o de ingeniería inversa. Salvo que la ley lo exija, no almacenamos de forma persistente tus prompts ni tus resultados, ni los usamos para entrenar modelos, y la consola muestra los tokens y el coste de cada petición.
