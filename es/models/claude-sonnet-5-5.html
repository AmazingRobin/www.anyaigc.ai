Qué es Claude Sonnet 5.5

  • NUEVO28 sep 2026

    El segundo modelo de la familia Claude 5.5

    Anthropic lanzó Claude Sonnet 5.5 el 28 de septiembre de 2026 como un complemento más rápido y económico de Opus 5.5. Según Anthropic, es una mejora clara respecto a Sonnet 5: funciona más de un 30% más rápido y cuesta hasta un 30% menos en la mayoría de los trabajos. Opus 5.5 está pensado para trabajo complejo que exige un criterio cuidadoso; Sonnet 5.5 está pensado para tareas cotidianas bien delimitadas, corrección de errores y documentos, presentaciones y hojas de cálculo bien acabados.

Llama a la API de Claude Sonnet 5.5 en tres pasos

  1. Regístrate y recarga saldo: crea una cuenta en anyaigc.ai. Tu saldo sirve para todos los modelos de la plataforma.
  2. Crea una clave de API: crea un token en la consola y copia la clave que empieza por sk-.
  3. Envía una petición: haz un POST con una petición Anthropic Messages a https://anyaigc.ai/v1/messages y autentícate con Authorization: Bearer.

Para ver más parámetros (herramientas, thinking, streaming, entrada de PDF e imágenes y más), consulta la documentación de la API Messages de AnyAIGC. Los campos se comportan igual que en la documentación oficial de Anthropic.

Preguntas frecuentes sobre la API de Claude Sonnet 5.5

¿Cuánto cuesta la API de Claude Sonnet 5.5?

En AnyAIGC, claude-sonnet-5-5 se factura por token: $0.2382 por millón de tokens de entrada, $1.191 por millón de tokens de salida, $0.2978 por escritura en caché de 5 minutos, $0.4765 por escritura en caché de 1 hora y $0.0119 por acierto de caché. El precio de lista de Anthropic es $2 de entrada y $10 de salida, así que AnyAIGC queda en aproximadamente el 11.9% del precio de lista.

¿Cuál es el ID del modelo Claude Sonnet 5.5?

El ID del modelo es claude-sonnet-5-5. Ponlo en el campo model del cuerpo de la petición.

¿En qué destaca Claude Sonnet 5.5 y debo elegir Sonnet 5.5 u Opus 5.5?

Anthropic describe Sonnet 5.5 como un complemento más rápido y económico de Opus 5.5. Opus 5.5 está pensado para trabajo complejo que exige un criterio cuidadoso, mientras que Sonnet 5.5 destaca en tareas cotidianas bien delimitadas, corrección de errores y creación de documentos, presentaciones y hojas de cálculo bien acabados. Los precios de lista son $2 de entrada / $10 de salida para Sonnet 5.5 y $4 / $20 para Opus 5.5. Una opción práctica por defecto es Sonnet 5.5 para la programación cotidiana y las llamadas de alto volumen, y cambiar a claude-opus-5-5 para las tareas más difíciles.

¿Es la API de Claude de AnyAIGC compatible con la API oficial de Anthropic?

Sí. El endpoint es https://anyaigc.ai/v1/messages y el cuerpo de la petición sigue el formato Anthropic Messages (model, max_tokens, system, messages, tools, cache_control, etc.). Autentícate con Authorization: Bearer seguido de tu clave de API. Con el SDK oficial, basta con establecer la URL base en https://anyaigc.ai.

¿Puedo usar Claude Sonnet 5.5 en Claude Code?

Sí. En el bloque env de ~/.claude/settings.json, establece ANTHROPIC_BASE_URL en https://anyaigc.ai, ANTHROPIC_AUTH_TOKEN en tu clave de API, y tanto ANTHROPIC_MODEL como ANTHROPIC_DEFAULT_SONNET_MODEL en claude-sonnet-5-5; después ejecuta claude. También puedes instalar y configurarlo todo con un solo comando: curl -fsSL https://www.anyaigc.ai/install.sh | bash.

¿Cómo se factura la caché de prompts?

Añade cache_control a un bloque de contenido para activar la caché. La primera escritura se factura a la tarifa de escritura en caché ($0.2978 por 5 minutos o $0.4765 por 1 hora, por millón de tokens). Después, los tokens en caché cuestan solo $0.0119 por millón, el 5% del precio normal de entrada. La caché funciona bien con prompts de sistema largos, contexto de bases de código y tareas de agentes de varios turnos.

¿Hay límites de concurrencia o de peticiones?

AnyAIGC no fija ningún límite de concurrencia para claude-sonnet-5-5. Todas las cuentas lo tienen por defecto, así que es adecuado para trabajos por lotes y para ejecutar varios agentes en paralelo.

¿Cómo obtengo una clave de API de Claude Sonnet 5.5?

Regístrate en anyaigc.ai, añade saldo y crea un token en la consola. La misma clave sirve para Claude Sonnet 5.5 y para más de 300 modelos de la plataforma.

¿Puedo obtener una factura de AnyAIGC?

Sí. Puedes emitir tus propias facturas en la consola, por el importe que hayas recargado realmente.

¿Qué métodos de pago se admiten?

Puedes recargar saldo con WeChat Pay, Alipay, USDT o tarjeta de crédito. Tu saldo está en USD y sirve para todos los modelos de la plataforma. Las facturas se pueden emitir en la consola por el importe recargado.

¿Hay crédito de prueba gratuito para usuarios nuevos?

Sí. Las cuentas nuevas reciben 2 millones de tokens de crédito de prueba para que pruebes antes de decidir si recargas saldo. Las recargas empiezan en $1.

¿Puedo pedir el reembolso de mi saldo?

Sí. El saldo no utilizado se puede reembolsar sin comisión. Contacta con soporte para iniciar el reembolso.

¿Son los modelos reales? ¿Están seguros mis datos?

Las peticiones van a los canales oficiales de los modelos, nunca a sustitutos más baratos o de ingeniería inversa. Salvo que la ley lo exija, no almacenamos de forma persistente tus prompts ni tus resultados, ni los usamos para entrenar modelos, y la consola muestra los tokens y el coste de cada petición.

¿Se usan mis datos para entrenamiento?

Las peticiones se cifran en tránsito mediante HTTPS. Consulta la Política de privacidad de AnyAIGC para conocer cómo se tratan los datos. La política de datos del propio modelo se rige por los términos oficiales de Anthropic.
