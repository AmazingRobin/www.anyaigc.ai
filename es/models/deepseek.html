Inicio rápido

Empieza con la API de DeepSeek en tres pasos

  1. Regístrate y recarga saldo: crea una cuenta en anyaigc.ai. Recarga desde $1; tu saldo sirve para todos los modelos de la plataforma.
  2. Crea una clave de API: crea una clave en la consola, copia la clave sk- y guárdala en la variable de entorno ANYAIGC_API_KEY.
  3. Envía una petición: llama a POST https://anyaigc.ai/v1/chat/completions con model igual a deepseek-v4.1-flash y una cabecera Authorization: Bearer. Con el SDK de OpenAI, basta con establecer base_url en https://anyaigc.ai/v1.

Parámetros: Según DeepSeek, la serie V4 razona por defecto. El campo thinking del cuerpo de la petición lo activa o desactiva ({"type": "enabled"} o {"type": "disabled"}), y reasoning_effort define la profundidad (oficialmente low / high / max). Los tokens de razonamiento cuentan como salida y aparecen en usage.completion_tokens_details.reasoning_tokens. Los parámetros de muestreo como temperature no tienen efecto en el modo de razonamiento.

Consulta la referencia de la API Chat Completions para ver todos los parámetros. En los ejemplos de la documentación, sustituye el nombre del modelo por el ID del modelo de DeepSeek que quieras usar.

Claude Code

Usa DeepSeek en Claude Code

Conecta Claude Code a DeepSeek: edita un solo archivo de configuración y tu agente de programación en la terminal funcionará con DeepSeek V4.1 Flash, con facturación por token.

  1. Instala Claude Code: usa el instalador oficial, por ejemplo curl -fsSL https://claude.ai/install.sh | bash en macOS o Linux.
  2. Añade la configuración: edita ~/.claude/settings.json, añade el bloque env de abajo y sustituye ANTHROPIC_AUTH_TOKEN por la clave que creaste en AnyAIGC.
  3. Empieza a programar: ejecuta claude en la carpeta de tu proyecto. Escribe /model para comprobar que el modelo actual es deepseek-v4.1-flash.

Cambiar de modelo: para usar V4 Pro, sustituye deepseek-v4.1-flash por deepseek-v4-pro en la configuración. También puedes mantener ANTHROPIC_DEFAULT_HAIKU_MODEL en V4.1 Flash para las subtareas ligeras.

Para ver los pasos completos y los errores más comunes, consulta la guía de configuración de Claude Code. En la guía, sustituye el nombre del modelo por deepseek-v4.1-flash.

Preguntas frecuentes

Preguntas frecuentes sobre la API de DeepSeek

¿Cuánto cuesta la API de DeepSeek?

DeepSeek en AnyAIGC se factura por token. Por millón de tokens: deepseek-v4.1-flash cuesta $0,1215 de entrada, $0,4860 de salida y $0,0024 por acierto de caché; deepseek-v4-pro cuesta $0,5346 de entrada, $1,6038 de salida y $0,0178 por acierto de caché; deepseek-v4-flash tiene el mismo precio que V4.1 Flash. Los precios en tiempo real aparecen en el catálogo de modelos.

¿AnyAIGC tiene tarifas de hora punta y de fuera de hora punta?

No. La API oficial de DeepSeek aplica precios según la hora del día: de lunes a viernes, de 01:00 a 04:00 y de 06:00 a 10:00 UTC (9:00–12:00 y 14:00–18:00, hora de Pekín) es hora punta, y los precios en hora punta son el doble que fuera de hora punta. En AnyAIGC, todos los modelos de DeepSeek se facturan a una sola tarifa todo el día. Esa tarifa es aproximadamente un 60 % menos que el precio oficial en hora punta. Los precios en tiempo real aparecen en el catálogo de modelos.

¿Qué modelos de DeepSeek ofrece AnyAIGC y cuáles son sus IDs?

Esta página cubre tres: deepseek-v4.1-flash (el modelo Flash más reciente de DeepSeek, con visión nativa), deepseek-v4-pro (el modelo insignia de V4, con 1,6T de parámetros) y deepseek-v4-flash (el modelo Flash en versión preliminar de V4, que DeepSeek ha sustituido por V4.1 Flash). Indica el ID del modelo en el campo model del cuerpo de la petición. Para cambiar de modelo, solo tienes que modificar ese campo.

¿Debo usar V4.1 Flash o V4 Pro?

Empieza con V4.1 Flash para la mayoría de las tareas. Según DeepSeek, ya supera a V4 Pro en rendimiento, coste, velocidad y tiempo total de tarea, su precio de entrada es aproximadamente una cuarta parte del de V4 Pro y puede leer imágenes. Si ya tienes V4 Pro ajustado en producción, puedes seguir usando V4 Pro: DeepSeek ha dicho que seguirá ofreciendo la API de V4 Pro después del 14 de septiembre de 2026.

¿Qué tamaño tiene la ventana de contexto? ¿Puedo enviar imágenes?

DeepSeek indica un contexto de 1M de tokens y hasta 384K tokens de salida tanto para V4.1 Flash como para V4 Pro. Solo V4.1 Flash acepta imágenes; V4 Pro y V4 Flash admiten únicamente texto.

¿La API de DeepSeek es compatible con OpenAI?

Sí. Los tres modelos usan POST https://anyaigc.ai/v1/chat/completions con el mismo formato de petición y respuesta que OpenAI Chat Completions. Con el SDK oficial de OpenAI, define base_url como https://anyaigc.ai/v1. También se admite el formato de Anthropic, por lo que Claude Code funciona.

¿Puedo usar DeepSeek en Claude Code?

Sí. Los modelos de DeepSeek en AnyAIGC admiten tanto el formato de API de OpenAI como el de Anthropic. En el bloque env de ~/.claude/settings.json, define ANTHROPIC_BASE_URL como https://anyaigc.ai, ANTHROPIC_AUTH_TOKEN como tu clave de API y ANTHROPIC_MODEL como deepseek-v4.1-flash, y luego ejecuta claude. Pagas por token.

¿Hay límites de concurrencia o de peticiones?

AnyAIGC no limita la concurrencia de la serie DeepSeek, y todos los usuarios lo tienen por defecto. Es ideal para trabajos por lotes, pipelines de CI y agentes en paralelo.

¿Cómo obtengo una clave de API de DeepSeek?

Regístrate en anyaigc.ai, recarga saldo y crea una clave en la consola. La misma clave funciona con todos los modelos de DeepSeek y con más de 300 modelos de la plataforma, así que no necesitas una cuenta aparte en DeepSeek Platform.

¿Puedo obtener una factura de AnyAIGC?

Sí. Puedes emitir tus propias facturas en la consola, por el importe que hayas recargado realmente.

¿Qué métodos de pago se admiten?

Puedes recargar saldo con WeChat Pay, Alipay, USDT o tarjeta de crédito. Tu saldo está en USD y sirve para todos los modelos de la plataforma. Las facturas se pueden emitir en la consola por el importe recargado.

¿Hay crédito de prueba gratuito para usuarios nuevos?

Sí. Las cuentas nuevas reciben 2 millones de tokens de crédito de prueba para que pruebes antes de decidir si recargas saldo. Las recargas empiezan en $1.

¿Puedo pedir el reembolso de mi saldo?

Sí. El saldo no utilizado se puede reembolsar sin comisión. Contacta con soporte para iniciar el reembolso.

¿Son los modelos reales? ¿Están seguros mis datos?

Las peticiones van a los canales oficiales de los modelos, nunca a sustitutos más baratos o de ingeniería inversa. Salvo que la ley lo exija, no almacenamos de forma persistente tus prompts ni tus resultados, ni los usamos para entrenar modelos, y la consola muestra los tokens y el coste de cada petición.
