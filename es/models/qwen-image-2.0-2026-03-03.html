ESPECIFICACIONES

Especificaciones y cuándo elegirlo

qwen-image-2.0-2026-03-03 es una instantánea de qwen-image-2.0 con las mismas capacidades. Alibaba Cloud la describe como parte de la serie acelerada de Qwen para generación y edición de imágenes, que equilibra calidad y velocidad de respuesta.

El total de píxeles de salida debe estar entre 512×512 y 2048×2048, y la resolución predeterminada es 2048×2048.

Cada petición puede devolver de 1 a 6 imágenes.

Los prompts pueden tener hasta 1.300 tokens, frente a los 800 tokens de qwen-image-2.0-pro.

Esta página indica Salida de imagen a $0.0258 / imagen, igual que la tabla de precios anterior.

En comparación con qwen-image-3.0: qwen-image-3.0 acepta de 1 a 3 imágenes de entrada para imagen a imagen y edición, mientras que qwen-image-2.0-2026-03-03 pertenece a la serie acelerada que equilibra calidad y velocidad.

Las especificaciones proceden de la documentación oficial del proveedor (alibabacloud.com). La tabla de esta página muestra el precio, y el catálogo de modelos es la referencia para las tarifas en tiempo real.

Preguntas frecuentes sobre la API de Qwen Image 2.0

¿Para qué sirve Qwen Image 2.0?

Una instantánea acelerada de Qwen Image 2.0 que combina generación y edición, con hasta 1K tokens de instrucción.

¿Cómo se factura el uso de la API?

Salida de imagen $0.0258/imagen. Consulta el catálogo para ver los precios en tiempo real.

¿Hay un límite de concurrencia?

AnyAIGC no fija un límite de concurrencia para este modelo; está disponible de forma predeterminada.

¿Cómo obtengo una clave de API?

Crea una cuenta de AnyAIGC y luego crea una clave de API en la consola.

¿Puedo usar los resultados con fines comerciales?

El uso comercial se rige por las condiciones oficiales de Qwen y Alibaba Cloud.

¿Puedo obtener una factura de AnyAIGC?

Sí. Puedes emitir tus propias facturas en la consola, por el importe que hayas recargado realmente.

¿Qué métodos de pago se admiten?

Puedes recargar saldo con WeChat Pay, Alipay, USDT o tarjeta de crédito. Tu saldo está en USD y sirve para todos los modelos de la plataforma. Las facturas se pueden emitir en la consola por el importe recargado.

¿Hay crédito de prueba gratuito para usuarios nuevos?

Sí. Las cuentas nuevas reciben 5 millones de tokens de crédito de prueba.

¿Puedo pedir el reembolso de mi saldo?

Sí. El saldo no utilizado se puede reembolsar sin comisión.

¿Están seguros mis datos?

Los prompts y las salidas no se almacenan de forma persistente ni se usan para entrenamiento, salvo que la ley lo exija.
