Qué es Seedream 4.0

Seedream 4.0 es un modelo de imágenes multimodal del equipo ByteDance Seed que unifica texto a imagen, edición de imágenes y composición de varias imágenes en un solo marco. Razona sobre el prompt para elegir una relación de aspecto y un número de imágenes adecuados, y devuelve hasta 15 imágenes temáticamente relacionadas por petición.

ByteDance también informa de mejoras claras en la precisión del texto en chino y en la variedad de resultados, además de salida en 4K. En AnyAIGC el ID del modelo es doubao-seedream-4-0-250828, desde $0,0203 por imagen.

Empieza con la API de Seedream 4.0

  1. Regístrate en AnyAIGC. Las cuentas nuevas reciben 2M de tokens gratis y puedes recargar saldo desde $1.
  2. Crea una clave de API en la consola y guárdala en la variable de entorno ANYAIGC_API_KEY.
  3. Envía una petición a POST https://anyaigc.ai/v1/images/generations (compatible con OpenAI) con model establecido en doubao-seedream-4-0-250828.

De los tres modelos que admiten conjuntos de imágenes, 4.0 es el único con un nivel 1K, adecuado para trabajos por lotes que no necesitan alta resolución.

Autentica con Authorization: Bearer <API Key>. La respuesta tiene la forma {"created": ..., "data": [{"url": ...}]}; define response_format como b64_json para recibir base64. watermark es true por defecto, así que pasa false de forma explícita para obtener imágenes limpias. Los detalles de los campos están en la documentación de la API de Seedream de AnyAIGC.

Preguntas frecuentes sobre la API de Seedream 4.0

¿Cuánto cuesta la API de Seedream 4.0?

En AnyAIGC, Seedream 4.0 (doubao-seedream-4-0-250828) parte de $0,0203 / imagen. Los precios varían según la resolución; las tarifas en tiempo real de 2K y 4K están en el catálogo de modelos. Los conjuntos de imágenes se cobran por imagen generada. Solo se cobra por cada generación correcta; los precios en tiempo real están en el catálogo de modelos.

¿Qué es Seedream 4.0?

Seedream 4.0 es un modelo de imágenes multimodal del equipo ByteDance Seed, con el ID de modelo doubao-seedream-4-0-250828 en AnyAIGC. Unifica texto a imagen, edición de imágenes y composición de varias imágenes en un solo marco, elige una relación de aspecto y un número de imágenes adecuados a partir del prompt, devuelve hasta 15 imágenes relacionadas por petición y admite 4K.

¿Qué resoluciones se admiten?

Según la documentación de Volcano Engine Ark, 4.0 acepta valores de size de 1K, 2K y 4K, o dimensiones en píxeles, con relaciones de aspecto de 1:16 a 16:1.

¿Cuántas imágenes de referencia puedo enviar? ¿Qué tamaño puede tener un conjunto de imágenes?

image acepta hasta 14 imágenes de referencia (según la documentación actual de Volcano Engine Ark). Los conjuntos de imágenes devuelven hasta 15 imágenes por petición; con imágenes de referencia, las referencias más las imágenes generadas no pueden superar 15.

¿Sigue valiendo la pena usar 4.0?

4.0 sigue disponible, cuesta menos que 4.5 (desde $0,0203 / imagen) y ofrece un nivel 1K. Para proyectos nuevos, prueba primero 5.0 lite o 4.5. La API es idéntica, así que migrar solo cambia el ID del modelo.

¿Hay límite de concurrencia? ¿Qué necesito para registrarme?

AnyAIGC no fija ningún límite de concurrencia en Seedream 4.0, y todas las cuentas lo tienen por defecto. La URL base es https://anyaigc.ai. No necesitas una cuenta de Volcano Engine ni verificación de identidad, y la misma clave también funciona con más de 300 modelos de la plataforma.

¿Puedo obtener una factura de AnyAIGC?

Sí. Puedes emitir tus propias facturas en la consola, por el importe que hayas recargado realmente.

¿Qué métodos de pago se admiten?

Puedes recargar saldo con WeChat Pay, Alipay, USDT o tarjeta de crédito. Tu saldo está en USD y sirve para todos los modelos de la plataforma. Las facturas se pueden emitir en la consola por el importe recargado.

¿Hay crédito de prueba gratuito para usuarios nuevos?

Sí. Las cuentas nuevas reciben 2 millones de tokens de crédito de prueba para que pruebes antes de decidir si recargas saldo. Las recargas empiezan en $1.

¿Puedo pedir el reembolso de mi saldo?

Sí. El saldo no utilizado se puede reembolsar sin comisión. Contacta con soporte para iniciar el reembolso.

¿Son los modelos reales? ¿Están seguros mis datos?

Las peticiones van a los canales oficiales de los modelos, nunca a sustitutos más baratos o de ingeniería inversa. Salvo que la ley lo exija, no almacenamos de forma persistente tus prompts ni tus resultados, ni los usamos para entrenar modelos, y la consola muestra los tokens y el coste de cada petición.

¿Puedo usar las imágenes con fines comerciales? ¿Puedo quitar la marca de agua?

Los derechos de uso y las políticas de contenido se rigen por los términos oficiales de ByteDance / Volcano Engine. Define watermark como false en la petición y no se añadirá la marca «generado por IA» en la esquina inferior derecha. AnyAIGC solo ofrece acceso a la API y no añade restricciones adicionales sobre cómo usas el resultado; para retratos de personas reales, logotipos de marca y contenido similar, asegúrate de tener los derechos necesarios.
