Sobre el modelo

Eleven v3 Conversational: síntesis de voz (TTS) conversacional

Eleven v3 Conversational es la versión de v3 ajustada para conversación en tiempo real. Según ElevenLabs, conserva la expresividad dramática de v3 con menor latencia y admite etiquetas de audio personalizadas. El catálogo de modelos lo describe como un modelo pensado para conversar, relajado y natural, adecuado para el chat informal.

La documentación oficial indica una latencia de aproximadamente 165 ms para v3 Conversational (latencia de inferencia mediana, sin contar la latencia de red ni la de la aplicación) y más de 70 idiomas. La interfaz oficial de streaming en tiempo real no forma parte de lo que AnyAIGC ofrece hoy: el catálogo de modelos solo incluye POST /v1/audio/speech para este modelo.

En AnyAIGC, eleven_v3_conversational se factura según el número de caracteres de entrada, a la mitad del precio de Eleven v3 y sin límite de concurrencia.

Inicio rápido

Llama a la API de Eleven v3 Conversational en tres pasos

  1. Regístrate y recarga saldo: crea una cuenta en anyaigc.ai. Las recargas empiezan en $1 y el saldo sirve para todos los modelos de la plataforma.
  2. Crea una clave de API: crea un token en la consola, copia la clave que empieza por sk- y guárdala en la variable de entorno ANYAIGC_API_KEY.
  3. Envía una petición: llama a POST https://anyaigc.ai/v1/audio/speech con model igual a eleven_v3_conversational y voice igual a un voice_id de ElevenLabs, autentícate con Authorization: Bearer y guarda el audio devuelto como mp3.

Notas sobre los parámetros: el ID del modelo distingue mayúsculas y minúsculas, así que escribe eleven_v3_conversational. voice recibe un voice_id de ElevenLabs; si es desconocido o no está disponible, devuelve 400. La referencia indica un máximo de 4.096 caracteres para input, así que divide los textos más largos. Los ejemplos guardan el cuerpo de la respuesta como archivo mp3.

Los parámetros completos están en la referencia de la API Create speech. Sustituye el nombre del modelo del ejemplo por el ID del modelo Eleven que quieras.

Preguntas frecuentes

Preguntas frecuentes sobre la API de Eleven v3 Conversational

¿Cuánto cuesta la API de Eleven v3 Conversational?

En AnyAIGC, eleven_v3_conversational se factura por carácter a $0.3240 por 10 000 caracteres, aproximadamente un 19 % menos que el precio de lista de ElevenLabs de $0.40 por 10 000 caracteres. El precio es fijo, sin suscripción ni cuota mensual. Los precios en tiempo real están en el catálogo de modelos.

¿Cuál es el ID del modelo Eleven v3 Conversational y qué relación tiene con ElevenLabs?

El ID del modelo es eleven_v3_conversational (distingue mayúsculas y minúsculas) y coincide con el model_id de ElevenLabs. AnyAIGC es un proveedor de API independiente que ofrece una llamada /v1/audio/speech al estilo de OpenAI y no está afiliado a ElevenLabs.

¿Cómo elijo entre Eleven v3 Conversational y los demás modelos Eleven?

La plataforma tiene 7 modelos de voz Eleven: Eleven v4 (modelo insignia), Eleven v4 Turbo (baja latencia), Eleven v3, Eleven v3 Conversational, Eleven Multilingual v2, Eleven Flash v2.5 y Eleven Flash v2. Elige v4 para audio final pulido, v4 Turbo para asistentes de voz, Multilingual v2 para textos largos e idiomas mezclados y Flash v2.5 para grandes lotes de subtítulos. Prueba el mismo texto en cada modelo antes de decidir.

¿Cómo obtengo una clave de API de Eleven v3 Conversational?

Regístrate y recarga saldo en anyaigc.ai y crea un token en la consola. Una sola clave sirve para más de 300 modelos de la plataforma y no necesitas una cuenta aparte de ElevenLabs. Indica eleven_v3_conversational en el campo model del cuerpo de la petición.

¿Cómo llamo a la API de Eleven v3 Conversational y qué va en voice?

Llama a POST https://anyaigc.ai/v1/audio/speech con los campos obligatorios model, input y voice. voice recibe un voice_id de ElevenLabs, y un voice_id desconocido o no disponible devuelve 400. response_format admite mp3, opus, aac y flac. Consulta la referencia de la API.

¿Qué longitud puede tener el texto en una petición a Eleven v3 Conversational?

La documentación de ElevenLabs no indica un límite de caracteres por petición para este modelo. La referencia Create speech de AnyAIGC indica que la longitud máxima de input es de 4.096 caracteres, así que divide los textos más largos con esa longitud y une el audio después.

¿Eleven v3 Conversational admite chino y cuántos idiomas tiene?

Sí. La documentación oficial indica más de 70 idiomas para este modelo y el mandarín (zh) es uno de ellos. Para ver los idiomas exactos, consulta la documentación de modelos de ElevenLabs.

¿Qué diferencia hay entre Eleven v3 Conversational y Eleven v3?

La versión conversacional está pensada para el diálogo, suena más hablada, tiene una latencia indicada de aproximadamente 165 ms y cuesta la mitad que Eleven v3. Eleven v3 es más dramático y encaja con relatos y dramas cortos. Prueba el mismo texto con ambos. Consulta Eleven v3.

¿Hay límite de peticiones?

AnyAIGC no fija ningún límite de concurrencia para eleven_v3_conversational y todas las cuentas lo tienen por defecto, así que puedes generar por lotes y en paralelo. La facturación es por carácter, sin cuota mensual ni cupo que se reinicie por ventana de tiempo.

¿Puedo usar mi propia voz clonada?

La referencia de la API solo indica que voice recibe un voice_id de ElevenLabs. No aclara si una voz clonada de tu propia cuenta de ElevenLabs puede usarse con una clave de AnyAIGC. Consulta con el soporte de AnyAIGC para confirmarlo.

¿Puedo obtener una factura de AnyAIGC?

Sí. Puedes emitir tus propias facturas en la consola, por el importe que hayas recargado realmente.

¿Qué métodos de pago se admiten?

Puedes recargar saldo con WeChat Pay, Alipay, USDT o tarjeta de crédito. Tu saldo está en USD y sirve para todos los modelos de la plataforma. Las facturas se pueden emitir en la consola por el importe recargado.

¿Hay crédito de prueba gratuito para usuarios nuevos?

Sí. Las cuentas nuevas reciben 2 millones de tokens de crédito de prueba para que pruebes antes de decidir si recargas saldo. Las recargas empiezan en $1.

¿Puedo pedir el reembolso de mi saldo?

Sí. El saldo no utilizado se puede reembolsar sin comisión. Contacta con soporte para iniciar el reembolso.

¿Son los modelos reales? ¿Están seguros mis datos?

Las peticiones van a los canales oficiales de los modelos, nunca a sustitutos más baratos o de ingeniería inversa. Salvo que la ley lo exija, no almacenamos de forma persistente tus prompts ni tus resultados, ni los usamos para entrenar modelos, y la consola muestra los tokens y el coste de cada petición.

¿Se usan mi texto y el audio generado para entrenamiento?

No. Salvo que la ley lo exija, AnyAIGC no almacena de forma persistente tus entradas ni tus salidas y no las usa para entrenamiento. Las peticiones se cifran con HTTPS. Consulta la Política de privacidad de AnyAIGC. La política de datos del propio modelo la define ElevenLabs.
