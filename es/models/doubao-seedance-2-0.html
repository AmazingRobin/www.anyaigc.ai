Preguntas frecuentes sobre la API de Seedance

¿Cuánto cuesta la API de Seedance 2.0?

AnyAIGC factura por millón de tokens, con tarifas que varían según la resolución y el uso de vídeo de referencia. 480p / 720p (sin vídeo de referencia): $8,505 / 1M de tokens; 480p / 720p (con vídeo de referencia): $5,225 / 1M de tokens; 1080p (sin vídeo de referencia): $9,356 / 1M de tokens; 1080p (con vídeo de referencia): $5,711 / 1M de tokens; 4K (sin vídeo de referencia): $4,860 / 1M de tokens; 4K (con vídeo de referencia): $2,916 / 1M de tokens. Consulta el catálogo de modelos para ver las tarifas en tiempo real.

¿Qué entradas admite Seedance?

Seedance 2.0 acepta texto, imágenes, audio y vídeo como referencias, con edición y extensión de vídeo y audio nativo. 2.0 Fast prioriza la velocidad, 2.0 mini está pensado para cargas de trabajo de alta frecuencia y 2.5 añade narrativas largas más sólidas, mejores referencias y ediciones precisas.

¿Cuántos vídeos devuelve una petición?

Una petición de creación devuelve un ID de tarea. Cuando la tarea asíncrona termina, al consultarla se obtiene una URL de vídeo. La duración se controla con el campo duration o con el propio modelo.

¿Qué resoluciones, relaciones de aspecto y duraciones se admiten?

Seedance 2.0 admite 480p, 720p, 1080p y 4K; el nivel 4K ya está disponible. Seedance 2.5 admite 480p, 720p y 1080p, con duration de 4–30 o -1. Fast y mini tienen niveles de precio de 480p / 720p. Para la relación de aspecto y la duración, sigue la documentación de la API de cada modelo.

¿Cómo obtengo el resultado?

Guarda el id que devuelve la llamada de creación y luego llama a GET /api/v3/contents/generations/tasks/{id}. Cuando la tarea termine con éxito, lee content.video_url. Los valores exactos de estado dependen de la respuesta de la API.

¿Hay un límite de concurrencia?

AnyAIGC no fija ningún límite de concurrencia para Seedance, y todas las cuentas lo tienen por defecto. Para lotes grandes, usa una cola y una estrategia de reintentos.

¿Puedo obtener una factura de AnyAIGC?

Sí. Puedes emitir tus propias facturas en la consola, por el importe que hayas recargado realmente.

¿Qué métodos de pago se admiten?

Puedes recargar saldo con WeChat Pay, Alipay, USDT o tarjeta de crédito. Tu saldo está en USD y sirve para todos los modelos de la plataforma. Las facturas se pueden emitir en la consola por el importe recargado.

¿Hay crédito de prueba gratuito para usuarios nuevos?

Sí. Las cuentas nuevas reciben 2 millones de tokens de crédito de prueba, y las recargas empiezan en $1.

¿Puedo pedir el reembolso de mi saldo?

El saldo no utilizado se puede reembolsar sin comisión. Contacta con soporte para conocer el proceso.

¿Son los modelos reales? ¿Están seguros mis datos?

Las peticiones pasan por canales oficiales de los modelos. Salvo que la ley lo exija, los prompts y las salidas no se almacenan de forma persistente ni se usan para entrenar; la consola muestra los detalles de cada petición.
