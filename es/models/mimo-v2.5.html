Streaming en Python
# pip install openai
import os
from openai import OpenAI

client = OpenAI(api_key=os.environ["ANYAIGC_API_KEY"], base_url="https://anyaigc.ai/v1")

stream = client.chat.completions.create(
    model="mimo-v2.5",
    messages=[{"role": "user", "content": "Introduce yourself in three sentences and say what tasks you are best at."}],
    stream=True,
)
for chunk in stream:
    if chunk.choices and chunk.choices[0].delta.content:
        print(chunk.choices[0].delta.content, end="", flush=True)
print()

ESPECIFICACIONES

Especificaciones y cuándo elegirlo

mimo-v2.5 se lanzó el 2026-04-23 con comprensión nativa de imágenes, vídeo, audio y texto, y una ventana de contexto de 1M.

Los parámetros por defecto cambian en mimo-v2.6-flash: max_completion_tokens pasa a 131.072 por defecto en lugar de 32.768, y temperature y top_p no se admiten en modo de razonamiento (thinking).

Esta página indica una entrada de $0.1418 / 1M de tokens, una salida de $0.2835 / 1M de tokens y un acierto de caché de $0.0028 / 1M de tokens, igual que la tabla de precios de arriba.

Las especificaciones proceden de la documentación oficial del proveedor (mimo.mi.com). La tabla de esta página muestra los precios; para las tarifas en tiempo real, la referencia es el catálogo de modelos.

Preguntas frecuentes

Preguntas frecuentes sobre la API de MiMo-V2.5

¿Cuánto cuesta la API de MiMo-V2.5?

Se factura por token, en USD por millón de tokens: entrada $0.1418; salida $0.2835; acierto de caché $0.0028. Xiaomi ha retirado este modelo, así que no hay un precio oficial vigente con el que comparar; su sustituto, MiMo-V2.6-Flash, cuesta $0.0563 de entrada, aproximadamente el 40 % del precio oficial. Consulta el catálogo para ver las tarifas actuales.

¿Se ha retirado MiMo-V2.5?

Sí. Desde el 2026-10-14 a las 18:00 (UTC+8), Xiaomi redirigió las peticiones de mimo-v2.5 a mimo-v2.6-flash, y el nombre antiguo dejó de funcionar en la plataforma de Xiaomi el 2026-10-21 a las 10:00. El catálogo de AnyAIGC sigue incluyendo mimo-v2.5; los proyectos nuevos deberían usar mimo-v2.6-flash.

¿Cómo migro a MiMo-V2.6-Flash?

El endpoint es el mismo; cambia model a mimo-v2.6-flash. Xiaomi señala que el valor por defecto de max_completion_tokens sube de 32768 a 131072, así que indícalo de forma explícita si necesitas un tope fijo. En modo de razonamiento (thinking), temperature y top_p quedan fijos en 1.0 y 0.95.

¿Qué endpoint de la API debo usar?

Usa el endpoint compatible con OpenAI POST https://anyaigc.ai/v1/chat/completions con Authorization: Bearer <API Key> y model establecido en mimo-v2.5. Los proyectos existentes con el SDK de OpenAI solo necesitan establecer base_url en https://anyaigc.ai/v1.

¿Hay límites de concurrencia o de RPM?

AnyAIGC ofrece MiMo con concurrencia sin límite y sin tope fijo de RPM, para todas las cuentas por defecto. Las peticiones de contexto largo y de razonamiento profundo tardan más, así que establece tiempos de espera y reintentos razonables.

¿Puedo usar los resultados con fines comerciales?

El uso de los modelos y de sus resultados se rige por las condiciones oficiales de Xiaomi MiMo. AnyAIGC es un proveedor de API independiente y no está afiliado a Xiaomi.

¿Puedo obtener una factura de AnyAIGC?

Sí. Puedes emitir tus propias facturas en la consola, por el importe que hayas recargado realmente.

¿Qué métodos de pago se admiten?

Puedes recargar saldo con WeChat Pay, Alipay, USDT o tarjeta de crédito. Tu saldo está en USD y sirve para todos los modelos de la plataforma. Las facturas se pueden emitir en la consola por el importe recargado.

¿Hay crédito de prueba gratuito para usuarios nuevos?

Sí. Las cuentas nuevas reciben 2 millones de tokens de crédito de prueba para que pruebes antes de decidir si recargas saldo. Las recargas empiezan en $1.

¿Puedo pedir el reembolso de mi saldo?

Sí. El saldo no utilizado se puede reembolsar sin comisión. Contacta con soporte para iniciar el reembolso.

¿Son los modelos reales? ¿Están seguros mis datos?

Las peticiones van a los canales oficiales de los modelos, nunca a sustitutos más baratos o de ingeniería inversa. Salvo que la ley lo exija, no almacenamos de forma persistente tus prompts ni tus resultados, ni los usamos para entrenar modelos, y la consola muestra los tokens y el coste de cada petición.
