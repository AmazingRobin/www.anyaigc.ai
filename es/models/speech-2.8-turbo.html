Python
import json
import os
import urllib.request

# MINIMAX_VOICE_ID must be a voice ID available to your account.
payload = {
    "model": "speech-2.8-turbo",
    "text": "Hello, welcome to speech synthesis with AnyAIGC.",
    "voice_setting": {
        "voice_id": os.environ["MINIMAX_VOICE_ID"]
    }
}

request = urllib.request.Request(
    "https://anyaigc.ai/minimax/v1/t2a_v2",
    data=json.dumps(payload, ensure_ascii=False).encode("utf-8"),
    headers={
        "Authorization": "Bearer " + os.environ["ANYAIGC_API_KEY"],
        "Content-Type": "application/json",
    },
    method="POST",
)
with urllib.request.urlopen(request, timeout=300) as response:
    result = json.load(response)

print(json.dumps(result, ensure_ascii=False, indent=2))

Establece MINIMAX_VOICE_ID con una voz disponible en tu cuenta. El ejemplo usa síntesis síncrona; sigue la documentación actual para los parámetros asíncronos, la consulta y las descargas.

Speech 2.8

Especificaciones y cuándo elegirlo

MiniMax presenta speech-2.8-turbo como: velocidad sin fisuras, fluidez natural.

Speech 2.8 incorpora etiquetas de sonido nativas para muletillas como «um», «uh» y «ah», clona una voz a partir de una muestra de 10 segundos, reduce el ruido de fondo y los artefactos sintéticos, y mejora la salida multilingüe, empezando por mandarín-japonés.

Cada petición admite menos de 10.000 caracteres de texto, frecuencias de muestreo de 8000 a 44100 Hz y salida en mp3, pcm, flac, wav, opus y otros formatos.

speech-2.8-hd, de la misma generación, se presenta como «calidad ultrarrealista con etiquetas de sonido». Elígelo para audiolibros y locuciones de marca donde la calidad es lo primero; quédate con Turbo para conversación y narración en directo.

Preguntas frecuentes sobre la API de MiniMax

Precios, endpoints, resultados y acceso para empresas en un solo lugar.

¿Cuánto cuesta la API de MiniMax Speech 2.8 TURBO?

Síntesis de voz a $0.3176/10.000 caracteres. Todos los precios están en USD; consulta el catálogo de modelos para ver las tarifas actuales.

¿Cuál es la diferencia entre speech-2.8-turbo y speech-2.8-hd?

MiniMax presenta speech-2.8-turbo como «velocidad sin fisuras, fluidez natural» y speech-2.8-hd como «calidad ultrarrealista con etiquetas de sonido». HD prioriza la similitud de la voz y la calidad del audio, y Turbo prioriza la baja latencia; ambos usan la misma API y los mismos parámetros.

¿Qué idiomas y formatos de audio admite speech-2.8-turbo?

Speech 2.8 incorpora etiquetas de sonido nativas para muletillas como «um», «uh» y «ah», clona una voz a partir de una muestra de 10 segundos, reduce el ruido de fondo y los artefactos sintéticos, y mejora la salida multilingüe, empezando por mandarín-japonés. Cada petición admite menos de 10.000 caracteres de texto, frecuencias de muestreo de 8000 a 44100 Hz y salida en mp3, pcm, flac, wav, opus y otros formatos.

¿Qué endpoint de la API debo usar?

Usa POST /minimax/v1/t2a_v2; POST /minimax/v1/t2a_async_v2 en https://anyaigc.ai y envía tu clave de API en Authorization: Bearer.

¿Cómo elijo una voz y puede tener un coste adicional?

Define voice_setting.voice_id con una voz disponible para tu cuenta. El catálogo indica que las voces no predefinidas pueden tener un cargo aparte; confirma el cargo de la voz que elijas.

¿Qué devuelve una petición?

El ejemplo síncrono devuelve JSON; data.audio contiene los datos de audio o una URL según la petición y la respuesta real. El catálogo también lista un endpoint asíncrono. Consulta su documentación actual para la consulta de tareas y las descargas.

¿Hay límites de concurrencia o de RPM?

AnyAIGC ofrece concurrencia sin límite para MiniMax, sin tope fijo de RPM. La generación sigue requiriendo tiempo; configura tiempos de espera, gestión de errores y reintentos adecuados en tu aplicación.

¿Se puede usar el contenido generado con fines comerciales?

El uso comercial de los modelos y sus resultados se rige por los términos oficiales de MiniMax. Asegúrate de contar con los derechos necesarios sobre el material de referencia, las voces y el contenido generado. AnyAIGC es un proveedor de API independiente.

¿Puedo obtener una factura de AnyAIGC?

Sí. Puedes emitir tus propias facturas en la consola, por el importe que hayas recargado realmente.

¿Qué métodos de pago se admiten?

Puedes recargar saldo con WeChat Pay, Alipay, USDT o tarjeta de crédito. Tu saldo está en USD y sirve para todos los modelos de la plataforma. Las facturas se pueden emitir en la consola por el importe recargado.

¿Hay crédito de prueba gratuito para usuarios nuevos?

Sí. Las cuentas nuevas reciben 2 millones de tokens de crédito de prueba para que pruebes antes de decidir si recargas saldo. Las recargas empiezan en $1.

¿Puedo pedir el reembolso de mi saldo?

Sí. El saldo no utilizado se puede reembolsar sin comisión. Contacta con soporte para iniciar el reembolso.

¿Son los modelos reales? ¿Están seguros mis datos?

Las peticiones van a los canales oficiales de los modelos, nunca a sustitutos más baratos o de ingeniería inversa. Salvo que la ley lo exija, no almacenamos de forma persistente tus prompts ni tus resultados, ni los usamos para entrenar modelos, y la consola muestra los tokens y el coste de cada petición.
