CAPACIDADES DEL MODELO

Qué puede hacer Kling Video V4 Flash

Resumido a partir del catálogo de modelos y la referencia de la API actuales. Consulta la documentación de la API para los parámetros exactos.

De texto a vídeo

Envía un prompt y una duración para obtener un clip en 720p de 3–30 segundos. La duración por defecto es de 5 segundos.

Primer y último fotograma

Marca una imagen de image_list como first_frame. Un end_frame debe ir acompañado de un first_frame; si solo envías el fotograma final, se devuelve 400.

Referencia multimagen

Hasta 10 imágenes de referencia, citadas en el prompt como @image_1, @image_2 en el orden en que las envíes, para reutilizar personajes, el aspecto de un producto y escenas.

Vídeo de referencia

Hasta 5 vídeos de referencia, solo con referencia de tipo feature: URL http(s) públicas, de al menos 3 segundos cada una y 30 segundos en total, para reutilizar movimientos de cámara y ritmo de movimiento.

Sujetos y voces

Hasta 7 sujetos en element_list y 3 voces en voice_list, citados como @element_1 y así sucesivamente. En conjunto, los recursos de referencia no pueden superar 15.

Relación de aspecto y resolución

La salida es fija en 720p (envía mode std u omítelo). Las relaciones de aspecto son 21:9, 16:9, 9:16, 1:1 o adaptive para seguir tus recursos.

INICIO RÁPIDO

Integra la API de Kling Video V4 Flash

  1. 1Regístrate, crea una clave de API y define ANYAIGC_API_KEY
  2. 2Envía POST /kling/v1/videos/omni-video para crear una tarea y obtener su task_id
  3. 3Haz sondeo de GET /kling/v1/videos/omni-video/{id} y descarga el vídeo cuando la tarea se complete correctamente

Define model_name como "kling-video-v4-flash". Este modelo solo genera en 720p: mode debe ser std o omitirse, resolution debe ser 720p o omitirse, y pro o 1080p devuelve 400 sin cargo. Incluye las imágenes y los vídeos de referencia en image_list y video_list y cítalos como @image_1 y @video_1 en el prompt.

Python

import json
import os
import time
import urllib.request

BASE = "https://anyaigc.ai"
HEADERS = {
    "Authorization": "Bearer " + os.environ["ANYAIGC_API_KEY"],
    "Content-Type": "application/json",
}


def call(method, path, payload=None):
    data = json.dumps(payload, ensure_ascii=False).encode("utf-8") if payload else None
    request = urllib.request.Request(BASE + path, data=data, headers=HEADERS, method=method)
    with urllib.request.urlopen(request, timeout=60) as response:
        return json.load(response)


payload = {
    "model_name": "kling-video-v4-flash",
    "prompt": "The camera glides down to a neon street after rain as an orange cat walks across the wet pavement, cinematic lighting",
    "duration": 5,
    "aspect_ratio": "16:9"
}

task_id = call("POST", "/kling/v1/videos/omni-video", payload)["data"]["task_id"]
print("task_id:", task_id)

# Poll every 10 seconds; print the video URL once the task succeeds
for _ in range(90):
    data = call("GET", f"/kling/v1/videos/omni-video/{task_id}")["data"]
    if data["task_status"] == "succeed":
        break
    if data["task_status"] == "failed":
        raise RuntimeError(data.get("task_status_msg"))
    time.sleep(10)
else:
    raise TimeoutError(task_id)

for video in data["task_result"]["videos"]:
    print(video["url"])

ESPECIFICACIONES

Especificaciones y cuándo elegirlo

Kling 4.0 Flash (kling-4.0-flash) genera vídeos de 3 a 20 segundos, con 720P SDR como única salida.

Las relaciones de aspecto admitidas son 21:9, 16:9, 1:1, 9:16, 4:3, 3:4 y adaptive.

La generación con referencias Omni admite hasta 5 vídeos de referencia y 7 sujetos, y tanto cada vídeo de referencia como la duración total deben estar entre 3 y 20 segundos.

Kling lo describe como un modelo más ligero y de menor coste que admite referencias Omni, edición de vídeo y voz multilingüe.

Preguntas frecuentes

Preguntas frecuentes sobre la API de Kling Video V4 Flash

¿Cuánto cuesta la API de Kling Video V4 Flash?

Se factura por segundo: $0.1206 por segundo sin vídeo de referencia y $0.0808 por segundo con uno, siempre en 720p. Los precios están en USD y se cobran cuando el envío se realiza correctamente; consulta el catálogo de modelos para ver las tarifas actuales.

¿A qué endpoint debo llamar?

Envía la petición con POST /kling/v1/videos/omni-video, definiendo model_name como kling-video-v4-flash, y obtén los resultados con GET /kling/v1/videos/omni-video/{id}. El host de la API es https://anyaigc.ai y la cabecera es Authorization: Bearer <API Key>.

¿Qué modos de generación se admiten?

De texto a vídeo, de imagen a vídeo con primer fotograma y con primer y último fotograma, hasta 10 imágenes de referencia, hasta 5 vídeos de referencia, además de hasta 7 sujetos y 3 voces. En conjunto, los recursos de referencia no pueden superar 15. Consulta la referencia de la API para ver los campos exactos.

¿Cómo se factura y por qué la tarifa es menor con un vídeo de referencia?

Sin vídeo de referencia, los segundos facturados equivalen a la duración de salida, a $0.1206 por segundo. Con uno, la tarifa es de $0.0808 por segundo, pero los segundos facturados = duración de salida + max(duración total de los vídeos de referencia, duración de salida); una salida de 5 segundos con un vídeo de referencia de 5 segundos factura 10 segundos, es decir, $0.808. Las imágenes de referencia, los sujetos y las voces son gratis.

¿Cuáles son los límites de resolución, duración y relación de aspecto?

La salida es fija en 720p: mode debe ser std o omitirse y resolution debe ser 720p o omitirse; pro o 1080p devuelve 400 sin cargo. duration es un entero de 3 a 30 segundos, con 5 por defecto. Las relaciones de aspecto son 21:9, 16:9, 9:16, 1:1 y adaptive.

¿Qué no se admite?

Este modelo no admite sonido (on devuelve 400), multi_shot, el modo 4K ni la edición de vídeo con refer_type base. Los vídeos de referencia deben usar feature.

¿Cómo obtengo el resultado?

La API es asíncrona. El envío devuelve un task_id; haz sondeo del endpoint de consulta y, cuando la tarea se complete correctamente, lee la URL del vídeo en task_result. Consulta la referencia de la API para ver los valores de estado y los campos de respuesta exactos.

¿Hay límites de concurrencia?

Los modelos de Kling en AnyAIGC tienen concurrencia sin límite por defecto en todas las cuentas.

¿Puedo usar los vídeos con fines comerciales?

Los derechos de uso y la política de contenido se rigen por las condiciones oficiales de Kuaishou Kling. Asegúrate de tener los derechos sobre las imágenes o los vídeos de referencia que subas.

¿Puedo obtener una factura de AnyAIGC?

Sí. Puedes emitir tus propias facturas en la consola, por el importe que hayas recargado realmente.

¿Qué métodos de pago se admiten?

Puedes recargar saldo con WeChat Pay, Alipay, USDT o tarjeta de crédito. Tu saldo está en USD y sirve para todos los modelos de la plataforma. Las facturas se pueden emitir en la consola por el importe recargado.

¿Hay crédito de prueba gratuito para usuarios nuevos?

Sí. Las cuentas nuevas reciben 2 millones de tokens de crédito de prueba para que pruebes antes de decidir si recargas saldo. Las recargas empiezan en $1.

¿Puedo pedir el reembolso de mi saldo?

Sí. El saldo no utilizado se puede reembolsar sin comisión. Contacta con soporte para iniciar el reembolso.

¿Son los modelos reales? ¿Están seguros mis datos?

Las peticiones van a canales oficiales de los modelos, nunca a sustitutos más baratos ni de ingeniería inversa. Salvo que la ley lo exija, no almacenamos de forma persistente tus prompts ni tus salidas ni los usamos para entrenamiento, y la consola muestra el coste de cada petición.
