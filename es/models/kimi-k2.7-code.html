Acerca de

K2.6, con entrenamiento adicional para programación

Moonshot AI presenta Kimi K2.7 Code como su modelo de programación más sólido hasta ahora. Parte de K2.6 con entrenamiento adicional, sigue las instrucciones con más fiabilidad en contextos largos, completa más tareas de programación y usa aproximadamente un 30 % menos de tokens de razonamiento que K2.6.

La arquitectura es la de K2.6: MoE con 1T de parámetros en total y 32B activos, 8 de 384 expertos por token, ventana de contexto de 256K y entrada de texto e imagen. K2.7 Code siempre razona y admite razonamiento intercalado con llamadas a herramientas de varios pasos, lo que encaja con los agentes de programación.

En AnyAIGC, kimi-k2.7-code funciona en el endpoint /v1/chat/completions compatible con OpenAI y se usa directamente en Claude Code, con concurrencia sin límite.

Inicio rápido

Conéctate a la API de Kimi K2.7 Code en tres pasos

  1. Regístrate y recarga saldo: crea una cuenta en anyaigc.ai. Recarga desde $1; tu saldo sirve para todos los modelos de la plataforma.
  2. Crea una clave de API: crea una clave en la consola, copia el valor que empieza por sk- y guárdalo en la variable de entorno ANYAIGC_API_KEY.
  3. Envía una petición: llama a POST https://anyaigc.ai/v1/chat/completions con model igual a kimi-k2.7-code y una cabecera Authorization: Bearer. Con el SDK de OpenAI, basta con establecer base_url en https://anyaigc.ai/v1.

Consejo: K2.7 Code siempre razona, y el razonamiento llega en reasoning_content. Moonshot recomienda temperature=1.0 y top_p=0.95. En chats de varios turnos y llamadas a herramientas, devuelve sin cambios en la siguiente petición el mensaje completo del asistente que entrega la API (incluidos reasoning_content y tool_calls).

Consulta la referencia de Chat Completions para ver todos los parámetros. Sustituye el nombre del modelo de los ejemplos de la documentación por el ID del modelo Kimi que quieras usar.

Claude Code

Usa Kimi K2.7 Code en Claude Code

Cambia Claude Code a Kimi K2.7 Code. Está entrenado para programar y cuesta aproximadamente la mitad que K3.1 Pro.

  1. Instala Claude Code: usa el instalador oficial (por ejemplo, npm install -g @anthropic-ai/claude-code).
  2. Añade la configuración: edita ~/.claude/settings.json, añade el bloque env de abajo y sustituye ANTHROPIC_AUTH_TOKEN por la clave que creaste en AnyAIGC.
  3. Empieza a programar: ejecuta claude en la carpeta de tu proyecto. Escribe /model para confirmar que el modelo actual es kimi-k2.7-code.

Para repositorios grandes: K2.7 Code tiene una ventana de contexto de 256K. Si un proyecto es demasiado grande para leerlo de una vez, cambia el modelo en la configuración a kimi-k3.1-pro (contexto de 1M).

Para ver la guía completa y los errores habituales, consulta la guía de configuración de Claude Code. Sustituye en la guía el nombre del modelo por kimi-k2.7-code.

Preguntas frecuentes

Preguntas frecuentes sobre la API de Kimi K2.7 Code

¿Cuánto cuesta la API de Kimi K2.7 Code?

En AnyAIGC, kimi-k2.7-code se factura por token: entrada $0,3847 por millón de tokens, salida $1,5980 por millón de tokens y acierto de caché $0,0770 por millón de tokens. Los precios oficiales de Moonshot en USD son entrada $0,95, salida $4,00 y acierto de caché $0,19, así que AnyAIGC cuesta aproximadamente el 40 % del precio oficial. La salida incluye los tokens de razonamiento (thinking). Consulta el catálogo de modelos para ver los precios en tiempo real.

¿Cuál es el ID del modelo Kimi K2.7 Code y qué tamaño tiene su contexto?

El ID del modelo es kimi-k2.7-code. Moonshot indica una ventana de contexto de 262.144 tokens (256K), con entrada de texto e imagen.

¿En qué se diferencia Kimi K2.7 Code de K2.6?

K2.7 Code parte de K2.6 con un entrenamiento adicional centrado en programación, sobre la misma arquitectura (1T de parámetros en total, 32B activos). Moonshot afirma que sigue las instrucciones con más fiabilidad en contextos largos, completa más tareas de programación y usa aproximadamente un 30 % menos de tokens de razonamiento (thinking) que K2.6; en Kimi Code Bench v2 pasa de 50,9 a 62,0. K2.7 Code solo funciona en modo de razonamiento (thinking), mientras que K2.6 permite desactivarlo. Ambos tienen los mismos precios de entrada y salida en AnyAIGC.

¿Puedo desactivar el modo de razonamiento (thinking) en Kimi K2.7 Code?

No. Moonshot indica que K2.7 Code siempre se ejecuta con thinking y preserve thinking activados, y que no admite el modo sin razonamiento. Para respuestas rápidas sin modo de razonamiento, usa kimi-k2.6. Moonshot recomienda temperature=1.0 y top_p=0.95.

¿Kimi K2.7 Code admite llamadas a herramientas?

Sí. K2.7 Code admite razonamiento intercalado y llamadas a herramientas de varios pasos, lo que encaja con los agentes de programación. En chats de varios turnos y llamadas a herramientas, devuelve sin cambios en la siguiente petición el mensaje completo del asistente (incluidos reasoning_content y tool_calls).

¿Puedo usar Kimi K2.7 Code en Claude Code?

Sí. En el bloque env de ~/.claude/settings.json, establece ANTHROPIC_BASE_URL en https://anyaigc.ai, ANTHROPIC_AUTH_TOKEN en tu clave de API y ANTHROPIC_MODEL en kimi-k2.7-code. Después ejecuta claude.

Kimi K2.7 Code o Kimi K3.1 Pro: ¿cuál debo usar?

K2.7 Code es un modelo de programación de 1T de parámetros con contexto de 256K, a $0,3847 de entrada y $1,5980 de salida en AnyAIGC, pensado para programar a diario y para llamadas de agentes de alto volumen. Kimi K3.1 Pro es el modelo más reciente de clase 3T, con contexto de 1M, a $0,8100 de entrada y $4,0500 de salida, pensado para repositorios grandes y las tareas más difíciles. Ambos usan la misma clave.

¿Hay límites de concurrencia o de peticiones?

AnyAIGC no limita la concurrencia de kimi-k2.7-code, y todos los usuarios la tienen por defecto. Es adecuado para trabajos por lotes, pipelines de CI y agentes en paralelo. La propia plataforma de Moonshot limita la concurrencia, RPM, TPM y TPD según el nivel de recarga; esos niveles no se aplican cuando llamas a través de AnyAIGC.

¿Cómo obtengo una clave de API de Kimi K2.7 Code?

Regístrate en anyaigc.ai, recarga saldo y crea una clave en la consola. La misma clave sirve para todos los modelos Kimi y para más de 300 modelos adicionales de la plataforma, así que no necesitas una cuenta aparte en la plataforma de Moonshot.

¿Puedo obtener una factura de AnyAIGC?

Sí. Puedes emitir tus propias facturas en la consola, por el importe que hayas recargado realmente.

¿Qué métodos de pago se admiten?

Puedes recargar saldo con WeChat Pay, Alipay, USDT o tarjeta de crédito. Tu saldo está en USD y sirve para todos los modelos de la plataforma. Las facturas se pueden emitir en la consola por el importe recargado.

¿Hay crédito de prueba gratuito para usuarios nuevos?

Sí. Las cuentas nuevas reciben 2 millones de tokens de crédito de prueba para que pruebes antes de decidir si recargas saldo. Las recargas empiezan en $1.

¿Puedo pedir el reembolso de mi saldo?

Sí. El saldo no utilizado se puede reembolsar sin comisión. Contacta con soporte para iniciar el reembolso.

¿Son los modelos reales? ¿Están seguros mis datos?

Las peticiones van a los canales oficiales de los modelos, nunca a sustitutos más baratos o de ingeniería inversa. Salvo que la ley lo exija, no almacenamos de forma persistente tus prompts ni tus resultados, ni los usamos para entrenar modelos, y la consola muestra los tokens y el coste de cada petición.

¿Se usarán mis datos para entrenar modelos?

No. Salvo que lo exija la ley, AnyAIGC no almacena de forma persistente tus prompts ni las salidas y no los usa para entrenar modelos. Las peticiones se cifran mediante HTTPS.
