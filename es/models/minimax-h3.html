Lee la referencia de la API ↗
cURL
curl --request POST "https://anyaigc.ai/minimax/v2/video_generation" \
  --header "Authorization: Bearer $ANYAIGC_API_KEY" \
  --header "Content-Type: application/json" \
  --data '{
  "content": [
    {
      "text": "A sunset over the sea, with the camera slowly pushing forward.",
      "type": "text"
    }
  ],
  "duration": 5,
  "model": "MiniMax-H3",
  "ratio": "16:9",
  "resolution": "768P"
}'
Python
import json
import os
import urllib.request

payload = {
    "content": [
        {
            "text": "A sunset over the sea, with the camera slowly pushing forward.",
            "type": "text"
        }
    ],
    "duration": 5,
    "model": "MiniMax-H3",
    "ratio": "16:9",
    "resolution": "768P"
}

request = urllib.request.Request(
    "https://anyaigc.ai/minimax/v2/video_generation",
    data=json.dumps(payload, ensure_ascii=False).encode("utf-8"),
    headers={
        "Authorization": "Bearer " + os.environ["ANYAIGC_API_KEY"],
        "Content-Type": "application/json",
    },
    method="POST",
)
with urllib.request.urlopen(request, timeout=120) as response:
    result = json.load(response)

print(json.dumps(result, ensure_ascii=False, indent=2))

La creación devuelve task_id. Este ejemplo envía la tarea y no espera a que termine el vídeo. Ver la documentación de consulta de tareas ↗

ESPECIFICACIONES

Especificaciones y cuándo elegirlo

La documentación de MiniMax describe MiniMax-H3 como un modelo de vídeo multimodal abierto y de propósito general que entiende de forma unificada entradas de texto, imagen, vídeo y audio, y admite generación de vídeo, creación basada en referencias y edición de vídeo.

La especificación de salida oficial es 768P y 2K con una duración de 4 a 15 segundos, solo valores enteros; admite relaciones de aspecto comunes o adaptive.

Las peticiones usan una estructura multimodal content[] en la que cada elemento se distingue por type, y las imágenes y vídeos de referencia se marcan mediante el campo role.

La documentación indica que usar MiniMax-H3 requiere la API de pago por uso.

Esta página muestra el vídeo de salida en 768P a $0.0750 / segundo, el vídeo de entrada en 768P a $0.0750 / segundo, el vídeo de salida en 2K a $0.1219 / segundo y el vídeo de entrada en 2K a $0.1219 / segundo, tal como figura en la tabla de precios anterior.

Las especificaciones proceden de la documentación oficial del proveedor (platform.minimax.io). La tabla de esta página muestra los precios; para las tarifas en tiempo real, la referencia es el catálogo de modelos.

Preguntas frecuentes

Preguntas frecuentes sobre la API de MiniMax

Precios, endpoints, resultados y acceso para empresas en un solo lugar.

¿Cuánto cuesta la API de MiniMax H3?

Vídeo de salida 768P $0.0750/segundo; vídeo de entrada 768P $0.0750/segundo; vídeo de salida 2K $0.1219/segundo; vídeo de entrada 2K $0.1219/segundo; regeneración de vídeo $0.0450/segundo; imágenes de referencia (las 5 primeras) $0/imagen; imágenes de referencia (a partir de la 6.ª) $0.0375/imagen. Todos los precios están en USD; consulta el catálogo de modelos para ver las tarifas actuales.

¿Qué endpoint de la API debo usar?

Usa POST /minimax/v2/video_generation en https://anyaigc.ai y pasa tu clave de API mediante Authorization: Bearer.

¿Qué duraciones, resoluciones y referencias admite H3?

MiniMax-H3 admite de 4 a 15 segundos en 768P o 2K. El array content debe contener exactamente un elemento de texto no vacío. Usa primer y último fotograma, o bien imágenes, vídeo y audio de referencia; no mezcles esos modos. La generación solo con texto requiere ratio.

¿Qué devuelve una petición?

Una tarea asíncrona genera un vídeo de 4–15 segundos de duración.

¿Hay límites de concurrencia o de RPM?

AnyAIGC ofrece concurrencia sin límite para MiniMax, sin tope fijo de RPM. La generación sigue requiriendo tiempo; configura tiempos de espera, gestión de errores y reintentos adecuados en tu aplicación.

¿Se puede usar el contenido generado con fines comerciales?

El uso comercial de los modelos y sus resultados se rige por los términos oficiales de MiniMax. Asegúrate de contar con los derechos necesarios sobre el material de referencia, las voces y el contenido generado. AnyAIGC es un proveedor de API independiente.

¿Puedo obtener una factura de AnyAIGC?

Sí. Puedes emitir tus propias facturas en la consola, por el importe que hayas recargado realmente.

¿Qué métodos de pago se admiten?

Puedes recargar saldo con WeChat Pay, Alipay, USDT o tarjeta de crédito. Tu saldo está en USD y sirve para todos los modelos de la plataforma. Las facturas se pueden emitir en la consola por el importe recargado.

¿Hay crédito de prueba gratuito para usuarios nuevos?

Sí. Las cuentas nuevas reciben 2 millones de tokens de crédito de prueba para que pruebes antes de decidir si recargas saldo. Las recargas empiezan en $1.

¿Puedo pedir el reembolso de mi saldo?

Sí. El saldo no utilizado se puede reembolsar sin comisión. Contacta con soporte para iniciar el reembolso.

¿Son los modelos reales? ¿Están seguros mis datos?

Las peticiones van a los canales oficiales de los modelos, nunca a sustitutos más baratos o de ingeniería inversa. Salvo que la ley lo exija, no almacenamos de forma persistente tus prompts ni tus resultados, ni los usamos para entrenar modelos, y la consola muestra los tokens y el coste de cada petición.
