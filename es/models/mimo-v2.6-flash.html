Python
# pip install openai
import os
from openai import OpenAI

client = OpenAI(api_key=os.environ["ANYAIGC_API_KEY"], base_url="https://anyaigc.ai/v1")

completion = client.chat.completions.create(
    model="mimo-v2.6-flash",
    messages=[{"role": "user", "content": "Introduce yourself in three sentences and say what tasks you are best at."}],
)
print(completion.choices[0].message.content)
Streaming en Python
# pip install openai
import os
from openai import OpenAI

client = OpenAI(api_key=os.environ["ANYAIGC_API_KEY"], base_url="https://anyaigc.ai/v1")

stream = client.chat.completions.create(
    model="mimo-v2.6-flash",
    messages=[{"role": "user", "content": "Introduce yourself in three sentences and say what tasks you are best at."}],
    stream=True,
)
for chunk in stream:
    if chunk.choices and chunk.choices[0].delta.content:
        print(chunk.choices[0].delta.content, end="", flush=True)
print()

Preguntas frecuentes

Preguntas frecuentes sobre la API de MiMo-V2.6-Flash

¿Cuánto cuesta la API de MiMo-V2.6-Flash? ¿De verdad tiene un 60 % de descuento?

Se factura por token en USD por 1M de tokens: entrada $0,0563 (oficial $0,14); salida $0,1126 (oficial $0,28); acierto de caché $0,0011 (oficial $0,0028). La entrada y la salida equivalen a aproximadamente el 40 % del precio oficial en USD de pago por uso de Xiaomi MiMo, es decir, cerca de un 60 % menos. Consulta el catálogo para ver las tarifas actuales.

¿Qué entradas se admiten y qué longitud tiene el contexto?

Especificaciones oficiales: entrada de texto, imagen, vídeo y audio con salida de texto, contexto de 1M de tokens y hasta 128K tokens de salida. La documentación de AnyAIGC muestra por ahora ejemplos con text e image_url; para entrada de audio y vídeo, sigue la documentación de la API.

¿Qué endpoint de la API debo usar?

Usa POST https://anyaigc.ai/v1/chat/completions, compatible con OpenAI, con Authorization: Bearer <API Key> y model establecido en mimo-v2.6-flash. Los proyectos que ya usan el SDK de OpenAI solo necesitan establecer base_url en https://anyaigc.ai/v1.

¿Qué debería usar, MiMo-V2.6-Flash o MiMo-V2.6-Pro?

V2.6-Pro está pensado para agentes de larga duración, programación e investigación; V2.6-Flash, para cargas de oficina de alto volumen a aproximadamente un tercio del precio de Pro. Ambos cuestan aproximadamente el 40 % del precio oficial, así que prueba cada uno con tus propias tareas.

¿Hay límites de concurrencia o de RPM?

AnyAIGC ofrece MiMo con concurrencia sin límite y sin tope fijo de RPM, para todas las cuentas por defecto. Las peticiones de contexto largo y de razonamiento profundo tardan más, así que establece tiempos de espera y reintentos razonables.

¿Puedo usar los resultados con fines comerciales?

El uso de los modelos y de sus resultados se rige por las condiciones oficiales de Xiaomi MiMo. AnyAIGC es un proveedor de API independiente y no está afiliado a Xiaomi.

¿Puedo obtener una factura de AnyAIGC?

Sí. Puedes emitir tus propias facturas en la consola, por el importe que hayas recargado realmente.

¿Qué métodos de pago se admiten?

Puedes recargar saldo con WeChat Pay, Alipay, USDT o tarjeta de crédito. Tu saldo está en USD y sirve para todos los modelos de la plataforma. Las facturas se pueden emitir en la consola por el importe recargado.

¿Hay crédito de prueba gratuito para usuarios nuevos?

Sí. Las cuentas nuevas reciben 2 millones de tokens de crédito de prueba para que pruebes antes de decidir si recargas saldo. Las recargas empiezan en $1.

¿Puedo pedir el reembolso de mi saldo?

Sí. El saldo no utilizado se puede reembolsar sin comisión. Contacta con soporte para iniciar el reembolso.

¿Son los modelos reales? ¿Están seguros mis datos?

Las peticiones van a los canales oficiales de los modelos, nunca a sustitutos más baratos o de ingeniería inversa. Salvo que la ley lo exija, no almacenamos de forma persistente tus prompts ni tus resultados, ni los usamos para entrenar modelos, y la consola muestra los tokens y el coste de cada petición.
