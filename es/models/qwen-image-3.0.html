ESPECIFICACIONES

Especificaciones y cuándo elegirlo

qwen-image-3.0 es el modelo estándar de Qwen-Image 3.0 y admite tanto texto a imagen como imagen a imagen y edición de imágenes.

Las tareas de imagen a imagen y de edición aceptan de 1 a 3 imágenes de entrada.

El total de píxeles de salida debe estar entre 512×512 y 2048×2048, la relación de aspecto puede ir de 1:8 a 8:1 y cada petición devuelve de 1 a 6 imágenes.

Esta página indica una tarifa base de $0.00159 / unidad de facturación, igual que la tabla de precios de arriba.

En comparación con qwen-image-3.0-pro: qwen-image-3.0-pro es el modelo insignia de la misma serie y qwen-image-3.0 es el modelo estándar. Ambos comparten el mismo rango de resolución y el mismo límite de imágenes de entrada.

Las especificaciones proceden de la documentación oficial del proveedor (alibabacloud.com). La tabla de esta página muestra el precio, y el catálogo de modelos es la referencia para las tarifas en tiempo real.

Preguntas frecuentes

Preguntas frecuentes sobre la API de Qwen Image 3.0

¿Para qué sirve Qwen Image 3.0?

Crea pósteres, infografías e interfaces con hasta 4.5K tokens de instrucción y maquetaciones de texto detalladas.

¿Cómo se factura el uso de la API?

Tarifa base por unidad de facturación: $0.00159/unidad de facturación. Aplica estos multiplicadores: imagen de salida ×18; imagen de referencia ×2; los cargos de salida y de referencia se suman. La tarifa base no es el precio final de una imagen de salida. Consulta el catálogo para ver los precios en tiempo real.

¿Hay un límite de concurrencia?

AnyAIGC no fija un límite de concurrencia para este modelo; está disponible de forma predeterminada.

¿Cómo obtengo una clave de API?

Crea una cuenta de AnyAIGC y luego crea una clave de API en la consola.

¿Puedo usar los resultados con fines comerciales?

El uso comercial se rige por las condiciones oficiales de Qwen y Alibaba Cloud.

¿Puedo obtener una factura de AnyAIGC?

Sí. Puedes emitir tus propias facturas en la consola, por el importe que hayas recargado realmente.

¿Qué métodos de pago se admiten?

Puedes recargar saldo con WeChat Pay, Alipay, USDT o tarjeta de crédito. Tu saldo está en USD y sirve para todos los modelos de la plataforma. Las facturas se pueden emitir en la consola por el importe recargado.

¿Hay crédito de prueba gratuito para usuarios nuevos?

Sí. Las cuentas nuevas reciben 2 millones de tokens de crédito de prueba.

¿Puedo pedir el reembolso de mi saldo?

Sí. El saldo no utilizado se puede reembolsar sin comisión.

¿Están seguros mis datos?

Los prompts y las salidas no se almacenan de forma persistente ni se usan para entrenamiento, salvo que la ley lo exija.
