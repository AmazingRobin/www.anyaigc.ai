Llama a la API de Suno en tres pasos

Flujo de tareas asíncrono: envía una petición, recibe un task_id y sondea (polling) hasta obtener el resultado. Puedes escuchar tu primera canción en cuestión de minutos.

  1. Regístrate y recarga saldo

    Crea una cuenta en anyaigc.ai y recarga saldo. Tu saldo sirve para todos los modelos de la plataforma.

  2. Crea una clave de API

    Crea un token en la consola y copia la clave. La URL base es https://anyaigc.ai y la autenticación usa Authorization: Bearer.

  3. Envía y sondea (polling)

    Haz un POST a /suno/submit/music para obtener un task_id y luego llama a GET /suno/fetch/{id} cada 5–10 segundos. Cuando termine, toma la URL del audio.

Para ver más modos (extender, cover, Persona, efectos de sonido, mashup, reescritura parcial y más) y la lista completa de parámetros, consulta la documentación de la API de Suno en AnyAIGC. mv acepta desde chirp-v3-5 hasta chirp-v6; consulta la documentación para ver la lista actual.

Preguntas frecuentes sobre la API de Suno

Lo que debes saber para usar la API de Suno en AnyAIGC.

¿Cuánto cuesta la API de Suno?

Precios fijos, de pago por petición: generar canción $0.1191, Max Mode $0.2382, efectos de sonido $0.0238, separación de voz/instrumental $0.1191, separación completa de stems + MIDI $0.5956 y cronología de la letra $0.0596 por petición. Generar letra, potenciar el estilo musical, subir audio de referencia y crear una Persona son gratis, y la subida de archivos con suno_uploads cuesta $0.000993 por petición. Sin suscripción ni cuota mensual.

¿Suno tiene una API oficial?

En octubre de 2026, Suno no ofrece una API oficial pública de autoservicio. AnyAIGC es una plataforma de API independiente de terceros que ofrece una interfaz unificada para la generación de música de Suno y no tiene vínculo con Suno, Inc.

¿Cómo obtengo una clave de API de Suno?

Regístrate en anyaigc.ai, recarga saldo y crea una clave de API en la página de Tokens de la consola. La misma clave sirve para Suno y para más de 300 modelos de la plataforma.

¿Cuáles son los límites de frecuencia de la API de Suno?

La API de Suno admite 200 RPM (200 peticiones por minuto) por defecto, suficiente para generar bandas sonoras por lotes, plataformas de contenido de usuarios (UGC) y flujos automatizados. Todos los usuarios lo tienen, sin necesidad de solicitarlo, y se puede ampliar si necesitas más. Contacta con soporte para ampliar tu límite.

¿La API de Suno es síncrona o asíncrona? ¿Cuánto tarda una canción?

Es asíncrona. Envía la petición a /suno/submit/music para obtener un task_id y luego sondea (polling) /suno/fetch/{id} hasta que la tarea termine. La mayoría de las canciones se completan en 1–3 minutos, según la duración de la canción y la carga actual.

¿Qué puedo hacer con la API de Suno?

Generar canciones completas con voz o instrumentales a partir de una descripción de texto o de tu propia letra, generar letras y efectos de sonido, potenciar las etiquetas de estilo, subir audio de referencia, separar la voz del instrumental, separar todos los stems y exportar MIDI, obtener cronologías de la letra línea por línea y crear Personas con estilo de artista.

¿Qué versiones del modelo de Suno se admiten?

Elige una versión con el parámetro mv: chirp-v3-0, chirp-v3-5, chirp-v4, chirp-v4-5, chirp-v5, chirp-v5-5, chirp-v6, chirp-v6-wild y chirp-v6-mini, que cubren desde Suno v3 hasta la familia v6 más reciente. Si omites mv, se usa la versión por defecto. Consulta la documentación de AnyAIGC para ver la lista actual.

¿Qué diferencia hay entre Max Mode y la generación estándar?

Max Mode usa ajustes de generación de mayor calidad y suele ofrecer más detalle en la voz y arreglos más completos, al doble del precio estándar ($0.2382 por petición). Usa Max Mode para temas listos para publicar y el modo estándar para demos y exploración por lotes.

¿Puedo obtener una factura de AnyAIGC?

Sí. Puedes emitir tus propias facturas en la consola, por el importe que hayas recargado realmente.

¿Puedo usar la música generada con fines comerciales?

Los derechos comerciales dependen de las condiciones de licencia más recientes de Suno y de tu caso de uso concreto. Revisa las condiciones oficiales de Suno antes de cualquier publicación comercial y contacta con el soporte de AnyAIGC si tienes dudas.

¿Qué métodos de pago se admiten?

Puedes recargar saldo con WeChat Pay, Alipay, USDT o tarjeta de crédito. Tu saldo está en USD y sirve para todos los modelos de la plataforma. Las facturas se pueden emitir en la consola por el importe recargado.

¿Hay crédito de prueba gratuito para usuarios nuevos?

Sí. Las cuentas nuevas reciben 2 millones de tokens de crédito de prueba para que pruebes antes de decidir si recargas saldo. Las recargas empiezan en $1.

¿Puedo pedir el reembolso de mi saldo?

Sí. El saldo no utilizado se puede reembolsar sin comisión. Contacta con soporte para iniciar el reembolso.

¿Son los modelos reales? ¿Están seguros mis datos?

Las peticiones van a los canales oficiales de los modelos, nunca a sustitutos más baratos o de ingeniería inversa. Salvo que la ley lo exija, no almacenamos de forma persistente tus prompts ni tus resultados, ni los usamos para entrenar modelos, y la consola muestra los tokens y el coste de cada petición.

¿Qué géneros e idiomas se admiten?

Suno cubre los principales géneros, entre ellos pop, rock, electrónica, lo-fi, hip-hop, folk y bandas sonoras de cine, con letras y voces en inglés, chino, japonés, coreano y muchos otros idiomas.
