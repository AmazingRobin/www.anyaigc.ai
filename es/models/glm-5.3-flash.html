Acerca de

Un modelo nativamente multimodal sobre una base y una arquitectura nuevas

Zhipu presenta GLM-5.3-Flash como el primer modelo GLM-5 nativamente multimodal, que ofrece más que GLM-5.2 a un coste muy bajo. A diferencia de GLM-5.3, parte de un modelo base entrenado desde cero, preentrenado con aproximadamente 30T tokens que incluyen datos multimodales.

Es un MoE con 320B de parámetros totales y 18B activos. Zhipu afirma que es el primer modelo de frontera con pesos abiertos que combina atención dispersa con atención lineal, y usa hiperconexiones con restricción de variedad (mHC). En comparación con GLM-5.3, el cómputo de atención baja aproximadamente 3x y la caché KV aproximadamente 4.4x, lo que mantiene la capacidad de contexto largo y reduce mucho el coste de servicio. Tiene una ventana de contexto de 1M de tokens, hasta 128K de salida, y el modo de razonamiento (thinking) está siempre activo.

En AnyAIGC, glm-5.3-flash funciona con el endpoint /v1/chat/completions compatible con OpenAI, acepta texto e imágenes y se usa directamente en Claude Code, con concurrencia sin límite.

Inicio rápido

Conéctate a la API de GLM-5.3-Flash en tres pasos

  1. Regístrate y recarga saldo: crea una cuenta en anyaigc.ai. Recarga desde $1; tu saldo sirve para todos los modelos de la plataforma.
  2. Crea una clave de API: crea una clave en la consola, copia el valor que empieza por sk- y guárdalo en la variable de entorno ANYAIGC_API_KEY.
  3. Envía una petición: llama a POST https://anyaigc.ai/v1/chat/completions con model igual a glm-5.3-flash y una cabecera Authorization: Bearer. Con el SDK de OpenAI, basta con establecer base_url en https://anyaigc.ai/v1.

Consejo: GLM-5.3-Flash siempre razona. Su razonamiento llega en el campo reasoning_content, y reasoning_effort (low / high / max) fija la profundidad. Envía las imágenes como bloques de contenido image_url, con una URL pública o en Base64. En chats de varios turnos y llamadas a herramientas, devuelve el mensaje completo del asistente en la siguiente petición, sin modificarlo.

Consulta la referencia de Chat Completions para ver todos los parámetros. Sustituye el nombre del modelo en los ejemplos de la documentación por el ID del modelo GLM que quieras.

Claude Code

Usa GLM-5.3-Flash en Claude Code

Cambia Claude Code a GLM-5.3-Flash: a aproximadamente 1/15 del precio de GLM-5.3, resuelve la programación diaria y lee capturas de pantalla para corregir la interfaz.

  1. Instala Claude Code: usa el instalador oficial, por ejemplo curl -fsSL https://claude.ai/install.sh | bash en macOS o Linux.
  2. Añade la configuración: edita ~/.claude/settings.json, añade el bloque env de abajo y sustituye ANTHROPIC_AUTH_TOKEN por la clave que creaste en AnyAIGC.
  3. Empieza a programar: ejecuta claude en la carpeta de tu proyecto. Escribe /model para confirmar que el modelo actual es glm-5.3-flash.

Para problemas difíciles: en refactorizaciones complejas entre módulos o tareas de larga duración, cambia ANTHROPIC_MODEL en la configuración a glm-5.3 y deja Flash para las subtareas ligeras.

Para el recorrido completo y los errores habituales, consulta la guía de configuración de Claude Code. Sustituye el nombre del modelo de la guía por glm-5.3-flash.

Preguntas frecuentes

Preguntas frecuentes sobre la API de GLM-5.3-Flash

¿Cuánto cuesta la API de GLM-5.3-Flash?

En AnyAIGC, glm-5.3-flash se factura por token: entrada a $0.0607 por millón de tokens, salida a $0.2025 por millón de tokens y acierto de caché a $0.0122 por millón de tokens. Los precios oficiales de Zhipu en USD son $0.15 de entrada, $0.50 de salida y $0.03 de acierto de caché, así que AnyAIGC cuesta aproximadamente el 40.5 % del precio oficial (aproximadamente un 60 % menos). La salida incluye los tokens de razonamiento (thinking). Consulta el catálogo de modelos para ver los precios en tiempo real.

¿Cuál es el ID del modelo de GLM-5.3-Flash y qué tamaño tiene el contexto?

El ID del modelo es glm-5.3-flash. Zhipu indica una ventana de contexto de 1M de tokens y hasta 128K tokens de salida. A través de AnyAIGC acepta texto e imágenes como entrada.

¿En qué se diferencia GLM-5.3-Flash de GLM-5.3?

GLM-5.3-Flash se basa en un modelo base entrenado desde cero: 320B de parámetros totales y 18B activos, con atención híbrida dispersa y lineal. Es el primer modelo GLM-5 multimodal nativo. Según Zhipu, comparado con GLM-5.3, necesita aproximadamente 3 veces menos cálculo de atención y aproximadamente 4.4 veces menos caché KV. GLM-5.3 es el modelo insignia más potente para el trabajo de programación más difícil y acepta solo texto. Flash acepta imágenes y cuesta aproximadamente 1/15 (entrada $0.0607 frente a $0.9450).

¿Es GLM-5.3-Flash mejor que GLM-5.2?

Zhipu afirma que GLM-5.3-Flash supera en conjunto a GLM-5.2 con aproximadamente una décima parte del precio. Comparaciones publicadas: DeepSWE 63.4 frente a 46.2, Toolathlon Verified 78.4 frente a 59.9, AutomationBench 48.8 frente a 26.2 y GDPval-AA v2 1773 frente a 1504.

¿GLM-5.3-Flash acepta imágenes? ¿Cómo se envían?

Sí. Añade un bloque de contenido {"type": "image_url", "image_url": {"url": ...}} al array messages[].content. El valor de url puede ser una URL pública de imagen o una URL de datos en Base64. Para varias imágenes, añade varios bloques.

¿Puedo usar GLM-5.3-Flash en Claude Code?

Sí. En el bloque env de ~/.claude/settings.json, establece ANTHROPIC_BASE_URL en https://anyaigc.ai, ANTHROPIC_AUTH_TOKEN en tu clave de API y ANTHROPIC_MODEL en glm-5.3-flash. Después ejecuta claude. Pagas por token, sin una ventana de cuota de 5 horas como en un plan de suscripción.

¿Puedo desactivar el razonamiento (thinking) en GLM-5.3-Flash?

No. GLM-5.3-Flash siempre razona, y Zhipu no permite desactivarlo. Usa reasoning_effort para fijar la profundidad: low, high o max (por defecto max). En tareas sencillas como clasificación y extracción, low reduce los tokens de salida.

¿GLM-5.3-Flash es de código abierto?

Sí. Zhipu ha publicado los pesos de GLM-5.3-Flash en Hugging Face (zai-org/GLM-5.3-Flash) con licencia MIT. Si llamas a la API a través de AnyAIGC, no necesitas alojarlo tú mismo. El uso comercial se rige por los términos oficiales de Zhipu AI.

¿Hay límites de concurrencia o de peticiones?

AnyAIGC no limita la concurrencia de glm-5.3-flash, y todos los usuarios la tienen por defecto. Es adecuado para trabajos por lotes, pipelines de CI y agentes en paralelo. La facturación es por token, así que no hay una cuota que se reinicie por ventana de tiempo como en un plan de suscripción.

¿Cómo obtengo una clave de API de GLM-5.3-Flash?

Regístrate en anyaigc.ai, recarga saldo y crea una clave en la consola. La misma clave sirve para todos los modelos GLM y para más de 300 modelos de la plataforma, así que no necesitas una cuenta aparte en la plataforma de Zhipu ni un GLM Coding Plan.

¿Puedo obtener una factura de AnyAIGC?

Sí. Puedes emitir tus propias facturas en la consola, por el importe que hayas recargado realmente.

¿Qué métodos de pago se admiten?

Puedes recargar saldo con WeChat Pay, Alipay, USDT o tarjeta de crédito. Tu saldo está en USD y sirve para todos los modelos de la plataforma. Las facturas se pueden emitir en la consola por el importe recargado.

¿Hay crédito de prueba gratuito para usuarios nuevos?

Sí. Las cuentas nuevas reciben 2 millones de tokens de crédito de prueba para que pruebes antes de decidir si recargas saldo. Las recargas empiezan en $1.

¿Puedo pedir el reembolso de mi saldo?

Sí. El saldo no utilizado se puede reembolsar sin comisión. Contacta con soporte para iniciar el reembolso.

¿Son los modelos reales? ¿Están seguros mis datos?

Las peticiones van a los canales oficiales de los modelos, nunca a sustitutos más baratos o de ingeniería inversa. Salvo que la ley lo exija, no almacenamos de forma persistente tus prompts ni tus resultados, ni los usamos para entrenar modelos, y la consola muestra los tokens y el coste de cada petición.

¿Se usarán mis datos para entrenar modelos?

No. Salvo cuando lo exija la ley, AnyAIGC no almacena de forma persistente tus prompts ni tus resultados, y no los usa para entrenar modelos. Las peticiones se cifran mediante HTTPS.
