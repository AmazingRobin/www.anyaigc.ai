Acerca de

Un modelo de agente abierto y multimodal de propósito general

Moonshot AI presenta Kimi K2.6 como un modelo de agente abierto y nativamente multimodal. Según Moonshot, escribe código largo con más capacidad y consistencia, con mejoras claras en el seguimiento de instrucciones y la autocorrección. Acepta texto e imágenes como entrada y tiene modo de razonamiento (thinking) y modo sin razonamiento, así que sirve tanto para chat como para tareas de agente.

Por dentro es un MoE con 1T de parámetros en total y 32B activos, contexto de 256K y cuantización INT4 nativa. Moonshot destaca cuatro áreas: programación de larga duración, interfaz a partir de prompts o imágenes (Coding-Driven Design), Agent Swarm con escalado hasta 300 subagentes y agentes proactivos que funcionan 24/7.

En AnyAIGC, kimi-k2.6 funciona con el endpoint /v1/chat/completions compatible con OpenAI y directamente en Claude Code, con concurrencia sin límite.

Inicio rápido

Conéctate a la API de Kimi K2.6 en tres pasos

  1. Regístrate y recarga saldo: crea una cuenta en anyaigc.ai. Recarga desde $1; tu saldo sirve para todos los modelos de la plataforma.
  2. Crea una clave de API: crea una clave en la consola, copia el valor que empieza por sk- y guárdalo en la variable de entorno ANYAIGC_API_KEY.
  3. Envía una petición: llama a POST https://anyaigc.ai/v1/chat/completions con model igual a kimi-k2.6 y una cabecera Authorization: Bearer. Con el SDK de OpenAI, basta con establecer base_url en https://anyaigc.ai/v1.

Consejo: K2.6 razona por defecto y el razonamiento se devuelve en reasoning_content. En la API de Moonshot, thinking: {"type": "disabled"} desactiva el modo de razonamiento (thinking) (con el SDK de OpenAI, pásalo en extra_body); Moonshot recomienda temperature=0.6 en el modo sin razonamiento. En el modo de razonamiento, para chats de varios turnos y llamadas a herramientas, devuelve el mensaje completo del asistente sin cambios en la siguiente petición.

Consulta la referencia de Chat Completions para ver todos los parámetros. Sustituye el nombre del modelo de los ejemplos de la documentación por el ID del modelo Kimi que quieras usar.

Claude Code

Usa Kimi K2.6 en Claude Code

Cambia Claude Code a Kimi K2.6. Es multimodal y de bajo coste, adecuado para programar a diario y corregir interfaces a partir de capturas de pantalla.

  1. Instala Claude Code: usa el instalador oficial (por ejemplo, npm install -g @anthropic-ai/claude-code).
  2. Añade la configuración: edita ~/.claude/settings.json, añade el bloque env de abajo y sustituye ANTHROPIC_AUTH_TOKEN por la clave que creaste en AnyAIGC.
  3. Empieza a programar: ejecuta claude en la carpeta de tu proyecto. Escribe /model para confirmar que el modelo actual es kimi-k2.6.

Cambia al modelo de programación: para una mayor tasa de éxito al programar, sustituye kimi-k2.6 en la configuración por kimi-k2.7-code. Ambos cuestan lo mismo.

Para ver la guía completa y los errores habituales, consulta la guía de configuración de Claude Code. Sustituye el nombre del modelo de la guía por kimi-k2.6.

Preguntas frecuentes

Preguntas frecuentes sobre la API de Kimi K2.6

¿Cuánto cuesta la API de Kimi K2.6?

En AnyAIGC, kimi-k2.6 se factura por token: entrada $0.3847 por millón de tokens, salida $1.5980 por millón de tokens, acierto de caché $0.0651 por millón de tokens. Los precios oficiales de Moonshot en USD son entrada $0.95, salida $4.00 y acierto de caché $0.16, de modo que AnyAIGC cuesta aproximadamente el 40 % del precio oficial. Consulta el catálogo de modelos para ver los precios en tiempo real.

¿Cuál es el ID del modelo Kimi K2.6 y qué tamaño tiene el contexto?

El ID del modelo es kimi-k2.6. Moonshot indica una ventana de contexto de 262.144 tokens (256K), con entrada de texto e imagen.

¿Puedo desactivar el modo de razonamiento (thinking) en Kimi K2.6?

K2.6 admite tanto el modo de razonamiento (thinking) como el modo sin razonamiento (Instant). En la API de Moonshot, thinking: {"type": "disabled"} desactiva el modo de razonamiento; con el SDK de OpenAI, pásalo en extra_body. Moonshot recomienda temperature=1.0 para el modo de razonamiento y temperature=0.6 para el modo sin razonamiento, con top_p 0.95 en ambos.

¿Qué distingue a Kimi K2.6?

Moonshot presenta K2.6 como un modelo de agente multimodal nativo y abierto con cuatro áreas principales: programación de larga duración (Rust, Go, Python, front end, DevOps y ajuste de rendimiento), interfaces listas para producción a partir de prompts o imágenes, Agent Swarm (escala hasta 300 subagentes y 4.000 pasos coordinados) y agentes proactivos que se ejecutan en segundo plano 24/7.

¿Kimi K2.6 o K2.7 Code: cuál debo usar?

Comparten arquitectura y cuestan lo mismo en entrada y salida en AnyAIGC. K2.7 Code es K2.6 con entrenamiento adicional para programación, con mejores puntuaciones en código y menos tokens de razonamiento, pero solo funciona en modo de razonamiento (thinking). K2.6 puede desactivarlo, lo que encaja con chat rápido, clasificación, extracción y agentes generales.

¿Puedo usar Kimi K2.6 en Claude Code?

Sí. En el bloque env de ~/.claude/settings.json, establece ANTHROPIC_BASE_URL en https://anyaigc.ai, ANTHROPIC_AUTH_TOKEN en tu clave de API y ANTHROPIC_MODEL en kimi-k2.6. Después ejecuta claude.

¿Kimi K2.6 admite llamadas a herramientas y entrada de imágenes?

Sí. K2.6 admite llamadas a herramientas de varios pasos, streaming y entrada de imágenes. En el modo de razonamiento (thinking), para chats de varios turnos y llamadas a herramientas, devuelve el mensaje completo del asistente (incluidos reasoning_content y tool_calls) sin cambios en la siguiente petición.

¿Hay límites de concurrencia o de peticiones?

AnyAIGC no limita la concurrencia de kimi-k2.6 y todos los usuarios la tienen por defecto. Es adecuado para trabajos por lotes, pipelines de CI y agentes en paralelo. La plataforma de Moonshot limita la concurrencia, RPM, TPM y TPD según el nivel de recarga; esos niveles no se aplican cuando llamas a través de AnyAIGC.

¿Cómo obtengo una clave de API de Kimi K2.6?

Regístrate en anyaigc.ai, recarga saldo y crea una clave en la consola. La misma clave sirve para todos los modelos Kimi y para más de 300 modelos adicionales de la plataforma, así que no necesitas una cuenta aparte en la plataforma de Moonshot.

¿Puedo obtener una factura de AnyAIGC?

Sí. Puedes emitir tus propias facturas en la consola, por el importe que hayas recargado realmente.

¿Qué métodos de pago se admiten?

Puedes recargar saldo con WeChat Pay, Alipay, USDT o tarjeta de crédito. Tu saldo está en USD y sirve para todos los modelos de la plataforma. Las facturas se pueden emitir en la consola por el importe recargado.

¿Hay crédito de prueba gratuito para usuarios nuevos?

Sí. Las cuentas nuevas reciben 2 millones de tokens de crédito de prueba para que pruebes antes de decidir si recargas saldo. Las recargas empiezan en $1.

¿Puedo pedir el reembolso de mi saldo?

Sí. El saldo no utilizado se puede reembolsar sin comisión. Contacta con soporte para iniciar el reembolso.

¿Son los modelos reales? ¿Están seguros mis datos?

Las peticiones van a los canales oficiales de los modelos, nunca a sustitutos más baratos o de ingeniería inversa. Salvo que la ley lo exija, no almacenamos de forma persistente tus prompts ni tus resultados, ni los usamos para entrenar modelos, y la consola muestra los tokens y el coste de cada petición.

¿Se usarán mis datos para entrenar modelos?

No. Salvo que lo exija la ley, AnyAIGC no almacena de forma persistente tus prompts ni las salidas y no los usa para entrenar modelos. Las peticiones se cifran mediante HTTPS. Consulta la Política de privacidad de AnyAIGC. La política de datos del propio modelo se rige por las condiciones oficiales de Moonshot AI.
