Streaming en Python
# pip install openai
import os
from openai import OpenAI

client = OpenAI(api_key=os.environ["ANYAIGC_API_KEY"], base_url="https://anyaigc.ai/v1")

stream = client.chat.completions.create(
    model="hy4",
    messages=[{"role": "user", "content": "Introduce yourself in three sentences and say what tasks you are best at."}],
    stream=True,
)
for chunk in stream:
    if chunk.choices and chunk.choices[0].delta.content:
        print(chunk.choices[0].delta.content, end="", flush=True)
print()

Preguntas frecuentes

Preguntas frecuentes sobre la API de Hy4

¿Cuánto cuesta la API de Hy4 y cuánto se queda por debajo del precio de lista?

Se factura por token en USD por millón de tokens: entrada $0.5630 (lista $0.834), salida $1.6880 (lista $2.501), acierto de caché $0.0283 (lista $0.042). El precio de lista de Tencent Cloud es ¥6 de entrada, ¥18 de salida y ¥0.3 por acierto de caché; los precios de lista en USD usan aproximadamente 7.19 CNY por USD. Las tres tarifas de AnyAIGC equivalen a aproximadamente el 67.5 % del precio de lista, es decir, aproximadamente el 32 % menos. Consulta el catálogo de modelos para ver las tarifas en tiempo real.

¿Qué diferencia hay entre Hy4 y Hy4 preview?

Según las notas de la versión de Tencent (2026-11-04), el Hy4 oficial añade por primera vez visión y computer use, refuerza el trabajo de agentes y de largo recorrido, y reduce la tasa de alucinaciones en su propia prueba del 15.76 % de preview al 5.45 %. Tencent también indica que el precio de la API no cambia respecto a preview. Estas cifras proceden de las notas de la versión; AnyAIGC no las ha vuelto a probar.

¿Hy4 admite imágenes como entrada?

Sí. Tencent indica que Hy4 incorpora visión por primera vez. Envía una URL de imagen o datos en base64 en una parte de contenido image_url en POST /v1/chat/completions; la salida es texto. La documentación de AnyAIGC no indica por ahora límites de tamaño ni de número de imágenes, así que sigue la documentación.

¿Qué endpoint de la API debo usar?

Funcionan ambos formatos: el POST https://anyaigc.ai/v1/chat/completions compatible con OpenAI y el POST https://anyaigc.ai/v1/messages de estilo Anthropic, los dos con Authorization: Bearer <API Key> y model establecido en hy4. Con el SDK de OpenAI, define base_url como https://anyaigc.ai/v1.

¿La concurrencia tiene límite?

AnyAIGC ofrece Hy4 con concurrencia sin límite para todas las cuentas por defecto. Las peticiones con contexto largo y las de agentes tardan más, así que configura tiempos de espera y reintentos razonables.

¿Puedo usar los resultados con fines comerciales?

El uso del modelo y de su salida se rige por los términos oficiales de Tencent Hunyuan. AnyAIGC es un proveedor de API independiente y no está afiliado a Tencent.

¿Puedo obtener una factura de AnyAIGC?

Sí. Puedes emitir tus propias facturas en la consola, por el importe que hayas recargado realmente.

¿Qué métodos de pago se admiten?

Puedes recargar saldo con WeChat Pay, Alipay, USDT o tarjeta de crédito. Tu saldo está en USD y sirve para todos los modelos de la plataforma. Las facturas se pueden emitir en la consola por el importe recargado.

¿Hay crédito de prueba gratuito para usuarios nuevos?

Sí. Las cuentas nuevas reciben 5 millones de tokens de crédito de prueba para que pruebes antes de decidir si recargas saldo. Las recargas empiezan en $1.

¿Puedo pedir el reembolso de mi saldo?

Sí. El saldo no utilizado se puede reembolsar sin comisión. Contacta con soporte para iniciar el reembolso.

¿Son los modelos reales? ¿Están seguros mis datos?

Las peticiones van a los canales oficiales de los modelos, nunca a sustitutos más baratos o de ingeniería inversa. Salvo que la ley lo exija, no almacenamos de forma persistente tus prompts ni tus resultados, ni los usamos para entrenar modelos, y la consola muestra los tokens y el coste de cada petición.
