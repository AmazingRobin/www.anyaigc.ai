Sobre el modelo

La versión 3.5 de iFLYTEK Spark Max

SparkDesk-v3.5 es la versión 3.5 de la API del modelo cognitivo Spark de iFLYTEK y corresponde al nivel oficial Spark Max. El catálogo lo describe como un modelo con conocimiento de varios dominios y comprensión del lenguaje que ejecuta tareas mediante conversación natural, y abarca comprensión del lenguaje, preguntas y respuestas sobre conocimiento, razonamiento lógico, resolución de problemas matemáticos y comprensión de código.

La documentación de iFLYTEK indica para este nivel una ventana de contexto de 8.192 tokens y una salida máxima de 8.192 tokens, con prompts de sistema (solo Max y Ultra) y un plugin de búsqueda web (Pro, Max y Ultra). El documento indica que las llamadas a funciones requieren el protocolo HTTP y no las detalla por nivel. Lo que funciona en la práctica a través de AnyAIGC conviene confirmarlo en la documentación de la API y con una petición de prueba.

En AnyAIGC, SparkDesk-v3.5 usa el endpoint /v1/chat/completions compatible con OpenAI con una única clave Bearer. No necesitas el APPID, la APIKey ni el APISecret de iFLYTEK, ni la firma oficial de WebSocket. La facturación es por token y sin límite de concurrencia.

Inicio rápido

Usa la API de SparkDesk-v3.5 en tres pasos

  1. Regístrate y recarga saldo: crea una cuenta en anyaigc.ai. Las recargas empiezan en $1 y el saldo sirve para todos los modelos de la plataforma.
  2. Crea una clave de API: genera un token en la consola, copia la clave que empieza por sk- y guárdala en la variable de entorno ANYAIGC_API_KEY.
  3. Envía una petición: llama a POST https://anyaigc.ai/v1/chat/completions con model establecido en SparkDesk-v3.5 y Authorization: Bearer. Con el SDK de OpenAI, basta con establecer base_url en https://anyaigc.ai/v1.

Consejo sobre parámetros: el ID del modelo distingue mayúsculas y minúsculas, así que escribe SparkDesk-v3.5. El formato de la respuesta coincide con OpenAI Chat Completions y el recuento de tokens de la petición está en el campo usage. El contexto es limitado, así que divide los documentos largos o recupera solo los fragmentos relevantes antes de preguntar.

Consulta la referencia de Chat Completions para ver todos los parámetros. Sustituye el nombre del modelo de los ejemplos por el ID del modelo SparkDesk.

ESPECIFICACIONES

Especificaciones y cuándo elegirlo

En la documentación oficial de WebSocket de iFlytek, el endpoint v3.5 (wss://spark-api.xf-yun.com/v3.5/chat) corresponde a Spark Max, con domain generalv3.5.

La documentación fija el rango de max_tokens de Max de 1 a 8192, con 4096 por defecto.

Según la documentación, Max admite el plugin de búsqueda web y, igual que Ultra, puede devolver los títulos y las URL de las fuentes web que ha usado.

Esta página indica Entrada a $13.1040 y Salida a $13.1040, igual que la tabla de precios anterior.

Si no necesitas los títulos ni las URL de las fuentes web, sparkdesk-v3.1 (Pro) también admite búsqueda web y tiene el mismo límite de 8192 para max_tokens.

Las especificaciones proceden de la documentación oficial del proveedor (xfyun.cn). La tabla de esta página muestra el precio, y el catálogo de modelos es la referencia para las tarifas en tiempo real.

Preguntas frecuentes

Preguntas frecuentes sobre la API de SparkDesk-v3.5

¿Cuánto cuesta la API de SparkDesk-v3.5?

En AnyAIGC, SparkDesk-v3.5 se factura por token: $13.1040 por millón de tokens de entrada y $13.1040 por millón de tokens de salida, el mismo precio para ambos. Los precios son fijos, sin suscripción ni cuota mensual. Los precios en tiempo real están en el catálogo de modelos.

¿Cuál es el ID del modelo SparkDesk-v3.5 y qué relación tiene con iFLYTEK Spark?

El ID del modelo es SparkDesk-v3.5 (distingue mayúsculas y minúsculas). Es una versión del modelo cognitivo Spark de iFLYTEK, que AnyAIGC ofrece mediante una API compatible con OpenAI. No tiene relación con Apache Spark ni con la aplicación de correo Spark.

¿Cómo elijo entre SparkDesk-v3.5 y los demás modelos SparkDesk?

SparkDesk-v3.1 y SparkDesk-v2.1 son los otros dos de la serie. Un número de versión más alto corresponde a un nivel más reciente de iFLYTEK: v3.5 es Max, v3.1 es Pro y v2.1 es una versión 2.x temprana. Elige v3.5 si necesitas un prompt de sistema. Considera v2.1 cuando el coste importe más y las exigencias de calidad sean moderadas, y pruébalo con tus propios datos antes del lanzamiento. Los tres cobran lo mismo por la entrada y por la salida en AnyAIGC.

¿SparkDesk es compatible con la API de OpenAI y cómo se llama?

Sí. SparkDesk-v3.5 usa POST https://anyaigc.ai/v1/chat/completions, y las peticiones y respuestas coinciden con OpenAI Chat Completions. Con el SDK oficial de OpenAI, establece base_url en https://anyaigc.ai/v1. No necesitas la firma WebSocket de iFLYTEK, solo Authorization: Bearer.

¿Qué tamaño tiene la ventana de contexto de SparkDesk-v3.5?

La documentación de iFLYTEK indica una ventana de contexto de 8.192 tokens y una salida máxima de 8.192 tokens para este nivel, así que divide los documentos largos o recupera fragmentos antes de preguntar. Confirma el comportamiento real con una petición de prueba a través de AnyAIGC.

¿Hay límite de peticiones?

AnyAIGC no establece ningún límite de concurrencia en SparkDesk-v3.5 y todas las cuentas lo tienen por defecto, así que los trabajos por lotes y las tareas en paralelo no suponen un problema. La facturación es por token, sin cuota mensual ni cupo por ventana de tiempo.

¿Está obsoleto SparkDesk-v3.5?

La documentación de iFLYTEK indica que el plan Max dejó de estar disponible el 10 de marzo de 2026 y que el backend se actualizó a Ultra. SparkDesk-v3.5 se puede llamar todavía hoy en el catálogo de modelos de AnyAIGC; consulta el catálogo para ver la disponibilidad actual.

¿Cómo consigo una clave de API de SparkDesk-v3.5?

Regístrate y recarga saldo en anyaigc.ai y crea un token en la consola. Una sola clave sirve para más de 300 modelos de la plataforma, así que no necesitas APPID, APIKey ni APISecret de la plataforma abierta de iFLYTEK. Establece model en SparkDesk-v3.5 en el cuerpo de la petición.

¿Puedo obtener una factura de AnyAIGC?

Sí. Puedes emitir tus propias facturas en la consola, por el importe que hayas recargado realmente.

¿Qué métodos de pago se admiten?

Puedes recargar saldo con WeChat Pay, Alipay, USDT o tarjeta de crédito. Tu saldo está en USD y sirve para todos los modelos de la plataforma. Las facturas se pueden emitir en la consola por el importe recargado.

¿Hay crédito de prueba gratuito para usuarios nuevos?

Sí. Las cuentas nuevas reciben 2 millones de tokens de crédito de prueba para que pruebes antes de decidir si recargas saldo. Las recargas empiezan en $1.

¿Puedo pedir el reembolso de mi saldo?

Sí. El saldo no utilizado se puede reembolsar sin comisión. Contacta con soporte para iniciar el reembolso.

¿Son los modelos reales? ¿Están seguros mis datos?

Las peticiones van a los canales oficiales de los modelos, nunca a sustitutos más baratos o de ingeniería inversa. Salvo que la ley lo exija, no almacenamos de forma persistente tus prompts ni tus resultados, ni los usamos para entrenar modelos, y la consola muestra los tokens y el coste de cada petición.

¿Mis prompts se usan para entrenar modelos?

No. Salvo que la ley lo exija, AnyAIGC no almacena de forma persistente tus prompts ni las salidas y no los usa para entrenar. Las peticiones se cifran con HTTPS. Consulta la Política de privacidad de AnyAIGC. La política de datos del propio proveedor del modelo se rige por las condiciones de iFLYTEK.
