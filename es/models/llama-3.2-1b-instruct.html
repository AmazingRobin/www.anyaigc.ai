Conéctate a la API de Llama 3.2 1B Instruct

No necesitas un despliegue local. Empieza con una petición de texto y después conecta tu aplicación.

  1. 01Crea una cuenta de AnyAIGC y una clave de API en la consola.
  2. 02Define la variable de entorno ANYAIGC_API_KEY.
  3. 03Envía un mensaje con el ID de modelo exacto.
POST https://anyaigc.ai/v1/chat/completionsLee la referencia de la API ↗
cURL
curl --request POST "https://anyaigc.ai/v1/chat/completions" \
  --header "Authorization: Bearer $ANYAIGC_API_KEY" \
  --header "Content-Type: application/json" \
  --data '{
  "model": "llama-3.2-1b-instruct",
  "messages": [
    {
      "role": "user",
      "content": "Explain what an API is in three sentences."
    }
  ],
  "n": 1,
  "stream": false
}'
Python
import json
import os
import urllib.request

payload = {
  "model": "llama-3.2-1b-instruct",
  "messages": [
    {
      "role": "user",
      "content": "Explain what an API is in three sentences."
    }
  ],
  "n": 1,
  "stream": False
}
request = urllib.request.Request(
    "https://anyaigc.ai/v1/chat/completions",
    data=json.dumps(payload, ensure_ascii=False).encode("utf-8"),
    headers={
        "Authorization": "Bearer " + os.environ["ANYAIGC_API_KEY"],
        "Content-Type": "application/json",
    },
    method="POST",
)
with urllib.request.urlopen(request, timeout=120) as response:
    result = json.load(response)

print(json.dumps(result, ensure_ascii=False, indent=2))

El ejemplo de cURL usa sintaxis de Bash / zsh; Python usa solo la biblioteca estándar. Con n=1 y stream=false, la respuesta contiene un candidato de respuesta en choices y usage. Define stream=true para obtener salida SSE.

Preguntas frecuentes sobre la API de Llama 3.2 1B Instruct

Precios, versiones, integración y compras para empresas.

¿Cuánto cuesta la API de Llama 3.2 1B Instruct?

La entrada cuesta $0.3375 y la salida $0.0844 por millón de tokens, en USD. Los modelos con la oferta ahorran un 32 %, tal como se muestra en el catálogo de modelos. Las tarifas publicadas ya incluyen el descuento; no lo apliques de nuevo. Consulta el catálogo de modelos para ver las tarifas actuales.

¿Qué relación hay entre Llama y Ollama? ¿Qué versiones figuran?

Meta desarrolla la familia de modelos Llama. Ollama es un entorno de ejecución de modelos y la categoría de proveedor que usa el catálogo de AnyAIGC. Estas guías cubren 12 modelos de Llama 2, 3, 3.1, 3.2 y 3.3. El uso comercial está sujeto a las condiciones oficiales de Meta.

¿Qué ID de modelo debo enviar y qué devuelve una petición?

Usa POST /v1/chat/completions con llama-3.2-1b-instruct y autenticación con clave de API Bearer. Los ejemplos fijan n=1 y stream=false para devolver un candidato de respuesta del asistente y el uso de tokens. El nombre llama se usa para este resumen.

¿Hay límites de concurrencia o de RPM? ¿Necesito instalar Ollama?

Todos los usuarios tienen concurrencia sin límite y sin tope fijo de RPM por defecto. Llama a la API en la nube de AnyAIGC sin instalar Ollama ni desplegar el modelo en local. Tu aplicación debe seguir gestionando los tiempos de espera de red y los errores de la API.

¿Qué modelos aceptan imágenes? ¿Y qué idiomas admiten?

Los modelos Llama 3.2 Vision Instruct de 11B y 90B son modelos de visión; los demás modelos listados son modelos de texto. Llama 3.1–3.3 admiten oficialmente ocho idiomas de texto, sin incluir el chino. En las tareas de imagen y texto, el idioma admitido oficialmente es el inglés. Evalúa otros idiomas con tus propios datos; estos ejemplos muestran peticiones de texto.

¿Puedo obtener una factura de AnyAIGC?

Sí. Puedes emitir tus propias facturas en la consola, por el importe que hayas recargado realmente.

¿Qué métodos de pago se admiten?

Puedes recargar saldo con WeChat Pay, Alipay, USDT o tarjeta de crédito. Tu saldo está en USD y sirve para todos los modelos de la plataforma. Las facturas se pueden emitir en la consola por el importe recargado.

¿Hay crédito de prueba gratuito para usuarios nuevos?

Sí. Las cuentas nuevas reciben 2 millones de tokens de crédito de prueba para que pruebes antes de decidir si recargas saldo. Las recargas empiezan en $1.

¿Puedo pedir el reembolso de mi saldo?

Sí. El saldo no utilizado se puede reembolsar sin comisión. Contacta con soporte para iniciar el reembolso.

¿Son los modelos reales? ¿Están seguros mis datos?

Las peticiones van a los canales oficiales de los modelos, nunca a sustitutos más baratos o de ingeniería inversa. Salvo que la ley lo exija, no almacenamos de forma persistente tus prompts ni tus resultados, ni los usamos para entrenar modelos, y la consola muestra los tokens y el coste de cada petición.
