INICIO RÁPIDO

Integra la API de Kling Image 3.0

  1. 1Regístrate, crea una clave de API y define ANYAIGC_API_KEY
  2. 2Envía POST /tencent-vod/v1/aigc-image para crear una tarea y obtener su TaskId
  3. 3Haz sondeo de GET /tencent-vod/v1/query/{task_id} y descarga la imagen cuando Status sea FINISH

Define model_name como "Kling", model_version como "3.0" y output_config.resolution como "2K" o "4K", en mayúsculas. El resultado está en Response.AigcImageTask.Output.FileInfos[].FileUrl; es almacenamiento temporal con fecha de caducidad, así que descárgalo cuanto antes.

Lee la referencia de la API ↗ · Ver la documentación de consulta de tareas ↗

cURL

curl --request POST "https://anyaigc.ai/tencent-vod/v1/aigc-image" \
  --header "Authorization: Bearer $ANYAIGC_API_KEY" \
  --header "Content-Type: application/json" \
  --data '{
  "model_name": "Kling",
  "model_version": "3.0",
  "prompt": "An orange cat on a rain-soaked windowsill, a neon-lit street outside, cinematic lighting, rich detail",
  "output_config": {
    "aspect_ratio": "16:9",
    "resolution": "2K"
  }
}'

# Query the result with the returned Response.TaskId
curl "https://anyaigc.ai/tencent-vod/v1/query/$TASK_ID" \
  --header "Authorization: Bearer $ANYAIGC_API_KEY"

Python

import json
import os
import time
import urllib.request

BASE = "https://anyaigc.ai"
HEADERS = {
    "Authorization": "Bearer " + os.environ["ANYAIGC_API_KEY"],
    "Content-Type": "application/json",
}


def call(method, path, payload=None):
    data = json.dumps(payload, ensure_ascii=False).encode("utf-8") if payload else None
    request = urllib.request.Request(BASE + path, data=data, headers=HEADERS, method=method)
    with urllib.request.urlopen(request, timeout=60) as response:
        return json.load(response)


payload = {
    "model_name": "Kling",
    "model_version": "3.0",
    "prompt": "An orange cat on a rain-soaked windowsill, a neon-lit street outside, cinematic lighting, rich detail",
    "output_config": {
        "aspect_ratio": "16:9",
        "resolution": "2K"
    }
}

task_id = call("POST", "/tencent-vod/v1/aigc-image", payload)["Response"]["TaskId"]
print("task_id:", task_id)

# Poll every 5 seconds; print the image URL once Status is FINISH
for _ in range(60):
    result = call("GET", f"/tencent-vod/v1/query/{task_id}")["Response"]
    if result["Status"] == "FINISH":
        break
    time.sleep(5)
else:
    raise TimeoutError(task_id)

for item in result["AigcImageTask"]["Output"]["FileInfos"]:
    print(item["FileUrl"])

Preguntas frecuentes

Preguntas frecuentes sobre la API de Kling Image 3.0

¿Cuánto cuesta la API de Kling Image 3.0?

$0.00169 por llamada, que devuelve una imagen, en 2K o 4K al mismo precio. Los precios están en USD y se cobran cuando el envío se realiza correctamente; consulta el catálogo de modelos para ver las tarifas actuales.

¿A qué endpoint debo llamar?

Envía con POST /tencent-vod/v1/aigc-image, con model_name como Kling y model_version como 3.0, y consulta los resultados con GET /tencent-vod/v1/query/{task_id}. El host de la API es https://anyaigc.ai y la cabecera es Authorization: Bearer <API Key>.

¿Cómo defino la resolución?

Define output_config.resolution como "2K" o "4K", en mayúsculas. Ambos cuestan lo mismo.

¿Qué modos de generación se admiten?

De texto a imagen, imagen a imagen, referencia multimagen, transferencia de estilo, referencia de personaje e inpainting. Las imágenes de referencia van en file_infos; consulta la referencia de la API para los campos exactos.

¿Cómo obtengo el resultado?

La API es asíncrona. El envío devuelve Response.TaskId; haz sondeo del endpoint de consulta y, cuando Status sea FINISH, descarga la imagen desde Response.AigcImageTask.Output.FileInfos[].FileUrl. Los archivos se almacenan temporalmente y caducan.

¿Hay límites de concurrencia?

Los modelos de Kling en AnyAIGC tienen concurrencia sin límite por defecto en todas las cuentas.

¿Puedo usar las imágenes con fines comerciales?

Los derechos de uso y la política de contenido se rigen por las condiciones oficiales de Kuaishou Kling. Asegúrate de tener los derechos de las imágenes de referencia que subas.

¿Puedo obtener una factura de AnyAIGC?

Sí. Puedes emitir tus propias facturas en la consola, por el importe que hayas recargado realmente.

¿Qué métodos de pago se admiten?

Puedes recargar saldo con WeChat Pay, Alipay, USDT o tarjeta de crédito. Tu saldo está en USD y sirve para todos los modelos de la plataforma. Las facturas se pueden emitir en la consola por el importe recargado.

¿Hay crédito de prueba gratuito para usuarios nuevos?

Sí. Las cuentas nuevas reciben 5 millones de tokens de crédito de prueba para que pruebes antes de decidir si recargas saldo. Las recargas empiezan en $1.

¿Puedo pedir el reembolso de mi saldo?

Sí. El saldo no utilizado se puede reembolsar sin comisión. Contacta con soporte para iniciar el reembolso.

¿Son los modelos reales? ¿Están seguros mis datos?

Las peticiones van a canales oficiales de los modelos, nunca a sustitutos más baratos ni de ingeniería inversa. Salvo que la ley lo exija, no almacenamos de forma persistente tus prompts ni tus salidas ni los usamos para entrenamiento, y la consola muestra el coste de cada petición.
