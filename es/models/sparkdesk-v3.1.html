Sobre el modelo

La versión 3.1 de iFLYTEK Spark Pro

SparkDesk-v3.1 es la versión 3.1 de la API del modelo cognitivo Spark de iFLYTEK y corresponde al nivel oficial Spark Pro. El catálogo lo describe como un modelo con conocimiento de varios dominios y comprensión del lenguaje que ejecuta tareas mediante conversación natural, y abarca comprensión del lenguaje, preguntas y respuestas sobre conocimiento, razonamiento lógico, resolución de problemas matemáticos y comprensión de código.

La documentación de iFLYTEK indica una ventana de contexto de 8.192 tokens y una salida máxima de 8.192 tokens para este nivel. Según la documentación, el rol system solo está disponible en Max y Ultra, y el plugin de búsqueda web figura para Pro. Si tu aplicación necesita un prompt de sistema fijo, usa SparkDesk-v3.5.

En AnyAIGC, SparkDesk-v3.1 usa el endpoint /v1/chat/completions compatible con OpenAI con una sola clave Bearer, sin necesidad de APPID, APIKey ni APISecret de iFLYTEK. La facturación es por token y no hay límite de concurrencia.

Inicio rápido

Usa la API de SparkDesk-v3.1 en tres pasos

  1. Regístrate y recarga saldo: crea una cuenta en anyaigc.ai. Las recargas empiezan en $1 y el saldo sirve para todos los modelos de la plataforma.
  2. Crea una clave de API: genera un token en la consola, copia la clave que empieza por sk- y guárdala en la variable de entorno ANYAIGC_API_KEY.
  3. Envía una petición: llama a POST https://anyaigc.ai/v1/chat/completions con model establecido en SparkDesk-v3.1 y Authorization: Bearer. Con el SDK de OpenAI, basta con establecer base_url en https://anyaigc.ai/v1.

Consejo sobre parámetros: el ID del modelo distingue mayúsculas y minúsculas, así que escribe SparkDesk-v3.1. El formato de respuesta coincide con OpenAI Chat Completions y el recuento de tokens de la petición está en el campo usage. El contexto es limitado, así que divide los documentos largos o recupera solo los fragmentos relevantes antes de preguntar.

Consulta la referencia de Chat Completions para ver todos los parámetros. Sustituye el nombre del modelo de los ejemplos por el ID del modelo SparkDesk.

Especificaciones y cuándo elegirlo

En la documentación oficial de WebSocket de iFlytek, el endpoint v3.1 (wss://spark-api.xf-yun.com/v3.1/chat) corresponde a Spark Pro, con domain generalv3.

La documentación fija el rango de max_tokens de Pro de 1 a 8192, con 4096 por defecto.

Según la documentación, Pro admite el plugin de búsqueda web. Devolver títulos y URL de las fuentes está limitado a Ultra y Max.

Preguntas frecuentes

Preguntas frecuentes sobre la API de SparkDesk-v3.1

¿Cuánto cuesta la API de SparkDesk-v3.1?

En AnyAIGC, SparkDesk-v3.1 se factura por token: $13.1040 por millón de tokens de entrada y $13.1040 por millón de tokens de salida, el mismo precio para ambos. Los precios son fijos, sin suscripción ni cuota mensual. Los precios en tiempo real están en el catálogo de modelos.

¿Cuál es el ID del modelo SparkDesk-v3.1 y qué relación tiene con iFLYTEK Spark?

El ID del modelo es SparkDesk-v3.1 (distingue mayúsculas y minúsculas). Es una versión del modelo cognitivo Spark de iFLYTEK, y AnyAIGC lo ofrece mediante una API compatible con OpenAI. No tiene relación con Apache Spark ni con la aplicación de correo Spark.

¿Cómo elijo entre SparkDesk-v3.1 y los demás modelos SparkDesk?

SparkDesk-v3.5 y SparkDesk-v2.1 son los otros dos de la serie. Un número de versión más alto corresponde a un nivel más reciente de iFLYTEK: v3.5 es Max, v3.1 es Pro y v2.1 es una versión 2.x temprana. Elige v3.5 si necesitas un prompt de sistema. Considera v2.1 cuando el coste importe más y las exigencias de calidad sean moderadas, y pruébalo con tus propios datos antes del lanzamiento. Los tres cobran lo mismo por la entrada y por la salida en AnyAIGC.

¿SparkDesk es compatible con la API de OpenAI y cómo se llama?

Sí. SparkDesk-v3.1 usa POST https://anyaigc.ai/v1/chat/completions, y las peticiones y respuestas coinciden con OpenAI Chat Completions. Con el SDK oficial de OpenAI, establece base_url en https://anyaigc.ai/v1. No necesitas la firma WebSocket de iFLYTEK, solo Authorization: Bearer.

¿Qué tamaño tiene la ventana de contexto de SparkDesk-v3.1?

La documentación de iFLYTEK indica una ventana de contexto de 8.192 tokens y una salida máxima de 8.192 tokens para este nivel, así que divide los documentos largos o recupera fragmentos antes de preguntar. Confirma el comportamiento real con una petición de prueba a través de AnyAIGC.

¿Hay límite de peticiones?

AnyAIGC no establece ningún límite de concurrencia en SparkDesk-v3.1 y todas las cuentas lo tienen por defecto, así que los trabajos por lotes y las tareas en paralelo no suponen un problema. La facturación es por token, sin cuota mensual ni cupo por ventana de tiempo.

¿Está obsoleto SparkDesk-v3.1?

La tabla de versiones actual de la plataforma abierta de iFLYTEK sigue incluyendo el nivel Pro. SparkDesk-v3.1 se puede usar hoy en el catálogo de modelos de AnyAIGC; consulta el catálogo para ver la disponibilidad actual.

¿Cómo obtengo una clave de API de SparkDesk-v3.1?

Regístrate y recarga saldo en anyaigc.ai y crea un token en la consola. Una sola clave sirve para más de 300 modelos de la plataforma, así que no necesitas APPID, APIKey ni APISecret de la plataforma abierta de iFLYTEK. Establece model en SparkDesk-v3.1 en el cuerpo de la petición.

¿Puedo obtener una factura de AnyAIGC?

Sí. Puedes emitir tus propias facturas en la consola, por el importe que hayas recargado realmente.

¿Qué métodos de pago se admiten?

Puedes recargar saldo con WeChat Pay, Alipay, USDT o tarjeta de crédito. Tu saldo está en USD y sirve para todos los modelos de la plataforma. Las facturas se pueden emitir en la consola por el importe recargado.

¿Hay crédito de prueba gratuito para usuarios nuevos?

Sí. Las cuentas nuevas reciben 2 millones de tokens de crédito de prueba para que pruebes antes de decidir si recargas saldo. Las recargas empiezan en $1.

¿Puedo pedir el reembolso de mi saldo?

Sí. El saldo no utilizado se puede reembolsar sin comisión. Contacta con soporte para iniciar el reembolso.

¿Son los modelos reales? ¿Están seguros mis datos?

Las peticiones van a los canales oficiales de los modelos, nunca a sustitutos más baratos o de ingeniería inversa. Salvo que la ley lo exija, no almacenamos de forma persistente tus prompts ni tus resultados, ni los usamos para entrenar modelos, y la consola muestra los tokens y el coste de cada petición.

¿Mis prompts se usan para entrenar modelos?

No. Salvo que la ley lo exija, AnyAIGC no almacena de forma persistente tus prompts ni las salidas y no los usa para entrenar. Las peticiones se cifran con HTTPS. Consulta la Política de privacidad de AnyAIGC. La política de datos del propio proveedor del modelo se rige por las condiciones de iFLYTEK.
