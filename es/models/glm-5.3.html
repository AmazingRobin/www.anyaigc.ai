Acerca de

El mismo modelo base, con un posentrenamiento mucho más potente

Zhipu presenta GLM-5.3 como su último modelo insignia, con mejoras generales en ingeniería de software compleja y tareas de agente. Según Zhipu, usa el mismo modelo base que GLM-5.2, y todas las mejoras proceden de un posentrenamiento a mayor escala que se apoya en el enfoque de aprendizaje por refuerzo introducido con GLM-5.2.

Las mejoras publicadas se centran en código y agentes: el Z.ai Code Bench interno de Zhipu es un 50 % superior a GLM-5.2 con menos tokens de salida en las mismas tareas, y Terminal Bench 3.0 pasó de 4.6 a 28.3. Zhipu también indica resultados de vanguardia en el benchmark de vulnerabilidades CyberGym. Tiene una ventana de contexto de 1M de tokens, hasta 128K de salida, y el razonamiento (thinking) está siempre activado.

En AnyAIGC, glm-5.3 funciona sobre el endpoint /v1/chat/completions compatible con OpenAI y se usa directamente en Claude Code. No necesitas una cuenta en la plataforma de Zhipu ni un Coding Plan: pagas por token, con concurrencia sin límite.

Inicio rápido

Conéctate a la API de GLM-5.3 en tres pasos

  1. Regístrate y recarga saldo: crea una cuenta en anyaigc.ai. Recarga desde $1; tu saldo sirve para todos los modelos de la plataforma.
  2. Crea una clave de API: crea una clave en la consola, copia el valor que empieza por sk- y guárdalo en la variable de entorno ANYAIGC_API_KEY.
  3. Envía una petición: llama a POST https://anyaigc.ai/v1/chat/completions con model igual a glm-5.3 y una cabecera Authorization: Bearer. Con el SDK de OpenAI, basta con establecer base_url en https://anyaigc.ai/v1.

Consejo: GLM-5.3 siempre razona. Su razonamiento llega en el campo reasoning_content y reasoning_effort fija la profundidad. Los valores por defecto de Zhipu son temperature=1.0 y top_p=0.95; si los ajustas, cambia solo uno. En chats de varios turnos y llamadas a herramientas, devuelve en la siguiente petición el mensaje completo del asistente que entrega la API (incluidos reasoning_content y tool_calls) sin modificarlo.

Consulta la referencia de Chat Completions para ver todos los parámetros. Sustituye el nombre del modelo en los ejemplos de la documentación por el ID del modelo GLM que quieras.

Claude Code

Usa GLM-5.3 en Claude Code

Cambia Claude Code a GLM-5.3 editando un solo archivo de configuración y programa en tu terminal con el último modelo insignia de Zhipu, facturado por token.

  1. Instala Claude Code: usa el instalador oficial, por ejemplo curl -fsSL https://claude.ai/install.sh | bash en macOS o Linux.
  2. Añade la configuración: edita ~/.claude/settings.json, añade el bloque env de abajo y sustituye ANTHROPIC_AUTH_TOKEN por la clave que creaste en AnyAIGC.
  3. Empieza a programar: ejecuta claude en la carpeta de tu proyecto. Escribe /model para confirmar que el modelo actual es glm-5.3.

Ahorra en tareas ligeras: la configuración asigna ANTHROPIC_DEFAULT_HAIKU_MODEL a glm-5.3-flash, de modo que las subtareas ligeras de Claude Code usan el modelo más barato mientras el trabajo principal sigue en GLM-5.3.

Para ver la guía completa y los errores habituales, consulta la guía de configuración de Claude Code. Sustituye en la guía el nombre del modelo por glm-5.3.

La documentación de Z.ai describe GLM-5.3 como su último modelo insignia; usa el mismo modelo base que GLM-5.2 y todas las mejoras proceden del posentrenamiento.

El proveedor indica que mejora un 50 % respecto a GLM-5.2 en Z.ai Code Bench y que alcanza un rendimiento de vanguardia entre los modelos de código abierto en benchmarks públicos como Terminal Bench 3.0.

Preguntas frecuentes

Preguntas frecuentes sobre la API de GLM-5.3

¿Cuánto cuesta la API de GLM-5.3?

En AnyAIGC, glm-5.3 se factura por token: entrada $0.9450 por millón de tokens, salida $2.9700 por millón de tokens, acierto de caché $0.1758 por millón de tokens. Los precios oficiales de Zhipu en USD son entrada $1.40, salida $4.40 y acierto de caché $0.26, así que la entrada y la salida en AnyAIGC cuestan aproximadamente el 67.5 % del precio oficial (aproximadamente un 30 % menos). La salida incluye los tokens de razonamiento (thinking). Consulta el catálogo de modelos para ver los precios en tiempo real.

¿Cuál es el ID del modelo GLM-5.3 y qué tamaño tiene su contexto?

El ID del modelo es glm-5.3. Zhipu indica una ventana de contexto de 1M de tokens y hasta 128K tokens de salida. Por ahora solo acepta texto como entrada.

¿En qué se diferencia GLM-5.3 de GLM-5.2?

Zhipu afirma que GLM-5.3 usa el mismo modelo base que GLM-5.2 y que toda la mejora procede de un posentrenamiento a mayor escala. Cambios informados: Z.ai Code Bench es un 50 % superior al de GLM-5.2, Terminal Bench 3.0 pasó de 4.6 a 28.3 y DeepSWE pasó de 46.2 a 66.9. Además, GLM-5.3 siempre razona y el modo de razonamiento no se puede desactivar. En AnyAIGC ambos cuestan lo mismo en entrada y salida, y GLM-5.3 tiene un precio de acierto de caché más bajo ($0.1758 frente a $0.2362).

¿Cómo ajusto la profundidad de razonamiento de GLM-5.3? ¿Puedo desactivar el modo de razonamiento (thinking)?

GLM-5.3 siempre razona y Zhipu no permite desactivarlo. Usa el campo reasoning_effort del cuerpo de la petición para fijar la profundidad: low, high o max (por defecto max, que Zhipu recomienda para programación). Usa low en tareas simples para reducir los tokens de salida.

¿GLM-5.3 admite llamadas a herramientas y salida estructurada?

Sí. La documentación de Zhipu indica compatibilidad con llamadas a funciones, salida estructurada (JSON), streaming y caché de contexto. En chats de varios turnos y llamadas a herramientas, devuelve en la siguiente petición el mensaje completo del asistente (incluidos reasoning_content y tool_calls) sin modificarlo.

¿Puedo usar GLM-5.3 en Claude Code?

Sí. En el bloque env de ~/.claude/settings.json, establece ANTHROPIC_BASE_URL en https://anyaigc.ai, ANTHROPIC_AUTH_TOKEN en tu clave de API y ANTHROPIC_MODEL en glm-5.3. Después ejecuta claude. Pagas por token, sin ventana de cuota de 5 horas como en un plan de suscripción.

¿GLM-5.3 es de código abierto?

Sí. Zhipu ha publicado los pesos de GLM-5.3 en Hugging Face (zai-org/GLM-5.3) bajo la licencia GLM-5.3 License. En general es una licencia permisiva, con una regla adicional: las empresas con ingresos anuales superiores a $10.000 millones que operen negocios de modelo como servicio deben superar una revisión de seguridad de Z.ai antes del uso comercial. Llamar a la API a través de AnyAIGC te evita tener que alojarlo tú mismo. El uso comercial se rige por los términos oficiales de Zhipu AI.

¿Hay límites de concurrencia o de peticiones?

AnyAIGC no limita la concurrencia de glm-5.3 y todos los usuarios la tienen por defecto. Es adecuado para trabajos por lotes, pipelines de CI y agentes en paralelo. La facturación es por token, así que no hay una cuota que se reinicie por ventana de tiempo como en un plan de suscripción.
