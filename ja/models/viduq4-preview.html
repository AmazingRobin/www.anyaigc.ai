3ステップで Vidu Q4 Preview を呼び出す

まず最小のリクエストを送り、それからプロダクトに組み込みます。

  1. 01登録して、コンソールでAPIキーを作成します。
  2. 02キーを環境変数 ANYAIGC_API_KEY に設定します。
  3. 03タスクを送信して task_id を受け取り、GET /ent/v2/tasks/{id}/creations をポーリングします。
  • POST /ent/v2/img2video画像から動画
  • POST /ent/v2/reference2video参照から動画
  • GET /ent/v2/tasks/{id}/creations結果を取得

cURL
# 1. Create the task; the response contains task_id
curl -X POST "https://anyaigc.ai/ent/v2/img2video" \
  -H "Authorization: Bearer $ANYAIGC_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
  "model": "viduq4-preview",
  "images": [
    "https://www.anyaigc.ai/assets/models/vidu/skycity.webp"
  ],
  "prompt": "Slow push-in as the sea of clouds rolls, distant city lights flicker on and the girl's red cape lifts in the wind.",
  "duration": 5,
  "resolution": "1080p"
}'

# 2. Fetch the result with the task_id
curl "https://anyaigc.ai/ent/v2/tasks/$TASK_ID/creations" \
  -H "Authorization: Bearer $ANYAIGC_API_KEY"
Python
import json
import os
import time
import urllib.request

BASE = "https://anyaigc.ai"
HEADERS = {
    "Authorization": "Bearer " + os.environ["ANYAIGC_API_KEY"],
    "Content-Type": "application/json",
}


def call(method, path, body=None):
    data = json.dumps(body, ensure_ascii=False).encode("utf-8") if body else None
    request = urllib.request.Request(BASE + path, data=data, headers=HEADERS, method=method)
    with urllib.request.urlopen(request, timeout=60) as response:
        return json.load(response)


payload = {
    "model": "viduq4-preview",
    "images": [
        "https://www.anyaigc.ai/assets/models/vidu/skycity.webp"
    ],
    "prompt": "Slow push-in as the sea of clouds rolls, distant city lights flicker on and the girl's red cape lifts in the wind.",
    "duration": 5,
    "resolution": "1080p"
}

created = call("POST", "/ent/v2/img2video", payload)
task_id = (created.get("data") or created)["task_id"]
print("task_id:", task_id)

# Poll every 10 seconds until the task leaves the queue
for _ in range(120):
    result = call("GET", f"/ent/v2/tasks/{task_id}/creations")
    state = (result.get("data") or result).get("state") or (result.get("data") or result).get("status")
    if state not in ("created", "queueing", "processing"):
        break
    time.sleep(10)

# creations holds the video or image URLs; they expire, so download promptly
print(json.dumps(result, ensure_ascii=False, indent=2))

サンプル画像をご自身の URL または Base64（png、jpeg、webp、最大50 MB）に置き換えてください。status フィールドは実際のレスポンスで確認してください。サンプルでは、タスクが created、queueing、processing のいずれでもなくなった時点でポーリングを終了します。

仕様

仕様と選び方

Vidu は viduq4-preview を、表現力豊かな音声と映像に向けた次世代フラッグシップと位置づけており、現在はプレビューとして公開されています。

24fpsで540p、720p、1080p、2K、4Kを出力します。モデルマップでは長さは1〜16秒ですが、画像から動画APIが受け付ける duration は3〜16秒で、デフォルトは5です。

画像から動画と参照から動画に対応しています。画像から動画APIでは、ネイティブ音声（セリフと効果音）がデフォルトでオンになり、カメラの自動切り替えにも対応します。

画像から動画では、開始フレームの画像をちょうど1枚指定します。プロンプトは最大20,000文字です。

このページでは、540p が$0.0486 / 秒、720p が$0.1026 / 秒、1080p が$0.1296 / 秒、2K が$0.2052 / 秒と記載しており、上の料金表と一致します。

テキストから動画や最初・最後のフレームが必要で（モデルマップには Q4 Preview の対応として記載がありません）、1080pの出力で足りる場合は viduq3-turbo を選んでください。

仕様はベンダーの公式ドキュメント（platform.vidu.com）に基づいています。このページの表が料金で、最新の料金はモデル一覧が正となります。

FAQ

Vidu Q4 Preview API のよくある質問

料金、エンドポイント、結果、法人向けの利用をまとめて確認できます。

Vidu Q4 Preview API の料金はいくらですか？

540p $0.0486 / 秒、720p $0.1026 / 秒、1080p $0.1296 / 秒、2K $0.2052 / 秒、4K $0.4212 / 秒。料金はすべて USD です。最新の料金はモデル一覧で確認してください。

どのエンドポイントを呼び出せばよいですか？

POST /ent/v2/img2video、POST /ent/v2/reference2video を使い、model に viduq4-preview を指定します。作成すると task_id が返るので、GET /ent/v2/tasks/{id}/creations で結果を取得します。ベースURLは https://anyaigc.ai で、APIキーは Authorization: Bearer で渡します。

対応している長さと解像度は何ですか？

Vidu Q4 Preview は540p / 720p / 1080p / 2K / 4Kで3〜16秒（デフォルトは5秒）の動画を生成します。課金は1秒単位で、単価 × クリップの長さです。audio パラメータを省略すると、音声はデフォルトで生成されます。

結果はどのように取得しますか？

タスクは非同期です。task_id を保存し、GET /ent/v2/tasks/{id}/creations をポーリングして、タスクの完了後に creations から動画または画像の URL を読み取ります。タスク作成時に callback_url を渡すこともできます。結果の URL には有効期限があるため、ファイルは早めに保存してください。

同時実行数やRPMの制限はありますか？

AnyAIGC の Vidu は、すべてのアカウントでデフォルトで同時実行数の上限がなく、固定の RPM 制限もありません。動画生成には時間がかかるため、アプリケーション側でポーリング間隔とタイムアウトを設定してください。

出力は商用利用できますか？

商用利用は Vidu（ShengShu Technology）の公式規約に従います。アップロードする参照画像、人物、ブランド素材については、ご自身に権利が必要です。AnyAIGC は独立した API プロバイダーです。

AnyAIGC で請求書を発行できますか？

はい。実際にチャージした金額分の請求書を、コンソールでご自身で発行できます。

対応している支払い方法は何ですか？

WeChat Pay、Alipay、USDT、クレジットカードでチャージできます。残高は USD で、プラットフォーム上のすべてのモデルで使えます。チャージした金額分の請求書は、コンソールで発行できます。

新規ユーザー向けの無料トライアルはありますか？

はい。新規アカウントには500万トークン分のトライアル枠が付与されるので、チャージするかどうか決める前に試せます。チャージは $1 から可能です。

残高は返金できますか？

はい。未使用の残高は手数料なしで返金できます。返金をご希望の場合は、サポートにご連絡ください。

本物のモデルですか？データは安全ですか？

リクエストは公式のモデルチャネルに送られ、安価な代替モデルやリバースエンジニアリングによるモデルは使いません。法令で求められる場合を除き、プロンプトや出力を永続的に保存せず、学習にも使用しません。コンソールでは、リクエストごとのトークン数と料金を確認できます。
