Seedream API を使い始める

  1. AnyAIGC に登録してください。新規アカウントには200万トークンの無料枠が付与され、$1からチャージできます。
  2. コンソールで APIキーを作成し、環境変数 ANYAIGC_API_KEY に保存します。
  3. model に doubao-seedream-5-0-pro-260628 を指定して、POST https://anyaigc.ai/v1/images/generations（OpenAI互換）にリクエストを送ります。

model を doubao-seedream-5-0-pro-260628、doubao-seedream-5-0-260128、doubao-seedream-4-5-251128、doubao-seedream-4-0-250828 のいずれかに変えるとモデルを切り替えられます。リクエストとレスポンスの形式は同じです。

認証には Authorization: Bearer <API Key> を使います。レスポンスは {"created": ..., "data": [{"url": ...}]} の形式で、response_format を b64_json にすると base64 で受け取れます。watermark のデフォルトは true なので、透かしなしの画像が必要な場合は明示的に false を渡してください。フィールドの詳細は AnyAIGC Seedream APIドキュメントをご覧ください。

Seedream API のよくある質問

Seedream API の料金はいくらですか？

AnyAIGC では、Seedream の各モデルが固定料金です。5.0 Pro は1枚あたり$0.0441から、5.0 lite は1枚あたり$0.0223から、4.5 は1枚あたり$0.0253から、4.0 は1枚あたり$0.0203から、3.0 は1リクエストあたり$0.0101です。解像度が高いほど料金も上がります。最新の料金はモデル一覧で確認できます。

Seedream とは何ですか？ Doubao や Jimeng とはどういう関係ですか？

Seedream は ByteDance の Seed チームによる画像生成モデルのファミリーです。Volcano Engine では「Doubao Seedream」（doubao-seedream）として提供されており、Jimeng などの ByteDance 製品の画像生成もこれをベースにしています。AnyAIGC は公式の Seedream モデルへの API アクセスを提供します。

5.0 Pro、5.0 lite、4.5、4.0 の違いは何ですか？

5.0 Pro はフラッグシップで、インフォグラフィック、精密編集、多言語テキストが得意です。最大2Kで、画像セットには非対応です。5.0 lite はWeb検索に対応した軽量モデルで、最大4Kです。4.5 はポスターのレイアウトと元画像のディテールの維持が得意です。4.0 は生成と編集を統合したリリースでした。5.0 lite、4.5、4.0 はいずれも画像セットと最大14枚の参照画像に対応しています。

どのエンドポイントを使いますか？ 画像の編集はできますか？

すべてのモデルで OpenAI 互換の POST /v1/images/generations を使います。モデルを切り替えるときに変えるのは model だけです。編集や複数画像の合成では、image に画像URLの配列を渡します。画像セットには sequential_image_generation: "auto" を指定します。すべてのフィールドは AnyAIGC APIドキュメントを参照してください。

同時実行数の上限はありますか？登録に必要なものは？

AnyAIGC では、Seedream のすべてのモデルで同時実行数に上限を設けておらず、どのアカウントでもデフォルトで利用できます。ベースURLは https://anyaigc.ai です。Volcano Engine のアカウントも本人確認も不要で、同じキーでプラットフォームの300以上のほかのモデルも使えます。

AnyAIGC で請求書を発行できますか？

はい。実際にチャージした金額分の請求書を、コンソールでご自身で発行できます。

対応している支払い方法は何ですか？

WeChat Pay、Alipay、USDT、クレジットカードでチャージできます。残高は USD で、プラットフォーム上のすべてのモデルで使えます。チャージした金額分の請求書は、コンソールで発行できます。

新規ユーザー向けの無料トライアルはありますか？

はい。新規アカウントには200万トークン分のトライアル枠が付与されるので、チャージするかどうか決める前に試せます。チャージは $1 から可能です。

残高は返金できますか？

はい。未使用の残高は手数料なしで返金できます。返金をご希望の場合は、サポートにご連絡ください。

本物のモデルですか？データは安全ですか？

リクエストは公式のモデルチャネルに送られ、安価な代替モデルやリバースエンジニアリングによるモデルは使いません。法令で求められる場合を除き、プロンプトや出力を永続的に保存せず、学習にも使用しません。コンソールでは、リクエストごとのトークン数と料金を確認できます。

商用利用はできますか？透かしは消せますか？

利用権とコンテンツポリシーは、ByteDance / Volcano Engine の公式規約に従います。リクエストで watermark を false にすると、右下に「AI生成」の表示は付きません。AnyAIGC は API アクセスを提供するだけで、出力の利用方法に追加の制限は設けていません。実在の人物の肖像やブランドロゴなどについては、必要な権利を確認してください。
