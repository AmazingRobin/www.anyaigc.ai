モデルについて

Eleven Scribe v2：録音の文字起こし

Eleven Scribe v2 は ElevenLabs の音声認識（STT）モデルです。公式のモデルドキュメントでは、以前の最先端の音声認識モデルとされており、後継は scribe_v3 で、90言語以上で正確に文字起こしできるよう設計されています。現在も利用可能で、公式の非推奨モデル一覧には含まれていません。AnyAIGC のモデル一覧では、90言語以上、単語単位のタイムスタンプ、話者分離、キータームプロンプト、マルチチャンネル分離に対応する旧世代の主力モデルと説明されています。

公式ドキュメントには、v2 の機能として単語単位のタイムスタンプ、話者分離、動的オーディオタグ付け、キータームプロンプト、エンティティ検出が挙げられています。公式の機能ページでは、ファイルサイズの上限は5 GB、1ファイルあたり最長15時間、マルチチャンネル音声は最大5チャンネルです。以上は ElevenLabs の公式ドキュメントに記載されている機能です。

AnyAIGC では、scribe_v2 は POST /v1/audio/transcriptions で動作し、音声の長さ（秒）で課金されます。料金は Eleven Scribe v3 と同じで、同時実行数の上限はありません。新規プロジェクトでは、同じ録音を両方で文字起こしして比較してください。

3ステップで Eleven Scribe v2 API を呼び出す

  1. 登録とチャージ：anyaigc.ai でアカウントを作成します。チャージは$1からで、残高はプラットフォームのすべてのモデルで共通して使えます。
  2. APIキーの作成：コンソールでトークンを作成し、sk- で始まるキーをコピーして、環境変数 ANYAIGC_API_KEY に保存します。
  3. 録音をアップロード：POST https://anyaigc.ai/v1/audio/transcriptions を multipart/form-data で呼び出し、file（音声ファイル）と、scribe_v2 を指定した model を送ります。認証は Authorization: Bearer で行い、文字起こし結果はレスポンスの text から取得します。

パラメータの補足：モデルIDは大文字小文字を区別するため、scribe_v2 と書いてください。リクエストは multipart/form-data で、file にはファイル名ではなく音声ファイルそのものを指定します。成功すると {"text": "..."} が返ります。

音声認識 API リファレンスを参照してください。Scribe を呼び出すには、model に scribe_v3 または scribe_v2 を指定します。

FAQ

Eleven Scribe v2 API のよくある質問

Eleven Scribe v2 API の料金はいくらですか？

AnyAIGC では、scribe_v2 は音声の長さ（秒）で課金され、1秒あたり$0.0000450、つまり1分あたり$0.0027、1時間あたり$0.162です。ElevenLabs の定価は1時間あたり$0.20で、そこから約19%オフです。料金は固定で、サブスクリプションや月額料金はありません。最新の料金はモデル一覧で確認できます。

Eleven Scribe v2 のモデルIDは何ですか？ ElevenLabs との関係は？

モデルIDは scribe_v2（大文字小文字を区別）で、ElevenLabs の model_id と同じです。AnyAIGC は OpenAI 形式の /v1/audio/transcriptions 呼び出しを提供する独立した API プロバイダーであり、ElevenLabs とは提携していません。

Eleven Scribe v2 とほかの Eleven モデルはどう使い分けますか？

AnyAIGC の Eleven モデルは2種類に分かれます。Eleven v4 をはじめとする7つの音声合成モデルと、Eleven Scribe v3、Eleven Scribe v2 の2つの音声認識モデルです。録音をテキストにするなら Scribe、テキストを音声にするなら v4、Multilingual v2 などの音声合成モデルを選んでください。

Eleven Scribe v2 の APIキーはどう取得しますか？

anyaigc.ai で登録してチャージし、コンソールでトークンを作成します。1つのキーでプラットフォーム上の300以上のモデルを使えるので、ElevenLabs のアカウントを別に用意する必要はありません。リクエストの model に scribe_v2 を指定してください。

Eleven Scribe v2 API はどのように呼び出しますか？

POST https://anyaigc.ai/v1/audio/transcriptions を multipart/form-data で呼び出し、file（音声ファイル）と model（scribe_v2）を指定します。認証は Authorization: Bearer で行います。成功すると {"text": "..."} が返ります。詳しくはAPIリファレンスを参照してください。

Eleven Scribe v2 が受け付ける音声フォーマットと、ファイルサイズの上限は？

APIリファレンスには、次のファイル形式が記載されています：flac、mp3、mp4、mpeg、mpga、m4a、ogg、wav、webm。ElevenLabs の機能ページでは、上限は1ファイルあたり5 GB、15時間とされています。

Eleven Scribe v2 は中国語に対応していますか。何言語に対応していますか？

はい。公式ドキュメントでは Scribe は90言語以上に対応しており、公式の言語一覧には北京語と広東語が含まれています。対応言語の詳細は ElevenLabs のモデルドキュメントをご覧ください。

Scribe v2 はまだ使えますか？ Scribe v3 とはどう選べばよいですか？

はい。公式のモデルドキュメントでは Scribe v2 は旧世代で、後継は Scribe v3 とされていますが、引き続き利用でき、公式の非推奨モデル一覧には含まれていません。AnyAIGC では両モデルの料金は同じです。すでに v2 を使っているプロジェクトはそのまま使い続けられます。新規プロジェクトでは、決める前に同じ録音を両方で文字起こしして比べてください。Eleven Scribe v3 を参照してください。今後も提供されるかどうかはモデル一覧で確認できます。

リアルタイム（ストリーミング）の文字起こしモデルはありますか？

このページで扱うのは、HTTP の /v1/audio/transcriptions で呼び出す録音ファイル向けモデル scribe_v3 と scribe_v2 です。録音を丸ごとアップロードすると、テキストが返ります。ElevenLabs にはリアルタイム向けモデル（scribe_v3_live など）もありますが、このページの対象外です。提供されているかどうかはモデル一覧で確認できます。

レート制限はありますか？

AnyAIGC では scribe_v2 に同時実行数の上限を設けておらず、すべてのアカウントでデフォルトで適用されます。そのため、バッチでの文字起こしや並列タスクも問題なく実行できます。課金は音声の長さ（秒）単位で、月額料金や、時間枠でリセットされるクォータはありません。

AnyAIGC で請求書を発行できますか？

はい。実際にチャージした金額分の請求書を、コンソールでご自身で発行できます。

対応している支払い方法は何ですか？

WeChat Pay、Alipay、USDT、クレジットカードでチャージできます。残高は USD で、プラットフォーム上のすべてのモデルで使えます。チャージした金額分の請求書は、コンソールで発行できます。

新規ユーザー向けの無料トライアルはありますか？

はい。新規アカウントには200万トークン分のトライアル枠が付与されるので、チャージするかどうか決める前に試せます。チャージは $1 から可能です。

残高は返金できますか？

はい。未使用の残高は手数料なしで返金できます。返金をご希望の場合は、サポートにご連絡ください。

本物のモデルですか？データは安全ですか？

リクエストは公式のモデルチャネルに送られ、安価な代替モデルやリバースエンジニアリングによるモデルは使いません。法令で求められる場合を除き、プロンプトや出力を永続的に保存せず、学習にも使用しません。コンソールでは、リクエストごとのトークン数と料金を確認できます。

アップロードした録音と文字起こし結果は学習に使われますか？

いいえ。法令で求められる場合を除き、AnyAIGC は入力と出力を永続的に保存せず、学習にも使用しません。リクエストは HTTPS で暗号化されます。AnyAIGC のプライバシーポリシーをご覧ください。モデル自体のデータの取り扱いは ElevenLabs が定めています。録音に個人情報が含まれる場合は、処理する権利があることをご確認ください。
