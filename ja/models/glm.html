クイックスタート

3ステップで GLM API に接続

  1. 登録とチャージ：anyaigc.ai でアカウントを作成します。$1からチャージでき、残高はプラットフォーム上のすべてのモデルで使えます。
  2. APIキーを作成：コンソールでキーを作成し、sk- で始まる値をコピーして、環境変数 ANYAIGC_API_KEY に保存します。
  3. リクエストを送信：POST https://anyaigc.ai/v1/chat/completions を呼び出し、model に glm-5.3 を指定して、Authorization: Bearer ヘッダーを付けます。OpenAI SDK なら、base_url を https://anyaigc.ai/v1 に設定するだけです。

Tipp: GLM liefert seine Reasoning-Ausgabe im Feld reasoning_content. Beim Streaming kommen zuerst die Reasoning-Deltas, danach die endgültige Antwort. Die Denktiefe stellen Sie mit reasoning_effort ein (low / high / max, Standard max). Senden Sie bei mehrstufigen Chats und Tool-Aufrufen die vollständige Assistant-Nachricht der API (einschließlich reasoning_content und tool_calls) in der nächsten Anfrage unverändert zurück.

全パラメータは Chat Completions リファレンスをご覧ください。ドキュメントの例にあるモデル名は、使いたい GLM のモデルIDに置き換えてください。

Claude Code

Claude Code で GLM を使う

設定ファイルを1つ編集するだけで Claude Code を GLM に切り替えられ、ターミナルのコーディングエージェントが GLM-5.3 で動作します。課金はトークン単位です。

  1. Claude Code をインストール：公式インストーラーを使います。macOS または Linux の場合は、たとえば curl -fsSL https://claude.ai/install.sh | bash です。
  2. 設定を追加：~/.claude/settings.json を編集し、下の env ブロックを追加して、ANTHROPIC_AUTH_TOKEN を AnyAIGC で作成したキーに置き換えます。
  3. コーディングを始める：プロジェクトフォルダで claude を実行します。/model と入力して、現在のモデルが glm-5.3 であることを確認してください。

軽いタスクは節約：この設定では ANTHROPIC_DEFAULT_HAIKU_MODEL を glm-5.3-flash にしているため、Claude Code の軽量なサブタスクは安いモデルで処理され、メインの作業は GLM-5.3 のままです。

手順の全体とよくあるエラーは Claude Code セットアップガイドをご覧ください。ガイド内のモデル名は glm-5.3 に置き換えてください。

FAQ

GLM API よくある質問

GLM API の料金はいくらですか？

GLM-Modelle bei AnyAIGC werden pro Token abgerechnet. Pro 1 Mio. Tokens: glm-5.3 Eingabe $0,9450, Ausgabe $2,9700, Cache-Treffer $0,1758; glm-5.3-flash Eingabe $0,0607, Ausgabe $0,2025, Cache-Treffer $0,0122; glm-5.2 Eingabe $0,9450, Ausgabe $2,9700, Cache-Treffer $0,2362. GLM-5.3 und GLM-5.2 liegen rund 30 % unter den offiziellen USD-Preisen von Zhipu, GLM-5.3-Flash rund 60 % darunter. Aktuelle Preise finden Sie im Modellkatalog.

AnyAIGC で使える GLM モデルと、そのモデルIDを教えてください。

Diese Seite behandelt drei: glm-5.3 (Zhipus neuestes Flaggschiff, für komplexes Coding und Agents), glm-5.3-flash (das erste nativ multimodale GLM-5-Modell, zu einem niedrigen Preis) und glm-5.2 (das vorherige Flaggschiff, gebaut für langfristige Aufgaben). Tragen Sie die Modell-ID in das Feld model des Anfrage-Bodys ein. Zum Wechseln des Modells ändern Sie nur dieses eine Feld. Ältere Modelle wie GLM-5.1, GLM-5 und GLM-4.5 sind ebenfalls auf der Plattform; siehe Modellkatalog.

GLM-5.3、GLM-5.3-Flash、GLM-5.2 のどれを選べばよいですか？

最も難しいコーディング、ターミナル、エージェント作業にはGLM-5.3を選んでください。大量処理、コスト重視、画像タスクにはGLM-5.3-Flashが向いています。料金は GLM-5.3 の約1/15で、Zhipu は GLM-5.2 を総合的に上回るとしています。思考モードをオフにする必要がある場合や、すでに本番で使っている場合はGLM-5.2のままで構いません。GLM-5.3 と GLM-5.2 は同じ料金なので、新規プロジェクトは GLM-5.3 から始めてください。

GLM API は OpenAI 互換ですか？

はい。3つのモデルともPOST https://anyaigc.ai/v1/chat/completionsを使い、リクエストとレスポンスの形式は OpenAI Chat Completions と同じです。公式の OpenAI SDK では、base_urlをhttps://anyaigc.ai/v1に設定します。推論の過程がある場合は、reasoning_contentフィールドで返されます。

Claude Code で GLM を使えますか？

はい。~/.claude/settings.json の env ブロックで、ANTHROPIC_BASE_URL を https://anyaigc.ai、ANTHROPIC_AUTH_TOKEN をご自身の APIキー、ANTHROPIC_MODEL を glm-5.3 に設定し、claude を実行します。課金はトークン単位で、サブスクリプションプランのような5時間のクォータ枠はありません。

コンテキスト長はどのくらいですか？

Zhipu によると、GLM-5.3、GLM-5.3-Flash、GLM-5.2 はいずれもコンテキスト長1Mトークン、最大128Kの出力トークンに対応しています。GLM-5.3 と GLM-5.2 はテキストのみ、GLM-5.3-Flash は画像も入力できます。

GLM Coding Plan との違いは何ですか？

GLM Coding Plan は Zhipu の月額制コーディングサブスクリプションで、クォータは5時間ごとと週ごとの枠でリセットされます。AnyAIGC は従量課金の API です。使った分だけ支払い、$1からチャージでき、時間枠の制限はなく、同時実行数も上限なしです。同じキーで他の300以上のモデルも呼び出せます。

GLM モデルはオープンソースですか？商用利用できますか？

Zhipu は GLM-5.3、GLM-5.3-Flash、GLM-5.2 のウェイトを Hugging Face で公開しています。GLM-5.2 と GLM-5.3-Flash は MIT ライセンス、GLM-5.3 は GLM-5.3 License で、寛容なライセンスですが、非常に大規模な MaaS 事業者向けに追加のセキュリティレビュー条項があります。AnyAIGC 経由で API を呼び出せば、自分でホストする必要はありません。モデルのライセンスと商用利用は、Zhipu AI の公式規約に従います。

同時実行数やレート制限はありますか？

AnyAIGC begrenzt die Parallelität für GLM-Modelle nicht, und jeder Nutzer erhält das standardmäßig. Das passt zu Batch-Jobs, CI-Pipelines und parallelen Agenten. Die Abrechnung erfolgt pro Token, daher gibt es kein Kontingent, das sich wie bei einem Abo-Tarif in einem Zeitfenster zurücksetzt.

GLM の APIキーはどうやって取得しますか？

anyaigc.ai で登録し、チャージして、コンソールでキーを作成します。同じキーで、すべての GLM モデルとプラットフォーム上の300以上のモデルを利用できます。Zhipu のプラットフォームのアカウントや GLM Coding Plan は別途必要ありません。

AnyAIGC で請求書を発行できますか？

はい。実際にチャージした金額分の請求書を、コンソールでご自身で発行できます。

対応している支払い方法は何ですか？

WeChat Pay、Alipay、USDT、クレジットカードでチャージできます。残高は USD で、プラットフォーム上のすべてのモデルで使えます。チャージした金額分の請求書は、コンソールで発行できます。

新規ユーザー向けの無料トライアルはありますか？

はい。新規アカウントには200万トークン分のトライアル枠が付与されるので、チャージするかどうか決める前に試せます。チャージは $1 から可能です。

残高は返金できますか？

はい。未使用の残高は手数料なしで返金できます。返金をご希望の場合は、サポートにご連絡ください。

本物のモデルですか？データは安全ですか？

リクエストは公式のモデルチャネルに送られ、安価な代替モデルやリバースエンジニアリングによるモデルは使いません。法令で求められる場合を除き、プロンプトや出力を永続的に保存せず、学習にも使用しません。コンソールでは、リクエストごとのトークン数と料金を確認できます。

入力したデータはトレーニングに使われますか？

いいえ。法令で求められる場合を除き、AnyAIGC はプロンプトや出力を永続的に保存せず、モデルのトレーニングにも使用しません。リクエストは HTTPS で暗号化されます。AnyAIGC のプライバシーポリシーをご覧ください。モデル自体のデータの扱いは Zhipu AI の公式規約に従います。
