Seedream 4.5 とは

Seedream 4.5 は ByteDance Seed チームの画像生成モデルです。テキスト、1枚の画像、複数枚の画像を入力として受け取り、被写体の一貫性を保つ複数画像の合成、画像編集、画像セットを1つのモデルで扱えます。

公式が挙げる特長は3つです。編集しても元画像の顔・光・ディテールが保たれること、ポスターやロゴのレイアウトが安定して小さな文字も読み取れること、複数画像の合成で被写体を捉えてキャラクターの一貫性を保つことです。AnyAIGC でのモデルID は doubao-seedream-4-5-251128 で、1枚あたり$0.0253からです。

Seedream 4.5 でできること

  • ポスターのレイアウトと小さな文字

    見出し、訴求ポイント、細かい注記までくっきり描画されます。キャンペーンポスター、パッケージ、ロゴデザインに使えます。

  • 元のディテールを保つ編集

    画像全体を描き直さず、顔・光・ディテールを保ったまま背景やスタイルを差し替えられます。

  • 画像をまたいで一貫したキャラクター

    参照画像は最大14枚。モデルが被写体を識別して固定するため、フレームが変わってもキャラクターが一貫します。

  • 画像セット

    1回のリクエストで関連画像を最大15枚まで。ポスターのシリーズ、絵本、商品の多角度ショットに使えます。

仕様と選び方

Seedream 4.5 は、ポスターのように文字が密集したデザインのレイアウトと描画を強化しています。

Seedream 4.5 は複数の入力画像にわたって被写体を識別して固定し、キャラクターの一貫性を保ちます。元画像の顔、光、色調、ディテールも維持します。

Seedream 4.5 の size には 2K または 4K、もしくは 2560×1440 から 4096×4096 の範囲の総ピクセル数を指定できます。

Seedream 4.5 は参照画像を最大14枚まで受け付けます。画像セットモードでは、参照画像と出力画像の合計は最大15枚です。

このページでは Seedream 4.5 を $0.0253 / 枚と記載しており、上の料金表と一致しています。

seedream-5.0-lite との比較：Seedream 4.5 は 2K と 4K の解像度に対応し、Seedream 5.0 lite は 3K とWeb検索が加わります。

仕様はベンダーの公式ドキュメント（docs.volcengine.com）に基づきます。このページの表が料金で、最新のレートはモデル一覧が正となります。

Seedream 4.5 API のよくある質問

Seedream 4.5 API の料金はいくらですか？

AnyAIGC では、Seedream 4.5（doubao-seedream-4-5-251128）は1枚あたり$0.0253からです。料金は解像度によって異なり、2K と 4K の最新料金はモデル一覧で確認できます。画像セットは生成した画像1枚ごとに課金されます。課金は生成に成功した分のみで、最新の料金はモデル一覧で確認できます。

Seedream 4.5 とは何ですか？

Seedream 4.5 は ByteDance Seed チームの画像生成モデルで、AnyAIGC でのモデルID は doubao-seedream-4-5-251128 です。テキスト、1枚の画像、複数枚の画像を入力として受け取り、被写体の一貫性を保つ複数画像の合成、画像編集、画像セットを扱えます。公式によると、元画像の顔・光・ディテールを保ち、ポスターやロゴのレイアウトがより安定し、小さな文字も読み取れる品質で描画します。

どの解像度に対応していますか？

Volcano Engine Ark のドキュメントによると、4.5 の size には 2K と 4K、またはピクセル寸法を指定でき、アスペクト比は 1:16 から 16:1 までです。

参照画像は何枚まで送れますか？画像セットは最大何枚ですか？

image には参照画像を最大14枚まで指定できます。画像セットは sequential_image_generation: "auto" を使い、1回のリクエストで最大15枚を返します。参照画像がある場合、参照画像と生成画像の合計は15枚を超えられません。

4.5 と 5.0 lite のどちらを選べばよいですか？

どちらも4K、画像セット、14枚の参照画像に対応しています。Web検索や意図の理解をより重視するなら、5.0 lite（1枚あたり$0.0223から）を選んでください。すでに 4.5 を組み込んでいて、ポスターのレイアウトと元のディテールの維持を最優先するなら、引き続き 4.5 をお使いください。

同時実行数の上限はありますか？登録に必要なものは？

AnyAIGC では Seedream 4.5 の同時実行数に上限を設けておらず、すべてのアカウントでデフォルトで利用できます。ベースURLは https://anyaigc.ai です。Volcano Engine のアカウントや本人確認は不要で、同じキーでプラットフォーム上の300以上のほかのモデルも使えます。

AnyAIGC で請求書を発行できますか？

はい。実際にチャージした金額分の請求書を、コンソールでご自身で発行できます。

対応している支払い方法は何ですか？

WeChat Pay、Alipay、USDT、クレジットカードでチャージできます。残高は USD で、プラットフォーム上のすべてのモデルで使えます。チャージした金額分の請求書は、コンソールで発行できます。

新規ユーザー向けの無料トライアルはありますか？

はい。新規アカウントには200万トークン分のトライアル枠が付与されるので、チャージするかどうか決める前に試せます。チャージは $1 から可能です。

残高は返金できますか？

はい。未使用の残高は手数料なしで返金できます。返金をご希望の場合は、サポートにご連絡ください。

本物のモデルですか？データは安全ですか？

リクエストは公式のモデルチャネルに送られ、安価な代替モデルやリバースエンジニアリングによるモデルは使いません。法令で求められる場合を除き、プロンプトや出力を永続的に保存せず、学習にも使用しません。コンソールでは、リクエストごとのトークン数と料金を確認できます。

商用利用はできますか？透かしは消せますか？

利用権とコンテンツポリシーは、ByteDance / Volcano Engine の公式規約に従います。リクエストで watermark を false にすると、右下に「AI生成」の表示は付きません。AnyAIGC は API アクセスを提供するだけで、出力の利用方法に追加の制限は設けていません。実在の人物の肖像やブランドロゴなどについては、必要な権利を確認してください。
