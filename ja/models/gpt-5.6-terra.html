3ステップで GPT-5.6 Terra API を呼び出す

  1. 登録とチャージ：anyaigc.ai でアカウントを作成します。残高はすべてのモデルで共通です。
  2. APIキーを作成：コンソールでトークンを作成し、sk- で始まるキーをコピーして、環境変数 ANYAIGC_API_KEY に保存します。
  3. リクエストを送信：https://anyaigc.ai/v1/chat/completions または https://anyaigc.ai/v1/responses を呼び出し、model に gpt-5.6-terra を指定して、Authorization: Bearer で認証します。

どちらのエンドポイントもツールに対応しています。OpenAI のモデルドキュメントによると、gpt-5.6-terra は Chat Completions、Responses、Batch の各エンドポイントに対応し、関数呼び出しは /v1/chat/completions と /v1/responses の両方で使えます。Web検索、ファイル検索、コードインタープリターなど OpenAI の組み込みツールは Responses API の一部で、強度は reasoning.effort に指定します。

すべてのパラメータは Chat Completions リファレンスと Responses リファレンスをご覧ください。フィールドは公式の OpenAI API と同じです。

Codex で GPT-5.6 Terra を使う

コマンド1つで Codex CLI をインストールし、AnyAIGC の設定を書き込みます。~/.codex/ の2つのファイルを自分で編集することもできます。

GPT-5.6 Terra API のよくある質問

GPT-5.6 Terra API の料金はいくらですか？

AnyAIGC では gpt-5.6-terra はトークン単位で課金されます。入力は100万トークンあたり$0.0993、出力は$0.5957、キャッシュ入力は$0.0099です。OpenAI の定価は、2026年7月30日の恒久的な20%値下げ後で入力$2.00、出力$12.00、キャッシュ入力$0.20です（発売時の価格は$2.50 / $15）。AnyAIGC は定価の約5%（95%オフ）です。1回のリクエストの入力が272Kトークンを超える場合、そのリクエスト全体が入力2倍、出力1.5倍で課金されます。

GPT-5.6 Terra のモデルIDは何ですか？

モデルIDは gpt-5.6-terra です。リクエストの model フィールドに指定してください。OpenAI は日付付きのスナップショットを公開していません。

Terra とは何で、GPT-5.6 Sol とどう違いますか？

OpenAI の命名では、数字が世代を表し、Sol、Terra、Luna はそれぞれ独立して進化する性能ティアです。Sol がフラッグシップ、Terra は日常業務向けのバランス型モデル、Luna は最も高速で低価格のティアです。Terra は、以前の GPT-5 ファミリーの mini ティアにおおむね相当します。OpenAI の結果では、Terra は Terminal-Bench 2.1 で87.4%（Sol は88.8%）、OSWorld 2.0 で50.2%（Sol は62.6%）です。Terra の定価は$2 / $12で、GPT-5.6 Sol のプロモーション価格は$4 / $20です。AnyAIGC では、100万トークンあたり Terra が入力$0.0993、出力$0.5957、Sol が入力$0.2482、出力$1.4890です。

GPT-5.6 Terra と GPT-5.6 Luna はどちらを使うべきですか？

どちらもコンテキスト長、最大出力、エンドポイントは同じです。OpenAI の結果では、Terra は多くのベンチマークで Luna を上回っており、たとえば Terminal-Bench 2.1 は87.4%対84.7%、OSWorld 2.0 は50.2%対45.6%、BrowseComp は87.5%対83.3%です。Luna の定価は Terra の10分の1（$0.20 / $1.20）です。コーディング、ナレッジワーク、複数ステップのタスクには Terra を使い、大量の分類、抽出、要約にはまず GPT-5.6 Luna を試してください。AnyAIGC では、Luna は100万トークンあたり入力$0.0270、出力$0.1620です。

GPT-5.6 Terra と GPT-5.5 はどう違いますか？

OpenAI は Terra を、低コストで GPT-5.5 に匹敵する性能と説明し、ナレッジワークでは GPT-5.5 を上回るとしています。OpenAI の結果では、Terra は Terminal-Bench 2.1（87.4%対85.6%）、SWE-Bench Pro（63.4%対59.4%）、BrowseComp（87.5%対84.4%）で GPT-5.5 を上回り、GPQA Diamond（92.9%対93.6%）ではわずかに下回ります。Terra の定価は$2 / $12、GPT-5.5 は$5 / $30です。Terra の知識のカットオフは2026-02-16、GPT-5.5 は2025-12-01です。

GPT-5.6 Terra は非推奨ですか？いつまで使えますか？

非推奨ではありません。OpenAI は GPT-5.6 Terra の提供終了日を発表しておらず、現在も問題なく呼び出せます。OpenAI の非推奨ページでは、今も gpt-5-mini や o4-mini など旧モデルの移行先として GPT-5.6 Terra が挙げられています。OpenAI は後継として GPT-6.1 Terra（gpt-6.1-terra）をリリースしており、AnyAIGC での料金は入力$0.0496、出力$0.2482（100万トークンあたり）です。新規プロジェクトにはこちらをおすすめします。ツール呼び出しには Responses API が必要なので、切り替える前にテストしてください。

Chat Completions と Responses API のどちらを使えばよいですか？ツールは使えますか？

どちらのエンドポイントも利用でき、関数呼び出しも両方で使えます。通常のチャット、関数呼び出し、ストリーミングには https://anyaigc.ai/v1/chat/completions を使ってください。Web検索やファイル検索など OpenAI の組み込みツールには https://anyaigc.ai/v1/responses を使い、強度は reasoning.effort に指定します。対応する推論の強度は none、low、medium（デフォルト）、high、xhigh、max です。

Codex で GPT-5.6 Terra を使えますか？

はい。curl -fsSL https://www.anyaigc.ai/install.sh | bash -s codex を実行してインストールと設定を行います（Windows では irm https://www.anyaigc.ai/install.ps1 | iex）。インストーラーのデフォルトは gpt-5.5 なので、その後 ~/.codex/config.toml の model を gpt-5.6-terra に変更してください。手動で設定する場合は、~/.codex/config.toml を編集して base_url を https://anyaigc.ai/v1、wire_api を responses、model を gpt-5.6-terra に設定し、OPENAI_API_KEY を ~/.codex/auth.json に記入します。

GPT-5.6 Terra の APIキーはどう取得しますか？

anyaigc.ai で登録してチャージし、コンソールでトークンを作成してください。同じキーで GPT-5.6 Terra とその他300以上のモデルを利用できます。料金は USD で請求され、WeChat Pay または Alipay で支払えます。

AnyAIGC で請求書を発行できますか？

はい。実際にチャージした金額分の請求書を、コンソールでご自身で発行できます。

対応している支払い方法は何ですか？

WeChat Pay、Alipay、USDT、クレジットカードでチャージできます。残高は USD で、プラットフォーム上のすべてのモデルで使えます。チャージした金額分の請求書は、コンソールで発行できます。

新規ユーザー向けの無料トライアルはありますか？

はい。新規アカウントには200万トークン分のトライアル枠が付与されるので、チャージするかどうか決める前に試せます。チャージは $1 から可能です。

残高は返金できますか？

はい。未使用の残高は手数料なしで返金できます。返金をご希望の場合は、サポートにご連絡ください。

本物のモデルですか？データは安全ですか？

リクエストは公式のモデルチャネルに送られ、安価な代替モデルやリバースエンジニアリングによるモデルは使いません。法令で求められる場合を除き、プロンプトや出力を永続的に保存せず、学習にも使用しません。コンソールでは、リクエストごとのトークン数と料金を確認できます。

データは学習に使われますか？

いいえ。法令で求められる場合を除き、AnyAIGC はプロンプトや出力を永続的に保存せず、学習にも使用しません。リクエストは HTTPS で通信中に暗号化されます。詳しくは AnyAIGC のプライバシーポリシーをご覧ください。モデル自体のデータの扱いは OpenAI の公式規約に従います。
