概要

長いタスク向けの1兆規模のオープンウェイトモデル

Moonshot AI によると、Kimi K3 は2.8兆パラメータに到達した初のオープンソースモデルです。Kimi Delta Attention（KDA）ハイブリッド線形アテンションと Attention Residuals を採用しています。どちらも、長いシーケンスや深いネットワークでも情報が流れ続けるようにするためのアーキテクチャ上の変更です。

Stable LatentMoE フレームワークでは、K3 はトークンごとに896のエキスパートのうち16を活性化します。Moonshot によると、改良した学習方法やデータレシピとあわせて、K3 は K2 の約2.5倍の総合的なスケーリング効率に達しています。ネイティブの画像理解に対応し、コンテキスト長は1,048,576トークンで、思考モードは常にオンです。

AnyAIGC では、kimi-k3 は OpenAI 互換の /v1/chat/completions エンドポイントで動作し、Claude Code でもそのまま使えます。Moonshot のプラットフォームのアカウントは不要で、チャージ額による段階もなく、同時実行数の上限もありません。

クイックスタート

3ステップで Kimi K3 API に接続

  1. 登録とチャージ：anyaigc.ai でアカウントを作成します。$1からチャージでき、残高はプラットフォーム上のすべてのモデルで使えます。
  2. APIキーを作成：コンソールでキーを作成し、sk- で始まる値をコピーして、環境変数 ANYAIGC_API_KEY に保存します。
  3. リクエストを送信：model を kimi-k3 にして、Authorization: Bearer ヘッダー付きで POST https://anyaigc.ai/v1/chat/completions を呼び出します。OpenAI SDK なら、base_url を https://anyaigc.ai/v1 に設定するだけです。

ヒント：K3 は常に思考し、推論内容は reasoning_content で返されます。Moonshot は temperature=1.0 と top_p=0.95 を推奨しています。マルチターンの会話やツール呼び出しでは、content だけでなく、API から返ったアシスタントのメッセージ全体（reasoning_content と tool_calls を含む）をそのまま次のリクエストで送り返してください。

Alle Parameter finden Sie in der Chat-Completions-Referenz. Ersetzen Sie den Modellnamen in den Beispielen der Dokumentation durch die gewünschte Kimi-Modell-ID.

Claude Code

Claude Code で Kimi K3 を使う

Claude Code を Kimi K3 に切り替えます。コンテキスト長1Mは、大規模なリポジトリでの長いコーディングセッションに向いています。

  1. Claude Code installieren: Verwenden Sie das offizielle Installationsprogramm (zum Beispiel npm install -g @anthropic-ai/claude-code).
  2. 設定を追加：~/.claude/settings.json を編集し、下の env ブロックを追加して、ANTHROPIC_AUTH_TOKEN を AnyAIGC で作成したキーに置き換えます。
  3. コーディングを始める：プロジェクトのフォルダで claude を実行します。/model と入力して、現在のモデルが kimi-k3 であることを確認してください。

サブタスクでコストを節約：ANTHROPIC_DEFAULT_HAIKU_MODEL を kimi-k2.7-code に設定すると、Claude Code の軽量なサブタスクには安価なモデルが使われ、メインのタスクは K3 のままです。

手順の詳細とよくあるエラーは Claude Code セットアップガイドをご覧ください。ガイド内のモデル名は kimi-k3 に置き換えてください。

FAQ

Kimi K3 API のよくある質問

Kimi K3 API の料金はいくらですか？

AnyAIGC では kimi-k3 はトークン単位で課金され、入力は100万トークンあたり$1.2150、出力は100万トークンあたり$6.0750、キャッシュヒットは100万トークンあたり$0.1215です。Moonshot 公式の USD 価格は入力$3.00、出力$15.00、キャッシュヒット$0.30なので、AnyAIGC は定価の約40%です。出力には思考トークンが含まれます。最新の料金はモデル一覧をご覧ください。

Kimi K3 のモデルIDとコンテキスト長は？

モデルIDは kimi-k3 です。Moonshot はコンテキスト長を1,048,576トークン（1M）としています。max_completion_tokens のデフォルトは131,072で、最大1,048,576まで設定できます。

Kimi K3 の特徴は何ですか？

Moonshot によると、Kimi K3 は2.8兆パラメータに到達した初のオープンソースモデルです。Kimi Delta Attention（KDA）ハイブリッド線形アテンションと Attention Residuals を採用し、MoE はトークンごとに896のエキスパートのうち16を活性化し、ネイティブの画像理解に対応しています。Moonshot は K2 の約2.5倍の総合的なスケーリング効率を報告しており、長期的なコーディング、ナレッジワーク、推論を想定しています。

Kimi K3 の思考の深さはどう調整しますか？

K3 は常に思考し、思考をオフにすることはできません。リクエストボディのトップレベルにある reasoning_effort フィールドで深さを設定します。low、high、max のいずれかです（デフォルトは max）。簡単なタスクでは low を使うと出力トークンを減らせます。

Kimi K3 はツール呼び出しと画像入力に対応していますか？

はい。K3 はツール呼び出し（tools / tool_choice）、構造化出力（json_schema）、ストリーミング、画像入力に対応しています。マルチターンの会話やツール呼び出しでは、アシスタントのメッセージ全体（reasoning_content と tool_calls を含む）をそのまま次のリクエストで送り返してください。

Claude Code で Kimi K3 を使えますか？

はい。~/.claude/settings.json の env ブロックで、ANTHROPIC_BASE_URL を https://anyaigc.ai、ANTHROPIC_AUTH_TOKEN を APIキー、ANTHROPIC_MODEL を kimi-k3 に設定してください。その後 claude を実行します。

Kimi K3 と K3.1 Pro の違いは何ですか？

Kimi K3.1 Pro は K3.1 シリーズ最初のモデルです。Moonshot によると、K3 にポストトレーニングの計算資源を大幅に追加したもので、コーディング、3D制作、金融リサーチ、長期的なエージェントで明確に向上しています。パラメータの制約は K3 と同じなので、移行はモデル名を変えるだけです。AnyAIGC では K3.1 Pro は入力$0.8100、出力$4.0500で、K3 より約3分の1安くなっています。新規プロジェクトでは K3.1 Pro から始めてください。

Kimi K3 と K2.7 Code はどちらを使うべきですか？

K3 は2.8Tパラメータの前世代フラッグシップで、コンテキスト長1M、大規模なリポジトリ、長時間のタスク、最も難しい推論に向いています。K2.7 Code は1Tパラメータのコーディングモデルで、コンテキスト長は256K、AnyAIGC での料金は入力$0.3847、出力$1.5980で、K3 の約3分の1です。多くのチームは普段は K2.7 Code を使い、難しい問題のときだけ同じキーで K3 に切り替えています。

同時実行数やレート制限はありますか？

AnyAIGC は kimi-k3 の同時実行数に上限を設けておらず、すべてのユーザーがデフォルトで利用できます。バッチ処理、CI パイプライン、並列エージェントに向いています。Moonshot 自身のプラットフォームでは、チャージ額のティアごとに同時実行数、RPM、TPM、TPD が制限されますが、AnyAIGC 経由で呼び出す場合、その段階は適用されません。

Kimi K3 の APIキーはどう取得しますか？

anyaigc.ai で登録し、残高をチャージして、コンソールでキーを作成します。同じキーで、プラットフォーム上のすべての Kimi モデルと300以上のほかのモデルを呼び出せるため、Moonshot のプラットフォームアカウントは別途必要ありません。

AnyAIGC で請求書を発行できますか？

はい。実際にチャージした金額分の請求書を、コンソールでご自身で発行できます。

対応している支払い方法は何ですか？

新規ユーザー向けの無料トライアルはありますか？

はい。新規アカウントには200万トークン分のトライアル枠が付与されるので、チャージするかどうか決める前に試せます。チャージは $1 から可能です。

残高は返金できますか？

はい。未使用の残高は手数料なしで返金できます。返金をご希望の場合は、サポートにご連絡ください。

本物のモデルですか？データは安全ですか？

リクエストは公式のモデルチャネルに送られ、安価な代替モデルやリバースエンジニアリングによるモデルは使いません。法令で求められる場合を除き、プロンプトや出力を永続的に保存せず、学習にも使用しません。コンソールでは、リクエストごとのトークン数と料金を確認できます。

入力したデータはトレーニングに使われますか？

いいえ。法令で必要な場合を除き、AnyAIGC はプロンプトや出力を永続的に保存せず、モデルの学習にも使用しません。リクエストは HTTPS で暗号化されます。AnyAIGC のプライバシーポリシーをご覧ください。モデル自体のデータポリシーは Moonshot AI の公式規約に従います。
