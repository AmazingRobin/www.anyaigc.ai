クイックスタート

Kling Image 3.0 API を組み込む

  1. 1登録して APIキーを作成し、ANYAIGC_API_KEY を設定します
  2. 2POST /tencent-vod/v1/aigc-image でタスクを送信し、TaskId を取得します
  3. 3GET /tencent-vod/v1/query/{task_id} をポーリングし、Status が FINISH になったら画像をダウンロードします

model_name に "Kling"、model_version に "3.0"、output_config.resolution に大文字の "2K" または "4K" を指定します。結果は Response.AigcImageTask.Output.FileInfos[].FileUrl にあります。一時保存で有効期限があるため、早めにダウンロードしてください。

cURL

curl --request POST "https://anyaigc.ai/tencent-vod/v1/aigc-image" \
  --header "Authorization: Bearer $ANYAIGC_API_KEY" \
  --header "Content-Type: application/json" \
  --data '{
  "model_name": "Kling",
  "model_version": "3.0",

  "output_config": {
    "aspect_ratio": "16:9",

  }
}'

# Query the result with the returned Response.TaskId
curl "https://anyaigc.ai/tencent-vod/v1/query/$TASK_ID" \
  --header "Authorization: Bearer $ANYAIGC_API_KEY"

Python

import json
import os
import time
import urllib.request

BASE = "https://anyaigc.ai"
HEADERS = {
    "Authorization": "Bearer " + os.environ["ANYAIGC_API_KEY"],
    "Content-Type": "application/json",
}


def call(method, path, payload=None):
    data = json.dumps(payload, ensure_ascii=False).encode("utf-8") if payload else None
    request = urllib.request.Request(BASE + path, data=data, headers=HEADERS, method=method)
    with urllib.request.urlopen(request, timeout=60) as response:
        return json.load(response)


payload = {
    "model_name": "Kling",
    "model_version": "3.0",
    "prompt": "An orange cat on a rain-soaked windowsill, a neon-lit street outside, cinematic lighting, rich detail",
    "output_config": {
        "aspect_ratio": "16:9",
        "resolution": "2K"
    }
}

task_id = call("POST", "/tencent-vod/v1/aigc-image", payload)["Response"]["TaskId"]
print("task_id:", task_id)

# Poll every 5 seconds; print the image URL once Status is FINISH
for _ in range(60):
    result = call("GET", f"/tencent-vod/v1/query/{task_id}")["Response"]
    if result["Status"] == "FINISH":
        break
    time.sleep(5)
else:
    raise TimeoutError(task_id)

for item in result["AigcImageTask"]["Output"]["FileInfos"]:
    print(item["FileUrl"])

仕様

仕様と選び方

3.0 Omni は連続画像を生成できますが、3.0 は生成できません。

参照する被写体と参照画像は、合わせて10までです。

ポジティブプロンプトとネガティブプロンプトはそれぞれ2,500文字までです。画像から画像では、ネガティブプロンプトに対応していません。

このページでは テキスト/画像から画像 (2K) を$0.00169 / 枚、テキスト/画像から画像 (4K) を$0.00169 / 枚として掲載しており、上の料金表と一致しています。

kling-custom-elements と比べると、Kling Image 3.0 は保存済みの被写体を参照できます。被写体は被写体管理 API で作成します。

仕様はベンダーの公式ドキュメント（klingai.com）に基づいています。このページの表は料金を示したもので、最新の料金はモデル一覧が正となります。

FAQ

Kling Image 3.0 API のよくある質問

Kling Image 3.0 API の料金はいくらですか？

1回の呼び出しで1枚を返し、$0.00169です。2Kでも4Kでも同じ料金です。料金は USD で、送信が成功した時点で課金されます。最新の料金はモデル一覧をご確認ください。

どのエンドポイントを呼び出せばよいですか？

POST /tencent-vod/v1/aigc-image で送信し、model_name に Kling、model_version に 3.0 を指定します。結果は GET /tencent-vod/v1/query/{task_id} で取得します。APIホストは https://anyaigc.ai、ヘッダーは Authorization: Bearer <API Key> です。

解像度はどう指定しますか？

output_config.resolution に大文字の "2K" または "4K" を指定します。料金はどちらも同じです。

どの生成モードに対応していますか？

テキストから画像、画像から画像、複数画像の参照、スタイル転送、キャラクター参照、インペイントに対応します。参照画像は file_infos に入れます。正確なフィールドは APIリファレンスをご確認ください。

結果はどう取得しますか？

API は非同期です。送信すると Response.TaskId が返るので、照会エンドポイントをポーリングし、Status が FINISH になったら Response.AigcImageTask.Output.FileInfos[].FileUrl から画像をダウンロードします。ファイルは一時的に保存され、期限が切れます。

同時実行数に制限はありますか？

AnyAIGC の Kling モデルは、すべてのアカウントでデフォルトで同時実行数の上限がありません。

生成した画像は商用利用できますか？

利用権とコンテンツポリシーは Kuaishou Kling の公式規約に従います。アップロードする参照画像の権利をお持ちであることをご確認ください。

AnyAIGC で請求書を発行できますか？

はい。実際にチャージした金額分の請求書を、コンソールでご自身で発行できます。

対応している支払い方法は何ですか？

WeChat Pay、Alipay、USDT、クレジットカードでチャージできます。残高は USD で、プラットフォーム上のすべてのモデルで使えます。チャージした金額分の請求書は、コンソールで発行できます。

新規ユーザー向けの無料トライアルはありますか？

はい。新規アカウントには200万トークン分のトライアル枠が付与されるので、チャージするかどうか決める前に試せます。チャージは $1 から可能です。

残高は返金できますか？

はい。未使用の残高は手数料なしで返金できます。返金をご希望の場合は、サポートにご連絡ください。

本物のモデルですか？データは安全ですか？

リクエストは公式のモデルチャネルに送られ、安価な代替モデルやリバースエンジニアリングによるモデルは使いません。法令で求められる場合を除き、プロンプトと出力を永続的に保存せず、学習にも使用しません。コンソールではリクエストごとの料金を確認できます。
