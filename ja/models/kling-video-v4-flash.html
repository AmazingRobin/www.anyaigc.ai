Kling Video V4 Flash API

Kling Video V4 Flash は、Kuaishou の Kling 4.0 シリーズの軽量モデルです。速度とコストを重視し、高頻度のクリエイティブ作業向けに作られています。720pでテキストから動画、最初のフレームを使った画像から動画、参照から動画に対応します。AnyAIGC では$0.1206 / 秒の秒単位課金で、同時実行数の上限はありません。

モデルの機能

Kling Video V4 Flash でできること

現在のモデル一覧と APIリファレンスをもとにまとめています。正確なパラメータは APIドキュメントをご確認ください。

テキストから動画

プロンプトと長さを送信すると、3〜30秒の720pクリップが生成されます。長さのデフォルトは5秒です。

最初・最後のフレーム

image_list 内の画像に first_frame を指定します。end_frame は first_frame と組み合わせて使う必要があり、最後のフレームだけを送ると400が返されます。

複数画像の参照

参照画像は最大10枚まで指定できます。プロンプトでは送信した順に @image_1、@image_2 のように指定し、キャラクター、商品の見た目、シーンを再利用できます。

参照動画

参照動画は最大5本で、feature 参照のみです。公開された http(s) URL を指定し、1本あたり3秒以上、合計30秒までです。カメラワークや動きのリズムを再利用できます。

被写体と音声

element_list に被写体を最大7件、voice_list に音声を最大3件指定でき、@element_1 のように指定します。参照アセットは合計で15件までです。

アスペクト比と解像度

出力は720p固定です（mode は std を指定するか省略します）。アスペクト比は21:9、16:9、9:16、1:1、またはアセットに合わせる adaptive です。

Kling Video V4 Flash API を組み込む

  1. 1登録して APIキーを作成し、ANYAIGC_API_KEY を設定します
  2. 2POST /kling/v1/videos/omni-video でタスクを送信し、task_id を取得します
  3. 3GET /kling/v1/videos/omni-video/{id} をポーリングし、成功したら動画をダウンロードします

model_name に "kling-video-v4-flash" を指定します。このモデルの出力は720pのみです。mode は std を指定するか省略し、resolution は720pを指定するか省略してください。pro や1080pを指定すると400が返され、課金されません。参照画像と参照動画は image_list と video_list に入れ、プロンプトでは @image_1、@video_1 のように指定します。

Python

import json
import os
import time
import urllib.request

BASE = "https://anyaigc.ai"
HEADERS = {
    "Authorization": "Bearer " + os.environ["ANYAIGC_API_KEY"],
    "Content-Type": "application/json",
}


def call(method, path, payload=None):
    data = json.dumps(payload, ensure_ascii=False).encode("utf-8") if payload else None
    request = urllib.request.Request(BASE + path, data=data, headers=HEADERS, method=method)
    with urllib.request.urlopen(request, timeout=60) as response:
        return json.load(response)


payload = {
    "model_name": "kling-video-v4-flash",
    "prompt": "The camera glides down to a neon street after rain as an orange cat walks across the wet pavement, cinematic lighting",
    "duration": 5,
    "aspect_ratio": "16:9"
}

task_id = call("POST", "/kling/v1/videos/omni-video", payload)["data"]["task_id"]
print("task_id:", task_id)

# Poll every 10 seconds; print the video URL once the task succeeds
for _ in range(90):
    data = call("GET", f"/kling/v1/videos/omni-video/{task_id}")["data"]
    if data["task_status"] == "succeed":
        break
    if data["task_status"] == "failed":
        raise RuntimeError(data.get("task_status_msg"))
    time.sleep(10)
else:
    raise TimeoutError(task_id)

for video in data["task_result"]["videos"]:
    print(video["url"])

仕様

仕様と選び方

Kling 4.0 Flash（kling-4.0-flash）は3〜20秒の動画を生成でき、出力は720P SDRのみです。

対応するアスペクト比は21:9、16:9、1:1、9:16、4:3、3:4、adaptive です。

Omni 参照生成では、参照動画を最大5本、被写体を最大7件まで指定でき、参照動画1本ごとの長さと合計の長さはいずれも3〜20秒である必要があります。

Kling によると、より軽量で低コストなモデルで、Omni 参照、動画編集、多言語音声に対応しています。

このページでは、テキスト、最初のフレーム、複数画像の参照（参照動画なし）を$0.1206 / 秒、参照動画を使った参照から動画を$0.0808 / 秒として掲載しており、上の料金表と一致しています。

仕様はベンダーの公式ドキュメント（klingai.com）に基づいています。このページの表は料金を示したもので、最新の料金はモデル一覧が正となります。

FAQ

Kling Video V4 Flash API のよくある質問

Kling Video V4 Flash API の料金はいくらですか？

秒単位の課金で、参照動画なしは1秒あたり$0.1206、参照動画ありは1秒あたり$0.0808で、いずれも720pです。料金は USD で、送信が成功した時点で課金されます。最新の料金はモデル一覧をご確認ください。

どのエンドポイントを呼び出せばよいですか？

POST /kling/v1/videos/omni-video で送信し、model_name に kling-video-v4-flash を指定します。結果は GET /kling/v1/videos/omni-video/{id} で取得します。APIホストは https://anyaigc.ai、ヘッダーは Authorization: Bearer <API Key> です。

どの生成モードに対応していますか？

テキストから動画、最初のフレーム、または最初と最後のフレームを使った画像から動画に対応し、参照画像は最大10枚、参照動画は最大5本、さらに被写体は最大7件、音声は最大3件まで指定できます。参照アセットは合計で15件までです。正確なフィールドは APIリファレンスをご確認ください。

課金の仕組みと、参照動画ありの単価が低い理由を教えてください。

参照動画がない場合、課金秒数は出力の長さと同じで、1秒あたり$0.1206です。ある場合は1秒あたり$0.0808ですが、課金秒数 = 出力の長さ + max(参照動画の合計の長さ, 出力の長さ) となるため、5秒の出力に5秒の参照動画を付けると10秒分、つまり$0.808が課金されます。参照画像、被写体、音声は無料です。

解像度、長さ、アスペクト比にはどのような制限がありますか？

出力は720p固定です。mode は std を指定するか省略し、resolution は720pを指定するか省略してください。pro や1080pを指定すると400が返され、課金されません。duration は3〜30秒の整数で、デフォルトは5です。アスペクト比は21:9、16:9、9:16、1:1、adaptive です。

非対応の機能は何ですか？

このモデルは、sound（on を指定すると400が返されます）、multi_shot、4Kモード、refer_type が base の動画編集に対応していません。参照動画には feature を使う必要があります。

結果はどう取得しますか？

API は非同期です。送信すると task_id が返されるので、照会エンドポイントをポーリングし、タスクが成功したら task_result から動画のURLを取得します。正確なステータス値とレスポンスのフィールドは APIリファレンスをご確認ください。

同時実行数に制限はありますか？

AnyAIGC の Kling モデルは、すべてのアカウントでデフォルトで同時実行数の上限がありません。

動画を商用利用できますか？

利用権とコンテンツポリシーは Kuaishou Kling の公式規約に従います。アップロードする参照画像や参照動画の権利を持っていることを確認してください。

AnyAIGC で請求書を発行できますか？

はい。実際にチャージした金額分の請求書を、コンソールでご自身で発行できます。

対応している支払い方法は何ですか？

WeChat Pay、Alipay、USDT、クレジットカードでチャージできます。残高は USD で、プラットフォーム上のすべてのモデルで使えます。チャージした金額分の請求書は、コンソールで発行できます。

新規ユーザー向けの無料トライアルはありますか？

はい。新規アカウントには200万トークン分のトライアル枠が付与されるので、チャージするかどうか決める前に試せます。チャージは $1 から可能です。

残高は返金できますか？

はい。未使用の残高は手数料なしで返金できます。返金をご希望の場合は、サポートにご連絡ください。

本物のモデルですか？データは安全ですか？

リクエストは公式のモデルチャネルに送られ、安価な代替モデルやリバースエンジニアリングによるモデルは使いません。法令で求められる場合を除き、プロンプトと出力を永続的に保存せず、学習にも使用しません。コンソールではリクエストごとの料金を確認できます。
