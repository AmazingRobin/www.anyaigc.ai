    インフォグラフィックと図解

Nano Banana API を使い始める

  1. 登録：AnyAIGC のアカウントを作成します。新規アカウントには500万トークン分のお試しクレジットが付与され、チャージは$1から可能です。
  2. APIキーを作成：コンソールでキーを発行し、環境変数 ANYAIGC_API_KEY に保存します。
  3. リクエストを送信：POST https://anyaigc.ai/v1beta/models/gemini-nano-banana-2.1:generateContent（Gemini ネイティブ形式）を呼び出します。すでに OpenAI SDK を使っているプロジェクトでは、model に gemini-nano-banana-2.1 を指定して /v1/chat/completions を使えます。

モデルを切り替えるには、MODEL だけを変更します：gemini-nano-banana-2.1、gemini-3.1-flash-image、gemini-3-pro-image。リクエストとレスポンスの形式は同じです。

認証には Authorization: Bearer <API Key> を使います。imageConfig.imageSize には 1K、2K、4K を指定でき、デフォルトは 1K です。response_format はプラットフォーム独自の拡張で、url を指定すると一時的な fileData.fileUri リンクが返ります（非ストリーミングのみ）。省略すると base64 で返ります。安全フィルタでリクエストがブロックされた場合、finishReason は SAFETY または PROHIBITED_CONTENT となり、画像は返りません。

Nano Banana API よくある質問

Nano Banana API の料金はいくらですか？

AnyAIGC では、すべての Nano Banana モデルが1枚あたりで課金されます。1枚あたり、Nano Banana 2.1 は$0.0128から、Nano Banana 2 は$0.0164から、Nano Banana Pro は$0.0328からです。これらはモデル一覧の最安値で、2K・4Kの最新料金はモデル一覧に表示されます。課金は成功したリクエストごとです。

Nano Banana 2.1、Nano Banana 2、Nano Banana Pro の違いは何ですか？

Nano Banana 2.1（gemini-nano-banana-2.1）は、Google が2026年10月6日にリリースした Nano Banana 2 のアップグレード版で、画質、文字の描画、マルチターンでの一貫性が向上しています。Nano Banana 2（gemini-3.1-flash-image）は、Flash クラスのスループットの高い画像モデルです。Nano Banana Pro（gemini-3-pro-image）は Gemini 3 Pro をベースに推論を行うモデルで、複雑なレイアウトやプロ品質のレタッチに向いています。3つとも1K、2K、4Kで出力できます。

Nano Banana とは何ですか？ Gemini との関係は？

Nano Banana は、Google の Gemini 画像生成モデルの愛称です。最初の Nano Banana は Gemini 2.5 Flash Image で、その後に Nano Banana Pro（Gemini 3 Pro Image）、Nano Banana 2（Gemini 3.1 Flash Image）、Nano Banana 2.1 が続きました。いずれも Gemini API の generateContent エンドポイントで呼び出します。

対応しているエンドポイントは？ 画像を編集できますか？

Gemini ネイティブ形式の POST /v1beta/models/<model>:generateContent と、OpenAI 互換の /v1/chat/completions の両方に対応しています。テキストから画像を生成する場合は、テキストのパートを1つ送ります。編集や合成では、指示と参照画像（inlineData）を同じ parts リストに入れます。参照画像は最大14枚です。各フィールドの詳細は AnyAIGC APIドキュメントを参照してください。

同時実行数に制限はありますか？

AnyAIGC では、すべての Nano Banana モデルで同時実行数に上限を設けておらず、すべてのアカウントでデフォルトで適用されます。ベースURLは https://anyaigc.ai で、Google アカウントは不要です。同じキーで300以上の他のモデルも使えます。

AnyAIGC で請求書を発行できますか？

はい。実際にチャージした金額分の請求書を、コンソールでご自身で発行できます。

対応している支払い方法は何ですか？

WeChat Pay、Alipay、USDT、クレジットカードでチャージできます。残高は USD で、プラットフォーム上のすべてのモデルで使えます。チャージした金額分の請求書は、コンソールで発行できます。

新規ユーザー向けの無料トライアルはありますか？

はい。新規アカウントには500万トークン分のトライアル枠が付与されるので、チャージするかどうか決める前に試せます。チャージは $1 から可能です。

残高は返金できますか？

はい。未使用の残高は手数料なしで返金できます。返金をご希望の場合は、サポートにご連絡ください。

本物のモデルですか？データは安全ですか？

リクエストは公式のモデルチャネルに送られ、安価な代替モデルやリバースエンジニアリングによるモデルは使いません。法令で求められる場合を除き、プロンプトや出力を永続的に保存せず、学習にも使用しません。コンソールでは、リクエストごとのトークン数と料金を確認できます。

生成した画像は商用利用できますか？透かしは入りますか？

利用権とコンテンツポリシーは Google の公式規約に従います。Google は、Nano Banana が生成するすべての画像に、目に見えない SynthID のデジタル透かしを埋め込みます。画像上では確認できません。AnyAIGC は API アクセスを提供するだけで、出力の利用方法に追加の制限は設けていません。実在の人物の肖像や第三者の商標を含む画像については、必要な権利を確認してください。
