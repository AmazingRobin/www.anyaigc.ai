モデルについて

iFLYTEK Spark Pro の 3.1 リリース

SparkDesk-v3.1 は、iFLYTEK の Spark 認知モデルの 3.1 API リリースで、公式の Spark Pro ティアに対応します。モデル一覧では、分野をまたぐ知識と言語理解を備え、自然な会話を通じてタスクを実行するモデルと説明されており、言語理解、ナレッジ Q&A、論理推論、数学の問題解決、コード理解をカバーします。

iFLYTEK のドキュメントでは、このティアのコンテキスト長は8,192トークン、最大出力も8,192トークンと記載されています。システムロールは Max と Ultra のみで、Pro には Web 検索プラグインが記載されています。固定のシステムプロンプトが必要なアプリでは、代わりに SparkDesk-v3.5 を使ってください。

AnyAIGC では、SparkDesk-v3.1 は OpenAI 互換の /v1/chat/completions エンドポイントで、Bearer キー1つだけで利用でき、iFLYTEK の APPID、APIKey、APISecret は不要です。課金はトークン単位で、同時実行数の上限はありません。

クイックスタート

3ステップで SparkDesk-v3.1 API を呼び出す

  1. 登録とチャージ：anyaigc.ai でアカウントを作成します。チャージは$1からで、残高はプラットフォームのすべてのモデルで共通して使えます。
  2. APIキーを作成：コンソールでトークンを作成し、sk- で始まるキーをコピーして、環境変数 ANYAIGC_API_KEY に保存します。
  3. リクエストを送信：model に SparkDesk-v3.1 を指定し、Authorization: Bearer を付けて POST https://anyaigc.ai/v1/chat/completions を呼び出します。OpenAI SDK を使う場合は、base_url を https://anyaigc.ai/v1 に設定するだけです。

パラメータのヒント：モデルIDは大文字小文字を区別するため、SparkDesk-v3.1 と書いてください。レスポンス形式は OpenAI Chat Completions と同じで、リクエストのトークン数は usage フィールドで確認できます。コンテキスト長には上限があるため、長いドキュメントは分割するか、検索で必要な部分に絞ってから渡してください。

すべてのパラメータは Chat Completions のリファレンスをご覧ください。サンプルのモデル名は、SparkDesk のモデルIDに置き換えてください。

仕様と選び方

iFlytek の公式 WebSocket ドキュメントでは、v3.1 エンドポイント（wss://spark-api.xf-yun.com/v3.1/chat）が Spark Pro に対応し、domain は generalv3 です。

ドキュメントでは、Pro の max_tokens の範囲は1〜8192、デフォルトは4096とされています。

ドキュメントによると、Pro は Web 検索プラグインに対応しています。出典のタイトルと URL を返せるのは Ultra と Max に限られます。

このページに掲載している入力は$13.1040、出力は$13.1040で、上の料金表と一致しています。

Web 検索結果に出典のタイトルと URL を返したい場合は、sparkdesk-v3.5（Max）を選んでください。ドキュメントでは Pro は非対応とされています。

仕様はベンダーの公式ドキュメント（xfyun.cn）によるものです。このページの表は価格を示しており、最新の料金はモデル一覧が正です。

FAQ

SparkDesk-v3.1 API のよくある質問

SparkDesk-v3.1 API の料金はいくらですか？

AnyAIGC では、SparkDesk-v3.1 はトークン単位の従量課金で、入力100万トークンあたり$13.1040、出力100万トークンあたり$13.1040と、どちらも同じ価格です。価格は固定で、サブスクリプションや月額料金はありません。最新の料金はモデル一覧でご確認ください。

SparkDesk-v3.1 のモデルIDは何で、iFLYTEK Spark とはどういう関係ですか？

モデルIDは SparkDesk-v3.1（大文字小文字を区別）です。iFLYTEK の Spark 認知モデルのリリースの1つで、AnyAIGC が OpenAI 互換の API として提供しています。Apache Spark や、メールアプリの Spark とは関係ありません。

SparkDesk-v3.1 と他の SparkDesk モデルは、どう選べばよいですか？

シリーズのほかの2つは SparkDesk-v3.5 と SparkDesk-v2.1 です。バージョン番号が大きいほど iFLYTEK の新しいティアに対応し、v3.5 は Max、v3.1 は Pro、v2.1 は初期の 2.x リリースです。システムプロンプトが必要なら v3.5 を選んでください。コストを最優先し、品質への要求が高くない場合は v2.1 も候補になりますが、本番前に自社のデータで検証してください。AnyAIGC では3つとも入力と出力が同じ価格です。

SparkDesk は OpenAI API と互換性がありますか？ 呼び出し方も教えてください。

はい。SparkDesk-v3.1 は POST https://anyaigc.ai/v1/chat/completions を使い、リクエストとレスポンスは OpenAI Chat Completions と同じ形式です。公式の OpenAI SDK では、base_url を https://anyaigc.ai/v1 に設定してください。iFLYTEK の WebSocket 署名は不要で、必要なのは Authorization: Bearer だけです。

SparkDesk-v3.1 のコンテキスト長はどれくらいですか？

iFLYTEK のドキュメントでは、このティアのコンテキスト長は8,192トークン、最大出力も8,192トークンと記載されています。長い文書は分割するか、検索で必要な箇所を取り出してから質問してください。実際の動作は AnyAIGC 経由のテストリクエストでご確認ください。

レート制限はありますか？

AnyAIGC は SparkDesk-v3.1 に同時実行数の上限を設けておらず、すべてのアカウントでデフォルトで利用できるため、バッチ処理や並列タスクも問題ありません。課金はトークン単位で、月額料金や時間枠ごとのクォータはありません。

SparkDesk-v3.1 は非推奨ですか？

iFLYTEK Open Platform の現行のバージョン表には、Pro ティアが引き続き掲載されています。SparkDesk-v3.1 は現時点では AnyAIGC のモデル一覧から呼び出せます。現在の提供状況はモデル一覧でご確認ください。

SparkDesk-v3.1 の APIキーはどうやって取得しますか？

anyaigc.ai でアカウントを登録してチャージし、コンソールでトークンを作成してください。1つのキーでプラットフォーム上の300以上のモデルを呼び出せるため、iFLYTEK Open Platform の APPID、APIKey、APISecret は不要です。リクエストボディの model に SparkDesk-v3.1 を指定してください。

AnyAIGC で請求書を発行できますか？

はい。実際にチャージした金額分の請求書を、コンソールでご自身で発行できます。

対応している支払い方法は何ですか？

WeChat Pay、Alipay、USDT、クレジットカードでチャージできます。残高は USD で、プラットフォーム上のすべてのモデルで使えます。チャージした金額分の請求書は、コンソールで発行できます。

新規ユーザー向けの無料トライアルはありますか？

はい。新規アカウントには500万トークン分のトライアル枠が付与されるので、チャージするかどうか決める前に試せます。チャージは $1 から可能です。

残高は返金できますか？

はい。未使用の残高は手数料なしで返金できます。返金をご希望の場合は、サポートにご連絡ください。

本物のモデルですか？データは安全ですか？

リクエストは公式のモデルチャネルに送られ、安価な代替モデルやリバースエンジニアリングによるモデルは使いません。法令で求められる場合を除き、プロンプトや出力を永続的に保存せず、学習にも使用しません。コンソールでは、リクエストごとのトークン数と料金を確認できます。

プロンプトは学習に使われますか？

いいえ。法令で求められる場合を除き、AnyAIGC はプロンプトや出力を永続的に保存せず、学習にも使用しません。リクエストは HTTPS で暗号化されます。詳しくは AnyAIGC のプライバシーポリシーをご覧ください。モデル提供元のデータの扱いは、iFLYTEK の規約に従います。
