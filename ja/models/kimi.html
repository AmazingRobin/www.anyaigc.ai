クイックスタート

3ステップで Kimi API に接続

  1. 登録とチャージ：anyaigc.ai でアカウントを作成します。$1からチャージでき、残高はプラットフォーム上のすべてのモデルで使えます。
  2. APIキーを作成：コンソールでキーを作成し、sk- で始まる値をコピーして、環境変数 ANYAIGC_API_KEY に保存します。
  3. リクエストを送信：POST https://anyaigc.ai/v1/chat/completions を呼び出し、model に kimi-k3.1-pro を指定して、Authorization: Bearer ヘッダーを付けます。OpenAI SDK を使う場合は、base_url を https://anyaigc.ai/v1 に設定するだけです。

ヒント：Kimi は推論の内容を reasoning_content フィールドで返します。ストリーミングでは、推論の差分が先に届き、そのあと最終的な回答が届きます。マルチターンの会話やツール呼び出しでは、API から返ってきた アシスタントのメッセージ（reasoning_content と tool_calls を含む）を、変更せずそのまま次のリクエストに含めて送ってください。

Alle Parameter finden Sie in der Chat-Completions-Referenz. Ersetzen Sie den Modellnamen in den Beispielen der Dokumentation durch die gewünschte Kimi-Modell-ID.

Claude Code

Claude Code で Kimi を使う

設定ファイルを1つ編集するだけで Claude Code を Kimi に切り替えられ、ターミナル上のコーディングエージェントが Kimi で動きます。

  1. Claude Code installieren: Verwenden Sie das offizielle Installationsprogramm (zum Beispiel npm install -g @anthropic-ai/claude-code).
  2. 設定を追加：~/.claude/settings.json を編集し、下の env ブロックを追加して、ANTHROPIC_AUTH_TOKEN を AnyAIGC で作成したキーに置き換えます。
  3. コーディングを開始：プロジェクトのフォルダーで claude を実行します。/model と入力して、現在のモデルが kimi-k3.1-pro になっていることを確認してください。

モデルの切り替え：より安価なコーディングモデルを使うには、設定内のすべての kimi-k3.1-pro を kimi-k2.7-code に置き換えます。K3.1 Pro は大規模なリポジトリ向けにコンテキスト長1Mを備え、K2.7 Code は価格が約半分です。

手順の詳細とよくあるエラーについては、Claude Code セットアップガイドをご覧ください。ガイド内のモデル名を kimi-k3.1-pro に置き換えてください。

FAQ

Kimi API のよくある質問

Kimi API の料金はいくらですか？

AnyAIGC の Kimi モデルはトークン単位で課金されます。100万トークンあたり、kimi-k3.1-pro は入力$0.8100、出力$4.0500、キャッシュヒット$0.0810、kimi-k3 は入力$1.2150、出力$6.0750、キャッシュヒット$0.1215、kimi-k2.7-code は入力$0.3847、出力$1.5980、キャッシュヒット$0.0770、kimi-k2.6 は入力$0.3847、出力$1.5980、キャッシュヒット$0.0651です。Moonshot 公式の USD 価格の約40%にあたります。最新の料金はモデル一覧でご確認ください。

AnyAIGC で使える Kimi のモデルとモデルID を教えてください。

このページでは4モデルを扱います。kimi-k3.1-pro（K3.1 シリーズ最初のモデルで、コンテキスト長1M）、kimi-k3（前世代のフラッグシップで、2.8Tパラメータのオープンウェイトモデル）、kimi-k2.7-code（コーディングエージェント向けモデル）、kimi-k2.6（汎用のマルチモーダルエージェントモデル）です。モデルID はリクエストボディの model フィールドに指定します。モデルを切り替えるときは、このフィールドを1つ変えるだけです。

Kimi K3.1 Pro、K3、K2.7 Code、K2.6 のどれを使えばよいですか？

コンテキスト長1M、最も難しい長期的なコーディング、3D制作、金融リサーチが必要なら Kimi K3.1 Pro を選びます。最新世代で、価格は K3 より約3分の1安価です。すでに K3 で動かしているワークロードは、そのままで構いません。日常のコーディングやコーディングエージェントには K2.7 Code を選びます。Moonshot によると、Kimi Code Bench v2 で K2.6 より21.8%高いスコアです。非思考モードや素早い応答、汎用チャットが必要なら K2.6 を選びます。K2.7 Code と K2.6 は同じ価格で、K3.1 Pro の約半分です。

Kimi API は OpenAI 互換ですか？

はい。4モデルとも POST https://anyaigc.ai/v1/chat/completions を使い、リクエストとレスポンスの形式は OpenAI Chat Completions と同じです。公式の OpenAI SDK では、base_url を https://anyaigc.ai/v1 に設定します。推論の内容は reasoning_content フィールドで返ります。

Claude Code で Kimi を使えますか？

はい。~/.claude/settings.json の env ブロックで、ANTHROPIC_BASE_URL を https://anyaigc.ai、ANTHROPIC_AUTH_TOKEN をご自身のAPIキー、ANTHROPIC_MODEL を kimi-k3.1-pro に設定し、claude を実行してください。

コンテキスト長はどのくらいですか？

Moonshot によると、Kimi K3.1 Pro と K3 は1,048,576トークンのコンテキスト長に対応し、K2.7 Code と K2.6 は262,144トークン（256K）に対応します。4モデルとも画像入力とツール呼び出しに対応しています。

Kimi のモデルはオープンソースですか？商用利用できますか？

Moonshot AI は Kimi K3、K2.7 Code、K2.6 のウェイトを Hugging Face で公開しており、K3.1 Pro のウェイト全体も2026年11月4日までに公開するとしています。AnyAIGC 経由で API を呼び出せば、自分でホスティングする必要はありません。モデルのライセンスと商用利用は Moonshot AI の公式規約に従います。

同時実行数やレート制限はありますか？

AnyAIGC は Kimi モデルの同時実行数に上限を設けておらず、すべてのユーザーがデフォルトで利用できます。バッチ処理、CI パイプライン、並列エージェントに向いています。Moonshot 自身のプラットフォームでは、チャージ額のティアに応じて同時実行数、RPM、TPM、TPD が制限されますが、AnyAIGC 経由で呼び出す場合、その段階は適用されません。

Kimi の APIキーはどうやって取得しますか？

anyaigc.ai で登録し、残高をチャージして、コンソールでキーを作成します。同じキーで、プラットフォーム上のすべての Kimi モデルと300以上のほかのモデルを呼び出せるため、Moonshot のプラットフォームアカウントは別途必要ありません。

AnyAIGC で請求書を発行できますか？

はい。実際にチャージした金額分の請求書を、コンソールでご自身で発行できます。

対応している支払い方法は何ですか？

WeChat Pay、Alipay、USDT、クレジットカードでチャージできます。残高は USD で、プラットフォーム上のすべてのモデルで使えます。チャージした金額分の請求書は、コンソールで発行できます。

新規ユーザー向けの無料トライアルはありますか？

はい。新規アカウントには500万トークン分のトライアル枠が付与されるので、チャージするかどうか決める前に試せます。チャージは $1 から可能です。

残高は返金できますか？

はい。未使用の残高は手数料なしで返金できます。返金をご希望の場合は、サポートにご連絡ください。

本物のモデルですか？データは安全ですか？

リクエストは公式のモデルチャネルに送られ、安価な代替モデルやリバースエンジニアリングによるモデルは使いません。法令で求められる場合を除き、プロンプトや出力を永続的に保存せず、学習にも使用しません。コンソールでは、リクエストごとのトークン数と料金を確認できます。

入力したデータはトレーニングに使われますか？

いいえ。法令で必要な場合を除き、AnyAIGC はプロンプトや出力を永続的に保存せず、モデルの学習にも使用しません。リクエストは HTTPS で暗号化されます。AnyAIGC のプライバシーポリシーをご覧ください。モデル自体のデータポリシーは Moonshot AI の公式規約に従います。
