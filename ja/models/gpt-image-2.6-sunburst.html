GPT Image 2.6 Sunburst API のよくある質問

GPT Image 2.6 Sunburst API の料金はいくらですか？

AnyAIGC では gpt-image-2.6-sunburst はトークン単位で課金されます。100万トークンあたり、テキスト入力は$0.4118、画像入力は$0.6589、画像出力は$2.4710で、テキストのキャッシュ入力は$0.1647、画像のキャッシュ入力は$0.2636です。OpenAI の定価は$5.00、$8.00、$30.00なので、AnyAIGC は定価から約92%オフです。1024×1024 の画像1枚の画像出力コストは、low 品質で約$0.0020（定価では$0.0247）、medium 品質で$0.0036（定価では$0.0435）です。1枚あたり課金版の gpt-image-2.6-sunburst-c は1枚$0.0206です。最新の料金はモデル一覧でご確認ください。

Sunburst と Flare のどちらを選べばよいですか？ GPT Image 2.5 からの変更点は？

どちらも GPT Image 2.6 で、AnyAIGC での料金もパラメータも同じです。OpenAI は Sunburst を、ディテールが求められるビジュアル作業向けと位置づけており、medium または high の品質で編集がより安定します。Flare は高速な反復向けで、low の品質なら最短6秒で画像を返せます。GPT Image 2.5 Sunburst と比べると、2.6 では complexity、マークアップ、SVG、GIF が加わりました。low と medium の品質では、2.6 は2.5より1枚あたりの出力トークン数が多くなり、high 以上では同じです。

GIF と SVG はどのように生成しますか？

どちらも POST /v1/images/generations を使います。GIF の場合は、format を gif、frame_count を2–64（デフォルト9）、frame_duration_ms を20–2000 ms（デフォルト200）に設定します。size は各フレームのサイズです。SVG の場合は、format を svg、n を1に設定します。quality は SVG の元になる参照画像に適用され、結果は静止したベクター画像です。どちらも edits エンドポイント、ストリーミング、圧縮設定には対応していません。

complexity とマークアップ編集はどう使いますか？

complexity には low、medium、high を指定でき、デフォルトは high です。変更しても追加料金はかかりません。OpenAI は、ほとんどの編集では必要な品質に合わせて low を使い、要素や制約が多いシーンでは medium または high を使うことを推奨しています。マークアップ編集には POST /v1/images/edits を使います。元画像を最初の image として送り、同じ幅と高さの透明PNGを markup として添えます。変更したい領域に印を付け、プロンプトで変更内容を説明します。マークアップは mask と併用できません。

1枚あたり課金のバージョンはありますか？ gpt-image-2.6-sunburst-c の料金は？

はい。gpt-image-2.6-sunburst-c は GPT Image 2.6 Sunburst の1枚あたり課金版です。エンドポイントは同じで、変わるのは model フィールドだけです。1K・2K・4K、どの品質レベルでも1枚あたり一律$0.0206です。1回のリクエストで返る画像は1枚で、n、mask、透過背景には対応していません。ほとんどの品質レベルとサイズでは、トークン課金のほうが1枚あたりの料金は安くなります（1024×1024、medium 品質で約$0.0036）。1枚あたり課金は、料金を固定して予算を立てやすくしたい場合に向いており、1枚あたり課金のほうが安くなるのは 2048×2048 と 3840×2160 の max 品質だけです。
