Chat Completions から始める

  1. コンソールでアカウントとAPIキーを作成します。
  2. Base URL を https://anyaigc.ai/v1 に設定します。
  3. model を指定して messages を送信します。
cURL · POST /v1/chat/completions
curl https://anyaigc.ai/v1/chat/completions \
  -H "Authorization: Bearer $ANYAIGC_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"qwen3.8-max","messages":[{"role":"user","content":"Explain what a MoE model is in three sentences."}]}'
Python · OpenAI SDK
from openai import OpenAI
import os
client = OpenAI(api_key=os.environ["ANYAIGC_API_KEY"], base_url="https://anyaigc.ai/v1")
response = client.chat.completions.create(model="qwen3.8-max", messages=[{"role":"user","content":"Explain what a MoE model is in three sentences."}])
print(response.choices[0].message.content)

FAQ

Qwen3.8 Max API のよくある質問

Qwen3.8 Max API はどのエンドポイントを使いますか？

対話モデルは POST https://anyaigc.ai/v1/chat/completions を使います。model と messages を送信し、Authorization: Bearer <API Key> を付けてください。

Qwen3.8 Max API の料金はいくらですか？

Qwen3.8 Max はトークン単位で課金されます。100万トークンあたり、入力$0.8040、出力$2.4120、キャッシュヒット$0.1005です。最新の料金はモデル一覧でご確認ください。

同時実行数に上限はありますか？

このページの Qwen 対話モデルは同時実行数の上限がなく、すべてのユーザーが利用できます。

APIキーはどう取得しますか？

AnyAIGC アカウントを作成し、コンソールでAPIキーを作成してください。1つのキーで300以上のモデルを利用できます。

画像入力やツール呼び出しに対応していますか？

対応状況はモデルごとに異なります。モデル一覧のタグで確認してください。エンドポイントは共通です。

AnyAIGC で請求書を発行できますか？

はい。実際にチャージした金額分の請求書を、コンソールでご自身で発行できます。

対応している支払い方法は何ですか？

WeChat Pay、Alipay、USDT、クレジットカードでチャージできます。残高は USD で、プラットフォーム上のすべてのモデルで使えます。チャージした金額分の請求書は、コンソールで発行できます。

新規ユーザー向けの無料トライアルはありますか？

はい。新規アカウントには200万トークンのお試しクレジットが付きます。

残高は返金できますか？

はい。未使用の残高は手数料なしで返金できます。

公式モデルですか？データは安全ですか？

リクエストは公式のモデルチャネルを通ります。法令で求められる場合を除き、プロンプトと出力は永続的に保存されず、学習にも使われません。
