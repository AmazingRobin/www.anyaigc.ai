Seedream 4.0 とは

Seedream 4.0 は ByteDance Seed チームのマルチモーダル画像モデルで、テキストから画像、画像編集、複数画像の合成を1つのフレームワークにまとめています。プロンプトを推論して適切なアスペクト比と枚数を選び、1回のリクエストでテーマの関連する画像を最大15枚返します。

ByteDance は、中国語テキストの精度と出力の多様性が明確に向上し、4K出力にも対応したと報告しています。AnyAIGC でのモデルIDは doubao-seedream-4-0-250828 で、1枚あたり$0.0203からです。

Seedream 4.0 でできること

  • 画像セット

    1回のリクエストでテーマの関連する画像を最大15枚。枚数と比率はモデルが選びます。

  • 指示による編集

    一文の指示で編集できます。要素の追加や削除、スタイルや背景の変更に対応し、マスクは不要です。

  • 複数画像の合成

    複数の参照画像にある人物、商品、シーンを1つの画面にまとめます。

  • 知識系イラスト

    数式や科学の解説図など、知識を伝える画像を描けます。中国語テキストの精度も向上しています。

Seedream 4.0 API を使い始める

  1. AnyAIGC に登録してください。新規アカウントには200万トークンの無料枠が付与され、$1からチャージできます。
  2. コンソールで APIキーを作成し、環境変数 ANYAIGC_API_KEY に保存します。
  3. POST https://anyaigc.ai/v1/images/generations（OpenAI 互換）にリクエストを送り、model に doubao-seedream-4-0-250828 を指定します。

画像セットに対応する3つのモデルのうち、1K ティアがあるのは4.0だけで、高解像度が不要なバッチ処理に向いています。

認証には Authorization: Bearer <API Key> を使います。レスポンスは {"created": ..., "data": [{"url": ...}]} の形式で、response_format を b64_json にすると base64 で受け取れます。watermark のデフォルトは true なので、透かしなしの画像が必要な場合は明示的に false を渡してください。フィールドの詳細は AnyAIGC Seedream APIドキュメントをご覧ください。

Seedream 4.0 API のよくある質問

Seedream 4.0 API の料金はいくらですか？

AnyAIGC では、Seedream 4.0（doubao-seedream-4-0-250828）は$0.0203 / 枚から利用できます。料金は解像度によって異なり、2Kと4Kの最新レートはモデル一覧で確認できます。画像セットは生成した枚数分が課金されます。課金は生成に成功した分のみで、最新の料金はモデル一覧に表示されます。

Seedream 4.0 とは何ですか？

Seedream 4.0 は ByteDance Seed チームのマルチモーダル画像モデルで、AnyAIGC でのモデルIDは doubao-seedream-4-0-250828 です。テキストから画像、画像編集、複数画像の合成を1つのフレームワークにまとめ、プロンプトから適切なアスペクト比と枚数を選び、1回のリクエストで関連する画像を最大15枚返し、4Kに対応しています。

どの解像度に対応していますか？

Volcano Engine Ark のドキュメントによると、4.0 の size には 1K、2K、4K、またはピクセル寸法を指定でき、アスペクト比は1:16から16:1まで対応します。

参照画像は何枚まで送れますか？画像セットは最大何枚ですか？

image には最大14枚の参照画像を指定できます（現行の Volcano Engine Ark ドキュメントによる）。画像セットは1回のリクエストで最大15枚を返し、参照画像がある場合は、参照画像と生成画像の合計が15枚を超えることはできません。

4.0 は今でも使う価値がありますか？

4.0 は引き続き利用でき、4.5 より安く（$0.0203 / 枚から）、1Kティアもあります。新規プロジェクトでは、まず 5.0 lite か 4.5 をお試しください。APIは同じなので、移行ではモデルIDを変えるだけです。

同時実行数の上限はありますか？登録に必要なものは？

AnyAIGC は Seedream 4.0 に同時実行数の上限を設けておらず、すべてのアカウントでデフォルトで利用できます。ベースURLは https://anyaigc.ai です。Volcano Engine のアカウントや本人確認は不要で、同じキーでプラットフォームの300以上の他のモデルも使えます。

AnyAIGC で請求書を発行できますか？

はい。実際にチャージした金額分の請求書を、コンソールでご自身で発行できます。

対応している支払い方法は何ですか？

WeChat Pay、Alipay、USDT、クレジットカードでチャージできます。残高は USD で、プラットフォーム上のすべてのモデルで使えます。チャージした金額分の請求書は、コンソールで発行できます。

新規ユーザー向けの無料トライアルはありますか？

はい。新規アカウントには200万トークン分のトライアル枠が付与されるので、チャージするかどうか決める前に試せます。チャージは $1 から可能です。

残高は返金できますか？

はい。未使用の残高は手数料なしで返金できます。返金をご希望の場合は、サポートにご連絡ください。

本物のモデルですか？データは安全ですか？

リクエストは公式のモデルチャネルに送られ、安価な代替モデルやリバースエンジニアリングによるモデルは使いません。法令で求められる場合を除き、プロンプトや出力を永続的に保存せず、学習にも使用しません。コンソールでは、リクエストごとのトークン数と料金を確認できます。

商用利用はできますか？透かしは消せますか？

利用権とコンテンツポリシーは、ByteDance / Volcano Engine の公式規約に従います。リクエストで watermark を false にすると、右下に「AI生成」の表示は付きません。AnyAIGC は API アクセスを提供するだけで、出力の利用方法に追加の制限は設けていません。実在の人物の肖像やブランドロゴなどについては、必要な権利を確認してください。
