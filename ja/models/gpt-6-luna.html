3ステップで GPT-6 Luna API を呼び出す

  1. 登録とチャージ：anyaigc.ai でアカウントを作成します。残高はすべてのモデルで共通です。
  2. APIキーを作成：コンソールでトークンを作成し、sk- で始まるキーをコピーして、環境変数 ANYAIGC_API_KEY に保存します。
  3. リクエストを送信：https://anyaigc.ai/v1/chat/completions または https://anyaigc.ai/v1/responses を呼び出し、model に gpt-6-luna を指定して、Authorization: Bearer で認証します。

ツールには Responses API をおすすめします。OpenAI によると、gpt-6-luna が Chat Completions で関数呼び出しに対応するのは、reasoning_effort が "none" のときだけです。ほかの強度での関数呼び出しや、Web検索・ファイル検索などの組み込みツールを使う場合は、/v1/responses に切り替えて、強度を reasoning.effort に指定してください。通常のチャットとストリーミングは /v1/chat/completions で問題なく動作します。

すべてのパラメータは Chat Completions リファレンスと Responses リファレンスをご覧ください。フィールドは公式の OpenAI API と同じです。

GPT-6 Luna API のよくある質問

GPT-6 Luna API の料金はいくらですか？

AnyAIGC では gpt-6-luna はトークン単位で課金されます。入力は100万トークンあたり$0.0135、出力は$0.0675、キャッシュ入力は$0.0014です。OpenAI の定価は入力$0.10、出力$0.50、キャッシュ入力$0.01なので、AnyAIGC は定価の約13.5%（86%オフ）です。1回のリクエストの入力が272Kトークンを超える場合、そのリクエスト全体が入力とキャッシュは2倍、出力は1.5倍で課金されます。

GPT-6 Luna と GPT-5.6 Luna では何が変わりましたか？

GPT-6 Luna は GPT-5.6 Luna の次の世代です。定価は入力$0.20、出力$1.20から$0.10と$0.50に下がり、入力は半額、出力は約58%安くなりました。OpenAI によると、推論の強度 max の AutomationBench では GPT-5.6 Luna の17.0%に対して20.7%で、推論の強度 high では前世代よりスコアが5.4ポイント高く、1タスクあたりのコストは58%下がっています。知識のカットオフは2026-05-18です。AnyAIGC では、100万トークンあたり GPT-6 Luna が入力$0.0135、出力$0.0675、GPT-5.6 Luna が入力$0.0270、出力$0.1620です。

GPT-6 Luna は最も安い GPT モデルですか？

OpenAI の現行の GPT-6 ティア（Astra、Sol、Terra、Luna）のなかで、Luna は定価が最も低く、OpenAI は最速かつ最もコスト効率の高いティアだとしています。AnyAIGC での入力料金は、GPT-6.1 Sol の約7分の1、GPT-6 Astra の約37分の1です。最新の料金は AnyAIGC のモデル一覧でご確認ください。

GPT-6 Luna と GPT-6.1 Sol はどちらを使うべきですか？

OpenAI は、Luna を範囲の限られたタスク、トリアージ、頻繁な自動化向け、Sol を時間とコストの管理も必要な複雑なタスク向けと位置づけています。分類、抽出、要約、一括の書き換えなどの大量処理には GPT-6 Luna を使ってください。複数ファイルにまたがるコーディング、コンピュータ操作（computer use）、長時間のエージェント実行には GPT-6.1 Sol に移行してください。

Chat Completions と Responses API のどちらを使えばよいですか？ツールは使えますか？

どちらのエンドポイントも使えます。通常のチャットとストリーミングには https://anyaigc.ai/v1/chat/completions を使ってください。OpenAI によると、gpt-6-luna が Chat Completions で関数呼び出しに対応するのは、reasoning_effort が none のときだけです。ほかの強度での関数呼び出しや組み込みツールには https://anyaigc.ai/v1/responses を使い、強度を reasoning.effort に指定してください。

Codex で GPT-6 Luna を使えますか？

はい。curl -fsSL https://www.anyaigc.ai/install.sh | bash -s codex を実行すると、インストールと設定ができます（Windows では irm https://www.anyaigc.ai/install.ps1 | iex）。インストーラーのデフォルトは gpt-5.5 なので、その後 ~/.codex/config.toml の model を gpt-6-luna に変更してください。手動で ~/.codex/config.toml を編集する場合は、base_url を https://anyaigc.ai/v1、wire_api を responses、model を gpt-6-luna に設定し、OPENAI_API_KEY を ~/.codex/auth.json に記入してください。
