Suno API で、音楽制作に必要なものを
すべてそろえられます

1つのAPIで、テキストのプロンプトからミックスに使えるステムまで、音楽制作のワークフロー全体をカバーします。

  • 1曲まるごと生成

    1行で曲を説明するだけで、ボーカルとアレンジ入りの完成した曲が得られます。歌詞、スタイルタグ、タイトルを自分で渡して、ジャンル、雰囲気、構成を指定することもできます。v3 から v6 / v6-wild / v6-mini に対応しています。

    曲

  • Max Mode の品質

    Max Mode をオンにすると、ボーカルの表現が豊かで、アレンジが厚い、リリース品質の曲が得られます。料金は標準の2倍です。

    MAX

  • ボーカル/インストの分離

    生成した曲を、ボーカルとインストのステムに分けられます。カラオケ、カバー用のバッキングトラック、リミックスに便利です。

  • 全ステム分離 + MIDI

    曲をドラム、ベース、ギター、キーボード、ボーカルなどに分け、MIDI を書き出してそのまま DAW に取り込めます。

    MIDI

  • AI歌詞生成とスタイル強化

    1つのテーマから、Aメロやサビを備えた構成済みの歌詞を作ったり、短いスタイルタグをより具体的な説明に広げたりできます。どちらも無料です。

    歌詞

  • 歌詞タイムライン

    歌詞を行ごとのタイムスタンプで取得でき、スクロール歌詞、字幕、ミュージックビジュアライザーに使えます。手作業でタイミングを合わせる必要はありません。

    00:42

  • 効果音

    トランジション、通知音、環境音などの短い効果音をテキストから生成できます。1回$0.0238です。ゲームやショート動画の大量制作向けです。

  • 参照音声と Persona

    参照音声をアップロードして、カバーや延長に使えます。気に入ったボーカルをアーティストスタイルの Persona として保存すれば、今後の曲で繰り返し使えます。

    ボーカル

登録して200万トークンを受け取る

3ステップで Suno API を呼び出す

非同期のタスクフローです。リクエストを送信して task_id を受け取り、ポーリングで結果を取得します。数分で最初の曲を聴けます。

  1. 登録してチャージ

    anyaigc.ai でアカウントを作成し、チャージします。残高はプラットフォーム上のすべてのモデルで共通して使えます。

  2. APIキーを作成

    コンソールでトークンを作成し、キーをコピーします。ベースURLは https://anyaigc.ai、認証には Authorization: Bearer を使います。

  3. 送信してポーリング

    /suno/submit/music に POST して task_id を取得し、5–10秒ごとに GET /suno/fetch/{id} を呼び出します。完了したら音声URLを取得してください。

そのほかのモード（延長、カバー、Persona、効果音、マッシュアップ、部分修正など）と全パラメータは、AnyAIGC の Suno API ドキュメントをご覧ください。mv には chirp-v3-5 から chirp-v6 まで指定できます。最新の一覧はドキュメントでご確認ください。

Suno API のよくある質問

AnyAIGC で Suno API を使うときに知っておきたいことをまとめました。

Suno API の料金はいくらですか？

リクエストごとの固定従量課金です。曲の生成 $0.1191、Max Mode $0.2382、効果音 $0.0238、ボーカル/インストの分離 $0.1191、全ステム分離 + MIDI $0.5956、歌詞タイムライン $0.0596（いずれも1回あたり）。歌詞の生成、音楽スタイルの強化、参照音声のアップロード、Persona の作成は無料で、suno_uploads のファイルアップロードは1回あたり $0.000993 です。サブスクリプションや月額料金はありません。

Suno に公式APIはありますか？

2026年10月時点で、Suno は一般向けのセルフサービス型の公式APIを提供していません。AnyAIGC は独立したサードパーティのAPIプラットフォームで、Suno の音楽生成を統一されたインターフェースで利用できるようにしています。Suno, Inc. とは提携していません。

Suno の APIキーはどうやって取得しますか？

anyaigc.ai で登録してチャージし、コンソールのトークンのページで APIキーを作成します。同じキーで Suno とプラットフォーム上の300以上のほかのモデルを利用できます。

Suno API のレート制限はどうなっていますか？

Suno API はデフォルトで 200 RPM（1分あたり200リクエスト）に対応しており、BGMのバッチ生成、UGCプラットフォーム、自動化パイプラインに向いています。すべてのユーザーが申請なしで利用でき、必要な場合は引き上げも可能です。上限の引き上げについてはサポートまでお問い合わせください。

Suno API は同期ですか、非同期ですか？1曲にどのくらいかかりますか？

非同期です。/suno/submit/music に送信して task_id を取得し、タスクが完了するまで /suno/fetch/{id} をポーリングします。ほとんどの曲は1–3分で完了します。曲の長さと現在の負荷によって変わります。

Suno API でできることは何ですか？

テキストの説明や手持ちの歌詞から、ボーカル入りまたはインストの1曲まるごとを生成できます。そのほか、歌詞と効果音の生成、スタイルタグの強化、参照音声のアップロード、ボーカルとインストの分離、全ステムの分離と MIDI の書き出し、行ごとの歌詞タイムラインの取得、アーティスト風 Persona の作成に対応しています。

対応している Suno のモデルバージョンは何ですか？

mv パラメータでバージョンを指定します：chirp-v3-0、chirp-v3-5、chirp-v4、chirp-v4-5、chirp-v5、chirp-v5-5、chirp-v6、chirp-v6-wild、chirp-v6-mini。Suno v3 から最新の v6 ファミリーまでをカバーしています。mv を省略するとデフォルトのバージョンが使われます。最新の一覧は AnyAIGC のドキュメントをご覧ください。

Max Mode と標準の生成はどう違いますか？

Max Mode はより高品質な生成設定を使い、通常はボーカルの細部が良くなり、アレンジにも厚みが出ます。料金は標準の2倍（1回あたり $0.2382）です。リリース向けのトラックには Max Mode、デモや大量の試作には標準モードをお使いください。

AnyAIGC で請求書を発行できますか？

はい。実際にチャージした金額分の請求書を、コンソールでご自身で発行できます。

生成した音楽を商用利用できますか？

商用利用の権利は、Suno の最新のライセンス条件と具体的な用途によって異なります。商用リリースの前に Suno の公式規約をご確認ください。ご不明な点は AnyAIGC のサポートまでお問い合わせください。

対応している支払い方法は何ですか？

WeChat Pay、Alipay、USDT、クレジットカードでチャージできます。残高は USD で、プラットフォーム上のすべてのモデルで使えます。チャージした金額分の請求書は、コンソールで発行できます。

新規ユーザー向けの無料トライアルはありますか？

はい。新規アカウントには200万トークン分のトライアル枠が付与されるので、チャージするかどうか決める前に試せます。チャージは $1 から可能です。

残高は返金できますか？

はい。未使用の残高は手数料なしで返金できます。返金をご希望の場合は、サポートにご連絡ください。

本物のモデルですか？データは安全ですか？

リクエストは公式のモデルチャネルに送られ、安価な代替モデルやリバースエンジニアリングによるモデルは使いません。法令で求められる場合を除き、プロンプトや出力を永続的に保存せず、学習にも使用しません。コンソールでは、リクエストごとのトークン数と料金を確認できます。

対応しているジャンルと言語は何ですか？

Suno は、ポップ、ロック、エレクトロニック、ローファイ、ヒップホップ、フォーク、映画音楽などの主要なジャンルをカバーし、英語、中国語、日本語、韓国語など多くの言語の歌詞とボーカルに対応しています。
