3ステップで GPT-6 Astra API を呼び出す

  1. 登録とチャージ：anyaigc.ai でアカウントを作成します。残高はすべてのモデルで共通です。
  2. APIキーを作成：コンソールでトークンを作成し、sk- で始まるキーをコピーして、環境変数 ANYAIGC_API_KEY に保存します。
  3. リクエストを送信：model に gpt-6-astra を指定し、Authorization: Bearer 認証で https://anyaigc.ai/v1/chat/completions または https://anyaigc.ai/v1/responses を呼び出します。

ツール呼び出しには /v1/responses をおすすめします。OpenAI のモデルページには、gpt-6-astra の Chat Completions でのツール呼び出しに関する制限は記載されていませんが、同じ世代の GPT-6.1 Sol は Chat Completions でツール呼び出しに対応していません。通常のチャットとストリーミングには /v1/chat/completions、関数呼び出し、コンピュータ操作、Web検索などのツールには /v1/responses を使い、強度は reasoning.effort に指定します。Astra は料金が高いため、単純なタスクは low か medium にすると料金を抑えられます。

すべてのパラメータは Chat Completions リファレンスと Responses リファレンスをご覧ください。フィールドは公式の OpenAI API と同じです。

Codex で GPT-6 Astra を使う

コマンド1つで Codex CLI をインストールし、AnyAIGC の設定を書き込みます。~/.codex/ の2つのファイルを自分で編集することもできます。

ワンライン・インストーラーはモデルを gpt-5.5 に設定するため、インストール後に ~/.codex/config.toml の model を gpt-6-astra に変更してください。両方のファイルを保存し、プロジェクトのフォルダで codex を実行します。Codex は Responses API を使うため、ツール呼び出しは通常どおり動作します。小さな編集では model_reasoning_effort を medium のままにし、難しい問題では high か xhigh に上げてください。詳しい手順とよくあるエラーは Codex 設定ガイドをご覧ください。

GPT-6 Astra API のよくある質問

GPT-6 Astra API の料金はいくらですか？

AnyAIGC では、gpt-6-astra はトークン単位で課金され、入力は100万トークンあたり$0.4964、出力は$2.4810、キャッシュ入力は$0.0496です。OpenAI の定価は入力$10.00、出力$50.00、キャッシュ入力$1.00なので、AnyAIGC は定価の約5%（95%オフ）です。1回のリクエストの入力が272Kトークンを超える場合、そのリクエスト全体が入力とキャッシュは2倍、出力は1.5倍で課金されます。

GPT-6 Astra のモデルIDは何ですか？

モデルIDは gpt-6-astra です。リクエストの model フィールドに指定してください。OpenAI は日付付きのスナップショットを公開していません。

GPT-6 Astra と GPT-6.1 Sol はどちらを使うべきですか？

OpenAI によると、GPT-6.1 Sol はエージェント型コーディング、コンピュータ操作、専門業務で GPT-6 Astra に迫り、標準価格は Astra の5分の1です。OpenAI の結果では、Terminal-Bench Science は Astra が引き続きリードしており（68.1% 対 57.0%）、1タスクあたりの費用は Astra が約$23.80、GPT-6.1 Sol が$5.47です（いずれも定価）。日常的なコーディングやエージェント作業にはまず GPT-6.1 Sol を使い、最も難しい推論、リサーチ、長いエンドツーエンドのタスクには GPT-6 Astra を使ってください。AnyAIGC での料金は、GPT-6 Astra が入力$0.4964、出力$2.4810、GPT-6.1 Sol が入力$0.0993、出力$0.4964です（いずれも100万トークンあたり）。

GPT-6.1 Astra がないのはなぜですか？

現時点で、OpenAI は GPT-6.1 Astra をリリースしていません。GPT-6.1 でこれまでにアップグレードされたのは Sol と Terra のティアです。OpenAI の現行の GPT-6 API ラインナップは gpt-6-astra、gpt-6.1-sol、gpt-6.1-terra、gpt-6-luna なので、Astra ティアは引き続き gpt-6-astra です。OpenAI のモデルカタログには、どこから始めるか迷ったら GPT-6 Astra を使うよう書かれています。

Chat Completions と Responses API のどちらを使えばよいですか？ツールは使えますか？

どちらのエンドポイントも利用できます。通常のチャットとストリーミングには https://anyaigc.ai/v1/chat/completions を使ってください。OpenAI のモデルページには、gpt-6-astra の Chat Completions でのツール呼び出しに関する制限は記載されていませんが、同じ世代の GPT-6.1 Sol は Chat Completions でツール呼び出しに対応していないため、関数呼び出しと組み込みツールには https://anyaigc.ai/v1/responses をおすすめします。強度は reasoning.effort に指定します。

Codex で GPT-6 Astra を使えますか？

はい。curl -fsSL https://www.anyaigc.ai/install.sh | bash -s codex を実行してインストールと設定を行います（Windows では irm https://www.anyaigc.ai/install.ps1 | iex）。インストーラーのデフォルトは gpt-5.5 なので、その後 ~/.codex/config.toml の model を gpt-6-astra に変更してください。手動で設定する場合は、~/.codex/config.toml を編集して base_url を https://anyaigc.ai/v1、wire_api を responses、model を gpt-6-astra に設定し、OPENAI_API_KEY を ~/.codex/auth.json に記入します。

同時実行数やレート制限はありますか？

AnyAIGC は gpt-6-astra に同時実行数の上限を設けていません。すべてのアカウントでデフォルトで適用されるため、バッチ処理や並列エージェントも待たされずに動かせます。

GPT-6 Astra の APIキーはどう取得しますか？

anyaigc.ai で登録してチャージし、コンソールでトークンを作成してください。同じキーで GPT-6 Astra とその他300以上のモデルを利用できます。公式の OpenAI SDK なら、base_url を https://anyaigc.ai/v1 に設定するだけです。

AnyAIGC で請求書を発行できますか？

はい。実際にチャージした金額分の請求書を、コンソールでご自身で発行できます。

対応している支払い方法は何ですか？
