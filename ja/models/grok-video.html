Grok Video モデルでできること

これらのクリップは Grok Imagine で生成されたもので、xAI の公式ページから引用しています。クリックすると再生されます（音声あり）。

  • ネイティブ音声とセリフ

    映像、効果音、環境音、セリフが1回の処理で出力され、リップシンクも付くため、ナレーションを後から入れる工程は不要です。

  • テキストから動画と画像から動画

    1文からクリップを生成することも、最初のフレームをアップロードして動かすこともできます。

    香水、飲料、ファッション広告向けに、光、素材、カメラワークを細かく表現します。

  • 1〜15秒、複数の比率

    長さは1〜15秒で指定でき、16:9 の横長、9:16 の縦長、1:1 の正方形から選べます。

Grok Video API を使い始める

  1. AnyAIGC に登録してください。新規アカウントには200万トークンの無料枠が付与され、$1 からチャージできます。
  2. コンソールで APIキーを作成し、環境変数 ANYAIGC_API_KEY に保存します。
  3. model に grok-imagine-video-1.5-preview を指定して POST https://anyaigc.ai/v1/videos/generations にジョブを送信し、GET /v1/videos/{request_id} をポーリングして結果を取得します。

動画生成は非同期です。ジョブIDが返るので、完了するまでポーリングし、その後で動画リンクを取得します。リンクは一時的なものなので、すぐにダウンロードしてください。フィールドの詳細は AnyAIGC ドキュメントをご覧ください：動画を作成、動画を取得、動画を編集。

Grok Video API のよくある質問

Grok Video API の料金はいくらですか？

AnyAIGC では出力動画の1秒あたりで課金されます。Video 1.5 は$0.0476（480p）、$0.0834（720p）/ 秒、1.5 Lite は$0.0119（480p）、$0.0179（720p）、$0.0834（1080p）/ 秒、Video は$0.0298（480p）、$0.0417（720p）/ 秒です。画像から動画では、入力画像ごとの料金が加算されます。480pで6秒の1.5 Liteクリップは約$0.071です。最新の料金はモデル一覧でご確認ください。

Video 1.5、1.5 Lite、Video のどれを使えばよいですか？

Grok Imagine Video 1.5（grok-imagine-video-1.5-preview）は、映像、動き、セリフでシリーズをリードするモデルで、$0.0476 / 秒から。広告や完成度が求められる作品に向いています。1.5 Lite（grok-imagine-video-1.5-lite）はシリーズで最も低価格で、$0.0119 / 秒から、最大1080pに対応し、大量処理やドラフトに向いています。Grok Imagine Video（grok-imagine-video）は第1世代のモデルで、$0.0298 / 秒から。シリーズの中でアップロードした動画を編集できるのはこのモデルだけです。

動画の長さはどこまで指定できますか？対応している解像度とアスペクト比は？

duration には1〜15秒を指定でき、実際の長さに対して課金されます。resolution：Video 1.5 と Video は 480p と 720p、1.5 Lite は 480p、720p、1080p に対応しています。aspect_ratio は 16:9、9:16、1:1 に対応し、画像から動画ではフレームが入力画像に従います。

動画がすぐに返ってこないのはなぜですか？

動画生成は非同期です。送信するとジョブIDが返るので、約10秒ごとに GET /v1/videos/{request_id} をポーリングし、ジョブが完了したら動画のリンクを読み取ります。ほとんどのジョブは数十秒から数分かかります。リンクは一時的なものなので、早めにファイルをダウンロードして保存してください。

動画に音声はつきますか？

はい。Grok Imagine は映像と音声を一緒に生成し、効果音、環境音、セリフも含まれるので、別途ボイスオーバーは不要です。Video 1.5 と 1.5 Lite はリップシンクした音声に対応しています。

xAI のアカウントは必要ですか？

xAI アカウントは不要です。AnyAIGC に登録して APIキーを取得してください。エンドポイントは https://anyaigc.ai で、同じキーでプラットフォーム上のほかの300以上のモデルも使えます。

同時実行数の制限はありますか？

AnyAIGC は Grok Video モデルに同時実行数の制限を設けていません。すべてのアカウントでデフォルトで有効なので、バッチジョブでもクォータの申請は不要です。

AnyAIGC で請求書を発行できますか？

はい。実際にチャージした金額分の請求書を、コンソールでご自身で発行できます。

対応している支払い方法は何ですか？

WeChat Pay、Alipay、USDT、クレジットカードでチャージできます。残高は USD で、プラットフォーム上のすべてのモデルで使えます。チャージした金額分の請求書は、コンソールで発行できます。

新規ユーザー向けの無料トライアルはありますか？

はい。新規アカウントには200万トークン分のトライアル枠が付与されるので、チャージするかどうか決める前に試せます。チャージは $1 から可能です。

残高は返金できますか？

はい。未使用の残高は手数料なしで返金できます。返金をご希望の場合は、サポートにご連絡ください。

本物のモデルですか？データは安全ですか？

リクエストは公式のモデルチャネルに送られ、安価な代替モデルやリバースエンジニアリングによるモデルは使いません。法令で求められる場合を除き、プロンプトや出力を永続的に保存せず、学習にも使用しません。コンソールでは、リクエストごとのトークン数と料金を確認できます。

動画を商用利用できますか？

利用権とコンテンツポリシーは xAI の公式規約に従います。AnyAIGC は API アクセスを提供するだけで、出力の利用方法に追加の制限は設けません。
