HappyHorse 1.0

仕様と選び方

happyhorse-1.0-video-edit は、テキストの指示で既存のクリップを編集する、HappyHorse 1.0 の動画編集モデルです。

Alibaba Cloud のドキュメントでは、出力は720Pと1080P、1クリップあたり3〜15秒、24 fps、MP4で、映像と同時に音声が生成されると記載されています。

このページでは、720P動画を$0.1161 / 秒、1080P動画を$0.2065 / 秒と掲載しています。上の料金表と同じ数値です。

動画編集はバージョン1.0のみの対応です。新しい映像を生成する場合は、同じファミリーのテキスト、画像、参照のモデルを使ってください。

仕様は Alibaba Cloud Model Studio の動画生成ドキュメントに基づいています。このページの表が料金で、最新の料金はモデル一覧が正となります。

HappyHorse 1.0 Video Edit API よくある質問

HappyHorse 1.0 Video Edit は何に使えますか？

HappyHorse 1.0 の動画編集。自然言語と最大5枚の参照画像で、既存の動画を部分的にも全体的にも編集できます。

happyhorse-1.0-video-edit はどの解像度と長さに対応していますか？

Alibaba Cloud のドキュメントによると、720Pと1080P、1クリップあたり3〜15秒、24 fps、MP4で、音声も生成されます。

HappyHorse 1.1 と 1.0 の違いは何ですか？

動画編集は 1.0 のみの対応です。1.1 のテキスト、画像、参照のモデルでは480Pティアが加わります。
