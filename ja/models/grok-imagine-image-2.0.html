Grok Imagine Image 2.0 とは

Grok Imagine Image 2.0 は、xAI が2026年8月にリリースした画像モデルです。grok.com と Grok アプリでは新しい Quality モード、API では grok-imagine-image-2.0 として提供されています。xAI は、仕事で実際に使える画像を作るモデルとして位置づけています。プロンプトの細部に忠実に従い、デザイナーのように文字とレイアウトを設計し、生成や編集を重ねても渡した内容を保持します。

xAI のローンチ記事によると、Arena の画像編集とテキストから画像の両方のリーダーボードで2位でした（2026年8月7日時点のデータ）。2026年11月から、xAI は従来の grok-imagine-image-quality をこのモデルに統合しています。

AnyAIGC では解像度と品質ごとに料金が決まり、1枚あたり$0.0179（1K Low）から$0.0357（2K Medium）です。xAI の定価は1枚$0.04–$0.08なので、約55%安くなります。編集では入力画像1枚につき$0.00447が加算されます。

Grok Imagine Image 2.0 でできること

これらのサンプルは Imagine Image 2.0 で生成されたもので、xAI のローンチ記事から引用しています。

  • 文字とレイアウト

    見出し、小さな注記、スケジュール、キャプションをデザイナーが組んだように配置するので、情報量の多いポスター、旅程、インフォグラフィックも読みやすく仕上がります。

  • 精密な編集

    指示した部分だけを変え、残りはそのまま保てます。背景の差し替え、商品の色替え、不要物の除去を一文の指示で行えます。

  • 一貫したスタイル

    キャラクター、場所、小道具を別々に生成しても同じ雰囲気を保てるため、絵コンテ、絵本、ゲームアセットに向いています。

  • 多彩なスタイル

    フォトリアル、水墨画、ピクセルアート、マンガ、レトロなポスターのいずれも、細部と質感をはっきり保って安定して仕上がります。

  • 15種類のアスペクト比

    1:2の縦長から21:9のワイドまで対応します。比率を選ぶと、モデルは画像を切り抜くのではなく、シーンを再構成します。

  • 商品・マーケティング用の画像

    カラーバリエーション、マーケットプレイスのメイン画像、雑誌風の商品ポスターを、1回の呼び出しですぐ使える形で生成できます。

Grok Imagine Image 2.0 API のよくある質問

Grok Imagine Image 2.0 API の料金はいくらですか？

AnyAIGC では、Grok Imagine Image 2.0（grok-imagine-image-2.0）の料金は解像度と品質ごとに決まります。1K / 1.5K / 2K で、Low は1枚あたり$0.0179 / $0.0223 / $0.0268、Medium は$0.0268 / $0.0313 / $0.0357です。編集では入力画像1枚につき$0.00447が加算されます。xAI の定価は1枚$0.04–$0.08に加えて入力画像1枚につき$0.01なので、AnyAIGC は約55%安くなります。生成に成功した分のみ課金され、最新の料金はモデル一覧でご確認ください。

Image 2.0 は以前の Grok Imagine と何が違いますか？

2.0 は文字の描画、プロンプトへの追従、編集が向上しています。インフォグラフィックやポスターの小さな文字がより鮮明になり、複数回の編集でも元の内容が保たれます。また quality（low / medium / auto）と、新しい比率 21:9 と 5:2 が加わりました。第1世代の grok-imagine-image は、1枚$0.0119で引き続き利用できます。

quality パラメータはどう設定すればよいですか？

quality には low、medium、auto を指定できます。xAI のドキュメントによると、デフォルトの auto は現在、生成では low、編集では medium を使います。Low は高速で、medium はディテールが増えます。AnyAIGC では Medium のほうが高く、1K では Low が1枚あたり$0.0179、Medium が$0.0268です。

対応しているアスペクト比と解像度は何ですか？

aspect_ratio には 1:1、3:4、4:3、9:16、16:9、2:3、3:2、9:19.5、19.5:9、9:20、20:9、1:2、2:1、21:9、5:2、または auto を指定できます。resolution には 1k、1.5k、2k を指定します。

画像を編集するにはどうすればよいですか？複数の参照画像は使えますか？

image、prompt、model を multipart/form-data で POST /v1/images/edits に送信します。変更したい部分だけを記述すれば、残りはそのまま保たれます。xAI は1リクエストあたり最大5枚の参照画像の合成に対応していますが、AnyAIGC のドキュメントには現在、画像1枚の例のみが載っています。複数画像の入力については AnyAIGC の API ドキュメントをご確認ください。

grok-imagine-image-quality は今も使えますか？

xAI は2026年11月2日に grok-imagine-image-quality を 2.0 に統合したため、このモデル名へのリクエストは low 品質の 2.0 で処理されます。古いコードは AnyAIGC で引き続き動作します（1枚$0.0223から）。ただし Low 品質の 2.0 はどの解像度でも1枚あたり$0.0044–$0.0045安いため、model を grok-imagine-image-2.0 に切り替えると費用を抑えられます。

xAI のアカウントは必要ですか？

xAI アカウントは不要です。AnyAIGC に登録して APIキーを取得してください。エンドポイントは https://anyaigc.ai で、同じキーでプラットフォーム上のほかの300以上のモデルも使えます。

同時実行数の制限はありますか？

AnyAIGC は Grok Image モデルに同時実行数の制限を設けていません。すべてのアカウントでデフォルトで適用されるため、バッチ処理でも割り当ての申請は不要です。

AnyAIGC で請求書を発行できますか？

はい。実際にチャージした金額分の請求書を、コンソールでご自身で発行できます。

対応している支払い方法は何ですか？

WeChat Pay、Alipay、USDT、クレジットカードでチャージできます。残高は USD で、プラットフォーム上のすべてのモデルで使えます。チャージした金額分の請求書は、コンソールで発行できます。

新規ユーザー向けの無料トライアルはありますか？

はい。新規アカウントには200万トークン分のトライアル枠が付与されるので、チャージするかどうか決める前に試せます。チャージは $1 から可能です。

残高は返金できますか？

はい。未使用の残高は手数料なしで返金できます。返金をご希望の場合は、サポートにご連絡ください。

本物のモデルですか？データは安全ですか？

リクエストは公式のモデルチャネルに送られ、安価な代替モデルやリバースエンジニアリングによるモデルは使いません。法令で求められる場合を除き、プロンプトや出力を永続的に保存せず、学習にも使用しません。コンソールでは、リクエストごとのトークン数と料金を確認できます。

生成した画像は商用利用できますか？

利用権とコンテンツポリシーは xAI の公式規約に従います。AnyAIGC は API アクセスを提供するだけで、出力の利用方法に追加の制限は設けません。
