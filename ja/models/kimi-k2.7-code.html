概要

コーディング向けにさらに学習させた K2.6

Moonshot AI は Kimi K2.7 Code を、これまでで最も強力な自社のコーディングモデルと位置づけています。K2.6 をさらに学習させたモデルで、長いコンテキストでも指示に忠実に従い、より多くのコーディングタスクを完了し、思考トークンは K2.6 より約30%少なくなります。

Die Architektur entspricht K2.6: MoE mit insgesamt 1T und 32B aktiven Parametern, 8 von 384 Experten pro Token, 256K Kontext sowie Text- und Bildeingabe. K2.7 Code denkt immer und unterstützt Interleaved Thinking mit mehrstufigen Tool-Aufrufen, was zu Coding-Agenten passt.

AnyAIGC では kimi-k2.7-code は OpenAI 互換の /v1/chat/completions エンドポイントで動作し、Claude Code でそのまま使えます。同時実行数の上限はありません。

3ステップで Kimi K2.7 Code API に接続

  1. 登録とチャージ：anyaigc.ai でアカウントを作成します。$1からチャージでき、残高はプラットフォーム上のすべてのモデルで使えます。
  2. APIキーを作成：コンソールでキーを作成し、sk- で始まる値をコピーして、環境変数 ANYAIGC_API_KEY に保存します。
  3. リクエストを送信：POST https://anyaigc.ai/v1/chat/completions を呼び出し、model に kimi-k2.7-code を指定して、Authorization: Bearer ヘッダーを付けます。OpenAI SDK なら base_url を https://anyaigc.ai/v1 に設定するだけです。

ヒント：K2.7 Code は常に思考し、推論内容は reasoning_content で返されます。Moonshot は temperature=1.0 と top_p=0.95 を推奨しています。マルチターンの会話やツール呼び出しでは、API が返したアシスタントメッセージ（reasoning_content と tool_calls を含む）を変更せずにそのまま次のリクエストで送り返してください。

Alle Parameter finden Sie in der Chat-Completions-Referenz. Ersetzen Sie den Modellnamen in den Beispielen der Dokumentation durch die gewünschte Kimi-Modell-ID.

Claude Code

Claude Code で Kimi K2.7 Code を使う

Claude Code のモデルを Kimi K2.7 Code に切り替えます。コーディング向けに学習されており、料金は K3.1 Pro の約半分です。

  1. Claude Code installieren: Verwenden Sie das offizielle Installationsprogramm (zum Beispiel npm install -g @anthropic-ai/claude-code).
  2. 設定を追加：~/.claude/settings.json を編集し、下の env ブロックを追加して、ANTHROPIC_AUTH_TOKEN を AnyAIGC で作成したキーに置き換えます。
  3. コーディングを始める：プロジェクトのフォルダで claude を実行します。/model と入力して、現在のモデルが kimi-k2.7-code であることを確認してください。

大規模リポジトリの場合：K2.7 Code のコンテキスト長は256Kです。プロジェクトが大きく一度に読み込めない場合は、設定のモデルを kimi-k3.1-pro（コンテキスト長1M）に切り替えてください。

詳しい手順とよくあるエラーは Claude Code 設定ガイドをご覧ください。ガイド内のモデル名は kimi-k2.7-code に置き換えてください。

FAQ

Kimi K2.7 Code API のよくある質問

Kimi K2.7 Code API の料金はいくらですか？

AnyAIGC では kimi-k2.7-code はトークン単位で課金されます。入力は100万トークンあたり$0.3847、出力は100万トークンあたり$1.5980、キャッシュヒットは100万トークンあたり$0.0770です。Moonshot の公式の定価（USD）は入力$0.95、出力$4.00、キャッシュヒット$0.19で、AnyAIGC は定価の約40%です。出力には思考トークンが含まれます。最新の料金はモデル一覧をご確認ください。

Kimi K2.7 Code のモデルIDとコンテキスト長は？

モデルIDは kimi-k2.7-code です。Moonshot は262,144トークン（256K）のコンテキスト長を掲載しており、テキストと画像の入力に対応しています。

Kimi K2.7 Code は K2.6 とどう違いますか？

K2.7 Code は K2.6 をベースにコーディング向けに追加学習したモデルで、アーキテクチャは同じです（総パラメータ1T、アクティブパラメータ32B）。Moonshot によると、長いコンテキストでも指示により確実に従い、より多くのコーディングタスクを完了でき、思考トークンは K2.6 より約30%少なくなります。Kimi Code Bench v2 は50.9から62.0に向上しています。K2.7 Code は思考モードでのみ動作しますが、K2.6 は思考モードをオフにできます。AnyAIGC での入力と出力の料金はどちらも同じです。

Kimi K2.7 Code で思考モードをオフにできますか？

できません。Moonshot によると、K2.7 Code は常に思考モードと preserve thinking をオンにして動作し、非思考モードには対応していません。思考なしの高速な応答が必要な場合は kimi-k2.6 を使ってください。Moonshot は temperature=1.0 と top_p=0.95 を推奨しています。

Kimi K2.7 Code はツール呼び出しに対応していますか？

Ja. K2.7 Code unterstützt Interleaved Thinking und mehrstufige Tool-Aufrufe, was zu Coding-Agenten passt. Senden Sie in Multi-Turn-Chats und bei Tool-Aufrufen die vollständige Assistant-Nachricht (einschließlich reasoning_content und tool_calls) in der nächsten Anfrage unverändert zurück.

Claude Code で Kimi K2.7 Code を使えますか？

はい。~/.claude/settings.json の env ブロックで、ANTHROPIC_BASE_URL を https://anyaigc.ai、ANTHROPIC_AUTH_TOKEN をご自身の APIキー、ANTHROPIC_MODEL を kimi-k2.7-code に設定し、claude を実行してください。

Kimi K2.7 Code と Kimi K3.1 Pro はどちらを使えばよいですか？

K2.7 Code は1Tパラメータのコーディング特化モデルで、コンテキスト長256K、AnyAIGC では入力$0.3847、出力$1.5980です。日常的なコーディングや大量のエージェント呼び出しに向いています。Kimi K3.1 Pro は最新の3T級モデルで、コンテキスト長1M、入力$0.8100、出力$4.0500です。大規模リポジトリや最も難しいタスクに向いています。どちらも同じキーで使えます。

同時実行数やレート制限はありますか？

AnyAIGC begrenzt die Parallelität für kimi-k2.7-code nicht, und jeder Nutzer hat das standardmäßig. Das eignet sich für Batch-Jobs, CI-Pipelines und parallele Agenten. Die Plattform von Moonshot begrenzt Parallelität, RPM, TPM und TPD nach Aufladestufe; diese Stufen gelten nicht, wenn Sie über AnyAIGC aufrufen.

Kimi K2.7 Code の APIキーはどう取得しますか？

anyaigc.ai で登録し、残高をチャージして、コンソールでキーを作成します。同じキーで、プラットフォーム上のすべての Kimi モデルと300以上のほかのモデルを呼び出せるため、Moonshot のプラットフォームアカウントは別途必要ありません。

AnyAIGC で請求書を発行できますか？

はい。実際にチャージした金額分の請求書を、コンソールでご自身で発行できます。

対応している支払い方法は何ですか？

WeChat Pay、Alipay、USDT、クレジットカードでチャージできます。残高は USD で、プラットフォーム上のすべてのモデルで使えます。チャージした金額分の請求書は、コンソールで発行できます。

新規ユーザー向けの無料トライアルはありますか？

はい。新規アカウントには200万トークン分のトライアル枠が付与されるので、チャージするかどうか決める前に試せます。チャージは $1 から可能です。

残高は返金できますか？

はい。未使用の残高は手数料なしで返金できます。返金をご希望の場合は、サポートにご連絡ください。

本物のモデルですか？データは安全ですか？

リクエストは公式のモデルチャネルに送られ、安価な代替モデルやリバースエンジニアリングによるモデルは使いません。法令で求められる場合を除き、プロンプトや出力を永続的に保存せず、学習にも使用しません。コンソールでは、リクエストごとのトークン数と料金を確認できます。

入力したデータはトレーニングに使われますか？

いいえ。法令で必要な場合を除き、AnyAIGC はプロンプトや出力を永続的に保存せず、モデルの学習にも使用しません。リクエストは HTTPS で暗号化されます。AnyAIGC のプライバシーポリシーをご覧ください。モデル自体のデータポリシーは Moonshot AI の公式規約に従います。
