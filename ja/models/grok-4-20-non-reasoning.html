04 / クイックスタート

Grok 4.20 Non-Reasoning API を組み込む

最小限のリクエストから始めて、アプリケーションに組み込みます。

  1. 01登録して、コンソールでAPIキーを作成します。
  2. 02環境変数 ANYAIGC_API_KEY を設定します。
  3. 03grok-4-20-non-reasoning でリクエストを送信し、コンソールで使用量を確認します。
POST /v1/chat/completions ↗

cURL の例は Bash / WSL 用です。Python は SDK を使わず、標準ライブラリで書いています。リクエストは完全な JSON を返し、Python では choices[0].message.content を読み取ります。

cURL
curl https://anyaigc.ai/v1/chat/completions \
  -H "Authorization: Bearer $ANYAIGC_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
  "model": "grok-4-20-non-reasoning",
  "messages": [
    {
      "role": "user",
      "content": "Organize product feedback into problems, impact, and suggestions, with at most three points in each."
    }
  ],
  "stream": false
}'
Python · 標準ライブラリ
import json
import os
import urllib.request

payload = {'model': 'grok-4-20-non-reasoning', 'messages': [{'role': 'user', 'content': 'Organize product feedback into problems, impact, and suggestions, with at most three points in each.'}], 'stream': False}
request = urllib.request.Request(
    "https://anyaigc.ai/v1/chat/completions",
    data=json.dumps(payload).encode("utf-8"),
    headers={
        "Authorization": f"Bearer {os.environ['ANYAIGC_API_KEY']}",
        "Content-Type": "application/json",
    },
    method="POST",
)
with urllib.request.urlopen(request, timeout=180) as response:
    result = json.load(response)
print(result["choices"][0]["message"]["content"])

リクエストとレスポンスのフィールドは AnyAIGC のドキュメントに定義されています。Messages のページには Grok 固有のレスポンスの違いが記載されていないため、この例ではレスポンスに追加のフィールドを想定せず、リクエストのみを示しています。

仕様

仕様と選び方

公式ドキュメントでは、Grok 4.20 の推論なしバリアントとされており、説明は推論ありのバリアントと同じで、高性能、速度、エージェント型のツール呼び出しが挙げられています。

公式の仕様表では、コンテキスト長1,000,000トークン、テキストと画像の入力、テキスト出力、関数呼び出しと構造化出力に対応していると記載されています。

リリースノートによると、Grok 4.20 は2026年3月10日にリリースされました。

このページの料金（Grok 4.20 Non-Reasoning 基本ティア · 入力 ≤ 200,000トークン）は、入力$0.1241 / 100万トークン、出力$0.2482 / 100万トークンです。ほかのティアは上の料金表をご覧ください。

grok-4-20-reasoning との比較：公式ドキュメントでは、もう一方のバリアントは推論ありのモデルとされています。コンテキスト長と入出力の種類は共通なので、回答の前にモデルに考えさせたい場合はそちらを選んでください。

仕様はベンダーの公式ドキュメント（docs.x.ai）に基づいています。このページの表は料金を示したもので、最新の料金はモデル一覧が正となります。

07 / FAQ

Grok 4.20 Non-Reasoning API のよくある質問

Grok 4.20 Non-Reasoning には、どのモデルIDを使えばよいですか？

grok-4-20-non-reasoning をそのまま指定してください。シリーズのほかのモデルは Grok 4.x の概要ページをご覧ください。

Grok API の料金はどのくらいですか？

入力は100万トークンあたり$0.1241、出力は$0.2482です。入力が200,000トークンを超え500,000トークン以下の Grok 4.20 Non-Reasoning のリクエストでは、入力が100万トークンあたり$0.2482、出力が$0.4963です。これらはモデル一覧に表示されている最低料金です。最新の料金はモデル一覧でご確認ください。

対応しているAPIエンドポイントは何ですか？

モデル一覧に現在記載されているとおり、POST /v1/chat/completions に対応しています。

同時実行数やRPMの制限はありますか？

ここに掲載しているすべてのモデルで、全ユーザーの同時実行数は標準で上限なしです。個別の有効化は不要です。接続数、タイムアウト、リトライはアプリケーション側で管理してください。

APIには X のリアルタイムデータが自動的に含まれますか？

通常のチャットには、リアルタイムの出来事は自動では含まれません。xAI では、リアルタイムのデータには検索ツールが必要です。ここで紹介する基本的な例は検索を使用せず、上流のすべての検索ツールへの対応を約束するものでもありません。商用利用は xAI の規約に従います。

AnyAIGC で請求書を発行できますか？

はい。実際にチャージした金額分の請求書を、コンソールでご自身で発行できます。

対応している支払い方法は何ですか？

WeChat Pay、Alipay、USDT、クレジットカードでチャージできます。残高は USD で、プラットフォーム上のすべてのモデルで使えます。チャージした金額分の請求書は、コンソールで発行できます。

新規ユーザー向けの無料トライアルはありますか？

はい。新規アカウントには200万トークン分のトライアル枠が付与されるので、チャージするかどうか決める前に試せます。チャージは $1 から可能です。

残高は返金できますか？

はい。未使用の残高は手数料なしで返金できます。返金をご希望の場合は、サポートにご連絡ください。

本物のモデルですか？データは安全ですか？

リクエストは公式のモデルチャネルに送られ、安価な代替モデルやリバースエンジニアリングによるモデルは使いません。法令で求められる場合を除き、プロンプトや出力を永続的に保存せず、学習にも使用しません。コンソールでは、リクエストごとのトークン数と料金を確認できます。
