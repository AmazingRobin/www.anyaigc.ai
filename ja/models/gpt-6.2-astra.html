OpenAI の新しいフロンティアモデルを、定価の約5%で

OpenAI は 2026年11月17日に GPT-6.2 Astra と GPT-6.2 Sol を同時にリリースし、Astra は最も難しいプロジェクト向けの新しいフロンティアモデルです。OpenAI によると、スライド、スプレッドシート、文書は AI らしくなくなり、テンプレートや分野の慣例により忠実に沿い、コードもより簡潔になり、見た目も動作も優れたフロントエンドを作れます。API 料金は GPT-6 Astra より低く、入力と出力のトークン価格は20%、キャッシュ入力は60%低くなっています（入力$8.00、キャッシュ入力$0.40、出力$40.00、いずれも100万トークンあたり）。

3ステップで GPT-6.2 Astra API を呼び出す

  1. 登録とチャージ：anyaigc.ai でアカウントを作成します。残高はすべてのモデルで共通です。
  2. APIキーを作成：コンソールでトークンを作成し、sk- で始まるキーをコピーして、環境変数 ANYAIGC_API_KEY に保存します。
  3. リクエストを送信：model を gpt-6.2-astra に設定し、Authorization: Bearer で認証して、https://anyaigc.ai/v1/chat/completions または https://anyaigc.ai/v1/responses を呼び出します。

ツール呼び出しには /v1/responses をおすすめします。通常のチャットとストリーミングには /v1/chat/completions を使い、関数呼び出し、コンピュータ操作、Web検索などのツールには /v1/responses を使い、強度は reasoning.effort に指定してください。このページの関数呼び出しのサンプルは /v1/responses を使っています。

すべてのパラメータは Chat Completions リファレンスと Responses リファレンスをご覧ください。フィールドは公式の OpenAI API と同じです。

Codex で GPT-6.2 Astra を使う

コマンド1つで Codex CLI をインストールし、AnyAIGC の設定を書き込みます。~/.codex/ の2つのファイルを自分で編集することもできます。

ワンライン・インストーラーはモデルを gpt-5.5 に設定するため、インストール後に ~/.codex/config.toml の model を gpt-6.2-astra に変更してください。両方のファイルを保存し、プロジェクトのフォルダで codex を実行します。Codex は Responses API を使うため、ツール呼び出しは通常どおり動作します。小さな編集では model_reasoning_effort を medium のままにし、難しい問題では high または xhigh に上げてください。手順の詳細とよくあるエラーは Codex 設定ガイドをご覧ください。

GPT-6.2 Astra API のよくある質問

GPT-6.2 Astra API の料金はいくらですか？

AnyAIGC では、gpt-6.2-astra はトークン単位で課金されます。入力100万トークンあたり$0.3971、出力100万トークンあたり$1.9860、キャッシュ入力100万トークンあたり$0.0199です。OpenAI の定価は入力$8.00、出力$40.00、キャッシュ入力$0.40なので、AnyAIGC は定価の約5%（95%オフ）です。1回のリクエストの入力が272Kから1Mトークンの場合は上位の料金区分で課金され、100万トークンあたり入力$0.7942、出力$2.9780です。

GPT-6.2 Astra のモデルIDは何ですか？

モデルIDは gpt-6.2-astra です。リクエストの model フィールドに指定してください。

GPT-6.2 Astra と GPT-6 Astra では何が変わりましたか？

OpenAI は GPT-6.2 Astra を、最も難しいプロジェクト向けの新しいフロンティアモデルと呼んでいます。API の定価は GPT-6 Astra より低く、入力と出力のトークンは20%安く（$8と$40）、キャッシュ入力は60%安くなっています（$0.40）。OpenAI によると、Agents’ Last Exam では3分の1未満のコストで GPT-6 Astra を5.2ポイント上回り、Terminal-Bench-Science 0.1 でも3分の1未満のコストで9ポイント高く、GDPval v2 では出力トークンを22%減らしながら6.2ポイント高くなっています。AnyAIGC では、100万トークンあたり gpt-6.2-astra が入力$0.3971・出力$1.9860、gpt-6-astra が入力$0.4964・出力$2.4810です。

GPT-6.2 Astra と GPT-6.2 Sol はどちらを使うべきですか？

OpenAI によると、GPT-6.2 Sol は Cognition の FrontierCode 2.0 で GPT-6.2 Astra の0.5ポイント以内に収まり、コストは約5分の1です（どちらも max）。ほとんどのコーディングやエージェント作業にはまず GPT-6.2 Sol から始め、最も難しいプロジェクト、専門的な文書、リサーチには GPT-6.2 Astra に移ってください。AnyAIGC では、100万トークンあたり GPT-6.2 Astra が入力$0.3971・出力$1.9860、GPT-6.2 Sol が入力$0.0993・出力$0.4964です。

Chat Completions と Responses API のどちらを使えばよいですか？ツールは使えますか？

どちらのエンドポイントも使えます。通常のチャットとストリーミングには https://anyaigc.ai/v1/chat/completions を使います。関数呼び出し、Web検索、コンピュータ操作などのツールには https://anyaigc.ai/v1/responses をおすすめし、強度は reasoning.effort に指定してください。Responses API では、マルチエージェント（ベータ）でサブエージェントにタスクを委任することもできます。

Codex で GPT-6.2 Astra を使えますか？

使えます。curl -fsSL https://www.anyaigc.ai/install.sh | bash -s codex を実行してインストールと設定を行います（Windows では irm https://www.anyaigc.ai/install.ps1 | iex）。インストーラーのデフォルトは gpt-5.5 なので、その後 ~/.codex/config.toml の model を gpt-6.2-astra に変更してください。または ~/.codex/config.toml を自分で編集し、base_url を https://anyaigc.ai/v1、wire_api を responses、model を gpt-6.2-astra に設定して、OPENAI_API_KEY を ~/.codex/auth.json に記入します。

同時実行数やレート制限はありますか？

AnyAIGC は gpt-6.2-astra に同時実行数の上限を設けていません。すべてのアカウントでデフォルトで適用されるため、バッチ処理や並列エージェントも待たされることなく実行できます。

GPT-6.2 Astra の APIキーはどう取得しますか？

anyaigc.ai で登録してチャージし、コンソールでトークンを作成してください。同じキーで GPT-6.2 Astra とその他300以上のモデルを利用できます。公式の OpenAI SDK なら、base_url を https://anyaigc.ai/v1 に設定するだけです。

AnyAIGC で請求書を発行できますか？

はい。実際にチャージした金額分の請求書を、コンソールでご自身で発行できます。

対応している支払い方法は何ですか？

WeChat Pay、Alipay、USDT、クレジットカードでチャージできます。残高は USD で、プラットフォーム上のすべてのモデルで使えます。チャージした金額分の請求書は、コンソールで発行できます。

新規ユーザー向けの無料トライアルはありますか？

はい。新規アカウントには500万トークン分のトライアル枠が付与されるので、チャージするかどうか決める前に試せます。チャージは $1 から可能です。

残高は返金できますか？

はい。未使用の残高は手数料なしで返金できます。返金をご希望の場合は、サポートにご連絡ください。

本物のモデルですか？データは安全ですか？

リクエストは公式のモデルチャネルに送られ、安価な代替モデルやリバースエンジニアリングによるモデルは使いません。法令で求められる場合を除き、プロンプトや出力を永続的に保存せず、学習にも使用しません。コンソールでは、リクエストごとのトークン数と料金を確認できます。

データは学習に使われますか？

いいえ。法令で求められる場合を除き、AnyAIGC はプロンプトや出力を永続的に保存せず、学習にも使用しません。リクエストは HTTPS で通信中に暗号化されます。詳しくは AnyAIGC のプライバシーポリシーをご覧ください。モデル自体のデータの扱いは OpenAI の公式規約に従います。
