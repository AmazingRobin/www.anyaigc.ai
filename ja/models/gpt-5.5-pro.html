GPT-5.5 Pro API を3ステップで呼び出す

  1. 登録とチャージ：anyaigc.ai でアカウントを作成します。残高はすべてのモデルで共通です。
  2. APIキーを作成：コンソールでトークンを作成し、sk- で始まるキーをコピーして環境変数 ANYAIGC_API_KEY に保存します。Pro は料金が高いため、このキーには利用上限を設定してください。
  3. リクエストを送信：model に gpt-5.5-pro を指定し、Authorization: Bearer 認証で https://anyaigc.ai/v1/responses を呼び出します。

Responses API のみ対応です。OpenAI によると、gpt-5.5-pro は /v1/chat/completions とストリーミング（stream）に対応していません。/v1/responses を呼び出し、強度は reasoning.effort で指定し、クライアントのタイムアウトを長めに設定してください。リクエストによっては数分かかるため、OpenAI はバックグラウンドモード（background: true）で実行し、結果をポーリングすることを推奨しています。

すべてのパラメータは Responses リファレンスをご覧ください。フィールドは OpenAI 公式 API と同じです。

GPT-5.5 Pro API よくある質問

GPT-5.5 Pro API の料金はいくらですか？

AnyAIGC では、gpt-5.5-pro はトークン単位で課金され、入力100万トークンあたり$17.8200、出力100万トークンあたり$106.9200です。OpenAI の定価は入力$30.00、出力$180.00なので、AnyAIGC は定価の約59.4%（41%オフ）です。OpenAI によると GPT-5.5 Pro にはキャッシュ入力の割引がないため、繰り返しの入力も入力料金で課金されます。

GPT-5.5 Pro のモデルIDは何ですか？

モデルIDは gpt-5.5-pro です。リクエストの model フィールドに指定してください。OpenAI は日付付きスナップショット gpt-5.5-pro-2026-04-23 も公開しています。

GPT-5.5 Pro と GPT-5.5 の違いは何ですか？

OpenAI は GPT-5.5 Pro を、より多くの計算資源を使ってじっくり考える GPT-5.5 のバージョンと説明しており、精度が最も重要となる極めて複雑な問題を対象としています。OpenAI の結果では、BrowseComp のスコアは Pro が90.1%、標準の GPT-5.5 が84.4%ですが、GDPval では標準の GPT-5.5 のほうが高くなっています（84.9% 対 82.3%）。Pro は Responses API のみ対応で、ストリーミングもキャッシュ割引もなく、推論の強度は medium、high（デフォルト）、xhigh に対応します。AnyAIGC では、GPT-5.5 が入力$0.2482、出力$1.4890、Pro が入力$17.8200、出力$106.9200（いずれも100万トークンあたり）です。まず標準の GPT-5.5 から始め、間違いのコストが大きい難問で Pro に切り替えてください。

GPT-5.5 Pro は高価です。コストを抑えるには？

high から始め、必要なときだけ xhigh を使ってください。推論トークンは出力として課金されるためです。Pro にはキャッシュ割引がないので、送るコンテキストは必要な分だけにしてください。max_output_tokens で返答ごとの上限を設け、コンソールで Pro 用の APIキーに利用上限を設定し、日常的な質問は GPT-5.5 や GPT-6.1 Sol に振り分けて、難しいものだけを Pro に送るようにします。

Chat Completions やストリーミングは使えますか？

いいえ。OpenAI によると、gpt-5.5-pro は Responses API（Batch を含む）でのみ利用できます。/v1/chat/completions とストリーミングには対応していません。https://anyaigc.ai/v1/responses を呼び出し、強度は reasoning.effort で指定してください。

リクエストが遅いのはなぜですか？タイムアウトを避けるには？

Pro は推論により多くの計算資源を使うため、OpenAI によるとリクエストによっては数分かかります。クライアントのタイムアウトを10分以上に延ばしてください。より確実なのは、OpenAI も推奨しているバックグラウンドモードです。リクエストに background: true を追加し、返された id で responses.retrieve をポーリングして、ステータスが queued や in_progress でなくなるまで待ちます。

Codex で GPT-5.5 Pro を使えますか？

使えますが、遅くて高価なためデフォルトには向きません。curl -fsSL https://www.anyaigc.ai/install.sh | bash -s codex を実行してインストールし（Windows では irm https://www.anyaigc.ai/install.ps1 | iex）、~/.codex/config.toml に [profiles.pro] ブロックを追加して model に gpt-5.5-pro を指定します。普段はデフォルトのモデルを使い、難しいタスクのときだけ codex --profile pro を実行してください。

GPT-5.5 Pro は非推奨ですか？いつまで使えますか？

非推奨ではありません。OpenAI は GPT-5.6 と GPT-6 のファミリーをリリースしましたが、API での gpt-5.5-pro の提供終了日は発表しておらず、現在も AnyAIGC で通常どおり利用できます。非推奨になった旧世代の Pro モデルについては、OpenAI の非推奨ページが GPT-5.6 Sol の pro モード（reasoning.mode: pro）を案内しています。新規プロジェクトでは、GPT-6 Astra または GPT-5.6 Sol を検討してください。

APIキーはどう取得しますか？

anyaigc.ai で登録してチャージし、コンソールでトークンを作成してください。同じキーで GPT-5.5 Pro とその他300以上のモデルを利用できます。公式の OpenAI SDK なら、base_url を https://anyaigc.ai/v1 に設定するだけです。

AnyAIGC で請求書を発行できますか？
