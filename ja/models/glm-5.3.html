同じベースモデル、大幅に強化されたポストトレーニング

Zhipu は GLM-5.3 を最新のフラッグシップと位置づけ、複雑なソフトウェアエンジニアリングとエージェントタスクの全般で向上したとしています。GLM-5.2 と同じベースモデルを使っており、改善はすべて、GLM-5.2 で導入した強化学習の手法を土台にしたポストトレーニングの拡大によるものだと説明しています。

3ステップで GLM-5.3 API に接続

  1. 登録とチャージ：anyaigc.ai でアカウントを作成します。$1からチャージでき、残高はプラットフォーム上のすべてのモデルで使えます。
  2. APIキーを作成：コンソールでキーを作成し、sk- で始まる値をコピーして、環境変数 ANYAIGC_API_KEY に保存します。
  3. リクエストを送信：POST https://anyaigc.ai/v1/chat/completions を呼び出し、model に glm-5.3 を指定して、Authorization: Bearer ヘッダーを付けます。OpenAI SDK なら、base_url を https://anyaigc.ai/v1 に設定するだけです。

Tipp: GLM-5.3 denkt immer. Das Reasoning kommt im Feld reasoning_content zurück, und reasoning_effort legt die Tiefe fest. Die Standardwerte von Zhipu sind temperature=1.0 und top_p=0.95; wenn Sie sie anpassen, ändern Sie nur einen davon. Senden Sie bei mehrstufigen Chats und Tool-Aufrufen die vollständige Assistant-Nachricht der API (einschließlich reasoning_content und tool_calls) in der nächsten Anfrage unverändert zurück.

全パラメータは Chat Completions リファレンスをご覧ください。ドキュメントの例にあるモデル名は、使いたい GLM のモデルIDに置き換えてください。

Claude Code

Claude Code で GLM-5.3 を使う

設定ファイルを1つ編集するだけで、Claude Code を GLM-5.3 に切り替えられます。Zhipu の最新フラッグシップモデルをターミナルで使ってコーディングでき、課金はトークン単位です。

  1. Claude Code をインストール：公式インストーラーを使います。macOS または Linux の場合は、たとえば curl -fsSL https://claude.ai/install.sh | bash です。
  2. 設定を追加：~/.claude/settings.json を編集し、下の env ブロックを追加して、ANTHROPIC_AUTH_TOKEN を AnyAIGC で作成したキーに置き換えます。
  3. コーディングを始める：プロジェクトフォルダで claude を実行します。/model と入力して、現在のモデルが glm-5.3 であることを確認してください。

軽いタスクは節約：この設定では ANTHROPIC_DEFAULT_HAIKU_MODEL を glm-5.3-flash にしているため、Claude Code の軽量なサブタスクは安いモデルで処理され、メインの作業は GLM-5.3 のままです。

手順の全体とよくあるエラーは Claude Code セットアップガイドをご覧ください。ガイド内のモデル名は glm-5.3 に置き換えてください。

仕様

仕様と選び方

Z.ai のドキュメントでは、GLM-5.3 は最新のフラッグシップモデルとされています。ベースモデルは GLM-5.2 と同じで、改善はすべてポストトレーニングによるものです。

ベンダーによると、Z.ai Code Bench では GLM-5.2 より50%向上し、Terminal Bench 3.0 などの公開ベンチマークでオープンソースモデルの中で最高水準の性能に達しています。

現在はテキスト入力のみに対応し、コンテキスト長は1Mトークン、最大出力は128Kトークンです。推論は常にオンで、強度は low、high、max（デフォルトは max）から選べます。推論をオフにすることはできなくなりました。

Diese Seite nennt Eingabe $0,9450, Ausgabe $2,9700 und Cache-Treffer $0,1758, passend zur Preistabelle oben.

glm-5.2 との比較：公式ドキュメントによると GLM-5.3 は推論をオフにできないため、thinking.type を disabled にしているリクエストは、モデルを切り替える前に enabled に変更してください。変更しないと失敗します。

仕様はベンダーの公式ドキュメント（docs.z.ai）に基づいています。このページの表は料金を示したもので、最新の料金はモデル一覧が正となります。

FAQ

GLM-5.3 API よくある質問

GLM-5.3 API の料金はいくらですか？

Bei AnyAIGC wird glm-5.3 pro Token abgerechnet: Eingabe $0,9450 pro 1 Mio. Tokens, Ausgabe $2,9700 pro 1 Mio. Tokens, Cache-Treffer $0,1758 pro 1 Mio. Tokens. Die offiziellen USD-Preise von Zhipu betragen für Eingabe $1,40, für Ausgabe $4,40 und für Cache-Treffer $0,26. Eingabe und Ausgabe kosten bei AnyAIGC also rund 67,5 % des offiziellen Preises (rund 30 % Rabatt). Die Ausgabe schließt Denk-Tokens ein. Aktuelle Preise finden Sie im Modellkatalog.

GLM-5.3 のモデルIDは何ですか？コンテキスト長はどのくらいですか？

モデルIDは glm-5.3 です。Zhipu はコンテキスト長1Mトークン、最大128Kの出力トークンと記載しています。現在はテキスト入力のみに対応しています。

GLM-5.3 と GLM-5.2 の違いは何ですか？

Laut Zhipu nutzt GLM-5.3 dasselbe Basismodell wie GLM-5.2, und alle Verbesserungen stammen aus hochskaliertem Post-Training. Gemeldete Änderungen: Z.ai Code Bench liegt 50 % über GLM-5.2, Terminal Bench 3.0 stieg von 4,6 auf 28,3 und DeepSWE von 46,2 auf 66,9. GLM-5.3 denkt außerdem immer, der Denkmodus lässt sich nicht abschalten. Bei AnyAIGC kosten beide für Eingabe und Ausgabe gleich viel, und GLM-5.3 hat den niedrigeren Cache-Treffer-Preis ($0,1758 gegenüber $0,2362).

GLM-5.3 の思考の深さはどう調整しますか？思考モードをオフにできますか？

GLM-5.3 は常に思考し、Zhipu はオフにすることに対応していません。深さはリクエストボディの reasoning_effort フィールドで指定します。low、high、max から選べ、デフォルトは max で、Zhipu はコーディングにこれを推奨しています。簡単なタスクでは low を使うと出力トークンを減らせます。

GLM-5.3 はツール呼び出しと構造化出力に対応していますか？

Ja. Die Dokumentation von Zhipu nennt Funktionsaufrufe, strukturierte Ausgabe (JSON), Streaming und Context Caching. Senden Sie bei mehrstufigen Chats und Tool-Aufrufen die vollständige Assistant-Nachricht (einschließlich reasoning_content und tool_calls) in der nächsten Anfrage unverändert zurück.

GLM-5.3 を Claude Code で使えますか？

はい。~/.claude/settings.json の env ブロックで、ANTHROPIC_BASE_URL を https://anyaigc.ai、ANTHROPIC_AUTH_TOKEN をご自身の APIキー、ANTHROPIC_MODEL を glm-5.3 に設定し、claude を実行します。課金はトークン単位で、サブスクリプションプランのような5時間のクォータ枠はありません。

GLM-5.3 はオープンソースですか？

はい。Zhipu は GLM-5.3 のウェイトを GLM-5.3 License のもとで Hugging Face（zai-org/GLM-5.3）に公開しています。全体として寛容なライセンスですが、追加の規定が1つあります。年間売上が$100億を超え、モデル・アズ・ア・サービス事業を運営する企業は、商用利用の前に Z.ai のセキュリティレビューを通過する必要があります。AnyAIGC 経由で API を呼び出せば、自分でホストする必要はありません。商用利用は Zhipu AI の公式規約に従います。

同時実行数やレート制限はありますか？

AnyAIGC begrenzt die Parallelität für glm-5.3 nicht, und jeder Nutzer erhält das standardmäßig. Das passt zu Batch-Jobs, CI-Pipelines und parallelen Agenten. Die Abrechnung erfolgt pro Token, es gibt also kein Kontingent, das sich wie bei einem Abo-Tarif nach einem Zeitfenster zurücksetzt.

GLM-5.3 の APIキーはどう取得しますか？

anyaigc.ai で登録し、チャージして、コンソールでキーを作成します。同じキーで、すべての GLM モデルとプラットフォーム上の300以上のモデルを利用できます。Zhipu のプラットフォームのアカウントや GLM Coding Plan は別途必要ありません。

AnyAIGC で請求書を発行できますか？

残高は返金できますか？

はい。未使用の残高は手数料なしで返金できます。返金をご希望の場合は、サポートにご連絡ください。

本物のモデルですか？データは安全ですか？
