Grok Imagine Image とは

Grok Imagine Image（grok-imagine-image）は、xAI が2026年初めに Grok Imagine API とともにリリースした画像モデルです。xAI のドキュメントでは 1.0 とされ、スナップショット名は grok-imagine-image-2026-03-02 です。テキストの説明から画像を生成でき、複数のアスペクト比と1k / 2kの出力に対応しています。

2026年8月に xAI は Image 2.0 をリリースしました。文字の描画と編集が強化されており、AnyAIGC での料金はやや高くなります（1枚$0.0179から。第1世代は$0.0119）。第1世代のモデルは提供終了していないので、既存の連携はそのまま動作します。

AnyAIGC では1枚$0.0119で、xAI の定価は1枚$0.02です。このモデルは AnyAIGC では /v1/images/generations エンドポイントを使います。

Grok Imagine Image でできること

  • 01

    テキストから画像

    1文から画像を生成できます。フォトリアル、イラスト、ポスターなど、一般的なスタイルに対応します。

  • 02

    複数のアスペクト比

    aspect_ratio で1:1、16:9、9:16、3:2 などを指定でき、カバー画像、縦型ポスター、バナーに合わせられます。

  • 03

    1k / 2k 出力

    resolution で1kか2kを選べます。xAI は両方を同じ価格にしています。

  • 04

    base64 または URL

    response_format を b64_json にすると画像データそのものが、url にすると一時リンクが返ります。

  • 05

    互換インターフェース

    リクエスト形式は OpenAI の /v1/images/generations と同じなので、既存の画像生成コードは model を変えるだけで使えます。

  • 06

    2.0 へ簡単にアップグレード

    編集や、より優れた文字の描画が必要なときは、model を grok-imagine-image-2.0 に切り替えてください（1枚$0.0179から）。

Grok Imagine Image API を始める

  1. AnyAIGC に登録してください。新規アカウントには200万トークンの無料枠が付与され、$1 からチャージできます。
  2. コンソールで APIキーを作成し、環境変数 ANYAIGC_API_KEY に保存します。
  3. POST https://anyaigc.ai/v1/images/generations にリクエストを送り、model に grok-imagine-image を指定します。

認証は Authorization: Bearer <API Key> で行います。レスポンスは {"created": ..., "data": [{"b64_json": ...}], "usage": {"generated_images": 1, ...}} の形式です。response_format を url にすると一時リンクが返るので、早めにダウンロードしてください。フィールドの詳細は AnyAIGC のドキュメントをご覧ください：画像を作成。

仕様と選び方

公式のモデルページによると、grok-imagine-image はテキストと画像を入力として受け取り、画像を返します。

ベンダーが挙げている日付付きのエイリアスは grok-imagine-image-2026-03-02 で、このバージョンを固定したい場合に呼び出せます。

公式の画像生成ドキュメントでは xAI の画像モデルについて、解像度は1k（デフォルト）と2kで、n パラメータで1回の呼び出しあたり1〜10枚の画像を生成できるとされています。

このページの料金（Grok Imagine Image grok-imagine-image）は、1K / 2K が1枚$0.0119です。ほかのティアは上の料金表をご覧ください。

grok-imagine-image-2.0 との比較：公式のモデル選択表では、画像タスクにはまず Image 2.0 が案内されています。

仕様はベンダーの公式ドキュメント（docs.x.ai）に基づいています。このページの表は料金を示したもので、最新の料金はモデル一覧が正となります。

Grok Imagine Image API のよくある質問

Grok Imagine Image API の料金はいくらですか？

AnyAIGC では、Grok Imagine Image（grok-imagine-image）は画像1枚あたり$0.0119で、1kでも2kでも同じです。xAI の定価は1枚$0.02です。生成に成功した分のみ課金されます。最新の料金はモデル一覧でご確認ください。

Image 2.0、Image、Quality のどれを使えばよいですか？

Grok Imagine Image 2.0（grok-imagine-image-2.0）は、xAI が現在おすすめしているモデルで、文字の描画、プロンプトへの追従、編集が強化されています。AnyAIGC では1枚$0.0179からなので、新規プロジェクトはこちらから始めてください。Grok Imagine Image（grok-imagine-image）は第1世代の Imagine モデルで1枚$0.0119、シリーズ最安です。シンプルなテキストから画像や既存のコードには十分です。Grok Imagine Image Quality は2026年11月2日に xAI が提供を終了しており、そのリクエストは現在、2.0 の low 品質で処理されます。

grok-imagine-image は提供終了になりますか？

今回の変更の影響はありません。xAI が2026年11月2日に提供を終了したモデルは grok-imagine-image-quality で、grok-imagine-image は引き続き利用できます。編集や、より優れた文字の描画が必要な場合は grok-imagine-image-2.0（1枚$0.0179から）をご検討ください。

対応しているアスペクト比と解像度は何ですか？

aspect_ratio には 1:1、16:9、9:16、3:2、2:3、4:3、3:4 などの値を、resolution には 1k か 2k を指定します。quality パラメータは Image 2.0 のみ対応しています。

画像を編集できますか？

AnyAIGC では、grok-imagine-image は生成用の /v1/images/generations エンドポイントを使います。画像をアップロードして修正したい場合は、grok-imagine-image-2.0 で /v1/images/edits を呼び出してください。

xAI のアカウントは必要ですか？

xAI アカウントは不要です。AnyAIGC に登録して APIキーを取得してください。エンドポイントは https://anyaigc.ai で、同じキーでプラットフォーム上のほかの300以上のモデルも使えます。

同時実行数の制限はありますか？

AnyAIGC は Grok Image モデルに同時実行数の制限を設けていません。すべてのアカウントでデフォルトで適用されるため、バッチ処理でも割り当ての申請は不要です。

AnyAIGC で請求書を発行できますか？

はい。実際にチャージした金額分の請求書を、コンソールでご自身で発行できます。

対応している支払い方法は何ですか？

WeChat Pay、Alipay、USDT、クレジットカードでチャージできます。残高は USD で、プラットフォーム上のすべてのモデルで使えます。チャージした金額分の請求書は、コンソールで発行できます。

新規ユーザー向けの無料トライアルはありますか？

はい。新規アカウントには200万トークン分のトライアル枠が付与されるので、チャージするかどうか決める前に試せます。チャージは $1 から可能です。

残高は返金できますか？

はい。未使用の残高は手数料なしで返金できます。返金をご希望の場合は、サポートにご連絡ください。

本物のモデルですか？データは安全ですか？

リクエストは公式のモデルチャネルに送られ、安価な代替モデルやリバースエンジニアリングによるモデルは使いません。法令で求められる場合を除き、プロンプトや出力を永続的に保存せず、学習にも使用しません。コンソールでは、リクエストごとのトークン数と料金を確認できます。

生成した画像は商用利用できますか？

利用権とコンテンツポリシーは xAI の公式規約に従います。AnyAIGC は API アクセスを提供するだけで、出力の利用方法に追加の制限は設けません。
