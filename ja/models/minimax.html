  --header "Authorization: Bearer $ANYAIGC_API_KEY" \

  --data '{

      "role": "user",

Python
import json
import os
import urllib.request

payload = {
    "model": "MiniMax-M3.1-Flash",
    "messages": [
        {
            "role": "user",
            "content": "Design three clear API endpoints for a to-do application."
        }
    ]
}

request = urllib.request.Request(
    "https://anyaigc.ai/v1/chat/completions",
    data=json.dumps(payload, ensure_ascii=False).encode("utf-8"),
    headers={
        "Authorization": "Bearer " + os.environ["ANYAIGC_API_KEY"],
        "Content-Type": "application/json",
    },
    method="POST",
)
with urllib.request.urlopen(request, timeout=120) as response:
    result = json.load(response)

print(json.dumps(result, ensure_ascii=False, indent=2))

FAQ

MiniMax API のよくある質問

料金、エンドポイント、結果、法人向けの利用をまとめて確認できます。

MiniMax API の最低料金はいくらですか？

M3.1 Flash の入力は100万トークンあたり$0.0603、Speech は10,000文字あたり Turbo が$0.3176、HD が$0.5559、H3 768P の出力は1秒あたり$0.0750です。単位はサービスごとに異なります。最新の料金は、全体の料金表とモデル一覧をご確認ください。公式の定価に対して、M3.1 Flash は59%オフ、M3 と M2.5 は32%オフです。割引はここに掲載した料金に適用されます。最新のオファーはモデル一覧をご確認ください。

13モデルの中からどう選べばよいですか？

チャットと開発には M3.1 Flash、M3、M2.7、M2.5、動画には MiniMax H3 または Hailuo H3（高速版の H3-Max を含む）、ナレーションには6つの Speech バージョンと HD / Turbo の各版、テキストで指定する声には Voice Design を選びます。まずは実際のワークロードと音声で試してください。

これらのモデルは同じエンドポイントを使いますか？

AnyAIGC の同じAPIキーとドメインを共有します。チャットは /v1/chat/completions、MiniMax H3 は /minimax/v2/video_generation、Hailuo H3 は /tencent-vod/v1/aigc-video、音声は /minimax/v1/t2a_v2 または /minimax/v1/t2a_async_v2、Voice Design は /minimax/v1/voice_design を使います。

動画、音声、ボイスデザインの結果はどう受け取りますか？

H3 は作成時にまず task_id が返ります。同期の音声は、音声に関する JSON が返ります。Voice Design はドキュメント上で結果のフィールドが一貫していないため、レスポンス全体を保存し、仕様を確認してください。各ガイドに最小限のリクエスト例があります。

同時実行数やRPMの制限はありますか？

AnyAIGC では MiniMax の同時実行数に上限がなく、固定の RPM 上限もありません。生成には時間がかかるため、タイムアウト、エラー処理、適切なリトライはアプリケーション側で設定してください。

生成したコンテンツは商用利用できますか。

モデルとその出力の商用利用は MiniMax の公式規約に従います。参照素材、音声、生成コンテンツについて必要な権利をお持ちであることをご確認ください。AnyAIGC は独立した API プロバイダーです。

AnyAIGC で請求書を発行できますか？

はい。実際にチャージした金額分の請求書を、コンソールでご自身で発行できます。

対応している支払い方法は何ですか？

WeChat Pay、Alipay、USDT、クレジットカードでチャージできます。残高は USD で、プラットフォーム上のすべてのモデルで使えます。チャージした金額分の請求書は、コンソールで発行できます。

新規ユーザー向けの無料トライアルはありますか？

はい。新規アカウントには200万トークン分のトライアル枠が付与されるので、チャージするかどうか決める前に試せます。チャージは $1 から可能です。

残高は返金できますか？

はい。未使用の残高は手数料なしで返金できます。返金をご希望の場合は、サポートにご連絡ください。

本物のモデルですか？データは安全ですか？

リクエストは公式のモデルチャネルに送られ、安価な代替モデルやリバースエンジニアリングによるモデルは使いません。法令で求められる場合を除き、プロンプトや出力を永続的に保存せず、学習にも使用しません。コンソールでは、リクエストごとのトークン数と料金を確認できます。
