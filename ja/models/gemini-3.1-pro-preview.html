複雑な推論向けに作られた Gemini 3 の Pro ティア

Google は 2026年2月19日に Gemini 3.1 Pro Preview をリリースし、「最も複雑なタスクのための、より賢いモデル」と紹介しました。さらに「3.1 Pro は、単純な答えでは足りないタスク向けに設計されています」と説明しています。モデルカードによると、このモデルは Gemini 3 Pro がベースです。2026年3月9日以降、Google の API では gemini-3-pro-preview が gemini-3.1-pro-preview を指しています。

FAQ

Gemini 3.1 Pro API のよくある質問

Gemini 3.1 Pro Preview API の料金はいくらですか？

AnyAIGC では、gemini-3.1-pro-preview はトークン単位の段階料金です。プロンプトが200Kトークン以下の場合は、100万トークンあたり入力$0.1985、出力$1.1910、キャッシュヒット$0.0199です。200Kトークンを超える場合は、入力$0.3970、出力$1.7865、キャッシュヒット$0.0398です。Google の標準価格は$2.00 / $12.00 / $0.20と$4.00 / $18.00 / $0.40なので、AnyAIGC は Google の定価の約10%です。出力には思考トークンが含まれます。

200Kトークンを超えるプロンプトはどう課金されますか？

1回のリクエストのプロンプトが200Kトークンを超えると、そのリクエスト全体が上位ティアで課金されます。入力とキャッシュヒットは2倍、出力は1.5倍で、100万トークンあたり入力$0.3970、出力$1.7865、キャッシュヒット$0.0398になります。Google と同じティアの仕組みです。最新の料金はモデル一覧でご確認ください。

Gemini 3.1 Pro はまだプレビューですか？終了する予定はありますか？

はい、まだプレビューです。Google は2026年2月19日に Gemini 3.1 Pro Preview をリリースし、2026年10月時点でもモデルID gemini-3.1-pro-preview のパブリックプレビューのままです。Google の非推奨ページには「終了日は未発表」とあり、一般提供の開始日も公開されていません。プレビューの動作は変わる可能性があるため、安定したモデルが必要な新規プロジェクトには、一般提供中の Gemini 4 Argon をおすすめします。

コンテキスト長と最大出力はどれくらいですか？

Google の仕様では、入力上限は1,048,576トークン、1回のリクエストの最大出力は65,536トークン、知識のカットオフは2025年1月です。テキスト、画像、動画、音声、PDFを入力でき、出力はテキストです。

ネイティブの Gemini API と OpenAI互換エンドポイントのどちらを使うべきですか？

どちらでも使えます。ネイティブのエンドポイントは POST https://anyaigc.ai/v1beta/models/gemini-3.1-pro-preview:generateContent で、Google の Gemini API と同じリクエストボディを受け付けます。OpenAI互換のエンドポイントは POST https://anyaigc.ai/v1/chat/completions です。公式の OpenAI SDK の base_url を https://anyaigc.ai/v1 にして、model に gemini-3.1-pro-preview を指定してください。どちらも Authorization: Bearer を使います。

思考レベルはどう設定しますか？

Gemini 3.1 Pro は low、medium、high の3つの思考レベルに対応しています。デフォルトは high（動的な思考）で、minimal は非対応です。ネイティブAPIでは generationConfig.thinkingConfig.thinkingLevel を設定します。単純なタスクでは low を使うと、レイテンシと出力トークンを減らせます。

Gemini 3.1 Pro と Gemini 4 Argon はどちらを使うべきですか？

AnyAIGC ではどちらも入力は100万トークンあたり$0.1985ですが、Gemini 4 Argon は出力が安く（$0.9927 に対して $1.1910）、一般提供中です。3.1 Pro はまだプレビューです。新規プロジェクトは Gemini 4 Argon から始めるのがおすすめです。すでに 3.1 Pro 向けにプロンプトや評価を調整している場合は、そのまま使い、移行前に比較してください。大量処理やレイテンシが重要な用途には、Gemini 3.8 Flash（入力$0.0744、出力$0.3722）もご検討ください。

レート制限や同時実行数の制限はありますか？

AnyAIGC は gemini-3.1-pro-preview に同時実行数の上限を設けていません。すべてのアカウントでデフォルトで利用できるため、バッチ処理や並列のエージェントもそのまま動かせます。
