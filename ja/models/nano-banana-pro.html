Nano Banana Pro API をはじめる

  1. 登録：AnyAIGC のアカウントを作成します。新規アカウントには200万トークン分のお試しクレジットが付与され、チャージは$1から可能です。
  2. APIキーを作成：コンソールでキーを発行し、環境変数 ANYAIGC_API_KEY に保存します。
  3. リクエストを送信：POST https://anyaigc.ai/v1beta/models/gemini-3-pro-image:generateContent（Gemini ネイティブ形式）を呼び出します。すでに OpenAI SDK を使っているプロジェクトでは、model に gemini-3-pro-image を指定して /v1/chat/completions を使えます。

Nano Banana Pro では思考が常にオンで、オフにはできません。対応するアスペクト比は10種類のみで、1:4、4:1、1:8、8:1には対応していません。

認証には Authorization: Bearer <API Key> を使います。imageConfig.imageSize には 1K、2K、4K を指定でき、デフォルトは 1K です。response_format はプラットフォーム独自の拡張で、url を指定すると一時的な fileData.fileUri リンクが返ります（非ストリーミングのみ）。省略すると base64 で返ります。安全フィルタでリクエストがブロックされた場合、finishReason は SAFETY または PROHIBITED_CONTENT となり、画像は返りません。

仕様と選び方

Nano Banana Pro は Gemini 3 Pro Image のことで、Gemini 3 Pro をベースに Google が2025年11月20日にリリースしました。

複数の言語で正確に文字を描画でき、ローカライズ編集に加えて、カメラアングル、フォーカス、カラーグレーディング、ライティングも制御できます。

Nano Banana Pro API よくある質問

Nano Banana Pro API の料金はいくらですか？

AnyAIGC では Nano Banana Pro は1枚あたりの従量課金で、1枚あたり$0.0328からです（モデル一覧の最安値。2K・4Kの最新料金はモデル一覧に表示されます）。gemini-3-pro-image と gemini-3-pro-image-preview のどちらも利用できます。Google の定価は、1K / 2K / 4Kで1枚あたり$0.134 / $0.134 / $0.24です。

Nano Banana Pro はどのモデルですか？

Nano Banana Pro は、Google の Gemini 3 Pro Image の愛称です。プレビュー版は2025年11月20日に公開され、GA版の gemini-3-pro-image が2026年5月28日に続きました。描画の前に推論を行うため、複雑なレイアウト、文字の多い画像、商用レタッチ、現実世界の知識が必要なシーンに向いています。

Nano Banana Pro と Nano Banana 2.1 はどちらを使うべきですか？

複雑なレイアウト、文字の多い画像、複数キャラクターで一貫したシーン、プロ品質のディテールには Pro を選んでください。日常的な画像、バッチ処理、1:8や8:1の超ワイド比率には Nano Banana 2.1 を選んでください。料金も安く、1枚あたり$0.0128からです。

Nano Banana Pro は4Kに対応していますか？ アスペクト比は何が使えますか？

はい。imageConfig.imageSize には 1K、2K、4K を指定できます。2K・4Kの最新料金はモデル一覧で確認できます。imageConfig.aspectRatio は、1:1、2:3、3:2、3:4、4:3、4:5、5:4、9:16、16:9、21:9の10種類に対応しています。

参照画像は何枚までアップロードできますか？ キャラクターの一貫性は保てますか？

1リクエストあたり最大14枚の参照画像を指定できます。内訳は、オブジェクト画像が最大6枚、キャラクター画像が5枚、スタイル参照が3枚です。キャラクター画像を使うと、複数のカットにわたって同じ人物の一貫性を保てます。

同時実行数に制限はありますか？

AnyAIGC では Nano Banana Pro の同時実行数に上限を設けておらず、すべてのアカウントでデフォルトで適用されます。ベースURLは https://anyaigc.ai で、Google アカウントは不要です。同じキーで300以上の他のモデルも使えます。

AnyAIGC で請求書を発行できますか？

はい。実際にチャージした金額分の請求書を、コンソールでご自身で発行できます。

対応している支払い方法は何ですか？

WeChat Pay、Alipay、USDT、クレジットカードでチャージできます。残高は USD で、プラットフォーム上のすべてのモデルで使えます。チャージした金額分の請求書は、コンソールで発行できます。

新規ユーザー向けの無料トライアルはありますか？

はい。新規アカウントには200万トークン分のトライアル枠が付与されるので、チャージするかどうか決める前に試せます。チャージは $1 から可能です。

残高は返金できますか？

はい。未使用の残高は手数料なしで返金できます。返金をご希望の場合は、サポートにご連絡ください。

本物のモデルですか？データは安全ですか？

リクエストは公式のモデルチャネルに送られ、安価な代替モデルやリバースエンジニアリングによるモデルは使いません。法令で求められる場合を除き、プロンプトや出力を永続的に保存せず、学習にも使用しません。コンソールでは、リクエストごとのトークン数と料金を確認できます。

生成した画像は商用利用できますか？透かしは入りますか？

利用権とコンテンツポリシーは Google の公式規約に従います。Google は、Nano Banana が生成するすべての画像に、目に見えない SynthID のデジタル透かしを埋め込みます。画像上では確認できません。AnyAIGC は API アクセスを提供するだけで、出力の利用方法に追加の制限は設けていません。実在の人物の肖像や第三者の商標を含む画像については、必要な権利を確認してください。
