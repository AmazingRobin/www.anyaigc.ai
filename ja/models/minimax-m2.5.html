cURL
curl --request POST "https://anyaigc.ai/v1/chat/completions" \
  --header "Authorization: Bearer $ANYAIGC_API_KEY" \
  --header "Content-Type: application/json" \
  --data '{
  "model": "MiniMax-M2.5",
  "messages": [
    {
      "role": "user",
      "content": "Design three clear API endpoints for a to-do application."
    }
  ]
}'
Python
import json
import os
import urllib.request

payload = {
    "model": "MiniMax-M2.5",
    "messages": [
        {
            "role": "user",
            "content": "Design three clear API endpoints for a to-do application."
        }
    ]
}

request = urllib.request.Request(
    "https://anyaigc.ai/v1/chat/completions",
    data=json.dumps(payload, ensure_ascii=False).encode("utf-8"),
    headers={
        "Authorization": "Bearer " + os.environ["ANYAIGC_API_KEY"],
        "Content-Type": "application/json",
    },
    method="POST",
)
with urllib.request.urlopen(request, timeout=120) as response:
    result = json.load(response)

print(json.dumps(result, ensure_ascii=False, indent=2))

仕様

仕様と選び方

MiniMax は2026年2月12日に M2.5 をリリースし、コーディング、エージェントによるツール利用と検索、オフィス業務といった実務の生産性向上向けのモデルとして位置づけています。

MiniMax は、M2.5 の SWE-Bench Verified のスコアを80.2%と報告しています。

MiniMax は M2.5 を毎秒約50トークン（M2.5-Lightning は約100）と記載し、M2.1 よりタスクを37%速く完了できるとしています。

このページでは、入力$0.2025 / 100万トークン、出力$0.8100 / 100万トークン、5分キャッシュ書き込み$0.2531 / 100万トークン、1時間キャッシュ書き込み$0.4050 / 100万トークンと記載しており、上の料金表と一致しています。

minimax-m2.7 との比較：多くの複雑なスキルを実行し、スキルへの高い準拠性が求められるエージェント用途には M2.7 を選んでください。

仕様はベンダーの公式ドキュメント（minimax.io）に基づいています。このページの表は料金を示したもので、最新の料金はモデル一覧が正となります。

FAQ

MiniMax API のよくある質問

料金、エンドポイント、結果、法人向けの利用をまとめて確認できます。

MiniMax M2.5 API の料金はいくらですか？

入力$0.2025/100万トークン、出力$0.8100/100万トークン、5分キャッシュ書き込み$0.2531/100万トークン、1時間キャッシュ書き込み$0.4050/100万トークン。料金はすべて USD です。最新の料金はモデル一覧でご確認ください。モデル一覧では、ここに表示している料金が定価より32%安いと記載されています。最新の料金と割引はモデル一覧でご確認ください。

どのAPIエンドポイントを使えばよいですか？

https://anyaigc.ai の POST /v1/chat/completions を使い、APIキーは Authorization: Bearer で渡します。

MiniMax M2.5 は何に向いていますか？

コーディング、ツール呼び出し、検索、オフィス業務の自動化向けの M シリーズ言語モデルです。

1回のリクエストで何が返りますか。

1回のリクエストで1つのモデル応答が返ります。キャッシュパラメータの対応状況は、最新のAPIドキュメントをご確認ください。

同時実行数やRPMの制限はありますか？

AnyAIGC では MiniMax の同時実行数に上限がなく、固定の RPM 上限もありません。生成には時間がかかるため、タイムアウト、エラー処理、適切なリトライはアプリケーション側で設定してください。

生成したコンテンツは商用利用できますか。

モデルとその出力の商用利用は MiniMax の公式規約に従います。参照素材、音声、生成コンテンツについて必要な権利をお持ちであることをご確認ください。AnyAIGC は独立した API プロバイダーです。

AnyAIGC で請求書を発行できますか？

はい。実際にチャージした金額分の請求書を、コンソールでご自身で発行できます。

対応している支払い方法は何ですか？

WeChat Pay、Alipay、USDT、クレジットカードでチャージできます。残高は USD で、プラットフォーム上のすべてのモデルで使えます。チャージした金額分の請求書は、コンソールで発行できます。

新規ユーザー向けの無料トライアルはありますか？

はい。新規アカウントには500万トークン分のトライアル枠が付与されるので、チャージするかどうか決める前に試せます。チャージは $1 から可能です。

残高は返金できますか？

はい。未使用の残高は手数料なしで返金できます。返金をご希望の場合は、サポートにご連絡ください。

本物のモデルですか？データは安全ですか？

リクエストは公式のモデルチャネルに送られ、安価な代替モデルやリバースエンジニアリングによるモデルは使いません。法令で求められる場合を除き、プロンプトや出力を永続的に保存せず、学習にも使用しません。コンソールでは、リクエストごとのトークン数と料金を確認できます。
