3ステップで GPT-5.5 API を呼び出す

  1. 登録とチャージ：anyaigc.ai でアカウントを作成します。残高はすべてのモデルで共通です。
  2. APIキーを作成：コンソールでトークンを作成し、sk- で始まるキーをコピーして、環境変数 ANYAIGC_API_KEY に保存します。
  3. リクエストを送信：https://anyaigc.ai/v1/chat/completions または https://anyaigc.ai/v1/responses を、model に gpt-5.5 を指定し、Authorization: Bearer 認証で呼び出します。

ツール呼び出しは両方のエンドポイントで使えます。gpt-5.5 は /v1/chat/completions と /v1/responses のどちらでも関数呼び出しに対応しているため、既存の Chat Completions のコードもそのまま動きます。新規の連携、複数ステップのエージェント、Codex には Responses API を使い、強度は reasoning.effort で指定してください。Chat Completions では、トップレベルの reasoning_effort を使います。

すべてのパラメータは Chat Completions リファレンスと Responses リファレンスをご覧ください。フィールドは公式の OpenAI API と同じです。

Codex で GPT-5.5 を使う

コマンド1つで Codex CLI をインストールし、AnyAIGC の設定を書き込みます。~/.codex/ の2つのファイルを自分で編集することもできます。

ワンライン・インストーラーはすでにモデルを gpt-5.5 に設定しているため、インストール後に変更する必要はありません。後でモデルを切り替えるには、model を ~/.codex/config.toml で編集します。両方のファイルを保存し、プロジェクトのフォルダで codex を実行してください。Codex は Responses API を使います。手順とよくあるエラーは Codex 設定ガイドをご覧ください。

GPT-5.5 API のよくある質問

GPT-5.5 API の料金はいくらですか？

AnyAIGC では、gpt-5.5 はトークン単位で課金されます。入力は100万トークンあたり$0.2482、出力は$1.4890、キャッシュ入力は$0.0248です。OpenAI の定価は入力$5.00、出力$30.00、キャッシュ入力$0.50なので、AnyAIGC は定価の約5%（95%オフ）です。1回のリクエストの入力が272Kトークンを超える場合、そのリクエスト全体が入力2倍、出力1.5倍で課金されます。

GPT-5.5 のモデルIDは何ですか？

モデルIDは gpt-5.5 です。リクエストの model フィールドに指定してください。バージョンを固定したい場合は、OpenAI が公開している日付付きスナップショット gpt-5.5-2026-04-23 も使えます。

GPT-5.5 は非推奨ですか？いつまで使えますか？

いいえ。OpenAI は新しい GPT-5.6 と GPT-6 のファミリーを公開しましたが、API の gpt-5.5 に非推奨の通知はありません。OpenAI から提供終了日も発表されておらず、現在も問題なく呼び出せます。AnyAIGC では、コードを変更せずに gpt-5.5 を使い続けられます。新規プロジェクトには GPT-6.1 Sol もご検討ください。

gpt-5.5 で「model not found」と表示されます。何を確認すればよいですか？

次の3点を確認してください。model フィールドがちょうど gpt-5.5（小文字、ドット付き）であること。base_url が https://anyaigc.ai/v1 であること。リクエストヘッダーが Authorization: Bearer と AnyAIGC の APIキーであること。Codex では、model_provider が ~/.codex/config.toml で AnyAIGC を指していることを確認してください。それでも解決しない場合は、24/7 サポートにお問い合わせください。

GPT-5.5 から GPT-5.6 Sol や GPT-6.1 Sol に移行したほうがよいですか？

状況によります。プロンプトを調整済みで問題なく動いている連携は、gpt-5.5 のままで構いません。固定できるスナップショットもあります。OpenAI の GPT-5.6 リリース時の結果では、Terminal-Bench 2.1 で GPT-5.6 Sol が88.8%、GPT-5.5 が85.6%です。AnyAIGC では、GPT-5.6 Sol は GPT-5.5 と同じ価格（入力$0.2482、出力$1.4890）で、GPT-6.1 Sol は100万トークンあたり入力$0.0993、出力$0.4964とさらに安くなっています。新規プロジェクトでは、まず GPT-6.1 Sol をお試しください。

Chat Completions と Responses API のどちらを使えばよいですか？ツールは使えますか？

どちらのエンドポイントも使え、https://anyaigc.ai/v1/chat/completions と https://anyaigc.ai/v1/responses の両方で関数呼び出しに対応しています。既存の Chat Completions のコードはそのまま動きます。新規の連携、複数ステップのエージェント、Codex には Responses API を使い、強度は reasoning.effort に none、low、medium（デフォルト）、high、xhigh のいずれかで指定してください。

Codex で GPT-5.5 を使えますか？

はい。curl -fsSL https://www.anyaigc.ai/install.sh | bash -s codex を実行すると、インストールと設定ができます（Windows では irm https://www.anyaigc.ai/install.ps1 | iex）。インストーラーはすでにモデルを gpt-5.5 に設定しているので、すぐに使えます。自分で ~/.codex/config.toml を編集する場合は、base_url を https://anyaigc.ai/v1、wire_api を responses、model を gpt-5.5 に設定し、OPENAI_API_KEY を ~/.codex/auth.json に入れてください。

同時実行数やレート制限はありますか？

AnyAIGC は gpt-5.5 の同時実行数に上限を設けていません。すべてのアカウントで標準で利用できるため、バッチ処理や並列エージェントも待たされることなく実行できます。

AnyAIGC で請求書を発行できますか？
