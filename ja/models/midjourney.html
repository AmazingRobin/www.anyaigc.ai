Midjourney · Niji · 14の操作

Midjourney API

HTTPで Midjourney を呼び出せます。プロンプト1つで4枚のグリッドが返り、そこからアップスケール、バリエーション、ズームアウト、領域の部分修正に進めます。Imagine は1回$0.0595、アップスケールと Describe は$0.0298で、同時実行数の上限はありません。

  • Imagine 1回$0.0595
  • アップスケール 1回$0.0298
  • 操作数 14
  • 同時実行数 上限なし
  • 法人向け 請求書をセルフサービスで発行

#Midjourney API のしくみ

Web アプリや Discord と同じ流れです。4枚のグリッドを生成し、その結果に表示されるボタンを押します。API はすべてのボタンを返すので、実行したいボタンの customId を送り返してください。

  1. 01

    POST/mj/submit/imagine

    プロンプトを送信

    タスクIDを返します。--ar、--v、--niji はプロンプトにそのまま書けます。1回$0.0595

  2. 02

    GET/mj/task/{id}/fetch

    タスクを取得

    SUCCESS になるまでポーリングすると、imageUrl と buttons のリストが得られます。取得は無料です

  3. 03

    POST/mj/submit/action

    ボタンを押す

    taskId とボタンの customId を送ります：アップスケールは$0.0298、バリエーション、ズーム、パンは$0.0595

  4. 04

    POST/mj/submit/modal

    モーダルを確定

    バリエーション（領域）とカスタムズームは、マスクまたは新しいプロンプトを送る2段階目が必要です。1回$0.0595

#Midjourney API でできること

  • Imagine（画像生成）

    プロンプト1つで4つの候補が返り、base64Array で画像プロンプトも指定できます。Midjourney は、写真風でもイラストでも、光、質感、構図の表現で知られています。

  • アニメ・イラスト向けの Niji

    botType を NIJI_JOURNEY にすると Niji に切り替わり、アニメ、マンガ、イラスト調のスタイルを生成できます。

  • バリエーション

    V1-V4 は1枚の画像から派生させます。バリエーション（強め）は大きく変化し、バリエーション（控えめ）は少しだけ変化します。

  • アップスケール

    U1-U4 で1枚を取り出し、Subtle または Creative のアップスケールで仕上げます。

  • ズームアウトとパン

    フレームを1.5倍または2倍に広げたり、一方向に拡張したりできます。たとえば縦長の画像を横長にできます。

  • ブレンドと Describe

    2-5枚の画像を合成して新しい1枚にしたり、画像を送ってその内容を説明する4つのプロンプトを得たりできます。

#Midjourney コミュニティから

Midjourney Explore の人気画像から選んだものです。キャプションは、Midjourney の表現の幅を示すために各作者のプロンプトを要約したものです。実際の結果は、プロンプト全文、モデルバージョン、パラメータによって変わります。

#AnyAIGC 経由で Midjourney を呼び出す理由

  • Discord アカウント不要

    Midjourney は現在、公開APIを提供していません。AnyAIGC のキーがあれば、アカウントやチャンネルを自分で管理せずに、HTTP で呼び出せます。

  • 同時実行数の上限なし

    どのアカウントにも同時実行数の上限がないため、クォータの引き上げを申請せずに、バッチ処理を並列で実行できます。

  • 1回ごとの従量課金

    月額プランはありません。Imagine は$0.0595、アップスケールは$0.0298で、使った分だけお支払いいただきます。

  • 1つのキーで300以上のモデル

    同じキーと残高で、GPT Image、Nano Banana、Seedream などの画像モデルも使えるので、並べて比較できます。

#Midjourney API を始める

  1. AnyAIGC に登録します。新規アカウントには200万トークンの無料枠があり、チャージは$1から可能です。
  2. コンソールでAPIキーを作成し、ANYAIGC_API_KEY として保存します。
  3. プロンプトを付けて POST https://anyaigc.ai/mj/submit/imagine を呼び出し、返されたタスクIDで /mj/task/{id}/fetch をポーリングします。

認証は Authorization: Bearer <API Key> で行います。送信系のエンドポイントは {"code": 1, "result": "task ID"} を返し、取得エンドポイントは status、progress、imageUrl、buttons などを返します。すべてのフィールドは AnyAIGC の Midjourney API ドキュメントをご覧ください。

#Midjourney API のよくある質問

Midjourney API の料金はいくらですか？

AnyAIGC では Midjourney を1回ごとに課金します。Imagine、ブレンド、バリエーション、再生成、ズーム、パン、モーダルは各$0.0595、アップスケールと Describe は$0.0298、画像のアップロードは$0.000595で、カスタムズームとバリエーション（領域）は無料です（モーダルの手順がモーダルとして課金されます）。タスクの取得は無料で、最新の料金はモデル一覧でご確認いただけます。

Midjourney に公式APIはありますか？

Midjourney は現在、公開APIを提供しておらず、Web サイトと Discord 上で動作しています。AnyAIGC は Midjourney のサービスを HTTP エンドポイントとしてラップしています。そのため、画像は代替モデルではなく Midjourney 自身のモデル（Niji を含む）で生成され、自分の Discord アカウントがなくても、1つのAPIキーで Imagine、アップスケール、バリエーション、ズームなどを実行できます。

14の操作とは何で、どのエンドポイントを使いますか？

14のモデル名は Midjourney の14の操作に対応しており、すべて上の料金表に載っています。Imagine、ブレンド、Describe にはそれぞれ専用のエンドポイントがあります。アップスケール、バリエーション、バリエーション（強め/控えめ）、再生成、ズーム、パン、カスタムズーム、バリエーション（領域）は、いずれも /mj/submit/action を使い、ボタンの customId で操作を選びます。モーダルは確認のための手順で、アップロードは参考画像の送信に使います。

対応している Midjourney のバージョンは？Niji は使えますか？

バージョンは、プロンプトの末尾に --v パラメータを付けて指定します（APIドキュメントでは --v 6.1 を使用）。公式アプリと同じ書き方で、そのまま Midjourney に渡されます。アニメ向けの Niji モデルを使うには、botType を NIJI_JOURNEY に設定してください。デフォルトは MID_JOURNEY です。

1回の呼び出しで何枚の画像が返りますか？

Imagine、バリエーション、再生成、ズーム、パンなどは4つの候補のグリッドを返し、課金は1回分です。高解像度の画像を1枚だけ得るには、そのうちの1枚にアップスケールを実行します。

アップスケールやバリエーションはどう実行しますか？

/mj/task/{id}/fetch でタスクを取得します。buttons の各項目には customId があるので、タスクIDとその customId を /mj/submit/action に送信してください。customId は自分で組み立てず、必ずレスポンスの値を使ってください。

同時実行数の制限はありますか？

ありません。AnyAIGC は Midjourney に対して、どのアカウントにも同時実行数の上限を設けていないので、タスクを並列で送信できます。すべてのリクエストはベースURL https://anyaigc.ai に送信し、同じキーで300以上のほかのモデルも使えます。

AnyAIGC で請求書を発行できますか？

はい。実際にチャージした金額分の請求書を、コンソールでご自身で発行できます。

対応している支払い方法は何ですか？

WeChat Pay、Alipay、USDT、クレジットカードでチャージできます。残高は USD で、プラットフォーム上のすべてのモデルで使えます。チャージした金額分の請求書は、コンソールで発行できます。

新規ユーザー向けの無料トライアルはありますか？

はい。新規アカウントには200万トークン分のトライアル枠が付与されるので、チャージするかどうか決める前に試せます。チャージは $1 から可能です。

残高は返金できますか？

はい。未使用の残高は手数料なしで返金できます。返金をご希望の場合は、サポートにご連絡ください。

本物のモデルですか？データは安全ですか？

リクエストは公式のモデルチャネルに送られ、安価な代替モデルやリバースエンジニアリングによるモデルは使いません。法令で求められる場合を除き、プロンプトや出力を永続的に保存せず、学習にも使用しません。コンソールでは、リクエストごとのトークン数と料金を確認できます。

生成した画像は商用利用できますか？

利用権とコンテンツポリシーは Midjourney の公式規約に従います。AnyAIGC はAPIアクセスを提供するのみで、出力の使い方に追加の制限は設けていません。
