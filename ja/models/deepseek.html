クイックスタート

DeepSeek APIを3ステップで始める

  1. 登録とチャージ：anyaigc.ai でアカウントを作成します。$1からチャージでき、残高はプラットフォーム上のすべてのモデルで使えます。
  2. APIキーの作成：コンソールでキーを作成し、sk- で始まるキーをコピーして、環境変数 ANYAIGC_API_KEY に保存します。
  3. リクエストの送信：POST https://anyaigc.ai/v1/chat/completions を呼び出し、model に deepseek-v4.1-flash を指定して、Authorization: Bearer ヘッダーを付けます。OpenAI SDKなら、base_url を https://anyaigc.ai/v1 に設定するだけです。

パラメータ: DeepSeek によると、V4 シリーズはデフォルトで思考します。リクエストボディの thinking フィールドでオン/オフを切り替え（{"type": "enabled"} または {"type": "disabled"}）、reasoning_effort で思考の深さを指定します（公式では low / high / max）。思考トークンは出力トークンとして計算され、usage.completion_tokens_details.reasoning_tokens に表示されます。temperature などのサンプリングパラメータは、思考モードでは効果がありません。

すべてのパラメータは Chat Completions API リファレンスをご覧ください。ドキュメントのサンプルにあるモデル名を、使いたい DeepSeek のモデルID に置き換えてください。

Claude Code

Claude Code で DeepSeek を使う

Claude Code の接続先を DeepSeek に切り替えます。設定ファイルをひとつ編集するだけで、ターミナルのコーディングエージェントが DeepSeek V4.1 Flash で動き、トークン単位で課金されます。

  1. Claude Code をインストール: 公式インストーラーを使います。macOS または Linux の場合は、たとえば curl -fsSL https://claude.ai/install.sh | bash です。
  2. 設定を追加: ~/.claude/settings.json を編集し、下の env ブロックを追加して、ANTHROPIC_AUTH_TOKEN を AnyAIGC で作成したキーに置き換えます。
  3. コーディングを開始: プロジェクトのフォルダで claude を実行します。/model と入力し、現在のモデルが deepseek-v4.1-flash であることを確認してください。

モデルの切り替え: V4 Pro を使う場合は、設定の deepseek-v4.1-flash を deepseek-v4-pro に置き換えます。軽量なサブタスク用に、ANTHROPIC_DEFAULT_HAIKU_MODEL を V4.1 Flash のままにしておくこともできます。

詳しい手順とよくあるエラーは Claude Code 設定ガイドをご覧ください。ガイド内のモデル名は deepseek-v4.1-flash に置き換えてください。

FAQ

DeepSeek API のよくある質問

DeepSeek API の料金はいくらですか？

AnyAIGC の DeepSeek はトークン単位で課金されます。100万トークンあたり、deepseek-v4.1-flash は入力 $0.1215、出力 $0.4860、キャッシュヒット $0.0024、deepseek-v4-pro は入力 $0.5346、出力 $1.6038、キャッシュヒット $0.0178 です。deepseek-v4-flash は V4.1 Flash と同額です。リアルタイムの価格はモデル一覧でご確認ください。

AnyAIGC にピーク／オフピーク料金はありますか？

いいえ。DeepSeek 公式 API は時間帯別料金で、平日の UTC 01:00–04:00 と 06:00–10:00（北京時間 9:00–12:00 と 14:00–18:00）がピーク時間で、ピーク時の価格はオフピークの2倍です。AnyAIGC では、すべての DeepSeek モデルが終日同じ料金で課金されます。この料金は公式のピーク価格より約60%お得です。リアルタイムの価格はモデル一覧でご確認ください。

AnyAIGC で使える DeepSeek モデルとモデルID を教えてください。

このページでは三つのモデルを扱います。deepseek-v4.1-flash（DeepSeek 最新の Flash モデルで、ネイティブ画像入力に対応）、deepseek-v4-pro（1.6T パラメータの V4 フラッグシップ）、deepseek-v4-flash（V4 プレビュー版の Flash モデルで、DeepSeek により V4.1 Flash に置き換えられました）です。モデルID はリクエストボディの model フィールドに指定します。モデルの切り替えは、このフィールドを変えるだけです。

V4.1 Flash と V4 Pro のどちらを使うべきですか？

ほとんどの用途では、まず V4.1 Flash をおすすめします。DeepSeek によると、性能、コスト、速度、タスク全体の所要時間のいずれでも V4 Pro を上回っており、入力価格は V4 Pro の約4分の1で、画像も読み取れます。すでに V4 Pro を本番環境で調整済みの場合は、引き続き V4 Pro を使えます。DeepSeek は、2026年9月14日以降も V4 Pro API の提供を続けると述べています。

コンテキスト長はどれくらいですか？画像は送れますか？

DeepSeek は、V4.1 Flash と V4 Pro のどちらも 1M トークンのコンテキスト長と最大 384K の出力トークンと記載しています。画像を受け付けるのは V4.1 Flash だけで、V4 Pro と V4 Flash はテキスト専用です。

DeepSeek API は OpenAI 互換ですか？

はい。三つのモデルすべてが POST https://anyaigc.ai/v1/chat/completions を使い、リクエストとレスポンスの形式は OpenAI Chat Completions と同じです。公式の OpenAI SDK では、base_url を https://anyaigc.ai/v1 に設定してください。Anthropic 形式にも対応しているため、Claude Code も使えます。

Claude Code で DeepSeek を使えますか？

はい。AnyAIGC の DeepSeek モデルは、OpenAI 形式と Anthropic 形式の API の両方に対応しています。~/.claude/settings.json の env ブロックで、ANTHROPIC_BASE_URL を https://anyaigc.ai、ANTHROPIC_AUTH_TOKEN を APIキー、ANTHROPIC_MODEL を deepseek-v4.1-flash に設定し、claude を実行します。料金はトークン単位です。

同時実行数やレート制限はありますか？

AnyAIGC では DeepSeek シリーズの同時実行数に上限を設けておらず、すべてのユーザーにデフォルトで適用されます。バッチ処理、CI パイプライン、並列エージェントに向いています。

DeepSeek の APIキーはどうすれば取得できますか？

anyaigc.ai で登録し、残高をチャージして、コンソールで APIキーを作成します。同じキーで、すべての DeepSeek モデルとプラットフォーム上の 300+ のモデルを利用できるため、DeepSeek Platform の別アカウントは不要です。

AnyAIGC で請求書を発行できますか？

はい。実際にチャージした金額分の請求書を、コンソールでご自身で発行できます。

対応している支払い方法は何ですか？

WeChat Pay、Alipay、USDT、クレジットカードでチャージできます。残高は USD で、プラットフォーム上のすべてのモデルで使えます。チャージした金額分の請求書は、コンソールで発行できます。

新規ユーザー向けの無料トライアルはありますか？

はい。新規アカウントには200万トークン分のトライアル枠が付与されるので、チャージするかどうか決める前に試せます。チャージは $1 から可能です。

残高は返金できますか？

はい。未使用の残高は手数料なしで返金できます。返金をご希望の場合は、サポートにご連絡ください。

本物のモデルですか？データは安全ですか？

リクエストは公式のモデルチャネルに送られ、安価な代替モデルやリバースエンジニアリングによるモデルは使いません。法令で求められる場合を除き、プロンプトや出力を永続的に保存せず、学習にも使用しません。コンソールでは、リクエストごとのトークン数と料金を確認できます。
