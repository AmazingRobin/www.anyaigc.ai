Seedream 5.5 とは

Seedream 5.5 は ByteDance Seed チームのマルチモーダル画像生成モデルで、公式には創造性と精密な実行をともに高めたモデルとされています。テキストから画像、1枚の画像、複数の参照画像による生成に対応し、マルチターン編集の一貫性、ネイティブのRGBA画像生成、レイヤー分離を強化しています。

AnyAIGC でのモデルIDは doubao-seedream-5-5-261028 で、OpenAI互換の /v1/images/generations から利用できます。出力解像度による区分課金で、1K / 1.5K は1枚あたり$0.0229から、入力画像は別途課金されます。Volcano Engine のアカウントや本人確認は不要です。

Seedream 5.5 でできること

この4つの機能は ByteDance Seed の公式モデルページと Volcano Engine Ark のドキュメントに基づいています。

  • 一貫性のあるマルチターン編集

    1枚の画像を複数ラウンドにわたって修正しても、変更されるのは指定した箇所だけです。公式ページによると、編集領域の外のピクセルはそのまま保てます。

  • ネイティブのRGBA透過

    透過・半透過の背景をネイティブでサポートしているため、手動で切り抜かなくても、テキストや参照画像からRGBA画像を生成できます。

  • レイヤー分離

    1枚の画像をベース画像と最大99レイヤーに分割し、差し替え、移動、再配置ができます。ベース画像と各レイヤーは1枚ごとに課金されます。

  • 通常テキスト向けのリッチテキストOCR

    通常のテキストレイヤーでは、テキストとその位置、およその見た目のスタイルを返します。装飾文字や手書き文字は何も返しません。

Seedream 5.5 API を使い始める

  1. AnyAIGC に登録してください。新規アカウントには200万トークンの無料枠が付与され、$1からチャージできます。
  2. コンソールで APIキーを作成し、環境変数 ANYAIGC_API_KEY に保存します。
  3. POST https://anyaigc.ai/v1/images/generations（OpenAI互換）にリクエストを送り、model には doubao-seedream-5-5-261028 を指定します。

5.5 は1回のリクエストで1枚を返し、画像セット（sequential_image_generation）、Web検索、ストリーミングには対応していません。画像セットが必要な場合は model を doubao-seedream-5-0-260128（5.0 lite）に変更してください。

認証には Authorization: Bearer <API Key> を使います。レスポンスは {"created": ..., "data": [{"url": ...}]} の形式で、response_format を b64_json にすると base64 で受け取れます。watermark のデフォルトは true なので、透かしなしの画像が必要な場合は明示的に false を渡してください。フィールドの詳細は AnyAIGC Seedream APIドキュメントをご覧ください。

Seedream 5.5 API のよくある質問

Seedream 5.5 API の料金はいくらですか？

AnyAIGC では、Seedream 5.5（doubao-seedream-5-5-261028）は出力画像1枚あたりのピクセル数による区分課金です：1K / 1.5K（2,601,123 ピクセル以下）は$0.0229 / 枚、2K（2,601,124 ～ 4,624,220 ピクセル）は$0.0402 / 枚で、size を省略すると 2K で課金されます。入力画像（各参照画像、または分割したい元画像）は$0.00918 / 枚です。レイヤー分離では、ベース画像とすべてのレイヤーが1枚ごとに課金されます。課金は生成に成功した分のみで、最新の料金はモデル一覧で確認できます。

Seedream 5.5 とは何ですか？

Seedream 5.5 は ByteDance Seed チームのマルチモーダル画像生成モデルで、公式には創造性と精密な実行をともに高めたモデルとされています。テキストから画像、1枚の画像、複数の参照画像による生成に対応し、マルチターン編集の一貫性、ネイティブのRGBA画像生成、レイヤー分離を強化しています。

対応している解像度は？4K出力はできますか？

4Kには対応していません。Volcano Engine Ark のドキュメントによると、5.5 の画像生成では size に 1K、1.5K、2K（デフォルトは2K）を指定でき、または幅 x 高さのピクセル寸法で、合計 921,600（1280x720）から 4,624,220 ピクセル、アスペクト比は1:16から16:1までです。4Kが必要な場合は Seedream 5.0 lite または 4.5 を使ってください。

参照画像は何枚まで送れますか？画像セットには対応していますか？

image には、編集や複数画像の合成用に最大10枚の参照画像を指定でき、1枚ごとに入力画像として課金されます。5.5 は1回のリクエストで1枚を返し、画像セット、Web検索、ストリーミングには対応していません。画像セットには 5.0 lite、4.5、4.0 を使ってください。

レイヤー分離とRGBA出力で何ができますか？

レイヤー分離は1枚の画像をベース画像と最大99レイヤーに分割します。通常のテキストレイヤーでは、テキストとその位置、およその見た目のスタイル（リッチテキストOCR）を返せます。装飾文字や手書き文字は何も返しません。5.5 は透過・半透過の背景もネイティブでサポートしているため、RGBA画像を直接出力できます。これらの機能のリクエストフィールドは公式ドキュメントと AnyAIGC の API ドキュメントに従います。組み込む前にサポートに確認してください。

5.5 と 5.0 Pro のどちらを選ぶべきですか？

5.5 はより低い料金から始まり（1枚あたり$0.0229から、5.0 Pro は$0.0441）、最大99レイヤーを分離でき、テキストからRGBA画像を生成できます。5.0 Pro は最大16レイヤーまで分離でき、テキストだけではRGBAを生成しません。どちらも上限は2Kで、参照画像は最大10枚、画像セットはありません。その他の強みは Seedream 5.0 Pro をご覧ください。

同時実行数の上限はありますか？登録に必要なものは？

AnyAIGC は Seedream 5.5 に同時実行数の上限を設けておらず、すべてのアカウントがデフォルトで利用できます。ベースURLは https://anyaigc.ai です。Volcano Engine のアカウントや本人確認は不要で、同じキーでプラットフォーム上の他の300以上のモデルも利用できます。

AnyAIGC で請求書を発行できますか？

はい。実際にチャージした金額分の請求書を、コンソールでご自身で発行できます。

対応している支払い方法は何ですか？

WeChat Pay、Alipay、USDT、クレジットカードでチャージできます。残高は USD で、プラットフォーム上のすべてのモデルで使えます。チャージした金額分の請求書は、コンソールで発行できます。

新規ユーザー向けの無料トライアルはありますか？

はい。新規アカウントには200万トークン分のトライアル枠が付与されるので、チャージするかどうか決める前に試せます。チャージは $1 から可能です。

残高は返金できますか？

はい。未使用の残高は手数料なしで返金できます。返金をご希望の場合は、サポートにご連絡ください。

本物のモデルですか？データは安全ですか？

リクエストは公式のモデルチャネルに送られ、安価な代替モデルやリバースエンジニアリングによるモデルは使いません。法令で求められる場合を除き、プロンプトや出力を永続的に保存せず、学習にも使用しません。コンソールでは、リクエストごとのトークン数と料金を確認できます。

商用利用はできますか？透かしは消せますか？

利用権とコンテンツポリシーは、ByteDance / Volcano Engine の公式規約に従います。リクエストで watermark を false にすると、右下に「AI生成」の表示は付きません。AnyAIGC は API アクセスを提供するだけで、出力の利用方法に追加の制限は設けていません。実在の人物の肖像やブランドロゴなどについては、必要な権利を確認してください。
