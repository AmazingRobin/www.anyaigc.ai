doubao-seed-2-1-pro API を組み込む

  1. AnyAIGC のアカウントを作成すると、200万トークンの無料トライアルから始められます。
  2. コンソールでキーを作成し、ANYAIGC_API_KEY として保存します。
  3. POST /v1/chat/completions にチャットリクエストを送り、JSON レスポンスから返信を読み取ります。

デフォルトの例は最新のスナップショットを使っています。「旧版」タブを選ぶと、1つ前のスナップショット用の完全なコードを表示できます。概要は最新バージョンについて説明しています。

Python の例は標準ライブラリを使っています。SDK の例には openai をインストールしてください。これらのストリーミングなしの呼び出しは choices と usage を返します。ほかのフィールドは Chat Completions リファレンスをご覧ください。

仕様と選び方

Volcengine Ark は2026年6月に doubao-seed-2-1-pro-260628 をリリースしました。コーディングとエージェント向けの新しいフラッグシップで、コーディングの成果物、複数ステップにわたる長いエージェントタスク、マルチモーダル理解が強化されています。

doubao-seed-2-1-pro-260915 バージョン（2026年9月）は、コンテキスト長1024K、最大出力256K、最大推論256Kです。260628 バージョンのコンテキスト長は256Kです。

どちらのバージョンも、ディープシンキング、マルチモーダル理解、GUIタスク、ツール呼び出し、構造化出力に対応しています。

このページでは、入力は100万トークンあたり$0.9113、出力は$4.5560、キャッシュヒットは$0.1823と掲載しており、上の料金表と一致しています。

doubao-seed-2-1-turbo との比較：コストとレイテンシを最優先する大量処理の本番運用で、コンテキスト長256Kで足りる場合は Seed 2.1 Turbo を選んでください。

仕様はベンダーの公式ドキュメント（docs.volcengine.com）に基づいています。このページの表は料金を示したもので、最新の料金はモデル一覧が正となります。

doubao-seed-2-1-pro API のよくある質問

doubao-seed-2-1-pro API の料金はいくらですか？

入力は100万トークンあたり$0.9113から、出力は$4.5560からです。表には公開されているすべてのティアと、該当するキャッシュと音声の料金を掲載しています。最新の料金はモデル一覧で確認してください。

どのように組み込めばよいですか？呼び出しは何を返しますか？

model と messages を指定して POST /v1/chat/completions を呼び出します。これらのストリーミングなしの例は JSON を返し、返信は choices[0].message.content、トークン使用量は usage から読み取れます。APIリファレンスをご覧ください。

同時実行数の制限はありますか？

AnyAIGC では、この Doubao Seed ファミリーの同時実行数に上限を設けていません。

このモデルは、どのような用途向けですか？

複数の段階にまたがる複雑なエージェント作業向けに作られています。非同期のサブタスクを調整・レビューし、画像、動画、ページの内容を推論と行動に活かして、リサーチやオフィス業務のワークフローで使えます。

デフォルトで使われるバージョンはどれですか？古いバージョンも使えますか？

概要とデフォルトのコード例には、モデル一覧に掲載されている最新のスナップショットを使用しています。クイックスタートには、既存の連携向けに旧版のコード例も載せています。機能はスナップショットによって異なる場合があります。掲載の料金は確認時点で一致していました。

出力を商用利用できますか？

AnyAIGC で請求書を発行できますか？

はい。実際にチャージした金額分の請求書を、コンソールでご自身で発行できます。

対応している支払い方法は何ですか？

WeChat Pay、Alipay、USDT、クレジットカードでチャージできます。残高は USD で、プラットフォーム上のすべてのモデルで使えます。チャージした金額分の請求書は、コンソールで発行できます。

新規ユーザー向けの無料トライアルはありますか？

はい。新規アカウントには200万トークン分のトライアル枠が付与されるので、チャージするかどうか決める前に試せます。チャージは $1 から可能です。

残高は返金できますか？

はい。未使用の残高は手数料なしで返金できます。返金をご希望の場合は、サポートにご連絡ください。

本物のモデルですか？データは安全ですか？
