機能

動画も画像も、1つのキーで

Vidu の生成機能を、プロダクトやパイプラインにそのまま組み込めます。

01

テキストから動画

Q3 Pro、Q3 Turbo、Q2 はテキストから直接動画を生成します。

02

画像と最初・最後のフレーム

Q4、Q3、Q2 Pro/Turbo は最初のフレームから動画を生成します。Q3 と Q2 Pro/Turbo は最後のフレームも指定できます。

03

参照から動画

Q4 Preview、Q2、Q2 Pro では、複数の画像や被写体を参照して、キャラクターの一貫性を保てます。

04

ネイティブ音声

Q4 Preview と Q3 はデフォルトで音声を生成し、Q2 はタスクごとにネイティブ音声を追加できます。

05

540pから4K

Q4 Preview は4K、Q3 と Q2 は1080pまで対応し、1秒あたりで課金されます。

06

画像生成

Q2 Image はテキストから画像と、1–7枚の参照画像を使った生成に対応し、最大4Kです。

Python
import json
import os
import time
import urllib.request

BASE = "https://anyaigc.ai"
HEADERS = {
    "Authorization": "Bearer " + os.environ["ANYAIGC_API_KEY"],
    "Content-Type": "application/json",
}


def call(method, path, body=None):
    data = json.dumps(body, ensure_ascii=False).encode("utf-8") if body else None
    request = urllib.request.Request(BASE + path, data=data, headers=HEADERS, method=method)
    with urllib.request.urlopen(request, timeout=60) as response:
        return json.load(response)


payload = {
    "model": "viduq3-turbo",
    "prompt": "A red fox crosses thin ice on a mountain lake at dawn; low tracking shot, its breath drifting in the sunlight.",
    "duration": 5,
    "resolution": "540p",
    "aspect_ratio": "16:9"
}

created = call("POST", "/ent/v2/text2video", payload)
task_id = (created.get("data") or created)["task_id"]
print("task_id:", task_id)

# Poll every 10 seconds until the task leaves the queue
for _ in range(120):
    result = call("GET", f"/ent/v2/tasks/{task_id}/creations")
    state = (result.get("data") or result).get("state") or (result.get("data") or result).get("status")
    if state not in ("created", "queueing", "processing"):
        break
    time.sleep(10)

# creations holds the video or image URLs; they expire, so download promptly
print(json.dumps(result, ensure_ascii=False, indent=2))

サンプル画像をご自身の URL または Base64（png、jpeg、webp、最大50 MB）に置き換えてください。status フィールドは実際のレスポンスで確認してください。サンプルでは、タスクが created、queueing、processing のいずれでもなくなった時点でポーリングを終了します。

FAQ

Vidu API のよくある質問

料金、エンドポイント、結果、法人向けの利用をまとめて確認できます。

Vidu API の最低料金はいくらですか？

動画は Q2 Turbo 540p の最初の1秒 $0.0223 から（以降は+$0.00744/秒）です。Q3 Turbo 540p は$0.0298/秒、Q4 Preview 540p は$0.0486/秒、Q2 Image のテキストから画像（1080p）は1枚あたり$0.0298です。料金は USD 表記です。最新の料金はモデル一覧で確認してください。

7つのモデルはどう選べばよいですか？

2K/4K が必要な場合や最新モデルを使いたい場合は Q4 Preview、音声の同期とスマートなショット切り替えが必要なら Q3 Pro、速度重視なら Q3 Turbo を選びます。予算を抑えた画像から動画や最初・最後のフレームの生成には Q2 Turbo、より高い画質には Q2 Pro、テキストから動画と複数画像を使う参照から動画には Q2、静止画には Q2 Image を選びます。

モデルごとにエンドポイントは共通ですか？

エンドポイントはタスクの種類で決まります：/ent/v2/text2video、/ent/v2/img2video、/ent/v2/start-end2video、/ent/v2/reference2video、/ent/v2/reference2image。モデルは model フィールドで指定し、結果はすべて GET /ent/v2/tasks/{id}/creations で取得します。

結果はどのように取得しますか？

すべてのタスクは非同期です。作成すると task_id が返るので、クエリ用エンドポイントをポーリングして creations から動画または画像の URL を読み取ります。callback_url を渡してコールバックを受け取ることもできます。

同時実行数やRPMの制限はありますか？

AnyAIGC の Vidu は、すべてのアカウントでデフォルトで同時実行数の上限がなく、固定の RPM 制限もありません。動画生成には時間がかかるため、アプリケーション側でポーリング間隔とタイムアウトを設定してください。

出力は商用利用できますか？

商用利用は Vidu（ShengShu Technology）の公式規約に従います。アップロードする参照画像、人物、ブランド素材については、ご自身に権利が必要です。AnyAIGC は独立した API プロバイダーです。

AnyAIGC で請求書を発行できますか？

はい。実際にチャージした金額分の請求書を、コンソールでご自身で発行できます。

対応している支払い方法は何ですか？

WeChat Pay、Alipay、USDT、クレジットカードでチャージできます。残高は USD で、プラットフォーム上のすべてのモデルで使えます。チャージした金額分の請求書は、コンソールで発行できます。

新規ユーザー向けの無料トライアルはありますか？

はい。新規アカウントには500万トークン分のトライアル枠が付与されるので、チャージするかどうか決める前に試せます。チャージは $1 から可能です。

残高は返金できますか？

はい。未使用の残高は手数料なしで返金できます。返金をご希望の場合は、サポートにご連絡ください。

本物のモデルですか？データは安全ですか？

リクエストは公式のモデルチャネルに送られ、安価な代替モデルやリバースエンジニアリングによるモデルは使いません。法令で求められる場合を除き、プロンプトや出力を永続的に保存せず、学習にも使用しません。コンソールでは、リクエストごとのトークン数と料金を確認できます。
