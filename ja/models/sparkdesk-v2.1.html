SparkDesk-v2.1 は、iFLYTEK の Spark 認知モデルの初期2.x API リリースです。モデル一覧では、分野をまたぐ知識と言語理解を備え、自然な会話でタスクをこなすモデルとされており、言語理解、ナレッジ Q&A、論理推論、数学の問題解決、コード理解に対応します。

現行の iFLYTEK Open Platform のバージョン表にはこのティアが掲載されていないため、出典のない数値を載せず、このページでは公式のコンテキスト長、最大出力、機能の制限を記載していません。AnyAIGC の3モデルの中で最も低価格で、すでにこのモデルを使っているワークロードや、品質をそれほど問わない低コストのタスクに向いています。

AnyAIGC では、SparkDesk-v2.1 は OpenAI 互換の /v1/chat/completions エンドポイントを Bearer キー1つで利用できます。新規プロジェクトでは、まず SparkDesk-v3.1 または SparkDesk-v3.5 を評価してください。課金はトークン単位で、同時実行数の上限はありません。

クイックスタート

3ステップで SparkDesk-v2.1 API を呼び出す

  1. 登録とチャージ：anyaigc.ai でアカウントを作成します。チャージは$1からで、残高はプラットフォームのすべてのモデルで共通して使えます。
  2. APIキーを作成：コンソールでトークンを作成し、sk- で始まるキーをコピーして、環境変数 ANYAIGC_API_KEY に保存します。
  3. リクエストを送信：POST https://anyaigc.ai/v1/chat/completions を呼び出し、model に SparkDesk-v2.1 を指定して Authorization: Bearer を付けます。OpenAI SDK を使う場合は、base_url を https://anyaigc.ai/v1 に設定するだけです。

パラメータのヒント：モデルIDは大文字小文字を区別するため、SparkDesk-v2.1 と書いてください。レスポンス形式は OpenAI Chat Completions と同じで、リクエストのトークン数は usage フィールドで確認できます。コンテキスト長には上限があるため、長いドキュメントは分割するか、検索で必要な部分に絞ってから渡してください。

すべてのパラメータは Chat Completions のリファレンスをご覧ください。サンプルのモデル名は、SparkDesk のモデルIDに置き換えてください。

FAQ

SparkDesk-v2.1 API のよくある質問

SparkDesk-v2.1 API の料金はいくらですか？

AnyAIGC では、SparkDesk-v2.1 はトークン単位の従量課金で、入力100万トークンあたり$8.7360、出力100万トークンあたり$8.7360と、どちらも同じ価格です。価格は固定で、サブスクリプションや月額料金はありません。最新の料金はモデル一覧でご確認ください。

SparkDesk-v2.1 のモデルIDは何で、iFLYTEK Spark とはどういう関係ですか？

モデルIDは SparkDesk-v2.1（大文字小文字を区別）です。iFLYTEK の Spark 認知モデルのリリースの1つで、AnyAIGC が OpenAI 互換の API として提供しています。Apache Spark や、メールアプリの Spark とは関係ありません。

SparkDesk-v2.1 と他の SparkDesk モデルはどう選べばよいですか？

このシリーズの他の2モデルは SparkDesk-v3.5 と SparkDesk-v3.1 です。バージョン番号が大きいほど新しい iFLYTEK のティアに対応し、v3.5 は Max、v3.1 は Pro、v2.1 は初期2.xリリースです。システムプロンプトが必要なら v3.5 を選んでください。コストを最優先し、品質への要求が高くない場合は v2.1 を検討できます。本番前に、自分のデータで試してください。AnyAIGC では3モデルとも入力と出力が同じ価格です。

SparkDesk は OpenAI API と互換性がありますか？ 呼び出し方も教えてください。

はい。SparkDesk-v2.1 は POST https://anyaigc.ai/v1/chat/completions を使い、リクエストとレスポンスは OpenAI Chat Completions と同じです。公式の OpenAI SDK を使う場合は、base_url を https://anyaigc.ai/v1 に設定してください。iFLYTEK の WebSocket 署名は不要で、必要なのは Authorization: Bearer だけです。

SparkDesk-v2.1 のコンテキスト長はどれくらいですか？

現行の iFLYTEK Open Platform のバージョン表には2.xリリースが掲載されていないため、引用できる公式のコンテキスト長はありません。実際の入力の長さでテストするか、公式に記載された上限が必要な場合は SparkDesk-v3.1 または SparkDesk-v3.5 を選んでください。

レート制限はありますか？

AnyAIGC は SparkDesk-v2.1 に同時実行数の上限を設けておらず、すべてのアカウントでデフォルトで利用できるため、バッチ処理や並列タスクも問題ありません。課金はトークン単位で、月額料金や時間枠ごとのクォータはありません。

SparkDesk-v2.1 は非推奨ですか？

現行の iFLYTEK Open Platform のバージョン表には2.xリリースが掲載されていないため、旧世代のモデルとして扱ってください。SparkDesk-v2.1 は現時点では AnyAIGC のモデル一覧から呼び出せます。新規プロジェクトでは SparkDesk-v3.1 または SparkDesk-v3.5 を使ってください。現在の提供状況はモデル一覧でご確認ください。

SparkDesk-v2.1 の APIキーはどこで取得できますか？

anyaigc.ai で登録してチャージし、コンソールでトークンを作成します。1つのキーでプラットフォーム上の300以上のモデルを利用できるため、iFLYTEK Open Platform の APPID、APIKey、APISecret は不要です。リクエストボディの model に SparkDesk-v2.1 を指定してください。

AnyAIGC で請求書を発行できますか？

はい。実際にチャージした金額分の請求書を、コンソールでご自身で発行できます。

対応している支払い方法は何ですか？

WeChat Pay、Alipay、USDT、クレジットカードでチャージできます。残高は USD で、プラットフォーム上のすべてのモデルで使えます。チャージした金額分の請求書は、コンソールで発行できます。

新規ユーザー向けの無料トライアルはありますか？

はい。新規アカウントには200万トークン分のトライアル枠が付与されるので、チャージするかどうか決める前に試せます。チャージは $1 から可能です。

残高は返金できますか？

はい。未使用の残高は手数料なしで返金できます。返金をご希望の場合は、サポートにご連絡ください。

本物のモデルですか？データは安全ですか？

リクエストは公式のモデルチャネルに送られ、安価な代替モデルやリバースエンジニアリングによるモデルは使いません。法令で求められる場合を除き、プロンプトや出力を永続的に保存せず、学習にも使用しません。コンソールでは、リクエストごとのトークン数と料金を確認できます。

プロンプトは学習に使われますか？

いいえ。法令で求められる場合を除き、AnyAIGC はプロンプトや出力を永続的に保存せず、学習にも使用しません。リクエストは HTTPS で暗号化されます。詳しくは AnyAIGC のプライバシーポリシーをご覧ください。モデル提供元のデータの扱いは、iFLYTEK の規約に従います。
