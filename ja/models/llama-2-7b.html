Python
import json
import os
import urllib.request

payload = {
  "model": "llama-2-7b",
  "messages": [
    {
      "role": "user",
      "content": "Explain what an API is in three sentences."
    }
  ],
  "n": 1,
  "stream": False
}
request = urllib.request.Request(
    "https://anyaigc.ai/v1/chat/completions",
    data=json.dumps(payload, ensure_ascii=False).encode("utf-8"),
    headers={
        "Authorization": "Bearer " + os.environ["ANYAIGC_API_KEY"],
        "Content-Type": "application/json",
    },
    method="POST",
)
with urllib.request.urlopen(request, timeout=120) as response:
    result = json.load(response)

print(json.dumps(result, ensure_ascii=False, indent=2))

cURL の例は Bash / zsh の構文です。Python は標準ライブラリのみを使います。n=1、stream=false の場合、レスポンスには choices に返信候補が1件と usage が含まれます。SSE で出力するには stream=true を設定してください。

Llama 2 7B API のよくある質問

料金、バージョン、導入、法人での購入について。

Llama 2 7B API の料金はいくらですか？

入力は100万トークンあたり$1.3500、出力は$1.3500です（USD）。オファー対象のモデルは、モデル一覧の表示どおり32%オフです。掲載料金には割引がすでに含まれているため、重ねて適用しないでください。最新の料金はモデル一覧でご確認ください。

Llama と Ollama はどのような関係ですか？ どのバージョンが掲載されていますか？

Meta が Llama モデルファミリーを開発しています。Ollama はモデルのランタイムで、AnyAIGC のモデル一覧ではプロバイダーのカテゴリとして使っています。これらのガイドは Llama 2、3、3.1、3.2、3.3 の12モデルを扱います。商用利用は Meta の公式規約に従います。

どのモデルIDを送ればよいですか？ リクエストは何を返しますか？

POST /v1/chat/completions に llama-2-7b を指定し、Bearer の APIキー認証を使います。例では n=1、stream=false を設定し、アシスタントの返信候補1件とトークン使用量を返します。この概要ページでは llama という名前を使います。

同時実行数や RPM に制限はありますか？ Ollama のインストールは必要ですか？

すべてのユーザーが、デフォルトで同時実行数の上限なし、固定のRPM上限なしで利用できます。Ollama のインストールやモデルのローカルデプロイなしで、AnyAIGC のクラウド API を呼び出せます。ネットワークのタイムアウトや API エラーへの対応は、アプリケーション側で行ってください。

画像を受け付けるモデルはどれですか？ 対応言語は？

Llama 3.2 Vision Instruct の11B と90B はビジョンモデルで、掲載しているそれ以外のモデルはテキストモデルです。Llama 3.1〜3.3 は、中国語を除く8つのテキスト言語を公式にサポートしています。画像とテキストのタスクは、公式には英語をサポートしています。その他の言語は自分のデータで評価してください。これらの例はテキストリクエストを示しています。

AnyAIGC で請求書を発行できますか？

はい。実際にチャージした金額分の請求書を、コンソールでご自身で発行できます。

対応している支払い方法は何ですか？

WeChat Pay、Alipay、USDT、クレジットカードでチャージできます。残高は USD で、プラットフォーム上のすべてのモデルで使えます。チャージした金額分の請求書は、コンソールで発行できます。

新規ユーザー向けの無料トライアルはありますか？

はい。新規アカウントには200万トークン分のトライアル枠が付与されるので、チャージするかどうか決める前に試せます。チャージは $1 から可能です。

残高は返金できますか？

はい。未使用の残高は手数料なしで返金できます。返金をご希望の場合は、サポートにご連絡ください。

本物のモデルですか？データは安全ですか？

リクエストは公式のモデルチャネルに送られ、安価な代替モデルやリバースエンジニアリングによるモデルは使いません。法令で求められる場合を除き、プロンプトや出力を永続的に保存せず、学習にも使用しません。コンソールでは、リクエストごとのトークン数と料金を確認できます。
