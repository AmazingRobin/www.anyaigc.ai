3ステップで GPT Image API を始める

  1. 登録：AnyAIGC のアカウントを作成します。新規アカウントには200万トークン分のトライアル枠が付与され、チャージは $1 から可能です。
  2. APIキーを作成：コンソールでキーを発行し、環境変数 ANYAIGC_API_KEY に保存します。
  3. リクエストを送信：model に gpt-image-2.5-flare を指定して https://anyaigc.ai/v1/images/generations を呼び出します。画像を編集するときは /v1/images/edits を使います。

モデルを切り替えるには、model フィールドだけを変更します：gpt-image-2.6-sunburst、gpt-image-2.6-flare、gpt-image-2.5-sunburst、gpt-image-2.5-flare、gpt-image-2、または1枚あたり課金の -c 版。-c 版には n や mask を送信しないでください。

出力形式のフィールドは format（png / jpeg / webp）で、レスポンスは data[0].url を返します。base64 で受け取るには response_format=b64_json を指定します。すべてのパラメータは generations のドキュメントと edits のドキュメントをご覧ください。

GPT Image API のよくある質問

GPT Image API の料金はいくらですか？

トークン課金のモデル：GPT Image 2.6 Sunburst と Flare は、100万トークンあたりテキスト入力$3.9710、画像入力$6.3530、画像出力$23.8240です。GPT Image 2.5 Sunburst と Flare は、100万トークンあたりテキスト入力$2.9700、画像入力$4.7520、画像出力$17.8200で、定価から約41%オフです。GPT Image 2 は$0.3971、$0.6354、$2.3830で、定価から約92%オフです。1枚あたり課金の -c 版：gpt-image-2.6-sunburst-c と gpt-image-2.6-flare-c は、1K、2K、4K のいずれも1枚$0.0199、gpt-image-2.5-sunburst-c と gpt-image-2.5-flare-c は、1K は1枚$0.0159、2K/4K は1枚$0.0199、gpt-image-2-c は$0.0119と$0.0149です。最新の料金はモデル一覧でご確認ください。

Sunburst、Flare、GPT Image 2 の違いは何ですか？

OpenAI が2026年11月にリリースした GPT Image 2.6 が最新世代です。こちらにも Sunburst（より精細で、複数回の編集が安定）と Flare（より高速）があり、GIF と SVG の出力、マークアップを使った編集、complexity の設定が加わりました。GPT Image 2.5 の Sunburst と Flare は2026年9月にリリースされました。OpenAI は、Sunburst を編集精度が最も高いモデル、Flare を日常用途向けの最速の高品質モデルと位置づけています。公式のトークン料金は同じで、どちらも xhigh と max の品質レベルが加わります。GPT Image 2 は2026年4月にリリースされた旧世代で、品質は low、medium、high、auto です。

トークン課金と1枚あたり課金（-c）のどちらを選ぶべきですか？

トークン課金では、コストはサイズと品質で決まります。小さい低品質の画像はとても安く、品質と解像度が上がるほど高くなります。-c 版はどの品質でも1枚あたりの料金が一定（1K と 2K/4K の2段階）ですが、1回のリクエストで返る画像は1枚で、n、mask、透過背景には対応していません。1024×1024、high 品質の場合、GPT Image 2.5 はトークン課金で1枚あたり約$0.0313、-c では$0.0159です。

対応しているエンドポイントは？ 画像を編集できますか？

1枚あたり課金の -c 版を含め、すべての GPT Image モデルが POST /v1/images/generations（テキストから画像）と POST /v1/images/edits（画像から画像、複数画像の合成）に対応しています。edits は参照画像を16枚未満、合計50MBまで受け付けます。トークン課金のモデルは、マスクを使ったインペイントにも対応しています。すべてのフィールドは AnyAIGC API ドキュメントをご覧ください。

同時実行数に制限はありますか？

AnyAIGC は GPT Image のラインナップ全体で同時実行数に上限を設けておらず、すべてのアカウントでデフォルトで適用されます。ベースURLは https://anyaigc.ai/v1 です。課金は USD で、WeChat Pay、Alipay、USDT、クレジットカードで支払え、同じキーで300以上のほかのモデルも使えます。

対応している支払い方法は何ですか？

WeChat Pay、Alipay、USDT、クレジットカードでチャージできます。残高は USD で、プラットフォーム上のすべてのモデルで使えます。チャージした金額分の請求書は、コンソールで発行できます。

新規ユーザー向けの無料トライアルはありますか？

はい。新規アカウントには200万トークン分のトライアル枠が付与されるので、チャージするかどうか決める前に試せます。チャージは $1 から可能です。

残高は返金できますか？

はい。未使用の残高は手数料なしで返金できます。返金をご希望の場合は、サポートにご連絡ください。

本物のモデルですか？データは安全ですか？

リクエストは公式のモデルチャネルに送られ、安価な代替モデルやリバースエンジニアリングによるモデルは使いません。法令で求められる場合を除き、プロンプトや出力を永続的に保存せず、学習にも使用しません。コンソールでは、リクエストごとのトークン数と料金を確認できます。

生成した画像を商用利用できますか？

利用権とコンテンツポリシーは OpenAI の公式規約に従います。AnyAIGC は API アクセスを提供するだけで、出力の利用方法に追加の制限は設けていません。実在の人物の肖像や第三者の商標が含まれる画像では、必要な権利を確保してください。
