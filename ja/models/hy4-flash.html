公式 API 料金（100万トークンあたり）：Hy4 flash は入力¥0.5、出力¥2、キャッシュヒット¥0.02、Hy4 は¥6、¥18、¥0.3です。

FAQ

Hy4 Flash API のよくある質問

Hy4 Flash API の料金はいくらですか？定価からどのくらい安いですか？

トークン単位の従量課金で、USD の100万トークンあたりの料金は、入力$0.0281（定価$0.0695）、出力$0.1130（定価$0.2782）、キャッシュヒット$0.0012（定価$0.0028）です。Tencent Hunyuan のリリースノートでは入力¥0.5、出力¥2、キャッシュヒット¥0.02で、USD の定価は1USDあたり約7.19CNYで換算しています。AnyAIGC の入力と出力は定価の約40%、キャッシュヒットは約43%で、全体では約60%オフです。Tencent Cloud TokenHub では2026-11-30まで期間限定の50%オフキャンペーンも実施されていますが、このページではキャンペーン価格を基準にしていません。最新の料金はモデル一覧をご確認ください。

Hy4 flash と Hy4 の違いは何ですか？

Tencent Hunyuan のリリースノート（2026-11-16）によると、Hy4 flash は総パラメータ224B（うち64B は Engram）、アクティブパラメータ12Bで、API 料金は入力¥0.5、出力¥2です（Hy4 は¥6と¥18）。Tencent によると、flash の KV キャッシュは Hy4 の6分の1で、デコード速度は150 tps を超えます。WorkBuddy の日常タスク評価では、平均タスク時間は Hy4 より70%短く、平均コストは約15分の1で、日常タスクの品質はほぼ同等、長期的なコーディングではわずかに低下します。Tencent は、日常業務には flash を、長期的なソフトウェアエンジニアリングなどの複雑なタスクには Hy4 を推奨しています。これらは Tencent 自身の数値であり、AnyAIGC では再検証していません。

Hy4 Flash は画像入力に対応していますか？

はい。モデル一覧に画像理解が掲載されており、Tencent も Hy4 flash をマルチモーダルと説明しています。POST /v1/chat/completions の image_url コンテンツパートで画像の URL または base64 データを送ってください。出力はテキストです。画像サイズや枚数の上限は、現在 AnyAIGC のドキュメントに記載がないため、ドキュメントに従ってください。

どのAPIエンドポイントを使えばよいですか？

どちらの形式も使えます。OpenAI 互換の POST https://anyaigc.ai/v1/chat/completions と、Anthropic 形式の POST https://anyaigc.ai/v1/messages で、どちらも Authorization: Bearer <API Key> を付け、model に hy4-flash を指定します。OpenAI SDK では base_url を https://anyaigc.ai/v1 に設定してください。

同時実行数に制限はありますか？

AnyAIGC では、Hy4 Flash はすべてのアカウントでデフォルトで同時実行数の上限なしで利用できます。長いコンテキストやエージェントのリクエストは時間がかかるため、タイムアウトとリトライを適切に設定してください。

出力は商用利用できますか？

モデルと出力の利用は Tencent Hunyuan の公式規約に従います。AnyAIGC は独立した API プロバイダーであり、Tencent とは提携関係にありません。

AnyAIGC で請求書を発行できますか？

はい。実際にチャージした金額分の請求書を、コンソールでご自身で発行できます。

対応している支払い方法は何ですか？

WeChat Pay、Alipay、USDT、クレジットカードでチャージできます。残高は USD で、プラットフォーム上のすべてのモデルで使えます。チャージした金額分の請求書は、コンソールで発行できます。

新規ユーザー向けの無料トライアルはありますか？

はい。新規アカウントには500万トークン分のトライアル枠が付与されるので、チャージするかどうか決める前に試せます。チャージは $1 から可能です。

残高は返金できますか？

はい。未使用の残高は手数料なしで返金できます。返金をご希望の場合は、サポートにご連絡ください。

本物のモデルですか？データは安全ですか？

リクエストは公式のモデルチャネルに送られ、安価な代替モデルやリバースエンジニアリングによるモデルは使いません。法令で求められる場合を除き、プロンプトや出力を永続的に保存せず、学習にも使用しません。コンソールでは、リクエストごとのトークン数と料金を確認できます。
