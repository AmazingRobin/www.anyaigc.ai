仕様

仕様と選び方

Custom Voices は、アップロードした音声・動画ファイル、または対象となる過去の生成結果から声を抽出します。ソースは必ず1つだけ指定してください。

アップロードできる形式は mp3、wav、mp4、mov です。ノイズのないクリアな声が1人分だけ入った、長さ5〜30秒のものが対象です。

対象となる過去の生成結果は、音声ありの V2.6 動画、Avatar API の動画、Lip Sync API の動画です。

ボイス名は20文字までで、使っていないボイスは API から削除できます。

このページのカスタムボイスは$0.00844/回で、上の料金表と一致しています。

kling-audio との違い：Custom Voices は再利用できる新しい声を作成し、Kling Audio は内蔵の音声で音声合成と効果音を生成します。

仕様はベンダーの公式ドキュメント（klingai.com）に基づいています。このページの表は料金で、最新の料金はモデル一覧が正となります。

FAQ

Kling Custom Voices API の料金はいくらですか？

Kling Custom Voices は AnyAIGC で1回あたり$0.00844から利用できます。課金単位はモデル一覧の表示に従います。最新の料金はモデル一覧で確認してください。

Kling Custom Voices では何ができますか？

アップロードした音声や既存の動画の音声から、TTS や吹き替えに使える再利用可能なカスタムボイスのプロファイルを作成します。

API は非同期ですか？

はい。/kling/v1/general/custom-voices にタスクを送信してタスクIDを受け取り、ドキュメントに記載のクエリ用エンドポイントで結果をポーリングします。

同時実行数に制限はありますか？

AnyAIGC の Kling モデルは、デフォルトで同時実行数の上限がありません。

認証はどのように行いますか？

Authorization: Bearer <API Key> を送信します。キーは環境変数 ANYAIGC_API_KEY から読み込んでください。

生成したコンテンツは商用利用できますか？

利用権とコンテンツポリシーは Kling の公式規約に従います。

AnyAIGC で請求書を発行できますか？

はい。実際にチャージした金額分の請求書を、コンソールでご自身で発行できます。

どの支払い方法に対応していますか？

WeChat Pay、Alipay、USDT、クレジットカードでチャージできます。残高は USD で、プラットフォーム上のすべてのモデルで使えます。チャージした金額分の請求書は、コンソールで発行できます。

新規ユーザー向けのトライアル枠はありますか？

新規ユーザーは、登録後に2Mトークンのトライアル枠を受け取れます。

未使用の残高は返金できますか？

未使用の残高は、サポートにご連絡いただければ返金できます。

Kling Custom Voices はどんな用途に向いていますか？

Kling Custom Voices はカスタムボイスの作成向けです。ワークフローを選ぶ前に、このページの機能とユースケースのセクションを確認してください。

Kling Custom Voices をほかの Kling モデルと比較できるのはどこですか？

このページの Kling モデルファミリーのセクションで、関連する生成、制御、音声、アセットのツールを比較できます。

エンドポイントはどのように実装すればよいですか？

エンドポイントごとの APIドキュメントを参照してください。すべての Kling エンドポイントが汎用の prompt ペイロードを受け付けるとは限りません。
