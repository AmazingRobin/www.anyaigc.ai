仕様はベンダーの公式ドキュメント（platform.claude.com）に基づいています。このページの表は料金を示したもので、最新の料金はモデル一覧が正となります。

Claude Fable 5.2 API のよくある質問

Claude Fable 5.2 API の料金はいくらですか？

AnyAIGC では、claude-fable-5-2 はトークン単位で課金されます。入力は100万トークンあたり$1.906、出力は100万トークンあたり$9.529、5分キャッシュ書き込みは$2.3820、1時間キャッシュ書き込みは$3.8120、キャッシュヒットは$0.0476です。Anthropic の定価は入力$8、出力$40、キャッシュヒット$0.20のため、AnyAIGC は定価の約23.8%で、およそ76%オフです。

Claude Fable 5.2 のモデルIDは何ですか？

モデルIDは claude-fable-5-2 です。リクエストボディの model フィールドに指定してください。

Claude Fable 5.2 は Fable 5.1 とどう違いますか？

Anthropic は2026年11月9日に Fable 5.2 をリリースしました。定価は入力$10・出力$50から$8・$40に下がり、出力は最大30%高速になり、Medium の effort（推論の強度）では難しい問題を解くのに使うトークンが少なくなり、安全性の分類器が正当なリクエストをブロックする割合は Fable 5.1 より約55%少なくなっています。ベンチマークでは、FrontierSWE v2 が56.3%から69.9%に、Remote Labor Index が17.9%から41.3%に上がっています。どちらのモデルも AnyAIGC で利用でき、Fable 5.2 の方が安く、入力は100万トークンあたり$1.906で、Fable 5.1 の$2.382を下回ります。

AnyAIGC の Claude API は Anthropic の公式APIと互換性がありますか？

はい。エンドポイントは https://anyaigc.ai/v1/messages で、リクエストボディは Anthropic Messages 形式（model、max_tokens、system、messages、tools、cache_control など）に従います。認証は Authorization: Bearer のあとにAPIキーを続けます。公式SDKを使う場合は、ベースURLを https://anyaigc.ai に設定するだけです。

Claude Fable 5.2 を Claude Code で使えますか？

はい。~/.claude/settings.json の env ブロックで、ANTHROPIC_BASE_URL に https://anyaigc.ai、ANTHROPIC_AUTH_TOKEN にAPIキー、ANTHROPIC_MODEL と ANTHROPIC_DEFAULT_OPUS_MODEL の両方に claude-fable-5-2 を設定し、claude を実行してください。1つのコマンドでインストールと設定をまとめて行うこともできます：curl -fsSL https://www.anyaigc.ai/install.sh | bash -s claude。

プロンプトキャッシュはどのように課金されますか？

キャッシュを有効にするには、コンテンツブロックに cache_control を追加します。最初の書き込みはキャッシュ書き込みの料金で課金されます（5分で100万トークンあたり$2.3820、1時間で$3.8120）。それ以降、キャッシュされたトークンは100万トークンあたり$0.0476で、通常の入力料金の約2.5%です。同じコンテキストを繰り返し読み込む長時間実行のエージェントで最も効果を発揮します。

同時実行数やレート制限はありますか？

AnyAIGC では claude-fable-5-2 の同時実行数に上限を設けていません。すべてのアカウントで標準で利用できるため、バッチ処理や複数エージェントの並列実行に向いています。

Claude Fable 5.2 は何が得意ですか？Opus 5.5 より選ぶべきですか？

Anthropic は、Fable 5.2 は最も野心的で自由度の高い技術的な作業、たとえば数時間に及ぶエージェント型コーディング、複数ステップのリサーチ、データ量の多い分析に最適だとしています。また、Haiku、Sonnet、Opus が難しい問題で相談する Advisor としても、より単純なタスクを小さなモデルに任せる Orchestrator としても使えます。Anthropic は、コーディングや知識労働の大半にはまず Claude Opus 5.5 を使い、必要に応じて Fable 5.2 に切り替えることを推奨しています。どちらも同じ AnyAIGC のキーで使えるため、model フィールドを変えるだけでタスクごとに切り替えられます。

anyaigc.ai でアカウントを登録し、チャージしたうえで、コンソールでトークンを作成してください。同じキーで Claude Fable 5.2 と、プラットフォーム上の300以上のモデルを利用できます。

本物のモデルですか？データは安全ですか？

リクエストは公式のモデルチャネルに送られ、安価な代替モデルやリバースエンジニアリングによるモデルは使いません。法令で求められる場合を除き、プロンプトや出力を永続的に保存せず、学習にも使用しません。コンソールでは、リクエストごとのトークン数と料金を確認できます。

データは学習に使われますか？
