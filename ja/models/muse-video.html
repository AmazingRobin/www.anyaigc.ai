Muse Video とは？

Muse Video は、Meta Superintelligence Labs が Muse Image と合わせてプレビュー公開した動画モデルで、同じ事前学習ベースの上に構築されています。Meta は、プロンプトへの忠実さ、映像の忠実度、時間的な一貫性で競争力があるとしています。音声もネイティブに生成し、環境音、効果音、ナレーション、セリフが映像と一緒に出力されます。

Meta によると、Muse Video は2026年7月5日時点で、Arena のテキストから動画部門で3位でした。早期プレビューであり、音声と映像の同期や、物理的に正確な高速の動きにはまだ課題があると Meta は述べています。

AnyAIGC でのモデル名は muse-video です。POST /v1/videos の非同期タスクとして実行し、テキストから動画と先頭フレームからの動画生成に対応します。1280×720 の横向きまたは 720×1280 の縦向きの MP4 を、1秒あたり$0.0397で返します。

Muse Video でできること

  • ネイティブ音声

    効果音、環境音、ナレーション、セリフが映像と一緒に生成されるため、別途吹き替えの工程は不要です。Meta のサンプルでは、落ちるオレンジの一つひとつに音が付いています。

  • プロンプトへの忠実さ

    数、順序、動作がプロンプトに従います。サンプルではアヒルの子をちょうど5羽と指定していて、全編を通して5羽が映り続けます。

  • 時間的な一貫性

    転がったり振り向いたりしても、被写体はクリップの最後まで同じ見た目を保ちます。

  • UGC風の広告

    手持ちのブレ、ピントの移動、カメラに向かって話すクリエイターを再現し、俳優やスタッフなしで自撮り風のスポットを作れます。

  • 話すキャラクター

    プロンプトにセリフを書くとキャラクターがそのセリフを話し、口の動きも音声に合わせられます。

  • カメラとムード

    一人称視点の歩きや手持ちの追従ショットがプロンプトに沿って再現され、照明、天候、環境音が雰囲気を作ります。

Muse Video API を始める

  1. AnyAIGC に登録します。新規アカウントには200万トークンの無料枠があり、チャージは$1から可能です。
  2. コンソールでAPIキーを作成し、ANYAIGC_API_KEY として保存します。
  3. POST https://anyaigc.ai/v1/videos にタスクを送信し、model に muse-video を指定します。その後、status が completed になるまで GET /v1/videos/{id} をポーリングします。

ステータスは queued → in_progress → completed / failed と遷移します。10秒までのクリップは約1–2分、15–30秒は約3–7分かかります。失敗すると error が返されます。video_generation_failed は動画が生成されなかったことを示し（ポリシー違反、または上流の一時的なエラー）、プロンプトを言い換えるか、しばらくしてから再試行してください。video_rejected は出力が検査に通らず破棄されたことを示すので、そのまま再試行してください。すべてのフィールドは AnyAIGC API ドキュメントを参照してください。

Muse Video API のよくある質問

Muse Video API の料金はいくらですか？

AnyAIGC では、Muse Video（muse-video）は1秒あたり$0.0397で、指定した seconds に基づいて課金されます。5秒で$0.199、10秒で$0.397、30秒で$1.19です。金額は送信時に確保され、失敗したタスクは返金されます。最新の料金はモデル一覧で確認できます。

Muse Video とは？

Muse Video は、Meta Superintelligence Labs が Muse Image と同じ事前学習ベースでプレビューした、ネイティブ音声付きの動画モデルです。初期のプレビュー段階にあり、Meta によると2026年7月5日時点で、Arena のテキストから動画部門で3位でした。

動画の長さはどこまで指定できますか？

seconds には4〜30の整数を指定します（デフォルトは4）。出力は切り上げのみで、4または5なら5秒、7または8なら8秒、11–15なら15秒、というようになります。10秒を超えるクリップはセグメントに分けて生成され、10秒と20秒の位置でカットが入ります。課金は指定した秒数で計算されます。

対応しているサイズと解像度は何ですか？

size は 1280x720（横向き）または 720x1280（縦向き）で、デフォルトは横向きです。resolution は 720p のみで、省略できます。出力は音声付きの MP4 です。

画像から動画を生成できますか？

はい。input_reference に画像を渡すと、先頭フレームとして使われます。画像URLまたはデータURL（PNG、JPEG、WebP）を指定するか、multipart/form-data でファイルを直接アップロードしてください。ファイルIDには対応していません。

所要時間はどれくらいで、結果はどう取得しますか？

非同期です。POST /v1/videos でタスクの id が返るので、GET /v1/videos/{id} を10–20秒ごとにポーリングしてください。10秒までのクリップは約1–2分、15–30秒は約3–7分かかります。

生成に失敗した場合も課金されますか？

いいえ。失敗したタスクは自動的に返金されます。無効なパラメータは400（client_local_validation）を返し、タスクは作成されず、課金もされません。

同時実行数の制限はありますか？

AnyAIGC では、どのアカウントでも Muse Video の同時実行数に上限はありません。ベースURLは https://anyaigc.ai で、Meta アカウントは不要です。同じキーで他の300以上のモデルも利用できます。

AnyAIGC で請求書を発行できますか？

はい。実際にチャージした金額分の請求書を、コンソールでご自身で発行できます。

対応している支払い方法は何ですか？

WeChat Pay、Alipay、USDT、クレジットカードでチャージできます。残高は USD で、プラットフォーム上のすべてのモデルで使えます。チャージした金額分の請求書は、コンソールで発行できます。

新規ユーザー向けの無料トライアルはありますか？

はい。新規アカウントには200万トークン分のトライアル枠が付与されるので、チャージするかどうか決める前に試せます。チャージは $1 から可能です。

残高は返金できますか？

はい。未使用の残高は手数料なしで返金できます。返金をご希望の場合は、サポートにご連絡ください。

本物のモデルですか？データは安全ですか？

リクエストは公式のモデルチャネルに送られ、安価な代替モデルやリバースエンジニアリングによるモデルは使いません。法令で求められる場合を除き、プロンプトや出力を永続的に保存せず、学習にも使用しません。コンソールでは、リクエストごとのトークン数と料金を確認できます。

動画を商用利用できますか？

利用権とコンテンツポリシーは Meta の公式規約に従います。AnyAIGC は API アクセスを提供するだけで、出力の利用方法に追加の制限は設けません。
