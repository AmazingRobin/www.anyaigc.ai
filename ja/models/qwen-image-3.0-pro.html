仕様

仕様と選び方

Alibaba Cloud は qwen-image-3.0-pro をフラッグシップ品質のモデルと位置付けています。プロンプトの自動書き換えに対応し、中国語と英語の文字を実物の素材になじむように描画できます。

テキストから画像と、画像から画像・編集の両方に対応し、編集では1〜3枚の入力画像を指定できます。

出力の総ピクセル数は512×512から2048×2048の範囲で、アスペクト比は1:8から8:1、1リクエストで1〜6枚の画像を返します。

このページでは、課金単位の基本料金を$0.00159 / 課金単位と掲載しており、上の料金表と一致します。

wan2.7-image-pro との比較：wan2.7-image-pro はテキストから画像で4Kに対応し、最大9枚の入力画像を受け付けます。一方、qwen-image-3.0-pro は最大2048×2048、入力画像は最大3枚です。

仕様はベンダーの公式ドキュメント（alibabacloud.com）に基づいています。このページの表は料金を示したもので、最新の料金はモデル一覧が正となります。

FAQ

Qwen Image 3.0 Pro API のよくある質問

Qwen Image 3.0 Pro は何に向いていますか？

新聞、メニュー、ストーリーボード、インターフェースを、4.5Kトークンの指示と、1K / 2K別の出力料金で作成できます。

API の料金体系はどうなっていますか？

課金単位の基本料金は$0.00159/課金単位です。次の倍率を適用します：1K出力画像 ×25、2K出力画像 ×50、参照画像 ×2。出力料金と参照料金は合算されます。基本料金は出力画像1枚の最終価格ではありません。最新の料金はモデル一覧をご確認ください。

同時実行数に上限はありますか？

AnyAIGC はこのモデルに同時実行数の上限を設けておらず、デフォルトで利用できます。

APIキーはどう取得しますか？

AnyAIGC のアカウントを作成し、コンソールでAPIキーを作成します。

出力を商用利用できますか？

商用利用は Qwen と Alibaba Cloud の公式規約に従います。

AnyAIGC で請求書を発行できますか？

はい。実際にチャージした金額分の請求書を、コンソールでご自身で発行できます。

対応している支払い方法は何ですか？

WeChat Pay、Alipay、USDT、クレジットカードでチャージできます。残高は USD で、プラットフォーム上のすべてのモデルで使えます。チャージした金額分の請求書は、コンソールで発行できます。

新規ユーザー向けの無料トライアルはありますか？

はい。新規アカウントには500万トークンのトライアル枠が付与されます。

残高は返金できますか？

はい。未使用の残高は手数料なしで返金できます。

データは安全ですか？

プロンプトと出力は、法令で求められる場合を除き、永続的に保存されず、学習にも使われません。
