3ステップで Claude Sonnet 5.5 API を呼び出す

  1. 登録してチャージする：anyaigc.ai でアカウントを作成します。残高は、プラットフォーム上のすべてのモデルで使えます。
  2. APIキーを作成する：コンソールでトークンを作成し、sk- で始まるキーをコピーします。
  3. リクエストを送信：Anthropic Messages 形式のリクエストを https://anyaigc.ai/v1/messages に POST し、Authorization: Bearer で認証します。

そのほかのパラメータ（tools、thinking、ストリーミング、PDF・画像入力など）は AnyAIGC Messages API ドキュメントをご覧ください。各フィールドの動作は Anthropic の公式ドキュメントと同じです。

Claude Sonnet 5.5 API FAQ

Claude Sonnet 5.5 APIの料金はいくらですか？

AnyAIGC では claude-sonnet-5-5 をトークン単位で課金します。入力は100万トークンあたり$0.2382、出力は100万トークンあたり$1.191、5分キャッシュ書き込みは$0.2978、1時間キャッシュ書き込みは$0.4765、キャッシュヒットは$0.0119です。Anthropic の定価は入力$2、出力$10なので、AnyAIGC は定価の約11.9%です。

Claude Sonnet 5.5 のモデルIDは何ですか？

モデルIDは claude-sonnet-5-5 です。リクエストボディの model フィールドに指定してください。

Claude Sonnet 5.5 は何が得意ですか？Sonnet 5.5 と Opus 5.5 のどちらを選ぶべきですか？

Anthropic は Sonnet 5.5 を、Opus 5.5 を補う、より高速で低コストなモデルと説明しています。Opus 5.5 は慎重な判断が必要な複雑な作業向け、Sonnet 5.5 は範囲が明確な日常タスク、バグ修正、仕上がりのよいドキュメント・スライド・スプレッドシートの作成が最も得意です。定価は Sonnet 5.5 が入力$2 / 出力$10、Opus 5.5 が$4 / $20です。実用的には、日常的なコーディングや大量の呼び出しは Sonnet 5.5 を既定にし、最も難しいタスクで claude-opus-5-5 に切り替える使い方がおすすめです。

AnyAIGC の Claude API は Anthropic の公式APIと互換性がありますか？

はい。エンドポイントは https://anyaigc.ai/v1/messages で、リクエストボディは Anthropic Messages 形式（model、max_tokens、system、messages、tools、cache_control など）に従います。認証は Authorization: Bearer のあとにAPIキーを続けます。公式SDKを使う場合は、ベースURLを https://anyaigc.ai に設定するだけです。

Claude Code で Claude Sonnet 5.5 を使えますか？

はい。~/.claude/settings.json の env ブロックで、ANTHROPIC_BASE_URL に https://anyaigc.ai、ANTHROPIC_AUTH_TOKEN にAPIキー、ANTHROPIC_MODEL と ANTHROPIC_DEFAULT_SONNET_MODEL の両方に claude-sonnet-5-5 を設定し、claude を実行してください。次のコマンド1つでインストールと設定をまとめて行うこともできます：curl -fsSL https://www.anyaigc.ai/install.sh | bash。

プロンプトキャッシュはどのように課金されますか？

キャッシュを有効にするには、コンテンツブロックに cache_control を追加します。最初の書き込みはキャッシュ書き込み料金（100万トークンあたり、5分は$0.2978、1時間は$0.4765）で課金されます。それ以降、キャッシュされたトークンは100万トークンあたり$0.0119のみで、通常の入力料金の5%です。長いシステムプロンプト、コードベースのコンテキスト、複数ターンのエージェントタスクに向いています。

同時実行数やレート制限はありますか？

AnyAIGC は claude-sonnet-5-5 の同時実行数に上限を設けていません。すべてのアカウントでデフォルトでこの設定になっているため、バッチ処理や複数エージェントの並列実行に適しています。

Claude Sonnet 5.5 のAPIキーはどうすれば取得できますか？

anyaigc.ai で登録し、チャージしたうえで、コンソールでトークンを作成してください。同じキーで Claude Sonnet 5.5 とプラットフォーム上の300以上の他のモデルを利用できます。

AnyAIGC で請求書を発行できますか？

はい。実際にチャージした金額分の請求書を、コンソールでご自身で発行できます。

対応している支払い方法は何ですか？

WeChat Pay、Alipay、USDT、クレジットカードでチャージできます。残高は USD で、プラットフォーム上のすべてのモデルで使えます。チャージした金額分の請求書は、コンソールで発行できます。

新規ユーザー向けの無料トライアルはありますか？

はい。新規アカウントには200万トークン分のトライアル枠が付与されるので、チャージするかどうか決める前に試せます。チャージは $1 から可能です。

残高は返金できますか？

はい。未使用の残高は手数料なしで返金できます。返金をご希望の場合は、サポートにご連絡ください。

本物のモデルですか？データは安全ですか？

リクエストは公式のモデルチャネルに送られ、安価な代替モデルやリバースエンジニアリングによるモデルは使いません。法令で求められる場合を除き、プロンプトや出力を永続的に保存せず、学習にも使用しません。コンソールでは、リクエストごとのトークン数と料金を確認できます。

データは学習に使われますか？

リクエストはHTTPSで暗号化されて送信されます。データの取り扱いについては、AnyAIGC のプライバシーポリシーをご覧ください。モデル自体のデータポリシーは Anthropic の公式規約に従います。
