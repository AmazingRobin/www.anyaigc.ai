cURL
# Set MINIMAX_DESIGNED_VOICE_ID to a unique custom voice ID.
curl --request POST "https://anyaigc.ai/minimax/v1/voice_design" \
  --header "Authorization: Bearer $ANYAIGC_API_KEY" \
  --header "Content-Type: application/json" \
  --data @- <<JSON
{
  "preview_text": "Night fell, the streetlights went dark, and a soft knock echoed in the distance.",
  "prompt": "A suspense-story narrator with a deep, resonant voice.",
  "voice_id": "${MINIMAX_DESIGNED_VOICE_ID}"
}

Python
import json
import os
import urllib.request

# MINIMAX_DESIGNED_VOICE_ID must be a unique custom voice ID.
payload = {
    "preview_text": "Night fell, the streetlights went dark, and a soft knock echoed in the distance.",
    "prompt": "A suspense-story narrator with a deep, resonant voice.",
    "voice_id": os.environ["MINIMAX_DESIGNED_VOICE_ID"]
}

request = urllib.request.Request(
    "https://anyaigc.ai/minimax/v1/voice_design",
    data=json.dumps(payload, ensure_ascii=False).encode("utf-8"),
    headers={
        "Authorization": "Bearer " + os.environ["ANYAIGC_API_KEY"],
        "Content-Type": "application/json",
    },
    method="POST",
)
with urllib.request.urlopen(request, timeout=300) as response:
    result = json.load(response)

print(json.dumps(result, ensure_ascii=False, indent=2))

ドキュメントでは voice_id と記載されていますが、レスポンス例には data.task_id が示されています。これらの例は、結果のフィールドを仮定せずJSON全体を出力します。連携前に、実際のレスポンスと課金対象のテキストを確認してください。

FAQ

MiniMax API のよくある質問

料金、エンドポイント、結果、法人向けの利用をまとめて確認できます。

MiniMax Voice Design APIの料金はいくらですか？

モデル一覧には10,000文字あたり$0.3176と記載されています。一括展開の前に、どのテキストが課金対象になるか、いつ課金されるかをサポートに確認してください。

どのAPIエンドポイントを使えばよいですか？

https://anyaigc.ai の POST /minimax/v1/voice_design を使い、APIキーは Authorization: Bearer で渡します。Voice Designは prompt、preview_text、カスタムの voice_id を受け取り、model フィールドは使いません。

Voice Designでは何を指定しますか？

prompt に希望するボイスと話し方を記述し、preview_text にサンプルテキストを入れ、一意のカスタム voice_id を選びます。例では、そのIDを MINIMAX_DESIGNED_VOICE_ID から読み込みます。

1回のリクエストで何が返りますか。

ドキュメントでは voice_id の結果が記載されていますが、例には data.task_id が示されています。例ではフィールドやダウンロード手順を仮定せず、JSONレスポンス全体を出力します。連携前に実際のレスポンスを確認してください。

同時実行数やRPMの制限はありますか？

AnyAIGC では MiniMax の同時実行数に上限がなく、固定の RPM 上限もありません。生成には時間がかかるため、タイムアウト、エラー処理、適切なリトライはアプリケーション側で設定してください。

生成したコンテンツは商用利用できますか。

モデルとその出力の商用利用は MiniMax の公式規約に従います。参照素材、音声、生成コンテンツについて必要な権利をお持ちであることをご確認ください。AnyAIGC は独立した API プロバイダーです。

AnyAIGC で請求書を発行できますか？

はい。実際にチャージした金額分の請求書を、コンソールでご自身で発行できます。

対応している支払い方法は何ですか？

WeChat Pay、Alipay、USDT、クレジットカードでチャージできます。残高は USD で、プラットフォーム上のすべてのモデルで使えます。チャージした金額分の請求書は、コンソールで発行できます。

新規ユーザー向けの無料トライアルはありますか？

はい。新規アカウントには500万トークン分のトライアル枠が付与されるので、チャージするかどうか決める前に試せます。チャージは $1 から可能です。

残高は返金できますか？

はい。未使用の残高は手数料なしで返金できます。返金をご希望の場合は、サポートにご連絡ください。

本物のモデルですか？データは安全ですか？

リクエストは公式のモデルチャネルに送られ、安価な代替モデルやリバースエンジニアリングによるモデルは使いません。法令で求められる場合を除き、プロンプトや出力を永続的に保存せず、学習にも使用しません。コンソールでは、リクエストごとのトークン数と料金を確認できます。
