Seedream 5.0 Pro API のよくある質問

Seedream 5.0 Pro API の料金はいくらですか？

AnyAIGC では、Seedream 5.0 Pro（doubao-seedream-5-0-pro-260628）は$0.0441 / 枚からです。料金は解像度によって異なり、size を省略するとより高い区分で課金される場合があるため、1K または 2K を明示的に指定してください。課金は生成に成功した分のみで、最新の料金はモデル一覧で確認できます。

Seedream 5.0 Pro とは何ですか？

Seedream 5.0 Pro は ByteDance Seed チームのフラッグシップ画像モデルで、公式には、推論を組み込み効率的な制作と生産を支えるマルチモーダル画像生成モデルとされています。高密度な情報レイアウト、インタラクティブな精密編集、リアルな写真とポートレート、10以上の言語のネイティブ対応に重点を置いています。AnyAIGC では2026年8月に追加しました。

対応している解像度は？4K出力はできますか？

4Kには対応していません。Volcano Engine Ark のドキュメントによると、5.0 Pro の size は 1K、1.5K、2K（デフォルトは2K）、または 2048x2048、2816x1584 などのピクセル指定を受け付け、アスペクト比は1:16から16:1です。4Kが必要な場合は Seedream 5.0 lite または 4.5 を使ってください。

参照画像は何枚まで送れますか？画像セットには対応していますか？

image には、編集や複数画像の合成用に最大10枚の参照画像を指定できます。5.0 Pro は画像セット（1回のリクエストで関連する画像を複数枚生成）に対応していません。その場合は 5.0 lite、4.5、4.0 を使ってください。

5.0 Pro と 5.0 lite のどちらを選ぶべきですか？

インフォグラフィック、ポスター、UI など文字の多い画像や、注釈・選択領域による精密な編集には 5.0 Pro を選んでください。日常的なバッチ処理、4K、画像セット、Web検索には 5.0 lite を選んでください。料金も低めです（$0.0223 / 枚から）。

同時実行数の上限はありますか？登録に必要なものは？

AnyAIGC は Seedream 5.0 Pro に同時実行数の上限を設けておらず、すべてのアカウントがデフォルトで利用できます。ベースURLは https://anyaigc.ai です。Volcano Engine のアカウントや本人確認は不要で、同じキーでプラットフォーム上の他の300以上のモデルも利用できます。

はい。実際にチャージした金額分の請求書を、コンソールでご自身で発行できます。

対応している支払い方法は何ですか？

WeChat Pay、Alipay、USDT、クレジットカードでチャージできます。残高は USD で、プラットフォーム上のすべてのモデルで使えます。チャージした金額分の請求書は、コンソールで発行できます。

新規ユーザー向けの無料トライアルはありますか？

はい。新規アカウントには200万トークン分のトライアル枠が付与されるので、チャージするかどうか決める前に試せます。チャージは $1 から可能です。

残高は返金できますか？

はい。未使用の残高は手数料なしで返金できます。返金をご希望の場合は、サポートにご連絡ください。

本物のモデルですか？データは安全ですか？

リクエストは公式のモデルチャネルに送られ、安価な代替モデルやリバースエンジニアリングによるモデルは使いません。法令で求められる場合を除き、プロンプトや出力を永続的に保存せず、学習にも使用しません。コンソールでは、リクエストごとのトークン数と料金を確認できます。

商用利用はできますか？透かしは消せますか？

利用権とコンテンツポリシーは、ByteDance / Volcano Engine の公式規約に従います。リクエストで watermark を false にすると、右下に「AI生成」の表示は付きません。AnyAIGC は API アクセスを提供するだけで、出力の利用方法に追加の制限は設けていません。実在の人物の肖像やブランドロゴなどについては、必要な権利を確認してください。
