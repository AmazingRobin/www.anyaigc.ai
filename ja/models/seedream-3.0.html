Seedream 3.0 とは

Seedream 3.0 は、ByteDance Seed チームが2025年4月にリリースした、中国語と英語の両方に対応する画像生成の基盤モデルです。ネイティブ2Kで出力し、小さな文字、タイポグラフィ、指示追従、美的品質で前世代から明確に改善されています。

AnyAIGC でのモデルIDは doubao-seedream-3-0-t2i-250415 で、1リクエストあたり$0.0101で課金されます。テキストから画像のみ対応で、参照画像、編集、画像セットには対応していません。

Seedream 3.0 API を使い始める

  1. AnyAIGC に登録してください。新規アカウントには200万トークンの無料枠が付与され、$1からチャージできます。
  2. コンソールで APIキーを作成し、環境変数 ANYAIGC_API_KEY に保存します。
  3. POST https://anyaigc.ai/v1/images/generations（OpenAI互換）に、model を doubao-seedream-3-0-t2i-250415 にしてリクエストを送ります。

移行するには、model を doubao-seedream-4-0-250828 かそれより新しいモデルに変更し、size を 2K などのティア値に切り替えます。

認証には Authorization: Bearer <API Key> を使います。レスポンスは {"created": ..., "data": [{"url": ...}]} の形式で、response_format を b64_json にすると base64 で受け取れます。watermark のデフォルトは true なので、透かしなしの画像が必要な場合は明示的に false を渡してください。フィールドの詳細は AnyAIGC Seedream APIドキュメントをご覧ください。

仕様と選び方

Seedream 3.0 は、中国語と英語に対応したテキストから画像の基盤モデルです。

Seedream 3.0 は後処理なしでネイティブ2K画像を出力し、さまざまなアスペクト比で512×512から2048×2048までの解像度に対応します。

Seedream 3.0 は、1K解像度の画像をエンドツーエンドで約3秒で生成します。

Seedream 3.0 は、小さな文字や複数行のテキストレイアウトの描画が改善されています。

このページでは Seedream 3.0 を $0.0101 / リクエストで掲載しており、上の料金表と一致します。

seedream-4.0 との比較：Seedream 3.0 はテキストから画像のみで、最大 2048×2048 です。Seedream 4.0 は編集、最大14枚の参照画像、最大4Kの出力に対応します。

仕様はベンダーの公式ドキュメント（seed.bytedance.com）によるものです。このページの表は料金で、最新の料金はモデル一覧が正となります。

Seedream 3.0 API のよくある質問

Seedream 3.0 API の料金はいくらですか？

AnyAIGC では、Seedream 3.0（doubao-seedream-3-0-t2i-250415）は$0.0101 / リクエストからです。3.0 はモデル一覧でリクエスト単位の課金で、1リクエストで画像が1枚返ります。課金は生成に成功した分のみで、最新の料金はモデル一覧で確認できます。

Seedream 3.0 は提供終了しましたか？

いいえ。doubao-seedream-3-0-t2i-250415 は、現在 AnyAIGC で問題なく動作します。ただし、現在の Volcano Engine Ark の画像生成ドキュメントには 3.0 が掲載されていないため、今後提供終了になる可能性があります。新規プロジェクトでは Seedream 4.0 または 5.0 lite を使ってください。APIは同じなので、移行で変更するのはモデルIDだけです。

Seedream 3.0 とは？

Seedream 3.0 は、ByteDance Seed チームが2025年4月にリリースした、中国語と英語の両方に対応するテキストから画像の基盤モデルです。ネイティブ2Kで出力し、小さな文字とタイポグラフィをより正確に描画し、指示追従と美的品質も前世代から向上しています。

3.0 は画像編集や参照画像に対応していますか？

いいえ。3.0（t2i）はテキストから画像のみで、参照画像、編集、画像セットには対応していません。編集には 4.0 以降を使ってください。

size には何を指定すればよいですか？

3.0 の size にはピクセル寸法を指定します。例：1024x1024、1280x720、720x1280。

同時実行数の上限はありますか？登録に必要なものは？

AnyAIGC では Seedream 3.0 に同時実行数の上限を設けておらず、すべてのアカウントがデフォルトで利用できます。ベースURLは https://anyaigc.ai です。Volcano Engine のアカウントや本人確認は不要で、同じキーでプラットフォーム上の他の300以上のモデルも利用できます。

AnyAIGC で請求書を発行できますか？

はい。実際にチャージした金額分の請求書を、コンソールでご自身で発行できます。

対応している支払い方法は何ですか？

WeChat Pay、Alipay、USDT、クレジットカードでチャージできます。残高は USD で、プラットフォーム上のすべてのモデルで使えます。チャージした金額分の請求書は、コンソールで発行できます。

新規ユーザー向けの無料トライアルはありますか？

はい。新規アカウントには200万トークン分のトライアル枠が付与されるので、チャージするかどうか決める前に試せます。チャージは $1 から可能です。

残高は返金できますか？

はい。未使用の残高は手数料なしで返金できます。返金をご希望の場合は、サポートにご連絡ください。

本物のモデルですか？データは安全ですか？

リクエストは公式のモデルチャネルに送られ、安価な代替モデルやリバースエンジニアリングによるモデルは使いません。法令で求められる場合を除き、プロンプトや出力を永続的に保存せず、学習にも使用しません。コンソールでは、リクエストごとのトークン数と料金を確認できます。

商用利用はできますか？透かしは消せますか？

利用権とコンテンツポリシーは、ByteDance / Volcano Engine の公式規約に従います。リクエストで watermark を false にすると、右下に「AI生成」の表示は付きません。AnyAIGC は API アクセスを提供するだけで、出力の利用方法に追加の制限は設けていません。実在の人物の肖像やブランドロゴなどについては、必要な権利を確認してください。
