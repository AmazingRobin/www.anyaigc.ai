Muse Image とは？

Muse Image は Meta Superintelligence Labs が2026年7月にリリースした画像生成モデルで、Muse Spark と同じ Muse ファミリーに属します。Meta は、指示への忠実さ、精密な編集、複数の参照画像からの合成という3点を軸に位置づけています。

プロンプトからそのまま画素を生成するだけのモデルではありません。レンダリングの前に、実在のランドマークや商品、最新の出来事を検索したり、グラフや QR コードを正確に描くためにコードを書いたりでき、その過程で自分の下書きを見直して修正します。Meta によると、Muse Image は2026年7月5日時点で、Arena のテキストから画像、単一画像の編集、複数画像の編集の3部門で2位でした。

AnyAIGC でのモデル名は muse-image です。OpenAI 互換の /v1/images/generations エンドポイントを使い、料金は1枚あたり$0.00596で、Meta の定価$0.01を下回ります。

Muse Image でできること

  • プロンプトへの忠実さとタイポグラフィ

    見出し、細かい注記、日付、価格が書いたとおりに画像へ描かれるため、ポスター、表紙、パッケージに向いています。

  • 精密な編集

    指示した部分だけを変更します。プロンプト：「この画像の霧を晴らして、下に広がる美しい谷を見せてください。」車、標識、構図はそのままです。

  • マルチターンでの調整

    1つの会話の中で編集を続けても、各ターンの一貫性が保たれます。リビングルームをジャパンディ風に模様替えしたあと、元のランプとキャビネットを戻すこともできます。

  • 複数画像の合成

    複数の参照画像から人物、物、服装、スタイル、背景を組み合わせられます。プロンプトにはテキストと画像を交互に入れられます。

  • Webに基づく事実

    先に情報源や参照画像を調べるため、知識を要するプロンプトや最新の出来事を扱うプロンプトでも、より正確な画像になります。

  • コードによる精密なグラフィック

    正確なグラフや QR コードのためにコードを書き、その結果を画像に描き込むことを学習しています。このサンプルの QR コードは meta.ai を指し、スキャンできます。

Muse Image API を始める

  1. AnyAIGC に登録します。新規アカウントには200万トークンの無料枠があり、チャージは$1から可能です。
  2. コンソールでAPIキーを作成し、ANYAIGC_API_KEY として保存します。
  3. model に muse-image を指定して、POST https://anyaigc.ai/v1/images/generations（OpenAI 互換）にリクエストを送ります。

認証には Authorization: Bearer <API Key> を使います。レスポンスは {"created": ..., "data": [{"b64_json": ...}]} の形式です。response_format に url を指定すると一時リンクが返るので、早めにダウンロードしてください。パラメータの詳細は Meta のドキュメントをご覧ください。ベースURLとキーは AnyAIGC のものを使います。

仕様と選び方

Meta の公式開発者ドキュメントによると、Muse Image は会話形式のインターフェースで画像を生成・編集します。テキストと参照画像を交互に入力すると画像が返り、同じ会話の中でターンごとに調整を重ねられます。

編集では指示した部分だけが変わり、ほかはそのまま維持されます。1回のリクエストに複数の参照画像を含められ、後のターンで新しい画像を追加することもできます。

提供元はエージェント型のモデルと説明しています。描画の前に、参考画像や実在の場所・商品・ブランドの最新情報をWeb検索で調べられ、コードを実行してインフォグラフィックやチャートなどの構造化されたグラフィックをレイアウトすることもできます。

単発の画像エンドポイントは OpenAI Images API と互換性があり、base_url を https://api.meta.ai/v1 にすれば OpenAI クライアントを使えます。size パラメータで指定できるのはアスペクト比だけで、正確なピクセル数ではありません。出力形式はデフォルトで webp、png と jpeg も選べます。

このページには、テキストから画像を$0.00596 / 枚、編集 / 複数画像を$0.00596 / 枚と掲載しており、上の料金表と一致しています。

仕様はベンダーの公式ドキュメント（dev.meta.ai）に基づきます。このページの表は料金で、最新の料金はモデル一覧が正です。

Muse Image API よくある質問

Muse Image API の料金はいくらですか？

AnyAIGC では、Muse Image（muse-image）は1枚あたり$0.00596で、トークンではなくリクエスト単位で課金されます。Meta の定価は1枚あたり$0.01です。n 枚を指定したリクエストは n 枚分が課金され、成功した生成のみが対象です。最新の料金はモデル一覧でご確認ください。

Muse Image とは？

Muse Image は、Meta Superintelligence Labs が2026年7月に公開した画像生成・画像編集モデルです。描画の前にWeb検索やコードの作成ができ、自身の下書きを見直して改善します。プロンプトへの忠実さ、精密な編集、複数画像の合成を重視して作られています。

サイズやアスペクト比はどう指定しますか？

size に "WxH" の形式で指定します（例："1024x1536"）。Meta のドキュメントによると、指定できるのはアスペクト比のみで、モデルは独自の解像度で描画するため、返される寸法は完全には一致しません。16:1 を超える比率はエラーになり、size を省略するとデフォルトの比率が使われます。

1回のリクエストで何枚まで生成でき、どの形式で返りますか？

n は1〜10（デフォルトは1）で、画像1枚につき data の要素が1つ返ります。output_format は webp（デフォルト）、png、jpeg から選べます。response_format はデフォルトで base64 を返し、url を指定すると一時リンクを返します。

画像の編集や、複数の参照画像の合成はできますか？

はい。1つのモデルで生成と編集の両方を扱えます。画像と指示を送ればその部分だけを変更し、複数の画像を送れば1つのシーンに合成します。AnyAIGC のモデル一覧では、muse-image は画像編集エンドポイント /v1/images/edits にも掲載されています。フィールドは AnyAIGC の API ドキュメントでご確認ください。

Web検索やコードツールは追加料金がかかりますか？

いいえ。Meta は組み込みの検索ツールとコードツールを1枚あたりの料金に含めており、AnyAIGC も同じ方式で課金します。1枚あたり$0.00596で、ツールの別料金はありません。

同時実行数の制限はありますか？

AnyAIGC では、どのアカウントでも Muse Image の同時実行数に上限を設けていません。ベース URL は https://anyaigc.ai で、Meta の開発者アカウントは不要です。同じキーで他の300以上のモデルも使えます。

AnyAIGC で請求書を発行できますか？

はい。実際にチャージした金額分の請求書を、コンソールでご自身で発行できます。

対応している支払い方法は何ですか？

WeChat Pay、Alipay、USDT、クレジットカードでチャージできます。残高は USD で、プラットフォーム上のすべてのモデルで使えます。チャージした金額分の請求書は、コンソールで発行できます。

新規ユーザー向けの無料トライアルはありますか？

はい。新規アカウントには200万トークン分のトライアル枠が付与されるので、チャージするかどうか決める前に試せます。チャージは $1 から可能です。

残高は返金できますか？

はい。未使用の残高は手数料なしで返金できます。返金をご希望の場合は、サポートにご連絡ください。

本物のモデルですか？データは安全ですか？

リクエストは公式のモデルチャネルに送られ、安価な代替モデルやリバースエンジニアリングによるモデルは使いません。法令で求められる場合を除き、プロンプトや出力を永続的に保存せず、学習にも使用しません。コンソールでは、リクエストごとのトークン数と料金を確認できます。

生成した画像は商用利用できますか？

利用権とコンテンツポリシーは Meta の公式規約に従います。AnyAIGC は API アクセスを提供するだけで、出力の利用方法に追加の制限は設けません。
