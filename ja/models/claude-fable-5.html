Claude Fable 5 API のよくある質問

Claude Fable 5 API の料金はいくらですか？

AnyAIGC では、claude-fable-5 はトークン単位で課金されます。入力は100万トークンあたり$2.382、出力は100万トークンあたり$11.912、5分キャッシュ書き込みは$2.9779、1時間キャッシュ書き込みは$4.7647、キャッシュヒットは$0.2382です。Anthropic の定価は入力$10、出力$50のため、AnyAIGC は定価の約23.8%で、76%オフです。

Claude Fable 5 のモデルIDは何ですか？APIは Anthropic 互換ですか？

モデルIDは claude-fable-5 です。リクエストボディの model フィールドに指定してください。エンドポイントは https://anyaigc.ai/v1/messages で、リクエストボディは Anthropic Messages 形式（model、max_tokens、system、messages、tools、cache_control など）に従います。認証は Authorization: Bearer のあとにAPIキーを続けます。公式SDKを使う場合は、ベースURLを https://anyaigc.ai に設定するだけです。

Claude Fable とは何ですか？Opus とはどう違いますか？

Claude Fable は、Anthropic の Mythosクラスのモデルのラインです。Anthropic は Claude Fable 5 を、一般利用向けに安全性を高めた Mythosクラスのモデルと説明し、Mythosクラスのモデルは能力の面で Opus クラスの上に位置するとしています。Claude Mythos 5 は同じ基盤モデルで安全対策を減らしたもので、認証済みの組織にのみ提供されています。Anthropic によると、タスクが長く複雑になるほど、Fable 5 と他のモデルとの差は大きくなります。

Claude Fable 5 は提供終了になりましたか？いつまで使えますか？

引き続き利用できます。Anthropic は Claude Fable 5 を Active（Legacy）としており、2027年6月9日より前には提供を終了しないとしています。新規プロジェクトでは、Anthropic は Claude Fable 5.1（claude-fable-5-1）を推奨しています。

Claude Fable 5 は何が得意ですか？

難度が高く、長期にわたる作業に向いています。長時間実行のエージェント型コーディング、複数ステップのリサーチ、ドキュメント・スプレッドシート・スライドの作業、コンピュータ操作（computer use）のエージェントなどです。Anthropic のドキュメントでは、コンテキスト長は1Mトークン、最大出力は128Kとされています。Anthropic が公表した結果では、SWE-Bench Pro で80.3%、OSWorld-Verified で85.0%を記録しています。

Claude Fable 5 を Claude Code で使えますか？

はい。~/.claude/settings.json の env ブロックで、ANTHROPIC_BASE_URL に https://anyaigc.ai、ANTHROPIC_AUTH_TOKEN にAPIキー、ANTHROPIC_MODEL と ANTHROPIC_DEFAULT_OPUS_MODEL の両方に claude-fable-5 を設定し、claude を実行してください。1つのコマンドでインストールから設定まで済ませることもできます：curl -fsSL https://www.anyaigc.ai/install.sh | bash。

プロンプトキャッシュはどのように課金されますか？

キャッシュを有効にするには、コンテンツブロックに cache_control を追加します。最初の書き込みはキャッシュ書き込みの料金で課金されます（5分で100万トークンあたり$2.9779、1時間で$4.7647）。それ以降、キャッシュされたトークンは100万トークンあたり$0.2382で、通常の入力料金の10%です。長いシステムプロンプト、大規模なコードベースのコンテキスト、長時間実行のエージェントタスクで効果を発揮します。

同時実行数やレート制限はありますか？

AnyAIGC では claude-fable-5 の同時実行数に上限を設けていません。すべてのアカウントで標準で利用できるため、バッチ処理や複数エージェントの並列実行に向いています。

Claude Fable 5 のAPIキーはどのように取得しますか？

anyaigc.ai でアカウントを登録し、チャージしたうえで、コンソールでトークンを作成してください。同じキーで Claude Fable 5 と、プラットフォーム上の300以上のモデルを利用できます。

AnyAIGC で請求書を発行できますか？

はい。実際にチャージした金額分の請求書を、コンソールでご自身で発行できます。

対応している支払い方法は何ですか？

WeChat Pay、Alipay、USDT、クレジットカードでチャージできます。残高は USD で、プラットフォーム上のすべてのモデルで使えます。チャージした金額分の請求書は、コンソールで発行できます。

新規ユーザー向けの無料トライアルはありますか？

はい。新規アカウントには200万トークン分のトライアル枠が付与されるので、チャージするかどうか決める前に試せます。チャージは $1 から可能です。

残高は返金できますか？

はい。未使用の残高は手数料なしで返金できます。返金をご希望の場合は、サポートにご連絡ください。

本物のモデルですか？データは安全ですか？

リクエストは公式のモデルチャネルに送られ、安価な代替モデルやリバースエンジニアリングによるモデルは使いません。法令で求められる場合を除き、プロンプトや出力を永続的に保存せず、学習にも使用しません。コンソールでは、リクエストごとのトークン数と料金を確認できます。

データは学習に使われますか？

リクエストはHTTPSで暗号化されて送信されます。データの取り扱いについては、AnyAIGC のプライバシーポリシーをご覧ください。Anthropic によると、Fable の利用では安全性の監視のため、デフォルトで30日間のデータ保持が必要です。モデル自体のデータポリシーは Anthropic の公式規約に従います。
