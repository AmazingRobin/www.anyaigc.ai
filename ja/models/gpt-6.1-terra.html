GPT-6.1 Terra API を3ステップで呼び出す

  1. 登録とチャージ：anyaigc.ai でアカウントを作成します。残高はすべてのモデルで共通です。
  2. APIキーを作成：コンソールでトークンを作成し、sk- で始まるキーをコピーして、環境変数 ANYAIGC_API_KEY に保存します。
  3. リクエストを送信：model に gpt-6.1-terra を指定し、Authorization: Bearer 認証で https://anyaigc.ai/v1/chat/completions または https://anyaigc.ai/v1/responses を呼び出します。

ツール呼び出しには Responses API を使ってください。OpenAI によると、gpt-6.1-terra でのツール呼び出し（関数呼び出し、コンピュータ操作などのツール）には Responses API が必要です。通常のチャット、画像入力、ストリーミングはこれまでどおり /v1/chat/completions を使い、ツールが必要になったら /v1/responses に切り替えて、強度は reasoning.effort で指定します。

すべてのパラメータは Chat Completions リファレンスと Responses リファレンスをご覧ください。フィールドは公式の OpenAI API と同じです。

Codex で GPT-6.1 Terra を使う

コマンド1つで Codex CLI をインストールし、AnyAIGC の設定を書き込みます。~/.codex/ の2つのファイルを自分で編集することもできます。

ワンライン・インストーラーはモデルを gpt-5.5 に設定するため、そのあとで ~/.codex/config.toml の model を gpt-6.1-terra に変更してください。両方のファイルを保存し、プロジェクトのフォルダで codex を実行します。Codex は Responses API を使うので、ツール呼び出しも通常どおり動作します。Terra は高速で低コストなので、文章の校正、ドキュメント、スクリーンショットを使う作業に向いています。複数ファイルにまたがる複雑なコーディングには GPT-6.1 Sol に切り替えてください。詳しい手順とよくあるエラーは Codex 設定ガイドをご覧ください。

GPT-6.1 Terra API の料金はいくらですか？

AnyAIGC では、gpt-6.1-terra はトークン単位で課金され、入力は100万トークンあたり$0.0496、出力は$0.2482、キャッシュ入力は$0.0025です。OpenAI の定価は入力$1.00、出力$5.00、キャッシュ入力$0.05なので、AnyAIGC は定価の約5%（95%オフ）です。1回のリクエストの入力が272Kトークンを超える場合、そのリクエスト全体が入力とキャッシュは2倍、出力は1.5倍で課金されます。最新の料金はモデル一覧でご確認ください。

GPT-6.1 Terra のモデルIDは何ですか？

モデルIDは gpt-6.1-terra です。リクエストの model フィールドに指定してください。

GPT-6.1 Terra と GPT-5.6 Terra の違いは何ですか？

GPT-6.1 Terra は GPT-5.6 Terra の後継です。定価は、入力$2、出力$12、キャッシュ入力$0.20から、100万トークンあたり$1、$5、$0.05に下がりました。OpenAI によると、Terminal-Bench 4.0 のスコアは21.5%から50.3%に上がり、Agents' Last Exam は15ポイント高く、社内評価の事実の誤り率は53.6%から16.7%に下がっています。知識のカットオフは2026-02-16から2026-06-01に更新されました。AnyAIGC では、100万トークンあたり、GPT-6.1 Terra は入力$0.0496、出力$0.2482、GPT-5.6 Terra は入力$0.0993、出力$0.5957です。

GPT-6.1 Terra と GPT-6.1 Sol のどちらを使うべきですか？

Terra の定価は Sol の半額で、OpenAI によるとタスクの完了は3倍以上速くなっています。画像理解、コンピュータ操作、技術文書の作成では Sol に近く、それ以外の多くの用途では少し劣ります。画像理解、フォーム入力、文章、ドキュメントはまず Terra で始め、複数ファイルにまたがる複雑なコーディング、長いエージェントのチェーン、深い推論には GPT-6.1 Sol を選んでください。AnyAIGC では、100万トークンあたり、GPT-6.1 Terra は入力$0.0496、出力$0.2482、GPT-6.1 Sol は入力$0.0993、出力$0.4964です。

Chat Completions と Responses API のどちらを使えばよいですか？ツールは使えますか？

どちらのエンドポイントも使えます。通常のチャット、画像入力、ストリーミングには https://anyaigc.ai/v1/chat/completions を使ってください。OpenAI によるとツール呼び出しには Responses API が必要なので、関数呼び出し、コンピュータ操作などのツールには https://anyaigc.ai/v1/responses を使い、強度は reasoning.effort で指定します。
