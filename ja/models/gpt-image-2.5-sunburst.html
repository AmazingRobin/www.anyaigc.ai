GPT Image 2.5 Sunburst API のよくある質問

GPT Image 2.5 Sunburst API の料金はいくらですか？

AnyAIGC では gpt-image-2.5-sunburst はトークン単位で課金され、100万トークンあたりテキスト入力$2.9700、画像入力$4.7520、画像出力$17.8200です。テキストのキャッシュ入力は$1.1880、画像のキャッシュ入力は$1.9010です。OpenAI の定価は$5.00、$8.00、$30.00です。1024×1024、medium 品質の画像は、画像出力で約$0.0078（定価では約$0.0132）です。最新の料金はモデル一覧でご確認ください。

Sunburst と Flare の違いは何ですか？

どちらも GPT Image 2.5 で、OpenAI の公式トークン料金は同じで、品質は low から max まで選べます。OpenAI は Sunburst を編集精度が最も高いモデル（性能は「Highest」、速度は「Medium」）、Flare を日常的な作業向けの最速の高品質モデル（性能は「Higher」、速度は「Very fast」）と位置づけています。レタッチや編集には Sunburst、大量処理や速度重視には Flare を選んでください。AnyAIGC では料金は同じです。

対応しているサイズ、品質、フォーマットは？

一般的なサイズは 1024×1024、1536×1024、1024×1536、2048×2048、2048×1152、3840×2160、2160×3840、auto です。長辺が3840px以下、両辺が16の倍数、アスペクト比が3:1以下、総ピクセル数が655,360〜8,294,400であれば、カスタムサイズも使えます。品質は low、medium、high、xhigh、max、auto から選べます。format フィールドで png、jpeg、webp を指定でき、画像URLまたは base64 で受け取れます。最低価格はカスタムサイズにも適用され、透過背景はモデル一覧に記載のとおり料金が高くなります。

画像から画像への編集やインペイントはどうすればよいですか？

multipart/form-data で POST /v1/images/edits を呼び出します。image フィールドには、16枚未満、合計50MBまでの参照画像を渡せます。インペイントでは mask も送ります。マスクの透明な部分が再描画され、4MB未満で、1枚目の画像と同じサイズの PNG である必要があります。パラメータはedits のドキュメントをご覧ください。

1枚あたり課金のバージョンはありますか？ gpt-image-2.5-sunburst-c の料金は？

はい。AnyAIGC の gpt-image-2.5-sunburst-c は、GPT Image 2.5 Sunburst の1枚あたり課金版です。エンドポイントは同じで、変わるのは model フィールドだけです。どの品質でも1枚あたりの料金は一定で、1K出力は$0.0159、2Kと4K出力は$0.0199です。1回のリクエストで1枚が返され、n、mask、透過背景には対応していません。high 以上の品質や大きいサイズでは、1枚あたり課金のほうが通常は安くなります。

AnyAIGC は gpt-image-2.5-sunburst の同時実行数に上限を設けておらず、すべてのアカウントでデフォルトで適用されます。ベースURLは https://anyaigc.ai/v1 です。課金は USD で、WeChat Pay、Alipay、USDT、クレジットカードで支払えます。同じキーで300以上のほかのモデルも使えます。
