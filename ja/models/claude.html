Anthropic ネイティブAPI をフルサポート

リクエストは Anthropic の Messages 形式なので、公式 SDK と既存のコードをそのまま使えます。

  • Messages API

    /v1/messages を呼び出します。Anthropic 公式 SDK では、ベース URL を https://anyaigc.ai に設定してください。

  • プロンプトキャッシュ

    コンテンツブロックに cache_control を追加すると、5分または1時間のキャッシュが使えます。キャッシュヒットの料金は通常の入力料金の約2.5–10%です。

  • ツール利用と構造化出力

    tools で関数を定義するか、JSON スキーマで出力を制約して、自社のシステムに組み込めます。

  • アダプティブシンキング

    thinking と推論の強度（effort）のパラメータを使います。Anthropic のドキュメントによると、Fable 5.1 や Sonnet 5 などのモデルはデフォルトでアダプティブシンキングを使います。詳しくは各モデルのページをご覧ください。

  • 画像と PDF の入力

    AnyAIGC のドキュメントには PDF ドキュメントの例があり、Claude モデルの画像入力については Anthropic のドキュメントで説明されています。

  • ストリーミング

    "stream": true を指定すると、生成された出力を順次受け取れます。チャット UI や長い応答に便利です。

3ステップで始める

  1. 登録してチャージする：anyaigc.ai でアカウントを作成します。残高は、プラットフォーム上のすべてのモデルで使えます。
  2. APIキーを作成する：コンソールでトークンを作成し、sk- で始まるキーをコピーします。
  3. リクエストを送る：Anthropic の Messages リクエストで https://anyaigc.ai/v1/messages を呼び出し、認証には Authorization: Bearer を使います。

そのほかのパラメータ（tools、thinking、ストリーミング、PDF・画像入力など）は AnyAIGC Messages API ドキュメントをご覧ください。各フィールドの意味は Anthropic の API ドキュメントと同じです。

Claude API のよくある質問

Claude API の料金はいくらですか？

AnyAIGC のすべての Claude モデルは、サブスクリプションや月額料金なしで、100万トークンあたりの USD でトークン単位に課金されます。現行モデル：Opus 5.5 は入力 $0.4765、出力 $2.3820。Sonnet 5.5 は入力 $0.2382、出力 $1.1910。Haiku 5.5 は入力 $0.0119、出力 $0.0596。Fable 5.2 は入力 $1.9060、出力 $9.5290。Opus、Sonnet、Haiku は Anthropic の定価から88%オフ、Fable は76%オフです。キャッシュ書き込み、キャッシュヒット、旧世代モデルの料金はこのページの料金表に掲載しています。最新の料金は AnyAIGC モデル一覧でご確認ください。

Claude の APIキーはどう取得しますか？

anyaigc.ai で登録し、残高をチャージして、コンソールでトークンを作成してください。同じキーで、このページの Claude 全11モデルと、プラットフォーム上のほかの 300+ モデルを利用でき、すべて1つの残高から差し引かれます。

AnyAIGC の Claude API は Anthropic の公式 SDK で使えますか？

はい。エンドポイントは https://anyaigc.ai/v1/messages で、リクエストボディは Anthropic の Messages 形式（model、max_tokens、system、messages、tools、cache_control など）に従います。認証は Authorization: Bearer と APIキーを使います。公式の anthropic SDK では base_url を https://anyaigc.ai に設定するだけで、ほかのコードは変更不要です。

利用できる Claude モデルはどれですか？どれを選べばよいですか？

AnyAIGC では Claude の11モデルを提供しています。現行モデルは Opus 5.5、Sonnet 5.5、Haiku 5.5、Fable 5.2 です。複雑なコーディングと AIエージェントには Opus 5.5、範囲が明確な日常的なコーディング、バグ修正、ドキュメントには Sonnet 5.5、大量の分類、リアルタイムのサポート、サブエージェントには Haiku 5.5（Anthropic が Claude 5.5 ファミリーで最速かつ最も効率的なモデルとしています）、最も野心的で答えが決まっていない技術的課題や長時間実行のエージェントには Fable 5.2 をお使いください。ひとつ前の Fable 5.1 と、旧世代の Opus 5、Fable 5、Sonnet 5、Opus 4.8、Opus 4.7、Opus 4.6 は、既存プロジェクト向けに引き続き利用できます。

Claude Opus と Sonnet の違いは何ですか？

Anthropic は Sonnet 5.5 を、Opus 5.5 を補う、より高速で低コストなモデルと位置づけています。Opus 5.5 は慎重な判断が必要な複雑な作業向け、Sonnet 5.5 は範囲が明確な日常タスク、バグ修正、完成度の高いドキュメント、スライド、スプレッドシート向けです。Sonnet 5.5 の料金は半額で、AnyAIGC では入力 $0.2382、出力 $1.1910（Opus 5.5 は $0.4765 と $2.3820）です（100万トークンあたり）。

Claude Fable と Opus の違いは何ですか？

Anthropic は Fable 5.2 を、長時間実行のエージェント向けの次世代インテリジェンスで、最も野心的で答えが決まっていない技術的課題向けに作られたモデルと説明しています。Anthropic は、ほとんどのコーディングとナレッジワークをまず Claude Opus 5.5 で始め、必要に応じて Fable に切り替えることを推奨しています。AnyAIGC では、Fable 5.2 は100万トークンあたり入力 $1.9060、出力 $9.5290 で、Opus 5.5 は $0.4765 と $2.3820 です。どちらも同じキーで使えるので、model フィールドを変えるだけでタスクごとに切り替えられます。

旧バージョンの Claude モデルも使えますか？

はい。Anthropic が旧世代としている Opus 5、Fable 5、Sonnet 5、Opus 4.8、Opus 4.7、Opus 4.6 は、AnyAIGC ですべて引き続き利用できます。Anthropic が示す最も早い提供終了日は、Opus 4.6 が2027年2月5日、Opus 4.7 が2027年4月16日、Opus 4.8 が2027年5月28日、Fable 5 が2027年6月9日、Sonnet 5 が2027年6月30日、Opus 5 が2027年7月24日です。ひとつ前の Fable 5.1 も引き続き利用できます。新規プロジェクトでは、対応する現行モデルをお使いください。

Claude Code で使えますか？

はい。curl -fsSL https://www.anyaigc.ai/install.sh | bash -s claude を実行すると、インストールと設定がまとめて行われます。手動で設定する場合は、~/.claude/settings.json の env ブロックで、ANTHROPIC_BASE_URL に https://anyaigc.ai、ANTHROPIC_AUTH_TOKEN に APIキー、ANTHROPIC_MODEL に claude-opus-5-5 を設定してください。さらに ANTHROPIC_DEFAULT_HAIKU_MODEL に claude-haiku-5-5 を設定すると、バックグラウンドタスクとサブエージェントを Haiku 5.5 で実行できます。

同時実行数に制限はありますか？

ありません。AnyAIGC はどの Claude モデルにも同時実行数の上限を設けておらず、すべてのユーザーがデフォルトで利用できます。バッチ処理や並列のエージェントも待たされません。

AnyAIGC で請求書を発行できますか？

はい。実際にチャージした金額分の請求書を、コンソールでご自身で発行できます。

対応している支払い方法は何ですか？

WeChat Pay、Alipay、USDT、クレジットカードでチャージできます。残高は USD で、プラットフォーム上のすべてのモデルで使えます。チャージした金額分の請求書は、コンソールで発行できます。

新規ユーザー向けの無料トライアルはありますか？

はい。新規アカウントには200万トークン分のトライアル枠が付与されるので、チャージするかどうか決める前に試せます。チャージは $1 から可能です。

残高は返金できますか？

はい。未使用の残高は手数料なしで返金できます。返金をご希望の場合は、サポートにご連絡ください。

本物のモデルですか？データは安全ですか？

リクエストは公式のモデルチャネルに送られ、安価な代替モデルやリバースエンジニアリングによるモデルは使いません。法令で求められる場合を除き、プロンプトや出力を永続的に保存せず、学習にも使用しません。コンソールでは、リクエストごとのトークン数と料金を確認できます。
