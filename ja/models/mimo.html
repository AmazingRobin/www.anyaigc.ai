Python ストリーミング
# pip install openai
import os
from openai import OpenAI

client = OpenAI(api_key=os.environ["ANYAIGC_API_KEY"], base_url="https://anyaigc.ai/v1")

stream = client.chat.completions.create(
    model="mimo-v2.6-flash",
    messages=[{"role": "user", "content": "Introduce yourself in three sentences and say what tasks you are best at."}],
    stream=True,
)
for chunk in stream:
    if chunk.choices and chunk.choices[0].delta.content:
        print(chunk.choices[0].delta.content, end="", flush=True)
print()

FAQ

MiMo API のよくある質問

Xiaomi MiMo API の料金はいくらですか。60%オフはどのように計算されますか。

MiMo-V2.6-Pro は入力 $0.1749、出力 $0.3497（公式は $0.435 と $0.87）、MiMo-V2.6-Flash は $0.0563 と $0.1126（公式は $0.14 と $0.28）で、単位は USD / 100万トークンです。お支払いは Xiaomi MiMo 公式の従量課金 USD 価格の約40%、つまり約60%オフです。最新の料金はモデル一覧でご確認ください。

MiMo の4つのモデルはどう選べばよいですか。

複雑で長期にわたるエージェント、コーディング、リサーチには MiMo-V2.6-Pro、大量のオフィス業務には MiMo-V2.6-Flash を選んでください。Xiaomi は MiMo-V2.5-Pro と MiMo-V2.5 の提供を終了しているため、新規プロジェクトでは V2.6 を使ってください。

MiMo-V2.5 シリーズは提供終了しましたか。

はい。Xiaomi は mimo-v2.5-pro と mimo-v2.5 を 2026-10-21 10:00（UTC+8）に提供終了しました。後継は mimo-v2.6-pro と mimo-v2.6-flash です。AnyAIGC のモデル一覧には両方が引き続き掲載されており、移行は model フィールドを変更するだけです。

OpenAI SDK で使えますか。エンドポイントはどれですか。

はい。4つのモデルすべてで、OpenAI 互換の POST https://anyaigc.ai/v1/chat/completions を使い、Authorization: Bearer <API Key> で認証します。OpenAI SDK では base_url を https://anyaigc.ai/v1 に設定してください。

同時実行数やRPMの制限はありますか？

AnyAIGC の MiMo は同時実行数の上限がなく、固定の RPM 上限もありません。すべてのアカウントでデフォルトです。長いコンテキストやディープシンキングのリクエストは時間がかかるため、タイムアウトとリトライを適切に設定してください。

出力は商用利用できますか？

モデルとその出力の利用は Xiaomi MiMo の公式規約に従います。AnyAIGC は独立した API プロバイダーであり、Xiaomi とは提携していません。

AnyAIGC で請求書を発行できますか？

はい。実際にチャージした金額分の請求書を、コンソールでご自身で発行できます。

対応している支払い方法は何ですか？

WeChat Pay、Alipay、USDT、クレジットカードでチャージできます。残高は USD で、プラットフォーム上のすべてのモデルで使えます。チャージした金額分の請求書は、コンソールで発行できます。

新規ユーザー向けの無料トライアルはありますか？

はい。新規アカウントには200万トークン分のトライアル枠が付与されるので、チャージするかどうか決める前に試せます。チャージは $1 から可能です。

残高は返金できますか？

はい。未使用の残高は手数料なしで返金できます。返金をご希望の場合は、サポートにご連絡ください。

本物のモデルですか？データは安全ですか？

リクエストは公式のモデルチャネルに送られ、安価な代替モデルやリバースエンジニアリングによるモデルは使いません。法令で求められる場合を除き、プロンプトや出力を永続的に保存せず、学習にも使用しません。コンソールでは、リクエストごとのトークン数と料金を確認できます。
