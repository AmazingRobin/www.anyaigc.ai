概要

汎用のオープンなマルチモーダルエージェントモデル

Moonshot AI は Kimi K2.6 を、オープンなネイティブマルチモーダルのエージェントモデルと位置づけています。Moonshot によると、長いコードをより高い能力で安定して書けるようになり、指示追従と自己修正も明確に向上しています。テキストと画像を入力でき、思考モードと非思考モードがあるため、チャットにもエージェントタスクにも使えます。

Technisch ist es ein MoE mit 1T Gesamtparametern und 32B aktiven Parametern, 256K Kontext und nativer INT4-Quantisierung. Moonshot hebt vier Bereiche hervor: langfristiges Coding, UI aus Prompts oder Bildern (Coding-Driven Design), Agent Swarm mit Skalierung auf 300 Sub-Agenten sowie proaktive Agenten, die rund um die Uhr laufen.

AnyAIGC では、kimi-k2.6は OpenAI 互換の/v1/chat/completionsエンドポイントで動作し、Claude Code でそのまま使えます。同時実行数は上限なしです。

クイックスタート

3ステップで Kimi K2.6 API に接続

  1. 登録とチャージ：anyaigc.ai でアカウントを作成します。$1からチャージでき、残高はプラットフォーム上のすべてのモデルで使えます。
  2. APIキーを作成：コンソールでキーを作成し、sk- で始まる値をコピーして、環境変数 ANYAIGC_API_KEY に保存します。
  3. リクエストを送る：POST https://anyaigc.ai/v1/chat/completions を呼び出し、model に kimi-k2.6 を指定して、Authorization: Bearer ヘッダーを付けます。OpenAI SDK なら、base_url を https://anyaigc.ai/v1 に設定するだけです。

ヒント：K2.6 はデフォルトで思考し、推論内容は reasoning_content で返ります。Moonshot の API では thinking: {"type": "disabled"} で思考モードをオフにできます（OpenAI SDK では extra_body で渡します）。非思考モードでは、Moonshot は temperature=0.6 を推奨しています。思考モードでのマルチターン会話やツール呼び出しでは、アシスタントのメッセージ全体を変更せずに次のリクエストへ送り返してください。

Alle Parameter finden Sie in der Chat-Completions-Referenz. Ersetzen Sie den Modellnamen in den Beispielen der Dokumentation durch die gewünschte Kimi-Modell-ID.

Claude Code

Claude Code で Kimi K2.6 を使う

Claude Code を Kimi K2.6 に切り替えます。マルチモーダルで低コストなので、日常のコーディングや、スクリーンショットからの UI 修正に向いています。

  1. Claude Code installieren: Verwenden Sie das offizielle Installationsprogramm (zum Beispiel npm install -g @anthropic-ai/claude-code).
  2. 設定を追加：~/.claude/settings.json を編集し、下の env ブロックを追加して、ANTHROPIC_AUTH_TOKEN を AnyAIGC で作成したキーに置き換えます。
  3. Loslegen: Führen Sie claude in Ihrem Projektordner aus. Geben Sie /model ein, um zu prüfen, ob das aktuelle Modell kimi-k2.6 ist.

コーディング用モデルに切り替える：コーディングの成功率を上げたい場合は、設定の kimi-k2.6 を kimi-k2.7-code に置き換えます。料金は同じです。

Die vollständige Anleitung und häufige Fehler finden Sie in der Einrichtungsanleitung für Claude Code. Ersetzen Sie den Modellnamen in der Anleitung durch kimi-k2.6.

FAQ

Kimi K2.6 API のよくある質問

Kimi K2.6 API の料金はいくらですか？

Bei AnyAIGC wird kimi-k2.6 pro Token abgerechnet: Eingabe $0,3847 pro 1 Mio. Tokens, Ausgabe $1,5980 pro 1 Mio. Tokens, Cache-Treffer $0,0651 pro 1 Mio. Tokens. Die offiziellen USD-Preise von Moonshot betragen $0,95 für die Eingabe, $4,00 für die Ausgabe und $0,16 für Cache-Treffer. AnyAIGC kostet also rund 40 % des offiziellen Preises. Aktuelle Preise finden Sie im Modellkatalog.

Kimi K2.6 のモデルIDとコンテキスト長は？

モデルIDは kimi-k2.6 です。Moonshot は262,144トークン（256K）のコンテキスト長を掲載しており、テキストと画像を入力できます。

Kimi K2.6 で思考モードをオフにできますか？

K2.6 は思考モードと非思考（Instant）モードの両方に対応しています。Moonshot の API では thinking: {"type": "disabled"} で思考モードをオフにでき、OpenAI SDK では extra_body で渡します。Moonshot は、思考モードでは temperature=1.0、非思考モードでは temperature=0.6 を推奨しており、top_p はどちらも0.95です。

Kimi K2.6 の特長は何ですか？

Moonshot positioniert K2.6 als offenes, nativ multimodales Agent-Modell mit vier Schwerpunkten: Coding über lange Zeiträume (Rust, Go, Python, Frontend, DevOps und Performance-Tuning), produktionsreife UIs aus Prompts oder Bildern, Agent Swarm (Skalierung auf 300 Sub-Agents und 4.000 koordinierte Schritte) und proaktive Agents, die 24/7 im Hintergrund laufen.

Kimi K2.6 と K2.7 Code はどちらを使うべきですか？

Beide teilen sich die Architektur und kosten bei AnyAIGC für Eingabe und Ausgabe gleich viel. K2.7 Code ist ein für Coding weitertrainiertes K2.6 mit höheren Coding-Werten und weniger Denk-Tokens, läuft aber nur im Denkmodus. K2.6 lässt sich ohne Denkmodus betreiben, was zu schnellem Chat, Klassifikation, Extraktion und allgemeinen Agenten passt.

Claude Code で Kimi K2.6 を使えますか？

はい。~/.claude/settings.json の env ブロックで、ANTHROPIC_BASE_URL を https://anyaigc.ai、ANTHROPIC_AUTH_TOKEN をご自身の APIキー、ANTHROPIC_MODEL を kimi-k2.6 に設定し、claude を実行してください。

Kimi K2.6 はツール呼び出しと画像入力に対応していますか？

はい。K2.6 は複数ステップのツール呼び出し、ストリーミング、画像入力に対応しています。思考モードでのマルチターン会話やツール呼び出しでは、アシスタントのメッセージ全体（reasoning_content と tool_calls を含む）を変更せずに次のリクエストへ送り返してください。

同時実行数やレート制限はありますか？

AnyAIGC begrenzt die Parallelität für kimi-k2.6 nicht, und jeder Nutzer hat das standardmäßig. Das passt zu Batch-Jobs, CI-Pipelines und parallelen Agenten. Die Plattform von Moonshot begrenzt Parallelität, RPM, TPM und TPD nach Aufladestufe; diese Stufen gelten nicht, wenn Sie über AnyAIGC aufrufen.

Kimi K2.6 の APIキーはどうやって取得しますか？

anyaigc.ai で登録し、残高をチャージして、コンソールでキーを作成します。同じキーで、プラットフォーム上のすべての Kimi モデルと300以上のほかのモデルを呼び出せるため、Moonshot のプラットフォームアカウントは別途必要ありません。

はい。実際にチャージした金額分の請求書を、コンソールでご自身で発行できます。

対応している支払い方法は何ですか？

残高は返金できますか？

本物のモデルですか？データは安全ですか？

リクエストは公式のモデルチャネルに送られ、安価な代替モデルやリバースエンジニアリングによるモデルは使いません。法令で求められる場合を除き、プロンプトや出力を永続的に保存せず、学習にも使用しません。コンソールでは、リクエストごとのトークン数と料金を確認できます。

入力したデータはトレーニングに使われますか？
