OpenAI ネイティブのエンドポイントに完全対応

リクエストは公式の OpenAI API と同じ形式なので、公式 SDK や既存のコードは base_url を変更するだけで移行できます。

  • Chat Completions

    チャットエンドポイント

    標準の messages 形式で /v1/chat/completions を呼び出します。既存のコードやフレームワークはそのまま動作します（GPT-5.5 Pro を除く）。

  • Responses API

    Responses とツール呼び出し

    関数呼び出しには /v1/responses を使用します。Codex もこのエンドポイントを使います。

  • 構造化出力（Structured Outputs）

    構造化出力

    JSON Schema でレスポンスを制約できるため、正規表現によるフォールバックなしで結果を解析・保存できます。

  • reasoning_effort

    推論の強度

    Chat Completions では reasoning_effort、Responses では reasoning.effort を使います。GPT-6 は max まで指定できます。GPT-6 Sol と GPT-6 Luna は none にも対応していますが、GPT-6.1 Sol と GPT-6 Astra は対応していません。

  • 画像入力

    画像入力

    すべてのモデルがテキストと画像を入力でき、テキストを返すため、スクリーンショット、グラフ、スキャン画像も送信できます。

  • ストリーミング

    ストリーミング

    stream: true を指定すると、生成されたトークンを順次受け取れます。GPT-5.5 Pro はストリーミングに対応していません。

GPT-6 のツール呼び出しには /v1/responses を使ってください。OpenAI によると、gpt-6.1-sol は Chat Completions でのツール呼び出しに対応しておらず、gpt-6.2-sol と gpt-6.2-astra には明記された制限がないものの、こちらも /v1/responses の利用をおすすめします。gpt-6-sol と gpt-6-luna は reasoning_effort を none に設定した場合のみそこで関数呼び出しに対応し、gpt-6-astra はどちらともドキュメントに記載がありません。通常のチャットとストリーミングは /v1/chat/completions で引き続き使えます。gpt-5.5-pro は /v1/responses のみで動作します。

3ステップで GPT API を呼び出す

  1. 登録とチャージ：anyaigc.ai でアカウントを作成します。残高はすべてのモデルで共通です。
  2. APIキーを作成：コンソールでトークンを作成し、sk- で始まるキーをコピーして、環境変数 ANYAIGC_API_KEY に保存します。
  3. リクエストを送信：OpenAI SDK の base_url を https://anyaigc.ai/v1 に設定し、model にこのページのいずれかのモデルIDを指定して、Authorization: Bearer で認証します。

すべてのパラメータは Chat Completions リファレンスと Responses リファレンスをご覧ください。フィールドは公式の OpenAI API と同じです。

Codex で GPT モデルを使う

コマンド1つで Codex CLI をインストールし、AnyAIGC の設定を書き込みます。~/.codex/ の2つのファイルを自分で編集することもできます。

ワンライン・インストーラーはモデルを gpt-5.5 に設定するため、インストール後に ~/.codex/config.toml の model を gpt-6.2-sol に変更してください（最も難しいタスクには gpt-6.2-astra）。両方のファイルを保存し、プロジェクトのフォルダで codex を実行します。Codex は Responses API を使うため、ツール呼び出しは通常どおり動作します。手順の詳細とよくあるエラーは Codex 設定ガイドをご覧ください。

GPT API のよくある質問

GPT API の料金はいくらですか？

AnyAIGC のすべての GPT モデルは、100万トークンあたりの USD でトークン単位の従量課金で、サブスクリプションや月額料金はありません。現行のティアは、GPT-6.2 Astra が入力$0.3971・出力$1.9860、GPT-6.2 Sol が入力$0.0993・出力$0.4964、GPT-6.1 Terra が入力$0.0496・出力$0.2482、GPT-6 Luna が入力$0.0135・出力$0.0675です。ほとんどのモデルは OpenAI の定価の約5%（95%オフ）、GPT-6 Luna と GPT-5.6 Luna は約13.5%、GPT-5.5 Pro は約59%です。全12モデルは 料金表を、最新の料金は AnyAIGC のモデル一覧をご覧ください。

GPT の APIキーはどう取得しますか？

anyaigc.ai で登録し、チャージして、コンソールでトークンを作成すると sk- で始まるキーを取得できます。同じキーで、このページの GPT 全12モデルと300以上のほかのモデルが、共通の残高で使えます。

公式の OpenAI SDK で使えますか？

はい。base_url を https://anyaigc.ai/v1 に、api_key を AnyAIGC のキーに設定すれば、既存のコードはほとんど、または全く変更せずに動作します。/v1/chat/completions と /v1/responses の両方に対応し、認証は Authorization: Bearer を使い、フィールドは公式の OpenAI API と同じです。

GPT の Astra、Sol、Terra、Luna はどれを使うべきですか？

これらは OpenAI の現行の4つの性能ティアです。OpenAI によると、Astra が最も高い知能を持ち、現行バージョンは GPT-6.2 Astra で、最も難しいプロジェクト向け、定価は GPT-6 Astra より20%低くなっています。Sol は速度、コスト、知能のバランスが取れており、現行バージョンは GPT-6.2 Sol で、OpenAI によると同じ定価（$2 / $10）で GPT-6.1 Sol より賢く、効率的です。Terra は Sol と Luna の中間で、現行バージョンは GPT-6.1 Terra、視覚的な推論、コンピュータ操作（computer use）、文章作成向けに作られ、高速で、定価は Sol の半額です。Luna は最速かつ最もコスト効率が高く、範囲の限られた高頻度のタスク向けです。ほとんどのコーディングやエージェント作業にはまず GPT-6.2 Sol から始め、最も難しいタスクには GPT-6.2 Astra に移り、大量の単純な作業には GPT-6 Luna を使ってください。

GPT-5.6 Terra と GPT-6.1 Terra はどういう関係ですか？

Terra は GPT-5.6 のバランス型ティアです。OpenAI は、GPT-5.5 並みの性能を低コストで提供する、日常業務向けのバランスの取れたモデルと説明しています。2026年10月26日に OpenAI は後継の GPT-6.1 Terra をリリースし、定価を $2 / $12から$1 / $5に引き下げました。GPT-5.6 Terra も引き続き呼び出せます。AnyAIGC では、100万トークンあたり gpt-5.6-terra が入力$0.0993・出力$0.5957、gpt-6.1-terra が入力$0.0496・出力$0.2482です。

GPT-6.1 Sol と GPT-6 Sol：何が変わりましたか？

OpenAI は GPT-6.1 Sol を GPT-6 Sol のアップグレードと説明しています。入力と出力の定価は$2と$10のままで、キャッシュ入力は$0.20から$0.10に下がり、OpenAI によると DeepSWE v1.1 や OSWorld 2.0 などのベンチマークで GPT-6 Sol より高いスコアです。GPT-6.1 Sol は推論の強度 none に対応しておらず、Chat Completions でのツール呼び出しにも対応していません。AnyAIGC ではどちらも入力$0.0993・出力$0.4964で、キャッシュ入力はそれぞれ$0.0050と$0.0099です。新規プロジェクトには GPT-6.1 Sol をお使いください。既存の連携は gpt-6-sol のままで構いません。

旧世代の GPT モデルも引き続き使えますか？

GPT-6 Sol、GPT-5.6 Sol、GPT-5.6 Terra、GPT-5.6 Luna、GPT-5.5、GPT-5.5 Pro にはいずれも新しい後継モデルがありますが、OpenAI は API の提供終了日を発表しておらず、現在 AnyAIGC ではすべて利用できます。新規プロジェクトには GPT-6.1 Sol、GPT-6.1 Terra、GPT-6 Astra、GPT-6 Luna をお使いください。

Codex で GPT モデルを使えますか？

はい。curl -fsSL https://www.anyaigc.ai/install.sh | bash -s codex を実行すると、インストールと設定ができます（Windows では irm https://www.anyaigc.ai/install.ps1 | iex）。インストーラーのデフォルトは gpt-5.5 なので、インストール後に ~/.codex/config.toml の model を gpt-6.1-sol または gpt-6-astra に変更してください。手動で設定する場合は、~/.codex/config.toml で base_url を https://anyaigc.ai/v1、wire_api を responses に設定し、~/.codex/auth.json に OPENAI_API_KEY を記述します。

同時実行数に制限はありますか？

AnyAIGC では、どの GPT モデルにも同時実行数の上限を設けていません。すべてのアカウントでデフォルトで適用されるため、バッチ処理や並列エージェントも待たされることなく実行できます。

AnyAIGC で請求書を発行できますか？

はい。実際にチャージした金額分の請求書を、コンソールでご自身で発行できます。

はい。新規アカウントには500万トークン分のトライアル枠が付与されるので、チャージするかどうか決める前に試せます。チャージは $1 から可能です。

残高は返金できますか？

はい。未使用の残高は手数料なしで返金できます。返金をご希望の場合は、サポートにご連絡ください。

本物のモデルですか？データは安全ですか？
