3ステップで GPT-5.6 Luna API を呼び出す

  1. 登録とチャージ：anyaigc.ai でアカウントを作成します。残高はすべてのモデルで共通です。
  2. APIキーを作成：コンソールでトークンを作成し、sk- で始まるキーをコピーして、環境変数 ANYAIGC_API_KEY に保存します。
  3. リクエストを送信：https://anyaigc.ai/v1/chat/completions または https://anyaigc.ai/v1/responses を呼び出し、model に gpt-5.6-luna を指定して、Authorization: Bearer で認証します。

ツール呼び出しは両方のエンドポイントで使えます。OpenAI によると、gpt-5.6-luna は Chat Completions、Responses、Batch に対応し、関数呼び出しと構造化出力を利用できます。通常のチャットと関数呼び出しには /v1/chat/completions、Responses API の組み込みツールや複数ステップのエージェントワークフローには /v1/responses を使い、推論の強度は reasoning.effort で指定します。

すべてのパラメータは Chat Completions リファレンスと Responses リファレンスをご覧ください。フィールドは公式の OpenAI API と同じです。

GPT-5.6 Luna API のよくある質問

GPT-5.6 Luna API の料金はいくらですか？

AnyAIGC では、gpt-5.6-luna はトークン単位で課金され、入力は100万トークンあたり$0.0270、出力は$0.1620、キャッシュ入力は$0.0027です。OpenAI の定価は入力$0.20、出力$1.20、キャッシュ入力$0.02なので、AnyAIGC は定価の約13.5%（86%オフ）です。1回のリクエストの入力が272Kトークンを超える場合、そのリクエスト全体が入力2倍、出力1.5倍で課金されます。

GPT-5.6 Luna のモデルIDは何ですか？

モデルIDは gpt-5.6-luna です。リクエストの model フィールドに指定してください。OpenAI は日付付きのスナップショットを公開していません。

GPT-5.6 Luna の値下げ幅はどのくらいでしたか？

2026年7月30日、OpenAI は GPT-5.6 Luna の API 料金を恒久的に80%引き下げました。100万トークンあたり、入力は$1から$0.20に、出力は$6から$1.20に、キャッシュ入力は$0.10から$0.02になりました。AnyAIGC の料金は値下げ後の定価を基準にしており、入力$0.0270、出力$0.1620、キャッシュ入力$0.0027です。

GPT-5.6 Luna は非推奨ですか？いつまで使えますか？

いいえ。OpenAI は新しい GPT-6 Luna をリリースしましたが、GPT-5.6 Luna も引き続き API で提供されています。OpenAI は提供終了日を発表しておらず、現在も問題なく呼び出せ、AnyAIGC 側でも変更はありません。新規プロジェクトでは GPT-6 Luna を検討し、プロンプトを調整済みのバッチ処理には引き続き gpt-5.6-luna を使えます。

Chat Completions と Responses API のどちらを使えばよいですか？ツールは使えますか？

どちらのエンドポイントも使え、どちらもツール呼び出しに対応しています。OpenAI によると、gpt-5.6-luna は Chat Completions、Responses、Batch に対応し、ストリーミング、関数呼び出し、構造化出力を利用できます。通常のチャットと関数呼び出しには https://anyaigc.ai/v1/chat/completions、Responses API の組み込みツールや複数ステップのエージェントワークフローには https://anyaigc.ai/v1/responses を使い、推論の強度は reasoning.effort で指定します。

Codex で GPT-5.6 Luna を使えますか？

はい。curl -fsSL https://www.anyaigc.ai/install.sh | bash -s codex を実行すると、インストールと設定ができます（Windows では irm https://www.anyaigc.ai/install.ps1 | iex）。インストーラーのデフォルトは gpt-5.5 なので、インストール後に ~/.codex/config.toml の model を gpt-5.6-luna に変更してください。手動で設定する場合は、~/.codex/config.toml を編集し、base_url に https://anyaigc.ai/v1、wire_api に responses、model に gpt-5.6-luna を設定したうえで、OPENAI_API_KEY を ~/.codex/auth.json に記載します。

同時実行数やレート制限はありますか？

AnyAIGC では gpt-5.6-luna に同時実行数の上限を設けていません。すべてのアカウントでデフォルトで適用されるため、大規模な分類・抽出や並列エージェントのジョブも待たされることなく実行できます。

GPT-5.6 Luna の APIキーはどう取得しますか？

anyaigc.ai で登録し、チャージして、コンソールでトークンを作成します。同じキーで GPT-5.6 Luna と300以上のほかのモデルを利用できます。公式の OpenAI SDK では、base_url を https://anyaigc.ai/v1 に設定するだけです。
