仕様と選び方

ByteDance は Seedream 5.0 lite を、ディープシンキングとオンライン検索を備えた統合マルチモーダル画像生成モデルと位置づけています。

Seedream 5.0 lite は web_search ツールに対応しており、リアルタイムのニュースや話題に関連した画像を生成できます。

Seedream 5.0 lite の size には 2K、3K、4K、または2560×1440から4096×4096までの合計ピクセル数を指定できます。

Seedream 5.0 lite は最大14枚の参照画像を受け付けます。画像セットモードでは、参照画像と出力画像の合計は最大15枚です。

このページでは Seedream 5.0 lite を1枚あたり$0.0223としており、上の料金表と一致しています。

seedream-5.0-pro との比較：Seedream 5.0 lite は画像セット、14枚の参照画像、最大4Kに対応します。一方、Seedream 5.0 pro は1回の呼び出しで1枚を出力し、参照画像は最大10枚、最大2Kです。

仕様はベンダーの公式ドキュメント（docs.volcengine.com）に基づきます。このページの表が料金で、最新のレートはモデル一覧が正となります。

Seedream 5.0 lite API のよくある質問

Seedream 5.0 lite API の料金はいくらですか？

AnyAIGC では、Seedream 5.0 lite（doubao-seedream-5-0-260128）は1枚あたり$0.0223からです。料金は解像度によって異なり、2K・3K・4Kの最新料金はモデル一覧で確認できます。画像セットは複数枚を返し、生成された画像1枚ごとに課金されます。課金は生成に成功した分のみで、最新の料金はモデル一覧で確認できます。

Seedream 5.0 lite とは？

Seedream 5.0 lite は Seedream 5.0 世代の軽量モデルで、AnyAIGC でのモデルIDは doubao-seedream-5-0-260128 です。公式が重視するのはディープシンキングとリアルタイム検索で、意図をより正確に読み取り、スタイルとレイアウトを制御し、Webから最新情報を取り込めます。AnyAIGC には2026年2月に追加されました。

対応している解像度は？4K出力はできますか？

はい。Volcano Engine Ark のドキュメントによると、5.0 lite は size に 2K、3K、4K またはピクセル寸法を指定でき、アスペクト比は1:16から16:1までです。

画像セットの仕組みは？何枚まで生成できますか？

sequential_image_generation: "auto" を渡し、sequential_image_generation_options.max_images（1–15）で上限を設定します。テキストのみのプロンプトでは最大15枚を返し、参照画像がある場合は、参照画像と生成画像の合計が15枚を超えられません。

参照画像は何枚まで送れますか？Web検索はできますか？

image には最大14枚の参照画像を指定できます。5.0 lite は Seedream モデルの中で唯一Web検索に対応しており、祝日のテーマ、話題のトピック、最新情報が必要な場面に役立ちます。

同時実行数の上限はありますか？登録に必要なものは？

AnyAIGC では Seedream 5.0 lite に同時実行数の上限を設けておらず、すべてのアカウントでデフォルトで利用できます。ベースURLは https://anyaigc.ai です。Volcano Engine のアカウントや本人確認は不要で、同じキーでプラットフォームの他の300以上のモデルも利用できます。

AnyAIGC で請求書を発行できますか？

はい。実際にチャージした金額分の請求書を、コンソールでご自身で発行できます。

対応している支払い方法は何ですか？

WeChat Pay、Alipay、USDT、クレジットカードでチャージできます。残高は USD で、プラットフォーム上のすべてのモデルで使えます。チャージした金額分の請求書は、コンソールで発行できます。

新規ユーザー向けの無料トライアルはありますか？

はい。新規アカウントには200万トークン分のトライアル枠が付与されるので、チャージするかどうか決める前に試せます。チャージは $1 から可能です。

残高は返金できますか？

はい。未使用の残高は手数料なしで返金できます。返金をご希望の場合は、サポートにご連絡ください。

本物のモデルですか？データは安全ですか？

リクエストは公式のモデルチャネルに送られ、安価な代替モデルやリバースエンジニアリングによるモデルは使いません。法令で求められる場合を除き、プロンプトや出力を永続的に保存せず、学習にも使用しません。コンソールでは、リクエストごとのトークン数と料金を確認できます。
