GPT-6.1 Sol API を3ステップで呼び出す

  1. 登録とチャージ：anyaigc.ai でアカウントを作成します。残高はすべてのモデルで共通です。
  2. APIキーを作成：コンソールでトークンを作成し、sk- で始まるキーをコピーして、環境変数 ANYAIGC_API_KEY に保存します。
  3. リクエストを送信：https://anyaigc.ai/v1/chat/completions または https://anyaigc.ai/v1/responses を呼び出し、model に gpt-6.1-sol を指定して、Authorization: Bearer で認証します。

ツールには Responses API を使います。OpenAI によると、gpt-6.1-sol は Chat Completions でのツール呼び出し（関数呼び出し）に対応していません。通常のチャットとストリーミングには引き続き /v1/chat/completions を使い、関数呼び出し、コンピュータ操作（computer use）などのツールには /v1/responses に切り替えて、強度は reasoning.effort に指定してください。

すべてのパラメータは Chat Completions リファレンスと Responses リファレンスをご覧ください。フィールドは公式の OpenAI API と同じです。

Codex で GPT-6.1 Sol を使う

コマンド1つで Codex CLI をインストールし、AnyAIGC の設定を書き込みます。~/.codex/ の2つのファイルを自分で編集することもできます。

ワンライン・インストーラーはモデルを gpt-5.5 に設定するため、インストール後に ~/.codex/config.toml の model を gpt-6.1-sol に変更してください。両方のファイルを保存し、プロジェクトのフォルダで codex を実行します。Codex は Responses API を使うため、ツール呼び出しも通常どおり動作します。詳しい手順とよくあるエラーは Codex 設定ガイドをご覧ください。

GPT-6.1 Sol API のよくある質問

GPT-6.1 Sol API の料金はいくらですか？

AnyAIGC では gpt-6.1-sol はトークン単位で課金されます。入力は100万トークンあたり$0.0993、出力は$0.4964、キャッシュ入力は$0.0050です。OpenAI の定価は入力$2.00、出力$10.00、キャッシュ入力$0.10なので、AnyAIGC は定価の約5%（95%オフ）です。1回のリクエストの入力が272Kトークンを超える場合、そのリクエスト全体が入力とキャッシュは2倍、出力は1.5倍で課金されます。

GPT-6.1 Sol のモデルIDは何ですか？

モデルIDは gpt-6.1-sol です。リクエストの model フィールドに指定してください。OpenAI は日付付きのスナップショットを公開していません。

GPT-6.1 Sol と GPT-6 Sol：何が変わりましたか？

OpenAI は GPT-6.1 Sol を GPT-6 Sol の後継と説明しています。入力と出力の定価は$2と$10のままで、キャッシュ入力は$0.20から$0.10に下がりました。OpenAI によると、DeepSWE v1.1 では GPT-6 Sol の最高スコアを6.4ポイント上回り、OSWorld 2.0 では約7ポイント高く、Terminal-Bench Science では GPT-6 Sol の2倍以上です。知識のカットオフは2026-04-20から2026-04-30に更新されました。GPT-6.1 Sol は推論の強度 none に対応しておらず、Chat Completions でのツール呼び出しにも対応していません。

GPT-6.1 Sol と GPT-6 Astra はどちらを使うべきですか？

OpenAI によると、GPT-6.1 Sol はエージェント型コーディング、コンピュータ操作、専門業務で GPT-6 Astra に迫る性能で、標準の入力・出力価格は Astra の5分の1です。コーディングやエージェント作業の大半は GPT-6.1 Sol から始め、最も難しい推論や研究タスクには GPT-6 Astra に移るとよいでしょう。Terminal-Bench Science などのベンチマークでは、今も Astra が上回っています。AnyAIGC では、GPT-6.1 Sol が入力$0.0993、出力$0.4964、GPT-6 Astra が入力$0.4964、出力$2.4810です（いずれも100万トークンあたり）。

Chat Completions と Responses API のどちらを使えばよいですか？ツールは使えますか？

どちらのエンドポイントも使えます。通常のチャットとストリーミングには https://anyaigc.ai/v1/chat/completions を使います。OpenAI によると、gpt-6.1-sol は Chat Completions でのツール呼び出しに対応していないため、関数呼び出しと組み込みツールには https://anyaigc.ai/v1/responses を使い、推論の強度は reasoning.effort に指定してください。

Codex で GPT-6.1 Sol を使えますか？

はい。curl -fsSL https://www.anyaigc.ai/install.sh | bash -s codex を実行すると、インストールと設定ができます（Windows では irm https://www.anyaigc.ai/install.ps1 | iex）。インストーラーのデフォルトは gpt-5.5 なので、その後 ~/.codex/config.toml の model を gpt-6.1-sol に変更してください。手動で ~/.codex/config.toml を編集する場合は、base_url を https://anyaigc.ai/v1、wire_api を responses、model を gpt-6.1-sol に設定し、OPENAI_API_KEY を ~/.codex/auth.json に記載してください。

同時実行数やレート制限はありますか？

AnyAIGC は gpt-6.1-sol に同時実行数の上限を設けていません。すべてのアカウントでデフォルトで適用されるため、バッチ処理や並列エージェントも待たされずに実行できます。

GPT-6.1 Sol の APIキーはどう取得しますか？

anyaigc.ai で登録してチャージし、コンソールでトークンを作成します。同じキーで GPT-6.1 Sol とほかの300以上のモデルを呼び出せます。公式の OpenAI SDK を使う場合は、base_url を https://anyaigc.ai/v1 に設定するだけです。
