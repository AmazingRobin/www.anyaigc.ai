GPT-6 Sol API を3ステップで呼び出す

  1. 登録とチャージ：anyaigc.ai でアカウントを作成します。残高はすべてのモデルで共通です。
  2. APIキーを作成：コンソールでトークンを作成し、sk- で始まるキーをコピーして、環境変数 ANYAIGC_API_KEY に保存します。
  3. リクエストを送信：https://anyaigc.ai/v1/chat/completions または https://anyaigc.ai/v1/responses を呼び出し、model に gpt-6-sol を指定して、Authorization: Bearer で認証します。

推論とツールを併用するなら Responses API を使います。OpenAI によると、gpt-6-sol が Chat Completions で関数呼び出しに対応するのは、reasoning_effort が "none" のときだけです。推論しながら関数を呼び出す場合や、コンピュータ操作（computer use）、Web検索などの組み込みツールを使う場合は、/v1/responses に切り替え、強度は reasoning.effort に指定してください。

すべてのパラメータは Chat Completions リファレンスと Responses リファレンスをご覧ください。フィールドは公式の OpenAI API と同じです。

Codex で GPT-6 Sol を使う

コマンド1つで Codex CLI をインストールし、AnyAIGC の設定を書き込みます。~/.codex/ の2つのファイルを自分で編集することもできます。

ワンライン・インストーラーはモデルを gpt-5.5 に設定するため、インストール後に ~/.codex/config.toml の model を gpt-6-sol に変更してください。両方のファイルを保存し、プロジェクトのフォルダで codex を実行します。Codex は Responses API を使うため、Chat Completions で推論の強度によってツールが制限される点は当てはまりません。詳しい手順とよくあるエラーは Codex 設定ガイドをご覧ください。

GPT-6 Sol API のよくある質問

GPT-6 Sol API の料金はいくらですか？

AnyAIGC では gpt-6-sol はトークン単位で課金されます。入力は100万トークンあたり$0.0993、出力は$0.4964、キャッシュ入力は$0.0099です。OpenAI の定価は入力$2.00、出力$10.00、キャッシュ入力$0.20なので、AnyAIGC は定価の約5%（95%オフ）です。1回のリクエストの入力が272Kトークンを超える場合、そのリクエスト全体が入力とキャッシュは2倍、出力は1.5倍で課金されます。

GPT-6 Sol のモデルIDとコンテキスト長は？

モデルIDは gpt-6-sol です。リクエストの model フィールドに指定してください。OpenAI は日付付きのスナップショットを公開していません。OpenAI のモデルページによると、コンテキスト長は1,050,000トークン、最大出力は128,000トークン、知識のカットオフは2026年4月20日です。

GPT-6 Sol は非推奨ですか？いつまで使えますか？

いいえ。OpenAI は新しい Sol モデルとして GPT-6.1 Sol をリリースしましたが、GPT-6 Sol は OpenAI の非推奨ページに載っておらず、提供終了日も発表されていません。現在も問題なく呼び出せ、AnyAIGC で gpt-6-sol を引き続き使えます。新規プロジェクトには GPT-6.1 Sol（gpt-6.1-sol）をおすすめします。

GPT-6 Sol と GPT-6.1 Sol：移行すべきですか？

入力と出力の定価は同じ（$2と$10）で、GPT-6.1 Sol はキャッシュ入力が安くなっています（GPT-6.1 Sol は$0.10、GPT-6 Sol は$0.20）。OpenAI の結果では、GPT-6.1 Sol は DeepSWE v1.1、OSWorld 2.0、Terminal-Bench Science のスコアが高く、知識のカットオフは2026-04-30に更新されています。切り替える前に2点を確認してください。GPT-6.1 Sol は推論の強度 none に対応しておらず、Chat Completions でのツール呼び出しにも対応していません。Chat Completions で reasoning_effort: "none" を指定して関数を呼び出している場合は、当面 GPT-6 Sol を使い続けるか、先に Responses API へ移行してから gpt-6.1-sol に切り替えてください。OpenAI は、切り替える前に移行ガイドを確認するよう推奨しています。

Chat Completions と Responses API のどちらを使えばよいですか？ツールは使えますか？

どちらのエンドポイントも使えます。通常のチャットとストリーミングには https://anyaigc.ai/v1/chat/completions を使います。OpenAI によると、gpt-6-sol が Chat Completions で関数呼び出しに対応するのは、reasoning_effort が none のときだけです。推論しながら関数を呼び出す場合や組み込みツールを使う場合は、https://anyaigc.ai/v1/responses を使い、強度は reasoning.effort に指定してください。

Codex で GPT-6 Sol を使えますか？

はい。curl -fsSL https://www.anyaigc.ai/install.sh | bash -s codex を実行すると、インストールと設定ができます（Windows では irm https://www.anyaigc.ai/install.ps1 | iex）。インストーラーのデフォルトは gpt-5.5 なので、その後 ~/.codex/config.toml の model を gpt-6-sol に変更してください。手動で ~/.codex/config.toml を編集する場合は、base_url を https://anyaigc.ai/v1、wire_api を responses、model を gpt-6-sol に設定し、OPENAI_API_KEY を ~/.codex/auth.json に記載してください。

同時実行数やレート制限はありますか？

AnyAIGC は gpt-6-sol に同時実行数の上限を設けていません。すべてのアカウントでデフォルトで適用されるため、バッチ処理や並列エージェントも待たされずに実行できます。

GPT-6 Sol の APIキーはどう取得しますか？

anyaigc.ai で登録してチャージし、コンソールでトークンを作成してください。同じキーで GPT-6 Sol と300以上のほかのモデルを利用できます。公式の OpenAI SDK では、base_url を https://anyaigc.ai/v1 に設定するだけです。
