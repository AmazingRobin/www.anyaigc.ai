Seedance 2.5 API をはじめる

  1. AnyAIGC に登録して、APIキーを作成します。
  2. タスク作成のエンドポイントにJSONをPOSTし、返された id を保存します。
  3. 照会のエンドポイントをポーリングし、成功したら content.video_url をダウンロードします。

2.5 は 480p / 720p / 1080p（デフォルトは 720p）に対応し、duration は 4–30 または -1 を指定できます。編集、延長、最初のフレーム / 最初と最後のフレームのタスクでは ratio="adaptive" が必要で、編集では duration=-1 が必要です。長さを指定した参照動画では、omni_reference_task_type="reference" を設定してください。

フィールドとレスポンスの構造は AnyAIGC Seedance API ドキュメントに従います。タスク照会のドキュメント

仕様と選び方

Volcengine のドキュメントによると、Seedance 2.5 は4–30秒のクリップに対応し、-1 を指定すると長さをモデルが選びます。

ByteDance Seed によると、1本のクリップが最長30秒に達し、最大2回まで延長できます。ホワイトモデル制御とグリーンバック編集にも対応しています。

Seedance API のよくある質問

Seedance 2.5 API の料金はいくらですか？

AnyAIGC は100万トークン単位で課金し、解像度と参照動画の入力有無によって料金が変わります。480p / 720p（参照動画なし）：$13.001 / 100万トークン、480p / 720p（参照動画あり）：$7.776 / 100万トークン、1080p（参照動画なし）：$14.216 / 100万トークン、1080p（参照動画あり）：$8.505 / 100万トークン。最新の料金はモデル一覧で確認できます。

Seedance は何を入力として受け付けますか？

Seedance 2.0 は、テキスト、画像、音声、動画を参照として受け付け、動画の編集、延長、ネイティブ音声に対応しています。2.0 Fast は速度を優先し、2.0 mini は高頻度の利用向けに設計されています。2.5 は、長いストーリー、参照、精密な編集が強化されています。

1回のリクエストで動画はいくつ返されますか？

作成リクエストはタスクIDを1つ返します。非同期タスクが完了したら、照会して動画URLを1つ取得します。長さは duration フィールドまたはモデルによって決まります。

対応している解像度、アスペクト比、長さは何ですか？

Seedance 2.0 は480p、720p、1080p、4Kに対応しており、4Kティアは現在利用できます。Seedance 2.5 は480p、720p、1080pに対応し、duration は4–30または-1です。Fast と mini の料金ティアは480p / 720pです。アスペクト比と長さのパラメーターは、各モデルのAPIドキュメントに従ってください。

結果はどのように取得しますか？

作成の呼び出しで返された id を保存し、GET /api/v3/contents/generations/tasks/{id} を呼び出します。成功したら content.video_url を読み取ります。ステータスの正確な値はAPIのレスポンスで確認してください。

同時実行数の制限はありますか？

AnyAIGC では Seedance の同時実行数に上限を設けておらず、すべてのアカウントで最初からこの設定です。大量のバッチ処理では、キューとリトライの仕組みを使ってください。

AnyAIGC で請求書を発行できますか？

はい。実際にチャージした金額分の請求書を、コンソールでご自身で発行できます。

対応している支払い方法は何ですか？

WeChat Pay、Alipay、USDT、クレジットカードでチャージできます。残高は USD で、プラットフォーム上のすべてのモデルで使えます。チャージした金額分の請求書は、コンソールで発行できます。

新規ユーザー向けの無料トライアルはありますか？

はい。新規アカウントには200万トークン分のトライアル枠が付与され、チャージは$1から可能です。

残高は返金できますか？

未使用の残高は手数料なしで返金できます。手続きについてはサポートにお問い合わせください。

本物のモデルですか？データは安全ですか？

リクエストは公式のモデルチャネルを経由します。法令で必要な場合を除き、プロンプトと出力は永続的に保存されず、学習にも使用されません。コンソールでリクエストの詳細を確認できます。
