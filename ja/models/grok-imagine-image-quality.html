grok-imagine-image-quality に何が起きたか

Grok Imagine Image Quality は、xAI が2026年5月に導入した高品質の生成・編集モードで、よりリアルな画像と多言語の文字表現の改善に重点を置いていました。2026年8月に xAI は Image 2.0 をリリースし、grok.com の新しい Quality モードにしました。

xAI は2026年9月に grok-imagine-image-quality の提供終了を発表し、11月2日に完了しました。このモデル名への生成・編集リクエストは、現在 quality: "low" を指定した grok-imagine-image-2.0 で処理され、リクエストとレスポンスの形式は変わりません（xAI の移行ガイド）。

このモデル名は AnyAIGC で引き続き使え、料金は1枚あたり$0.0223（1K）から$0.0313（2K）です。Low 品質の Image 2.0 はどの解像度でも1枚あたり$0.0044–$0.0045安いため、grok-imagine-image-2.0 に移ると費用を抑えられ、quality: "medium" と新しい 21:9、5:2 の比率も使えるようになります。

これらのサンプルは Imagine Image 2.0 で生成されたもので、xAI のローンチ記事から引用しています。

  • 文字とレイアウト

  • 精密な編集

    指示した部分だけを変え、残りはそのまま保てます。背景の差し替え、商品の色替え、不要物の除去を一文の指示で行えます。

    1:2の縦長から21:9のワイドまで対応します。比率を選ぶと、モデルは画像を切り抜くのではなく、シーンを再構成します。

3ステップで移行

  • ステップ1

    レスポンスを確認する

    形式は変わりません。data には引き続き b64_json または url が入るため、パース処理はそのまま使えます。

Grok Imagine Image Quality API のよくある質問

grok-imagine-image-quality は提供終了になりましたか？

はい。xAI は2026年11月2日に grok-imagine-image-quality を提供終了にしました。リクエストは現在 quality: "low" を指定した grok-imagine-image-2.0 で処理され、リクエストとレスポンスの形式は変わりません。このモデル名は AnyAIGC でも引き続き使えますが、新規プロジェクトでは Grok Imagine Image 2.0 をご利用ください。

Grok Imagine Image Quality API の料金はいくらですか？

AnyAIGC では1枚あたり、1Kが$0.0223、1.5Kが$0.0268、2Kが$0.0313で、編集では入力画像1枚につき$0.00447が加算されます。これは Low 品質の Image 2.0 より、各解像度で$0.0044–$0.0045高い料金です。xAI は Quality の個別の定価を公開しなくなりました。生成に成功した分のみ課金され、最新の料金はモデル一覧でご確認ください。

2.0 に移行するには、どのコードを変更する必要がありますか？

model を grok-imagine-image-2.0 に変えるだけです。エンドポイント、リクエストのフィールド、レスポンスの形式は同じです。2.0 では quality（low / medium / auto）と 21:9、5:2 の比率も使えます。

何も変更しないとどうなりますか？

リクエストが失敗することはありません。2.0 の low 品質で処理され、レスポンスの model フィールドには実際に処理したモデルが表示されます。料金も引き続き Quality の価格で、2.0 Low より高くなります。medium 品質が必要な場合は、2.0 に切り替えて quality を指定してください。

Image 2.0、Image、Quality のどれを使えばよいですか？

Grok Imagine Image 2.0（grok-imagine-image-2.0）は、xAI が現在おすすめしているモデルで、文字の描画、プロンプトへの追従、編集が強化されています。AnyAIGC では1枚$0.0179からなので、新規プロジェクトはこちらから始めてください。Grok Imagine Image（grok-imagine-image）は第1世代の Imagine モデルで1枚$0.0119、シリーズ最安です。シンプルなテキストから画像や既存のコードには十分です。Grok Imagine Image Quality は2026年11月2日に xAI が提供を終了しており、そのリクエストは現在、2.0 の low 品質で処理されます。

xAI のアカウントは必要ですか？

xAI アカウントは不要です。AnyAIGC に登録して APIキーを取得してください。エンドポイントは https://anyaigc.ai で、同じキーでプラットフォーム上のほかの300以上のモデルも使えます。

同時実行数の制限はありますか？

AnyAIGC は Grok Image モデルに同時実行数の制限を設けていません。すべてのアカウントでデフォルトで適用されるため、バッチ処理でも割り当ての申請は不要です。

AnyAIGC で請求書を発行できますか？

はい。実際にチャージした金額分の請求書を、コンソールでご自身で発行できます。

対応している支払い方法は何ですか？

WeChat Pay、Alipay、USDT、クレジットカードでチャージできます。残高は USD で、プラットフォーム上のすべてのモデルで使えます。チャージした金額分の請求書は、コンソールで発行できます。

新規ユーザー向けの無料トライアルはありますか？

はい。新規アカウントには200万トークン分のトライアル枠が付与されるので、チャージするかどうか決める前に試せます。チャージは $1 から可能です。

残高は返金できますか？

はい。未使用の残高は手数料なしで返金できます。返金をご希望の場合は、サポートにご連絡ください。

本物のモデルですか？データは安全ですか？

リクエストは公式のモデルチャネルに送られ、安価な代替モデルやリバースエンジニアリングによるモデルは使いません。法令で求められる場合を除き、プロンプトや出力を永続的に保存せず、学習にも使用しません。コンソールでは、リクエストごとのトークン数と料金を確認できます。

生成した画像は商用利用できますか？

利用権とコンテンツポリシーは xAI の公式規約に従います。AnyAIGC は API アクセスを提供するだけで、出力の利用方法に追加の制限は設けません。
