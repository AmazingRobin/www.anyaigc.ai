モデルについて

Flash の速度とコストで、フラッグシップに近いコーディングとエージェント性能

Google は 2026年9月2日に Gemini 3.8 Flash を一般提供しました。Google はこれを「最もインテリジェントな Flash モデル」と呼び、長期的なソフトウェアエンジニアリング、自律型エージェント、複雑なエンタープライズワークフロー向けで、「Flash の速度とコスト効率をすべて備えている」としています。発表記事では、3.7 Flash と同じ速度と低コストのまま、Flash シリーズでこれまでで最高の推論・コーディングモデルと説明されています。

モデルカードによると、3.8 Flash は 3.7 Flash をベースにしています。入力は最大1,048,576トークン、出力は最大65,536トークンで、テキスト、画像、動画、音声、PDF をネイティブに受け付けます。Google は2026年10月に 3.7 Flash を非推奨とし、API リクエストを 3.8 Flash にルーティングしているため、3.8 Flash は Gemini 3 シリーズの主要な安定版モデルです。

AnyAIGC では、gemini-3.8-flash はネイティブの /v1beta/models/gemini-3.8-flash:generateContent エンドポイントと、OpenAI互換の /v1/chat/completions の両方で使えます。Google Cloud アカウントは不要で、同時実行数は上限なしなので、本番トラフィックにもそのまま対応できます。

Gemini 3.8 Flash が得意なこと

  • 日常のコーディングを支える主力

    Google の報告では、DeepSWE v1.1 で73.7%、Terminal-bench 2.1 で89.4%です。補完、バグ修正、テストなど頻度の高い作業を、速く安く任せられます。

  • 自律型エージェント

    関数呼び出し、コード実行、構造化出力、URL コンテキスト、Google 検索と Google マップによるグラウンディングに加え、プレビューでコンピューター操作にも対応。OSWorld-2.0 で59.0%です。

  • 大量の本番処理

    入力100万トークンあたり$0.1575、キャッシュヒット100万トークンあたり$0.0158で、AnyAIGC では同時実行数に上限がありません。分類、抽出、要約、モデレーションを大規模に実行できます。

  • 1Mトークンのコンテキスト

    1,048,576トークンの入力ウィンドウに、コードベース全体、長いレポート、複数の契約書をまとめて収められるため、ドキュメントをまたぐ検索や比較を1回のリクエストで行えます。

  • ネイティブマルチモーダル

    画像、動画、音声、PDF をそのまま入力できます。Google の報告では、長尺動画の LVBench で87.8%、グラフ推論の CharXiv で86.2%です。

  • 調整できる思考

    思考レベルは3段階です。単純な呼び出しではトークンを節約するために low、難しい問題では high を使います。1つのモデルで、素早い応答から深い推論までカバーできます。

  1. 登録とチャージ：anyaigc.ai でアカウントを作成します。残高はプラットフォーム上のすべてのモデルで使えます。

FAQ

Gemini 3.8 Flash API のよくある質問

Gemini 3.8 Flash API の料金はいくらですか？

AnyAIGC では、gemini-3.8-flash はトークン単位で課金されます。入力100万トークンあたり$0.1575、出力100万トークンあたり$0.7875、キャッシュヒット100万トークンあたり$0.0158です。Google の Standard 価格（2026年12月31日までの導入価格）は入力$0.75、出力$3.75、キャッシュ$0.075なので、AnyAIGC は定価の約21%です。出力には思考トークンが含まれます。

Google の導入期間が終わると、AnyAIGC の価格は変わりますか？

いいえ。2027年1月1日から、Google の Standard 価格は100万トークンあたり入力$1.50、出力$7.50、キャッシュ$0.15になります。AnyAIGC は現在の価格（入力$0.1575、出力$0.7875、キャッシュ$0.0158）を維持するため、Google の価格の約10.5%になります。

モデルIDは何ですか？Gemini 3.8 Flash は一般提供されていますか？

モデルIDは gemini-3.8-flash です。Google は2026年9月2日に一般提供（GA）としてリリースしており、終了日は発表していません。ネイティブAPIではモデル名をURLに含め（/v1beta/models/gemini-3.8-flash:generateContent）、OpenAI互換APIでは model フィールドに指定します。

コンテキスト長と最大出力はどれくらいですか？

Google が示す入力上限は1,048,576トークン、出力上限は65,536トークンです。入力はテキスト、画像、動画、音声、PDF、出力はテキストです。ナレッジカットオフは2026年3月です。

ネイティブ Gemini API と OpenAI互換API のどちらを使うべきですか？

どちらでも使えます。ネイティブエンドポイントは POST https://anyaigc.ai/v1beta/models/gemini-3.8-flash:generateContent で、リクエストボディは Google Gemini API と同じです。OpenAI互換エンドポイントは POST https://anyaigc.ai/v1/chat/completions で、公式の OpenAI SDK では base_url を https://anyaigc.ai/v1 に設定します。どちらも Authorization: Bearer で認証します。

思考レベルはどう設定しますか？

Gemini 3.8 Flash は low、medium、high の思考レベルに対応し、デフォルトは medium です。ネイティブAPIでは generationConfig.thinkingConfig.thinkingLevel を設定します。Google によると、minimal には対応しておらずエラーになります。また、レベルが高いほどトークンを多く使うことがあるため、コストを重視するバッチ処理は low から始めるのがおすすめです。

Gemini 3.8 Flash と Gemini 4 Argon のどちらを選ぶべきですか？

Gemini 3.8 Flash は、大量処理、レイテンシとコストに敏感な処理、日常のコーディングやエージェントのワークフローに向いており、AnyAIGC では入力$0.1575、出力$0.7875です。Gemini 4 Argon は Google の現行フラッグシップで、Google が公表している DeepSWE、Terminal-bench 4.0、法務・金融エージェントのベンチマークで 3.8 Flash を上回り、AnyAIGC では入力$0.4200、出力$2.1000です。まず 3.8 Flash を使い、最も難しいタスクを Argon に回してください。どちらも同じキーで使えます。

Gemini 3.7 Flash はまだ使えますか？3.8 Flash は何が違いますか？

Google は gemini-3.7-flash を2026年10月8日に非推奨とし、gemini-3.8-flash に置き換えました。Google 自身の API では 3.7 Flash へのリクエストが自動的に 3.8 Flash にルーティングされます。Google によると、3.8 Flash は 3.7 Flash をベースに、ソフトウェアエンジニアリングとエージェントタスクが大きく向上しています。たとえば DeepSWE v1.1 は65.3%から73.7%に上がっています。AnyAIGC では両者の価格は同じなので、新規プロジェクトでは gemini-3.8-flash を使ってください。

同時実行数やレート制限はありますか？

AnyAIGC は gemini-3.8-flash の同時実行数に上限を設けていません。すべてのアカウントにデフォルトで適用されるため、バッチ処理や並列エージェントに向いています。

Gemini 3.8 Flash の APIキーはどうやって取得しますか？

anyaigc.ai で登録し、チャージして、コンソールでトークンを作成します。同じキーで Gemini 3.8 Flash と300以上のほかのモデルを呼び出せ、Google Cloud アカウントは不要です。
