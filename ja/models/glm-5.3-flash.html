概要

新しいベースとアーキテクチャによるネイティブマルチモーダルモデル

Zhipu は GLM-5.3-Flash を GLM-5 で初のネイティブマルチモーダルモデルと位置づけ、非常に低いコストで GLM-5.2 以上の性能を提供するとしています。GLM-5.3 とは異なり、新たに学習したベースモデルから始まっており、マルチモーダルデータを含む約30Tトークンで事前学習されています。

Es ist ein MoE mit 320B Gesamtparametern und 18B aktiven Parametern. Laut Zhipu ist es das erste offene Frontier-Modell, das Sparse Attention mit Linear Attention kombiniert, und es nutzt Manifold-Constrained Hyper-Connections (mHC). Gegenüber GLM-5.3 sinkt der Attention-Rechenaufwand um um rund den Faktor 3 und der KV-Cache um um rund den Faktor 4,4. So bleibt die Langkontext-Fähigkeit erhalten, während die Serving-Kosten deutlich sinken. Es bietet 1M Tokens Kontext, bis zu 128K Ausgabe, und der Denkmodus ist immer aktiv.

AnyAIGC では、glm-5.3-flash は OpenAI 互換の /v1/chat/completions エンドポイントで動作し、テキストと画像を受け付け、Claude Code でそのまま使えます。同時実行数の上限もありません。

Claude Code

Claude Code で GLM-5.3-Flash を使う

Claude Code を GLM-5.3-Flash に切り替えます。価格は GLM-5.3 の約1/15で、日常的なコーディングをこなし、スクリーンショットを読み取って UI を修正できます。

  1. Claude Code をインストール：公式インストーラーを使います。macOS または Linux の場合は、たとえば curl -fsSL https://claude.ai/install.sh | bash です。
  2. 設定を追加：~/.claude/settings.json を編集し、下の env ブロックを追加して、ANTHROPIC_AUTH_TOKEN を AnyAIGC で作成したキーに置き換えます。
  3. コーディングを開始：プロジェクトフォルダで claude を実行します。/model と入力して、現在のモデルが glm-5.3-flash であることを確認してください。

難しい課題には：複数モジュールにまたがる複雑なリファクタリングや長時間のタスクでは、設定の ANTHROPIC_MODEL を glm-5.3 に変更し、軽量なサブタスクには Flash を使い続けてください。

手順の詳細とよくあるエラーは、Claude Code 設定ガイドを参照してください。ガイド内のモデル名は glm-5.3-flash に置き換えてください。

仕様

仕様と選び方

Z.ai のドキュメントでは、GLM-5.3-Flash は GLM-5 シリーズ初のネイティブマルチモーダルモデルで、GLM-5.2 より高い知能を備えるとされています。

ドキュメントには総パラメータ数320B、アクティブパラメータ数18Bと記載されています。スパースアテンションとリニアアテンションを組み合わせた初のオープンソースのフロンティアモデルとされ、GLM-5.3 と比べてアテンションの計算量を3.01倍、KV キャッシュを4.44倍削減するとしています。

公式のモデル概要表には、コンテキスト長1Mトークンと記載されています。

このページには入力$0.0607、出力$0.2025、キャッシュヒット$0.0122と記載しており、上の料金表と一致しています。

glm-5.3 との比較：公式ドキュメントによると、GLM-5.3 は現時点ではテキストのみの入力に対応しています。画像などのマルチモーダル入力が必要な場合は GLM-5.3-Flash を選んでください。

仕様はベンダーの公式ドキュメント（docs.z.ai）に基づいています。このページの表は料金を示したもので、最新の料金はモデル一覧が正となります。

FAQ

GLM-5.3-Flash API のよくある質問

GLM-5.3-Flash API の料金はいくらですか？

Bei AnyAIGC wird glm-5.3-flash pro Token abgerechnet: Eingabe $0,0607 pro 1 Mio. Tokens, Ausgabe $0,2025 pro 1 Mio. Tokens, Cache-Treffer $0,0122 pro 1 Mio. Tokens. Die offiziellen USD-Preise von Zhipu betragen $0,15 für die Eingabe, $0,50 für die Ausgabe und $0,03 für Cache-Treffer. AnyAIGC kostet also rund 40,5 % des offiziellen Preises (rund 60 % Rabatt). Die Ausgabe enthält Denk-Tokens. Aktuelle Preise finden Sie im Modellkatalog.

GLM-5.3-Flash のモデルIDは何ですか？コンテキスト長はどのくらいですか？

モデルIDは glm-5.3-flash です。Zhipu はコンテキスト長1Mトークン、最大128K出力トークンと記載しています。AnyAIGC 経由では、テキストと画像の入力に対応します。

GLM-5.3-Flash は GLM-5.3 とどう違いますか？

GLM-5.3-Flash は新たに学習したベースモデル上に構築されており、総パラメータ数320B、アクティブパラメータ数18Bで、スパースアテンションとリニアアテンションを組み合わせた構成です。GLM-5 シリーズで初のネイティブマルチモーダルモデルです。Zhipu によると、GLM-5.3 と比べて、アテンションの計算量は約3倍、KV キャッシュは約4.4倍削減されます。GLM-5.3 は最も難しいコーディング作業向けのより強力なフラッグシップで、テキストのみに対応します。Flash は画像を受け付け、価格は約1/15です（入力$0.0607 対 $0.9450）。

GLM-5.3-Flash は GLM-5.2 より優れていますか？

Zhipu は、GLM-5.3-Flash は価格が約10分の1でありながら、総合的に GLM-5.2 を上回るとしています。報告されている比較は次のとおりです。DeepSWE 63.4 対 46.2、Toolathlon Verified 78.4 対 59.9、AutomationBench 48.8 対 26.2、GDPval-AA v2 1773 対 1504。

GLM-5.3-Flash は画像に対応していますか？どのように送りますか？

はい。messages[].content 配列に {"type": "image_url", "image_url": {"url": ...}} のコンテンツブロックを追加します。url には、公開されている画像 URL または Base64 の data URL を指定できます。複数の画像を送る場合は、ブロックを複数追加してください。

Claude Code で GLM-5.3-Flash を使えますか？

はい。~/.claude/settings.json の env ブロックで、ANTHROPIC_BASE_URL を https://anyaigc.ai、ANTHROPIC_AUTH_TOKEN をご自身の APIキー、ANTHROPIC_MODEL を glm-5.3-flash に設定し、claude を実行します。料金はトークン単位で、サブスクリプションプランのような5時間のクォータ枠はありません。

Kann ich den Denkmodus bei GLM-5.3-Flash abschalten?

できません。GLM-5.3-Flash は常に思考モードで動作し、Zhipu はオフにする設定に対応していません。深さは reasoning_effort で指定します。low、high、max から選べ、デフォルトは max です。分類や抽出のような単純なタスクでは、low にすると出力トークンを減らせます。

GLM-5.3-Flash はオープンソースですか？

はい。Zhipu は GLM-5.3-Flash のウェイトを、MIT ライセンスで Hugging Face（zai-org/GLM-5.3-Flash）に公開しています。AnyAIGC 経由で API を呼び出せば、自前でホスティングする必要はありません。商用利用は Zhipu AI の公式規約に従います。

同時実行数やレート制限はありますか？

AnyAIGC begrenzt die Parallelität für glm-5.3-flash nicht, und jeder Nutzer erhält das standardmäßig. Das passt zu Batch-Jobs, CI-Pipelines und parallelen Agenten. Abgerechnet wird pro Token, es gibt also kein Kontingent, das sich wie bei einem Abo-Tarif nach einem Zeitfenster zurücksetzt.

GLM-5.3-Flash の APIキーはどうすれば取得できますか？

anyaigc.ai で登録し、チャージして、コンソールでキーを作成します。同じキーで、すべての GLM モデルとプラットフォーム上の300以上のモデルを利用できます。Zhipu のプラットフォームのアカウントや GLM Coding Plan は別途必要ありません。

AnyAIGC で請求書を発行できますか？

はい。実際にチャージした金額分の請求書を、コンソールでご自身で発行できます。

対応している支払い方法は何ですか？

WeChat Pay、Alipay、USDT、クレジットカードでチャージできます。残高は USD で、プラットフォーム上のすべてのモデルで使えます。チャージした金額分の請求書は、コンソールで発行できます。

新規ユーザー向けの無料トライアルはありますか？

はい。新規アカウントには200万トークン分のトライアル枠が付与されるので、チャージするかどうか決める前に試せます。チャージは $1 から可能です。

残高は返金できますか？

はい。未使用の残高は手数料なしで返金できます。返金をご希望の場合は、サポートにご連絡ください。

本物のモデルですか？データは安全ですか？

リクエストは公式のモデルチャネルに送られ、安価な代替モデルやリバースエンジニアリングによるモデルは使いません。法令で求められる場合を除き、プロンプトや出力を永続的に保存せず、学習にも使用しません。コンソールでは、リクエストごとのトークン数と料金を確認できます。

入力したデータはトレーニングに使われますか？

いいえ。法令で求められる場合を除き、AnyAIGC はプロンプトや出力を永続的に保存せず、モデルのトレーニングにも使用しません。リクエストは HTTPS で暗号化されます。AnyAIGC のプライバシーポリシーをご覧ください。モデル自体のデータの扱いは Zhipu AI の公式規約に従います。
