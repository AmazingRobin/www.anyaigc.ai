Gemini 3.8 Flash TTS API

Google の3.8 Flash 音声合成モデルです。スタジオ品質のボイス、表現力のある読み上げ、安定した長時間ナレーションを想定して作られています。AnyAIGC では Google の定価の36%で使えます。

Google は、このモデルを「スタジオ品質の音声再現性、表現力のある演技、長時間の安定性を追求して設計」したものと説明しています。30種類のプリセットボイスから選べ、1回のリクエストで最大2人の話者を使え、<laugh> や <short pause> のようなタグで話し方を調整できます。gemini-3.8-flash-tts の料金は、テキスト入力が100万トークンあたり$0.1787、音声出力が100万トークンあたり$3.2163で、音声1分あたり約$0.0048です。

モデルについて

長編ナレーションと表現力のあるボイスオーバー向けに設計

Google は Gemini 3.8 Flash TTS を2026年9月22日に一般提供として公開しました。モデルIDは gemini-3.8-flash-tts です。役割は1つで、テキストを入力して音声を出力します。

30種類のプリセットボイスから選べるほか、1回のリクエストに2人の話者を入れて、ポッドキャスト風の会話やサポート対話も作れます。言語は自動で判別され、Google は130以上の言語に対応しているとしています。<sigh>、<whispers>、<long pause> などのインラインタグで話し方を細かく調整できます。

AnyAIGC では、ネイティブの /v1beta/models/gemini-3.8-flash-tts:generateContent エンドポイントで gemini-3.8-flash-tts を呼び出すと、base64エンコードされた音声が返ります。Google Cloud アカウントは不要で、同時実行数の上限もありません。

機能

Gemini 3.8 Flash TTS でできること

  • 30種類のプリセットボイス

    明るい Zephyr、しっかりした Kore、温かみのある Sulafat まで、ボイスごとに個性があります。切り替えは voiceName フィールド1つで済みます。

  • 2話者の対話

    2人の話者にそれぞれボイスを割り当てれば、1つのスクリプトからポッドキャストの1コーナー、インタビュー、サポート通話をまるごと生成できます。つなぎ合わせる作業は不要です。

  • 話し方とテンポの制御

    <laugh>、<sigh>、<whispers>、<short pause> などのタグをテキストに入れて、笑い、息づかい、間を狙った位置に置けます。

  • 130以上の言語

    英語、中国語、日本語などは自動で判別されるため、言語コードは不要です。同じボイスで複数の言語を読み上げられます。

  • 長時間でも安定した出力

    Google は長時間の安定性を特長に挙げています。1回のリクエストで最大16,384音声トークン（約10分）を返せるので、オーディオブックの1章や長いナレーションにも十分です。

  • トークン単位の課金

    音声出力は100万トークンあたり$3.2163です。Google の1秒あたり25音声トークンで計算すると、音声1分は約$0.0048で、文字数ごとの最低料金はありません。

3ステップで始める Gemini 3.8 Flash TTS API

  1. 登録とチャージ：anyaigc.ai でアカウントを作成します。残高はプラットフォーム上のすべてのモデルで使えます。

  3. リクエストを送信：generationConfig.responseModalities を ["AUDIO"] にし、Authorization: Bearer を付けて https://anyaigc.ai/v1beta/models/gemini-3.8-flash-tts:generateContent を呼び出し、inlineData.data から音声をデコードします。

ネイティブの Gemini TTS API ドキュメントを参照し、モデル名を gemini-3.8-flash-tts に置き換えてください。ボイス、タグ、複数話者のルールは Google の音声生成ドキュメントに記載されています。

FAQ

Gemini 3.8 Flash TTS API のよくある質問

Gemini 3.8 Flash TTS API の料金はいくらですか？

AnyAIGC では、gemini-3.8-flash-tts はトークン単位で課金され、テキスト入力は100万トークンあたり$0.1787、音声出力は100万トークンあたり$3.2163です。Google の標準定価（2026年12月31日まで）はテキスト入力が$0.50、音声出力が$9.00なので、AnyAIGC は定価の約36%、つまり約64%オフです。

音声1分の料金はいくらですか？音声トークンはどう数えますか？

Google は音声を1秒あたり25トークンで数えるため、1分は1,500出力トークンで、AnyAIGC では約$0.0048に加えてごくわずかなテキスト入力料金がかかります。1時間分の音声は約90,000出力トークンで、約$0.29です。

2026年以降の Google の定価はどうなりますか？

2027年1月1日から、Google の定価は100万トークンあたり、テキスト入力が$1.00、音声出力が$18.00になります。AnyAIGC の現在の料金（入力$0.1787、出力$3.2163）で比べると、定価の約18%です。最新の料金は AnyAIGC のモデル一覧でご確認ください。

モデルIDは何ですか？一般提供されていますか？

モデルIDは gemini-3.8-flash-tts で、プレビューを示す接尾辞はありません。Google は2026年9月22日に一般提供を開始しました。ネイティブAPIでは、モデル名がURLに入ります：/v1beta/models/gemini-3.8-flash-tts:generateContent。

使えるボイスと言語は？

30種類のプリセットボイスがあり、Kore（しっかり）、Puck（軽快）、Charon（説明的）、Sulafat（温かい）などを speechConfig.voiceConfig.prebuiltVoiceConfig.voiceName で指定します。言語は自動で判別され、Google は130以上の言語に対応しているとしています。

複数の話者に対応していますか？

はい、1回のリクエストで最大2人の話者に対応しており、プリセットボイスのみ使えます。speechConfig.multiSpeakerVoiceConfig.speakerVoiceConfigs で各話者にボイスを割り当て、スクリプト中の名前を各 speaker の値と一致させてください。3人以上の番組では、セグメントごとに音声を生成してつなぎ合わせます。

トーン、感情、間はどう制御しますか？

<laugh>、<sigh>、<whispers>、<short pause>、<long pause> などのインラインタグをテキストに挿入します。Google によると、3.8 Flash TTS はテキストを文字どおりの書き起こしとして扱うため、「Say cheerfully:」のような指示は読み上げられることがあり、現在は推奨されていません。

返ってくる音声形式は？MP3にするには？

音声は candidates[0].content.parts[0].inlineData.data に base64 で入っており、形式は mimeType で分かります。AnyAIGC のドキュメントの例では audio/L16;codec=pcm;rate=24000（24kHz、16-bit、モノラルPCM）が返ります。再生するには WAV ヘッダーを付けるか、ffmpeg -f s16le -ar 24000 -ac 1 -i output.pcm output.mp3 で MP3 に変換してください。mimeType が audio/wav の場合は、デコードしたバイト列をそのまま保存すれば使えます。

1回のリクエストで生成できる長さは？

Google は入力上限を8,192トークン、出力上限を16,384トークンとしており、1秒あたり25トークンで約10分の音声に相当します。オーディオブックや長いナレーションは、段落や章ごとに分割し、リクエストを並列で実行して、順番につなげてください。

同時実行数やレート制限はありますか？

AnyAIGC は gemini-3.8-flash-tts の同時実行数に上限を設けていません。すべてのアカウントがデフォルトで対象なので、本まるごとや大量のプロンプトを一度に実行できます。
