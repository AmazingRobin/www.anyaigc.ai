Grok Imagine Video とは

Grok Imagine Video（grok-imagine-video）は、xAI が2026年1月28日に Grok Imagine API とともにリリースした動画モデルです。テキストから動画、画像から動画、動画編集に対応し、動画には音声が付きます。

xAI のローンチ記事によると、Artificial Analysis のテキストから動画のリーダーボードで1位でした（2026-01-28時点のデータ）。その後 xAI は Video 1.5 と 1.5 Lite をリリースしましたが、第1世代のモデルは提供終了になっておらず、xAI のドキュメントでは現在、動画の編集と延長向けの位置づけになっています。

AnyAIGC では480pが$0.0298 / 秒、720pが$0.0417 / 秒です。画像から動画では入力画像1枚につき$0.00119、動画編集では元動画1秒につき$0.00596が加算されます。xAI の定価は$0.05（480p）、$0.07（720p）/ 秒です。

  1. AnyAIGC に登録してください。新規アカウントには200万トークンの無料枠が付与され、$1 からチャージできます。
  2. コンソールで APIキーを作成し、環境変数 ANYAIGC_API_KEY に保存します。
  3. model に grok-imagine-video を指定して POST https://anyaigc.ai/v1/videos/generations にジョブを送信し、GET /v1/videos/{request_id} をポーリングして結果を取得します。

Grok Imagine Video API のよくある質問

Grok Imagine Video API の料金はいくらですか？

AnyAIGC では、Grok Imagine Video（grok-imagine-video）は出力動画の1秒あたりで課金され、480pは$0.0298 / 秒、720pは$0.0417 / 秒です。画像から動画では入力画像1枚につき$0.00119、動画編集では元動画1秒につき$0.00596が加算されます。6秒の480pクリップは約$0.179です。xAI の定価は480pが$0.05、720pが$0.07 / 秒です。最新の料金はモデル一覧でご確認ください。

Video 1.5、1.5 Lite、Video のどれを使えばよいですか？

Grok Imagine Video 1.5（grok-imagine-video-1.5-preview）は、映像、動き、セリフでシリーズをリードするモデルで、$0.0476 / 秒から。広告や完成度が求められる作品に向いています。1.5 Lite（grok-imagine-video-1.5-lite）はシリーズで最も低価格で、$0.0119 / 秒から、最大1080pに対応し、大量処理やドラフトに向いています。Grok Imagine Video（grok-imagine-video）は第1世代のモデルで、$0.0298 / 秒から。シリーズの中でアップロードした動画を編集できるのはこのモデルだけです。

動画はどのように編集しますか？

model、prompt、元のvideo（URL）を POST /v1/videos/edits に送り、変更したい内容を記述します。xAI のドキュメントによると、元動画は最大8.7秒、出力は最大720pです。現時点で、シリーズの中で編集に対応しているのは grok-imagine-video だけです。

grok-imagine-video は提供終了になりますか？

いいえ、現時点では提供終了していません。xAI が2026年11月2日に提供を終了したのは画像モデルの grok-imagine-image-quality で、動画モデルは影響を受けません。xAI のドキュメントでは、第1世代の動画モデルは動画の編集と延長向けと位置づけられています。

動画がすぐに返ってこないのはなぜですか？

動画生成は非同期です。送信するとジョブIDが返るので、約10秒ごとに GET /v1/videos/{request_id} をポーリングし、ジョブが完了したら動画のリンクを読み取ります。ほとんどのジョブは数十秒から数分かかります。リンクは一時的なものなので、早めにファイルをダウンロードして保存してください。

動画に音声はつきますか？

はい。Grok Imagine は映像と音声を一緒に生成し、効果音、環境音、セリフも含まれるので、別途ボイスオーバーは不要です。Video 1.5 と 1.5 Lite はリップシンクした音声に対応しています。

xAI のアカウントは必要ですか？

xAI アカウントは不要です。AnyAIGC に登録して APIキーを取得してください。エンドポイントは https://anyaigc.ai で、同じキーでプラットフォーム上のほかの300以上のモデルも使えます。

同時実行数の制限はありますか？

AnyAIGC は Grok Video モデルに同時実行数の制限を設けていません。すべてのアカウントでデフォルトで有効なので、バッチジョブでもクォータの申請は不要です。

AnyAIGC で請求書を発行できますか？

はい。実際にチャージした金額分の請求書を、コンソールでご自身で発行できます。

対応している支払い方法は何ですか？

WeChat Pay、Alipay、USDT、クレジットカードでチャージできます。残高は USD で、プラットフォーム上のすべてのモデルで使えます。チャージした金額分の請求書は、コンソールで発行できます。

新規ユーザー向けの無料トライアルはありますか？

はい。新規アカウントには200万トークン分のトライアル枠が付与されるので、チャージするかどうか決める前に試せます。チャージは $1 から可能です。

残高は返金できますか？

はい。未使用の残高は手数料なしで返金できます。返金をご希望の場合は、サポートにご連絡ください。

本物のモデルですか？データは安全ですか？

リクエストは公式のモデルチャネルに送られ、安価な代替モデルやリバースエンジニアリングによるモデルは使いません。法令で求められる場合を除き、プロンプトや出力を永続的に保存せず、学習にも使用しません。コンソールでは、リクエストごとのトークン数と料金を確認できます。
