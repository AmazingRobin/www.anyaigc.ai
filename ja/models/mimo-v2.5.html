from openai import OpenAI

FAQ

MiMo-V2.5 API のよくある質問

MiMo-V2.5 API の料金はいくらですか？

トークン単位の従量課金で、100万トークンあたりのUSDです。入力$0.1418、出力$0.2835、キャッシュヒット$0.0028。Xiaomi はこのモデルの提供を終了したため、比較できる現行の定価はありません。後継の MiMo-V2.6-Flash は入力$0.0563で、定価の約40%です。最新の料金はモデル一覧をご確認ください。

MiMo-V2.5 は提供終了になりましたか？

はい。Xiaomi は2026-10-14 18:00 (UTC+8) から mimo-v2.5 へのリクエストを mimo-v2.6-flash に振り分け、2026-10-21 10:00 に Xiaomi のプラットフォームで旧名称が使えなくなりました。AnyAIGC のモデル一覧には mimo-v2.5 が引き続き掲載されていますが、新規プロジェクトでは mimo-v2.6-flash をご利用ください。

MiMo-V2.6-Flash へ移行するにはどうすればよいですか？

エンドポイントは同じで、model を mimo-v2.6-flash に変更するだけです。Xiaomi によると max_completion_tokens のデフォルトは32768から131072に上がるため、上限を固定したい場合は明示的に指定してください。思考モードでは temperature と top_p は1.0と0.95に固定されます。

どのAPIエンドポイントを使えばよいですか？

OpenAI 互換の POST https://anyaigc.ai/v1/chat/completions を使い、Authorization: Bearer <API Key> を付けて、model に mimo-v2.5 を指定します。既存の OpenAI SDK プロジェクトは、base_url を https://anyaigc.ai/v1 に設定するだけで使えます。

同時実行数やRPMの制限はありますか？

AnyAIGC の MiMo は同時実行数の上限がなく、固定の RPM 上限もありません。すべてのアカウントでデフォルトです。長いコンテキストやディープシンキングのリクエストは時間がかかるため、タイムアウトとリトライを適切に設定してください。

出力は商用利用できますか？

モデルとその出力の利用は Xiaomi MiMo の公式規約に従います。AnyAIGC は独立した API プロバイダーであり、Xiaomi とは提携していません。

AnyAIGC で請求書を発行できますか？

はい。実際にチャージした金額分の請求書を、コンソールでご自身で発行できます。

対応している支払い方法は何ですか？

WeChat Pay、Alipay、USDT、クレジットカードでチャージできます。残高は USD で、プラットフォーム上のすべてのモデルで使えます。チャージした金額分の請求書は、コンソールで発行できます。

新規ユーザー向けの無料トライアルはありますか？

はい。新規アカウントには200万トークン分のトライアル枠が付与されるので、チャージするかどうか決める前に試せます。チャージは $1 から可能です。

残高は返金できますか？

はい。未使用の残高は手数料なしで返金できます。返金をご希望の場合は、サポートにご連絡ください。

本物のモデルですか？データは安全ですか？

リクエストは公式のモデルチャネルに送られ、安価な代替モデルやリバースエンジニアリングによるモデルは使いません。法令で求められる場合を除き、プロンプトや出力を永続的に保存せず、学習にも使用しません。コンソールでは、リクエストごとのトークン数と料金を確認できます。
