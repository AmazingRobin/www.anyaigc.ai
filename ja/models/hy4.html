Python ストリーミング
# pip install openai
import os
from openai import OpenAI

client = OpenAI(api_key=os.environ["ANYAIGC_API_KEY"], base_url="https://anyaigc.ai/v1")

stream = client.chat.completions.create(
    model="hy4",
    messages=[{"role": "user", "content": "Introduce yourself in three sentences and say what tasks you are best at."}],
    stream=True,
)
for chunk in stream:
    if chunk.choices and chunk.choices[0].delta.content:
        print(chunk.choices[0].delta.content, end="", flush=True)
print()

Chat Completions は OpenAI 形式の JSON を返します。usage には prompt_tokens と completion_tokens が含まれ、キャッシュヒットは usage.prompt_tokens_details.cached_tokens に表示されます。Anthropic 形式の例は API ドキュメントに沿っています。hy4 での画像、ツール、thinking パラメータについてはドキュメントをご確認ください。

FAQ

Hy4 API のよくある質問

Hy4 API の料金はいくらですか？定価からどのくらい安くなりますか？

トークン単位の従量課金で、100万トークンあたりのUSDで計算します。入力は$0.5630（定価$0.834）、出力は$1.6880（定価$2.501）、キャッシュヒットは$0.0283（定価$0.042）です。Tencent Cloud の定価は入力¥6、出力¥18、キャッシュヒット¥0.3で、USD の定価は1USDあたり約7.19CNYで換算しています。AnyAIGC の3つの料金はいずれも定価の約67.5%、つまり約32%オフです。最新の料金はモデル一覧でご確認ください。

Hy4 と Hy4 preview の違いは何ですか？

Tencent のリリースノート（2026-11-04）によると、正式版の Hy4 は初めてビジョンとコンピューター操作に対応し、エージェントと長期的なタスクの能力を強化しました。Tencent 独自のテストでは、ハルシネーション率が preview の15.76%から5.45%に下がっています。Tencent は、API の料金も preview から変わらないとしています。これらの数値はリリースノートに基づくもので、AnyAIGC では再検証していません。

Hy4 は画像入力に対応していますか？

はい。Tencent によると、Hy4 は初めてビジョンに対応しました。POST /v1/chat/completions の image_url コンテンツパートに、画像の URL または base64 データを渡してください。出力はテキストです。AnyAIGC のドキュメントには現在、画像のサイズや枚数の上限が記載されていないため、ドキュメントに従ってください。

どのAPIエンドポイントを使えばよいですか？

どちらの形式でも利用できます。OpenAI 互換の POST https://anyaigc.ai/v1/chat/completions と、Anthropic 形式の POST https://anyaigc.ai/v1/messages のどちらも、Authorization: Bearer <API Key> を付け、model に hy4 を指定します。OpenAI SDK では base_url に https://anyaigc.ai/v1 を設定してください。

同時実行数に制限はありますか？

AnyAIGC の Hy4 は、デフォルトですべてのアカウントで同時実行数の上限がありません。長いコンテキストやエージェントのリクエストは時間がかかるため、タイムアウトとリトライを適切に設定してください。

出力は商用利用できますか？

モデルと出力の利用は Tencent Hunyuan の公式規約に従います。AnyAIGC は独立した API プロバイダーであり、Tencent とは提携関係にありません。

AnyAIGC で請求書を発行できますか？

はい。実際にチャージした金額分の請求書を、コンソールでご自身で発行できます。

対応している支払い方法は何ですか？

WeChat Pay、Alipay、USDT、クレジットカードでチャージできます。残高は USD で、プラットフォーム上のすべてのモデルで使えます。チャージした金額分の請求書は、コンソールで発行できます。

新規ユーザー向けの無料トライアルはありますか？

はい。新規アカウントには500万トークン分のトライアル枠が付与されるので、チャージするかどうか決める前に試せます。チャージは $1 から可能です。

残高は返金できますか？

はい。未使用の残高は手数料なしで返金できます。返金をご希望の場合は、サポートにご連絡ください。

本物のモデルですか？データは安全ですか？

リクエストは公式のモデルチャネルに送られ、安価な代替モデルやリバースエンジニアリングによるモデルは使いません。法令で求められる場合を除き、プロンプトや出力を永続的に保存せず、学習にも使用しません。コンソールでは、リクエストごとのトークン数と料金を確認できます。
