概要

K3.1 最初のモデル、ポストトレーニングを大幅に強化

Moonshot AI によると、Kimi K3.1 Pro は新しい K3.1 シリーズの最初のモデルで、同社のこれまでで最も強力な3T級オープンウェイトモデルです。Moonshot は、Kimi K3 をポストトレーニングしたバージョンで、はるかに多くのポストトレーニング計算資源を投じ、数百の下流ドメインにまたがる共同強化学習で構築したと説明しています。

Moonshot は4つの分野での向上を報告しています。長時間コーディング（Unity、Unreal Engine、Godot への対応に加え、フロントエンドと Three.js でのレイアウト、タイポグラフィ、アニメーションの完成度向上）、3D制作（パラメトリックモデリング向けの Blender と CAD スクリプト）、金融リサーチ（OfficeQA Pro v2 で64.4）、そしてハルシネーション率の低下です。コンテキスト長は1,048,576トークン、思考モードは常にオンで、テキスト、画像、動画の入力に対応しています。

AnyAIGC では、kimi-k3.1-pro は OpenAI 互換の /v1/chat/completions エンドポイントで動作し、パラメータの制約は K3 と同じです。K3 からの移行はモデル名を変更するだけで済みます。Claude Code でもそのまま使え、同時実行数に上限はありません。

3ステップで Kimi K3.1 Pro API に接続

  1. 登録とチャージ：anyaigc.ai でアカウントを作成します。$1からチャージでき、残高はプラットフォーム上のすべてのモデルで使えます。
  2. APIキーを作成：コンソールでキーを作成し、sk- で始まる値をコピーして、環境変数 ANYAIGC_API_KEY に保存します。
  3. リクエストを送信：POST https://anyaigc.ai/v1/chat/completions を呼び出し、model に kimi-k3.1-pro を指定して、Authorization: Bearer ヘッダーを付けます。OpenAI SDK を使う場合は、base_url を https://anyaigc.ai/v1 に設定するだけです。

ヒント：K3.1 Pro は常に思考し、推論の内容は reasoning_content で返されます。temperature や top_p などのサンプリングパラメータは Moonshot 側で固定されているため、送信しないでください。マルチターンの会話やツール呼び出しでは、APIが返したアシスタントのメッセージ全体（reasoning_content と tool_calls を含む）を、変更せずに次のリクエストで送り返してください。

Alle Parameter finden Sie in der Chat-Completions-Referenz. Ersetzen Sie den Modellnamen in den Beispielen der Dokumentation durch die gewünschte Kimi-Modell-ID.

Claude Code

Claude Code で Kimi K3.1 Pro を使う

Claude Code のモデルを Kimi K3.1 Pro に切り替えます。コンテキスト長は1Mで、Moonshot はコーディング系のベンチマークの大半を、ハーネスに Claude Code を使って実行しています。

  1. Claude Code installieren: Verwenden Sie das offizielle Installationsprogramm (zum Beispiel npm install -g @anthropic-ai/claude-code).
  2. 設定を追加：~/.claude/settings.json を編集し、下の env ブロックを追加して、ANTHROPIC_AUTH_TOKEN を AnyAIGC で作成したキーに置き換えます。
  3. コーディングを開始：プロジェクトのフォルダーで claude を実行します。/model と入力して、現在のモデルが kimi-k3.1-pro になっていることを確認してください。

補助タスクのコストを抑える：ANTHROPIC_DEFAULT_HAIKU_MODEL を kimi-k2.7-code に設定すると、Claude Code の軽量なサブタスクには安いモデルが使われ、メインのタスクは K3.1 Pro のままになります。

手順の詳細とよくあるエラーについては、Claude Code セットアップガイドをご覧ください。ガイド内のモデル名を kimi-k3.1-pro に置き換えてください。

FAQ

Kimi K3.1 Pro API のよくある質問

Kimi K3.1 Pro API の料金はいくらですか？

AnyAIGC では、kimi-k3.1-pro はトークン単位で課金されます。入力は100万トークンあたり$0.8100、出力は100万トークンあたり$4.0500、キャッシュヒットは100万トークンあたり$0.0810です。Moonshot の公式USD価格は入力$2.00、出力$10.00、キャッシュヒット$0.20で、AnyAIGC は定価の約40%です。出力には思考トークンが含まれます。最新の料金はモデル一覧をご確認ください。

Kimi K3.1 Pro のモデルIDは何ですか？コンテキスト長はどれくらいですか？

モデルIDは kimi-k3.1-pro です。Moonshot は1,048,576トークン（1M）のコンテキスト長を掲載しています。max_completion_tokens のデフォルトは131,072で、最大1,048,576まで設定できます。

Kimi K3.1 Pro は K3 と何が違いますか？

Moonshot によると、K3.1 Pro は Kimi K3 に、はるかに多くのポストトレーニング計算量をかけ、数百の下流ドメインをまたぐ共同の強化学習で訓練したモデルです。Moonshot が報告している向上点には、長期的なコーディング（Kimi Code Bench 3.0が55.95から61.2に向上）、金融リサーチ（社内評価が58.8から70.4に向上）、事実の正確性（主張ごとのハルシネーション率が23.4%から8.3%に低下）があります。パラメータの制約は K3 と同じなので、移行はモデル名を変更するだけです。AnyAIGC での K3.1 Pro の料金は入力$0.8100、出力$4.0500で、K3 より約3分の1安くなっています。

Kimi K3.1 Pro の思考の深さはどう調整しますか？

K3.1 Pro は常に思考し、思考をオフにすることはできません。深さはリクエストボディのトップレベルにある reasoning_effort フィールドで指定します。low、high、max のいずれかで、デフォルトは max です。temperature や top_p などのサンプリングパラメータは Moonshot 側で固定されているため、リクエストに含めないでください。

Kimi K3.1 Pro はツール呼び出し、画像・動画の入力に対応していますか？

はい。Moonshot のドキュメントには、ツール呼び出し（tools / tool_choice）、構造化出力（json_schema）、ストリーミング、画像・動画の入力が記載されています。マルチターンの会話やツール呼び出しでは、アシスタントのメッセージ全体（reasoning_content と tool_calls を含む）を、変更せずに次のリクエストで送り返してください。

Kimi K3.1 Pro は Claude Code で使えますか？

はい。~/.claude/settings.json の env ブロックで、ANTHROPIC_BASE_URL を https://anyaigc.ai、ANTHROPIC_AUTH_TOKEN をご自身のAPIキー、ANTHROPIC_MODEL を kimi-k3.1-pro に設定し、claude を実行してください。

Kimi K3.1 Pro はオープンソースですか？

Moonshot は K3.1 Pro を、これまでで最も強力な3Tクラスのオープンウェイトモデルと位置づけており、完全な重みを2026年11月4日までに公開するとしています。AnyAIGC 経由でAPIを呼び出せば、自分でホストする必要はありません。モデルのライセンスと商用利用は、Moonshot AI の公式規約に従います。

同時実行数やレート制限はありますか？

AnyAIGC は kimi-k3.1-pro の同時実行数に上限を設けておらず、すべてのユーザーがデフォルトで利用できます。バッチ処理、CIパイプライン、並列エージェントに向いています。Moonshot 自身のプラットフォームでは、チャージ額のティアに応じて同時実行数、RPM、TPM、TPD が制限されますが、AnyAIGC 経由で呼び出す場合、そのティアは適用されません。

Kimi K3.1 Pro APIキーはどうすれば取得できますか？

anyaigc.ai で登録し、残高をチャージして、コンソールでキーを作成します。同じキーで、プラットフォーム上のすべての Kimi モデルと300以上のほかのモデルを呼び出せるため、Moonshot のプラットフォームアカウントは別途必要ありません。

AnyAIGC で請求書を発行できますか？

はい。実際にチャージした金額分の請求書を、コンソールでご自身で発行できます。

対応している支払い方法は何ですか？

WeChat Pay、Alipay、USDT、クレジットカードでチャージできます。残高は USD で、プラットフォーム上のすべてのモデルで使えます。チャージした金額分の請求書は、コンソールで発行できます。

新規ユーザー向けの無料トライアルはありますか？

はい。新規アカウントには200万トークン分のトライアル枠が付与されるので、チャージするかどうか決める前に試せます。チャージは $1 から可能です。

残高は返金できますか？

はい。未使用の残高は手数料なしで返金できます。返金をご希望の場合は、サポートにご連絡ください。

本物のモデルですか？データは安全ですか？

リクエストは公式のモデルチャネルに送られ、安価な代替モデルやリバースエンジニアリングによるモデルは使いません。法令で求められる場合を除き、プロンプトや出力を永続的に保存せず、学習にも使用しません。コンソールでは、リクエストごとのトークン数と料金を確認できます。

入力したデータはトレーニングに使われますか？

いいえ。法令で必要な場合を除き、AnyAIGC はプロンプトや出力を永続的に保存せず、モデルの学習にも使用しません。リクエストは HTTPS で暗号化されます。AnyAIGC のプライバシーポリシーをご覧ください。モデル自体のデータポリシーは Moonshot AI の公式規約に従います。
