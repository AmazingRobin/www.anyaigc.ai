doubao-seed-2-0-lite API を組み込む

  1. AnyAIGC のアカウントを作成すると、500万トークンの無料トライアルから始められます。
  2. コンソールでキーを作成し、ANYAIGC_API_KEY として保存します。
  3. POST /v1/chat/completions にチャットリクエストを送り、JSON レスポンスから返信を読み取ります。

デフォルトの例は最新のスナップショットを使っています。「旧版」タブを選ぶと、1つ前のスナップショット用の完全なコードを表示できます。概要は最新バージョンについて説明しています。

Python の例は標準ライブラリを使っています。SDK の例には openai をインストールしてください。これらのストリーミングなしの呼び出しは choices と usage を返します。ほかのフィールドは Chat Completions リファレンスをご覧ください。

仕様と選び方

Volcengine のドキュメントでは、Seed 2.0 Lite を、性能とコストのバランスを取った、利用頻度の高い企業向けシナリオ用のモデルと位置付け、総合的な能力は前世代の Doubao-Seed-1.8 を上回るとしています。

公式のモデル一覧には、コンテキスト長256K、最大入力224K、最大出力128Kと記載されています。

ベンダーによると、2026年4月にリリースされた260428 LTS版は、テキスト、画像、音声、動画をまとめて理解できます。

このページの料金（入力トークン [0, 32,000]）は、入力$0.0911 / 100万トークン、出力$0.5569 / 100万トークン、キャッシュヒット$0.0182 / 100万トークンです。ほかのティアは上の料金表に掲載しています。

doubao-seed-2-0-mini との比較：ベンダーによると、Mini は低レイテンシ、高い同時実行数、コスト重視のシナリオを対象としているため、応答の速さを最優先するときに選んでください。

仕様はベンダーの公式ドキュメント（docs.volcengine.com）に基づいています。このページの表は料金を示したもので、最新の料金はモデル一覧が正となります。

doubao-seed-2-0-lite API のよくある質問

doubao-seed-2-0-lite API の料金はいくらですか？

入力は100万トークンあたり$0.0911から、出力は$0.5569からです。表には公開されている全ティアと、該当するキャッシュ・音声の料金を掲載しています。最新の料金はモデル一覧で確認してください。

どのように組み込めばよいですか？呼び出しは何を返しますか？

model と messages を指定して POST /v1/chat/completions を呼び出します。これらのストリーミングなしの例は JSON を返し、返信は choices[0].message.content、トークン使用量は usage から読み取れます。APIリファレンスをご覧ください。

同時実行数の制限はありますか？

AnyAIGC では、この Doubao Seed ファミリーの同時実行数に上限を設けていません。

このモデルは、どのような用途向けですか？

動画、画像、音声、テキストの理解を統合し、エージェント、コーディング、GUIの能力も強化されています。複数の種類の入力を読み取り、その情報をプログラミングやインターフェースのタスクにつなげるアプリケーションに向いています。

デフォルトで使われるバージョンはどれですか？古いバージョンも使えますか？

概要とデフォルトのコード例には、モデル一覧に掲載されている最新のスナップショットを使用しています。クイックスタートには、既存の連携向けに旧版のコード例も載せています。機能はスナップショットによって異なる場合があります。掲載の料金は確認時点で一致していました。

出力を商用利用できますか？

商用利用とコンテンツの権利は、ByteDance の公式規約に従います。人物、商標、第三者の素材に関する権利を確認してください。

AnyAIGC で請求書を発行できますか？

はい。実際にチャージした金額分の請求書を、コンソールでご自身で発行できます。

対応している支払い方法は何ですか？

WeChat Pay、Alipay、USDT、クレジットカードでチャージできます。残高は USD で、プラットフォーム上のすべてのモデルで使えます。チャージした金額分の請求書は、コンソールで発行できます。

新規ユーザー向けの無料トライアルはありますか？

はい。新規アカウントには500万トークン分のトライアル枠が付与されるので、チャージするかどうか決める前に試せます。チャージは $1 から可能です。

残高は返金できますか？

はい。未使用の残高は手数料なしで返金できます。返金をご希望の場合は、サポートにご連絡ください。

本物のモデルですか？データは安全ですか？

リクエストは公式のモデルチャネルに送られ、安価な代替モデルやリバースエンジニアリングによるモデルは使いません。法令で求められる場合を除き、プロンプトや出力を永続的に保存せず、学習にも使用しません。コンソールでは、リクエストごとのトークン数と料金を確認できます。
