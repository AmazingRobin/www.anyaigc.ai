クイックスタート

Chat Completions から始める

  1. コンソールでアカウントとAPIキーを作成します。
  2. Base URL を https://anyaigc.ai/v1 に設定します。
  3. model を指定して messages を送信します。
cURL · POST /v1/chat/completions
curl https://anyaigc.ai/v1/chat/completions \
  -H "Authorization: Bearer $ANYAIGC_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"qwen3.8-flash","messages":[{"role":"user","content":"Explain what a MoE model is in three sentences."}]}'
Python · OpenAI SDK
from openai import OpenAI
import os
client = OpenAI(api_key=os.environ["ANYAIGC_API_KEY"], base_url="https://anyaigc.ai/v1")
response = client.chat.completions.create(model="qwen3.8-flash", messages=[{"role":"user","content":"Explain what a MoE model is in three sentences."}])
print(response.choices[0].message.content)

FAQ

Qwen API のよくある質問

Qwen はどのエンドポイントを使いますか？

対話モデルは POST https://anyaigc.ai/v1/chat/completions を使います。model と messages を送信し、Authorization: Bearer <API Key> を付けてください。

Qwen API の料金はいくらですか？

Qwen の対話モデルは、入力トークンと出力トークンを分けて、100万トークンあたりのUSDで課金されます。入力は$0.0338（qwen-flash）から$1.6875（qwen3.7-max）、出力は$0.2700（qwen-flash）から$5.0625（qwen3.7-max）です。各モデルの料金は上の料金表に記載しています。最新の料金はモデル一覧が正となります。

同時実行数に上限はありますか？

このページの Qwen 対話モデルは同時実行数の上限がなく、すべてのユーザーが利用できます。

APIキーはどう取得しますか？

AnyAIGC のアカウントを作成し、コンソールでAPIキーを作成します。1つのキーで300以上のモデルを利用できます。

画像入力やツール呼び出しには対応していますか？

対応する機能はモデルによって異なります。モデル一覧の最新のタグを確認してください。エンドポイントは変わりません。

AnyAIGC で請求書を発行できますか？

はい。実際にチャージした金額分の請求書を、コンソールでご自身で発行できます。

対応している支払い方法は何ですか？

WeChat Pay、Alipay、USDT、クレジットカードでチャージできます。残高は USD で、プラットフォーム上のすべてのモデルで使えます。チャージした金額分の請求書は、コンソールで発行できます。

新規ユーザー向けの無料トライアルはありますか？

はい。新規アカウントには200万トークンのトライアル枠が付与されます。

残高は返金できますか？

はい。未使用の残高は手数料なしで返金できます。

これらは公式のモデルですか？データは安全ですか？

リクエストは公式のモデルチャネルを経由します。プロンプトと出力は、法令で求められる場合を除き、永続的に保存されず、学習にも使われません。
