Claude Opus 4.6 API を3ステップで呼び出す

  1. 登録してチャージする：anyaigc.ai でアカウントを作成します。残高は、プラットフォーム上のすべてのモデルで使えます。
  2. APIキーを作成する：コンソールでトークンを作成し、sk- で始まるキーをコピーします。
  3. リクエストを送信：Anthropic Messages 形式のリクエストを https://anyaigc.ai/v1/messages に POST し、Authorization: Bearer で認証します。

そのほかのパラメータ（tools、thinking、ストリーミング、PDF・画像入力など）は AnyAIGC Messages API ドキュメントをご覧ください。各フィールドの動作は Anthropic の公式ドキュメントと同じです。

Claude Opus 4.6 API のよくある質問

Claude Opus 4.6 API の料金はいくらですか？

AnyAIGC では claude-opus-4-6 はトークン単位の従量課金で、入力は100万トークンあたり $0.5956、出力は100万トークンあたり $2.978、5分キャッシュ書き込みは $0.7445、1時間キャッシュ書き込みは $1.1912、キャッシュヒットは $0.0596 です。Anthropic の公式の定価は入力 $5、出力 $25 なので、AnyAIGC は定価の約11.9% になります。

Claude Opus 4.6 は提供終了になりましたか？いつまで使えますか？

提供終了にはなっていません。Anthropic は Claude Opus 4.6 を旧世代モデル（Active, Legacy）としており、提供終了は早くても2027年2月5日です。現在も問題なく呼び出せ、AnyAIGC でも claude-opus-4-6 として利用できます。新規プロジェクトには、Anthropic は Claude Opus 5.5（claude-opus-5-5）を推奨しています。

Claude Opus 4.6 のモデルID は何ですか？API は Anthropic 互換ですか？

モデルID は claude-opus-4-6 で、リクエストボディの model フィールドに指定します。エンドポイントは https://anyaigc.ai/v1/messages で、リクエストボディは Anthropic の Messages 形式（model、max_tokens、system、messages、tools、cache_control など）に従います。認証は Authorization: Bearer に続けて APIキーを指定します。公式 SDK では、ベース URL を https://anyaigc.ai に設定するだけです。

Claude Code で Claude Opus 4.6 を使えますか？

はい。~/.claude/settings.json の env ブロックで、ANTHROPIC_BASE_URL を https://anyaigc.ai、ANTHROPIC_AUTH_TOKEN をご自身の APIキー、ANTHROPIC_MODEL を claude-opus-4-6 に設定し、claude を実行してください。1つのコマンドでインストールと設定をまとめて行うこともできます：curl -fsSL https://www.anyaigc.ai/install.sh | bash

プロンプトキャッシュはどのように課金されますか？

コンテンツブロックに cache_control を追加すると、キャッシュが有効になります。最初の書き込みはキャッシュ書き込みレートで課金されます（100万トークンあたり、5分は $0.7445、1時間は $1.1912）。その後、キャッシュされたトークンは100万トークンあたり $0.0596 だけで、通常の入力価格の約10% です。キャッシュは、長いシステムプロンプト、大きなコードベースのコンテキスト、マルチターンのエージェントタスクで特に効果があります。

同時実行数やレート制限はありますか？

AnyAIGC では claude-opus-4-6 に同時実行数の上限を設けていません。すべてのアカウントでデフォルトで利用でき、バッチ処理や複数エージェントの並列実行に向いています。

Claude Opus 4.6 は何が得意ですか？

Anthropic によると、Opus 4.6 はより慎重に計画を立て、エージェントタスクを長く持続し、大規模なコードベースでもより安定して動作し、コードレビューとデバッグの能力も向上しています。Opus 4.6 向けに調整済みの既存の連携、コーディングとコードレビュー、長いコンテキストの分析、エージェントのワークフローに向いています。Anthropic が公開した結果では、Terminal-Bench 2.0 で 65.4% のスコアです。

Claude Opus 4.6 の APIキーはどうすれば取得できますか？

anyaigc.ai で登録し、クレジットをチャージして、コンソールでトークンを作成してください。同じキーで Claude Opus 4.6 とプラットフォーム上の 300+ のその他のモデルを利用できます。

AnyAIGC で請求書を発行できますか？

はい。実際にチャージした金額分の請求書を、コンソールでご自身で発行できます。

対応している支払い方法は何ですか？

WeChat Pay、Alipay、USDT、クレジットカードでチャージできます。残高は USD で、プラットフォーム上のすべてのモデルで使えます。チャージした金額分の請求書は、コンソールで発行できます。

新規ユーザー向けの無料トライアルはありますか？

はい。新規アカウントには200万トークン分のトライアル枠が付与されるので、チャージするかどうか決める前に試せます。チャージは $1 から可能です。

残高は返金できますか？

はい。未使用の残高は手数料なしで返金できます。返金をご希望の場合は、サポートにご連絡ください。

本物のモデルですか？データは安全ですか？

リクエストは公式のモデルチャネルに送られ、安価な代替モデルやリバースエンジニアリングによるモデルは使いません。法令で求められる場合を除き、プロンプトや出力を永続的に保存せず、学習にも使用しません。コンソールでは、リクエストごとのトークン数と料金を確認できます。

データは学習に使われますか？

リクエストはHTTPSで暗号化されて送信されます。データの取り扱いについては、AnyAIGC のプライバシーポリシーをご覧ください。モデル自体のデータポリシーは Anthropic の公式規約に従います。
