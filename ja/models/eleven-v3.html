モデルについて

Eleven v3：ドラマチックなナレーション

Eleven v3 は ElevenLabs の旧世代フラッグシップの音声合成モデルです。ElevenLabs は、高い感情表現の幅と文脈理解を備えた、自然でリアルな音声を生成すると説明しています。モデル一覧では、表現力が強く、物語やショートドラマの吹き替えに向き、雰囲気がしっかり出ると説明されています。

公式ドキュメントでは、70言語以上に対応し、1回の生成で5,000文字までと記載されています。ドキュメントでは v3 は旧世代、最新のフラッグシップは Eleven v4 とされています。AnyAIGC では2つの料金が同じなので、新規プロジェクトでは同じテキストを両方で聴き比べてみる価値があります。

AnyAIGC では eleven_v3 は POST /v1/audio/speech で動作し、入力文字数に応じて課金されます。同時実行数の上限はありません。

3ステップで Eleven v3 API を呼び出す

  1. 登録とチャージ：anyaigc.ai でアカウントを作成します。チャージは$1からで、残高はプラットフォームのすべてのモデルで共通して使えます。
  2. APIキーの作成：コンソールでトークンを作成し、sk- で始まるキーをコピーして、環境変数 ANYAIGC_API_KEY に保存します。
  3. リクエストを送信：POST https://anyaigc.ai/v1/audio/speech を呼び出し、model に eleven_v3、voice に ElevenLabs の voice_id を指定します。認証は Authorization: Bearer で行い、返ってきた音声を mp3 として保存します。

パラメータの補足：モデルIDは大文字小文字を区別するため、eleven_v3 と書いてください。voice には ElevenLabs の voice_id を指定します。存在しない、または利用できない voice_id を指定すると400が返ります。リファレンスでは input は最大4,096文字なので、それより長いテキストは分割してください。サンプルでは、レスポンスボディを mp3 ファイルとして保存しています。

すべてのパラメータは 音声生成 API リファレンスをご覧ください。サンプルのモデル名は、使いたい Eleven のモデルIDに置き換えてください。

FAQ

Eleven v3 API のよくある質問

Eleven v3 API の料金はいくらですか？

AnyAIGC では、eleven_v3 は文字数単位の課金で、1万文字あたり$0.6480です。ElevenLabs の定価は1万文字あたり$0.80で、そこから約19%オフです。料金は固定で、サブスクリプションや月額料金はありません。最新の料金はモデル一覧で確認してください。

Eleven v3 のモデルIDは何ですか？ ElevenLabs との関係は？

モデルIDは eleven_v3（大文字小文字を区別）で、ElevenLabs の model_id と同じです。AnyAIGC は OpenAI 形式の /v1/audio/speech 呼び出しを提供する独立した API プロバイダーであり、ElevenLabs とは提携していません。

Eleven v3 とほかの Eleven モデルはどう使い分けますか？

プラットフォームには7つの Eleven 音声モデルがあります：Eleven v4（フラッグシップ）、Eleven v4 Turbo（低レイテンシ）、Eleven v3、Eleven v3 Conversational、Eleven Multilingual v2、Eleven Flash v2.5、Eleven Flash v2。仕上げ用の高品質な音声には v4、音声アシスタントには v4 Turbo、長文や多言語が混在するテキストには Multilingual v2、字幕の大量バッチには Flash v2.5 が向いています。決める前に、同じテキストで試聴して比べてください。

Eleven v3 の APIキーはどう取得しますか？

anyaigc.ai で登録してチャージし、コンソールでトークンを作成します。1つのキーでプラットフォーム上の300以上のモデルを使えるので、ElevenLabs のアカウントを別に用意する必要はありません。リクエストボディの model に eleven_v3 を指定してください。

Eleven v3 API はどう呼び出しますか？voice には何を指定しますか？

POST https://anyaigc.ai/v1/audio/speech を呼び出し、必須の model、input、voice を指定します。voice には ElevenLabs の voice_id を指定します。不明または利用できない voice_id は400を返します。response_format は mp3、opus、aac、flac に対応しています。APIリファレンスを参照してください。

Eleven v3 の1回のリクエストで、テキストは何文字まで使えますか？

ElevenLabs のドキュメントでは、このモデルの上限は1回の生成あたり5,000文字とされています。AnyAIGC の Create speech リファレンスでは input の最大長が4,096文字なので、それより長いテキストはその長さで分割し、生成後に音声を結合してください。

Eleven v3 は中国語に対応していますか？対応言語数は？

はい。公式ドキュメントでは、このモデルは70言語以上に対応しており、中国語（Mandarin、zh）も含まれます。対応言語の詳細は ElevenLabs のモデルドキュメントをご覧ください。

Eleven v3 は提供終了になりましたか？

いいえ。公式ドキュメントでは v3 を旧世代、Eleven v4 を最新のフラッグシップとしており、v3 は公式の非推奨モデル一覧（eleven_turbo_v2_5、eleven_turbo_v2 など）には含まれていません。新規プロジェクトでは、同じテキストを Eleven v4 でも試してください。AnyAIGC では両者の料金は同じです。モデルが引き続き利用できるかどうかは、モデル一覧で確認できます。

レート制限はありますか？

AnyAIGC は eleven_v3 に同時実行数の上限を設けておらず、すべてのアカウントがデフォルトで利用できるため、バッチ生成や並列タスクも問題ありません。課金は文字数単位で、月額料金や一定期間でリセットされるクォータはありません。

自分でクローンした音声は使えますか？

API リファレンスには、voice に ElevenLabs の voice_id を指定すると書かれているだけです。ご自身の ElevenLabs アカウントのクローン音声を AnyAIGC のキーで使えるかどうかは記載されていません。AnyAIGC のサポートにお問い合わせのうえ、ご確認ください。

AnyAIGC で請求書を発行できますか？

はい。実際にチャージした金額分の請求書を、コンソールでご自身で発行できます。

対応している支払い方法は何ですか？

WeChat Pay、Alipay、USDT、クレジットカードでチャージできます。残高は USD で、プラットフォーム上のすべてのモデルで使えます。チャージした金額分の請求書は、コンソールで発行できます。

新規ユーザー向けの無料トライアルはありますか？

はい。新規アカウントには500万トークン分のトライアル枠が付与されるので、チャージするかどうか決める前に試せます。チャージは $1 から可能です。

残高は返金できますか？

はい。未使用の残高は手数料なしで返金できます。返金をご希望の場合は、サポートにご連絡ください。

本物のモデルですか？データは安全ですか？

リクエストは公式のモデルチャネルに送られ、安価な代替モデルやリバースエンジニアリングによるモデルは使いません。法令で求められる場合を除き、プロンプトや出力を永続的に保存せず、学習にも使用しません。コンソールでは、リクエストごとのトークン数と料金を確認できます。

入力したテキストや生成した音声は学習に使われますか？

いいえ。法令で求められる場合を除き、AnyAIGC は入力と出力を永続的に保存せず、学習にも使用しません。リクエストは HTTPS で暗号化されます。AnyAIGC のプライバシーポリシーをご覧ください。モデル自体のデータの取り扱いは ElevenLabs が定めています。
