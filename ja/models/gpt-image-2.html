3ステップで GPT Image 2 API を始める

  1. 登録：AnyAIGC のアカウントを作成します。新規アカウントには200万トークン分のトライアル枠が付与され、チャージは $1 から可能です。
  2. APIキーを作成：コンソールでキーを発行し、環境変数 ANYAIGC_API_KEY に保存します。
  3. リクエストを送信：model に gpt-image-2 を指定して https://anyaigc.ai/v1/images/generations を呼び出します。画像を編集するには /v1/images/edits を使います。

1枚あたりの固定料金で使いたい場合は、model を gpt-image-2-c（1K は1枚$0.0119、2K/4K は$0.0149）に変更し、n と mask を外してください。

レスポンスは data[0].url を返します。base64 で受け取るには response_format=b64_json を指定します。プロンプトは最大1000文字です。すべてのパラメータは generations のドキュメントをご覧ください。

GPT Image 2 API のよくある質問

GPT Image 2 API の料金はいくらですか？

AnyAIGC では、gpt-image-2 はトークン単位で課金されます。100万トークンあたり、テキスト入力$0.3971、画像入力$0.6354、画像出力$2.3830で、テキストのキャッシュ入力は$0.1588、画像のキャッシュ入力は$0.2541です。OpenAI の定価は$5.00、$8.00、$30.00です。1024×1024、medium 品質の画像1枚の画像出力コストは約$0.0042です（定価では約$0.0530）。最新の料金はモデル一覧でご確認ください。

gpt-image-2 はまだ使えますか？ GPT Image 2.5 に切り替えるべきですか？

はい、引き続き使えます。OpenAI のガイドは新規の連携に GPT Image 2.5 を推奨していますが、gpt-image-2 に非推奨の通知はなく、AnyAIGC では通常どおり動作します。GPT Image 2.5 では xhigh と max の品質レベルが加わりますが、価格では gpt-image-2 が有利です。AnyAIGC の画像出力は100万トークンあたり、gpt-image-2 が$2.3830、2.5 が$17.8200です。切り替えは model フィールドを変えるだけなので、同じプロンプトを 2.5 Flare でも実行して比較できます。

対応しているサイズ、品質、フォーマットは？

一般的なサイズは 1024×1024、1536×1024、1024×1536、2048×2048、2048×1152、3840×2160、2160×3840、auto です。長辺が3840px以下、両辺が16の倍数、アスペクト比が3:1以下、総ピクセル数が655,360〜8,294,400であれば、カスタムサイズも使えます。品質は low、medium、high、auto です。format フィールドで png、jpeg、webp を選べ、結果は画像URLまたは base64 で受け取れます。最低価格は上記のプリセットサイズが対象で、カスタムサイズと透過背景はモデル一覧に記載のとおり高くなります。

画像から画像への編集やインペイントはどうすればよいですか？

multipart/form-data で POST /v1/images/edits を呼び出します。image フィールドは、参照画像を16枚未満、合計50MBまで受け付けます。インペイントでは mask も送信します。透明な部分が描き直される領域になり、PNG で4MB未満、サイズは最初の画像と同じにする必要があります。パラメータは edits のドキュメントをご覧ください。

1枚あたり課金のバージョンはありますか？ gpt-image-2-c の料金は？

はい。AnyAIGC の gpt-image-2-c は、GPT Image 2 の1枚あたり課金版です。エンドポイントは同じで、変わるのは model フィールドだけです。どの品質でも1枚あたりの料金は一定で、1K出力は$0.0119、2K・4K出力は$0.0149です。1回のリクエストで返る画像は1枚で、n、mask、透過背景には対応していません。high 以上の品質や大きいサイズでは、1枚あたり課金のほうが通常は安くなります。

同時実行数に制限はありますか？

AnyAIGC は gpt-image-2 の同時実行数に上限を設けておらず、すべてのアカウントでデフォルトで適用されます。ベースURLは https://anyaigc.ai/v1 です。課金は USD で、WeChat Pay、Alipay、USDT、クレジットカードで支払え、同じキーで300以上のほかのモデルも使えます。

AnyAIGC で請求書を発行できますか？

はい。実際にチャージした金額分の請求書を、コンソールでご自身で発行できます。

対応している支払い方法は何ですか？

WeChat Pay、Alipay、USDT、クレジットカードでチャージできます。残高は USD で、プラットフォーム上のすべてのモデルで使えます。チャージした金額分の請求書は、コンソールで発行できます。

新規ユーザー向けの無料トライアルはありますか？

はい。新規アカウントには200万トークン分のトライアル枠が付与されるので、チャージするかどうか決める前に試せます。チャージは $1 から可能です。

残高は返金できますか？

はい。未使用の残高は手数料なしで返金できます。返金をご希望の場合は、サポートにご連絡ください。

本物のモデルですか？データは安全ですか？

リクエストは公式のモデルチャネルに送られ、安価な代替モデルやリバースエンジニアリングによるモデルは使いません。法令で求められる場合を除き、プロンプトや出力を永続的に保存せず、学習にも使用しません。コンソールでは、リクエストごとのトークン数と料金を確認できます。

生成した画像を商用利用できますか？

利用権とコンテンツポリシーは OpenAI の公式規約に従います。AnyAIGC は API アクセスを提供するだけで、出力の利用方法に追加の制限は設けていません。実在の人物の肖像や第三者の商標が含まれる画像では、必要な権利を確保してください。
