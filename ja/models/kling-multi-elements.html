仕様

仕様と選び方

マルチエレメント動画編集は、まずソース動画の初期化から始まります。エレメントの置き換えや削除には、先に選択範囲のマーキングが必要です。

入力は MP4 または MOV で、長さは2〜5秒または7〜10秒です。

動画の辺の長さは720〜2160px、フレームレートは24、30、60fpsのいずれかです。

初期化で発行されるセッション ID の有効期間は24時間です。過去の生成結果は、直近30日以内のものに限られます。

このページでは v1-6 std 5秒を$0.5064、v1-6 std 10秒を$1.013、v1-6 pro 5秒を$0.8440、v1-6 pro 10秒を$1.688として掲載しており、上の料金表と一致しています。

kling-motion-control と比べると、Multi Elements は既存の動画に含まれるオブジェクトを編集し、Motion Control は参照動画のモーションを新しいキャラクターに転送します。

仕様はベンダーの公式ドキュメント（klingai.com）に基づいています。このページの表は料金を示したもので、最新の料金はモデル一覧が正となります。

FAQ

Kling Multi Elements API の料金はいくらですか？

AnyAIGC では、Kling Multi Elements は1回あたり$0.5064からです。課金単位はモデル一覧の表示に従います。最新の料金はモデル一覧でご確認ください。

Kling Multi Elements では何ができますか？

動画内の複数のエレメントをブレンドし、レイヤーを重ねた複雑なクリエイティブ制作に対応します。

API は非同期ですか？

はい。/kling/v1/videos/multi-elements にタスクを送信してタスク ID を受け取り、ドキュメントに記載の照会エンドポイントで結果をポーリングします。

同時実行数に制限はありますか？

AnyAIGC の Kling モデルは、デフォルトで同時実行数の上限がありません。

認証はどのように行いますか？

Authorization: Bearer <API Key> を送信します。キーは環境変数 ANYAIGC_API_KEY から読み込んでください。

生成したコンテンツは商用利用できますか？

利用権とコンテンツポリシーは Kling の公式規約に従います。

AnyAIGC で請求書を発行できますか？

はい。実際にチャージした金額分の請求書を、コンソールでご自身で発行できます。

どの支払い方法に対応していますか？

WeChat Pay、Alipay、USDT、クレジットカードでチャージできます。残高は USD で、プラットフォーム上のすべてのモデルで使えます。チャージした金額分の請求書は、コンソールで発行できます。

新規ユーザー向けのトライアル枠はありますか？

新規ユーザーは、登録後に2Mトークンのトライアル枠を受け取れます。

未使用の残高は返金できますか？

未使用の残高は、サポートにご連絡いただければ返金できます。

Kling Multi Elements はどのような用途に向いていますか？

Kling Multi Elements はマルチエレメント合成向けです。ワークフローを選ぶ前に、このページの機能と利用シーンのセクションを確認してください。

Kling Multi Elements を他の Kling モデルと比較するには、どこを見ればよいですか？

このページの Kling モデルファミリーのセクションで、関連する生成、制御、音声、アセットのツールを比較できます。

エンドポイントはどのように実装すればよいですか？

エンドポイントごとの APIドキュメントを参照してください。すべての Kling エンドポイントが汎用の prompt ペイロードを受け付けるとは限りません。
