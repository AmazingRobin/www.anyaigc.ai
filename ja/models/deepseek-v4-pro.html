モデルについて

1.6TパラメータのV4フラッグシップ

DeepSeekは2026年4月にV4プレビューとしてV4 ProとV4 Flashの2モデルを公開し、1Mトークンのコンテキスト長を標準にしました。V4 Proは8月13日に一般提供（GA）となり、low、high、maxの3段階の推論強度に対応しました。

V4 Proは総パラメータ1.6T、アクティブパラメータ49BのMoEです。Compressed Sparse AttentionとHeavily Compressed Attentionのハイブリッドを採用し、32Tトークンで事前学習されており、MITライセンスのオープンウェイトです。1Mトークンのコンテキスト長、最大384Kの出力トークン、思考モードと非思考モードに対応し、思考モードがデフォルトでオンです。

9月にV4.1 Flashが公開されたあと、DeepSeekは一時V4 Proの提供終了を予定していましたが、その後、課金を変えずに提供を続けると発表しました。AnyAIGCではdeepseek-v4-proがOpenAI互換の/v1/chat/completionsエンドポイントで動作し、Claude Codeでもそのまま使えます。料金は終日同一で、同時実行数の上限もありません。

クイックスタート

DeepSeek V4 Pro API をはじめる

  1. 登録とチャージ：anyaigc.ai でアカウントを作成します。$1からチャージでき、残高はプラットフォーム上のすべてのモデルで使えます。
  2. APIキーの作成：コンソールでキーを作成し、sk- で始まるキーをコピーして、環境変数 ANYAIGC_API_KEY に保存します。
  3. リクエストを送信: POST https://anyaigc.ai/v1/chat/completions を呼び出し、model に deepseek-v4-pro を指定して、Authorization: Bearer ヘッダーを付けます。OpenAI SDK を使う場合は、base_url を https://anyaigc.ai/v1 に設定するだけです。

パラメータ: DeepSeek によると、V4 シリーズはデフォルトで思考します。リクエストボディの thinking フィールドでオン/オフを切り替え（{"type": "enabled"} または {"type": "disabled"}）、reasoning_effort で思考の深さを指定します（公式では low / high / max）。思考トークンは出力トークンとして計算され、usage.completion_tokens_details.reasoning_tokens に表示されます。temperature などのサンプリングパラメータは、思考モードでは効果がありません。

すべてのパラメータは Chat Completions API リファレンスをご覧ください。ドキュメントのサンプルにあるモデル名を、使いたい DeepSeek のモデルID に置き換えてください。

Claude Code

Claude Code で DeepSeek V4 Pro を使う

Claude Code の接続先を DeepSeek V4 Pro に切り替えます。設定ファイルを 1 つ編集するだけで、ターミナルのコーディングエージェントが V4 Pro で動き、料金はトークン単位で課金されます。

  1. Claude Code をインストール: 公式インストーラーを使います。macOS または Linux の場合は、たとえば curl -fsSL https://claude.ai/install.sh | bash です。
  2. 設定を追加: ~/.claude/settings.json を編集し、下の env ブロックを追加して、ANTHROPIC_AUTH_TOKEN を AnyAIGC で作成したキーに置き換えます。
  3. コーディングを開始: プロジェクトのフォルダーで claude を実行します。/model と入力して、現在のモデルが deepseek-v4-pro になっていることを確認してください。

サブタスクのコストを節約: この設定では ANTHROPIC_DEFAULT_HAIKU_MODEL に deepseek-v4.1-flash を指定しているため、Claude Code は軽量なサブタスクを低価格なモデルに回し、メインのタスクは V4 Pro のまま処理します。

詳しい手順とよくあるエラーは、Claude Code 設定ガイドをご覧ください。ガイド内のモデル名は deepseek-v4-pro に置き換えてください。

公式の料金ページには、バージョン DeepSeek-V4-Pro-0813、コンテキスト長 1M、最大出力 384K と記載されており、思考モードと非思考モードの両方に対応しています。

JSON 出力、ツール呼び出し、Responses API、Anthropic API に対応しています。画像入力には対応しておらず、公式の同時実行数の上限は 500 です。

このページでは、入力 $0.5346、出力 $1.6038、キャッシュヒット $0.0178 を掲載しており、上の料金表と一致しています。

deepseek-v4.1-flash との比較: 公式の料金ページによると、V4.1 Flash は 画像入力に対応しており Pro は対応していません。同時実行数の上限は V4.1 Flash が 2500、Pro が 500 です。

仕様はベンダーの公式ドキュメント（api-docs.deepseek.com）に基づいています。このページの表が料金で、リアルタイムのレートはモデル一覧が正となります。

FAQ

DeepSeek V4 Pro API のよくある質問

DeepSeek V4 Pro API の料金はいくらですか?

AnyAIGC の deepseek-v4-pro はトークン単位の課金で、入力は100万トークンあたり $0.5346、出力は100万トークンあたり $1.6038、キャッシュヒットは100万トークンあたり $0.0178 です。DeepSeek 公式のオフピーク時の USD 価格は、入力 $0.66、出力 $1.98、キャッシュヒット $0.022 で、ピーク時はその 2 倍になります。出力には思考トークンも含まれます。リアルタイムの価格はモデル一覧でご確認ください。

AnyAIGC にピーク／オフピーク料金はありますか？

いいえ。DeepSeek 公式 API は時間帯別の料金体系で、平日の UTC 01:00–04:00 と 06:00–10:00(北京時間 9:00–12:00 と 14:00–18:00)がピーク時間となり、ピーク時の料金はオフピークの 2 倍です。AnyAIGC の deepseek-v4-pro は、時間帯にかかわらず同一料金で課金されます。この料金は公式のピーク価格より約60%お得です。リアルタイムの価格はモデル一覧でご確認ください。

DeepSeek V4 Pro は提供終了になりますか?

現時点では終了しません。DeepSeek は 2026年9月10日に V4 Pro の提供終了を予定していると発表しましたが、その後、公式の更新履歴で、ユーザーからの要望を受けて、9月14日以降も V4 Pro API を料金を変えずに提供し続けると案内しています。

V4 Pro と V4.1 Flash のどちらを使えばよいですか?

DeepSeek によると、V4.1 Flash は性能、コスト、速度、タスク完了までの総時間のいずれでも V4 Pro を上回っています。入力価格は V4 Pro の約4分の1で、画像も入力できるため、新規プロジェクトではまず V4.1 Flash をお試しください。本番環境で V4 Pro 向けにプロンプトやワークフローを調整済みの場合は、V4 Pro を使い続けても構いません。

V4 Pro の推論強度はどう設定しますか?

8月の V4 Pro GA リリースで、low、high、max の 3 段階の推論強度が追加されました。思考モードはデフォルトでオンになっており、強度は high です。強度は reasoning_effort で指定し、思考をオフにするには thinking フィールドに {"type": "disabled"} を指定します。コード例は、このページのクイックスタートをご覧ください。

V4 Pro のパラメータ数とコンテキスト長は?

DeepSeek の公表によると、V4 Pro は総パラメータ数 1.6T、アクティブパラメータ数 49B の MoE で、ハイブリッドアテンション構造を採用し、事前学習のトークン数は 32T です。コンテキスト長は 1M トークン、出力は最大 384K トークンで、入力はテキストのみ。重みは MIT ライセンスで公開されています。

Claude Code で DeepSeek V4 Pro を使えますか?

はい。AnyAIGC の DeepSeek モデルは、OpenAI 形式と Anthropic 形式の両方の API に対応しています。~/.claude/settings.json の env ブロックで、ANTHROPIC_BASE_URL に https://anyaigc.ai、ANTHROPIC_AUTH_TOKEN にご自身の APIキー、ANTHROPIC_MODEL に deepseek-v4-pro を設定し、claude を実行してください。料金はトークン単位です。

同時実行数やレート制限はありますか？

AnyAIGC は deepseek-v4-pro の同時実行数に上限を設けておらず、すべてのユーザーがデフォルトでこの条件で利用できます。バッチ処理、CI パイプライン、並列エージェントに向いています。

DeepSeek V4 Pro の APIキーはどうすれば取得できますか?

anyaigc.ai で登録し、残高をチャージして、コンソールで APIキーを作成します。同じキーで、すべての DeepSeek モデルとプラットフォーム上の 300+ のモデルを利用できるため、DeepSeek Platform の別アカウントは不要です。

AnyAIGC で請求書を発行できますか？

はい。実際にチャージした金額分の請求書を、コンソールでご自身で発行できます。

対応している支払い方法は何ですか？

WeChat Pay、Alipay、USDT、クレジットカードでチャージできます。残高は USD で、プラットフォーム上のすべてのモデルで使えます。チャージした金額分の請求書は、コンソールで発行できます。

新規ユーザー向けの無料トライアルはありますか？

はい。新規アカウントには200万トークン分のトライアル枠が付与されるので、チャージするかどうか決める前に試せます。チャージは $1 から可能です。

残高は返金できますか？

はい。未使用の残高は手数料なしで返金できます。返金をご希望の場合は、サポートにご連絡ください。

本物のモデルですか？データは安全ですか？

リクエストは公式のモデルチャネルに送られ、安価な代替モデルやリバースエンジニアリングによるモデルは使いません。法令で求められる場合を除き、プロンプトや出力を永続的に保存せず、学習にも使用しません。コンソールでは、リクエストごとのトークン数と料金を確認できます。
