Python
import json
import os
import time
import urllib.request

BASE = "https://anyaigc.ai"
HEADERS = {
    "Authorization": "Bearer " + os.environ["ANYAIGC_API_KEY"],
    "Content-Type": "application/json",
}


def call(method, path, body=None):
    data = json.dumps(body, ensure_ascii=False).encode("utf-8") if body else None
    request = urllib.request.Request(BASE + path, data=data, headers=HEADERS, method=method)
    with urllib.request.urlopen(request, timeout=60) as response:
        return json.load(response)


payload = {
    "model": "viduq3-turbo",
    "prompt": "清晨的雪山湖面，一只红狐狸踩着薄冰走过，镜头低机位缓慢跟拍，呼出的白气在阳光里散开。",
    "duration": 5,
    "resolution": "540p",
    "aspect_ratio": "16:9"
}

created = call("POST", "/ent/v2/text2video", payload)
task_id = (created.get("data") or created)["task_id"]
print("task_id:", task_id)

# 每 10 秒查询一次，直到任务不再处于排队或处理中
for _ in range(120):
    result = call("GET", f"/ent/v2/tasks/{task_id}/creations")
    state = (result.get("data") or result).get("state") or (result.get("data") or result).get("status")
    if state not in ("created", "queueing", "processing"):
        break
    time.sleep(10)

# creations 里是视频或图片地址，地址有时效，请及时下载
print(json.dumps(result, ensure_ascii=False, indent=2))

示例图片可换成你自己的 URL 或 Base64（png / jpeg / webp，≤50MB）。查询结果的状态字段以实际返回为准，示例在任务离开 created / queueing / processing 后停止轮询。

FAQ

Vidu API 常见问题

价格、接口、结果和企业接入，一次说清楚。

Vidu API 起步价是多少？

视频最低是 Q2 Turbo 540p 首秒 $0.0223（之后每秒 +$0.00744）；按秒计费的 Q3 Turbo 540p 为 $0.0298/秒；Q4 Preview 540p 为 $0.0486/秒；Q2 Image 文生图 1080p 为 $0.0298/张。单位 USD，实时价格以模型广场为准。

7 个模型怎么选？

要 2K / 4K 或最新效果选 Q4 Preview；要音画同出、智能切镜选 Q3 Pro，追求速度选 Q3 Turbo；纯图生或首尾帧、预算敏感选 Q2 Turbo，效果优先选 Q2 Pro；文生视频和多图参考生视频选 Q2；生成图片选 Q2 Image。

这些模型用同一个接口吗？

按能力区分接口：文生视频 /ent/v2/text2video，图生视频 /ent/v2/img2video，首尾帧 /ent/v2/start-end2video，参考生视频 /ent/v2/reference2video，图像 /ent/v2/reference2image；用 model 字段选择型号，结果统一用 GET /ent/v2/tasks/{id}/creations 查询。

生成结果怎么拿？

所有任务都是异步的：创建请求返回 task_id，轮询查询接口，完成后从 creations 里取视频或图片地址；也可以传 callback_url 接收回调。

并发和 RPM 有限制吗？

AnyAIGC 的 Vidu 接入并发不限，所有用户默认享有，不设固定 RPM 上限。视频生成需要处理时间，请在应用里设置轮询间隔和超时。

生成的内容可以商用吗？

模型与生成内容的商用授权以生数科技（Vidu）官方条款为准；使用的参考图、人物和品牌素材需要你有相应权利。AnyAIGC 是独立 API 服务商。

AnyAIGC 能开发票吗？支持增值税专票吗？

支持。可按实际充值金额开具增值税普通发票和增值税专用发票，联系企业客服办理即可。

企业可以对公转账和签合同吗？

可以。支持企业对公转账充值，可签订服务合同，并提供专属客服与技术对接。

支持哪些支付方式？

支持微信支付、支付宝、USDT 和信用卡充值，企业还可以对公转账，并开具增值税普通发票或专用发票。余额按美元计价，对平台所有模型通用。

新用户有免费试用额度吗？

有。新用户注册后赠送 200 万 tokens 的试用额度，可以先测试效果再决定是否充值。最低 1 美元起充。

余额可以退款吗？

可以。未使用的余额可以申请退款，不收取手续费。具体流程请联系客服。

会不会用低配模型冒充？我的数据安全吗？

请求走官方模型渠道，不用低配或逆向模型冒充。除法律法规要求外，我们不会对你的输入输出内容做持久化存储，也不会用于训练模型；控制台可以查看每次调用的 tokens 与扣费明细。
