curl https://anyaigc.ai/v1/chat/completions \
  -H "Authorization: Bearer $ANYAIGC_API_KEY" \
  -H "Content-Type: application/json" \

  "stream": false
}'
Python · 标准库
import json
import os
import urllib.request

payload = {'model': 'grok-4-20-non-reasoning', 'messages': [{'role': 'user', 'content': '将一段产品反馈归纳为问题、影响和建议三个部分，每部分不超过三点。'}], 'stream': False}
request = urllib.request.Request(
    "https://anyaigc.ai/v1/chat/completions",
    data=json.dumps(payload).encode("utf-8"),
    headers={
        "Authorization": f"Bearer {os.environ['ANYAIGC_API_KEY']}",
        "Content-Type": "application/json",
    },
    method="POST",
)
with urllib.request.urlopen(request, timeout=180) as response:
    result = json.load(response)
print(result["choices"][0]["message"]["content"])

接口字段与返回格式以 AnyAIGC 文档为准。Messages 文档未单独说明 Grok 的响应差异，因此示例仅展示请求，不假设额外返回字段。

07 / FAQ

Grok 4.20 Non-Reasoning API 常见问题

Grok 4.20 Non-Reasoning 的 API 模型名是什么？

使用 grok-4-20-non-reasoning，保持大小写和符号一致。Grok 4.x 总览可查看同系列其他型号。

Grok API 如何计费？

输入 $0.1241、输出 $0.2482/百万 tokens。输入超过 200,000 且不超过 500,000 tokens 时，Grok 4.20 Non-Reasoning 输入 $0.2482、输出 $0.4963/百万 tokens。以上为模型广场最低展示价，实时价格以模型广场为准。

支持哪些 API 接口？

支持 POST /v1/chat/completions，按模型广场当前标注接入。

并发和 RPM 有限制吗？

以上型号所有用户默认并发不限，无需单独申请开通。请在应用中合理管理连接、超时与重试。

Grok API 能直接获取 X 的实时数据吗？

普通对话不会自动获得实时事件。xAI 官方文档要求启用搜索工具才能使用实时数据；本页基础示例不包含搜索，也不承诺 AnyAIGC 支持所有上游搜索工具。商用以 xAI 官方条款为准。

支持增值税普通发票和增值税专用发票，按实际充值金额开具。

可以。支持企业对公转账充值、签订服务合同，并提供专属客服和技术对接。
