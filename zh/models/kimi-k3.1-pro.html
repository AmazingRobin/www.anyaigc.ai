快速开始

三步接入 Kimi K3.1 Pro API

  1. 注册并充值：在 anyaigc.ai 注册账号，最低 $1 起充，余额对平台所有模型通用。
  2. 创建 API Key：在控制台创建令牌，复制以 sk- 开头的 Key，存到环境变量 ANYAIGC_API_KEY。
  3. 发起请求：请求 POST https://anyaigc.ai/v1/chat/completions，model 填 kimi-k3.1-pro，鉴权用 Authorization: Bearer。OpenAI SDK 把 base_url 改成 https://anyaigc.ai/v1 即可。

参数提示：K3.1 Pro 思考始终开启，思考过程在 reasoning_content 字段。temperature、top_p 等采样参数由官方固定，请求里不要传。多轮对话和工具调用时，要把 API 返回的完整 assistant 消息（包括 reasoning_content 和 tool_calls）原样放回下一次请求。

完整参数见 Chat Completions 接口文档，文档示例里的模型名换成对应的 Kimi 模型 ID 即可。

Claude Code

在 Claude Code 中使用 Kimi K3.1 Pro

把 Claude Code 的模型换成 Kimi K3.1 Pro：1M 上下文，官方的大部分编程成绩就是用 Claude Code 测出来的。

  1. 安装 Claude Code：按官方方式安装（如 npm install -g @anthropic-ai/claude-code）。
  2. 写入配置：编辑 ~/.claude/settings.json，把下面的 env 加进去，ANTHROPIC_AUTH_TOKEN 换成你在 AnyAIGC 创建的 Key。
  3. 开始使用：在项目目录运行 claude，输入 /model 可以确认当前模型是 kimi-k3.1-pro。

省钱搭配：可以把 ANTHROPIC_DEFAULT_HAIKU_MODEL 换成 kimi-k2.7-code，让 Claude Code 的轻量子任务用更便宜的模型，主任务继续用 K3.1 Pro。

完整步骤和常见报错见 Claude Code 安装与使用教程，教程里的模型名换成 kimi-k3.1-pro 即可。

Kimi K3.1 Pro API 常见问题

Kimi K3.1 Pro API 多少钱？

AnyAIGC 上 kimi-k3.1-pro 按 token 计费：输入 $0.8100/百万 tokens，输出 $4.0500/百万 tokens，缓存命中 $0.0810/百万 tokens。Moonshot 官方美元价为输入 $2.00、输出 $10.00、缓存命中 $0.20，AnyAIGC 约为官方价的 40%（约 4 折）。输出包含思考 tokens，实时价格以模型广场为准。

Kimi K3.1 Pro 的模型 ID 是什么？上下文多大？

模型 ID 是 kimi-k3.1-pro。Moonshot 官方公布的上下文窗口为 1,048,576 tokens（1M），max_completion_tokens 默认 131,072，最大可设到 1,048,576。

Kimi K3.1 Pro 和 K3 有什么区别？

官方说明 K3.1 Pro 是在 Kimi K3 基础上用大幅增加的后训练算力得到的版本，在数百个下游领域做联合强化学习。官方公布的提升包括：长程编程（Kimi Code Bench 3.0 从 55.95 到 61.2）、金融研究（内部评测从 58.8 到 70.4）、事实准确性（逐条事实幻觉率从 23.4% 降到 8.3%）。参数约束与 K3 相同，迁移只要改模型名。AnyAIGC 上 K3.1 Pro 输入 $0.8100、输出 $4.0500，比 K3 低三分之一。

怎么调整 Kimi K3.1 Pro 的思考深度？

K3.1 Pro 始终开启思考，不能关闭。用请求体顶层的 reasoning_effort 字段调整思考深度，可选 low、high、max，默认 max。temperature、top_p 等采样参数由官方固定，请求里不用传。

Kimi K3.1 Pro 支持工具调用、图片和视频输入吗？

支持。官方文档列出函数调用（tools / tool_choice）、结构化输出（json_schema）、流式输出，以及图片和视频输入。多轮和工具调用时，需要把返回的完整 assistant 消息（含 reasoning_content 和 tool_calls）原样放回下一次请求。

可以在 Claude Code 里使用 Kimi K3.1 Pro 吗？

可以。在 ~/.claude/settings.json 的 env 中设置 ANTHROPIC_BASE_URL 为 https://anyaigc.ai、ANTHROPIC_AUTH_TOKEN 为你的 API Key、ANTHROPIC_MODEL 为 kimi-k3.1-pro，然后运行 claude 即可。
