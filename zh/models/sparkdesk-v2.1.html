快速开始

三步接入 SparkDesk-v2.1 API

  1. 注册并充值：在 anyaigc.ai 注册账号，最低 $1 起充，余额对平台所有模型通用。
  2. 创建 API Key：在控制台创建令牌，复制以 sk- 开头的 Key，存到环境变量 ANYAIGC_API_KEY。
  3. 发起请求：请求 POST https://anyaigc.ai/v1/chat/completions，model 填 SparkDesk-v2.1，鉴权用 Authorization: Bearer。OpenAI SDK 把 base_url 改成 https://anyaigc.ai/v1 即可。

参数提示：模型 ID 区分大小写，写成 SparkDesk-v2.1。返回格式与 OpenAI Chat Completions 一致，本次请求的 tokens 在 usage 字段里。该型号上下文有限，长文档请先分段或检索后再提问。

完整参数见 Chat Completions 接口文档，文档示例里的模型名换成对应的 SparkDesk 模型 ID 即可。

SparkDesk-v2.1 API 常见问题

SparkDesk-v2.1 API 多少钱？

AnyAIGC 上 SparkDesk-v2.1 按 token 计费：输入 $8.7360/百万 tokens，输出 $8.7360/百万 tokens，输入和输出同价。固定单价，没有订阅和月费，实时价格以模型广场为准。

SparkDesk-v2.1 的模型 ID 是什么？和讯飞星火是什么关系？

模型 ID 是 SparkDesk-v2.1（区分大小写）。它是科大讯飞星火认知大模型的一个版本，AnyAIGC 提供 OpenAI 兼容的调用方式。注意它和 Apache Spark、Spark 邮箱等同名产品无关。

SparkDesk-v2.1 和其他 SparkDesk 型号怎么选？

SparkDesk-v3.5 和 SparkDesk-v3.1 是同系列的另外两款。版本号越大，对应讯飞官方的档位越新：v3.5 对应 Max，v3.1 对应 Pro，v2.1 是早期 2.x 版本。需要系统提示词时选 v3.5；预算优先且质量要求不高时可以看 v2.1，上线前请用自己的数据实测。三款在 AnyAIGC 上都是输入输出同价。

SparkDesk 兼容 OpenAI 接口吗？怎么调用？

兼容。SparkDesk-v2.1 走 POST https://anyaigc.ai/v1/chat/completions，请求和返回格式与 OpenAI Chat Completions 一致，OpenAI 官方 SDK 把 base_url 改成 https://anyaigc.ai/v1 即可。讯飞官方的 WebSocket 签名鉴权不需要处理，只要 Authorization: Bearer。

SparkDesk-v2.1 的上下文窗口有多大？

讯飞开放平台当前文档的版本表已不再列出 2.x 版本，所以没有可引用的官方上下文数字。建议用你的真实输入长度实测，需要更确定的参数时选 SparkDesk-v3.1 或 SparkDesk-v3.5。

并发和速率有限制吗？

AnyAIGC 对 SparkDesk-v2.1 不设并发限制，所有用户默认享有，适合批量处理和多任务并行。按 token 计费，没有月费和按时间窗口重置的额度。
