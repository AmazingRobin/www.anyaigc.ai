Python
import json
import os
import time
import urllib.request

BASE = "https://anyaigc.ai"
HEADERS = {
    "Authorization": "Bearer " + os.environ["ANYAIGC_API_KEY"],
    "Content-Type": "application/json",
}


def call(method, path, body=None):
    data = json.dumps(body, ensure_ascii=False).encode("utf-8") if body else None
    request = urllib.request.Request(BASE + path, data=data, headers=HEADERS, method=method)
    with urllib.request.urlopen(request, timeout=60) as response:
        return json.load(response)


payload = {
    "model": "viduq4-preview",
    "images": [
        "https://www.anyaigc.ai/assets/models/vidu/skycity.webp"
    ],
    "prompt": "镜头缓慢推进，云海翻涌，远处的城市亮起灯光，少女的红色披风被风吹起。",
    "duration": 5,
    "resolution": "1080p"
}

created = call("POST", "/ent/v2/img2video", payload)
task_id = (created.get("data") or created)["task_id"]
print("task_id:", task_id)

# 每 10 秒查询一次，直到任务不再处于排队或处理中
for _ in range(120):
    result = call("GET", f"/ent/v2/tasks/{task_id}/creations")
    state = (result.get("data") or result).get("state") or (result.get("data") or result).get("status")
    if state not in ("created", "queueing", "processing"):
        break
    time.sleep(10)

# creations 里是视频或图片地址，地址有时效，请及时下载
print(json.dumps(result, ensure_ascii=False, indent=2))

示例图片可换成你自己的 URL 或 Base64（png / jpeg / webp，≤50MB）。查询结果的状态字段以实际返回为准，示例在任务离开 created / queueing / processing 后停止轮询。

FAQ

Vidu Q4 Preview API 常见问题

价格、接口、结果和企业接入，一次说清楚。

Vidu Q4 Preview API 多少钱？

540p $0.0486 / 秒；720p $0.1026 / 秒；1080p $0.1296 / 秒；2K $0.2052 / 秒；4K $0.4212 / 秒。单位 USD，实时价格以模型广场为准。

调用哪个接口？

POST /ent/v2/img2video、POST /ent/v2/reference2video，model 填 viduq4-preview。创建请求返回 task_id，再用 GET /ent/v2/tasks/{id}/creations 查询结果。API 域名为 https://anyaigc.ai，用 Authorization: Bearer 传入 API Key。

支持哪些时长和清晰度？

Vidu Q4 Preview 时长 3–16 秒，默认 5 秒；清晰度 540p / 720p / 1080p / 2K / 4K。按秒计费，费用 = 每秒单价 × 视频秒数。不传 audio 参数时默认同时生成音频。

生成结果怎么拿？

任务是异步的。创建后保存 task_id，轮询 GET /ent/v2/tasks/{id}/creations，状态完成后从返回的 creations 里取视频或图片地址；也可以在创建时传 callback_url 接收回调。下载地址有时效，请及时转存。

并发和 RPM 有限制吗？

AnyAIGC 的 Vidu 接入并发不限，所有用户默认享有，不设固定 RPM 上限。视频生成需要处理时间，请在应用里设置轮询间隔和超时。

生成的内容可以商用吗？

模型与生成内容的商用授权以生数科技（Vidu）官方条款为准；使用的参考图、人物和品牌素材需要你有相应权利。AnyAIGC 是独立 API 服务商。

AnyAIGC 能开发票吗？支持增值税专票吗？

支持。可按实际充值金额开具增值税普通发票和增值税专用发票，联系企业客服办理即可。

可以。支持企业对公转账充值，可签订服务合同，并提供专属客服与技术对接。
