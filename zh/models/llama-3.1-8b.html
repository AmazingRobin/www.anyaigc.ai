curl --request POST "https://anyaigc.ai/v1/chat/completions" \
  --header "Authorization: Bearer $ANYAIGC_API_KEY" \
  --header "Content-Type: application/json" \
  --data '{

  "stream": false
}'
Python
import json
import os
import urllib.request

payload = {
  "model": "llama-3.1-8b",
  "messages": [
    {
      "role": "user",
      "content": "请用三句话解释什么是 API。"
    }
  ],
  "n": 1,
  "stream": False
}
request = urllib.request.Request(
    "https://anyaigc.ai/v1/chat/completions",
    data=json.dumps(payload, ensure_ascii=False).encode("utf-8"),
    headers={
        "Authorization": "Bearer " + os.environ["ANYAIGC_API_KEY"],
        "Content-Type": "application/json",
    },
    method="POST",
)
with urllib.request.urlopen(request, timeout=120) as response:
    result = json.load(response)

print(json.dumps(result, ensure_ascii=False, indent=2))

cURL 示例适用于 Bash / zsh；Python 示例仅依赖标准库。n=1 返回一个候选回复，stream=false 返回完整 JSON；响应包含 choices 和 usage。可将 stream 改为 true 接收 SSE 增量输出。

Llama 3.1 8B API 常见问题

价格、版本、接入与企业采购。

Llama 3.1 8B API 多少钱？68 折如何计算？

输入 $1.3500，输出 $1.3500，均为每百万 tokens 的美元单价。标有优惠的型号为 68 折（模型广场显示省 32%），表内已是优惠后价格，无需再次打折。实时价格以模型广场为准。

Llama 和 Ollama 是什么关系？支持哪些版本？

Llama 是 Meta 开发的模型系列；Ollama 是模型运行工具，也是 AnyAIGC 模型广场的供应商分类。本专题收录 Llama 2、3、3.1、3.2 和 3.3 共 12 个型号。商用授权以 Meta 官方条款为准。

应该填写哪个模型名？一次调用返回什么？

使用 POST /v1/chat/completions，model 填写 llama-3.1-8b，通过 Bearer API Key 鉴权。本页示例设置 n=1、stream=false，返回一个助手回复候选和 token 用量信息；llama 是专题总览名。

并发和 RPM 有限制吗？需要安装 Ollama 吗？

所有用户默认并发不限，无固定 RPM 上限。通过 AnyAIGC 云端 API 调用，无需在本地安装 Ollama 或部署模型。应用仍应处理网络超时和接口错误。

可以处理图片和中文吗？

Llama 3.2 的 11B/90B Vision Instruct 是视觉型号，其余型号为文本模型。Llama 3.1–3.3 官方支持的文本语言列表未包含中文；图文任务官方支持英语。中文任务请先用实际数据评估，本页只展示文本接入示例。

AnyAIGC 能开发票吗？支持增值税专票吗？

支持。按实际充值金额开具增值税普通发票和增值税专用发票，可联系企业客服办理。

企业可以对公转账和签合同吗？

可以。支持企业对公转账充值、签订服务合同，并提供专属客服与技术对接。

支持哪些支付方式？

支持微信支付、支付宝、USDT 和信用卡充值，企业还可以对公转账，并开具增值税普通发票或专用发票。余额按美元计价，对平台所有模型通用。

新用户有免费试用额度吗？

有。新用户注册后赠送 200 万 tokens 的试用额度，可以先测试效果再决定是否充值。最低 1 美元起充。

余额可以退款吗？

可以。未使用的余额可以申请退款，不收取手续费。具体流程请联系客服。

会不会用低配模型冒充？我的数据安全吗？

请求走官方模型渠道，不用低配或逆向模型冒充。除法律法规要求外，我们不会对你的输入输出内容做持久化存储，也不会用于训练模型；控制台可以查看每次调用的 tokens 与扣费明细。
