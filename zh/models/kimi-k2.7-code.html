关于模型

基于 K2.6 的编程强化版

Moonshot AI 称 Kimi K2.7 Code 是 Kimi 迄今最强的编程模型。它基于 K2.6 继续训练，在长上下文里更稳定地遵循指令，编程任务的完成率更高，同时思考 tokens 比 K2.6 少约 30%。

在 AnyAIGC 上，kimi-k2.7-code 走 OpenAI 兼容的 /v1/chat/completions，也能在 Claude Code 里直接使用，并发不限。

快速开始

三步接入 Kimi K2.7 Code API

  1. 注册并充值：在 anyaigc.ai 注册账号，最低 $1 起充，余额对平台所有模型通用。
  2. 创建 API Key：在控制台创建令牌，复制以 sk- 开头的 Key，存到环境变量 ANYAIGC_API_KEY。
  3. 发起请求：请求 POST https://anyaigc.ai/v1/chat/completions，model 填 kimi-k2.7-code，鉴权用 Authorization: Bearer。OpenAI SDK 把 base_url 改成 https://anyaigc.ai/v1 即可。

参数提示：K2.7 Code 强制开启思考，思考过程在 reasoning_content 字段。官方推荐 temperature=1.0、top_p=0.95。多轮对话和工具调用时，要把 API 返回的完整 assistant 消息（包括 reasoning_content 和 tool_calls）原样放回下一次请求。

完整参数见 Chat Completions 接口文档，文档示例里的模型名换成对应的 Kimi 模型 ID 即可。

FAQ

Kimi K2.7 Code API 常见问题

Kimi K2.7 Code API 多少钱？

AnyAIGC 上 kimi-k2.7-code 按 token 计费：输入 $0.3847/百万 tokens，输出 $1.5980/百万 tokens，缓存命中 $0.0770/百万 tokens。Moonshot 官方美元价为输入 $0.95、输出 $4.00、缓存命中 $0.19，AnyAIGC 约为官方价的 40%（约 4 折）。输出包含思考 tokens，实时价格以模型广场为准。

Kimi K2.7 Code 的模型 ID 是什么？上下文多大？

模型 ID 是 kimi-k2.7-code。Moonshot 官方公布的上下文窗口为 262,144 tokens（256K），支持文本和图片输入。

Kimi K2.7 Code 和 K2.6 有什么区别？

K2.7 Code 基于 K2.6 继续训练，专注编程，架构相同（1T 总参数、32B 激活）。官方称它在长上下文里更稳定地遵循指令，编程任务成功率更高，思考 tokens 比 K2.6 少约 30%；Kimi Code Bench v2 从 50.9 提升到 62.0。区别是 K2.7 Code 只有思考模式，K2.6 可以关闭思考。两者在 AnyAIGC 输入、输出单价相同。

Kimi K2.7 Code 能关闭思考模式吗？

不能。官方说明 K2.7 Code 强制开启思考和保留思考（preserve thinking），不支持非思考模式。需要快速、非思考的响应可以用 kimi-k2.6。官方推荐参数为 temperature=1.0、top_p=0.95。

Kimi K2.7 Code 支持工具调用吗？

支持。K2.7 Code 支持交错思考（interleaved thinking）和多步工具调用，适合 Coding Agent。多轮和工具调用时，需要把返回的完整 assistant 消息（含 reasoning_content 和 tool_calls）原样放回下一次请求。

可以在 Claude Code 里使用 Kimi K2.7 Code 吗？

可以。在 ~/.claude/settings.json 的 env 中设置 ANTHROPIC_BASE_URL 为 https://anyaigc.ai、ANTHROPIC_AUTH_TOKEN 为你的 API Key、ANTHROPIC_MODEL 为 kimi-k2.7-code，然后运行 claude 即可。

Kimi K2.7 Code 和 Kimi K3.1 Pro 怎么选？

K2.7 Code 是 1T 参数的编程模型，上下文 256K，AnyAIGC 输入 $0.3847、输出 $1.5980，适合日常编码和高频 Agent 调用；Kimi K3.1 Pro 是最新一代 3T 级模型，有 1M 上下文，输入 $0.8100、输出 $4.0500，适合大仓库和最难的任务。两者共用同一个 Key。

并发和速率有限制吗？

AnyAIGC 对 kimi-k2.7-code 不设并发限制，所有用户默认享有，适合批量任务、CI 流水线和多 Agent 并行。Moonshot 官方平台按充值等级限制并发、RPM、TPM 和 TPD，通过 AnyAIGC 调用不受这些等级限制。
