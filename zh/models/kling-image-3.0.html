接入 Kling Image 3.0 API

  1. 1注册 AnyAIGC 并创建 API Key，放进 ANYAIGC_API_KEY 环境变量
  2. 2POST /tencent-vod/v1/aigc-image 提交任务，拿到 TaskId
  3. 3GET /tencent-vod/v1/query/{task_id} 轮询，Status 为 FINISH 后下载图片

请求里 model_name 填 "Kling"，model_version 填 "3.0"，output_config.resolution 必须是大写的 "2K" 或 "4K"。结果在 Response.AigcImageTask.Output.FileInfos[].FileUrl，为临时存储，有过期时间，请及时下载。

Python

import json
import os
import time
import urllib.request

BASE = "https://anyaigc.ai"
HEADERS = {
    "Authorization": "Bearer " + os.environ["ANYAIGC_API_KEY"],
    "Content-Type": "application/json",
}


def call(method, path, payload=None):
    data = json.dumps(payload, ensure_ascii=False).encode("utf-8") if payload else None
    request = urllib.request.Request(BASE + path, data=data, headers=HEADERS, method=method)
    with urllib.request.urlopen(request, timeout=60) as response:
        return json.load(response)


payload = {
    "model_name": "Kling",
    "model_version": "3.0",
    "prompt": "一只橘猫坐在雨后的窗台上，窗外是霓虹灯街道，电影感光影，细节丰富",
    "output_config": {
        "aspect_ratio": "16:9",
        "resolution": "2K"
    }
}

task_id = call("POST", "/tencent-vod/v1/aigc-image", payload)["Response"]["TaskId"]
print("task_id:", task_id)

# 每 5 秒查询一次，Status 为 FINISH 后打印图片地址
for _ in range(60):
    result = call("GET", f"/tencent-vod/v1/query/{task_id}")["Response"]
    if result["Status"] == "FINISH":
        break
    time.sleep(5)
else:
    raise TimeoutError(task_id)

for item in result["AigcImageTask"]["Output"]["FileInfos"]:
    print(item["FileUrl"])

FAQ

Kling Image 3.0 API 常见问题

Kling Image 3.0 API 多少钱？

每次调用 $0.00169，生成 1 张图，2K 和 4K 同价。单位 USD，按成功提交计费，实时价格以模型广场为准。

应该调用哪个接口？

提交任务用 POST /tencent-vod/v1/aigc-image，body 里 model_name 填 Kling、model_version 填 3.0；查询结果用 GET /tencent-vod/v1/query/{task_id}。API 域名为 https://anyaigc.ai，请求头 Authorization: Bearer <API Key>。

分辨率怎么设置？

在 output_config.resolution 里填大写的 "2K" 或 "4K"，两种分辨率价格相同。

支持哪些生成方式？

支持文生图、图生图、多图参考、风格转绘、人像/角色参考和局部重绘。参考图通过 file_infos 传入，具体字段以接口文档为准。

结果怎么获取？

接口是异步的：提交后返回 Response.TaskId，轮询查询接口，Status 为 FINISH 时从 Response.AigcImageTask.Output.FileInfos[].FileUrl 下载图片。文件为临时存储，有过期时间。

AnyAIGC 的 Kling 系列默认并发不限，所有用户都可以直接使用。
