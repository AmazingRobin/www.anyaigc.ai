Python 流式
# pip install openai
import os
from openai import OpenAI

client = OpenAI(api_key=os.environ["ANYAIGC_API_KEY"], base_url="https://anyaigc.ai/v1")

stream = client.chat.completions.create(
    model="mimo-v2.6-flash",
    messages=[{"role": "user", "content": "用三句话介绍你自己，并说明你擅长的任务。"}],
    stream=True,
)
for chunk in stream:
    if chunk.choices and chunk.choices[0].delta.content:
        print(chunk.choices[0].delta.content, end="", flush=True)
print()

FAQ

MiMo-V2.6-Flash API 常见问题

MiMo-V2.6-Flash API 多少钱？是官方 4 折吗？

按 token 计费，单位 USD/百万 tokens：输入 $0.0563（官方 $0.14）；输出 $0.1126（官方 $0.28）；缓存命中 $0.0011（官方 $0.0028）。输入与输出约为小米 MiMo 开放平台美元按量价的 40%，即约官方 4 折。实时价格以模型广场为准。

支持哪些输入？上下文有多长？

官方规格：输入支持文本、图像、视频、音频，输出为文本，上下文 1M tokens，最大输出 128K tokens。AnyAIGC 文档目前给出文本与 image_url 图像输入示例，音频、视频的传参方式请以 API 文档为准。

应该使用哪个 API 接口？

使用 OpenAI 兼容的 POST https://anyaigc.ai/v1/chat/completions，请求头 Authorization: Bearer <API Key>，model 填 mimo-v2.6-flash。已有 OpenAI SDK 项目只需改 base_url 为 https://anyaigc.ai/v1。

MiMo-V2.6-Flash 和 MiMo-V2.6-Pro 怎么选？

V2.6-Pro 面向长程、复杂的 Agent、编程与科研任务；V2.6-Flash 面向高频调用和规模化办公任务，价格约为 Pro 的三分之一。两者都是约官方 4 折，建议用自己的任务各测一轮。

并发和 RPM 有限制吗？

AnyAIGC 的 MiMo 接入并发不限，不设固定 RPM 上限，所有用户默认享有。长上下文和深度思考请求耗时更长，请在应用里设置合理的超时与重试。

生成内容可以商用吗？

模型与输出的使用条款以小米 MiMo 官方条款为准。AnyAIGC 是独立 API 服务商，与小米无隶属关系。

AnyAIGC 能开发票吗？支持增值税专票吗？

支持。可按实际充值金额开具增值税普通发票和增值税专用发票，联系企业客服办理即可。

企业可以对公转账和签合同吗？

可以。支持企业对公转账充值，可签订服务合同，并提供专属客服与技术对接。

支持哪些支付方式？

支持微信支付、支付宝、USDT 和信用卡充值，企业还可以对公转账，并开具增值税普通发票或专用发票。余额按美元计价，对平台所有模型通用。

新用户有免费试用额度吗？

有。新用户注册后赠送 200 万 tokens 的试用额度，可以先测试效果再决定是否充值。最低 1 美元起充。

余额可以退款吗？

可以。未使用的余额可以申请退款，不收取手续费。具体流程请联系客服。

会不会用低配模型冒充？我的数据安全吗？

请求走官方模型渠道，不用低配或逆向模型冒充。除法律法规要求外，我们不会对你的输入输出内容做持久化存储，也不会用于训练模型；控制台可以查看每次调用的 tokens 与扣费明细。
