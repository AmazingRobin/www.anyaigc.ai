快速开始

三步接入 GLM-5.3 API

  1. 注册并充值：在 anyaigc.ai 注册账号，最低 $1 起充，余额对平台所有模型通用。
  2. 创建 API Key：在控制台创建令牌，复制以 sk- 开头的 Key，存到环境变量 ANYAIGC_API_KEY。
  3. 发起请求：请求 POST https://anyaigc.ai/v1/chat/completions，model 填 glm-5.3，鉴权用 Authorization: Bearer。OpenAI SDK 把 base_url 改成 https://anyaigc.ai/v1 即可。

参数提示：GLM-5.3 思考始终开启，思考过程在 reasoning_content 字段，思考深度用 reasoning_effort 调整。官方默认 temperature=1.0、top_p=0.95，建议只调其中一个。多轮对话和工具调用时，要把 API 返回的完整 assistant 消息（包括 reasoning_content 和 tool_calls）原样放回下一次请求。

完整参数见 Chat Completions 接口文档，文档示例里的模型名换成对应的 GLM 模型 ID 即可。

FAQ

GLM-5.3 API 常见问题

GLM-5.3 API 多少钱？

AnyAIGC 上 glm-5.3 按 token 计费：输入 $0.9450/百万 tokens，输出 $2.9700/百万 tokens，缓存命中 $0.1758/百万 tokens。智谱官方美元价为输入 $1.40、输出 $4.40、缓存命中 $0.26，AnyAIGC 的输入、输出约为官方价的 67.5%（约 7 折）。输出包含思考 tokens，实时价格以模型广场为准。

GLM-5.3 的模型 ID 是什么？上下文多大？

模型 ID 是 glm-5.3。智谱官方公布的上下文窗口为 1M tokens，最大输出 128K tokens，目前只支持文本输入。

GLM-5.3 和 GLM-5.2 有什么区别？

官方说明 GLM-5.3 与 GLM-5.2 使用同一个基座模型，所有提升都来自扩展后训练。官方公布的变化：Z.ai Code Bench 比 GLM-5.2 提升 50%，Terminal Bench 3.0 从 4.6 提升到 28.3，DeepSWE 从 46.2 提升到 66.9。另一个区别是 GLM-5.3 思考始终开启，不能关闭。两者在 AnyAIGC 输入、输出单价相同，GLM-5.3 的缓存命中价更低（$0.1758 对 $0.2362）。

怎么调整 GLM-5.3 的思考深度？能关闭思考吗？

GLM-5.3 思考始终开启，官方不支持关闭。用请求体的 reasoning_effort 字段调整思考深度，可选 low、high、max，默认 max，编程任务官方推荐 max。简单任务用 low 可以减少输出 tokens。

GLM-5.3 支持工具调用和结构化输出吗？

支持。官方文档列出函数调用、结构化输出（JSON）、流式输出和上下文缓存。多轮和工具调用时，需要把返回的完整 assistant 消息（含 reasoning_content 和 tool_calls）原样放回下一次请求。

可以在 Claude Code 里使用 GLM-5.3 吗？

可以。在 ~/.claude/settings.json 的 env 中设置 ANTHROPIC_BASE_URL 为 https://anyaigc.ai、ANTHROPIC_AUTH_TOKEN 为你的 API Key、ANTHROPIC_MODEL 为 glm-5.3，然后运行 claude 即可。按 token 计费，没有订阅套餐的 5 小时额度窗口。

GLM-5.3 是开源的吗？

是。智谱已在 Hugging Face 发布 GLM-5.3 权重（zai-org/GLM-5.3），许可为 GLM-5.3 License：整体是宽松许可，另规定集团年收入超过 100 亿美元、经营模型即服务业务的企业，商用前需通过 Z.ai 的安全审查。通过 AnyAIGC 调用 API 不需要自己部署，商用授权以智谱官方条款为准。
