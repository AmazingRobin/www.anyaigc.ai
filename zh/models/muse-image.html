Muse Image 是什么

Muse Image 是 Meta 超级智能实验室（Meta Superintelligence Labs）在 2026 年 7 月发布的图像生成模型，和 Muse Spark 同属 Muse 系列。官方的定位是三件事：忠实遵循指令、精准编辑、从多张参考图合成画面。

它和一般的「提示词进、图片出」不同：生成前会按需调用搜索和代码工具，比如查真实的地标、商品和时事，或者先写代码算出准确的图表、二维码，再据此出图；生成过程中还会检查草稿并自我修正。按 Meta 官方博客，Muse Image 在 Arena 的文生图、单图编辑、多图编辑三项人类偏好排名中均位列第 2（2026-07-05 数据）。

在 AnyAIGC 上，模型名是 muse-image，走 OpenAI 兼容的 /v1/images/generations，每张 ¥0.04，比 Meta 官方的 ¥0.07 / 张更低。

Muse Image 能做什么

  • 指令遵循与文字排版

    标题、小字、日期和票价都能按提示词准确写进画面，适合海报、封面和包装。

  • 精准改图

    只改你要求的部分。示例指令：「把雾散开，露出下面美丽的山谷」，车、路牌和构图保持不变。

  • 多轮迭代

    在对话里一轮轮修改，前后保持一致。示例：先把客厅改成 Japandi 风，再把原图里的台灯和柜子放回来。

  • 多图合成

    把多张参考图里的人物、物品、服装、风格和场景组合到一张图里，可以在提示词里穿插图片。

  • 联网检索事实

    先搜索科学资料和参考图，再生成信息图，知识密集或涉及时事的提示词更准确。

  • 写代码作图

    训练中学会写代码生成准确的图表和二维码，再把结果画进图里。示例里的二维码指向 meta.ai，可以扫描。

Muse Image API 常见问题

Muse Image API 多少钱？

Muse Image 是什么？

Muse Image 是 Meta 超级智能实验室在 2026 年 7 月发布的图像生成与编辑模型。它在生成前会按需联网检索、写代码作图，并在生成过程中自我修正，擅长指令遵循、精准编辑和多图合成。

怎么控制尺寸和比例？

用 size 传 "宽x高"，例如 "1024x1536"。按 Meta 官方文档，这个值只决定宽高比，实际像素由模型自己决定，返回尺寸不会和数字完全一致；宽高比超过 16:1 会报错。不传则用默认比例。

一次能生成几张？输出什么格式？

n 可填 1–10，默认 1，data 里每张图一条。output_format 支持 webp（默认）、png、jpeg；response_format 默认返回 base64，填 url 返回临时链接。

能改图和多图合成吗？

能。Muse Image 用同一个模型做生成和编辑：传入一张图加指令只改指定部分，传入多张图可以把不同图里的元素合成到一个场景。AnyAIGC 模型广场显示 muse-image 同时支持图片编辑接口 /v1/images/edits，字段以 AnyAIGC 接口文档为准。

联网检索和写代码要额外付费吗？

不用。按 Meta 官方说明，检索和代码工具是模型内置能力，包含在每张图的价格里。在 AnyAIGC 上同样按张计费，每张 ¥0.04，不另外收工具费用。
