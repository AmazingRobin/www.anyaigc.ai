常见问题

Claude Sonnet 5.5 API 多少钱？

AnyAIGC 上 claude-sonnet-5-5 按 token 计费：输入 $0.2382/百万 tokens，输出 $1.191/百万 tokens，5 分钟缓存写入 $0.2978，1 小时缓存写入 $0.4765，缓存命中 $0.0119。Anthropic 官方价为输入 $2、输出 $10，AnyAIGC 约为官方价的 11.9%。

Claude Sonnet 5.5 的模型 ID 是什么？

模型 ID 是 claude-sonnet-5-5，在请求体的 model 字段里填写即可。

Claude Sonnet 5.5 适合做什么？和 Opus 5.5 怎么选？

Anthropic 称 Sonnet 5.5 是 Opus 5.5 更快、更低成本的搭档：Opus 5.5 面向需要审慎判断的复杂工作，Sonnet 5.5 擅长范围明确的日常任务、修复 bug，以及制作文档、幻灯片和表格。两者官方价分别为 Sonnet 5.5 输入 $2、输出 $10，Opus 5.5 输入 $4、输出 $20。日常编码和高频调用可以默认用 Sonnet 5.5，难度高、需要反复推敲的任务再切到 claude-opus-5-5。

AnyAIGC 的 Claude API 兼容 Anthropic 官方接口吗？

兼容。接口地址是 https://anyaigc.ai/v1/messages，请求体沿用 Anthropic Messages 格式（model、max_tokens、system、messages、tools、cache_control 等），鉴权使用 Authorization: Bearer 你的 API Key。用官方 SDK 时把 base URL 改为 https://anyaigc.ai 即可。

可以在 Claude Code 里使用 Claude Sonnet 5.5 吗？

可以。在 ~/.claude/settings.json 的 env 中设置 ANTHROPIC_BASE_URL 为 https://anyaigc.ai、ANTHROPIC_AUTH_TOKEN 为你的 API Key、ANTHROPIC_MODEL 和 ANTHROPIC_DEFAULT_SONNET_MODEL 为 claude-sonnet-5-5，然后运行 claude。也可以用一行命令 curl -fsSL https://www.anyaigc.ai/install.sh | bash 自动安装和配置。

提示词缓存怎么计费？

在内容块上加 cache_control 即可开启缓存。首次写入缓存按缓存写入价计费（5 分钟 $0.2978、1 小时 $0.4765 每百万 tokens），之后命中缓存的部分只按 $0.0119 每百万 tokens 计费，为普通输入价的 5%。长系统提示词、代码库上下文和多轮 Agent 任务适合用缓存。

并发和速率有限制吗？

AnyAIGC 对 claude-sonnet-5-5 不设并发限制，所有用户默认享有，适合批量任务和多 Agent 并行。

国内可以直接调用 Claude Sonnet 5.5 API 吗？

可以。AnyAIGC 面向国内网络优化，通常无需额外代理即可调用 https://anyaigc.ai/v1/messages，按美元价格计费，企业可对公转账并开具增值税发票。
