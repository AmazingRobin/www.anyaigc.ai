Python
import json
import os
import time
import urllib.request

BASE = "https://anyaigc.ai"
HEADERS = {
    "Authorization": "Bearer " + os.environ["ANYAIGC_API_KEY"],
    "Content-Type": "application/json",
}


def call(method, path, payload=None):
    data = json.dumps(payload, ensure_ascii=False).encode("utf-8") if payload else None
    request = urllib.request.Request(BASE + path, data=data, headers=HEADERS, method=method)
    with urllib.request.urlopen(request, timeout=120) as response:
        return json.load(response)


payload = {
    "model_name": "Hailuo",
    "model_version": "H3",
    "prompt": "海边日落，镜头缓慢推进，海浪轻拍礁石。",
    "output_config": {
        "aspect_ratio": "16:9",
        "duration": 6,
        "resolution": "768P"
    }
}

task_id = call("POST", "/tencent-vod/v1/aigc-video", payload)["Response"]["TaskId"]
print("task_id:", task_id)

# 每 10 秒查询一次，Status 为 FINISH 后打印完整结果（含视频地址）
while True:
    result = call("GET", f"/tencent-vod/v1/query/{task_id}")["Response"]
    if result["Status"] == "FINISH":
        break
    time.sleep(10)

print(json.dumps(result, ensure_ascii=False, indent=2))

创建请求返回 Response.TaskId；用 GET /tencent-vod/v1/query/{task_id} 查询，Status 为 FINISH 时从结果的 Output.FileInfos[].FileUrl 下载视频（临时存储，有过期时间）。 查看任务查询文档 ↗

MiniMax API 常见问题

价格、接口、结果和企业接入，一次说明白。

Hailuo H3 API 多少钱？

H3 768P 输出视频 $0.0972/秒; H3 768P 输入视频 $0.0972/秒; H3 2K 输出视频 $0.1579/秒; H3 2K 输入视频 $0.1579/秒; H3-Max 480P 输出视频 $0.0607/秒; H3-Max 768P 输出视频 $0.0972/秒; 输入图片（前 5 张） $0/张; 输入图片（第 6 张起） $0.0486/张。单位为 USD，实时价格以模型广场为准。

应该使用哪个 API 接口？

使用 POST /tencent-vod/v1/aigc-video、GET /tencent-vod/v1/query/{task_id}，API 域名为 https://anyaigc.ai，通过 Authorization: Bearer 传入 API Key。

H3 和 H3-Max 有什么区别？

H3 支持 4–15 秒、768P 或 2K（传 1080P 按 768P 生成，传 4K 按 2K 生成），画幅 21:9、16:9、4:3、1:1、3:4、9:16，支持文生、首尾帧图生和多模态参考。H3-Max 是 H3 的极速版，支持 5–15 秒、480P 或 768P，只支持文生和首尾帧图生，不支持中间帧、多模态参考和输入视频。

一次请求会返回什么？

异步任务，一次生成一段视频：H3 4–15 秒，H3-Max 5–15 秒，按实际输出秒数计费。

并发和 RPM 有限制吗？

AnyAIGC 的 MiniMax 接入并发不限，不设固定 RPM 上限。模型生成仍需要处理时间，请在应用中配置超时、错误处理和合理重试。

生成内容可以商用吗？

模型与输出的商用授权以 MiniMax 官方条款为准。使用参考素材、音色及生成内容时，也应具备相关权利或授权。AnyAIGC 是独立 API 服务商。

AnyAIGC 能开发票吗？支持增值税专票吗？

支持。可按实际充值金额开具增值税普通发票和增值税专用发票，联系企业客服办理即可。

企业可以对公转账和签合同吗？

可以。支持企业对公转账充值，可签订服务合同，并提供专属客服与技术对接，配合采购、财务和研发流程。

支持哪些支付方式？
