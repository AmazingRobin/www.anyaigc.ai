快速开始

三步接入 DeepSeek API

  1. 注册并充值：在 anyaigc.ai 注册账号，最低 $1 起充，余额对平台所有模型通用。
  2. 创建 API Key：在控制台创建令牌，复制以 sk- 开头的 Key，存到环境变量 ANYAIGC_API_KEY。
  3. 发起请求：请求 POST https://anyaigc.ai/v1/chat/completions，model 填 deepseek-v4.1-flash，鉴权用 Authorization: Bearer。OpenAI SDK 把 base_url 改成 https://anyaigc.ai/v1 即可。

参数提示：DeepSeek 官方说明 V4 系列默认开启思考。请求体里的 thinking 字段控制开关（{"type": "enabled"} 或 {"type": "disabled"}），reasoning_effort 调整思考强度（官方可选 low / high / max）。思考消耗的 tokens 计入输出，可在 usage.completion_tokens_details.reasoning_tokens 查看。思考模式下 temperature 等采样参数不生效。

完整参数见 Chat Completions 接口文档，文档示例里的模型名换成对应的 DeepSeek 模型 ID 即可。

Claude Code

在 Claude Code 中使用 DeepSeek

把 Claude Code 的模型换成 DeepSeek：改一个配置文件，终端里的编程 Agent 就由 DeepSeek V4.1 Flash 驱动，按 token 计费。

  1. 安装 Claude Code：按官方方式安装，例如 macOS / Linux 运行 curl -fsSL https://claude.ai/install.sh | bash。
  2. 写入配置：编辑 ~/.claude/settings.json，把下面的 env 加进去，ANTHROPIC_AUTH_TOKEN 换成你在 AnyAIGC 创建的 Key。
  3. 开始使用：在项目目录运行 claude，输入 /model 可以确认当前模型是 deepseek-v4.1-flash。

换模型：想用 V4 Pro，把配置里的 deepseek-v4.1-flash 换成 deepseek-v4-pro 即可；也可以只把 ANTHROPIC_DEFAULT_HAIKU_MODEL 留给 V4.1 Flash 处理轻量子任务。

完整步骤和常见报错见 Claude Code 安装与使用教程，教程里的模型名换成 deepseek-v4.1-flash 即可。

FAQ

DeepSeek API 常见问题

DeepSeek API 多少钱？

AnyAIGC 上 DeepSeek 按 token 计费，每百万 tokens：deepseek-v4.1-flash 输入 $0.1215、输出 $0.4860、缓存命中 $0.0024；deepseek-v4-pro 输入 $0.5346、输出 $1.6038、缓存命中 $0.0178；deepseek-v4-flash 与 V4.1 Flash 同价。实时价格以模型广场为准。

AnyAIGC 也分高峰和闲时价格吗？

不分。DeepSeek 官方 API 采用峰谷定价，北京时间工作日 9:00–12:00、14:00–18:00为高峰时段，高峰价是闲时价的 2 倍。AnyAIGC 上 DeepSeek 各型号 全天按模型广场的同一单价计费，约为官方高峰价的 4 折，实时价格以模型广场为准。

AnyAIGC 上有哪些 DeepSeek 模型？模型 ID 是什么？

本页介绍三款：deepseek-v4.1-flash（DeepSeek 最新的 Flash 模型，原生多模态）、deepseek-v4-pro（1.6T 参数的 V4 旗舰）、deepseek-v4-flash（V4 预览版的 Flash 模型，官方已升级到 V4.1 Flash）。调用时把模型 ID 写在请求体的 model 字段里，切换模型只需要改这一个字段。

V4.1 Flash 和 V4 Pro 怎么选？

大多数任务优先用 V4.1 Flash：DeepSeek 官方称它在性能、费用、速度和总用时上已全面超越 V4 Pro，输入单价约为 V4 Pro 的四分之一，还能看图。已经在生产里调好 V4 Pro 的业务可以继续用 V4 Pro，官方已宣布在 2026 年 9 月 14 日之后继续提供 V4 Pro API 服务。

上下文窗口有多大？支持图片输入吗？

DeepSeek 官方公布 V4.1 Flash 和 V4 Pro 都支持 1M tokens 上下文，最大输出 384K tokens。图片输入只有 V4.1 Flash 支持，V4 Pro 和 V4 Flash 只支持文本。

DeepSeek API 兼容 OpenAI 吗？

兼容。三款模型都走 POST https://anyaigc.ai/v1/chat/completions，请求和返回格式与 OpenAI Chat Completions 一致，OpenAI 官方 SDK 把 base_url 改成 https://anyaigc.ai/v1 即可。也支持 Anthropic 接口格式，可以接入 Claude Code。

可以在 Claude Code 里使用 DeepSeek 吗？

可以。AnyAIGC 上的 DeepSeek 模型同时支持 OpenAI 和 Anthropic 两种接口格式。在 ~/.claude/settings.json 的 env 中设置 ANTHROPIC_BASE_URL 为 https://anyaigc.ai、ANTHROPIC_AUTH_TOKEN 为你的 API Key、ANTHROPIC_MODEL 为 deepseek-v4.1-flash，然后运行 claude 即可，按 token 计费。

并发和速率有限制吗？

AnyAIGC 对 DeepSeek 系列 不设并发限制，所有用户默认享有，适合批量任务、CI 流水线和多 Agent 并行。

国内可以直接调用 DeepSeek API 吗？

可以。AnyAIGC 面向国内网络优化，通常无需额外代理即可调用 https://anyaigc.ai，按美元价格计费，支持微信支付、支付宝、USDT 和信用卡，企业可对公转账并开具增值税发票。

能。AnyAIGC 可以按实际充值金额开具增值税普通发票和增值税专用发票，开票信息提交给客服即可。
