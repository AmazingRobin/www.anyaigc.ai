Anthropic 原生接口，功能齐全

请求格式与 Anthropic Messages API 一致，官方 SDK 和现有代码可以直接迁移。

  • Messages API

    接口地址 /v1/messages，用 Anthropic 官方 SDK 时把 base URL 设为 https://anyaigc.ai 即可。

  • 提示词缓存

    在内容块上加 cache_control，支持 5 分钟和 1 小时缓存，命中部分约为普通输入价的 2.5%–10%。

  • 工具调用与结构化输出

    通过 tools 定义函数，或用 JSON Schema 约束输出格式，接入现有业务系统。

  • 自适应思考

    支持 thinking 和推理强度（effort）参数。按 Anthropic 文档，Fable 5.1、Sonnet 5 等型号默认开启自适应思考，具体见各型号页。

  • 图片与 PDF 输入

    AnyAIGC 文档提供 PDF 文档输入示例；按 Anthropic 文档，Claude 模型也支持图片输入。

  • 流式输出

    请求里设置 "stream": true，边生成边返回，适合聊天界面和长输出。

三步开始调用

  1. 注册并充值：在 anyaigc.ai 注册账号，余额对平台所有模型通用。
  2. 创建 API Key：在控制台创建令牌，复制以 sk- 开头的 Key。
  3. 发起请求：向 https://anyaigc.ai/v1/messages 发送 Anthropic Messages 格式的请求，鉴权用 Authorization: Bearer。

更多参数（tools、thinking、流式输出、PDF 与图片输入等）见 AnyAIGC Messages 接口文档，字段含义与 Anthropic 官方文档一致。

常见问题

Claude API 怎么收费？多少钱？

AnyAIGC 上的 Claude 模型都按 token 计费，没有订阅和月费，单位为美元每 100 万 tokens。当前型号：Opus 5.5 输入 $0.4765、输出 $2.3820；Sonnet 5.5 输入 $0.2382、输出 $1.1910；Haiku 5.5 输入 $0.0119、输出 $0.0596；Fable 5.1 输入 $2.3820、输出 $11.9120。Opus、Sonnet、Haiku 约为 Anthropic 官方价的 1.2 折（节省 88%），Fable 约为 2.4 折（节省 76%）。缓存写入、缓存命中和旧版型号的价格见本页价格表，实时价格以 AnyAIGC 模型广场为准。

国内可以直接调用 Claude API 吗？

可以。AnyAIGC 面向国内网络优化，通常无需额外代理即可调用 https://anyaigc.ai/v1/messages，按美元价格计费，企业可对公转账并开具增值税发票。

如何获取 Claude API Key？

在 anyaigc.ai 注册并充值，进入控制台创建令牌即可。同一个 Key 可以调用本页全部 10 个 Claude 型号，以及平台上 300+ 其他模型，余额通用。

AnyAIGC 的 Claude API 兼容 Anthropic 官方 SDK 吗？

兼容。接口地址是 https://anyaigc.ai/v1/messages，请求体沿用 Anthropic Messages 格式（model、max_tokens、system、messages、tools、cache_control 等），鉴权使用 Authorization: Bearer 你的 API Key。用官方 anthropic SDK 时把 base_url 改为 https://anyaigc.ai 即可，现有代码基本不用改。

Claude 有哪些模型？该选哪个？

AnyAIGC 目前提供 10 个 Claude 型号，当前型号是 Opus 5.5、Sonnet 5.5、Haiku 5.5 和 Fable 5.1。复杂编码和 AI Agent 用 Opus 5.5；范围明确的日常编码、修 bug 和文档表格用 Sonnet 5.5；批量分类、实时客服和子 Agent 用 Haiku 5.5，Anthropic 称它是 Claude 5.5 系列中速度最快、效率最高的模型；最难的长时间运行任务用 Fable 5.1。旧版 Opus 5、Fable 5、Sonnet 5、Opus 4.8、Opus 4.7、Opus 4.6 仍可调用，适合已有项目。

Claude Opus 和 Sonnet 有什么区别？

Anthropic 将 Sonnet 5.5 定位为 Opus 5.5 更快、更低成本的搭档：Opus 5.5 面向需要审慎判断的复杂工作，Sonnet 5.5 擅长范围明确的日常任务、修复 bug，以及制作文档、幻灯片和表格。价格上，Sonnet 5.5 是 Opus 5.5 的一半：AnyAIGC 上 Sonnet 5.5 输入 $0.2382、输出 $1.1910，Opus 5.5 输入 $0.4765、输出 $2.3820（每 100 万 tokens）。

Claude Fable 和 Opus 有什么区别？

Fable 是 Anthropic 的 Mythos 级模型系列，Anthropic 称 Mythos 级模型的能力在 Opus 级之上。Anthropic 文档建议多数工作负载先用 Claude Opus 5.5，把最难的任务交给 Fable 5.1。Fable 5.1 的价格是 Opus 5.5 的两倍多：AnyAIGC 上输入 $2.3820、输出 $11.9120 每 100 万 tokens。两者用同一个 Key，按任务切换 model 字段即可。

旧版 Claude 模型还能用吗？

能。Anthropic 已把 Opus 5、Fable 5、Sonnet 5、Opus 4.8、Opus 4.7、Opus 4.6 列为旧版，目前在 AnyAIGC 仍可正常调用。官方承诺的最早退役日期：Opus 4.6 为 2027 年 2 月 5 日，Opus 4.7 为 2027 年 4 月 16 日，Opus 4.8 为 2027 年 5 月 28 日，Fable 5 为 2027 年 6 月 9 日，Sonnet 5 为 2027 年 6 月 30 日，Opus 5 为 2027 年 7 月 24 日。新项目建议使用对应的最新型号。

可以在 Claude Code 里使用吗？

可以。用一行命令 curl -fsSL https://www.anyaigc.ai/install.sh | bash -s claude 自动安装和配置；或在 ~/.claude/settings.json 的 env 中设置 ANTHROPIC_BASE_URL 为 https://anyaigc.ai、ANTHROPIC_AUTH_TOKEN 为你的 API Key、ANTHROPIC_MODEL 为 claude-opus-5-5。把 ANTHROPIC_DEFAULT_HAIKU_MODEL 设为 claude-haiku-5-5，后台任务和子 Agent 就会用 Haiku 5.5。

并发有限制吗？

AnyAIGC 对 Claude 全系型号不设并发限制，所有用户默认享有，适合批量任务和多 Agent 并行。

AnyAIGC 能开发票吗？支持增值税专票吗？

能。AnyAIGC 可以按实际充值金额开具增值税普通发票和增值税专用发票，开票信息提交给客服即可。

企业可以对公转账和签合同吗？

可以。支持企业对公转账充值，也可以签订服务合同，并提供专属客服和技术对接。企业采购请联系 AnyAIGC 客服。
