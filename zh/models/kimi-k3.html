关于模型

三万亿级开放权重模型，为长程任务设计

Moonshot AI 称 Kimi K3 是首个达到 2.8 万亿参数的开源模型。它基于 Kimi Delta Attention（KDA）混合线性注意力和注意力残差（Attention Residuals）构建，两项结构改动都是为了让信息在更长的序列和更深的网络里流动得更顺。

在 Stable LatentMoE 框架下，K3 每个 token 从 896 个专家中激活 16 个。官方表示，结合训练方法和数据配方的改进，K3 的整体扩展效率约为 K2 的 2.5 倍。模型原生支持视觉理解，上下文窗口 1,048,576 tokens，思考模式始终开启。

在 AnyAIGC 上，kimi-k3 走 OpenAI 兼容的 /v1/chat/completions，也能在 Claude Code 里直接使用。不需要 Moonshot 开放平台账号，没有充值等级限制，并发不限。

快速开始

三步接入 Kimi K3 API

  1. 注册并充值：在 anyaigc.ai 注册账号，最低 $1 起充，余额对平台所有模型通用。
  2. 创建 API Key：在控制台创建令牌，复制以 sk- 开头的 Key，存到环境变量 ANYAIGC_API_KEY。
  3. 发起请求：请求 POST https://anyaigc.ai/v1/chat/completions，model 填 kimi-k3，鉴权用 Authorization: Bearer。OpenAI SDK 把 base_url 改成 https://anyaigc.ai/v1 即可。

参数提示：K3 思考始终开启，思考过程在 reasoning_content 字段。官方推荐 temperature=1.0、top_p=0.95。多轮对话和工具调用时，要把 API 返回的完整 assistant 消息（包括 reasoning_content 和 tool_calls）原样放回下一次请求，不要只保留 content。

完整参数见 Chat Completions 接口文档，文档示例里的模型名换成对应的 Kimi 模型 ID 即可。

FAQ

Kimi K3 API 常见问题

Kimi K3 API 多少钱？

AnyAIGC 上 kimi-k3 按 token 计费：输入 $1.2150/百万 tokens，输出 $6.0750/百万 tokens，缓存命中 $0.1215/百万 tokens。Moonshot 官方美元价为输入 $3.00、输出 $15.00、缓存命中 $0.30，AnyAIGC 约为官方价的 40%（约 4 折）。输出包含思考 tokens，实时价格以模型广场为准。

Kimi K3 的模型 ID 是什么？上下文多大？

模型 ID 是 kimi-k3。Moonshot 官方公布的上下文窗口为 1,048,576 tokens（1M），max_completion_tokens 默认 131,072，最大可设到 1,048,576。

Kimi K3 有什么特点？

Moonshot 称 Kimi K3 是首个达到 2.8 万亿参数的开源模型，基于 Kimi Delta Attention（KDA）混合线性注意力和注意力残差构建，MoE 每个 token 从 896 个专家中激活 16 个，原生支持视觉理解。官方说整体扩展效率约为 K2 的 2.5 倍，面向长程编程、知识工作和推理。

怎么调整 Kimi K3 的思考深度？

K3 始终开启思考，不能关闭。官方用请求体顶层的 reasoning_effort 字段调整思考深度，可选 low、high、max，默认 max。简单任务用 low 可以减少输出 tokens。

Kimi K3 支持工具调用和图片输入吗？

支持。K3 支持函数调用（tools / tool_choice）、结构化输出（json_schema）、流式输出和图片输入。多轮和工具调用时，需要把返回的完整 assistant 消息（含 reasoning_content 和 tool_calls）原样放回下一次请求。

可以在 Claude Code 里使用 Kimi K3 吗？

可以。在 ~/.claude/settings.json 的 env 中设置 ANTHROPIC_BASE_URL 为 https://anyaigc.ai、ANTHROPIC_AUTH_TOKEN 为你的 API Key、ANTHROPIC_MODEL 为 kimi-k3，然后运行 claude 即可。

Kimi K3 和 K2.7 Code 怎么选？

K3 是 2.8T 参数的旗舰级模型，有 1M 上下文，适合大仓库、长周期任务和最难的推理；K2.7 Code 是 1T 参数的编程模型，上下文 256K，AnyAIGC 输入 $0.3847、输出 $1.5980，约为 K3 的三分之一。可以日常用 K2.7 Code，难题切到 K3，两者共用同一个 Key。

并发和速率有限制吗？

AnyAIGC 对 kimi-k3 不设并发限制，所有用户默认享有，适合批量任务、CI 流水线和多 Agent 并行。Moonshot 官方平台按充值等级限制并发、RPM、TPM 和 TPD，通过 AnyAIGC 调用不受这些等级限制。

可以。AnyAIGC 面向国内网络优化，通常无需额外代理即可调用 https://anyaigc.ai，按美元价格计费，支持微信支付、支付宝、USDT 和信用卡，企业可对公转账并开具增值税发票。
