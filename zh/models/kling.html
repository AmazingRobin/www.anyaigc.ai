Kling API 有哪些模型？

Kling 系列包含 15 个图片、视频、音频与创作工具模型，覆盖视频生成、参考控制、数字人、音效、口型同步、主体创建、特效和视频延长。

Kling API 怎么选？

文生视频可从 Kling Video、Kling 3.0 Turbo 或 Kling Video V4 开始；动作迁移选 Motion Control，数字人选 Avatar Image2Video，音效和配音选 Kling Audio。
