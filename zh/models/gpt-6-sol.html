三步接入 GPT-6 Sol API

  1. 注册并充值：在 anyaigc.ai 注册账号，余额对平台所有模型通用。
  2. 创建 API Key：在控制台创建令牌，复制以 sk- 开头的 Key，存到环境变量 ANYAIGC_API_KEY。
  3. 发起请求：向 https://anyaigc.ai/v1/chat/completions 或 https://anyaigc.ai/v1/responses 发送请求，model 填 gpt-6-sol，鉴权用 Authorization: Bearer。

需要推理加工具调用时，请用 Responses API。按 OpenAI 的说明，gpt-6-sol 在 Chat Completions 上只有把 reasoning_effort 设为 "none" 时才支持函数调用（function calling）。需要在推理的同时调用函数，或使用计算机使用、网页搜索等内置工具时，改用 /v1/responses，推理强度写在 reasoning.effort 里。

完整参数见 Chat Completions 接口文档 和 Responses 接口文档，字段含义与 OpenAI 官方 API 一致。

GPT-6 Sol API 常见问题

GPT-6 Sol API 多少钱？

AnyAIGC 上 gpt-6-sol 按 token 计费：输入 $0.0993/百万 tokens，输出 $0.4964/百万 tokens，缓存输入 $0.0099/百万 tokens。OpenAI 官方价为输入 $2.00、输出 $10.00、缓存输入 $0.20，AnyAIGC 约为官方价的 5%（约 0.5 折）。单次请求输入超过 272K tokens 时，整次请求的输入和缓存按 2 倍、输出按 1.5 倍计费。

GPT-6 Sol 的模型 ID 和上下文窗口是多少？

模型 ID 是 gpt-6-sol，在请求体的 model 字段里填写即可，OpenAI 没有为它发布带日期的快照版本。按 OpenAI 模型文档，上下文窗口为 1,050,000 tokens，单次最多输出 128,000 tokens，知识截止日期为 2026 年 4 月 20 日。

GPT-6 Sol 停用了吗？还能用多久？

没有停用。OpenAI 已推出 GPT-6.1 Sol 作为新的 Sol 模型，但 GPT-6 Sol 没有列入 OpenAI 的弃用页面，OpenAI 尚未公布停用时间，目前仍可正常调用，AnyAIGC 上也可以继续使用 gpt-6-sol。新项目建议使用 GPT-6.1 Sol（gpt-6.1-sol）。

GPT-6 Sol 和 GPT-6.1 Sol 有什么区别？要不要迁移？

两者官方输入、输出单价相同（$2 / $10），GPT-6.1 Sol 的缓存输入更便宜（$0.10，GPT-6 Sol 为 $0.20）。按 OpenAI 公布的数据，GPT-6.1 Sol 在 DeepSWE v1.1、OSWorld 2.0 和 Terminal-Bench Science 上得分都更高，知识截止日期更新到 2026-04-30。迁移前注意两点：GPT-6.1 Sol 不支持 none 推理强度，在 Chat Completions 上也不支持工具调用。如果你的集成依赖 Chat Completions 加 reasoning_effort: "none" 调用函数，可以继续用 GPT-6 Sol，或先改用 Responses API 再切换到 gpt-6.1-sol。OpenAI 建议迁移前先阅读其迁移说明。

用 Chat Completions 还是 Responses API？可以调用工具吗？

两个接口都能用。普通对话、流式输出用 https://anyaigc.ai/v1/chat/completions 即可。按 OpenAI 的说明，gpt-6-sol 在 Chat Completions 上只有把 reasoning_effort 设为 none 时才支持函数调用；需要推理的同时调用函数，或使用内置工具时，请用 https://anyaigc.ai/v1/responses，推理强度写在 reasoning.effort 里。

可以在 Codex 里使用 GPT-6 Sol 吗？

可以。运行 curl -fsSL https://www.anyaigc.ai/install.sh | bash -s codex 一键安装（Windows 用 irm https://www.anyaigc.ai/install.ps1 | iex），脚本默认写入 gpt-5.5，装好后把 ~/.codex/config.toml 里的 model 改为 gpt-6-sol。也可以手动配置：在 ~/.codex/config.toml 里把 base_url 设为 https://anyaigc.ai/v1、wire_api 设为 responses、model 设为 gpt-6-sol，并在 ~/.codex/auth.json 写入 OPENAI_API_KEY。
