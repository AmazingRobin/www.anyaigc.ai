Grok Imagine API 常见问题

Grok Imagine API 多少钱？

在 AnyAIGC 上都按张计费，不按 token 算：Grok Imagine Image 每张 ¥0.08（1K、2K 同价）；Image 2.0 按分辨率和画质分档，¥0.12–¥0.24 / 张；Quality ¥0.15–¥0.21 / 张。改图时每张输入图另收 ¥0.03。xAI 官方价 2.0 为 $0.04–$0.08 / 张（约 ¥0.27–¥0.54），Image 为 $0.02 / 张（约 ¥0.13）。实时价格以模型广场为准。

Image 2.0、Image 和 Quality 有什么区别，该选哪个？

Grok Imagine Image 2.0（grok-imagine-image-2.0）是 xAI 当前推荐的型号，文字排版、指令遵循和改图都更强，在 AnyAIGC 上 ¥0.12 / 张起，新项目直接选它。Grok Imagine Image（grok-imagine-image）是第一代 Imagine 生图模型，¥0.08 / 张，是系列里最便宜的，适合只需要文生图的场景。Grok Imagine Image Quality 已被 xAI 在 2026 年 11 月 2 日并入 2.0，在 AnyAIGC 上 ¥0.15 / 张起，比 2.0 Low 每档贵约 ¥0.03，建议迁移。

grok-imagine-image-quality 停用了吗？

xAI 在 2026 年 11 月 2 日停用了 grok-imagine-image-quality，之后发往这个模型名的请求会由 grok-imagine-image-2.0 以 quality: "low" 处理，请求和返回格式不变。AnyAIGC 上这个模型名仍可调用，¥0.15–¥0.21 / 张，比 2.0 Low 同分辨率贵约 ¥0.03；建议直接把 model 改成 grok-imagine-image-2.0。

支持哪些宽高比和分辨率？

用 aspect_ratio 指定比例，支持 1:1、3:4、4:3、9:16、16:9、2:3、3:2、1:2、2:1、21:9 等，也可以填 auto 让模型决定；用 resolution 选分辨率：Image 2.0 和 Quality 支持 1k、1.5k、2k，Image 支持 1k、2k。Image 2.0 还支持 quality（low / medium / auto）。分辨率和画质越高，单价越高。

能用参考图改图吗？

Image 2.0 支持图片编辑：向 POST /v1/images/edits 用 multipart/form-data 上传原图和修改指令即可。xAI 官方支持一次最多 5 张参考图合成，AnyAIGC 文档目前给出的是单张原图的示例，多图请以 AnyAIGC 接口文档为准。

没有 xAI 账号能调用吗？国内能直连吗？

能。在 AnyAIGC 注册即可拿到 API Key，不需要 xAI 账号或海外信用卡。接口地址是 https://anyaigc.ai，国内网络可以直接调用，同一个 Key 还能调用平台上 300+ 其他模型。

并发有限制吗？

AnyAIGC 对 Grok Image 系列不设并发限制，所有用户默认享有，批量出图不用排队申请。

AnyAIGC 能开发票吗？支持增值税专票吗？

能。AnyAIGC 可以按实际充值金额开具增值税普通发票和增值税专用发票，开票信息提交给客服即可。
