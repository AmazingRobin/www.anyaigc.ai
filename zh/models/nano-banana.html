快速接入 Nano Banana API

  1. 注册 AnyAIGC，新用户送 200 万 tokens 试用额度，最低 $1 起充。
  2. 在控制台创建 API Key，保存到环境变量 ANYAIGC_API_KEY。
  3. 向 POST https://anyaigc.ai/v1beta/models/gemini-nano-banana-2.1:generateContent 发请求（Gemini 原生格式）；已有 OpenAI SDK 的项目也可以用 /v1/chat/completions，model 填 gemini-nano-banana-2.1。

换型号只改 MODEL：gemini-nano-banana-2.1、gemini-3.1-flash-image 或 gemini-3-pro-image，请求和返回格式完全相同。

请求头用 Authorization: Bearer <API Key>。imageConfig.imageSize 支持 1K、2K、4K，默认 1K；response_format 是平台扩展字段，填 url 时返回 fileData.fileUri 临时链接（仅非流式），不填默认返回 base64。安全策略拦截时 finishReason 为 SAFETY 或 PROHIBITED_CONTENT，不返回图片。

Nano Banana API 常见问题

Nano Banana API 多少钱？

Nano Banana 2.1、Nano Banana 2 和 Nano Banana Pro 有什么区别？

Nano Banana 2.1（gemini-nano-banana-2.1）是 Google 2026 年 10 月 6 日发布的 Nano Banana 2 升级版，画质、文字渲染和多轮一致性更好。Nano Banana 2（gemini-3.1-flash-image）是 Flash 级的高效生图模型。Nano Banana Pro（gemini-3-pro-image）基于 Gemini 3 Pro，带推理能力，适合复杂排版和专业级精修。三者都支持 1K、2K、4K 输出。

Nano Banana 是哪个模型？和 Gemini 是什么关系？

Nano Banana 是 Google Gemini 图像生成模型的昵称。最早的 Nano Banana 是 Gemini 2.5 Flash Image，之后有 Nano Banana Pro（Gemini 3 Pro Image）、Nano Banana 2（Gemini 3.1 Flash Image）和 Nano Banana 2.1。它们都通过 Gemini API 的 generateContent 接口调用。

支持哪些接口？可以改图吗？

支持 Gemini 原生格式 POST /v1beta/models/<模型名>:generateContent，也支持 OpenAI 兼容的 /v1/chat/completions。文生图只放一段文字；改图、多图合成时把一段文字和多张参考图（inlineData）放在同一个 parts 里，最多 14 张参考图。字段说明见 AnyAIGC API 文档。

并发有限制吗？国内能直接调用吗？

AnyAIGC 对 Nano Banana 全系 不设并发限制，所有用户默认享有。接口地址是 https://anyaigc.ai，面向国内网络优化，通常无需额外代理，也不需要 Google 账号和海外信用卡；同一个 Key 还能调用平台上 300+ 其他模型。

AnyAIGC 能开发票吗？支持增值税专票吗？

能。AnyAIGC 可以按实际充值金额开具增值税普通发票和增值税专用发票，开票信息提交给客服即可。

有。新用户注册后赠送 200 万 tokens 的试用额度，可以先测试效果再决定是否充值。最低 1 美元起充。

余额可以退款吗？

可以。未使用的余额可以申请退款，不收取手续费。具体流程请联系客服。

会不会用低配模型冒充？我的数据安全吗？

请求走官方模型渠道，不用低配或逆向模型冒充。除法律法规要求外，我们不会对你的输入输出内容做持久化存储，也不会用于训练模型；控制台可以查看每次调用的 tokens 与扣费明细。

生成的图片可以商用吗？有水印吗？

图片的使用权和内容政策以 Google 官方条款为准。Google 会在 Nano Banana 生成的所有图片里加入不可见的 SynthID 数字水印，画面上看不到。AnyAIGC 只提供 API 调用通道，不额外限制你对生成结果的使用；涉及人物肖像、品牌商标等内容时，请自行确认授权。
