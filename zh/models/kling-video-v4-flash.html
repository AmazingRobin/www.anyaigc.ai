MODEL CAPABILITIES

Kling Video V4 Flash 能做什么

以下按模型广场和接口文档当前公开信息整理，调用参数以 API 文档为准。

文生视频

只传 prompt 和 duration，就能生成 3–30 秒的 720p 视频，duration 默认 5 秒。

首帧与首尾帧

在 image_list 里用 type 标记 first_frame 作为首帧；end_frame 必须和 first_frame 成对，只传尾帧会返回 400。

多图参考

最多 10 张参考图，在提示词里用 @image_1、@image_2 按传入顺序引用，复用角色、商品外观和场景。

参考视频

最多 5 段参考视频，只能作特征参考（feature）：须为公网 http(s) 地址，每段至少 3 秒、合计不超过 30 秒，用来复用运镜与动作节奏。

主体与音色

element_list 最多 7 个主体，voice_list 最多 3 个音色，在提示词里用 @element_1 等引用；各类素材合计不超过 15 个。

画幅与分辨率

输出固定 720p（mode 传 std 或不传）；画幅支持 21:9、16:9、9:16、1:1，以及按素材自适应的 adaptive。

Python

import json
import os
import time
import urllib.request

BASE = "https://anyaigc.ai"
HEADERS = {
    "Authorization": "Bearer " + os.environ["ANYAIGC_API_KEY"],
    "Content-Type": "application/json",
}


def call(method, path, payload=None):
    data = json.dumps(payload, ensure_ascii=False).encode("utf-8") if payload else None
    request = urllib.request.Request(BASE + path, data=data, headers=HEADERS, method=method)
    with urllib.request.urlopen(request, timeout=60) as response:
        return json.load(response)


payload = {
    "model_name": "kling-video-v4-flash",
    "prompt": "镜头从高空缓缓推进到雨后的霓虹街道，一只橘猫走过湿润的路面，电影感光影",
    "duration": 5,
    "aspect_ratio": "16:9"
}

task_id = call("POST", "/kling/v1/videos/omni-video", payload)["data"]["task_id"]
print("task_id:", task_id)

# 每 10 秒查询一次，成功后打印视频地址
for _ in range(90):
    data = call("GET", f"/kling/v1/videos/omni-video/{task_id}")["data"]
    if data["task_status"] == "succeed":
        break
    if data["task_status"] == "failed":
        raise RuntimeError(data.get("task_status_msg"))
    time.sleep(10)
else:
    raise TimeoutError(task_id)

for video in data["task_result"]["videos"]:
    print(video["url"])

FAQ

Kling Video V4 Flash API 常见问题

Kling Video V4 Flash API 多少钱？

按秒计费：不带参考视频 $0.1206 / 秒，带参考视频 $0.0808 / 秒，输出固定 720p。单位 USD，按成功提交计费，实时价格以模型广场为准。

应该调用哪个接口？

提交任务用 POST /kling/v1/videos/omni-video，body 里 model_name 填 kling-video-v4-flash；查询结果用 GET /kling/v1/videos/omni-video/{id}。API 域名为 https://anyaigc.ai，请求头 Authorization: Bearer <API Key>。

支持哪些生成方式？

支持文生视频、首帧与首尾帧图生视频、最多 10 张参考图、最多 5 段参考视频，以及主体（最多 7 个）和音色（最多 3 个）引用，各类素材合计不超过 15 个。具体字段以接口文档为准。

怎么计费？带参考视频为什么单价更低？

不带参考视频时，计费秒数等于输出时长，单价 $0.1206 / 秒。带参考视频时单价为 $0.0808 / 秒，但计费秒数 = 输出时长 + max(参考视频总时长, 输出时长)，例如 5 秒输出加 5 秒参考视频按 10 秒计费，合计 $0.808。参考图、主体、音色不另计费。

分辨率、时长和画幅有什么限制？

输出固定 720p：mode 只能传 std 或不传，resolution 只能传 720p 或不传，传 pro 或 1080p 返回 400，且不扣费。duration 为 3–30 的整数秒，默认 5。画幅可选 21:9、16:9、9:16、1:1 和 adaptive。

有哪些参数不支持？

该型号不支持 sound（传 on 会返回 400）、multi_shot 多镜头、4K 模式，以及 refer_type 为 base 的视频编辑；视频参考只能用 feature。

结果怎么获取？

接口是异步的：提交后返回 task_id，再用查询接口轮询，任务成功后从返回的 task_result 里取视频地址。任务状态值和返回字段以接口文档为准。

并发有限制吗？

AnyAIGC 的 Kling 系列默认并发不限，所有用户都可以直接使用。
