GPT Image 2：文字渲染和写实感的一次跃升

OpenAI 于 2026 年 4 月 21 日发布 ChatGPT 图像 2.0，同期在 API 推出 gpt-image-2（快照 gpt-image-2-2026-04-21）。官方介绍它支持快速、高质量的图像生成和编辑，可以灵活设置尺寸，图片输入始终按高保真处理，不需要也不能设置 input_fidelity。

质量档位为 low、medium、high、auto。尺寸可以自定义，最长边不超过 3840px，宽高都是 16 的倍数，长短边比例不超过 3:1，总像素在 655,360 到 8,294,400 之间。常用尺寸有 1024×1024、1536×1024、1024×1536、2048×2048、2048×1152 和 3840×2160。

GPT Image 2 API 常见问题

GPT Image 2 API 多少钱？

AnyAIGC 上 gpt-image-2 按 token 计费：文本输入 $0.3971、图片输入 $0.6354、图片输出 $2.3830（每百万 tokens），缓存输入文本 $0.1588、图片 $0.2541。OpenAI 官方价为文本输入 $5.00、图片输入 $8.00、图片输出 $30.00。以 1024×1024、medium 质量为例，每张图片输出约 $0.0042（官方约 $0.0530）。实时价格以模型广场为准。

gpt-image-2 还能用吗？要不要换 GPT Image 2.5？

能用。OpenAI 官方指南建议新集成优先使用 GPT Image 2.5，但 gpt-image-2 目前没有停用公告，在 AnyAIGC 上照常调用。2.5 多了 xhigh 和 max 质量档；gpt-image-2 的优势是便宜，在 AnyAIGC 上图片输出 $2.3830 / 百万 tokens，2.5 为 $17.8200。换型号只改 model 字段，可以先拿同一批提示词对比 2.5 Flare。

支持哪些尺寸、质量和格式？

常用尺寸有 1024×1024、1536×1024、1024×1536、2048×2048、2048×1152、3840×2160、2160×3840 和 auto；自定义尺寸需满足最长边不超过 3840px，宽高都是 16 的倍数，长短边比例不超过 3:1，总像素在 655,360 到 8,294,400 之间。质量档位为 low、medium、high、auto。输出格式用 format 字段选 png、jpeg 或 webp，返回图片 URL 或 base64。最低价支持上述预设尺寸，自定义尺寸和透明背景的单价更高，以模型广场为准。

怎么做图生图和局部重绘？

调用 POST /v1/images/edits（multipart/form-data），image 字段可以传少于 16 张参考图，总计 50MB 以内；需要局部重绘时再传 mask，它的透明区域就是要重画的部分，必须是 PNG、小于 4MB、与第一张图同尺寸。参数见 编辑接口文档。

有按张计费的版本吗？gpt-image-2-c 怎么收费？

有。AnyAIGC 平台上的 gpt-image-2-c 是 GPT Image 2 的按张计费版，接口相同，只改 model 字段。每张固定价，质量档位不影响单价：1K 出图每张 ¥0.08，2K、4K 出图每张 ¥0.1。每次请求出 1 张，不支持 n、mask 参数，也不支持透明背景。质量开到 high 或出大图时，按张计费通常更省。

并发有限制吗？国内能直接调用吗？

AnyAIGC 对 gpt-image-2 不设并发限制，所有用户默认享有。接口地址是 https://anyaigc.ai/v1，面向国内网络优化，通常无需额外代理；按美元计费，支持微信支付和支付宝，同一个 Key 还能调用平台上 300+ 其他模型。
