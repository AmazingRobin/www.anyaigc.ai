关于模型

非对称结构，小成本大智能

DeepSeek 在 2026 年 9 月发布 V4.1 Flash，官方称它是全新模型结构系列中尺寸最小的模型，具备原生多模态视觉理解能力。新结构的设计目标是能力上限更高、推理更快、吞吐更大，并且可以扩展到更大参数的模型。

架构上是 552B 参数的 MoE，采用 Causal-Encoder-Decoder 结构，输入和输出不对称：输入激活 8B，输出激活 16B。官方称新一代模型的 KV Cache 对 HBM 的需求减少到上一代的 1/4、对 SSD 的需求减少到 1/8，Agent 场景里占比较高的缓存费用因此明显下降。10 月官方又把它更新到 V4.1-Flash-1017 版本，称项目开发能力提升显著。

在 AnyAIGC 上，deepseek-v4.1-flash 走 OpenAI 兼容的 /v1/chat/completions，支持文本和图片输入，也能在 Claude Code 里直接使用，全天同价，并发不限。

快速开始

三步接入 DeepSeek V4.1 Flash API

  1. 注册并充值：在 anyaigc.ai 注册账号，最低 $1 起充，余额对平台所有模型通用。
  2. 创建 API Key：在控制台创建令牌，复制以 sk- 开头的 Key，存到环境变量 ANYAIGC_API_KEY。
  3. 发起请求：请求 POST https://anyaigc.ai/v1/chat/completions，model 填 deepseek-v4.1-flash，鉴权用 Authorization: Bearer。OpenAI SDK 把 base_url 改成 https://anyaigc.ai/v1 即可。

参数提示：DeepSeek 官方说明 V4 系列默认开启思考。请求体里的 thinking 字段控制开关（{"type": "enabled"} 或 {"type": "disabled"}），reasoning_effort 调整思考强度（官方可选 low / high / max）。思考消耗的 tokens 计入输出，可在 usage.completion_tokens_details.reasoning_tokens 查看。思考模式下 temperature 等采样参数不生效。

完整参数见 Chat Completions 接口文档，文档示例里的模型名换成对应的 DeepSeek 模型 ID 即可。

DeepSeek V4.1 Flash API 常见问题

DeepSeek V4.1 Flash API 多少钱？

AnyAIGC 上 deepseek-v4.1-flash 按 token 计费：输入 $0.1215/百万 tokens，输出 $0.4860/百万 tokens，缓存命中 $0.0024/百万 tokens。DeepSeek 官方美元价闲时为输入 $0.15、输出 $0.60、缓存命中 $0.003，高峰时段翻倍。输出包含思考 tokens，实时价格以模型广场为准。

AnyAIGC 也分高峰和闲时价格吗？

不分。DeepSeek 官方 API 采用峰谷定价，北京时间工作日 9:00–12:00、14:00–18:00为高峰时段，高峰价是闲时价的 2 倍。AnyAIGC 上 deepseek-v4.1-flash 全天按模型广场的同一单价计费，约为官方高峰价的 4 折，实时价格以模型广场为准。

DeepSeek V4.1 Flash 有什么新变化？

DeepSeek 官方介绍，V4.1 Flash 是全新模型结构系列中尺寸最小的模型：552B 参数的 MoE，采用 Causal-Encoder-Decoder 非对称结构，输入激活 8B、输出激活 16B，具备原生多模态视觉理解能力。官方称它的 KV Cache 对 HBM 的需求减少到上一代的 1/4、对 SSD 的需求减少到 1/8，Agent 场景的缓存成本明显降低。

V4.1 Flash 比 V4 Pro 强吗？

DeepSeek 官方称，经多方测试，V4.1 Flash 在性能、费用、速度、总用时等指标上已全面超越 V4 Pro。官方模型卡公布的对比：DeepSWE v1.1 74.2 对 62.7，Terminal-Bench 2.1 90.6 对 87.9。在 AnyAIGC 上，V4.1 Flash 的输入单价 $0.1215，约为 V4 Pro（$0.5346）的四分之一。

DeepSeek V4.1 Flash 支持图片输入吗？怎么传？

支持。在 messages[].content 数组里放 {"type": "image_url", "image_url": {"url": ...}} 内容块，url 可以是公网图片地址，也可以是 Base64 Data URL。

上下文多长？支持思考模式吗？

DeepSeek 官方公布 V4.1 Flash 上下文 1M tokens，最大输出 384K tokens，支持思考和非思考两种模式，默认开启思考，同时支持工具调用和 JSON 输出。
