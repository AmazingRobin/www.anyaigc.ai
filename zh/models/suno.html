三步调用 Suno API

异步任务流程：提交请求拿到 task_id，再轮询结果。几分钟就能听到第一首歌。

  1. 注册并充值

    在 anyaigc.ai 注册账号并充值，余额对平台所有模型通用。

  2. 创建 API Key

    在控制台创建令牌，复制 Key。接口地址为 https://anyaigc.ai，鉴权方式 Authorization: Bearer。

  3. 提交并轮询

    POST /suno/submit/music 拿到 task_id，再用 GET /suno/fetch/{id} 每 5–10 秒查询一次，完成后取回音频地址。

更多模式（续写、翻唱、Persona、音效、混搭、局部重写等）和完整参数见 AnyAIGC Suno API 文档。mv 可选 chirp-v3-5 到 chirp-v6，以文档为准。

常见问题

关于在 AnyAIGC 上使用 Suno API，你需要知道的事。

Suno API 多少钱一次？

固定价格、按次计费：发起创作 $0.1191/次，Max Mode $0.2382/次，生成音效 $0.0238/次，人声伴奏分离 $0.1191/次，全轨道词曲分离 + MIDI $0.5956/次，获取歌词时间线 $0.0596/次。生成歌词、提升音乐风格、上传参考音频和创建 Persona 免费，suno_uploads 文件上传 $0.000993/次。无订阅、无月费。

Suno 有官方 API 吗？

截至 2026 年 10 月，Suno 尚未向公众开放自助式官方 API。AnyAIGC 是独立的第三方 API 平台，提供 Suno 音乐生成能力的统一接口，与 Suno, Inc. 没有隶属关系。

如何获取 Suno API Key？

在 anyaigc.ai 注册并充值，进入控制台的令牌页面创建 API Key。同一个 Key 可调用 Suno 以及平台上 300+ 其他模型。

Suno API 支持多大并发？

支持 300 RPM（每分钟 300 次请求），适合批量配乐、UGC 平台和自动化流水线。所有用户默认享有，无需申请。需要更高配额可以联系客服评估。

Suno API 是同步还是异步？生成一首歌要多久？

异步任务：向 /suno/submit/music 提交后返回 task_id，再用 /suno/fetch/{id} 轮询直到任务完成。多数歌曲在 1–3 分钟内完成，具体取决于歌曲长度和当前负载。

Suno API 能做哪些事？

用文本描述或自定义歌词生成带人声的完整歌曲或纯音乐，生成歌词和音效，提升风格标签，上传参考音频，做人声伴奏分离、全轨道分离并导出 MIDI，获取逐句歌词时间线，以及创建歌手风格 Persona。

支持哪些 Suno 模型版本？

通过 mv 参数选择版本：chirp-v3-0、chirp-v3-5、chirp-v4、chirp-v4-5、chirp-v5、chirp-v5-5、chirp-v6、chirp-v6-wild、chirp-v6-mini，覆盖 Suno v3 到最新的 v6 系列。不传 mv 时使用默认版本，可用版本以 AnyAIGC 文档为准。

Max Mode 和普通创作有什么区别？

Max Mode 使用更高质量的生成设置，通常在人声细节和编曲完整度上更好，价格为普通创作的 2 倍（$0.2382/次）。正式发布的成品用 Max Mode，小样和批量探索用普通模式更划算。

国内可以直接调用 Suno API 吗？

可以。AnyAIGC 面向国内网络优化，通常无需额外代理即可调用，企业用户可以联系客服确认发票方案。

生成的音乐可以商用吗？

商用权利取决于 Suno 的最新授权条款和你的具体使用场景。正式商用发布前请查阅 Suno 官方条款，有疑问可以联系 AnyAIGC 客服。

支持哪些曲风和语言？

覆盖流行、摇滚、电子、Lo-fi、说唱、民谣、电影配乐等主流曲风，支持中文、英文、日文、韩文等多种语言的歌词与人声。
