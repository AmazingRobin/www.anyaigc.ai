Python
import json
import os
import urllib.request

payload = {
    "model": "MiniMax-M3.1-Flash",
    "messages": [
        {
            "role": "user",
            "content": "请为一个待办应用设计三个清晰的 API 端点。"
        }
    ]
}

request = urllib.request.Request(
    "https://anyaigc.ai/v1/chat/completions",
    data=json.dumps(payload, ensure_ascii=False).encode("utf-8"),
    headers={
        "Authorization": "Bearer " + os.environ["ANYAIGC_API_KEY"],
        "Content-Type": "application/json",
    },
    method="POST",
)
with urllib.request.urlopen(request, timeout=120) as response:
    result = json.load(response)

print(json.dumps(result, ensure_ascii=False, indent=2))

常见问题

MiniMax API 常见问题

价格、接口、结果和企业接入，一次说明白。

MiniMax API 的起步价格是多少？

M3.1 Flash 输入 $0.0603/百万 tokens；Speech Turbo 语音 $0.3176/万字符，HD 语音 $0.5559/万字符；H3 768P 输出视频 $0.0750/秒。各功能采用不同计费单位，完整价格见表格，实时价格以模型广场为准。 M3.1 Flash 比官方省 59%；M3、M2.5 省 32%。折扣与本页单价对应，以模型广场实时标注为准。

12 个模型如何选择？

对话与开发可选 M3.1 Flash、M3、M2.7 或 M2.5；视频选 H3；文本转语音按版本和 HD/Turbo 选择六个 Speech 型号；文字设计音色选 Voice Design。请先用自己的任务和音色做小规模测试。

这些模型使用同一个接口吗？

使用同一个 AnyAIGC API Key 和域名，但端点按能力区分：对话用 /v1/chat/completions，H3 用 /minimax/v2/video_generation，语音用 /minimax/v1/t2a_v2 或 /minimax/v1/t2a_async_v2，音色设计用 /minimax/v1/voice_design。

视频、语音和音色设计如何获取结果？

H3 创建请求先返回 task_id；同步语音返回音频相关 JSON。Voice Design 文档正文与响应示例的字段不一致，接入时保留原始响应并确认格式。各独立专题提供对应的最小请求。

并发和 RPM 有限制吗？

AnyAIGC 的 MiniMax 接入并发不限，不设固定 RPM 上限。模型生成仍需要处理时间，请在应用中配置超时、错误处理和合理重试。

生成内容可以商用吗？

模型与输出的商用授权以 MiniMax 官方条款为准。使用参考素材、音色及生成内容时，也应具备相关权利或授权。AnyAIGC 是独立 API 服务商。

AnyAIGC 能开发票吗？支持增值税专票吗？

支持。可按实际充值金额开具增值税普通发票和增值税专用发票，联系企业客服办理即可。

企业可以对公转账和签合同吗？

可以。支持企业对公转账充值，可签订服务合同，并提供专属客服与技术对接，配合采购、财务和研发流程。

支持哪些支付方式？

支持微信支付、支付宝、USDT 和信用卡充值，企业还可以对公转账，并开具增值税普通发票或专用发票。余额按美元计价，对平台所有模型通用。

新用户有免费试用额度吗？

有。新用户注册后赠送 200 万 tokens 的试用额度，可以先测试效果再决定是否充值。最低 1 美元起充。

余额可以退款吗？

可以。未使用的余额可以申请退款，不收取手续费。具体流程请联系客服。

会不会用低配模型冒充？我的数据安全吗？

请求走官方模型渠道，不用低配或逆向模型冒充。除法律法规要求外，我们不会对你的输入输出内容做持久化存储，也不会用于训练模型；控制台可以查看每次调用的 tokens 与扣费明细。
