快速开始

三步接入 DeepSeek V4 Pro API

  1. 注册并充值：在 anyaigc.ai 注册账号，最低 $1 起充，余额对平台所有模型通用。
  2. 创建 API Key：在控制台创建令牌，复制以 sk- 开头的 Key，存到环境变量 ANYAIGC_API_KEY。
  3. 发起请求：请求 POST https://anyaigc.ai/v1/chat/completions，model 填 deepseek-v4-pro，鉴权用 Authorization: Bearer。OpenAI SDK 把 base_url 改成 https://anyaigc.ai/v1 即可。

参数提示：DeepSeek 官方说明 V4 系列默认开启思考。请求体里的 thinking 字段控制开关（{"type": "enabled"} 或 {"type": "disabled"}），reasoning_effort 调整思考强度（官方可选 low / high / max）。思考消耗的 tokens 计入输出，可在 usage.completion_tokens_details.reasoning_tokens 查看。思考模式下 temperature 等采样参数不生效。

完整参数见 Chat Completions 接口文档，文档示例里的模型名换成对应的 DeepSeek 模型 ID 即可。

  2. 写入配置：编辑 ~/.claude/settings.json，把下面的 env 加进去，ANTHROPIC_AUTH_TOKEN 换成你在 AnyAIGC 创建的 Key。

省钱搭配：配置里已把 ANTHROPIC_DEFAULT_HAIKU_MODEL 设成 deepseek-v4.1-flash，Claude Code 的轻量子任务走更便宜的模型，主任务继续用 V4 Pro。

完整步骤和常见报错见 Claude Code 安装与使用教程，教程里的模型名换成 deepseek-v4-pro 即可。

DeepSeek V4 Pro API 常见问题

DeepSeek V4 Pro API 多少钱？

AnyAIGC 上 deepseek-v4-pro 按 token 计费：输入 $0.5346/百万 tokens，输出 $1.6038/百万 tokens，缓存命中 $0.0178/百万 tokens。DeepSeek 官方美元价闲时为输入 $0.66、输出 $1.98、缓存命中 $0.022，高峰时段翻倍。输出包含思考 tokens，实时价格以模型广场为准。

AnyAIGC 也分高峰和闲时价格吗？

不分。DeepSeek 官方 API 采用峰谷定价，北京时间工作日 9:00–12:00、14:00–18:00为高峰时段，高峰价是闲时价的 2 倍。AnyAIGC 上 deepseek-v4-pro 全天按模型广场的同一单价计费，约为官方高峰价的 4 折，实时价格以模型广场为准。

DeepSeek V4 Pro 会下线吗？

目前不会。DeepSeek 在 2026 年 9 月 10 日曾计划下线 V4 Pro，之后在官方更新日志中宣布，应用户需求，9 月 14 日之后继续提供 V4 Pro 的 API 服务，计费方式不变。

V4 Pro 和 V4.1 Flash 怎么选？

DeepSeek 官方称 V4.1 Flash 在性能、费用、速度、总用时上已全面超越 V4 Pro，输入单价约为 V4 Pro 的四分之一，还支持图片输入，新项目建议优先试 V4.1 Flash。已经在生产里针对 V4 Pro 调好提示词和流程的业务，可以继续用 V4 Pro。

怎么调整 V4 Pro 的思考强度？

DeepSeek 官方在 8 月的 V4 Pro 正式版中新增了 low、high、max 三档思考强度，默认开启思考、强度 high。请求时用 reasoning_effort 设置强度，用 thinking 字段的 {"type": "disabled"} 关闭思考，示例见本页快速开始。

V4 Pro 的参数和上下文是多少？
