Python
import json
import os
import urllib.request

payload = {
    "content": [
        {
            "text": "海边日落，镜头缓慢推进。",
            "type": "text"
        }
    ],
    "duration": 5,
    "model": "MiniMax-H3",
    "ratio": "16:9",
    "resolution": "768P"
}

request = urllib.request.Request(
    "https://anyaigc.ai/minimax/v2/video_generation",
    data=json.dumps(payload, ensure_ascii=False).encode("utf-8"),
    headers={
        "Authorization": "Bearer " + os.environ["ANYAIGC_API_KEY"],
        "Content-Type": "application/json",
    },
    method="POST",
)
with urllib.request.urlopen(request, timeout=120) as response:
    result = json.load(response)

print(json.dumps(result, ensure_ascii=False, indent=2))

MiniMax API 常见问题

价格、接口、结果和企业接入，一次说明白。

MiniMax H3 API 多少钱？

768P 输出视频 $0.0750/秒; 768P 输入视频 $0.0750/秒; 2K 输出视频 $0.1219/秒; 2K 输入视频 $0.1219/秒; 视频再生成 $0.0450/秒; 参考图（前 5 张） $0/张; 参考图（第 6 张起） $0.0375/张。单位为 USD，实时价格以模型广场为准。

应该使用哪个 API 接口？

使用 POST /minimax/v2/video_generation，API 域名为 https://anyaigc.ai，通过 Authorization: Bearer 传入 API Key。

H3 支持哪些时长、分辨率和参考素材？

MiniMax-H3 支持 4–15 秒、768P 或 2K。content 必须包含且只包含一段非空文本；可提供首尾帧或参考图片、视频、音频，两种模式不能混用。纯文生视频需指定 ratio。

一次请求会返回什么？

异步生成任务，输出 4–15 秒的视频。

并发和 RPM 有限制吗？

AnyAIGC 的 MiniMax 接入并发不限，不设固定 RPM 上限。模型生成仍需要处理时间，请在应用中配置超时、错误处理和合理重试。

生成内容可以商用吗？

模型与输出的商用授权以 MiniMax 官方条款为准。使用参考素材、音色及生成内容时，也应具备相关权利或授权。AnyAIGC 是独立 API 服务商。

AnyAIGC 能开发票吗？支持增值税专票吗？

支持。可按实际充值金额开具增值税普通发票和增值税专用发票，联系企业客服办理即可。

企业可以对公转账和签合同吗？

可以。支持企业对公转账充值，可签订服务合同，并提供专属客服与技术对接，配合采购、财务和研发流程。

支持哪些支付方式？

支持微信支付、支付宝、USDT 和信用卡充值，企业还可以对公转账，并开具增值税普通发票或专用发票。余额按美元计价，对平台所有模型通用。

有。新用户注册后赠送 200 万 tokens 的试用额度，可以先测试效果再决定是否充值。最低 1 美元起充。
