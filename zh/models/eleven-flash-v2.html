Eleven Flash v2：轻量高速播报

Eleven Flash v2 是 ElevenLabs 的轻量高速语音合成模型。官方文档的模型表里它只列了英语（en），官方标注延迟约 135ms，单次生成上限 30,000 字符。模型广场的说明是「轻量高速播报模型，性价比高，适合短句朗读」。

要注意：官方文档只列了英语，所以中文等其他语言请选 Eleven Flash v2.5、Multilingual v2 或 v4 等多语言型号。

在 AnyAIGC 上，eleven_flash_v2 走 POST /v1/audio/speech，按输入文本的字符数计费，价格是 Eleven v4 的一半，并发不限。

快速开始

三步接入 Eleven Flash v2 API

  1. 注册并充值：在 anyaigc.ai 注册账号，最低 $1 起充，余额对平台所有模型通用。
  2. 创建 API Key：在控制台创建令牌，复制以 sk- 开头的 Key，存到环境变量 ANYAIGC_API_KEY。
  3. 发起请求：请求 POST https://anyaigc.ai/v1/audio/speech，model 填 eleven_flash_v2，voice 填 ElevenLabs 的 voice_id，鉴权用 Authorization: Bearer，把返回的音频保存为 mp3。

参数提示：模型 ID 区分大小写，写成 eleven_flash_v2；voice 填 ElevenLabs 的 voice_id，不存在或不可用时返回 400；接口文档标注 input 最大 4,096 字符，长文本请分段。示例把响应体按音频文件保存为 mp3。

完整参数见 创建语音接口文档，文档示例里的模型名换成对应的 Eleven 模型 ID 即可。

FAQ

Eleven Flash v2 API 常见问题

Eleven Flash v2 API 多少钱？

AnyAIGC 上 eleven_flash_v2 按字符计费：$0.3240 / 万字符，约为 ElevenLabs 官方价（$0.40 / 万字符）的 8.1 折。固定单价，没有订阅和月费，实时价格以模型广场为准。

Eleven Flash v2 的模型 ID 是什么？和 ElevenLabs 是什么关系？

模型 ID 是 eleven_flash_v2（区分大小写），和 ElevenLabs 官方的 model_id 一致。AnyAIGC 是独立的 API 服务商，提供 OpenAI 风格的 /v1/audio/speech 调用方式，与 ElevenLabs 没有隶属关系。

Eleven Flash v2 和其他 Eleven 型号怎么选？

平台上共有 7 款 Eleven 语音模型：Eleven v4（旗舰）、Eleven v4 Turbo（低延迟）、Eleven v3、Eleven v3 Conversational、Eleven Multilingual v2、Eleven Flash v2.5、Eleven Flash v2。追求成品音质选 v4，做语音助手选 v4 Turbo，长文本和双语混读选 Multilingual v2，大批量字幕选 Flash v2.5，同一段文本建议分别试听再定。

如何获取 Eleven Flash v2 API Key？

在 anyaigc.ai 注册并充值，进入控制台创建令牌即可。同一个 Key 可以调用平台上 300+ 个模型，不需要单独注册 ElevenLabs 账号。请求体的 model 填 eleven_flash_v2。

怎么调用 Eleven Flash v2 API？voice 填什么？

请求 POST https://anyaigc.ai/v1/audio/speech，必填 model、input、voice。voice 填 ElevenLabs 的 voice_id，voice_id 不存在或不可用时接口返回 400；response_format 支持 mp3、opus、aac、flac。完整参数见接口文档。

Eleven Flash v2 一次能合成多长的文本？

ElevenLabs 官方文档标注该模型单次生成上限为 30,000 字符。AnyAIGC 创建语音接口文档里 input 一栏标注的最大长度是 4,096 字符，长文本请按这个长度分段请求，再把音频拼接起来。

Eleven Flash v2 支持中文吗？支持多少种语言？

官方文档的模型表里它只列了英语，中文请改用其他型号。具体语种以 ElevenLabs 官方文档为准。

Eleven Flash v2 支持中文吗？

官方文档的模型表里 Flash v2 只列了英语（en），所以中文等其他语言不要选它，请用 Eleven Flash v2.5、Eleven Multilingual v2 或 Eleven v4。

并发和速率有限制吗？

AnyAIGC 对 eleven_flash_v2 不设并发限制，所有用户默认享有，适合批量生成和多任务并行。按字符计费，没有月费和按时间窗口重置的额度。

能用自己克隆的声音吗？

接口文档只写明 voice 填 ElevenLabs 的 voice_id。你自己 ElevenLabs 账号里的克隆音色能否通过 AnyAIGC 的 Key 调用，文档没有说明，请联系 AnyAIGC 客服确认。
