#Midjourney API 怎么调用

和在 Discord 或网页里一样：先出一组 4 张，再在结果上点按钮。API 把每个按钮都返回给你，带上它的 customId 再提交一次就行。

  1. 01

    POST/mj/submit/imagine

    提交提示词

    返回任务 ID。提示词里可直接写 --ar、--v、--niji 等参数。$0.0595 / 次

  2. 02

    GET/mj/task/{id}/fetch

    查询任务

    轮询到 SUCCESS 后拿到 imageUrl，同时返回 buttons 列表。查询不收费

  3. 03

    POST/mj/submit/action

    点按钮

    传 taskId 和按钮的 customId：放大 $0.0298，变体、扩图、平移 $0.0595

  4. 04

    POST/mj/submit/modal

    弹窗确认

    局部重绘、自定义扩图需要第二步，提交蒙版或新提示词。$0.0595 / 次

#Midjourney API 能做什么

  • Imagine 文生图

    一句提示词出 4 张候选，支持垫图（base64Array）。Midjourney 擅长光影、质感和构图，写实摄影和插画都很稳。

  • Niji 动漫与插画

    botType 填 NIJI_JOURNEY 切到 Niji 模型，二次元、漫画、日系插画更对味。

  • Variation 变体

    V1–V4 在某一张上继续变化；Vary (Strong) 幅度大，Vary (Subtle) 只做微调。

  • Upscale 放大

    U1–U4 选出单张，再用 Subtle 或 Creative 放大，适合交付高清图。

  • Zoom Out 与 Pan 扩图

    向外扩展 1.5x / 2x，或向一个方向平移延展，把竖图扩成横图也可以。

  • Blend 混图与 Describe 图生文

    2–5 张图融合成一张新图；或者上传一张图，让 Midjourney 反推 4 条提示词。

#Midjourney API 常见问题

Midjourney API 多少钱？

AnyAIGC 上 Midjourney 按次计费：Imagine、Blend、Variation、Reroll、Zoom、Pan 和 Modal 每次 $0.0595（约 ¥0.40），Upscale 放大和 Describe 图生文每次 $0.0298，上传参考图每次 $0.000595，Custom Zoom 和 Vary (Region) 免费（它们的弹窗确认按 Modal 计费）。查询任务不收费，实时价格以模型广场为准。

Midjourney 有官方 API 吗？

Midjourney 官方目前没有面向开发者的公开 API，只能在网页和 Discord 里使用。AnyAIGC 把 Midjourney 服务封装成 HTTP 接口，出图的就是 Midjourney 自己的模型（含 Niji），不是用其他模型冒充；用一个 API Key 就能调用 Imagine、放大、变体、扩图等功能，不需要自己的 Discord 账号。

14 个模型名有什么区别？分别走哪个接口？

14 个模型名对应 Midjourney 的 14 种操作，都在本页价格表里：Imagine、Blend、Describe 各有独立接口；Upscale、Variation、Vary (Strong/Subtle)、Reroll、Zoom、Pan、Custom Zoom、Vary (Region) 都走 /mj/submit/action，由按钮的 customId 决定；Modal 是弹窗确认；Upload 用来上传参考图。

支持哪些 Midjourney 版本？能用 Niji 吗？

在提示词末尾用 --v 参数选择版本（接口文档示例为 --v 6.1），写法和官方一致，参数原样传给 Midjourney。botType 填 NIJI_JOURNEY 使用 Niji 动漫模型，默认 MID_JOURNEY。

一次调用返回几张图？

Imagine、Variation、Reroll、Zoom、Pan 等每次返回一组 4 张候选（拼成一张网格图），按一次计费。要单张高清图，再对其中一张执行 Upscale。

放大、变体这些操作怎么调用？

先用 /mj/task/{id}/fetch 查到任务结果，返回的 buttons 里每个按钮都有 customId；把任务 ID 和 customId 传给 /mj/submit/action 即可。customId 必须取自返回结果，不要自己拼。

并发有限制吗？国内能直接调用吗？

AnyAIGC 对 Midjourney 不设并发限制，所有用户默认享有。接口地址是 https://anyaigc.ai，国内网络可以直接调用。

AnyAIGC 能开发票吗？支持增值税专票吗？

能。AnyAIGC 可以按实际充值金额开具增值税普通发票和增值税专用发票，开票信息提交给客服即可。
