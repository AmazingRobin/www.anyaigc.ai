三步接入 GPT-5.6 Luna API

  1. 注册并充值：在 anyaigc.ai 注册账号，余额对平台所有模型通用。
  2. 创建 API Key：在控制台创建令牌，复制以 sk- 开头的 Key，存到环境变量 ANYAIGC_API_KEY。
  3. 发起请求：向 https://anyaigc.ai/v1/chat/completions 或 https://anyaigc.ai/v1/responses 发送请求，model 填 gpt-5.6-luna，鉴权用 Authorization: Bearer。

两个接口都支持工具调用。按 OpenAI 的说明，gpt-5.6-luna 支持 Chat Completions、Responses 和 Batch，支持函数调用（function calling）和结构化输出。普通对话和函数调用用 /v1/chat/completions 即可；需要 Responses API 的内置工具或多步骤 Agent 工作流时用 /v1/responses，推理强度写在 reasoning.effort 里。

完整参数见 Chat Completions 接口文档 和 Responses 接口文档，字段含义与 OpenAI 官方 API 一致。

GPT-5.6 Luna API 常见问题

GPT-5.6 Luna API 多少钱？

AnyAIGC 上 gpt-5.6-luna 按 token 计费：输入 $0.0270/百万 tokens，输出 $0.1620/百万 tokens，缓存输入 $0.0027/百万 tokens。OpenAI 官方价为输入 $0.20、输出 $1.20、缓存输入 $0.02，AnyAIGC 约为官方价的 13.5%（约 1.3 折）。单次请求输入超过 272K tokens 时，整次请求的输入按 2 倍、输出按 1.5 倍计费。

GPT-5.6 Luna 的模型 ID 是什么？

模型 ID 是 gpt-5.6-luna，在请求体的 model 字段里填写即可。OpenAI 没有为它发布带日期的快照版本。

GPT-5.6 Luna 降价了多少？

OpenAI 于 2026 年 7 月 30 日将 GPT-5.6 Luna 的 API 价格永久下调 80%：输入从 $1 降到 $0.20，输出从 $6 降到 $1.20，缓存输入从 $0.10 降到 $0.02（每百万 tokens）。AnyAIGC 的价格以降价后的官方价为基准，输入 $0.0270、输出 $0.1620、缓存输入 $0.0027。

GPT-5.6 Luna 还能用多久？停用了吗？

没有停用。OpenAI 已推出更新的 GPT-6 Luna，但 GPT-5.6 Luna 仍在 API 中正常提供，OpenAI 尚未公布停用时间，目前仍可正常调用，AnyAIGC 上的调用方式不变。新项目可以考虑 GPT-6 Luna；已经用 gpt-5.6-luna 调好提示词的批量任务可以继续使用。

用 Chat Completions 还是 Responses API？可以调用工具吗？

两个接口都能用，都支持工具调用。按 OpenAI 的说明，gpt-5.6-luna 支持 Chat Completions、Responses 和 Batch，支持流式输出、函数调用（function calling）和结构化输出。简单对话和函数调用用 https://anyaigc.ai/v1/chat/completions 即可；需要 Responses API 的内置工具或多步骤 Agent 工作流时用 https://anyaigc.ai/v1/responses，推理强度写在 reasoning.effort 里。

可以在 Codex 里使用 GPT-5.6 Luna 吗？

可以。运行 curl -fsSL https://www.anyaigc.ai/install.sh | bash -s codex 一键安装（Windows 用 irm https://www.anyaigc.ai/install.ps1 | iex），脚本默认写入 gpt-5.5，装好后把 ~/.codex/config.toml 里的 model 改为 gpt-5.6-luna。也可以手动配置：在 ~/.codex/config.toml 里把 base_url 设为 https://anyaigc.ai/v1、wire_api 设为 responses、model 设为 gpt-5.6-luna，并在 ~/.codex/auth.json 写入 OPENAI_API_KEY。

并发和速率有限制吗？

AnyAIGC 对 gpt-5.6-luna 不设并发限制，所有用户默认享有，适合大批量分类、抽取和多 Agent 并行任务。
