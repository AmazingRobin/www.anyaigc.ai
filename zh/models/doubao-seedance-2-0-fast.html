Seedance API 常见问题

Seedance 2.0 Fast API 多少钱？

AnyAIGC 按 1M tokens 计费，价格取决于分辨率和是否包含参考视频。480p / 720p（不含参考视频）：$4.914 / 1M tokens；480p / 720p（含参考视频）：$2.896 / 1M tokens。实时价格以模型广场为准。

Seedance 支持哪些输入和能力？

Seedance 2.0 支持文字、图片、音频和视频作为参考输入，并支持视频编辑、延长与原生音频。2.0 Fast 侧重更快生成，2.0 mini 面向高频规模化场景；2.5 增强长叙事、参考和精准编辑。

一次调用会返回几条视频？

一次创建任务返回一个任务 ID，任务完成后通过查询接口取得一个视频链接。生成是异步的，具体时长由 duration 参数或模型选择决定。

支持哪些分辨率、比例和时长？

Seedance 2.0 支持 480p、720p、1080p 和 4K，4K 当前可调用。Seedance 2.5 支持 480p、720p、1080p，duration 为 4–30 或 -1；Fast 和 mini 的价格档位为 480p / 720p。比例、时长等参数按具体型号的 API 文档传入。

如何查询生成结果？

创建任务后保存返回的 id，调用 GET /api/v3/contents/generations/tasks/{id} 查询。成功时从 content.video_url 取得临时视频链接，状态字段以接口返回为准。

并发有限制吗？

AnyAIGC 对 Seedance 不设置并发限制，所有用户默认享有。大批量请求仍建议根据任务返回和业务队列做好重试与下载。

AnyAIGC 能开发票吗？支持增值税专票吗？

可以。AnyAIGC 支持按实际充值金额开具增值税普通发票和增值税专用发票。

企业可以对公转账和签合同吗？

可以。支持企业对公转账充值、签订服务合同，并提供专属客服和技术对接。

支持哪些支付方式？

支持微信支付、支付宝、USDT 和信用卡充值，企业还可以对公转账。余额按 USD 计价，对平台所有模型通用。

新用户有免费试用额度吗？

有。新用户注册后赠送 200 万 tokens 试用额度，最低 1 美元起充。

余额可以退款吗？

可以。未使用余额可申请退款，不收手续费。具体流程请联系客服。
