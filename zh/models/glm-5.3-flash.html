关于模型

新基座、新架构的原生多模态模型

智谱称 GLM-5.3-Flash 是 GLM-5 系列首个原生多模态模型，以极低成本提供超过 GLM-5.2 的能力。和 GLM-5.3 不同，它从一个全新训练的基座开始，预训练语料约 30T tokens，覆盖多模态数据。

架构上是 320B 总参数、18B 激活的 MoE，官方称它是首个把稀疏注意力和线性注意力结合起来的开源前沿模型，并采用流形约束超连接（mHC）。相比 GLM-5.3，注意力计算降低约 3 倍、KV cache 降低约 4.4 倍，在保持长上下文能力的同时大幅降低了服务成本。上下文 1M tokens，最大输出 128K，思考始终开启。

在 AnyAIGC 上，glm-5.3-flash 走 OpenAI 兼容的 /v1/chat/completions，支持文本和图片输入，也能在 Claude Code 里直接使用，并发不限。

快速开始

三步接入 GLM-5.3-Flash API

  1. 注册并充值：在 anyaigc.ai 注册账号，最低 $1 起充，余额对平台所有模型通用。
  2. 创建 API Key：在控制台创建令牌，复制以 sk- 开头的 Key，存到环境变量 ANYAIGC_API_KEY。
  3. 发起请求：请求 POST https://anyaigc.ai/v1/chat/completions，model 填 glm-5.3-flash，鉴权用 Authorization: Bearer。OpenAI SDK 把 base_url 改成 https://anyaigc.ai/v1 即可。

参数提示：GLM-5.3-Flash 思考始终开启，思考过程在 reasoning_content 字段，用 reasoning_effort（low / high / max）调整思考深度。图片用 image_url 内容块传入，支持公网 URL 和 Base64。多轮对话和工具调用时，要把完整的 assistant 消息原样放回下一次请求。

完整参数见 Chat Completions 接口文档，文档示例里的模型名换成对应的 GLM 模型 ID 即可。

FAQ

GLM-5.3-Flash API 常见问题

GLM-5.3-Flash API 多少钱？

AnyAIGC 上 glm-5.3-flash 按 token 计费：输入 $0.0607/百万 tokens，输出 $0.2025/百万 tokens，缓存命中 $0.0122/百万 tokens。智谱官方美元价为输入 $0.15、输出 $0.50、缓存命中 $0.03，AnyAIGC 约为官方价的 40.5%（约 4 折）。输出包含思考 tokens，实时价格以模型广场为准。

GLM-5.3-Flash 的模型 ID 是什么？上下文多大？

模型 ID 是 glm-5.3-flash。智谱官方公布的上下文窗口为 1M tokens，最大输出 128K tokens，通过 AnyAIGC 支持文本和图片输入。

GLM-5.3-Flash 和 GLM-5.3 有什么区别？

GLM-5.3-Flash 基于全新训练的基座：320B 总参数、18B 激活，混合稀疏注意力与线性注意力，是 GLM-5 系列首个原生多模态模型。官方称相比 GLM-5.3，注意力计算降低约 3 倍、KV cache 降低约 4.4 倍。GLM-5.3 是更强的旗舰，适合最难的编程任务，只支持文本；Flash 支持图片输入，单价约为 GLM-5.3 的十五分之一（输入 $0.0607 对 $0.9450）。

GLM-5.3-Flash 比 GLM-5.2 强吗？

官方称 GLM-5.3-Flash 整体超过 GLM-5.2，价格约为其十分之一。官方公布的对比：DeepSWE 63.4 对 46.2，Toolathlon Verified 78.4 对 59.9，AutomationBench 48.8 对 26.2，GDPval-AA v2 1773 对 1504。

GLM-5.3-Flash 支持图片输入吗？怎么传？

支持。在 messages[].content 数组里放 {"type": "image_url", "image_url": {"url": ...}} 内容块，url 可以是公网图片地址，也可以是 Base64 Data URL，多张图就放多个内容块。

可以在 Claude Code 里使用 GLM-5.3-Flash 吗？

可以。在 ~/.claude/settings.json 的 env 中设置 ANTHROPIC_BASE_URL 为 https://anyaigc.ai、ANTHROPIC_AUTH_TOKEN 为你的 API Key、ANTHROPIC_MODEL 为 glm-5.3-flash，然后运行 claude 即可。按 token 计费，没有订阅套餐的 5 小时额度窗口。

GLM-5.3-Flash 能关闭思考吗？

GLM-5.3-Flash 思考始终开启，官方不支持关闭。用 reasoning_effort 调整思考深度，可选 low、high、max，默认 max。分类、抽取这类简单任务用 low 可以减少输出 tokens。

GLM-5.3-Flash 是开源的吗？

是。智谱已在 Hugging Face 以 MIT 许可发布 GLM-5.3-Flash 权重（zai-org/GLM-5.3-Flash）。通过 AnyAIGC 调用 API 不需要自己部署，商用授权以智谱官方条款为准。
