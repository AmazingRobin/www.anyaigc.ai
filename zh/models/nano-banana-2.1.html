Nano Banana 2.1 API 常见问题

Nano Banana 2.1 API 多少钱？

AnyAIGC 上 Nano Banana 2.1 按张计费：1K 每张 ¥0.08、2K 每张 ¥0.12、4K 每张 ¥0.28。Google 官方价为 1K $0.0336、2K $0.0504、4K $0.113 每张。按成功提交计费，实时价格以模型广场为准。

Nano Banana 2.1 是什么？什么时候发布的？

Nano Banana 2.1（Gemini Nano Banana 2.1，模型名 gemini-nano-banana-2.1）是 Google 在 2026 年 10 月 6 日发布的图像生成与编辑模型，是 Nano Banana 2（Gemini 3.1 Flash Image）的升级版。Google 把它定位为 Nano Banana 系列的主力高效模型。

Nano Banana 2.1 和 Nano Banana 2 有什么区别？

2.1 在画质、文字渲染和多轮对话中的角色一致性上都有提升，修复了 1:4、4:1、1:8、8:1 等极端比例在 2K / 4K 下的拼接问题，单价也更低。2.1 不支持 512px（0.5K）档位，只支持 1K、2K、4K。接口完全相同，迁移只需把 model 换成 gemini-nano-banana-2.1。

Nano Banana 2.1 和 Nano Banana Pro 怎么选？

日常出图、批量生成和超宽比例选 2.1，单价更低（1K ¥0.08 / 张）。版式复杂、文字密集、需要更强推理和细节的商业物料选 Pro（1K/2K ¥0.22 / 张）。

支持哪些分辨率和宽高比？

imageConfig.imageSize 支持 1K、2K、4K，默认 1K，不支持 512。imageConfig.aspectRatio 支持 1:1、2:3、3:2、3:4、4:3、4:5、5:4、9:16、16:9、21:9、1:4、4:1、1:8、8:1 共 14 种。例如 16:9 的 2K 输出是 2752×1536，4K 是 5504×3072。

能上传几张参考图？可以开关思考吗？

一次请求最多 14 张参考图：最多 10 张物体图和 4 张角色图。思考用 thinkingConfig.thinkingLevel 控制，支持 minimal 和 high，不支持 thinkingBudget；也可以在模型名后加 -thinking 或 -nothinking。

并发有限制吗？国内能直接调用吗？

AnyAIGC 对 Nano Banana 2.1 不设并发限制，所有用户默认享有。接口地址是 https://anyaigc.ai，面向国内网络优化，通常无需额外代理，也不需要 Google 账号和海外信用卡；同一个 Key 还能调用平台上 300+ 其他模型。
