快速开始

用 Chat Completions 接入

  1. 注册并在控制台创建 API Key。
  2. 将 Base URL 设为 https://anyaigc.ai/v1。
  3. 设置 model 并发送 messages。
cURL · POST /v1/chat/completions
curl https://anyaigc.ai/v1/chat/completions \
  -H "Authorization: Bearer $ANYAIGC_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"qwen3.8-flash","messages":[{"role":"user","content":"用三句话解释什么是 MoE 模型。"}]}'
Python · OpenAI SDK
from openai import OpenAI
import os
client = OpenAI(api_key=os.environ["ANYAIGC_API_KEY"], base_url="https://anyaigc.ai/v1")
response = client.chat.completions.create(model="qwen3.8-flash", messages=[{"role":"user","content":"用三句话解释什么是 MoE 模型。"}])
print(response.choices[0].message.content)

FAQ

Qwen API FAQ

Qwen API 走什么接口？

对话模型统一使用 POST https://anyaigc.ai/v1/chat/completions，请求体填写 model 和 messages，并用 Authorization: Bearer 鉴权。

价格是多少？

按输入和输出 tokens 计费，当前价格见本页表格。实时价格以模型广场为准。

并发有限制吗？

本页 Qwen 对话模型并发不限，所有用户默认享有。

如何获取 API Key？

在AnyAIGC 注册页创建账户后，进入控制台创建 API Key。一个 Key 可以调用 300+ 模型。

支持图片和工具调用吗？

不同型号能力不同，请以模型广场的实时标签为准；接口入口保持一致。

AnyAIGC 能开发票吗？支持增值税专票吗？

能。按实际充值金额开具增值税普通发票和增值税专用发票。

企业可以对公转账和签合同吗？

可以。支持企业对公转账充值、签订服务合同，并提供专属客服和技术对接。

支持哪些支付方式？

支持微信支付、支付宝、USDT 和信用卡；企业还可以对公转账。

新用户有免费试用额度吗？

有。新用户注册即送 200 万 tokens 试用额度。

余额可以退款吗？

可以。未使用余额可退款，不收手续费。

会不会用低配模型冒充？我的数据安全吗？

请求走官方模型渠道，除法律法规要求外不做持久化存储，也不用于训练。
