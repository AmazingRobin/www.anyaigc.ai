关于模型

为长程任务设计的 1M 上下文旗舰

智谱把 GLM-5.2 定位为面向长任务时代的旗舰模型。官方称它提供真正可用的 1M 上下文，能装下项目级的工程上下文，长程任务执行更稳定，也更可靠地遵循工程规范。

上下文从 GLM-5.1 的 200K 扩展到 1M。架构上沿用 MoE 加 DSA 稀疏注意力，并引入 IndexShare：每 4 个稀疏注意力层共享一个索引器，官方称在 1M 上下文下每 token 计算量降低 2.9 倍。GLM-5.2 默认动态思考，也可以关闭，以 MIT 许可开源。

在 AnyAIGC 上，glm-5.2 走 OpenAI 兼容的 /v1/chat/completions，也能在 Claude Code 里直接使用，并发不限。新项目可以考虑同价的 GLM-5.3，它在同一基座上进一步提升了编程能力。

快速开始

三步接入 GLM-5.2 API

  1. 注册并充值：在 anyaigc.ai 注册账号，最低 $1 起充，余额对平台所有模型通用。
  2. 创建 API Key：在控制台创建令牌，复制以 sk- 开头的 Key，存到环境变量 ANYAIGC_API_KEY。
  3. 发起请求：请求 POST https://anyaigc.ai/v1/chat/completions，model 填 glm-5.2，鉴权用 Authorization: Bearer。OpenAI SDK 把 base_url 改成 https://anyaigc.ai/v1 即可。

参数提示：GLM-5.2 默认动态思考，思考过程（如有）在 reasoning_content 字段，可以用 reasoning_effort 调整思考深度。多轮对话和工具调用时，要把 API 返回的完整 assistant 消息（包括 reasoning_content 和 tool_calls）原样放回下一次请求。

完整参数见 Chat Completions 接口文档，文档示例里的模型名换成对应的 GLM 模型 ID 即可。

FAQ

GLM-5.2 API 常见问题

GLM-5.2 API 多少钱？

AnyAIGC 上 glm-5.2 按 token 计费：输入 $0.9450/百万 tokens，输出 $2.9700/百万 tokens，缓存命中 $0.2362/百万 tokens。智谱官方美元价为输入 $1.40、输出 $4.40、缓存命中 $0.26，AnyAIGC 的输入、输出约为官方价的 67.5%（约 7 折）。实时价格以模型广场为准。

GLM-5.2 的模型 ID 是什么？上下文多大？

模型 ID 是 glm-5.2。智谱官方公布的上下文窗口为 1M tokens，最大输出 128K tokens，只支持文本输入。

GLM-5.2 能关闭思考吗？

能。智谱官方说明 GLM-5.2 默认开启动态思考，由模型自行判断是否需要思考，也支持关闭思考；这是它和 GLM-5.3 的主要区别之一（GLM-5.3 思考始终开启）。在 AnyAIGC 上可以用 reasoning_effort 调整思考深度。

GLM-5.2 有什么特点？

官方把 GLM-5.2 定位为面向长任务时代的旗舰模型：提供真正可用的 1M 上下文，能装下项目级工程上下文；长程任务执行更稳定，更可靠地遵循工程规范，可以在单个任务里完成从需求到多端部署的完整开发链路。官方称 IndexShare 设计在 1M 上下文下把每 token 计算量降低 2.9 倍。

GLM-5.2 和 GLM-5.3 怎么选？

两者是同一个基座，在 AnyAIGC 输入、输出单价相同。GLM-5.3 在此基础上扩展了后训练，官方称编程能力提升 50%，缓存命中价也更低（$0.1758 对 $0.2362），新项目建议直接用 GLM-5.3；需要关闭思考、或已经在生产里调好 GLM-5.2 的业务，可以继续用 GLM-5.2。

可以在 Claude Code 里使用 GLM-5.2 吗？

可以。在 ~/.claude/settings.json 的 env 中设置 ANTHROPIC_BASE_URL 为 https://anyaigc.ai、ANTHROPIC_AUTH_TOKEN 为你的 API Key、ANTHROPIC_MODEL 为 glm-5.2，然后运行 claude 即可。按 token 计费，没有订阅套餐的 5 小时额度窗口。

GLM-5.2 是开源的吗？可以商用吗？

是。智谱以 MIT 许可在 Hugging Face（zai-org/GLM-5.2）和魔搭社区发布了 GLM-5.2 权重。通过 AnyAIGC 调用 API 不需要自己部署，商用授权以智谱官方条款为准。

并发和速率有限制吗？

AnyAIGC 对 glm-5.2 不设并发限制，所有用户默认享有，适合批量任务、CI 流水线和多 Agent 并行。按 token 计费，也没有订阅套餐那种按时间窗口重置的额度。
