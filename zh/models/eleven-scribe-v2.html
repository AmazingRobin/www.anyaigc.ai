Eleven Scribe v2：录音转写

Eleven Scribe v2 是 ElevenLabs 的语音转文字（STT）模型。官方模型文档称它是「上一代最先进的语音识别模型」，已由 scribe_v3 接替，针对 90+ 种语言的准确转写设计，并且仍然可用，不在官方的停用模型列表里。模型广场的说明是「上一代主力版本，支持 90+ 语言、词级时间戳、说话人分离、关键词提示与多声道分轨」。

官方文档列出的 v2 能力包括：词级时间戳、说话人分离、动态音频标注、关键词提示、实体检测。官方能力页写明单个文件最大 5 GB、最长 15 小时，多声道最多 5 个声道。这些是 ElevenLabs 官方文档列出的能力。

在 AnyAIGC 上，scribe_v2 走 POST /v1/audio/transcriptions，按音频秒数计费，价格和 Eleven Scribe v3 相同，并发不限。新项目可以先用同一段录音分别转写，再决定用哪个版本。

Eleven Scribe v2 API 接入教程

  1. 注册并充值：在 anyaigc.ai 注册账号，最低 $1 起充，余额对平台所有模型通用。
  2. 创建 API Key：在控制台创建令牌，复制以 sk- 开头的 Key，存到环境变量 ANYAIGC_API_KEY。
  3. 上传录音：请求 POST https://anyaigc.ai/v1/audio/transcriptions，用 multipart/form-data 提交 file（音频文件）和 model（填 scribe_v2），鉴权用 Authorization: Bearer，返回里的 text 就是转写文字。

参数提示：模型 ID 区分大小写，写成 scribe_v2；请求体是 multipart/form-data，file 是音频文件本身（不是文件名）；成功时返回 {"text": "..."}。

完整说明见 音频转文字接口文档。调用 Scribe 时，把 model 填成 scribe_v3 或 scribe_v2。

FAQ

Eleven Scribe v2 API 常见问题

Eleven Scribe v2 API 多少钱？

AnyAIGC 上 scribe_v2 按音频秒数计费：$0.0000450 / 秒，折合 $0.0027 / 分钟、$0.162 / 小时，约为 ElevenLabs 官方价（$0.20 / 小时）的 8.1 折。固定单价，没有订阅和月费，实时价格以模型广场为准。

Eleven Scribe v2 的模型 ID 是什么？和 ElevenLabs 是什么关系？

模型 ID 是 scribe_v2（区分大小写），和 ElevenLabs 官方的 model_id 一致。AnyAIGC 是独立的 API 服务商，提供 OpenAI 风格的 /v1/audio/transcriptions 调用方式，与 ElevenLabs 没有隶属关系。

Eleven Scribe v2 和其他 Eleven 型号怎么选？

Eleven 系列在 AnyAIGC 上分两类：语音合成（文字转语音）7 款，见 Eleven v4 等页面；语音转文字（录音转写）2 款，即 Eleven Scribe v3 和 Eleven Scribe v2。要把录音变成文字选 Scribe，要把文字变成语音选 v4、Multilingual v2 等合成模型。

怎么调用 Eleven Scribe v2 API？

请求 POST https://anyaigc.ai/v1/audio/transcriptions，用 multipart/form-data 提交 file（音频文件）和 model（填 scribe_v2），鉴权用 Authorization: Bearer。成功时返回 {"text": "..."}。完整说明见接口文档。
