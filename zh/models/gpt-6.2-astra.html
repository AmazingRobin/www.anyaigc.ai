GPT-6.2 Astra API 接入教程

  1. 注册并充值：在 anyaigc.ai 注册账号，余额对平台所有模型通用。
  2. 创建 API Key：在控制台创建令牌，复制以 sk- 开头的 Key，存到环境变量 ANYAIGC_API_KEY。
  3. 发起请求：向 https://anyaigc.ai/v1/chat/completions 或 https://anyaigc.ai/v1/responses 发送请求，model 填 gpt-6.2-astra，鉴权用 Authorization: Bearer。

建议工具调用使用 /v1/responses。普通对话和流式输出可以用 /v1/chat/completions；需要函数调用、计算机操作、网页搜索等工具时用 /v1/responses，推理强度写在 reasoning.effort 里。本页的函数调用示例走的就是 /v1/responses。

完整参数见 Chat Completions 接口文档 和 Responses 接口文档，字段含义与 OpenAI 官方 API 一致。

GPT-6.2 Astra 和 GPT-6 Astra 有什么区别？

OpenAI 称 GPT-6.2 Astra 是应对最棘手项目的新前沿模型。API 官方价比 GPT-6 Astra 更低：输入和输出 Token 单价低 20%（$8 / $40），缓存输入低 60%（$0.40）。按 OpenAI 公布的数据，它在 Agents’ Last Exam 上得分比 GPT-6 Astra 高 5.2 分，成本不到其三分之一；Terminal-Bench-Science 0.1 高 9 个百分点，成本同样不到三分之一；GDPval v2 高 6.2 个百分点，输出 Token 少 22%。AnyAIGC 上 gpt-6.2-astra 输入 $0.3971、输出 $1.9860，gpt-6-astra 输入 $0.4964、输出 $2.4810（每百万 tokens）。

GPT-6.2 Astra 和 GPT-6.2 Sol 怎么选？

用 Chat Completions 还是 Responses API？可以调用工具吗？
