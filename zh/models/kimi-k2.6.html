关于模型

通用的开源多模态 Agent 模型

Moonshot AI 把 Kimi K2.6 定位为开源原生多模态 Agent 模型。官方称它的长程代码编写更强、更稳定，指令遵循和自我纠错明显提升，支持文本、图片输入，支持思考和非思考两种模式，对话和 Agent 任务都能用。

架构上是 MoE，1T 总参数、32B 激活参数，上下文 256K，原生 INT4 量化。官方重点展示了四个方向：长程编程、从提示词或图片生成界面（Coding-Driven Design）、横向扩展到 300 个子 Agent 的 Agent Swarm，以及 7×24 运行的主动式 Agent。

快速开始

三步接入 Kimi K2.6 API

  1. 注册并充值：在 anyaigc.ai 注册账号，最低 $1 起充，余额对平台所有模型通用。
  2. 创建 API Key：在控制台创建令牌，复制以 sk- 开头的 Key，存到环境变量 ANYAIGC_API_KEY。
  3. 发起请求：请求 POST https://anyaigc.ai/v1/chat/completions，model 填 kimi-k2.6，鉴权用 Authorization: Bearer。OpenAI SDK 把 base_url 改成 https://anyaigc.ai/v1 即可。

参数提示：K2.6 默认开启思考，思考过程在 reasoning_content 字段。Moonshot 官方 API 用 thinking: {"type": "disabled"} 关闭思考（OpenAI SDK 写在 extra_body），非思考模式官方推荐 temperature=0.6。思考模式下多轮和工具调用时，要把完整的 assistant 消息原样放回下一次请求。

完整参数见 Chat Completions 接口文档，文档示例里的模型名换成对应的 Kimi 模型 ID 即可。

FAQ

Kimi K2.6 API 常见问题

Kimi K2.6 API 多少钱？

AnyAIGC 上 kimi-k2.6 按 token 计费：输入 $0.3847/百万 tokens，输出 $1.5980/百万 tokens，缓存命中 $0.0651/百万 tokens。Moonshot 官方美元价为输入 $0.95、输出 $4.00、缓存命中 $0.16，AnyAIGC 约为官方价的 40%（约 4 折）。实时价格以模型广场为准。

Kimi K2.6 的模型 ID 是什么？上下文多大？

模型 ID 是 kimi-k2.6。Moonshot 官方公布的上下文窗口为 262,144 tokens（256K），支持文本和图片输入。

Kimi K2.6 能关闭思考模式吗？

K2.6 支持思考和非思考（Instant）两种模式。Moonshot 官方 API 用 thinking: {"type": "disabled"} 关闭思考，OpenAI SDK 里写在 extra_body。官方推荐思考模式 temperature=1.0，非思考模式 temperature=0.6，top_p 都是 0.95。

Kimi K2.6 有什么特点？

官方把 K2.6 定位为开源原生多模态 Agent 模型，重点在四个方向：长程编程（Rust、Go、Python，前端、运维和性能优化）、从提示词或图片生成可上线的界面、Agent Swarm（横向扩展到 300 个子 Agent、4,000 个协同步骤），以及 7×24 后台运行的主动式 Agent。

Kimi K2.6 和 K2.7 Code 怎么选？

两者架构相同、在 AnyAIGC 输入和输出单价相同。K2.7 Code 是基于 K2.6 的编程强化版，编程基准更高、思考 tokens 更少，但只能思考模式；K2.6 可以关闭思考，更适合需要快速响应的对话、分类、抽取和通用 Agent。

可以在 Claude Code 里使用 Kimi K2.6 吗？

可以。在 ~/.claude/settings.json 的 env 中设置 ANTHROPIC_BASE_URL 为 https://anyaigc.ai、ANTHROPIC_AUTH_TOKEN 为你的 API Key、ANTHROPIC_MODEL 为 kimi-k2.6，然后运行 claude 即可。

Kimi K2.6 支持工具调用和图片输入吗？

支持。K2.6 支持多步工具调用、流式输出和图片输入。思考模式下多轮和工具调用时，需要把返回的完整 assistant 消息（含 reasoning_content 和 tool_calls）原样放回下一次请求。

并发和速率有限制吗？

AnyAIGC 对 kimi-k2.6 不设并发限制，所有用户默认享有，适合批量任务、CI 流水线和多 Agent 并行。Moonshot 官方平台按充值等级限制并发、RPM、TPM 和 TPD，通过 AnyAIGC 调用不受这些等级限制。

可以。AnyAIGC 面向国内网络优化，通常无需额外代理即可调用 https://anyaigc.ai，按美元价格计费，支持微信支付、支付宝、USDT 和信用卡，企业可对公转账并开具增值税发票。
