Python 流式
# pip install openai
import os
from openai import OpenAI

client = OpenAI(api_key=os.environ["ANYAIGC_API_KEY"], base_url="https://anyaigc.ai/v1")

stream = client.chat.completions.create(
    model="hy4",
    messages=[{"role": "user", "content": "用三句话介绍你自己，并说明你擅长的任务。"}],
    stream=True,
)
for chunk in stream:
    if chunk.choices and chunk.choices[0].delta.content:
        print(chunk.choices[0].delta.content, end="", flush=True)
print()

FAQ

Hy4 API 常见问题

Hy4 API 多少钱？比官方便宜多少？

按 token 计费，单位 USD/百万 tokens：输入 $0.5630（官方 $0.834）、输出 $1.6880（官方 $2.501）、缓存命中 $0.0283（官方 $0.042）。腾讯云官方挂牌价为输入 ¥6、输出 ¥18、缓存命中 ¥0.3，美元官方价按约 7.19 元/美元折算。AnyAIGC 三项都约为官方价的 67.5%，即约官方 6.75 折。实时价格以模型广场为准。

Hy4 和 Hy4 preview 有什么区别？

据腾讯混元官方发布页（2026-11-04），正式版首次引入视觉理解和电脑操作，强化了 Agent 与长程任务能力，并称在自建测试中幻觉率由 preview 的 15.76% 降到 5.45%。官方同时称 API 价格与 preview 相同。以上数据来自官方发布页，AnyAIGC 未独立复测。

Hy4 支持图片输入吗？

支持。官方称 Hy4 首次引入视觉理解。在 POST /v1/chat/completions 里用 image_url 内容块传入图片链接或 base64，输出为文本。AnyAIGC 文档目前没有给出图片尺寸与数量的限制，请以文档为准。

应该使用哪个 API 接口？

两种格式都支持：OpenAI 兼容的 POST https://anyaigc.ai/v1/chat/completions，以及 Anthropic 格式的 POST https://anyaigc.ai/v1/messages，鉴权都用 Authorization: Bearer <API Key>，model 填 hy4。OpenAI SDK 只需把 base_url 设为 https://anyaigc.ai/v1。

并发有限制吗？

AnyAIGC 的 Hy4 接入并发不限，所有用户默认享有。长文本和 Agent 类请求耗时更长，请在应用里设置合理的超时与重试。

生成内容可以商用吗？

模型与输出的使用条款以腾讯混元官方条款为准。AnyAIGC 是独立 API 服务商，与腾讯无隶属关系。

AnyAIGC 能开发票吗？支持增值税专票吗？

支持。可按实际充值金额开具增值税普通发票和增值税专用发票，联系企业客服办理即可。

企业可以对公转账和签合同吗？

可以。支持企业对公转账充值，可签订服务合同，并提供专属客服与技术对接。

支持哪些支付方式？

支持微信支付、支付宝、USDT 和信用卡充值，企业还可以对公转账，并开具增值税普通发票或专用发票。余额按美元计价，对平台所有模型通用。

新用户有免费试用额度吗？

有。新用户注册后赠送 200 万 tokens 的试用额度，可以先测试效果再决定是否充值。最低 1 美元起充。

余额可以退款吗？

可以。未使用的余额可以申请退款，不收取手续费。具体流程请联系客服。

会不会用低配模型冒充？我的数据安全吗？

请求走官方模型渠道，不用低配或逆向模型冒充。除法律法规要求外，我们不会对你的输入输出内容做持久化存储，也不会用于训练模型；控制台可以查看每次调用的 tokens 与扣费明细。
