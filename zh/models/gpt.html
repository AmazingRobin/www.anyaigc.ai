按任务选型号

不确定用哪个？按手上的任务挑一个起步，之后随时切换。下面的定位来自 OpenAI 对各档模型的说明。

  • 01 · 最难的任务

    最难的推理、编码与专业工作 → GPT-6 Astra

    OpenAI 称 Astra 是智能水平最高的一档，面向要求最高的推理、编码和专业工作。输入 $0.4964 / 百万 tokens。

  • 02 · 主力

    日常编码与 Agent → GPT-6.1 Sol

    OpenAI 称它在智能体编程、计算机使用和专业工作上接近 Astra，标准价只有 Astra 的五分之一，适合当默认模型。

  • 03 · 批量

    分类、抽取、摘要等高频任务 → GPT-6 Luna

    OpenAI 称 Luna 速度最快、性价比最高，适合范围明确的高频自动化。输入 $0.0135 / 百万 tokens。

  • 04 · Codex

    Codex 编程 → GPT-6.1 Sol + GPT-6 Astra

    日常改代码用 gpt-6.1-sol，跨多文件的难题换 gpt-6-astra。Codex 走 Responses API，配置见下方 Codex 版块。

  • 05 · 高准确率

    准确性要求最高的研究 → GPT-5.5 Pro

    OpenAI 称它用更多算力深入思考，为极端复杂、追求极高准确率的问题设计。仅支持 /v1/responses，单价较高，建议只用在关键请求上。

  • 06 · 均衡

    沿用 GPT-5.x 的日常工作 → GPT-5.6 Terra

    OpenAI 称 Terra 是适用于日常工作的均衡模型，性能与 GPT-5.5 相当且成本更低，适合已有 GPT-5.x 提示词的项目。

获取 API Key 在模型广场查看

OpenAI 原生接口，全部支持

请求格式与 OpenAI 官方 API 一致，官方 SDK 和现有代码改个 base_url 就能迁移。

  • Chat Completions

    对话接口

    接口地址 /v1/chat/completions，messages 格式与 OpenAI 一致，现有代码和框架直接可用（GPT-5.5 Pro 除外）。

  • Responses API

    Responses 与工具调用

    接口地址 /v1/responses，支持函数调用（function calling），Codex 也走这个接口。

  • Structured Outputs

    结构化输出

    用 JSON Schema 约束返回格式，结果可以直接解析入库，不用再写正则兜底。

  • reasoning_effort

    推理强度

    Chat Completions 用 reasoning_effort，Responses 用 reasoning.effort。GPT-6 系列最高支持 max；GPT-6 Sol 和 GPT-6 Luna 还支持 none，GPT-6.1 Sol 和 GPT-6 Astra 不支持 none。

  • Image input

    图片输入

    全部型号支持文本和图片输入、文本输出，可以直接传截图、图表和扫描件。

  • Streaming

    流式输出

    设置 stream: true 边生成边返回，适合聊天界面和长输出。GPT-5.5 Pro 不支持流式输出。

GPT-6 系列的工具调用请走 /v1/responses。按 OpenAI 的说明，gpt-6.1-sol 在 Chat Completions 上不支持工具调用，gpt-6-sol 和 gpt-6-luna 只在 reasoning_effort 为 none 时支持函数调用，gpt-6-astra 未写明。普通对话和流式输出可以继续用 /v1/chat/completions；gpt-5.5-pro 只支持 /v1/responses。

三步接入 GPT API

  1. 注册并充值：在 anyaigc.ai 注册账号，余额对平台所有模型通用。
  2. 创建 API Key：在控制台创建令牌，复制以 sk- 开头的 Key，存到环境变量 ANYAIGC_API_KEY。
  3. 发起请求：把 OpenAI SDK 的 base_url 设为 https://anyaigc.ai/v1，model 填本页任一型号 ID，鉴权用 Authorization: Bearer。

完整参数见 Chat Completions 接口文档 和 Responses 接口文档，字段含义与 OpenAI 官方 API 一致。

GPT API 常见问题

GPT API 怎么收费？多少钱？

AnyAIGC 上的 GPT 模型都按 token 计费，没有订阅和月费，单位为美元每 100 万 tokens。当前三档：GPT-6 Astra 输入 $0.4964、输出 $2.4810；GPT-6.1 Sol 输入 $0.0993、输出 $0.4964；GPT-6 Luna 输入 $0.0135、输出 $0.0675。多数型号约为 OpenAI 官方价的 0.5 折（节省 95%），GPT-6 Luna 和 GPT-5.6 Luna 约 1.3 折，GPT-5.5 Pro 约 5.9 折。全部 9 个型号的价格见本页价格表，实时价格以 AnyAIGC 模型广场为准。

国内可以直接调用 OpenAI API 吗？

可以。AnyAIGC 面向国内网络优化，通常无需额外代理即可调用 https://anyaigc.ai/v1，按美元价格计费，支持微信支付和支付宝，企业可对公转账并开具增值税发票。

如何获取 GPT API Key？

在 anyaigc.ai 注册并充值，进入控制台创建令牌，复制以 sk- 开头的 Key 即可。同一个 Key 可以调用本页全部 9 个 GPT 型号，以及平台上 300+ 其他模型，余额通用。

兼容 OpenAI 官方 SDK 吗？

兼容。用 OpenAI 官方 SDK 时把 base_url 改为 https://anyaigc.ai/v1、api_key 换成 AnyAIGC 的 Key，现有代码基本不用改。支持 /v1/chat/completions 和 /v1/responses 两个接口，鉴权使用 Authorization: Bearer，字段含义与 OpenAI 官方 API 一致。

GPT-6 Astra、Sol、Luna 有什么区别？怎么选？

这是 OpenAI GPT-6 的三档能力层级。按 OpenAI 的说明，Astra 智能水平最高，面向要求最高的推理、编码和专业工作；Sol 在速度、成本和智能之间取得平衡，当前版本是 GPT-6.1 Sol，OpenAI 称它接近 Astra 而标准价只有 Astra 的五分之一；Luna 速度最快、性价比最高，适合范围明确的高频任务。多数编码和 Agent 任务建议先用 GPT-6.1 Sol，最难的任务换 GPT-6 Astra，大批量简单任务用 GPT-6 Luna。

GPT-5.6 Terra 是什么？

Terra 是 GPT-5.6 代的均衡档，OpenAI 称它是适用于日常工作的均衡模型，性能与 GPT-5.5 相当且成本更低。GPT-5.6 分为 Sol、Terra、Luna 三档；GPT-6 目前只有 Astra、Sol、Luna，尚未发布 GPT-6 Terra。AnyAIGC 上 gpt-5.6-terra 输入 $0.0993、输出 $0.5957（每 100 万 tokens）。

GPT-6.1 Sol 和 GPT-6 Sol 有什么区别？

OpenAI 称 GPT-6.1 Sol 是 GPT-6 Sol 的升级版，输入和输出官方单价不变（$2 / $10），缓存输入从 $0.20 降到 $0.10，按 OpenAI 公布的数据，它在 DeepSWE v1.1、OSWorld 2.0 等基准上都高于 GPT-6 Sol。GPT-6.1 Sol 不支持 none 推理强度，在 Chat Completions 上不支持工具调用。AnyAIGC 上两者都是输入 $0.0993、输出 $0.4964，缓存输入分别为 $0.0050 和 $0.0099。新项目建议用 GPT-6.1 Sol，已有集成可以继续用 gpt-6-sol。

旧版 GPT 模型还能用吗？

GPT-6 Sol、GPT-5.6 Sol、GPT-5.6 Terra、GPT-5.6 Luna、GPT-5.5 和 GPT-5.5 Pro 都已有更新的型号，但 OpenAI 尚未公布它们在 API 中的停用时间，目前在 AnyAIGC 都可正常调用。新项目建议使用 GPT-6.1 Sol、GPT-6 Astra 或 GPT-6 Luna。

可以在 Codex 里使用 GPT 模型吗？

可以。运行 curl -fsSL https://www.anyaigc.ai/install.sh | bash -s codex 一键安装（Windows 用 irm https://www.anyaigc.ai/install.ps1 | iex），脚本默认写入 gpt-5.5，装好后把 ~/.codex/config.toml 里的 model 改为 gpt-6.1-sol 或 gpt-6-astra。也可以手动配置：在 ~/.codex/config.toml 里把 base_url 设为 https://anyaigc.ai/v1、wire_api 设为 responses，并在 ~/.codex/auth.json 写入 OPENAI_API_KEY。

并发有限制吗？

AnyAIGC 对 GPT 全系型号不设并发限制，所有用户默认享有，适合批量任务和多 Agent 并行。

AnyAIGC 能开发票吗？支持增值税专票吗？

能。AnyAIGC 可以按实际充值金额开具增值税普通发票和增值税专用发票，开票信息提交给客服即可。

企业可以对公转账和签合同吗？

可以。支持企业对公转账充值，也可以签订服务合同，并提供专属客服和技术对接。企业采购请联系 AnyAIGC 客服。
