关于模型

V4 预览版的轻量模型

DeepSeek 在 2026 年 4 月发布 V4 预览版，同时推出 V4 Pro 和 V4 Flash。V4 Flash 是其中的轻量型号：284B 总参数、13B 激活的 MoE，与 V4 Pro 同架构，上下文 1M tokens，以 MIT 许可开放权重。

9 月 10 日 DeepSeek 发布 V4.1 Flash，同时下线 V4 Flash。出于兼容考虑，官方 API 暂时把 deepseek-v4-flash 的请求路由到 V4.1 Flash，并按 Flash 价格计费。

如果你的代码里还写着 deepseek-v4-flash，在 AnyAIGC 上可以继续调用；新项目建议把模型名换成 deepseek-v4.1-flash，两者单价相同，V4.1 Flash 还支持图片输入。

FAQ

DeepSeek V4 Flash API 常见问题

DeepSeek V4 Flash 停用了吗？

DeepSeek 官方已在 2026 年 9 月 10 日发布 V4.1 Flash 时下线 V4 Flash。出于兼容考虑，官方 API 仍接受 deepseek-v4-flash 这个模型名，请求由 V4.1 Flash 处理，按 Flash 价格计费。新项目建议直接使用 deepseek-v4.1-flash，在 AnyAIGC 上两者单价相同。

DeepSeek V4 Flash API 多少钱？

AnyAIGC 上 deepseek-v4-flash 按 token 计费：输入 $0.1215/百万 tokens，输出 $0.4860/百万 tokens，缓存命中 $0.0024/百万 tokens，与 V4.1 Flash 相同。DeepSeek 官方对旧模型名按 Flash 价格计费，闲时为输入 $0.15、输出 $0.60、缓存命中 $0.003，高峰时段翻倍。实时价格以模型广场为准。

AnyAIGC 也分高峰和闲时价格吗？

不分。DeepSeek 官方 API 采用峰谷定价，北京时间工作日 9:00–12:00、14:00–18:00为高峰时段，高峰价是闲时价的 2 倍。AnyAIGC 上 deepseek-v4-flash 全天按模型广场的同一单价计费，约为官方高峰价的 4 折，实时价格以模型广场为准。

从 V4 Flash 迁移到 V4.1 Flash 要改什么？

把请求体里的 model 从 deepseek-v4-flash 改成 deepseek-v4.1-flash 即可，接口地址、鉴权和参数都不用变。V4.1 Flash 额外支持图片输入，官方称它在基准测试中超越了 V4 Pro。

V4 Flash 的参数和上下文是多少？

DeepSeek 官方公布 V4 Flash 为 284B 总参数、13B 激活的 MoE，与 V4 Pro 同架构，上下文 1M tokens，只支持文本输入，以 MIT 许可开放权重。

可以在 Claude Code 里使用 DeepSeek V4 Flash 吗？

可以。AnyAIGC 上的 DeepSeek 模型同时支持 OpenAI 和 Anthropic 两种接口格式。在 ~/.claude/settings.json 的 env 中设置 ANTHROPIC_BASE_URL 为 https://anyaigc.ai、ANTHROPIC_AUTH_TOKEN 为你的 API Key、ANTHROPIC_MODEL 为 deepseek-v4-flash，然后运行 claude 即可，按 token 计费。

并发和速率有限制吗？

AnyAIGC 对 deepseek-v4-flash 不设并发限制，所有用户默认享有，适合批量任务、CI 流水线和多 Agent 并行。

国内可以直接调用 DeepSeek V4 Flash API 吗？

可以。AnyAIGC 面向国内网络优化，通常无需额外代理即可调用 https://anyaigc.ai，按美元价格计费，支持微信支付、支付宝、USDT 和信用卡，企业可对公转账并开具增值税发票。
