GPT-5.5 Pro API 常见问题

GPT-5.5 Pro API 多少钱？

AnyAIGC 上 gpt-5.5-pro 按 token 计费：输入 $17.8200/百万 tokens，输出 $106.9200/百万 tokens。OpenAI 官方价为输入 $30.00、输出 $180.00，AnyAIGC 约为官方价的 59.4%（约 5.9 折）。按 OpenAI 的说明，GPT-5.5 Pro 没有缓存输入折扣，重复的输入也按输入价计费。

GPT-5.5 Pro 的模型 ID 是什么？

模型 ID 是 gpt-5.5-pro，在请求体的 model 字段里填写即可。OpenAI 还提供带日期的快照 gpt-5.5-pro-2026-04-23。

GPT-5.5 Pro 和 GPT-5.5 有什么区别？

OpenAI 称 GPT-5.5 Pro 是用更多算力深入思考的 GPT-5.5 版本，面向极端复杂、对准确率要求极高的问题。按 OpenAI 公布的数据，Pro 在 BrowseComp 上得分 90.1%，标准版为 84.4%；但在 GDPval 上标准版 84.9% 高于 Pro 的 82.3%。Pro 只支持 Responses API、不支持流式输出、没有缓存折扣，推理强度为 medium、high（默认）、xhigh。在 AnyAIGC 上，GPT-5.5 输入 $0.2482、输出 $1.4890，Pro 输入 $17.8200、输出 $106.9200（每百万 tokens）。大多数任务先用标准版，答错代价高的难题再用 Pro。

GPT-5.5 Pro 很贵，怎么控制成本？

先用 high 推理强度，只在必要时用 xhigh，推理 tokens 按输出价计费；输入只放必要的上下文，因为 Pro 没有缓存折扣；用 max_output_tokens 限制单次输出；在控制台给调用 Pro 的 API Key 设置额度上限；常规问题交给 GPT-5.5 或 GPT-6.1 Sol，难题再升级到 Pro。

能用 Chat Completions 调用吗？支持流式输出吗？

不能。按 OpenAI 的说明，gpt-5.5-pro 只支持 Responses API（含 Batch），不支持 /v1/chat/completions，也不支持流式输出。请调用 https://anyaigc.ai/v1/responses，推理强度写在 reasoning.effort 里。

请求为什么很慢？怎么避免超时？

Pro 会花更多算力推理，OpenAI 说明部分请求要几分钟才能完成。建议把客户端超时调到 10 分钟以上；更稳妥的做法是按 OpenAI 的建议使用后台模式：请求里加 background: true，拿到任务 id 后用 responses.retrieve 轮询，直到状态不再是 queued 或 in_progress。

可以在 Codex 里使用 GPT-5.5 Pro 吗？

可以配置，但不建议作为默认模型，因为它响应慢、单价高。运行 curl -fsSL https://www.anyaigc.ai/install.sh | bash -s codex 一键安装（Windows 用 irm https://www.anyaigc.ai/install.ps1 | iex），然后在 ~/.codex/config.toml 里加一个 [profiles.pro]，把 model 设为 gpt-5.5-pro。平时用默认模型，遇到难题时运行 codex --profile pro。

GPT-5.5 Pro 停用了吗？还能用多久？

没有停用。OpenAI 已推出更新的 GPT-5.6 和 GPT-6 系列，但 OpenAI 尚未公布 gpt-5.5-pro API 的停用时间，目前在 AnyAIGC 上仍可正常调用。对于已弃用的旧 Pro 模型，OpenAI 弃用页面给出的替代是 GPT-5.6 Sol 的 pro 模式（reasoning.mode: pro）。新项目建议先评估 GPT-6 Astra 或 GPT-5.6 Sol。
