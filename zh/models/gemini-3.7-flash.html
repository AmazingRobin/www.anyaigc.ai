  1. 注册并充值：在 anyaigc.ai 注册账号，余额对平台所有模型通用。

FAQ

Gemini 3.7 Flash API 常见问题

Gemini 3.7 Flash API 多少钱？

AnyAIGC 上 gemini-3.7-flash 按 token 计费：输入 $0.0744/百万 tokens，输出 $0.3722/百万 tokens，缓存命中 $0.0074/百万 tokens。Google 发布时公布的官方优惠价为输入 $0.75、输出 $3.75（有效期至 2026 年 12 月 31 日，之后为 $1.50 / $7.50），AnyAIGC 约为官方优惠价的 10%（约 1 折）。Google 没有公布 3.7 Flash 的缓存价格。

Gemini 3.7 Flash 停用了吗？还能调用吗？

Google 在 2026 年 10 月 8 日的更新日志中宣布 gemini-3.7-flash 已弃用、由 gemini-3.8-flash 取代，它在 Google AI Studio 中不能再选择，Google Gemini API 中对 gemini-3.7-flash 的请求会自动路由到 gemini-3.8-flash。Vertex AI 上的停用日期为 2027 年 1 月 28 日。在 AnyAIGC 上，模型名 gemini-3.7-flash 仍可以正常调用，已有代码不需要修改；新项目建议直接使用 gemini-3.8-flash。

Gemini 3.7 Flash 和 Gemini 3.8 Flash 有什么区别？

两者的上下文（1,048,576 tokens）、最大输出（65,536 tokens）、输入模态和思考级别相同。Google 称 3.8 Flash 是其最智能的 Flash 模型，在软件工程、Agent 任务等方面相比 3.7 Flash 有明显提升。在 AnyAIGC 上两者价格相同，都是输入 $0.0744、输出 $0.3722（每百万 tokens），所以迁移到 3.8 Flash 不会增加单价。

上下文窗口和最大输出是多少？

Google 公布的输入上限为 1,048,576 tokens，输出上限为 65,536 tokens。输入支持文本、图片、视频、音频和 PDF，输出为文本。

用原生 Gemini 接口还是 OpenAI 兼容接口？

两种都可以。原生接口是 POST https://anyaigc.ai/v1beta/models/gemini-3.7-flash:generateContent，请求体和 Google Gemini API 一致。OpenAI 兼容接口是 POST https://anyaigc.ai/v1/chat/completions，OpenAI 官方 SDK 把 base_url 改成 https://anyaigc.ai/v1 即可。两种接口都用 Authorization: Bearer 鉴权。

怎么设置思考级别？

Gemini 3.7 Flash 支持 low、medium、high 三档思考级别，默认 medium。原生接口写在 generationConfig.thinkingConfig.thinkingLevel。Google 说明 minimal 不受支持，传入会报错。

并发和速率有限制吗？

AnyAIGC 对 gemini-3.7-flash 不设并发限制，所有用户默认享有，适合批量任务和高并发业务。

国内可以直接调用 Gemini 3.7 Flash API 吗？

可以。AnyAIGC 面向国内网络优化，通常无需额外代理即可调用 https://anyaigc.ai，按美元价格计费，支持微信支付和支付宝，企业可对公转账并开具增值税发票。

能。AnyAIGC 可以按实际充值金额开具增值税普通发票和增值税专用发票，开票信息提交给客服即可。
