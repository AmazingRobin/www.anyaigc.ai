三步接入 GPT-5.6 Sol API

  1. 注册并充值：在 anyaigc.ai 注册账号，余额对平台所有模型通用。
  2. 创建 API Key：在控制台创建令牌，复制以 sk- 开头的 Key，存到环境变量 ANYAIGC_API_KEY。
  3. 发起请求：向 https://anyaigc.ai/v1/chat/completions 或 https://anyaigc.ai/v1/responses 发送请求，model 填 gpt-5.6-sol，鉴权用 Authorization: Bearer。

两个接口都能调用函数工具。按 OpenAI 的说明，gpt-5.6-sol 支持函数调用（function calling）和结构化输出，在 /v1/chat/completions 上也能用 tools 参数。网页搜索、计算机使用、托管 shell、MCP 等内置工具和多智能体（beta）属于 Responses API 的功能，需要时改用 /v1/responses，推理强度写在 reasoning.effort 里。

完整参数见 Chat Completions 接口文档 和 Responses 接口文档，字段含义与 OpenAI 官方 API 一致。

GPT-5.6 Sol API 常见问题

GPT-5.6 Sol API 多少钱？

AnyAIGC 上 gpt-5.6-sol 按 token 计费：输入 $0.2482/百万 tokens，输出 $1.4890/百万 tokens，缓存输入 $0.0248/百万 tokens。OpenAI 官方当前是推广价：输入 $4.00、输出 $20.00、缓存输入 $0.40（官方称推广价至少持续到 2026 年 11 月 21 日，发布时原价为输入 $5、输出 $30），AnyAIGC 约为该推广价的 6.2%（约 0.6 折）。单次请求输入超过 272K tokens 时，整次请求的输入按 2 倍、输出按 1.5 倍计费。

GPT-5.6 Sol 的模型 ID 是什么？

模型 ID 是 gpt-5.6-sol，在请求体的 model 字段里填写即可。按 OpenAI 的说明，别名 gpt-5.6 也指向 GPT-5.6 Sol；OpenAI 没有为它发布带日期的快照版本。

GPT-5.6 Sol 和 GPT-6.1 Sol 怎么选？

GPT-6.1 Sol 是更新的一代，OpenAI 官方标准价为输入 $2、输出 $10，低于 GPT-5.6 Sol 的推广价 $4 / $20；在 AnyAIGC 上 GPT-6.1 Sol 输入 $0.0993、输出 $0.4964，GPT-5.6 Sol 输入 $0.2482、输出 $1.4890（每百万 tokens）。新项目建议直接用 GPT-6.1 Sol。以下情况可以继续用 GPT-5.6 Sol：提示词和评测已经按 GPT-5.6 调好、需要 none 推理强度（GPT-6.1 Sol 不支持）、需要在 Chat Completions 上调用工具（GPT-6.1 Sol 在 Chat Completions 上不支持工具调用）。

GPT-5.6 Sol 还能用多久？停用了吗？

没有停用。OpenAI 已推出更新的 GPT-6 Sol 和 GPT-6.1 Sol，但尚未公布 GPT-5.6 Sol 的停用时间，目前在 API 中仍可正常调用，AnyAIGC 上也照常提供。新项目建议使用 GPT-6.1 Sol。

用 Chat Completions 还是 Responses API？可以调用工具吗？

两个接口都能用。按 OpenAI 的说明，gpt-5.6-sol 支持函数调用（function calling）、结构化输出和流式输出，在 https://anyaigc.ai/v1/chat/completions 上也可以调用函数工具。网页搜索、计算机使用、托管 shell、MCP 等内置工具以及多智能体（beta）属于 Responses API 的功能，需要时请用 https://anyaigc.ai/v1/responses，推理强度写在 reasoning.effort 里。

可以在 Codex 里使用 GPT-5.6 Sol 吗？

可以。运行 curl -fsSL https://www.anyaigc.ai/install.sh | bash -s codex 一键安装（Windows 用 irm https://www.anyaigc.ai/install.ps1 | iex），脚本默认写入 gpt-5.5，装好后把 ~/.codex/config.toml 里的 model 改为 gpt-5.6-sol。也可以手动配置：在 ~/.codex/config.toml 里把 base_url 设为 https://anyaigc.ai/v1、wire_api 设为 responses、model 设为 gpt-5.6-sol，并在 ~/.codex/auth.json 写入 OPENAI_API_KEY。

并发和速率有限制吗？

AnyAIGC 对 gpt-5.6-sol 不设并发限制，所有用户默认享有，适合批量任务和多 Agent 并行。
