Seedream 5.5 是什么

Seedream 5.5 是字节跳动 Seed 团队的多模态图像生成模型，官方定位为「创造力与精确执行能力共同提升的多模态图像生成模型」。它支持文生图、单图生图和多参考图生图，并进一步增强了多轮编辑的一致性、原生 RGBA 图片生成和图层拆分能力。

Seedream 5.5 能做什么

下面四项来自字节跳动 Seed 官方页面和火山方舟文档。

  • 多轮编辑保持一致

    连续多轮修改同一张图时，只改你要求的区域；官方页面写明支持非编辑区域的像素级保持。

  • 原生 RGBA 透明图

    原生支持透明与半透明背景，文字或参考图都能生成带透明通道的 RGBA 图片，不用再手动抠图。

  • 图层拆分

    把一张图拆成最多 1 张底图和 99 个图层，分别替换、调整位置或重新排版；底图和每个图层逐张计费。

  • 规整文字的富文本 OCR

    对拆分出的规整文字图层，返回文字内容、位置和近似的视觉样式；艺术字、手写体等非规整文字不返回。

  1. 注册 AnyAIGC，新用户送 200 万 tokens 试用额度，最低 $1 起充。

请求头用 Authorization: Bearer <API Key>。返回体是 {"created": ..., "data": [{"url": ...}]}，response_format 填 b64_json 时返回 base64。watermark 默认为 true，需要无水印图请显式传 false。字段说明见 AnyAIGC Seedream 接口文档。

Seedream 5.5 API 常见问题

Seedream 5.5 API 多少钱？

AnyAIGC 上 Seedream 5.5（doubao-seedream-5-5-261028）按单张输出图片的像素分档计费：1K / 1.5K（≤ 2,601,123 像素）¥0.15 / 张（$0.0229），2K（2,601,124 ~ 4,624,220 像素）¥0.27 / 张（$0.0402），不传 size 默认按 2K。输入图片（每张参考图，或待拆分的原图）¥0.06 / 张（$0.00918）。图层拆分时，底图和每个图层逐张计费。按成功生成计费，实时价格以模型广场为准。

Seedream 5.5 是什么？

Seedream 5.5 是字节跳动 Seed 团队的多模态图像生成模型，官方定位是「创造力与精确执行能力共同提升的多模态图像生成模型」。它支持文生图、单图生图和多参考图生图，并进一步增强了多轮编辑的一致性、原生 RGBA 图片生成和图层拆分能力。

支持哪些分辨率？能出 4K 吗？

不能。按火山方舟文档，5.5 生成图片时 size 支持 1K、1.5K、2K（默认 2K），也可以直接写宽x高的像素尺寸，总像素范围 1280x720（921,600）到 4,624,220，宽高比范围 1:16 到 16:1。需要 4K 请用 Seedream 5.0 lite 或 4.5。

能上传几张参考图？支持组图吗？

image 最多传 10 张参考图，用于改图和多图融合，每张参考图按输入图片计费。5.5 一次只返回 1 张图，不支持组图、联网搜索和流式输出；需要组图请用 5.0 lite、4.5 或 4.0。

图层拆分和透明图（RGBA）能做什么？

图层拆分可以把一张图拆成最多 1 张底图和 99 个图层，对规整文字图层还能返回文字内容、位置和近似的视觉样式（富文本 OCR）；艺术字、手写体等非规整文字不返回。5.5 还原生支持透明与半透明背景，可以直接生成 RGBA 图片。这些能力的请求参数以官方文档和 AnyAIGC 接口文档为准，接入前可以联系客服确认。

5.5 和 5.0 Pro 怎么选？

5.5 起步价更低（¥0.15 / 张起，5.0 Pro 为 ¥0.30 / 张起），图层最多 99 个，也支持文字直接生成 RGBA 图；5.0 Pro 图层最多 16 个，不支持文生 RGBA 图。两者都最高 2K、参考图最多 10 张、不支持组图。5.0 Pro 的详细能力见 Seedream 5.0 Pro。

AnyAIGC 对 Seedream 5.5 不设并发限制，所有用户默认享有。接口地址是 https://anyaigc.ai，国内网络可以直接调用，不需要火山引擎账号和实名认证；同一个 Key 还能调用平台上 300+ 其他模型。
