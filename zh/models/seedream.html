快速接入 Seedream API

  1. 注册 AnyAIGC，新用户送 200 万 tokens 试用额度，最低 $1 起充。
  2. 在控制台创建 API Key，保存到环境变量 ANYAIGC_API_KEY。
  3. 向 POST https://anyaigc.ai/v1/images/generations 发请求（OpenAI 兼容格式），model 填 doubao-seedream-5-0-pro-260628。

换型号只改 model：doubao-seedream-5-0-pro-260628、doubao-seedream-5-0-260128、doubao-seedream-4-5-251128 或 doubao-seedream-4-0-250828，请求和返回格式相同。

请求头用 Authorization: Bearer <API Key>。返回体是 {"created": ..., "data": [{"url": ...}]}，response_format 填 b64_json 时返回 base64。watermark 默认为 true，需要无水印图请显式传 false。字段说明见 AnyAIGC Seedream 接口文档。

Seedream API 常见问题

Seedream API 多少钱？

AnyAIGC 上 Seedream 全系固定单价：5.0 Pro ¥0.30 / 张起，5.0 lite ¥0.15 / 张起，4.5 ¥0.17 / 张起，4.0 ¥0.14 / 张起，3.0 ¥0.07 / 次。不同分辨率单价不同，实时价格以模型广场为准。

Seedream 是什么？和豆包、即梦是什么关系？

Seedream 是字节跳动 Seed 团队的图像生成模型系列，在火山引擎上以「豆包 Seedream」（doubao-seedream）的名字提供 API，即梦等字节产品里的生图能力也基于它。AnyAIGC 提供的是 Seedream 官方模型的 API 调用。

5.0 Pro、5.0 lite、4.5、4.0 有什么区别？

5.0 Pro 是旗舰，擅长信息图、精准编辑和多语种，最高 2K，不支持组图。5.0 lite 是轻量版，带联网检索，最高 4K。4.5 强在海报排版和保持原图细节。4.0 是第一个把生成和编辑合在一起的版本。5.0 lite、4.5、4.0 都支持组图和最多 14 张参考图。

支持哪些接口？可以改图吗？

全系走 OpenAI 兼容的 POST /v1/images/generations，换型号只改 model。改图、多图融合时在 image 里传图片 URL 数组；组图用 sequential_image_generation: "auto"。字段说明见 AnyAIGC 接口文档。

并发有限制吗？国内能直接调用吗？

AnyAIGC 对 Seedream 全系 不设并发限制，所有用户默认享有。接口地址是 https://anyaigc.ai，国内网络可以直接调用，不需要火山引擎账号和实名认证；同一个 Key 还能调用平台上 300+ 其他模型。

AnyAIGC 能开发票吗？支持增值税专票吗？

能。AnyAIGC 可以按实际充值金额开具增值税普通发票和增值税专用发票，开票信息提交给客服即可。

企业可以对公转账和签合同吗？

可以。支持企业对公转账充值，也可以签订服务合同，并提供专属客服和技术对接。企业采购请联系 AnyAIGC 客服。

支持哪些支付方式？

支持微信支付、支付宝、USDT 和信用卡充值，企业还可以对公转账，并开具增值税普通发票或专用发票。余额按美元计价，对平台所有模型通用。

余额可以退款吗？

可以。未使用的余额可以申请退款，不收取手续费。具体流程请联系客服。

会不会用低配模型冒充？我的数据安全吗？

请求走官方模型渠道，不用低配或逆向模型冒充。除法律法规要求外，我们不会对你的输入输出内容做持久化存储，也不会用于训练模型；控制台可以查看每次调用的 tokens 与扣费明细。

生成的图片可以商用吗？能去掉水印吗？

图片的使用权和内容政策以字节跳动 / 火山引擎官方条款为准。请求里把 watermark 设为 false 就不会在画面右下角加「AI 生成」水印。AnyAIGC 只提供 API 调用通道，不额外限制你对生成结果的使用；涉及人物肖像、品牌商标等内容时，请自行确认授权。
