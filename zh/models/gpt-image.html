三步接入 GPT Image API

  1. 注册 AnyAIGC，新用户送 200 万 tokens 试用额度，最低 $1 起充。
  2. 在控制台创建 API Key，保存到环境变量 ANYAIGC_API_KEY。
  3. 向 https://anyaigc.ai/v1/images/generations 发请求，model 填 gpt-image-2.5-flare；改图用 /v1/images/edits。

换型号只改 model 字段：gpt-image-2.5-sunburst、gpt-image-2.5-flare、gpt-image-2，或按张计费的 -c 版。-c 版不要传 n 和 mask。

图片格式字段是 format（png / jpeg / webp），返回 data[0].url；传 response_format=b64_json 可以拿 base64。完整参数见 生成接口文档 与 编辑接口文档。

GPT Image API 常见问题

GPT Image API 多少钱？

按 token 计费的型号：GPT Image 2.5 Sunburst 与 Flare 文本输入 $2.9700、图片输入 $4.7520、图片输出 $17.8200（每百万 tokens），约官方价 6 折；GPT Image 2 文本输入 $0.3971、图片输入 $0.6354、图片输出 $2.3830，约官方价 0.8 折。按张计费的 -c 版：gpt-image-2.5-sunburst-c 与 gpt-image-2.5-flare-c 1K 出图每张 ¥0.1、2K/4K 每张 ¥0.13；gpt-image-2-c 1K 每张 ¥0.08、2K/4K 每张 ¥0.1。实时价格以模型广场为准。

Sunburst、Flare 和 GPT Image 2 有什么区别？

Sunburst 和 Flare 是 OpenAI 2026 年 9 月发布的 GPT Image 2.5 系列。OpenAI 把 Sunburst 定位为编辑精度最高的型号，Flare 是速度最快的高质量日常出图型号，两者官方 token 单价相同，都新增了 xhigh 和 max 两档质量。GPT Image 2 是 2026 年 4 月发布的上一代，质量档位为 low、medium、high、auto。

按 token 计费和按张计费（-c 版）怎么选？

按 token 计费的费用随尺寸和质量变化：低质量小图很便宜，质量越高、尺寸越大越贵。-c 版每张固定价（1K、2K/4K 两档），不受质量档位影响，但一次只出 1 张，不支持 n 和 mask 参数，也不支持透明背景。以 1024×1024、high 质量为例，2.5 按 token 计费每张约 $0.0313，-c 版每张 ¥0.1。

支持哪些接口？可以改图吗？

GPT Image 全系（包括 -c 按张计费版）都支持 POST /v1/images/generations（文生图）和 POST /v1/images/edits（图生图、多图合成）。编辑时可以上传少于 16 张参考图（总计 50MB 以内）；按 token 计费的型号还支持用 mask 局部重绘。字段说明见 AnyAIGC API 文档。

并发有限制吗？国内能直接调用吗？

AnyAIGC 对 GPT Image 全系 不设并发限制，所有用户默认享有。接口地址是 https://anyaigc.ai/v1，面向国内网络优化，通常无需额外代理；按美元计费，支持微信支付和支付宝，同一个 Key 还能调用平台上 300+ 其他模型。
