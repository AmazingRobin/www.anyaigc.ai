三步接入 GPT-5.5 API

  1. 注册并充值：在 anyaigc.ai 注册账号，余额对平台所有模型通用。
  2. 创建 API Key：在控制台创建令牌，复制以 sk- 开头的 Key，存到环境变量 ANYAIGC_API_KEY。
  3. 发起请求：向 https://anyaigc.ai/v1/chat/completions 或 https://anyaigc.ai/v1/responses 发送请求，model 填 gpt-5.5，鉴权用 Authorization: Bearer。

两个接口都支持工具调用。gpt-5.5 在 /v1/chat/completions 和 /v1/responses 上都能做函数调用（function calling），已有的 Chat Completions 代码可以直接沿用。新接入、多步骤 Agent 和 Codex 建议用 Responses API，推理强度写在 reasoning.effort 里；Chat Completions 用顶层的 reasoning_effort。

完整参数见 Chat Completions 接口文档 和 Responses 接口文档，字段含义与 OpenAI 官方 API 一致。

GPT-5.5 API 常见问题

GPT-5.5 API 多少钱？

AnyAIGC 上 gpt-5.5 按 token 计费：输入 $0.2482/百万 tokens，输出 $1.4890/百万 tokens，缓存输入 $0.0248/百万 tokens。OpenAI 官方价为输入 $5.00、输出 $30.00、缓存输入 $0.50，AnyAIGC 约为官方价的 5%（约 0.5 折）。单次请求输入超过 272K tokens 时，整次请求的输入按 2 倍、输出按 1.5 倍计费。

GPT-5.5 的模型 ID 是什么？

模型 ID 是 gpt-5.5，在请求体的 model 字段里填写即可。OpenAI 还发布了带日期的快照 gpt-5.5-2026-04-23，需要固定版本时可以参考。

GPT-5.5 停用了吗？还能用多久？

没有。OpenAI 已推出更新的 GPT-5.6 和 GPT-6 系列，但 gpt-5.5 的 API 目前没有弃用公告，OpenAI 尚未公布停用时间，目前仍可正常调用。在 AnyAIGC 上继续使用 gpt-5.5 不需要改任何代码；新项目可以考虑 GPT-6.1 Sol。

调用 gpt-5.5 提示 model not found 怎么办？

先确认三件事：model 字段写的是 gpt-5.5（全小写，中间是点号）；base_url 是 https://anyaigc.ai/v1；请求头是 Authorization: Bearer 加你的 AnyAIGC API Key。如果用的是 Codex，检查 ~/.codex/config.toml 里的 model_provider 是否指向 AnyAIGC。仍然报错可以联系 7×24 客服排查。

要不要从 GPT-5.5 换到 GPT-5.6 Sol 或 GPT-6.1 Sol？

看需求。已经调好提示词、跑得稳定的老集成可以继续用 gpt-5.5，它还有固定快照。在 OpenAI 的 GPT-5.6 发布页评测中，GPT-5.6 Sol 在 Terminal-Bench 2.1 上为 88.8%，GPT-5.5 为 85.6%。在 AnyAIGC 上，GPT-5.6 Sol 和 GPT-5.5 单价相同（输入 $0.2482、输出 $1.4890）；GPT-6.1 Sol 更便宜，输入 $0.0993、输出 $0.4964（每百万 tokens）。新项目可以优先试 GPT-6.1 Sol。

用 Chat Completions 还是 Responses API？可以调用工具吗？

两个接口都能用，函数调用（function calling）在 https://anyaigc.ai/v1/chat/completions 和 https://anyaigc.ai/v1/responses 上都支持。已有的 Chat Completions 代码可以直接沿用；新接入、多步骤 Agent 和 Codex 建议用 Responses API，推理强度写在 reasoning.effort 里，可选 none、low、medium（默认）、high、xhigh。

可以在 Codex 里使用 GPT-5.5 吗？

可以。运行 curl -fsSL https://www.anyaigc.ai/install.sh | bash -s codex 一键安装（Windows 用 irm https://www.anyaigc.ai/install.ps1 | iex），脚本默认写入的模型就是 gpt-5.5，装好即可使用。也可以手动配置：在 ~/.codex/config.toml 里把 base_url 设为 https://anyaigc.ai/v1、wire_api 设为 responses、model 设为 gpt-5.5，并在 ~/.codex/auth.json 写入 OPENAI_API_KEY。

并发和速率有限制吗？

AnyAIGC 对 gpt-5.5 不设并发限制，所有用户默认享有，适合批量任务和多 Agent 并行。
