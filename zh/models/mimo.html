# pip install openai
import os
from openai import OpenAI

client = OpenAI(api_key=os.environ["ANYAIGC_API_KEY"], base_url="https://anyaigc.ai/v1")

stream = client.chat.completions.create(
    model="mimo-v2.6-flash",
    messages=[{"role": "user", "content": "用三句话介绍你自己，并说明你擅长的任务。"}],
    stream=True,
)
for chunk in stream:
    if chunk.choices and chunk.choices[0].delta.content:
        print(chunk.choices[0].delta.content, end="", flush=True)

FAQ

MiMo API 常见问题

小米 MiMo API 多少钱？官方 4 折怎么算？

MiMo-V2.6-Pro 输入 $0.1749、输出 $0.3497（官方 $0.435、$0.87）；MiMo-V2.6-Flash 输入 $0.0563、输出 $0.1126（官方 $0.14、$0.28），单位 USD/百万 tokens，约为小米 MiMo 开放平台美元按量价的 40%。实时价格以模型广场为准。

4 个 MiMo 模型怎么选？

复杂、长程的 Agent、编程与科研任务选 MiMo-V2.6-Pro；高频调用和规模化办公选 MiMo-V2.6-Flash。MiMo-V2.5-Pro 与 MiMo-V2.5 已被小米官方停用，新项目请使用 V2.6 系列。

MiMo-V2.5 系列停用了吗？

是。小米官方于 2026-10-21 10:00（UTC+8）停用 mimo-v2.5-pro 和 mimo-v2.5，替代型号分别是 mimo-v2.6-pro 和 mimo-v2.6-flash。AnyAIGC 模型广场目前仍列出这两个型号，迁移只需修改 model 字段。

支持 OpenAI SDK 吗？用哪个接口？

支持。4 个模型都走 OpenAI 兼容的 POST https://anyaigc.ai/v1/chat/completions，鉴权用 Authorization: Bearer <API Key>。OpenAI SDK 只需把 base_url 设为 https://anyaigc.ai/v1。

并发和 RPM 有限制吗？

AnyAIGC 的 MiMo 接入并发不限，不设固定 RPM 上限，所有用户默认享有。长上下文和深度思考请求耗时更长，请在应用里设置合理的超时与重试。

生成内容可以商用吗？

模型与输出的使用条款以小米 MiMo 官方条款为准。AnyAIGC 是独立 API 服务商，与小米无隶属关系。

AnyAIGC 能开发票吗？支持增值税专票吗？

支持。可按实际充值金额开具增值税普通发票和增值税专用发票，联系企业客服办理即可。

企业可以对公转账和签合同吗？

可以。支持企业对公转账充值，可签订服务合同，并提供专属客服与技术对接。

支持哪些支付方式？

支持微信支付、支付宝、USDT 和信用卡充值，企业还可以对公转账，并开具增值税普通发票或专用发票。余额按美元计价，对平台所有模型通用。

新用户有免费试用额度吗？

有。新用户注册后赠送 200 万 tokens 的试用额度，可以先测试效果再决定是否充值。最低 1 美元起充。

余额可以退款吗？

可以。未使用的余额可以申请退款，不收取手续费。具体流程请联系客服。

会不会用低配模型冒充？我的数据安全吗？

请求走官方模型渠道，不用低配或逆向模型冒充。除法律法规要求外，我们不会对你的输入输出内容做持久化存储，也不会用于训练模型；控制台可以查看每次调用的 tokens 与扣费明细。
