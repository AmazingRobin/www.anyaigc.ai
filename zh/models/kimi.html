快速开始

三步接入 Kimi API

  1. 注册并充值：在 anyaigc.ai 注册账号，最低 $1 起充，余额对平台所有模型通用。
  2. 创建 API Key：在控制台创建令牌，复制以 sk- 开头的 Key，存到环境变量 ANYAIGC_API_KEY。
  3. 发起请求：请求 POST https://anyaigc.ai/v1/chat/completions，model 填 kimi-k3，鉴权用 Authorization: Bearer。OpenAI SDK 把 base_url 改成 https://anyaigc.ai/v1 即可。

参数提示：Kimi 的思考过程在 reasoning_content 字段，流式输出时先返回思考增量，再返回最终回答。多轮对话和工具调用时，要把 API 返回的完整 assistant 消息（包括 reasoning_content 和 tool_calls）原样放回下一次请求。

完整参数见 Chat Completions 接口文档，文档示例里的模型名换成对应的 Kimi 模型 ID 即可。

Claude Code

在 Claude Code 中使用 Kimi

把 Claude Code 的模型换成 Kimi：改一个配置文件，终端里的编程 Agent 就由 Kimi 驱动。

  1. 安装 Claude Code：按官方方式安装（如 npm install -g @anthropic-ai/claude-code）。
  2. 写入配置：编辑 ~/.claude/settings.json，把下面的 env 加进去，ANTHROPIC_AUTH_TOKEN 换成你在 AnyAIGC 创建的 Key。
  3. 开始使用：在项目目录运行 claude，输入 /model 可以确认当前模型是 kimi-k3。

换模型：想用更便宜的编程模型，把配置里的 kimi-k3 全部换成 kimi-k2.7-code 即可。K3 有 1M 上下文，适合大仓库；K2.7 Code 单价约为 K3 的三分之一。

完整步骤和常见报错见 Claude Code 安装与使用教程，教程里的模型名换成 kimi-k3 即可。

FAQ

Kimi API 常见问题

Kimi API 多少钱？

AnyAIGC 上 Kimi 系列按 token 计费，每百万 tokens：kimi-k3 输入 $1.2150、输出 $6.0750、缓存命中 $0.1215；kimi-k2.7-code 输入 $0.3847、输出 $1.5980、缓存命中 $0.0770；kimi-k2.6 输入 $0.3847、输出 $1.5980、缓存命中 $0.0651。约为 Moonshot 官方美元价的 4 折，实时价格以模型广场为准。

AnyAIGC 上有哪些 Kimi 模型？模型 ID 是什么？

本页介绍三款：kimi-k3（2.8T 参数开放权重模型，1M 上下文）、kimi-k2.7-code（编程向 Agent 模型）、kimi-k2.6（通用多模态 Agent 模型）。调用时把模型 ID 写在请求体的 model 字段里，切换模型只需要改这一个字段。

Kimi K3、K2.7 Code 和 K2.6 怎么选？

需要 1M 上下文、最难的长程编程和深度推理时选 Kimi K3；日常写代码、跑 Coding Agent 选 K2.7 Code，官方称它在 Kimi Code Bench v2 上比 K2.6 提升 21.8%；需要非思考模式、快速响应或通用对话选 K2.6。K2.7 Code 和 K2.6 单价相同，都约为 K3 的三分之一。

Kimi API 兼容 OpenAI 吗？

兼容。三款模型都走 POST https://anyaigc.ai/v1/chat/completions，请求和返回格式与 OpenAI Chat Completions 一致，OpenAI 官方 SDK 把 base_url 改成 https://anyaigc.ai/v1 即可。思考过程在返回的 reasoning_content 字段里。

可以在 Claude Code 里使用 Kimi 吗？

可以。在 ~/.claude/settings.json 的 env 中设置 ANTHROPIC_BASE_URL 为 https://anyaigc.ai、ANTHROPIC_AUTH_TOKEN 为你的 API Key、ANTHROPIC_MODEL 为 kimi-k3，然后运行 claude 即可。

上下文窗口有多大？

Moonshot 官方公布：Kimi K3 支持 1,048,576 tokens 上下文；K2.7 Code 和 K2.6 支持 262,144 tokens（256K）。三款都支持图片输入和工具调用。

Kimi 模型是开源的吗？可以商用吗？

Kimi K3、K2.7 Code 和 K2.6 都由 Moonshot AI 在 Hugging Face 公开了模型权重。通过 AnyAIGC 调用 API 不需要自己部署。模型许可和商用授权以 Moonshot AI 官方条款为准。

并发和速率有限制吗？

AnyAIGC 对 Kimi 系列不设并发限制，所有用户默认享有，适合批量任务、CI 流水线和多 Agent 并行。Moonshot 官方平台按充值等级限制并发、RPM、TPM 和 TPD，通过 AnyAIGC 调用不受这些等级限制。

国内可以直接调用 Kimi API 吗？

可以。AnyAIGC 面向国内网络优化，通常无需额外代理即可调用 https://anyaigc.ai，按美元价格计费，支持微信支付、支付宝、USDT 和信用卡，企业可对公转账并开具增值税发票。
