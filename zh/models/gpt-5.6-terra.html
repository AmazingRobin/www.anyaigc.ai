三步接入 GPT-5.6 Terra API

  1. 注册并充值：在 anyaigc.ai 注册账号，余额对平台所有模型通用。

完整参数见 Chat Completions 接口文档 和 Responses 接口文档，字段含义与 OpenAI 官方 API 一致。

GPT-5.6 Terra API 常见问题

GPT-5.6 Terra API 多少钱？

AnyAIGC 上 gpt-5.6-terra 按 token 计费：输入 $0.0993/百万 tokens，输出 $0.5957/百万 tokens，缓存输入 $0.0099/百万 tokens。OpenAI 官方价为输入 $2.00、输出 $12.00、缓存输入 $0.20（2026 年 7 月 30 日起永久降价 20%，发布时为 $2.50 / $15），AnyAIGC 约为官方价的 5%（约 0.5 折）。单次请求输入超过 272K tokens 时，整次请求的输入按 2 倍、输出按 1.5 倍计费。

GPT-5.6 Terra 的模型 ID 是什么？

模型 ID 是 gpt-5.6-terra，在请求体的 model 字段里填写即可。OpenAI 没有为它发布带日期的快照版本。

什么是 Terra？和 GPT-5.6 Sol 有什么区别？

按 OpenAI 的说明，版本号标注代系，Sol、Terra、Luna 是各自独立演进的能力层级：Sol 是旗舰，Terra 是“适用于日常工作的均衡模型”，Luna 是速度最快、价格最低的一档；Terra 大致对应以往 GPT-5 系列的 mini 档。按 OpenAI 公布的数据，Terra 在 Terminal-Bench 2.1 上为 87.4%（Sol 88.8%），在 OSWorld 2.0 上为 50.2%（Sol 62.6%）。官方价 Terra 为 $2 / $12，GPT-5.6 Sol 当前推广价为 $4 / $20。在 AnyAIGC 上，Terra 输入 $0.0993、输出 $0.5957，Sol 输入 $0.2482、输出 $1.4890（每百万 tokens）。

GPT-5.6 Terra 和 GPT-5.6 Luna 怎么选？

两者上下文窗口、最大输出和支持的接口相同。按 OpenAI 公布的数据，Terra 在多数评测上高于 Luna，例如 Terminal-Bench 2.1 为 87.4% 对 84.7%，OSWorld 2.0 为 50.2% 对 45.6%，BrowseComp 为 87.5% 对 83.3%；Luna 的官方价是 Terra 的十分之一（$0.20 / $1.20）。编码、知识型工作和多步骤任务建议用 Terra；分类、抽取、摘要等大批量任务可以先试 GPT-5.6 Luna。在 AnyAIGC 上，Luna 输入 $0.0270、输出 $0.1620（每百万 tokens）。

GPT-5.6 Terra 和 GPT-5.5 比怎么样？

OpenAI 称 Terra 是“性能与 GPT‑5.5 相当且成本更低的模型”，在知识型工作上“以更低的成本超越了 GPT‑5.5 的表现”。按 OpenAI 公布的数据，Terra 在 Terminal-Bench 2.1（87.4% 对 85.6%）、SWE-Bench Pro（63.4% 对 59.4%）和 BrowseComp（87.5% 对 84.4%）上高于 GPT-5.5，在 GPQA Diamond 上略低（92.9% 对 93.6%）。官方价 Terra 为 $2 / $12，GPT-5.5 为 $5 / $30；知识截止日期 Terra 为 2026-02-16，GPT-5.5 为 2025-12-01。

GPT-5.6 Terra 还能用多久？停用了吗？

没有停用。OpenAI 尚未公布 GPT-5.6 Terra 的停用时间，目前仍可正常调用，OpenAI 的弃用说明里它还是 gpt-5-mini、o4-mini 等旧模型的推荐替代。GPT-6 系列目前只有 Astra、Sol、Luna 三档，没有 Terra。如果想用更新一代的均衡型模型，可以考虑 GPT-6.1 Sol，它在 AnyAIGC 上输入 $0.0993、输出 $0.4964（每百万 tokens），但在 Chat Completions 上不支持工具调用，迁移前请先测试。

用 Chat Completions 还是 Responses API？可以调用工具吗？

两个接口都能用，函数调用（function calling）在两个接口上都支持。普通对话、函数调用和流式输出用 https://anyaigc.ai/v1/chat/completions 即可；需要网页搜索、文件搜索等 OpenAI 内置工具时用 https://anyaigc.ai/v1/responses，推理强度写在 reasoning.effort 里。推理强度支持 none、low、medium（默认）、high、xhigh、max。
