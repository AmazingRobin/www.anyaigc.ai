常见问题

Claude Fable 5 API 多少钱？

AnyAIGC 上 claude-fable-5 按 token 计费：输入 $2.382/百万 tokens，输出 $11.912/百万 tokens，5 分钟缓存写入 $2.9779，1 小时缓存写入 $4.7647，缓存命中 $0.2382。Anthropic 官方价为输入 $10、输出 $50，AnyAIGC 约为官方价的 23.8%（约 2.4 折）。

Claude Fable 5 的模型 ID 是什么？兼容 Anthropic 官方接口吗？

模型 ID 是 claude-fable-5，填在请求体的 model 字段里。接口地址是 https://anyaigc.ai/v1/messages，请求体沿用 Anthropic Messages 格式（model、max_tokens、system、messages、tools、cache_control 等），鉴权使用 Authorization: Bearer 你的 API Key。用官方 SDK 时把 base URL 改为 https://anyaigc.ai 即可。

Claude Fable 是什么？和 Opus 有什么区别？

Claude Fable 是 Anthropic 的 Mythos 级模型系列。Anthropic 称 Claude Fable 5 是一款已为通用场景做了安全处理的 Mythos 级模型，Mythos 级模型的能力在 Opus 级之上；同一底层模型、安全限制更少的版本 Claude Mythos 5 只向经过验证的机构开放。官方称任务越长越复杂，Fable 5 相对其他模型的优势越大。

Claude Fable 5 停用了吗？还能用多久？

没有停用。Anthropic 已将 Claude Fable 5 列为旧版（Active · Legacy），官方承诺最早于 2027 年 6 月 9 日退役，目前仍可正常调用。新项目建议使用 Claude Fable 5.1（claude-fable-5-1）。

Claude Fable 5 适合做什么？

适合难度高、周期长的任务：长时间运行的 Agent 编码、多步骤研究、文档/表格/演示文稿处理和电脑操作类 Agent。官方文档列出它支持 100 万 tokens 上下文和 128K 最大输出。按 Anthropic 公布的数据，它在 SWE-Bench Pro 上得分 80.3%，OSWorld-Verified 上得分 85.0%。

可以在 Claude Code 里使用 Claude Fable 5 吗？

可以。在 ~/.claude/settings.json 的 env 中设置 ANTHROPIC_BASE_URL 为 https://anyaigc.ai、ANTHROPIC_AUTH_TOKEN 为你的 API Key、ANTHROPIC_MODEL 和 ANTHROPIC_DEFAULT_OPUS_MODEL 为 claude-fable-5，然后运行 claude。也可以用一行命令 curl -fsSL https://www.anyaigc.ai/install.sh | bash 自动安装和配置。

提示词缓存怎么计费？

在内容块上加 cache_control 即可开启缓存。首次写入缓存按缓存写入价计费（5 分钟 $2.9779、1 小时 $4.7647 每百万 tokens），之后命中缓存的部分只按 $0.2382 每百万 tokens 计费，为普通输入价的 10%。长系统提示词、大段代码库上下文和长时间运行的 Agent 任务最适合用缓存。

并发和速率有限制吗？

AnyAIGC 对 claude-fable-5 不设并发限制，所有用户默认享有，适合批量任务和多 Agent 并行。
