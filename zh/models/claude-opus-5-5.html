常见问题

Claude Opus 5.5 API 多少钱？

AnyAIGC 上 claude-opus-5-5 按 token 计费：输入 $0.4765/百万 tokens，输出 $2.382/百万 tokens，5 分钟缓存写入 $0.5956，1 小时缓存写入 $0.953，缓存命中 $0.0238。Anthropic 官方价为输入 $4、输出 $20，AnyAIGC 约为官方价的 11.9%。

Claude Opus 5.5 的模型 ID 是什么？

模型 ID 是 claude-opus-5-5，在请求体的 model 字段里填写即可。

AnyAIGC 的 Claude API 兼容 Anthropic 官方接口吗？

兼容。接口地址是 https://anyaigc.ai/v1/messages，请求体沿用 Anthropic Messages 格式（model、max_tokens、system、messages、tools、cache_control 等），鉴权使用 Authorization: Bearer 你的 API Key。用官方 SDK 时把 base URL 改为 https://anyaigc.ai 即可。

可以在 Claude Code 里使用 Claude Opus 5.5 吗？

可以。在 ~/.claude/settings.json 的 env 中设置 ANTHROPIC_BASE_URL 为 https://anyaigc.ai、ANTHROPIC_AUTH_TOKEN 为你的 API Key、ANTHROPIC_MODEL 为 claude-opus-5-5，然后运行 claude。也可以用一行命令 curl -fsSL https://www.anyaigc.ai/install.sh | bash 自动安装和配置。

提示词缓存怎么计费？

在内容块上加 cache_control 即可开启缓存。首次写入缓存按缓存写入价计费（5 分钟 $0.5956、1 小时 $0.953 每百万 tokens），之后命中缓存的部分只按 $0.0238 每百万 tokens 计费，约为普通输入价的 5%。长系统提示词、大段代码库上下文和多轮 Agent 任务最适合用缓存。

并发和速率有限制吗？

AnyAIGC 对 claude-opus-5-5 不设并发限制，所有用户默认享有，适合批量任务和多 Agent 并行。

Claude Opus 5.5 适合做什么？

Anthropic 将 Opus 5.5 定位为面向严肃编码和 AI Agent 的混合推理模型，适合大型代码库重构、多步骤 Agent 任务、长文档分析和复杂推理。按 Anthropic 公布的数据，它在 Terminal-Bench 4.0 上得分 66.4%。
